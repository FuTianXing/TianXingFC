# 理论辩论

- **日期**：2026-09-16
- **定位**：与外部理论作者（公开平台评论、私下交流）的辩论记录、口径核对与回应稿存放处。目录内文档属工作记录，不新增科学断言，不改动 `理论总纲/` 基准，未确认结论按状态标注
- **文件分工**：每场辩论一份记录（`辩论记录-<主题>：<对象>.md`）；同场辩论的核对分析写 `审读-<主题>.md`；对外发布的答复写 `回应稿-<主题>.md`
- **引用规则**：作者与对方的原话原样引用，不改字、不节略原意；涉及外部理论时以 `外部理论参考/` 下既有材料与工作区正稿为准，不另起一套口径
- **状态约定**：`已核对` 与内部基准一致；`待裁决` 内部无定案、需作者确认；`冲突` 与既有基准相悖、需修正其中一方
- **边界**：本目录不替代 `评审报告/`（论文七维评审）与 `冲突诊断/`（体系内部机制冲突）
