## 1. 理论定位

元相方程是一组描述**单一元相子**演化的基本动力学方程组，充当个体基元的第一运动法则。它与描述无穷多元相子纠缠网络宏观兴衰的**天行方程**处于不同理论层级：元相方程提供微观基元的精确动力学，天行方程是其统计热力学或流体力学极限。两者共同构成天行力学体系的两个支柱。

- 数学灵魂：欧拉公式 $e^{i\theta} = \cos\theta + i\sin\theta$
- 方程组形式极其简洁，**不含任何自由参数**，自然融合三大基本常数 $\hbar$、$c$、$G$
- 元相子定义为包含连续旋转与离散跃迁机制的完整圆柱螺旋几何实体：底面为复平面单位圆（半径对应 $\hbar$），本征斜率等于 $c$，几何刚度潜伏 $G$（时空写入倾斜系数）

## 2. 元相方程（完整形式）

**方程 (I)（连续旋转方程，波性本质）**：

$$
\boxed{i\hbar \frac{d\psi}{dt} = E_P \psi} \tag{I}
$$

刻画相位指针 $\psi(t) = e^{i\theta(t)}$ 在单位圆上的连续幺正旋转，$\dot{\theta}(t) = \omega_P$（普朗克角频率）。解为 $\psi(t) = \psi(0)e^{-i\omega_P t}$，初始相位定于正实轴时 $\psi(t) = \cos(\omega_P t) - i\sin(\omega_P t)$（余弦项 = 实轴投影 = 粒性侧可观测量；正弦项 = 虚轴旋转 = 波性侧潜在演化）。

**方程 (II)（离散跃迁方程，粒性本质）**：

$$
\boxed{\frac{dz}{dt} = 2\pi c \, \delta(\arg\psi)} \tag{II}
$$

其中 $\delta(\arg\psi) = \sum_{k\in\mathbb{Z}} \delta(\arg\psi - 2\pi k)$ 是周期狄拉克梳：每当相位完成一个满周（$\arg\psi = 2\pi k$），法线坐标 $z$ 阶跃一个普朗克长度 $l_P$。方程在除跃迁点外所有时刻为零，仅在相位闭合瞬间产生无限大速度，积分给出严格阶梯函数。

## 3. 推导要点

### 3.1 方程 (I)：能量-频率关系的非循环推导

$E_P = \hbar\omega_P$ 在标准量子力学中是公理包，元相方程将其拆解为三个来源独立的几何事实，避免循环论证：

1. **前提一（复平面旋转的几何动力学）**：相位以恒定内禀角频率 $\omega_P$ 连续旋转，公理规定的几何事实，不涉及能量和作用量。
2. **前提二（满周闭合的作用量量子）**：每完成一次满周（作用量周长 $2\pi\hbar$），粒性侧支付一份最小作用量子 $h = 2\pi\hbar$（自耦合定理导出，涉及作用量范畴，独立于能量和角频率概念）。
3. **前提三（能量作为作用量的时间密度）**：周期过程中时间平均能量 $E = \Delta S \times f$，是能量概念在周期系统中的普遍定义。

推导：满周周期 $T = 2\pi/\omega_P$，频率 $f = 1/T = \omega_P/2\pi$，每次事件支付 $h = 2\pi\hbar$，故

$$
E_P = h \cdot f = 2\pi\hbar \cdot \frac{\omega_P}{2\pi} = \hbar\omega_P
$$

$2\pi$ 因子在分子分母中恰好消去，这是同一满周闭合过程在空间侧面（弧长 $2\pi\hbar$）与时间侧面（周期 $2\pi/\omega_P$）共享同一几何源头的必然结果。逐项审查三个前提均不含结论或其等价形式，推导无循环论证。

**与标准普朗克能量的关系（2026-10-19 补）**：由 $t_P = 2\pi/\omega_P$ 反解得 $E_P = \hbar\omega_P = h/t_P$；而标准普朗克能量为 $E_{Pl} = \sqrt{\hbar c^5/G} = \hbar/t_P = m_Pc^2$。两者之比恰为 $h/\hbar$：

$$E_P = \frac{h}{t_P} = 2\pi E_{Pl}$$

读法是"同一条 $t_P$，两种作用量子"：元相子每满周结算一份 $h$（周期族），普朗克能量按每弧度一份 $\hbar$ 计（弧度族）。$2\pi$ 不属于动力学，它是"一圈含多少弧度"的换算。故元相子基模能量等于 $2\pi$ 个标准普朗克能量，$E_P$ 不得对外称普朗克能量；标准值在本体系中由 $E_P^{(t)} = \hbar/t_P$ 承担（两套约定与配对规则见[[术语表]]）。

### 3.2 方程 (II)：离散跃迁方程与脉冲落点

**推导**：要求每当 $\arg\psi$ 穿越 $2\pi k$ 时 $z$ 阶跃 $l_P$。设 $dz/dt = A\,\delta(\arg\psi)$，积分得 $\Delta z = A/\omega_P \times$（满周次数）；令每次满周 $\Delta z = l_P$ 得 $A = \omega_P l_P$。由普朗克关系 $\omega_P l_P = 2\pi c$，得到方程 (II)。

**脉冲落点的必然性**（3.2.1）：脉冲落在 $2\pi k$ 处是方程 (I) 连续解的特性与幅角函数筛选特性的共同结果。解 $\psi(t) = e^{-i\omega_P t}$ 的真实连续相位 $\theta(t) = -\omega_P t$ 是线性无界单调函数；取主值区间后 $\arg\psi$ 在 $\theta \equiv 0 \pmod{2\pi}$ 处回归筛选点。初始条件 $\psi(0) = 1$（正实轴），$t = t_P$ 时 $\theta(t_P) = -2\pi$，$\arg\psi$ 精确位于 0，狄拉克梳被激活。

**深层物理事实**：跃迁事件（粒性）的触发时间由波性侧自身的连续幺正演化达到特定相位决定，与外部计时器无关。

**量纲自洽性验证**：一个周期内积分 $\Delta z = \int_0^{t_P} 2\pi c\,\delta(\arg\psi)\,dt$，变量代换 $u = \arg\psi$（$du/dt = \omega_P$）得 $\Delta z = 2\pi c/\omega_P = ct_P = l_P$。$\omega_P$ 与 $l_P$ 在单体层面首次通过 $2\pi c$ 统一。

### 3.3 解的宏观极限：光速不变原理的导出

阶梯函数解：$z(t) = l_P\lfloor ct/l_P\rfloor = c\,t_P\lfloor t/t_P\rfloor$；宏观物理时间必为普朗克时间整数倍。当 $t \gg t_P$ 时 $z(t) \approx ct$，即 $R = ct$（时空同一化方程，光速是时间与空间之间的转译常数，犹如汇率）。

**光速不变原理从最底层动力学导出**：基态光子（元相子基元）在时空生成中的自然节律即是光速，$c$ 无需作为外加公设。

## 4. 数学结构与解

- 三维螺旋轨迹参数曲线：

$$
\begin{pmatrix} x \\ y \\ z \end{pmatrix} =
\begin{pmatrix} \cos(\omega_P t) \\ \sin(\omega_P t) \\ l_P \lfloor \frac{\omega_P t}{2\pi} \rfloor \end{pmatrix}

标准连续螺旋线，半径 1（对应 $\hbar$ 标度），导程 $l_P$，升角 $\arctan(l_P/2\pi)$，法线方向速度 $c$。

- **状态空间几何速率**：归一化相位坐标 $\phi = \theta/2\pi$，平直度规 $ds^2 = d\phi^2 + dz^2$，自然单位制下 $\phi(t) = t$、$z(t) = t$，速度矢量 $\mathbf{v} = (1,1)$，切向合速率 $|\mathbf{v}|_{geo} = \sqrt{2}c$。该速率是数学空间中相位参数的纯粹几何演化，无物理信号传递，不受光速上限制约（类比量子纠缠在希尔伯特空间的瞬时非定域性）；元相子法线方向（真实物理空间）速度严格为 $c$。**必须严格区分数学空间与物理空间的几何边界**。
- 耦合特征：离散事件时间点由连续变量的周期边界条件决定，连续演化整体效果通过离散阶梯累积宏观显现。

## 5. 三大常数的角色

### 5.1 $\hbar$：单位圆转子的内禀作用量标度

$\hbar$ 量纲为作用量（亦等于角动量）。复平面单位圆是作用-角变量 $(\theta, J)$ 下的转子：转子量子化要求一整圈相空间作用量面积为 $2\pi J = nh$，基态作用变量 $J = \hbar$。基态能量即标准转子公式 $E = J\omega$ 在 $J = \hbar$ 处取值：$E_P = \hbar\omega_P$（整圈相空间面积量子 $h = 2\pi\hbar$ 与旋转周期 $T = 2\pi/\omega_P$ 之比）。几何图像中 $\hbar$ 占据单位圆"半径"位置，物理量纲中对应作用量，是同一本体在两个层面的投影。

### 5.2 $c$：螺旋面的本征斜率

$c$ 在方程 (II) 系数 $2\pi c$ 中控制离散跃迁的幅度-节拍比，宏观极限 $Z = cT$ 中表现为时空生成速率。元相子的物侧延展体为 $D^2\times\mathbb{R}$（3 维，见《螺旋阶梯几何》），不承载状态自由度；物侧状态空间是其边界的波性轨迹空间 $S^1\times\mathbb{R}$（2 维），相位指针只在边界上运动。$c$ 是相位方向（$S^1$）与法线方向（$\mathbb{R}$）之间的尺度转换常数，即螺旋面的升角。

- $c$ 作为状态空间内禀标度，在单体层面不随内部状态改变，解释了理论内部为何普适。
- **边界声明**：完整洛伦兹不变性（多惯性观测者、洛伦兹变换、涌现闵可夫斯基度规）尚待多体元相子的时空动力学导出，不能仅凭单体螺旋均匀斜率断言。$c$ 的数值仍是外部输入（定理二公设承载），螺旋几何解释其内部不变性但不独立预言数值。

### 5.3 $G$：生成标度与写入换算系数

$G$ 未直接出现在单体元相方程中，通过定义普朗克标度进入理论：$l_P = \sqrt{\hbar G/c^3}$。单体层面 $G$ 的角色隐含于 $\delta\theta = m/m_P = m\sqrt{G/\hbar c} \propto \sqrt{G}$：**G 越大，有质量粒子每次碰撞写入的标架倾斜越大**（碰撞写入机制，2026-09-06 方案定稿、2026-09-09 作者确认）。

因此 $G$ 是质量到写入幅度的**写入换算系数**；该方向性与公理体系文档"生成刚度"（生成标度义）各自成立、面向不同对象，命名统一口径见 2026-09-11 语义裁决（"像素被压弯""柔度"一类字面读法退役，格距不因引力场伸缩，晶格刚性）。

$m_P = \sqrt{\hbar c/G}$ 相应定位为引力响应的满量程标度兼晶格承载上限（2026-09-05 固化；承载上限为 2026-09-17 作者口径，即令最近邻格点达满偏的质量）：$m = m_P$ 即满偏（$\theta = 1$，取向自由度压弯 $180^\circ$，法线轴本身保持笔直，2026-09-15 角度映射裁定），实际缺陷质量 $m \ll m_P$ 故每次写入倾斜极小；元相子基态 $m = 0$，其普朗克能量不作为引力源，引力源仅为缺陷能差（详见注记-普朗克质量的角色）。

多体扩展：写入倾斜经最近邻耦合逐层偏置邻居碰撞几何（网络整体相干性），稳态为格点上的离散调和分布，长波极限导出泊松方程：

$$
\nabla^2 \Phi = 4\pi G \rho
$$

推导链条：微观偏转 $\delta\theta \propto \sqrt{G}$ → 宏观曲率源 $\langle S\rangle = (4\pi G/\hbar)\rho$ → 泊松方程。**引力量子性在单体层面已经存在，多体层面只是放大，不新增量子性**。

### 5.4 波粒二象的动力学消解

波与粒是同一圆柱螺旋几何体在两个正交维度上的投影：欧拉公式连续旋转投影到复平面给出波性侧全部信息，狄拉克梳离散阶跃投影到法线轴给出粒性侧位置序列，二者通过周期条件彻底锁定。测量"坍缩"是从波性连续相空间向粒性离散编号序列的信息取舍，是有限认知系统提取时空定位信息的最经济策略。

### 5.5 最小作用量原理的几何对应

元相子螺旋面是直纹极小曲面（平均曲率处处为零），以最小连续面积实现波粒完整耦合。方程 (I) 是波性侧最短作用量路径的几何表达；方程 (II) 将连续几何在满周闭合时离散化为法线跃迁，保持空间增长与螺旋面几何精确对位。最小作用量原理获得几何对应：螺旋面极小曲面性质在波性连续演化与粒性离散投影之间的统一体现。

## 7. 与天行方程、天行力的层级定位

- **层级**：元相方程 = 单一元相子（终极母体）的内在运动法则（微观精确动力学）；天行方程 = 无穷多元相子纠缠网络的宏观统计描述（方向对齐/结构秩序/增长动能/异化耗散四序参量，对应四种基本力的宏观角色）。元相方程是微观基元动力学，天行方程是其统计热力学或流体力学极限。
