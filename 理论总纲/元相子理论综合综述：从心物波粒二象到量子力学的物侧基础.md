## 6 电磁与引力

### 6.1 电磁的双重几何

麦克斯韦方程组的无源组与有源组在元相子几何中获得各自独立的来源。无源组等于 Bianchi 恒等式：法拉第定律是曲率一致性条件（混合偏导可交换），$\nabla\cdot\mathbf{B} = 0$ 与 $\nabla\times\mathbf{E} + \partial_t\mathbf{B} = 0$ 对应实轴方向场曲率张量的恒等组合，其成立不依赖任何动力学假设。有源组等于校准动力学：高斯定律是校准源的散度，安培定律与位移电流是校准重排磁场源。$E\perp B\perp k$ 的正交关系是相位扰动空间结构与时间结构的正交投影，从螺旋几何的法线与切线正交直接读出。

电磁现象的解释存在三个层次：狭义相对论把电磁统一为张量（法拉第 = 比安基恒等式，停在洛伦兹公设）、规范场论把电磁归为联络曲率（停在规范不变公设）、元相子理论提供实体推论（独立实轴方向 → 规范变换 → 实轴方向场曲率 → 比安基恒等式），三者数学同构、本体论分层。磁单极问题经实轴方向场的分区化升级处理（非平凡丛、双表述）。光子的零电荷属于零电荷家族（$Z^0$ 对角模式、胶子不登记、中微子对称往复），其共同机制是不携带非零净 $U(1)$ 缠绕登记。

### 6.2 引力的碰撞写入网络

引力常数 $G$ 承担三重角色。单体层面，它是碰撞写入放大系数：有质量粒子在每次全局普朗克碰撞事件写入标架倾斜 $\delta\theta = m/m_P$（$m_P\propto 1/\sqrt{G}$，故 $\delta\theta \propto \sqrt{G}$，引力越强倾斜越大）；多体层面，写入倾斜经最近邻耦合逐层偏置邻居碰撞几何，稳态为格点上的离散调和分布，$G$ 转为宏观引力耦合常数，写入幅度与宏观耦合常数的同一性（$G$ 仅经 $m_P = \sqrt{\hbar c/G}$ 进入一次）保证推导自洽；标度层面，$G$ 与 $\hbar$、$c$ 联合定义普朗克标度（$l_P = \sqrt{\hbar G/c^3}$），参与时空标架的生成。由此得出"引力本来就是量子的"的结论：$G$ 从生成环节起就是量子时空的内在属性，无需量子化。

静态弱场导出链：每拍写入 $\delta\theta = m/m_P$ → 稳态格林函数 $\theta(r) = Gm/(c^2r)$（$4\pi$ 由立体角自动涌现）→ 泊松方程 $\nabla^2\Phi = 4\pi G\rho$。标架网络四步推到爱因斯坦场方程 $G_{\mu\nu} = 8\pi G T_{\mu\nu}/c^4$，两侧同源（能量动量张量 = 缺陷写入的源项，几何侧与物质侧都是同一晶格的描述）。曲率是拓扑性："疤定源，场定形"（光滑标架零曲率，曲率只存在于缺陷处，2026-09-06 确认）。天行力的几何效应即恢复平直，其语义（2026-09-11 裁决）分两层。场侧，平直是源自由动力学的吸引子，缺陷在场写入持久、缺陷消失场以光速回归平直（“写入记录住”即“源在场在”），判据 C 阻尼项为其机制化身（量级与微观来源待导出）；响应侧，自由运动沿测地线、偏离需力（惯性）。此天行力几何效应即等效原理的涌现形态，回归只发生于光滑倾斜部分，与“疤定源，场定形”相容。

刷新与累积对立的消解（2026-09-06）：写入记录住波性侧标架场，摆程折返刷新不影响记录；像素偏转五层冲突全部消解（碰撞写入方案，2026-09-09 作者确认）。遗留待攻：引力波波动方程、张量推广、无质量粒子（光子）的引力量子机制、强场非线性。$G$ 的"生成刚度/柔度"命名差异已由 2026-09-11 语义统一裁决（生成标度义加写入换算义，双义各安其位；"被压弯"字面读法退役，晶格刚性）。

## 7 量子力学物侧基础（三部曲与总结论）

**元相方程（单体定态）**。方程 (I) $i\hbar\,d\psi/dt = E_P\psi$ 是定态薛定谔方程的单体形式，$E_P = \hbar\omega_P$ 非循环导出。

**薛定谔方程的公设降级**。一般薛定谔方程（含动能与势）从束缚振荡晶格推导：有质量模式色散 $\omega^2 = \omega_0^2 + c^2k^2$（低能）谱对偶为晶格 Klein-Gordon 方程，旋转波分解（抽出 $e^{-i\omega_0 t}$ 本底）后慢包络满足

$$i\hbar\,\partial_t\Psi = -\frac{\hbar^2}{2m}\nabla^2\Psi, \qquad m = \frac{\hbar\omega_0}{c^2}$$

**有效质量恒等式**（定理）：包络动能系数 $\hbar c^2/2\omega_0$ 与体系质量定义逐字恒等（$\hbar^2/2m$），质量 = 色散曲率。势 $V = \hbar\delta\omega$ 来自局域能隙调制。

**序参量份额定理**。概率幅系数定义为份额的振幅开方 $c_a = \sqrt{N_a/N}\,e^{i\tilde\Phi_a}$，$|c_a|^2 = N_a/N$ 与归一化 $\sum|c_a|^2 = 1$ 由定义与份额恒等式直接给出（无需同步条件）；幺正性由结构路径（因子相位旋转张量积保内积）与守恒路径（人数守恒 + Wigner）双推导；混合态 = 份额已知但块内不相干，退相干 = 相干因子衰减（概率不变、干涉消失）；连续谱由格距正则化承担。P7 精确形态：波函数的模方分解 = 序参量的份额分布（波函数是序参量的开方像）。

**总结论**。五公设（方程、质量、Born、归一化、幺正）全部降为束缚振荡晶格与系综结构的推论，两个恒等式级闭环保住了解释的硬核；低能预言与标准量子力学无差别（必要条件），竞争力在修正项结构签名（Klein-Gordon 残差 $(E/mc^2)^2$、晶格离散 $(E/E_P)^2$、采样极端偏差）。
