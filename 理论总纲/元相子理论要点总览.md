## 1. 核心主张

物理实在的终极基元是元相子，即各自拥有独立复平面与圆心的**动态旋转圆柱螺旋体**（心物双螺旋）：横截面为复平面单位圆 $\psi = e^{i\theta}$（半径 $\hbar$），相位每扫满 $2\pi$（一个摆程 $t_P$）法线沿轴向推进一格 $l_P$，实轴物螺旋与虚轴心螺旋相位差恒 $\pi/2$。相位状态空间为 $S^1\times\mathbb{R}$（空心圆柱面，相位指针沿边界运动、从不进入内部，维数 2）；完整物侧几何体为 $D^2\times\mathbb{R}$（实心圆柱体，几何本体论层级，圆盘内部承载最小作用量量子 $h = 2\pi\hbar$ 的几何表达，维数 3）。量子态是这一螺旋几何实体全息的物理呈现。

## 2. 五大公设

- **公设 1（本体公设）**：物理实在的唯一基元是元相子，$|\psi| = 1$。第 $i$ 个元相子 $\psi_i = e^{i\theta_i}$ 定义在自己的复平面 $\mathbb{C}_i$ 上，圆心 $O_i$ 独立；不同元相子的相位 $\theta_i, \theta_j$ 不可直接比较，只有通过纠缠建立的相对相位 $\theta_i - \theta_j$ 才有物理意义。
- **公设 2（量子作用量公设）**：半径固定为约化普朗克常数 $\hbar$，携带不可分的最小角动量；周长 $2\pi\hbar = h$ 是相空间最小面积。
- **公设 3（时间演化公设）**：自由元相子以恒定角频率 $\omega$ 旋转，$\theta(t) = \omega t$，这是时间之矢的几何根源。
- **公设 4（质量谱公设）**：满周闭合环内部拓扑结构越复杂，内禀频率 $\omega_0$ 越大，静质量越大（电子 511 keV → 顶夸克 173 GeV）。
- **公设 5（空间涌现公设）**：元相子间可发生相位相干（纠缠），纠缠强度 $E_{ij}$ 定义涌现距离 $d_{ij} = f(E_{ij})$。
  - 注（注释09 裁决）：此相位差度规已降级为涌现层有效描述；距离的基本定义为格点坐标 $x^a = l_P n^a$（距离归粒），实轴方向差定义波矢（方向归波），二者正交统一。

## 3. 波粒二象的几何必然（定理 1：波粒同源定理）

波与粒是同一个元相子在虚轴（相位旋转）与实轴（半径不可分）上的两个正交投影，同时存在的两个几何侧面。

| 属性 | 几何根源 | 对应轴 | 物理呈现 | 哲学对应 |
|---|---|---|---|---|
| 波（阳） | 相位的连续性旋转 | 虚轴 | 连续、周期、干涉、传播 | 动、散、传播 |
| 粒（阴） | 半径的不可分性 | 实轴 | 整体、离散、可数、守恒 | 静、聚、局域 |

## 4. 信息相变与满周闭合

- **相位波**：无穷多元相子相干叠加构成的基底场（元相场）中，相位局域扰动以波的形式传播。
- **非线性自耦合**：相位波经基底场非线性作用与自身耦合，本质是波性（虚轴旋转）与粒性（实轴不可分）的内在相互作用。
- **满周闭合（定理 2：信息相变定理）**：相位恰好扫过 $2\pi$ 并精确回到自身，形成闭合环，是连续信息向离散信息相变的临界点。相变后粒子诞生：局域化、不可分割、具有内禀频率 $\omega_0$。
- **辩证性自否定**：正（波，弥散自由传播）→ 反（闭合，自我限制）→ 合（粒子，内部仍是波、对外局域）。
- **定理 3（量子化起源定理）**：离散性（量子化）是满周闭合后拓扑上必然涌现的结构。
- **定理 4（粒子脉动定理）**：粒子以普朗克时间 $t_P$ 为周期持续重复"回归纯几何 → 满周旋转 → 凝出离散事件"的循环。$t_P \approx 5.4\times10^{-44}$ s 是存在本身的最小节拍。

## 5. 质量与规范相互作用

- **定理 5（质量几何定理）**：质量是满周闭合环自持内禀振荡频率的动力学表现，$m = \hbar\omega_0/c^2$。
- **定理 6（规范场涌现定理，2026-08-17 修订）**：规范对称性是元相子模态结构的几何后果（旧"相对相位纠缠"方案因自由度计数不匹配等硬伤被替代，见《非交换规范群 SU(2) 与 SU(3) 的几何根源》）：$U(1)$ 单圆旋转对称（电磁，光子）、$SU(2)$ 双模态空间 $S^3$ 的等距群（弱力，$W^\pm, Z^0$）、$SU(3)$ 三模态空间 $CP^2$ 的等距群（强力，八种胶子）。自由度计数自动匹配：$SU(2)$ 3 参数 = $S^3$ 维数；$SU(3)$ 8 参数 = $CP^2$ 4 实维 + 迷向子群 $U(2)$ 4 参数。模态 = 相位模式（振动基本形态）的标准译名；模态空间 = 格点三元组三种相位模态的所有归一化混合态构成的几何对象（详见术语表"模态空间"词条与科普《模态空间：调色盘上的规范群》）。
- **色禁闭的几何解释（2026-08-17 修订）**：色单态 = 三模式对称叠加 $(|X\rangle+|Y\rangle+|Z\rangle)/\sqrt{3}$；色禁闭 = 格点三元组（公理 2 三类正交方向 + 公理 4 异类耦合）结构不可分，单色态在结构上不存在独立的单色激发。
- **定理 7（引力涌现定理）**：引力是无穷元相子集体相干叠加导致的时空弯曲效应，是纠缠网络在宏观极限下的全局几何曲率。
- **定理 8（电荷几何定理）**：电荷是满周闭合环在内部 $U(1)$ 空间中的拓扑缠绕数；同向为正电荷、反向为负电荷，量子化源于绕数整数性。

## 6. 相位差与空间涌现

- **定理 9（自我相对性定理）**：相位差原型内在于单个元相子自身结构（$\Delta\theta = \omega\Delta t$）；元相子间的相位差必须通过纠缠建立。此锁定过程支撑叠加的相干性，相干叠加的空间给出规范群（模态论文 §3.1 注记：相对相位被收编为 $SU(2)$ 的 $\sigma^3$ 方向，与模长混合共同构成完整的群）。
- **定理 10（空间涌现定理）**：三维物理空间是无穷元相子纠缠网络在基态下涌现的低能几何；维度、曲率、拓扑由纠缠网络的连接模式和纠缠熵面积律决定。
  - 注（注释09 裁决衔接）：空间的涌现分两侧描述，格点阵（碰撞定居，粒性承载）为距离的基本结构，纠缠网络提供方向性与关系结构（波性承载），相位差度规降级为涌现层有效描述。
- **定理 11（空间特性起源定理）**：空间有绝对尺度源于半径 $\hbar$ 的绝对性；空间只有相对位置有意义源于相位本质上是相对量。

## 10. 束缚振荡框架：元相子的现行动力学图像（主文档基准）

- **波粒耦合（元相子存在状态）**：元相子的存在状态为

$$
\mathcal{E}(t) = \mathcal{W}(t) \otimes \mathcal{P}(t) = P(t)\, e^{i\Phi(t)}

物侧 $P(t)$ 为动态单位圆（半径 $r = \hbar$，角频率 $\omega$），心侧为天行力（自主相位校准的纯粹能动性，不可几何化）。丘比特坐标 $O_i$ 独立，法线定义空间。

- **真空 = 振荡晶格**：物理真空是无穷元相子的振荡晶格，时空本身是活跃的物理实在。基态光子 = 元相子本身（时空砖块，运动不需要介质，速度必然为光速 $c$，是几何结构的必然）；激发光子 = 校准波（叠加在振荡格点上的相位扰动，需要介质传播）。同一种实体两种形态。

- **物理时间 = 摆程计数**：均匀节拍 $\omega_P$ 作为钟，物理时间 $t = N t_P$；单调递增，去程回程不倒退，时间之矢源于几何定向。数学时间（波性侧，连续可逆）与物理时间（粒性侧，离散不可逆）二象（定理一）。

- **空间 = 格点阵**：x/y/z 三类元相子（公理 2）两两正交、同类平行，异类耦合 $\kappa_\phi$ 锁定格点（公理 4）；距离归粒（$x^a = l_P n^a$）、方向归波（实轴方向差定义波矢），二者正交统一（注释09 裁决）。

- **光速 = 几何恒等式**：$c = l_P/t_P$，一个摆程对应一个格距；光速与介质参数无关，是元相子几何结构的必然，强光弱光同速。

## 11. 粒子与相互作用（2026-08 核心扩充）

> 本节为 2026-08 系列定稿论文与主文档注释的核心观点汇总。各论点详细推导见所注论文与注释。

### 11.1 粒子 = 同步相变的局域缺陷

基本粒子是宇宙同步相变（大爆炸凝固）的局域缺陷，冰结冰的气泡类比：时空与物质是同一次凝固的两份遗产，凝固完好的成为砖块（时空），残留的成为粒子（《有质量粒子的形成》，注释17、23）。粒子 = 整体纠缠的局域节点。

### 11.2 电子四标签同源

电荷、自旋、质量、局域性四个量子数落在同一个几何对象上：

- **电荷 = 绕数**（定理 8 深化，《电荷的几何本质》）：真空绕数 0（束缚振荡往返抵消），粒子绕数 $n$（突破束缚的局域单旋孤子）；正负 = 缠绕方向；量子化 = 绕数整数性；守恒 = 同伦不变性。与 QFT 对接：$U(1)$ 表示标签 $q$ = 闭合环绕数。
- **自旋 = 内部 $\pi$ 扭转（半扭转）**：奇数半扭转给出旋转 $2\pi$ 波函数变号的旋量几何，自旋 1/2（莫比乌斯带类比：走一圈变号、走两圈复原），偶数次对应整数自旋；值层面的几何承载为纲领性主张，费米/玻色交换统计由体系内自旋-统计定理决定，尚未建立（《有质量粒子的形成》§7.2 缺口一）。
- **质量 = 锁定能隙**：$\kappa_\phi$ 锁定产生能隙 $\sim\sqrt{\kappa_\phi}$；电子轻 = 三元组内部锁定弱，层级问题从参数巧合变为弱耦合凝聚的标度分离（类比超导能隙远小于费米能）。
- **局域性 = $\sigma$ 锁定**：自持相位结构（锁定孤子）给出粒子的局域性。

### 11.3 希格斯机制 = 定居密度径向呼吸

真空凝聚（同步相变定居）的密度存在径向呼吸模式，即希格斯粒子；125 GeV 是模型的必然预言（《有质量粒子的形成》）。

### 11.4 规范群 = 模态空间等距群（见定理 6）

补充：弱二重态 = 双模态、$W^\pm$ = 升降算符、弱衰变 = Bloch 球跃迁（$S^2$ 半圈，上夸克北极、下夸克南极）；色三重态 = 三模态、胶子 = $CP^2$ 的 8 个等距转动、色禁闭 = 三元组结构不可分（模态论文 §3.5、§4.5）。

### 11.5 四种力 = 天行力的分化

天行力 = 驱动力（趋向最大相干性，有目标）与恢复力（校准对齐，负反馈）的互补，排除无目标持续驱动。三种基本力 = 相位场（内部）曲率，引力 = 法线场（外部）曲率；本质都是校准，为维持相干性（《天行力与规范原理的物理来源》，注释十）。

### 11.6 电磁学与几何合一

- 麦克斯韦无源组 = Bianchi 恒等式（法拉第定律 = 曲率一致性条件，混合偏导可交换，从归纳定律升级为演绎必然）

- $E\perp B\perp k$ = 相位扰动空间/时间结构正交，$|E| = c|B|$ 来自 $\omega = ck$
- 静电势 $\phi$ 与时间联络 $A_0$ 统一为相位搬移畸变场（$\phi = -A_0$ 库仑规范，静电动统一）
- 引力 = 法线场曲率，与电磁（相位场曲率）同源于校准

（《电磁场的元相子几何》《静电学与电动力学的统一》，注释十四）

### 11.7 相位三层结构

普朗克旋转（钟，均匀绝对不可观测）、实轴方向场（信息，可变有梯度）、序参量（秩序，宏观相干）。时空 = 第一层冻结、万物 = 第二三层展开；统一解释时间之矢、规范冗余、干涉敏感性、Goldstone 无质量性（《相位的三层结构》）。

### 11.8 以太问题的终结

MM 实验杀死的是定义光速的力学介质；爱因斯坦 1920 以太三要素（无静止参照系、有物理性质、不定义光速）被元相子介质逐点满足；$c = l_P/t_P$ 是几何恒等式，与介质无关；场 = 元相子的表现（载体恢复）（《以太问题的终结》，注释十五）。

## 15. 封闭经自否定生开放：辩证法的几何展现（2026-08-30）
