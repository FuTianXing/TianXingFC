5. **连续与离散互根**：文小刚离散本体论与体系第三条路的辨析（连续是波的姿态，离散是粒的姿态）。（定案）

46. **叠加态的场侧实现（单一场承载）**：两瓣叠加态由单一背景场承载的载体是相干结构（叠加像），全局相干代价与实通道预算精确折叠为单缺陷一份（成员数变份额深度），权重由线性泛函精确承载，分离两瓣的相对相位住在质心零模相干；经典纯位形支付挫折弦并塌缩，不能稳定承载。（判据级，模型内，17 项判据全过；2026-09-14 M7b 专项轮，作者裁决三项均采 (i)）

## 七、热力学与温度

47. **温度定义（主式定案，2026-09-08）**：$k_BT = E_P^{(t)} D$，$D$ = 复相干无序度 $1 - |\langle z\rangle|/\sqrt{\langle|z|^2\rangle}$；柯西-施瓦茨定理给 $D \in [0,1]$，普朗克温度 $T_P = E_P^{(t)}/k_B \approx 1.4\times10^{32}$ K 为定义上限（恒等式，经典发散截断）；冻结族 $D = 1-\eta$ 全阶精确（相位无序度定义收编为特例）；四角精确（纯态 0、冻结族 $1-\eta$、定居率族 $1-\sqrt q$、完全混乱 1）；Hagedorn 型饱和 $E = E_P D(2-D)/(2(1-D)^2)$。（定案 + 数值确认）
48. **温度语义与统计层闭合**：温度独立于熵定义（载体 = 相位分布熵）、定义域覆盖相变前（高温先于大爆炸，$T_P$ 是元相海属性，凝固与校准是降温过程）；波粒互补双侧性（粒侧 = 粒核实存强度局域涨落，不采用天行方程形式）；对数熵 $S = k_B\ln(2\pi D)$ 唯一性、因子 2 裁决（遗漏幅度自由度）、能量均分无特设系数。（定案 + 条件性 + 数值自检）
49. **温度宇宙学读出**：原初混沌两路同指 $T_P$；今天 $D_0 = T_0/T_P \approx 1.9\times10^{-32}$（三十二个数量级降温史）；阈值 $D_c \sim m/m_P$ 与标准宇宙学粒子冻结次序一致；可检验预言 = CMB 涨落双分量无序度比 $2:1$、涨落能量均分。（条件性 + 数值）

50. **圆心碰撞是完美弹性的（定理形式）**：三条公理层输入（相位推进速率恒定、法线坐标与相位刚性锁定、圆心不可重合）给出等速硬点链定理：碰撞只交换摆程方向标签，位置多重集按自由运动演化，不变量为逐支能量、总动量与摆程方向和，两体碰撞无耗散通道（$\gamma_{\text{碰撞}} = 0$）；与宏观小球的分界在于元相子无内部自由度。判据 K1 至 K3（结构，[[内部草稿/注记-碰撞的完美弹性：无内部自由度与符号翻转实现的结构性论证]]）与 J1 至 J6（等速硬点链，2026-09-20）。（严格定理｜公理级：速度幅度恒定与恢复系数恒为 1 由公理 5、刚性锁定与圆心不可重合直接导出，判据 V1 至 V5；模型内核对 J1 至 J6）

51. **引力线线性动态半边（协变形式、链接级合成与矢量扇区口径）**：动态写入的协变形式 $\eta^{\mu\nu}\partial_\mu\partial_\nu\theta + (\gamma/c)u^\mu\partial_\mu\theta = (4\pi G/c^2)\rho$ 已写入并验证（判据 D1 至 D7：静态通量二阶、$c_s = c$、$\gamma/2$ 与 $\gamma/(2c)$、帧依赖 $10^{-19}$ 至 $10^{-22}$），阻尼项为式中唯一破坏洛伦兹协变的片段；$h_{00} = 2\theta$ 由链接读数路径合成给出（判据 J1 至 J4），与空间侧 $\lambda = 1$ 并列构成 3+1 链接级读数；矢量扇区的源口径定为动量密度（速度读数），强度由单一入口钉为 $1$（判据 N1 至 N3）。动量读数项的第一原理随后把该通道立为逐拍写入的协变完备化（判据 Z1 至 Z4）：零拖曳读数改标为旧版写规则产物，与 GPB 的 $5.17\sigma$ 张力在方向上解除。链接级合成随后给出（判据 K1 至 K5，同一核作用于动量密度）：静止源严格零、$h_{0i}/(h_{00}v_i) = 2$ 与速率无关、取向无关、偶极 $J/(2\rho^2)$ 与绕源回路签名与连续求积一致到机器精度。阻尼观测上界与候选率阶梯排除抄写平均率（$59.25$ 个数量级）。（条件性命题级加数值验证；非线性封装仍由 C1 门控）
