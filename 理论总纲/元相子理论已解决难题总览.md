## 一、公理与本体

1. **唯一公理**：心物波粒二象 = 阴阳 = 太极，派生万物的形而上最高本原，内禀五重法则（波粒互斥、互补、波主粒从、波粒互根、波粒互化）。（《公理体系》定案）
2. **元相子的完整几何**：螺旋阶梯几何三定理（旋转轴唯一性、平移旋转轴重合、法线标记点分工）。（严格定理）
3. **相位状态空间修正**：D²×ℝ 实心圆柱体，豪斯多夫维数 3，与王虹挂谷集精确对应。（严格几何对应）
4. **采样定理统一连续与离散**：粒性侧阶梯函数是波性侧螺旋体的采样，离散从连续内部自发涌现（满周闭合内生嘀嗒）。（定案）
5. **连续与离散互根**：文小刚离散本体论与体系第三条路的辨析（连续是波的姿态，离散是粒的姿态）。（定案）
6. **数学结构同址于物理几何**：黎曼面、基本群、极小曲面、单值化结构同址于元相子物理几何；范畴论为描述语言不进入本体层。（定案）

## 二、时空与时间

7. **定理一（时空二象性）**：数学时空（波性侧，连续可逆）与物理时空（粒性侧，离散不可逆）二象结构 + 最小作用量子存在性。（严格定理）
8. **定理二（物理标度）**：ħ（作用量标度）、c（时空转译常数）、G（时空生成刚度）独立公设；普朗克标度 l_P = √(ħG/c³)、t_P = l_P/c 导出。（严格定理）
9. **物理时间的起源**：物理时间 = 摆程计数，单调递增，时间之矢源于几何定向；所有钟挂在同一面碰撞之墙上（时间的社会性）。（定案）
10. **光速涌现**：c = l_P/t_P，光的传播 = 逐格点碰撞接力（一步一摆程一格）。（条件性 + 定案）
11. **洛伦兹涌现**：束缚态时钟时间膨胀与长度收缩推导（ω = ω_b/γ、ξ/γ），v = 0.3 时数值偏差 0.07%。（条件性 + 数值验证）
12. **时间膨胀与普朗克时间兼容**：普朗克时间是步长（t_P 固定），相对论效应是步数（世界线摆程计数差）；固有时离散化推论（τ = n·t_P）。（定案）
13. **时间困境消解（连续偏转不构成第二时间流）**：实轴取向 α 的演化参数来自钟层（参数共享），可测性经摆程采样（采样测量），信息层以钟层为时基。（定案）
14. **引力时间膨胀完整链条**：质量 → 每摆程偏转 → 曲率 → 势阱 → 世界线计数减少 → 钟慢；源的机制（引力微观起源）与响应的机制（观测者响应）闭合。（定案）
15. **时空是当下结构**：逐摆程折返刷新（旧像素被新状态重新确定），与广义相对论"瞬时源决定"相容，"像素不可更新"路径废除。（定案）

## 三、光、电磁与规范

16. **光的传播机制**：光子 = 实轴方向场（相位 = 实轴方向 α 对应层）Goldstone 涨落；采样 = 碰撞 = 测量 = 快照抄写（延迟拷贝行波，无色散，α(xₙ,t) = α(x₀, t−nt_P)）。（定案）
17. **规范对称性的起源**：规范群 = 模态空间等距群（U(1) = S¹ 旋转、SU(2) = 双模式 S³、SU(3) = 三模式 CP²），从设定输入变为颜料混合规则；定域化唯一性成立。（定案，前提为模态公设 P7）
18. **规范势** = 平行搬运联络（比较相邻零度基准编配与实轴方向差）；**电磁场** = 实轴方向场曲率。（定理 3、4）
19. **麦克斯韦方程组双重几何来源**：无源组 = 比安基恒等式（曲率一致性，算术必然），有源组 = 校准动力学。（后者为纲领性主张）
20. **规范变换的实体操作** = 零度基准的局域旋转（∠0 转 λ，α 重标定，物理实轴不参与）；零度基准三层客观性（存在论 / 编配论 / 否定论）：绝对方向无物理意义，存在与编配客观。（定案 2026-09-01）
21. **规范断崖的填补（约定如何产生物理效应）**：零度基准结构方位客观性 + 绕数拓扑承载，纯约定不能产生拓扑荷。（定案）
22. **静电学与电动力学统一**：静电势 φ 与时间联络 A₀ 是同一对象（相位搬移畸变场）的两种表述。（定案）
23. **磁铁机制（部分推进）**：南北极 = 闭合扭转圈两个外窗口、同斥异吸 = 校准代价最小化、磁单极拓扑排除。（条件性；自旋排列 → 外部实轴方向场扭转的定量桥梁为开放问题）

## 四、电荷与粒子

24. **电荷** = 满周闭合环内部 U(1) 空间中的拓扑缠绕数（绕数），拓扑荷而非 Noether 荷。（定理 8；束缚振荡表述为条件性）
25. **真空电中性** = 束缚振荡净绕数为零（去程 +2π、回程 −2π 对称折返）。（条件性）
26. **光子零电荷**（零电荷家族推广）：光子（平凡表示，实轴涨落不变）、Z⁰（对角模式不转换）、胶子（不在电荷载体登记）、中微子（左手扭转与内部缠绕反向抵消，纲领构想）。（分层：条件性至纲领性）
27. **解释已知事实齐备**：电荷量子化、电荷守恒、正反粒子湮灭、分数电荷 n/3（超荷分量）。（解释层齐备，未达预言层）
28. **磁单极不存在** = 闭合扭转圈拓扑排除（无孤立的 U(1) 磁单极）。（条件性）
29. **质量 = 拓扑缺陷绑定能**（σ 锁定孤子与真空的能量差，非振荡激发能）；ω₀ ~ √κ_φ 为缺陷刚度特征频率；Yukawa 系数为导出量 y_f = √2ħ√κ_φ/v；层级问题 = 两级标度分离。（定案）
30. **有质量粒子形成** = 大爆炸同步相变局域缺陷（粒子诞生是整体事件）。（定案）
31. **三代费米子质量谱**：三类等价方向 → Z₃ 轮换 → 120° 体系 → 实轴投影准则 → Koide 公式；观测 Q = 0.6666605（偏离 0.005%~0.012%）；φ = 2/9 预言经 μ/e、τ/e 两条独立通道反推符合至 10⁻⁶ rad 级；μ/e = 206.7703 对观测 206.7683。（数值验证；投影准则与 φ 机制为开放问题）
32. **自旋 = 内部 π 扭转**：奇数半扭转闭合环给出旋转 2π 波函数变号的旋量几何（自旋 1/2）；旋量性与 SU(2) 双值表示逐项相容。（体系内合理内核；统计层面悬置）
33. **色禁闭** = 三元组结构不可分（条件性）；**渐近自由** = 模式纠缠尺度依赖（纲领性）；**任意子** = 三元组模式缺陷（2+1 维材料晶格，分数电荷 e/3、分数统计 θ = π/3、色禁闭拓扑全息）。（条件性）

## 五、引力

34. **引力微观起源**：δθ = m/m_P 每摆程偏转 → 微观曲率源 κ̇ = 4πGm/ħ（不依赖 l_P，宏观与普朗克细节分离）→ 静态弱场下经高斯定理导出泊松方程 ∇²Φ = 4πGρ，G 微观定义与宏观耦合自洽。（静态弱场严格推导）
35. **等效原理内禀化**：惯性质量与引力质量出自同一个内禀节律（ω₀），任意速度恒等；质能等价 → 总能量调制像素生成频率增强引力源（ω_eff = γω₀）。（定案）
36. **引力不需量子化**：引力量子性内禀于微观机制（κ̇ 分母含 ħ；定理二"引力本来就是量子的"独立支撑）。（定案）
37. **γ 双重角色澄清**：读数率 ω_b/γ（钟慢）与源强度 γω₀（引力增强）互补，方向相反物理不同，共同构成相对论效应完整图景。（定案 2026-09-01）
38. **紫外截断与光速同源**：采样率 = 碰撞率 = 每摆程一次（ω_P）；采样定理硬界限（周期 ≥ 2t_P、频率 ≤ ω_P/2 精确为普朗克频率一半，往返对称性 = Nyquist 因子 2 的几何根源）；短于 t_P/l_P 的间隔内无采样，物理效应不能发生于普朗克尺度以下，引力亦然。（定案；精确形式待推导）

## 六、测量、认知与语义

39. **测量 = 凝固**：本体叠加（波性侧，潜在并存）→ 现象分立（粒性侧，彼此分明）；分立性由采样定理保证（现象层即采样层）。（定案）
40. **一切相互作用 = 测量（碰撞）**：采样、碰撞测量、校准、快照抄写四者同一；测量论与相互作用论在几何上合流；无独立于相互作用的观察者。（定案 2026-09-01）
41. **相位语义归属**：物理学"相位"一词唯一定位在实轴方向 α（相位差 = α 差）；旋转角 θ = 时间（相对自身物理实轴的旋转角，完全不可测、无相位差）；摆程 = 法线跃迁（时间计数）；零度基准为数学零度方向（绝对方向无物理意义，存在与编配客观）。（定案 2026-09-01 系列）
42. **Born 规则的基石辨析**：模方的旋转不变性、全局相位不可观测的精确含义、实轴投影直觉在量子语境的失败、实化时刻锚定。（定案；分工命题为模型方案）
43. **同底异显（可观测性 = 差异）**：规范冗余的本体论根基；"相位零点没有理由全局一致"为种子命题；三代质量谱 120° 有效恰因它是差。（定案）
44. **连续-离散-连续 = 正-反-合**：三层递进采样链（连续生成事件，事件组成尺子，尺子再次丈量连续）与辩证法三段式结构同构；采样定理为"合"的操作定义。（定案）
