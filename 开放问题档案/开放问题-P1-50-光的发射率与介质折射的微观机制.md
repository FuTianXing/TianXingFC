## 2026-10-01 首轮登记：结构定律判据级锁定

- 判语：发射率标度判据（`minimal_verification_emission_rate_scaling.py`，判据 3/3，E2 兼 EP5 齿）。发射率 = $2\pi\vert g\vert^2\times$ 态密度的黄金规则在晶格真空上成立（三档 $\omega_0$ 比值 $1.0000/0.9994/0.9924$），一维范霍夫奇点驱动标度（$\Gamma(1.9)/\Gamma(1.0)$ 实测 3.29 对理论 2.77，容差内），缺陷频率移出能带则发射消失（束缚态后段平均 0.97，带内对照 0.011）。
- 结论句：发射机制的形态学约束锁定——任何候选通道的发射率必须写成矩阵元平方乘态密度，态密度由判据第 522 条的色散唯一给出；耦合通道定 $\cos$ 高阶项（方案注记第九节，依据增强）、爱因斯坦 A 系数数值与折射机制仍开放，见 [[验证脚本/注记-发射率标度判据（第524条）：黄金规则、范霍夫效应与带外反例|第 524 条注记]]。

## 2026-10-01 第三轮登记：三维维数面闭合

- 判语：三维发射率标度判据（`minimal_verification_3d_emission_rate.py`，判据 3/3，B2 兼 EP5 齿）——经典波场中缺陷振子份额的黄金规则式衰减成立（三档 Γ·ω0²/ρ_N 常数性 1.04）、κ² 律成立（时间尺度比 3.48 对期望 4）、带外束缚（ω0=3.9 份额后段 0.96）。位移型耦合的黄金规则形态 Γ ∝ κ²ρ(ω0)/ω0²（低频平坦），解析系数与数值标定差 3.4 挂归一细节。
- 结论句：通道问题从「形式未知」细化为「耦合型（位移型已判、相位型待查）与归一两个待定项」，见 [[验证脚本/注记-三维发射率标度与带外束缚（第525条）：黄金规则的维数面与κ²律|第 525 条注记]]。介质折射机制仍开放。

## 2026-10-01 第四轮登记：通道二分签名锁定

- 判语：通道二分判据（`minimal_verification_channel_dichotomy.py`，判据 3/3，C3 兼 EP5）——位移型（弹簧）签名：Γ·ω0²/ρ 常数（低频平坦，0.8/1.2 两档 1.043/1.051）；速度型签名：Γ/ρ 常数（低频禁戒，Γ ∝ ω² → 0，三档常数性 1.054）；判别量 D(0.8)/D(1.2) = 0.422 对期望 0.444，两签名互斥可判。
- 结论句：体系耦合形式一经确定即可对号入座定案低频禁戒是否成立；缺陷微观结构（cos 高阶项矩阵元）仍属本条攻坚，介质折射机制仍开放；位移型 ω0=1.0 档单档读数异常（3.7 倍偏低）登记为观察项，见 [[验证脚本/注记-耦合通道红外行为二分判别（第526条）：位移型平坦与速度型禁戒的签名锁定|第 526 条注记]]。

## 2026-10-04 第五轮登记：能隙型折射图像与判据设计草案

- 判语：作者提问「光在介质中为何速度不同」，答出三段闭合加一段方案。去耦引理（§6.2）排除均匀弹性负载慢化，唯一入口为 $\cos$ 高阶项开启的两扇区非对角耦合；能隙型混合模式色散 $\omega^2=c^2k^2+3\omega_P\kappa_\varphi$ 给出 $v_g=c^2k/\sqrt{c^2k^2+3\omega_P\kappa_\varphi}$ 与 $n(k)=\sqrt{1+3\omega_P\kappa_\varphi/(c^2k^2)}$，三个行为特征（能隙下禁戒、高频回归、全程亚光速）可判；已知失配已登记：闭式只取共振项同相部分，低频端给 $n\to\infty$ 而真实材料静态 $n(0)$ 有限，缺反向项与完整响应函数。四条判据 M1 至 M4 已设计（含 EP5 反例齿），本轮未写脚本、未跑数值、未占 README 号。
- 结论句：慢化的机制入口收敛为唯一一条（两扇区非线性混合），能隙型图像升为方案层草案并带可搭判据；$\kappa_\varphi$ 原子值、耦合常数 $e$ 来源（P1-49）、两扇区耦合矩阵元形式三项定量缺口不变，介质折射机制仍开放；静态低频段失配已诚实登记，见 [[内部草稿/注记-介质中光速的微观机制：混合本征模、能隙型折射通道与两扇区耦合的判据设计（2026-10-04）|本轮注记]]。
