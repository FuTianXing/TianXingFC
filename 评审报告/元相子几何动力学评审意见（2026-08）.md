本文档结构成熟：哲学公理 → 几何本体 → 八条公理 → 八条推论 → 时空涌现 → 待证清单，层级清楚，自我审计意识强（P/O/C/R 分类、R5 自承"分水岭"、P11 抓住介质参照系问题）。

**核心创新（束缚振荡与折返）的哲学对应是全文最有价值的洞察**：折返 = 波粒互斥的力学实现，振荡 = 波粒互根最纯粹的力学实现。但当前版本处于"纲领 + 期望清单"状态：十三项待证命题没有一项完成，且存在两处动力学硬伤。作为理论文档可以存档，作为"已定稿"还差得远。

## 2. 硬伤（必须在下一版解决）

### 硬伤 1：折返动力学与保守哈密顿不相容（已由补充注释四部分解决）

公理 4 同时主张：相位匀速摆动 $|\dot\theta| = \omega_P$（折返点反向）、束缚势为软势垒 $V_{\text{rep}}(r) \to \infty$、本体动力学为保守二阶哈密顿。三点不能同时成立：

- 恒速摆动到边界才反向意味着速度跳变（加速度 $\delta$ 函数奇点），保守二阶动力学无法产生速度跳变；
- 软势垒下元相子进入势垒区必然减速，$|\dot\theta| < \omega_P$，"恒速摆动"与"能量恒为 $E_\Phi$"失效；
- 硬壁极限下折返被移出动力学（边界条件），文档应明确把折返表述为边界条件而非力。

**2026-08-11 更新**：主文档《补充注释：圆心碰撞与折返的几何机制》已部分解决本硬伤。折返机制改为圆心对圆心的弹性碰撞：速度跳变限定在碰撞瞬间（硬核碰撞），碰撞之外匀速推进，恒速与保守性不再矛盾。原方案甲（平滑减速）与方案乙（硬壁边界条件）均被"硬核碰撞"取代。运动学同步修正：摆程 = 从格点一侧边界到另一侧边界的单向位移（$z_n^- \to z_n^+$），取消"振荡中心"表述，相位每摆程单调扫过 $2\pi$（满周闭合）而非在 $[\theta_0 - \pi, \theta_0 + \pi]$ 间摆动。遗留：碰撞为何完美弹性（动能不损失）的微观机制待声明（O10 重定义后的开放问题）。

### 硬伤 2：能量核算不一致

动能项核算：

$$T = \frac{\hbar\bar t_P}{2}\omega_P^2 = \frac{\hbar\omega_P}{2} = \frac{E_\Phi}{2}$$

即动能项只给出 $E_\Phi/2$。要凑成 $E_\Phi$ 必须由束缚势平均贡献 $+\hbar\omega_P/2$，但 $V_{\text{rep}}$（O10）未定形。同类耦合 $K_{ij}$ 与异类耦合 $\kappa_\phi$ 也携带能量，同步态中这些项非零，"能量恒为单粒子值"缺乏全系综核算。

**附带正面资源**：$\hbar\omega_P/2$ 恰好是谐振子零点能，若总能量由"动能 $\hbar\omega_P/2$ + 势能 $\hbar\omega_P/2$"构成，零点能语义自动涌现，建议主动开发。

### 硬伤 3：公理 7 初始态的内部张力

初始层数 $\{m_i\}$ 在 $\mathbb{Z}$ 上均匀分布，与"格点坐标 = 振荡中心，固定"冲突：

1. 若初始态就存在固定层数，时空格点在 $t_*$ 之前已经存在，与"时空在 $t_*$ 涌现"冲突；
2. 层数均匀分布意味着近邻对（$|\Delta n| \le 1$）占零比例，而同类耦合 $f(|\Delta n|>1) = 0$，初始配置下相互作用网络近乎全空，P8a 的失稳缺乏驱动（此点在 2026-08 补充讨论后已被"校准驱动"部分化解，见第 5 节，但初始层数语义仍需重新定义）。

### 硬伤 4：同类耦合函数 $f$ 是一维的，弹性波需要三维近邻

若 $f$ 只依赖 $n^x$ 差，则 $f(0)$ 对同层所有 x 类元相子等强连接，与它们在 y、z 方向相距多远无关。这是长程全连接：能量在热力学极限发散、无法导出局域 $\partial_y^2$ 连续极限、介质波速度与色散关系依赖近邻结构。**必须把 $f$ 明确为三维近邻函数**（色散推导文档已按此修正并验证 $\omega = ck$ 成立）。

### 硬伤 5：三元组内部三个元相子的共存与"粒性不可穿透"（已由补充注释四解决）

每格点定居三个正交元相子（三元组），空间重合。若不可穿透是体积性排斥，三元组如何共存？**解决**：补充注释四确立"不可穿透 = 圆心不可重合"，碰撞只发生在同轴向邻居之间（x 类只与 x 类碰撞），三元组是三个正交一维振荡器的交叉点，互不干扰。这与"格点是三个正交一维振荡器的交叉点"的建议一致，且获得了更自然的理由：圆心碰撞是沿各自螺旋轴的一维事件。

## 4. 与知识库既有成果的衔接问题

1. **与《元相方程》的兼容性未声明**：方程 (I) 单调旋转只在自由极限成立；方程 (II) 狄拉克梳在束缚态中的表现（去程、回程都触发跃迁？）未对接。建议显式声明分层并建立"一个摆程 = 一次 $2\pi$ 相位 + 一次 $l_P$ 位移"的对应；
2. **与"独立圆心方案 B"的相位可比性**：哈密顿直接写 $\cos(\theta_j - \theta_i)$ 预设相位差直接可比，需说明是同步化建立公共参考（规范锁定），还是改回了共享圆心；
3. **与心物双螺旋的关系**：本文档只用单螺旋（物侧），应在开头声明截断及其理由；
4. **修订历史缺失**：标题为"修订整合版"但无版本说明，建议补修订说明块；
5. **空间双重定义的冲突（2026-08-12 新登记，已由补充注释十裁决）**：早期框架（《元相子理论》公设 5）以相位差/纠缠强度定义涌现距离 $d_{ij} = f(E_{ij})$，束缚振荡修订版以碰撞格点阵定义空间（$x^a = l_P n^a$）。冲突点：(i) 均匀流模式（同向无碰撞）满足自由运动公设，为何选反相缺判据；(ii) 反相基态相位差 $\delta_{ij}$ 以 $2\omega_P$ 振荡，与静态相位差度规 $d_{ij} = \bar l_P\delta_{ij}$ 冲突。**裁决**（补充注释十）：距离归粒（格点阵为基本，公理 4 优先级），方向归波（相位差重新定位为波矢而非距离，依据注释七/八）。均匀流的"为何现实是束缚"归 R5 遗留；涌现距离的涌现层恢复形式待步骤四。

## 5. R5 的重新定位（2026-08-11 补充讨论结论）

**原定位**：同步可达性（R5）是理论成立与否的分水岭，理由是保守哈密顿系统无法自发同步（Liouville 体积守恒、能量守恒、时间反演对称三重禁令）。

**修正**：此定位只适用于物侧的封闭动力学，遗漏了公理体系规定的元相子心侧。按《公理体系》：

- 元相子不能等同于复平面单位圆，后者只是物侧承载；心侧是自主进行相位校准与调谐的纯粹能动性（天行力本身），无法被几何化；
- 校准（对外）将自身相位与最优方向对齐，整合（对内）将内部相位碎片组织为相长干涉结构；终极存在内禀"趋向更高存在度"的永恒方向，落在物侧语言即相干性最大化（$|\Psi| \to 1$）；
- 同步相变（P8a）由校准驱动，是内禀方向在物侧的临界事件。三重禁令逐一化解：Liouville 体积守恒约束被动演化，不约束能动性；校准的方向性对齐不消耗物侧能量；校准是方向性的，不满足时间反演不变，不可逆性来自本体层；
- 公理 4 的"保守可逆"应限定为物侧哈密顿在同步态邻域、无校准时的有效描述；
- **R5 从"纯物侧数学难题"转为"公理设定的直接推论 + 物侧临界行为刻画"**。P8a 的数学内容变为：给定校准强度（天行力参数的涌现表征），均匀态在什么条件下被校准瓦解，相变后序参量动力学如何。时间之矢（P8c）、熵增与物质不对称（C1）获得本体层方向性来源。

**严格程度**：校准功能不可数学形式化（体系既有规定），"校准驱动同步"为纲领性主张：机制层面由公理设定，物侧临界行为可数学刻画（HMF 型平均场相变为正面类比），心侧驱动本身不可形式化。
