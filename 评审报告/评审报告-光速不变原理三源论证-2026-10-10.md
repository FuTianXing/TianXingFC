## 一、结论摘要

审查认定存在三处实质问题与三处表述问题，其中前两处触及论证有效性。

**实质问题**

1. **形式层的恒真与物理层的非平凡**（2026-10-10 作者裁决后修正，详见 §1.1）：数值输入不构成循环。三源推导的落点在形式层归结为 \(c = l_P/t_P\)，该式在 \(l_P\) 由 \(c\) 定义时为恒真；接力几何的实质断言在物理层，即速度表达式不含耦合刚度 \(K_0\)。导出光速不变原理的力量在物理层。原"因 \(c\) 为公设输入故循环"的指控撤回。
2. **三源非独立**：三条来源均归结为 \(c = l_P/t_P\)，共享同一前提，不构成独立交叉验证。"三源互为印证"的表述在此失效。
3. **L2 近似循环**：boost 解由"低能有效作用量的洛伦兹不变性"给出，而该洛伦兹不变性正是 L2 所要支持的结论。低能洛伦兹不变、\(\omega = ck\)、光速不变三者等价，以其中一项论证另一项不产生独立信息。

**表述问题**

4. L3 与第二源及 L2 任务重叠，体系已自承（P11 攻坚计划、PB-0 轮裁决）。
5. L4 为否定性存在命题，论证负担未完成，R1 风险条目自承"绝对时间参数与洛伦兹不变性的相容性悬而未决"。
6. 概念置换未显式声明：标准光速不变原理指"任意惯性系测得真空光速相同"，体系实际论证的是"物理光速相对晶格为 \(l_P/t_P\)"加"观测者读数经补偿相同"，二者概念内容不同。

## 一之一、作者回应与审查者修正（2026-10-10）

作者指出：\(c\) 的数值是公设输入，斜率是几何性质，二者不应改变"导出光速不变原理"的结论。

审查者接受该区分，并作如下修正。

**撤回的部分**。导出光速不变原理导出的是结构命题（斜率锁定与普适性），\(c\) 的数值由经验锚定。标准物理同样不导出 \(c\) 的数值，只导出"存在一个不变量速度"这一结构。故"\(c\) 是公设输入"不构成循环依据。原 §2 中"因 \(c\) 为公设输入故循环"的指控撤回。

**形式层与物理层的分离**。形式层上，"光速 \(= l_P/t_P\)"在 \(l_P\) 由 \(c\) 定义时为恒真。接力几何的实质断言在物理层：速度表达式不含耦合刚度 \(K_0\)。旧表述 \(v_s^2 = K_0 l_P^2/\bar t_P\) 依赖 \(K_0\)，接力几何排除这一依赖。该断言非平凡，且不因形式层的恒真而削弱。导出光速不变原理的力量在物理层。

**收窄后仍成立的三点**（与数值输入无关，见 §3、§4、§6）。

其一，第一源相对第二源无独立信息：元相方程 §3.2 末步以 \(\omega_P l_P = 2\pi c\) 回代，即预设 \(c = l_P/t_P\)。第一源的物理内容（匀速性）虽与第二源不同，它仍属第二源在方程语言下的表现，不宜计为独立的第三条来源。

其二，L2 的 boost 解由"低能有效作用量的洛伦兹不变性"给出，而后者是 L2 要支持的结论。

其三，概念置换需显式声明。

**一处建议统一的表述**（公理表述层，不触及导出结论）。若"斜率是几何性质"成立，\(l_P\)、\(t_P\) 宜作为独立几何单元；而 [[元相子理论中的温度定义：相位无序度的能量化与宇宙学意义]] 写 \(l_P = \sqrt{\hbar G/c^3}\)，把 \(l_P\) 定义为 \(c\) 的函数。定理二公设 2 的"三量捆绑"表述（每满周跃迁 \(l_P\)、历时 \(t_P\)、速度 \(c\) 一并设定）与前者自洽，与后者不并立。建议统一，以免"斜率是几何性质"与"\(c\) 为独立公设"在文字上互相消解。

## 二、循环定义：\(c\) 的地位矛盾（2026-10-10 部分修正，以 §1.1 为准）

### 2.1 公设层的原文

[[关于天行力学的一份理论纲领]] 定理二写明三个普适常数作为独立公设被确立，其公设 2 为时空转译常数 \(c\) 的数值与普适性，并把 \(c = l_P/t_P\) 一并写入公设内容：元相子每完成一次 \(2\pi\) 相位旋转，跃迁一个 \(l_P\)，历时一个 \(t_P\)，速度恰为 \(c = l_P/t_P\)。

[[元相子理论中的温度定义：相位无序度的能量化与宇宙学意义]] 进一步给出普朗克标度由物理标度定理定义：\(\hbar\)、\(c\)、\(G\) 为独立公设，\(l_P = \sqrt{\hbar G/c^3}\)。

### 2.2 两处原文不相容

若采纳温度定义文件的写法，\(l_P\) 由 \(c\) 定义，则 \(c = l_P/t_P\) 是定义恒等式，"导出光速"为循环。若采纳接力几何的写法，\(l_P\) 与 \(t_P\) 为晶格的独立几何单元（公理 5 的摆程节律加螺旋刚性），则 \(c\) 为派生量，定理二"\(c\) 为独立公设"的表述需改写。

两种写法在同一体系内并存，构成一处需要作者裁决的内部不一致。审查者判断：这一不一致不是措辞疏漏，而是"光速究竟属输入还是输出"这一实质定位的悬置。

### 2.3 第一源的恒真结构

[[元相方程：从欧拉公式到连续与离散统一的螺旋动力学]] §3.2 的推导链条为：设 \(dz/dt = A\,\delta(\arg\psi)\)，积分得 \(\Delta z = (A/\omega_P)\times\) 满周次数；令每次满周 \(\Delta z = l_P\) 得 \(A = \omega_P l_P\)；用普朗克关系 \(\omega_P l_P = 2\pi c\) 得方程 (II)；宏观平滑得 \(Z = cT\)。

其中 \(\omega_P = 2\pi/t_P\)，故 \(\omega_P l_P = 2\pi l_P/t_P\)，普朗克关系 \(\omega_P l_P = 2\pi c\) 与 \(c = l_P/t_P\) 完全等价。第 3 步与第 4 步合并即 \(A = 2\pi l_P/t_P\)。再对 \(Z = cT\) 积分核验：\(\int 2\pi c\,\delta(\arg\psi)\,dt = c\,t_P N\)，而 \(Z = l_P N\)、\(T = t_P N\)，故 \(Z/T = l_P/t_P\)。

前提（每次满周位移 \(l_P\)）与结论（\(Z/T = l_P/t_P\)）是同一陈述的微观与宏观两种写法。该推导不含独立信息。

按 [[AGENTS.md]] 的恒真检验纪律，任何判据须给出"改掉它就 FAIL"的反例检验；此处改掉 \(c = l_P/t_P\) 会使前提与结论同时失效，属构造恒真，PASS 不含物理信息。

**2026-10-10 修正**：上述恒真性判断限于形式层。作者指出接力几何的物理断言为"速度表达式不含 \(K_0\)"，该断言非平凡。故本节的恒真性结论收窄为：第一源相对第二源无独立信息，不宜表述为独立的第三条来源；接力几何本身（第二源）的物理内容不受影响。

## 三、三源非独立

三条来源的落点逐一核对如下。

第一源：末步以 \(\omega_P l_P = 2\pi c\) 回代，等价于 \(c = l_P/t_P\)（见 §2.3）。

第二源：接力几何直接命名 \(c = l_P/t_P\)。

第三源：色散 \(\omega^2 = \frac{4}{t_P^2}\sum_a \sin^2\frac{k_a l_P}{2}\) 低能展开得 \(\omega^2 \approx \frac{l_P^2}{t_P^2}k^2\)，其中 \(\frac{l_P^2}{t_P^2}\) 被识别为 \(c^2\)。

三源共享同一关系 \(c = l_P/t_P\)。文献中"三条独立来源，互为印证"（[[晶格何以不破坏洛伦兹不变性：元相子理论的时空机制与分层定理]] §4）与"三条来源一致说明"（[[狭义相对论两条公设的几何归结：元相子框架下的推导、检验与可证伪边界]] §3.4）的"独立"与"一致"在此不成立：三者从同一前提出发，"一致"为必然。

审查者判断：三源在**结构层**各有实质内容，在**数值层**共享输入，二者应分开陈述。

- 第一源的实质内容为匀速性：满周跃迁机制给出宏观匀速，依据是摆程节律恒定。
- 第二源的实质内容为与介质无关：接力速度由每步距离与每步用时决定，耦合刚度 \(K_0\) 不进入速度，排除弹性介质依赖。
- 第三源的实质内容为低能各向同性：晶格色散的各向异性只出现在 \(k^4\) 阶，低能方向依赖消失。

这三项内容均不导出 \(c\) 的数值。\(c\) 的数值来自公设输入（或来自 \(l_P/t_P\) 的命名），须显式声明。

## 四、L2 的近似循环

[[晶格何以不破坏洛伦兹不变性：元相子理论的时空机制与分层定理]] §6.2 的 boost 解由"低能有效作用量的洛伦兹不变性"给出，形式为 \(\varphi_v = \psi_0(\gamma(x-vt))\cos[\omega_b\gamma(t-vx/c^2)]\)，\(\gamma = 1/\sqrt{1-v^2/c^2}\)。

而 §5.3 说明该低能有效作用量的洛伦兹不变性来自 \(\omega = ck\) 线性色散与局域耦合。故论证链为：\(\omega = ck\)（低能）给出低能有效作用量洛伦兹不变，后者给出 boost 解与 \(\gamma\)，\(\gamma\) 又用于论证光速不变与洛伦兹不变。

低能洛伦兹不变、\(\omega = ck\)、光速不变三者在低能层互相等价，用其一论证另一项不产生独立信息。

缓解之处在于：\(\omega = ck\) 由晶格哈密顿的显式色散计算给出，且带 \(k^4\) 阶偏离与方向比 \(6:3:2\) 的具体预言，属可检验的计算结果。故"低能近似洛伦兹不变"有实质内容，问题集中于 \(\gamma\) 与 boost 解的使用方式：应声明其为"低能有效理论的内部自洽"，不宜表述为对洛伦兹不变性的独立导出。

## 五、L3 重叠与 L4 论证负担

L3（光速外置）与第二源、L2 重叠。[[理论攻坚/P11 攻坚计划：介质不可探测性的四处形式化缺口与引理收敛]] 已指出 L3 与 L2 任务重叠，L3 管"数值"一侧，真正承担"不变"的是 L2 的补偿机制。[[内部草稿/研究方向-PB-0 引理收敛的裁决：L3 并入 L2 与三引理论证链]] 已裁决 L3 并入 L2。故 L3 不构成独立证据。

L4（绝对运动态不可读）为否定性存在命题：须证明不存在任何内部判据。现有论证依赖"可探测量只依赖相位差"这一相位差本体论前提，属前提而非结论。体系 R1 风险条目自承"束缚振荡晶格定义潜在优选参照系，绝对时间参数与洛伦兹不变性的相容性悬而未决"，与此判断一致。

## 六、概念置换未声明

标准相对论的光速不变原理指"任意惯性系测得真空光速相同"。体系实际论证的内容为两项：物理光速相对晶格为 \(l_P/t_P\)；观测者读数经 \(\gamma\) 补偿后相同。

前者是相对晶格定义的绝对量，后者是测量读数的不变性。这一置换在物理预言层与相对论等价（相对论亦只谈测量），但概念内容不同：体系保留特优系，相对论取消特优系。若不在正文显式声明这一置换，则"导出光速不变原理"的措辞有夸大之嫌。

## 七、修补方向（建议，待作者裁决）

1. **澄清 \(c\) 的地位**。若 \(c\) 为公设输入，则"三源"应改述为"三条一致性表述"，撤销"导出光速不变原理"的措辞，改为"把光速不变原理分解为公设输入（常数性）与可论证部分（与光源、观测者无关）"。
2. **若坚持 \(c\) 为导出量**，须把 \(l_P\)、\(t_P\) 立为独立公设，改写定理二，并说明 \(l_P/t_P\) 与经验 \(c\) 数值的相符步骤（该步骤仍需经验锚定）。
3. **三源去重**。承认三源共享 \(c = l_P/t_P\)，改述为"同一关系的三种表述"，并补入真正独立的检验（色散 \(k^4\) 偏离的数值结果）。
4. **L2 去循环**。为 boost 解给出独立于洛伦兹变换的晶格推导，或显式声明其低能自洽的循环结构。
5. **L4 补正面证明**。穷举内部判据以支持"不可读"的否定命题。
6. **显式声明概念置换**。在论文正文写明体系版光速不变原理与标准版的概念差异。
