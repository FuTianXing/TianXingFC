# 评审报告-粒子运动速度的决定因素注记审查报告（2026-09-06）

## 评审报告

**论文标题**：《注记-粒子运动速度的决定因素：质量、动量与色散》（几何机制版，冲突诊断/，2026-09-06）

**评审日期**：2026-09-06

**总体评价**：注记的论证结构清晰，几何化重写成功把速度问题的每个环节锚定到体系机制（群速度 = 色散斜率、动量 = 相位梯度、光色散 = 注释 03 已知关系、速度上限 = 晶格因果、惯性 = Peierls 势垒），并诚实标注了待验证项（kink 色散），引用（注释 03/04/09）准确。但发现一处 A 级数学错误（第五节速度公式最终表达式的量纲不自洽，少因子 $c$），该错误同时存在于配套科普文章；另有三处 B 级问题（$c_{\text{eff}}$ 平均因子表述、$p = \hbar k$ 的体系内依据未标注、地球元相子数量级不准确）。修正后注记可达 A 级。

### A级问题

| # | 位置 | 问题描述 | 建议修改 |
|---|------|---------|---------|
| 1 | §五 速度公式 | 最终表达式 $v = \frac{pc}{\sqrt{p^2c^2 + m^2c^4}}$ 量纲不自洽（结果为无量纲，正确应量纲 $L/T$）。正确推导：$v = \frac{dE}{dp} = \frac{pc^2}{E} = \frac{pc^2}{\sqrt{m^2c^4+p^2c^2}}$，等价形式 $\frac{pc}{\sqrt{m^2c^2+p^2}}$。注记少因子 $c$。配套科普文章《为什么光总是一步到顶》同一公式同样错误，需一并修复 | 改为 $v = \frac{pc^2}{\sqrt{p^2c^2 + m^2c^4}}$（或等价 $\frac{pc}{\sqrt{p^2 + m^2c^2}}$）；科普文章同步 |

### B级问题

| # | 位置 | 问题描述 | 建议修改 |
|---|------|---------|---------|
| 1 | §四 $c_{\text{eff}}$ | "各向同性平均因子"表述错误：长波展开 $\omega^2 \approx \frac{l_P^2}{t_P^2}\sum_a k_a^2 = c^2 k^2$，三维立方晶格长波极限对任意方向精确各向同性，$c_{\text{eff}} = c = l_P/t_P$ 精确，无平均因子。有限 $k$ 的修正方向是 $v_g < c$（$\sin$ 展开高阶项，注释 03 已有声明），方向与"平均因子"无关 | 删除"各向同性平均因子"，写 $c_{\text{eff}} = c = l_P/t_P$（几何恒等式）；补充一句有限 $k$ 修正为 $(k l_P)^2$ 量级、$v_g < c$ |
| 2 | §三 动量 | $p = \hbar k$ 直接使用德布罗意关系，但体系内位置、动量算符的严格导出是开放问题（P3-10：从 $S^1$ 本位严格导出），未标注依赖 | 标注"期望在体系内导出，P3-10 遗留"或改为"波矢 $k$ 的几何身份 = 相位梯度（注释 09），动量关系 $\hbar k$ 依赖 P3-10" |
| 3 | §九 宏观物体 | "约 $10^{57}$ 量级的元相子"数量级不准确：地球核子数约 $3.6\times10^{51}$；若指真空格点数则约 $10^{125}$。$10^{57}$ 与两者都不符 | 删除具体数字，改为"天文数字（核子数约 $10^{51}$ 量级）"或明确口径 |
| 4 | §五 表述 | "同样的动量，曲线越陡（质量越大）速度越小"表述含糊：质量大时色散曲线抬升更高但给定动量下斜率（速度）更小，"陡"与"斜率"易混 | 改为"质量大时色散曲线在原点抬升更高（$E(0) = mc^2$ 更大），给定动量下曲线斜率（速度）更小" |
