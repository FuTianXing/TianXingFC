# 论文评审联动协议

> 定义天行新学论文的完整评审闭环：定稿 → 一致性检查 → paper-review 评审 → paper-revise 修订 → 复核 → 状态登记。
> 联动对象：`paper-review`（六维评审，A/B/C 分级报告）、`paper-revise`（逐级修改）、`D:/software/TianXingFC/理论总纲/子理论索引.md`（状态跟踪区）。

## 1. 完整流程

```
论文成稿
  ↓
[1] 一致性检查：《一致性检查清单.md》26 项全部 ✅
  ↓
[2] 🔴 CHECKPOINT：向作者确认进入评审（作者可跳过评审直接定稿）
  ↓
[3] 状态登记：子理论索引状态跟踪区标记「评审中」
  ↓
[4] 调用 paper-review 评审（六维 + 体系专属附加检查，见第 2 节）
  ↓
[5] 🔴 CHECKPOINT：向作者展示评审报告（A/B/C 分级问题清单），确认处理范围
  ↓
[6] 调用 paper-revise 修改：按 A → B → C 逐级处理
      每级完成后用 read_file 验证改动上下文，确保不引入新问题
  ↓
[7] 复核：对照评审报告逐条关闭问题 + 重跑一致性检查清单
  ↓
[8] 状态更新：全部关闭 → 「已定稿」；有遗留 → 「修订中」并说明
  ↓
[9] 若修订引入了体系新思想 → 走《更新协议》暂存 → 确认 → 固化
  ↓
[10] 自动 git 提交本轮改动（一篇文档一次提交），报告改动文件清单；不自动推送
```

> **版本提交约定**：全流程（含 [6] paper-revise 逐级修改）中，**提交自动，推送人工**。每完成一个实质工作单元即自动 `git add` + `git commit`，同一篇文档的多次编辑合并为一次提交，不在编辑中途提交；`git push origin master` 仅在作者明示"推送"时执行（见 `D:/software/TianXingFC/AGENTS.md`「git 规范」）。

## 2. 体系专属附加检查（叠加在 paper-review 六维之上）

paper-review 自带六维（结构完整性、内容与论证质量、LaTeX 与数学格式、语言与表达、引用与参考文献、逻辑一致性）。评审天行新学论文时，**必须追加**以下检查项：

| # | 附加检查项 | 检查内容 |
|---|---|---|
| E1 | 理论位置声明 | 引言是否声明本文在体系中的位置（承接对象、不重复推导内容） |
| E2 | 公理一致性 | 新概念是否与心物波粒二象公理及五重法则矛盾 |
| E3 | 术语符号一致性 | 是否遵循术语表标准符号；偏航相位是否用负号约定（$\Omega(t) = -\eta\pi\ln\tilde{D}(t)$） |
| E4 | 引用版本正确性 | 体系内引用是否使用子理论索引 ✅ 状态版本，未引用被取代初版 |
| E5 | 严格程度声明 | 每个核心结论是否标注严格程度（严格定理/条件性命题/纲领性主张/模型方案） |
| E6 | 可检验性 | 是否给出可检验预测或显式声明为开放问题 |

附加检查发现的问题按 paper-review 的 A/B/C 分级纳入同一份评审报告。

## 3. 失败模式与处理

| 触发条件 | 处理动作 |
|---|---|
| 一致性检查未全过（❌ 项未清零） | 不进入评审，先修正 ❌ 项（见一致性检查清单"失败处理"列） |
| paper-review 技能不可用 | 回退：按《一致性检查清单》六类 + 附加检查 E1-E6 人工评审，产出同格式 A/B/C 报告 |
| 评审报告与体系基准冲突 | 暂停修改，将冲突点记入 `drafts/`，提交作者裁决谁修正谁 |
| paper-revise 修改后出现新问题 | 立即 read_file 验证上下文并修复，修复后重新走该级验证 |
| 作者对评审报告有异议 | 记录异议理由，不强行修改；标注"作者保留意见"后按作者决定处理 |
| 修订涉及体系核心思想变更 | 不直接改 `D:/software/TianXingFC/理论总纲/`，走《更新协议》暂存 → 确认 → 固化 |
| 修订完成后需要入库 | 自动 `git commit`（同一篇文档的多次编辑合并为一次）；报告改动文件清单；`git push` 仅在作者明示"推送"时执行 |

## 4. 状态登记规范（子理论索引状态跟踪区）

| 状态 | 含义 | 进入条件 |
|---|---|---|
| 计划中 | 论文主题已提出，尚未成稿 | 提出新论文方向时 |
| 评审中 | 已通过一致性检查，正在评审 | 进入评审流程第 3 步 |
| 修订中 | 评审发现问题，正在修改 | 评审报告存在未关闭问题 |
| 已定稿 | 评审问题全部关闭（或作者确认跳过评审） | 复核通过 |

状态变更时更新 `子理论索引.md` 状态跟踪区对应行（含日期与备注）。
