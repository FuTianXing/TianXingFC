# 论文评审技能

你对一篇学术论文进行系统性评审。评审按以下七个维度逐一检查，每个维度输出具体问题清单（按严重程度分级），最后给出总体评价。

评审时**不要**修改原文——评审产出是一份独立的评审报告。

---

## 评审流程

### 第零步：机器预检

先跑脚本，把机器可判的问题一次性收齐，避免它们混在人工评审的输出里稀释了真正的 A/B 级问题。

```bash
python .agents/skills/paper-review/scripts/check_discipline.py <论文绝对路径> --root <工作区根目录>
```

退出码 0 表示通过，1 表示有命中（按 A/B/C/D 四组分类，附行号与原文片段），2 表示用法错误或文件不存在。加 `--root` 才启用死链检查；`--limit N` 可改段落字符上限（默认 300）。

覆盖四组：

| 组 | 覆盖内容 |
|---|---|
| A 语言纪律 | 序列词、套话、强调词 |
| B 转义安全 | 控制字符、U+FFFD 损坏字符、Unicode 数学符号、转义七判据、`\vert` 紧邻字母、LaTeX 命令残部、行内 `$` 奇偶 |
| C 格式结构 | 表格列数不一致、段落超长、一级节号不连续、缺摘要/关键词/参考文献 |
| D 内部链接 | wikilink 死链（需 `--root`） |

**脚本的判定边界**：它只判形式，不判论证。维度二、维度六、维度七（内容质量、内部自洽、数学正确性）全部仍须人工评审，脚本不代劳。脚本报告的每一处仍需在报告里定级——通常 C 组归 C 级、B 组中的转义崩溃归 B 级。

预检通过不等于论文合格，只说明形式层干净。

### 第一步：全局概览

读一遍全文，建立整体印象：
- 论文的核心论纲是什么？是否清晰？
- 论证的逻辑链条是否完整？
- 目标读者是谁？语言和深度是否匹配？

### 第二步：逐维度审查

按以下七个维度逐一深入。

---

## 维度一：结构完整性

检查论文是否具备完整的学术结构：

- [ ] 标题是否准确反映内容？
- [ ] 摘要是否独立可读？包含问题、方法、结果、结论四要素？
- [ ] 关键词是否覆盖核心概念？
- [ ] 引言是否交代背景、问题、相关工作、本文贡献？
- [ ] 正文各节之间逻辑衔接是否顺畅？有无跳跃或断层？
- [ ] 结论是否回应引言中提出的问题？
- [ ] 参考文献格式是否统一、完整？

## 维度二：内容与论证质量

- [ ] 核心论纲是否有充分论证支撑，还是仅靠断言？
- [ ] 命题/定理/定义的陈述是否精确？条件是否完备？
- [ ] 论证是否存在逻辑跳跃或隐含假设？
- [ ] 是否存在未经辩护的强主张（如"唯一""所有""必然"）？
- [ ] 与既有工作的关系是否清晰？是否准确区分了"本文的工作"与"他人的工作"？
- [ ] 开放问题与局限是否被诚实对待？

## 维度三：LaTeX 与数学格式

逐条检查所有数学公式：

- [ ] 花括号 `{` `}` 是否已用 `\{` `\}` 转义？（LaTeX 中最常见的渲染崩溃原因）
- [ ] set builder 中的竖线是否用 `\mid` 而非普通 `|`？
- [ ] 积分、求和等算子的上下限是否使用 `\int_0^T` 等正确语法？
- [ ] 求和/积分后的微分元是否有正确间距（`\, dx` 而非 `dx`）？
- [ ] 中文与 LaTeX 公式之间是否需要空格？（一般不需要，但若紧邻标点需检查）
- [ ] 无法在 LaTeX 中直接显示的 Unicode 字符（如 `ℏ` 应写为 `\hbar`，`∫` 应写为 `\int`）？
- [ ] 所有数学标识符是否使用正确的数学字体（`\mathcal`、`\mathfrak`、`\mathbb` 等）？
- [ ] 括号大小是否使用了 `\left` `\right` 或手动调整？
- [ ] 多行公式是否有合理的对齐？

## 维度四：语言与表达

- [ ] 中英文混排中，是否有散落的英文单词未被引号包裹或未翻译？
- [ ] 标点符号是否统一（全角中文标点 vs 半角英文标点）？
- [ ] 是否存在病句、冗长句或歧义表达？
- [ ] 同一概念在全文中是否使用同一术语？（术语一致性）
- [ ] 是否存在口语化或非学术化表达？

## 维度五：引用与参考文献

- [ ] 文内引用是否存在，格式是否统一？
- [ ] 参考文献列表是否完整？每条是否包含作者、标题、期刊/出版社、年份？
- [ ] 是否存在"该引用但未引用"的明显缺失？
- [ ] 参考文献编号是否与正文中的引用对应？
- [ ] 是否引用了竞争对手或批评者的工作？（学术诚信标志）

## 维度六：逻辑一致性与内部自洽

- [ ] 论文内部是否存在矛盾的主张？
- [ ] 各命题/定理之间是否存在循环依赖或未声明的预设？
- [ ] 数学符号在全文是否一致？
- [ ] 如果有层级结构图或表格，其内容是否与正文一致？
- [ ] 从前提是否能逻辑推出结论？有无推理缺口？

## 维度七：数学正确性与推导严谨性

这一维度检查**数学内容**的正确性，与"维度三：LaTeX 与数学格式"（仅检查排版/转义语法）互补。维度三管公式怎么写，本维度管公式对不对。

- [ ] **推导步骤是否可复现**：每个等式能否从前一步经标准代数/微积分/群论合法推出？有无跳步、漏项或凭空出现的项？
- [ ] **符号与约定是否自洽**：同一 $g$、$\hbar$、$\kappa$ 等符号在全文是否指同一含义？若吸收了物理常数进变量（如把 $g$ 吸收进 $A_\mu$），则场强/展开式的定义是否与整体约定一致，有无前后矛盾？
- [ ] **是否引用标准既有结果且用对**：若引用标准定理（格点规范理论、自旋-统计定理、sine-Gordon 孤子、Bianchi 恒等式），其前提是否满足、结论是否被正确引用且没有断章取义？
- [ ] **物理量的一致性**：公式两侧的量纲/单位应一致；守恒律（份额、能量、电荷、协变守恒）的推导是否来自正确的恒等式？

---

### 第三步：问题分级

将所有发现的问题按严重程度分为三级：

| 级别 | 标签 | 定义 |
|:-----|:-----|:-----|
| **A级** | 严重 | 逻辑断裂、逻辑跳跃、严重矛盾、**循环论证、明显数学错误**（推导不可复现的跳步/漏项、系数与约定整体矛盾、极限退化到错误结果） |
| **B级** | 中等 | 论证不充分、术语不一致、公式渲染崩溃、重要引用缺失、结构缺失（如缺引言/结论）、**局部数学瑕疵**（符号/约定前后不一致、某一步系数漏项但不致整体结论错误） |
| **C级** | 轻微 | 标点问题、轻微语病、格式细节 |

## 给出评审之后

评审报告产出后，询问作者是否需要对某些条目深入探讨，或是否需要转为修改模式逐条修复。在作者明确指示之前，不自行修改论文。

**版本提交约定**：评审报告写入 `评审报告/` 后自动 `git commit`（一篇报告一次提交），无需等待作者指示；`git push` 不自动执行，仅在作者明示"推送"时执行（完整规则见 `D:/software/TianXingFC/AGENTS.md`「git 规范」）。
