# 去 AI 味指南（paper-review 附属）

修改论文时若作者要求或评审指出「AI 味道过重」，在完成 A/B 级问题后、C 级问题之前，专门执行一轮 AI 味清洗。**不删内容，只改表达**：改变「怎么说」，不改变「说什么」；保持学术性、去掉模板感；原文故意使用的排比或文武句不要强行打破。

## 1. 序列词滥用

| AI 味写法 | 去除后 |
|----------|--------|
| "首先，……其次，……最后，……" | 打破序列，改用自然衔接（如"一是……二是……"或直接递进） |
| "第一，……第二，……第三，……" | 仅保留到第二层，第三点融入前文或用"此外"过渡 |
| "主要有以下三个方面" | 直接陈述，不预先宣告 |

## 2. 套话空话

| AI 味写法 | 去除后 |
|----------|--------|
| "值得注意的是，" | 直接陈述事实本身 |
| "需要指出的是，" | 同上 |
| "众所周知，" | 删除或改为具体背景 |
| "不可否认的是，" | 删除 |
| "从某种意义上说，" | 删除或具体化 |
| "在某种程度上，" | 删除或量化 |
| "显而易见，" | 直接陈述 |
| "毋庸置疑，" | 删除 |

## 3. 过度强调词

逐处检查以下词汇，删除或替换一半以上：

- "深刻" → 删或具体化（"深刻影响" → "重塑"）
- "重要" → 保留 1/3，其余删或替换为"关键""核心"等有实际含义的词
- "关键" → 只在真正关键处使用
- "根本" → 只在真正根本处使用
- "极其" → 删
- "十分" → 删
- "非常" → 保留 1/5

## 4. 过度规整的段首句式

扫描全文段首句：

- 如果连续 3 段以上以同一句式开头（如全是"XX是……""XX的……"），打乱节奏
- 将部分段首改为直接设问、引语、数据或短句

## 5. 连接词堆砌

| 过度使用 | 处理方式 |
|----------|---------|
| "然而" | 保留 1/3，其余改为"但""不过"或直接不用 |
| "因此" | 保留 1/3，其余改为"所以""故"或因果关系隐含在句式中 |
| "从而" | 保留 1/3，其余删除或改为"因而" |
| "由此可见" | 删 |
| "基于此" | 改为"由此"或删 |
| "换言之" | 保留 1/2 |

## 6. 句式高度一致

如果连续段落都是"主题句 + 展开句 + 总结句"的三句结构，打破之：

- 部分段落只用一句收束
- 部分段落以反问结尾
- 部分段落插入括号补语或破折号插入语（仅限短插入）
- 部分段落用短句收尾（3-5 字）

## 7. 个性化缺失

一篇有思想深度的论文应当有作者的"声音"：

- 检查是否有独到的比喻、出人意料的类比；如有，保留并突出
- 检查句式是否过于"顺畅"：偶尔的断句、让步、插入语反而更接近人的写作
- 检查是否存在作者个人的学术判断句式（"本文更倾向于……"而非"研究表明……"）

## 清洗后的验证

随机抽 3-5 段读一遍：读起来像人写的吗？有没有觉得"太顺了，不对"的地方？有没有仍然残留的"首先"/"值得注意的是"？
