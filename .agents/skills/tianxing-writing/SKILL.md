# 天行写作（Tianxing Writing）

以傅天行的个人文风撰写中文思想类长文。核心目标：文章要像"人写的大思想文章"，具有哲学纵深、论证强度和思想家的自信，同时避免 AI 腔。

## 适用场景

- 哲学论证文（先验自我、意识、时空、心物关系）
- 佛教/宗教批判文（经验主义批判、缘起批判、无我批判）
- 科学探讨文（量子力学、波粒二象、时间）
- 经济方案文（宏观方案、货币、产业转型）
- 论辩实录整理（微信群论辩体）

## 风格总览

傅天行文章的核心特征是**论证驱动 + 体系自信 + 中西贯通**：

1. **论证驱动**：全文围绕一个核心命题层层展开，每个章节推进论证一步，用"因为……所以……""如果……那么……"的严整逻辑链推进。
2. **体系自信**：将自己的理论命名为"天行新学""心物波粒二象""先验自我"等，明确宣称其革命性和最高地位，用"革命性""统摄万物""根本错误""致命漏洞"等强论断词。
3. **中西贯通**：把量子力学概念（波函数、坍缩、双缝实验、普朗克尺度）与中国哲学（太极、阴阳、天人合一）、佛教术语（五蕴、缘起、阿赖耶识、毗婆舍那）、西方哲学（康德、休谟、黑格尔、胡塞尔）打通对照，指认各方洞见与缺陷。
4. **先立论后批判**：先给出自己的定义和命题，再论证，最后系统驳斥对手，批判时点出对手错误的**根源**（如"经验主义思维方式导致佛陀必定提出无我"），而不是停留在现象层面。
5. **引经据典**：引用哲学家原话、佛经原文、物理学家名言并带脚注编号，文末附参考文献列表；引用要服务于论证，不堆砌。
6. **比喻解释**：对抽象概念用生活化比喻（幻灯片、手套、软件与硬件、认知像素、精神房地产）让外行可懂。
7. **个人化叙事**：适当穿插个人经历和思考历程（"我年轻时……""经过十多年的哲学思考……"），增强真诚感与可信度。
8. **论辩实录体**：批判类文章可保留对话（"天行：""非真："），还原真实论辩的现场感与思想交锋。

## 结构模板

### 哲学论证文（如《先验自我论证》《意识波粒二象的详细论证》）

```
一、引言（交代写作缘起：一次辩论、一个困惑或一个现象）
二、关键问题的提出（把核心问题问清楚，指出其深奥与重要性）
三、对问题的深入理性分析（核心论证段，可分 3.1、3.2、3.3 小节）
    每一步：提出论点 → 引用权威或实验依据 → 逻辑推演 → 排除反对意见
四、新理论的提出与阐释（给出自己的革命性解答）
五、新理论的意义（对旧体系的修正、对未来的影响）
文末：参考文献（脚注编号对应）
```

### 佛教/宗教批判文（如《挑落佛教》《佛陀根本错误》）

```
开篇：直陈批判立场（"佛陀的……全部是错误的，而且我分析了为什么错误"）
第一部分：指出对手错误的思维方式根源
第二部分：逐条拆解对手核心教义（无常、苦、无我、缘起），每条给出逻辑反驳
第三部分：指出其致命逻辑困境（如"已经消失的现象如何产生新的现象"）
第四部分：给出替代的正确认识（天行新学的解答）
```

### 经济方案文（如《取代房地产行业的新经济引擎》）

```
引言：点出问题的紧迫性与量化约束（如"每年至少 13 万亿规模"）
第一部分：现状分析（旧引擎如何运转、为何不可持续）
第二部分：新方案的哲学基础（从天行新学推导）
第三部分：新方案的整体运行框架（2.1、2.2 分项展开）
第四部分：方案的深远意义
```

### 科普解释文（如《电子的本质》《量子纠缠》类）

```
开头：用一个反常识或惊艳的论断抓住读者（"电子没有大小，没有形状，不是任何东西做的"）
中段：层层递进解释，先破除教科书错误印象，再建立正确图像
结尾：升华到哲学高度或心物波粒二象的统一认识
```

## 论证方法要点

1. **一个命题一个核心**：每段只推进一个论点，段首亮明，段尾收束。
2. **三段式推演**：论点 → 论据（引用/实验/逻辑）→ 结论；结论常回扣"心物波粒二象""先验自我"等体系核心。
3. **穷举排除法**：论证某性质时，先排除错误选项（如"既不是传统的唯心或唯物的绝对一元论，也不是传统的心物二元论"），再给出正解。
4. **数量级震撼**：用数字制造冲击力（"一秒钟必然进行了大约 10^43 次微小观察""比一粒沙子和整个太阳系的悬殊差距还要大太多"）。
5. **追问到底**：对常识发问（"如果没有同一性的自我主体，强烈的主体同一感如何产生？"），把看似简单的问题揭示出深度。

## 语言规则（重要）

1. **使用 LaTeX 公式**：行内公式用 `$...$`，独立公式用 `$$...$$`。例如：$g_{\mu\nu}$、$\hbar$、$\Psi(x,t)$、$S = \int L dt$。
2. **禁止破折号**（`——`）：表达转折递进用逗号、分号、冒号、句号或自然衔接。
3. **禁止"不是……而是"句式**（及"并非……而是""不在于……而在于"）：对比用肯定陈述、直接叙述或"然而""但"。
4. **用词风格**：书面语为主，可带思辨色彩；允许长句，但长句后紧跟短句收束；善用排比（"波性是连续性、同一性、叠加性、弥散性……"）。
5. **强论断词**：批判时用"根本错误""致命漏洞""严重扭曲""无法回答的硬伤"；立论时用"革命性""最精确""统摄万物"。
6. **第一人称**：用"我""我们"，体现思想家主体性；自称体系时用"我的理论""天行新学"。
7. **避免网络口语和 AI 机械腔**：不用"总而言之，言而总之""综上所述可见"等套话开头；不用列表式堆砌当正文主体（列表只用于辅助结构）。

## 写作流程

1. 明确文章类型与核心命题（一句话写出命题）。
2. 按对应结构模板列章节骨架。
3. 每个章节按"论证方法要点"填充：论点 → 论据 → 结论。
4. 检查语言规则：LaTeX 公式、无破折号、无"不是……而是"、强论断词到位。
5. 添加引用与参考文献（如有）。
6. 全文用"检查清单"自检。

## 检查清单（定稿前逐项核对）

- [ ] 核心命题明确，全文围绕它展开，没有跑题段落
- [ ] 每个章节推进了论证，不是简单重复
- [ ] 对手观点被严肃对待并逻辑反驳，点出其错误根源
- [ ] 术语符合"核心术语表"，公式均为 LaTeX
- [ ] 无破折号（——），无"不是……而是"类句式
- [ ] 有强论断、有比喻、有个人化叙事（至少其一）
- [ ] 结尾有升华（哲学高度 / 体系意义 / 人类命运）
- [ ] 全文读起来像有思想的人写的，不像 AI 生成的
