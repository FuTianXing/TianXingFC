# wikilink-batch 批量内链化

工作区：天行新学（`D:\software\TianXingFC`，Obsidian 库，约百篇论文正稿在根目录）。四步流程：预检 → 目标解析 → 批量落盘 → 审计。核心原则：**先 find 后写**（任何链接目标先确认真实文件存在再落盘），**编号神圣**（清单条目编号被外部文档引用，绝不重排）。

## 0. 预检

1. `grep -n '^#' <文件>` 看结构；超 30KB 的文件用 bash 分段读（`sed -n '起,止p'`），勿一次整读。
2. `git status --short` 检查目标文件是否正被并行会话在途修改；是则在报告中声明，编辑前重读最新内容。

## 1. 目标解析规则

1. 链接目标写**完整文件名**（不含 `.md`）。文件名含 `——`、全角冒号等特殊字符时原样写入，不必转义。
2. 书名号短引用转 `[[完整文件名|短标题]]`（显示文本保持原引用样貌）；标题即文件名的转 `[[完整文件名]]`。
3. 行内 `§2.3`、`§6.3` 式小节引用：锚点留在链接**外**（`[[全名|短名]]§2.3`），避免指向不存在的小节锚。
4. 唯一性：裸文件名全库必须恰好对应一个文件；重名时用路径限定 `[[目录/文件名|短名]]`。
5. **根目录文件与子目录文件同名**时，根目录版无法用路径前缀消歧（裸名必然歧义）：换链同机制的替代目标，或路径限定子目录版。实例：《离散镶嵌》根目录版与 `内部草稿/` 版同名 → 改链《暗能量的元相子本质》。
6. 落点语义分层：公理级主张链总纲基准（如 `[[公理体系]]`）；机制细节链源论文并注补充注释号（如 `[[元相子几何动力学——束缚振荡修订整合版|元相子几何动力学]]补充注释07`）；一篇文档内多个条目链同一目标是正常的，按内容归属选，不追求目标分散。

## 2. 条目补链（速览/要点类清单）

1. 先扫缺链：逐条检查编号条目是否含 `[[`，列出缺链清单（`scripts/link_audit.py` 的条目覆盖检查可直接给）。
2. 用条目的**独有措辞**做关键词 `grep -l` 定位源文档；命中多个时再看第二特征短语或上下文计数收敛。候选优先级：作者定案 > 定稿论文 > 内部草稿。
3. 已废弃论文不作为正文主张的链接目标，改链继承其定案内容的后继论文；确需引用时注明废弃边界（实例：《有质量粒子的形成》形成方案已废弃、质量机制部分仍为定案）。
4. 追加格式：条目行尾加 `（[[目标|显示]]）`，不改动原文；新条目一律追加到节尾，绝不插入中部重排编号。
5. 每条内容过写作铁律：禁中文 em-dash、禁"不是……而是"及变体、禁"账"字、禁 AI 套话（首先/其次/值得注意的是/众所周知）。

## 3. 批量落盘纪律

1. 多处替换优先用固化脚本 `scripts/batch_link.py`（第 6 节）；脚本覆盖不到的定制替换才现写一次性 Python 脚本：Write 到 `_tools/`（一次性，任务完即删），含中文时禁止 bash 内联 `-c`/heredoc。
2. 替换前 `assert text.count(old) == 期望次数`，计数不符立即报错不落盘；含 LaTeX 反斜杠的模式一律 r-string。
3. 读写都用 `newline=""` 保持原行尾；落盘后核对行数与 CRLF 计数。
4. Edit 工具锚点陷阱：全角标点、弯引号、列表标记双空格（`9.  **`）都会让 old_string 失配——锚点选无标点子串，批量场景干脆走脚本。

## 4. 审计（每轮落盘后必跑）

```
python "C:\Users\Administrator\.agents\skills\wikilink-batch\scripts\link_audit.py" <文件.md>... [--suggest] [--root D:\software\TianXingFC]
```

检查项：wikilink 目标解析（裸名全库唯一 / 路径形式存在）、剩余书名号清单（`--suggest` 附候选文件与重名告警）、wikilink 外 em-dash、禁句式与"账"字、编号条目缺链清单、CRLF 残留。退出码 0 通过 / 1 有硬伤（未解析目标、em-dash、禁词）；剩余《》与缺链条目为 INFO 级，是否处理由任务决定（历史文档的《》引用按规范不强制迁移）。

审计退出码为 0 后，人工抽查 2-3 处修改点（sed 取行核对），再向用户报告。

## 5. 特例速查

| 情形 | 处理 |
|---|---|
| 总纲文件与 wiki 词条同名（螺旋阶梯几何） | `[[理论总纲/螺旋阶梯几何|螺旋阶梯几何]]`；短引用《螺旋阶梯几何》裸名歧义，宁可不链 |
| 根目录与内部草稿同名（离散镶嵌） | 裸名必然歧义：脚本宁可不链；确需链时换链替代目标（实例：改链《暗能量的元相子本质》）或路径限定子目录版 |
| 源论文已废弃（有质量粒子的形成） | 改链继承定案的后继论文；确需引用注明废弃边界 |
| 修订记录历史表述、论文标题内的旧词 | 不改（历史日志与标题原样） |
| 被并行会话在途编辑的文件 | 编辑前重读、锚点最小化、报告中声明在途状态 |

## 6. 批量自动化（batch_link.py）

大范围内链化（整目录逐篇处理）优先用固化脚本，不要每轮现写一次性脚本：

```
python "C:\Users\Administrator\.agents\skills\wikilink-batch\scripts\batch_link.py" \
  --dir 内部草稿 --prefix "注记-,研究方向-,总结报告-" \
  --skip "在途文件1.md,在途文件2.md" --root D:\software\TianXingFC
```

也可直接传文件列表。脚本内置全部解析规则与下述踩坑修正，span 级幂等（重复跑零改动），未解析引用保留原样并打印清单；落盘后仍须按第 4 节跑 `link_audit.py` 审计。

## 7. 踩坑清单（2026-09-12 三轮实战固化，脚本已内置修正）

1. **根目录文件 relpath == 裸名**：用 `inner in relpath集合` 判定命中会绕过重名检查（根目录版与子目录版同名时写出歧义裸链，实例 [[离散镶嵌：…]] 被审计判硬伤）。裸名命中必须查 basename 全库计数恰为 1。
2. **报告类文件名污染短名候选**：`正稿题-评审报告-日期.md`、`…-复审报告-日期.md`、`…_15秒视频动画提示词` 等以正稿题开头的派生文件会挤占前缀候选（实例：《温度的波粒互补定义》《论元相子的螺旋阶梯几何》）。短名前缀候选须排除含 报告词（评审/审查/总结/复审报告）或"提示词"的名字；正文类候选存在但重名时宁可不链；仅派生类命中且唯一才取。
3. **文献条目替换吞分隔符**：正则用 `\.\s*(天行新学)` 捕获时 `. ` 被消费，曾 146 处变成 `]]天行新学`。用零宽断言 `(?=天行新学)` 并显式补回 `". "`；落盘后必须抽查首条文献行。
4. **整文件级"已含 [[ 跳过"漏转残留**：部分内链文件中仍有可解析的书名号引用。转换须 span 级幂等（已转换 span 不再是《》，天然不重入），只跳过并行在途文件。
5. **写法差异归一化**：标题写法与文件名的分隔符差异（`——`/`_`/`-`/`（`/`，` vs `：`）、空格、LaTeX 记号（`$Z_3$` vs `Z₃`、`10^{-17}` vs `10^-17`）都须归一化后再匹配，匹配仍要求全库唯一。
6. **括注与标注剥离**：《题（工作文档，含补充注释…）》、`[M]`/`[J]` 类型标注、`注记：`/`评审报告-` 类前缀（冒号与连字符两种分隔都要认）、冒号前段都应剥离为多个候选形式逐一尝试；未命中再按 `注记-/论文草案-/研究方向-/总结报告-/评审报告-` 前缀补全。
7. **清单文件换行符**：Python 文本模式写清单默认带 `\r`，xargs 按行传参会把 `\r` 拼进路径导致"文件不存在"（105 个路径仅最后 1 个幸免）。写清单用 `newline="\n"`，或 xargs 前 `tr -d '\r'`。
8. **既有坏链勿模仿**：`[[螺旋阶梯几何]]`（裸名歧义）、`[[*]]`（指向 .py 无法解析）是历史遗留，审计会判硬伤，不要复制这种写法。
