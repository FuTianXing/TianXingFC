## 一、口径整理（三段通俗读法）

**相变。** 相变指**同步相变**：相变前相位场各站点按自己的节律自由漂移，彼此耦合把它们逐步带向同一节拍，当"带回"的力量超过"走音"的趋势，系统锁定成一个共同的参考节拍（Kuramoto 型同步）。它在路线甲中的位置：先验纠缠的整体态经同步相变投射为可观测的锁定帧，锁定耦合 $\kappa$ 是这场相变的产物。相变前的那段"自由"正好被借来给绕数分布洗牌；相变后锁定帧成型、绕数身份冻结。消歧：它与副线 P8a 的宇宙学结晶相变（Kibble 机制，算缺陷密度）是尺度与对象都不同的两件事。

**失配。** 失配 $\gamma$ 是相变前各站点固有频率分布的宽度（$\omega_j \sim \mathrm N(0,\gamma)$），即"每只钟走得差多少"的散度，属设定层物理量。它管两件事：其一，能否锁定，门槛带为 $\gamma_c/\kappa = 1.29 \pm 0.10$（约 $0.161$）；其二，锁定前集体相干能维持多久，相干度 $r = \exp(-\gamma^2t^2/2)$、$1/e$ 时间 $\tau = \sqrt2/\gamma$。失配越小，相变前的可用窗口越长。

**窗口 0.0139。** 联合条件 $\gamma \le \sqrt2\,\Gamma\,4\pi/L^2$ 给出的是"均匀化窗口"：失配不超过约 $0.014$ 时，相变前的自由漂移足以把绕数在 $L = 8$ 个扇区间洗匀，标准分支 $\kappa = \sum_W p_W^2 = 1/L$ 方可直接引用；超过它，扇区分布趋于集中，相关读数须按实际分布修正。两条门槛的关系：锁得住约 $16\%$（$0.161$），锁得匀约 $1.4\%$（$0.0139$），后者紧一个量级。窗口属规格线性质的量，随输入修正（带质量分支见 §二 2.4）。

## 二、139 象位核对

**2.1 精确形。** 取 $p = 1/20$、$L = 8$、$v = 1$（长波极限），

$$\gamma_{\max} = \sqrt2\,p\,\frac{4\pi}{L^2} = \frac{\sqrt2\,\pi}{320} = 0.013884009.$$

派生读数：$\gamma_{\max}\times100 = 5\sqrt2\pi/16 = 1.3884009$；$\gamma_{\max}\times10^4 = 138.8401$；$1/\gamma_{\max} = 72.0253$。

**2.2 家族对照。** "139 之象"家族的既有登记：相变常数 $\ln 4 = 1.386294$（收官记录 §五）与元相常数 $\mathcal{D}_p = \ln(1/(3H_0t_P))$，取普朗克 $H_0 = 67.4$ 时 $\mathcal{D}_p \approx 139.00$、取 $H_0 = 70$ 时 $\mathcal{D}_p/100 = 1.39158$（原登记口径）。四点对照（$\times100$ 刻度）：

| 成员 | 值 | 距 $\ln 4$ |
|---|---|---|
| $\ln 4$（相变常数） | $1.386294$ | 基准 |
| 联合条件窗口 $\gamma_{\max}\times100$ | $1.3884009$ | $+0.152\%$ |
| $\mathcal{D}_p\times10^{-2}$（普朗克，$139.00$） | $1.3900$ | $+0.267\%$ |
| $\mathcal{D}_p\times10^{-2}$（$H_0 = 70$，$139.15$） | $1.39158$ | $+0.38\%$（原登记口径） |

按 $\times10^4$ 读法：$138.840$ 距 $139.00$ 差 $0.115\%$、距 $139.15$ 差 $0.223\%$。结论：窗口在 $100$ 倍刻度上比元相常数自身更贴近相变常数（$0.15\%$ 对 $0.38\%$），按 $\times10^4$ 刻度则落在家族带内偏下一位。

**2.3 精确锁定的参数条件。** 窗口与家族成员精确相等所要求的 $p$：

- $\gamma_{\max}\times100 = \ln 4$ 需 $p = 0.049924$（比 $0.05$ 低 $0.152\%$）；
- $\gamma_{\max}\times10^4 = 139.00$ 需 $p = 0.050058$（高 $0.115\%$）；
- $\gamma_{\max}\times10^4 = 139.15$ 需 $p = 0.050112$（高 $0.223\%$）。

三个目标值都落在 $p = 0.05$ 的 $\pm 0.23\%$ 邻域内。故"139"能否从象位升级，系于 $p = 0.05$ 的严格值：它是框架取整值，出处与精度见 §三待决一。

**2.4 三条反证（冷却项）。** 其一，质量分支：代入体系实测两档缺陷质量得 $v = 0.9543$ 与 $0.9515$，窗口收紧为 $0.01325$ 与 $0.01321$，$\times100$ 值 $\approx 1.325$ 与 $1.321$，距 $\ln 4$ 达 $-4.4\%$ 与 $-4.7\%$：象位在该分支上消失，任何解释须先声明它只属于 $v = 1$ 分支。

其二，近合密度校准：$1/\gamma_{\max} = 72.0253$ 与 $72 = 8\times9$ 只差 $0.035\%$，比上面的 $0.15\%$ 更贴；其本源与 $\sqrt2\pi \approx 40/9$（差 $0.035\%$）同宗。可见 $0.0x\%$ 级近合在常数池里并不稀有，精度本身不构成结构证据。

其三，跨域撞串：$0.0139$ 这一数字串在完全无关的读数中也出现过（C1-6 凹口增益 $+0.0139$ 至 $+0.0716$），提示数字表情廉价，须靠机制锁定。

**2.5 层级判定。** 综合：窗口的"139"属**象层级候选**，且是家族内目前距 $\ln 4$ 最近的一员（$0.15\%$，优于既登记的 $0.38\%$）；未达"理"层：没有机制把窗口与 $\ln 4$ 或 $\mathcal{D}_p$ 连接，$p$ 的精度亦未钉死。判定口径与收官记录 §五的诚实边界一致：呼应落在象层，待机制或精度任一到位后再议升格。
