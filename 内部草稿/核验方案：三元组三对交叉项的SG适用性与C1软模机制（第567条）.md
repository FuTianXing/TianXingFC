## 一、问题的重述

第 566 条 B0 判负：三元组异类耦合以相对相位写为
$$H(\psi_1,\psi_2) = \cos\psi_1 + \cos\psi_2 + \cos(\psi_1+\psi_2),$$
含交叉项 $\cos(\psi_1+\psi_2)$，三对不可分离，故「kink 为纯 SG 解」不成立。而第 564 条的 $r \propto m^{-1}$ 以 SG 形式为前提，故该结论是条件性的。

## 二、关键发现：答案已在 C1 线（W4 轮）

侦察发现 **C1-6 W4 轮（2026-09-20 已判，判据 W4-1 至 W4-6 全过）已给出宽度机制**：

| 项 | 读数 |
|---|---|
| 宽度承载者 | **波性侧软模的关联长度**（非 SG kink 势） |
| 关联长度 | $\xi = 1/(2\pi\sqrt{K})$（$\kappa_e = 1$），带隙 $m = 2\pi\sqrt{K}$ |
| 软模色散 | $\omega^2(q) = \kappa_e \cdot 4\sin^2(q/2) + (2\pi)^2 K$ |
| 桥因子 | $l^*/\xi = \pi/\sqrt{3} = 1.8138$（实测 1.7845 至 1.8121） |
| 落窗区 | $K \le 1/48 = 0.02083$，与洛伦兹窗 $K \le 1/(16\pi^2)$ 联立给 $\xi = 2.0000$、$l^* = 3.6276$ |
| 三维复核 | 带隙与轴向、径向衰减率与一维一致（$0.4\%$ 内） |

**这与第 564 条的 SG 路线的关系**：

| 项 | SG 路线（第 564 条） | C1 软模机制（W4 轮） |
|---|---|---|
| 宽度来源 | SG kink 特征宽度 | 软模关联长度 |
| 表达式 | $\xi \propto K^{-1/2}$ | $\xi = 1/(2\pi\sqrt{K})$ |
| **$K$ 的幂** | $1/2$ | $1/2$ |
| 前提 | kink 为纯 SG 解（三对可分离） | 缠绕背景上的软模（**不需要可分离**） |
| 是否受 B0 判负影响 | **受影响** | **不受影响**（软模机制不看三对可分离性） |

**结论**：两条路线给出的 $K$ 的幂**相同**（$1/2$），但 C1 软模机制**不依赖 SG 可分离性**。故第 566 条 B0 判负所否定的只是「SG 路线的前提」，**不是 $r \propto m^{-1}$ 这个结论本身**：：后者可由软模机制独立支撑。

## 三、核验路径（三步）

### 第一步：标度对接（可立即做）

把 W4 轮的 $\xi = 1/(2\pi\sqrt{K})$ 与 M6 字典标度链 $K \propto (m_\delta/m_P)^2$ 对接，得
$$\xi \propto K^{-1/2} \propto (m_\delta/m_P)^{-1} \quad\Rightarrow\quad r(m) \propto m^{-1}.$$

这与第 564 条的结论**数值一致**（幂 $-1$），但依据不同（W4 轮的软模机制，不依赖 SG 可分离性）。**这一步闭合后，第 564 条的条件性标记可撤**，$r \propto m^{-1}$ 转为无条件结论。

### 第二步：SG 适用性的正式定位（B0 的补充）

B0 判负仍是有效的（kink 确非纯 SG 解），但它的后果应改写：**不再说「第 564 条前提不成立」，而说「$r$ 的 SG 路线被软模路线取代，两者幂相同」**。SG 路线保留为「若三对可分离化则另一独立路径」的备选，不作当前依据。

### 第三步：$r(m)$ 与位错宽度的关系澄清（需你定）

$r(m)$（并合轨道半径）与 $\xi$（位错宽度）是**两个不同物理量**：前者是宏观轨道尺度（引力线关心），后者是微观位错宽度（C1 关心）。第一步的对接是**标度类比**（幂相同），**不是说轨道半径等于位错宽度**。若要把两者等同或建立定量关系，需另立判据（属 BH1 与 C1 的接口），本方案不覆盖。

## 四、判据设计

**第一步（标度对接）判据**：
- S1：W4 轮的 $\xi$ 对 $K$ 的幂（解析，$K^{-1/2}$，与 C1-6 已判读数一致）
- S2：$K \propto m_\delta^2$ 的 M6 字典链对接，得 $r \propto m^{-1}$
- S3：两条路线（SG kink 与软模）的幂一致性（$1/2$ 对 $1/2$）
- S4：EP5（若两条路线幂不同则判据须能区分；同值时须以机制而非幂作区分）
- S5：边界标注（$r$ 与 $\xi$ 是不同物理量，标度类比非等同）

**第二步（定位改写）**：属文档层，同步第 566 条注记与轨道尺度计划。

## 五、结论的归属

若第一步闭合，则：

| 项 | 结论 |
|---|---|
| $r(m)$ 的幂 | $m^{-1}$，**无条件**（由 C1 软模机制支撑，不依赖 SG 可分离性） |
| 与 PN 的偏离 | 幂差 2.667（第 566 条 B3 读数）仍成立，但归属裁决可推进：体系幂 $-1$ 对 PN $5/3$，区间不相容 |
| 归属（E-b） | 若 $r \propto m^{-1}$ 无条件成立且不相容，则「体系特有特征」成立（拟议预言条目）；但需先核第三步（$r$ 与 $\xi$ 是否可等同） |
| B0 判负 | 保留（kink 确非纯 SG），但后果改写为「SG 路线被软模路线取代」 |

## 六、风险与不做的事

**风险一**：第一步的对接是标度类比，若 $r$ 与 $\xi$ 无物理关联，则 $r \propto m^{-1}$ 不能借用 $\xi$ 的幂。故第三步（$r$ 与 $\xi$ 的关系）是真问题，本方案只做到「幂相同」这一层，不主张等同。

**风险二**：$r(m)$ 的**绝对尺度**仍未定（$\xi$ 的绝对值有 $K$ 与 $\kappa_e$ 定，$r$ 的绝对值无来源）。这与第 564 条的边界一致。

**不做的事**：一，不重开 SG 路线（幂已被软模路线给出，SG 保留备选）；二，不改 C1 线的既有判据（W4 轮已判 6/6）；三，不在本方案内给 $r$ 与 $\xi$ 的定量关系（属 BH1×C1 接口，需另立）。
