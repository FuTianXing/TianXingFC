## 一、作者口径与它在既有表述中的位置

作者 2026-09-17 给出 $m_P$ 的正面刻画：它是元相子时空晶格能够承受的最大质量，与元相子自身的质量无关。

这条与既有两处表述直接衔接，不引入新参数。

其一，2026-09-05 固化的「引力响应满量程标度」是同一件事的计量学说法：$m_P$ 是 $\delta\theta = m/m_P$ 的归一化常数，$m = m_P$ 时写入达满偏。

其二，2026-09-15 作者裁定的角度映射给出满偏的物理内容：满偏 $180^\circ$ 意味着取向与法线方向彻底反向，时空晶格的结构被破坏，跃迁无法完成，晶格无法正常运行。

两处合起来，今天的口径补上的正是中间那一句。满量程在体系里因此有了物理内容：它就是晶格撑不住的那个点。前一处答「我们这样定义」，这一处答「晶格真的承受不了」，两者是同一个数的两种说法。

## 二、形式化：$\delta\theta$ 是最近邻格点上的载荷读数

这一步不引入新假设，全部是既有定案的代数。

碰撞写入的源强为 $s_{eff} = 4\pi m/m_P$，稳态为离散泊松格林函数，连续形式 $\theta(r) = s_{eff}l_P/(4\pi r)$，即

$$\theta(r) = \frac{m}{m_P}\cdot\frac{l_P}{r}.$$

取 $r = l_P$（晶格允许的最近距离，一个格距）得

$$\theta(l_P) = \frac{m}{m_P} = \delta\theta.$$

**每拍写入幅度恰是最近邻格点上的载荷读数。** 这一步把 $\delta\theta = m/m_P$ 从「归一化」变成「读数」。原来 $m_P$ 只是把 $m$ 归一到 1 的常数，现在它是「最近邻格点读数恰为 1」的那个质量。归一化常数与承载上限在此是同一个数，后者给出物理解释。

满偏条件 $\theta = 1$ 随即给出 $m = m_P$，满偏发生的位置为

$$r = \frac{m}{m_P}l_P = \frac{Gm}{c^2} = \frac{r_s}{2}.$$

对 $m < m_P$，满偏点落在首个格胞内部，没有格点承载该读数，记录被紫外截断吸收，晶格完好。对 $m > m_P$，满偏点外移到格点上，最近邻格点的取向自由度被压到 $180^\circ$（法线轴本身保持笔直），承载失效。$m = m_P$ 是两者的分界。

（等价形式 $\theta(r) = Gm/(c^2r)$ 与时空观 §7 的静态弱场写法一致，此处只做 $l_P = Gm_P/c^2$ 的代换。）

## 三、三个推论

**推论一，归谬论证变锋利。** 2026-09-05 的归谬是：若元相子自带 $m_P$，则每个元相子的史瓦西半径 $2l_P$ 与自身尺度同量级，每格点都是普朗克黑洞。按第二节的读数，同一件事可以不用黑洞语言说：若元相子自带 $m_P$，则每个格点的最近邻读数恒为 1，全空间处处处在承载极限上，晶格无处可运转。

**推论二，引力微弱获得承载力读法。** 已知最重的粒子（顶夸克）约 $1.4\times10^{-17}m_P$，比承载极限低十七个数量级。弱引力即载荷远未接近量程。这一读法与既有的 $\delta\theta \ll 1$ 同义，但它把「为何弱」从「比值小」翻成「离崩溃还远」。

**推论三，视界与满偏分居两层。** N5 史瓦西对齐给出 $\theta(r_s) = 1/2$（视界在半量程），承载失效在 $\theta = 1$，即 $r = r_s/2$，落在视界内部。按弱场外推，晶格破坏不发生在视界处，而发生在更深处。这与「视界是弱场构造的射程边界、黑洞内部是记录饱和区」相容，也与黑洞内部机制注记的破坏图像相容。该点之后记录场的真实行为尚无模型，属强场开放项。

## 四、四处待裁决边界

**边界一，承载对象需要口径。** 第二节的 $\theta(l_P) = m/m_P$ 对局域到格距尺度的质量成立（单个缺陷，或集中在单格胞内的质量）。对延展物体，峰值载荷出现在表面，$\theta(R) = GM/(c^2R)$，与总质量无单调关系，失效条件取决于紧致度。建议口径：承载上限 $m_P$ 适用于局域质量，延展物体的失效条件另用紧致度表述。

**边界二，与坍缩上限 $M_c$ 的分工。** BH4a 给出的 $M_c = C m_P^3/m^2$ 是天体的坍缩上限（引力与量子压缩动能的系数竞争，量级为太阳质量），与 $m_P$ 的格点承载上限分属两个层级，两者相差约四十个数量级。建议术语上分开：$m_P$ 用「承载上限」，$M_c$ 用「坍缩上限」，避免「最大质量」一词两用。

**边界三，障碍一未被本条消解。** 黑洞内部机制注记登记的障碍一（单个格点装不下 $m_P$，需约 $10^{19}$ 个质子、跨越 $10^{19}$ 个格点）在本条口径下反而更突出：阈值锁在单点或单胞，累积读法的数量级难题保持原样。出路甲（区域读法）与出路乙（层数读法）各有代价，仍待裁决。

**边界四，严格程度。** 本条属口径裁定（作者 2026-09-17），够不上定理。第二节的代数链可由既有定案推出，属整理；「承载上限」的物理内容（满偏之后晶格的动力学）尚无模型，依赖强场法线场工具（BH2、BH3）。2026-09-27 更新：作者认可推导层定级（条件性命题级候选），本条第二节的代数链已获反向推导形态（判据 A 支持、命题 B 待判据化），见[[内部草稿/注记-法线场倾角为什么是质量与普朗克质量之比：写入幅度的四条通道|推导层注记]]。
