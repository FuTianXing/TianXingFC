## 一、方案核心

把碰撞写入的引力载体**重读**为法线方向场（法线场）：SO(3) 标架的三根轴 = 局域晶轴（三元组法线方向值）；引力记录 = 质量缺陷造成的层法线静倾角场。**引力扇区的机制、数值、验证按形式原样继承（载体身份从实轴方向标架改为法线方向场，常数重定基等价）；电磁扇区一字不动**。

- **载体**：每个元相子的圆平面法线方向作为波性侧慢场，真空值 = 格键方向（与定理 3.2 在真空层一致）；标架 = 三元组法线方向场。**记录取值空间 = $\mathbb{R}$（法线轴高度差，非紧致裁定锚定）；S² 方向为其几何表述（小角近似：倾角 $\approx$ 高度差$/l_P$）**。裁决点收敛为角记录（$\delta\theta$）与高度差记录的换算（2026-09-10 二次收敛）。
- **动力学**：与碰撞写入完全同构：每拍缺陷注入倾斜 $\delta\theta = m/m_P$（朝源）→ 邻居抄写平均扩散 → 稳态离散泊松格林函数（$1/r$，$4\pi$ 自动涌现）→ 格面 holonomy（"疤定源，场定形"，曲率拓扑性）→ 3+1 时间向（潮汐 $2:-1:-1$、$c$ 前沿、瞬时源决定）。
- **引力专用（2026-09-10 作者指正）**：法线场只承载引力（静倾角 DC 模式，稳态 $1/r$，曲率 = 格面 holonomy）。电磁（波矢、光、静电、规范）留在实轴方向场，不迁入法线场。两场分离：静电场 = 实轴方向场直流模式，引力场 = 法线场直流模式，同场双静态源的分解唯一。
- **定名**（作者 2026-09-10 选定）：**法线场**（精确形式：**法向量场**，依《螺旋阶梯几何》§2.1 区分：法向量 = 自由向量，法线 = 锚定直线）。几何层 = 法线（锚定不动，摆程轴），波性侧 = 法向量场（自由倾斜）。

## 二、为什么数学上成立（接力困境不出现）

1. 标架场是 SO(3) 值场。"面内标记"读法与"法线方向"读法相差一个**常数重定基**（纯规范），holonomy 被共轭，物理不变量全同。所以"一字不改"在数学上为真。
2. 与弯曲晶格路线的本质区别：弯曲晶格动几何（冲突 3.4 刚性格点立即复活）；重读只动解释，**几何层零接触**（摆程、格距、圆心、碰撞日历一字未动）。
3. 接力困境（圆心错开）不出现的原因：偏转住在**波性侧数据层**，像实轴方向 $\alpha$ 一样只作场量、不反作用摆程（注释 08：格点不限制实轴方向取值；注释 09 方向归波背书）。几何法线锁格键（定理 3.2 真空层），波性侧法线方向值自由。

## 三、收益

1. **观感**：引力 = 空间轴静倾角，GR 式图像恢复；"引力变成相位偏转"的违和感消失。
2. **非紧致裁定兼容（硬技术收益）**：$1/r$ 势是要累积的记录，载体必须非紧致。面内标记 $\alpha \in S^1$ 紧致（表盘角度会绕回）；法线轴 = 非紧致、物理真实（总结报告-螺旋阶梯几何：$\mathbb{R}$ = 法线轴）；且与质量机制同族（绑定能 = 法线轴高度差的非紧致平方型，2026-09-06 作者裁定）。
3. **消解潜伏矛盾**：方向 6 二·五节"$\alpha$ 描述圆平面朝哪"与"$\alpha$ 是面内实轴方向"两处表述不一致；按"轴"读，矛盾消解，真空标架 = 晶轴字面成立。
4. **定位线字面兑现**："三种基本力 = 相位场（内部）曲率，引力 = 法线场（外部）曲率"（注释十）：引力回到定位线原本分配的那个场。
5. **开放问题表述自然化**："倾斜方向结构（$\alpha$ 组组合偏转的吸引性指向来源）"变为"轴朝源倾斜"一句话规则（机制本身仍待形式化，不因重读闭合）。

## 四、五条限定与裁决点

1. **不能逐元相子读成"实轴 = 法线"**：几何上实轴在平面内、法线垂直平面，二者恒垂直。重读是标架级改判 + 常数重定基（纯规范），需显式写清。
2. **自由度审查（替代原"术语退役"项，2026-09-10 修订）**：每元相子波性侧方向自由度从 1 个（$\alpha$）变为 3 个（法线方向 2 + $\alpha$ 1）。需论证为激活既有姿态自由度（平面朝向 + 面内标记 = SO(3) 姿态，法线锚定冻结的前 2 个），而非引入新实体；并核对与注释 03 手性守恒（旋向 $\varepsilon$ 为几何常数，倾斜不改变手性）及注释 04 节律约束（管 $\theta$，管不到 $\mathbf{n}$）的相容性。$\alpha$ 的电磁角色原样保留，无术语退役问题。
3. **电磁不迁入法线场（2026-09-10 作者指正）**：电磁扇区（波矢、光、静电、规范）留在实轴方向场，《实轴方向场与规范结构的涌现》、麦克斯韦推导链、P4-8、注释 08 全部不动，零重推导。"内外"定位线自然恢复：三种基本力 = 相位场（内部）曲率，引力 = 法线场（外部）曲率。原"DC/AC 同场分频"表述退役：引力静倾角与光同场会造成角色过载搬家，且 DC/AC 管不住静电场与引力场同为直流的区分；两场分离后分解唯一。
4. **两条记录补注**：2026-09-09 定案"波性侧实轴方向场直流模式，法线锚定不动"补两层读法（几何层锚定不动；波性侧方向场自由）；2026-09-05 撤回记录补注（撤回的是几何轴向调整机制；波性侧场量不冲突；"轴向调整机制不存在"在几何层仍然成立）。
5. **定理 3.2 重释（唯一实质裁决点）**：跃迁沿几何法线（真空层恒成立）；波性侧法线方向场倾斜不反作用摆程。与定案"物质不影响摆程怎么走"相容。

**第六条限定（倾角是取向自由度，不是法线偏转，2026-09-15 作者澄清）**：法线倾角是挂在法线上的一个附加取向自由度，**不改变法线本身的方向**。法线轴（推进方向）始终笔直，倾角只改变挂在其上的取向取值；这与本注记第一节「记录取值空间 = $\mathbb{R}$（法线轴高度差）」的表述一致，此处补的是它的反向限定。

**类比（作者给出）**：一列直线行驶的火车，轨道笔直，驾驶员的头可以偏转向不同方向；质量让头偏离，火车照常直线行驶。

**为什么这条区分是结构性的**：碰撞接力沿法线轴逐格推进，依赖的是相邻格点的法线关系。若把倾角读成法线本身的偏转，则每写一笔推进方向即变，碰撞日历随之错位，零接触与几何层刚性同时失守。**这条区分因此是「几何层零接触」的结构根据**：记录与推进方向住在不同的量上，谈不上"约定它们互不影响"。

## 五、并行线总结收敛（弯曲语义转移）

- **弯曲的从晶格换成记录场（法线场）**：晶格 = 笔直底层脚手架（相当于坐标网格），弯曲住在脚手架上的方向标签场里。合法，因为曲率本是关于尺、钟、自由粒子的行为（度规），与坐标网格直不直无关。
- **合法性条件**：记录场（法线场）接管全部物理测量的几何（尺、钟、粒子、光的偏折都响应它），否则退化为"场论意义上的力"，配不上"弯曲空间"。
- **耦合双向性（2026-09-10 讨论补充）**：载体分离不等于动力学解耦。两场分离限定源与内在动力学的载体；响应与反馈经度规双向耦合。响应侧：光（实轴方向场波）的传播方程升级为法线场度规下的协变波动方程，光偏折 = α 场波在法线场几何中的零测地线传播。反馈侧：光能量-动量经 $T_{\mu\nu}$ 微观分解成为法线场源（张量桥 d 段）；若只有响应无反馈，则光子气体不弯曲时空、双光束无引力吸引，与广义相对论定量偏离。"写源"因此必须从质量（缺陷绑定能）推广到全部能量-动量张量，这是 P1-24 与张量桥 d 的共同交付物。
- **耦合的微观形态与口径澄清（2026-09-10 补充）**：响应侧微机制两条等价表述：其一，波矢平行输运：法线场倾斜定义局域标架（SO(3) 联络），光波矢（实轴指向差的梯度）在传播中按联络平行输运，波矢旋转即光线弯曲；其二，局域钟率调制：时间向记录（$h_{00} = 2\Phi/c^2$）调制局域钟率，光的坐标速度在势阱中变化、波前横向倾斜，弱场偏折角 $\sim \int\nabla\Phi\,dt$，对账目标为太阳偏折 1.75"。二者与"零测地线传播"（上条响应侧）等价；光偏折即判据 B（平行输运测地线）在无质量波上的检验。口径澄清：与后果 2"无引力反向写入实轴方向场"相容，两通道分属不同层：α 场始终不被引力写入（两场无源项混合）；光子能量经 $T_{\mu\nu}$ 写入法线场是引力扇区源项推广（张量桥 d），不是跨场写入。
- **现状：方向对、定量未闭合**。钟慢 $h_{00}$ 为记录二阶差分（代理假设，显式 4D 链接合成待做）；粒子测地响应为 1D 转换波玩具级 O(1) 闭环，未升级到背景场几何；度规定义级（$g = \eta + \langle\delta\theta\delta\theta\rangle\,\partial_\mu\partial_\nu f(E)$，$f$ 未指定）；光偏折 = 无质量粒子机制待攻（P1-24）；爱因斯坦方程与引力波（P1-5）= 承重墙未盖完。蓝图 = 张量桥四分段（分段 a/b 攻坚计划注记已有；《爱因斯坦场方程的微观根基》P3 降级并随张量桥重写）。

## 七、两线评估并表（2026-09-10 二次收敛）

### 优势（并表十条，结构性四条）

1. **角色过载彻底消解**：两场分离，静电场（实轴方向场直流）与引力场（法线场直流）同为直流却分属两场，唯一分解问题不再存在。"角色过载只是搬家"的批评被结构性关闭。
2. **光的耗散豁免问题结构性关闭**：碰撞写入的开放问题（抄写平均对长波 $\propto k^2$ 的衰减豁免机制）随两场分离消失：抄写平均扩散随引力搬进法线场，实轴方向场只剩保差接力的采样抄写（波矢 = 指向差原样保留），豁免不再需要。
