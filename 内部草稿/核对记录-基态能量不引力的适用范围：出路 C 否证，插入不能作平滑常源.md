## 一、三处基准表述的原文

**时空观 §7**（两处相邻）：其一，引力源是拓扑缺陷绑定能（质量机制定案），元相子基态 $m = 0$，以 $\omega_P$ 全体同步旋转，不产生弯曲；$m_P$ 只作为 $\delta\theta = m/m_P$ 的归一化常数出现。其二，由此显式化隐含立场：基态能量不作为引力源，元相子基模能量 $E_\Phi = \hbar\omega_P = E_P$ 是时空结构的刚度能量，不进入 $\delta\theta$ 的分子 $m$；只有缺陷能差产生引力，这为真空能灾难提供消解方向。

**元相方程 §5.3**：元相子基态 $m = 0$，其普朗克能量不作为引力源，引力源仅为缺陷能差。

**术语表**：条目只写 $m_P$ 的两重身份（引力响应的满量程标度兼晶格承载上限），**未载**「基态能量不作为引力源」这一句。

## 二、适用范围判定

三处原文的划界方式是**按能量种类**：基态能量（刚度能量）不进入 $\delta\theta$ 的分子，只有**缺陷能差**产生引力。原文没有任何一处把该限制写成时间性条款或事件性条款（例如只约束既有格点），故新增格点携带的仍是基态能量，同样不产生引力。**出路 C 的期望口子不存在，C 否证。**

副产物一处登记订正：`P4-24⑦` 把术语表列为该原则的固化处之一，而术语表实际只载 $m_P$ 的两重身份，未载该原则。登记过宽，建议按此订正。

## 三、连带：出路 A 的两种形态各堵一处

**形态一（份额型）**：若插入释放的是序参量份额（相干份额），它不是缺陷能差，按上述划界同样不产生引力，故不能作源。

**形态二（缺陷型）**：若插入同时产生缺陷、使缺陷能量密度维持常量，则该密度是物质型密度，会随膨胀稀释，要靠持续补充才恒定；而持续补充即稳态物质创生，观测排除。若只补不加（不维持常量），则不构成常量源。

还有一处更硬的结构限制：$\delta\theta$ 的引力效应来自它的**梯度**（框架的静态解形如 $\theta(r) \propto m/r$）。空间均匀的插入只给均匀偏置，均匀偏置不产生曲率。故平滑的插入在几何侧本就没有引力效应，这与「暗能量均匀、不聚团」的观测特征是同一件事的两面：均匀所以无梯度，无梯度所以不弯曲。

## 四、结论

出路 C 否证；出路 A 的两种形态各有一处致命处；出路 B（插入是响应，暗能量另找承担者）是三者中唯一没有立刻致命伤的一条。

由此得一条更重的判断：**框架目前没有产生平滑常量引力源的机制**。引力源在体系内被唯一地限定为缺陷能差，而缺陷是局域对象；平滑恒定的能量密度既不属缺陷能差，均匀分布又不产生梯度，故无源可给。$\Lambda$ 因此应当与 $\hbar$、$c$、$G$ 同列，按 `P4-28` 的格式登记为理论输入（其数值与组分比例在暗能量论文 §五 已自认为观测输入）。
