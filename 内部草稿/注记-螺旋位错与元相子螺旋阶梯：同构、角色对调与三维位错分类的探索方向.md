## 二、材料科学的位错分类：判据与几何

晶体位错按 Burgers 矢量 $\mathbf{b}$ 与位错线方向 $\mathbf{t}$ 的夹角分类：

| 类型 | 判据 | 几何形象 |
|---|---|---|
| 刃型（edge） | $\mathbf{b} \perp \mathbf{t}$ | 多出半个原子面插在晶体里 |
| 螺型（screw） | $\mathbf{b} \parallel \mathbf{t}$ | 原子面绕位错线呈螺旋坡道，沿线走一圈升高一个 $|\mathbf{b}|$ |
| 混合型 | 一般夹角 | 刃型与螺型分量的叠加 |

螺型位错的标志性几何：沿位错线作闭合回路，原子面不回到原层，升高一个 Burgers 矢量。位错线本身是原子面的台阶线。判别统一用 Burgers 回路：绕位错线一圈，回路不闭合，差矢量为 $\mathbf{b}$。

## 三、三重关系

### 3.1 形式同构：绕一圈升一层

螺型位错的本质几何是"绕一圈升一层"。元相子理论的螺旋阶梯几何（$S^1 \times \mathbb{R}$，满周闭合沿法线轴平移 $l_P$，层数 = 距离，$x^a = l_P n^a$）是同一个数学结构。均匀缠绕背景（逐键一层）在形态上就是一张铺满全空间的螺型坡道面：每一对相邻元相子沿法线轴相差一层，等价于处处处于"绕一圈升一层"的坡道上。

形式同构的具体对照：

| 螺型位错理论 | 元相子理论 |
|---|---|
| 绕位错线一圈升高 $|\mathbf{b}|$ | 满周闭合沿法线轴平移 $l_P$（法线跃迁） |
| 螺旋坡道（原子面） | 均匀缠绕背景（$S^1 \times \mathbb{R}$ 螺旋真空） |
| 台阶线（位错线） | 层数突变的边界（待构造，见 D3） |
| Burgers 矢量 | 层差（$l_P$ 整数倍） |

### 3.2 角色对调：缺陷与基态的互换

这是体系独有的关系。材料科学中，螺旋坡道是缺陷，是晶体的不整齐，晶体学把原子面拧成坡道需要能量。元相子理论中，螺旋坡道（均匀缠绕背景）是真空基态，是整张螺旋阶梯阵的正常状态，粒子反而是坡道上的局部异常（复合位错 = 背景上多出一层）。

角色对调得以成立的关键是非紧致裁定（2026-09-06 作者裁定：键弹性原始形式 = 法线轴高度差，非紧致）。材料学的螺旋坡道可以松弛掉（位错湮灭），元相子理论的螺旋爬升是真实的空间累积，藏无可藏。同一个几何对象，一个体系把它当瑕疵，另一个体系把它当地板。

### 3.3 工具遗产：成熟数学可搬运

螺型位错理论有成熟数学：Burgers 矢量守恒（位错反应 $\mathbf{b}_1 + \mathbf{b}_2 = \mathbf{b}_3$）、Frank 能量规则（能量 $\propto |\mathbf{b}|^2$）、Peierls 势垒、滑移与攀移运动学。体系内已经借用其中一部分：晶格位错网络节点处 Burgers 矢量守恒 $\mathbf{b}_1 + \mathbf{b}_2 + \mathbf{b}_3 = 0$（三重结）、"位错滑移承载运动"候选、Peierls 势垒（惯性门槛，锚核 PN 代理）。未被开发的遗产：Frank 规则与绑定能的对应对、交叉滑移（螺型位错滑移面不唯一）与粒子运动通道的对应。

## 四、标准理论中螺型位错对应的物理现象（背景综述）

本节为材料学与凝聚态物理的既有事实综述，供形式同构（3.1）与工具遗产（3.3）溯源，不属体系内结论。按四组整理。

### 4.1 晶体生长的螺旋台阶（BCF 理论）

螺型位错最标志性的效应。理想晶面生长新原子层需二维成核（先聚出原子岛，后续原子才能接到岛边缘），所需过饱和度高。Burton-Cabrera-Frank 于 1951 年建立的理论（BCF 理论）指出：螺型位错露头到表面的地方天然提供永不消失的台阶，原子落在台阶上把台阶绕露头点向前推，每转一圈晶体升高一个 Burgers 矢量，表面长出金字塔状生长螺旋（阿基米德螺线形生长丘），生长所需过饱和度降低数个量级。1950 年代起在 SiC、石蜡、碘化镉、云母表面直接观察到生长螺旋，是位错理论最早的直接证据之一。现代延伸：石墨烯在铜箔上的生长常以螺位错露头为成核源；SiC 单晶的微管缺陷是大 Burgers 矢量螺位错（Frank 能量规则 $E \propto |\mathbf{b}|^2$ 下矢量大到挖空核心反而省能量，形成贯穿晶体的空心管），为碳化硅功率器件工艺的著名难题。本注记 3.1 的"绕一圈升一层"同构，其材料学现成标本即生长螺旋。

### 4.2 塑性变形的微观载体

晶体塑性变形靠位错滑移，金属可拉丝轧板而不断裂的根源是有位错可动。螺型位错承担其中三个标志性角色：其一，交叉滑移：刃型位错被锁在特定滑移面，螺型位错 $\mathbf{b} \parallel \mathbf{t}$ 使任何含位错线的晶面都可为滑移面，可中途换面；观测对应为退火金属滑移线平直、冷加工金属滑移带呈波状（波状即螺位错反复交叉滑移的痕迹），高温蠕变的动态回复（异号螺位错经交叉滑移相遇湮灭）亦由它承担。其二，体心立方金属的低温脆性：铁、钨等 bcc 金属螺位错核心为三维紧缩结构，Peierls 势垒高，低温下移动阻力骤增，屈服应力随降温快速上升，这是 bcc 金属低温变脆的微观根源。其三，加工硬化：位错互相缠结、增殖（Frank-Read 源），螺位错上生成割阶时留下点缺陷，是金属越敲越硬的微观机制。体系内对应：交叉滑移即 D6 的候选通道（粒子改变运动方向），Peierls 势垒已借为惯性门槛（锚核 PN 代理，见 3.3）。

### 4.3 弹性场与几何身份

螺位错位移场 $u_z = \frac{b}{2\pi}\theta$ 为绕线多值的角度函数：绕位错线一圈位移差恰为 $b$，晶体局域形状近似螺旋面（helicoid，微分几何中的极小曲面）。应力场为纯剪切，无静水分量，故与正应力场及靠尺寸效应聚集的溶质原子交互弱；单位长度能量约为刃型的四分之三（$E_{\text{screw}} \approx \frac{3}{4}E_{\text{edge}}$）。绕线闭合回路差出一个 $\mathbf{b}$ 的 Burgers 回路判据是所有位错的拓扑身份证。体系内对应：位移场的绕线多值与 $S^1 \times \mathbb{R}$ 的多值结构同族（3.1），能量各向异性数值（3/4 比）可作 D4（Frank 规则与绑定能对应）的定量参照。

### 4.4 量子化涡旋家族：同一数学结构的其他实现

螺位错在数学上是"序参量场绕线多值"的拓扑缺陷，同一类结构以量子化涡旋身份出现于凝聚态与宇宙学：超流氦涡旋线（环量量子化 $\oint \mathbf{v}\cdot d\mathbf{l} = h/m$）、超导 Abrikosov 磁通涡旋（磁通量子化 $\Phi_0 = h/2e$）、液晶螺位错（近晶相与胆甾相；TGB 扭转晶界相被明确构造为螺位错阵列与超导涡旋格子的对应物）、宇宙学 Kibble 机制相变产生的宇宙弦。它们与螺位错共享同一套数学：相场绕线一圈差一个量子，缺陷线拓扑保护，不能连续消掉，只能成对湮灭或终止于边界。体系内对应：绕数超选择的成对湮灭约束（排除链中孤立疤的对偶反绕数强制成对）与此家族的守恒机制同构；超导涡旋钉扎于位错处已是缺陷网络钉扎方案的先例来源。

## 五、体系内现状盘点

1. **晶格位错网络 = 刃型版本**。注记《缺陷网络钉扎方案》已明确认定："多出来的半排砖" = 相遇处格点序列的错排线，根源是两波前格点坐标系的平移失配，Burgers 回路差一个整数格矢。这是刃型位错的元相子版本。
2. **复合位错的型别归属未裁决**。法线轴位错（均匀缠绕背景上局部多出一层）在形态上接近刃型的"多余半排面"，但背景本身是螺型坡道铺满，粒子位错与背景坡道的型别关系未澄清。
3. **遗留严格化登记**。注记《缺陷网络钉扎方案》遗留项原文："三维推广（刃型/螺型/混合位错在同相泡图景下的几何，未构造）。"
4. **C1 攻坚登记**。开放问题总览 P1 区 C1（三维复合位错的形态与稳定性：法线轴位错在 3D 的闭合形态（环/畴壁/点）及其 Derrick 复查）已立项，形态枚举尚未区分刃/螺/混合。

## 六、双层统一假设：粒性刃型 = 螺型台阶线的物理空间投影

2026-09-06 位错问题深化讨论（作者提问：晶格位错网络是否在粒性侧为刃型位错、在波性侧为螺旋位错，且螺旋位错属于状态空间而非物理空间）后确立的假设，重要级。

### 6.1 假设陈述

晶格位错网络的双层读法：粒性侧（物理空间格点序列）为刃型位错，螺型几何的唯一住所是状态空间（$S^1 \times \mathbb{R}$ 螺旋真空），物理空间中不存在独立的螺型缺陷。强形式：粒性刃型位错是状态空间螺型台阶线（层数突变边界）的物理空间投影。

### 6.2 三环核验

1. **粒性侧刃型**：注记《缺陷网络钉扎方案》已认定："多出来的半排砖" = 格点序列错排，位错属性定义落在粒性侧，相位失配是伴随的波性后果。
2. **螺型几何住状态空间**：均匀缠绕背景 = $S^1 \times \mathbb{R}$ 螺旋真空，沿物理空间走一格、状态空间层数加一；理论总纲明令区分状态空间与物理空间（[[元相子理论的时空观：体系对时空的完整认识|元相子理论的时空观]]：状态空间几何演化无物理信号传递，混淆两个空间是体系明令避免的错误）。
3. **状态空间螺旋生成物理空间**：均匀缠绕背景就是空间格距结构本身（"螺旋的台阶铺成的格点阵"，[[从复合位错到爱因斯坦场方程：粒子机制现状综合与攻坚纲领|从复合位错到爱因斯坦场方程]]2.1），层数 = 距离（距离归粒定案 $x^a = l_P n^a$）。

### 6.3 两处精确化

1. **螺型是状态空间中的波粒耦合结构**。螺型几何 = $S^1$（旋转）与 $\mathbb{R}$（平移）的锁定耦合：转一圈、升一层，两者缺一不可。按"距离归粒、方向归波"分层：$S^1$ 部分归波，$\mathbb{R}$ 的层数部分归粒。螺型属于状态空间成立，纯波性侧归属需要修正：它是波粒耦合结构，与心物双螺旋（实轴物螺旋 + 虚轴心螺旋，相位差恒 $\pi/2$）同构。
2. **螺型与物理空间的关系比"不属于"更紧**。螺旋结构生成物理空间（6.2 第 3 环），层数突变投影到物理空间 = 格距异常 = 半排错位。准确表述：螺型几何是状态空间结构，它生成物理空间；物理空间中的缺陷是层数分布的错排，即刃型。

### 6.4 推论

物理空间只有刃型：螺型的层数突变落进物理空间就是半排错位；状态空间只有螺旋背景与它的局部异常（法线轴位错）。两层各有一种位错，同一个层数结构在两个空间里的两种读法。此推论与"距离归粒、方向归波"分层相容，并给出 D3 的候选答案：螺型台阶线的物理空间投影 = 刃型错排线。

### 6.5 严格程度

纲领性假设：三环核验基于既有定案（刃型认定、状态空间修正、距离归粒），投影关系本身未建模、未数值验证。

## 七、探索方向清单

以下全部为纲领性主张，未建模、未数值验证。按优先级排列。

### D1：均匀缠绕背景的螺型读法严格化

论证"背景 = 螺型坡道铺满全空间"的严格形式：对均匀缠绕背景作 Burgers 回路，证明每键一层等价于处处螺型坡道，螺旋阶梯几何的 $S^1 \times \mathbb{R}$ 与螺型位错面的数学同构（是否正是同一个流形结构）。判据：背景的 Burgers 回路闭合性分析 + 与法线跃迁定案的衔接。

### D2：复合位错的型别归属裁决

法线轴位错（多出一层）属于刃型、螺型还是混合型？多出的半层若集中在局域，形态接近刃型（多余半排面）；若层数突变线沿某方向延伸，接近螺型台阶线。裁决需要把复合位错的"额外一层集中于邻域"写进 Burgers 回路的元相子版本。此裁决直接影响 C1 三维形态枚举的分类框架。

### D3：螺型位错线的元相子构造

螺型位错线 = 台阶线 = 层数突变线。在 $S^1 \times \mathbb{R}$ 中层数差 1 的边界对应什么结构？候选答案（第六节双层统一假设）：台阶线的物理空间投影 = 刃型错排线，物理空间无需独立构造螺型缺陷；状态空间内台阶线对应结构仍需构造：反相壁（同相泡边界）、绕数缺陷线、法线轴位错的线状形态三候选。与反相泡图景（位错核心 = 局域同相区）的衔接：螺型核心的几何与刃型核心（半排砖）是否同构。

### D4：Frank 规则与绑定能的对应

材料学中位错能量 $\propto |\mathbf{b}|^2$（Frank 规则），元相子图景中绑定能 = 质量 = 缺陷刚度特征频率 $\omega_0 \sim \sqrt{\kappa_\phi}$ 定标。两者的对应关系：Burgers 矢量大小（层差数）与绑定能的标度律，是否给出质量对层差的依赖。若成立，位错反应（Burgers 守恒）给出粒子过程（电荷/质量守恒）的几何版本。

### D5：位错反应与粒子过程的类比

位错合并/分解（$\mathbf{b}_1 + \mathbf{b}_2 = \mathbf{b}_3$）对应粒子散射/衰变过程。Burgers 守恒对应拓扑荷守恒。此类比若成立，粒子反应道的选择规则可从位错反应几何读出。注意：此方向风险最高，位错反应是材料学中的静态几何约束，粒子反应是动力学过程，类比跨度大。

### D6：交叉滑移与转换波通道

螺型位错的滑移面不唯一（交叉滑移），对应粒子运动机制（转换波）的新通道？转换波 = 边界层逐格传播（换装前进），螺型位错的交叉滑移若存在元相子对应，可能给出粒子改变运动方向的机制。与锁定身份迁移方案（2026-08-13）的衔接。

### D7：与 C1 的衔接

## 八、严格程度声明
