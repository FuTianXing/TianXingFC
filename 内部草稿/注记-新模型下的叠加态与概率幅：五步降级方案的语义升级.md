## 一、背景：旧方案的硬核与三个自登记薄弱点

旧方案的硬核是两条恒等式。质量恒等式：旋转波分解后的动能系数组合 $\hbar c^2/2\omega_0$ 恒等于 $\hbar^2/2m$，质量 $m = \hbar\omega_0/c^2$ 与缺陷绑定能同义。份额恒等式：概率幅定义为系综份额的振幅开方 $c_a = \sqrt{N_a/N}\,e^{i\tilde\Phi_a}$，模方 $|c_a|^2 = N_a/N$，归一化无条件成立。加上快照抄写（测量采样）与人数守恒（幺正），五项公设全部接到束缚振荡晶格。

总结论文自登记的三个薄弱点：坍缩的动力学机制待形式化；单系统概率的采样语义停在纲领层；本体叠加与现象分立的二分（注释22）没有物理载具。**位置叠加态恰好同时踩在这三点上**：一个粒子的位置叠加，叠加的主体是谁、位置基从哪来、叠加与测量的边界在哪，旧方案均无机制级回答。

## 二、新模型的四个改进

### 2.1 位置基的出身落地

键弹性原始形式经作者裁定为法线轴高度差（非紧致，平方型），ℝ = 法线轴：满周闭合沿法线平移 $l_P$，层数 = 距离（$x^a = l_P n^a$，距离归粒）。位置本征态由此获得物侧形态：法线轴的层位构型（额外一层停留在第 $n$ 层）。位置基不再是外加的格点编号，而是场的自身结构；离散性与紫外正则的出身从晶格假设升级为距离归粒定案。

### 2.2 幅值有了可操作的载具

纠缠侧承载探路之后，波性侧幅值不再抽象：toric code 层的基态本身就是构型的等权叠加（弦网凝聚的字面结构），叠加与干涉是该层的原生语法。更关键的是经典化丢保护的数值结论：经典层绕数照样衰变，量子相干才能守恒。这把注释22 的二分从哲学立场变为两侧均有数值身份的分工：**幅值住波性侧（先验纠缠、相干叠加），层位住粒性侧（法线轴台阶、分立事实）**。

### 2.3 叠加的合法边界第一次被推导

扇区守卫给出电荷超选择规则：跨扇区算符是弦算符，不在局域生成元闭包内。推论：**同电荷的位置叠加态可以自由相干，不同电荷的态之间不能建立相干叠加**。标准量子力学中电荷超选择是一条插入的经验规则；五步降级的八项困境清单不含此项。新模型把它从守卫层结构推导出来，位置叠加态的合法范围由此有了来源。

### 2.4 叠加主体的本体答案

位置叠加的旧痛点是物质的粒子如何同时在两处。新模型中粒子 = 背景上的位错（图案），材料元相子原地不动：**叠加的是波性侧的幅值分布（位错位置的相干和），粒性侧的层位占据在测量时才定案**。双缝图像顺理成章：转换波携幅值过双缝（波性侧分波相干），探测时锚定凝固（粒性侧定案），电荷全程被扇区守卫看管。凝固的机制候选同步落地：碰撞接力（背景逐拍采样）与插入再锚定判据，快照抄写从纲领层词汇变为有力学候选的流程。

## 三、被加强的旧闭环

质量恒等式：旧方案为代数同义（色散能隙与绑定能），新模型给出数值出身：绑定能 = 复合位错锚核的实际数值（$\kappa_\varphi = 0.5/1/2$ 时 $E_B = 3.13/121.9/359.4$，标度已验证），薛定谔方程的质量参数站在实测过的绑定能上。色散：位错的相对论性色散三层面（能量弯曲、动量塌缩、洛伦兹不变量）已机器验证，薛定谔方程的长波极限现在站在一条实测色散关系上。份额恒等式与人数守恒不变（系综语法与新模型正交）。

## 五、剩余缺口与接续攻坚

其一，**幅值到层位的构造**：toric code 键变量幅值到位错位置基的映射未建（位错激发谱与宽度谱，对应已登记的 C4 类任务），这是把本注记的语义升级变成可算对象的关键一步。其二，凝固动力学：波性侧相干丢失与粒性侧锚定的完整形式化待做。其三，单系统 Born 采样：份额恒等式给出系综语义，单系统采样仍纲领层。其四，三维连续极限：toric code 层为二维小系统，向三维螺旋格点的推广未做。其五，先验纠缠到格点键的严格映射（O1）依旧是最深的洞，幅值载具的体系级身份系于此。
