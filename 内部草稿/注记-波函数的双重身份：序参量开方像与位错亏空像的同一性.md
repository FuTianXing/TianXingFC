## 一、层级对照表（任务 3-2）

| 层级 | 表述 | 承担职能 |
|---|---|---|
| 系综层（定案） | 波函数 = 全体元相子序参量的开方像：$\Psi = \frac{1}{N}\sum_i e^{i\theta_i}$ | 概率的数值来源（份额恒等式 $|c_a|^2 = N_a/N$） |
| 单粒子层（M5 推广） | 位错波函数 = 背景序参量局域亏空的开方像：$c_n = \sqrt{W_n}\,e^{i\Phi_n}$，$W_n$ 为归一化亏空深度 | 叠加的内容（位置相干和） |
| 衔接命题 | 背景 = 系综的局域化（序参量场的空间不均匀分布） | 两层表述的同一性论证对象 |

对照表的要点：两表述分属不同层级，承担不同职能，同一性论证的任务是建立衔接命题，而非把两个表述强行合并成一句话。

## 二、同一性推导链（逐步标注）

**第一步，局域化步（闭合，定义级）。** 把 P7 的全局平均窗口化：$w_n$ 为第 $n$ 层邻域的局域序参量。这是 M5 已实现的计算对象；均匀缠绕链上 $w_n$ 恒一，与全局 $\Psi$ 完全一致（基线 $|\Psi| = 1$、$\sum\delta_n = 0$，K1）。局域化步的意义：背景场就是系综平均的逐层版本，衔接命题的前半句由此获得可计算形态。

**第二步，亏空步（闭合，定义级加数值级）。** 位错占据的表现是局域相干亏空：$\delta_n = 1 - |w_n|$。纲领预估的未闭合环节"背景场如何减去位错占据"在此闭合：位错占据的到场方式是背景局域相干被位错转移走的份额；M5 确认两个一致代理（亏空深度与滑量密度），本注记沿用亏空深度为主线。

**第三步，开方步（闭合，代数级）。** $c_n = \sqrt{W_n}\,e^{i\Phi_n}$，$W_n = \delta_n/\sum_m\delta_m$。P7 的开方像操作在场层原样复用：被开方的东西从全局相干幅度换成局域亏空份额，操作本身不变。相位 $\Phi_n = \arg w_n$ 继承背景相位结构，核区相邻层相位差最大 0.87 rad（连续，K5）。

**第四步，守恒步（闭合，恒等式级）。** $\sum_n W_n = 1$ 来自背景序参量归一化，与系综层份额守恒同构。

**第五步，定量桥（闭合，数值级，本注记新凭据）。** 系综层的全局相干代价 $1 - |\Psi|$ 与场层的局域亏空预算 $\sum_n\delta_n$ 是同一笔相干转移的两种计量口径：$N(1-|\Psi|) = R\cdot\sum_n\delta_n$，实测 $R = 2.9796$ 且随 $N$（800、1000、1200）散布为零、随 kink 位置平移不变、随缺陷数精确可加（比值 1.0000）。这一步把衔接命题从口号升格为有换算常数的定量关系：全局代价就是亏空预算摊到每个格点的份额。

**第六步，叠加态的场侧实现（未闭合，纲领层）。** 两瓣 $W_n$（叠加态）如何由单一背景场承载，本路线未闭合：M5 的场侧代理在定态位错上验证，叠加态的场侧实现需要把"背景 = 系综的局域化"推广到系综相干资源的相干分配，其自然语言是 M4/M5 已验证的波侧份额向量。按纲领预案，此环节标注为纲领性主张，衔接命题的剩余部分并入 P4-5（系综到单粒子投影）。

## 三、结论

推导链六步：五步闭合（两步定义级、两步代数与恒等式级、一步数值级），一步纲领层。结论按纲领验收标准表述为：**系综层与单粒子层的同一性在定态位错上闭合（定量桥为凭据），叠加态的场侧实现维持纲领层并入 P4-5**。波函数的双重身份指同一份相干资源在两级分辨率下的两个像：系综层看总量（份额），场层看分配（亏空）。

## 四、兼容性检查（任务 3-4 前半）

其一，亏空泛函与份额恒等式不冲突：$|c_n|^2 = W_n$ 原样继承份额代数（M5 验证）。其二，层级对照表与五步降级不冲突：系综层对应份额定理的概率语义，单粒子层对应叠加语义升级注记的位置基出身与幅值载具，两级各安其位。其三，本注记不触碰质量恒等式的数值宣称（$\kappa_\varphi$ 标度维持 P1-2 登记）。其四，叠加普适性边界声明归 M8（任务 3-3，裁决点 5）。
