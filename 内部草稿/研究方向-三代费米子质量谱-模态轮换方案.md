## 一、问题的三层结构

三代费米子质量谱包含三个互相独立的子问题，历史上被混为一谈，先拆开。

第一层，**为什么恰好三代**。格点三元组只有三类正交方向，若代际与模态挂钩，三代就是公理结构的直接后果，不需要额外机制。

第二层，**为什么是这些质量比**。轻子质量比 $m_\mu/m_e = 206.768$、$m_\tau/m_\mu = 16.817$、$m_\tau/m_e = 3477.4$。若质量根比写为 $1 : 14.386 : 58.955$，可以立刻看出它们不是等间隔（泛音谱）、不是等比（均匀嵌套）、不是整幂（$n^2$ 型涡旋谱）。任何把三代视为同一机制重复的方案都必须解释这个特定形状。

第三层，**为什么是这个标度**。$m_e/E_P \sim 10^{-23}$、$m_\tau/E_P \sim 10^{-19}$，层级问题已是体系内已定稿的主题（弱耦合凝聚的标度分离，$\kappa_\phi \ll \omega_P^2$，[[有质量粒子的形成：大爆炸同步相变的局域缺陷方案|有质量粒子的形成]]§4.2）。本方案不重开此问题，只承接其结论。

本文的攻坚对象是第二层，附带给出第一层的公理级答案。第三层沿用体系既有叙事。

## 四、候选机制的排除论证

在选优之前，先以数学论证排除六类廉价的代际机制。这些排除是本文的严格贡献，防止后续工作重走死路。

**等间隔谱（谐振泛音、Mathieu 深阱）**：束缚振荡的谐波近似给出 $m_n \propto n+1/2$。观测 $1 : 207 : 3517$ 与其偏差 5 个数量级以上。浅势 Mathieu 的能级压缩也最多把间隔压到总深度的几分之一，无法跨越 $10^2$ 到 $10^3$ 的级差。类排除。

**等比谱（均匀嵌套、超螺旋层、几何级数环）**：设 $m_n = m_0 r^n$，则 $\ln(m_\mu/m_e) : \ln(m_\tau/m_\mu) = 1 : 1$。观测为 $5.331 : 2.822$，比值 1.889，偏离等比 90%。「螺旋的螺旋」嵌套方案（螺旋微分几何注记的质量谱猜想）归属此类，被观测排除，除非嵌套的层间压制比逐层变化，而这又引入新参数。

**整幂谱（涡旋 $n^2$、CP² 拉普拉斯 $l(l+2)$）**：涡旋绑定能 $E \propto n^2$ 给出 $1:4:9$。CP² 标量拉普拉斯谱 $\lambda_l = 4l(l+2)$ 给出 $l = 1,2,3$ 对应 $12:32:60$，质量根要求 $1:14.4:59$。两处不符：中间项 32 而不是 14.4，首项 12 与 14.4 差 20%，除非引入任意幂指数 $p$（$m \propto \lambda^p$ 对两段间隔要求 $p = 5.4$ 与 $p = 4.5$ 矛盾）。类排除。

**环面整数格（三元组相对相位绕数对 $(n_1, n_2) \in \mathbb{Z}^2$）**：相对相位空间 $T^2$ 上的驻波能 $E(n_1,n_2) = \kappa_1 n_1^2 + \kappa_2 n_2^2$。三个最低非零态 $(1,0), (0,1), (1,1)$ 的质量根比 $1 : \sqrt{\kappa_2/\kappa_1} : \sqrt{1+\kappa_2/\kappa_1}$。第三项只能落在 $\sqrt{1+a}$，而观测第三项是 $59 \neq \sqrt{1+207} = 14.4$。若第三态取 $(0,2)$，则 $2\sqrt{a}$ 与 $\sqrt{a}$ 成 2 倍关系，又撞上 $4\sqrt{a}$ 的 59 无来源。该族的方向性（两个不同曲率 $\kappa_1 \neq \kappa_2$）还违反公理 2 三类方向等价。类排除。

**纽结能量谱（Călugăreanu-White 通道）**：环拓扑的扭结绑定能（Möbius 能量）对 unknot、三叶结、五叶结约为 $12.6 : 74.5 : 168$，作为质量本身或质量幂都落在观测 $1:207:3517$ 的两个数量级之外；作为指数 $\exp(\text{能量})$ 又超出太多。且扭结能量谱给不出 Koide 的 $Q = 2/3$ 约束。类排除。

**三等分相位参数化本身的误读**：常有人说"Koide 公式 = 质量根在单位圆三等分点上的投影"，并据此断言三代质量根构成三等分。§五 的定理澄清了这句话的精确内容：三等分投影形式**充分**保证 $Q = 2/3$（严格代数定理），而反过来只自动给出两个矩条件，相位平衡是观测数据的事实性特征。把它当作某种独立几何机制（比如三个复平面三等分点）则无内容。方向澄清后，真正的任务变成回答三等分结构与相位平衡的**来源**，这正是 §六 的方案。

## 五、核心定理：Koide 关系的等价形式

**定理（Koide 结构定理）**。设 $\{m_i\}_{i=0,1,2}$ 为三个正数，$M = \sum\sqrt{m_i}/3$，$a_i = \sqrt{m_i}/M$，$c_i = (a_i - 1)/\sqrt{2}$。则有以下两个方向的结论：

1. **（投影形充分性）** 若存在相角 $\varphi$ 使 $c$ 取三等分形式 $\{c_k\} = \{\cos(\varphi+2\pi k/3)\}$（即 $\sqrt{m_k} = M(1+\sqrt2\cos(\varphi+2\pi k/3))$），则自动成立 $Q = \dfrac{\sum m_i}{(\sum\sqrt{m_i})^2} = \dfrac{2}{3}$。
2. **（矩条件必要性）** $Q = 2/3$ 成立时，$c$ 必满足两个矩条件 $\sum c_k = 0$、$\sum c_k^2 = 3/2$；反之亦然。矩条件单独不保证三等分形式（反例：$c = (1/2, 1/2, -1)$ 满足两矩条件，对应角 $\{60^\circ, 60^\circ, 180^\circ\}$ 等间隔性破坏），保证三等分还要求相位平衡 $\sum\sin\theta_k = 0$（$\theta_k = \arccos c_k$，符号适当选取），即三个单位复数 $z_k = e^{i\theta_k}$ 构成三角平衡构型 $\sum z_k = 0$。

**证明**。方向 1：三等分集满足 $\sum c_k = 0$（余弦和为零）与 $\sum c_k^2 = 3/2$（$\cos^2$ 平均值 $1/2$ 加上交叉项为零）。代入 $\sum a = 3$、$\sum a^2 = 3 + 2\sum c^2 = 6$，立得 $Q = \sum a^2/9 = 2/3$。方向 2：$Q = 2/3$ 给出 $\sum a_i^2 = 6$，而 $\sum a_i = 3$，故 $\sum c_i^2 = (\sum a_i^2 - 3)/2 = 3/2$，$\sum c_i = 0$。矩条件到三等分的缺口是真实的：$c = (1/2, 1/2, -1)$ 满足两矩条件但不构成 $\cos$ 的三等分集，因为它对应的三个单位复数之和不为零。观测数据（§二）的 $c$ 集为 $(-0.6785, -0.2969, 0.9753)$，对应相位 $(\arccos 0.9753, \arccos(-0.6785), \arccos(-0.2969)) = (12.735^\circ, 132.735^\circ, 252.735^\circ)$，恰为三等分集合（$132.735^\circ = 12.735^\circ + 120^\circ$，$252.735^\circ = 12.735^\circ + 240^\circ$），正弦和为 $0.2204 + 0.7345 - 0.9549 \approx 0$，满足相位平衡。因此观测的轻子质量根**事实性地**落在三等分投影族上，相角 $\varphi \approx 12.735^\circ$。∎

**说明**。由此，$Q = 2/3$ 与三等分投影形式在观测上同时成立，但逻辑上后者强于前者：Koide 关系的实测内容包含一个更精细的相位信息，即三个质量根的复数平衡。这个更强的断言正是 §六 方案要解释的对象。文献中常把两者混称，本文区分之：矩条件是 Koide 公式的代数内容，相位平衡是其几何内容（三个单位复数成等边三角形）。

**推论（质量比单参化）**。给定 $\varphi$，轻子质量比被唯一确定：

$$
\frac{m_\mu}{m_e} = \left[\frac{1+\sqrt2\cos(\varphi+2\pi/3)}{1+\sqrt2\cos\varphi}\right]^2, \qquad
\frac{m_\tau}{m_\mu} = \left[\frac{1+\sqrt2\cos(\varphi+4\pi/3)}{1+\sqrt2\cos(\varphi+2\pi/3)}\right]^2 .
$$

于是 $1 : 207 : 3517$ 的全部内容编码在单个相角 $\varphi = \arccos c_3$ 中，其中 $c_3$ 是三个 $c$ 值的最大者。三代谱的"形状"问题压缩为**一个角度的来源问题**。

观测值 $\varphi = 0.222270$ rad $\approx 12.735^\circ$（由 pole 质量算出）。文献（Koide 及其后续工作）长期注意到 $\varphi$ 与 $2/9 = 0.\dot2$ 的接近：实测差 $4.8\times10^{-5}$ rad（相对 0.02%），$\varphi \approx 2/9 = \dfrac{2}{3^2}$。用 $\varphi = 2/9$ 直接代入推论，预言质量比 $1 : 206.8 : 3477.5$，与观测 $1 : 206.768 : 3477.23$ 分别符合 0.001% 与 0.007%。

## 六、模态轮换方案（最佳方案）

### 6.1 三代数 = 三模态轮换轨道

公理 2：三类正交方向 $x/y/z$ 两两正交、同类平行、**三类等价**。"三类等价"是一个轮换对称性 $Z_3$：$|X\rangle \to |Y\rangle \to |Z\rangle \to |X\rangle$ 不改变任何公理内容。模态论文（非交换规范群推导）已确立格点三元组的三模态态空间为 $CP^2$，$SU(3)$ 等距群承载色荷。本方案主张：**代际数 = $Z_3$ 轮换轨道的长度 = 3**。这是第一层问题的公理级答案，零新装置。空间为何三维（开放问题 #32）仍是上游问题，但给定三维后三代的必然性不再需要独立论证。

### 6.2 质量根 = 模态权重的实轴投影

体系内已定稿的[[本体论断崖：规范场论从纯约定生成物理效应的因果跳跃与元相子的实轴实在论方案|本体论断崖]]确立实轴实在论：实轴是元相子的物理结构，承载粒性（半径不可分、摆程回归锚点、满周闭合坐标）。质量是最"粒性"的属性（实存、守恒、可数），由实轴承载顺理成章。同时[[概率幅与实轴：Born规则的模方本质与实轴投影直觉的辨析|概率幅与实轴]]已论证复数振幅向实轴的投影与 Born 模方规则的关系。

本方案提出**投影准则（准则性假设，待动力学推导）**：费米子的质量根是其"质量模态"复数 $w_k$ 向实轴的投影：

$$
\sqrt{m_k} = M \cdot \mathrm{Re}\, w_k, \qquad w_k = 1 + \sqrt{2}\,e^{i\theta_k} .
$$

$w_k$ 的几何：以 $1$（多模态共享的"真空凝聚根"）为圆心、半径 $\sqrt{2}$ 的圆上的点，向实轴投影。常数 $\sqrt{2}$ 来自二范数归一化（双模态与三模态归一化中标准出现的因子），$1$ 是全部模态共享的凝聚项。$M$ 携带整体标度（§八）。

准则的三个辩护。其一，实轴实在论：观测值（质量）是实数，复数结构向实轴的投影是体系内"复数到实在"的唯一标准通道。其二，Born 规则先例：概率是振幅模方的实输出，质量根是相干振幅实部的实输出，同属"复数结构 → 实观测"的投影家族。其三，代数必要性：§五已证明三等分投影形式对 $Q = 2/3$ 是充分定理，且观测谱形状事实性落在此投影族上，投影准则只是把这个形状翻译成几何语言，没有引入新自由参数。

### 6.3 定理：Z₃ 轮换对称 ⟹ Koide 关系

**定理（模态轮换定理）**。设三个质量模态 $w_k$ 构成 $Z_3$ 轨道

$$
\theta_k = \varphi + \frac{2\pi k}{3}, \qquad k = 0, 1, 2 ,
$$

则投影准则给出质量根 $\sqrt{m_k} = M\bigl(1+\sqrt2\cos(\varphi+2\pi k/3)\bigr)$，自动满足 Koide 关系 $Q = 2/3$，并将全部代际质量比压缩为单参数 $\varphi$。

**论证**。$Z_3$ 轮换对称要求费米子内部没有区分 $X/Y/Z$ 的绝对标记：三个模态的相位是轮换轨道上的三个点，轨道上的相位差只能是 $2\pi/3$ 的整数倍。轨道本身由起点 $\varphi$ 参数化。投影后即得上述质量根。三等分相位自动满足 $\sum e^{i\theta_k} = 0$（三角平衡），由 §五定理的方向 1（投影形充分性）立得 $Q = 2/3$。∎

至此推导链闭合：**公理 2（三类等价方向）⟹ $Z_3$ 轮换对称 ⟹ 三模态轨道 ⟹ 实轴投影 ⟹ 三代 + Koide 关系 + 单参数质量谱**。三代"恰好三个"与"恰好满足 $Q = 2/3$"从此是同一个结构的两个结论。

### 6.4 $\varphi = 2/9$：模态逆平方

观测 $\varphi \approx 0.2223$，而 $2/9 = 0.\dot2$，两者相差 $4.8\times10^{-5}$ rad（§五）。若 $\varphi = 2/9 = 2\cdot(1/3)^2$ 精确成立，则**质量谱的全部形状由模态数的逆平方锁定，零自由参数**。$1/3$ 是单模态的均匀权重（对称叠加 $(|X\rangle+|Y\rangle+|Z\rangle)/\sqrt3$ 的每个分量模方），$1/9$ 是其平方。

候选机制（均属纲领性主张，列为开放问题）：其一，**校准固定点**。天行力趋向最大相干性，DOGA 兴盛吸引子 $(1,1,1,0)$ 是收敛终点；$\varphi = 2/9$ 或为模态混合角在"最大相干"约束下的固定点值，类似重整化群不动点的位置由对称性决定。其二，**三模态均匀化的量子化**：作为 Z₃ 电荷的规范化相位，$2/9$ 是"三代荷"的偶然值，需从模态动力学的具体形式导出。其三，**数值复核**：$\varphi$ 与 $2/9$ 的符合精度依赖质量输入方案（pole 或 running），需要以最新 PDG 精确复核后再定论。

- **与"方是圆的积分"**：质量根 = 单位圆轨道向实轴的投影，是"圆决定整值/实数结构"家族的又一成员（螺旋阶梯几何的采样定理同族）。
- **与模态论文**：模态空间 $CP^2$ 保证 $SU(3)$ 色结构，本方案的 Z₃ 轨道是 $CP^2$ 中三模态的相位曲线，色（$SU(3)$ 等距）与代（Z₃ 轨道）在 $CP^2$ 上正交分解：色作用在轨道外的切向，代沿轨道方向。这个分解与模态论文 §4 的自由度计数无冲突（$SU(3)$ 8 参数 = 4 实维 + $U(2)$ 4 参数，Z₃ 轨道是其内一条曲线）。
- **与单环扭转方案**：单环扭转解释"为何有质量"（缺陷绑定能谱 $m = hN/(Lc)$），本方案解释"为何三代质量比是这个形状"。前者是拓扑层的共通骨架，后者是模态层的形状规则，二者可以叠加：环的参数（$N, M$）给共通标度，模态轨道给代际比。

## 八、标度 $M$ 与定居密度

$M = \sum\sqrt{m_i}/3 \approx 17.716$ MeV$^{1/2}$ 的整体标度不携带代际信息，它来自凝聚层面。承接[[有质量粒子的形成：大爆炸同步相变的局域缺陷方案|有质量粒子的形成]]：$m_\tau = \hbar\sqrt{\kappa_\phi^{(\tau)}}/c^2 \approx 1.777$ GeV 与 $v = 246$ GeV 通过 $y_\tau = \sqrt2\,m_\tau/v \approx 0.0102$ 连接。本方案中 $y_\tau$ 对应最大模态根 $(1+\sqrt2\cos\varphi)$：$y_k = y_0\bigl[1+\sqrt2\cos(\varphi+2\pi k/3)\bigr]^2$（$y_0$ 为凝聚层面的无量纲系数）。若 $y_0$ 与 $\varphi$ 都锁定，则三代 Yukawa 全部锁定，$m_e, m_\mu, m_\tau$ 只剩一个整体标度（对应 $v$），层级问题维持"弱耦合凝聚标度分离"的既有叙事不变。

## 九、夸克部分与色修饰

夸克三个事实：同代夸克重于轻子；代内 $u/d$、$c/s$、$t/b$ 分裂（质量比 0.46、13.6、41.3）；夸克 Koide 系数偏离 $2/3$。

本方案的定位陈述：色三重态占用 $CP^2$ 的等距自由度（模态论文已定稿），代际轨道（Z₃ 相位曲线）在 $CP^2$ 内与色方向正交分解，但**夸克的模态态同时承载色三重态与代际轨道**，两者的耦合（色联络对轨道的影响）会修饰纯 Z₃ 结构。三类可检验的修饰方向：

1. 同代内 $u/d$ 分裂的来源候选：弱二重态（双模态 $S^3$）内部的电磁分层（§模态论文 3.4），绕数（电荷）对锁定能隙的微小调制。$m_u/m_d = 0.46$ 与 $m_c/m_s = 13.6$ 的差异显示这个调制自身随代变化。
2. 夸克 Koide 偏离的候选来源：$\overline{\text{MS}}$ 质量的方案依赖，pole 质量下部分夸克族的 $Q$ 值更接近 $2/3$（b/c 族在文献中有接近 Koide 的报告），需系统复核。
3. 代际-色耦合的几何形式：$CP^2$ 上色联络的曲率沿 Z₃ 轨道的积分给出代际修正项，这是最高优先级的待定量对象（开放问题 1）。

本方案坦承：夸克分支目前停留在"修饰方向清单"层面，与轻子分支的完整度不对等。轻子是 Z₃ 结构的第一检验场。

## 十、可检验预言

1. **第四代不存在**。$Z_3$ 轨道恰好三支，公理 2 三类方向给出三代上限。若实验发现第四代轻子或夸克，本方案连同公理 2 的模态解读一并证伪。此预言与现有实验下限（第四代带电轻子下限数百 GeV）兼容。
2. **轻子质量比的单参数锁定**。$m_\mu/m_e$ 与 $m_\tau/m_\mu$ 由 $\varphi$ 唯一确定。若 $\varphi = 2/9$ 精确成立，这两个比被唯一预言（等价于精确 Koide + 相位锁定）。这是最强可检验结构：提高 $m_\tau$ 与 $m_\mu$ 的 pole 质量测量精度，直接检验 $\varphi = 2/9$。
3. **温度依赖的代际合并**。电弱相变临界温度之上定居密度 $v \to 0$，所有代质量消失；本方案进一步预言：模态轨道的 Z₃ 结构在高温也面临恢复（模态热退相干抹平相位），代际质量比随温度单调趋近 1。这给出一条标准模型没有的温度行为曲线，等待未来高能对撞或早期宇宙约束。
4. **与既有体系预言的相容**。125 GeV 希格斯、$(E/E_P)^2$ 量级洛伦兹破坏（实轴方向场论文）等体系预言不受本方案影响，本方案的增量只在费米子扇区。

## 十一、开放问题

1. **投影准则的动力学推导（P0）**：$\sqrt{m_k} = M\,\mathrm{Re}\,w_k$ 目前是准则性假设。攻坚正路：从元相方程 (I) 与定居密度场的耦合写出费米子模态态的期望值方程，证明其基态质量根等于相干振幅的实部投影。这是本方案升格为定理的必经之路，也是体系"系综到单粒子投影"缺口（开放问题 #30）的具体化。
2. **$\varphi = 2/9$ 的机制（P0）**：模态混合角为何是 $2/3^2$。候选：DOGA 兴盛吸引子的校准固定点、三模态均匀化的量子化条件。需要模态场论的具体形式。
3. **夸克 Koide 的系统复核与色修饰定量（P1）**：pole 质量下各夸克族的 $Q$ 值精确值，$CP^2$ 色联络沿 Z₃ 轨道的积分。
4. **Gatto 关系的模态表述（P1）**：$\sqrt{m_d/m_s} \approx |V_{us}|$ 在模态语言中对应双重态内部分裂与混合角的同一几何来源。若成立，CKM 混合将获得与质量谱同源的体系内构造。
5. **$\sqrt{2}$ 常数的确认**：投影中系数 $\sqrt2$ 来自二范数归一化，需在模态态的具体归一化约定下核实（是否应为其他常数，如三模态归一化的 $\sqrt3$ 修正项）。
6. **与束縳振荡主文档的衔接**：Z₃ 轨道的相位 $\varphi$ 是否与摆程锚点（满周闭合的 $\pi$ 相位约定）存在固定关系，$\varphi = 2/9$ 若成立则与 $2\pi$ 公约体系的关系待查。
