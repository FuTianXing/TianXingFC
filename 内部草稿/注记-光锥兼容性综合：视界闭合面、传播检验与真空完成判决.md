## 一、问题与定位

作者把「视界的形成要与相对论的光锥机制兼容」列为主攻问题之一，第二条主攻问题为黑洞奇点与普朗克尺度晶格损坏。此前相关读数散在两轮验证材料与计划条目里：视界等值线自洽（BH2 与 M4/D3）、弱场相速恒等式（GV4）、停滞律分叉（光锥轮）。本注记把它们合成一条链条，给出联合判定与剩余清单。

「兼容」在本注记里取三层可证伪含义：闭合位置（视界等值线即光锥闭合面）、因果结构（闭合、内翻与近视界停滞的形式）、强场形式（空间完成与真空条件的对应）。

## 二、链条四段

其一，识别式（N5）：$g_{00} = -(1-2\theta)$，视界条件 $\theta(r_s) = 1/2$，长波归一 $h_{00} = 2\theta$；因子 2 来自相对论约定（G6 已登记来源）。记录场按 2026-09-19 语义裁定属定义层（时空生成刚度的承载自由度）。

其二，强场剖面（D3 饱和源模型）：$\nabla^2\theta = -s(1-\theta^2)_+$ 的离散解（M=600、dr=1、RS=6、s0=1.0），视界位于 $\theta = 1/2$ 等值线 $r_h = 10.285$，远场回到 $1/r$（记录荷 $q = 2\pi r_h$）。

其三，协变相速恒等式（GV4）：径向坐标光速 $c_r^2 = -g_{00}/g_{xx}$；联络项只改幅度不改相速。

其四，完成判决（真空条件）：静态球形度规里奇为零强制 $AB = \mathrm{const}$；给定 $A = 1-2\theta$ 后 $B = 1/A$ 唯一，线性完成 $1+2\theta$ 被定量排除。

## 四、判定与条件转形

三层判定同时对齐：闭合位置精确（$r = r_h = 10.285$）；因果结构为 GR 型（闭合、内翻、对数冻结，冻结系数等于视界半径）；强场形式被真空条件唯一钉住，且记录场自身的 $1/r$ 结构恰是真空条件（连续恒等式机器精度）。

条件转形：$g_{xx}$ 从「未知函数」变为一个物理条件：强场处的几何是否保持真空（无额外有效应力）。开放的形态从「二选一」改为「动力学是否维持」，后者属 U2 正面攻坚（零接触边界失效区的写入-扩散-弹性完整动力学）。

与 GR 的对照：弱场首阶逐位一致；远场 $\theta = r_h/(2r)$ 配套时给出 $A = 1 - r_h/r$、$B = 1/A$，即史瓦西坐标形式；差异在晶格尺度与剖面来源（饱和源模型的格点求解），以及在动力学来源与内部图像。

## 五、边界

其一，层位：本注记判决的是运动学与几何层，动力学生成未给（U2）。其二，一维径向、静态、球形；旋转与含时未涉及。其三，$\lambda = 1$ 取 GV1 弱场真空条件，本轮未重开。其四，离散口径的系统差（剖面残差 $0.0349$、传播对连续参考的 $+3.3\%$ 至 $+3.5\%$ 格点色散）属数值层面。其五，第二主问题（奇点与晶格损坏）本注记未动。
