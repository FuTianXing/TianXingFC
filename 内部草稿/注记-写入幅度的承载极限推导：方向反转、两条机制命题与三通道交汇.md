## 一、问题与升格主张

碰撞写入公设 P3 的幅值句 $\delta\theta = m/m_P$（[[爱因斯坦场方程的微观根基：从碰撞写入法线场到连续时空几何|微观根基]] §2.1）目前是公设：写入幅度取物体质量与普朗克质量之比。2026-09-05 固化的满量程标度读法把它解释为归一化常数；2026-09-17 承载力读法进一步给出物理内容：$\delta\theta$ 恰是最近邻格点上的载荷读数。

但承载力读法注记边界四自认"属口径裁定，够不上定理"，原因是链的方向反着走：$\theta(l_P) = m/m_P$ 从归一化链输出整理而来，而归一化链以 PN 匹配 $\theta = Gm/(c^2 r)$ 为输入。承载读法是结果的重释，尚未反向生成结果。

作者 2026-09-27 把结构说全：格点有承载上限（前提一），上限由格点几何决定（前提二），上限恰为 $m_P$（结论），$\delta\theta = m/m_P$ 即占承载极限的比例（推论）。本注记论证：方向反转可行，需补两条机制命题，命题 A 已有两处独立裁决支持，命题 B 待判据化。

## 二、承载判据（命题 A）：满偏即退出承载

**命题内容**：取向自由度是有限角程结构，写入把它压到 $180^\circ$（与法线方向彻底反向）时跃迁无法完成，格点退出承载。满偏即退出，是几何必然而非约定。

**判据状态：两处独立支持。** 其一，2026-09-15 角度映射裁决：线性映射 $\alpha = 180^\circ\times\theta$，$\theta = 1$ 对应取向自由度压弯 $180^\circ$，即彻底反转与晶格破坏（[[内部草稿/注记-记录场读数的角度映射审查：满偏与视界角的三套候选读法|注记-角度映射审查]]）。

其二，黑洞线链条"引力塌缩与晶格破坏是同一机制的两端"：质量越大写入越快，逼近满偏，$m = m_P$ 时满量程占满、格点撑不住（[[内部草稿/注记-黑洞内部机制的候选方案：物质汇聚、晶格破坏与本原吸收|注记-黑洞内部机制]]），黑洞线术语表第十二节已有"支撑失效、格点退出"条目。

**临界质量的导出**。承载力读法注记给出满偏位置 $r = Gm/c^2$。满偏半径触及格距，即最近邻格点被压到满偏，承载退出，临界条件为

$$\frac{Gm_c}{c^2} = l_P \quad\Longrightarrow\quad m_c = \frac{c^2 l_P}{G} = m_P$$

末步用恒等式 $l_P/m_P = G/c^2$（微观根基 §2.3，浮点精度 0）。判据加恒等式，临界质量与 $m_P$ 逐位相同，零自由参数。对 $m < m_P$，满偏半径落在首格胞内部，无格点承载该读数，记录被紫外截断吸收；对 $m > m_P$，满偏半径越过最近邻格点，承载失效。$m = m_P$ 是分界。

## 三、作用量通道：每拍一份作用量量子即满载

承载上限在作用量侧有等价投影：

$$m_c\, c^2\, t_P = \hbar \quad\Longleftrightarrow\quad \frac{c^2 t_P}{\hbar} = \frac{1}{m_P}$$

内容：格点每拍能承载的作用量为一份 $\hbar$（作用量量子，几何载体为圆周 $2\pi\hbar = h$，时空观总览），超过即满载。该式是 $t_P$ 定义 $\sqrt{\hbar G/c^5}$ 的重排，零自由参数。由 $l_P = c\,t_P$，两条判据相互等价：$Gm_c/c^2 = l_P$ 与 $m_c c^2 t_P = \hbar$ 是同一条件的几何与作用量两种读出。

**口径声明**：本通道使用作用量份额语言（每拍作用量积累相对 $\hbar$ 的份额），不使用角度计量。$\theta$ 无量纲，其几何角值取决于映射约定，"每拍 1 弧度"旧读法已按 2026-09-15 裁决退役；现行口径为 $\theta = 1$ 满偏（线性映射 $\alpha = 180^\circ\theta$）。$m = m_P$ 时每拍作用量份额为 1，写入读数 $\theta = 1$，两个"1"的等同正是命题 B 的内容。

## 四、载荷等同写入（命题 B）：分配规则下的读数

**命题内容**：写入幅度 $\delta\theta$ 与最近邻格点载荷读数 $\theta(l_P)$ 等同。

承载力读法注记第二节由归一化链整理出该等同；方向反转要求它独立成立。独立根据由两件已交付的材料合成：写事件的分配规则（判据 L1 至 L5：标量写入进站点离散散度、六条链接各承 $1/6$、方向指标即链接取向，数值读数最大相对差 $0.00\times10^{0}$）与离散泊松格林函数的结构。写入落站后，最近邻读数由分配规则与核共同决定，$\theta(l_P) = m/m_P$ 是"分配规则加恒等式 $l_P/m_P = G/c^2$"的推论，无需引入 PN 匹配作为输入。

**判据状态：待判据化。** 等同句作为独立命题的显式数值演示（在判据 L 脚本框架内核对最近邻读数与写入幅值的比值恒等式）尚未立项。建议补一条最小判据，按验证脚本占位规范执行（见第九节）。

## 五、方向反转后的推导链

旧链（微观根基 §2.3）：PN 匹配 $\theta = Gm/(c^2 r)$，联立格林函数反推 $s_{eff} = 4\pi m/m_P$，回到 $\delta\theta = m/m_P$。幅值是匹配的输出，公设地位由此而来。

新链（方向反转）：判据 A（满偏即退出）给出临界质量 $m_c = c^2 l_P/G = m_P$；格林函数结构给出最近邻载荷 $\theta(l_P) = m/m_c$（命题 B：即写入幅度）$\delta\theta = m/m_P$；几何计数（$4\pi$ 立体角、$N_c = 2\pi\alpha/3$）给出 $s_{eff} = 4\pi m/m_P$；稳态格林函数给出 $\theta(r) = Gm/(c^2 r)$。PN 匹配与史瓦西对齐 $h_{00} = r_s/r$ 从输入降为输出。

$G$ 的单一入口性质保持：$G$ 经 $l_P$、$t_P$ 与恒等式网络进入（$l_P/m_P = G/c^2$ 与 $c^2 t_P/\hbar = 1/m_P$ 是同一网络的两种写法），量纲自洽清单（微观根基 §2.3）不变。若推导层获作者确认，P3 幅值句由公设改标条件性命题级（依据判据 A 定性与命题 B 待判据化的条件），微观根基 §2.3"归一化对接"段可补方向反转注记。

## 六、三通道交汇

| 通道 | 物理判据 | 恒等式 | 来源 |
|---|---|---|---|
| 几何 | 满偏半径触及格距即退出 | $Gm_P/c^2 = l_P$ | 承载力读法注记 §二 |
| 作用量 | 每拍一份作用量量子即满载 | $m_P c^2 t_P = \hbar$ | 本注记 §三 |
| 归一化 | PN 极限匹配 | $l_P/m_P = G/c^2$ | 微观根基 §2.3 |

三式互为同一恒等式网络（$l_P = c\,t_P$ 与普朗克定义式）的投影，"同值"是代数必然；各通道的物理判据（满偏退出、每拍一份 $\hbar$ 满载、弱场匹配）各自独立且各有来源。交汇形态本身构成"承载上限恰为 $m_P$ 属几何决定、非任意设定"的证据结构，对应作者前提二。
