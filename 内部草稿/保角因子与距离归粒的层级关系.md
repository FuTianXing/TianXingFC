# 保角因子与距离归粒的层级关系（已裁决，2026-08-12）

## 冲突内容

主文档第四部分"有效度规"写：

> 均匀情形 $g_{\mu\nu} = \text{diag}(-c^2, 1, 1, 1)$。非均匀情形 $g_{\mu\nu}(x) = r(x)\eta_{\mu\nu}$，保角因子由**局域相干强度**给出（引力涌现的种子，爱因斯坦方程步骤四）。

补充注释九裁决：**距离归粒**（空间标度由格点阵 $l_P n^a$ 提供），相位差（相干强度相关量）重新定位为波矢。

潜在冲突：保角因子 $r(x)$ 由"局域相干强度"给出，而相干强度是相位关联的统计量（波性侧）。若度规的整体标度（保角因子）由波性量决定，是否与"空间标度归粒"矛盾？

## 分析

- 基础层：格点阵决定空间的基础标度（$x^a = l_P n^a$，粒性承载），这是公理 4 的设定；
- 涌现层：度规是涌现层有效描述（公理 6），保角因子 $r(x)$ 是度规的自由度（共形自由度），描述的是"格点阵基础上的局部伸缩"；
- 二者层级不同：格点阵 = 基本层空间标度；保角因子 = 涌现层度规的局部修正（引力种子）。

结论倾向：**不矛盾，但需显式声明层级**。格点阵决定基础标度（粒性），保角因子是涌现层度规的局部修正（波性量的有效描述），二者分属基本层与涌现层。保角因子不是"定义距离"，而是"修正距离的涌现层因子"。

## 裁决结果（2026-08-12 已写入主文档）

**层级划分**：格点阵（格距 $l_P$，粒性承载）= 空间标度的**基本层**（基本常数、处处恒定）；保角因子 $r(x)$ = **涌现层**度规的局部修正（有效距离伸缩，由波性量相干强度驱动），不改变格距 $l_P$ 本身。如同晶格常数（基本层，固定）与弹性形变（涌现层，可变）的关系。

**关键定性**：保角因子不承担"定义距离"的职能，它只修正涌现层的有效距离；"距离归粒"管基本层，保角因子管涌现层修正，各安其位，不构成冲突。与早期框架 $d_{ij} = f(E_{ij})$（波性量定义距离）的区别：早期框架是"基本层距离由波性定义"（已被裁决否定），保角因子是"涌现层有效距离由波性修正"（保留），层级不同。

**待后续**：保角因子与实轴方向场（同为波性量）的驱动关系、引力构造（步骤四）的具体实现，仍待后续工作。
