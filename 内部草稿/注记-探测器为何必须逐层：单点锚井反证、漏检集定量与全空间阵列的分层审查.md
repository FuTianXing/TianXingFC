## 一、问题的提出

体系对测量端的空间结构有一处反直觉的结论：**可工作的探测器是一层一个指针的全空间阵列，它没有「一个位置」，非局域性是它的工作前提。**

这条结论推翻了一条经典预设（仪器是个小球）。本注记把它的论证链拆开，并标明每一段的层级。

## 二、反证：单点锚井的共模失败

原始记录出自 M2 轮（见 [[内部草稿/总结报告-测量问题攻坚战役收官：三面墙九里程碑与六个验证脚本：2026-09-13]] 的七次修正其一）：

> 单点锚井对相邻层位共模响应、记录为零，反证探测器须一层一个指针。

「共模响应」指源在层位 $n$ 与层位 $n+1$ 时，单点探测器给出同一个读数。读数不变意味着偏离为零，记录无从成立。

同一轮另有一组对照读数：甲组三协议（零模踢、宽脉冲、踢加阻尼，均无探测器）可见度保持不低于 $0.9755$；乙组（同款踢加阻尼加逐键探测器晶格）衰减至 $4\times10^{-6}$。归因链据此成立：阻尼共模不退相干，衰减的唯一来源是跨层记录。

## 三、判据级的三件读数

后续两轮把反证做成了定量。

**其一，漏检集。** 给指针间距 $d$（每隔 $d$ 层一根指针），考察哪些位移会被漏掉。

| 指针间距 | 漏检集 | 后果 |
| --- | --- | --- |
| $d = 1$ | 空 | 全部位移可辨 |
| $d = 2$ | $\{1\}$ | 移动一层被漏 |
| $d = 3$、$d = 4$ | $\{1, 2\}$ | 前两个位移被漏 |
| $d = 6$、$d = 8$、单点档 | 全部考察位移 | 记录完全失效 |

漏检处 $n_{\text{diff}} = 0$，于是 $\Delta = 0$，记录不成立。这张表把「必须逐层」从断言变成读数。

**其二，位移律。** 逐层档小位移段满足 $n_{\text{diff}} = 2\delta$，$\delta = 1$ 给出 $\Delta = 5\sqrt{2} = 7.0711$，与记录判据轮的周期往返读数独立印证；$\delta = 6$ 处饱和于 $10$（峰宽约 $5.9$ 格距）。剖面校验：解析峰值 $0.1414$ 对既有实测 $0.1399$，偏差 $1.09\%$。

**其三，分辨单元恰为一层。** 亚层位移的失明采样点占比在 $\delta = 0.25$、$0.5$、$0.75$ 处为 $0.688$、$0.437$、$0.187$，与 $1-\delta$ 相符到 $0.06$ 以内。该结论由两个独立来源供给：距离归粒（位置读数 $x^a = l_P n^a$ 取整数层号）与层位份额（$W_n$ 逐层承载位置概率）。

## 四、「全空间阵列」的层级与三维限定

**层级。** 逐层要求有判据级支撑（第三节）。而「全空间阵列」「装置没有位置」「非局域性是工作前提」这几句，出处是 [[叠加态的场侧画像：单一场承载、份额折叠与相位通道]] §7.3，该节自标为「模型内判据级**之上**的结构解读」。两者的层级不同，引用时须分开。

**三维限定。** 上述验证跑的是 FK 链，**一维**。三维与复合体上的层格定义仍为开放项（见 [[验证脚本/注记-限制二收口的最小验证：逐层指针与阈值读出的可分辨性]] 的剩余项）。故「全空间」目前是一维结论加结构解读，三维推广待做。

**几何内容待定。** 「全空间阵列」的几何内容（三个方向各一排、连续分布、逐站各一套）在现有材料里未写死，属定义缺口。

## 五、三重表面矛盾与消解

[[叠加态的场侧画像：单一场承载、份额折叠与相位通道]] §7.3 列出三处表面矛盾与统一消解。

| 表面矛盾 | 消解 |
| --- | --- |
| 位错局域，位置却非局域 | 实体不局域（实体的一份是缠绕） |
| 仪器该有「一个位置」 | 装置不局域（指针阵，非局域性是工作前提） |
| 测量总该发生在某一点 | 事件无单点（全空间相干向逐层记录投影） |

三处同源：一旦放弃「仪器是个小球」这条预设，三处一起消失。

## 六、分层审查

**本节为本注记的分析，非体系陈述。**

整条论证的实际强度是分层的，转述时若把它们混在一起，会读高。分层如下。

| 环节 | 层级 | 依据 |
| --- | --- | --- |
| 单点共模失败 | 数值读数（模型内） | v1 记录 |
| 漏检集、位移律、分辨单元 | 判据级 | 两轮脚本 |
| 逐层要求 | 判据级 | 由上一行推得 |
| 全空间阵列 | 一维判据级加结构解读 | §7.3 自标 |
| 三重矛盾消解 | 结构解读 | §7.3 自标 |
| 非局域性是工作前提 | 结构解读 | §7.3 自标 |

**读法建议**：引用这条结论时，「必须逐层」可以直接引，它判据级；「全空间阵列」须带一维限定，并注明结构解读的层级。

## 七、需收紧的六处

**本节为本注记的分析，非体系陈述。**

**其一，三维推广开放。** 验证是一维，结论说「全空间」。转述时须带限定，见第四节。

**其二，「全空间阵列」的几何内容未定死。** 这是定义缺口，非本注记可补。

**其三，共模失败的机制未给。** v1 的失败是数值事实，「为什么一个单点井会共模」这一步没有推导。转述时宜标明它是读数。

**其四，「记录编码位置」这一简化不准确。** 读数表明 $\Delta$ 是**幅度量**：周期往返档给出 $\Delta = 5$ 与 $5\sqrt{2}$ 两个值。故位置（哪个指针响应）与幅度（$\Delta$ 多大）都在记录里，两者并无对立。

**其五，从「逐层」到「全空间」有隐含前提。** 这一步需要「系统的位置索引本身铺满空间」作为前提。前提补齐后论证成立，引用时宜显式写出。

**其六，「非局域性是工作前提」措辞有歧义。** 它可被读成「事件层非定域」。而体系另有一处明确陈述：事件层的非定域「体系没有这条也不需要有」（见 [[内部草稿/注记-概率如何进入物理：从古典统计到玻恩规则，以及体系侧读法]] §六·补 的非定域三义）。按上下文，此处所指为**描述层**（全空间相干结构作为整体）。措辞若不收紧，会被读成自相矛盾。

## 八、一处更深的张力

**本节为本注记的分析，非体系陈述。**

第五节的消解第一项写「实体不局域（实体的一份是缠绕）」。而体系另处写「局域性等于锚核钉位」（见粒子三层解剖）。（2026-09-29 更新：该第四项的载体现记为内部壁承载绕数，锚核改注质量侧。）

两句并置，读者会问粒子究竟局不局域。一种读法是：**实体（缠绕）不局域，粒子（复合位错）局域**，两个对象不同。该读法若成立，则消解成立，但它靠一个未显式声明的区分撑着，跨文档引用时会撞。这与「位置」一词的多重所指同源。
