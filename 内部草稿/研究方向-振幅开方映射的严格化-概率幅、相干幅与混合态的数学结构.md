## 一、定位与动机

份额定理遗留 (g) 指出：振幅开方映射 $w_a \mapsto c_a = \sqrt{|w_a|}\,e^{i\arg w_a}$ 在部分相干（$|\eta_a| < 1$）时的系统数学未形式化。要害在于一个未言明的张力：按定义 $c_a := \sqrt{N_a/N}\,e^{i\tilde\Phi_a}$ 有 $|c_a|^2 = p_a$（份额，无条件）；而开方像 $\sqrt{|w_a|}e^{i\arg w_a}$ 的模方为 $p_a|\eta_a|$（份额乘相干度）。两者仅在纯态 $|\eta_a| = 1$ 时相等。本文以此张力为入口，给出完整结构：两个幅（概率幅与相干幅）、两个映射（概率开方与序参量开方）、一个纯态判据、一个混合态承接（密度矩阵）与一个相干归一化定理。

## 二、记号与准备

系综 $N$ 个元相子按模式块分解：块 $a$ 含 $N_a$ 个（$\sum_a N_a = N$），份额 $p_a := N_a/N$（$\sum_a p_a = 1$ 恒等）；块内相位 $\theta_i = \Phi_a + \delta_i$，相干因子 $\eta_a := \frac1{N_a}\sum_{i\in a}e^{i\delta_i}$，$|\eta_a| \le 1$；序参量分量 $w_a := p_a e^{i\Phi_a}\eta_a$（$\Psi = \sum_a w_a$）。

**两个幅的定义**：

$$ \text{概率幅} \quad \tilde c_a := \sqrt{p_a}\,e^{i\tilde\Phi_a}, \qquad
\text{相干幅} \quad \hat c_a := \sqrt{|w_a|}\,e^{i\arg w_a} = \sqrt{p_a|\eta_a|}\,e^{i(\Phi_a+\arg\eta_a)} $$

**基本关系式**：

$$ \hat c_a = \tilde c_a \cdot \sqrt{|\eta_a|}\,e^{i(\arg\eta_a)} , \qquad |\tilde c_a|^2 = p_a, \qquad |\hat c_a|^2 = p_a|\eta_a| $$

概率幅的相位 $\tilde\Phi_a$ 为块相位与相干相位的合成（纯态时 $\tilde\Phi_a = \Phi_a + \arg\eta_a$，见定理 2）。

## 三、四个定理

**定理 1（Born 规则的无条件性，概率幅层）**：$|\tilde c_a|^2 = p_a = N_a/N$，且 $\sum_a|\tilde c_a|^2 = 1$。证明：概率幅定义 + 份额恒等式，无需任何相干条件。$\blacksquare$

**定理 2（纯态合一判据）**：序参量开方像与概率幅一致（$\hat c_a = \tilde c_a$，对一切 $a$）当且仅当所有块内全相干（$|\eta_a| = 1$，$\tilde\Phi_a = \Phi_a + \arg\eta_a$）。证明：$|w_a| = p_a|\eta_a| = p_a \iff |\eta_a| = 1$；相位条件由 $\arg\sqrt{|w_a|}e^{i\arg w_a} = \arg w_a = \Phi_a + \arg\eta_a$ 与 $\tilde\Phi_a$ 的定义取齐。$\blacksquare$

**推论（P7 的严格表述升级）**："波函数 = 序参量开方像"仅对纯态（全部块全相干）成立；混合态（存在 $|\eta_a| < 1$）下波函数（态矢量）表述失效，正确对象是密度矩阵（定理 3）。P7 由此获得判据性内容。$\blacksquare$

**定理 3（混合态的密度矩阵承接）**：一般（含部分相干）组装的概率描述由 $\rho = \sum_a p_a\,|\varphi_a\rangle\langle\varphi_a|$ 给出，对角概率 $\rho_{aa} = p_a$（与相干度无关，与定理 1 一致）；块间关联由相干因子进入非对角元：$\rho_{ab} = \sqrt{p_ap_b}\,\tau_{ab}$，$\tau_{ab}$ 为相干输运因子（退相干极限 $\tau_{ab} \to 0$）。证明：概率的非负性与归一性由 $p_a$ 保证；$\tau_{ab}$ 的显式形式由 $\eta_a\eta_b^*$ 组合给出（干涉项因子分解，见定理 4 推论）。$\blacksquare$

**定理 4（相干归一化）**：相干幅的模方和等于相干度加权份额：$\sum_a|\hat c_a|^2 = \sum_a p_a|\eta_a| \le 1$，等式仅对纯态成立。证明：$\sum p_a|\eta_a| \le \sum p_a = 1$（$\sum p = 1$、$|\eta| \le 1$）；等式成立需 $|\eta_a| = 1$ 对一切有 $p_a > 0$ 的 $a$。$\blacksquare$

**推论（概率归一化与相干归一化的分层）**：体系存在两个归一化律：$\sum p_a = 1$（份额恒等，概率层，无条件）与 $\sum p_a|\eta_a| \le 1$（相干层，混合态时严格小于 1）。$\hat c$ 的模方与概率无关，其身份为"相干度加权份额"，即干涉能力指标。$\blacksquare$

**定理 4 推论（干涉项因子分解）**：双块干涉强度 $2\Re(w_aw_b^*) = 2\sqrt{p_ap_b}|\eta_a||\eta_b|\cos(\Phi_{ab} + \arg\eta_{ab})$，随相干因子衰减而消失；在密度矩阵语言中对应 $\rho_{ab}$ 的非对角因子 $\tau_{ab} = |\eta_a\eta_b|e^{i(\ldots)}$（退相干因子）。概率对角元与相干无关，干涉能力与相干有关，两者的分离是份额定理 §4.4 的严格化。$\blacksquare$
