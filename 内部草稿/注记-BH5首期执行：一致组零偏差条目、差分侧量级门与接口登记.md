## 二、BH5-3 差分侧量级门

候选：饱和压荷读数（S1）。代理设定：外区形状偏差按线性代理映射为阴影尺度偏差（$\delta b/b$ 与外区形状残差同量级），只判量级。

| 量 | 读数（S1；$N = 49$，均匀球源，容量裁剪 $h \le 1$） |
|---|---|
| 外区对「线性参照乘有效荷」的比例偏差 | 全档最大 $1.7\times10^{-5}$（$M/m_P = 16$ 档），次大 $1.1\times10^{-5}$，坍缩档为 $10^{-7}$ 至 $10^{-11}$ 级 |
| 形状判定 | 外区严格保持 $1/r$ 尾形；压荷只改荷值、不改尾形 |
| 荷值侧 | $q_{\text{eff}}/(M/m_P)$ 由 $1.0000$ 降至 $0.5850$、$0.1060$（$R_s = 8$），坍缩档 $0.0419$ 与 $0.0256$ |
| 观测门槛（量级口径） | EHT 类环直径精度约 $10^{-1}$ 级；下一代阵列目标约 $10^{-2}$ 级；光子环干涉测量为潜在亚百分比通道 |

判定两条。其一，形状门：$1.7\times10^{-5}$ 对 $10^{-2}$ 级门槛，裕度约两个数量级，判「观测不可及」；按裁决二十一封存该子项，重开条件为容量形式更新（P1-2 输入）、观测精度提升或模型升级。其二，荷值门：荷值比在过密档降至 $2.6\%$ 至 $10.6\%$，若作为稳态外场将与体系自身弱场对齐（$\theta(r_s) = 1/2$、60 数量级四天体校验）不相容，故只能作坍缩瞬态；瞬态窗口（时序印记）属 BH4b，待 C1 解除门控，本项不封存。

核对说明：本量的输入为 S1 表格读数与公开实验目标的量级口径，映射为最简线性代理；不含新计算，不承诺精确系数。
