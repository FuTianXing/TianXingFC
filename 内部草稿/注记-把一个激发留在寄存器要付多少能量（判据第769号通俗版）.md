## 一、一句话结论

**把一个激发留在寄存器里，每多一倍的耦合劲，持有它的时间就短到四分之一，能量刻度就翻到四倍。**

耦合开到极限时，一个激发在寄存器里待的时间**恰好等于一个摆程**，它的能量刻度**恰好等于一个基模能量**。

## 二、背景

案乙的判决点卡在一处：它要算一个比值 $\rho$，而那个比值要用到 $E_c$（记录寄存器每激发的持有刻度）。$E_c$ 此前只是登记在册的「一个待做的计算」。

上一轮（第 394 号）做的是它的概率那一半：写入耦合不能太大，否则写入的概率超过一，给出耦合上界 $g_w \le 0.0112\,\omega_P$。**能量那一半一直没做。** 本轮就做它。

**$E_c$ 是什么**：往寄存器里写一个激发，那个激发能被留多久、值多少能量。这是"记录侧"的能量刻度。

## 三、逐判据通俗版

**EC-1 幅度不依赖耦合**：写入时到底搬走几个激发？

六个耦合档的**完整转移事件计数皆为 $1$**，极差 $0$。**耦合再大再小，一次写入就是搬一个激发。** 通过

**EC-2 率接口的核对**：浴有多少个模？$C = 2\pi\rho\,t_P$ 算出来是多少？

$\rho = 31.9901435615$，$C = 201.000000000000$，与模数 $201$ 的相对偏差 $0.000\times10^{0}$。**恰等于浴的模数，说明公式里没有多余的因子。** 通过

**EC-3 持有时间**：一个激发能在寄存器里待多久？

$\tau_{\rm rec} = t_P/\eta$，$\eta = Cg^2$，所以**待的时间与耦合的平方成反比**。模型档幂次 $-2.000000000$（残差 $3.553\times10^{-15}$），物理档同。**这是 $E_c$ 的骨架。** 通过

**EC-4 耦合开到极限时**：$g_w = 0.07053456$（即 $0.01122592\,\omega_P$）给 $\eta = 1.0000000000$、$\tau_{\rm rec} = 1.00000000$、$E_c = 6.28318531\,\omega_P$。**待的时间恰为一个摆程，能量刻度恰为一个基模能量。** 通过

**EC-5 $E_c$ 怎么造**：三条候选构造并排报出。

- **构造甲**（把持有时间折成摆程数）：$E_c = E_P \times \tau_{\rm rec}/t_P$。幂次 $-2.000000000$（残差 $3.553\times10^{-15}$），各档 $E_c$ 为 $0.001489$、$0.001336$、$0.001206$、$0.001094$、$0.000997$、$0.000837$。
- **构造乙**（能量守恒的能级差）：三档耦合的转移能量代价**皆为 $1.0000000000$**，极差 $0.000\times10^{0}$。**它与耦合无关，是个常数，没有分辨力。**
- **构造丙**（甲乘乙）：与甲同幂次。

**本轮以构造甲为读数**，理由是它唯一给出 $g^{-2}$ 幂次且与率接口自洽；乙与丙的读数一并报出。 通过

**EC-6 恒真检验**：把耦合关掉。

$\eta = 0.0$，$\tau_{\rm rec}$ 不定义（无穷），构造甲的 $E_c$ 在 $\eta = 0$ 处发散故报不定义。**替身与真构型可区分。** 通过

**EC-6b 防恒真**：$E_c$ 确实随耦合变吗？模型档 $g$ 上的极差 $0.00065128$，幂次 $-2.000000000$。**确实变。** 通过

**EC-7 档位标注**：两套读数都给。

- **模型档**：$g$ 以装置的 $g_{\rm full} = 5.091585$ 为单位，$E_c$ 以 $\omega_P$ 为能量单位。
- **物理档**：$g$ 以 $\omega_P$ 计，$E_c$ 以 GeV 给出。基准约定五档为 $1.2286\times10^{21}$、$3.0714\times10^{20}$、$1.3651\times10^{20}$、$7.6785\times10^{19}$、$6.3459\times10^{19}$ GeV；折算约定相应小 $2\pi$ 倍。

**两套普朗克能量约定相差 $2\pi$ 倍，用途不同不能混搭。** 通过

**EC-8 前提守恒**：复现第 394 号与第 726 号的读数。

$1/\sqrt C = 0.07053456$ 对机制篇读数 $0.0705$ 的相对偏差 $4.9024\times10^{-4}$；反向代入给 $\eta = 0.99902025$；三条绝对约束：$g_w \le 0.070535$（$0.011226\,\omega_P$）、$S = 5$ 时 $g_h \le 0.014107$、$N_{\text{拍}} = 100$ 时 $g_h \le 1.1191\times10^{-3}\,\omega_P$。写入侧基线五项偏差在 $10^{-13}$ 量级。 通过

## 四、重要发现

**其一，$E_c$ 的绝对标度给出，且是平方反比。** $E_c = E_P/(Cg^2)$。**耦合只进率、幅度恒为 1 的分工原则在 $E_c$ 上得到贯彻**：$E_c$ 里只出现 $\eta$，幅度侧不出现。

**其二，概率那半与能量那半在上界处合拢。** 概率守恒说耦合不能更大（否则 $\eta > 1$）；能量那半说耦合到上界时，持有刻度落到一个基模能量。**两半说的是同一个 $g_w$。**

**其三，写入耦合开到上界时，一个激发在寄存器里待一个摆程。** 这是本轮最直观的读数：$g_w$ 处 $\tau_{\rm rec} = 1$，$E_c = 6.28318531\,\omega_P$。

**其四，两条不同的能量读数要分清。** 转移付的**能级差**与耦合无关（三档皆 $1.0000000000$），而耦合造成的**能级分裂**随耦合变（$0.03923$、$0.11803$、$0.47214$）。前者是 $E_c$ 的候选，后者是另一个物理量。

## 五、方法论收获

**其一，复现一条恒等式级陈述时，判据量须与陈述的类型相合。** 第 394 条说「一次写入转移一个激发」，那是**几个**，判据量就该是整数计数。我首版读的是"搬走了多少比例"（完成度），那读数随耦合变（$0.912$ 至 $1.000$），因为耦合越强写得越快。**测的是速度，不是数目。** 改成计数后六个档全为 $1$。

**其二，读数窗口须与所测事件对齐。** 一次写入周期里，$0.5$ 时刻写进去，$1.0$ 时刻折返回来。首版取到 $1.2$ 的窗口，把折返也算进去了。改到写入完成、折返未到的窗口（$0.9$）才干净。

**其三，耦合造成能级分裂与转移付能级差，是两件事。** 我首版把本征值之差当能级差读，那读的是分裂（随耦合变），于是判否。改读对角元之差（转移代价，不随耦合变）才对。

**其四，绝对标度的读数须把不确定度的来源逐项列出。** 本轮的 $E_c$ 绝对值依赖三处口径：$g$ 读数（库内自标为外推量级估计）、普朗克能量的两套约定（差 $2\pi$ 倍）、$C$ 的模数与带宽口径。**但形式是稳的**：幂次 $-2$ 与上界档的 $\eta = 1$ 在口径改变时不变。

## 六、还剩什么

**其一，$E_c$ 与 $E_a$ 的比值本轮没做。** 两者不同类（一个是束缚能刻度，一个是持有刻度），第 724 号已判跨模型对表不合法。案乙的比值 $\rho$ 要用 $E_c$，那一步的合法性须另行处理。

**其二，$g$ 读数的精确化仍是待做计算。** 库内已登记。本轮只给形式与档位，不给体系值。

**其三，能量代价是否给出比概率守恒更紧的耦合上界，本轮未判。** 本轮的 $E_c$ 构造不含这一约束。

**其四，$E_c$ 在三维延展构型上的读数未做。** 本轮在单站点装置上做。
