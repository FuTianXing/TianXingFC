## 一、相容的三级强度

「体系与量子力学、相对论、规范场论相容」这句话在库内出现过多种写法，强度并不一致。按可判伪性可分三级。

- 数值兼容：本体层方程经参数调节能拟合既有数据。任何改写都能做到，没有判据。
- 极限对应：本体层方程在给定极限下逐项落到标准方程，并且标准侧的公设已被导出为定理。
- 带签名的极限对应：极限之外报出唯一且可判的偏离，并给定量级。

前两级把体系定位为标准理论的一种再表述，第三级才使它成为可判伪的物理理论。本对照要回答两件事：本体层是否需要第二套方程；三条链各自现在停在哪一级。

## 二、本体层：一条母方程与三个扇区

### 2.1 母方程

库内本体层的演化式均取「二阶时间演化 + 格点拉普拉斯 + 局域周期势」这一结构，扇区之间的差别在势的展开阶数与耦合项，不在方程的类型。

束缚振荡扇区取势的小振幅展开，得线性格点场方程（Klein-Gordon 型晶格波动方程）

$$\ddot\psi_n = -\omega_0^2\,\psi_n + c^2(\nabla^2_{\text{lat}}\psi)_n .$$

质量项 $-\omega_0^2\psi$ 来自异类耦合能隙，刚度项来自同类耦合（[[薛定谔方程的公设降级：束缚振荡晶格中的包络动力学与有效质量|《薛定谔方程的公设降级》]] §3.1）。缺陷扇区保留锁定势的整周结构 $K(1-\cos 2\pi u)$ 并加驱动与阻尼，得离散 sine-Gordon 形式（D 线甲形式）

$$\ddot v_n = k_b\nabla^2 v_n - K\,2\pi\sin(2\pi v_n) + f - \gamma_d\dot v_n + \xi .$$

### 2.2 扇区一：束缚振荡

频率取普朗克频率，色散曲率给出有效质量恒等式 $m^{*} = \hbar\omega_0/c^2$。方程本身处在经典序参量层，描述确定性演化；叠加、概率与测量语义由[[序参量份额定理：Born规则、归一化与幺正性的系综推导|份额定理]]供给，两层在《薛定谔方程的公设降级》§6 汇合。层级包容为：经典力学 $\subset$ 量子力学 $\subset$ 天行力学。

### 2.3 扇区二：锚核缺陷

两条质量标签必须分开：涨落缺口 $m_{\rm gap} = 2\pi\sqrt K$ 进声子谱，孤子质量 $M = 4\sqrt{k_bK}/\pi$ 进缺陷能动量关系，两者比值 $4.93$（D-2）。

终端速度律 $v_{\rm term} = f/(\gamma_d M_{\rm zero})$ 实测 $11.01$ 对期望 $11.08$（差 $0.56\%$）；响应质量等于形状范数（$0.0908$ 对 $0.0903$）；既有迁移率 $18.9$ 反解 $\gamma_d = 0.5958$（D-3）。碰撞层是纯置换，等速与每拍一格只在该层成立，连续侧速率被锁定势逐点调制（D-1）。

### 2.4 扇区三：写入与场耦合

C1 线给出三维复合位错形态与保护层（弦算符结构与到边界的弦），驻留阈值 $K_c = 0.24$ 至 $0.25$，脱钉阈值 $0.15$，宽度窗口 $l^{*} \ge 2$。张量桥分段 d 给出空间扇区的同源同格林函数要求。这一扇区仍在攻，规范力的产生机制未闭。

### 3.2 相对论链

洛伦兹恢复出现在长波极限下，签名是 $(E/E_P)^2$ 型修正与带上界。孤子扇区已给出相对论色散 $E^2 = M^2 + p^2$（D-2）与速度上限闭式

$$v_{\max}(m) = \frac{\sqrt{m^2+4}-m}{2}, \qquad m = \frac{1-v^2}{v}.$$

严格程度为条件性，遗留是全能标严格性（接 P1 与 P11）。

### 3.3 规范链

势与规范耦合的降级在《薛定谔方程的公设降级》§5。局域规范不变性的几何来源是相位提升与实轴基准的实在性，签名是接缝项（见 §四）。遗留为规范力（含电磁力）的产生机制，落在张量桥分段 d 与 C1 线。

### 3.4 多体支链

现状为内部草稿（2026-09-02，待评审），组装规则可区分情形取张量积，全同粒子按置换群的对称与反对称两支组装。遗留五项：(a) 相互作用项 $u_{kl}$ 的显式形式；(b) 相对论色散的全能标严格性；(c) 二粒子散射的晶格方程数值对照；(d) 任意子的编织相位；(e) 二次量子化算子与 Q1 合并。

支链不能由单体合并省掉。单体只证明公设降级这条路可行；先验纠缠、交换统计与非定域关联只在多体层出现，也正是体系唯一可判伪的地方。

## 五、缺口清单

1. 连续与离散的接缝（D-5）：缺陷每穿过一个格点写下的笔数是否等于包络模方。判定形式干净：自动相等则双侧互补在这条线上成为定理，不等则得到限制量子化方式的负面结果。
2. 多体的相互作用项 $u_{kl}$ 与二次量子化算子（多体草稿遗留 a 与 e）。这两项在多体层之外看不见，无法由单体直接复制。
3. 规范局域不变性的来源与规范力的产生机制（张量桥分段 d、C1）。

## 六、多体草稿的转正条件

三条。其一，把遗留 (a) 的 $u_{kl}$ 从「硬核投影待定量」推进为显式形式或明确的待定式。其二，补一次二粒子散射的晶格方程数值对照（遗留 c）。其三，遗留 (e) 的二次量子化算子与 Q1（Fock 份额构造）合并后单独立条。三条齐备后走评审与修订流程，再按[[子理论索引]]登记。
