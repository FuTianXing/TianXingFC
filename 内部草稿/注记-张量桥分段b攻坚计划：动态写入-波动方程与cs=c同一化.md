## 一、任务定义与判据操作化

3+1 雏形的写入动力学为一阶扩散流（每拍注入 + 邻居抄写平均 = 离散拉普拉斯流），稳态 = 泊松，但**无波动模式**（引力波缺位）。色散论文[[元相子振荡晶格的色散关系：低能光速涌现与洛伦兹破坏首阶项|元相子振荡晶格的色散关系]]已证本体晶格相位波低能 $\omega = c|\mathbf{k}|$（$v_s = c$ 由 $K_0 = \bar t_P c^2/l_P^2$ 固定）。

分段 (b) 的核心命题：**写入场（标架倾斜场）的动态动力学是阻尼波动方程**

$$\ddot\theta + \gamma\dot\theta = c_s^2\nabla^2\theta + s$$

- $\gamma$ 大（过阻尼）：退化为写入-扩散，稳态 = 泊松（3+1 雏形已有）；
- $\gamma$ 小（弱阻尼）：波动模式，即引力波；
- 判据 b1：弱阻尼极限波前速度 = $c_s$，且 $c_s = c = l_P/t_P$（与本体晶格声速同一化）；
- 判据 b2：过阻尼极限收敛到泊松稳态（与 3+1 雏形 CG 解一致），机制统一；
- 判据 b3：连续极限恢复 d'Alembert 方程 $\square\theta = 0$（源外）。

## 二、数值设计

离散阻尼波动方程（leapfrog，$\Delta t = t_P$，$c$ 无量纲 = 1 格/拍）：

$$v \leftarrow v(1-\gamma) + c^2\nabla^2_{\text{disc}}\theta,\qquad \theta \leftarrow \theta + v$$

- 离散拉普拉斯 $\nabla^2_{\text{disc}}\theta = \frac{1}{l_P^2}\big(\sum_{\text{nb}}\theta - 6\theta\big)$；
- 源：中心格点振荡注入（脉冲或周期驱动）；
- 波前测量：沿 x 轴 $|\theta|$ 超阈值的最远格点位置 vs 时间，斜率 = 波速（格/拍）；
- 对照：弱阻尼波速 vs 1.0（$=c$）；过阻尼稳态 vs CG 泊松解。

## 四、风险登记

1. **阻尼与波速的耦合**：$\gamma$ 中等的频散（阻尼使波速略降），需区分本征色散（$k^2$ 修正）与阻尼频散；
2. **源的引力波谱**：真实引力波是源的 $\ddot Q$（四极矩）辐射，本分段只判传播速度，辐射机制（源项 $T_{\mu\nu}$ 微观分解）归分段 (d)；
3. **不扩展到判据之外**：不判引力波的极化结构（张量/标量自由度）、不判后牛顿修正（分段 (c)(d) 与总判据）。
