## 一、问题的提出

体系同时持有两条陈述，字面并列会读成矛盾。

其一，**粒子的局域性**：电子的四个标签之一是「局域性 = 锚核钉位」，与电荷、自旋、质量并列。

其二，**位置的铺开**：位置的读数一般铺开。《叠加态的场侧画像》§7.2 写「定域态（窄波包、扭结支）与铺开态（均匀轻微失焦）同为允许的场态」，定案之前粒子以铺开的场侧画像存在。

于是一处表面矛盾浮出：位错被钉住（局域），它的位置却铺开。

## 二、局域性三义

审查发现，矛盾的表层原因是**「局域性」一词在体系里至少有三个所指**。

| 所指 | 内容 | 出处 | 严格程度 |
| --- | --- | --- | --- |
| 粒子的局域性 | 锚核钉位（本相机制） | [[量子场论地位总论：模式与实体的双层结构]]；[[从复合位错到爱因斯坦场方程：粒子机制现状综合与攻坚纲领]] | 定案 |
| 相互作用的局域性 | 感知结构（每点只与邻居作用） | [[天行力与规范原理的物理来源：去中心化校准作为规范对称性与相干基态的基础]] 定理 6 | 条件性命题（耦合结构三维近邻时成立） |
| 位置读数的铺开 | 层位份额分布 | [[内部草稿/注记-层位份额语义：从人数份额到相干份额的物侧定义]] | 判据级 |

三义混用，是那处矛盾读起来古怪的真正来源。

## 三、各义的出处与限定

### 3.1 粒子的局域性

四标签的完整形式为：电荷 = 绕数、自旋 = $\pi$ 扭转、质量 = 锁定能隙、局域性 = 锚核钉位。前三项为不变量（拓扑量与能标），故并列写法诱导读者把第四项也读成不变量。

**此处有一处限定须同时引用**。[[粒子与时空的同生：凝固波前的缺陷形成机制]] 原文写：

> 四标签的承载机制各自定案或条件成立，本文的贡献是让它们落在同一时空事件上；**此为组合声明**，前作把四标签统一于单一几何对象的更强声称已随形成方案一并废弃。

也就是说，四标签是**组合声明**，与「统一于单一几何对象」的强声称有别。这一点在引用时必须带上。

另有一处术语须注意：《有质量粒子的形成》记「局域性 = $\sigma$ 锁定」，而「$\sigma$ 锁定」为退役术语（该方案 2026-09-05 废弃）。同一含义的现行写法是「锚核钉位」或「位错钉扎」。引用旧文时须换算。

### 3.2 相互作用的局域性

定理 6 是一条独立的定理，与粒子的位置无关。原文：

> **定理 6（局域性 = 感知结构）**：规范场论的局域性（每个时空点只与相邻点相互作用）来自每个元相子的感知结构：天行力只感知邻居（局域耦合），只校正自己（自主）。没有超距感知，没有全局协调，传播由局域感知-校正链产生。**局域性从元相子的感知结构推导出来，不是假设。**

它讲的是**规范场论**的局域性（相互作用只及近邻），严格程度为条件性命题。这一义与位置口径无关，但共用「局域性」一词，是混读的主要入口。

### 3.3 位置读数的铺开

位置概率的承载者是层位份额 $W_n$，它是背景场亏空深度的归一化分布。定域 kink 给峰形分布（质心即位置，宽度约 $\ell$），双 kink 给双峰且权重按各自滑量分配。

故「铺开」说的是**读数在层上的分布形态**，属关系层读数。

## 四、锚核与层位份额不在同一层

把三义分开之后，那处矛盾可以直接分辨。

**锚核钉位**说的是粒子的**本相机制**：格点内锁定提供绑定能并钉住位错。它属身份描述，描述的是粒子的定域本相。

**层位份额**说的是**态的读数分布**。它属关系层读数。

两者是不同层的量，本来就不该要求同域，故不构成矛盾。**这一分辨不需要改动任何一条既有陈述**：四标签仍成立（它们描述本相），铺开仍成立（它描述态读数）。

## 五、一处支持性证据：体系自己区分了本相与画像

[[叠加态的场侧画像：单一场承载、份额折叠与相位通道]] §2.1 原文：

> 扭结剖面……是单粒子的**定域本相**。位置基 $|n\rangle$ 即法线轴层位；**定案（层位占据转移）之后粒子以扭结本相现身，定案之前它以本文构造的场侧画像存在。**

这条给出本相与画像的时序：定案之后是本相（局域扭结），定案之前是画像（铺开）。它与第四节的层级分辨相容，并进一步说明**局域本相是定案的产物**。

## 六、坐标标签：网格刚性使非局域只住占据侧

「位置」的所指不止三处，还须加上**坐标标签**这一层：时空晶格的格点标签 $x^a = l_P n^a$。

**它完全局域而固定。** 依据是晶格刚性原理：格距 $l_P$ 与摆程 $t_P$ 是绝对常数，网格是固定参照网格，其中的物理不移动它（[[理论总纲/公理体系]] §6；该节同时写明「空间有绝对尺度、只有相对位置有意义」）。

加上这一层，方向分布变得清楚。

| 项 | 性质 |
| --- | --- |
| 坐标标签（格点 $x^a = l_P n^a$） | 完全局域且固定 |
| 锚核钉位（本相） | 严格局域 |
| 层位份额（读数） | 一般铺开 |

**由此得到一处澄清：非局域只住在占据侧，不住在坐标侧。**

展开说：坐标网格是刚性的、局域的、固定的，它本身没有任何非局域性；锚核被钉在**某一个**标签上，也是局域的；铺开的只是**粒子对这些标签的占据分布**。

所以准确的说法是「**占据模式铺开**」，与「位置非局域」有别。原先那处「位错局域而位置铺开」的矛盾感，来自把占据模式读成了坐标本身。

网格刚性在这里起决定作用：**网格不能动，故非局域无处可住，只能住在粒子的占据结构上。**

## 七、审查：原读法的成色

**本节为本注记的分析，非体系陈述。**

审查的对象是 [[内部草稿/注记-定域与非定域相互作用的互补结构]] 第八节原先登记的读法：「局域性属态的性质（局域态里两者都局域，铺开态里两者都铺开）」。

**该读法成立**，支持它的证据有三条：其一，§2.1 的本相与画像分辨（第五节）；其二，锚核的物理身份是格点内锁定势，在每个格点都在，故铺开态里钉扎在两瓣都在；其三，折叠恒等式给出叠加态的代价等于单缺陷的一份，质量（由锚核供给）是一份而分布在两瓣上，与之相容。

**但它有一处代价**：该读法需要把四标签中的「局域性」从身份陈述降为机制陈述。四标签的并列写法（与三个不变量并列）支持身份读法，故该读法属**修补**。

**第四节的分层分辨不需要这处修补**，因此更稳。两者的关系是：分层分辨说的是「两个量不同层」，原读法说的是「同一个量随态而变」。前者弱于后者，但已足以消解矛盾，且不动既有陈述。

**建议**：采用分层分辨为正式口径，原读法作为等价说法保留。第八节已按此改写，并把该接口从「开放项」改记为**术语口径项**。

## 八、一处物理待办：玻姆型结构

**本节为本注记的分析，非体系陈述。**

第六节的澄清解掉的是术语层的古怪。它同时暴露一处**物理**待办，两者须分列。

把两条并列：锚核**严格局域**（钉在某个标签上），层位份额**铺开**。合起来即：粒子有一个确定的锚核位置，同时有一个铺开的占据分布。

这一结构与玻姆力学同型（确定本体加统计读数）。体系里有一处登记在案的未建项正对此：

> 个体属性为何不提供额外预测力（量子平衡的对应物）——未做。

也就是说：若「锚核严格局域」是体系的正规陈述，那么按玻姆力学的经验，确定的位置应当给出可检验后果（非平衡制备下的频率偏离 Born 份额）。体系主张「态矢量对个体层沉默」，而这一主张需要一条论证来支撑。

两件事须分清，不可互相代替。

| 事项 | 状态 |
| --- | --- |
| 「位置」一词的所指混用 | **已清**（第六节的澄清） |
| 锚核确定位置的可观测后果 | **仍在**（对应上述未建项） |

前一轮把该接口判定为术语口径项，这一判定对术语层成立；对物理层，此处补记：**待办未消**。

## 九、结论

| 问题 | 判定 |
| --- | --- |
| 表面矛盾是否成立 | **不成立**，是术语混用所致 |
| 「局域性」有几个所指 | 至少三个（粒子、相互作用、位置读数） |
| 是否需要新物理 | **不需要** |
| 该接口的性质 | **术语口径项**，不属物理缺口（术语层） |
| 锚核确定位置的可观测后果 | **仍在**，对应「个体属性为何不提供额外预测力」未建项 |
| 首选口径 | 锚核属本相机制、层位份额属态读数，两者不同层 |

**处置建议两条**。其一，凡引用「局域性」处，宜带上所指（粒子的局域性 / 相互作用的局域性 / 位置读数的铺开），尤其在同时涉及位置与规范两处时。其二，引用四标签时须同时带「组合声明」的限定，避免读成「统一于单一几何对象」的强声称。
