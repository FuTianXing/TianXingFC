## 一、时空几何模型

取一维链，格距 $l_P$，速度 $c = l_P/t_P$。元相子 A 居格点 $n=0$（圆心活动区间 $[0,l_P]$），B 居格点 $n+1=1$（区间 $[l_P,2l_P]$），共享公共边界 $z = l_P$。两者反相（注释 03 第 5 点），相向运动。以碰撞时刻为原点 $t=0$（两圆心在公共边界 $z=l_P$ 处重合）。

圆心横坐标（取 $l_P$ 为单位，$|t| \le t_P$）：

$$\bar z_A(t) = 1 - |t|, \qquad \bar z_B(t) = 1 + |t|$$

其中 $\bar z = z/l_P$，$\bar t = t/t_P$。碰撞前 $t<0$ 为 A 去程 / B 回程（相向逼近），碰撞后 $t>0$ 为 A、B 各自折返背离。

**推论 1（圆心间距）**：两圆心间距

$$d(t) = \bar z_B - \bar z_A = 2|t| \cdot l_P$$

**推论 2（中点恒定）**：两圆心中点恒为

$$\bar z_{\text{mid}} = \frac{\bar z_A + \bar z_B}{2} = 1$$

即二圆心关于公共边界 $z=l_P$ 严格对称，无论何时。

## 二、正确的排斥判据

**关键澄清**：元相子的排斥约束是"圆心不可重合"，其根源是数学点不可重合（注释 15 第 4 点：数学点不可重合 = 粒性不可穿透的几何根源）。圆心是数学点，零维、无延伸、不可再分（注释 15 第 2 点），位置无延伸（第 7(c) 点："粒子有标度（半径）但位置无延伸（圆心），二者不冲突"）。

由此，**排斥判据是：两圆心在任一时刻不能落在同一连续坐标，两圆心坐标互异即可，不存在最小间距约束。** 复平面单位圆半径 $R = l_P/2\pi$（由螺距等式 $\lambda = 2\pi R = l_P$ 给出）是内部 U(1) 空间的弧长标度（数学层，第 127 行：周长 $2\pi R = \lambda$ 属数学层，不可直接测量），**不构成外部空间（法线方向）的位置延伸，不参与圆心间距的排斥判定。**

把单位圆直径 $2R$ 当作外部空间排斥约束，是把内部 U(1) 半径误当外部位置延伸，与原稿错误一致，本次修正予以消除。

## 三、C 落位的真正约束

新元相子 C 落位，需同时满足两条：

1. **圆心坐标互异**：C 的圆心坐标不与该时刻 A、B 的圆心坐标重合。因排斥 = 数学点不可重合，仅此一条，无间距下限。
2. **格点归属离散**：C 归属于一个离散格点 $l_P m$（$m \in \mathbb{Z}$，公理 2 格点坐标离散）。圆心在摆程内的连续位置 $z_C(t)$ 属于格点 $m$ 的活动区间 $[m l_P, (m+1) l_P]$。

## 四、空当窗口判定

**判定一（窗口宽度）**：因排斥只要求圆心坐标互异，C 在任何时刻都可以落位，只要它的圆心当前不恰好与 A、B 圆心重合。在 $|t|>0$ 的任一时刻，A、B 圆心分别在 $1-|t|$ 与 $1+|t|$（$l_P$ 单位），二者互异，C 可落在与原公共边界 $m=1$ 相应的格点（或其活动区间内的远离 A、B 圆心坐标之处），圆心不与 A、B 重合。**几何空当从碰撞按下（$|t|$ 任意小）即开始存在，无需等到 $|t| \ge 0.318\, t_P$。** 此前的 $2R$ 约束是错误引入的。

**判定二（落位坐标）**：C 归属的格点坐标 $l_P m$ 受离散约束。在 A、B 之间，唯一的整数格点是原公共边界 $m=1$；C 若落该格点，其圆心连续坐标 $z_C$ 处于区间 $[l_P, 2l_P]$ 内且不与 A、B 圆心重合即可。也可落在外侧格点（$m\le 0$ 或 $m\ge 2$），只要不与 A、B 圆心重合。

**判定三（格点归属重排）**：C 归属格点 $m=1$ 时，该格点的活动区间 $[l_P,2l_P]$ 原本归 B 所有。C 若要落户于此，需要 B 让位或该区间被重新分配，即**格点归属重排**。这是 C 插入的实质障碍，与"圆心是否够细"无关。

## 五、精确时空边界结论

修正判据后的结论如下。

1. **几何空当存在**：A、B 圆心间距在 $t = \pm t_P$ 时达到最大 $2l_P$（A 退回 $z=0$，B 退至 $z=2$），此时原公共边界 $z = l_P$ 处无圆心。几何空当始终存在（$|t|$ 从 0 增长到 $t_P$）。

2. **可容纳 C 的时间窗口**：因排斥只要求圆心坐标互异，C 在 $0 < |t| \le t_P$ 的整个窗口内均可落位（只需不与 A、B 圆心重合）。窗口总宽 $2t_P$（双侧），比原稿（$0.318\, t_P \le |t| \le t_P$）更宽。

3. **空间边界**：C 的归属格点必须取整数格 $l_P\mathbb{Z}$，在 A、B 之间仅 $m=1$ 可选，其余候选在外侧。

4. **决定性约束**：C 落在 $m=1$ 触发格点归属重排（B 让位等）。**空当为 C 插入提供了空间条件，格点归属重排是实际障碍。** 约束的核心在格点归属的离散与重排，不在圆心粗细。

## 六、严格程度

1. 上述时空轨迹（$\bar z_A = 1-|t|$、$\bar z_B = 1+|t|$、间距 $2|t|l_P$、中点恒定）为直接运动学推论，锚定注释 03 的碰撞折返几何，达到条件性命题级。

2. 排斥判据（圆心坐标互异、无 $2R$ 间距下限）依据注释 15 第 7(c) 点"位置无延伸"，为条件性命题。

3. C 插入的判定（C 归属整数格点、C 落 $m=1$ 触发格点归属重排）为条件性命题（依赖格点坐标离散公理 2）。

4. "格点归属重排"的具体动力学（B 让位顺序、能量代价、三维三元组推广）为开放问题，未在本注记闭合。本注记给出的是时空边界与判定，非已证定理。

## 七、遗留

- 格点归属重排的动力学：C 插入时 B 让位一格的具体顺序、位移链与能量代价。
- 三维三元组推广：三方向（X/Y/Z）空当窗口的交错时序、$\kappa_\phi$ 耦合对插入的影响。
- C 插入频率与哈勃膨胀 $H_0$ 的衔接：需要多少空当插入事件才产生观测到的膨胀速率。
- "格点归属重排"与"格距保持 $l_P$"能否同时严格成立的详细论证。
