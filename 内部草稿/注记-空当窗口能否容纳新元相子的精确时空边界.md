## 一、时空几何模型

取一维链，格距 $l_P$，速度 $c = l_P/t_P$。元相子 A 居格点 $n=0$（圆心活动区间 $[0,l_P]$），B 居格点 $n+1=1$（区间 $[l_P,2l_P]$），共享公共边界 $z = l_P$。两者反相（注释 03 第 5 点），相向运动。以碰撞时刻为原点 $t=0$（两圆心在公共边界 $z=l_P$ 处重合）。

圆心横坐标（取 $l_P$ 为单位，$|t| \le t_P$）：

$$\bar z_A(t) = 1 - |t|, \qquad \bar z_B(t) = 1 + |t|$$

其中 $\bar z = z/l_P$，$\bar t = t/t_P$。碰撞前 $t<0$ 为 A 去程 / B 回程（相向逼近），碰撞后 $t>0$ 为 A、B 各自折返背离。

**推论 1（圆心间距）**：两圆心间距

$$d(t) = \bar z_B - \bar z_A = 2|t| \cdot l_P$$

**推论 2（中点恒定）**：两圆心中点恒为

$$\bar z_{\text{mid}} = \frac{\bar z_A + \bar z_B}{2} = 1$$

即二圆心关于公共边界 $z=l_P$ 严格对称，无论何时。

## 二、空当的时空边界

元相子复平面单位圆半径（由螺距等式 $\lambda = 2\pi R = l_P$）为 $R = l_P/2\pi \approx 0.159\, l_P$，直径 $2R = l_P/\pi \approx 0.318\, l_P$。格距 $l_P$ 与之比较：$2R < l_P$，故相邻整数格点（间距 $l_P$）上的单位圆不重叠。

设新元相子 C 的圆心落在整数格点 $z_C = m l_P$（$m \in \mathbb{Z}$）。C 能与 A、B 并存的最小条件是：C 圆心到 A 圆心、C 圆心到 B 圆心的距离均不小于 $2R$（单位圆不重叠）。

**情形 α：C 落在原公共边界格点 $m=1$。** 此时

$$|z_C - \bar z_A| = |1 - (1-|t|)| = |t|, \qquad |z_C - \bar z_B| = |1 - (1+|t|)| = |t|$$

需 $|t| \ge 2R/l_P = 1/\pi \approx 0.318$（即 $|t| \ge 0.318\, t_P$）。此情形下 C 距 A、B 圆心等距，均为 $|t| l_P$。

**情形 β：C 落在外侧格点 $m=0$ 或 $m=2$。** 计算 $|z_C - \bar z_A|$、$|z_C - \bar z_B|$，在 $m=0$ 时 C 紧贴 A 的格点归属区，与 A 圆心距离 $= |0-(1-|t|)| = 1-|t|$，需 $\ge 2R \approx 0.318$，即 $|t| \le 0.682\, t_P$；同理 $m=2$ 对 B。

## 三、核心判定

格点坐标为整数格 $l_P\mathbb{Z}$（公理 2），C 的圆心只能落在整数格点。由此得到如下判定。

**判定一：空当内部有无"空置整数格点"。** A、B 占据相邻整数格点 $0,1$，二者之间没有任何其他整数格点。原公共边界 $m=1$ 本身是一个整数格点，但它被 A、B 的格点边界共享，并非"空置格位"。因此空当内部**没有天然的第三个整数格点**可直接安放 C。

**判定二：C 能否"借用"公共边界格点 $m=1$。** 当 A、B 圆心各退到一侧时（$|t|$ 增大），公共边界 $z=l_P$ 处暂时无圆心占据。具体地，在 $|t| \ge 0.318\, t_P$ 时，$m=1$ 处距 A、B 圆心均 $\ge 2R$，可容纳 C。此时 C 与 A、B 形成"三个圆心间距 $\ge 2R$"的合法构型。

**判定三：格距约束（C 占格点区间的问题）。** 这一判定是关键。A 归属格点 $0$（区间 $[0,l_P]$），B 归属格点 $1$（区间 $[l_P,2l_P]$）。若 C 落在 $m=1$，它需要自己的格点区间；但格点 $m=1$ 的区间 $[l_P,2l_P]$ 已被 B 占用。因此 C 落在 $m=1$ 必然要求格点归属重排，即原本的 A、B 相邻格点被重新划分为包含 C 的三个格点，且格距仍须保持 $l_P$。这等价于：**C 的插入伴随格点重排，不能单靠"空当"实现。**

## 四、精确时空边界结论

综合判定，空当窗口的精确时空边界如下。

1. **几何空当存在**：A、B 圆心间距在 $t = \pm t_P$ 时达到最大 $2l_P$（A 退回 $z=0$，B 退至 $z=2$），此时原公共边界 $z = l_P$ 处无圆心。几何上，这一个"空档"确实存在。

2. **可容纳 C 的时间窗口**：C 若落在公共边界格点，需 $|t| \ge 0.318\, t_P$（圆心间距 $\ge 2R \approx 0.318\, l_P$），窗口为 $0.318\, t_P \le |t| \le t_P$。窗口总宽度约 $0.68\, t_P$（双侧合计），最宽点（$|t|=t_P$）时 C 与 A、B 各距 $l_P$，构型最优。

3. **空间边界**：C 的圆心只能取整数格点 $l_P\mathbb{Z}$，在 A、B 之间仅 $m=1$ 可选，其余候选在外侧（$m\le 0$ 或 $m\ge 2$）。

4. **决定性约束**：空当窗口在几何上能容纳 C，但 C 落在 $m=1$ 必然触发格点归属重排（把相邻两格点区重划分为包含 C 的三格点区，格距仍为 $l_P$）。因此**空当是 C 插入的必要几何条件，格点重排是充分条件**，二者缺一不可。

## 五、时空能量的直觉刻画

沿对称性看，A、B 折返背离的行程在 $t=0$ 到 $t_P$ 内把"公共边界一点"的几何拉开成一整格 $l_P$ 的间隙。这个间隙若要在内部产生新格点，需要外部"提供"一个整数格位给 C，并让邻近元相子（A、B）各自的格点归属让出。因而插入的代价是一段格点重排，落点是格点归属的整体让位与空间调整，超出单纯填空。此机制把膨胀与振荡节拍耦合时，产生的是格点密度的局部重排，整体格距仍保持 $l_P$。

## 六、严格程度

1. 上述时空轨迹（$\bar z_A = 1-|t|$、$\bar z_B = 1+|t|$、间距 $2|t|l_P$、中点恒定）为直接运动学推论，锚定注释 03 的碰撞折返几何，达到条件性命题级。

2. C 插入的判定（$|t| \ge 0.318\, t_P$、须在整数格点、须格点重排）为基于格点离散与单位圆直径的分析，属条件性命题（依赖格点坐标离散公理 2 与单位圆半径约定 $R=l_P/2\pi$）。

3. "格点重排"的具体动力学（A、B 让位顺序、能量代价、三维三元组推广）为开放问题，未在本注记闭合。本注记给出的是时空边界与判定，非已证定理。

## 七、遗留

- 格点重排的动力学：C 插入时 A、B 让位一格的具体顺序、位移链与能量代价。
- 三维三元组推广：三方向（X/Y/Z）空当窗口的交错时序、$\kappa_\phi$ 耦合对插入的影响。
- C 插入频率与哈勃膨胀 $H_0$ 的衔接：需要多少空当插入事件才产生观测到的膨胀速率。
- "格点归属重排"与"格距保持 $l_P$"能否同时严格成立的详细论证。
