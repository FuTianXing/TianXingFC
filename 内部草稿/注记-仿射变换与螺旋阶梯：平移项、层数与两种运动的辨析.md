## 一、仿射变换（外部数学，标准内容）

一个神经元单层的计算写作 $y = \sigma(Wx + b)$。括号内那一步 $x \mapsto Wx + b$ 即仿射变换：矩阵 $W$ 是线性部分，向量 $b$ 是平移部分。线性部分由旋转、拉伸与剪切三种基本动作复合而成，它把原点钉在原地；平移部分把变换结果整体搬走，原点随之移动。

仿射变换与线性变换的分别只在原点。线性变换把原点映到原点，仿射变换允许原点搬家。若改用 $n+1$ 维齐次坐标书写，两者同为线性映射，这是把仿射单独列为一类变换的标准处理。

神经网络在仿射之后必须接非线性激活函数。省略它，多层仿射的复合仍是仿射：

$$W_2(W_1x + b_1) + b_2 = (W_2W_1)x + (W_2b_1 + b_2)$$

深度因此失去意义。这一节为外部标准内容，与体系无关。

## 二、对照骨架（体系定案）

螺旋阶梯几何的运动学是：相位角 $\theta$ 在复平面单位圆上连续旋转，每完成一次满周闭合 $\theta = 2\pi n$，圆心沿法线方向平移一格 $l_P$。参数化为

$$\mathbf{X}(\tau, r) = \left(r\cos\omega\tau,\; r\sin\omega\tau,\; c\tau\right)$$

相位 $\theta = \omega\tau$ 与位移 $z = c\tau$ 同为参数 $\tau$ 的线性函数，比例 $c/\omega = l_P/(2\pi)$ 恒定。

把旋转写成矩阵形式，对应关系可以更紧。设 $\mathbf{p}$ 为初始径向向量，$\mathbf{R}(\omega\tau)$ 为绕法线的旋转矩阵，$\mathbf{n}_{\text{法}}$ 为法线方向，则

$$\mathbf{X}(\tau) = \underbrace{\mathbf{R}(\omega\tau)\,\mathbf{p}}_{\text{旋转}} + \underbrace{c\tau\,\mathbf{n}_{\text{法}}}_{\text{位移}}.$$

这与 $Wx + b$ 同为矩阵项加平移项的形式，两项相加构成轨迹。文献的表述是相位向量在单位圆上连续旋转与法线方向推进两种活动同时进行，只有旋转则轨迹是圆，只有推进则轨迹是直线，两者耦合才给出螺旋。

按定理 3.1 与推论 3.1，旋转轴唯一且过圆心，圆心是旋转中唯一不动的点。按定理 3.2，平移方向必须与旋转轴重合，该定理只用到 $\mathrm{SO}(2)$ 对称性，不依赖动力学细节。按命题 3.1，波性侧活动在圆周上展开，粒性侧法线负责空间位移。

三处形式对应列在下表。

| 仿射变换          | 螺旋阶梯                     | 体系依据   |
| ------------- | ------------------------ | ------ |
| 线性部分 $W$，原点不动 | 相位旋转，圆心不动                | 推论 3.1 |
| 平移部分 $b$      | 法线层数 $n$，$b^a = l_P n^a$ | 距离归粒   |
| 复合 $Wx + b$   | 两项由同一 $\tau$ 驱动          | 参数化    |

末行的性质与前两行相反。仿射变换的两项互相独立，$W$ 与 $b$ 可以任意搭配；螺旋阶梯的旋转矩阵随 $\tau$ 转动、平移项随 $\tau$ 增长，两项由同一个参数驱动。据此，螺旋的每一时刻截面是仿射映射，整条轨迹是一族仿射映射，族参数为 $\tau$。这一处差别在第七节展开。

## 三、层数的两种含义（体系定案）

[[理论总纲/术语表]]「层数通道」条把层数定为承载满周闭合事件累计计数的离散通道，基矢由沿法线轴相对局域基准的键差分定义，取值于 $\mathbb{Z}$，真空锚定 $n = 0$，绕数为它沿闭合回路的净差。这一层含义是元相子的状态读数，问的是某个元相子处在第几层。

[[构型]] 另有一层用法：位错的层数偏离是构型，取值空间 $M = \mathbb{Z}$，即给每一个位置各指定一个层数取值之后得到的整体分布。这一层含义问的是层数在空间上如何分布。

同一批数据可以支撑两种提问，回答的对象不同。状态读数与构型的分野，是下文辨析两种运动的工具。

## 四、两种运动的分野（体系定案）

[[位错]] 的表述是"运动由转换波执行：位错（图案）换装前进，材料元相子原地不动"，[[复合位错粒子]] 补充为"前端格点锁定、后端格点释放，锁定区边界像波一样前进"。位错移动时，承载它的元相子没有跃迁，状态读数原地不变，变的是层数构型里异常的位置。

[[元相子]] 的表述是"碰撞接力，光速传播，一步一摆程"，[[元相方程]] 给出定量形式：摆锤转满一圈，钟向前挪一格，转圈快慢由 $\omega_P$ 定，步长由 $l_P$ 定，两者的比值即光速。这里状态读数确实递增，元相子本体在跃迁。

| 运动   | 状态读数 | 层数构型   | 载体         |
| ---- | ---- | ------ | ---------- |
| 光的传播 | 递增   | 随动     | 碰撞接力，一步一摆程 |
| 位错运动 | 不变   | 异常位置移动 | 转换波，前端锁后端放 |

两者落在"层数"一词的两侧。光让状态读数递增，位错让逐处分布变形。作者原先把两者统一在"层数的变化"之下，此处按体系定案拆开。

## 五、$b$ 在体系里的位置（体系定案加一处修正）

[[理论总纲/术语表]]把层数定为历史变量，物侧投影配置空间冠"投影"之名正因如此：$(\theta, n)$ 是对跃迁历史的投影。所以体系里 $b$ 存在，其值由演化累积给出。

神经网络里的 $b$ 由训练给出，两者同为历史沉淀，来源不同。前一版对话中说"体系里找不到一个与 $b$ 对应的可调量"，准确的说法是体系里没有与 $b$ 对应的自由参数，即它不由外部指定，而非它不存在。

## 六、天行方程的 $\tanh$ 与相变判据（体系定案加一处分辨）

天行方程的基本形式为

$$\Xi(T) = \tanh\left\{\Re\left[\left(\int_0^T \mathcal{W}(t)\otimes\mathcal{P}(t)\,dt\right)^2\right]\right\}.$$

外层的 $\tanh$ 是体系自带的激活函数，作用是把无界净值压缩到 $(-1,+1)$。按 [[关于天行力学的一份理论纲领]] 的四环节说明，净值跨过约 $\pm 1.39$ 的临界阈值时，系统命运发生不可逆的结构性跃迁，$+1$ 为兴，$-1$ 为衰，$0$ 为混沌未决。体系里因此同时存在激活函数与相变临界点，两者的阈值由 $\tanh$ 的数学性质内禀规定，不随外部调整。

满周闭合与相变的联系另有一处对照。[[单位圆、整数与物理离散性的同源结构]] §4.4 把自耦合定理的满周闭合与李-杨定理的相变判据并置：李-杨定理断言配分函数零点在正实轴 $z = 1$ 处堆积时触发宏观相变，自耦合定理断言相位每完成满周闭合时触发一次离散跃迁，两者共享同一几何触点，即单位圆与正实轴的交点。触发机制互相独立，前者是时间性的节拍，后者是空间性的密度。

需要分辨两个不同的 1。$\Xi = 1$ 是 $\tanh$ 的渐近饱和值，对应"兴"的极端；李-杨判据中的 $z = 1$ 是正实轴上的相变触点，满周闭合与之共享几何位置。把满周闭合说成对应 $\Xi = 1$，会把审计的饱和与相变的触发混为一谈。作者提示中的直觉在"满周闭合是相变"这一层成立；若要指出数值落点，体系文献给出的是正实轴上的交点。

## 七、分析性内容与严格程度

以下五条为本次对照的产出。前四条体系文献未载，按纲领级或直觉级看待；第五条为作者指示收录的层级定位，同样标为纲领级。

- **形式骨架的重合**。两者都是"保持某点不动的部分"加"搬运整体的部分"的组合，两项相加给出结果。推论 3.1 强调的圆心唯一不动，正是线性部分不动点结构的一个特例。
- **两者都在可逆骨架上插入多对一压缩**。$W$ 可逆时仿射是双射，相位旋转也可逆；ReLU 把负半轴压成 0，满周采样把相位区间 $[2\pi n, 2\pi(n+1))$ 压成一个格点，两者都是多对一。压缩的作用轴不同：激活函数压值域，满周采样压相位轴。体系侧的多对一是时间箭头的结构来源（[[物理时间不可逆的信息压缩起源：采样映射的非单射性、相位混叠与典范截面的不存在]]）。
- **体系里没有"一个"仿射变换**。每个元相子各有一个，位错运动是这一族变换的 $b$ 值分布在场空间里变形，单个仿射变换装不下它。这一点与神经网络的多单元结构相合。
- **自由度只能落在耦合上**。单个元相子内部没有可调参数，位移方向由定理 3.2 唯一锁定，步长由 $l_P$ 唯一锁定，判据阈值固定在 $2\pi n$。若体系要谈"学习"，自由度只能出现在元相子之间的耦合，即法线场与相位差网络。
- **几何化定位**。元相子的旋转+位移机制是仿射变换的几何化（2026-09-23 作者指示收录）。这一句是层级判断，把螺旋阶梯的两项合成置于更基本的地位，仿射变换作为它在计算层面的形式表达。本文档给出的是形式骨架的重合与三处差别，未论证该层级关系，故列纲领级。
