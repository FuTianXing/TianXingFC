## 一、概率进入物理的三次浪潮

第一次来自统计力学。气体分子数目巨大，逐点跟踪没有意义，于是引入相空间上的分布 $\rho(q,p)$，用平均代替个体。这一次的读法是认识论的：微观动力学仍旧确定，概率表达我们对初条件的无知。玻尔兹曼与吉布斯的分歧只在于这个分布应当按时间平均还是按系综解释。

第二次来自随机过程。布朗运动的分析把概率写成微分方程（朗之万、福克、普朗克），随机性被安放在粗粒化的界面上：底层可以确定，界面上的有效描述是随机的。

第三次来自量子力学。1926 年玻恩给出规则：波函数的模方给出概率。与前两次不同，这一次概率没有被安置在"无知"或"粗粒化"上，它被安置在状态本身：态矢量给出分布，而分布的计算规则（模方）成了公设。爱因斯坦在同年给玻恩的信里写下那句著名的反对意见，反对的正是这条安置方式的必然性。

## 二、为什么量子概率不像经典无知

如果量子概率只是无知，它就应当满足经典概率的加法：互斥备选的概率直接相加。双缝实验给出反例：屏幕上的强度与两条单缝图样之和相差一个干涉项。写成公式，$|c_1+c_2|^{2} = |c_1|^{2} + |c_2|^{2} + 2\,\mathrm{Re}(c_1^{*}c_2)$，第三项既非负也非零，加法律失效。

由此得到标准量子力学里的第一条结论：线性相加的是概率幅，概率则是幅的模方。这是"幅在前、概率在后"的经验根据。

另有一条边界由排除性定理给出。Bell 定理表明，任何同时具备局域性与"测量前结果已确定"的理论都给出某个不等式，而实验违背它。PBR 定理进一步表明，态若只是关于底层实在的知识，则在制备独立性下与量子预言冲突。两条定理合起来把"量子概率纯粹是局部无知"这条路线压得很窄；幸存者要么放弃局域确定性，要么放弃制备独立性，要么放弃"底层状态独立于观察者"。

## 三、为什么必须取模方：四把锁

第一把锁是线性与内积。量子态的变化是幺正的，幺正保持内积。若概率取幅的一次方，归一化在演化中守不住；取模方，归一化等于内积，随幺正演化自动守恒，概率守恒随之成立。

第二把锁是叠加。实验事实要求互斥备选的贡献线性叠加，而可加的观测量必须是非负的双线性型。$\langle \psi|P|\psi\rangle$ 是满足这两条的最简形式，模方正是它的特例（$P$ 取一维投影）。

第三把锁是 Gleason 定理。对维数不小于 3 的希尔伯特空间，任何在投影格上可加的概率指派都是 $p(P) = \mathrm{Tr}(\rho P)$。也就是说，一旦承认"概率指派给投影结果，且对正交备选可加"，玻恩形式就是唯一选择，不是可选约定。

第四把锁是复合与无信号。多体系统的态空间取张量积，若概率规则不是模方型，复合系统的边际分布会与单体分布冲突，或允许超光速传信。张量积结构加无信号要求同样把规则逼到模方。

四把锁给出同一句话：概率不是被外加给量子力学的，它是希尔伯特空间结构（线性、内积、张量积）与投影格可加性共同逼出的唯一非负双线性读数。

## 四、"投影给出概率幅"这句话的两个层次

严格分层是这样的。投影算符 $P_a$ 或更一般的正算符 $E_a$ 是提问装置，内积 $\langle a|\psi\rangle$ 是概率幅，模方 $|\langle a|\psi\rangle|^{2}$ 才是概率。连续谱里这套说法要换口径：位置基是广义基，$\psi(x)$ 是幅密度，$|\psi(x)|^{2}$ 是概率密度，单点概率为零（见 [[注记-态矢量与波函数的几何对应：分层结构、振幅与相位的来源分居]] §七·四）。

所以"投影给出概率幅"这句在口语里可以说，但要知道它省掉了一步：投影给出幅，平方才给出概率。省掉这一步的代价是后面所有"概率为什么必须平方"的问题都被问错方向。

## 五、随机性从哪来：五种立场的清单

| 立场 | 随机性住在哪 | 对"为什么取模方"的回答 |
|---|---|---|
| 哥本哈根式工具主义 | 公设层，不可再还原 | 公设本身，问它"为什么"不合法 |
| 统计／系综解释 | 对底层隐变量的无知 | 需附加条件才与 PBR 相容 |
| QBism、关系性 QM | 观察者的信念度与关系 | 由决策论或格结构唯一性推出（Gleason 型论证） |
| 多世界 | 分支权重 | Born 规则需另行推导（决策论路径为代表） |
| 玻姆力学 | 初始条件的典型性（量子平衡） | 由引导方程与平衡假设共同给出 |

这张表的意义在于：五种立场的数学部分完全一致，区别只在把随机性安放在哪一层。标准化表述可以说得很直白：在标准公理体系里，概率是原初的，理论的预言形式是概率分布，而不是个体轨迹。

## 六、体系侧读法

体系对同一个问题给出一套不同的安置方式，落点有三条。

其一，概率即份额。态矢量的模方给出的是份额，Born 规则由份额恒等式导出，不再作为独立公设（[[序参量份额定理：Born规则、归一化与幺正性的系统推导]]）。

其二，测量即采样。体系把测量与碰撞、快照抄写合为一件事，坍缩是采样的实现，不是额外的动力学过程。随机性因此定位在"采样落在哪一次"上，而不定位在态矢量内部。

其三，态矢量对个体层沉默。个体属性在体系里是确定的（位置与计数有确定值），态矢量只决定关系层的读数分布。随机性由此获得一个分层表述：它坐落在关系层读数的统计形态上，不上升为世界的形而上属性。

两处未建项必须同时说明。第一，个体属性为何不提供额外预测力（量子平衡的对应物）仍是登记在案的待补论证，见 [[注记-态矢量与波函数的几何对应：分层结构、振幅与相位的来源分居]] §八其四。第二，单体确定与集体谱之间的合法机制即 P3-13，仍为体系自标的最高优先级缺口。这两项不闭合，"随机性来自采样统计"就还只是框架性读法，不是定理。

## 六·补 单一结果与"全空间采样"：两层采样与一处未建（2026-09-18 补）

先纠一个前提。微观采样采到的是确定的局部读数（该处的实轴取向与相位），并不直接采到概率。概率不出现在单个格点上，它是份额：在系综层面（同一制备的大量实例）落在该格的实例数占比。所以"每个格点都在采样"提供的是处处都有的确定刻痕，概率是这些刻痕在系综上的分布。

单一结果出自另一层。一次测量是宏观跨层事件：它要形成不可逆的记录，需要放大与多自由度锁定，机制图像写为局部相变凝固（体系自标纲领级）。在这个图像里，单一结果等于一台宏观装置在某处凝固并放大了一个分支的读数，其余分支失去相干、退出记录。

于是两层分工是：微观自铭刻（处处、局域、保相干，只抄写取向）与宏观事件（一处、不可逆、选择性、成记录）。把两层合成一层，才会觉得"处处坍缩"与"只有一次结果"互相矛盾。两层用法的清点见 [[注记-采样的客观义与两层用法：自铭刻与快照抄写的区分]]。

"测量非定域"这个印象可以拆成三种含义。事件层的非定域指一个事件同时发生在多处，体系没有这条也不需要有；关联层的非定域指纠缠、非定域拓扑荷与先验纠缠，体系有这条，它正是电荷保护的根据；描述层的非定域指态矢量作为整体对象不能分解为局部片段，标准量子力学本来如此。

体系里的格点采样落在事件层之外：每个格点每摆程各自发生一次碰撞与自铭刻，事件之间不需要任何全局协调，接力速度由 $c = l_P/t_P$ 限定，属局域动力学。"处处在采样"因此读作"每个局域点各自在留刻痕"，与"一个全局测量同时在所有位置进行"是两回事。

若把所有碰撞都算作坍缩，就会与干涉现象冲突。体系的保护正是两层分工：自铭刻保相干，跨层事件才破坏相干并产生唯一结果。真正非定域的是关联结构，它不传信号；测量概率由份额给出，测量发生地点由装置位置给出。

仍缺的一环要写明：把"宏观事件 = 局部相变凝固"落到方程，是纲领级主张，尚未建；相邻两项（个体属性为何不提供额外预测力、P3-13 的单体确定与集体谱机制）也在登记中。所以"单一结果如何冒出来"目前在体系里是结构性回答加一处未建，不是定理。

## 六·补之二 通俗版：什么叫"局部相变凝固"（2026-09-18 补）

"凝固"这个词的贴切之处在于：它描述一个连续、可滑动、可逆的自由度被钉成一个确定的离散值，而且钉住之后回不去。两件事同时发生：对称性自发破缺（一堆等价的取向里选中一个）与不可逆（要把已凝固的部分化开，需要额外做功）。测量结果的两个特征恰好对位：离散、唯一、不可逆。

体系里"凝固"出现在三层尺度上，分清才不会混。第一层是每摆程的自铭刻：相位推进到临界点，留下一道不可逆的刻痕，处处发生、保相干，属背景过程。第二层是宏观测量：装置提供"核"，在一处把连续相位自由度锁定并放大成宏观记录，其余分支失去相干。第三层是宇宙学的同步相变：从原初之海凝固出时空，凝固即降温，凝固失败处成为缺陷，也就是粒子。

于是"宏观事件 = 局部相变凝固"的直译是：一次测量像整片过冷的水在一个点上突然结冰。结冰之前，水的取向可以连续地改来改去（对应各分支的相对相位仍在走）；晶核一出现，那一块立刻选定一个取向并长大（选择性）；长大之后要它化开需要外部做功（不可逆），所以记录只能读到一个值（结果的唯一性）。

三个类比可以互相补位。水的过冷与突然结冰给相变与对称破缺；蜡片或磁带被刻出凹槽给"写进去之后只能读出一个值"；底片银盐颗粒被光子击中后显影给"大量自由度被锁定成一份宏观记录"。三者的共同点是：连续的东西被锁定，锁定之后不可撤销地成为一个离散痕迹。

为什么必须是局部，而不是整片一起冻？整片一起冻等于要求一个全局协调，等于把非定域性放进事件层，那正是体系要避免的。所以机制写成局部发生加有限速度扩散：接力速度由 $c = l_P/t_P$ 限定，放大靠装置自身的多自由度。

两处提醒。其一，这条仍是纲领级：序参量、核形成率、放大阈值、时间尺度都还没有方程。其二，体系另有一条独立路线说"测量分立性由采样定理推出"（条件性命题级），与本条属两个候选机制，引用时不要混用。

## 六·补之三 测量分立性为何能由采样定理推出（2026-09-18 补）

这条主张的出处是《元相子几何动力学》补充注释 22（本体叠加与现象分立）。它要回答的问句很具体：投影公设只规定"测量结果属于算子的谱"，从未解释为什么现实呈分立、彼此分明的形态。注释的答复是：现象层本身就是采样层。

机制分三步。第一，本体层是连续的螺旋，相位连续旋转，数学时间连续可逆。第二，现象层是采样层：物理时间只在满周闭合的临界点给出节点 $t = n t_P$，物理空间只在格点上给出位置，一切读数必须落在节点上。第三，任何进入现象层的东西都被取点，连续量换成它在节点上的取值序列，即阶梯函数 $Z_{\text{粒}}(T_n) = Z(\tau_n)$。离散性来自取样网格，无需额外的"坍缩到本征值"公设。

取样网格固定之后，相邻节点的间距有限（$t_P$、$l_P$），读数之间天然有间隔，无法连续过渡；再叠加带限（尼奎斯特），不可分辨的振荡不存在，取值集合被截断。"一个一个、彼此分明"由此获得几何根据，这正是公设降级链条中的一环。

三条边界要同时写明。其一，这条只回答"为什么读数是分立的"，不回答"为什么是这一个读数"，后者落在两层采样与局部相变凝固（§六·补、§六·补之二），纲领级。其二，它不给出权重，权重由份额恒等式给出（[[序参量份额定理：Born规则、归一化与幺正性的系综推导]]）。其三，"分立性的来源"有两套，不能混成一套：结果事件在时空中的定位离散来自格点与采样；离散谱可观测量的取值集合离散来自谱结构本身，其整数性另有拓扑奠基（$\pi_{1}(S^{1}) \cong \mathbb{Z}$）。采样定理管前者，不管后者。

严格程度按原文：本体叠加与现象分立属公理体系显式化（条件性命题）；"测量分立性由采样定理推出"属条件性命题，依赖采样定理；"测量 = 局部相变凝固"属纲领性主张。采样定理本身的数学形式化挂在 P3-12，紫外截断界限挂在 P3-26。用词上还需注意：此处用的是"采样"的结构义（连续到离散的映射），与事件义（碰撞、快照抄写）分属两层，混用会把两层搅在一起。

## 六·补之四 结晶类比的逐项对照（2026-09-18 补）

把上一节的类比逐项落到体系对象上，四步各自对应什么，写清楚之后类比才有解释力。

| 结晶 | 体系对应 |
|---|---|
| 水分子的取向 | 元相子的实轴取向 $\alpha$（信息层自由度，可在相位圆上连续偏转） |
| 液态：取向连续涨落 | 各格点相对相位连续变化，干涉项随之连续变化，校准尚未锁定 |
| 过冷与杂质提供晶核 | 装置提供的局部强耦合，加上体系固有的不均匀处（缺陷、复合位错） |
| 晶核长大 | 相位锁定沿校准链扩散，一步一摆程，速度上限 $c$ |
| 结晶潜热 | 相变释放的锁定能（温度侧：凝固即降温） |
| 冰的取向单一 | 记录被锁定为单一读数，跨层事件留下不可撤销的铭刻 |
| 化开需要做功 | 不可逆性：校准不可逆，加采样映射非单射（无典范截面） |

第一步"选择"对应实轴取向的锁定。相位三层里，钟（普朗克旋转）绝对不可观测，信息层（实轴取向）是唯一可变的方向自由度，秩序层（序参量）承载宏观相干。结晶前可变的就是信息层，装置耦合把它从连续可调压成确定取值，这一步正是补充注释 22 所说的从本体层连续叠加到现象层分立事件的过渡。

第二步"长大"对应锁定沿校准链的扩散，不在全空间瞬时完成：元相子按摆程节拍跃迁、撞上邻居、邻居抄写取向继续向前，接力速度由 $c = l_P/t_P$ 限定。装置的作用是提供大量自由度，把这一处的锁定放大成宏观记录；这与温度侧的"凝固释放锁定能"是同一条线。

第三步"要化开得做功"对应不可逆性在体系里的两个来源。其一是校准不可逆：完整本体动力学为物侧哈密顿加心侧校准，时间反演不在其对称群中。其二是采样的信息压缩：采样映射非单射、典范截面不存在，记录一旦散入大量自由度，回程没有唯一路径可走。这与时空观列出的时间箭头三重来源（几何定向、潜无穷增长、校准不可逆）同源。

三处须谨慎。其一，此处的"取向"是各格点自己复平面内的实轴取向，与宏观物体在空间中的朝向无关，避免读成经典结晶的几何转向。其二，"凝固"在体系里还有宇宙学用法（时空凝固、凝固失败者为缺陷即粒子），尺度与机制同构但不能混着引用。其三，把这条机制写成方程（序参量、核形成率、放大阈值、时间尺度）尚未完成，仍属纲领级；它与"测量分立性由采样定理推出"（§六·补之三）是两个候选机制，不要合成一条。

## 六·补之五 概率幅在体系里对应什么（2026-09-18 补）

一句话版本：概率幅是态矢量（关系层的谱）里的一支复权重，模是该构型份额的平方根，辐角是该构型携带的实轴取向差。

| 对象 | 表达式 | 模方的含义 | 来源 |
|---|---|---|---|
| 概率幅 | $c = \sqrt{p}\,e^{i\Phi}$ | 份额 $p$ | 计数侧给模，实轴取向差给辐角 |
| 相干振幅 | $A = c\,\eta$ | 相干份额 $p\,|\eta|^{2}$ | 再乘局部齐整度，一次方进振幅、二次方进强度 |
| 序参量分量 | $w = p\,e^{i\Phi}\eta$ | 强度侧读数 $p^{2}|\eta|^{2}$，且 $w = \sqrt{p}\,A$ | 可测层的场量 |
| 波函数（位置表象） | $\psi(x) = \sqrt{\rho(x)}\,e^{i\Phi(x)}$ | 局部份额密度 | 集体合成读数的约化表象 |
| 场强（序参量） | $\Psi = \psi\,\eta$ | 份额密度乘齐整度的平方 | 可测层 |

三句话读这张表。第一，模与辐角来源分居：模来自计数（有多少份额落在这个构型上），辐角来自实轴取向差（相邻元相子的方向差即波矢）。第二，概率幅必然取复数，因为要同时装下这两件事；只保留模方，叠加退化为经典混合，干涉项消失。第三，概率幅是内积的输出，换探针即换基，态矢量本身不动。

两处相邻但不同的对象要分开。其一，波函数与场强属集体合成的约化表象，模方是份额密度与强度，它们是概率幅体系化之后的宏观读数。其二，元相方程里的 $\psi$ 指单体相位指针，属时空生成层面，与本节这一组不是同一层面（见 [[注记-态矢量与波函数的几何对应：分层结构、振幅与相位的来源分居]] §七·补）。

未建三处同挂：相干度 $\eta$ 的载体归属（O1）、单体确定与集体谱之间的合法机制（P3-13）、份额分布与概率份额的严格同一。模方等于份额由份额恒等式给出（[[序参量份额定理：Born规则、归一化与幺正性的系综推导]]），但从份额到"观测频率等于份额"这一步仍需动力学或遍历论证，即第三项。

## 六·补之六 序参量份额定理要点（2026-09-18 补，指向正稿）

正稿《序参量份额定理：Born规则、归一化与幺正性的系综推导》（2026-09-02 作者确认）要处理的问题很具体：标准框架里三条概率性公设（归一化、Born 规则、幺正演化）彼此独立、来源悬空。它的做法是把三条全部降为系综结构的推论。

设定是纯代数的。$N$ 个元相子分成 $M$ 个模式块，块 $a$ 含 $N_a$ 个，份额恒等式 $\sum_a N_a/N = 1$ 恒成立；块内相位分解为公共相位加涨落 $\theta_i = \Phi_a + \delta_i$；块内相干因子 $\eta_a = N_a^{-1}\sum_{i \in a} e^{i\delta_i}$，满足 $|\eta_a| \le 1$，等号当且仅当块内完全相干；序参量按块分解为 $\Psi = \sum_a w_a$，其中 $w_a = (N_a/N)\,e^{i\Phi_a}\eta_a$。

两个口径必须分清（这是 2026-09-17 更正执行的要点）。概率幅系数 $c_a := \sqrt{N_a/N}\,e^{i\tilde\Phi_a}$，模方无条件等于份额 $N_a/N$；相干振幅 $A_a := \sqrt{N_a/N}\,e^{i\Phi_a}\eta_a$，模方为相干份额 $(N_a/N)|\eta_a|^{2}$，相干度一次方进振幅、二次方进强度。同步纯态（$|\eta_a| = 1$）下两者重合；部分相干时分工：概率幅无条件承担概率，相干振幅承担干涉能力。原"振幅开方像"写法属相干度一次方进强度的形态，与判据不符，已退役。

主结果三条。定理 4.1：$|c_a|^{2} = N_a/N$ 且 $\sum_a |c_a|^{2} = 1$，无需同步条件。推论 4.2：由它直接得到 Born 规则 $p_a = |c_a|^{2}$ 与自动归一化。推论 4.3：波函数的模方分解对应份额分布，且 $w_a = \sqrt{N_a/N}\,A_a$。§4.3 另给唯一性环：份额到概率的赋值必须是模方，理由是 $U(1)$ 不变加正交可加，唯一性由 Gleason 定理给出。

幺正性走两条路径。结构路径（定理 5.1）把演化算符写成各因子相位旋转的张量积 $U(t) = \bigotimes_k e^{i\omega t}$，逐因子模恒一，故幺正；结论严格，但覆盖自由演化形态。守恒路径（定理 5.2）以确定性、线性、保份额为起点，经极化恒等式与 Wigner 定理得幺正或反幺正，连续性排除反幺正；结论更一般。两条路径在归一化-幺正闭环（推论 5.3）汇合。

测量语义在 §7。单次测量是一次快照抄写，落点按份额抽样；重复 $K$ 次独立采样按大数定律趋近 $K|c_a|^{2}$。模长给"多少"（采样密度），相位给"何时"（实轴锚点决定抄写时刻）。单次事件的随机性来自份额抽样与碰撞无记忆，不需额外公设。

严格程度要分行看。归一化与 Born 的无条件性是代数结论；叠加原理、纯态组装、混态演化属条件性；概率的测量语义属纲领层（采样投影的形式化待补）；幺正性按两条路径分别声明。开放问题 (a) 至 (g) 挂在正稿 §10，(g) 已部分结案，残留是与"强度平方份额"口径的统一。
