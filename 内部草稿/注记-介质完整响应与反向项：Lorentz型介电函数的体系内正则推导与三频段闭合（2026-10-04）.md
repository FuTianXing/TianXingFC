## 一、任务与三处失配

第 573 条确认能隙型闭式 $n(\omega) = \omega/\sqrt{\omega^2-\omega_0^2}$ 与真实材料有三处同源失配：低频端 $n\to\infty$ 对实测静态 $n(0)$ 有限；色散符号反号（闭式 $dn/d\omega<0$ 对日常正常色散）；高频端闭式全程 $n>1$ 对 X 射线实测 $n<1$。注记已把成因登记为「闭式只取共振项同相部分，缺反向项与完整响应函数」。

本轮把这句话兑现为可计算的模型：给出反向项在体系内的正则身份，推导完整响应的介电函数，核对三段行为是否全部接上。

## 二、三条通道的消元对照

介质内部振子（固有频率 $\omega_0$，即异类耦合能隙 $\sqrt{3\omega_P\kappa_\varphi}$）与光模式 $A$（实轴方向场波动模式的正则坐标，$E = -\dot A$）的耦合，厄米结构有三种最小候选，色散各不相同。推导全在模型单位 $c = l_P = t_P = 1$ 下进行。

**位移型（弹簧 $gAx$）**：消元给

$$\omega^2 = k^2 + \frac{g^2}{\omega_0^2-\omega^2}$$

$\omega\to 0$ 取静态值 $g^2/\omega_0^2$ 即第 573 条能隙型闭式的来源（同相部分）。但此结构 $\omega^2(0) = g^2/\omega_0^2 > 0$：无论取什么近似，位移型长波端**恒有隙**，静态折射率结构性发散。三处失配中的第一处在位移型内无解。

**质量混合型（$\nu p_A p_x$，第 573 条 M4 已实现）**：广义本征值问题给

$$\varepsilon_v(\omega) = \frac{k^2}{\omega^2} = 1 + \frac{\nu^2\omega^2}{\omega_0^2-\omega^2}$$

长波无隙（声学支），但 $\varepsilon_v(0) = 1$：介质对静态场零响应，静态段无慢化。第二处失配在此结构内同样无解。

**交叉型（$-\beta A p_x$）加 $A^2$ 项（$\beta^2 A^2/2$）**：联合完成平方 $\frac{1}{2}(p_x-\beta A)^2$，哈密顿有界。正则方程（每 $k$ 模）

$$\dot A = E,\qquad \dot E = -(k^2+\beta^2)A+\beta p_x,\qquad \dot x = p_x-\beta A,\qquad \dot p_x = -\omega_0^2 x$$

消元给久期方程

$$(k^2+\beta^2-\omega^2)(\omega_0^2-\omega^2) = \beta^2\omega_0^2 \;\Longleftrightarrow\; \omega^4 - (k^2+\beta^2+\omega_0^2)\,\omega^2 + k^2\omega_0^2 = 0$$

等价的介电函数形式为

$$k^2 = \omega^2\,\varepsilon(\omega),\qquad \varepsilon(\omega) = 1+\frac{\beta^2}{\omega_0^2-\omega^2}$$

这正是 Lorentz 振子型介电函数。三处失配的解全部在此结构内。单独的交叉项（去掉 $A^2$ 项）哈密顿无界（$\frac12(p_x+\beta A)^2$ 配出负势），久期方程出现不稳定实根：$A^2$ 项是稳定性必需，不是可选项。**口径订正（2026-10-05，见 [[内部草稿/注记-交叉顶点的形式推导：四约束穷举与通道形态的收窄（2026-10-05）|交叉顶点形式推导]] 结论二）**：$A^2$ 项与交叉顶点不同源：它超出顶点族，是稳定性补丁，其正四阶势来源另有三候选（同类耦合四次幂、异类内部四次幂、束缚势），哪个主导待数值轮判定；本注记把两者并列陈述仅为消元记法，不蕴含同源。

## 三、双支谱与三频段闭合

久期方程的两支（极化激元结构）：

$$\omega^2_\pm(k) = \frac{1}{2}\left[S \pm \sqrt{S^2-4k^2\omega_0^2}\right],\qquad S = k^2+\beta^2+\omega_0^2$$

长波极限 $k\to 0$：光支 $\omega_-^2 \to k^2/(1+\beta^2/\omega_0^2)$，无隙声学型，速度 $v(0) = 1/\sqrt{\varepsilon(0)}$；振子支 $\omega_+^2(0) \to \omega_0^2+\beta^2$，横向光学模被耦合抬高。两支之比的极限形式即 Lyddane-Sachs-Teller 关系的体系内影子。

三频段核对（相折射率口径 $n = k/\omega = \sqrt{\varepsilon}$，即 Snell 律所用口径）：

- **静态段**：$n(0) = \sqrt{1+\beta^2/\omega_0^2}$，有限。密度与弹性 jointly 决定静态折射率，第一处失配闭合。
- **正常色散段**（$\omega < \omega_0$）：$\dfrac{dn}{d\omega} = \dfrac{\beta^2\,\omega}{n\,(\omega_0^2-\omega^2)^2} > 0$，符号与日常经验（蓝光更折）一致，第二处失配闭合。
- **反常区与高频段**（$\omega > \omega_0$）：$\varepsilon < 1$；其中 $\omega_0 < \omega < \sqrt{\omega_0^2+\beta^2}$ 段 $\varepsilon < 0$，光支无实数解（剩余射线型禁带，真实离子晶体的 reststrahlen 带对应物）；$\omega > \sqrt{\omega_0^2+\beta^2}$ 后 $n < 1$ 且 $\omega\to\infty$ 时 $n\to 1^-$，X 射线从下方回归，第三处失配闭合。

群速口径（信号速度）：长波端无色散极限 $v_g = v(0) = 1/\sqrt{\varepsilon(0)} = 1/n(0)$；反常区群速可超 $c$，与第 522 条光锥定理无冲突（该定理管波包前沿）。

## 四、通道归属后果

三段行为中任何一段都同时超出位移型与质量混合型的结构能力：位移型恒有隙（静态发散不可修复），质量混合型 $\varepsilon(0)=1$（静态响应为零）。真实材料三段齐备这件事本身，构成比第 573 条 M4（低频带隙互斥）更强的通道判据：**介质折射的通道归属被推向交叉型**。交叉型顶点带单次 $\omega$（发射率侧 $|g_k|^2\propto\omega^2$，低频禁戒形态），按第 526 条二分签名归速度型家族，二分框架不破，家族内部细分为本轮新增的登记项。

$\beta^2$ 的身份：数密度乘耦合顶点平方（聚合层显式进入介电函数），对应注记第六节预告的「$\kappa_\varphi$ 乘数密度」类比物的精确化；其原子值与耦合常数来源仍归 P1-49。能隙型闭式的适用域随之收窄：它作为位移型静态近似只适用于近能隙边缘的行为描述，长波静态段由完整响应接管。

## 五、判据预研（R1 至 R5，数值轮执行）

- **R1 静态段**（判据稳健）：光支长波两档 $\omega_-$ 读数对久期方程精确根（离散模型无格点截断项，解析即精确谱），容差只含数值方法误差；群速 $v(0) = 1/\sqrt{\varepsilon(0)}$ 差分核对。EP5 齿：能隙型闭式预言 $\omega(0)>0$，同档必 FAIL。
- **R2 正常色散**（判据稳健）：$\omega<\omega_0$ 三档相折射率严格递增且 $n(0) = \sqrt{\varepsilon(0)}$。
- **R3 高频回归 $1^-$**（判据稳健）：高频档 $n<1$ 且随 $\omega$ 回升；与第 573 条闭式 $n>1$ 形成方向齿。
- **R4 剩余射线禁带**（判据稳健）：$\omega\in(\omega_0,\sqrt{\omega_0^2+\beta^2})$ 段光支无实数解（谱空段），配一档修逝衰减实测。
- **R5 稳定性与 $A^2$ 必要性**（EP5 齿）：完整模型全谱纯虚；去掉 $A^2$ 项出现非零实部根（不稳定）， $A^2$ 项的必要性由反例构造验证。

简并声明：振子支在全 $k$ 平坦（振子间无耦合），周期链上 $N$ 重简并；全部判据读数取光支（与振子支谱分离）与时域波包，不落简并子空间期望读数，谱扫描如实报告簇结构。

## 六、边界声明

本注记验证什么：反向项的正则身份（交叉耦合加 $A^2$ 项）、完整响应介电函数的体系内推导、三频段闭合、通道归属的结构性论证。

本注记不验证什么：$\beta^2$ 的原子值与耦合常数 $e$ 来源（P1-49）；Lorentz-Lorenz 局域场修正（密度依赖的下一层，$\varepsilon = (1+2\chi/3)/(1-\chi/3)$ 待下一轮）；介质界面的反射系数与 Snell 律数值；阻尼 $\gamma$ 与吸收带的定量；振子支与光支的混合模式在事件层的读法。

可逆性等级（预研）：R1 至 R4 判据稳健（解析恒等式与结构互斥）；R5 稳健（构造替换即翻）。推导链的物理对应假设：交叉型顶点由 $\cos$ 高阶项供给（非对角通道的具体形式仍归第 526 条待判项，本轮只锁定「三段行为排除位移型与质量混合型」这一层）。
