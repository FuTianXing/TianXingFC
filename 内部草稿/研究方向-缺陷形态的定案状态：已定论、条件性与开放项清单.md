## 二、已定论（判定级，模型内）

以下五项的严格程度为模型内判定级，可直接引用；「模型内」指结论的成立范围限于已建的格点模型与已测构型，不外推至物理标度。

### 2.1 形态选定

台阶面（面缺陷）为选定粒子形态，闭合环（线缺陷）未作粒子。依据为 [[台阶面的拓扑：三维元相子缺陷的结构、保护与写入节拍]] §11 形态分工表。

| 形态 | 余维 | 能量 | 保护机制 | 状态 |
|---|---|---|---|---|
| 台阶面 | 1 | $E = \sigma_{\rm wall}A$ | 边界数据或封闭边界固定的相对绕数 | 选定为粒子形态 |
| 闭合环 | 2 | $E \propto R^2$ | 同上 | 需 $K \ge 0.24$，未作粒子 |

该选定的直接依据是 [[内部草稿/开放问题总览：元相子理论待解决问题清单]] 第 325 条与第 326 条：壁项只在绕数被强制（边界或钉扎）的构型里出现（[[验证脚本/注记-涡旋对松弛器与对数项分解轮：松弛后既无对数项也无线性壁项（判据X1至X5）]]）；自支撑核环松弛到零，连亚稳都不是（[[验证脚本/注记-环边界下的面缺陷松弛轮：自支撑的核环不存活（判据Z1至Z5）]]）。

### 2.2 解析剖面与张力闭式

剖面为 $v(x) = -\frac{2}{\pi}\arctan e^{mx}$，$m = 2\pi\sqrt{2K/k}$；小刚度档张力闭式为

$$\sigma_{\rm wall} = \frac{4}{\pi}\sqrt{kK} = 1.273240\sqrt{K}$$

五档偏差 $\le 1.22\%$，一维链独立复核 $0.05\%$。大刚度档另有分级闭式（第 341 条）：两格快跳族调和式 $\sigma_2 = \frac{1}{2} - \frac{1}{A}$（$A = 3+4\pi^2K$）、四阶式 $\sigma_4$、指数尾式 $\sigma_{\rm tail}$，交叉点 $K^{*} = 0.051326$ 与 $0.061512$。

### 2.3 边界保护三层

定义层：$\Delta = 0$ 的对照终点严格取 $0$，受保护构型停在 $10.387697 = 1.008\,\sigma_{\rm wall}A$。守恒层：$\Delta$ 对 $-1$ 偏差全程为 $0$（200 次采样）。简并层：三种壁位同能量，散布 $1.74\times10^{-11}$，半格平移差 $7.78\times10^{-12}$，钉扎势垒在数值精度内为零。

三层合读：面可以挪，荷不能动。保护由边界冻结承担，即守卫归波。

### 2.4 绕数是边界量

横截面 $128^2$、$N_z = 8$ 上逐切片核对，面积求和与边界回路求和之差 $\le 2.66\times10^{-15}$。芯越过边界列 $x_0 = N = 128$ 时标签跳变，只在 $z = 4$ 层越界时该层归零。绕数的边界性是保护的机制根，属恒等式层面。

### 2.5 宽度由软模关联长度承担

$\xi = 1/(2\pi\sqrt{K})$ 由三把独立尺子确认：kink 尾部七档 $K$ 差 $\le 0.23\%$、零模包络差 $0.11\%$ 与 $0.01\%$、带边波长恒等式 $\lambda_{\rm gap} = 1/\sqrt{K} = 2\pi\xi$。宽度归波，粒性侧只给载体形态参数。

## 三、条件性命题级

以下六项站得住，但只在已测档位与最小模型内成立，跨档外推须另测。

**面积律与系数身份。** $E = \sigma_{\rm wall}A$。第 289 条三维延展构型复核给两档截面（$16\times16$ 与 $24\times24$）同一单位面积壁能 $0.040577$，对 $\sigma_{\rm wall} = 0.040263$ 高 $0.78\%$。单档核过，跨 $K$ 未测。

**桥因子与窗口算术。** $l^{*}/\xi = \pi/\sqrt{3} = 1.8138$，实测 $1.7845$ 至 $1.8121$（差 $1.6\%$）。两条窗口 $K \le 1/48 = 0.02083$（落窗）与 $K \le 1/(16\pi^2) = 0.00633$（洛伦兹），取交集后 $l^{*} \ge 3.63$，无需精细调节。

**写入节拍。** $N_{\rm 笔} = (\text{扫过层数})\times A$，实测 $3712 = 58\times64$；写入即折返（时刻差 $0$）；无噪声 Fano $0.0372$，加噪声升到 $1.9985$ 与 $1.4400$（转随机）。两档读数。

**时钟三段式。** $R(\Delta t_s) = R_0\cdot\min(1,w/(v\Delta t_s))/\min(1,t_P/\Delta t_s)$。稀疏取样系统性放大受激项 $w/(v t_P)\approx 158$ 倍，实测 $157.4$。

**三维维度无关性。** 软模带隙与一维相同；有隙格林函数的轴向与径向衰减率对一维预测差 $0.28\%$ 至 $0.43\%$。

**大刚度档张力闭式的适用范围。** 连续式在 $K \ge 0.10$ 失效（$K = 0.24$ 与 $0.30$ 分别低 $33.0\%$ 与 $38.1\%$），须改用四阶式或尾闭式。该失效对 C1 线有直接后果：其驻留窗口 $K \ge 0.24$ 正落在失效区，用量级估计会偏高约三成至六成。

## 四、负结论

### 4.1 余维二线扇区内驻设计关闭

横截面模型内（$N = 64$、$K_0 = 0.005$）三项结构读数：无保护时标签从 $1$ 衰减到 $0$（第 $450$ 步）；仅锚核同样衰减，钉芯救不了标签；仅保护时标签恒为 $1$，能量从 $36.6532$ 收敛到 $5.2529$。三项分工为：保护保标签不保位置（净荷滑到边界 $(1.00,32.00)$）、锚核只保形状（末态留 $(+1,-1)$ 偶极）、**体内不存在内驻亚稳线缺陷**。

第 329 条在平面三维环面上把 $K$ 提到 $0.24$（另加 $0.30$ 对照），核环仍不存活（末步 $9.08\times10^{-14}$，能量全为 $0.0000$，绕数全为 $0.00$）。故第 278 条的 $K \ge 0.24$ 门槛不能读成"只要抬 $K$ 就行"，它依赖 C1-4 的螺线背景与边界钉。

### 4.2 局域锚核内驻不可达（附第 342 条限定）

$l_{\max} = A/\sigma$，局域锚核中心驻留需 $w_a \gtrsim 47$，内驻设计关闭。

**第 342 条限定（2026-09-21）。** 该轮的拉力口径在刚度大档失效：三档拉力对同档张力之比 $0.88$、$2.56$、$3.01$，诊断定位为边界环按芯的解析相位冻结，其势能斜率随芯位漂移，在 $K = 0.24$ 与 $0.30$ 档占实测拉力 $84\%$ 与 $86\%$。自由芯五档全部逃逸（含 $w_a = 16$ 居中档），预期的判据翻转不成立。对照读数：环改成固定参考相位或整数后拉力降到 $6.5\times10^{-4}$ 与 $2\times10^{-6}$，弦不出现。

作废范围限于 AN 构型的拉力与判据量读数，**不动第 341 条张力闭式**（来自条带与一维链，净跳变被强制）。C1 窗口的驻留判据须改用强制弦的条带几何重测；P 轮「净荷滑向边界」的归因登记为待复核的同源重读假设（标签守恒不受影响）。

## 五、未定项清单

十条，按可下手程度排序。

**其一，三维形态唯一性。** 为何取面壁与点而不取线，仍为形态学问题；现有材料只有线扇区的负读数与面、点的正读数，从两端到完备性论证的缺口未补。层级：纲领级。来源：[[复合位错粒子的形态收束：宽度的波性侧承载、边界保护与锚核驻留判据]] §7.2 其五；[[内部草稿/总结报告-阶段进展与战线状态：2026-09-21]] 第 62 行同判。

**其二，C1 窗口驻留判据的条带几何重测。** 第 342 条后待做，须用强制弦的条带几何重测窗口档的 $l_{\max}$ 与所需 $w_a$。材料：`验证脚本/README.md` 第 342 条。

**其三，物理质量档未裁。** 宽度与膝位都随质量档 $1/(Mv)$ 缩放，哪一档算体系自己的缺陷未定，直接决定 C6 第一项前置。层级：条件性命题级。

**其四，边缘线终止在体内。** 台阶面的边界是一条核线，需要配对；论文与第 289、292 条只测贯穿盒子的面。层级：条件性命题级。

**其五，规范层荷是否携带同类切割能。** 决定锚核负结论的适用范围（toric code 层是否也产面积能）。来源：形态收束论文 §7.2。

**其六，环的稳定性。** 强钉扎判据已按新张力重估，但某参数区里环确实稳定缺直接读数。层级：纲领级。来源：台阶面论文 §14 其三。

**其七，松弛器。** 钉扎涡旋对显式梯度下降未收敛（第 288 条末步 $3.2\times10^{-1}$ 判负），需长波加速或隐式格式（部分已由第 330 条的曲率稳定化 IMEX 与谱隐式推进）。层级：纲领级。来源：台阶面论文 §14 其四。

**其八，本底算符。** 周期本底与时钟折返未在算符层立起。层级：纲领级。来源：台阶面论文 §14 其五，第 121 条遗留。

**其九，深阱与复合设计锚核族未测；$l_{\max} \propto w_a$ 线性外推待多档直接测量。** 建议档位 $w_a = 16$、$24$。来源：形态收束论文 §7.2。

**其十，$K$ 的体系值未导出与量纲桥缺口。** 三个同名 $K$ 的记号冲突未消解（锁定势 $K$、耦合系数 $K/J$、公理层 $K_0$，数值差四十三个数量级）；量纲桥四段分解的第三段「模型能量单位到物理能量」缺失，缺口性质为一个纯数因子。两条均有专门文档：[[内部草稿/研究方向-K 的体系值导出：判据草案与三条候选路线]]、[[理论攻坚/量纲桥攻坚计划：从本体层单位到物理质量标度的导出]]。

## 六、一句话回答

**缺陷形态可以定论到「选定台阶面（余维一）、闭合环降级、线扇区内驻关闭」这一层；尚未定论的是形态唯一性的完备性论证，仍停在纲领级。** 支撑定论的读数均为模型内判定级，跨 $K$ 与物理档的部分属条件性命题级；第 342 条限定把线扇区的负结论范围又收紧一格，这几个档位不可混同。
