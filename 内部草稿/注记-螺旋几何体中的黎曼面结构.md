## 一、核心发现：黎曼面在螺旋几何体中出现两处

### 1.1 螺旋体边界曲面（正螺旋面）本身是黎曼面

**事实链（全部为严格数学）**：

1. **正螺旋面是极小曲面**（平均曲率 $H=0$，体系定理 3 已确立）。
2. **每个极小曲面都携带复结构**：Enneper-Weierstrass 表示定理表明，极小曲面的共形参数化由全纯函数对 $(g, f)$ 给出。这是"极小性（面积极值）"与"全纯性"之间的经典等价。
3. **螺旋面共形等价于 $\mathbb{C}$**：含轴的螺旋面单连通、非紧、非球面。由单值化定理（uniformization），单连通黎曼面共形等价于 $\hat{\mathbb{C}}$、$\mathbb{C}$、$\mathbb{H}$ 三者之一；螺旋面非球面（排除 $\hat{\mathbb{C}}$）、非双曲（其模参数下共形于 $\mathbb{C}$ 为经典结论，悬链面-螺旋面形变族的等温参数化直接给出该复结构）。

**结论**：螺旋体的边界曲面不仅是一个实二维曲面，它上面天然长着一个复结构。波性侧（相位旋转）与粒性侧（半径承载）在极小曲面的全纯数据中合流。

### 1.2 相位覆盖结构 = log z 的黎曼面

单位圆论文的覆盖结构 $p: \mathbb{R} \to S^1$，$p(x) = e^{ix}$ 是标准事实的特例：

- $\mathbb{C}^*$ 的万有覆盖是 $\mathbb{C}$（经 $z \mapsto e^z$）。
- 多值函数 $\log z$ 的**黎曼面**就是这个万有覆盖：每点 $z$ 上有无穷多层，层指标 = $\arg z$ 的分支（模 $2\pi$）。
- 层间跃迁、缠绕计数在轴上累积的图像，就是 $\log$ 黎曼面的层叠结构在单位圆方向上的投影。

**统一**：缠绕数 $n$ = 覆盖空间的层指标 = $\log$ 的分支指标。整数分类标签（$\pi_1(S^1)\cong\mathbb{Z}$）与多值函数单值化（黎曼面）在这里是同一件事。

## 二、物理意义的三层诠释

| 层级 | 内容 | 严格程度 |
|---|---|---|
| 严格 | 螺旋面是黎曼面（共形 $\mathbb{C}$）；相位覆盖是 $\log$ 黎曼面的投影；缠绕数 = 层指标 = 分支指标 | 标准定理 |
| 条件性 | 波粒耦合的全纯表达：Enneper-Weierstrass 把"旋转 + 推进"写进全纯函数对，极小曲面性（$H=0$）对应全纯数据的相容条件 | 待构造 |
| 纲领性 | 螺旋面的黎曼面身份把元相子几何体正式接入"局部到整体"传统（单值化定理、黎曼面模空间）；螺距 $a = c/\omega$ 为螺旋面在极小曲面模空间中的形变参数；螺旋面、ζ 定义域、单位圆共享复平面 $\mathbb{C}$ 的黎曼面结构，可能深化三域同构 | 纲领性 |

## 三、边界与开放问题

1. **含轴 vs 去轴**：螺旋面含轴时共形 $\mathbb{C}$，去掉轴时共形 $\mathbb{C}^*$。体系当前用含轴完整螺旋体，对应 $\mathbb{C}$ 情形。
2. **全纯数据构造**：Enneper-Weierstrass 数据 $(g, f)$ 与 $\omega$、$c$、$\hbar$ 的显式对应尚未构造。这是本注记最重要的开放问题。
3. **与黎曼ζ的深层联系**：ζ 的定义域本身是黎曼面（$\mathbb{C}$ 去极点 $s=1$）；临界线经莫比乌斯变换映到单位圆。若螺旋面 = 共形 $\mathbb{C}$ 的黎曼面，三者的共享复结构可能深化《单位圆论文》的三域同构（§3.4 已声明黎曼对应停留在载体层面，此处不推翻该边界，仅指出可能的深化方向）。
4. **模参数**：$a = c/\omega$（螺距参数）作为极小曲面形变参数的地位待严格化（悬链面-螺旋面形变族是经典模型，可作参照）。
