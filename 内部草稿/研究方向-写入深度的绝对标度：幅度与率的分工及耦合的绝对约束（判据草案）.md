## 一、待补的一环与两条接口

写入深度 $G$ 在判据侧是寄存器读出量的跳变量（模型里取 $5$ 等），在机制侧对应"写一次转移一个激发"。两者之间需要两条接口：一条管幅度，一条管率。分清这两条是本节的任务，混用会把"耦合强"读作"记录深"。

## 二、两条接口

接口一（幅度）。机制篇 §2.2 的读数是写一次转移一个激发（激发数守恒到 $10^{-9}$，寄存器布居 $0.999$）。转移型耦合 $H_{\rm int} = g\,f(\hat\theta)(a^\dagger c + a c^\dagger)$ 的每次作用交换一个激发，与 $g$ 的大小无关。故

$$G_{\text{每次写入}} = 1\ \text{激发（以占据计）},$$

且判据侧的 $G$ 分解为放大链增益与这一次写入之积，$G = G_{\text{amp}} \times 1$。耦合不进幅度。

接口二（率）。机制篇 §8.1 给出登记效率 $\eta = 2\pi\rho\,t_P\,g^2$，其中 $\rho$ 为浴的态密度、$t_P$ 为一次折返时长。写成

$$\eta = C g^2, \qquad C = 2\pi\rho\,t_P.$$

机制篇的探测器模型给出 $201$ 个模、带宽 $2\pi$、密度 $31.99$，故 $\rho = 201/(2\pi)$，于是 $C = 201$（模型单位下 $t_P = 1$），即 $C$ 等于浴的模数。耦合只进率，不进幅度。

## 三、核对与推论

核对：$\eta = 1$ 要求 $g = 1/\sqrt{C} = 0.0705$，与机制篇给出的门限读数 $g = 0.0705 \approx 0.011\,\omega_P$ 逐位相符。这一步确认两条接口的读法自洽（$C$ 的数值与 $\eta$ 的公式用的是同一套约定）。

推论一（耦合的绝对上界）。$\eta$ 是概率，故 $\eta_w \le 1$，于是写入耦合有上界

$$g_w \le \frac{1}{\sqrt C} = 0.0705 \approx 0.011\,\omega_P.$$

这条上界的来源是概率守恒，不是能量代价。此前把"写入耦合的上界来源"列为开口项，本接口给出其一半：上界由 $\eta \le 1$ 承担，能量代价若另有约束会给出更紧的值。

推论二（双通道判据的绝对形式）。把 $\eta = Cg^2$ 代入上一轮的双通道判据 $\eta_h \le \eta_w^2/S^2$ 得

$$g_h \le \frac{\sqrt C\,g_w^2}{S}.$$

推论三（持久条件的绝对形式）。把 $\eta_h = Cg_h^2$ 代入 $\eta_h \ll 1/N_{\text{拍}}$ 得

$$g_h \ll \frac{1}{\sqrt{C\,N_{\text{拍}}}}.$$

## 五、执行顺序

第一步做 A1 与 A2，钉住两条接口。第二步做 A3 与 A4，完成 $C$ 与 $g$ 的核对。第三步做 A5 至 A7，给出三条推论的数值表。第四步做 A8，写明模型单位到物理量的对应与不确定度。

## 六、失败与降级预案

若 A4 的核对不符（$1/\sqrt C$ 与机制篇的 $g$ 读数不同），则 $C$ 的构成或 $\eta$ 的归一须重查，$\rho$ 的定义（每单位带宽还是每模）是首要嫌疑。若 $\rho$ 的口径在后续轮次改变，$C$ 随之改变，三条推论的数值表须重算（形式不变）。若机制篇的 $g$ 读数被证为不可用（其自标为外推量级估计），则本稿的绝对数全部降为量级指示，形式结论（两条接口、三个不等式）不受影响。
