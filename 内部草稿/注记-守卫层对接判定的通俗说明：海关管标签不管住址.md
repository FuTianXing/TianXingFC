## 一、这一轮在问什么

上一轮（第 484 条）把一对正反缺陷放到环形晶格上，看到的现象是：相互吸引、越靠越近、最后同归于尽，抓不住任何稳定位置。当时留了一个合理的疑问：那个晶格是裸的，没装守卫层。完整理论里缺陷受两重量子保护（绕数超选择与 toric code 结构），也许守卫层能阻止湮灭，把稳定定域救回来。第 593 条就是把这个问题判掉：守卫层装上之后，湮灭到底还被不被阻止。

## 二、三组实验，各说明一件事

**第一组：正反对照样湮灭。** 装上守卫层（做法是把绕数标签 $Q$ 写成固定的边界条件，让它根本不在可演化的量里面），正反对在五档参数下全部走向湮灭，最好的一档能量直接塌到机器零。原因一眼见底：正反对加起来的净绕数是零，湮灭之后还是零，标签从头到尾没变。守卫层查的是标签，标签不动它就无话可说。

**第二组：单个缺陷动不了。** 带一个单位净绕数的单个缺陷，五档参数下全程保住标签，一个也消失不了。想让它消失，就得把整个体系从 $Q = 1$ 扇区搬到 $Q = 0$ 扇区，而守卫层禁止任何演化做这件事。这正对接既有量子读数：跨扇区的一阶矩阵元为零。

**第三组：撤掉守卫，连单个缺陷也溜走。** 把环形边界换成开放边界（绕数守恒失效），单缺陷几千步内就滑出边界消失了。这确认守卫的来源就是净绕数守恒本身：有守恒，单个缺陷禁灭；没守恒，谁都保不住。

## 三、一个副产品：摊薄倾向

第二组里还有个意外收获：弱钉扎档下，局域缺陷并不保持局域，而是慢慢摊开，最终精确摊成整圈均匀扭转，能量终值与解析预期 $E = 1/(2N)$ 逐位吻合（偏差 $0.14\%$）。带净绕数的扇区里没有"聚成一点"的吸引子，绕数天然趋向摊薄到全场。既有静态结论（扇区极小离域）与这条动力学通道在同一个终点会师。

## 四、重要发现清单

1. **守卫层不阻止净绕数为零的对湮灭**：五档参数全部湮灭通道开放，第 484 条的判负在完整框架下维持，不被守卫层翻案。
2. **守卫层的保护对象是扇区标签**：$|Q| = 1$ 单缺陷跨扇区禁灭（五档全程恒 1），$Q = 0$ 对扇区内自由湮灭；两类过程一禁一许，判据有区分力。
3. **守卫的来源是净绕数守恒本身**：开放边界对照撤守卫后单缺陷也漏出，守卫与守恒律同生同灭。
4. **扇区极小离域获得动力学复现**：弱钉扎档弛豫终点逐位落到均匀扭转极小 $1/(2N)$，静态结论与动力学通道会师。
5. **"电荷型守恒"与"位置型稳定"分家**：守卫层管前者不管后者，分界线从表述层落到判据级。

## 五、意义

**守卫层和定域化的分工从此分家。** 守卫层像海关：查的是"这个缺陷带没带合法的绕数标签"，从来不管"它住在哪里、住不住得下"。所以环面上粒子要稳定待住，只能靠两个已经成立的候选：内部壁承接（第 485 条，在体系内部造冻结环来钉住）与边界环冻结（第 483 条，用样品边缘钉住）。

**三层分工完成一次自洽对接。** 既有图景是"拓扑序守电荷、格点内锁定给质量、弹性包层给宽度"。这轮验证恰好展示第一层与后两层互不越权：守卫层在定域化判负的地方不补位，正说明各层各司其职。电荷型守恒与位置型稳定是两件独立的事，这个区分以前停在表述层面，现在有了判据级的分界线。

## 六、严格程度与边界

守卫层不阻止对湮灭为结构事实加数值展示（$Q$ 守恒由构造保证，梯度流只是展示通道，判据稳健）；扇区极小离域为解析极小加数值逐位吻合；承接者收窄引自既有候选评估，非本轮新立。本轮不涉及：量子层动力学（toric code 激发谱与弦算符涨落）、湮灭时标与势垒形状、二维与三维环面、环面上粒子最终承载形式的表述（仍开放，属作者裁决面）。所有数值引自第 593 条验证注记。
