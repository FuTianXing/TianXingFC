## 一、评估的范围与尺子

"站稳"在 C1 的总判据里有一张明确的表：存在有限能量的驻留形态，且宽度落入色散窗口（落窗线 $\ell^{*} \ge 2$，洛伦兹口径收紧到 $3.61$）。把完整构建拆开是五件套：驻留、宽度、荷、质量、源。本评估按这五件逐路线盘点，并给出与引力线的接口现状。

评估只盘现状，不引入新断言；数字全部来自已落盘的注记与脚本（C1-0 至 C1-4c、L 系列、窗口算术 U、统一构型 AF、费米子四轮 F/G/H/P、量子层 Q4/Q5 与 $Z_N$ 重建、张量桥 d、引力线收束、识别式阶段 0 至 4）。

## 二、三路线的站立裁决

### 2.1 点/线核路线：钉得住，宽度不够

格点内锁定在 $K \ge 0.25$ 给出正面读数：环 R4/R5、畴壁平板与球泡都出现驻留（驻留比 $0.196$ 至 $0.243$；球泡尺寸门槛 $r_c = 3.0$），脱钉阈值 $\alpha^{*} = 0.15$，驻留能量标度 $E_{res} \propto K^{2.21}$，自由平衡宽度 $1.029$。锚核的钉扎阱语言成立。

短板在宽度：驻留态宽度只有 $0.25$ 至 $1.03$ 格（驻留锐化后 $0.251$）。驻留窗口要求 $K \ge 0.24$，落窗窗口要求 $K \le 0.0231$（一维与三维标度一致），两个窗口相差约十倍、交集为空。同机制不可兼得，这是 C1-4 一轮的核心负面判定，也是"驻留与落窗互斥"这条判据墙的来源。判定：钉得住，宽度不够。

### 2.2 环/泡路线：结构性地站不住

环的能量写成 $E(R) = 2\pi R\,a + \pi R^2\,\delta$，稳定半径 $R^{*} = |a| / \delta$ 存在的充要条件是负线项加正体项，即 $a < 0 < \delta$（C1-4b 对早期"体项为正即可"表述的精确化）。

四轮读数把这条线收了口。其一，体项现成：GL 两相（凝聚相与正常相）给 $\delta > 0$；层位真空与复结构双井都是简并，给不出体项。

其二，线项要负：C1-4c 给出正定泛函硬下界，参数型锚核把界面能从 $0.198$ 压到 $0.0507$ 即停；$a \ge 0$ 是精确性质，负线项需要显式负项（新元素）。

其三，幅度不够：L 系列软化反馈的折扣上确界为 $21.622\%$（$c = -0.8$），$|c| = 0.9$ 触及结构边界（与 $(1 - \mathrm{floor}) / s_{\max}$ 逐位一致）；脊后剖面塌缩、读数翻正，降低下限不提高上限。

其四，合成也不行：AF 统一构型判死越零。

判死的两层理由值得并列。结构性一层：统一构型仍逐点非负（$K_i \ge 0$、$\kappa_e \ge 0.1\kappa$），真空取零，故线项 $a = E \ge 0$，越零要求的总节省率超过 $1$ 被直接排除。实测一层：两机制的节省合成近乘法（$r \approx 1 - S_a$，相对协同 $1.1$ 至 $1.3$），加法读数被排除（强锚核处加法预测 $96.8\%$ 对实测 $81.6\%$）；网格最大总节省 $82.04\%$，最小残差 $a / \sigma_0 = 17.96\%$，外推到 W1/W2 档仍有约 $7\%$ 的正残差。

窗口算术给出配套数字：越零门槛 $\varepsilon = 0.100$（W1/W2 的 $10\%$ 缺口）或 $0.256$（构造档折算）；落窗要求 $\eta \ge \varepsilon + R^{*}_{\mathrm{req}}\,\delta / \sigma_0$，$12$ 档全部不达（缺口 $1.3$ 至 $11.7$ 倍）；最优越零情形的 $R^{*}$ 只有 $0.18$ 至 $0.62$ 格，够不到 $2$ 格的落窗线。判定：站不住，且是结构性的；重启只余三条出口（显式负项、Hopf、心侧校准，见第五节）。

### 2.3 kink 位错复合模型：存活，未组装完

构造是均匀缠绕背景上的 FK kink 位错，三层分工（电荷核携带绕数、锚核钉扎、包层给宽度与能量）。宽度缺口已经闭合：$\ell^{*} \ge 2$ 的参数区存在；洛伦兹口径把窗口收紧到 $K \le 0.00633$（$\ell^{*} \ge 3.61$），两套宽度定义之间的桥因子为 $1.803$，原文两处口径混用已订正。

费米子通道四轮相容性全过：宇称奇源判为内部相位（唯一 T 奇自由度；费米子通道不设独立约束，比光子通道宽松 $12$ 至 $34$ 个量级）；T 奇耦合系数为能量均分 $c_1 \approx 1/2$（$0.5003$ 至 $0.5100$）；T 奇效应核局域（$58\%$ 至 $75\%$）；三维面壁逐值复现一维读数（$\ell^{*} = 4.06 / 2.86 / 2.01$，$c_{\text{el}} = 0.5029$ 至 $0.5100$）。

挂起项三项：驻留稳定性判定、三元组哈密顿量、点/线形态（归 C1-6）；SME 对接还差复结构映射一步。判定：宽度活了，驻留未判；这是当前最接近全绿的一条路。

### 2.4 荷与保护（三路线共用）

绕数超选择已有结构性定论：$Z_2$ 下绕数受先验纠缠保护（$[H, W] = 0$，跨扇区一阶矩阵元为零）；$N > 2$ 需要定向口径重建（简并 $N^2$，泄漏 $\le 10^{-14}$；此前 $Z_3$ 的 $O(1)$ 泄漏判为压缩算子投影伪影，$Z_2$ 结论不受影响）。量子层补充：$Q4$ 泄漏最小阶数 $n_{\min}(L) = L$（指数 $\lambda^L$），$Q5$ 弦算符可形变完成。

需要牢记的上限：C1 至今的读数全在经典层，荷的最终判决须搬进量子层（载体层裁决已言明；经典层结论的上限是载体的能量、尺寸与驻留）。判定：五件套里最结实的一件。

## 三、与引力的关系

### 3.1 同源载体

引力与粒子共用一张晶格与一个记录场：引力是记录场的平滑弹性分量（层法线静倾角场，$h = l_P\theta$），粒子是记录场的局域锁定缺陷。形状归波、计数归粒。

引力线的弱场终态（GV0 至 GV8 收束）已相当闭合：$\lambda = 1$ 从第一原理导出；自旋 $2$ 运动学（螺旋度 $\pm 2$ 确认）；D6 引力波速对照（GW170817 类窗口 $-3\times 10^{-15}$ 至 $+7\times 10^{-16}$）；系统因子 $1.365$ 剖分为三重口径复合（$1.0045 \times 1.090 \times 1.139 \times 1.095$，无稳定物理因子，口径不确定度约 $\pm 10\%$）；能量口径审计确认三个上游未被占用，基准取场能匹配口径。

### 3.2 供源：张量桥

粒子是引力唯一的源形态，接口在张量桥。分段 (d) 的三段与 $T^{00}$ 装配已完成：静质量密度取振幅亏损的二次型（$E_B \propto W_{\text{amp}}^{2.04}$），动能流（相位梯度形式），应力（混合形式）。一处提示：环类构型的梯度能约为势能的 $9$ 至 $24$ 倍，静态梯度能在 $T^{00}$ 中的归属待定（W4-2）。质量在这一图景里是"褶子绷着的劲"：束缚能越大，静质量密度越高。

### 3.3 运动耦合

粒子运动是 $\sigma$ 锁定构型的边界传播（转换波），与光的传播同构；相对论色散、弹性身份、测地响应等判据已有读数。引力对粒子的作用走测地线响应（法线场响应侧判据），即"粒子在记录场的倾斜梯度里走最直的路"。

### 3.4 接口缺口

未锁死的环节三处。其一，具体粒子构型到精确源的定量推进（P1-24 光偏折完整系数与次阶源锁定复验）；其二，后牛顿扇区与并合波形（张量桥既有路线，判据 BH1 一线）；其三，强场端（D4 大振幅非线性已立项未启动；黑洞线的消费接口按 2026-09-19 裁决执行）。

## 六、风险与最坏情形

最坏情形：C1-6 撞上新的正定障碍；负线项被裁不合法；质量谱始终对不上。粒子机制停在存在性草图，引力线只剩源项形式，粒子到源的链条无法定量闭合。

中性情形：路线存活，但每一步都要引入新元素（显式负项、复结构、心侧参与），体系的新增假设数量上升，可证伪面变窄。

相对乐观情形：C1-6 通过，显式负项合法且够强，环路线复活，与 kink 路线互为交叉核对，两条路线的读数可以互相检验。

改变评估的触发器：作者对负线项出口的裁决；C1-6 的首轮读数；$\sigma_0$ 口径统一；费米子通道 SME 映射闭合；手征侧第 2 步的读数。
