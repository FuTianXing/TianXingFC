# 注记-位移电流的定量展开：规范块变分的时间分量与校准重排磁场源

- **日期**：2026-09-27 01:32:49
- **状态**：定量展开成立（规范块变分属严格层），判据见第 447 条（3/3）；既有纲领性定性表述升级为定量
- **定位**：闭合 P0-1 下游清单中的位移电流一项。既有材料给过定性图像（"位移电流 = 校准重排自身的磁场源"）并自标"动态过程尚未推导"，本注记给出定量展开
- **依据**：[[规范作用量的审计必然性：从净值审计到电磁场作用量的推导与数值验证]] §3.2 与 §3.4；[[电磁场的元相子几何：麦克斯韦方程组的双重几何来源]] §4.2 与 §6；[[变化磁场与变化电场的相互产生：从几何必然到实体根源]] §6

## 一、既有状态

《电磁场的元相子几何》§6 给出位移电流的物理图像（校准动力学重排实轴方向场时必生成新的空间扭转），同时明确声明"动态过程（运动绕数结构如何在实轴方向场中产生空间涡旋）尚未推导，待建立"；《变化磁场与变化电场的相互产生》把该项标为"纲领性主张（依赖校准作用量）"。校准作用量已于 2026-09-26 闭合，本注记据此把定性升级为定量。

## 二、定量展开

规范块是对曲率的计费

$$S_{\text{规范}} = -\frac{I_0}{2t_P^2}\sum_p\left[1-\cos(F_p\,l_P^2)\right],$$

对联络变分。低幅区的欧拉-拉格朗日方程为离散的散度式

$$\sum_p F_p\,\frac{\partial F_p}{\partial A_\nu} = 0 \quad\Longleftrightarrow\quad \partial_\mu F^{\mu\nu} = 0\ (\text{无源}),$$

分量拆开就是麦克斯韦有源组的无源形式。时间分量给出电场的空间散度型；空间分量给出

$$(\nabla\times\mathbf{B})_i - \partial_t E_i = 0,$$

即安培-麦克斯韦定律，其第二项就是位移电流。关键在于这一项**自动**出现：$F_{0i}$ 是电型格面值，对它取时间导数就得到 $\partial_t E_i$，而规范块对时间型与空间型格面一视同仁地计费，故变分必然同时产生旋度项与时间导数项。

## 三、机制读法

位移电流项的物理身份由此明确：$F_{0i}$ 的时间变化率就是校准重排的速率，规范块对它的计费在变分中表现为"磁场旋度"的源。这正与既有的定性表述"校准重排自身的磁场源"逐字对应，两者的差别只在层：定性表述是几何图像，本节的 $\partial_t E_i$ 是同一图像的变分内容。

传导电流项与位移电流项的分工也随之清楚。传导电流来自耦合块对物质场变分（电流 = 绕数结构迁移），位移电流来自规范块自身的时间型格面项；两块在审计结构里各管一半，合起来才是完整的安培-麦克斯韦定律。

## 四、判据设计（指向第 447 条）

D1 变分核对：规范块作用量的数值变分与解析式（离散散度型）逐点一致。

D2 系数匹配：空间分量中位移电流项与磁场旋度项的系数比为 1。

D3 环量判据：无传导电流配置下磁场沿闭合回路的环量非零，且等于电场通量的变化率。

## 五、严格程度与边界

严格：变分给 $\partial_\mu F^{\mu\nu} = 0$ 及其分量分解（标准结果，格点实现已由第 430、434 条覆盖）；位移电流项作为时间型格面时间导数的身份。

条件性：有源版本的源项装配（传导电流一侧的格点形式已由第 445 条的耦合块变分给出，两者的联合展开未做）。

不涉及：介质中的位移电流（体系无介质自由度）、量子层的真空极化修正（属 P1-8）。

## 六、与既有声明的衔接

《电磁场的元相子几何》§6 的"动态过程尚未推导"声明可更新为已给出定量（本注记与第 447 条）；《变化磁场与变化电场的相互产生》表中的"纲领性主张（依赖校准作用量）"可升为条件性命题级并注明依赖已闭合。
