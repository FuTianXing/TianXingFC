## 新增内容

感知-校正链的最小动力学模型（论文 3.1 节）：

$$\ddot\alpha_n + \frac{1}{\tau_{\text{corr}}}\dot\alpha_n = \omega_{\text{cal}}^2\big(\alpha_{n+1} + \alpha_{n-1} - 2\alpha_n\big)$$

- $\omega_{\text{cal}}^2$：校准刚度（天行力响应强度的涌现表征）
- $\tau_{\text{corr}}$：校正弛豫时间（感知-校正链的格点延迟）
- 连续极限：$\partial_t^2\alpha + \frac{1}{\tau_{\text{corr}}}\partial_t\alpha = c^2\partial_x^2\alpha$，$c^2 = \omega_{\text{cal}}^2 l_P^2$
- 忽略阻尼即得波动方程，光速 $c = \omega_{\text{cal}} l_P$，与 $c = l_P/t_P$ 统一要求 $\omega_{\text{cal}} = 1/t_P$

## 待作者确认要点

1. 校准刚度 $\omega_{\text{cal}} = 1/t_P$（由光速统一推出）是否认可；
2. 阻尼项（$\tau_{\text{corr}}$）的物理来源（感知-校正延迟）是否保留在模型中；
3. 该模型是否作为主文档补充注释十的正式内容固化（目前仅在论文中）。
