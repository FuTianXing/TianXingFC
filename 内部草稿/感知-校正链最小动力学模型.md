## 裁决结果

作者裁决（2026-09-26）：感知校正无时间、无阻尼、无耗散，弛豫项取零。原模型中的 $\tau_{\text{corr}}$ 项撤销。

最终形式（论文 3.1 节）：

$$\ddot\alpha_n = \frac{1}{t_P^2}\big(\alpha_{n+1} + \alpha_{n-1} - 2\alpha_n\big)$$

- 系数 $1/t_P^2$：摆程节拍的换算（每个摆程事件抄写一次邻居偏转差），无自由参数
- 连续极限：$\partial_t^2\alpha = c^2\partial_x^2\alpha$，$c^2 = l_P^2/t_P^2$
- 光速：$c = l_P/t_P$ 由摆程接力的节拍给出（每步一格、每步一摆程），与耦合强度无关（补充注释四第 3 点）；感知校正的响应时间不进入速度

## 裁决依据

其一，元相子没有组成部分，态变量只有提升相位、旋向与方向标签，运动学中不存在承载损耗的连续量（完美弹性定理，2026-09-20）。

其二，若保留实阻尼项，长波模式过阻尼：平面波解为 $\omega = -i\gamma \pm \sqrt{\Omega^2-\gamma^2}$（$\gamma = 1/(2\tau)$，$\Omega = \frac{2}{t_P}\lvert\sin(k/2)\rvert$），$\Omega \le \gamma$ 的模式只衰减不传播；取系数 $1/t_P^2$、$\tau = t_P$ 得截止波长 $\lambda_c = 4\pi l_P$，可见光波长远大于此，含阻尼模型下不能传播。详见 [[评审报告/评审报告-感知-校正链机制对光传播的解释力-2026-09-26]] 甲-2。
