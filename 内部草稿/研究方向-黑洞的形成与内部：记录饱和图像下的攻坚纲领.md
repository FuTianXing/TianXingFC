## 一、问题陈述：黑洞问题在体系内的三段划分

经典广义相对论的黑洞物理分三段：外部物理（吸引、红移、光线弯曲、并合 waveform）、视界定义、内部与奇点。体系当前对三段的支撑强度不同，攻坚须分段推进：

- **外部（强支撑）**：N5 史瓦西对齐零参数命中 $h_{00} = r_s/r$（60 个数量级四天体），测地线判据命中光偏折系数 $4\theta_0 r_0/b$。视界外一切行为由已验证的记录场联络给出，与 GR 预言一致。本段无需新攻坚，需补的是后牛顿扇区与并合波形的定量对接（张量桥路线）。
- **视界（定义已给，机制待阐释，底气有限定）**：视界 = 记录场的饱和等值线（$\theta = 1/2$ 的等值面），空间晶格在视界内外完全一样地运转。此定义为 N5 数值事实的机制解读，"视界 = 弱场构造的射程边界"。**底气限定（2026-09-10 评估）**：$\theta(r_s) = 1/2$ 是弱场公式的外推值，视界内真实记录未建模；"半满等值线"可能只是外推伪象而非物理等值线，其物理地位待判据 BH2（连续延伸、无附加表面层的显式检验）裁决。
- **内部与奇点（纲领级）**：视界内记录动力学未知（饱和/缠绕/耦合重开三候选），奇点发散按统一奇点截断方向替换为记录饱和，坍缩终态的体系叙事未成文。

## 二、形成的图像：写入与补位的竞赛（既有定案的外推）

黑洞形成 = 坍缩的终态，坍缩的对抗双方在体系内均有定案机制身份：

**正常恒星的平衡**。恒星物质缺陷每拍写入倾斜（源强 $s_{eff} = 4\pi m/m_P \propto m$，$N_c \approx 2.09$ 次碰撞/拍），倾斜稳态叠成势阱；晶格持续创生（内部落位 $3H_0$ + 边缘扩张）带来平直像素，稀释势阱曲率密度。写压弯、创生垫平，两侧平衡维持稳态。与"压强支撑对抗引力"同构，机制换成写入速率与补位速率的竞争。

**坍缩的发条（局域密度口径，2026-09-10 修正）**。坍缩判据是**局域缺陷密度阈值**，非总质量阈值。口径辨析：落位概率 $p = 3H_0 t_P$ 是**每个碰撞点**的候选窗口概率，总补位速率 = $p \times$ 活跃碰撞点数 $\propto$ 体积格点数；恒星的补位供给 $\propto$ 体积（$\propto m$，按平均密度），写入强度 $\propto m$，两者在体积尺度同标度增长，**不存在总质量口径的不对称**（原表述"补位速率有上限、不随质量增长"错误，已废弃）。修正后的发条在局域口径成立：坍缩是局域过程（密度集中），局域写入率 $\propto$ 局域缺陷密度 $\rho$（每缺陷每拍 $s_{eff} \propto m/m_P$，密度越高写入源越密），而局域补位率 $\propto p \times$ 局域碰撞点密度 = 恒定值（晶格密度均匀，$3H_0$ 是全空间均匀的膨胀项）。**局域缺陷密度越过临界值后写入赢**，势阱加深超过稀释，记录场逐拍变陡。修正后的版本反而更强：局域密度阈值判据与奥本海默极限（密度/紧致度判据，非总质量判据）同构，且解释了为何小质量致密天体（白矮星、中子星）不坍缩（局域密度未达写入阈值，补位仍能垫平）而超大城市质量恒星坍缩。

**坍缩的触发（缺位，最大空白，2026-09-10 评估新增）**。实测引力坍缩是毫秒级（自由落体时间）且伴随反弹与引力波暴；写入-补位竞赛图像是准静态的（写入逐拍累积），按此图像恒星应缓慢变密而非突然坍缩。缺一个触发机制使竞赛在毫秒内决出：候选包括局域密度越过阈值的失稳（补位稀释对高密度区的失效相变）、位错网络的集体失稳（关联 C1 缺陷物质模型）、铁核转变的体系对应。**此触发机制是当前图像与真实黑洞物理之间的最大空白**，列为判据 BH4 核心子问题与最优先攻坚。

**视界形成的定义性时刻**。物体半径压缩至 $r_s$ 时，表面记录达 $\theta = 1/2$（N5）。此为黑洞形成在体系内的定义性事件：弱场记录到达饱和量级，法线场进入强场区。自此三事并发：外部记录依然精确有效（史瓦西对齐保证视界外行为与 GR 一致）；视界内弱场构造到达射程边界（强场机制接管，未建模）；几何层照常运转（零接触边界假设保持范围内）。

**形成时标的定性估计（待数值）**。坍缩时标由写入-扩散前沿（每拍一格 = $c$）与补位稀释速率之比决定；定量模型需强场非线性动力学（前置工具，见第四节）。实测毫秒级坍缩时标与准静态竞赛图像的张力见"坍缩的触发"段，此为形成图像最紧迫的开放点。

## 三、黑洞的本体：体系内候选图像

1. **视界 = 饱和等值线**：$\theta = 1/2$ 等值面，非空间之墙；与 GR"视界为坐标效应非物理奇点"精神同构，且被机制化（弱场构造射程边界，位置 $r_s = 2Gm/c^2$ 已经 N5 零参数验证）。
2. **内部 = 记录饱和区**：三候选（统一奇点截断方向判据 U2）：记录饱和（有界）、缠绕（周期回绕，$S^1$ 紧致轴行为向非紧致轴投影）、耦合重开（强场下记录与摆程耦合重新打开，零接触边界失效）。三候选的判别 = 判据 U2，需强场非线性模型。
3. **奇点替换**：经典 $r \to 0$ 发散 = 线性化外推伪象，真实强场区由记录饱和后的动力学接管。并行结构：格点离散性使物质密度天然有界（每格点缺陷数有限，位错密度上限 = 格点密度），经典密度发散在离散基底上自动截断（与温度侧 $D \le 1$ 截断同型，见统一奇点截断方向候选一）。
4. **与大爆炸侧的对偶**：大爆炸 = 元相海（无序饱和 $T_P$）的凝固相变（P8a 成核-结晶）；黑洞 = 物质向高密度记录饱和区的汇聚。两处同为"经典发散被有界结构接管"的实例，统一奇点截断方向（判据 U3）检验两饱和是否同根。

## 三·五、光囚禁的机制解释（两层结构，2026-09-10 补充）

"光传不出黑洞"在体系内分两层回答，可靠度不同：

**第一层：钟慢红移（强支撑）**。记录场的时间向分量 $h_{00} = r_s/r$（N5 零参数验证）使深处的钟变慢：体系钟 = 摆程计数，势阱内世界线摆程计数变少（定案链条）。钟慢因子 $d\tau/dt = \sqrt{1 - r_s/r}$ 在视界处趋于零：远方观测者看视界上的钟完全停摆，那里发出的信号每步耗时越来越长、频率红移至零。光还是那个光、接力还是那个接力，但外界读不到完整的一步。此层与广义相对论逐项一致，属标准推论。

**第二层：接力几何断裂（外推图像，核心依据 = O(1) 论证）**。更机制化的一层：光是保差接力的取向波（波矢 = 相邻格点实轴指向差），其全部推导（色散 $\omega = ck$、线性波动方程、可叠加干涉）建立在**相邻差为小量**的前提上。视界内记录达 O(1) 量级（倾斜与 1 弧度同档，即"歪几十度"的档位，对比太阳表面仅 $10^{-6}$ 弧度档），抄写机制虽照常运转（每拍照抄），但每格的改写量与信号本身同量级：链上传递的对象从波形退化为逐格大幅跳变。**线性化失效处，波的组织性无保证**：非线性区可能存在稳定的非线性传播模式（本体系粒子本身就是非线性孤子，故不能排除），可能散架，可能被饱和封顶；三候选（饱和/缠绕/耦合重开）正是这三种可能的体系表述。**光没有变慢（光速恒等式 $c = l_P/t_P$ 全程不被破坏，几何层零接触）；出不去的原因在视界内的"写字"无法保证组织成向外的连贯接力波**。光子全程每步一格、每拍一步；变的是深处的钟率与浅处的组织度。

两层分工：红移解释"外面的人为什么永远收不到"（有零参数验证撑腰），接力断裂解释"里面的光为什么不组织成外传的波"（候选图像，待判据 U2/BH3 判别；若强场区实为缠绕或耦合重开，此层表述需改写）。系数级核对（光捕获临界 impact parameter $b_c = 3\sqrt{3}\,GM/c^2$ 等）属 P1-24 全链核对，未做。

## 四、可检验判据（分段）

- **判据 BH1（外部，近期可做）**：后牛顿扇区与并合波形对接：两体系统的记录场叠加、引力波辐射机制（张量桥 d 门控 C1），核对 LIGO 波形库的相位结构。本判据大部分属张量桥既有路线，黑洞语境只补两体边界条件。
- **判据 BH2（视界，中期）**：视界作为饱和等值线的自洽性检验：强场模型中 $\theta = 1/2$ 面的行为（外部解连续延伸、无附加表面层），以及"视界内外晶格运转不变"的显式验证。
- **判据 BH3（内部，远期）**：判据 U2 的三候选判别（饱和/缠绕/耦合重开），需强场法线场非线性动力学（前置工具）。
- **判据 BH4（形成动力学与触发，最优先，升位 2026-09-10）**：三部分。其一，局域密度阈值定量模型：局域写入率（$\propto \rho$）与局域补位率（恒定 $3H_0$ 型）的平衡方程，导出临界密度/紧致度（奥本海默极限的体系版本），检验是否与白矮星/中子星实测上限同量级；其二，**坍缩触发机制（核心子问题，最大空白）**：毫秒级时标的来源（失稳相变/位错网络集体失稳/铁核转变的体系对应）、超新星反弹的机制（落位抵抗的局域失效与恢复？）、引力波暴的激发（源 $\ddot Q$ 辐射的坍缩语境）；其三，坍缩时标数值。部分可先于强场工具（准静态平衡方程零阶），触发机制需缺陷物质模型（关联 C1）。
- **判据 BH5（观测差分，远期）**：体系专属强场预言（视界附近记录饱和导致的对 GR 的偏离，若有）；霍金辐射的体系对应（温度侧 $k_BT = E_P D$ 在视界处的读数？纲领级）。

## 五、攻坚路径与门控

1. **前置工具（与统一奇点截断方向共享）**：强场法线场非线性动力学（$\theta \sim O(1)$ 区的写入-扩散-弹性完整模型），判据 BH2/BH3 的共同前提。
2. **近期可独立推进**：判据 BH4 第一部分（局域密度平衡方程零阶，无需强场工具）；判据 BH1 的外部段（张量桥路线内）；形成图像的定性成文（本文件第二节的机制外推，经作者确认后可入科普层）。
3. **门控**：BH2/BH3 依赖强场工具；BH4 第二部分（触发机制）依赖 C1（三维复合位错，缺陷物质模型）；BH5 依赖 BH3。
4. **优先序（2026-09-10 评估后调整）**：BH4（局域密度阈值 + 触发机制）升为最优先：它是发条修正后检验局域密度判据的唯一通道，且触发机制是当前图像与真实黑洞物理（毫秒时标、反弹、引力波暴）之间的最大空白；零阶平衡方程无需强场工具，可立即立项。
4. **与姊妹方向的分工**：统一奇点截断方向管"截断机制是否同根"（温度侧与几何侧的统一）；本方向管"黑洞作为物理对象的形成、视界、内部"（几何侧的应用层）。两方向共享强场前置工具，判据编号不重叠（U 系 vs BH 系）。

## 六、诚实边界

外部物理有强支撑（零参数对齐）；视界定义与形成竞赛图像为既有定案的外推，未建模未验证；**视界的"半满等值线"地位未定（外推值 vs 物理等值线，待 BH2 裁决）**；**光囚禁第二层（接力几何断裂）为外推论证**：O(1) 处线性化失效是数学事实，"波的组织性无保证"是合理怀疑而非证明，非线性区存在稳定传播模式的可能（孤子先例）未排除，待强场动力学判别；**坍缩触发机制缺位（毫秒时标、反弹、引力波暴），为当前图像最大空白（BH4 核心子问题）**；内部三候选与奇点替换为纲领级；密度有界论证（格点离散性截断）为结构事实的定性引用，缺陷密度上限的精确形式未定；霍金辐射对应为最远期猜想。本方向不改动任何定案，全部新增内容待作者确认。
