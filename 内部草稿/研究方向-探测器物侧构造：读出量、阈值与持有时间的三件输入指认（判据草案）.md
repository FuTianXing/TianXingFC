## 一、为何要这三件输入

三处剩余项堵在同一处。场侧实现要求说出记录读数在体系里是哪个量；持有时间的换算要求说出记录的衰减率由什么定；登记效率与持有时间的衔接要求说出两者是否同源。三问共用同一个对象：探测器的物侧构造。

## 二、三件输入的候选指认

读出量 $y$。候选是机制篇 §2.2 写入算符中的记录寄存器模 $c$：该算符 $H_{\rm int} = g\,f(\hat\theta)(a^\dagger c + a c^\dagger)$ 以相位条件把站点模 $a$ 的一个激发转移到寄存器 $c$，寄存器即是记录的物理载体。逐键传感器阵的读数 $y_j$（一层一个指针、过阻尼一阶弛豫）是它的准经典极限，理由是后者的写入项 $G\,\Theta(w_j - \theta)$ 正是把二值判读经增益写入寄存器的古典化形态。

阈值 $\theta$。两层合成。机制层是过轴条件：$f(\hat\theta) = \exp[-(1-\cos\hat\theta)/(2w^2)]$ 在过轴处取峰，写入只在过轴时发生。读出层是键滑阈值：判读取 $w_j$ 是否越过 $\theta = w_{\max}/2$。两层的关系是"何时写"与"写什么判读"的分工，不是同一个阈值的两种说法。

持有时间 $\tau$。机制篇 §8.1 给出登记效率 $\eta = 2\pi\rho\,t_P\,g^2$，即可写成 $\eta = \Gamma\,t_P$，其中 $\Gamma = 2\pi\rho g^2$ 是寄存器与连续态浴的耦合率。写入与弛豫出自同一耦合，故寄存器的保持时间取该耦合率的倒数：

$$\tau_{\text{rec}} = \frac{1}{\Gamma} = \frac{t_P}{\eta}.$$

这条指认是本稿的关键一步：它把机制篇的登记效率与判据篇的持有时间接成同一个量的两种写法。若探测器用两条不同耦合（写入通道 $\eta_w$、保持通道 $\eta_h$），则上式分别适用于两侧。

## 三、由指认导出的两条条件

可读性（统计）：机制篇 §8.1 的统计要求给出 $N_{\text{事件}} \gtrsim (S/\eta_w)^2$，其中 $S$ 为所需显著性（该篇示例取 $S = 5$，得 $2.5\times10^{5}$ 次事件，与 $\eta = 10^{-2}$ 的读数一致）。

保持性（记录须活到被读出）：$\tau_{\text{rec}} \gtrsim N_{\text{事件}} t_P$，代入 $\tau_{\text{rec}} = t_P/\eta_h$ 得

$$\eta_h \lesssim \frac{1}{N_{\text{事件}}}.$$

## 四、单通道的反证与双通道判据

单通道指写入与保持共用一条耦合，$\eta_w = \eta_h = \eta$。两条条件合起来给出 $\eta \lesssim 1/N_{\text{事件}}$ 与 $N_{\text{事件}} \gtrsim (S/\eta)^2$，取最小的 $N_{\text{事件}} = (S/\eta)^2$ 代入得

$$S^2 \le \eta \le 1,$$

即单通道探测器只能达到约一个标准差的显著性。机制篇自己的示例取 $S = 5$，此时单通道无解。故单通道形态与"可读且可保持"不相容。

双通道指写入与保持分属两条耦合。两条条件给出 $\eta_h \lesssim 1/N_{\text{事件}} \lesssim \eta_w^2/S^2$，即

$$\eta_h \le \frac{\eta_w^2}{S^2}, \qquad \text{等价地} \qquad S^2 \le \frac{\eta_w^2}{\eta_h}.$$

设计判据由此成形：保持耦合须弱于写入耦合，且弱出的倍数不小于显著性的平方与写入耦合之比。取 $\eta_w = 0.5$、$S = 5$ 得 $\eta_h \le 0.01$，即保持通道须比写入通道弱五十倍以上。

这条判据给限制一的"放大链是跨层事件的构成条件"添了第二条理由。第一条是深度（写入幅度 $G$ 决定记录有多显著，见判据篇 §2.3），第二条是通道分离（放大链同时提供写入强、保持弱的不对称）。两条理由都指向同一个结构。

## 七、失败与降级预案

若 $\tau_{\text{rec}} = t_P/\eta$ 的指认不成立（写入与弛豫不同源，例如寄存器由紧致相位承担而无耗散），则持有时间为无穷，持久条件自动满足，本稿的窗口讨论作废，剩余项只剩 $\Delta$ 的场侧实现。若双通道判据的 $\eta_w$ 无上界（写入可任意强），则判据退化为"保持弱于写入若干倍"的定性陈述，须补写入侧的上界来源（如能量代价或反作用）。若逐键传感器阵的准经典极限不成立（$y_j$ 与 $c$ 无对应），则 D1 降为并列候选，读出量的指认须另找依据。
