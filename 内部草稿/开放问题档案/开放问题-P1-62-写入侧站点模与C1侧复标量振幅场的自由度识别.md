## 一、问题本身

判据第 722 号给出写入算符 $H_{\rm int} = g f(\hat\theta)(a^\dagger c + a c^\dagger)$，其中 $a$ 是站点模、$c$ 是记录寄存器。第 726 号给出该过程在装置内的长期平均净增量 $\bar{\Delta} = -0.50000000$。第 724 号则判：写入侧的能量是无量纲计数（布居），C1 侧是带长度量纲的复标量凝聚能，两侧「占据数不同质」，量纲不同类。

构造轮案乙要造一个把两边放进同一泛函的装置。其部件四的核心是净栏式

$$\varepsilon_{\rm wr}^{\rm net} = \nu\,\bar\Delta\,(E_c - E_a).$$

其中 $E_a$ 是站点模持有每个激发的能量刻度，$E_c$ 是记录寄存器持有每个激发的能量刻度，$\nu$ 是每单位长度的写入站点数。

**本条问的是 $E_a$ 与 $E_c$ 的地位。** 若写入侧的站点模与 C1 侧的复标量振幅场是同一个自由度，则 $E_a$ 就是该格点的凝聚能刻度，$E_c$ 是记录寄存器的持有刻度，两栏之差给出真实的线能量，案乙「不需要量纲桥」成立。若两者是各自独立的自由度而以固定系数连接，则净栏里多出一个未定的换算因子，案乙的「不需要量纲桥」随之落空，因为那正是第 724 号判否的跨装置对表换了一种形式。

## 二、库内既有表述的核对结果

2026-10-21 的库内事实核查给出六项结论，逐项如下。

**其一，写入算符里 $a$ 与 $c$ 的身份，库内已写明。** 两者是两个不同的模，写入是转移一个激发，不是同一物质对象的两种状态。逐字见《记录机制：碰撞即写入的算符形式、三维缺陷读数与弦的分层》§2.2 与 §4.1：「站点模与记录寄存器记为 $a$ 与 $c$，写入取相位条件耦合」；「三维格点上每站点带一个紧致相位指针与一对模（站点模 $a_j$、记录寄存器 $c_j$），写入取逐站点直和」。术语表把份额挂在激发数上：「$n$ 笔来自激发数（份额）」。**库内未说它们是同一物的两态。**

**其二，份额与凝聚能的关系，库内有歧义且未写死。** 反向检索「份额」与「凝聚能」的等同句零命中。库内反而把两者分在不同层，并明确说两侧「占据数不同质」（第 724 号 §3.2）。

**其三，锚核内芯区承载什么，库内已写明。** 锚核供的是「质量这一份能量」，即绑定能；而该能量的实际分布摊在整片缺陷上，核区一格只占 $O(1/\xi)$（电子档约 $2.1\times10^{-23}$），主体在包层。见 [[wiki/锚核]] 与术语表「缺陷、核区与边界」条。**故锚核内芯区不是「一份激发」的容器。**

**其四，本问题已被登记为待裁开放项。** 案乙设计提要 §10.3 第二问列出三选项：识别（$E_a$ 即该格点凝聚能刻度）／不识别而以固定系数连接（方案内含一个未定的换算因子，须显式登记为隐藏的量纲桥）／暂不决定（案乙按两种设定各跑一遍）。**本条即该问的正式立项，此前它未登记进开放问题总览。**

**其五，物侧两自由度通道的归属，库内已写明但不覆盖本问。** [[理论总纲/公理体系]] §3 载物侧投影配置空间为 $S^1\times\mathbb{Z}$，两通道正交且不构成重复计数。[[理论总纲/螺旋阶梯几何]] §写明「确定的位置（坐标标签、锚核位置）归层数通道，位置份额（概率幅 $c_a = \sqrt{w_a}$）归相位通道」。**归层数通道的是「锚核位置」（一个坐标落点），库内未把「锚核内那份物质」写成层数通道的载体。**

**其六，「锚核内一份物质」与「份额」是否等同，库内有并存两读法。** 一为作者裁决取甲「锚核与份额是同一物的两侧，按波粒互补在不同阶段显形」（[[内部草稿/注记-概率与位置的体系侧解释及其自洽审查：份额来源、两层采样与分层完备性]]）；二为分析稿「锚核与层位份额不在同一层」，该稿自标「未经体系确认」（[[内部草稿/注记-局域性三义与锚核份额接口：位置口径的术语分辨与结构审查]]）。**两者都不是「同一自由度」的判定，且该分歧本身尚未在库内被裁。**

**一句话结论**：库内没有写明「记录侧激发与 C1 侧锚核是同一自由度」。本问触及最高公理层，且库内相邻处存在两种并存读法，故**不能由 agent 代裁**。

## 三、为什么这是实质缺口

第 724 号判量级审计不可执行，理由是两侧量纲不同类且三条候选桥逐条不成立。案乙是绕开那道墙的正面路线，其全部价值建立在「两侧能量在同一泛函里出现」这一点上。

若本问取「不识别」，则净栏里有一个未定的换算因子，案乙退化为第 724 号的换一种形式；而案乙恰恰是为了给量级判语一个出口而造的。**这意味着本问不裁，案乙的立论基础就悬空。**

反过来说，本问若取「识别」，则得到三样东西：$E_a$ 有明确的物理身份（该格点的凝聚能刻度）；案乙的净栏式成为真实线能量而非形式量；量级比值 $\rho$ 在合并装置内可算。

## 四、两个待答子问

**子问一：识别关系的具体形式。** 若取识别，$E_a$ 与 $E_c$ 的关系由什么给出？候选至少两条：一是两栏共用同一套能量刻度，$E_c$ 由 $E_a$ 加上一个记录侧的持有代价给出；二是两栏刻度由装置自身的哈密顿量给出，无须外接。前者要求给出一个可算的持有代价，后者要求在合并装置里把两个自由度接起来。

**2026-10-21 补充：本题的一半已有库内依据，另一半才是本条的核心。** $E_a$ 侧：[[验证脚本/注记-张量桥d的W4通路：静质量密度与振幅亏损的标度关系]] 在复标量装置上给出 $E_B \propto W_{\rm amp}^{2.04}$（深度方向，同几何族），并由作者 2026-09-16 核定静质量密度的场侧形式取二次型（势能密度 $\lambda(A_0^2-|\psi|^2)^2$ 型），一次型降为幅度指标；[[wiki/锚核]] 给的束缚能定义是「整片缺陷相对真空（基态）的能量差」。**故 $E_a$ 可读作该格点的束缚能刻度，且该刻度在库内已有确定形式。** $E_c$ 侧：记录寄存器每激发的持有刻度，其身份为**写入耦合上界的能量代价**，**已于 2026-10-21 由判据第 769 号交付**（$E_c = E_P/(Cg^2)$，幂次 $-2.000000000$；$C = 201.000000000000$ 恰等于浴的模数；上界档 $g_w = 0.07053456$ 处 $\eta = 1.0000000000$、$\tau_{\rm rec} = 1.00000000$、$E_c = 6.28318531\,\omega_P$）。两栏刻度的关系因此可拆成两句：**$E_a$ 已定，$E_c$ 已定**，余下的是两者的可比性。**「$E_c > E_a$」这一条已由 2026-10-21 裁决取定**（案乙十问第四问，理由是净栏符号由 $E_c - E_a$ 决定而 $\bar{\Delta} < 0$，取同值则净栏为零、负线项不存在；**该式的符号已于 2026-10-21 修正**，初版写作 $E_a - E_c$ 少一个负号），故本子问问的是持有代价的具体形式，不是它与 $E_a$ 的大小关系。

**子问二：锚核与份额的并存两读法是否顺带裁定。** 本问的识别判定若取「识别」，则「锚核与份额是同一物的两侧」与「不在同一层」两读法中的分歧至少被部分解决；若取「不识别」，则该分歧保留。**但这两条是不同层面的问题**（前者问自由度的同一性，后者问描述的层次），前者的裁定不自动裁后者，**须分别处置**。

## 四之补、库内通道归属的核查结果（2026-10-21 追加）

立项之后按《最高公理与五大原则》的五问法（物侧两自由度通道不得混同）做了一次通道归属核查，结论对本题的选项集有直接影响，故单列。

**通道的库内定义。** [[理论总纲/公理体系]] §3 载：物侧投影配置空间为 $S^1 \times \mathbb{Z}$，相位通道取值于单位圆 $S^1$（连续旋转），层数通道承载满周闭合事件的累计计数 $n \in \mathbb{Z}$（基矢 $|n\rangle$ 由沿法线轴相对局域基准的键差分定义）。单个元相子的物侧状态为 $\mathcal{E}(t) = \mathcal{W}(t) \otimes \mathcal{P}(t) = P(t) e^{i\Phi(t)}$，**波性因子取值于单位圆，粒性因子 $P(t)$ 为径向坐标**。2026-09-30 作者裁决定案：相位通道是横向非定域内部空间，层数通道是纵向定域外部空间；确定的位置（坐标标签、锚核位置）归层数通道，位置份额（概率幅）归相位通道。

**两个对象的归属。**

其一，**C1 侧复标量振幅 $A$ 属粒性侧**。作者 2026-09-12 的原话是「纯相位载体肯定不行啊，应当加振幅自由度。而且粒性侧本来就应当是振幅」，该主张的推论一写明「粒性与波性的分工由序参量的两个实自由度承担：振幅 $A$ 给质量与密度，相位 $\theta$ 给相干与绕数」，推论二写明「锚核的本体是振幅锁定，即格点内异类耦合 $\kappa_\phi$」。**振幅与锚核都归粒性侧**，而粒性侧在两通道的划分里是纵向定域的那一侧。

其二，**写入侧站点模的激发数 $n$ 属层数通道**。写入算符 $H_{\rm int} = g f(\hat\theta)(a^\dagger c + a c^\dagger)$ 中 $a$ 是站点模，$n = a^\dagger a$ 即其激发数，术语表「每过轴写 $n+1$ 笔」条写「$n$ 笔来自激发数（份额）」。层数通道的基矢 $|n\rangle$ 正是由沿法线轴相对局域基准的键差分定义的。

**核查结论。** 两侧**同属粒性侧**，故「写入侧站点模与 C1 侧复标量振幅场是否同一自由度」在通道层面不与两通道正交性冲突。但**载体不同**：一层是径向坐标的连续值 $A$，一层是整数计数 $n$。因此本题的准确提法须改：原提法「是否同一自由度」不准确，应改为「**同一粒性侧的两个载体之间是什么关系**」，候选有四：径向坐标的连续化（$n$ 是 $A$ 的整数量化读数）、两个平行载体的独立实现（以固定系数连接）、粒性侧的两个互补自由度（不可互换亦不可相互代替）、暂不决定。

**一处须防的误读。** 库内「振幅通道」一词在叠加像与两瓣态的语境下另有所指（术语表「叠加像」条：振幅通道为亏空份额、相位通道为质心零模佩耶尔斯相干；[[wiki/实通道亏空]] 给实通道亏空份额等于 Born 权重）。那条是**场侧读数的两条通道**，与本题的复标量振幅 $A$ 不是同一件事，不可混用。

## 五、可判形态的设想

本条目前无判据，且它是口径裁定而非数值问题，第一步不是算，是**定读法**。

四条候选读法（第四条由 2026-10-21 的通道归属核查增补）：读法甲（识别，$E_a$ 即该格点凝聚能刻度，案乙的「不需要量纲桥」成立）；读法乙（不识别而以固定系数连接，案乙内含一个待定的换算因子，须显式登记为隐藏的量纲桥，量级比值改按条件报告处置）；读法丙（暂不决定，案乙按两种设定各跑一遍，成本升一档）；读法丁（径向坐标的连续化，$n$ 是 $A$ 的整数量化读数，此读法下 $E_a$ 与 $E_c$ 同源但不同刻度，净栏的量级由整数量化的分辨率给出）。

四条的区分方式可设计为判据：取读法甲时，合并装置内由同一组场变量给出的 $E_a$ 与 $E_c$ 之差须在装置内自洽地给出负号；取读法乙时，该差值须含一个不由装置给出的自由因子，装置内无法定其值。**这个区分是可判的**，因为前者的净栏由装置唯一确定，后者不是。读法丁与读法甲的区分须另设判据：它问的是**同一格点上 $n$ 与 $A$ 能否被同一组场变量同时读出且互相确定**，这是构型判据，若成立则 $E_a$ 与 $E_c$ 的关系由整数量化给出而无需外接系数。

**一条装置口径要求（2026-10-21 第 755 号实测得出）。** 写入事件计数的窗长须取**恰好一个写入门周期**。写入剖面 $f$ 以 $2\pi$ 为周期且 $\omega_P = 2\pi$，故剖面在 $t$ 上的周期为 $1$；若计数窗长 $T > 1$，窗内可含 $1$ 或 $2$ 笔，取决于局域标架偏移。

第 746 号的 shift 取值（$0$ 至 $1.4$）使过闸时刻全落在 $[0.500, 0.723]$，故窗 $[0, 1.2)$ 内恰含一笔，该轮的「每站恰一笔」读数成立。第 755 号耦合后的 shift 落到使过闸时刻处于第二圈的区间，同一窗长下读出两笔。**故 D-5 的「每过格恰写一笔」是单周期内的口径，跨周期窗会读出两笔，该读数出在口径而不在物理。** 装置须把计数窗长取为 $1$（或按 D-5 原义在单周期窗内数），并把该口径写进注记。

**一条须写明的判据设计纪律（2026-10-21 第 751 号实测得出）。** 读法丁的关系型是**台阶型**（$n$ 取整数值、$A$ 取连续值），而多档扫描纪律在台阶型关系上有额外要求：**扫描步长须与台阶宽度匹配**。第 751 号首版的读数里，相邻档的 $A$ 差值序列含**精确的零**（多个 $n$ 档给出逐位相同的 $A$），这说明多个扫描档落在了**同一台阶**上。**若台阶宽于扫描步长，则扫到的是台阶内的重复点，读数呈「连续」的假象，实为同一台阶的多次采样。** 处置有两步：先测出台阶宽度（找出 $A$ 逐位相同的最长连续 $n$ 段），再据此定扫描档位；必要时改扫台阶边界附近。**单步落差须大于容差**，否则台阶内外的读数不可分。**这条对任何「整数计数对连续量」的关系都适用**，不止读法丁。

**读法丁的射程须写明**：它要求合并装置内两栏共用同一组场变量，这正是案乙部件五的构造要求；故读法丁若成立，案乙的「不需要量纲桥」成立且比读法甲更强（它给出机制而非只给身份）。

**第一步交付建议为**：两条读法（识别／不识别）的形式化与区分判据，属设计工作，不涉及数值。

## 五之补、读法丁的库内结构同构与可判形式（2026-10-21 裁定依据）

**两侧是同一种结构。** 读法丁成立的前提是两侧能由同一组场变量给出，而库内两侧的结构本就同构：

| | C1 侧 | 写入侧 |
|---|---|---|
| 逐格点载体 | 复标量 $\psi_j = A_j e^{i\theta_j}$，$A_j$ 是格点 $j$ 的局部振幅 | 站点模 $a_j$ 与记录寄存器 $c_j$ |
| 写入作用 | 逐站点直和 $H_{\rm int} = \sum_j g f(\hat\theta_j - A_j)(a_j^\dagger c_j + a_j c_j^\dagger)$，每站点自带寄存器 | 同左 |
| 格点能量刻度 | 束缚能 $E_B$ 由 $A_j$ 的亏损给出，深度方向标度 $E_B \propto W_{\rm amp}^{2.04}$ | $E_a$ 是 $a_j$ 每激发的刻度，$E_c$ 是 $c_j$ 每激发的刻度 |
| 库内依据 | [[验证脚本/注记-张量桥d的W4通路：静质量密度与振幅亏损的标度关系]]；[[验证脚本/注记-写入过程的逐站点直和多站点扩展（判据第741号）|第 741 号注记]] | [[记录机制：碰撞即写入的算符形式、三维缺陷读数与弦的分层]] §4.1；[[验证脚本/注记-写入过程的逐站点直和多站点扩展（判据第741号）|第 741 号注记]] |

**两侧都是「逐格点的局部载体 + 该格点的能量刻度」这一形式。** 这使读法丁的落地点明确：**$n$ 与 $A$ 的整数量化关系是格点内的构造**，即在合并装置的同一个格点上，写入侧的激发数 $n$ 与 C1 侧的振幅亏损由同一组场变量给出且互相确定。

**可判形式（构型判据）**。读法丁若成立，须同时满足三条：

- 其一，同一格点上 $n$ 与 $A$ 能被**同一组场变量**同时读出（不是两个独立装置的读数拼接）。
- 其二，两者**互相确定**：给定 $A$ 的读数能定出 $n$，给定 $n$ 的读数能定出 $A$ 的读数，关系为**单值**（整数量化的台阶结构）。
- 其三，$E_a$ 与 $E_c$ 的关系**由该整数量化给出**，不由外接系数给出；即净栏的量级由台阶分辨率决定。

**这三条在案乙的合并装置内可判**，且不依赖 P1-62 之外的任何待裁项。**读法丁若成立，案乙的「不需要量纲桥」成立且比读法甲更强**：它给出机制（为什么两栏同源），而读法甲只给身份（两栏是什么）。

**一条射程限定须写明。** 库内**没有**已立的「振幅 $A$ 的整数量化读数」关系，故读法丁的**构造**（格点内如何由同一组场变量同时给出 $n$ 与 $A$）属新元素层，须在案乙部件五（泛函栏位）的设计中建立。本条裁定的是**采用哪条读法**（读法丁），不是该构造的具体形式。

**故 $E_c$ 的计算骨架已在案**：记录侧的每激发刻度与耦合 $g$ 的关系只能经**率** $\eta = Cg^2$ 进入（幅度恒为一次写入一个激发，与耦合无关），且 $g$ 的绝对上界由概率守恒给出。**这使 $E_c$ 的计算成为一项有明确输入的算术工作**（给出 $C$、$S$、放大链增益与这一次转移之积的对应关系），而不再是无形状的开放项。**这一条须与案乙的第四问对齐**：案乙净栏式里的 $E_c - E_a$ 取的是记录侧每激发的刻度，而上述分工说明该刻度由耦合经率进入，这与案乙的 $E_a$（该格点的束缚能刻度，由振幅亏损的二次型给出）是两条不同的来源路径，**两者的相对大小仍是 P1-62 待裁的对象**。

**它同时给案乙一个现成的取法**：$E_c$ 的值一旦由「耦合上界的能量代价」算出，案乙净栏式的 $E_c - E_a$ 就有确定的数值来源，量级比值 $\rho$ 的条件交付也随之落定。**这一条与读法丁是互补的**：读法丁给两栏同源的结构，$E_c$ 的计算给记录侧刻度的数值。
