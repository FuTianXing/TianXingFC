## 一、审查对象与总判断

审查对象是对话中草拟的"早期宇宙高温解释"，其逻辑链为：温度 = 相位无序度 → 高温来源 = 凝固能释放 + 淬冷无序 + 磨合期缺陷 → 高温与熵解耦 → 冷却 = 格点稀释 + 校准做功。

审查结论：该解释是候选机制清单与形态学类比的组合，各环节均停留在可能性层面，却被表述为已获解释。体系内目前推导不出早期高温。能确立的只有大爆炸 = 局域成核的结晶扩张相变（P8a 修订，作者 2026-09-04 确认）这一事件陈述，从事件陈述到"高温"之间隔着两处已登记、未闭合的缺口（见第三节断点一、断点二）。

## 二、断裂点清单

### 2.1 温度定义断裂（最严重）

草拟解释同时使用两个不相容的图像，未做选择。

图像甲：温度定义为相位无序度的函数（$T \propto 1 - \eta$，$\eta = \left|\left\langle e^{i\Phi(x)}\right\rangle\right|$），原初混沌态 $\eta \to 0$ 是"最热"，温度在原初混沌有定义。此图像锚定《从混沌到兴盛》§1.2 的单点相干度。

图像乙：热力学温度 $1/T = \partial S/\partial E$ 依赖熵；体系内第二定律涌现论证（《从混沌到兴盛》§4）主张原初混沌无时间箭头、熵未结晶，则温度在相变前无定义。

两图像给出相反答案：相变前有温度还是无温度。若温度独立于熵定义，状态方程 $T(\rho)$、温度与熵的关系从何而来，体系内无交代。此环不闭合，其余讨论悬空。

### 2.2 量级断裂

高温的量级目标 $T_P \sim 10^{32}$ K 对应 $\rho(t_*^+) \sim \rho_P$。但"淬冷无序初值：波前扫过的局域锁定统计能否给出 $\rho(t_*^+) \sim \rho_P$ 量级"是《原初校准与同时凝固》注记已登记的开放问题 3，未导出。体系目前只设定了目标量级，没有从元相子动力学到 $\rho_P$ 的推导。

### 2.3 翻译循环断裂

膨胀三阶段注记已有 2026-09-05 自我降级声明：$p \propto 1/t$ 给出 $H = 1/(2t)$ 只是 FLRW 的恒等式翻译（$p = 3t_P H$），减速段的独立机制未导出。草拟解释沿用同一模式，把"磨合期高 $p$ 平台对应早期高温"当作机制，而 $p(t)$ 若只是 $H(t)$ 的重写，则该陈述等价于"早期膨胀快则温度高"，是标准宇宙学结论的翻译，不含体系新推导。

### 2.4 冷却史断裂

"冷却 = 格点稀释 + 校准做功"依赖光子红移机制。落位窗口注记已登记："激发随格点生长的红移机制须从元相子动力学导出 $\rho(a)$，消除用 $\rho(t)$ 反推 $H(t)$ 的循环依赖，这是机制自洽的关键缺口"。更尖锐的约束是格距绝对性（定理 11：$x^a = l_P n^a$）：格距固定时光子波长如何在格点插入中拉长，红移的物侧载体在体系内尚无交代。

### 2.5 解耦表述越级

"高温与熵解耦"是体系的特色主张，但成立依赖整条第二定律涌现论证链（时间箭头 ← 相干性 ← 校准）。该链在《从混沌到兴盛》中标注为论证结构，其中"守恒-相干性定理"未定，"熵泵 vs 框架增强"两模型未选。草拟解释把它当作已确立结论陈述，属表述越级。

## 三、推导链应有的形态与断点定位

完整推导应形如四步链：

1. 从凝固动力学导出凝固释放能谱，得到 $\rho(t_*^+)$（断点一：P4-17 相变能量学，未闭合）；
2. 若 $\rho(t_*^+) \sim \rho_P$，与普朗克温度对接（承接断点一的量级，未验证）；
3. 从激发随格点生长的红移机制导出 $\rho(a)$ 演化（断点二：落位窗口注记，未闭合）；
4. 得冷却史 $T \propto 1/a$，与 CMB 观测（$T_0 = 2.725$ K）对接（依赖断点二，未成立）。

断点一与断点二均已由体系自身登记为关键缺口。在此之外还有温度定义域二义性（2.1）作为前置概念缺口：定义域未决时，第 2、4 步的"温度"含义都不确定。

体系内已确立的锚点：大爆炸 = 局域成核 + 结晶扩张（P8a 修订）；时空 = 元相子定居格点阵；基态能量不作为引力源（时空观 §7、元相方程 §5.3）。从锚点到"高温"的两座桥都断着。

## 四、登记建议

2. 本注记作为断点审查的来源登记入 P4-17 条目，并联动 P4-21（$\rho(a)$ 稀释动理学缺口已在 P4-21 登记，此处仅引用）。
