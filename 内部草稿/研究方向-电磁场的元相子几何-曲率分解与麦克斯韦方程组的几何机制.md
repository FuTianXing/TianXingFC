## 一、核心命题

**麦克斯韦方程组在元相子几何中获得双重来源：无源方程组是几何恒等式（Bianchi 恒等式），有源方程组是校准动力学方程。** 法拉第定律（变化磁场产生电场）是曲率的一致性条件，其成立由混合偏导可交换保证，属几何必然；安培-麦克斯韦定律（变化电场产生磁场）是校准代价最小化的动力学结果。

## 二、基础：实轴方向场与规范势

注释八确立：每个元相子有独立实轴方向 α_n（相位零点），相邻格点的实轴方向差定义空间联络 A_a，实轴方向的演化定义时间分量 A_0。规范势 A_μ = 实轴方向场的联络。此为 U(1) 情形的严格对应（附件对应表）。

## 三、电磁场 = 联络的曲率

电磁场是联络的曲率（附件表）：

$$E_a = F_{a0} = \partial_a A_0 - \partial_0 A_a, \qquad B_a = \frac{1}{2}\epsilon_{abc}F_{bc}$$

- **电场 = 联络的时间-空间曲率**：联络的时间分量 A_0 的空间变化，减去联络 A_a 的演化
- **磁场 = 联络的空间-空间曲率**：联络绕最小回路的净扭转（涡旋线）

## 四、麦克斯韦方程组的几何分解

麦克斯韦方程组四行分为两组：

**无源组（几何恒等式）**：
$$\nabla\cdot\mathbf{B} = 0, \qquad \nabla\times\mathbf{E} = -\partial_t\mathbf{B}$$

此组是 Bianchi 恒等式 dF = 0 的分量形式，从 F = dA 自动推出（d² = 0）。它们断言：电磁场是某个联络的曲率，这一几何事实本身。**法拉第定律从独立的实验定律转变为"电磁场 = 曲率"的一致性条件**。其成立根源：混合偏导可交换（∂_t∂_a = ∂_a∂_t），使电场（含 ∂_t 的分量）与磁场（纯空间分量）必须满足同一曲率的约束。

**有源组（动力学方程）**：
$$\nabla\cdot\mathbf{E} = \rho, \qquad \nabla\times\mathbf{B} = \mathbf{J} + \partial_t\mathbf{E}$$

此组是校准代价最小化的运动方程（作用量变分）。在元相子语言中，它们描述电荷（绕数源）与电流（涡旋线运动）如何通过校准动力学（感知-校正链）塑造实轴方向场的位形。

## 五、法拉第定律的元相子机制（变化磁场 ⟹ 电场）

1. 磁场 = 实轴方向场的空间涡旋（绕格点回路的净扭转）
2. 磁场变化 = 空间涡旋的强度正在改变，实轴方向场的空间结构正在重排
3. 重排期间，相邻格点实轴方向差（∇α）的时间变化率 ∂_t(∇α) 非零，这正是电场的时间-空间曲率来源
4. 关键约束：∂_t 与 ∇ 可交换，涡旋强度的时间变化率必然与梯度的时间变化率满足 Bianchi 关系，即 ∂_t B = -∇×E
5. 结论：变化磁场必然伴随电场，方向与大小由混合偏导可交换精确固定，旋向由反对称结构（叉积）固定

此机制的几何本质：电场与磁场是同一个实轴方向场的两个导数投影（时间与空间），它们之间的耦合是"同一个场的导数必须相容"的必然结果。传统物理把法拉第定律当作归纳实验定律，元相子几何把它还原为恒等式。

## 六、安培-麦克斯韦定律的元相子机制（变化电场 ⟹ 磁场）

1. 电流 = 涡旋线运动（电荷 = 绕数，电荷运动 = 绕数结构的迁移，已废弃草稿的拓扑结果独立保留）
2. 变化电场 = 实轴方向场重排的动力学过程，由感知-校正链驱动（校准波）
3. 校准动力学最小化校准代价（能量泛函），其变分方程即麦克斯韦有源方程
4. 涡旋线（J）与重排中的实轴方向场（∂_t E）共同产生新的空间扭转（B）
5. 位移电流 ∂_t E 项的几何意义：即使无电流，实轴方向场的动力学重排本身也产生磁场，这是麦克斯韦对安培定律的修正，在元相子语言中是"校准重排的磁场源"

## 七、电磁波与正交关系

真空（ρ = 0，J = 0）中的波动解：从两组方程联立得

$$\partial_t^2\mathbf{E} - c^2\nabla^2\mathbf{E} = 0, \qquad \partial_t^2\mathbf{B} - c^2\nabla^2\mathbf{B} = 0$$

色散 ω = ck（注释四的接力几何）。平面波 e^{i(k·x - ωt)} 代入：

- **E ⊥ k**：∇·E = 0（高斯无源）⟹ k·E = 0（横向性）
- **B ⊥ k**：∇·B = 0（Bianchi）⟹ k·B = 0
- **E ⊥ B**：法拉第定律 ∂_t B = -∇×E ⟹ -iωB = -ik×E ⟹ B = (k×E)/ω，故 B ⊥ E
- **|E| = c|B|**：ω = ck 代入 ⟹ |B| = |k×E|/ω = k|E|/ω = |E|/c

**正交关系的几何本质**：E 与 B 是同一个实轴方向场扰动 δα ∝ e^{i(k·x-ωt)} 的两个互补投影。δα 的空间导数（旋度）给出 B，时间导数给出 E（偏转量的变化率，与振荡速率即频率无关）。对于沿 k 传播的波，δα 只能在垂直于 k 的平面内振动（横向性，晶格介质波的横向极化，注释五），其空间旋度（B）与时间变化率（E）自动垂直。**E 与 B 的正交 = 同一相位扰动的空间结构与时间结构的正交 = 空间轴与时间轴的正交在相位扰动上的体现**。三者两两垂直（E⊥B⊥k）对应三维空间加时间的四维结构在平面波上的投影。
