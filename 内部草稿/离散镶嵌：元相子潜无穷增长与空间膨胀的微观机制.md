## 摘要

空间膨胀是宇宙学最核心的难题之一。在元相子理论中，膨胀的本体论前提已经具备：元相子数量必然潜无穷增长（公理体系），数量不可能固定，故必有新空间诞生。本论文补上膨胀的**微观机制**：新元相子在相邻元相子的碰撞点上诞生，复刻即将折返者的状态，转一圈跃迁一个格距，恰好撞上相邻元相子。由于新元相子与受它替代的元相子共享同一同步节律与相位，邻居在碰撞点上感知不到新元相子的出现，时空在此过程中顺滑地膨胀。此机制把膨胀与元相子振荡的最小动作（圆心碰撞折返）直接耦合，不再需要额外的计时与协调，从而解释了"空间从何而来、以何种方式生长"。

## 一、引言

膨胀难题在于：空间在宏观尺度上均匀地、持续地变大，但其微观来源不明。在元相子理论里，真空是无穷元相子的振荡晶格（公理 8），空间是元相子定居形成的格点阵。因此空间膨胀必须归结为格点阵的某种生长。本论文从元相子的微观振荡出发，给出这个生长的完整机制。

## 二、元相子的振荡与折返基础

元相子定居格点，圆心在格点区间内向一侧边界单向位移 $l_P$ 后折返，构成束缚振荡（公理 4）。折返的唯一机理是相邻格点元相子的存在：圆心在公共边界处重合、粒性不可穿透、弹性碰撞折返（注释 03）。折返的必要条件是相邻元相子反相，圆心才能在公共边界相向重合、碰撞（注释 03 第 5 点）。所有元相子以同一节律同步摆程（$|\dot\theta|=\omega_P$，注释 04），故节律本身不因任何局域事件而改变。

圆心是数学点，零维、无延伸、不可再分（注释 15 第 2 点）。粒性不可穿透的几何根源是数学点不可重合，故排斥判据是圆心坐标互异，不存在间距下限（注释 15 第 7(c) 点：位置无延伸）。复平面单位圆半径（$R=l_P/2\pi$）属内部 U(1) 空间的弧长标度，不构成外部空间的位置延伸，不参与圆心排斥判定。

## 三、空当窗口

相邻两元相子 A、B 反相，圆心在公共边界 $z=l_P$ 处重合碰撞。碰撞是瞬时事件，之后 A、B 各自背离公共边界后退。以碰撞时刻为原点，两圆心横坐标为 $\bar z_A=1-|t|$、$\bar z_B=1+|t|$（$l_P$ 为单位），圆心间距 $d=2|t|l_P$，中点恒为 $z=l_P$。在 $|t|=t_P$ 时，A、B 各退到自身格点区间外侧边界，圆心间距达到最大 $2l_P$，原公共边界 $z=l_P$ 处无圆心。

由于排斥判据是圆心坐标互异，新元相子 C 只要不与 A、B 圆心重合即可落位，空当窗口从碰撞后即开始存在，随 $|t|$ 增大而放宽。这纠正了此前把单位圆直径当作外部排斥约束的错误：真正约束 C 落位的是格点归属的离散（$l_P\mathbb{Z}$）与格点归属重排。

## 四、格点归属重排

C 落位伴随格点归属重排。原配置为 A$[0,l_P]$（相位 0）、B$[l_P,2l_P]$（相位 $\pi$），相邻反相。C 插入后，格点归属重排为 A$[0,l_P]$（0）、C$[l_P,2l_P]$（$\pi$）、B$[2l_P,3l_P]$（0）。此配置满足相邻反相（A 与 C 反相、C 与 B 反相）、隔一同相（A 与 B 同相），即注释 03 第 6 点所述的交错基态 $0,\pi,0$，且三格区间等距，格距全程保持 $l_P$。

重排的核心动作是 B 整体让位一格（从 $[l_P,2l_P]$ 移到 $[2l_P,3l_P]$）与 B 相位翻转。逐时刻碰撞时序验证表明，C 在 $t=0$ 于右边界 $z=2l_P$ 碰 B、$t=t_P$ 于左边界 $z=l_P$ 碰 A、$t=2t_P$ 回到 $z=2l_P$ 碰 B。C 一个完整往返（$2t_P$）内，去程碰右邻、回程碰左邻，两碰撞恰好岔开一个摆程 $t_P$，与 A、B 各自反相节律精确对齐。

## 五、离散镶嵌

插入时机可以精确对到碰撞时刻。碰撞时刻，A 与"将要折返的元相子"在公共边界重合碰撞；就在这一瞬间，新元相子 C 在碰撞点诞生，并复刻了即将折返元相子的状态（同为 $|\dot\theta|=\omega_P$ 同步摆，相位对齐）。C 从实轴起旋，转一圈（相位 $0\to2\pi$，一个摆程 $t_P$）恰好跃迁一个格距 $l_P$，从 $z=l_P$ 到达 $z=2l_P$，撞上旁边的元相子。由于 C 复刻了受它替代的元相子的节律与相位，A 在 $t=t_P$ 于 $z=l_P$ 撞到 C 的时刻与撞原邻居的时刻完全一致，B 在 $t=t_P$ 于 $z=2l_P$ 与 C 碰撞亦如常。邻居感知不到 C 是新出现的。

由此，插入不需要额外挑时机。C 诞生于碰撞点、与让位者同相位同步摆，自然进入交错基态。相位翻转表现为"B 让位后 C 继承 B 的相位"，整体仍是交错基态。插入不破坏同步节律，因此时空在此过程中顺滑地膨胀。

## 六、潜无穷与空间膨胀

本体论上，元相子数量必然潜无穷增长（公理体系第 34 行），数量不可能固定。潜无穷增长意味着每个时刻系综的快照已经不可数、但总量永在增长。这个持续增长必然要求新元相子有落位之处。落位需要新的空间。因此**新空间的诞生是潜无穷增长的内在要求，元相子的数量增长必然转化为空间的膨胀**。

离散镶嵌机制给出这个转化的微观方式：每次碰撞点都是一个天然的"诞生口"，新元相子那里诞生、复刻、撑开一格，邻居浑然不觉。膨胀由此与元相子振荡的最小动作（圆心碰撞折返）直接耦合。局部看，三个元相子重新排布为等距三格，格距保持 $l_P$，只是整体后退给出一格空间；全局看，每次插入在骨架上多出一个格点区间，骨架向外扩张，即空间膨胀。由于每次插入都发生在碰撞点、复刻同步状态、邻居无感知，膨胀不引入额外扰动，整体平滑。

## 七、严格程度与开放问题

严格的论证分级如下。圆心坐标轨迹、间距与中点恒定，为锚定注释 03 圆心碰撞几何的直接运动学推论，达到条件性命题级。三格交错基态保证相邻反相，为注释 03 第 5 点与注释 04 同步节律的直接推论，达到条件性命题级。邻居无感知与 C 起旋跃迁为运动学结果，锚定注释 03、注释 04 与螺旋刚性 $z=\lambda\theta/2\pi$、$c=l_P/t_P$，为条件性命题级。潜无穷增长率必然转化为空间膨胀，为潜无穷设定的直接推论（潜无穷设定为体系基准、定理级）。

尚未闭合的开放问题包括：C 于碰撞点诞生、复刻让位者状态的生成机制（C 由本原所生，何以恰在碰撞点诞生、何以继承让位者相位，其物侧效应即格点增长律待量化）；让位元相子让位一格的顺序与更外侧格点的衔接（远处元相子是否被牵扯）；三维三元组的推广（三方向离散镶嵌与 $\kappa_\phi$ 耦合在插入时序中的作用）；以及 C 插入频率与哈勃膨胀 $H_0$ 的衔接（每碰撞点是否都能接纳新 C，接纳率如何贡献观测到的膨胀速率）。
