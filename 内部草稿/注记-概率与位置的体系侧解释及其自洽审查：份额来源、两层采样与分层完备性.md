## 一、三问的定位

三问看似分属三个话题，在体系里是同一条线索的三个切面。Born 规则问的是概率的**形式**，即为什么取模方；概率的产生问的是这个形式的**来源**，即份额与采样；位置的不确定性问的是这个来源的**边界**，即态矢量对哪一层说话、对哪一层沉默。

三者共用同一个骨架：概率是份额，份额的承载者是关系层，而态矢量只对关系层完备。第三问是这套骨架最容易被读错的一环，因为通常的表述预设了粒子没有确定位置，而体系的回答恰好相反。

## 二、Born 规则的份额来源

### 2.1 设定与主结果

设定是纯代数的，出处为 [[序参量份额定理：Born规则、归一化与幺正性的系综推导]]（2026-09-02 作者确认）。$N$ 个元相子分成 $M$ 个模式块，块 $a$ 含 $N_a$ 个，份额恒等式

$$\sum_a \frac{N_a}{N} = 1$$

恒成立。块内相位分解为公共相位加涨落 $\theta_i = \Phi_a + \delta_i$，块内相干因子 $\eta_a = N_a^{-1}\sum_{i \in a} e^{i\delta_i}$ 满足 $|\eta_a| \le 1$，等号当且仅当块内完全相干。序参量按块分解为 $\Psi = \sum_a w_a$，其中 $w_a = (N_a/N)\,e^{i\Phi_a}\eta_a$。

主结果是模方等于份额，且归一化自动成立，无需同步条件：

$$|c_a|^{2} = \frac{N_a}{N}, \qquad \sum_a |c_a|^{2} = 1, \qquad p_a = |c_a|^{2}.$$

这一步是**代数结论，无条件**。标准框架里归一化、Born 规则与幺正演化三条概率性公设彼此独立、来源悬空，体系把三条一并降为系综结构的推论。

### 2.2 两个口径的分工

有一处口径必须分清，2026-09-17 曾专门更正。概率幅 $c_a := \sqrt{N_a/N}\,e^{i\tilde\Phi_a}$，其模方**无条件**等于份额，承担概率；相干振幅 $A_a := \sqrt{N_a/N}\,e^{i\Phi_a}\eta_a$，其模方为相干份额 $(N_a/N)|\eta_a|^{2}$，承担干涉能力，且相干度一次方进振幅、二次方进强度。同步纯态下两者重合，部分相干时分工明确。

原「振幅开方像」写法属相干度一次方进强度的形态，与判据不符，已退役。推论一侧另有 $w_a = \sqrt{N_a/N}\,A_a$，把可测层的场量与概率幅接起来。

### 2.3 唯一性环与四把锁

「为什么必须取模方」在体系里有两条支撑。内环是唯一性：份额到概率的赋值必须满足 $U(1)$ 不变与正交可加，由此唯一为模方，定理基础是 Gleason 定理。外环是四条独立约束，整理见 [[注记-概率如何进入物理：从古典统计到玻恩规则，以及体系侧读法]] §三。

四把锁依次是：幺正演化保内积，取一次方则归一化守不住；叠加要求贡献线性相加，而可加观测量必须是非负双线性型，$\langle\psi|P|\psi\rangle$ 是满足这两条的最简形式；Gleason 定理给出维数不小于 3 时概率指派的唯一形态 $\mathrm{Tr}(\rho P)$；张量积结构加无信号要求同样把规则逼到模方。

### 2.4 严格程度

归一化与 Born 的无条件性是代数结论；叠加原理、纯态组装与混态演化属条件性命题；**概率的测量语义属纲领层**，采样投影的形式化待补；幺正性按两条路径分别声明，结构路径为定理级，守恒路径以确定性、线性与保份额为起点经 Wigner 定理得出。

## 三、概率的产生：两层采样

### 3.1 一处须先纠正的前提

微观采样采到的是**确定的局部读数**，即该处的实轴取向与相位，并不直接采到概率。概率不出现在单个格点上，它是**份额**，即在系综层面（同一制备的大量实例）落在该格的实例数占比。

因此「每个格点都在采样」提供的是处处都有的确定刻痕，概率是这些刻痕在系综上的分布。这一条纠正的是把概率当作单点属性的常见误读。

### 3.2 两层分工

单一结果出自另一层。一次测量是宏观跨层事件，要形成不可逆的记录，需要放大与多自由度锁定。两层分工如下。

| | 微观自铭刻 | 宏观跨层事件 |
| --- | --- | --- |
| 范围 | 处处，每格点每摆程 | 一处 |
| 性质 | 局域、保相干 | 不可逆、选择性 |
| 抄写内容 | 只抄写取向 | 形成记录 |
| 结果 | 确定刻痕 | 单一读数 |

把两层合成一层，才会觉得「处处坍缩」与「只有一次结果」互相矛盾。体系的分工正是为了避免这一点：自铭刻保相干，跨层事件才破坏相干并产生唯一结果。若把所有碰撞都算作坍缩，会与干涉现象直接冲突。

### 3.3 单一结果的来源

单一结果等于一台宏观装置在某处凝固并放大了一个分支的读数，其余分支失去相干、退出记录。机制图像写为**局部相变凝固**，即一个连续、可滑动、可逆的自由度被钉成确定的离散值，钉住之后回不去。两件事同时发生：对称性自发破缺（一堆等价取向中选中一个）与不可逆（化开需要额外做功）。测量结果的离散、唯一、不可逆三个特征恰好对位。

单次事件的随机性来自份额抽样与碰撞无记忆，不需额外公设。模长给「多少」（采样密度），相位给「何时」（实轴锚点决定抄写时刻）。重复 $K$ 次独立采样按大数定律趋近 $K|c_a|^{2}$。

**这一条属纲领级**：序参量、核形成率、放大阈值与时间尺度都还没有方程。体系另有一条独立路线称测量分立性由采样定理推出，属条件性命题级，与本条是两个候选机制，引用时不得混成一条。

### 3.4 非定域三义的分辨

「测量非定域」这个印象可拆成三种含义。事件层的非定域指一个事件同时发生在多处，体系没有这条，也不需要；关联层的非定域指纠缠、非定域拓扑荷与先验纠缠，体系有这条，它正是电荷保护的根据；描述层的非定域指态矢量作为整体对象不能分解为局部片段，标准量子力学本来如此。

体系里的格点采样落在事件层之外：每个格点每摆程各自发生一次碰撞与自铭刻，事件之间不需要任何全局协调，接力速度由 $c = l_P/t_P$ 限定，属局域动力学。真正非定域的是关联结构，它不传信号。

## 四、位置为何给不出确定读数：分层完备性

### 4.1 中心命题

标准困境是二选一：态矢量若是本体，个体就没有确定属性；若只是认识，干涉与纠缠就成了认识不足造成的假象。体系把两个选项都剪掉：在粒性侧，位置与计数都有确定值，而关系结构同样实在（波性侧，先验纠缠在公理层）。

由此得到中心命题（判定级）：**态矢量对关系层完备，对个体层沉默**。因此「未测量的粒子位置完全不确定」这一表述，在体系里读作「态矢量给不出位置的预测」，并不读作「粒子没有位置」。

### 4.2 对个体层沉默的理由

沉默有具体机制，不是刻意留白。单体的径向地址由 $\hbar$ 占住，指向确定并以普朗克频率匀速转，**没有可编码的振幅自由度**；态矢量的分量标号是相对读数构型，个体身份（圆心）不进入标号。个体层因此没有多余内容可被写入，也谈不上被遗漏。

态矢量是关系层的完整描述：把众元相子之间的相位差结构写成按「相对读数构型」展开的复权重谱。个体各自的圆心与读数不进入它；对象（时空晶格与基本粒子）是关系结构闭合之后的产物。份额、相位差、总绕数三者都是差，没有一个是单体属性。

### 4.3 全空间性的归属

「全空间性」归**波性侧**，来源是先验纠缠（公理层）。本体层与现象层的对照如下，出处为 [[注记-本体叠加与现象分立]]。

| | 本体层（波性侧，量子态） | 现象层（粒性侧，经典态） |
| --- | --- | --- |
| 态结构 | 叠加（潜在并存） | 分立（彼此分明） |
| 空间性 | 非定域（先验纠缠） | 定域（格点接力） |
| 时间性 | 连续可逆 | 离散不可逆 |
| 认识论 | 潜在 | 现实 |

态矢量描述的是相位差结构，而相位差跨越整个晶格，不绑定任何空间位置，这是全空间性的直接来源。位置读数本身住在格点上（间距 $l_P$），连续位置基只是宏观极限里的描述，分辨率上限由采样几何给出。

### 4.4 基对结构与连续谱口径

还有一层来自基的选择。位置与动量是**同一个自由度的两组基**，由傅里叶变换联系，换来换去不增减信息；自旋是独立的张量因子。位置与动量不能同时有确定值，因为共用同一个因子，两组基互不对易。因此「位置完全不确定」正是动量本征态那一档，它是基对的性质，不表示粒子缺了位置。

连续谱另有一处口径。位置基是广义基，$|x\rangle$ 不可归一化，$\psi(x)$ 是幅密度，$|\psi(x)|^{2}$ 是概率密度，单点概率为零，区间概率为 $\int_{\Delta}|\psi(x)|^{2}dx$。基本读数住在格点上，位置读数本质是可数计数。

## 五、位置叠加态与背景场：场侧画像

### 5.1 背景场是什么

背景场是粒子赖以形成的基底，也就是它未被激发时的规则位形。模型里它是一条具体的链，一千个格点各安其位（$u_n = n$），由弹簧与周期势联结，处处相位对齐。体系里它是**波性侧的层数结构**，即法线轴层位；粒子（位错）是这张底网上的局部错位，链在某处整体滑过半格形成扭结。

模型取 FK 链（Frenkel-Kontorova 链），能量泛函为

$$E[u] = \sum_n \frac{k}{2}\left(u_{n+1}-u_n-1\right)^2 + \sum_n K\left(1-\cos 2\pi u_n\right).$$

逐项对应见 [[注记-FK链：从Frenkel-Kontorova模型到元相子时空晶格的一维代理]] §二，摘要如下。

| FK 链要素 | 体系对应物 |
| --- | --- |
| 格点索引 $n$ | 法线轴层位 $\lvert n\rangle$，距离归粒 $x^a = l_P n^a$ |
| 位形 $u_n$ | 提升相位：小数部分为 $S^1$ 相位角，整数部分为已叠层数 |
| 弹簧项 | 键弹性 $\kappa_\parallel$，法线轴高度差（非紧致） |
| 周期势 | 格点内锁定 $\kappa_\varphi$，锚核阱 |
| kink | 复合位错粒子 |
| 缠绕 $W$ | 绕数等于粒子数等于电荷（超选择荷） |

「单一背景场承载」的含义是判别性的：一张底网独自装下叠加态，没有第二份拷贝。这一条排除了「两个粒子各占一处」的读法，判别须由全局量（缠绕与代价预算）与局域量合取完成。

### 5.2 叠加像与折叠恒等式

叠加态由单一场承载，构造为叠加像

$$w^{\mathrm{img}}_n = q\,w^{(A)}_n + (1-q)\,w^{(B)}_n,$$

其中 $w_n[u] = \frac{1}{M}\sum_{m\in\mathrm{win}(n)} e^{2\pi i u_m}$ 为窗口序参量。这是载体映射的对角通道，分离瓣极限下即真实叠加态的局域序参量 $\langle\psi|\hat O_n|\psi\rangle$ 至 $O(s_0(D))$。

折叠恒等式（命题 2）给出

$$1-|\Psi_{\mathrm{img}}| = 1-|\Psi^{(A)}|, \qquad B_{\mathrm{re}}[\mathrm{img}] = B_{\mathrm{re}}[A], \qquad \tilde R_{\mathrm{img}} = \tilde R_{A},$$

对任意 $q\in[0,1]$ 精确成立（实测偏差 $2.7\times10^{-13}$）。对照系综像（两个完整缺陷、缠绕 2）的对应量为两倍，实测比 $2.000000$。这就是「背景等于系综的局域化」的定量形态：把系综折进单一场时，成员数消失，全局代价除以支数，权重变成份额深度。

### 5.3 概率密度的区域差异

位置概率由**线性泛函**精确承载，有两个等价代理：滑量份额（拓扑恒等，偏差 $7.3\times10^{-9}$）与实通道亏空份额 $\tilde\delta_n = 1-\mathrm{Re}\,w_n$。两者都等于 Born 权重。

机制一句话：粒子在哪个位置有多大把握，场的局域相位锁定度就在哪里凹多深。窗口序参量 $w_n$ 度量该处相位对齐程度，相位越不齐整（扭结所在），亏空越大，凹痕越深，该处的位置份额越大。两瓣情形下滑量按 $q:(1-q)$ 劈开。

全场凹痕总量恒为一份（缠绕），故归一化自动成立；「铺开」不等于「摊薄」，缠绕不因叠加摊薄或翻倍。两通道的分工须分清：实通道为线性泛函，承载位置权重；模通道 $\delta_n = 1-|w_n|$ 为非线性，承担相干代价的计量并携带混叠超额 $E_{\mathrm{mix}} \ge 0$。

### 5.4 表针与干涉禁闭

表针是整体读数，住在质心零模上，读数为佩耶尔斯相位 $\Phi_{\mathrm{cm}} = 2\pi\cdot\mathrm{frac}(x_{\mathrm{cm}})$。干涉禁闭（命题 4）给出局域序参量的跨项被支重叠一致压制

$$\left|\langle A|\hat O_n|B\rangle\right| \le s_0(D) = \exp\!\left(-\frac{D^2}{8\sigma_x^2}\right).$$

推论为局域干涉禁象：两瓣的相对相位不由局域亏空承载，叠加的全部局域可读内容都在对角像里。表针动力学同样闭合：同格内两支精确简并（$6.5\times10^{-15}$）故相对相位守恒，跨格两支有 Peierls 劈裂（$3.4\times10^{-9}$）故以该速率进动。

### 5.5 经典位形承载不了

经典分瓣位形的台面区 $u_n = n+q$ 让弹簧项为零，onsite 项逐格贡献，挫折弦（命题 6）给出

$$E[S_q] = \tau(q)\,D + O(1), \qquad \tau(q) = K(1-\cos 2\pi q).$$

台面以纯相位 $e^{2\pi iq}$ 贡献全局序参量，代价随间距线性发散（实测 $R_S = 48.72,\ 97.44,\ 194.88$，增长比 $2.0000$）。台面在 $q=1/2$ 处坐在 onsite 势极大上，指数失稳率 $\lambda = 2\pi\sqrt{K} = 0.444$。判别结论：经典纯位形要么是系综像（预算两倍），要么支付发散代价并塌缩，两瓣叠加的稳定承载必须由相干结构承担。

## 六、自洽性审查

**本节属本注记的分析，非体系陈述。** 以下判断由本注记给出，引用时须注明来源。

### 6.1 无矛盾的部分

三件事是硬的。其一，Born 的形式由份额恒等式直接给出，是代数结论，这一步没有含糊。其二，分层架构本身可以自洽持有，「对关系层完备、对个体层沉默」是一个立场清楚、边界明确的命题。其三，「全空间性」归波性侧与分层一致，波性侧非定域、位置读数住格点，两者各就各位。

### 6.2 三处承重缺口

| 缺口 | 现状 | 性质 |
| --- | --- | --- |
| 概率即份额的识别（观测频率等于份额） | 未做 | 需动力学或遍历论证 |

（2026-09-24 口径补记：本行所述识别的模型侧一半已由 P3-12 采样三联的无偏性读数结案，即抽样落点的频率分布等于份额，见 验证脚本/README.md 第 91 条与 [[注记-采样三联：自触发、无偏性与带限连续极限的合成命题]]；残项收窄为机制面，即真实碰撞动力学是否按份额抽样。原行的未做就机制面而言仍成立，故保留原措辞并以此补记对齐。）
| 宏观事件等于局部相变凝固 | 无方程 | 纲领级 |

第一条尤须点明：**体系导出的是「模方」这个形式，尚未导出「概率等于份额」这个识别。** 后者是从份额到观测频率的一步，注记原文写「仍需动力学或遍历论证」。因此严格说，Born 规则给出的是「给定识别之后形式唯一」，识别本身仍未被导出；唯一性那一环还借了 Gleason 定理这一外来标准结果。

### 6.3 两处术语未钉死

**其一，「位置」在库内至少有三个所指同时在场**：个体层位置（粒子本体的位置，声称有确定值）；物理位置可观测量 $\hat x$（由层位读数构造，属关系层）；「场承载的动力学变量」（2026-09-13 收官报告的措辞）。三者共用「位置」一词，跨文档引用时会撞。

具体撞点如下。2026-09-13 的报告写「实体与位置解绑，粒子的一份是缠绕（扇区属性），位置是场承载的动力学变量，确定位置是跨层事件的产物而非存在前提」。2026-09-18 的注记写「在粒性侧，位置与计数都有确定值」。前者把位置放在场承载一侧、说确定性由跨层事件产生，后者把位置放在粒性侧、说本就有确定值。

一种读法是两者分层不同：前者说现象层的确定读数，后者说个体层的确定位置。若该读法成立，建议在术语上分层标注（个体层位置与现象层位置读数），或由作者裁定口径。此点属引用风险，不判两条各自的成立与否。**2026-09-24 该撞点升级为裁决点，见 6.7。**

**其二，「坍缩不是额外的动力学过程」与「局部相变凝固是动力学过程」有措辞张力。** 前者的本意应是「不是额外公设」，但字面读成「不是额外动力学」时，与后者相抵。属措辞问题，引用时须补限定。

### 6.4 最深的一处张力

把两条主张并置：个体层位置有确定值（用以避免「态矢量是本体则个体无属性」）；随机性不是无知（用以避免经典无知读法）。两条同时要，就落入玻姆式的张力。若个体位置确定且测量在采样它，结果即被决定，随机性退化为无知；若采样本身不确定，则确定的个体位置对结果因果闲置。

体系的回答是「态矢量对个体层沉默」。这个回答**比玻姆力学更强，也更险**：玻姆那里波函数引导粒子，并不沉默；体系说沉默，意味着个体位置对预测不贡献任何东西。于是引入它的理由只剩「避免那个哲学困境」一条，代价是把「什么算物理实在」从个体属性扩展到关系层，并接受完备性成为分层概念。

这正是「个体属性为何不提供额外预测力」（量子平衡的对应物）那条未建项要付的账。它不构成矛盾，是一笔位于承重处的未付账。

**位置侧的同一处入口。** 2026-09-24 作者从另一头指出：若锚核一直有确定位置，则份额恒等式由无条件的代数结论降为关于初始分布的统计陈述，两个位置读数（锚核钉位与层位份额）之间须补一条平衡条件。两条入口指向同一条未建项，位置侧的分支见 [[内部草稿/注记-锚核铺开方案评估：三项后果、立场代价与备选路线登记]] 第十三节其一。

### 6.5 自洽性取决于未建项的闭合方向

弱义的自洽（无自相矛盾）基本成立，但有两处术语风险；强义的自洽（一个闭合的一致整体）尚未达到，因为三处缺口都在承重处。

走向取决于两条未建项朝哪边闭合。若「个体属性不提供额外预测力」按典型性或平衡路线闭合，整个解释自洽，且是一个有内容的立场：确定本体加几何起源的统计层。若闭合不了，或按「个体位置因果闲置」闭合，个体层即成为附现象，引入它的初衷落空，解释等于悄悄退回「态矢量是本体」那一侧，只是没有说出口。

因此这套解释做的是一次**分层搬迁**（把不确定性从个体层搬到关系层），尚未把问题消解。搬迁本身不矛盾，但它需要一张许可证，而许可证尚未开出。

### 6.6 场侧画像的自洽性

场侧画像（第五节）的自洽性弱点与第二至第四节**不同源**，须分开记。

**机制层自洽。** 支撑画像的四条命题为恒等式级，命题 4(ii) 与命题 7 分别为条件性与模型级，恒等式不自相矛盾。画像的两通道分工（凹痕承载位置分布、表针承载相对相位）互不越界，且解决了「两代理并立」的历史悬案，把模通道亏空的角色定为代价计量，把权重承载留给实通道。

**语义层未体系化。** 依据篇 §7.4 自标「载体语义的体系化（叠加态等于背景场的凹痕与表针结构升为体系口径）」为纲领性主张，待作者裁决。几何与代数部分站得硬，而「这就是叠加态本身」这一句尚未取得体系地位。

**三处限定。** 其一，叠加像等于真实对角通道仅在分离瓣极限（$D\gg\ell$，误差 $O(s_0(D))$），两瓣重叠时跨项进入。其二，折叠恒等式的证明用整数平移，即要求两支全局序参量相等；相同扭结满足，两支形状不同的叠加未被覆盖，而依据篇 §7.5 的边界表未显式列出这一条。其三，语义层待裁决。

**一处须说准的成色。** 「位置概率由线性泛函精确承载」是**实现**，尚未成为**推导**。叠加像按 $w^{\mathrm{img}}_n = q w^{(A)}_n + (1-q) w^{(B)}_n$ 构造，权重 $q$ 是输入，其来源为份额恒等式；实通道亏空对构造线性，故亏空份额等于 Born 权重属构造的推论。画像的贡献在于证明 Born 权重有场侧实现，而不在于从场侧导出权重。引用时若写成后者，即把这一条抬高了。

**本注记建议取乙。** 理由四条：它不需要平衡条件，概率保住代数地位；它的随机性来源与裁决点 3 一致；它使 6.2 第三处承重缺口消失；它的代价只落在术语与一句限定的射程上。丙的代价最大，可排除。

**引力侧与位置裁决正交（一处须点明）。** 引力源取甲之后是「缺陷相对基态的能量差」，即场构型的泛函，与锚核是否有事先确定的位置无关。故甲与乙在引力侧给出同一个场：局域写入作用在铺开的能量分布上，近场随源形状、远场守恒（K4、K5 已验）。标准物理的引力源 $\langle T_{\mu\nu}\rangle$ 同样铺开，从不需要粒子有位置。本条不构成偏向，但它说明取乙不必担心引力侧。

**甲的唯一实质优势是保住个体层的独立地位。** 体系当初提出「在粒性侧，位置与计数都有确定值」，用意之一是避免「态矢量是本体则个体无属性」这个困境。乙把这个困境接受了：测量之间，个体没有属性。若作者认为这一条不可放弃，则取甲，并须同时接受一条未建项（平衡条件）与一次已采纳裁决（裁决点 3）的替换。

**取乙的代价须说准性质：它是一个两难的选择，不是新增的开支。** 6.4 已写明，体系有两条主张同时要就落入玻姆式张力：个体层位置有确定值（避免「态矢量是本体则个体无属性」），以及随机性不是无知（避免经典无知读法）。两条只能保住一条。玻姆保第一条，把随机性退成统计；取乙保第二条，放弃第一条。

**两条主张的性质不对称，故取舍有方向。** 「随机性不是无知」是科学主张，讲随机性从哪来，且有已采纳的裁决点 3 撑腰；「个体层位置有确定值」是形而上学主张，动机是避开一个哲学困境。一边有物理侧后果，一边只有哲学动机。

**放弃的是个体的基本性，实在论搬了家。** 体系的实在落在实轴方向场与晶格构型上，个体粒子从基本实体降为构型里的图案，属性由事件产生。这与体系的实轴实在论一致，实在在场这一侧。故这一笔账的性质是搬迁，它影响体系怎么讲自己，不影响任何计算。

**取乙的连带清单。** 其一，「锚核钉位」的措辞须改，具体形态取决于第五项的裁决；若取两侧显形读法，宜改称「锚核（粒性侧的显形面）」，「钉位」不再使用（密度式命名亦不可取，理由见第五项）。其二，「在粒性侧，位置与计数都有确定值」须**拆句**：计数有确定值（由扇区给出，与测量无关），位置在定案之后有确定值。原句把两样来源不同的东西捆在一起，加限定语不足以订正。其三，[[内部草稿/注记-锚核铺开方案评估：三项后果、立场代价与备选路线登记]] §七「头在哪」四选与 §八「跳变问题」在取乙后同时消解，该两节须标为「在取甲读法下成立」。其四，本注记 6.4 所述玻姆式张力在取乙后降为「不发生」。

**取乙还会带出第五项，它是新增的待裁项。** 锚核在测量前的地位须重新界定：若粒性侧是跨层事件的产物，则测量前「锚核」作为粒性侧结构的存在方式不清楚。初版曾提一个候选答案，即锚核与层位份额**共外延**（同一片缺陷上挂两个密度）。该答案不成立：**铺开的密度不能是粒性侧的东西**。粒性侧的特征是确定值、计数与离散，把锚核读成密度等于给它贴粒性侧的标签、装波性侧的货，除非把两侧分界重新定义成「关于量的类型」。故排除。

**更硬的一步是功能清点。** 锚核在体系里只有两项功能，测量前两项都落空。

| 功能 | 测量前由谁承担 |
| --- | --- |
| 钉住位错位置 | 没有对象可钉，位置事实尚不存在 |
| 供绑定能即质量 | 由构型的能量差承担（取甲已裁），不需要锚核出面 |

锚核作为测量前的结构，功能上是空的。

**可行的答案是两侧显形。** 锚核与份额是同一物的两侧，按波粒互补在不同阶段显形：测量前显波性侧（份额，铺开带相位），测量时显粒性侧（锚核，确定离散，与跨层事件同时出现）。该答案保住波粒互补这条根本原则，也让粒性侧这个标签名副其实，因为锚核只在确定值出现时才出现。代价是「守卫归波、承载归粒」的**两层分工定律须改读为「两侧显形定律」**，即两侧不同时在场。若取此读法，连带清单其一就从「改名」升级为「重新界定所指」。

**一处边界。** 本节为裁决请求，不含新科学断言。取乙不改变任何数值结论与既有验证材料，只改一处术语与一句限定的射程。所引 2026-09-13 句照录原文，其中的「而非」为原句措辞，不作改写。
