## 一、两边闭式的原样登记

D 线（D-2，判据 4/4；标准 sine-Gordon 结果加数值核对）：涨落缺口 $m_{\rm gap} = 2\pi\sqrt{K_D}$ 进声子谱；孤子（缺陷）质量 $M_{\rm sol} = 4\sqrt{k_bK_D}/\pi$ 进缺陷能动量关系；两者比 $4.93$，D-2 判定不可互换。标定点 $k_b = 1$、$K_D = 0.005$ 给 $m_{\rm gap} = 0.4443$、$M_{\rm sol} = 0.0900$（数值松弛 $0.0898$，偏差 $0.28\%$）。

字典侧（裁决十七 R1）：$m_\delta/m_P = \sqrt{K/J}$；电子锚 $K/J = 1.7518\times10^{-45}$ 给 $m_\delta = 4.1855\times10^{-23}\,m_P = 0.511$ MeV。质量论文侧：粒子为 σ 锁定孤子，质量按锁定标度 $\propto\sqrt{\kappa_\phi}$；$\kappa_\phi$ 与 $K/J$ 的换算由 M6 字典核对给出（因子 $6\pi$）。

## 二、参数映射（口径，裁决二十七）

对位：D 线键刚度 $k_b$ 对应挫折弦键刚度 $J$；D 线锁定曲率 $K_D$ 对应 onsite 系数 $K$。记 $K/J = K_D/k_b$。该映射使两边闭式进入同一参数语言；映射为口径（2026-09-20 裁决二十七采纳），适用域限两闭式的对齐与换算表。

## 三、恒等式（机器级）

在映射下，两边闭式统一以本构比 $K/J$ 表示：$m_{\rm gap} = 2\pi\sqrt{K/J}\;m_P$、$M_{\rm sol} = (4/\pi)\sqrt{K/J}\;m_P$。与字典 $m_\delta = \sqrt{K/J}\;m_P$ 合取得两条恒等式：

$$
m_{\rm gap} = 2\pi\,m_\delta = 6.283185\,m_\delta, \qquad M_{\rm sol} = \frac{4}{\pi}\,m_\delta = 1.273240\,m_\delta .
$$

$k_b = 1$ 时两式为纯数字；一般 $k_b$ 下为 $2\pi\sqrt{k_b}$ 与 $4\sqrt{k_b}/\pi$。注（2026-09-22 第 358 条）：本节「缺口」$2\pi\sqrt{K/J}$ 为 D 线口径读数；MB-9 的缺口为 $2\pi\sqrt{K/m_\Phi} = \sqrt{K/J}$，两者相差 $m_\Phi = 2\pi$，属定义归一差（[[验证脚本/注记-孤子粒性归属（第358条）：三条读数口径统一、量子数清单与装订封口]]）。标定点核对：$K/J = 0.005$ 代入给 $m_{\rm gap} = 0.444288$、$M_{\rm sol} = 0.090032$，与 D-2 报告的 $0.4443$、$0.0900$ 逐位相同；比值 $4.9348$ 与 D-2 的 $4.93$ 一致。

## 四、物理点翻译（电子锚）

$m_\delta = 0.5110$ MeV（锚定值）；$M_{\rm sol} = 0.6506$ MeV（$4/\pi$ 倍）；$m_{\rm gap} = 3.2107$ MeV（$2\pi$ 倍）。反推两案：把电子质量当孤子质量，$K/J = 1.0806\times10^{-45}$（字典值的 $0.62$ 倍）；当缺口，$K/J = 4.4374\times10^{-47}$（$\kappa_\phi t_P$ 的 $0.48$ 倍）。两案都在一倍以内波动，无数量级冲突。

## 五、判定

其一（同一族）：两边闭式同为「耦合平方根」标度，且在 D-2 标定点逐位复现；在映射假设下判定两条闭式为同一对象的两条读数。

其二（纯数字差）：孤子标签与字典质量差 $4/\pi$，缺口标签差 $2\pi$；残差属口径（sine-Gordon 前因子与质量论文归一化的对接），不构成结构矛盾。

其三（标签，裁决二十七采纳）：粒子质量取孤子（缺陷静止能量）标签，依据为 D-2 的分工结论（缺口进声子谱）；据此 $m_\delta = (\pi/4)\,M_{\rm sol}$。「锁定能隙」一词按弱耦合下与孤子质量同阶理解，不作精确定义。

其四（通道状态）：对齐本身不定值（$K/J$ 为共同自由度）；价值在转换表与身份句。转换表：$m_\delta/m_P = \sqrt{K/J}$、$M_{\rm sol} = (4/\pi)m_\delta$、$m_{\rm gap} = 2\pi m_\delta$。任何 D 线或相变动力学给出的 $K/J$ 或孤子质量立即翻译到 $m_\delta$。

## 六、两处连带

其一，**D 线量纲读数为强耦合标定点**。D 线标定取 $K = 0.005$（缺口 $0.444\,m_P$、孤子 $0.090\,m_P$）；物理点 $K/J \sim 10^{-45}$ 下量纲读数按 $\sqrt{K/J}$ 缩放（约 22 个数量级）；无因次读数（速度上限、剖面形状、比例关系）不受影响。D-4 登记的「跨区桥梁 = $K$ 的体系具体值」在此获得字典刻度：电子锚给物理点 $K/J = 1.75\times10^{-45}$。

其二，**D-6 入口份额的质量标定点**。D-6 的 $\rho_{\rm def} = fM\rho_P$ 取 $M = 0.0900$（D 线标定点）；若物理点取 $m_\delta$ 档（$4.1855\times10^{-23}\,m_P$），入口份额按 $1/M$ 重标：$f = 9.069\times10^{-124} \to 1.950\times10^{-102}$（移 $21.3$ 个数量级），「每格一缺陷」缺口由 123 个数量级变为约 102 个。重标与否归 D 线与作者，本材料只登记耦合点。
