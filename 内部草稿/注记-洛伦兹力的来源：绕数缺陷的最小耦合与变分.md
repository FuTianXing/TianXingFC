# 注记-洛伦兹力的来源：绕数缺陷的最小耦合与变分

- **状态**：推导成立（最小耦合变分属严格层；缺陷轨道有效作用量属条件性命题），判据设计见 §五，数值验证见第 445 条
- **定位**：闭合 P1-6（洛伦兹力机制）。上游汇聚点 P0-1 已于 2026-09-26 闭合，本注记给出其解锁路径上的第一条下游推导
- **依据**：[[规范作用量的审计必然性：从净值审计到电磁场作用量的推导与数值验证]] §3.1 与 §3.4；[[电荷的几何本质：满周闭合环内部U(1)缠绕数方案的系统辨析]]（电荷 = 绕数）；[[电磁场的元相子几何：麦克斯韦方程组的双重几何来源]] 开放问题 2

## 一、问题

P1-6 的原始提法是：运动电荷在磁场中偏转（$\mathbf{F} = q\mathbf{v}\times\mathbf{B}$）如何从绕数结构与涡旋线的耦合涌现。正稿 §3.4 已给出框架句"含源方程由耦合块对物质场变分给出，洛伦兹力随最小耦合项的变分自动出现"，本注记把它展开为可判据的推导。

## 二、既有材料

耦合块（正稿 §3.1）：协变相位差 $\delta_a(n) = \theta_{n+\hat a} - \theta_n + A_a(n) l_P$ 的余弦代价 $\sum_n\sum_a[1-\cos\delta_a(n)]$，它是最小耦合的格点形式。电荷侧：电荷是满周闭合环内部的相位缠绕，荷量由绕数 $w$ 给出（既有裁决）。两者拼起来的路是：缺陷携带绕数，缺陷的移动经由相位搬运与规范势耦合。

## 三、推导三步

第一步，缺陷的相位搬运给出拓扑耦合。绕数缺陷沿路径移动时，其内部相位绕圈随行；把相位沿路径搬运要经过规范势，故作用量中出现

$$S_{\text{AB}} = 2\pi w \oint_\gamma A_\mu \mathrm{d}x^\mu,$$

即 Aharonov-Bohm 型耦合项，绕数 $w$ 扮演荷的角色。这一步只用到"电荷 = 绕数"与联络的搬运规则，不引入新假设。

第二步，把路径按时间参数化，耦合项成为标准最小耦合

$$S_{\text{AB}} = 2\pi w\int A_\mu \dot x^\mu \mathrm{d}t,$$

与连续最小耦合 $q\int A_\mu \dot x^\mu$ 同形，荷的对应是 $q \leftrightarrow 2\pi w$（模量纲归一）。

第三步，对轨道变分给出洛伦兹力。物质侧的轨道作用量取 $S_m = \int \frac{m}{2}\dot x^2\,\mathrm{d}t + S_{\text{AB}}$，对 $x^\mu$ 变分得

$$m\ddot x_\nu = 2\pi w\, F_{\mu\nu}\dot x^\mu,$$

即洛伦兹力，其磁场分量写成三维形式就是 $q\mathbf{v}\times\mathbf{B}$。磁力的来源因此落在拓扑耦合与最小耦合的同一个变分上，无需额外假设的规则。

## 四、格点细节

两点要交代。其一，规范不变性：$S_{\text{AB}}$ 是圈积分，在 $A \to A + \mathrm{d}\chi$ 下只增加 $2\pi w\times$（整数圈）的相位，模 $2\pi$ 不变，故与耦合块的规范不变性一致。其二，场强的格点身份：绕圈净变化 $F_p l_P^2$ 已由投影论证（正稿 §3.2）给出，与这里的 $F_{\mu\nu}$ 是同一个量，故"绕数乘场强"这一结构在格点与连续两侧同形。

## 五、判据设计（指向第 443 条）

V1 拓扑耦合：缺陷沿闭合路径绕一圈，作用量相位变化等于 $2\pi w\Phi$（$\Phi$ 为圈内磁通），与解析值相符。

V2 变分核对：对 $S_m$ 数值变分提取加速度，验证其与 $2\pi w F\dot x$ 成正比（长波与低幅前提下）。

V3 极限核对：静止荷（$\dot x = 0$）不受磁力；纯电场配置下给出库仑型力；纯梯度势（$F = 0$）下力为零。

## 六、严格程度与边界

严格：Aharonov-Bohm 耦合与最小耦合变分（标准结果）；绕数扮演荷的对应（既有裁决）。

条件性：缺陷轨道的有效作用量写法（把缺陷当作质点处理，忽略其内部结构对短程行为的影响）。

不涉及：自旋磁矩（需自旋与场的耦合，属另一条线）、辐射反作用（体系未建）、强场下的缺陷形变（BH 线）。

## 七、待攻项

缺陷轨道的有效作用量在**有限宽度**下的修正（复合位错有包层宽度）未做；这一项与 P1-11（锚核锁定动力学）同源，登记但不在本注记范围内。
