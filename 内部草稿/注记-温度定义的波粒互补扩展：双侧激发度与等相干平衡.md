## 一、任务与动机

波粒互补公理要求温度也是双侧的。既有定义 $k_BT = \hbar\omega_P(1-\eta)$ 只使用波侧（相位）无序度 $\eta$。7.7 为修复因子 2 补入幅度自由度，但默认相位与幅度涨落同由单一温度参数化（热化机制未形式化），且幅度标定 $\bar P = \sqrt{\tilde{O}\tilde{G}/\tilde{A}}$ 依赖天行方程序参量；7.9 数值探索定位该标定被三项 DOGA 结构问题阻塞（$\tilde{O}$/$\tilde{G}$ 激活机制、$\tilde{A}$ 下限来源、序参量界域），$\bar P$ 暂作自由参数。按作者指示，本注记把粒侧从序参量形式中解放：粒侧激发度只用振幅分布本身的矩定义，双侧各自携带激发度，单温度是两侧等温的平衡表现。

## 二、定义

设元相子复振幅 $z(x) = P(x)\,e^{i\Phi(x)}$，$P \geq 0$ 为粒性侧原初量（定居强度），不预设任何方程形式。单点分布给出两个互补的无序度：

**波侧激发度**（既有定义保留）：

$$t_w \equiv \hbar\omega_P\,(1-\eta), \qquad \eta = \left|\langle e^{i\Phi}\rangle\right|$$

**粒侧激发度**（新）：

$$t_p \equiv \hbar\omega_P\,(1-\xi), \qquad \xi \equiv \frac{\langle P\rangle^2}{\langle P^2\rangle}$$

$\xi$ 为振幅矩比相干度（反参与比型），性质：尺度不变（只依赖分布形状，不依赖绝对标度）；$\delta$ 分布给出 $\xi = 1$；小涨落 $P = \bar P(1+\epsilon)$ 给出精确式 $\xi = 1/(1+\sigma_\epsilon^2) \approx 1 - \sigma_P^2/\bar P^2$；完全离域给出 $\xi \to 0$。粒侧无序度 $p \equiv 1-\xi$ 的饱和途径是定居率趋零（$P$ 几乎处处为零、偶发闪现），与波侧无序度饱和于相位完全随机互补。

**等相干平衡**（体系"热平衡"定义提案）：

$$t_w = t_p \iff \eta = \xi$$

平衡温度 $T \equiv t_w/k_B = t_p/k_B = T_P\,(1-\eta)$，精确还原既有定义。平衡定量关系（小涨落）：

$$\frac{\sigma_P^2}{\bar P^2} = 1 - \eta \approx \frac12\langle\delta\Phi^2\rangle, \qquad \sigma_P^2 = \frac{\bar P^2}{2}\langle\delta\Phi^2\rangle$$

非平衡态一般 $t_w \neq t_p$，体系处于双温度态；热流方向由波粒耦合动力学决定（方向与耦合符号有关，第二定律方向的涌现依赖该动力学，与《从混沌到兴盛》§4 论证链衔接但未闭合）。

## 三、小涨落极限、能量均分与刚度

$w \equiv 1-\eta \approx \frac12\langle\delta\Phi^2\rangle$（已有）；$p \equiv 1-\xi \approx \sigma_P^2/\bar P^2$。定义两侧刚度：

$$\kappa_\Phi = \tfrac12\hbar\omega_P, \qquad \kappa_P \equiv \frac{\hbar\omega_P}{\bar P^2}$$

相位刚度与 7.8 一致；粒侧刚度把 7.8 的未定常数 $c$（$\kappa_P\bar P^2 = \hbar\omega_P/c$）由互补对称性固定为 1：两侧激发度-能量关系同构，无新增常数。平衡下：

$$E_w = \tfrac12\kappa_\Phi\langle\delta\Phi^2\rangle = \tfrac12\hbar\omega_P\, w = \tfrac12 k_BT, \qquad E_p = \tfrac12\kappa_P\sigma_P^2 = \tfrac12\hbar\omega_P\, p = \tfrac12 k_BT$$

**能量均分是等相干条件的直接推论**，每侧一个二次自由度携带 $\tfrac12 k_BT$，与标准能量均分定理同构，无特设系数。

## 四、闭合与溶解

**因子 2 的计数论表述**。纯波侧熵系数 $\tfrac12$ 是单个二次自由度熵的普适签名；$T_{vM} = 2T_{\text{def}}$ 即总自由度与波侧自由度之比（2 : 1），物理内容为把每自由度 $\tfrac12 k_BT$ 误读为整个 $k_BT$。7.7"遗漏幅度自由度"的裁决获得计数论表述，且不再依赖幅度被单一温度参数化的假设：两侧各有自己的激发度，相等只是平衡态。

**对数熵保持**。$S = S_w + S_p \approx C + \tfrac12\ln w + \tfrac12\ln p$；平衡 $w = p$ 给出 $S = C' + \ln(1-\eta)$，系数 $1 = \tfrac12 + \tfrac12$，精确恢复对数熵。熵-温度相容（平衡下）：

$$\frac{\partial S}{\partial E} = \frac{\tfrac12 k_B/w}{\tfrac12\hbar\omega_P} = \frac{k_B}{\hbar\omega_P w} = \frac{1}{T}$$

**发散截断保持**。两侧各自饱和于 $\hbar\omega_P$，平衡温度上限 $T_P$ 保持；时空外（相变前）$t_w = t_p = \hbar\omega_P$，$T = T_P$，推论一至三的全部数值锚点不变（$T_P$ 上限、$T_0 = 2.725$ K 读出 $1-\eta = 1.9\times10^{-32}$）。

**绝对零度细化**。零度 = $\eta = 1$ 且 $\xi = 1$，相位锁定且振幅定居，两侧同时凝固。单向锁定（一侧有序另一侧离域）仍携带另一半激发度，不构成零度。

**7.9 阻塞溶解**。定义依赖链中删除 $\tilde O$/$\tilde G$/$\tilde A$：$\xi$ 是振幅分布矩，$P$ 的动力学（定居机制）与温度定义解耦，只影响冷却史，不影响定义。$\tilde A \to 0$ 的 $\bar P$ 发散（7.9 发现二）不再威胁温度：粒侧无序度是形状量、尺度不变，$\bar P$ 绝对标度不进入温度，该发散残留为真空能绝对标定问题（P4-17 关联）。发现四的相变型饱和（拟合指数 $q\sim38$）是 $\bar P$ 动力学的性质，不构成温度结构威胁。发现三（序参量界域）归 DOGA 自身形式化，与温度无直接牵连。7.9 三项阻塞全部退出温度定义路径。

**热化机制重新定位**。7.7 待验证② 从定义承重墙拆下：单温度参数化不再需要先验论证，它是等相干平衡定义的内容。遗留的动力学问题变为：波粒耦合弛豫（两侧激发度如何趋同），耦合是波粒同一实体的固有结构，强度不引入新常数，形式化待攻。

## 十、v2 修订：复振幅正交分解与一般态温度（2026-09-08）

**修订缘起**。评审（[评审-温度定义的波粒互补扩展]（2026-09-08，内部草稿））提出两点异议。其一，定义域收窄：v1 温度仅在平衡（$\eta = \xi$）存在，非平衡态只有双温度读出，$T_0 = 2.725$ K 的语义依赖"今天近似平衡"这一经验事实或公设，原定义无此依赖。其二，公设自由度为 2：矩比 $\xi$ 与等相干平衡同时公设，尺度不变、小涨落精确式、定居率语义是矩比的选择理由，未经推导。两点均成立。本节以复振幅正交分解重构，两条异议同时溶解，等相干平衡公设撤销。

### 10.1 正交分解与运动学定理

锁定态取 $z = \bar P$（实轴），涨落分解为径向 $a$ 与切向 $b$ 两个正交分量，$z = (\bar P + a) + ib$：径向是振幅扰动（粒性侧），切向是相位扰动（波性侧），分解由波粒互补公理指定，不预设方程形式。小涨落展开（数值确认，$\sigma \leq 0.05$ 时千分位级吻合）：

$$1-\eta = \frac{\langle b^2\rangle}{2\bar P^2}, \qquad 1-\xi = \frac{\langle a^2\rangle}{\bar P^2}$$

波侧无序度只读切向方差，粒侧无序度只读径向方差（四种各向异性组合的数值确认：两侧独立进入各自无序度）。核心结果为各向同性下的运动学定理：

$$\sigma_a = \sigma_b \ \Longrightarrow\ 1-\xi = 2(1-\eta)$$

径向与切向方差相等（复平面旋转对称，高斯热态的自然对称性）时，粒侧无序度恒为波侧两倍。这是分解的恒等式，与平衡假设无关。

### 10.2 一般态温度与等分配平衡

涨落弹性能取各向同性复弹簧（互补公理的动力学读法：锁向只挑实轴方向，恢复力在复平面无各向异性；单点均匀模适用，空间梯度项的刚度差是动力学结构，不进入单点温度定义）：

$$E = \tfrac12\kappa\left(\langle a^2\rangle + \langle b^2\rangle\right) = \hbar\omega_P\left[(1-\eta) + \tfrac12(1-\xi)\right]$$

其中 $\kappa\bar P^2 = \hbar\omega_P$ 为唯一 $O(1)$ 归一化选择（7.8 未定常数 $c = 1$ 由此固定，无新增常数）。**一般态温度（v2 定义）**：$k_BT \equiv E$。任意锁定附近态有定义，无平衡公设，异议一溶解。原定义 $k_BT = \hbar\omega_P(1-\eta)$ 成为粒侧冻结极限（$\xi = 1$），波侧读出 $t_w = \hbar\omega_P(1-\eta)$ 是部分温度（只计切向能量 $E_w$）。定义域相对 v1 扩大：v1 需平衡才有温度，v2 中原定义本身是一般式的极限情形。

**平衡（v2 定义）**：各向同性复弹簧的玻尔兹曼分布自动各向同性（$\sigma_a = \sigma_b$），运动学定理给出 $1-\xi = 2(1-\eta)$；两侧能量自动均分（每分量一个二次自由度各携 $\tfrac12 k_BT$）。平衡温度三读出合一：

$$k_BT = E = \hbar\omega_P(1-\xi) = 2\hbar\omega_P(1-\eta)$$

平衡上限保持：$T = T_P(1-\xi) \leq T_P$，粒侧读出承载上限，$T_P$ 锚点不动。

异议二溶解：结构公设只剩一条（各向同性复弹簧加归一化），等分配平衡、$2:1$ 比值、矩比系数 $\tfrac12$ 全部为推导结论。矩比 $\xi$ 降格为径向无序度的导出量（小涨落测量算符）；熵基相干度等替代形式只影响有限涨落区的精确完成，不再承担定义结构。与第七节探索方向的衔接：基态 $T = 0$ 即相干态（$\Delta N\Delta\Phi$ 取等号），热态为复平面各向同性高斯，不确定关系探索与本结构同源。

### 10.3 v1 等相干平衡线的地位

v1 平衡线 $\eta = \xi$ 在正交分解下对应 $E_w = 2E_p$：径向方差为切向一半的调谐各向异性，测度为一，非热平衡的自然形态。v1 数值自检中 $w = p$ 成立，因为检验构造了 $\sigma^2 = s^2/2$ 的精确调谐态。平衡线随刚度比而变：一般地 $p = (2\kappa_\Phi/\kappa_P\bar P^2)\,w$，双侧同刚度给 $p = 2w$，7.8 记载的 $\kappa_\Phi = \hbar\omega_P/2$（其能量式的 $\tfrac12$ 惯例混用需统一）对应 $p = w$。v2 取同刚度的根据是互补公理（波粒两面无刚度特权），最终刚度比待作者裁决。

### 10.4 因子 2 定案与锚点重指派

熵路线与弹性能路线在平衡点会合：熵计入两个自由度（平衡下 $S = C + \ln(1-\eta)$，低温柔斯常数 $C = \ln(2\pi e\sqrt2)$，数值确认），能量计入两个分量，两者给出同一温度 $T = 2\hbar\omega_P(1-\eta)/k_B$。7.6 的 $T_{vM} = 2T_{\text{def}}$ 由此定案：熵温度自始正确，原定义是波侧部分读出，差额即粒侧能量。7.7"系数 1 维持"的裁决被一般式取代，原定义保留为粒侧冻结极限。

### 12.1 三问三答

**问一：两个交叉角态存在吗？**（相位完全无序 + 幅度完全有序；相位完全有序 + 幅度完全无序）

**问二：两种无序是并行且等价的同一过程吗？**

是。热无序是锁定背景在复平面上的各向同性弥散：一个云团、一个弥散参数 $u = (\langle a^2\rangle+\langle b^2\rangle)/\bar P^2$；$1-\eta$ 与 $1-\xi$ 是同一云团切向宽度与径向宽度的两种归一化读数，自然轨迹（各向同性族）上互为单值函数（等价），随弥散同增同减（并行）。$2:1$ 是该映射在小弥散端的切线（归一化影子），$O(1)$ 弥散处映射弯折（$\sigma = \bar P$ 处 $p/w \approx 0.45$，11.2 数据），单参数结构不变。本裁决定案 10.3 遗留的刚度比问题：云团无椭圆性，同刚度；$\hbar\omega_P$ 与 $\hbar\omega_P/2$ 两种惯例的统一列为 A 注记同步项。
