## 一、两支取法

$\omega_P$ 是元相子的相位速率。两支取法给出不同的满周历时：

- **候选甲**：$\omega_P = 1/t_P$。满周（$2\pi$）历时 $2\pi t_P$。
- **候选乙**：$\omega_P = 2\pi/t_P$。满周历时 $t_P$，圈频率 $\nu_P = 1/t_P$。

两者差 $2\pi$。判别的关键不在相位本身，在相位与格点跃迁的耦合。

## 二、裁决：候选乙成立

**公理 4 与自由元相子光速钉死候选乙。** 公理 4 规定相位每满周（$2\pi$）使圆心沿法线轴跃迁一个 $l_P$；同一处又规定自由元相子以光速无限直飞。元相子每满周前进 $l_P$，速度等于光速，故满周历时为 $l_P/c$。接力几何给出 $c = l_P/t_P$，于是满周历时 $t_P$，$\omega_P = 2\pi/t_P$。

候选甲给出满周历时 $2\pi t_P$，自由元相子速度随之变成 $l_P/(2\pi t_P) = c/2\pi$，与公理 4 的「以光速直飞」相抵，排除。

**库内主流口径与此一致，且相互独立。** 术语表 §八「普朗克角频率」写作 $\omega_P l_P = 2\pi c$，即 $\omega_P = 2\pi/t_P$。公理体系 §5 写作 $E_\Phi = \hbar\omega_P = E_P = 2\pi E_P^{(t)}$。四质量注记的恒等式层写作 $\omega_P t_P = 2\pi$ 与 $E_P t_P = h$。相位耦合标度条目写作 $\omega_P K_0 = 1/t_P^2$，代入 $K_0 = 1/(2\pi t_P)$ 同样给出 $\omega_P = 2\pi/t_P$。基准文档《元相子理论的时空观》亦取候选乙：紫外截断节把可分辨频率上界写作 $\omega_N = \pi/t_P$（即 $\omega_P/2$），离散镶嵌节写「转一圈（相位 $0 \to 2\pi$，一个摆程 $t_P$）恰好跃迁一个格距 $l_P$」，§7 基模能量写 $E_\Phi = \hbar\omega_P = 2\pi E_P^{(t)}$ 并明标「消除与标准普朗克能量的 $2\pi$ 混用」。判据级材料同向：量纲桥 MB-1b 注记写「$\omega_P$ 取角频率，按 $\omega_P = 1/t_P$ 读会引入一个 $2\pi$」。六处互相独立，同指候选乙。

## 三、$2\pi$ 的来路

两条「作用量储备」恒等式在体系内并存：$m_Pc^2t_P = \hbar$ 与 $E_\Phi t_P = h$。两者差 $2\pi$，来路是 $m_Pc^2$ 与 $E_\Phi$ 的身份不同。$E_\Phi = \hbar\omega_P$ 是元相子的能量量子，$m_Pc^2$ 是普朗克质量的质能当量，二者满足 $E_\Phi = 2\pi m_Pc^2$。公理体系 §5 已显式写下这条关系，故这处 $2\pi$ 是体系的既有结构，不构成口径冲突。

## 四、两处误写的来源

相位层关系在四质量注记的幸存清单里写作 $m/m_P = \omega_0 t_P$。2026-10-15 的核对注记 §五 第三把它写成「费米子内禀频率与普朗克频率之比 $\omega_0/\omega_P = m/m_P$」，并在同一段把「约化康普顿波长」称为「缺陷的满周步长」。

两处都差一个 $2\pi$。其一，$\omega_0/\omega_P = \omega_0 t_P/2\pi = (m/m_P)/2\pi$，不是 $m/m_P$；写成比值形式时应为 $(m/m_P)/2\pi$，写成相位层关系时应为 $\omega_0 t_P = m/m_P$。其二，约化康普顿波长是缺陷的宽度（衰减长度），满周步长是全周 $h/(mc)$，两者差 $2\pi$。

该误写随后被照录进术语表 §十「质量的长度投影」与洞见速览第 36 条。三处均为同一处转录错误的下游。

## 五、附：作者稿 $7\times10^{-24}$ 的正确读法

作者稿写「物质场相位速率只有普朗克节律的约 $7\times10^{-24}$」。按候选乙，$\omega_0/\omega_P = (m_e/m_P)/2\pi = 6.66\times10^{-24}$，故该数字作为角频率比本身无误。它与宽度比 $\xi/l_P$ 不互倒，乘积为 $1/2\pi$。互倒对是相位层关系 $\omega_0 t_P = m/m_P$（数值 $4.19\times10^{-23}$）与宽度比 $\xi/l_P = m_P/m$（数值 $2.39\times10^{22}$）。
