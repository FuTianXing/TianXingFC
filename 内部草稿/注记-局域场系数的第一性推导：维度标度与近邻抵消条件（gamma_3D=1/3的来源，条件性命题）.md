## 一、问题

第 582 条把密度标度建立在局域场修正 $\omega_r^2 = \omega_0^2 - \gamma_{3D}\beta^2$（$\gamma_{3D} = 1/3$，球腔几何）上，与 Clausius-Mossotti 分式逐位等价；$\gamma_{3D}$ 此前是几何输入，极化灾难的因子 3（$\beta^2 = 3\omega_0^2$）即其倒数。本注记在体系内推导这个系数。

## 二、推导

洛伦兹分解（582 口径，均匀模下平均场与自洽场在热力学极限等同）：偶极感受到的场

$$E_{\rm loc} = E_{\rm macro} + E_{\rm near} + E_{\rm cav}$$

三段的体系内地位与取值如下。

**第一段（宏观场）**：$E_{\rm macro}$ 为平均场（含样品退极化），热力学极限下与自洽场等同（第 582 条既有口径），非本轮内容。

**第二段（近邻抵消，体系几何事实）**：挖除半径 $R$ 的腔后，腔外其余偶极对中心贡献记 $E_{\rm cav}(R)$ 之外的近邻修正。对正交晶格上方向一致的偶极阵列，第一非零壳层（$2d$ 个最近邻）的偶极场和为**恒等式级零**：沿 $\hat a$ 方向的两邻居给出 $[3p\hat a\hat a - p] + [3(-\hat a)p(-\hat a) - p] \cdot$ 对称抵消，各轴同理，任意 $d$ 维正交晶格成立。这是晶格几何的对称性恒等式，也是立方对称介质局域场修正恰为洛伦兹值的标准原因。一般各向异性晶格（非正交或基元内多偶极）此项非零。

**第三段（腔项，维度标度为本轮推导）**：$d$ 维各向同性介质中挖 $d$ 维球腔（$d=2$ 为圆），腔面上极化电荷 $\sigma = \mathbf{P}\cdot\hat n$ 对腔心的场为

$$E_{\rm cav}^{(d)} = \frac{\mathbf{P}}{d}$$

推导：$d$ 维球面元立体角 $\mathrm{d}\Omega_d$，$\sigma = P\cos\theta$，场的径向分量沿轴积分 $\int \cos^2\theta\,\mathrm{d}\Omega_d / \Omega_d = 1/d$（$\cos^2$ 在球面平均为 $1/d$，维数唯一的来源）。$d = 3$ 给 $P/3$、$d = 2$ 给 $P/2$、$d = 1$ 给 $P$（两端面电荷场）。**$\gamma_d = 1/d$：维度标度是本轮的核心推导**，球腔的非平凡内容只是 $d = 3$ 的实例。

**合流**：$$\gamma_d = \frac{1}{d}\quad(\text{条件：介质各向同性、正交晶格、均匀极化})$$

## 三、结论形态与两层对照

结论为**条件性命题级**（三条件缺一即偏移）：其一，各向同性选球腔（针腔给 0、板腔给 1，非各向同性形状破坏唯一性）；其二，正交晶格近邻抵消（各向异性晶格 $E_{\rm near} \neq 0$，等效 $\gamma$ 偏移）；其三，均匀极化（582 口径）。

两层对照：其一，**极化灾难因子同源**：$\beta^2_{\rm crit} = \omega_0^2/\gamma_{3D} = 3\omega_0^2$ 的因子 3 即 $1/\gamma_{3D}$，本轮推导把它从「球腔输入的倒数」升为「维度标度 + 各向同性条件」的产物。其二，**与已知物理对齐**：2D 层状材料的局域场修正为 $1/2$、各向异性晶体偏离 $1/3$，均为标准介质物理的已知事实，体系推导给出其体系内来源（维度与对称条件），可作为体系对照支撑而非孤立假定。

## 四、判据设计（待立项）

V3a（维度标度）：偶极阵列数值求和（3D 立方与 2D 正方，偶极方向一致），测 $E_{\rm loc} - E_{\rm macro}$ 对 $P/d$ 的回归，两档维度各自逐位（退极化纠缠的处理方案：以「挖腔半径 $R$ 的平坦性」为读数：球对称壳层对腔心场贡献与 $R$ 无关，平坦值即含 $P/3$ 的洛伦兹分解值，避开样品形状假设）。

V3b（近邻抵消齿）：第一壳层求和的对称性恒等式数值确认（随机扰动破坏对称后偏移）。

V3c（维度对照齿）：2D 阵列若给 $1/3$ 而非 $1/2$ 即判据构造错误，维度区分力内置。

恒真风险：球面积分是标准数学，判据重心在离散晶格修正的收敛与维度区分；偶极场求和的条件收敛性（形状依赖）须以平坦性读数规避，禁用绝对宏观场对表。
