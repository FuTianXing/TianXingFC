## 一、方案陈述

作者 2026-09-15 提出如下链条。

其一，引力使视界内的物质必然共同流向中心，即汇聚到一个普朗克时空晶格。其二，物质（实际是 kink）在该格点内累积。其三，累积超过普朗克质量 $m_P$ 后，晶格本身被破坏。其四，纽结解体。其五，自身能量通过霍金辐射向外释放，也可能被本原完全吸收。其六，相位信息回归本原。

作者随后给出三处澄清与两处机制补充。**澄清**：晶格破坏必然导致碰撞接力机制失效，漏洞会扩大并可能摧毁整个时空，但本原的"补天"可以处理，因为本原具有生生不息的创生力量；元相海不必然是普朗克温度，那只是最初的无序状态；晶格破坏后物质不落入元相海，直接由本原吸收；绕数可以不解体，直接回归本原。**补充**：由于碰撞接力的频率与相位严格同步，漏洞也许根本不需要新元相子填补，它会自动闭合，即被旁边的元相子接管，总格点数因此减少。

**这个方案的价值在于它给出了三处此前空白的候选答案**：黑洞内部的终态机制、霍金辐射的来源、信息的去向。其中"阈值取 $m_P$"与体系既有的满偏标度（$m = m_P$ 时每拍写入 1 弧度）天然对齐，不需要新参数。

## 二、三处前提澄清

**澄清一：元相海不等于原初混沌。** 对话中曾以"元相海态对应 $D \to 1$、温度趋于 $T_P$"为由，指出"晶格破坏后落入元相海"与霍金辐射低温之间存在六十个数量级的温度矛盾。**该论证作废**：体系里元相海的定义是"元相子的最大集合"，不含无序限定；只有大爆炸前相位完全随机的原初态才对应 $D = 1$ 与 $T_P$。晶格破坏后并不蕴含落入普朗克温度。

**澄清二：绕数不解体。** 对话中曾担心"纽结解体"意味着绕数消失，从而违反电荷超选择保护的绝对守恒。作者澄清绕数直接回归本原，拓扑荷没有丢失。该张力解除。

**澄清三：破坏区被本原吸收，不留在物侧。** 这一条同时解决三件事：避开"破坏区处于何种热力学态"的追问；给信息一条不丢失的去路；解释为什么晶格破坏不会在宇宙里留下无法收拾的废墟。**对话中把"破坏"默认读成"变成局域元相海"，属外加假设，应删去。**

## 三、两处技术障碍的审查

**障碍一：单个格点装不下 $m_P$。**

先给数量级。质子质量约为 $1.3\times10^{-19}m_P$，故需要约 $10^{19}$ 个粒子、约 $10^{19}$ 个格点。取立方区域，边长约 $2.4\times10^6$ 个格距，即约 $4\times10^{-29}$ m。**这个尺度比普朗克长度大六个数量级。**

据此审查两条出路。

**出路甲（区域读法）**：把"格点"读成"普朗克尺度的区域"而非单个元相子。与位错相容（多个位错共存于不同格点），但"普朗克尺度"一词必须放宽为"介观小区域"，门槛随之变成需要另行标定的数。

**出路乙（层数读法）**：把累积放到法线轴的层数上。与"距离归粒"相容（层数即距离），但要回答与"圆心不可重合"约束的关系：若多个锚核落在同一格点则属重合，若落在沿法线的不同层则它们本是不同格点。**后者可行，但空间图像由点塌缩变为沿中心法线的一维塌缩。**

**作者倾向单个晶格更自然，本注记认同该倾向**，理由见第六节。

**障碍二：补天速率（已消解）。**

初版审查曾指出：体系的创生速率是内部落位 $3H_0$，每格点平均约 46 亿年落位一次，而视界内的动力学时标是毫秒，两者差二十个数量级；若补天走这条既有通道，它比漏洞扩张慢得多。当时给出三条出路（按需创生、补有序性、连格点一起吸收）。

**作者随后的补充消解了这条障碍**：漏洞自动闭合，不需要新元相子填补。既然不存在"补"这个动作，速率问题随之消失。**本注记撤回该审查，并把它降级为"若自动闭合失效时的备选"**：补天作为能力保留，自动闭合作为默认路径。

## 四、吸收的物侧机制：离散镶嵌的逆过程

作者给出的机制如下。设 A 为被破坏的格点，B 与 C 是其两侧邻居。A 退出后，B 的几何圆心跃迁到边上时，迎来的碰撞对象是 C 而不是 A。**格距全程不变，没有任何元相子跃迁超过一个普朗克长度。**

**这与体系的离散镶嵌机制同构，只是方向相反。** 离散镶嵌是：新格点插入 → 让位链瞬时重标 → 坐标被拉开 → 空间增加，全程属纯标记操作，除新格点之外不额外新增格点。**本机制把它倒过来跑**：A 退出 → 让位链反向重标 → B 与 C 的坐标差由 2 变为 1 → 空间减少一个格距，格点总数减一。

**由此得到三点。**

其一，**格点消失不需要新机制**，它是既有落位机制的逆操作。坐标重标是纯标记，格距不受影响，晶格刚性原理不被触碰。

其二，**"吸收"获得物侧的具体形态**：把一段空间连同格点一起退出物侧，边界随之靠拢，谈不上"把能量抽走"。

其三，**初版审查中的一处判断错误**：曾以"格点数减少而空间还在，则格距必然变大"为由判定该读法违反晶格刚性。**该判断作废**，它把"格点数减少"错读成了"格点密度降低"。消失的是一段空间，坐标是相对量，格距不变。

## 五、质量作为饱和驱动参数

作者 2026-09-15 提出：在新方案中，质量扮演饱和机制的角色，达到普朗克质量，时空晶格就被毁掉。

**质量在体系里本来有三重身份，这一条把它们串了起来。** 其一，质量决定写入幅度（$\delta\theta = m/m_P$），即「每拍写多少」。其二，$m_P$ 是满量程标度（见 [[注记-普朗克质量的角色：引力响应的满量程标度，非空间实体质量]]），即那把尺子。其三，质量同时是饱和的驱动参数：它越大，系统离满偏越近。

**由此，引力塌缩与晶格破坏成为同一机制的两端。** 引力由质量驱动写入，写入使记录场变陡；质量越大写入越快，于是逼近满偏；到 $m = m_P$ 时满量程被占满，格点撑不住。**整个链条只有一个参数在推动。**

**这一条同时化解了第三节障碍一的数量级难题。** 那里的困难是「单格点要塞进约 $10^{19}$ 个质子才够 $m_P$」。若饱和的参数是质量而非粒子数，则「达到 $m_P$」不必堆积粒子，只需格点内的绑定能被推到满量程，即第六节的 $\kappa_\phi$ 强度饱和路线。**该路线由此从「一个待选建议」升为「方案的自然读法」。**

**一条推论**：单格点的质量上限即 $m_P$。该上限对现有粒子极宽松（质子约为 $10^{-19}m_P$），不构成对粒子物理的约束，但它是结构性的：体系里任何格点都装不下一个普朗克质量的粒子。

**一条可检验的方向**：既然质量是饱和驱动参数，饱和的难易应随质量单调变化。黑洞质量越大，中心区域写入越快，饱和应越早发生。这与「大质量天体更易形成黑洞」方向一致，且它给出的是饱和速率的标度，谈不上质量阈值。

## 六、建议路线：$\kappa_\phi$ 强度饱和

体系里粒子的质量是格点内的绑定能，由格点内异类耦合 $\kappa_\phi$ 承载。**第五节已把这条路确立为方案的自然读法。具体地，若单格点能容纳的能量上限本就由 $\kappa_\phi$ 定在普朗克标度，则"累积超过 $m_P$"不必塞进 $10^{19}$ 个粒子，只需问：格点内耦合被推到何种程度时它自己撑不住。**

这条读法把门槛从"数量累积"改成"强度饱和"，好处有三：与满偏标度（$m = m_P$）的关系更直接；不需要放宽"圆心不可重合"；与作者"单个晶格更自然"的倾向一致。

**代价是它把门槛的来源推给了 $\kappa_\phi$ 的上限，而 $\kappa_\phi$ 的绝对标度本身列在开放问题中**（三代质量谱的绝对标度，P1-2）。所以这条路线不是免费的，它把问题从一个地方挪到了另一个地方，但挪向的那个地方有既有攻坚线在推进。

## 七、剩余开放项

**其一，格点内绑定能如何随外部质量增长。** 经第五节，本条的问法已从「单格点能装多少」改为「绑定能如何随外部质量增长」：前者当时看着不可算，后者可算。判定方向是强度饱和（$\kappa_\phi$ 上限对应 $m_P$），需要 $\kappa_\phi$ 上限的独立导出。

**其二，净增长率的表述修正。** 引入吸收之后，物侧格点总数成为"创生减吸收"的净值。**体系"格点只增不减"的表述需精确化为"净增长恒为正"**：这两句话在宇宙尺度上等价，在黑洞局部则完全不同。是否需要正式修订既有表述，待作者裁决。

**其三（细节），B 与 C 的相位关系。** 交错真空里相邻反相，而 B 与 C 原本相隔两个格距、属同相；A 退出后它们成为邻居，相位关系需要重新落定。方向是相容的（重标之后做一次局部再锁定），但需要确认由什么执行，是能量最小化自动完成，还是需要校准介入。

**其四（细节），重标的瞬时性。** 体系里让位链的重标是瞬时的（纯标记，不耗时间）。若消失方向沿用，则"空间减少"也是瞬时的，与"创生边界不受光速限制"一致。需确认这一条在吸收方向同样成立。

**其五（附带），破坏区与视界的关系。** 视界是 $\theta = 1/2$ 的等值面，而破坏发生在中心。两者之间的过渡区是什么状态、由三候选中的哪一个接管，本方案未涉及。

## 八、诚实边界

其一，方案的全部环节均为纲领级，无任何建模与数值。

其二，方案与既有定案的接触点有三处需要过闸：单格点容量与"圆心不可重合"；破坏区的性质与晶格刚性原理（按第四节，若破坏只是失序加空间退出，则不冲突）；本原吸收与"格点只增不减"的创生单向性（按第六节第二条，需要表述修正）。

其三，第二节三处澄清与第四节的逆镶嵌机制为作者陈述，本注记如实记录；第三节障碍一的审查、第五节建议路线、第六节开放项为对话产出。

其四，**本注记留痕两处撤回**：对话中"元相海等于原初混沌"的论证作废（未写入任何文档）；本注记初版"格点数减少导致格距变大"的判断作废（见第四节第三条）。两处均在此备查。

其五，本注记不改动任何基准文件与既有判据，不构成对 P1-34a 三候选的裁决。
