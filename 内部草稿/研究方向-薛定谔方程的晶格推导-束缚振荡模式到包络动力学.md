## 一、问题的定位

薛定谔方程的标准形式

$$i\hbar\frac{\partial}{\partial t}\Psi(\mathbf{x},t) = \left(-\frac{\hbar^2}{2m}\nabla^2 + V(\mathbf{x})\right)\Psi(\mathbf{x},t)$$

由三个成分构成：时间演化生成元 $i\hbar\partial_t$、动能算符 $-\hbar^2\nabla^2/2m$、势能 $V(\mathbf{x})$。体系内三个成分的素材已分头存在：时间生成元由公理 3/4 的相位推进与[[元相方程]]方程 (I) 给出（单体）；动能需要"动量算符 + 质量"；势需要"局域调制 + 规范联络"。本稿的任务是把三者接到同一个格点动力学上：有质量模式（相位差模式 $\delta_1, \delta_2$）的晶格场方程，经旋转波分解与长波极限，自然涌现完整的薛定谔方程，其中有效质量与体系既有质量定义逐字恒等。

## 二、候选路径与自检

**方案 A（紧束缚包络，本稿主张）**：有质量模式是束缚振荡晶格上的格点场，其色散关系已由《色散关系》论文给出。色散谱对偶定义晶格场方程，旋转波分解把快速振荡本底抽出，剩余慢包络满足薛定谔方程。该路径的全部输入都是体系既有推导（公理 4 哈密顿、异类耦合、正交变换），质量从色散曲率直接涌现。采纳。

**方案 B（对易算子路线，平行校验）**：以 $[x,p] = i\hbar$ 锚定（《对易关系根基》，$\hbar$ 的几何本体已锚定，$S^1 \to \mathbb{R}$ 解卷待完成）为依据，假定 $p^2/2m$ 型哈密顿，得同一方程的算子形式。该路线依赖未闭合的解卷环节，作为一致性校验使用：两条路线给出同一哈密顿量（动能 $\hbar^2k^2/2m$），互相印证，方案 B 不独立承担推导。

**方案 C（场论约化）**：从[[从约当谐振子到元相子：场的模式量子化与实体几何的统一|从约当谐振子到元相子]]的场量子化管道约化出单粒子扇区，属远期（与 QFT 四通道挂钩），本稿不展开。

**方案 D（单体方程直接推广）**：方程 (I) 的直接推广无法凭空产生空间结构（$E_P\psi$ 无 $\nabla^2$），需要模式空间作为载体，其正确形态即方案 A 的连续极限。不独立。

自检结论：方案 A 是唯一自足的物侧推导路径，B 提供平行校验，C/D 标记范围。

## 三、格点模型与经典谱

束缚振荡晶格的有质量模式（相位差模式 $\delta_1, \delta_2$）由公理 4 的异类耦合二次化给出（《色散关系》§6）。谱为

$$\omega^2(\mathbf{k}) = \frac{4}{t_P^2}\sum_a\sin^2\frac{k_a l_P}{2} + 3\omega_P\kappa_\phi$$

能隙

$$\omega_0 = \sqrt{3\omega_P\kappa_\phi}$$

低能极限（$k_al_P \ll 1$，$\sin x \approx x$）：

$$\omega^2(\mathbf{k}) \approx \frac{l_P^2}{t_P^2}|\mathbf{k}|^2 + \omega_0^2 = c^2|\mathbf{k}|^2 + \omega_0^2$$

即相对论型色散 $\omega = \sqrt{\omega_0^2 + c^2|\mathbf{k}|^2}$，与群速度公式 $v_g = c^2k/\omega < c$（《色散关系》§6）一致。

谱对偶地定义格点场的经典运动方程。设 $\psi_n(t)$ 为格点 $n$ 处有质量模式的复振幅（连续极限 $\psi(\mathbf{x},t)$；其系综语义由[[序参量份额定理：Born规则、归一化与幺正性的系综推导|序参量份额定理]]给出：振幅 = 模式块的序参量分量），色散 $\omega^2(\mathbf{k})$ 对应晶格波动方程

$$\ddot\psi_n(t) = -\omega_0^2\,\psi_n(t) + c^2\,(\nabla^2_{\text{lat}}\psi)_n , \qquad (\nabla^2_{\text{lat}}\psi)_n = \sum_a \frac{\psi_{n+\hat a} - 2\psi_n + \psi_{n-\hat a}}{l_P^2}$$

这是 Klein-Gordon 型晶格方程：质量项 $-\omega_0^2\psi$ 来自异类耦合能隙，刚度项 $c^2\nabla^2_{\text{lat}}\psi$ 来自同类耦合（波动刚度）。全程只使用公理 4 的耦合结构，无新输入。

## 四、包络方程推导与有效的质量恒等式

做旋转波分解：把快速振荡本底 $e^{-i\omega_0 t}$ 抽出，定义慢包络

$$\psi_n(t) = e^{-i\omega_0 t}\,\Psi_n(t)$$

代人晶格方程：

$$\ddot\psi_n = e^{-i\omega_0 t}\big(-\omega_0^2\Psi_n - 2i\omega_0\dot\Psi_n + \ddot\Psi_n\big) = e^{-i\omega_0 t}\big(-\omega_0^2\Psi_n + c^2(\nabla^2_{\text{lat}}\Psi)_n\big)$$

两侧消去 $e^{-i\omega_0 t}$ 公因子，得

$$-2i\omega_0\dot\Psi_n + \ddot\Psi_n = c^2(\nabla^2_{\text{lat}}\Psi)_n$$

旋转波近似（包络缓变：$|\ddot\Psi_n| \ll 2\omega_0|\dot\Psi_n|$，等价于关注能量 $\ll \hbar\omega_0$ 的动力学）：

$$-2i\omega_0\,\dot\Psi_n \approx c^2(\nabla^2_{\text{lat}}\Psi)_n$$

整理并乘 $\hbar$：

$$i\hbar\,\dot\Psi_n = -\frac{\hbar c^2}{2\omega_0}(\nabla^2_{\text{lat}}\Psi)_n \;\xrightarrow{\;l_P \to 0\;}\; i\hbar\,\partial_t\Psi = -\frac{\hbar c^2}{2\omega_0}\,\nabla^2\Psi$$

动能系数中的组合 $\hbar c^2/2\omega_0$ 与体系既有质量定义逐字恒等：

$$\frac{\hbar c^2}{2\omega_0} = \frac{\hbar^2}{2(\hbar\omega_0/c^2)} = \frac{\hbar^2}{2m}, \qquad m = \frac{\hbar\omega_0}{c^2} \quad (\text{《色散关系》§6})$$

**有效质量恒等式**：包络方程的有效质量 $m^* = \hbar\omega_0/c^2$ 与体系既有的质量定义逐字相同。质量在此获得动力学含义：它由有质量模式色散的曲率（能隙与光速的比值）唯一定出，与"质量 = 拓扑缺陷绑定能"（能隙 $\sim\sqrt{\kappa_\phi}$）同义。于是得到自由粒子的薛定谔方程：

$$\boxed{\;i\hbar\,\partial_t\Psi(\mathbf{x},t) = -\frac{\hbar^2}{2m}\,\nabla^2\Psi(\mathbf{x},t)\;}$$

能量展开的一致性检查：把色散直接展开为能量，$E = \hbar\omega = \hbar\sqrt{\omega_0^2 + c^2k^2} \approx mc^2 + \hbar^2k^2/2m$（$m = \hbar\omega_0/c^2$）。静止能 $mc^2$ 由旋转波分解中的 $e^{-i\omega_0 t}$ 本底吸收，剩余动能 $\hbar^2k^2/2m$ 由包络方程给出。两条路径（色散展开、包络方程）给出同一能量，闭环成立。

## 五、势项与规范耦合

**势项**：把能隙局域化（缺陷、晶格形变、外场对 $\kappa_\phi$ 或 $\omega_P$ 的局域调制）：$\omega_0 \to \Omega(\mathbf{x}) = \omega_0 + \delta\omega(\mathbf{x})$。慢变近似（$|\nabla\Omega| \ll \omega_0/l_P$）下，模化项变为 $-\Omega^2(\mathbf{x})\psi$，旋转波分解后贡献对角项 $-2\omega_0\,\delta\omega(\mathbf{x})\,\Psi$（$\ddot\Psi$ 项同前忽略）。定义

$$V(\mathbf{x}) = \hbar\,\delta\omega(\mathbf{x})$$

得到含势薛定谔方程：

$$i\hbar\,\partial_t\Psi = \left(-\frac{\hbar^2}{2m}\nabla^2 + V(\mathbf{x})\right)\Psi$$

势的物理语义：$V = \hbar\delta\omega$ 即局域能隙扰动携带的能量，对应局域质量调制 $\delta m = V/c^2$。三类候选微源：局域缺陷（σ 锁定孤子构成的势阱，与[[有质量粒子的形成：大爆炸同步相变的局域缺陷方案|有质量粒子的形成]]衔接）、晶格形变（引力势，与保角因子/度规衔接）、能隙的环境性调制（其他场的背景）。三类微源的定量形式列为遗留。

**规范耦合**：电磁势经实轴方向场联络进入（U(1) 规范结构，实轴方向场论文），标准最小耦合 $p \to p - qA$ 在包络层对应把 $\nabla$ 换为协变导数 $\nabla - (iq/\hbar)A$。本稿把该项登记为衔接方向：薛定谔方程载体的空间结构与 U(1) 联络的耦合由定域化机制统一给出，定量推导见后续规范场论衔接稿。

## 六、概率流与归一化衔接

薛定谔方程的标准推论：从复共轭组合可得概率流守恒

$$\partial_t|\Psi|^2 + \nabla\cdot\mathbf{j} = 0, \qquad \mathbf{j} = \frac{\hbar}{2mi}\big(\Psi^*\nabla\Psi - \Psi\nabla\Psi^*\big)$$

体系内概率 $|\Psi|^2$ 的语义已由[[序参量份额定理：Born规则、归一化与幺正性的系综推导|序参量份额定理]]给出（模方 = 模式块系综份额，$|c_a|^2 = N_a/N$），演化保份额（幺正性，[[序参量份额定理：Born规则、归一化与幺正性的系综推导|序参量份额定理]]§4.6）。两者在此闭合：包络方程是份额守恒（幺正）演化的微分形式，概率流守恒是该守恒律的局域形态。快照抄写（采样、测量）语义直接可用：$|\Psi|^2$ 是采样密度，流 $\mathbf{j}$ 是份额的输运。

## 九、可检验方向

(1) 包络方程的相对论修正项（遗留 (a)）在极端条件下的可能信号：若在强场或普朗克邻近尺度探测到薛定谔方程的高阶偏离，其结构应表现为 Klein-Gordon 残差与晶格离散修正的组合，可区分于其他新物理；(2) 概率流与份额输运的一致性：$|\Psi|^2$ 的采样语义与概率流守恒在干涉实验中的体现与标准量子力学无差别（低能），体系预言的一致之处在于修正项的特定结构；(3) 势的微源判据：若缺陷势阱型的 $V$ 与形变型 $V$ 在特定材料类比（晶格缺陷物理）中表现为不同标度律，可作体系性检验（与凝聚态对应）。
