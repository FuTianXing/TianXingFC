## 一、战役弧线

恢复法线偏转的直接途径被接力困境封死：摆程路径、法线与圆心连线三位一体，几何层法线偏转使两个圆心错开，碰撞日历崩塌（五层冲突 3.2/3.3）。出路只有方向归波条款预留的位置：偏转作为波性侧连续场量，不反作用摆程。

## 三、最有分量的结果：史瓦西对齐

### 3.1 结果本身

归一化数值步 N5 判据：记录场在史瓦西半径处取值**精确等于 1/2**。按 $r_s = 2Gm/c^2$ 定义史瓦西半径，则

$$\theta(r_s) = \frac{Gm}{c^2 r_s} = \frac{Gm}{c^2 \cdot 2Gm/c^2} = \frac{1}{2}$$

等价地，在度规记录识别 $h_{00}/2 = \theta$ 下，

$$h_{00} = 2\theta = \frac{2Gm}{c^2 r} = \frac{r_s}{r}$$

这正是史瓦西解弱场形式 $g_{00} = -(1 - r_s/r)$ 的逐项内容。数值验证横跨**六十个数量级**：电子（$r_s = 1.35\times10^{-57}$ m）、质子（$2.48\times10^{-54}$ m）、地球（$8.87\times10^{-3}$ m）、太阳（$2.95\times10^{+3}$ m），四例 $\theta(r_s) = 0.500000000000$ 全中。同判据给出钟慢系数的定量形式：记录 $\theta = r_s/(2r)$ 恰为史瓦新钟慢 $d\tau/dt = \sqrt{1 - r_s/r} \approx 1 - r_s/(2r)$ 的一阶亏缺，法线场写入链（质量 → 写入 → 势阱 → 摆程计数减少 → 钟慢）的系数与广义相对论**零参数精确一致**。

### 3.2 为什么它有分量：三条理由

**理由一：两条完全独立的构造路线在此会合。** 史瓦西解来自广义相对论的场方程（1916），是物理学中经受检验最严格的精确解（水星近日点进动、光线偏折、夏皮罗延迟、引力红移皆由它导出）。法线场记录来自一条毫不相干的构造路线：元相子晶格 → 碰撞写入动力学（每拍注入 + 邻居抄写平均）→ 离散泊松格林函数 → 归一化经普朗克质量锁定。整条构造链中没有任何一步引用场方程、等效原理公设或史瓦西边界条件；与广义相对论的唯一接触点是 $G$ 的数值本身（经 $m_P = \sqrt{\hbar c/G}$ 进入）。两条路线的会合点不在弱场极限的"某个系数"上，而在**函数形式**上：$r_s/r$ 的整体形状及其绝对标度。

**理由二：零自由参数的绝对归一化。** 这是最关键的一点。设想记录场带一个归一化自由度 $\theta = \kappa\,Gm/(c^2 r)$：则 $h_{00} = 2\kappa\,Gm/(c^2 r)$，与史瓦西对齐要求 $\kappa = 1$。许多把引力写成介质或载体场方案的理论恰恰死在这里：载体场与度规之间的耦合常数是一个自由参数，只能靠拟合Post-Newtonian系数反推。法线场的归一化**没有这个旋钮**：$G$ 仅经 $m_P$ 进入一次（恒等式 $G/(c^2 l_P) = 1/m_P$，浮点精度 0.00e+00），写入幅度 $\delta\theta = m/m_P$ 的绝对标度被普朗克标度刚性锁定，$N_c = 2\pi/3$ 是 O(1) 几何计数而非可调参数。绝对归一化落地即命中史瓦西，等效于说：**记录场与度规扰动的同一无需任何 rescaling，它的绝对尺度就是度规扰动的绝对尺度**。在有效场论的语言里，这相当于耦合的重整化自由度被机制结构完全锁死，这在载体场类引力方案中罕见。

**理由三：六十个数量级的跨度排除量级巧合。** 单点命中（比如只在太阳质量处对齐）可能是巧合；对齐在电子到太阳的 60 个数量级上逐位成立，说明它是恒等式层面的结构（代数上确实如此：$\theta(r_s) = 1/2$ 对一切 $m$ 精确成立，浮点验证只是确认实现无误）。量级的巨大跨度同时给出体系自己的定量图景：电子在 1 米处的度规扰动 $h_{00} \approx 1.35\times10^{-57}$，"写入极小 = 引力极弱"从定性口号变成常数级的数字。

### 3.3 突破的实现机制：三道闸门挤死自由参数

对齐为什么"自动"发生？把构造链拆到最细，每一步的贡献是：环节一，写入幅度 $\delta\theta = m/m_P$ 的绝对标度（质量机制定案 + 普朗克质量角色：$m_P$ 为响应满量程、基态不写入、缺陷能差进分子），写入幅度从一开始就只有这一个标度可用；环节二，稳态形状的几何必然性，泊松格林函数 $1/r$ 是三维均匀格点上注入-扩散平衡的唯一稳态（如同库仑律由三维性唯一决定），$4\pi$ 自动涌现；环节三，归一化的代数强制，恒等式 $G/(c^2 l_P) = 1/m_P$ 纯属普朗克标度定义的代数内蕴（$l_P$ 与 $m_P$ 同出一组 $(\hbar, c, G)$，相除自动消去独立出现），它把记录场的幅度单位与度规扰动的幅度单位强制到同一把尺子上；环节四，因子 2 的代数继承：识别式 $h_{00}/2 = \theta$ 中的相对论因子随弱场度规约定免费进入，其系数另有两处独立来历（3+1 潮汐 $2:-1:-1$ 数值事实、牛顿潮汐张量结构）。没有任何一步是在"对齐史瓦西"的目标下调整过的：对齐是三个既有闭合（稳态唯一性、$G$ 单一入口、潮汐系数）的联合显影。

更深一层的追问：为什么这条链恰好塞不进自由参数 $\kappa$？载体场方案之所以总带一个 $\kappa$，是因为场与度规是两个独立对象，耦合常数描述两者的关系，而关系天生可调。法线场里两者是同一对象，三道闸门叠加：其一，同源无量纲化，源的尺度（缺陷绑定能）与响应的尺度（$m_P$）定义在同一组普朗克常数上，绑定能与时空刚度同根（$\kappa_\phi$/晶格结构），$m/m_P$ 的无量纲化是结构事实而约定；其二，形状的动力学唯一性，线性算子加唯一源，稳态无第二解；其三，度规识别的单点接触，记录场与度规的全部关系浓缩在 $h_{00}/2 = \theta$ 一个识别式内，无结构可调。三道闸门的联合效果：链上任何一处想藏一个 $\kappa$，都会破坏另一处已验证的闭合（$4\pi$ 涌现、潮汐 $2:-1:-1$、$G$ 单一入口三者必失其一）。**自由参数被既有验证网联合挤死。** 这正是突破的真正机制：这条链的过人之处在每一环都被独立判据锁住，联合起来就没有缝隙。

重大性可依两个判据确认。判据一（不可逆性）：可逆的突破是"又多了一个一致的验证"，不可逆的突破是"排除了一类可能性"。对齐锁死了归一化自由度，方案的证伪成本从"重新拟合"降到"直接死亡"，未来任何 PN 级失配都不能靠调参吸收，这是把自己逼到没有退路位置的结构性进展。判据二（超出设计意图）：设计目标止步于"稳态 = 牛顿势"（泊松对接），$r_s/r$ 的相对论因子与绝对标度不在任何一步的设计目标里，是恒等式与代数继承白送的。超出设计意图的精确一致（unintended exactness）在物理学史上一直是深层结构的信号（狄拉克方程之自旋、广义相对论之近日点进动皆属此类）。两判据皆过，"重大"的判断成立；其性质要说准：它属于"构造与最严格精确解之间不存在任何可调缝隙"式的突破，而非"证明了广义相对论"式的突破，价值在锁死（归一化不可再调）与暴露（下一步战场 = 度规识别的微观导出，P1-5）。

### 3.4 一个深层的暗示：记录饱和点与视界重合

$\theta(r_s) = 1/2$ 还有一个值得记录的暗示。记录场的"满偏"概念（$m = m_P$ 时每拍写入 1 弧度）在体系里早已确立；N5 显示，一个天体的记录场在其视界处达到半满（0.5），在更深处按弱场公式外推将超过 1。换言之，**记录场的饱和尺度与黑洞视界在位置上重合**：弱场线性构造（几何层零接触、倾斜不反作用摆程）恰好在自己的饱和点处失去效力，而那个点正是广义相对论里强场物理（视界、潮汐撕裂、时间冻结）开始的地方。这与已登记的"强场零接触边界"开放问题（强场下法线场记录与摆程的耦合可能重新打开）指向同一处：体系的强场补全应当从记录饱和机制入手，那里对应广义相对论的黑洞物理。此为纲领性暗示，未经验证，仅作方向登记。

### 3.5 它证明了什么、没证明什么（诚实边界）

证明了：在度规记录识别 $h_{00}/2 = \theta$ 的前提下，法线场记录的**绝对归一化零自由参数地命中史瓦西弱场形式**，且该对齐是恒等式层面的结构（60 个数量级、四个天体、钟慢系数全中）。这是对度规记录识别假设迄今最强的间接支持：识别若带任何 rescaling 自由度，对齐即被破坏。

没有证明：其一，度规记录识别本身（它仍是模型假设，其微观导出为张量桥 b 响应侧 / P1-5 承重墙，N5 是对该假设的强支持而非推导）；其二，史瓦西解的非线性部分（只对齐弱场形式 $r_s/r$，$r^{-2}$ 以上的强场修正不在构造射程内）；其三，场方程本身（P1-5 总判据：两侧同源的证明未闭合，"质量弯曲空间"仍是待证明的纲领）；其四，强场与视界物理（3.4 的饱和-视界重合为暗示）；其五，本突破为回溯性对齐（retrodictive）而非新预言，其经验价值在识别支持与可证伪性锁定，独立确认待体系预言清单被实验裁决。

**循环性核对**（突破强度的前提）：识别式 $h_{00}/2 = \theta$ 若在建立时已参照史瓦西形式，对齐即有循环之嫌。历史核对：该识别在 3+1 验证中以"记录二阶差分代理铰链亏损"的形式出现，其系数 $2:-1:-1$ 的对标对象是牛顿潮汐张量结构（源外无迹、横向压扁），当时无史瓦西对标；因子 2 来自 $h_{00} = 2\Phi/c^2$ 的标准弱场约定（教科书关系，非本体系为对齐而设）。链条无循环；但"识别假设 × 史瓦西对齐"的联合强度要在 P1-5（从写入动力学推导识别式）完成后才升满，届时对齐从"零参数命中"升级为"必然命中"。
