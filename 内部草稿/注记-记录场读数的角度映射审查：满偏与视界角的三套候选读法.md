## 一、问题

体系有一处长期表述：满偏标度为「$m = m_P$ 时每拍写入 1 弧度」。作者 2026-09-15 提出：这个「1 弧度」可能是单位计量的产物，**1 这个数本身无量纲，它对应多少度取决于映射约定**，而 90°、180°、360° 这类特殊角可能比 57.3° 更自然。

**该质疑成立。** \(\delta\theta = m/m_P\) 给出的是无量纲比值；令 $m = m_P$ 得 1，这一步与角度无关。「1 等于多少度」是第二件事，体系此前用线性小角近似直接读成了弧度，这一步没有独立论证。

## 二、映射约定的位置

记记录场读数 $\theta$（无量纲，0 到 1 为弱场到满偏），几何角度 $\alpha$。二者关系为一映射 $\alpha = f(\theta)$，满足 $f(0) = 0$、$f(1) = \alpha_{\text{满偏}}$。

**体系现行的读法是线性且以弧度为单位**，即 $f(\theta) = \theta$ rad。[[注记-法线场重读：标架场的法线方向场语义重读与裁决清单]]第一节载明「小角近似：倾角约等于高度差除以 $l_P$」，这一句是现行读法的出处，**它本身是小角近似的产物，不构成对满偏角的论证**。

**因此满偏角与视界角是两个待定的约定参数**，其取值由体系内部的几何自洽性决定，不能由观测裁决（满偏对应 $m = m_P$ 的假想粒子，不可观测）。

## 三、三套候选

三套均取线性映射（$\alpha = \alpha_{\text{满偏}}\cdot\theta$），差别只在满偏角取值。

| 候选 | 满偏（$\theta = 1$） | 视界（$\theta = 1/2$） |
|---|---|---|
| A | $180^\circ$ | $90^\circ$ |
| B | $90^\circ$ | $45^\circ$ |
| C | $360^\circ$ | $180^\circ = \pi$ |

## 四、七维审查

**维度一，能否锚定在体系已有的角度尺度上。** 体系里真正有独立地位的角度只有两个：$2\pi$ 是元相子的本征运动（一个完整摆程），$\pi$ 是交错真空的特征相位差（相邻反相）。**$\pi/2$ 在体系内没有独立地位。** 据此：C 的两个锚点都有出处（满偏 $2\pi$、视界 $\pi$）；A 有一个（满偏 $\pi$）；B 为零。

**维度二，与「缠绕」候选的衔接。** C 的满偏即整周，绕数 $+1$，饱和与回绕是同一件事；A 为半周，之后还需走半个周期才回绕，属部分衔接；B 的满偏与回绕之间隔着一整段翻转区，无衔接。

**维度三，饱和判据的自然性。** 饱和的通用条件是扰动涨到与背景同量级，而元相子的背景运动即每拍 $2\pi$。C 令满偏等于背景量级，是标准失稳判据；A 为半个背景、B 为四分之一，两者都需要额外说明为何不到背景量级就撑不住。

**维度四，视界的物理意义。** C 的视界落在 $\pi$，即「交错结构被扰动到极限」，视界位置等于体系最基本的结构常数；A 的视界是「躺平」这一几何姿态，与结构尺度无关；B 的视界无特殊意义。

**维度五，与非紧致裁定的相容性。** 三者都需要「读数回绕、层数仍无界」这一句交代，本维不区分；但 C 的回绕最自然。

**维度六，与「相邻反相」定案的相容性。** 只有 C 的视界落在 $\pi$ 上，与那条定案直接对应。

**维度七，内在自洽性。** 三者同取线性映射，自洽程度相同。

## 五、结论：A 为首选

**经作者 2026-09-15 补充的「功能失效」判据，首选由 C 改为 A。**

**核心判据（作者给出）**：满偏 $180^\circ$ 意味着取向自由度与法线方向彻底反向，**相当于驾驶员已经完全看不到火车头前方，功能失效，崩溃由此而来**。这一条直接否定 C：C 的满偏是整周，取向回到起点，**相当于驾驶员转一圈之后又能看见前方**，功能恢复，崩溃无从谈起。**该判据比先前所有论证都直接**，因为它问的是"这个状态还能不能工作"，而不是"这个数是否漂亮"。

**另两条支持 A 的论证。**

其一，**梯度单调**。视界是结构开始失效的临界点，满偏是破坏点，故从视界到满偏应当越来越极端。A 为 $90^\circ \to 180^\circ$（躺平 → 翻转），单调递进；C 为 $180^\circ \to 360^\circ$（已翻转 → 回到原状），**越往里越像原状**，方向相反。

其二，**与广义相对论同形**。GR 中视界内 $g_{00}$ 与 $g_{rr}$ 角色互换；A 的图像（视界处法线躺平作为方向交换的临界，视界内继续偏到翻转、交换完成）与它同形，C 无对应。

**C 的两条锚定需重新评估。** 满偏锚在 $2\pi$ 一条不专属 C：A 同样可以主张满偏处扰动已达背景量级，该条是量级判据而非结构判据。视界锚在 $\pi$ 一条是**类比而非推导**：$\pi$ 是真空相邻格点的相位差，而记录场的偏离量能否与该相位差直接比大小，体系未作交代。**故两条锚定的分量低于此前评估。**

**C 剩余的资产是绕数衔接**（满偏即整周、绕数 $+1$）。它现在的位置是"选 C 会得到什么"，而非"支持 C 的论证"；且选 C 等于同时押注缠绕终态。

| 标准 | A | C |
|---|---|---|
| 功能失效（崩溃判据） | **胜** | 负（满偏时功能恢复） |
| 梯度单调 | **胜** | 负 |
| 与 GR 角色互换同形 | **胜** | 无对应 |
| 破坏的字面意义 | **胜** | 需重定义 |
| 锚定固有尺度 | 中（满偏 $\pi$） | 中（一条不专属、一条是类比） |
| 与缠绕衔接 | 部分 | 精确（但等于押注缠绕） |

## 六、A 的两处承诺与一处代价

**承诺一：视界内为「交换完成」区。** A 中视界对应 $90^\circ$，满偏对应 $180^\circ$，故视界内是从躺平走向完全翻转的区间。**这意味着 A 天然把视界内读成「方向交换的完成过程」**，与 GR 中 $g_{00}$ 与 $g_{rr}$ 互换的图像同形。这是一处实质承诺，需作者确认。

**承诺二：视界的「躺平」发生在取向自由度上。** 按 [[注记-法线场重读：标架场的法线方向场语义重读与裁决清单]]第六条限定，倾角挂在法线上，**法线轴照样笔直，不触碰碰撞接力**。此条必须与 A 同时陈述，否则会被误读为「视界处法线掉头」。

**代价：线性化偏差的表述要重算。** A 下视界处的实际角度为 $90^\circ$，$\tan$ 在该处发散，故既有那句「$\tan\theta \approx \theta$ 偏差约一成」需重算。这并不削弱「弱场构造在视界处失效」的结论，反而强化它。

## 七、更靠前的前提：线性还是正弦

**三套候选都建立在「角度与 $\theta$ 成线性映射」这一共同前提上。** 若核实后发现几何关系为正弦（即 $\sin\alpha = \Delta h/l_P$，高度差为垂直分量、格距为斜边），则三套全部重排，该支给出满偏 $90^\circ$、视界 $30^\circ$。

**支持线性的理由**：记录量按「每拍写一份」累积，累积是加法，角度按加法走更自然；正弦关系要求「记录量即角度的正弦」，需额外机制说明。**支持正弦的理由**：若高度差是垂直分量、格距是斜边，则几何关系本就是正弦。

**该前提比 A/B/C 之争更靠前，应优先判定。** 判定方式为核实体系内「法线轴高度差」与「格距 $l_P$」的精确几何定义，不需建模。

## 八、诚实边界

其一，本注记全部内容为读法约定层面的审查，不涉及任何数值结论。**$\theta(r_s) = 1/2$、光子球处 $1/3$ 等无量纲比值在任何读法下不变**，N5 与史瓦西对齐不受影响。

其二，三套候选的取舍依据是体系内部自洽性，不是观测；满偏对应不可观测的假想粒子，该问题无法由实验裁决。

其三，C 为首选是**在当前信息下的判断**，若第七节的前提判定为「正弦」，结论要重排。
