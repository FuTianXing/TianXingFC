## 一、问题

体系有一处长期表述：满偏标度为「$m = m_P$ 时每拍写入 1 弧度」。作者 2026-09-15 提出：这个「1 弧度」可能是单位计量的产物，**1 这个数本身无量纲，它对应多少度取决于映射约定**，而 90°、180°、360° 这类特殊角可能比 57.3° 更自然。

**该质疑成立。** \(\delta\theta = m/m_P\) 给出的是无量纲比值；令 $m = m_P$ 得 1，这一步与角度无关。「1 等于多少度」是第二件事，体系此前用线性小角近似直接读成了弧度，这一步没有独立论证。

## 二、映射约定的位置

记记录场读数 $\theta$（无量纲，0 到 1 为弱场到满偏），几何角度 $\alpha$。二者关系为一映射 $\alpha = f(\theta)$，满足 $f(0) = 0$、$f(1) = \alpha_{\text{满偏}}$。

**体系现行的读法是线性且以弧度为单位**，即 $f(\theta) = \theta$ rad。[[注记-法线场重读：标架场的法线方向场语义重读与裁决清单]]第一节载明「小角近似：倾角约等于高度差除以 $l_P$」，这一句是现行读法的出处，**它本身是小角近似的产物，不构成对满偏角的论证**。

**因此满偏角与视界角是两个待定的约定参数**，其取值由体系内部的几何自洽性决定，不能由观测裁决（满偏对应 $m = m_P$ 的假想粒子，不可观测）。

## 三、三套候选

三套均取线性映射（$\alpha = \alpha_{\text{满偏}}\cdot\theta$），差别只在满偏角取值。

| 候选 | 满偏（$\theta = 1$） | 视界（$\theta = 1/2$） |
|---|---|---|
| A | $180^\circ$ | $90^\circ$ |
| B | $90^\circ$ | $45^\circ$ |
| C | $360^\circ$ | $180^\circ = \pi$ |

## 四、七维审查

**维度一，能否锚定在体系已有的角度尺度上。** 体系里真正有独立地位的角度只有两个：$2\pi$ 是元相子的本征运动（一个完整摆程），$\pi$ 是交错真空的特征相位差（相邻反相）。**$\pi/2$ 在体系内没有独立地位。** 据此：C 的两个锚点都有出处（满偏 $2\pi$、视界 $\pi$）；A 有一个（满偏 $\pi$）；B 为零。

**维度二，与「缠绕」候选的衔接。** C 的满偏即整周，绕数 $+1$，饱和与回绕是同一件事；A 为半周，之后还需走半个周期才回绕，属部分衔接；B 的满偏与回绕之间隔着一整段翻转区，无衔接。

**维度三，饱和判据的自然性。** 饱和的通用条件是扰动涨到与背景同量级，而元相子的背景运动即每拍 $2\pi$。C 令满偏等于背景量级，是标准失稳判据；A 为半个背景、B 为四分之一，两者都需要额外说明为何不到背景量级就撑不住。

**维度四，视界的物理意义。** C 的视界落在 $\pi$，即「交错结构被扰动到极限」，视界位置等于体系最基本的结构常数；A 的视界是「躺平」这一几何姿态，与结构尺度无关；B 的视界无特殊意义。

**维度五，与非紧致裁定的相容性。** 三者都需要「读数回绕、层数仍无界」这一句交代，本维不区分；但 C 的回绕最自然。

**维度六，与「相邻反相」定案的相容性。** 只有 C 的视界落在 $\pi$ 上，与那条定案直接对应。

**维度七，内在自洽性。** 三者同取线性映射，自洽程度相同。

## 五、结论：A 为首选

**经作者 2026-09-15 补充的「功能失效」判据，首选由 C 改为 A。**

**核心判据（作者给出）**：满偏 $180^\circ$ 意味着取向自由度与法线方向彻底反向，**相当于驾驶员已经完全看不到火车头前方，功能失效，崩溃由此而来**。这一条直接否定 C：C 的满偏是整周，取向回到起点，**相当于驾驶员转一圈之后又能看见前方**，功能恢复，崩溃无从谈起。**该判据比先前所有论证都直接**，因为它问的是"这个状态还能不能工作"，而不是"这个数是否漂亮"。

**另两条支持 A 的论证。**

其一，**梯度单调**。视界是结构开始失效的临界点，满偏是破坏点，故从视界到满偏应当越来越极端。A 为 $90^\circ \to 180^\circ$（躺平 → 翻转），单调递进；C 为 $180^\circ \to 360^\circ$（已翻转 → 回到原状），**越往里越像原状**，方向相反。

其二，**与广义相对论同形**。GR 中视界内 $g_{00}$ 与 $g_{rr}$ 角色互换；A 的图像（视界处法线躺平作为方向交换的临界，视界内继续偏到翻转、交换完成）与它同形，C 无对应。

**C 的两条锚定需重新评估。** 满偏锚在 $2\pi$ 一条不专属 C：A 同样可以主张满偏处扰动已达背景量级，该条是量级判据而非结构判据。视界锚在 $\pi$ 一条是**类比而非推导**：$\pi$ 是真空相邻格点的相位差，而记录场的偏离量能否与该相位差直接比大小，体系未作交代。**故两条锚定的分量低于此前评估。**

**C 剩余的资产是绕数衔接**（满偏即整周、绕数 $+1$）。它现在的位置是"选 C 会得到什么"，而非"支持 C 的论证"；且选 C 等于同时押注缠绕终态。

| 标准 | A | C |
|---|---|---|
| 功能失效（崩溃判据） | **胜** | 负（满偏时功能恢复） |
| 梯度单调 | **胜** | 负 |
| 与 GR 角色互换同形 | **胜** | 无对应 |
| 破坏的字面意义 | **胜** | 需重定义 |
| 锚定固有尺度 | 中（满偏 $\pi$） | 中（一条不专属、一条是类比） |
| 与缠绕衔接 | 部分 | 精确（但等于押注缠绕） |

## 六、A 的两处承诺与一处代价

**承诺一：视界内为「交换完成」区。** A 中视界对应 $90^\circ$，满偏对应 $180^\circ$，故视界内是从躺平走向完全翻转的区间。**这意味着 A 天然把视界内读成「方向交换的完成过程」**，与 GR 中 $g_{00}$ 与 $g_{rr}$ 互换的图像同形。这是一处实质承诺，需作者确认。

**承诺二：视界的「躺平」发生在取向自由度上。** 按 [[注记-法线场重读：标架场的法线方向场语义重读与裁决清单]]第六条限定，倾角挂在法线上，**法线轴照样笔直，不触碰碰撞接力**。此条必须与 A 同时陈述，否则会被误读为「视界处法线掉头」。

**代价：线性化偏差的表述要重算。** A 下视界处的实际角度为 $90^\circ$，$\tan$ 在该处发散，故既有那句「$\tan\theta \approx \theta$ 偏差约一成」需重算。这并不削弱「弱场构造在视界处失效」的结论，反而强化它。

## 七、映射关系的位置：它只影响视界角

**初版把「线性还是正弦」列为比 A/B/C 更靠前的前提，该判断需修正。**

**核实结果**：体系里键弹性的原始形式是「法线轴高度差（平方型，非紧致）」，cos 书写为「角度投影」（作者 2026-09-06 裁定，见 [[wiki/位错]]、[[wiki/螺旋阶梯几何]]）。**但两者在小角下等价（$1-\cos\theta \approx \theta^2/2$），故小角范围无法区分线性与正弦；大角（满偏处）的精确关系体系未给出。** 换言之，该前提在文档中**是空的**，「线性」只是小角近似的默认延伸。

**关键修正**：作者的功能失效判据**不依赖映射形式**。无论线性还是正弦，「取向完全反向」都是 $180^\circ$，故**满偏角由该判据直接给出，与映射无关**。映射形式只影响**视界角**：线性读法给 $90^\circ$，正弦读法给 $\arcsin(0.5) = 30^\circ$ 一类。

**因此本节的地位由「A/B/C 的前置条件」降为「只决定视界角的次级问题」**，A 的首选地位不依赖它。该缺口登记为新的开放项（见第九节）。

## 八、作者给出的完整几何图像（2026-09-15）

作者随后给出完整图像，映射形式随之确定。

**无质量时**，法线倾角与法线方向一致，这代表完全的平直时空。**有质量时**，法线倾角沿法线平行方向被向下压弯，与法线方向产生偏离；**这个向下压弯的角度与物质质量和普朗克质量的比值成正比，为线性关系**。

**由此两个关键位置获得机制身份**：压弯达 $90^\circ$（对应 $\theta = 1/2$）即视界；压弯达 $180^\circ$（对应 $\theta = 1$）即彻底反转，**时空晶格的结构被破坏，跃迁将无法完成，晶格无法正常运行**。

**该陈述同时闭合了第七节登记的前提**：映射形式为线性，即 $\alpha = 180^\circ \times \theta$。故 A 的满偏 $180^\circ$ 与视界 $90^\circ$ 均获得作者裁定的依据，**P1-36 由开放转为已裁定**。

**与既有定案的相容性**：压弯发生在「取向自由度」上（见 [[注记-法线场重读：标架场的法线方向场语义重读与裁决清单]]第六条限定），法线轴本身仍笔直，碰撞接力不受影响；压弯达 $180^\circ$ 时取向与法线方向反向，这正是「功能失效」判据所描述的状态，晶格因无法完成跃迁而崩溃。**两条判据（功能失效与几何压弯）在此汇合。**

## 九、可见性临界：视界的直观图像（2026-09-15）

作者给出一个几何直观：设观察者位于坐标轴右侧半区，法线倾角在 $0$ 到 $90^\circ$ 之间时（法线朝向观察者一侧），观察者仍能读到它；**一旦超过 $90^\circ$，法线转向背侧，右侧的观察者便读不到了，它被 Y 轴这道墙挡住**。

**这个图像给出的是视界的单向膜性质。** 越过 $90^\circ$ 后取向转向背侧，观察者读不到。**这与「光出不去」是同一件事的两种说法**：读不到，正因为没有信号能从那一侧传过来。它天然是单向的，观察者读不到内部，而内部朝外的方向仍然存在。

**与广义相对论同形**：GR 中视界内径向坐标时间化，「向外」这一方向本身消失；这里则是法线越过 $90^\circ$ 后，「朝向观察者」不再属于可达取向。两者都在说：**视界是取向越过某个临界之后某些方向不再存在，谈不上有厚度的墙。**

**两处必须写明的前提。**

其一，**可见性判的是取向，不是法线轴**。法线若读作无方向的轴，则 $90^\circ$ 与 $270^\circ$ 同轴，判据会失效。按 [[注记-法线场重读：标架场的法线方向场语义重读与裁决清单]]第六条限定，倾角正是挂在法线上的取向自由度，故该图像自洽；但须写明「Y 轴的墙」挡的是取向的朝向，谈不上法线轴本身被挡。

其二，**几何遮挡与信号阻断不是同一件事**。图像中「读不到」表现为几何遮挡，而物理上读不到的原因是接力几何断裂（信号无法传出）。**两者要对应，需要一个前提：法线取向的朝向就是信息传递的方向。** 该前提在体系内有依据（接力沿法线逐格推进），但同样需要显式说出。

**一处附带的收益**：该图像让「视界内外晶格同样运转」这句既有表述变得可理解，**晶格照常运转，变的是「哪个方向还通」**。这也是它比「晶格被破坏」更保守、代价更小的原因。

## 十、广义相对论中的对应理解（$1/2$ 与光锥）

体系那个「压弯 $90^\circ$」的图像在广义相对论里有对应物，本节给出公式层面的对照。

**$1/2$ 在 GR 里的位置。** 史瓦西度规（$r_s = 2GM/c^2$）

$$ds^2 = -\left(1-\frac{r_s}{r}\right)c^2dt^2 + \left(1-\frac{r_s}{r}\right)^{-1}dr^2 + r^2\,d\Omega^2$$

弱场展开写作 $g_{00} = -(1-h_{00})$、$h_{00} = 2\Phi/c^2$、$\Phi = -GM/r$。代入 $r = r_s$ 得 $|\Phi|/c^2 = 1/2$，等价于 $h_{00} = 1$ 与 $g_{00} = 0$。**GR 里没有机制去「制造」这个 $1/2$，它是 $r_s$ 定义式中系数 2 的副产品。**

**为什么 $g_{00} = 0$ 意味着光出不来。** 取径向类光测地线（$ds^2 = 0$、$d\Omega = 0$），得坐标光速

$$\frac{dr}{dt} = \pm c\left(1-\frac{r_s}{r}\right).$$

$r \gg r_s$ 时给 $\pm c$（45° 光锥）；$r \to r_s$ 时归零（光锥外边缘变竖直）；$r < r_s$ 时**连 $+$ 号那一支也指向 $r$ 减小方向**。**所以本质是：视界以内，未来指向的类光测地线全部指向内。** 谈不上「光被挡住」，而是「向外」这一支光锥不存在。

**去掉坐标奇点后更清楚。** 用 Eddington-Finkelstein 坐标（$v = ct + r_*$，$r_* = r + r_s\ln|r/r_s - 1|$），度规为

$$ds^2 = -\left(1-\frac{r_s}{r}\right)dv^2 + 2\,dv\,dr + r^2\,d\Omega^2,$$

向外光的坐标速度 $dr/dv = \frac{1}{2}(1 - r_s/r)$，在 $r = r_s$ 处为零、$r < r_s$ 处为负。**光锥倾斜是连续变化的，视界不是任何东西的奇点。**

**本质的一句话表述**：$\xi = \partial_t$ 为静态 Killing 矢量，$\xi\cdot\xi = g_{00}$，在 $r = r_s$ 处其模长为零，即 **$\xi$ 变成类光矢量**（故视界亦称 Killing 视界）。**物理含义是 $t$ 方向在视界处不再是类时方向**；静止要求世界线沿 $\xi$，而类光世界线只能由无质量粒子走，故静止于视界需无限加速度。

**对照**：

| 广义相对论 | 体系 |
|---|---|
| $g_{00} = 0$ | 法线压弯 $90^\circ$ |
| $h_{00} = 1$ | 取向与法线方向成直角 |
| 向外光锥分支消失 | 取向转过 $90^\circ$ 后转向背侧、观察者读不到 |
| Killing 矢量类光 | 「向外」不再是可达取向 |

**两边说的是同一个几何事实**：某个方向在临界角之后不再存在。GR 从度规分量的符号翻转看出它，体系从取向越过直角看出它。

**一处提醒**：$1/2$ 这个数本身不承载物理，它随弱场约定而变（若把 $h_{00}$ 写成 $k\Phi/c^2$，视界处读数就是 $1/k$）。**承载物理的是 $g_{00}$ 的零点**，$1/2$ 只是它在弱场坐标系里的投影。这与第五节结论一致：数字是约定的，几何位置才是物理的。
