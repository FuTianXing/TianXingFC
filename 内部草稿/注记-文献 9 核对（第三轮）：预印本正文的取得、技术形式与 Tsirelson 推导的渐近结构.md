## 二、核对项五条

**其一，原则陈述（正文）**。原文：Bob 能获得的关于 Alice 的、此前未知数据集的信息，"by using all his local resources and m classical bits communicated by Alice, is at most m bits"；并注明 "For m = 0, Information Causality reduces to the standard no-signaling principle"。第一轮的核到结论维持。

**其二，技术形式（补充材料第 III 节）**。原理的原式写作 $I(\vec a : \vec x, B) \le m$，其中 $\vec a$ 为 Alice 的数据比特串、$\vec x$ 为她的经典消息、$B$ 为预共享无信号资源的 Bob 侧。本文两篇论文所用的和式 $\sum_k I(a_k : G_k) \le m$ 属下形式：由式 (11) $I(\vec a : \vec x, B) \ge \sum_K I(a_K : \beta \vert b = K)$ 推出。故和式上界属推论层，与原理原式同源而异形。

**其三，证明链条与适用条件（第 III 节余部）**。上界由三条抽象性质加两条前提证出。三条性质为一致性（经典子系统上退化为 Shannon 互信息）、数据处理不等式（对一侧作允许的局域变换不增互信息）、链式法则（存在条件互信息使 $I(A : B, C) = I(A : C) + I(A : B \vert C)$）；两条前提为无信号（数据与预共享侧独立，$I(\vec a : B) = 0$）与消息为 $m$ 比特经典（$H(\vec x) \le m$）。证明骨架一段写成：$I(\vec a : \vec x, B) = I(\vec a : \vec x \vert B) = I(\vec x : \vec a, B) - I(\vec x : B) \le I(\vec x : \vec a, B) \le I(\vec x : \vec x) = H(\vec x) \le m$。

**其四，量子侧验证（第 V 节）**。三条性质在量子侧逐条核过：互信息取 von Neumann 互信息，一致性与 Shannon 一致，链式法则为恒等式，数据处理不等式即量子数据处理不等式，非负性由强次可加性给出；推导中 Alice 的数据作为参考系寄存器进入，预共享态 $\rho_{AB}$ 与数据独立。故信息因果性在经典与量子理论里是定理，其条件是信息测度的三条性质。

**其五，Tsirelson 界的推导形式（第 VI 节）**。推导取含参数 $n$ 的族形式：Alice 通信 $m = 1$ 比特、数据为 $N = 2^n$ 比特、两侧共享 $N - 1$ 个无信号盒、递归协议；Bob 的正确率 $P_K = \frac{1}{2}\left[1 + E_{\text{I}}^{n-k} E_{\text{II}}^{k}\right]$，和式下界 $I \ge \frac{1}{2\ln 2}\left(E_{\text{I}}^2 + E_{\text{II}}^2\right)^n$；判定为若 $E_{\text{I}}^2 + E_{\text{II}}^2 > 1$，则存在 $n$ 使 $I > 1$，即违反上界。各向同性族处 $E_{\text{I}} = E_{\text{II}} = E$、$P_K = \frac{1}{2}\left[1 + E^n\right]$。所以答案是渐近族判定，单副本对应不存在。同一节末尾另有一句：不违反信息因果性的 $(E_{\text{I}}, E_{\text{II}})$ 都有量子协议达到，界可由量子侧取满。
