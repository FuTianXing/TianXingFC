## 一、问题的分解

碰撞写入公设 P3 的幅值句（微观根基 §2.1）：

$$\delta\theta = \frac{m}{m_P}$$

把"法线场倾角为什么是这个比值"分解为三个子问题。(a) 为什么与质量成正比（线性）；(b) 为什么分母恰为普朗克质量（标度来源）；(c) 为什么写入幅度就是这个比值本身（机制等同，即倾角与质量的换算为何恰是"除以 $m_P$"这一个动作）。

四条通道分工：通道一（量纲与线性）答 (a)；通道二（作用量转录）与通道三（承载极限）各给出 (b)(c) 的正面机制；通道四（归一化链）以弱场匹配反向核对全部。通道二、三相互独立，通道四是既有论文的现状。

贯穿四通道的主命题：倾角是质量与普朗克质量之比，而这一比值由格点几何结构决定。几何给出量纲标度（通道一）、每拍作用量量子（通道二）、承载上限与满偏点（通道三），三条路径的出发点都是格点的几何结构而非动力学约定。承载极限通道是其中最直接的相关问题，几何结构是共同根源。

## 二、通道一：量纲唯一性与线性（答 a）

$\delta\theta$ 无量纲（微观根基 §2.3 量纲自洽清单：全链唯一带量纲的量是 $l_P$ 与 $t_P$，不进入静态幅值）。若写入幅度只依赖质量与体系标度（$\hbar$、$c$、$G$ 经普朗克定义式），唯一可构造的无量纲组合是 $m/m_P$，故 $\delta\theta = f(m/m_P)$。

线性 $f(x) = x$ 的支持有二：写入叠加性（多粒子记录为各自格林函数的线性叠加，稳态方程本身线性）与读数端线性映射裁决（$\alpha = 180^\circ\times\theta$，2026-09-15）。归一化斜率不由本通道定，交给通道二、三、四。

判据状态：量纲论证为结构性（可靠）；线性为裁决加结构支持（强）；具体斜率待其余通道。

## 三、通道二：作用量转录（答 b、c 的正面机制）

缺陷的绑定能为 $mc^2$，一拍 $t_P$ 内的作用量积累为 $mc^2 t_P$，相对作用量量子 $\hbar$ 的份额为

$$\delta\theta = \frac{mc^2 t_P}{\hbar} = \frac{m}{m_P}$$

末步用恒等式 $c^2 t_P/\hbar = 1/m_P$（$t_P$ 定义 $\sqrt{\hbar G/c^5}$ 的重排，零自由参数）。机制图像：碰撞写入把缺陷当拍的作用量状态转录到波性侧记录，写入幅度即每拍作用量份额；质量越大每拍积累越多，写下的倾角越大。$m = m_P$ 时每拍份额为 1，写入读数 $\theta = 1$（满偏）。

**口径声明**：本通道使用作用量份额语言，不使用角度计量；"每拍 1 弧度"旧读法已按 2026-09-15 裁决退役（$\theta$ 无量纲，几何角值取决于映射约定）。

判据状态：恒等式为零自由参数代数（可靠）；"写入即作用量转录"的机制句为候选（待判据化），接口接质量机制（绑定能）与摆程作用量归一化（$\epsilon = 1$，量纲桥 MB 线）。

## 四、通道三：承载极限（作者 2026-09-27 结构，答 b、c）

**作者结构的完整表述**：前提一，每个普朗克格点（由三个正交元相子构成）有确定的承载能力上限；前提二，这个上限由格点本身的几何结构决定，不能任意设定；结论，承载能力上限恰好是普朗克质量 $m_P$；推论，质量为 $m$ 的粒子写入的倾斜幅度 $\delta\theta = m/m_P$，等于该质量占格点最大承载能力的比例。若这个结构成立，$\delta\theta = m/m_P$ 就不再是假设，而是从格点几何结构的承载极限导出的必然结果。

**几何结构的内容（前提二的具体化）**：格点由三个正交元相子构成，承载写入的是其取向自由度：圆周结构、角程有限，写入把取向从直位压弯。角程与节律由公理给定（满周跃迁、普朗克拍），体系内没有可调参数；满偏点（$180^\circ$，取向与法线彻底反向）由圆周几何唯一标出。"不能任意设定"的确切含义在此：满偏条件与格距 $l_P$ 一起把临界质量钉死为 $m_P$，全程无第二个可调量（见下方恒等式）。

**命题 A（满偏即退出承载）**：取向自由度压到 $180^\circ$ 时跃迁无法完成，格点退出承载。定性支持两处：2026-09-15 角度映射裁决（$180^\circ$ 即彻底反转与晶格破坏）；黑洞线"引力塌缩与晶格破坏是同一机制的两端"链条与术语表第十二节（支撑失效、格点退出）。临界质量由满偏半径触及格距给出：

$$\frac{Gm_c}{c^2} = l_P \quad\Longrightarrow\quad m_c = \frac{c^2 l_P}{G} = m_P$$

**命题 B（载荷等同写入）**：写入幅度与最近邻格点载荷读数 $\theta(l_P)$ 的等同，由写事件分配规则（判据 L1 至 L5：六链接各承 $1/6$，数值读数最大相对差 $0.00\times10^{0}$）与离散格林函数结构给出，待显式判据化。

**写入时刻约束与位移完成条件（作者 2026-09-27 补充，命题 A 的机制候选）**：写入只能发生在碰撞时刻，不能中途。原因在几何：只有在碰撞时刻（满周完成、几何中心回到法线轴上的时刻）产生的倾斜，才能避免元相子的几何中心点脱离法线轴；中途写入的倾斜叠加在螺旋中途，中心偏轴。这为 P3 的每拍写入节律给出几何必然性候选。

位移完成条件：倾斜角达到阈值时，法线轴上的位移（跃迁 $l_P$）无法完成，格点退出承载。阈值取 $90^\circ$ 还是 $180^\circ$ 暂不确定：若 $90^\circ$，位移失效对应视界（$\theta = 1/2$，读数失效的机制来源）；若 $180^\circ$，对应满偏（$\theta = 1$，承载退出与晶格破坏）。两个候选恰与"视界、满偏分居两层"的既有结构对应，阈值取值由体系内部几何自洽性决定（与 2026-09-16 满偏与视界角待定口径衔接），登记为待裁决点。

推论：满偏点 $r = Gm/c^2 = r_s/2$；视界 $\theta = 1/2$ 与满偏 $\theta = 1$ 分居两层；$m < m_P$ 满偏点在首格胞内部被紫外截断吸收，$m > m_P$ 满偏点越过最近邻格点、承载失效（黑洞线）。

## 五、通道四：归一化链的反向核对（现状，答全部的核对侧）

微观根基 §2.3 的既有链：PN 匹配 $\theta = Gm/(c^2 r)$ 联立格林函数反推 $s_{eff} = 4\pi m/m_P$，回到 $\delta\theta = m/m_P$。方向与前三条相反：前三条正向导出，本条以弱场匹配为输入反向核对。史瓦西对齐（电子到太阳六十个数量级四例 $\theta(r_s) = 1/2$ 全中）是该通道的外部一致性检验。

地位：在通道二、三判据化之前，本通道是 $\delta\theta = m/m_P$ 的主要支撑（数值验证齐备）；判据化之后，它降为输出核对。

## 六、方向反转与四通道合成

若通道二或通道三的机制句判据化成立，链条反转：通道给出 $m_P$ 的承载或转录地位与 $\delta\theta$ 的形式，几何计数（$4\pi$、$N_c$）给出 $s_{eff}$，稳态格林函数给出 $\theta(r) = Gm/(c^2 r)$，PN 匹配与史瓦西对齐从输入降为输出。$G$ 的单一入口保持：各恒等式（$c^2 t_P/\hbar = 1/m_P$、$c^2 l_P/G = m_P$、$l_P/m_P = G/c^2$）属同一恒等式网络（$l_P = c\,t_P$ 连通），量纲自洽清单不变。

四通道交汇于同一个数，这种交汇形态本身构成"倾角比值属体系几何决定、非任意设定"的证据结构。
