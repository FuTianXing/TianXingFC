## 一、背景：上一轮在一个格点上问过什么

碰撞"写入"时，物质从格点搬进记录器。上一轮（第 726 号）在**一个格点**上把这事测清了：搬一次之后，格点上留下的东西会**来回晃**（每个 2 个时间单位倒一次），长期平均比什么都不写时低一半，即长期平均增量 $\bar{\Delta} = -0.50000000$（MS-1d 与 MS-1e 逐位复现第 726 号，最大相对偏差 $1.785\times10^{-13}$）。

这轮问的是：**位错是一条线**，线上有好多格点。线越长，是不是"负得更多"？

## 二、为什么这不是显然的

直觉上，一根线扫过八个格点，八个格点各被写一次，负的量该是单格点的八倍。

**结果不是。** 原因在于写入这动作有"节拍"：指针转到特定角度时才写，而且一写就是**把材料整个搬走**，不是搬一点。所以单格点上是一次全搬空，**八个格点各自也是一次全搬空**（只要它们各自都完成了自己那一拍）。

于是负的量按格点数累加的是"每格各负 $-0.5$"（MS-3 四档 $N_{\rm site}=2,4,8,16$ 皆 $-0.5000000000$，最大相对偏差 $0.000\times10^{0}$），而**单位长度的负量**由"每格摊到多长的线上"决定。这两件事是不同的量。

## 三、这条结论有多硬：三层核验

要害是"逐站点独立演化"这件事必须是**精确**的，不能是近似。三层核验如下。

**算符层**：把多个格点合成一个大矩阵算，指数可以按张量积精确拆开。$N_{\rm site}=2,3,4$ 的偏差分别为 $1.110\times10^{-15}$、$1.110\times10^{-15}$、$1.665\times10^{-15}$。

**大档**：格点数加到十六，矩阵建不起来了（$4^{16}$ 维，稠密矩阵要 $4.3\times10^{9}$ 维）。但只要各格点的算符**两两对易**，分解就仍然精确。$N_{\rm site}=8$ 与 $16$ 的对易性核给出**机器零**（$0.000\times10^{0}$）。

**态层**：直接造两个格点的联合态来演化，逐格读数与分开算**逐位一致**（相对偏差 $5.162\times10^{-14}$ 与 $5.365\times10^{-14}$），**连两格写入时刻不同的情况也一致**（MS-2b 偏差 $7.905\times10^{-14}$）。

**通俗讲法**：像两台互不干扰的机器，每台各自算，加起来等于一起算；而且格点再多也不差，因为机器之间根本不通话。

另外，含**实际空间剖面**（各格点系数不同）的算符层分解在 $N=2,3$ 给出 $1.554\times10^{-15}$，说明上面这条不依赖于"所有格点一样"这个简化。

## 四、真正变的是什么

长期平均**一点没变**，但**同一时刻各格点之间**的差别很大。

让八个格点错开写入时刻（沿位错线均匀相位梯度，$N_{\rm site}=8$）：

| 相位梯度 $\Delta A$（rad） | 站点 0 至站点 7 的布居 | 站点间极差 |
|---|---|---|
| $0$ | 全 $0.500000$ | $0.000000$ |
| $0.05$ | $0.500000 \to 0.749488$ | $0.249488$ |
| $0.10$ | $0.500000 \to 0.902983$ | $0.402983$ |
| $0.20$ | $0.500000 \to 0.983898$ | $0.483898$ |

**通俗讲法**：总量不变，但分布变了。这正是位错作为「线」与作为「点」的区别所在：线上的各点不是同时被写的。

方向也有机制解释：站点 $j$ 的过闸时刻是 $t_j = 0.5 + A_j/(2\pi)$，$A_j$ 越大过闸越晚，所以在 $t=0.5$ 这一时刻，$A_j$ 大的站点累积角更小、保留的材料更多。

## 五、一个恰好是 0.5 的读数不是巧合

异相档里站点 1 的布居恰为 $0.500000000000$，我要求队友核这是否为构造的巧合。**结论：不是巧合，是机制。**

指针剖面关于过闸时刻左右对称（$f(\theta_p(t))$ 在 $t \mapsto 1-t$ 下不变），故半个周期攒下的累积角恰为 $\pi/4$，而站点侧布居 $=\cos^2 A$，得 $\cos^2(\pi/4) = 0.5$。

**通俗讲法**：走到一半时，"已经搬走的比例"和"还留着的比例"恰好各半。

## 六、一条判据写错了（如实说）

有一条判据（MS-4b）原想测"格点错开写入时刻后，总搬运量会不会变"。**实测是不变**，偏离量在 $10^{-14}$ 量级（浮点噪声）。

**这是判据的期望写错，不是物理判否。** 原因是一条解析恒等式。

站点系内的指针剖面在 $s$ 上严格周期为 $1$，记 $F(s) = g_{\rm full}\int_0^s f̃$，则

$$F(s+1) = F(s) + \frac{g_{\rm full}}{\omega_P}\,\text{area} = F(s) + \frac{\pi}{2},$$

末步用 $g_{\rm full} = (\pi/2)\omega_P/\text{area}$。偏移 $A_j$ 对应 $\delta_j = A_j/(2\pi)$，累积角为 $A_j(t) = F(t-\delta_j) + F(\delta_j)$。因 $\cos^2 A_j$ 在 $t$ 上周期为 $2$，一个读数周期上的积分给出

$$\int_0^2 \cos^2 A_j\,dt = \int_0^1\big[\cos^2 x + \cos^2(x + \pi/2)\big]\,dv = 1,$$

**与 $\delta_j$ 无关**。故 $\langle\cos^2 A_j\rangle = 1/2$ 对任意偏移成立。

数值核验：五档偏移（$A = 0$、$0.05$、$0.20$、$0.80$、$1.5708$）的单周期积分皆为 $1.000000000000$，与 $1$ 的偏差最大 $1.332\times10^{-15}$。

**通俗讲法**：一个周期里的前半段和后半段恰好互补，加起来是定值，起点挪到哪里都不影响这个和。

**一条协议条件**：这条不变性要求积分窗取读数周期 $2$ 的整数倍。$T = 8.0$ 给 $0.5000000000$，$T = 7.0$ 给 $0.5044176691$，$T = 6.5$ 给 $0.5354391927$。本轮全部长期平均档都满足整周期条件。

## 七、这轮对案乙的意义

案乙要把写入过程与位错的能量分栏放进同一个装置，里头有一项「每单位长度的净负量」：

$$\varepsilon_{\rm wr}^{\rm net} = \nu\,\bar{\Delta}\,(E_a - E_c),$$

其中 $\nu$ 是每单位长度的写入站点数，$\bar{\Delta}$ 取第 726 号给的单站点长期平均增量，$E_a$ 与 $E_c$ 是站点侧与记录侧每激发的能量刻度。

**本轮证明那个 $\bar{\Delta}$ 对多站点扩展不变**，所以 $\bar{\Delta} = -0.5$ **可以直接用，不必按站点数重新标定**。这是案乙开工前的一个前提守恒项，现已核验成立。

换句话说，案乙的负线项**完全由几何量 $\nu$ 与两个能量刻度之差决定**，写入的动力学细节（多站点、错开时刻）不进入系数。

## 八、方法论收获

**一、判据的期望也会预设物理。** MS-4b 写的是"各档 $\bar{\Delta}$ 应与同相档不同"，这**预设了**"相位梯度改变长期平均沉积量"。本轮证明该预设在装置内不成立。**教训**：写判据时要说清期望背后的机制假设，机制若被证伪，判据要跟着改判语，而不能把判否读成物理。

**二、"看起来不可建"的大矩阵有替代核。** $4^{16}$ 维稠密矩阵不可建，但"各格点算符两两对易"这一**结构性事实**本身就是核（机器零），且对任意大格点数成立。**教训**：算不动的时候先找结构性证据，不必硬算。

**三、恒真的口径要当场认。** 队友把 MS-5 原写的"布居为 1 的站点数"从判据里拆了出来：写入选中剖面无紧支撑（$f(\pi) = 0.0183$ 非零），布居从 1 连续下降，该口径下答案恒为 0，属恒真无信息。改以有效窗口径（$f < 1/2$，承第 726 号 DS-2 口径）报出未被有效写入的站点数，得 4（共 8 站）。**教训**：发现判据恒真时，先改判据口径还是先读数，顺序不能反。

**四、相对偏差的分母要取绝对值。** 队友自曝一处：MS-3 首版把基准量取成正数 $0.5$ 而 $\bar{\Delta}$ 是负数，四档全为 $-0.5$ 时偏差被算成 $2.0$ 而误判否。**教训**：基准量为负时这两种写法差一个符号号。
