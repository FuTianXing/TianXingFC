## 一、问题与已锁定的约束

要回答的问题是：锁定刚度 $\kappa$ 从哪里来。它是场层把局域涨落拉回共同相位的强度，在既有各轮里一直作为输入参数出现；把它换成导出量，就是「先验纠缠锁定帧」这句话的机制化，也是 P4-16 的第一步（把无穷张量积的整体态经同步相变投射为可观测量的锁定结构）。

已锁定的约束有五条。其一，门槛约束：$\kappa$ 必须使系统落在同步门槛以上，否则锁定坐标不存在（第 190 条实测门槛以上 $r = 0.771$ 至 $0.858$、门槛以下 $0.059$ 至 $0.107$）。其二，闭式约束：$\kappa$ 只以 $\alpha = 1-\kappa$ 进入场层闭式 $C(r) = a q^r + b \alpha^r$，任何候选值必须落回该闭式（第 181、182 条）。其三，保护约束：锁定模的改写需非定域操作，保护距离 $d = L$（第 184 条），故 $\kappa$ 不得随局域扰动改变。其四，规模约束：共享分量方差 $P = S(0)/Z + \sigma^2/(\kappa N)$ 为 $O(1/规模)$（第 189、190 条），$\kappa$ 的标度须与平台高度随规模稀释相容。其五，参数经济：不引入新的可调常数；若必须引入，须给出其体系内来源。

## 二、三条候选路线

**路线甲（同步相变投射）。** 把 $\kappa$ 作为同步相变的序参量刚度导出：由整体态的耦合强度与自然频率分布宽度给出 $\kappa$ 的形式，门槛 $K_c$ 作为判据的一部分。代价是先要把整体态投射成有效耦合，工作量大。

**路线乙（稳定子层的胶合，推荐为主）。** 把 $\kappa$ 从 toric code 稳定子层的谱隙导出：锁定刚度由码空间能隙与规模共同定住，保护距离 $L$ 自动进入。好处是直接接第 184 条的资产（独立生成元 $126$、编码比特 $2$、保护距离 $8$），量级与标度都可用既有脚本核算。

**路线丙（键能曲率，推荐为对照）。** 把 $\kappa$ 定义为棱差（实轴方向差）键能在锁定点的二阶曲率，接第 178 条的键能与界面读数。好处是接既有键能线，代价是键能函数本身还需给出。

推荐以乙为主、丙为对照、甲为升级：乙能最快给出可核对的形式，丙提供独立通道，甲是 P4-16 的正式目标、待前两者给出资产后再上。
