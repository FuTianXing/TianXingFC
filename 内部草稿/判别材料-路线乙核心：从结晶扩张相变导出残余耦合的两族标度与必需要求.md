## 一、问题与约定

目标：给 $\kappa_\phi$ 的取值一个来源，即给出 $\kappa_\phi = F(\text{相变参数})$ 且 $F$ 以 O(1) 输入复现登记小量。登记小量取质量论文口径 $\varepsilon := \kappa_\phi/\omega_P^2 = 4.437\times10^{-47}$；与字典的换算链为 $K/J = 4\pi^2\varepsilon = 1.7518\times10^{-45}$、登记组合 $(2\pi/3)\varepsilon = 9.2936\times10^{-47}$（即「$\kappa_\phi t_P$」条目），两式本次逐位核过。

「导出」的操作定义：$F$ 的具体形式即一条标度假设；标度假设要可判定，需列出它要求的相变参数取值，并与在册相变图景（P8a）对照。

相变图景按两段处理。生产段：Kibble 因果论证给缺陷密度 $\sim 1/(ct_*)^3$、接缝必然（P8a 修订保留该框架）。愈合段：磨合期规则化，残余份额无定量（三阶段注记有叙述、无公式）。

## 三、读数与判定

其一，幂律族的相变时标要求：$p = 3$ 把相变放在 $1.5\times10^{-28}$ 秒，$p = 4$ 放在 $2.1\times10^{-32}$ 秒，$p = 6$ 放在 $2.9\times10^{-36}$ 秒（GUT 档）。把相变放在近普朗克档（$\xi \le 10\,l_P$）需 $p = 46.35$，$100\,l_P$ 需 $p = 23.18$，指数不合理。

其二，指数族的自然读法：$\lambda \approx 107$ 与「相变在约 100 个普朗克时标内完成、每步 O(1) 抑制」同量级。这条与幂律族在近普朗克档的失败互补：**若相变时标是普朗克档，指数族是唯一可行的族**。

其三，朴素占用率假说排除。接缝薄层体积占比约 $3\,l_P/\xi$，缺陷格点占比为 $f_{\rm KZ} = (l_P/\xi)^3$。对任何 $\xi \le 10^8\,l_P$（覆盖 GUT 之前全部档），前者不小于 $3\times10^{-8}$、后者不小于 $10^{-24}$，与 $\varepsilon = 4.4\times10^{-47}$ 相差至少 23 至 39 个数量级。故 $\varepsilon$ 不能正比于任何缺陷或接缝的**体积占比**，只能是指数残存，或与缺陷清单解耦。

其四，口径说明。以质量比平方 $(m_e/m_P)^2 = 1.7518\times10^{-45}$ 作幂律对象时，$\lambda = 103.06$，$\xi$ 按 $(4\pi^2)^{1/p}$ 缩放（$p = 4$ 为 $2.51$，$p = 6$ 为 $1.85$，$p = 10$ 为 $1.44$）；族间判决不移动。

其五，判决输入。两族的分岔由**相变时标或冻结关联长度的独立读数**裁决：普朗克档指向指数族，$10^{-28}$ 至 $10^{-36}$ 秒档指向幂律族。该输入即 P4-27 的接缝密度定量（关联长度的波前动力学来源）。**（2026-09-20 部分供给并订正）**：因果饱和档下 $t_* \le 10^{-39.4}$ 至 $10^{-34.5}$ 秒、幂指数 $p \ge 5$ 至 $12$（方向订正）；湮灭轮给所需存活表 $A_{\rm req}(p,D)$（$0.76$ 至 $10^{-25}$）与 $t_*^{\min}(p,D)$，指数族的普朗克时标读法被排除，见 [[内部草稿/判别材料-湮灭轮：随机符号涨落下限、所需存活表与相变时标一致域（附 P4-27 首轮订正）]]。
