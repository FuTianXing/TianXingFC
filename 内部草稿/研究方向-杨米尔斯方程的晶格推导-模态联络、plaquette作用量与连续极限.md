## 一、公设清单与降级路径

杨-米尔斯理论的公设原料：规范场 $A_\mu$ 的引入（与定域规范不变性要求）、协变导数 $D_\mu = \partial_\mu + igA_\mu$、场强 $F_{\mu\nu} = \partial_\mu A_\nu - \partial_\nu A_\mu + ig[A_\mu, A_\nu]$、作用量 $S = -\frac{1}{4}\int\mathrm{Tr}(F_{\mu\nu}F^{\mu\nu})$（其变分给出运动方程 $D^\mu F_{\mu\nu} = J_\nu$）、以及 Bianchi 恒等式 $D_\mu\tilde F^{\mu\nu} = 0$。逐项降级路径：

| 公设 | 体系来源 |
| --- | --- |
| 规范场存在性 | 模态论文集域化：内部基准逐点独立 → 局域变换与联络作为几何必然涌现（模态论文 §5） |
| 协变导数 | 模式空间的平行搬运（体系术语：实轴方向/模态基准的逐点搬运） |
| 场强形式 | 搬运的非对易性（曲率）；奇形式偶代数（dd = 0） |
| 作用量形式 | 格点 plaquette 作用量（相位差耦合的全环形式）的长波极限（本稿） |
| 运动方程（有源） | 格点运动方程的连续极限（本稿） |
| Bianchi（无源） | 曲率恒等式：无源组是几何必然（与电磁 Bianchi 同源） |
| 源项 $J_\mu$ | 模式份额流（Fock 密度算符的协变形式） |

本稿完成中间三行（作用量、运动方程、源项）的推导；前两行与 Bianchi 已由模态论文与电磁论文承担，本稿补衔接。

## 二、格点规范哈密顿的物侧构造

### 2.1 自由度：逐点模态基准

模态论文定域化给出每个格点 $n$ 的独立内部基准 $u_n \in U(1) \times SU(2) \times SU(3)$（超荷、弱同位旋、色的几何来源）。链接变量为两格点基准的平行搬运：

$$U_{n,\hat a} = u_n^\dagger\,u_{n+\hat a} \in G$$

（$U(1)$ 情形退化为相位比 $e^{i(\alpha_{n+\hat a} - \alpha_n)}$，即实轴方向场的链接，与实轴方向场论文一致。）

### 2.2 plaquette 作用量（来源：相位差耦合）

公理 4 的耦合结构在模式层推广为环绕单格（plaquette）的相位乘积（Wilson 形式）：

$$S_P = \sum_{n,\{\hat a\hat b\}} \beta\,\Big(1 - \mathrm{Re}\,\mathrm{Tr}\,U_{n,\hat a}U_{n+\hat a,\hat b}U_{n+\hat b,-\hat a}U_{n,-\hat b}\Big)$$

物侧来源：相位差耦合的体系原型（$\cos(\theta_j - \theta_i)$ 型）在格点规范理论中的标准实现（1 − cos 类），系数 $\beta = 2/g^2$（$g$ 为规范耦合，即模态耦合强度参数，来源见 §四）。$U(1)$ 极限：plaquette 项 = $1 - \cos(\Phi_P)$（$\Phi_P$ 为围梯方向差），与电磁论文的校准动力学衔接。

### 2.3 时间方向项

摆程节律沿时间方向的梯度（电场项）取格点规范哈密顿的 Kogut-Susskind 标准形式 $\frac{g^2}{2}\sum E_n^2$（$E_n$ 为规范电场 = 格点链上的时间链接导数），其连续极限给出 $F_{0a}$ 项。

## 三、连续极限 → 杨-米尔斯作用量

链接小转角展开 $U_{n,\hat a} = e^{ig l_P A_a}$（$A_a$ 为连续规范场）：

$$U_P = 1 + ig l_P^2 F_{ab} + O(l_P^3), \qquad F_{ab} = \partial_a A_b - \partial_b A_a + ig[A_a, A_b]$$

代回作用量，$1 - \mathrm{Re}\,\mathrm{Tr}\,U_P \to \tfrac12 l_P^4 \,\mathrm{Tr}(F_{ab}^2)$，求和取连续极限（$\sum l_P^4 \to \int d^4x$）：

$$S_{\text{YM}} = -\frac{1}{4}\int \mathrm{Tr}\big(F_{\mu\nu}F^{\mu\nu}\big) d^4x$$

**定理（杨-米尔斯作用量的涌现）**：公理 4 相位差耦合的全环形式（§二 plaquette 作用量）在长波极限精确给出曲率平方作用量。证明：小转角展开为标准格点规范数学 [Wilson 1974]，系数 $\beta = 2/g^2$ 由链接展开的 $g l_P$ 归一化固定。$\blacksquare$

由此：作用量形式从公设变为"晶格 plaquette 的长波极限"；规范性（$F^2$ 唯一性）来自连续极限对曲率的唯一收缩（维度 + 迹）。

## 四、运动方程与源项

**无源组（Bianchi）**：$D_\mu\tilde F^{\mu\nu} = 0$ 是曲率的恒等式（$dd = 0$ 的协变形式），与电磁 Bianchi 同源（电磁场论文：无源组 = 几何必然，无需动力学假设）。在体系内：奇形式闭合是联络定义的恒等结果，本稿不复推，只登记衔接。

**有源组**：格点运动方程（作用量变分）取格点规范理论标准形式；连续极限给出

$$D^\mu F_{\mu\nu} = J_\nu$$

**源项的份额语义**：物质电流 $J_\nu$ = 模式份额流的协变形式（QFT 总成：Fock 密度算符 $\hat\psi^\dagger\hat\psi$ 的期待值流），其协变守恒 $D^\mu J_\mu = 0$ 来自份额恒等式（总份额守恒）加规范变换不变性。由此：运动方程的形式从公设变为"格点变分 + 长波极限 + 份额守恒"的组合。

**规范耦合参数的来源**：$g$ 在此前是公设；体系内候选来源：模态耦合强度（$\kappa_\phi$ 的规范层组合）与手征性方案的模态参与度（$T_3$ 投影荷）。定量关系留作遗留（g 的"从 $\kappa_\phi$ 涌现"路径登记）。
