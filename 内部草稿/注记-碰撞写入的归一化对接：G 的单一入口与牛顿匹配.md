## 一、对接目标与量纲分析

碰撞写入机制的全部定量结果目前在格点单位下陈述：写入幅度 $\delta\theta = m/m_P$（无量纲），每拍注入 $w$（无量纲/拍），稳态记录 $\theta(r)$（无量纲）。要与真实引力对接，需回答三个量纲问题：其一，记录场的物理单位是什么；其二，$G$ 从哪里进入、是否只进入一次；其三，每拍注入与牛顿源强度之间的换算常数是否引入新标度。

量纲盘点：倾斜记录是无量纲角；度规扰动 $h_{00}$ 是无量纲量；牛顿势除以 $c^2$ 也是无量纲量。三者单位相容，对接不需要任何新的量纲桥梁，只需要一个常数匹配。

## 二、推导

### 2.1 稳态格林函数（已数值验证的前提）

写入过程：每拍邻居抄写平均 $\theta_n \leftarrow \theta_n + \alpha(\bar\theta_{nn} - \theta_n)$，缺陷世界线处每拍注入 $w_{eff}$。稳态满足

$$-\nabla^2\theta = s_{eff}\,\delta, \qquad s_{eff} = \frac{6 w_{eff}}{\alpha}$$

（三维立方格点，因子 6 为配位数）。格林函数在格点单位下为 $\theta(r) = s_{eff}\,l_P/(4\pi r)$，已数值验证：$1/r$ 系数偏差 $1.9\times10^{-4}$，球面通量恒等源强，$4\pi$ 由立体角换算自动涌现。

### 2.2 PN 极限对接

牛顿引力势 $\Phi_N(r) = -Gm/r$；弱场度规 $g_{00} = -(1 + h_{00})$，$h_{00} = 2\Phi_N/c^2$（符号约定按吸引要求定向，见第四节）。度规记录识别（模型假设，已在主论文 §3.3 与 §5.3 声明）：记录场即度规扰动的载体，$h_{00}/2 = \theta(r)$。PN 对接要求

$$\theta(r) = \frac{Gm}{c^2 r}$$

与稳态格林函数比对：

$$\frac{s_{eff}\, l_P}{4\pi r} = \frac{Gm}{c^2 r} \quad\Longrightarrow\quad s_{eff} = \frac{4\pi G m}{c^2 l_P}$$

### 2.3 G 的单一入口

关键恒等式：由 $l_P = \sqrt{\hbar G/c^3}$ 与 $m_P = \sqrt{\hbar c/G}$ 直接相除，

$$\frac{G}{c^2 l_P} = \frac{1}{m_P}$$

（验证：$c^2 l_P = c^2\sqrt{\hbar G/c^3} = \sqrt{c\hbar G}$，故 $G/(c^2 l_P) = \sqrt{G/(c\hbar)} = 1/m_P$。）代入得

$$s_{eff} = 4\pi\,\frac{m}{m_P}$$

**$G$ 仅经 $m_P = \sqrt{\hbar c/G}$ 进入一次**：归一化不引入任何新常数、新标度或新的常数组合。记录场的物理形式为

$$\theta(r) = \frac{m}{m_P}\cdot\frac{l_P}{r} = \frac{Gm}{c^2 r}$$

（末步用了 $l_P/m_P = G/c^2$，同一恒等式的另一面。）即**记录场在数值上就是牛顿势除以 $c^2$**：度规记录识别 $h_{00}/2 = \theta$ 与标准弱场度规 $h_{00} = 2\Phi_N/c^2$ 完全相容。

## 三、归一化定理（条件性命题）与推论

**定理（条件性命题）**：给定（i）写入过程的稳态格林函数 $\theta(r) = s_{eff}\,l_P/(4\pi r)$（数值事实）；（ii）度规记录识别 $h_{00}/2 = \theta$（模型假设）；（iii）PN 极限对接 $\theta = Gm/(c^2 r)$，则每拍有效注入为

$$s_{eff} = 4\pi\,\frac{m}{m_P}, \qquad w_{eff} = \frac{2\pi\alpha}{3}\cdot\frac{m}{m_P}$$

且 $G$ 仅经 $m_P$ 进入一次，无新常数与新标度。

**推论一（写入碰撞计数）**：每拍有效注入分解为 $w_{eff} = N_c\,\delta\theta$（$N_c$ = 每拍携带写入的碰撞次数），则归一化要求

$$N_c = \frac{2\pi\alpha}{3} \approx 2.09 \quad (\alpha = 1)$$

$N_c$ 为 O(1) 几何计数（缺陷边界每拍携带写入的碰撞次数），由锁定区的边界形状与碰撞日程决定，不含新物理标度。其几何导出（锁定区边界形状与碰撞计数的对应）为遗留项。

**推论二（量纲自洽）**：全链量纲闭合：$\delta\theta$ 无量纲、$s_{eff}$ 无量纲/拍、$\theta$ 无量纲、$h_{00}$ 无量纲；$G$ 的一次入口使 $\theta(r) = Gm/(c^2 r)$ 自动具有正确量纲。

**推论三（潮汐自洽）**：记录场的二阶差分已数值验证给出无迹潮汐（$(2,-1,-1)$、$r^{-3.19}$ 衰减），与牛顿潮汐张量 $E_{ij} = \partial_i\partial_j\Phi_N$ 的结构一致：归一化不改变第 3.3 节的潮汐结论，只为其提供量纲。

**推论四（与文献[2]的 G 定位自洽）**：文献[2]中 $G$ 经 $l_P = \sqrt{\hbar G/c^3}$ 进入像素机制（自洽性证明，非独立推导）；本对接中 $G$ 经 $m_P = \sqrt{\hbar c/G}$ 进入归一化。两者是同一 $G$ 的两种普朗克标度入口（$l_P m_P$ 组合恒等），不冲突：写入幅度 $\delta\theta = m/m_P$ 用 $m_P$ 入口，格距用 $l_P$ 入口，衔接处即推论的恒等式 $l_P/m_P = G/c^2$。

## 四、边界与遗留

其一，**符号与吸引方向**：本对接固定记录场的幅值与量纲；吸引方向（记录使测试粒子落向源）的定向结构属倾斜方向结构问题，已在主论文边界中登记，本对接假设符号约定可按吸引要求选取。其二，**$N_c$ 的几何导出**：每拍携带写入的碰撞次数由锁定区边界形状决定，最小缺陷（单格点锁定）与扩展缺陷的 $N_c$ 计数待三维三元组推广时处理。其三，**度规识别的假设地位**：$h_{00}/2 = \theta$ 为模型假设（主论文已声明潮汐代理），本对接在该假设内闭合；显式 4D 链接合成留作后续。其四，**动态极限**：本对接为静态弱场；后牛顿扇区与引力波（开放问题 ②）以本定理为量纲基础。其五，$t_P$ 的角色：静态场幅与节拍频率无关（稳态只依赖每拍注入量），$t_P$ 经 $c = l_P/t_P$ 进入传播与潮汐的时间结构，不入静态幅值。
