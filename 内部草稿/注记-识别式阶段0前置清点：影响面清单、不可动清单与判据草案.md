## 四、判据草案

**T0-1 判定项读数化。** 构造同一格点构型下两种读法的差异预测：度规结构读法给"钟与尺的独立响应"，线性换算因子读法给"两者同一因子的两个投影"。通过条件：差异落在某个可算且可测的量上（候选：同一构型下 $g_{00}$ 与 $g_{xx}$ 的独立性关系、光的传播方程的二阶项）。判负条件：两种读法在任何可算量上给出同一预测。

**T0-2 可复现形式。** 把 T0-1 的差异写成脚本可判形式：同一源构型，分别按两种读法生成度量，比较预设读数向量的可分性。通过条件：可分性判据落成数值；判负条件：读数向量在两种读法下不可分。

**T0-3 影响面核对。** 以本清点 §二 为准，核对判定结论会触碰哪些文档，写死"改字不改读数"与"改读数"两栏。

**A1 自撑四通道显式系数。** 在自撑阱装置上把四个响应系数 $a_i$ 的显式值算出来（从判据 P、S 的"同齐次度"细化为数值），并与唯一解定理的均匀标度（$a_1 = a_2 = a_4 = a$、$a_3 = a + 2$）对照。

**A2 与既有读数一致。** A1 读数与判据 P、S 的既有输出逐项比对。通过条件：一致到装置精度；判负条件：出现不一致，包层重锚不成立。

**B1 自撑恒等式三维径向细化。** 把 $V''$ 分裂恒等式在三维径向下逐点验证（判据 S 的收紧版）。

**B2 退化定理读数化。** 给出"乘积不可分"的数值版：在同一组既有观测读数下，两种读法共享同一乘积；检查是否存在任何既有读数能把乘积拆开。

**B3 与 M6 边界对接。** 把二次型可推导边界接进识别式链条，标明它覆盖了识别式的哪一部分、还差哪一部分（对接表）。
