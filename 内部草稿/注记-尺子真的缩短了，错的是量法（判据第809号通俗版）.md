## 一句话

尺子确实缩短了，缩的比例正好是 $1/\gamma$。前面七轮量不出来，是因为那套装置的尺子一开始就没摆对。

## 前面七轮发生了什么

从第 691 号到第 805 号，我们一次又一次地得到同一个坏消息：尺缩测不出来。

第 691 号说，运动的波包拖着一条长尾巴，宽度读数被污染。第 783 号换了随动坐标系，说污染源是波包整体平移，不是辐射尾。第 797 号换了完全不看载波的量法，说坏消息更大。第 800 号发现尾巴长度恰好等于它跑过的距离，说这套装置在物理上就没法同时做到「尾巴可忽略」和「跑够了」。第 805 号把这七轮整理成一条四环因果链。

每一轮都换了一种量法，每一轮都指向同一句话：**这个体系上尺缩不成立。**

那句话现在要改了。改动的原因不在量法，在尺子本身。

## 那套装置的尺子是怎么摆错的

第 691 号的脚本开头写着一段说明，交代运动态的初始波形怎么摆。说明里写的很清楚：波形按 $s_0 = \gamma x$ 收缩（$x$ 是实验室坐标，$s_0$ 是物体自己的坐标），相位梯度给成 $-\omega_b\gamma v x$。

这是对的写法。物体自己看过去，包络缩了 $1/\gamma$；实验室看过去，波峰之间的相位跑得更快，快 $\gamma$ 倍。

代码写的是：

```python
s0 = shrink * xf            # shrink = 1/g，所以 s0 = x/gamma
th0 = -wb * shrink * v * xf  # 相位梯度 -wb v x / gamma
```

$s_0 = x/\gamma$，而正确是 $s_0 = \gamma x$。一个是放大，一个是收缩，方向正好反。相位梯度那里，正确是乘 $\gamma$，代码是除以 $\gamma$，差 $\gamma^2$ 倍。

还有第三处：阱的宽度也按 $1/\gamma$ 缩了。阱是外部加的场，boost 不变换外部的场。

三处一起错，凑成一套自洽的错装置：**井缩着，波包涨着，相位慢着。** 波包一开始比井宽得多，运动档一开局就在剧烈弛豫。前面七轮量到的，是弛豫过程中的形状，不是 boost 之后的样子。

这段说明文字是当初的设计意图，代码是后来改坏的。这是很常见的一种坏法：注释里写着正确答案，代码里跑着另一个答案。

## 找到正确的变量

格点的色散关系不是连续空间里那个椭圆，是

$$\omega^2 = 1 + 4\sin^2(k/2)$$

这个式子乍看很难看。但令 $p = 2\sin(k/2)$，它立刻变成

$$\omega^2 = 1 + p^2$$

**这就是相对论里那个精确的式子。** 洛伦兹变换写在 $p$ 变量上是精确的：

$$p' = \gamma(p + v\omega), \qquad \omega' = \gamma(\omega + vp)$$

变换完 $\omega^2 - p^2$ 一点不变，质量壳守得死死的。而格点波数是 $k = 2\arcsin(p/2)$，频率是 $\omega = \sqrt{1+p^2}$，用这个 $p$ 谱去搭波包，格点方程一根弦都不差。

反过来看，写在 $k$ 变量上就不行。$k$ 和 $p$ 之间有个非线性，连续论里 $k' = \gamma(k + v\omega)$ 落到格点上，$k$ 和 $p$ 对不上，模就掉出壳外。这个掉壳量是 $k^4/12$ 的量级，$v = 0.30$ 档是 $3.699\times10^{-4}$，$v = 0.40$ 档是 $1.264\times10^{-3}$。

还有一层更根本的：亚能隙里的束缚态，动量是虚的 $p = i\kappa$。boost 把虚数带到复平面上，格点里没有对应的实模。**所以「亚隙束缚态做载波式 boost」这件事在格点上根本没有载体**，跟初始条件怎么写无关。

这一层解释了为什么第 691 号那条路走不通：它读的是阱里的束缚态，束缚态在格点的能隙里。

## 换一套装置

既然带内态有载体，那就用带内态。

新装置不用阱，用一个自由波包，宽 300 格，用 $p$ 空间谱搭起来，101 个动量采样点。速度四档：0.10、0.20、0.30、0.40。静止档的包络宽解析值是 543.70657 格，量出来 543.68339 格，差 $4.264\times10^{-5}$。这就是标定：尺子先得能量静止的东西。

## 三个检查

一个判据能测出东西，得先问它会不会不管什么都能测出。本轮造了两个「看起来应该也通过」的错误装置：一个是动量变换忘了乘 $\gamma$，一个是照连续论在 $k$ 变量上做 boost。八个档全部被判「不通过」。这说明判据有牙。

第二个检查是标度。测出来的偏差应该按某个幂次长。宽度偏差实测幂次 2.121，解析预期 2；钟慢偏差 3.684，预期 4；漂移偏差 1.918，预期 2。系数上，宽度偏差的 0.136026 与解析的 $\gamma^2/8$ 均值 0.135661 几乎逐位相同。

第三个检查是换一条路算。谱解和时间步进是两条完全不同的演化路径，末宽相差 $4.170\times10^{-6}$。

## 预言不是 $1/\gamma$

细看宽度那一栏，预言值比朴素 $1/\gamma$ 差一点。$v = 0.40$ 档，朴素 $1/\gamma$ 是 0.917431，实测 0.894459，差 $2.4065\times10^{-2}$，比判据预算大一个数量级。

差在哪？$k = 2\arcsin(p/2)$，导数是 $1 + p^2/8$。动量展宽是精确的，但换到波数上要过这个非线性，它把展宽压回去一点。所以格点上的收缩比朴素值更小，修正项是 $-(\gamma v)^2/8$。

钟慢的修正项是 $+\gamma^3 v^4/12$，在 $v = 0.20$ 档起就大于读数的抖动，能分出来。

**这个修正项里那个 2 是格距的倒数。** 物理档的格距是 $m_P/m_e = 2.389\times10^{22}$ 格（第 622 号恒等式），$kl_P$ 小到 $10^{-22}$，修正项随 $(kl_P)^2$ 缩到 $10^{-44}$ 量级。**在物理档上，预言就是 $1/\gamma$ 本身，格点修正项可以忽略不计。**

## 这件事和体系最根本的原则

格点上的长度收缩，是靠动量展宽实现的。动量展宽在相位通道那一边完成，是精确的相对论关系。

层数通道的格距不参与收缩。$k = 2\arcsin(p/2)$ 那个非线性，正是格距在最终结果里留下的唯一痕迹，落在修正项中。

这就是波粒互补在格点上的具体分工：**相位通道的连续演化承担对称关系，层数通道的离散格点提供计数与截断，不承担收缩。** 前面七轮之所以量不出来，一半是因为尺子摆错，一半是因为把格点当成了连续空间。

## 一条方法论

判据被否之后，先查前提，再查读法。

前面七轮的次序是：换读法、换装置、换构造。每次都得到同一个坏消息，于是那个坏消息就被归给了物理。归给物理之前，从来没有人回去看一眼那套装置的初始条件是照哪一段说明写的。

**判据连着否七次，该被怀疑的是判据的前提，不是判据。** 尤其当说明文字和代码不一致的时候，说明文字往往是当初的意图。

另一条：找格点上的对称性写在哪个变量里。写对了就精确，写错了就掉壳。这一步找到之后，装置的问题一次性消失。
