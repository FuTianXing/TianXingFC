## 一、机制陈述

前注记把"插入窗口与碰撞瞬间的精确对齐"列为开放问题。作者指出它并不难：**插入正好发生在碰撞的时刻。** 完整时序如下。

1. 碰撞时刻 $t_0$：A（去程末）与"将要折返的元相子"在公共边界 $z=l_P$ 重合碰撞（原本的反相碰撞，注释 03）。
2. 就在这一瞬间：新元相子 C 在碰撞点 $z=l_P$ 诞生，并**复刻了即将折返的那个元相子的状态**（同为 $|\dot\theta|=\omega_P$ 的同步摆，相位对齐）。
3. C 立刻从实轴开始旋转：转一圈（相位 $0\to2\pi$，一个摆程 $t_P$），恰好在摆程内跃迁一个格距 $l_P$，从 $z=l_P$ 到达 $z=2l_P$。
4. C 到达 $z=2l_P$ 时撞上旁边的元相子。**旁边的元相子并不知道，它此刻撞上的其实是一个新的元相子**，因为 C 复刻了让位者的状态。

## 二、数值验证（邻居无感知 + 跃迁自洽）

用三角波运动学（每个元相子在其格点区间内往返，周期 $2t_P$，速度 $c$，$|\dot\theta|=\omega_P$）验证两个关键点。

**验证一：A 对 C 的插入无感知。**

- A（格点 $[0,l_P]$，$\phi=0$，$t=0$ 在 $z=0$）：去程末 $t=t_P$ 到达 $z=l_P$。
- 被替代的元相子（格点 $[l_P,2l_P]$，$\phi=1$，$t=0$ 在 $z=2l_P$）：回程末 $t=t_P$ 到达 $z=l_P$。

二者都在 $t=t_P$ 到达 $z=l_P$，即 A 与"原邻居"在 $t=t_P$ 碰撞。C 以相同的 $\phi=1$、相同的同步摆复刻被替代者后，A 仍在 $t=t_P$ 于 $z=l_P$ 与 C 碰撞，**碰撞时刻不变**。因此 A 对 C 的插入无感知。

**验证二：C 的起旋跃迁恰好撞上邻居。**

- C 诞生于 $z=l_P$，从实轴起旋，一个摆程 $t_P$ 内跃迁 $l_P$ 到 $z=2l_P$。
- 让位后的邻居（格点 $[2l_P,3l_P]$，$\phi=1$，$t=0$ 在 $z=3l_P$）回程末 $t=t_P$ 到达 $z=2l_P$。

C 在 $t=t_P$ 到达 $z=2l_P$，与让位邻居同时到达，发生碰撞。**C 转一圈（$t_P$）跃迁 $l_P$，恰好撞上让位邻居，时序自洽。**

## 三、对前注记开放问题的回应

1. **插入窗口对齐**：前注记列为开放问题。本机制表明插入就发生在碰撞时刻，无需额外挑时机。C 诞生于碰撞点，且与让位者同相位、同步摆，自然进入交错基态（$0,\pi,0$），无需调整。

2. **B 相位翻转的时机**：前注记把"B 相位翻转"列为开放问题。本机制给出更自然的表述：**C 直接复刻了"即将折返的 B"的状态**，故翻转表现为"B 让位后，C 继承了 B 的相位"。B 退到 $[2l_P,3l_P]$ 时带走的相位，与 C 继承的相位衔接，整体仍是交错基态。

3. **邻居无感知的根源**：插入不破坏同步节律（注释 04：所有元相子 $|\dot\theta|=\omega_P$ 同步摆程），C 与它替代者共享同一节律与相位，故 A、B 分别在各自边界撞到 C 时，一切如常。**时空就在这个过程中膨胀，且非常顺滑。**

## 四、格点膨胀的顺滑图景

碰撞点 $z=l_P$ 每 $2t_P$ 出现一次（A 去程末）。每次碰撞瞬间可接纳一个新 C，C 撑开一个格距并让位邻居。可以如下理解：

- 局部（单次插入）：三个元相子（A、C、让位的 B）重新排布为等距三格，格距保持 $l_P$，只是整体后退给出一格空间。
- 全局（累积插入）：每次插入在骨架上多出一个格点区间，骨架向外扩张，即空间膨胀。由于每次插入都发生在碰撞点、复刻同步状态、邻居无感知，膨胀不引入额外扰动，整体平滑。

## 五、严格程度

1. 邻居无感知（A 在 $t=t_P$ 撞 C 时刻不变）为运动学结果，锚定注释 03 圆心碰撞几何与注释 04 同步节律，达到条件性命题级。

2. C 起旋跃迁（$t_P$ 内跃迁 $l_P$，恰好撞邻居）为运动学结果，锚定螺旋刚性 $z=\lambda\theta/2\pi$ 与 $c=l_P/t_P$，为条件性命题。

3. C 于碰撞点诞生、复刻让位者状态的**生成机制**（C 从何而来、如何继承相位、让位邻居的让位顺序与能量代价）为开放问题，本注记给出的是时序与状态自洽方案，非已证定理。

## 六、遗留

- C 的生成机制：C 由本原创生（注释 18），何以恰在碰撞点诞生、何以继承让位者相位，其物侧效应（格点增长律）待量化。
- 让位邻居的让位顺序与能量代价：B 让位一格时，与更外侧格点的衔接（远端元相子是否被牵扯）。
- 三维三元组推广：三方向（X/Y/Z）的顺滑插入、$\kappa_\phi$ 耦合在插入时序中的作用。
- C 插入频率与哈勃膨胀 $H_0$ 的衔接：每次碰撞点是否都能接纳 C，还是需特定条件；接纳率如何贡献膨胀速率。
