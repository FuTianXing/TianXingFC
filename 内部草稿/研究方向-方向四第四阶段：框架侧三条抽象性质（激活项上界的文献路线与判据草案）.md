## 一、路线的一句话

激活项的上界的身份是定理：只要框架的信息测度满足三条性质（一致性、局域数据处理、链式法则），再加上无信号与"消息是经典 $m$ 比特"两条前提，上界 $I \le m$ 自动成立。三条性质若能在框架内立起，公理级候选退回判据级，这正是开放问题三要的结果；立不起，则缺口精确到哪条性质，供作者裁决。

## 二、三条性质在框架内的候选读法

**C1 一致性**。经典子系统上，框架的互信息须退化为 Shannon 互信息。候选载体：层位占据与缺陷读数为离散经典变量（M5 与记录机制），记录数为整数计数（2.1 节）。待定项：相位的连续自由度如何进入经典变量（走统计通道，见 2.1 节末段）。

**C2 局域数据处理**。对一侧作允许的局域操作不增互信息。三条里最吃紧的一条：Bob 选择设置并取出盒输出属于局域操作，而这个动作正是把零互信息变成正互信息的机制（PR 强度处 $I(a_K : \beta \vert b = K)$ 从零涨到一）。候选资产：M6 的扇区操作刚性与局域不可见、2.3 节的单侧不可写。待定项：允许操作类怎样划线，既不把 Bob 的设置选择排除在外，又在模型边处不失效。

**C3 链式法则**。存在条件互信息使 $I(A : B, C) = I(A : C) + I(A : B \vert C)$。若框架读数构成 Shannon 型离散联合分布（层位占据、记录数、扇区标签），本条为恒等式级。

**前提两条**。无信号（对侧边际与设置无关，J2 与陈述二给出）与消息经典性（一次跨层记录一比特，2.1 节）。

## 三、判据草案 D1 至 D6

- D1 反重述：三条性质的陈述只许用框架量（记录数、层位占据、扇区标签、局域操作类），不得出现 $2\sqrt{2}$、$\cos^2(\pi/8)$ 或任何目标值。
- D2 模型内可核：在脚本 369 的模型上逐条检验。C1 取经典极限 $\varepsilon = 0$；C3 作恒等式核对；C2 分 $\varepsilon < 1/\sqrt{2}$ 与 $\varepsilon = 1$ 两档核，读出失败点。
- D3 极限退化：$m = 0$ 时必须退化为无信号。
- D4 非空转：若三条成立，模型边必须回到 $\cos^2(\pi/8)$ 与 $J = 1$（369 的既有读数），偏离即证明有误。
- D5 反特设：允许操作类的定义须先于目标值独立立起；为压住 $\varepsilon = 1$ 而事后裁剪操作类者判负。
- D6 诚实条款：任一条立不起就按缺口登记，不改目标值，不把公设改写成定理。

## 四、预判与代价

最可能的失败点是 C2 的允许操作类划线，次可能失败点是 C1 的经典变量界定。若 C2 只能靠"禁止 Bob 的设置选择"这类裁剪来救，则本条与公设等价，第四阶段判负，公理候选维持。执行成本预估：D2 一轮（复用 369 模型），C1 与 C3 各半轮，C2 视划线而定。
