## 一、三个对象各自的体系身份

三个对象在标准物理里分属三处。康普顿波长是散射公式里的一个常数组合；狄拉克方程是给出旋量与 $g=2$ 的相对论波动方程；ZBW 是后者位置算符读出的一个振荡项。体系对三者的身份认定深浅不一，先把已有的部分并排摆开。

康普顿波长在体系内是缺陷宽度。宽度与质量由同一个锁定耦合 $K$ 给出，宽度正比于 $1/\sqrt{K}$、质量正比于 $\sqrt{K}$，两者互反，乘积被两条已裁决关系钉为 $1$（Planck 单位），于是宽度精确等于约化康普顿波长 $\hbar/(mc)$（第 622 号）。

同一个粒子上还有全周读数。相位转满一圈，沿轴推进 $2\pi c/\omega_0 = h/(mc)$，即螺距（第 626 号 U6）。宽度与螺距差 $2\pi$，成因是衰减长度与周期两种读数，口径出处见 [[内部草稿/注记-台阶面宽度取约化康普顿波长：衰减读数对周期读数与系数口径]]。

狄拉克方程在体系内的现状是骨架已交付、几何导出未完成。第 489 号在 $S^1\times\mathbb{R}$ 上交付 $\hat D$ 的离散骨架，$\pi$ 扭转实现为反周期边界条件；第 499 号在 $3+1$ 维平行自旋下读到 $g=2.000000$ 精确。

这些是标准 Dirac 构造在框架内的复现。[[π扭转的层次分解：旋量结构与费米统计的边界]] 已把自旋 $1/2$ 的旋量性列为严格层，把从元相子几何自动导出 Dirac 算子列为开放层，两者须分开说。

ZBW 的现状最浅。[[内部草稿/注记-相位钟的归属审查：康普顿频率即相位旋转频率，及两处定案的口径修正]] 第七节其四把它登记为待查；[[内部草稿/注记-半扭转环上的两个读数：每拍相位推进与转两圈回原样，及ZBW因子2的三条候选口径]] 把它化为一处口径问题（体系给 $\omega_0$，ZBW 是 $2\omega_0$）。两者都停在数对不上这一层，未接上宽度读数。

## 二、边一：康普顿波长与狄拉克方程

狄拉克方程的质量项 $m$ 在体系内就是缺陷相对真空（基态）的绑定能 $E_B = mc^2$，这是本会话收紧过的质量定义（[[wiki/质量]]）。绑定能给缺陷定出两个长度，两者都是同一个 $m$ 的几何读数：扩散式的衰减长度 $\xi = \hbar/(mc)$ 与螺旋式的螺距 $2\pi\hbar/(mc)$。

格点骨架把这条边坐实到离散层。$S^1$ 上的反周期条件给出半整数模 $k_\theta/(2\pi) = n+\tfrac12$（第 489 号 SK3，偏差 $8.88\times10^{-16}$），谱关于 $E=0$ 严格对称且无零模。低 $k$ 连续极限下 $E^2 = c^2k^2+m^2$，残差 $3.21\times10^{-3}$ 恰为 $\sin$ 展开预算 $k^2/3$（SK2）。

由此「质量项即绑定能」在骨架上有谱层证据，$\hat D$ 的 $m$ 与第 622 号的 $m$ 指同一个量。须记明的分界：这条边说的是同一个 $m$ 出现在两处，不构成从元相子几何导出 Dirac 算子，后者的缺失正是上一层的开放项。

## 三、边二：康普顿波长与 ZBW（核心读数）

ZBW 的两条标准读数，取 $p\to0$ 极限后为

$$\text{振幅} = \frac{\hbar c}{2E}\Big|_{p\to0} = \frac{\hbar}{2mc},\qquad \text{角频率} = \frac{2E}{\hbar}\Big|_{p\to0} = \frac{2mc^2}{\hbar} = 2\omega_0 .$$

把第一条与缺陷宽度并排，得到一个直接读数：$\hbar/(2mc)$ 恰为 $\hbar/(mc)$ 的一半，即 ZBW 的振幅等于缺陷宽度的一半。电子档实测宽度 $\xi = 3.8615926772\times10^{-13}$ m，ZBW 振幅 $1.9307963386\times10^{-13}$ m，比值 $0.5$ 精确。

把第二条与体系相位速率并排，得到第二个读数：ZBW 的角频率是 $\omega_0$ 的两倍（电子档 $\omega_0 = 7.7634407111\times10^{20}$ rad/s，ZBW 角频率 $1.5526881422\times10^{21}$ rad/s）。

两个「半」与「两倍」互补，落在同一条恒等式上。体系已有的 $\xi\,\omega_0 = c$（衰减长度乘相位速率等于格点光速）在 ZBW 读数下写成

$$\text{振幅}\times\text{角频率} = \Big(\frac{\xi}{2}\Big)\big(2\omega_0\big) = \xi\,\omega_0 = c .$$

电子档实测 $A\Omega/c = 1.0000000000$，即位移振荡的速度峰值恰好是光速。这一条是本轮最实的读数，也解释了标准物理里 ZBW 图像的自洽：振荡的极值速度就是光速。

## 四、边三：狄拉克方程与 ZBW

ZBW 在标准物理里是速度算符 $\alpha$ 中扣除平均速度后那一半的时间演化。自由粒子哈密顿量 $H = c\alpha\cdot p + \beta mc^2$，速度算符 $\dot x = (i/\hbar)[H,x] = c\alpha$，把 $\alpha$ 按正负两支分解，位置算符分成慢部与振荡部

$$x(t) = x(0) + \frac{c^2p}{H}\,t + \xi_{\rm ZBW}(t),\qquad \xi_{\rm ZBW} \propto \alpha_{\rm 跨支}\,e^{-2iHt/\hbar}.$$

连接正负两支的那部分 $\alpha$ 随时间以支间差频振荡，这就是 ZBW 的来源。把 $H$ 投影到正能子空间（Foldy-Wouthuysen 表示）后该项为零，故 ZBW 是两支结构的读数，出自场的完整性，不属单个粒子。

体系在物侧已经有这两支。第 489 号 SK3 在格点 $\hat D$ 上读到谱关于 $E=0$ 严格对称（$\max|E_i+E_{N+1-i}| = 3.18\times10^{-14}$）且无零模。第 494、495 条把两支的区分量定为能量符号（粒子扇区与反粒子扇区），第 491、500 条给出手性算符 $\Gamma_5$ 与 $H$ 的对易、反对易关系。

这几条合起来说明，ZBW 所需要的那两支在体系的格点 Dirac 算子上是现成的，且落在物侧，不必到心侧的场里去取。

## 五、因子 2 的统一：候选 (a) 与 (b) 是一件事

[[内部草稿/注记-半扭转环上的两个读数：每拍相位推进与转两圈回原样，及ZBW因子2的三条候选口径]] 曾把「体系 $\omega_0$ 对 ZBW $2\omega_0$」的因子 2 拆成三条候选。边三给出一个化简：候选 (a)（对能隙对单粒子能隙）与候选 (b)（两支拍频）是同一结构在能量侧与时间侧的两种读数。

能量侧看，两支的能隙在 $p\to0$ 时为 $E_+ - E_- = 2mc^2$，故支间相位速率由 $2mc^2/\hbar$ 给出。时间侧看，两支的相位因子是 $e^{\mp iEt/\hbar}$，一正一负互为反向旋转，其拍频同样是 $2E/\hbar$。两个数在标准推导里是同一个 $2E/\hbar$ 的两个来路，不存在取 (a) 还是取 (b) 的取舍。

此处须分辨一个易混的「反向」。ZBW 要的是 $\pm E$ 这一对（时间上反向旋转，故有 $2\omega_0$ 的拍频），不是 $\pm k$ 这一对空间反向传播模。$\pm k$ 同属一个能支，二者同频，叠起来是驻波，不给时间拍频。第 489 号 SK4 的 $w=\pm1$ 谱逐位恒等属第三层（电荷两支），也不充当 ZBW 的两支。

这条分辨解除了原注记留的一处阻塞。原注记曾判 (b) 需要先核对环上两支是否反向，而既有环构造把半扭转建在心物双螺旋之间，按「不加入心侧」的约束无法直接核对。现在 (b) 的两支由 $\pm E$ 提供，第 489 号 SK3 已在物侧读到它，且它同时就是 (a) 的对能隙。故 (b) 不再依赖心侧，也不再依赖环构造。

候选 (c)（自旋双覆盖）仍排除，理由不变：反周期只把模量子数平移到半整数（第 489 号 SK3），并让状态周期成为相位周期的两倍；若取状态基频反而给 $\omega_0/2$，方向与所需的 2 相反。

## 六、边界：能说什么、不能说什么

能说三条。其一，ZBW 的振幅与缺陷宽度成定比（$1/2$），ZBW 的频率与缺陷相位速率成定比（$2$）。其二，两个比值在同一恒等式 $\xi\omega_0 = c$ 上互补，乘积恒为格点光速。其三，因子 2 的来源是正负两支的对能隙，而这两支在体系第 489 号的格点 Dirac 算子上已读到。

不能说的有四条。其一，不能说「缺陷在颤动」。ZBW 是场层（两支）的读数，投影到单支后为零；体系的单个缺陷对应单支，它本身没有 ZBW。把 ZBW 说成缺陷的物理晃动，还与第 627 号「质量摊在包络、缺陷再无额外运动」的读数相抵。

其二，不能由 $(\xi/2)(2\omega_0)=c$ 反推体系与 ZBW 同源。这条乘法是运动学恒等式，凡是「半宽度乘双频率」的任意构造都会通过，故它只算一致性读数，不作机制证据。

其三，不能把宽度读数与 ZBW 振幅混为一谈。宽度 $\xi$ 是空间衰减长度，ZBW 振幅是位置算符期望值的振荡幅，两者数值差 $1/2$，量纲相同而所指不同；包络的第二矩另有读数 $\sigma/\xi = \pi/\sqrt{12} = 0.9069$（第 627 号），比 ZBW 振幅大 $1.814$ 倍。

其四，不能宣布体系已解释 ZBW。本轮给出的是三条边的对接与一组定比读数，缺的是格点上的显式构造。

## 七、一条可执行的判据提案（不执行）

要把边三从「谱层两支已在」推到「位置算符的 ZBW 分量已现」，可执行的最小判据是：在既有 $S^1\times\mathbb{R}$ 格点 $\hat D$ 上构造位置算符，取其在正能子空间外（跨支）分量随时间的演化，读其振荡频率与振幅。

判据期望须先立后实现：频率按支间差频 $2E/\hbar$ 定标（对 $E$ 而非对 $\omega_0$），振幅取长度量 $\hbar c/(2E)$；换 $m$ 档扫描时，振幅与 $1/m$ 成正比、频率与 $m$ 成正比，二者之积恒为 $c$。

反例检验不可省：把跨支分量换成支内分量（如 $\beta$），振荡须随之消失；若换后判据照样通过，则该判据为恒真，不含物理信息。此判据为提案，未写脚本、未占位、未执行；登记去向为电子场攻坚计划阶段 2（D3 已关闭，可作 D6 候选）。

**2026-10-15 判定：不立案**，理由为该判据的核心关系（振幅与宽度之比 $\xi/2$ 对 $\xi$）是定义恒等，任何实现都会通过；频率关系则归结为第 489 条 SK1 已判的格点色散，增量近于零。判定与两条理由见 [[内部草稿/裁决备忘-狄拉克线阶段二前置：分量计数定案、ZBW判据提案的恒真判定，与第一轮判据问题]]；第六节「不能说的」其一条（不能由 $(\xi/2)(2\omega_0)=c$ 反推同源）即此判定的前身。

## 八、严格程度声明与边界声明

**严格层**（可逐位复核的恒等式与读数）：$\hbar c/(2E)|_{p\to0} = \hbar/(2mc) = \xi/2$；$2E/\hbar|_{p\to0} = 2\omega_0$；$(\xi/2)(2\omega_0) = \xi\omega_0 = c$；电子档三数的数值对照（振幅比 $0.5$、$A\Omega/c = 1.0000000000$）。

**口径层**：ZBW 的 $2mc^2$ 取对能隙（(a)）与取反向两支拍频（(b)）为同一结构的两读；ZBW 依赖表示，投影到单支为零；ZBW 的两支取 $\pm E$ 而非 $\pm k$。

**引录层**（照录不改判）：第 489 号 SK2、SK3 的读数；第 499 号 $g=2$；第 491、494、495、500 条的两支与手性结构；第 622、626 号的宽度与螺距口径；[[π扭转的层次分解：旋量结构与费米统计的边界]] 的三层划分。

**未做层**：格点上位置算符 ZBW 分量的显式数值（第七节提案）；$\hat D$ 的表示论导出（开放层）；半扭转环两支的相对旋向（在「不加入心侧」约束下已由边三绕开，不再需要）。

**边界声明**：本注记不改动 [[理论总纲]] 基准，不裁决「体系是否真与 ZBW 对应」（只给三边对接与定比读数），不新增机制断言，不宣布因子 2 已解（因子 2 的来源归位为对能隙属口径归位，是否接受待作者裁决）。[[理论总纲/术语表]]「物质场相位」条所记的「Zitterbewegung 的体系对应待查」在本轮获得部分回答（对能隙口径），该条属基准，未经作者确认不动。
