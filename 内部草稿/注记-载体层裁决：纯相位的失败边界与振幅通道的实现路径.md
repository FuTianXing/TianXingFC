## 二、失败边界

纯相位并非处处失败，把边界写准比写强有用。成立的情形有两条：其一，一维 sine-Gordon 扭结（相位自 $0$ 走到 $2\pi$）局域且稳定；其二，二维 XY 点涡由 $\pi_1(S^1) = \mathbb{Z}$ 保护。

失败的是下面这组条件同时出现的情形：三维闭合环、真空渐近、芯需要有能代价、锚核需要有可节约的对象。此时芯是相位奇点，梯度能按 $\log$ 发散而无凝聚能代价；环的边界映射为 $S^2 \to S^1$，$\pi_2(S^1) = 0$，没有拓扑兜底。

把断言写成「纯相位一律不行」会与一维、二维的既有正例冲突，可检验的表述是上面那组条件。第一节的四条读数正好落在这组条件内。

## 三、归因：通道选错

计划 §七 的裁决一（钉扎阱与键弱化二选一）是伪二分。两条路线各自只动了载体的一个参数。

- 势项钉扎约束相位取值。相位是紧致的，局部被拉到目标值后，其余位置的相位仍可自由滑移把绕数卸载；包层梯度与相位梯度不平行处还会自己生成涡对。判据给出 $\kappa_p \le 2$ 时全盒涡量归零，$2\pi$ 周期形式同结果，故「$\pi$ 周期留出 $\varphi \to \psi + \pi$ 分支」这一解释被排除，卸载的机制是相位滑移。
- 键弱化改的是梯度代价。环的线张力由体积项与磁项主导，降低梯度系数压不过 $\mathrm{d}E/\mathrm{d}R > 0$。

两次负面结果的正确解读是实现通道选错，不能读成锚核概念不成立。

## 四、三条可实现的正回馈机制

要在 $E(R)$ 上得到稳定点，需要一条随半径增长的正回馈。三条候选各自独立可判。

**其一，振幅缺陷钉扎。** 芯位处把偏好振幅 $A_0$ 或势系数 $\lambda$ 局域下调，芯的凝聚能代价随之降低，形成对芯的势阱。这是超导涡旋钉扎的成熟机制：阱深正比于缺陷与芯的重叠体积，脱钉垒可测。

**其二，泡壁环复合体。** 环内外落在不同真空，能量写成 $E(R) = 2\pi R\,\sigma_{\text{壁}} + \pi R^2\,\Delta\varepsilon_{\text{体}} + 2\pi R\,\mu_{\text{芯}}$，体项为正时出现稳定 $R^*$，尺寸由体项与壁项之比选定。**（2026-09-16 精确化：稳定 $R^*$ 的充要条件为负线项加正体项，即 $\sigma_{\text{壁}} + \mu_{\text{芯}} < 0 < \Delta\varepsilon_{\text{体}}$，原表述漏线项前提；见 [[注记-C1-4b体项可行性判定：泡壁环稳定条件的精确化、体项扫描与机制清单]] 第二节。）**这与「复合位错」的字面含义一致，也天然给出 C1-5 要的宽度窗口。

**其三，四次项与 Hopf 保护。** 加 Faddeev-Skyrme 型四次项后，构型搬到 $S^2$ 值场上，闭合涡线的链接给出 Hopf 不变量，分类为 $\pi_3(S^2) = \mathbb{Z}$。二次项与四次项的平衡选定尺寸，Derrick 定理被规避，保护从亚稳升级为拓扑。

三条不互斥：第一条给驻留与脱钉垒，第二条给尺寸窗口，第三条给拓扑保护。

### 第一条机制的判据读数（2026-09-12 执行）

[[注记-振幅通道下涡旋环径向曲线的最小验证：钉扎井存在但无稳定半径]] 在最小复标量载体上给出四条读数。

- 钉扎井成立：$\Delta E(R)$ 有内部极小（$R = 6.0$，细网格井深 $6.0$），位置随锚核半径移动（偏移 $+0.5$ 至 $+1.0$ 格），对应「锚核可节约芯能」。
- 稳定半径不成立：$\lambda$ 扫至 $16$、$d$ 扫至 $0.9$（另测 $d = 1$ 的硬锚核）、$w$ 扫至 $3.0$，总能量 $E_{\text{锚}}(R)$ 全部单调，最接近的临界缺口约为线张力的 $10\%$。
- 电荷不守恒：九组自由复场弛豫全部把绕数卸载到 $0$，终态落到无涡旋真空值。
- 粒性读数成立：芯处 $A(0) = 0.298$ 至 $0.429$，芯区振幅亏损与 $\Delta E$ 同向。

据此，本节第一条（振幅缺陷钉扎）判为不足：它交出粒性侧的两个可观测量，交不出稳定半径与电荷保护。第三条（四次项与 Hopf 保护）与格点内锁定因此升为必需。

## 五、作者主张与推论

作者 2026-09-12 指示（原话）：「纯相位载体肯定不行啊，应当加振幅自由度。而且粒性侧本来就应当是振幅。」

推论一，粒性与波性的分工由序参量的两个实自由度承担：振幅 $A$ 给质量与密度，相位 $\theta$ 给相干与绕数。这与体系既有的两句判断一致（质量归粒、格点内锁定；绕数承载归波性侧、超选择层）。

推论二，锚核的本体是振幅锁定，即格点内异类耦合 $\kappa_\phi$。计划 §七 的裁决一应改写为载体选择与锚核实现通道两问。

推论三，静质量密度应正比于振幅亏损，$\rho_m \propto \int (1 - A^2)$。这条若在最小模型上成立，等于给张量桥分段 (d) 的 $T_{\mu\nu}$ 微观分解递上静质量密度的具体形式。

推论四，标量块已闭合为牛顿极限，而标量块的源就是质量。把粒性接到振幅上，等于把质量源接到已闭合的扇区上，两条线说的是同一件事。

锚核把 $A_0(x)$ 在芯管区域局域下调。格点内耦合 $\kappa_\phi$ 与格点间耦合 $\kappa_\parallel$ 分开写，供 C1-6 使用。

## 七、与既有攻线的接口

**张量桥分段 (d)。** 源项的静质量密度取振幅亏损形式，动能流取相位梯度形式，应力取两者的混合。判据 W4 给该分解提供最小模型证据。

**张量桥分段 (c)。** 无变化，仍门控于 C1 的形态枚举与宽度窗口。

**识别式线。** 判据 P 与判据 S 已表明，$\kappa = 1$ 自动成立要求定域阱与常数质量项同源，即势曲率 $V''$ 参与均匀标度。振幅通道是 $V''$ 的本体，判据 W6 把这条接上。

**引力线的排序。** 分段 (d) 的源项分解原先门控于分段 (c)，推论三给出一条不依赖 (c) 的通路。是否启用由作者裁决。

## 八、超选择层给 C1 的输入与能测边界

### 论文的机制与它的精确形态

[[绕数超选择：先验纠缠作为电荷保护层]] 把保护层归到态空间扇区结构：态空间按绕数分扇区，跨扇区算符是沿回路分布的非局域弦算符，局域生成元闭包内各扇区互不相通。保护不靠垒高，属超选择机制。

[[注记-纠缠侧承载：绕数 = 非定域关系通量的量子保护探路]] 给出更硬的不变量形态：绕数是**基态空间投影量子数**。$[H, W] = 0$ 的全空间对易只在 $Z_2$ 成立；$Z_N$（$N > 2$）下 $[H, W] \ne 0$（激发部分），但 $W$ 保持基态空间、在基态空间内可对角化、跨扇区一阶矩阵元为零（实测 $0.000000$），二阶泄漏经激发态走（实测 $2.000$，$L = 2$ 有限尺寸）。该注记自述这是在修正论文的「守恒量」措辞。

长程纠缠在此扮演的角色是局域不可分辨：toric code 与 Levin-Wen 弦网的基态简并按非缩并环通量分扇区，局域算符无法连接不同通量扇区，唯一跨扇区的操作是非缩并 Wilson 环算符。探路实测 $L = 2$ 环面简并 $4$（$2^{2g}$，$g = 1$），$Z_N$ 简并为 $N^2$，与 $L$、$N$ 无关。

### 对本注记上一轮判断的修正

先前由「闭合环的局域绕数无保护」推出「局域粒子不能有守恒荷」，这一步过强。在任意子图景里，局域激发可以继承扇区荷：荷的定义来自基态空间结构，不来自它自身的局域绕数。

修正后的表述：环的局域绕数不承载守恒荷；粒子的荷若要守恒，须由扇区结构赋予。论文 §六 的两种绕数裁决（环面绕数为真扇区内容，局域涡量为表示性，可经 $2\pi$ 偶极子隐藏）与这条一致。

### 三条输入

其一，C1 的经典读数测不到这层保护。探路注记写明经典层（cos 软模型）通量线仍衰变，保护依赖量子相干。第一节与 [[注记-涡旋初始化与横截面绕数测量装置的最小验证：切平面零读数的根因]] 的全部读数都是经典梯度流，故 C1 在经典层的结论上限是载体的能量、尺寸与驻留，荷的判决必须搬进量子层。

其二，宽度问题获得第四次独立确认。拓扑序层的激发是点状的（涡旋激发约 $0$ 格距，电荷激发约 $1$ 格距），经典层给 $\ell^* = 1.00$，都不落 C1-5 的窗口。宽度只能由转换波或 $\kappa_\parallel$ 软模提供。

其三，质量与荷分挂两层由论文与本注记独立得到。扇区守恒全局绕数而不供能量与尺寸，粒子的能量与尺寸由格点内离散结构即振幅侧承担。

### 待作者确认的修订点（论文侧）

其一，摘要与 §4.1 的措辞应同步为「基态空间投影量子数加跨扇区一阶矩阵元为零」，并把 $Z_2$ 的全空间对易标注为特例。探路注记已作此更正，论文侧尚未同步。
