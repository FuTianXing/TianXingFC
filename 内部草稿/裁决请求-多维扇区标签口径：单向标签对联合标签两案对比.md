## 一、待裁决的一句话

锁定刚度 $\kappa$ 的扇区分布在多维晶格上按什么标签计数：单向扇区标签给 $\kappa = 1/L$（每方向一套标签），多维联合标签给 $\kappa = L^{-d}$（全方向联合一套标签）。第 198、212 条共同暴露此口径分歧，第 212 条注记登记为待裁决。

## 二、两案定义与推导链

| 案 | 推导链 | 数值（$L = 8$） |
| --- | --- | --- |
| 案甲：单向扇区标签 | 整数格点模 $2\pi$ 恒等式 $\theta_j^{(W+L)} \equiv \theta_j^{(W)}$（第 212 条，解析加数值 $1.42\times10^{-14}$）给出每个方向相异扇区数 $N_W = L$；锁定刚度定义在单一方向的绕数扇区分布上，裸耦合 = 扇区分布纯度 $\kappa = \sum_W p_W^2$（第 211 条，构造内严格），均匀分布给 $1/N_W$ | $\kappa = 1/L = 0.125$ |
| 案乙：多维联合标签 | 逐方向同构（构造内成立）把标签升级为 $d$ 元组 $W = (W_1, \ldots, W_d)$，每分量独立取 $\mathbb{Z}_L$，联合扇区数 $N_W = L^d$；联合分布均匀时纯度落到 $1/L^d$ | 二维 $L^{-2} = 0.0156$，三维 $L^{-3} = 0.00195$ |

两案的数学事实部分无分歧：$N_W = L$ 与 $N_W = L^d$ 都在构造内成立（第 212 条）。分歧只在锁定刚度的物理载体按哪套标签定义。

## 五、推荐：案甲（单向扇区标签，$\kappa = 1/L$，逐方向分解）

其一，实测合流是硬约束：三条独立通道（保护距离、键曲率、扇区纯度）只在 $0.125$ 取同一数值，案乙的 $0.0156$ 已被第 209 条键频口径实测排除，$0.00195$ 更在可行域外；采案乙等于让体系内唯一完成三线合流的耦合读数作废。

其二，本体论同构：公理 2 的三类正交方向把方向分立标记，格点三元组经异类耦合 $\kappa_\phi$ 锁定，单向标签与该结构逐项对应；联合标签在体系内没有动力学来源，第 213 条给出的绕数扩散是逐方向、逐子格过程，均匀联合分布需要额外假设跨方向混合。

其三，经济性：案甲保持十五轮判据与门槛带标定不动，三维推广按逐方向复用推进；案乙要求全部重标并重开丙通道。

其四，案乙的数学内容不因裁决作废：$N_W = L^d$ 作为构造内事实保留在注记中，案甲只是裁定锁定刚度的物理载体取单向标签，两种计数可以在文档中长期并存。

**建议的重开条件**（裁决时一并确认）：若后续三维构造交付跨方向绕数关联的判据级读数（方向间扇区分布不独立），或规范侧证据要求三方向绕数联合化（例如 $SU(3)$ 三模态锁定被证为绕数联合标签），本裁决重开。
