## 一、问题与已锁定的约束

要回答的问题是：先把「无穷张量积的整体态经同步相变投射」这一步写成可算的映射，再从该映射导出锁定耦合 $\kappa$，即路线甲。它与乙、丙两条通道的关系是：乙给 $\kappa$ 的数值（$0.125$）、丙给曲率通道的可行区间，甲要给出**来源**。

已锁定的约束有四条。其一，投射必须落在超选择分解 $\mathcal H = \bigoplus_W \mathcal H_W$ 上（第 190 条的资产），即整体态先按扇区分解、再取同步相变后的有效自由度。其二，投射的输出必须与既有两条通道相容：线性口径下 $\kappa = 0.125$（第 209 条裁决）。其三，投射的自由度数目须与保护距离相容：第 184 条给 $d = L = 8$。其四，投射不得引入新的可调常数，其参数须取自既有量（扇区权重、复相干无序度 $D$、规模 $N$）。

## 二、投射的候选形式

**候选形式（待裁决）。** 取 $\kappa = \dfrac{1-D}{N_{\rm eff}}$，其中 $D$ 为复相干无序度（速览第 27 条，$D \in [0,1]$，度量未参与宏观相干的份额），$N_{\rm eff}$ 为投射后的等效分量数（扇区分解下参与锁定的分量个数）。含义是：相干份额 $(1-D)$ 分摊到 $N_{\rm eff}$ 个分量上，每个分量贡献的即是每步线性回拉份额。

**与既有读数的对应。** $\kappa = 0.125$ 在该形式下对应一族组合：$D = 0$、$N_{\rm eff} = 8$（与保护距离 $8$ 一致）；或 $D = 0.5$、$N_{\rm eff} = 4$；或 $D = 0.75$、$N_{\rm eff} = 2$。故形式本身不唯一，须由独立读数把两个因子分别定下（这正是判据清单 A3 与 A4 的内容）。

**备选形式（作为对照）。** $\kappa = (1-D)^{1/N_{\rm eff}}$ 或 $\kappa = (1-D)\cdot\frac{1}{N_{\rm eff}}$ 的幂次变体；若前者在 A3 的测量下优于后者，则以测量为准。
