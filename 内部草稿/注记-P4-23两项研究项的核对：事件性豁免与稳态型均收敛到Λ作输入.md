## 二、研究项一（事件性豁免）核对

要求新增事件注入的能量同时满足三条：光滑、不随膨胀稀释、可引力。与体系已固化的能量分类逐项对照：

| 能量种类 | 光滑 | 不稀释 | 可引力 | 判定 |
|---|---|---|---|---|
| 基态能量（既有与新增格点） | 是 | 是 | 否（不进入 $\delta\theta$ 分子） | 不满足可引力 |
| 缺陷能差 | 否（局域聚团） | 否（物质型 $\propto a^{-3}$） | 是 | 不满足光滑与不稀释 |
| 份额重排（均匀形态） | 是 | 待定 | 否（均匀偏置无梯度） | 不满足可引力 |
| 均匀场型（假设新增） | 是 | 是 | 否（无梯度） | 不满足可引力 |

互斥链：可引力要求 $\delta\theta$ 有梯度，故非均匀，与光滑冲突；光滑且不稀释则无梯度，与可引力冲突。**三条要求在源项语言内没有共同的能量种类，研究项一否证。**

## 三、研究项二（稳态型）核对

**源项版**（以恒定速率均匀产生带负压的有效流体，进 $T_{\mu\nu}$）：均匀场型无梯度，撞「均匀偏置不产生曲率」同一堵墙，否证。

**几何项版**：负压加速在标准物理里由背景方程实现（$\ddot a/a = -\frac{4\pi G}{3}(\rho + 3p)$），$\Lambda$ 位于方程的几何侧。这与 2026-09-21 裁定的「$\Lambda$ 作输入」是同一条登记，不构成新的机制来源。另有一条恒等限制：由格距绝对性得 $p = 3Ht_P$（其三），格点创生与膨胀是同一关系的两种写法，不能从前者独立读出 $\Lambda$。

**判定**：源项版否证；几何项版归入既有裁定，无新增内容。

$\Lambda$ 的输入地位加固：三条源项化路径（缺陷补充、基态能量、均匀场）全部判负；「框架无平滑常量引力源」的论证从一条理由扩为分类穷举。剩余登记全部保留给另案：长期项（均匀能量的引力耦合压制，一石二鸟）、P4-21（膨胀史十量级）、P4-23①（组分比例）与 P4-23③（状态方程窗口）。
