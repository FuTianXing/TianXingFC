## 一、问题定义

任意子（anyons）是 2+1 维材料中的准粒子，三特征：分数电荷（e/3、e/5）、分数统计（交换相位 e^{iθ}，θ 任意）、由模张量范畴分类（拓扑序）。体系此前的缺口：绕数整数性与 π 扭转二分只有两种统计，无任意相位因子；融合范畴无元相子对应。

## 二、核心构造：多圆纠缠缺陷

### 2.1 粒子 = 多圆纠缠缺陷

元相子体系的粒子 = 缺陷结构（满周闭合环，注释23）。推广：粒子可以是 **k 圆纠缠缺陷**，即 k 个元相子圆以固定相对相位锁定形成的结构：

- k = 1：单圆缺陷（U(1)，电磁侧）
- k = 2：双圆纠缠缺陷（SU(2) 双圆四元数纠缠，弱力侧）
- k = 3：三圆 120° 纠缠缺陷（SU(3)，强力侧，色禁闭）

k 圆缺陷的旋转对称性：三圆以 120°（2π/3）相位差锁定（知识库定理 6）。

### 2.2 分数电荷 = 多圆纠缠中单圆缺陷的 U(1) 分量

三圆 120° 纠缠中，整体 U(1) 相位 = 三个圆的相位和。若缺陷只在其中一个圆上局域化（单色缺陷），其携带的 U(1) 绕数 = 总绕数的 1/3：

$$
q = \frac{n}{3}, \qquad n \in \mathbb{Z}
$$

分数电荷 e/3 由此涌现：三圆纠缠结构的 U(1) 分量。这与 SU(3) 表示论一致（三重态的 U(1) 超荷 = 1/3 的整数倍，标准结果），元相子给出几何解释：三个圆分担整体相位，单圆缺陷携带 1/3。**这是《任意子的安放》遗留 2 的具体化。**

### 2.3 分数统计 = 缺陷交换时圆间相对相位的缠绕

两个缺陷交换 = 世界线编织。编织相位来自粒子内部相位结构的相对转动：

**交换一次 = 内部圆结构相对缠绕一次。** 若粒子内部是单圆（连续旋转对称），缠绕等价于相对旋转，给出 ±1（费米/玻色，由 π 扭转决定）；若粒子内部是 n 圆 2π/n 锁定结构，缠绕必须经过锁定角度，累积相位：

$$
\theta_{\text{stat}} = \frac{2\pi}{n} \times \text{（编织圈数）}, \qquad e^{i\theta_{\text{stat}}} = e^{i2\pi/n}
$$

**n 圆纠缠给出 1/n 分数统计**：三圆 120° 纠缠 → 统计角 2π/3 的任意子。此构造与分数电荷 1/3 完全平行：**同一个结构（三圆 120° 纠缠）同时给出分数电荷与分数统计**，二者同源，正如弦网模型中二者同源于融合范畴，但元相子给出几何载体（圆的锁定角度 = 120°）。

### 2.4 维度条件：为什么任意子只在 2+1 维材料中

**任意子的存在 = 晶格维数的几何后果**：

- 3+1 维真空晶格：两根缺陷世界线可以互相绕开（第三个空间维）→ 交换只有 ±1（费米/玻色）
- 2+1 维材料晶格：世界线被限制在平面内，不能互相穿过 → 必须编织 → 任意相位

材料 = 元相海的准二维子结构（注释24：材料是元相海中的有序子结构）。任意子 = 2+1 维格点阵中缺陷交换的几何必然。**体系不需要额外机制解释任意子的存在：低维晶格中世界线拓扑自动给出。**

### 2.5 拓扑序分类 = 多圆编织-融合代数

融合范畴的元相子对应：

| 范畴结构 | 元相子对应 |
| --- | --- |
| object（准粒子） | k 圆纠缠缺陷（k = 1, 2, 3, ...） |
| 融合规则 | 缺陷合并：k1 圆 ⊕ k2 圆 → \|k1-k2\|, ..., k1+k2 圆（角动量加法类比） |
| 编织（R 矩阵） | 缺陷交换时圆间相对相位缠绕（2π/n 锁定） |
| F 矩阵（6j） | 多圆相位重排的相容性（三圆 120° 锁定的重排恒等式） |
| 量子维度 d_a | 纠缠结构的配分函数（待定） |
| 拓扑自旋 θ_a | 自转与公转的分数螺距关系（螺旋几何） |

融合规则与角动量加法平行（SU(2) 的 Clebsch-Gordan 结构在双圆纠缠中的对应已在弱力方案中确立），编织由锁定角度给出。**融合范畴在元相子语言中的对应物 = 多圆纠缠系统的编织-融合代数。**

## 六、R 矩阵的 Chern-Simons 对齐（遗留 a 推进，2026-08-16 二次攻坚）

### 6.1 推导框架

编织相位的最严格推导路径：三圆纠缠给出 U(1) 规范结构（电磁侧，知识库定理 6）。在 2+1 维中，规范场的动力学可由 Chern-Simons 项描述：

$$
S_{\text{CS}} = \frac{k}{4\pi}\int A \wedge dA
$$

Chern-Simons 项给带电粒子统计角的标准结果（Witten、Fradkin 等，严格）：

$$
\theta = \frac{\pi m^2}{k}, \qquad q = \frac{m}{k} \quad (m \in \mathbb{Z})
$$

### 6.2 元相子对应

**三圆 120° 纠缠 ↔ U(1)_k Chern-Simons，k = 3**（k = 2π/θ_lock = 2π/(2π/3) = 3，锁定角度直接给出 Chern-Simons 级别）。单圆缺陷（携带 1/3 电荷，m = 1）：

$$
q = \frac{1}{3}, \qquad \theta = \frac{\pi}{3} \quad (\text{交换一次}), \qquad h = \frac{\theta}{2\pi} = \frac{1}{6} \quad (\text{共形权})
$$

三圆缺陷（m = 2）：q = 2/3，θ = 4π/3 ≡ -2π/3（与电荷 -1/3 粒子配对）。

### 6.3 自洽性验证

- 交换两次（编织一圈）：e^{i2θ} = e^{i2π/3}，即三圆锁定角度的整数倍，回到锁定结构的对称性
- 融合规则：1/3 ⊕ (-1/3) = 0（粒子 + 反粒子湮灭，三圆矢量和为零）
- 与色禁闭一致：单圆缺陷（单色）不能在体内独立存在（见第八节）

## 七、色禁闭 = 拓扑全息原理（遗留 d 推进）

### 7.1 对应

拓扑全息原理（体由边界决定）在元相子语言中的自然实现：**色禁闭 = 体内无单色激发**。

- 三圆 120° 锁定（色单态）：体内只有锁定结构（白色）
- 单圆缺陷（单色）：不能在体内独立存在（分离任一圆破坏几何对称导致能量线性增长，知识库色禁闭几何解释）
- **单色只能在边界作为边界激发存在**（开放色荷端点）

### 7.2 推论

拓扑全息 = 色禁闭的必然推论：体内只有锁定结构（决定体的全部内容 = 锁定的三圆结构），任何未锁定（单色）自由度只能存在于边界。这与 QCD 禁闭的体边对应一致，且比弦网模型的"边界决定体"更具体：**边界自由度 = 被禁闭在体内的单色缺陷的逃逸口**。
