## 一、问题的表述

低能极限下体系精确重现 $\omega = c|\mathbf{k}|$（光速涌现），但精确色散关系并非线性。波在离散格点上传播受布里渊区约束，色散是格点波长的周期函数，线性关系只是其在长波端的极限。于是必然存在偏离线性的修正项，其首阶形态、幂次标度与方向依赖全部由格点几何锁死。本注记把这一链条完整写出，作为"洛伦兹破坏首阶项从哪来"的标准答案。

## 二、第一步：格点上的精确色散关系

本体哈密顿线性化（公理 4，保留到二次项）为

$$\mathcal{H}_{\text{lin}} = \sum_n\frac{\hbar}{2\omega_P}\dot{\theta}_n^2 + \frac{\hbar K_0}{2}\sum_{\langle nm\rangle}(\theta_n - \theta_m)^2$$

耦合刚度 $K_0 = \bar t_P c^2/l_P^2$ 由光速几何恒等式固定，无自由参数。对平面波 $\theta_n = A\,e^{i(\mathbf{k}\cdot\mathbf{x}_n - \omega t)}$ 写出运动方程，最近邻求和经三角恒等式化为

$$\sum_{m\in\text{NN}}(\theta_n - \theta_m) = 2\sum_{a=x,y,z}\big(1 - \cos k_a l_P\big)\theta_n$$

得精确色散

$$\omega^2(\mathbf{k}) = \frac{4}{t_P^2}\sum_a \sin^2\frac{k_a l_P}{2}$$

要点：这不是近似式，是离散格点耦合振子的严格本征值关系。连续波动方程的 $\omega = ck$ 在这里只是 $k \to 0$ 极限，有限 $k$ 处二者必然分岔，修正项的存在性由此一步确立。

## 三、第二步：修正项的泰勒出身

对 $\sin^2 x = x^2 - x^4/3 + \cdots$ 展开得

$$\omega^2(\mathbf{k}) = c^2 k^2 - \frac{c^2 l_P^2}{12}\sum_a k_a^4 + \mathcal{O}(k^6)$$

对频率本身的首阶相对修正为

$$\frac{\delta\omega}{\omega}\bigg|_{\text{LV}} = -\frac{l_P^2}{24}\cdot\frac{\sum_a k_a^4}{k^2}$$

修正项的全部内容就是正弦函数与抛物线在有限宗量处的偏离，无任何附加假设。

## 四、第三步：为什么幂次是 $(E/E_P)^2$

首阶相对修正取平方标度，由三重对称性结构共同锁定。

其一，奇次幂被反演对称杀光。精确色散是 $\cos(k_a l_P)$ 的多项式，偶函数性质使展开只含 $k$ 的偶次幂，物理对应 $k \to -k$ 不变（传播方向反演对称），故修正从四阶开始，无三阶项。

其二，相对修正降两次幂。首个修正项 $k^4$ 除以领头项 $k^2$ 得相对修正 $\propto k^2 l_P^2$。代换 $l_P k = ct_P\,k = E/E_P$（用 $E = \hbar ck$、$E_P = \hbar/t_P$）给出

$$\frac{\delta\omega}{\omega} \sim -\frac{1}{24}\Big(\frac{E}{E_P}\Big)^2$$

其三，一次幂修正无位置可放。洛伦兹不变色散 $\omega^2 = c^2k^2 + \omega_0^2$ 的首个可写破坏项在有效场论语言中是质量维度 4 算子 $\xi^{(4)}_{abcd}k^ak^bk^ck^d$（SME 框架形态），其系数在本框架被几何固定为 $l_P^2/24$ 量级，无自由参数。

方向依赖同样被锁死：立方晶格破坏旋转对称、残留立方对称，$\sum_a k_a^4/k^2$ 沿 [100]/[110]/[111] 分别给出 $-\frac{1}{24}$、$-\frac{1}{48}$、$-\frac{1}{72}$ 倍的 $(E/E_P)^2$，各向异性比值 $6:3:2$。修正可分解为各向同性部分 $\frac{3}{5}k^4$（球面平均非零）与立方各向异性部分（球面平均为零）。这一指纹是本框架独有的可检验预言：若观测到普朗克抑制水平的洛伦兹破坏，其形态应为 $(E/E_P)^2$ 标度、立方方向依赖、系数无自由参数。

## 五、第四步：物质模式的修正与能隙

加入异类耦合 $\kappa_\phi$ 后正交对角化，三类相位分解为整体相位 $\Phi$ 与两个相位差模式 $\delta_1,\delta_2$，色散为

$$\omega^2(\mathbf{k}) = \frac{4}{t_P^2}\sum_a\sin^2\frac{k_a l_P}{2} + 3\omega_P\kappa_\phi$$

整体相位保持无隙（光的候选），相位差模式获得能隙 $\omega_0 = \sqrt{3\omega_P\kappa_\phi}$，即静止质量 $m = \hbar\omega_0/c^2$。群速度

$$v_g = \frac{c^2k}{\sqrt{c^2k^2 + \omega_0^2}} < c$$

物质模式恒在光锥内传播，因果边界成立。这正是慢-弱同根的数学形态：同一个 $\omega_0/\omega_P$ 比值既压低群速度（费米子慢），又压低每拍写入幅度 $\delta\theta = m/m_P$（引力弱），见[[元相子理论的时空观：体系对时空的完整认识]]§7。

kink 侧同构：转换波在 FK/sine-Gordon 链上的色散为 $E^2 = E_{rest}^2 + c_s^2P^2$ 加正号 $v^4$ 修正，数值上 SG 拟合残差比牛顿形式好 20-100 倍，修正随 kink 宽度 $\ell$ 增大单调消失，收敛比符合格点效应 $\mathcal{O}((a/\ell)^2)$ 衰减（《注记-相对论色散完整验证：动量扇区与洛伦兹不变量》；[[碰撞写入标架几何：引力场的碰撞写入与费米子的转换波运动]]§4.3）。两侧一致表明相对论结构是格点波系统的长波性质，修正项是同一离散性的短波残余。

## 六、第五步：实验地位

修正量级即实验地位：$E = 1$ eV 光子的相对修正 $\sim 10^{-56}$，现有实验不可见；接近 $\mathcal{O}(10^{-2})$ 需能量逼近普朗克标度。故该项不与任何现有实验冲突，地位为体系给出的首阶洛伦兹破坏预言（无自由参数、普朗克压低、可证伪）。其缺失只压低"时空在普朗克尺度为简单立方格点"这一具体实现，不动摇修正项的数学出身：只要时空是任何离散结构上的波，$(ka)^2$ 量级的对称性约束修正在原理上存在。
