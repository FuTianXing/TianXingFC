## 十、v2 评审：复振幅正交分解与一般态温度（2026-09-08）

**评审对象**：方案注记第十节 v2 修订（等相干平衡公设撤销，代之以一般态温度与等分配平衡）。v2 是对本评审两点异议的实质回应：异议一（定义域收窄）与异议二（公设自由度为 2）均成立，v2 以复振幅正交分解重构。

**数值核验**：重跑 `_tools/explore_complementary_temperature2.py`（四百万采样）全部通过：运动学定理 $p/w \to 2$（$\sigma = 0.02$ 给 1.9945、$\sigma = 0.2$ 给 1.7537 为小涨落边界）、三读出合一（$\sigma \leq 0.1$ 相符）、各向异性独立性（径向/切向各自精确恢复）、复合相干双重计入 $1-\xi_2 = 2(1-\xi)$ 确认。代数独立复核：$1-\eta = \langle b^2\rangle/(2\bar P^2)$、$1-\xi = \langle a^2\rangle/\bar P^2$、$E_w = \hbar\omega_P(1-\eta)$、$E_p = \frac{1}{2}\hbar\omega_P(1-\xi)$、三读出合一（$k_BT = E = 2\hbar\omega_P(1-\eta) = \hbar\omega_P(1-\xi)$ 平衡下）、熵-能量会合 $dS/dE = 1/(k_BT)$，全部自洽。

### 10.1 两点异议的解决（核验）

1. 异议一（定义域收窄）：实质解决。一般态温度 $k_BT = \hbar\omega_P[(1-\eta) + \frac{1}{2}(1-\xi)]$ 对任意锁定附近态有定义，无平衡公设；原定义成为粒侧冻结极限（$\xi = 1$），定义域从收窄恢复为扩大。
2. 异议二（公设自由度 2）：实质收敛。矩比 $\xi$ 降格为径向无序度的导出量，等分配平衡、$2:1$ 比值、$\frac{1}{2}$ 系数全部成为推导结论；结构公设收敛为一个（各向同性复弹簧 + $O(1)$ 归一化），其根据为"波粒两面无刚度特权"（哲学依据，刚度比仍待作者裁决，属一个待裁决的结构公设而非零公设）。

### 10.2 新引入的三个需盯点

1. **端点不自洽（最重要）**：$\eta = 0$、$\xi = 0$（双侧完全无序）在一般式给出 $E = 1.5\hbar\omega_P$（$1.5T_P$），突破粒侧读出上限 $T_P$。已固化推论一"相位完全随机 = $T_P$"在 v2 中只能靠粒侧冻结极限（$\xi = 1$）保住，而"相位随机 + 粒侧定居"是调谐态而非自然组合。10.5 列为开放项（"外推不可信"），但 $\eta = 0, \xi = 0$ 是定义直接赋值处而非外推；上限论证依赖粒侧读出，一般式与粒侧读出在端点不再合一，须正面回答。
2. **与已固化内容的冲突**：2026-09-08 固化含定义系数 1（7.7 裁决）与锚点 $1-\eta = 1.9\times10^{-32}$；v2 一般式取代系数 1、锚点重指派（$1-\xi = 1.9\times10^{-32}$、$1-\eta = 9.6\times10^{-33}$，波侧减半）。若接受 v2 需同步注记头部定案、P4-17、温度攻坚成果总览三处登记。建议表述为"一般化"而非"取代"（粒侧冻结极限下 7.7 全部结论保持），但锚点减半是实质变更。
3. **平衡态 $\eta \geq 1/2$ 新约束**：各向同性平衡下 $T \leq T_P$ 推出 $1-\eta \leq 1/2$，$\eta \to 0$ 不再是平衡态；与 7.6 图景（$\eta \to 0$ 可达 $T_P$）冲突。与端点问题同源。

### 10.3 判定与建议

v2 结构更优，数学扎实、数值过硬，建议接受为定义的一般化形式；接受时须同步处理：端点语义（正面回答 $\eta = 0, \xi = 0$ 的温度）、已固化登记同步（锚点重指派三处）、平衡约束展开。裁决顺序建议：① v2 一般式取代 vs 保留冻结极限；② 锚点重指派同步；③ 端点攻坚列入 P4-25 高温过渡区；④ 刚度比（各向同性）作为唯一结构公设单独裁决。本评审注记第五节（等相干与能量均分等价）随 v1 等相干平衡公设撤销而降格为 v1 历史记录。

**比较结论：v3 结构上优于方案 A（相位无序度载体）**，四个决定性理由：

1. 精确实现"不可或缺 ≠ 各半"裁决：$|\langle z\rangle|$ 非零要求相位相干与振幅相干同时成立，一次介入两侧，无加性结构、无 $E_w = E_p$；

### 11.1 10.9 vs v3 端点案裁决（2026-09-08）

**分歧点裁决**。两案对完全混乱端与定居率端的温度归属给出不同判定，逐一裁决：

1. **完全混乱端（$\eta = 0, \xi = 0$）**：10.9 判不可达（线性式 $1.5E_P$ 超预算）；v3 给 $T = T_P$（$\langle z\rangle = 0 \Rightarrow D = 1$，可达）。**v3 正确**：均匀相位 + 完全离域是合法分布，最混乱的态应恰为最热（$T_P$），10.9 的"不可达"是线性式越界的数学后果而非物理事实。
2. **定居率端（相位锁定 + $q \to 0$）**：10.9 线性式给 $T \to \frac{1}{2}T_P$；v3 给 $T \to T_P$（$D = 1-\sqrt q \to 1$）。**v3 正确**：粒侧完全离域 = 粒侧最大无序，温度应饱和于上限；$\frac{1}{2}T_P$ 是线性式欠估计伪值（数值：线性式 $\to (1-q)/2$，v3 $\to 1-\sqrt q$）。"实存消失 = 最热"（Hagedorn 型）物理图像自洽。

**方法论裁决**：定理（柯西-施瓦茨）替代公设（预算约束 + 不可达排除），定义域无洞，无争议。

**饱和面物理意义**：10.9 饱和面 $w + \frac{1}{2}p = 1$ 是线性式系数的人为构造；v3 饱和面 $\langle z\rangle = 0$（宏观相干场消失）有独立物理意义，且是"不可或缺"的直接体现（两侧相干同时消失）。10.9 的正确直觉（能量-温度分离、饱和结构真实）由 v3 的 Hagedorn 型 $E(D)$ 保留。

**预算约束的降级**：$E \leq E_P$ 保留为与温度定义无关的独立物理命题（单元相子能量上限）候选，不承担温度定义结构；其动力学证据留待后续。

**结论**：10.9 不再作为温度载体候选；v3 主式 + A 冻结族保留 + v2 二阶截断的登记建议不变。
