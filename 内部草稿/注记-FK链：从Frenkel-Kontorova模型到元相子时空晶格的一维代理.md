## 一、FK 链是什么

FK 链（Frenkel-Kontorova 链）由 Frenkel 与 Kontorova 于 1938 年为研究晶体位错提出，物理原型是吸附在晶体表面的一层原子。模型只有两个成分：相邻粒子之间的弹性耦合，以及粒子所在的周期性基底势。

体系内使用的标准形式为

$$E[u] = \sum_n \frac{k}{2}\left(u_{n+1}-u_n-1\right)^2 + \sum_n K\left(1-\cos 2\pi u_n\right).$$

第一项是弹簧项，自然长度取一个周期（相邻格点的相位差为 1）；第二项是周期势，周期为 1。连续极限称为 sine-Gordon 模型，离散形式称为离散 sine-Gordon 方程，体系内常并称 FK/SG 链。

模型的失配由弹簧自然间距与基底势周期之比决定。两者不严格匹配时，矛盾无法在每一处都满足，全部失配集中到一处释放，形成 kink（扭结）。kink 的拓扑荷为绕数 1，是模型中最小的定域拓扑缺陷。

kink 剖面在体系内取扭结形式

$$p_x(n) = n + \frac{2}{\pi}\arctan\, e^{(n-x)/\ell},\qquad \ell = \left(2\pi\sqrt{K/k}\right)^{-1},$$

其中 $\ell$ 为核宽。该剖面带缠绕 $W = 1$，是单粒子的定域本相。

## 二、与元相子时空晶格的逐项对应

对应关系的根据是：时空晶格由"满周闭合沿法线轴平移一层"逐层累积生成，层与层之间由键弹性耦合，格点内由锁定势约束。FK 链的弹簧项与周期势正是这两条耦合的最低阶形式，链的格点则取法线轴层位。

| FK 链要素 | 数学形式 | 元相子时空晶格中的对应物 |
|---|---|---|
| 格点索引 $n$ | 整数 | 法线轴层位 $\|n\rangle$，距离归粒 $x^a = l_P n^a$ |
| 位形 $u_n$ | 实数场 | 第 $n$ 层元相子的提升相位（相位展开到实轴，可读作以层为单位的轴向位置）：小数部分 = $S^1$ 相位角，整数部分 = 已叠层数 |
| 弹簧项 | $\frac{k}{2}(u_{n+1}-u_n-1)^2$ | 键弹性 $\kappa_\parallel$：法线轴高度差（非紧致，自然长度为一个周期） |
| 周期势 | $K(1-\cos 2\pi u_n)$ | 格点内锁定 $\kappa_\varphi$：锚核阱，把元相子钉在格点内 |
| kink | $\Delta u$ 由 1 过渡到 2 | 复合位错粒子：电荷核 + 锚核 + 包层 |
| 缠绕 $W$ | $u_{N-1}-u_0-(N-1)$ | 绕数 = 粒子数 = 电荷（超选择荷） |

两点补充。其一，$u$ 变量是 $S^1\times\mathbb{R}$ 的实现：整数部分对应沿法线轴的层数，小数部分对应相位角，见 [[注记-复合模型：粒子 = 均匀缠绕背景上的 FK kink 位错与宽度参数区]] 第五节。

其二，弹簧项取平方型（非紧致）是宽度机制的关键。紧致 cos 弹性下位错塌缩为单键尖锐位错（$\ell^* = 1.00$ 恒等，与参数比无关），宽度窗口为空；平方弹性下位错展宽，$K/k \le 0.02$ 时 $\ell^* \ge 2$ 落入洛伦兹色散窗口。见 [[注记-弹性身份裁决：紧致cos与螺旋平方弹性下的位错窗口]]。

## 三、量子力学侧的用法

**其一，粒子本相与超选择荷。** kink 的缠绕数就是粒子数，也就是电荷，整数量子化由拓扑直接保证。链的边界条件 $u_{N-1} = u_0 + N$（缠绕守恒边界）从拓扑上禁锢 kink，固定提升边界会把 kink 钉死，这是转换波得以存在与运动的前提条件，见 [[注记-转换波运动学验证：方向甲三判据的数值检验]]。

**其二，概率权重与 Born 规则。** 局域序参量 $w_n$ 是窗口内的相位平均，其亏空 $\delta_n = 1-|w_n|$ 度量该处被转移走的局域相干。层位份额 $W_n$ 由此定义，位置概率的承载者从人数份额置换为相干份额，并端到端恢复 Born 位置频率，见 [[注记-层位份额语义的最小验证：相干份额作为位置概率]]。进一步引入线性泛函实通道亏空 $1-\mathrm{Re}\,w_n$，可证 Born 权重被线性泛函精确承载，见 [[注记-两瓣叠加态单场承载的最小验证：份额折叠、挫折弦与相位通道]]。

**其三，叠加与测量。** 叠加态的场侧载体由三类对象对照确定（经典分瓣、叠加像、双 kink 系综像），17 项判据全过，载体指认为相干结构，见 [[叠加态的场侧画像：单一场承载、份额折叠与相位通道]]。U 过程与 R 过程的区分由链上的碰撞协议给出：无探测器时可见度保持，加逐键探测器时衰减至 $4\times10^{-6}$，衰减唯一来源是跨层记录，见 [[注记-相互作用分层判据的最小验证：两协议可见度与生死闸门]]。

## 四、引力侧的用法

**其一，缺陷作为源。** 缺陷的绑定能等于质量，是引力源的候选。自撑阱验证在 $\phi^4$ kink 的自洽结构上给出关键结果：自洽恒等式 $V'' = 4k^2 - 6k^2\operatorname{sech}^2(kx)$ 使定域阱与常数质量项同源于一个参数，四个响应通道的系数自动连线，$\kappa = 1$ 自动成立且与阱宽、格距无关；三维径向推广同样成立（$\mathrm{d}\ln/\mathrm{d}\ln k = 2.0000$）。见 [[注记-自撑阱均匀标度的最小验证：kink自洽结构下的响应系数]] 与 [[注记-自撑阱三维径向推广的最小验证：四通道同齐次度]]。

**其二，记录场写入与传导。** 每普朗克拍，缺陷世界线上的碰撞事件写入一份幅度 $\delta\theta = m/m_P$ 的标架倾斜，邻居通过碰撞接力传导，稳态即离散泊松方程的格林函数。

一维写入动力学的相对误差为 $1.8\times10^{-11}$，三维远场 $1/r$ 系数偏差 $1.9\times10^{-4}$，$4\pi$ 由立体角换算自动出现，格面通量恒等源强到机器精度，见 [[注记-碰撞写入标架联络的最小验证]]。

时间向补全（3+1 雏形）给出牛顿 sector：记录的空间二阶差分给出潮汐型曲率，源外无迹，$E_{xx}:E_{yy}:E_{zz} = 2:-1:-1$ 逐位成立，见 [[注记-3+1雏形验证：时间向写入铰链补全牛顿极限]]。

**其三，运动与惯性。** kink 的等效质量、惯性、测地响应与速度上限四判据全部闭合，相对论色散 $E^2 = m^2c_s^4 + p^2c_s^2$ 在能量、动量、不变量三层面成立，见 [[注记-相对论色散完整验证：动量扇区与洛伦兹不变量]] 与 [[注记-测地响应线性验证与质量对齐：2.7倍差异的分解]]。

## 六、差异与代理适用性

FK 链与元相子时空晶格在结构上高度对应，但两者存在多处差异。这些差异是否导致代理错误需要逐项判定：已实证两项确实导致失效，一项属口径敏感，一项为显式标注的近似，一项经作者裁决关闭（场变量打包），一项仍属遗留（背景序），另有一项属叙述层面的失真风险。

### 6.1 差异分类

| 差异 | 是否导致代理错误 | 依据与处置 |
|---|---|---|
| 维度：一维与三维 | 是，已实证 | 环的裁决实验：光滑场涡旋环在三维塌缩、绕数流失；一维 kink 的稳定不外推三维 |
| 守恒机制：经典拓扑与量子保护 | 是，已实证 | 经典层绕数在弛豫中流失；守恒须搬进量子层（toric code，$[H,W]=0$） |
| 弹性形式：平方与紧致 cos | 是，口径敏感 | 紧致 cos 下位错塌缩为单键（$\ell^*=1.00$）、宽度窗口为空；原始形式经作者裁定为螺旋高度差 |
| 场性质：经典标量与量子态 | 是，已标注近似 | 叠加像的对角通道为 $O(s_0(D))$ 近似，论文已显式声明 |
| 场变量：实标量与 $S^1\times\mathbb{Z}$ | 否，已裁决 | 底层晶格刚性使相位与层数同步，不存在独立变化，打包在底层精确（2026-09-14 作者裁决） |
| 背景序：均匀缠绕与交错序 | 未判定，遗留 | 交错序 $\pi$ 与铁磁 $2\pi$ 的 cos 对应未建立 |
| 引力侧对象：记录场与相位场 | 是，表述风险 | 引力侧共享工具链而非同一泛函 |

### 6.2 已实证的代理失效

**维度差异。** 一维 kink 的稳定来自 $\pi_1(S^1)=\mathbb{Z}$ 与一维能量的尺度行为；三维的对应物是涡旋环，能量含线张力（正比于 $R$）与曲率项（反比于 $R$）的竞争。环的裁决实验在体系完整哈密顿量下扫描，驻留极小不存在（梯度流、惯性阻尼、多组 $R_c$ 全部塌缩到精确真空），滑移垒不存在，绕数在弛豫初始段流失。一维的安稳由此不能外推三维，三维形态列为 C1 攻坚项，是 P1-33 与 P1-5 的共同前置。见 [[注记-环的裁决实验：裸模型无亚稳与绕数承载层问题]]。

**守恒机制差异。** FK 链的 kink 数守恒是经典拓扑守恒，在理想连续动力学下成立；体系要求的是电荷的绝对守恒。实测结果是经典层给不出这个守恒：环的裁决实验里绕数在数值弛豫中流失到零，扇区约束动力学在经典层给出两线裁决（局域涡量可隐藏、真扇区极小拓扑强制离域）。

处置是把绕数承载搬进量子层（toric code，$[H,W]=0$ 精确成立、基态空间投影量子数、跨扇区一阶矩阵元为零），经典层只负责载体的能量、尺寸与驻留。见 [[注记-扇区约束动力学：两种绕数的裁决与T4T5判定]]。

### 6.3 口径敏感：弹性形式

弹性形式决定宽度窗口的存亡。FK 链的标准写法用平方弹性（非紧致），与作者裁定后的体系原始形式（螺旋高度差，非紧致）一致；体系哈密顿量早先的 cos 书写是紧致的，两种书写在宽度问题上给出相反答案。

紧致 cos 下位错塌缩为单键尖锐位错（$\ell^* = 1.00$ 恒等、与参数比无关，弹性项对 $\Delta u = 2$ 完全免费），宽度窗口为空；平方弹性下位错展宽，$K/k \le 0.02$ 时 $\ell^* \ge 2$ 落窗。弹性身份裁决实验以同 PN、同边界、同初条件、同宽度定义并排测量，确认宽度机制完全寄生在非紧致弹性上。见 [[注记-弹性身份裁决：紧致cos与螺旋平方弹性下的位错窗口]]。基准表述的调整由作者主导。

### 6.4 已标注的近似：经典场与量子态

叠加像的对角通道被论证为真实叠加态局域序参量的 $O(s_0(D))$ 近似，跨项由干涉禁闭压制，误差随两瓣间距指数消退。该近似在论文里写明为条件性命题并附条件（分离瓣极限、支撑不交），属已披露而非隐含。见 [[叠加态的场侧画像：单一场承载、份额折叠与相位通道]]。

### 6.5 遗留缺口

其一，场变量的打包（2026-09-14 作者裁决关闭）。FK 链的 $u$ 是单一实标量，体系物侧自由度是相位 $S^1$ 与层数 $\mathbb{Z}$ 两个。作者指出：底层普朗克时空中晶格刚性、普朗克频率不变、跃迁距离不变、满周闭合不变，四者咬合使相位与层数必然同步，不存在两者的独立变化，打包在底层是精确的。

该裁决与晶格刚性原理（2026-09-11 作者确认：格距全程保持 $l_P$、步长恒定、只重排格点归属）一致。关闭范围限定在经典层；$u$ 量子化后与 P4-37 双通道态空间 $L^2(S^1)\otimes\ell^2(\mathbb{Z})$ 的关系归 P3-10/11 下游，属另一问题。

其二，背景序。FK 链的背景是均匀缠绕（每键 $\Delta u = 1$，铁磁型 $2\pi$ 背景），体系的粒子坐落在交错序背景上。cos 势在交错序 $\pi$ 附近与铁磁 $2\pi$ 背景的对应关系未建立，见 [[注记-复合模型：粒子 = 均匀缠绕背景上的 FK kink 位错与宽度参数区]] 第六节。

### 6.6 表述风险：工具共享与泛函同一

引力侧共享的是工具链，不是同一个泛函。引力记录场是标架倾斜记录（每拍写入 $\delta\theta = m/m_P$，邻居碰撞接力传导），稳态由扩散型方程给出；源侧的自撑阱用的是 $\phi^4$ kink 的自洽结构。三者只在"格点加局域耦合加缺陷作源"这一层共享工具，在泛函层各不相同。把三者统称"FK 链模拟引力"会掩盖这个分层，属叙述层面的失真。

### 6.7 处置原则与剩余边界

链上结论一律标注"模型内判据级"，模型外的普适性未声明。凡依赖非紧致弹性、经典拓扑或一维几何的结论都写明条件，不外推的场合单列遗留。残余风险落在使用习惯上：把判据级读成定理级，或把工具共享说成泛函同一。

引力侧未闭合项：张量桥分段 (c)(d)、$T_{\mu\nu}$ 的微观分解与强场非线性仍待攻（P1-5 与 P1-34a）。
