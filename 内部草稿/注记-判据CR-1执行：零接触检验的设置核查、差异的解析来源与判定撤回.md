## 一、判据内容

判据 CR-1（列于 [[黑洞线攻坚计划：坍缩机制重定位与强场终态]] BH3-3）：核查零接触那次数值测试的倾斜取值与场强。若在倾斜约为零或极弱场下测得严格零，则高阶耦合未被排除；若在有限倾斜下仍测得严格零，则高阶项也被排除。

## 二、检验的定位与设置

零接触数值事实的出处是 [[碰撞写入标架几何：引力场的碰撞写入与费米子的转换波运动]]§2.1。该论文的参考文献 [6] 指向四篇验证注记，逐篇排查后，检验的实现落在 `验证脚本/minimal_verification_derrick_3d.py` 的第一部分（脚本标题「摆程层：σ 锁定区的能量学可见性」）。

设置如下。格点取 $N = 12$ 立方，交错真空基准相位 $\text{base} = \pi(i + j + k)$，相邻 σ 反号（$\sigma_{\text{vac}} = 1 - 2\cdot\text{stagger}$）；中心半径 $R_d = 2$ 的球内取 $\sigma = +1$ 恒定作为锁定滴，滴外维持真空模式。拍内以线性参数化扫掠相位

$$\theta = \text{base} + \sigma \cdot 2\pi s,$$

能量取 $E = J\sum\cos(\Delta\theta)$，$J = 1$。四组配置分别取 $s \in \{0,\ 0.25,\ 0.5,\ 0.75\}$，其中 $s = 0.5$ 与 $s = 0.75$ 用反号扫掠的真空模式。

## 三、实测读数与差异的解析来源

以系统 Python 3.13（numpy 2.4.1）复跑原脚本，第一部分输出如下。

| 时刻 | $E$(真空) | $E$(锁定滴) | 差 | 相对总能量 |
|---|---|---|---|---|
| 边界拍 $s = 0$ | $-5184.0$ | $-5184.0$ | $0$ | $0$ |
| 拍中 $s = 0.25$ | $+5184.0$ | $+5016.0$ | $-168$ | $3.2\%$ |
| 拍中 $s = 0.5$ | $-5184.0$ | $-5184.0$ | $0$ | $0$ |
| 拍中 $s = 0.75$ | $+5184.0$ | $+4956.0$ | $-228$ | $4.4\%$ |

**这组差异可以完整解析求出，不需要任何物理假设。** 记键差 $\Delta\theta = \pi + \Delta\sigma\cdot2\pi s$，其中 $\Delta\sigma \in \{0, \pm 2\}$。于是同 σ 键的贡献恒为 $\cos\pi = -1$，异 σ 键的贡献为 $\cos(\pi \pm 4\pi s) = -\cos(4\pi s)$，故

$$E = -\#(\text{同}\sigma) - \cos(4\pi s)\cdot\#(\text{异}\sigma).$$

在 $s = 0$ 与 $s = 0.5$，$\cos(4\pi s) = 1$，同 σ 与异 σ 的贡献相同，$E$ 与 σ 配置无关，故差为零。在 $s = 0.25$ 与 $s = 0.75$，$\cos(4\pi s) = -1$，两类键的贡献相反，差为

$$\Delta E = -2\,\#(\text{滴内同}\sigma\text{键}).$$

数值核对：$s = 0.25$ 时滴内同 σ 键 $84$ 个，$-2\times84 = -168$ 与实测一致；$s = 0.75$ 时 $114$ 个，$-2\times114 = -228$ 与实测一致；真空侧同 σ 键恒为 $0$。

**所以那 $3.2\%$ 与 $4.4\%$ 的全部内容是「锁定滴把多少个异 σ 键变成了同 σ 键」，即锁定滴的几何尺寸本身。** 它是计数，不是耦合强度。

## 四、判定：原判据未被回答，初版判定撤回

三条理由。

**其一，该检验不含写入过程。** 脚本比较的是「纯真空」与「含锁定滴」两种静态配置的能量，没有写入动作，也没有反作用过程。它测的问题是「锁定区的存在是否改变层内能量」，而不是「写入是否影响摆程」。

**其二，拍内差异被解析为纯几何计数。** 初版判定建立在「拍内差异等于耦合通道迹象」这一步上，而第三节已证明该差异等于 $2\times$（滴内同 σ 键数），与写入、与耦合通道无关。这一步不成立，判定随之撤回。

**其三，该检验的参数化不构成对倾斜的扫描。** 线性相位扫掠只是遍历拍内时刻的手段，不是「改变倾斜看耦合如何变化」的实验设计。CR-1 问的是后者。

**修正后的判定：判据 CR-1 无法执行，因为它所依赖的既有检验与它的问题无关。** 初版结论「高阶耦合未被排除，候选 A 存活」撤回，代之以「本次执行未取得关于高阶耦合的任何证据」。

## 五、这次执行暴露的两点认识

**其一，零接触的精确性被加强，这对耦合重开不利。** 在碰撞时刻（$s = 0$ 与 $s = 0.5$），能量简并对全部 σ 配置成立，且可由 $\cos(4\pi s) = 1$ 解析给出，不依赖模型细节。碰撞时刻正是写入发生的时刻，所以「写入不反作用摆程」在检验范围内是精确的，谈不上近似。**耦合重开若指望「零接触只是弱场近似」这条路，本检验给出的读数不支持。**

**其二，判据 CR-1 的设计本身有缺陷。** 它假定存在一项随倾斜增长的高阶耦合、只是尚未被检出，并指望用既有检验的设置来判断。实际发现既有检验的目标与它无关，于是它既得不到支持也得不到否定。这条教训可以推广：**判据的设计必须与被检对象在同一层，否则执行的只是形式。**
