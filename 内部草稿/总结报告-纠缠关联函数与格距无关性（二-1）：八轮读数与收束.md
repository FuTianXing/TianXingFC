## 一、任务与目标

计划书对 二-1 的表述是：把纠缠度与格点距离无关性从定性陈述升级为显式函数 $f(E_{xy})$，给出「格距 $n\,l_P$ 任意增大而 $\Delta\alpha$ 不变」的定量表述，路线为扇区约束动力学的 toric code 工具链上数值先行、解析构造随后。判据草案列出 C1 至 C7 七条，其中 C3 要求输出函数形状 $C(E)$。

八轮的分工是一条链：首轮立住格距标度与显式函数的形式，解析段给出锁定场的两层来源，第三、四段把场层相关函数算到底（含系数闭式与窗口漂移预测），第五段把显式函数改写成配对相干的形式，第六段给锁定模一个稳定子层来源，第七、八段把共享分量方差拆成两项并各自给出闭式。

## 二、结论速览

其一，格距无关性成立，其精确含义是差分方差饱和（第 174 条），并在配对相干语言下写成 $C = f(E_{xy}) = 2\sigma^2(1-m)$，$m = (E - E_\infty)/(1 - E_\infty)$（第 183 条）。函数形式不含格距，格距只进 $m$。

其二，函数形状与锁定强弱无关：三档锁定值的数据在 $(m, C/2\sigma^2)$ 平面上塌缩到直线 $1-m$（最大偏离 $4.171\times10^{-3}$）。

其三，判别式可检验：对照档的排除依据是配对相干缺少平台（大格距窗散布 $19.9\%$ 对锁定档 $1.94\%$），与相干数值本身的大小无关。

其四，锁定模有体系内来源：环面 toric code 的同调扇区标签（保护距离 $d = L = 8$、可纠权重 $3$），可观测的连续共享分量则是场层零模。

其五，共享分量方差两项都取闭式：$P = S(0)/Z + \sigma^2/(\kappa N)$（场层零模与锁定坐标涨落），两者同为 $O(1/规模)$，故平台高度随体系规模稀释。

## 六、边界与不成立范围

**模型边界。** 局域场取高斯平稳场（相关函数两点指数，源自 AR(1) 噪声驱动的漏积分响应）；锁定坐标取全环共同相位并在线性化档内工作；同步门槛用洛伦兹自然频率分布下的标准结果 $K_c = 2\gamma$。

**不成立的读法。** 其一，不得引用单一 $\xi_f$：场层是两点指数叠加，报值属窗口相关量。其二，不得把场层零模方差当作平台高度：求和规则使大格距协方差归零（第 189 条）。其三，同调标签不承担可观测的连续相位：整数倍 $2\pi$ 平移在模 $2\pi$ 读数下不可见。其四，差分方差的线性读数在包裹占比显著时失效。

**覆盖边界。** 判据 C4 的去约束对照已由补缺轮补齐（第 191 条）；三维与缺陷构型未涉及；先验纠缠到锁定耦合 $\kappa$ 的接口与任何子到滑移、通量的对应按条件性命题处理。
