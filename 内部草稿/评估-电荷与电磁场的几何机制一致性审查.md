## 一、电荷的几何机制（全面描述）

### 1.1 电荷 = 内部 U(1) 缠绕数（定理 8）

电荷是满周闭合环在内部 $U(1)$ 空间中的拓扑缠绕数。真空元相子去程扫 $+2\pi$、回程扫 $-2\pi$，净绕数为 0（真空不带电）；粒子是突破束缚折返的单旋孤子，相位闭合环单方向缠绕，绕数 $n$ 即电荷（《电荷的几何本质》§2）。

### 1.2 电荷的正负

绕数符号 = 相位缠绕方向（瞬时旋转方向，动力学量）：$+n$ 正转 = 正电荷，$-n$ 反转 = 负电荷。此方向是动力学量，与旋向 $\varepsilon$（螺旋手性，几何常数）相互独立（注释三第 8 点）。正负的物理内容由同斥异引定义（符号是约定性的，物理在相互作用）。

### 1.3 电荷的量子数

- 量子化：绕数是同伦不变量，只能取整数，半个绕数拓扑上不存在（定理 8，量子化自动）
- 守恒：绕数连续形变下不变（电荷守恒自动）
- 分数电荷：夸克 ±1/3、±2/3 来自 $SU(3)$ 三圆纠缠的 $U(1)$ 分量（纲领性主张，《电荷的几何本质》§7）
- 电荷-自旋-质量四标签：电荷 = 绕数、自旋 = π 扭转、质量 = 锁定能隙、局域性 = σ 锁定（《有质量粒子的形成》§5）

## 二、电场的几何机制

### 2.1 静态电场（《电荷的几何本质》§6）

带电粒子（绕数 n）是晶格相位场的永久拓扑扰动源。周围元相子校准对齐它，但绕数守恒禁止完全对齐，校准平衡位形即静电势：

$$\nabla^2\phi = -4\pi n\,\delta^3(\mathbf{r}), \qquad \phi = \frac{n}{r}, \qquad \mathbf{E} = -\nabla\phi$$

电势 = 相对相位畸变场，电场 = 平衡位形梯度。同斥异引从校准代价最小化涌现。

### 2.2 动态电场（《电磁场的元相子几何》§3）

电场 = 联络的时间-空间曲率：

$$E_a = F_{a0} = \partial_a A_0 - \partial_0 A_a$$

变化磁场产生电场 = Bianchi 恒等式（曲率一致性条件，混合偏导可交换，严格）。

## 三、磁场的几何机制

### 3.1 磁场 = 空间-空间曲率（《电磁场的元相子几何》§3）

$$B_a = \frac{1}{2}\epsilon_{abc}F_{bc}$$

磁场 = 实轴方向场的空间涡旋（绕格点回路的净扭转）。

### 3.2 电流磁场（拓扑结果，独立保留）

空间绕数（涡旋线）：$\oint_C \nabla\alpha\cdot\,dl = 2\pi n$。切向场与无限长载流导线磁场同构，安培环路定律 = 绕数定理，$\nabla\cdot\mathbf{B}=0$ 自动（无磁单极）。

### 3.3 变化电场产生磁场（《电磁场的元相子几何》§6）

位移电流 = 校准重排的磁场源（感知-校正链），纲领性主张。

## 四、一致性审查

### 4.1 自洽的部分（确认无误）

1. **电荷量子化与守恒自洽**：绕数拓扑性质自动给出，与电磁场几何（曲率语言）无冲突。
2. **法拉第定律与电场定义自洽**：Bianchi 恒等式与 $E = F_{a0}$、$B = F_{bc}$ 严格一致（同一曲率的分量）。
3. **相对论统一自洽**：电场磁场 = 同一 $F_{\mu\nu}$ 的分量，洛伦兹变换自然混合，与传统物理完全兼容。
4. **正负湮灭自洽**：$+n$ 与 $-n$ 抵消，绕数账守恒（$n + (-n) = 0$），电场随源消失而恢复均匀。
5. **正交关系自洽**：E⊥B⊥k 从曲率分量与 $\omega=ck$ 严格推出。

### 4.2 难以解决的问题（真实缝隙，按严重程度排序）

**缝隙 1（最严重）：静电学与电动力学的两套语言未缝合。**
静电场 = 校准平衡位形（电势 $\phi$ = 相对相位畸变场，源 = 绕数 n）；动态电场 = 联络的曲率（$E_a = F_{a0}$）。两个电场定义来自两套语言：一个来自绕数结构对相位场的扰动，一个来自联络的曲率。它们的精确对应（$\phi$ 与 $A_0$ 的关系）未建立（《电荷的几何本质》开放问题 4）。现状：静态电学（绕数语言）与电动力学（实轴方向场语言）是两条平行轨道，尚未在数学上合并。

**缝隙 2：静磁学（磁铁）的几何机制缺失。**
磁场 = 涡旋线 = 基准方向场的空间扭转。电流磁场有拓扑对应（涡旋线 = 安培环路），但磁铁没有宏观电流，其磁场来自自旋排列（π 扭转结构的有序化）。"自旋排列如何产生基准方向场的静态扭转"未给出任何机制（2026-09-26 载体订正：扭转载体为基准方向场）。方案目前只能解释电流磁场（动态），无法解释永磁体的静态磁场（自旋磁矩）。这是传统电磁学"磁单极子对偶"之外的真实空白：源（自旋）与场（涡旋线）的耦合机制缺失。

**缝隙 3：绕数结构与实轴方向场的耦合动力学未形式化。**
电荷（绕数）如何弯曲周围的实轴方向场？《电荷的几何本质》说"校准对齐它但绕数禁止完全对齐，平衡位形即静电势"，这是机制描述，但"绕数结构 → 实轴方向场位形"的动力学方程未写出（依赖校准作用量，纲领）。

**缝隙 4：分数电荷与 U(1) 电磁场的精确关系未展开。**
夸克分数电荷（±1/3）来自三圆纠缠的 U(1) 分量，但电磁场耦合的是单圆实轴方向场（U(1)）。三圆纠缠的整体 U(1) 与电磁 U(1) 的关系（为什么色三重态携带分数电荷耦合到电磁场）未建立。

**缝隙 5：运动电荷产生磁场的动态过程依赖纲领。**
静态对应（涡旋线 = 安培环路积分）严格；动态过程（运动绕数结构如何产生空间涡旋）待建立（《电磁场的元相子几何》§6 已声明边界）。

### 4.3 潜在的概念混淆（需澄清）

**混淆候选：磁场既是"涡旋线"又是"电流"。**
方案中磁场 = 空间-空间曲率（涡旋线），电流 = 涡旋线运动。但"磁场 = 涡旋线"与"电流 = 涡旋线运动"使用同一个对象（涡旋线）的两种状态（静态存在 vs 运动）。这本身不矛盾（静态磁场 = 静止涡旋线？），但"涡旋线是磁场还是电流的载体"的表述容易混淆。澄清：涡旋线是实轴方向场的拓扑结构，其静态位形对应磁场（curl B = J 中 J = 0 时），其运动对应电流（J ≠ 0）。两者是同一结构的静/动态。

**混淆候选：静电场源（绕数 n）与电磁场源（电荷密度 ρ）。**
绕数 n 是拓扑量，ρ 是连续量。静态严格（平衡位形 ∇²φ = -4πnδ³），动态纲领（ρ 的连续性从绕数结构如何涌现）。需声明：n 是基元电荷，宏观 ρ 是 n 的分布密度。

## 五、结论

方案核心自洽：电荷（绕数拓扑）与电磁场（曲率几何）在各自层面严格成立，法拉第定律、正交关系、相对论统一无矛盾。五个真实缝隙中，最严重的是静电学与电动力学的两套语言未缝合（缝隙 1），以及静磁学（磁铁）机制缺失（缝隙 2）。这两个缝隙共同指向一个未完成的环节：绕数结构与实轴方向场之间的耦合动力学（即校准作用量）。缝隙 1-5 全部收敛于此：校准作用量一旦写出，静态/动态电场统一、电流/位移电流、运动电荷磁场、磁铁机制都从同一动力学导出。

**结论一句话**：方案无自相矛盾，但有五个未完成的缝隙，全部收敛于"校准作用量"这一个未闭合环节。
