## 一、要裁决的问题

`研究方向-P11的解决` 给出四条引理（L1 至 L4）与分层定理。P11 攻坚计划的缺口 P0 指出 L2 与 L3 存在任务重叠：L3 说的是光速不定义于介质参数（介质参数不进入传播速度），L2 说的是运动束缚态经 boost 解给出补偿。前者属「数值」一侧，后者属「不变」一侧。

裁决的形式是二选一。**结局甲**：L3 是 L2 的推论，四引理收敛为三条。**结局乙**：L3 承担独立功能，维持四条并在表述中显式写出该功能。

## 二、L3 的现行表述与证明状态

L3 原文为：光速 \(c = l_P/t_P\) 锚定在基态光子的摆程几何上，介质弹性参数（\(K_0\) 等）不进入速度；关于「光速相对介质是否变化」的提问在结构上失去对象。原文自标严格程度为条件性，依据是「接力几何 + \(K_0\) 数值不进速度已验证」。

原文给的是核对，不是证明。核对的内容是：在具体数值下 \(K_0\) 不进入速度。要升格为证明，需要给出 \(K_0\) 在结构上不进入速度的一般论证。这一般论证在体系内已经存在，只是它此前没有被接到 L3 上。

## 三、收敛的依据：两个独立事实

### 3.1 事实一，物质模式去耦引理

色散论文 §6.2 给出：二次型在 \((\Phi, \delta_1, \delta_2)\) 分解下严格块对角，无交叉项。

证明的关键一步是：最近邻弹簧项 \(\frac{\hbar K_0}{2}\sum_{\langle nm\rangle}|\boldsymbol{\theta}_n - \boldsymbol{\theta}_m|^2\) 中的空间差分算符只作用于格点指标，对内部分量指标是恒等算符；内部正交变换 \(O\) 逐格点同一地作用，故与空间差分对易，弹簧项变换后仍正比于内部单位算符。

异类项二次化后为逐格点的内部型 \(\mathrm{diag}(0, 3\hbar\kappa_\phi/2, 3\hbar\kappa_\phi/2)\)，本身块对角。故总二次型无交叉项，\(\Phi\) 扇区与 \(\delta\) 扇区严格解耦。

这条引理的分量需要说清。它是一条**精确**结果（对易是精确的，误差只出现在超出线性理论的 \(\cos\) 高阶项，属非线性范畴），且解耦的代价是零。它的直接含义是：空间传播扇区（\(\Phi\)）的动力学与内部规范扇区（\(\delta\)）严格分离。\(K_0\) 出现在空间扇区内部，它决定该扇区内部的模式结构，但不改变扇区之间的分离关系。

### 3.2 事实二，螺旋刚性与节律

`元相子几何动力学` 补充注释 04 第三条给出：速度值与耦合强度无关。论证是「传播一步的事件 = 摆程完成」，摆程历时 \(t_P\) 是公理设定的节律，摆程前进一格是圆心位移 \(l_P\)，属几何恒等式（螺旋刚性 \(z = \lambda\theta/2\pi\)）。\(c = l_P/t_P\) 直接来自几何与节律，\(K_0\) 的角色退化为「保证事件确实传递」。

把两条事实接起来：去耦引理保证空间扇区与内部扇区严格分离（\(K_0\) 不跨扇区泄漏），螺旋刚性保证传播速率由几何与节律给定（\(K_0\) 不改变这个速率）。两条合起来就是 L3 的完整证明，且证明中不含「\(K_0\) 数值恰好不进速度」这类需要逐案核对的环节。

### 3.3 结论

**L3 可由体系既有结果证明，且该证明不依赖 L2。**这一点与收敛提案的表面相反，需要说清。

L3 独立可证，收敛的理由因此需要重新表述。收敛成立的理由不是「L3 无法独立证明，只能靠 L2」，而是：**L3 与 L2 是同一结构在两侧的表述**。去耦引理给出的「内部扇区与空间扇区严格分离」正是 L2 补偿机制的结构前提；boost 解之所以能给出 \(\omega_b/\gamma\) 与 \(\xi_0/\gamma\)，前提是内部扇区不被空间传播污染。换言之，L2 使用的分离性就是 L3 使用的分离性。

因此收敛的正确形式是：**把去耦引理提升为 L2 与 L3 的共用前提，两引理成为该前提在传播侧与测量侧的分别推论。** 这不是削掉一条引理，而是把两条引理共用的隐性前提显式化为一条，论证链从「四引理并列」变为「一前提加两侧推论」。

## 四、收敛后的论证链

收敛形式（三引理加一前提）：

**前提（去耦与刚性）**。内部规范扇区与空间传播扇区严格解耦（去耦引理，精确）；传播速率由螺旋刚性 \(z = \lambda\theta/2\pi\) 与节律 \(|\dot\theta| = \omega_P\) 给定，与耦合强度无关（接力几何）；全域次光速定理给出 \(|\mathbf{v}_g| \le c\) 且等号仅在无隙长波极限（严格）。

**P-a（传播侧，原 L3）**。由前提直接得：介质弹性参数不进入传播速度，球面波速率在长波极限为 \(c\)，各向同性由 \(f(0) = f(1)\) 的三维最近邻读法给出。关于「光速相对介质变不变」的提问，其对象（介质依赖的传播速度）不存在。严格程度：条件性命题级（前提中的去耦与刚性均已证明，条件是三维最近邻读法）。

**P-b（测量侧，原 L2）**。由前提给出内部扇区不被空间传播污染，运动束缚态存在 boost 解，时钟频率 \(\omega_b/\gamma\)、结构尺度 \(\xi_0/\gamma\)。局部测量经 \(\gamma\) 补偿重现同型物理。严格程度：条件性命题级，数值验证级读数在收缩阱口径下为 \(0.054\%\)（\(v = 0.3\)）、\(1.310\%\)（\(v = 0.6\)）、\(7.853\%\)（\(v = 0.8\)）。

**P-c（机制，原 L2 与 L3 共用）**。内部过程计数速率在本征系恒为一摆程一计数，与振幅、宽度、所在格点无关。此条是 P-a 的「节律」与 P-b 的「补偿」在机制层的共同内容，出处为我（小新）的补口，非体系定案。

**L1（协议不变性）**。维持原表述，依赖复合体构成规则的形式化（缺口 P1）。

**L4（绝对运动态不可读）**。维持原表述，依赖快照抄写投影的形式化（缺口 P4）。

收敛后的结构是「一前提、两侧推论、两引理（L1 与 L4）」，比原先的四引理并列更紧：原先 L3 与 L2 被当作两条独立论据加入联合论证，现在它们的共同前提被显式化，联合论证的支撑点从四条减为三条（前提、L1、L4）加两条推论。

## 五、对 P11 攻坚计划的影响

三处需要同步。

第一，缺口总览的「缺口 P0」一行由「引理收敛待裁决」改为「已裁决：收敛成立」，任务 PB-0 标记完成。第二，PB-6 与 PB-7 的内容并入前提的证明（P-a 与 P-c），PB-6b（频率取景）不变。第三，缺口 P2/P3 的措辞需要调整：原先写「L2 与采样定理同时挂在这两处」，现在应写「前提中的去耦与刚性已证，L2 另行依赖 boost 解的精确动力学」。这个调整降低了一处工作量估计。

同时要登记一个新增项。收敛把 P-c（计数节律不变）提为机制层内容，它的证明依赖对「摆程计数」的形式化，而摆程计数的严格形式正是缺口 P2/P3 的计量层内容。故 P-c 与计量层共用前置，这一条应在 P11 计划的依赖链中标出。

## 六、严格程度与边界

本轮裁决的严格程度分三档。

**证明级**：去耦引理与螺旋刚性是既有结果，本轮只做接线，不含新断言。

**条件性命题级**：收敛后的 P-a，条件是三维最近邻读法（该读法同时承担各向同性，是自洽性的唯一出路，见色散论文 §6.4）。

**我的判断，非体系定案**：收敛提案本身。体系原稿把 L3 与 L2 并列为两条引理，本轮的收敛是重新组织，不是发现错误。作者若认为 L3 仍应独立列示（理由是保持与以太论文、注释四的表述衔接），则维持四条并列，收敛提案作为附注保留。

**边界声明**。其一，本轮不验证：去耦引理的三维推广（原文为一维口径）；boost 解的自指闭合（缺口 P4 的 PB-4）。其二，本轮不含数值轮，不新建脚本。其三，L3 的「K_0 不进入速度」与 L2 的补偿在低能层已分别有读数，收敛不改变任何既有读数，只改变论证的组织形式。
