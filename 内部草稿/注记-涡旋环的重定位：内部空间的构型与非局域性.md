## 一、修正的内容

原方案：涡旋环 = 三维物理空间里，光滑相位场上的闭合环管，局域客体。

该方案被裁决实验否定。[[从绕数困境到复合位错粒子：电荷载体问题的完整解决]] 记录：在无阻尼、过阻尼、含 $\kappa_\phi$ 完整哈密顿量的全部测试协议下，涡旋环塌缩到精确真空，塌缩路径能量单调下降无滑移垒，绕数在弛豫初始段经应变驱动分支穿越于体内部丢失。

作者提出的两项修正：

其一，**空间归属**：涡旋环不住在三维物理空间，住在内部空间（复平面）。

其二，**局域性**：涡旋环为非局域客体，其局域读法不成立。

修正后的读法：涡旋环是内部空间里相位缠绕的拓扑构型，其非局域性由绕数超选择的保护机制给出。

## 二、支撑一：内部空间才是它的本籍

[[割裂的终结：内部空间与外部空间的统一问题与元相子理论的框架意义]] 第 122 行原话：

> 内部数学空间（复平面）与外部物理空间（格点阵）属于同一个螺旋阶梯几何实体：元相子既是内部空间的拥有者，也是外部时空的砖块，并且两者通过螺旋线的几何演化实现同步，所以分离在源头上就不存在。

这句话直接支持第一项修正。原方案把内部空间的构型塞进外部空间去画成一维环管，本身就错位。元相方程的分工印证这一点：方程 (I)（连续旋转）在内部空间，方程 (II)（狄拉克梳离散跃迁）在外部空间，是同一实体的两个侧面。绕数是内部空间旋转角的构型，理应画在内部空间上。

体系另有独立理由要求绕数不住格点。[[绕数]] 词条与承载层五站裁决实验的结论是：位形侧的四种实现（光滑场环、单值场孤立疤、离散化、表示性绕数）全部被否定，绕数由波性侧的纠缠结构承载，与归粒性侧的局部质量形成分工。内部空间属波性侧，修正后的归属与这条一致。

## 三、支撑二：非局域是它的存活条件

这一项修正比第一项更关键。[[绕数超选择：先验纠缠作为电荷保护层]] 给出的机制是：跨扇区算符只有一种类型，即沿闭合回路分布的非局域弦算符，它不在任何局域生成元的闭包内。保护不靠把势垒堆高，靠扇区结构。

[[内部草稿/注记-载体层裁决：纯相位的失败边界与振幅通道的实现路径]] 第 113 行把这一机制说成局域不可分辨：长程纠缠在此扮演的角色是局域不可分辨，toric code 与 Levin-Wen 弦网的基态简并按非缩并环通量分扇区，局域算符无法连接不同通量扇区，唯一跨扇区的操作是非缩并 Wilson 环算符。

原方案之所以塌缩，正因它是局域的：局域环管上的绕数可作局域形变，形变至中途经分支穿越即可丢失圈数。撤去"局域"这一前提，等于撤掉了塌缩的机制根源。**这一步是把它放回体系本来给它安排的位置，不属补救。**

## 四、剩余问题：局域粒子与守恒荷如何并存

修正后仍需处理一点。[[内部草稿/注记-载体层裁决：纯相位的失败边界与振幅通道的实现路径]] 第 117 行记录了一个被推翻的过强推论：

> 先前由「闭合环的局域绕数无保护」推出「局域粒子不能有守恒荷」，这一步过强。在任意子图景里，局域激发可以继承扇区荷：荷的定义来自基态空间结构，不来自它自身的局域绕数。

这条修正的含义要读准：荷来自扇区结构，粒子本体可以是局域的。那么问题落到：非局域的涡旋环（负责荷）与局域的复合位错粒子（负责质量与位置）是什么关系。

体系已有现成答案，即两层分工定律：**守卫归波、承载归粒，运动为两侧耦合**。复合位错粒子分三层，其中电荷核为 toric code 层关系自由度，锚核为 $\kappa_\phi$ 格点内锁定（供绑定能即质量），包层为法线轴弹性（供宽度与洛伦兹色散）。

据此，修正后的分层读法为：**涡旋环描述电荷核那一层**（波性侧、内部空间、非局域），**复合位错粒子描述锚核与包层那两层**（粒性侧、格点、局域）。两者是同一粒子的两侧，不构成竞争方案。这一读法与本轮此前确认的三层相位归属、距离归粒方向归波闭合一致。

该分层读法为本文提出的组织（出处为本注记），不是既有定案文字，待作者确认。

## 五、同义关系声明（作者裁定）

作者 2026-09-21 裁定：**内部空间与纤维是同一个东西**，不作区分。

这是对 [[割裂的终结：内部空间与外部空间的统一问题与元相子理论的框架意义]] 的一处口径澄清。该文把纤维丛的"内部空间"用作批判对象，批判的靶子是**两者的分离**（底流形与纤维是两个数学对象、结构是设定输入），而无关内部空间本身的身份。

第 166 行原有表述可作为这一裁定的支撑：

> 元相子中内部空间（复平面）与外部空间（晶格阵）属于同一螺旋几何实体的两个侧面，元相子既是内部空间的拥有者，也是时空的砖块，直积结构从定义上不存在。

即：元相子理论与纤维丛框架的分歧在**归属**（同一实体两个侧面，还是两个分离对象）与**来源**（结构涌现，还是设定输入），不在"内部空间是什么"。裁定后，讨论内部空间时可径称纤维，勿再造一个独立名目。
