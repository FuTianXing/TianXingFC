## 二、拓扑排除（定理级）

候选直觉"电荷 = 实轴方向场的涡旋缺陷"被拓扑学排除：实轴方向 $\alpha$ 是角变量，取值于 $S^1$；空间三维中的点缺陷需要球面映射 $\alpha: S^2 \to S^1$，同伦群

$$\pi_2(S^1) = 0$$

平凡。角场本身不允许点状单极缺陷，电荷不可能是实轴方向场的空间涡旋。

**意外收获（独立成立，不受下文问题影响）**：空间中的涡旋线（$\pi_1$ 缺陷）是允许的：

$$\oint_C \nabla\alpha\cdot dl = 2\pi n$$

对应切向场 $\nabla\alpha = n/r\,\hat\varphi$，与无限长载流导线的磁场 $\mathbf{B} = \mu_0 I/2\pi r\,\hat\varphi$ 同构。安培环路定律与绕数定理是同一个公式：

$$\text{电流} = \text{实轴方向涡旋线}，\qquad \text{磁场} = \text{涡旋线的环绕梯度场}$$

$\nabla\cdot\mathbf{B} = 0$ 自动涌现（涡旋线不能凭空断开，无磁单极是拓扑结论）。

## 三、核心候选：电荷 = 实轴旋转速率场的源

实轴方向本身是实在结构，可以随时间转动（注释七第 1 点）。考虑一个实轴方向以恒定速率旋转的格点：

$$\alpha_n(t) = \alpha_n(0) + q\,t$$

**物理图像**：电荷是"校准的永久源头"，一个让天行力永远在追赶、永远追不上的存在。邻居校准想与它对齐，但它的指针一直在转，对齐之后立刻又偏开。

定义电势为实轴旋转速率场，电场为其负空间梯度：

$$\phi(\mathbf{r}) \equiv \dot\alpha(\mathbf{r}) = \frac{q}{r}, \qquad \mathbf{E} = -\nabla\phi = -\nabla\dot\alpha = q\,\frac{\hat r}{r^2}$$

**与附件对应表对接**：$A_0$（时间联络）= 实轴旋转速率 $\dot\alpha$，$F_{a0} = \partial_a A_0$，"电场 = 实轴方向场动力学的时空耦合"落实为具体几何。

**库仑定律涌现（校准代价最小化）**：天行力追求最大相干，校准代价正比于相位差梯度，类比 XY 模型弹性能：

$$U = \frac{K}{2}\int(\nabla\dot\alpha)^2\,d^3r = \frac{K}{2}\int E^2\,d^3r$$

相互作用能 $\sim K q_1 q_2/r$，符号自动正确：同号电荷叠加后中间场抵消、远处场增强，总能量随距离减小而增大，排斥；异号电荷中间场增强、远处场抵消，吸引。$1/r$ 律和同斥异引从"校准代价最小化"一个原则涌现。

**辐射涌现**：感知-校正链响应相位差的变化；静止电荷周围是恒定位形不辐射，加速电荷改变相位差分布触发校准波。麦克斯韦"加速度才辐射"自动涌现。

**电荷量子化与正负电荷**（候选）：实轴转满 $2\pi$ 回到自身（离散性）；$q>0$ 正转、$q<0$ 反转（与旋向概念挂钩，P6/C1 的物质反物质不对称获得机制候选）。

## 四、麦克斯韦方程组的元相子几何对应

| 麦克斯韦方程 | 元相子几何对应 |
| --- | --- |
| $\nabla\cdot\mathbf{E} = \rho$ | 电荷 = 实轴旋转速率场的源 |
| $\nabla\cdot\mathbf{B} = 0$ | 涡旋线无端点，拓扑定理 |
| $\nabla\times\mathbf{B} = \mathbf{J} + \partial_t\mathbf{E}$ | 涡旋线 = 电流，变化电场卷绕涡旋 |
| $\nabla\times\mathbf{E} = -\partial_t\mathbf{B}$ | 旋转速率梯度的时间变化与涡旋耦合 |

前两条最硬（拓扑与源定义），后两条还只是形式对应。

## 五、备选方案

- **方案 A（旋向不对称）**：正负电荷 = $\varepsilon = \pm1$ 元相子数目的局域不平衡。可直接解释电荷守恒（旋向守恒，注释十三层次 B），但缺"手性不平衡产生电效应"的机制。可与核心候选合并：电荷符号 = 实轴旋转方向，旋向与旋转方向是注释三第 8 点区分的两个量。
- **方案 D（三元组内部模式）**：电荷 = 异类耦合 $\kappa_\phi$ 的相对相位模式激发。解释电荷是格点属性，但能隙模式与守恒荷的关系待证。

### B 级问题（建议解决）

1. **电势 $1/r$ 衰减是假设**：先写出 $1/r$ 再验证高斯定律有事后拟合嫌疑，需从 $\nabla^2\dot\alpha = 0$ 加源条件解出，或声明为候选。
2. **电荷量子化是论证跳跃**：周期性 $\alpha\sim\alpha+2\pi$ 只约束 $\alpha$ 取值于 $S^1$，不约束 $\dot\alpha$，经典指针可以任意速率转。离散性需额外约束（如实轴旋转与摆程节律锁定 $q = 2\pi n/t_P$），不能直接断言。
3. **校准代价形式是隐含假设**：取 $(\nabla\dot\alpha)^2$ 而非更自然的 $(\nabla\alpha)^2$；且注释七第 8 点允许实轴长波梯度存在（$\nabla\alpha$ 即光），与 $(\nabla\alpha)^2$ 禁令冲突。需显式声明：校准对齐的是节律（相对相位），实轴方向梯度（波矢/光）被允许，旋转速率梯度（电场）承载校准代价。
4. **旋转的驱动者未回答**：天行力是恢复力（注释十第 2 点），谁持续制造旋转偏离？候选：旋转是旋向 $\varepsilon$ 赋予的固有动力学模式；否则电荷成了永动机。
5. **天行方程对接是宣言**："$\Xi$ 最大化等价于 $\int E^2$ 最小化"无推导。需给出映射：$D$（方向对齐度）局域偏离对应 $\nabla\dot\alpha$，$\mathcal{F}[D] = -\delta\Xi/\delta D$ 在平衡位形附近线性化为 $-\nabla^2\dot\alpha$。
6. **电荷守恒未论证**：旋转源为何不能停止或启动？候选为旋向守恒对旋转方向的双重约束。

### C 级问题（可选）

1. **格点截断**：$\dot\alpha = q/r$ 在 $r\to0$ 发散，格点 $l_P$ 天然截断（$\dot\alpha_{\max} = q/l_P$），与注释十二第 6 点紫外截断精神一致。
2. **绝对旋转与规范冗余**：整体匀速旋转等于连续施行的全局 $U(1)$ 变换（不可观测），电荷旋转必须是"相对旋转"；可观测的是 $\dot\alpha$ 的梯度（电场），与注释八规范不变可观测量的原则对齐。

### 值得保留的亮点

1. $\pi_2(S^1)=0$ 的排除是真正的拓扑贡献，定理级，堵死"电荷 = 角场点缺陷"的错误路线。
2. 涡旋线 ↔ 电流、绕数 ↔ 安培环路定律、无磁单极涌现，全推演最硬的部分，独立成立。
3. 电势 = $A_0$ 时间联络 = 实轴旋转速率，与附件对应表精确咬合。
4. 同斥异引符号规则从 $\int E^2$ 能量随距离单调性定性涌现。
5. 诚实边界标注到位。
