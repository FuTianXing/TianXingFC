## 一、问题的定位

标准模型中手征性悬而未决的部分不在“左手态存在”这个事实，而在三个层次的追问：

1. **表示层**：为什么弱相互作用精确地是 $V-A$ 形式，即为什么弱荷只加载在 $\frac{1-\gamma_5}{2}$ 投影的分支上，且破坏是最大的；
2. **谱层**：为什么右手费米子分支在弱作用中完全惰性（$T_3 = 0$），中微子为什么没有右手分支（标准模型内无质量）；
3. **根源层**：手征性（chirality）与螺旋度（helicity）在几何上到底是什么，宇称算符 $P$ 在元相子框架中对应的操作是什么，以及强、电磁相互作用为什么宇称守恒。

体系现状：模态论文把 $SU(2)_L$ 识别为双模态系统的模式混合群（Bloch 球跃迁），手征性列为开放问题；带电判据草案把“弱作用为何只选左手”与带电分界线归并为旋向 $\varepsilon$、摆程方向 $\sigma(t)$、缠绕方向三者的耦合拓扑问题，但未给出几何定义。本稿的贡献是把上述三层追问统一到单个几何对象上：**波函数相位空间的复结构**。

## 二、候选方案与筛选

**方案一（旋向方案）**：手征性直接等同元相子旋向 $\varepsilon$。此方案在第一步即被排除。原版内部约束 C1（初始旋向对称，2026-09-02 已撤销）曾推出两类旋向数目恒等，作为否决理由之一；撤销后弱作用只耦合一种旋向虽无数目障碍，但根本困难依旧：层级错配，旋向是元相子（单体）的属性，手征性是费米子（复合体）内部的分量结构，两者不共享层级。其次，把左手等同于一种螺旋绕向，无法容纳“有质量费米子同时含左右手分量”这一标准事实，因为同一个电子的两个手征分量对应同一个 $\varepsilon$。

**方案二（内外相对取向方案）**：手征性 = 螺旋绕向 $\varepsilon$ 与内部拓扑（$Tw/Wr/Lk$ 与缠绕数符号）的相对取向 $\chi = \varepsilon \times s$。此方案在变换性质上完全正确：空间镜像翻转 $\varepsilon$ 不翻内部符号，故 $\chi$ 在 $P$ 下变号；反粒子经 Feynman–Stückelberg 对应同时翻转 $\varepsilon$ 与内部符号，$\chi$ 在 $C$ 下不变；$CP$ 下 $\chi$ 变号、$CPT$ 下不变，与标准物理的手征变换表逐项吻合。但它在根源层空缺：它只给出“手征性是什么”的守恒量定义，没有回答“弱荷为什么只加载在一个分支”和“为什么破坏是最大的 $V-A$”。作为预备层结构保留（$\chi$ 的变换表），本稿主张根源在更基本的复结构。

**方案三（复结构方案，本稿主张）**：手征性 = 波函数相位空间的复结构 $J$ 的本征分支。螺旋阶梯几何已定案：完整元相子是心物双螺旋，实轴物螺旋与虚轴心螺旋相位差恒 $\pi/2$。相位差 $\pi/2$ 正是复平面上“乘 $i$”的几何操作，即一个复结构。“谁超前谁滞后”（$\pm\pi/2$）是二值的，这个二择一就是左手与右手的几何区分。左手 = 复结构 $J$ 的 $+i$ 本征分支，右手 = $-i$ 分支。弱相互作用只耦合左手，即弱荷只加载在全纯分支上；$V-A$ 的最大破坏、中微子的无右手分支、有质量费米子的双分量结构，全部从这一个对象推出。方案三继承方案二的变换表，同时把“为什么只有左手”从公设降为下述几何事实：物理态是复振幅（序参量模式，P7），复振幅的动力学只与其自身（全纯方向）共轭相容，反全纯分支只能通过实结构（质量项）进入。

## 三、复结构与手征性的几何定义

### 3.1 心物双螺旋给出复结构

螺旋阶梯几何定案：完整元相子是双螺旋，实轴物螺旋承载粒性摆程，虚轴心螺旋与物螺旋相位差恒 $\pi/2$。令 $\theta$ 为旋转角（摆程相位，时间），则心螺旋的相位为 $\theta \pm \pi/2$，二者合成：

$$\Phi_{\text{compound}} = e^{i\theta} + e^{i(\theta \pm \pi/2)} i = (1 \pm i)\, e^{i\theta}$$

统一描述：双螺旋的联合相位 = 复平面上对旋转角 $\theta$ 的两种升序之一，其几何内容是一个正交算符 $J$（相位平移 $\pi/2$），满足 $J^2 = -1$。超前（$+\pi/2$）与滞后（$-\pi/2$）对应 $\pm J$。复结构符号 $s = \pm 1$ 是元相子层的第一个手征量。

### 3.2 模态空间上的复结构与旋量分解

模态论文已确立：双模态系统的归一化态空间为 $S^3 = SU(2)$，模式混合群 $SU(2)_L$ 左乘作用于叠加空间。数学结构（标准定理）：$S^3$ 上的左不变复结构 $J$ 把复化切空间分解为 $+i$ 与 $-i$ 本征空间，Spin(1,3)（欧氏化）分解为 $SU(2)_L \times SU(2)_R$，左乘保持 $J$，右乘保持 $-J$。四个分量 Dirac 旋量按手征投影 $\frac{1 \mp \gamma_5}{2}$ 分解为两个 Weyl 旋量，恰好对应这两个本征空间。因此：

$$\gamma_5 \ \longleftrightarrow \ J , \qquad \frac{1-\gamma_5}{2} \psi \ \longleftrightarrow \ \psi \text{ 的 } +i \text{ 本征分量}$$

**元相子翻译（纲领性主张）**：手征性属于双螺旋内部“心物相位差符号”在模态叠加层上的继承，与外部运动学性质无关。左手 = 心螺旋超前物螺旋（$s = +1$）对应的模态分支，右手 = 滞后（$s = -1$）分支。螺旋度（自旋沿动量投影）是独立的运动学量，在无质量极限下与手征重合，有质量后分离；这个分离正是质量混合的形态学表现（§5）。

### 3.3 宇称与电荷共轭的几何操作

空间反射在螺旋几何中的操作：镜像翻转螺旋绕向，即 $\varepsilon \to -\varepsilon$，同时交换 $SU(2)_L$ 与 $SU(2)_R$ 因子（表示论事实：宇称把 $(1/2,0)$ 表示映到 $(0,1/2)$）。因此 $P$ 交换复结构的两个本征分支，手征变号：

$$P: \quad \chi \to -\chi$$

电荷共轭的几何对应是 Feynman–Stückelberg 式的组合：时间反向 + 内部反向。元相子层上 $C$ 同时翻转旋向与内部缠绕符号（螺旋反转），$T$ 翻转摆程方向 $\sigma(t)$。变换表如下（对照表）：

| 变换 | 元相子层操作 | 模态分支效果 | 手征 $\chi$ |
| --- | --- | --- | --- |
| $P$（空间反射） | $\varepsilon \to -\varepsilon$，交换 $SU(2)_L \leftrightarrow SU(2)_R$ | 交换 $\pm i$ 本征空间 | 翻转 |
| $C$（电荷共轭） | $\varepsilon \to -\varepsilon$，内部符号反向 | 保持本征空间 | 保持 |
| $CP$ | 两者复合 | 交换本征空间 | 翻转 |
| $CPT$ | 上述加摆程方向反转 $\sigma(t) \to -\sigma(t)$ | 保持本征空间 | 保持 |

与标准物理逐项吻合：$C$ 保持手征（$v_L \to \bar v_R$ 中反粒子右手螺旋度对应左手手征分量），$P$、$CP$ 翻转（$v_L \to v_R$、$v_L \to \bar v_L$），$CPT$ 保持（$v_L \to \bar v_R$）。此表同时修正了方案二的 $\chi = \varepsilon \times s$：变换性质由 $s$（复结构符号）承载，$\varepsilon$ 只参与 $P$ 的镜像与 $C$ 的反粒子对应，两者在 $CPT$ 下复合为恒等。旋向守恒（公理 4）不受影响，因为 $s$ 是复合体（双螺旋模态）属性，不进入元相子级的旋向统计；公理 7 的初始旋向对称预设已于 2026-09-02 撤销，本方案不依赖该项。

## 四、宇称不守恒的推导

### 4.1 弱荷只加载在全纯分支

模态论文：弱同位旋二重态 = 双模态 $(|A\rangle, |B\rangle)$，$W^\pm$ 发射吸收 = 升降算符 $\sigma^\pm$ 的模式跃迁，Bloch 球跃迁即弱衰变。本稿补充结构：**模式混合（左乘 $SU(2)_L$）保持复结构 $J$，因此它是定义在全纯分支上的变换**。反全纯分支对应 $SU(2)_R$ 右乘，不参与模式混合动力学。弱荷 $T_3$ 的几何内容 = 全纯分支上的模态参与度；反全纯分支的模态参与度恒为零：

$$T_3 \ \text{只加载于} \ \chi = -1 \ \text{分支（左手）}$$

这是把模态论文的“为什么 $SU(2)$ 前下标是 $L$”从命名还原为几何：$SU(2)_L$ 之 L 来自复结构选择 $J$（排除 $-J$）的直接后果。

### 4.2 V−A 的最大破坏

弱带电流在四分量语言中是 $J^\mu = \bar\psi \gamma^\mu (1-\gamma_5)\psi$，即矢量流与轴矢流之差。在复结构语言中，$1-\gamma_5$ 是全纯投影，于是 $V-A$ 形式的含义是：**弱电流是模式流的全纯投影**。宇称 $P$ 交换 $SU(2)_L$ 与 $SU(2)_R$ 因子，全纯投影变为反全纯投影，$V-A$ 变为 $V+A$，耦合结构不相等。其中矢量部分（格点坐标流，极矢）与轴矢部分（螺旋关联流，轴矢）在镜像下行为相反：极矢空间分量变号、轴矢空间分量不变号。两者以固定符号差组合，镜像后不回到自身。因此：

**命题（几何必然）**：只要弱耦合同时含极矢与轴矢分量，宇称破坏就是必然的；若弱荷只加载在单一全纯分支（$T_3$ 只在左手），破坏必然是最大的（$V-A$ 精确）。

电磁与强相互作用的宇称守恒同源可解：它们的耦合是全纯-全纯连接（$U(1)_{em}$ 与 $SU(3)_C$ 均保持复结构 $J$，作用在全体分量上而无手征投影），极矢与轴矢分量不出现符号差组合，镜像下耦合回到自身。弱作用之“弱”与其宇称破坏之“最大”在几何上是一件事的两面：弱荷是全纯投影荷，投影本身破坏镜对称。

### 4.3 中微子与谱不对称

复结构方案给出中微子零电荷与无右手分支的统一几何说明（并与带电判据草案衔接）：中微子属于“左手螺旋的往复对称构型”（带电判据条件 2 失效分支），其内部缠绕反向抵消、净绕数为零（§8.6 机制）；在模态层，中性 + 无净绕数的复合体没有与反全纯分支形成实结构（质量）混合的拓扑通道。标准模型内中微子无质量，右手分支完全不进入动力学，这是谱不对称（$v_R$ 缺席）的根源，也是 $C$ 破坏的根源：电荷共轭把参与弱作用的 $v_L$ 映到谱中不存在的态。

有质量中微子（振荡已证实）的两种出路皆兼容：Dirac 型（惰性右手中微子 $v_R$ 以 seesaw 大质量进入，弱惰性、零荷）与 Majorana 型（手征共轭等同）。这构成对带电判据草案预言的一条修订：草案 §八 (c) 预留的“右手中微子若进入理论需容纳新分支”在此落实为明确图像，右手中微子若存在应为弱惰性单态且可带任意超荷分配，说不上必然带电。判据中“右手中微子若带电则证伪”的判词仍有效，但方向性预言改为“右手中微子应弱惰性”。

## 五、质量、左右混合与手征对称性破缺

质量项 $m\bar\psi\psi = m(\bar\psi_L \psi_R + \mathrm{h.c.})$ 在复结构语言中是**全纯分支与反全纯分支的实结构混合**：把 $+i$ 与 $-i$ 本征分量耦合成一个实表示。体系定案“质量 = 拓扑缺陷绑定能”在此获得形态学翻译：

- 无质量（标准模型内中微子）：无反全纯分支可混合，实结构封闭，质量项不存在；
- 有质量费米子：左右分量通过绑定通道（缺陷绑定能 $\omega_0 \sim \sqrt{\kappa_\phi}$，Yukawa 系数为导出量 $y_f = \sqrt{2}\hbar\sqrt{\kappa_\phi}/v$）耦合成实结构，形成四分量 Dirac 场；
- 弱耦合仍只作用于左手分量：弱荷是全纯投影荷，即便在实结构（有质量费米子）中，$T_3$ 也只投影到全纯分量。这解释了为什么电子有质量（含右手分量）而弱作用仍精确只耦合左手：质量混合改变的是态的实结构，不改变弱荷的投影定义。

手征对称性的自发破缺（QCD 手征凝聚）与显式破缺（夸克质量）在几何上对应实结构混合的强度与真空实现，属涌现层粗粒化描述，与本方案无冲突。

6. **手征-物质不对称联动（新候选，2026-09-02 随公理 7 修订引入）**：初始旋向对称设定撤销后（主文档公理 7、C1，2026-09-02），C1 不再禁止初始旋向偏置。由此获得一条统一候选：世界选择 $J$、排除 $-J$（弱作用为何只选左手）与物质-反物质不对称共享同一起源，即公理 7 初始条件的旋向偏置 $\delta = (N_+ - N_-)/(N_+ + N_-) \neq 0$。天行力方向性（终极存在内禀的丰富化方向）选定偏置符号，偏置经复合体组建规则传递给模态层的手征符号 $s$，$s$ 决定全纯分支（§3.3），全纯分支承载弱荷（§4.1），同时 P6（反物质与旋向对应）把偏置映射为物质过剩。此候选把观测上两个独立的符号事实（宇称破坏的方向、物质过剩的方向）绑定为同一个初始参数，预言二者符号一致。诚实声明：元相子层到模态层的传递链路（$\varepsilon$ 偏置 $\to$ $s$ 选择 $\to$ 弱荷分配）尚未形式化，属纲领层；若未来出现“右手中微子与物质过剩符号相反而弱作用仍左手”的迹象，此候选与预言 (a) 一并被改写。
