## 一、问题陈述

引力当前定稿机制把记录写在波性侧连续标架场上：标架由三元组实轴取向构成，缺陷世界线每普朗克拍写入一份倾斜 $\delta\theta = m/m_P$，邻居抄写平均扩散，稳态为离散泊松格林函数 $\theta(r) = (m/m_P)(l_P/r)$。该方案在数学上闭合、数值上通过、作者确认定案。但载体语义存在三层错位。

其一，实轴取向是圆平面朝向，属信息层内部自由度，与空间本身隔一层，图像不清晰。其二，$\delta\theta$ 记号与泊松场 $\theta(r)$ 读作角度或相位，造成"引力 = 相位偏转"的观感。其三，实轴取向同时承载电磁（取向差连接、Goldstone 波动）、引力（标架倾斜）与三代质量谱（$Z_3$ 取向差），角色过载，双静态源（电荷与质量）在同一场中的唯一分解未证明。

体系裁定为法线语义提供了更强依据：非紧致裁定给出 $\mathbb{R}$ = 法线轴、层数 = 距离、$x^a = l_P n^a$。法线就是空间轴。法线偏转 = 层叠方向的空间变化 = 度规空间部分的弯曲，是引力最直接的几何图像，不需要内部自由度中转。

## 二、接力困境的精确表述

摆程路径、法线与圆心连线三位一体。法向事件假设 H1（$q_{n+1} - q_n = \ell e_z$）使摆程沿法线，碰撞要求相邻反相迎头相撞。若偏转作用在圆心轨迹（粒性侧）上，两个圆心错开，碰撞日历崩。这正是方向归波（注释 09）与摆程层失明（数值：碰撞时刻锁定区与真空总能量严格简并）的物理含义。任何让摆程路径偏转的方案都回到五层冲突。

因此恢复法线偏转的合法位置只有两处：波性侧的连续场（倾斜作为静态记录），或缺陷世界线本身（粒子不摆程，其内部法线可偏转）。

## 三、三条途径

**途径一：语义修复，标架场重读为法线场。**

标架 $F(n) \in SO(3)$ 的三根轴是局域晶轴（三元组法线），标架倾斜即层法线倾角。引力 = 质量缺陷造成的层法线静倾角场，稳态 $\theta(r) = (m/m_P)(l_P/r)$。机制、数值与全部验证不变，只改语义与记号。电磁扇区（波矢、光、规范连接）留在实轴取向场，不迁入法线场（2026-09-10 作者指正，分工双场）；两场分离后，电荷静电场与质量引力场同为直流却不再共享载体，分解唯一。分离限定为源的载体分离，耦合经度规双向进行：光（实轴取向场波）在法线场度规中协变传播（响应侧，光偏折），光能量-动量经 $T_{\mu\nu}$ 微观分解反馈为法线场源（反馈侧，张量桥 d 段）；两场分离不是动力学解耦。与方向归波（法线倾角场是波性侧连续场）和非紧致裁定（法线 = 空间轴）同时兼容。此途径不改变物理预言，价值在图像清晰与角色解耦。

**途径二：源项弹性化，缺陷绑定能作为法线轴弹性背景的源项。**

复合位错包层已是法线轴弹性（$\kappa_\parallel$ 原始形式）。质量 = 法线轴背景的局域错排源（粒子 = 法线轴位错），引力场 = 背景弹性平衡场：位移场 $u \sim 1/r$，应变 $\sim 1/r^2$，层法线倾角 = 应变的切变分量。弹性平衡 $\nabla\cdot u = s\,\delta$ 的离散稳态与现有离散泊松同构。接力保持，因为应变是静态背景场，不动摆程路径。

**途径三：粒性侧局部恢复，缺陷世界线的法线偏转。**

粒子（复合位错）不摆程，摆程层对它失明，其内部法线轴可偏转而不破真空接力。粒子法线沿背景法线场排列（平行输运）给出自由粒子的测地线运动。该途径把"运动 = 转换波"与"引力 = 测地响应"统一到粒子自身法线轴，解决响应侧；源侧仍走途径二。

## 四、两条最小验证判据

判据 A（语义同构核对）：将 `验证脚本/minimal_verification_frame_tilt.py` 的标架倾斜场重读为层位移场，核对离散弹性平衡方程（$\nabla\cdot u = s\,\delta$ 的七点离散形式）的稳态是否同样收敛到 $1/r$ 格林函数，误差标度是否保持 $(l_P/r)^2$。通过则途径一获得数值背书，途径二获得同构基础。

判据 B（测地线判据）：构造粒子法线沿背景法线场平行输运的判据脚本。模型：背景法线场为已知稳态倾角场，粒子为携带内部法线的复合位错代理。检验：粒子法线按背景联络平行输运的离散更新，是否给出与测地线方程一致的轨迹（小力区线性、方向保留、轨迹与质量无关）。通过则途径三成立，等效原理的响应侧从一维链玩具升级为背景场几何。

## 五、诚实边界

途径二、三为纲领级，无数值验证。双源（电荷与质量）唯一分解问题随分工双场消解（引力 = 法线场、电磁 = 实轴取向场，2026-09-10 作者指正），遗留为实轴取向场内部电磁与 $Z_3$ 真空取向配置的共存说明，以及法线场被引力独占的验证；应变场波动模式（引力波）与抄写平均动力学的共存照旧登记。途径三只覆盖响应侧；源侧仍依赖途径二与拓扑曲率结论（光滑标架零曲率、绑定能作源为机制必要）。
