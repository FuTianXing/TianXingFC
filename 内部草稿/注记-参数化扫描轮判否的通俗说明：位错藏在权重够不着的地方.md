## 一、这轮在问什么

弹性本构线走到第 596 条之后，问题收得很窄：缺陷（位错）要想在体系里稳定住，需要一份额外的"交叉耦合"，把格点内三个互相垂直的振子股拴在一起。第 596 条问的是"这根拴绳该长什么样"，答案是体系自己定不下来（约束三条，自由度无限维）。作者裁决走参数化构造层路线后，第 598 条退一步问一个更朴素的问题：**不管形状，只问粗细，拴绳要多粗才能起作用**。

做法是把交叉项的强度 $\xi$ 当成可调旋钮，装进最小位错模型（一维周期链三分量，$N = 256$，$k = J = 1$），扫 $\xi$ 的正负各档，看两种错排分配的能量排序 $D_{\rm assign} = E_\beta - E_\alpha$ 在哪一档翻转。翻转点就是"稳定化元素要多少份量才够"的定量门槛。扫到的结局决定裁决：门槛在合理区间内，参数化路线拿到定量挂账；门槛在窗外，结论仍是"缺来源"，但拿到定量的形状。

## 二、先修尺子：接缝口径审定

动手扫描前先审了上一轮的尺子，审出一个必须修的问题。周期链是环，环上有一个"接缝"（首尾相接处）。第 595 条的能量实现里，接缝键的应变没有扣掉整数绕数：错排在弛豫过程中可以悄悄漏进接缝这个单键里，能量账因此含了一份"接缝收容错排"的口径贡献。实测证据很直接：$\beta$ 终态三股端点差的连续值之和 $\approx 0$，整化读出的 $[1,0,0]$ 靠的是四舍五入。

本轮改成 FK 标准口径：接缝键应变补上整数 $Q$，绕数扇区在初值处定死、全程守恒，错排漏不出去。两把尺子各跑一遍基线：旧口径 $D_{\rm assign}(0) = +0.656$（逐位复现第 595 条，说明移植对齐无误），新口径 $+0.327$，差额 $-0.329$ 就是接缝口径项。**第 595 条的定性结论不翻**（两种口径下 $\alpha$ 侧同为真空，排序一致），但位错能量的数值基准从此换成 $0.327$，后续引用第 595 条数字须注明口径。这是本轮第一笔净收益：判据还没跑，尺子先修准了。

## 三、发现一：位错的藏身术

新口径下位错长什么样？图 3 左面板给了直接答案：**一个单格点的整数台阶**。相位差 $\delta^{12}$ 沿链只有两个取值，$0$ 与 $2\pi$，从 $0$ 跳到 $2\pi$ 的过程压缩在一个格点内完成。$k = J = 1$ 的强离散区里，异类耦合把位错芯压到极限宽度，一格。

这个形态直接决定了扫描的结局。负 $\xi$ 通道（$g_1 = 1-\cos 2\pi\Delta v$ 调制）的设想是：位错芯里 $\delta$ 非整圈，交叉项在负 $\xi$ 下给那里打折，位错就变便宜了。但台阶形态下，错排所在的格点相位差恰好是整圈（$\Delta v \in \{0, 1\}$），$1-\cos 2\pi\Delta v$ 在整圈处精确为零。

**位错把自己缩进了权重够不着的地方**：整个构型里交叉项能发力的区域几乎不存在，实测交叉密度 $X_\beta \sim 10^{-3}$，四档扫描 $D_{\rm assign}$ 从 $0.327$ 到 $0.323$ 纹丝不动，外推门槛 $|\xi_c| \sim 10^2$，远在稳定窗之外。

换 $g_2 = (1-\cos)^2$（权重更集中）同形态。负侧判否：无供货。

## 四、发现二：cos 支的方向反转

设计阶段清点形式空间时抓到一个此前漏掉的候选：$g_3 = \cos 2\pi\Delta v$ 调制。它与 $g_1$ 同样真空稳定（均匀背景上力为零），但行为相反：在整圈处取 $+1$（罚），在半圈处取 $-1$（奖）。当时的预期是"正 $\xi$ 给半圈处的芯发奖金"，位错芯会变便宜，门槛应在主窗内。

实测把这个预期判否了，判得干脆：$X_\beta(g_3)$ 恒正（$0.62$ 到 $0.28$），正 $\xi$ 逐档加贵位错。原因还是台阶形态：**应变恰好全部住在整圈区**（台阶键上 $\Delta v$ 取整圈，$\cos = +1$ 罚），而设想中的半圈奖金区（$\delta \approx \pi$ 的展宽芯）在单格点台阶里根本不存在。应变与权重空间错位，$\xi$ 越大罚得越重，$D_{\rm assign}$ 从 $0.327$ 一路升到 $2.29$（$\xi = 4$）。

$\xi$ 再大（$\ge 6$），交叉项强到能跟异类锁掰手腕，链条进入 kink 增殖的新相（错排分配 $[4,2,2]$，多缺陷态）：那是交叉项自己造的新世界，与"给位错供货"无关。

## 五、发现三：失稳墙，强度的可用窗口被两头挤死

负 $\xi$ 侧还有一道更硬的墙。交叉项变负后开始跟键弹性竞速：均匀应变区每键能量 $\frac{\Delta v^2}{2}(1+\xi)$，$\xi < -1$ 时系数翻负，能量无下界，链条可以从任何一处应变里无中生有地榨出能量。实测 $g_3$ 支恰在 $\xi = -1$ 发散（与解析阈值逐位吻合），$g_1$ 支在 $\xi = -4$ 发散（解析无界判据 $|\xi| > 0.5$，差额是逃逸势垒）。发散不是数值故障：加发散检测后按失稳实证登记，它是模型的真实性质。

三面合围的图像就此完整：**$\xi$ 弱，则交叉项对位错总账的修正只有 $10^{-3}$ 量级，无用；$\xi$ 强，则负侧撞失稳墙、正侧撞新相，毁灭。** 强度的可用窗口两头挤死，中间没有一段"刚好够把位错扶稳"的区间。

## 六、这对裁决意味着什么

参数化构造层路线的判否可以一句话说清：**拴绳的粗细不归体系调**。第 596 条说"绳的形状体系定不了"，第 598 条补上"绳的粗细也被稳定性钉死"。两条合起来，"在构造层加交叉耦合"这条路的自由度被清空：形式不唯一、强度不可调、可达区间内不供货。

裁决面因此维持第 596 条的二选一（公设级新元素对心侧校准），并新增一条硬约束：任何进构造层的新元素，其耦合强度必须有自己的来源，不能以"调参数"的方式供货；若新元素以交叉耦合形态出现，还必须解释为什么它能躲开单格点台阶的藏身术（本轮只审了 $(\Delta v)^2$ 因子最低阶两支，差应变因子 $(\Delta v^a-\Delta v^b)^2$ 与高阶形式族未扫，这是二选一裁决时需要向作者如实交代的射程边界）。

## 七、边界声明

其一，本轮判否只覆盖 $(\Delta v)^2$ 因子配 $1-\cos$ 与 $\cos$ 的最低阶两支，高阶与差应变形式在射程外。其二，$\xi \ge 6$ 新相的读数未收敛（$D = -2320$ 只证相变存在，不作定量引用）。其三，失稳阈值的解析骨架只对 $g_3$ 支 $\delta = 0$ 通道严格（$\xi = -1$ 精确），$g_1$ 支阈值为动力学实测值。其四，接缝口径审定只影响数值基准，不改第 595/596 条定性结论；上游文档若引用位错能量 $0.657$，应加口径注。

## 附：过程教训四条

1. 形式清点按"应变幂次 × 周期函数"矩阵清点，不按族名：$(\Delta v)^2\cos$ 与 $(\Delta v)^1\cos$ 是两个形式，前者真空稳定且非全导数，漏扫它就漏掉了半支候选。
2. 恒真对照须隔离被试项：S4 首版把常数项与 $g_3$ 交叉项同开，$\xi = 0.5$ 档读数与主扫描逐位一致暴露了这一点；隔离后 PASS。
3. NaN 先查真实失稳再归协议伪影：$\xi = -3$ 档发散最终定性为能量无下界的物理性质，发散检测进了弛豫器，发散档按实证登记。
4. 构型跳变区的变号插值无物理意义：$D$ 从 $+2.29$ 跳到 $-2320$ 之间的"门槛 $4.002$"是伪影，脚本已标注，判读按"新相入口"处理。
