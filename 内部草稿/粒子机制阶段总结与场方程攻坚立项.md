## 一、阶段判断：已闭合清单（凭据版）

## 二、行军地图：四站

**第一站：三维复合位错（C1，最近且风险最高）。** 裸环前车之鉴：一维一切安好，三维 Derrick 一次塌到底。复合位错多了锚核，稳定性问题已被改变（钉扎阱数值确认存在），但形态与稳定性必须数值回答。判据：法线轴弹性 + 锚核的三维位错形态枚举、Derrick 型稳定性复查（梯度流 + 惯性双协议）、驻留判定。产出决定 C3 能否启动。

**第二站：定量对接（C2、C3 + 归一化）。** 锚核身份（PN 势与 $\kappa_\varphi$ 三元组锁定恒等）、落窗区宽度-色散同测（C3）、写入幅度 $w$ 与 $8\pi Gm$ 归一化。此站完成则 $G$ 从自洽输入走向机制导出，粒子与真实引力常数接通。

**第三站：标量到张量的定量桥（主战役，爱因斯坦场方程）。** 老论文 §6.2 自评"巨大理论空白"，未被后续进展覆盖，是地图上最大的一块空白；但材料已齐：源有微观身份（复合位错的碰撞写入，$\delta\theta = m/m_P$）、介质有裁定弹性（非紧致法线轴，稳态给泊松已验证、加时间项即 $c$ 传播波方程）、$3+1$ 分解有雏形（时间向写入铰链：潮汐无迹、瞬时源决定）。分四段推进：

- (a) SO(3) 标架 $3+1$ 分解的定量装配（脚本 3 雏形扩展，显式 4D 链接合成替代潮汐代理）；
- (b) 动态写入-波动方程：写入接力加时间项导出 $c$ 传播波方程，完成 $c_s$ 与 $c$ 的同一化；
- (c) 潮汐项与曲率的对应：$(0i)$ 铰链亏损升级为里奇张量分量的显式构造；
- (d) 源项 $T_{\mu\nu}$ 的微观分解：复合位错的碰撞写入形态对应能量-动量张量的各分量。

判据：连续极限恢复爱因斯坦场方程的静态之外分量 + 引力波波动方程。依赖：(a)(b) 不依赖三维位错（标量层可先行），(c)(d) 依赖 C1 的源形态。

**第四站：形式化收尾（并行低火）。** 凝固动力学（波性侧相干丢失 + 粒性侧锚定的完整形式化）、单系统 Born 采样、先验纠缠到格点键的映射（O1）、toric code 层向三维螺旋格点推广（C4）。
