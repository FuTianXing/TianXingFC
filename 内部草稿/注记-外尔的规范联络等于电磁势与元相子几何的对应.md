## 一、外尔 1918 的三步推理

**第一步（数学必然）：局域规范不变要求联络。** 若物理规律允许每个时空点独立改变相位基准（局域 $U(1)$ 变换），不同点的相位比较就必须引入联络（搬运规则），告诉"把 A 点相位搬到 B 点途中怎么转"。

**第二步（结构匹配）：联络的曲率与电磁场同构。** $U(1)$ 联络的曲率是二阶反对称张量 $F_{\mu\nu}$，6 个独立分量，与麦克斯韦电磁场分量数相同。

**第三步（对象同一）：变换规律相同 = 物理对象相同。** 电磁势变换 $A_\mu \to A_\mu + \partial_\mu\chi$，联络在局域变换下的变换形式相同。变换性质相同，即同一个数学对象的两个名字。$A_\mu$ 不可观测（规范依赖），$F_{\mu\nu}$ 可观测（规范不变），恰是"联络 + 曲率"结构的原型。外尔由此断定：规范联络就是电磁势，电磁学就是 $U(1)$ 规范几何。

## 二、历史转折：为什么选相位而不是长度

外尔 1918 年最初的规范是**长度标尺重定标**（标度变换），被爱因斯坦批评（长度重定标破坏可观测长度）。1929 年 London 指出应换成**相位变换**（波函数相位），规范理论才成立。

元相子几何对此给出结构裁决：**为什么是相位而不是长度？因为元相子的实轴方向（相位零点）是自由变量（柔性层），而半径（$\hbar$，长度标尺）是刚性固定的（刚性层）**。实轴方向可独立转动，半径不可变。规范变换的对象只能是可变自由度（实轴方向），不能是刚性的量（半径）。外尔当年的错误（选长度）与 London 的修正（选相位），由刚性层/柔性层的结构直接裁决：能变的才配做规范自由度。

## 三、元相子几何中电磁势的对应

| 电磁量 | 元相子几何对应 |
| --- | --- |
| 电磁势 $A_\mu$ | 实轴方向场的联络：$A_a$ = 相邻元相子实轴方向的差（空间连接规则），$A_0$ = 时间方向相位搬移畸变（电势 = $-A_0$） |
| 电磁场 $F_{\mu\nu}$ | 实轴方向场的曲率：电场 = 时间-空间曲率，磁场 = 空间-空间曲率 |
| 规范变换 | 实轴重定义（每个元相子独立重选相位零点） |
| 电势 | 绕数结构（电荷）的时间方向相位畸变（$A_0 = -\varphi$） |
| 矢势 | 实轴方向场的空间连接规则 |

**通俗版**：每个元相子的实轴方向（相位零点）是它自带的起点标记。相邻元相子的起点标记不同，要比较相位必须知道"从 A 的起点到 B 的起点怎么换算"，此换算规则即电磁势。换算规则绕一圈不还原（净扭转），即电磁场。

## 四、元相子几何对外尔推理的推进

外尔说"规范联络 = 电磁势"，元相子几何说"实轴方向场的联络 = 电磁势"。同一个数学，元相子补充了联络的物理载体：实轴方向是元相子的几何自由度（独立圆心方案 B），把外尔的抽象联络落实为可理解的几何对象。外尔需要公设局域规范不变，元相子几何把局域规范不变还原为实体结构推论（每个元相子有自己的实轴方向，重定义不改变物理）。
