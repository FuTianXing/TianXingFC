## 一、定位与分层声明

单体层的公设降级已完成（方程、质量、势、概率、演化）。Q2 的目标：$N$ 个粒子型模式块（σ 锁定缺陷 + 慢包络）的联合动力学。多体薛定谔方程的标准形式为

$$i\hbar\,\partial_t\Psi(\mathbf{x}_1,\dots,\mathbf{x}_N,t) = \left[\sum_k\!\left(-\frac{\hbar^2}{2m_k}\nabla_k^2 + V_k(\mathbf{x}_k)\right) + \sum_{k<l} U_{kl}(\mathbf{x}_k - \mathbf{x}_l)\right]\Psi$$

推导得分两块：联合包络动力学（单体五步的多块版本，本节完成）与交换统计（§四，按体系审查分层）。

**统计分层声明（沿用《π 扭转的层次分解》）**：交换统计的选择落在 $\mathbb{Z}_2$ 的哪一支，纯几何无法裁决（三维构型空间交换群只提供变号与不变号两个选项），需要动力学定理。本稿不越过此线：值层面（自旋 = 内部拓扑）与统计层面（交换分支）分开陈述，统计层面走自旋-统计定理的前提验证路径，并给出机制通道候选。

## 二、多块格点动力学

体系内粒子 = σ 锁定孤子（同步相变局域缺陷），携带慢包络自由度。取 $N$ 个粒子型模式块，第 $k$ 块在格点 $n$ 的振幅 $\psi_{k,n}(t)$ 满足

$$\ddot\psi_{k,n} = -\omega_{0k}^2\,\psi_{k,n} + c^2(\nabla^2_{\text{lat}}\psi_k)_n + (\text{块间耦合})_n$$

块间耦合由两类源构成：硬核排斥（圆心不可重合：两缺陷不得占据同一格点，$\psi_{k,n}\psi_{l,n} = 0$ 的约束式）与相位耦合（同类耦合对两个孤子模式的重叠贡献，长程候选）。单体五步（旋转波分解 $e^{-i\omega_{0k}t}$、缓变包络、长波极限）对每块逐字成立，得单块包络方程

$$i\hbar\,\partial_t\Psi_k = \left(-\frac{\hbar^2}{2m_k}\nabla_k^2 + V_k\right)\Psi_k, \qquad m_k = \frac{\hbar\omega_{0k}}{c^2}$$

（质量恒等式逐块成立。）

## 三、联合包络与多体薛定谔方程

**组装规则**：联合波函数由块包络按交换统计组装。对可区分（块拓扑可辨）情形，联合态为张量积 $\Psi = \prod_k\Psi_k$；对全同粒子（块拓扑同型），联合态为置换群的对称（+1）或反对称（−1）组装（§四决定支）。联合密度的份额语义：$|\Psi(\mathbf{x}_1,\dots,\mathbf{x}_N)|^2$ = 各位置联合占有份额密度，$\int|\Psi|^2\prod d^3x_k = 1$（联合份额恒等式，份额语义的多块推广）。

**联合演化方程（推导）**：N 块包络方程取直和（单块项）+ 相互作用项（块间耦合的慢包络）。相互作用的两类形态：硬核排斥在包络层对应短程势（$\mathbf{x}_k = \mathbf{x}_l$ 处，接触型），相位耦合重叠对应长程修正（候选）。联合方程：

$$i\hbar\,\partial_t\Psi = \left[\sum_k h_k(\mathbf{x}_k) + \sum_{k<l} u_{kl}(\mathbf{x}_k - \mathbf{x}_l)\right]\Psi$$

其中 $h_k$ 为单块哈密顿（$-\hbar^2\nabla_k^2/2m_k + V_k$），$u_{kl}$ 为块间有效势（硬核排斥的包络投影，短程）。推导步骤与单体完全同源（谱对偶、旋转波分解、缓变近似），无新假设；$u_{kl}$ 的具体形态由硬核约束的包络投影给出，其短程性继承圆心不可重合。

**概率流守恒**：联合方程的物质守恒对应 $\partial_t|\Psi|^2 + \sum_k\nabla_k\cdot\mathbf{j}_k = 0$，即联合份额守恒（多体幺正性，份额恒等式的多块形式）。

## 四、交换统计的份额来源（分层）

**值层面（自旋 = 内部拓扑）**：粒子缺陷内部为半扭转环（反周期边界条件 $\psi(\theta+2\pi) = -\psi(\theta)$），自旋量子数由扭转奇偶承担（《π 扭转的层次分解》命题 1；值层面与统计层面分离后保留）。

**统计层面（自旋-统计定理的前提验证）**：标准自旋-统计定理（相对论性、正能谱、微观因果性三前提 → 半整数自旋为费米、整数为玻色）在体系内的对应物逐一核对：

| 标准前提 | 体系内对应物 | 状态 |
| --- | --- | --- |
| 相对论性（洛伦兹协变场方程） | 有质量模式准相对论色散 $\omega^2 = \omega_0^2 + c^2k^2$（低能），完整洛伦兹由 P11 分层支持 | 条件性成立 |
| 正能谱 | 能隙 $\omega_0 > 0$（$m > 0$），谱 $\omega \ge \omega_0$ | 成立 |
| 微观因果性 | 群速度 $v_g < c$、接力几何光锥即因果边界 | 成立 |

三前提在体系内均有对应物后，可援引标准定理得：半整数自旋（奇数 $\pi$ 扭转）粒子交换变号（费米），整数自旋（偶数扭转）交换不变号（玻色）。此路径把统计选择落到标准定理 + 三个物侧前提，避开"纯几何裁决"的越界，与《π 扭转》统计重建路径一致。严格程度：前提验证为条件性（相对论性一行依赖 P11），结论继承标准定理。

**机制通道（候选）**：交换 = 两根缺陷世界线的编织。3+1 维中世界线可互相绕开，交换群为 $\mathbb{Z}_2$，编织相位由内部相位结构的相对缠绕给出：缠绕一次 → 偶数扭转不变号、奇数扭转变号（$Lk = Tw + Wr$ 通道；任意子注记：单模式缠绕给出 ±1）。2+1 维约束平面内必须编织，相位任意（任意子，体系对分数统计的衔接点）。此通道登记为候选，不承担论证（与审查降级一致）。

**份额语义的组装推论**：全同粒子组装中，反对称要求 $\Psi(\dots, \mathbf{x}_j, \dots, \mathbf{x}_i, \dots) = -\Psi(\dots, \mathbf{x}_i, \dots, \mathbf{x}_j, \dots)$，对应联合份额在坐标对换下不变（$|\Psi|^2$ 对称）而相位变号。泡利不相容（同态双粒子反对称 → 对角位置 $|\Psi(\mathbf{x},\mathbf{x})|^2 = 0$）由此获得份额语义表述：两缺陷同格点在硬核层已被禁止，包络层由反对称性自动维持。

## 五、与标准多体量子力学的一致性

低能一致的逐项核对：乘积态（可区分）、全同粒子组装（玻色对称/费米反对称）、联合概率 = 份额乘积、纠缠 = 块间相位关联（先验纠缠映射）、相互作用项结构（短程排斥 + 候选长程项）。与标准多体薛定谔方程在低能逐项吻合，故与全部既有多体实验兼容；差异仅在普朗克修正（继承单体层签名）与相互作用项的具体形态（$u_{kl}$ 的晶格来源）。
