## 一、问题的精确表述

缝隙 1：静电场有两个定义。
- 静电学语言（[[电荷的几何本质：满周闭合环内部U(1)缠绕数方案的系统辨析|电荷的几何本质]]§6）：电势 φ = 校准平衡位形，源 = 绕数 n，$\nabla^2\varphi = -4\pi n\,\delta^3$，$\mathbf{E} = -\nabla\varphi$
- 电动力学语言（[[电磁场的元相子几何：麦克斯韦方程组的双重几何来源|电磁场的元相子几何]]§3）：电场 = 联络的曲率 $E_a = F_{a0} = \partial_a A_0 - \partial_0 A_a$

两套语言的合并要求建立 φ 与 A_0 的精确对应。

## 二、候选方案排查（自审记录 1）

**候选 A（废弃）**：A_0 = ∂_t α（实轴方向演化速率）。静电要求 A_0 ≠ 0，即实轴方向持续旋转，需要持续驱动，属于天行力排除的无目标持续驱动（注释十第 2 点：驱动力与恢复力互补，驱动必须有目标）。此即已被废弃的实轴旋转源方案的重现（永动机问题）。排除。

**候选 B（废弃）**：A_0 = 摆程节律畸变（改变 ω_P）。ω_P 是刚性层（公理 5），节律不可变。排除。

**候选 C（采纳）**：A_0 = 时间方向相位搬移畸变。绕数结构（电荷核）的相位单方向缠绕，每闭合周期搬移 2πn（注释十六）；真空元相子每摆程搬移 2π。两者的差即时间方向相位搬移畸变，其空间分布从绕数结构中心向外衰减，此分布即静电势。

## 三、核心方案：相位搬移畸变场 A_μ

### 3.1 机制定义

定义时间方向搬移畸变：

$$A_0(\mathbf{x}) = \text{绕数结构在时间方向的额外相位搬移率} = \omega(\mathbf{x}) - \omega_P$$

其中 $\omega(\mathbf{x})$ 是局域相位搬移率：绕数结构中心 $\omega = n\omega_0$（内禀频率，每闭合周期 2πn），真空远处 $\omega = \omega_P$，过渡区连续变化。空间方向搬移畸变：

$$A_a(\mathbf{x}) = \text{相邻格点相位搬移的取向差} = \alpha_{n+\hat a} - \alpha_n$$

（注释八的空间联络定义）。

### 3.2 数学统一

静电势与时间联络的等同：

$$\varphi(\mathbf{x}) = -A_0(\mathbf{x}) \quad \Longleftrightarrow \quad A_0 = -\varphi$$

（库仑规范约定）。验证：

- 静电学：$\nabla^2\varphi = -4\pi n\,\delta^3$，$\mathbf{E} = -\nabla\varphi$
- 电动力学静态：$E_a = \partial_a A_0 - \partial_0 A_a$，静态 $\partial_0 A_a = 0$，$E_a = \partial_a A_0 = -\partial_a\varphi$ ✓
- 泊松方程统一：$\nabla^2 A_0 = 4\pi n\,\delta^3$（源 = 绕数 n）✓

**两套语言合并的结论**：静电学的"校准平衡位形"与电动力学的"时间联络静态位形"是同一个对象（时间方向搬移畸变场 A_0）的两种表述。绕数结构是搬移畸变的源（中心 2πn、远处 2π、过渡区为势的分布）。静电场 = 搬移畸变的空间梯度。

### 3.3 动态推广

电荷运动时，搬移畸变分布随时间演化，空间搬移畸变 A_a 也非零，电场由完整曲率给出：

$$E_a = \partial_a A_0 - \partial_0 A_a$$

法拉第定律 = Bianchi 恒等式（[[电磁场的元相子几何：麦克斯韦方程组的双重几何来源|电磁场的元相子几何]]§4，严格）。动态电场的"曲率语言"与静态电场的"平衡位形语言"在此统一为同一曲率公式的静态与动态情形。

## 四、自审记录 2（方案审查）

### 4.1 与传统物理兼容性

A_0 = φ（符号约定）是标准库仑规范结果。E = -∇φ - ∂_t A、B = ∇×A 全部保留。数学零改动，只补充机制。✓

### 4.2 与体系一致性

1. 无永动机问题：A_0 是搬移畸变的静态编码（中心 2πn、远处 2π 的分布），不要求实轴方向持续旋转（候选 A 已排除）。✓
2. 与刚性层兼容：不改变 ω_P（真空节律），绕数结构的 2πn 搬移是其内禀行为（电荷核，注释十六）。✓
3. 与注释八兼容：A_a = 相邻实轴方向差（原定义保留），A_0 获得机制内容（时间方向搬移畸变）。附件表"电场 = 实轴方向场动力学的时空耦合"获得具体实现。✓
4. 与[[电荷的几何本质：满周闭合环内部U(1)缠绕数方案的系统辨析|电荷的几何本质]]兼容：φ = 校准平衡位形保留，现在它是 A_0 的静态表述。"电势 = 相对相位畸变场"与"电势 = 搬移畸变"的统一：相对相位畸变的本质就是时间方向搬移畸变。✓

### 4.3 遗留问题

1. 过渡区的动力学：绕数结构中心 2πn 到远处 2π 的过渡区如何具体形成，依赖绕数与晶格的耦合动力学（校准作用量，未完成）。这是统一后唯一遗留的动力学环节。
2. A_0 的量纲与符号约定：需要按单位制（自然单位或 SI）明确 A_0 = -φ/c 的系数，本文用 φ = -A_0 的约定表述，物理内容不受影响。
3. 磁铁机制（缝隙 2）获得部分推进：A_a = 空间搬移畸变，静态磁场 = A_a 的空间涡旋；但自旋排列如何产生 A_a 涡旋仍待建立。

## 六、自审记录 3（数学一致性深度检查）

1. **符号检查**：E = -∇φ（静电学）与 E = ∂_a A_0（电动力学静态）在 A_0 = -φ 下恒等（∂_a A_0 = -∂_a φ）。泊松方程 ∇²φ = -4πnδ³ 与 ∇²A_0 = +4πnδ³ 自洽（∇²A_0 = ∇²(-φ)）。✓
2. **量纲检查**：φ = n/r 有 [1/L] 量纲（自然单位），A_0 = ω - ω_P 有 [1/T] = [1/L] 量纲（c=1），两者兼容。✓
3. **边界检查**：A_0 在远处 → 0（ω → ω_P），φ 在远处 → 0；中心发散由格点 l_P 截断（注释十二第 6 点）。✓
4. **机制自洽**：φ 的源（∇²φ = -4πnδ³）来自 ω 分布（中心 nω₀、远处 ω_P），搬移畸变分布决定势，无循环依赖。✓
5. **无永动机**：A_0 是搬移畸变的静态编码，绕数结构的 2πn 搬移是电荷核内禀行为（拓扑锁定），不需要持续驱动。与废弃的实轴旋转源方案（α̇ ≠ 0 需驱动）本质区别。✓
6. **动力学边界**：电荷运动时搬移畸变演化，此动力学依赖校准作用量（遗留 1），已诚实标注。✓

自审 3 结论：方案数学自洽（符号、量纲、边界全部通过），机制无永动机问题，遗留收敛于校准作用量。

## 七、结论

缝隙 1 的解决：静电势 φ 与时间联络 A_0 是同一对象（时间方向相位搬移畸变场）的两种表述。绕数结构（电荷）是搬移畸变的源，静电场 = 畸变的空间梯度，动态电场 = 畸变的曲率（Bianchi）。两套语言在 A_0 = -φ 处合并，无永动机问题，与传统物理零冲突，与体系全部既有结论兼容。遗留唯一的动力学环节（过渡区形成）收敛于校准作用量，与既有开放问题一致。
