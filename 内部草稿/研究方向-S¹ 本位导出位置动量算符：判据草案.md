## 一、问题与已锁定的约束

要回答的问题是：如何从 $S^1$ 上的角动量 $\hat J = -i\hbar\,\partial_\theta$ 导出位置算符与动量算符，并使标准对易关系恢复。既有四轮读数把候选构造的边界条件钉住了四条。

其一，单站点给不出相位读数，相位住关系层（第 139 条）。其二，整数谱与提升关系在模空间内部成立（第 140、148 条）。其三，提升关系的失配恰为一条连接，位置随切割选择移动，抹掉该连接后正则关系在覆盖空间上精确成立（第 161 条）。其四，有效接缝项等于 $Z$ 乘态在切割连接上的相干，光滑带限态上按 $Z^2$ 指数衰减，幂律衰减被排除（第 165 条）。

四条合起来给出一条硬约束：任何候选的位置、动量算符都必须把边界项显式带出来。边界项已被证明只挂在一条连接上，其大小由态在该连接上的权重决定，且随切割选择移动。

## 二、两条候选路线

**路线甲（先解卷后量子化）。** 取环的万有覆盖 $\mathbb{R}$，把 $\hat J$ 与提升相位搬上去，在 $\mathbb{R}$ 上定义 $\hat x = l_P\,\theta$（提升值）、$\hat p = (\hbar/l_P)\,\hat J$。标准对易关系在 $\mathbb{R}$ 上精确成立。代价是覆盖的选取（切开哪一条连接）成为构造的一部分，且从 $\mathbb{R}$ 回到物理的环要再做一次选择。

**路线乙（留在环上，把边界项作为规范依赖的读出）。** 保留 $Z$ 档环，用带限子空间上的投影算符定义 $\hat x_N$ 与 $\hat p_N$，核对标准形式的偏差恰等于边界项，并把边界项归到切割选择上。这条路线与第 136、152、161、165 条的规范结论同族。

推荐以乙为主、甲为对照：甲给出"精确成立"的极限陈述，乙给出该陈述在环上的偏差形式，两者合起来才是一条完整的导出。

## 三、期望形式（判据的解析来源，待核）

取 $\theta$ 在 $[0, 2\pi)$ 上取值，接缝落在 $0$ 处。对周期函数 $\psi$，

$$\partial_\theta(\theta\psi) = \psi + \theta\,\psi' - 2\pi\,\psi(0)\,\delta(\theta),$$

末项来自 $\theta\psi$ 在接缝处的跳变。于是

$$[\hat L, \hat\theta] = \hat L\hat\theta - \hat\theta\hat L = -i\left(1 - 2\pi\,\vert\delta_{\rm 接缝}\rangle\langle\delta_{\rm 接缝}\vert\right),$$

即对任意归一化态（$\int_0^{2\pi}\vert\psi\vert^2\,\mathrm{d}\theta = 1$，于是 $2\pi\rho$ 无量纲）

$$\langle[\hat\theta, \hat L]\rangle = i\left(1 - 2\pi\rho_{\rm 接缝}\right), \qquad \rho_{\rm 接缝} = \vert\psi(\text{接缝})\vert^2 .$$

取 $\hat x = l_P\hat\theta$、$\hat p = (\hbar/l_P)\hat L$，得

$$\langle[\hat x, \hat p]\rangle = i\hbar\left(1 - 2\pi\rho_{\rm 接缝}\right).$$

三个直接推论。其一，态在接缝处无重量时，标准对易关系精确成立。其二，偏差只由接缝密度决定，式中的 $2\pi$ 为跳变量（一圈）。其三，接缝位置属切割选择，故 $\rho_{\rm 接缝}$ 随选择变，第 165 条已把这一步的量级核过。

该式是本草案的**待核预期**，不是已确认读数。判据全部围绕它设计；若实测给出别的形式或别的系数，按实测订正并把教训写进过程记录。

## 五、与既有读数的衔接点

其一，与第 161 条的衔接：那里把失配定成单条连接，并通过抹掉它给出覆盖空间形式；本草案把同一条连接写成位置-动量对易关系的边界项，故 P8 是 161 的 W4 在位置-动量侧的对应。

其二，与第 165 条的衔接：那里把边界项的量级写成 $Z\rho$ 并给出三种区制；本草案的 $\rho_{\rm 接缝}$ 是同一相干在位置-动量侧的表现，P6 直接承接该轮的 S2（超指数衰减）。

其三，与第 140、148 条的衔接：整数谱与提升关系是本草案里 $\hat p$ 定义的前提（P3）。

其四，与定位注记的衔接：那里把标准形式的衔接条件列为三条（$e^{i\theta}$ 版本、无接缝权带限、准经典极限）；本草案的 P7 把"无接缝权"一条换成定量条件 $\rho_{\rm 接缝} \to 0$，把定性限制写成量值。

本草案不含新科学断言，只组织既有读数并给出待核预期。三条边界：其一，$\rho_{\rm 接缝}$ 的解析式在连续侧给出，格点上的系数换算由 P2 与 P4 核；其二，只处理单体一侧的算符定义，不涉及写入算符与曲率；其三，不涉及连续谱解卷（P3-14），该条与覆盖空间的严格构造有关，另案处理。
