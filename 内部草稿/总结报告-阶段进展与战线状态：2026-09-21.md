## 一、本阶段增量（按投入顺序）

**其一，条带分歧定位并关闭（第 335 条）。** 三向对照证明成因是 FFT 隐式把 $x$ 当周期，与竖条的两端固定几何不符，两端各多贴半张虚假壁；修正实现与第 286 条原实现逐位复现（$0.177866$ 与 $0.040242$，偏差 $0.00\%$）。作废范围收窄为第 333 条五档值与第 330 条条带表的小刚度档。

**其二，连续式的适用域与八档表（第 336 条）。** 修好实现后重测八档 $K$：$\sigma = \frac4\pi\sqrt K$ 只在 $K \le 0.02$ 档成立（差 $0.05\%$ 至 $1.2\%$），$K = 0.10$ 起掉到 $-14.3\%$，$K = 0.24$ 与 $0.30$ 差 $-33.0\%$ 与 $-38.1\%$。C1 的驻留窗口恰好落在失效区，这条读数把该线此前的量级估计标成了偏高。

**其三，大刚度档张力的解析式（第 341 条）。** 最优剖面认成「近整数平台加一次快速跳变加指数尾」，得到调和式 $\frac12 - \frac{1}{3+4\pi^2K}$、四阶式 $\frac12 - \frac1A - \frac{4\pi^4K}{3A^4}$ 与尾闭式（$\cosh\kappa = 1 + 2\pi^2K$）。

尾闭式与一维精确极小逐位重合（$K \ge 0.5$ 档 $1.3\times10^{-13}$），大 $K$ 渐近系数由四点拟合确认，两支交接点 $K^{*} = 0.051326$（四阶支）与 $0.061512$（调和支）闭合上轮待办。一维精确极小与第 336 条八档三维读数逐位一致（$0.002\%$），故那张表无需修正。

**其四，C1 窗口驻留判据重测并判负旧口径（第 342 条）。** 把 AN 构型的拉力搬到 $K = 0.24$ 与 $0.30$ 档，实测给 $1.0731$ 与 $1.3011$，而同档张力闭式为 $0.4186$ 与 $0.4318$，比值 $2.56$ 与 $3.01$。

诊断定位成因：边界环按芯的解析相位冻结，其势能斜率随芯位漂移（占实测拉力 $84\%$ 与 $86\%$，小档只占 $24\%$），把环改成不带漂移的取法后拉力降到 $6.5\times10^{-4}$ 与 $2\times10^{-6}$，弦在该构型里不出现。结论：该几何缺「强制一次净跳变」的边界数据，C1 窗口的驻留数须换条带几何重测。

**其五，固化与改口。** 术语表第十节新增「台阶面壁张力（两支与闭式）」一目并补节标题增补日期；时空观 §三 补机制段（标为解析式级）与 §十 边界句；子理论索引改台阶面核心结论行；论文 [[台阶面的拓扑：三维元相子缺陷的结构、保护与写入节拍]] §5.1 写入可引用命题；C1 论文 §5.1／§5.3／§7.1 与攻坚计划补口径限定。

## 三、困难清单（按性质分类）

**口径类。** 这一类是本阶段撞得最多也最值得记的：条带分歧用了两轮错误归因才定位到边界实现；C1 驻留判据的拉力把边界相位漂移当成了弦张力。两件都属读数没错而口径错，共同特征是数值稳定可复现、梯度与残差都能收敛，靠收敛指标查不出来。

**工具类。** 钉扎涡旋对的显式梯度下降不收敛（第 288 条判负，末步 $3.2\times10^{-1}$），环稳定性与 C6 第一项都卡在这里，办法是长波加速或隐式格式。刚性区松弛器已由第 330 条修好，可作为先例。

**裁决类。** 物理质量档未裁（哪一档 $K$ 对应体系自己的缺陷），直接决定 C6 第一项前置；体系自身的 $K$ 取值因此仍空着，时空观 §十 已登记。另有 P4-5 的三项裁定、测量纲领裁决点 3 与 6。

**结构性。** 三维形态的唯一性（为什么取面壁与点而不取线）仍属形态学问题；张量桥分段 (c)(d) 的非线性封装以 C1 为门控；战线三的「为何非紧致」与「为何取三维」维持纲领表述。
