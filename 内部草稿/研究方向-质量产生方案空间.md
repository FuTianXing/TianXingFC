## 二、七案详述

### ① 单环内部扭转（详见《研究方向-费米子质量重构-单环内部扭转.md》）

- 机制：费米子 = 奇数半扭转闭合心物双螺旋环（莫比乌斯型），自旋 1/2 来自反周期边界条件，质量来自环上驻波：$m = hN/(Lc)$。
- 体系依据：守恒律表（自旋 = 内部 $\pi$ 扭转次数）；定理 5；自耦合定理；心物双螺旋。
- 优点：自旋/统计/质量同源；无新装置；化解自耦合定理冲突。
- 硬伤：标度难题（$m_e/m_P \sim 10^{-22}$）；半扭转环稳定性论证待做。

### ② 本征谱（CY 上同调）

- 机制：质量 = 粒子内部几何流形上 Dirac 算子本征值，$m_f = \hbar\lambda_f/c^2$，$\lambda_f \in \operatorname{Spec}(\not{D})$。代际 = 谱阶数。
- 体系依据：卡拉比-丘构造论文 §8.2（"费米子质量谱由 CY 的特定上同调类决定"）；定理 5；公设 4。CY 为 Ricci 平坦 Kähler 流形，天然 spin 流形。
- 优点：本征值无自由函数；代际 = 阶数；与弦论 KK 紧致化同族，外部锚点最强。
- 硬伤：需确定具体 CY 与嵌入方式；谱不可解析（需对称性约化）；三圆纠缠（$SU(3)$）玻色性，费米子 spin 嵌入需新论证。

### ③ 内部满周节律稀释

- 机制：内禀频率 = 粒子内部有效满周节律，$\omega_0 = \omega_P/n$，$m = m_P/n$。
- 体系依据：元相方程 (II) 狄拉克梳；粒子脉动定理。
- 优点：完全使用体系核心动力学，概念最直接。
- 硬伤：等间隔谱与实验冲突；$n$ 量子化机制无来源；$10^{22}$ 因子无从产生。当前最弱，备选。

### ④ 先验纠缠质量

- 机制：惯性质量 = 粒子内部元相子与环境（元相海）的先验纠缠度，$m \sim (\hbar/c)\cdot dS_{\text{ent}}/dA$。
- 体系依据：公设 5（纠缠强度定义涌现距离）；先验纠缠（$\mathcal{H}_{\text{total}}$ 不可分离）；信息守恒律。
- 优点：与熵引力/全息原理同族（Jacobson、Verlinde）；自然给出马赫式惯性；与像素偏转 $\delta\theta = m/m_P$ 衔接天然。
- 硬伤：连续量给不出三代离散谱；面积律在粒子尺度存疑；数值标定无路。

### ⑤ DOGA 粒核凝聚

- 机制：粒子 = 元相海中满足 DOGA 稳态条件的自持凝聚，质量 ∝ 粒核值 $m_f \propto \sqrt{\tilde{O}\tilde{G}/\tilde{A}}\big|_{\text{稳态}}$。
- 体系依据：天行方程粒核；DOGA 四序参量；兴盛吸引子 $(1,1,1,0)$。
- 优点：与天行方程直接衔接；粒核公式现成；给出质量产生的动力学叙事。
- 硬伤：DOGA 是宏观统计，单粒子序参量微观定义不存在；连续量给不出离散谱；数值预测无路。

### ⑥ 相位锁定凝聚

- 机制：背景元相场自发相位对齐后，粒子内部相位与锁定模的重叠产生质量，$m_f = \kappa\langle\Psi_f|\Psi_H\rangle v$。
- 体系依据：旧方案 §6.1（Higgs 吸收为全局相位锁定模）；$\tilde{D}$ 全局平均值对应 $v$。
- 优点：解释质量产生的动力学事件；与标准模型 Higgs 机制同族。
- 硬伤：只解释产生事件，不解释数值；$v$ 来源需 ⑤ 补充。单独使用即"Higgs 换皮"。

### ⑦ G 刚度振荡

- 机制：闭合环弹性扭转振荡基频，刚度来自时空生成刚度 $G$，$\omega_0^2 = \kappa/I$。
- 体系依据：定理二公设 3（$G$ 为时空生成刚度）；元相方程 §5.3（$G$ 为偏转柔度）。
- 优点：$G$ 直接参与，引力与质量同源，符合"引力本来就是量子的"主张。
- 硬伤：具体形式未定；无量纲参数易滑回拟合。备选。

## 四、三层架构（合并建议）

单方案难过"离散谱 + 数值 + 公理衔接"三关，三个互补方案叠加为完整架构：

1. **拓扑层（① + ②）**：费米子 = 奇数扭转闭合双螺旋环，质量谱 = 环上本征值谱。① 回答"费米子从哪来"（自旋与统计），② 回答"质量是多少"（谱计算）。合流为"扭转环的谱论"。
2. **凝聚层（⑤ + ⑥）**：背景场相位锁定给出质量产生动力学事件，DOGA 演化给出凝聚强度数值（旧方案 §9.1 预告的"从天行方程推导 $\tilde{D}_{\text{global}}(t)$"方向）。回答"谱如何被调制"（同代内差异、轻子/夸克差异）。
3. **纠缠层（④）**：惯性机制与引力衔接，解释"为什么质量弯曲时空"（$\delta\theta = m/m_P$ 的微观根源）。

拓扑层定谱，凝聚层定调制，纠缠层定惯性。三层分别对应体系三支柱：元相子几何、天行方程、先验纠缠。
