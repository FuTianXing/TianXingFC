## 一、问题重述：A1 的精确形态

论文 §3.1 确定空间系数的方式是：取 ansatz $h_{ij} = 2\lambda\,\theta\,\delta_{ij}$，算出 $G_{ij} = (1-\lambda)E_{ij}$，再用"真空要求 $G_{ij} = 0$"、结合源外潮汐 $E_{ij} \neq 0$，得唯一解 $\lambda = 1$。其中 $G_{ij} = 0$ 是真空爱因斯坦方程，即本文声称要导出的对象。用它定系数，再在 §7 回扣"恒等满足线性化爱因斯坦方程的 00 分量"，构成循环。

本轮核实补充两点，使 A1 的形态比报告更精确：

其一，$\lambda$ 与 PPN 参数 $\gamma$ 同指。本文度规 $g_{ij} = (1 + 2\lambda\theta)\delta_{ij}$ 与标准 PPN 形式 $g_{ij} = (1 + 2\gamma U)\delta_{ij}$ 逐项对应（$U = Gm/(c^2r) = \theta$），故 $\lambda = 1$ 等价于 $\gamma = 1$。$\gamma = 1$ 的独立经验判定途径是光偏折角 $(\gamma+1)/2 \cdot 4GM/(c^2b)$，即 P1-24。

其二，$\lambda = 1$ 也可以从场方程的 00 分量（含源）反解出来，而不止真空分量。对一般 $\lambda$ 复算：$R_{00} = -\nabla^2\theta$、$R_{ij} = (1-\lambda)\partial_i\partial_j\theta - \lambda\delta_{ij}\nabla^2\theta$、$R = (2-4\lambda)\nabla^2\theta$，故 $G_{00} = R_{00} + \tfrac12 R = -2\lambda\nabla^2\theta$。代入记录方程 $\nabla^2\theta = -4\pi G\rho/c^2$ 与 $T_{00} = \rho c^2$，得 $G_{00} = 8\pi\lambda G\rho/c^2$，要求 $G_{00} = 8\pi G T_{00}/c^4$ 即 $\lambda = 1$。也就是说，$\lambda = 1$ 等价于在 00 分量上假定爱因斯坦方程。两条路径（真空空间分量、有源时间分量）都归于同一循环，说明这超出措辞层面，指向当前形式化缺少一个独立的 $\lambda$ 来源。

## 二、方案二可行性预判：从碰撞写入导出 $\lambda$

**结论：在当前形式化下不成立。** 障碍是结构性的，且已被体系自己的材料记录在案。

### 2.1 设想的论证及其落点

方案二的思路是：引力的记录载体是同一个法线场 $\theta$，标架统一写为 $F(x) = \exp(\theta(x)K)$，于是时间链接 $U_0 = F(n,t+1)F(n,t)^{-1}$ 与空间链接 $U_a = F(n+\hat a)F(n)^{-1}$ 都由同一个 $\theta$ 生成，系数自然相同，从而 $\lambda = 1$ 由"同一载体"推出，无需额外假设。

这个论证的成立前提是：空间链接能独立读出 $\theta$ 的贡献。而这一步恰好被证伪。

### 2.2 决定性证据：纯规范陷阱

`验证脚本/注记-张量桥分段a S1探测结果：纯规范陷阱重现与判据修正.md` 记录了直接探测结果。在 SO(3) 标架 3+1 装配中，单值标架场 $F(n)$ 的空间链接 $U_a = F(n+\hat a)F(n)^{-1}$ 绕格面的乘积伸缩恒等抵消，空间格面亏损为机器零（$1.7\times10^{-17}$，远场 $9.2\times10^{-18}$）。该注记的结论原文：

> 3+1 雏形的牛顿扇区能工作，恰因它用的是标量二阶差分代理，该代理在 SO(3) 表述下没有对应物。

> 空间曲率应从"时间向潮汐 + 真空里奇约束"导出（直接测空间格面亏损一途已失效）。

也就是说，现形式化中**空间扇区不携带任何独立的 $\theta$ 信息**：只要标架是单值的，空间 holonomy 恒为零，无论 $\theta$ 多大。$\lambda$ 无法从空间链接读出，因为它根本没有读数。

### 2.3 两条逃逸路线及其成本

路线甲：改变写入的作用对象，从格点标架改为链接（非可积链接），使空间扇区获得非零曲率。这正是 S1 注记第五节风险 2 登记的选项，原文判断其"将触及碰撞写入的本体层形式化（开放问题总览第 32 条本体层三项），属更大工程"。成本：需重建写入的本体层表述，并重新验证已闭合的五层冲突与稳态格林函数链，量级远超一次论文修订。

路线乙：证明"同一载体必然同幅"不依赖标架构造。但 §2.2 的证据表明，在单值标架下 $\theta$ 只住时间向（其空间二阶差分给出时间向曲率 $R_{00} = -\nabla^2\theta$），空间向没有独立的 $\theta$ 通道可供"同幅"。因此该路线要求先解决路线甲的同一个本体层问题，不构成独立的第二选项。

### 2.4 对评审判断的修正

第四轮评审把方案二列为"收益最高但唯一可能白做的路径"。本轮核实后应升级为：**方案二在当前形式化下不可执行**，其真正障碍（空间扇区纯规范）已由 S1 注记独立记录，属结构性障碍，超出表述层面。这也意味着 A1 超出措辞瑕疵：现形式化确实缺一个非循环的 $\lambda$ 来源，方案一（降级）如实描述当前状态，超出权宜之计。
