## 一、定位

粒子 = 拓扑孤子（kink，Q3）与模式块（Q2）的双重实现。本稿把多粒子态空间写成 Fock 形式：每个粒子对应一个模式块（含份额 $p_k$），总系统份额恒等式为

$$p_{\text{vac}} + \sum_k n_k p_k = 1$$

其中 $n_k$ 为模式 $k$ 的占有数，$p_{\text{vac}}$ 为剩余系综（真空块）份额。产生 = 真空份额凝结为粒子块，湮灭 = 粒子块份额回归真空。

## 二、占有数表示与份额容量

一个粒子 = 一个拓扑孤子块（kink 的元相子构成数固定，对应份额量子 $p_k$）。多粒子态由占有数 $|n_1, n_2, \dots\rangle$ 标记（Q2 组装规则给出全同粒子的对称/反对称结构）。真空态 $|0\rangle$ = 全部份额留在剩余系综（$p_{\text{vac}} = 1$）。

**定理 F1（份额容量）**：总粒子数 $N = \sum_k n_k$ 受份额不等式约束：

$$\sum_k n_k p_k \le 1 \iff p_{\text{vac}} \ge 0$$

存在最大容量 $N_{\max} = \lfloor 1/p_{\min}\rfloor$（$p_{\min}$ 为最小粒子块份额），真空耗尽边界 $p_{\text{vac}} = 0$。证明：份额恒等式 + $p_k > 0$。$\blacksquare$

**推论（容量与体积）**：长波粒子块份额随体积稀释（$p_k \sim (V_k/V_{\text{total}})$），容量 $N_{\max}$ 随容器体积增长：有限宇宙内粒子数总有限（与系综守恒一致）。

## 三、产生湮灭 = 份额转移

**定义（份额转移算符）**：湮灭算符 $a_k$ 把模式 $k$ 的一个粒子块份额返还真空（$n_k \to n_k - 1$，$p_{\text{vac}}$ 增加 $p_k$）；产生算符 $a_k^\dagger$ 把真空份额 $p_k$ 凝结为模式 $k$ 的一个粒子块（$n_k \to n_k + 1$，$p_{\text{vac}}$ 减少 $p_k$）。份额在转移中守恒（总量 $\equiv 1$）。

**基的作用规则**：

$$a_k|n_k\rangle = \sqrt{n_k}\,|n_k - 1\rangle, \qquad a_k^\dagger|n_k\rangle = \sqrt{n_k + 1}\,|n_k + 1\rangle$$

系数 $\sqrt{n}$ 来自 Fock 标准结构；份额语义给出其物侧解释：模式 $k$ 内 $n_k$ 个等价块的置换权重（$n!$ 组合因子的平方根）。

**定理 F2（算符代数）**：按 Q2 统计层（费米 = 奇数扭转 + 相对论/正能/因果三前提；玻色 = 偶数扭转），份额转移算符满足

$$[a_k, a_l^\dagger]_\pm = \delta_{kl}$$

（$+$ 玻色对易、$-$ 费米反对易；系数 1 由"一个粒子 = 一个份额量子单元"固定，跨模式算符对易/反对易为零来自块的互斥性）。证明：份额转移的单单元性质 + 统计层结论。$\blacksquare$

## 四、场算符与真空的份额语义

**定理 F3（场算符 = 份额转移场）**：场算符展开 $\hat\psi(\mathbf{x}) = \sum_k \varphi_k(\mathbf{x})\,a_k$ 中，$a_k$ 为份额转移算符（定理 F2），$\varphi_k$ 为单粒子波函数（M1 概率幅层，份额开方像）。密度算符

$$\hat\psi^\dagger(\mathbf{x})\hat\psi(\mathbf{x}) = \sum_{k,l}\varphi_k^*\varphi_l\,a_k^\dagger a_l$$

其期望给出份额密度 $|\Psi|^2$ 的多体推广（对角项）与相干密度（非对角项，$\eta$ 复合律控制，Q4）。$\blacksquare$

**定理 F4（真空非空与真空涨落）**：真空态 $|0\rangle$ 携带剩余份额 $p_{\text{vac}}$ 与真空块相干涨落（$\eta_{\text{vac}}$ 的量子涨落，Q4 流给出尺度依赖）。相互作用项（Q3 双孤子势 / 三线性候选）可使真空份额激发为粒子对：

$$|0\rangle \to a_k^\dagger a_l^\dagger|0\rangle \quad (\text{份额：} p_{\text{vac}} \to p_{\text{vac}} - p_k - p_l)$$

此即真空极化的份额机制候选（接[[电荷的几何本质：满周闭合环内部U(1)缠绕数方案的系统辨析|电荷的几何本质]]开放问题 8：真空涨落激发探测粒子）。$\blacksquare$

## 五、哈密顿的 Fock 形式

单粒子项 $H_0 = \sum_k \hbar\omega_k\, n_k$（$\omega_k = \sqrt{\omega_{0k}^2 + c^2k^2}$，Q3 非线性修正按 Q4 参数流）；相互作用项（Q3 双孤子势）

$$H_{\text{int}} = \sum_{k<l} U_{kl}\, n_k n_l, \qquad U_{kl} = \int d^3x d^3y\, u_{kl}(\mathbf{x}-\mathbf{y})|\varphi_k(\mathbf{x})|^2|\varphi_l(\mathbf{y})|^2$$

（密度-密度型，Q4 重整化参数承担）。三线性产生项（模态转换通道，Q3 候选）：$H_{\text{decay}} = \sum g_{klm}a_k^\dagger a_l a_m + \mathrm{h.c.}$ 登记为候选（衰变/产生过程初胚）。演化由份额守恒（总份额 $\equiv 1$）与 Q4 的 $\eta$ 流共同约束。

## 六、与标准 QFT 的一致性

低能逐项一致：Fock 基、升降算符代数（定理 F2）、密度-密度相互作用、二次量子化展开（定理 F3）。体系特有的份额语义提供物侧解释层：场算符 = 份额转移；真空 = 剩余系综（真空不空）；真空涨落 = 真空块相干涨落（可激发粒子对，真空极化候选）。与[[量子场论地位总论：模式与实体的双层结构|量子场论地位总论]]的双层结构（模式层 = 份额转移场，实体层 = 元相子系综）直接衔接；与全部既有多体/QFT 实验低能兼容，差异仅在普朗克修正（继承各层签名）。
