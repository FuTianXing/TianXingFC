## 摘要

量子力学攻坚线的 P1-11（σ 锁定动力学方程）长期缺一条自己的方程。本文把它补上，并把缺陷（σ 锁定孤子）的动力学收成一篇判据级论文。

方程取二阶晶格形式，势为整周锁定势 $K(1-\cos 2\pi u)$，等价地写成偏离量的 sine-Gordon 型。连续极限给出涨落缺口 $m_{\rm gap} = 2\pi\sqrt K$ 与孤子质量 $M = 4\sqrt{k_bK}/\pi$，两者比值 $4.93$，数值 kink 能量 $0.0898$ 与既有绑定能读数逐位相同。

质量按入路分成一组标签：孤子质量进能动量关系，形状范数 $\sum(\Delta w)^2$ 即响应质量并进终端速度律（$11.01$ 对 $11.08$，差 $0.56\%$），涨落缺口只进声子谱。既有迁移率 $18.9$ 反解出阻尼口径值 $\gamma_d = 0.5958$。

与三维复合位错线的口径映射给出两条结论：两线泛函逐点同一（残差 $0$，梯度流与过阻尼右端残差 $4.00\times10^{-13}$），但参数区间不相交（刚性区 $K \in [0.24, 0.25]$ 对软区 $K = 0.005$，质量比 $7.00$），跨区引用前须先定 $K$ 的体系值。

与写入机制的接口给出互补性的定理形式：份额 = 抽样落点分布，笔数 = 相位绕数增量。缺陷每穿一格恰写一笔（$18$ 组偏差 $0$），逐站笔数分布与份额分布的总变差 $0.9432$，抽样落点分布对份额的最大标准化偏差 $2.148$；欠计数比值 $0.3333$ 与记录机制线命题 17 独立一致。

密度与质量的入口为 $\rho_{\rm def} = fM\rho_P$，观测重子密度反解 $f = 9.07\times10^{-124}$，每格一缺陷与观测相差 $123.0$ 个数量级。

最小量子化取单个集体坐标：松弛到离散极小后零模唯一（与解析平移模重合 $0.999942$），形状范数与孤子质量同源，能级对 $\hbar$ 的标度精确为平方，零点能与格点缺口的零点能相差 $2.12$ 个数量级，两者不同源。三维定数与费米统计分别挂 C1 线与多体论文。

## 1 引言

记录机制线给出缺陷的写入规则与运动读数，三维复合位错线给出形态与驻留阈值，两条线都用到缺陷在动，但缺陷自己的方程一直缺位。缺位带来的后果是三处读数没有统一的动能与质量定义：驻留阈值只能表述为格点模型内的几何量，写入率与缺陷速度的关系只能取经验值，密度的入场只能靠量级估计。

本文的任务是补齐这条方程线。取二阶晶格动力学为甲形式（惯性主导），过阻尼梯度流为乙形式（耗散主导），两者在同势上给出同一 $k$ 结构，差别只在时间阶数。所有读数在最小模型上给出，并与既有读数逐项对照。

全文结构：§2 方程与候选形式；§3 连续极限与色散；§4 质量与迁移率；§5 与三维复合位错线的口径映射；§6 与写入机制的接口；§7 密度与质量的入口；§8 最小量子化；§9 三维形式（条件性）；§10 严格程度与遗留。

## 2 方程与候选形式

取相位场 $u_n$ 以整圈为单位（$u$ 增一等于指针转满一圈），甲形式的能量泛函为

$$E = \sum_n\Big[\tfrac12 k_b\,(u_{n+1}-u_n-1)^2 + K\,(1-\cos 2\pi u_n)\Big],$$

其动力学方程为离散 sine-Gordon 加驱动与阻尼

$$\ddot v_n = k_b\nabla^2 v_n - K\,2\pi\sin(2\pi v_n) + f - \gamma_d\dot v_n ,$$

其中 $v_n = u_n - n$ 为偏离量，键项在远离缺陷处为零。乙形式取过阻尼极限 $\gamma_d\dot v = k_b\nabla^2 v - K2\pi\sin(2\pi v) + f$，弛豫率 $\lambda(k) = \omega(k)^2/\gamma_d$，与甲同 $k$ 结构。

碰撞层与连续层分开读。碰撞层是纯置换（摆程方向标签交换），位置不变故势能不变，等速与「每拍走一格」只在该层成立；连续层里速率被锁定势逐点调制，调制量随 $K$ 增大（由 $0.0202$ 增至 $0.55279$）。

## 3 连续极限与色散

在锁定势的均匀基态上线性化，Hessian 本征值逐位等于

$$\omega^2(k) = (2\pi)^2K + 4k_b\sin^2(k/2),$$

与既有晶格色散族一致（最大偏差 $4.88\times10^{-15}$）。缺口由势的曲率给出，$m_{\rm gap} = 2\pi\sqrt K$。

孤子质量由标准 sine-Gordon 结果给出

$$M = \frac{4\sqrt{k_bK}}{\pi}.$$

链上数值松弛（开放链、偏离量参数化、两端固定在相邻整数）给 kink 能量 $0.0898$，闭式给 $0.0900$，偏差 $0.28\%$，且与既有绑定能读数逐位相同。缺口与孤子质量的比值为 $4.93$，故第 227 条的速度上限 $v_{\max}(m) = (\sqrt{m^2+4}-m)/2$ 中的 $m$ 只能取孤子质量，取缺口会给出明显偏小的上限。

## 4 质量与迁移率

平衡 kink 的平移模投影给出终端速度律

$$v_{\rm term} = \frac{f}{\gamma_d M_{\rm zero}}, \qquad M_{\rm zero} = \sum_n \Big(\frac{\mathrm dv}{\mathrm dn}\Big)^2 .$$

数值迁移率 $11.01$ 对理论 $1/(\gamma_d M_{\rm zero}) = 11.08$，偏差 $0.56\%$。形状范数由平衡剖面直接算出（$0.0903$），与响应质量（$0.0908$）相符，两者的同源性给出「响应质量等于形状范数」这一条。

三个质量标签的排序固定：形状范数 $0.0888$ 至 $0.0903$、窗口质量 $0.0936$、涨落缺口换算质量量级更高。前两者属同一刻度（相对散度 $1.67\%$），窗口质量偏离闭式 $4.0\%$，按独立刻度登记。

阻尼系数在此前的模型里是自由参数。既有迁移率 $18.9$ 与形状范数 $0.0888$ 反解出 $\gamma_d = 0.5958$，登记为本模型的阻尼口径值。此处须说明：这是把模型参数标定到既有读数，不构成对既有迁移率的独立预测。

## 5 与三维复合位错线的口径映射

D 线与 C1 线使用同一个能量泛函，差别只在参数取值。逐点核对给出两式相等（残差 $0$）；C1 的梯度流步长 $\eta$ 与本文的阻尼系数由 $\gamma_d = 1/\eta$ 换算后，右端逐点相等（残差 $4.00\times10^{-13}$，受有限差分精度限制）。势形、弹性归一化与相位单位三项全部相同。

参数区间不相交。C1 的驻留与脱钉读数落在 $K \in [0.24, 0.25]$，本文的孤子与迁移率读数落在 $K = 0.005$，两段孤子质量相差 $7.00$ 倍。C1 侧的边界声明早已写明「不验证 $K$ 的体系具体值」，本文把这一空缺读成结构结论：两线可以互换使用，但在参数空间上分居两段。

阈值口径需要分开。C1 的脱钉读数 $0.15$ 是相位扰动幅度，与 $K$ 的量纲不同，两者直接比较没有意义；可比的量是扰动能量对钉扎势幅度 $2K$ 之比，一维代理给出 $1.75\times10^{-1}$，属量级读数。

## 6 与写入机制的接口

写入规则取记录机制线的口径：指针每转满一圈记一笔，故单站笔数等于相位增量的绕数。缺陷每穿过一格恰写一笔，$18$ 组（速度 $6$ 档乘宽度 $3$ 档）偏差为 $0$，与速度、宽度无关。笔数是拓扑量，落在粒性侧计数。

单次穿越的逐站笔数分布均匀（每站一次），包络份额分布局域（平移零模的 $\mathrm{sech}^2$ 型），两者的总变差距离 $0.9432$。把逐站笔数直接读成份额，在逐事件层面不成立。

正确的配对是抽样：按份额抽取 $4096$ 个落点，每站笔数对期望值的最大标准化偏差 $2.148$（$3\sigma$ 内），频次分布对份额的总变差 $0.0198$。由此得到互补性在这条线上的定理形式：

$$\text{份额} = \text{抽样落点分布}, \qquad \text{笔数} = \text{相位绕数增量}.$$

采样定理的落点与记录机制线对上。跃迁时长达到取样间隔 $t_P$ 时全额计数（$4$、$2$、$1$ 三档比值 $1.000$），缩短到三分之一间隔时计数比 $0.3333$（$12/36$），与命题 17 的读数一致。两个速度上界有层次：采样上界为 $1$ 格每 $t_P$，色散带边给出 $v_{\max}(0.0900) = 0.95601$，后者更紧，质量趋于零时两界重合。

## 7 密度与质量的入口

把缺陷质量接到能量密度上取最简形式

$$\rho_{\rm def} = f\,M\,\rho_P, \qquad \rho_P = \frac{m_P}{l_P^3},$$

其中 $f$ 为缺陷占位份额。量纲自洽由 $m_P = \hbar/(t_Pc^2)$ 校验（偏差 $0$）。逆式给出观测到格点侧的入口：

$$f = \frac{\rho_b}{M\rho_P}.$$

取观测重子密度 $\rho_b = 4.2075\times10^{-28}\,\mathrm{kg\,m^{-3}}$（$\Omega_bh^2 = 0.0224$）与 $M = 0.0900$，得 $f = 9.069\times10^{-124}$。把 $f = 1$（每格一缺陷）代入，密度与观测相差 $123.0$ 个数量级。

敏感性：因 $f \propto 1/\sqrt K$，$K$ 的 $48$ 倍区间只让 $f$ 变动 $7.00$ 倍，相对 $123$ 个数量级的跨度可忽略。稀疏因子 $f$ 的体系内来源属同步相变密度的定量（P1 第 4 条），把它演化到今天属膨胀史（P8a）；本文交付的是把两端与观测量连起来的式子。

## 8 最小量子化

孤子扇区的最小量子化取集体坐标：把 kink 中心与共轭动量提升为算符，$\hat H_{\rm coll} = \hat P^2/(2M_{\rm zero})$。量子化的前提在离散模型上先要核清。

解析 kink 剖面直接离散化后，最低模为小负值（对第一个体模之比 $-0.0079$），说明它不是离散极小点。数值松弛到离散极小后，零模恰一个（$\lvert\lambda_0\rvert = 7.6\times10^{-7}$），其本征矢与解析平移模重合 $0.999942$，背景能量 $0.08978$ 与第 3 节的读数 $0.0898$ 偏差 $0.02\%$。

离散钉扎势垒为 $1.36\times10^{-9}$（对第一个体模能标之比小于 $10^{-3}$），其能量尺度对集体模频率之比 $4.07\times10^{-7}$。在这一档参数下，格点对缺陷的钉扎可以忽略。

环上集体坐标的能级为 $E_n = 2\pi^2\hbar^2n^2/(M_{\rm zero}L^2)$，最低能级间距 $3.336\times10^{-3}$（模型单位），能级对 $\hbar$ 的标度精确为平方（比值 $4.000000$），最小不确定态上 $\Delta X\Delta P = \hbar/2$ 精确饱和。

零点能的口径需要分开。环上集体模频率是尺寸效应（正比于 $1/L^2$），与格点缺口 $2\pi\sqrt K = 0.4443$ 相差 $2.12$ 个数量级。三-4 交付的折返点计数 $\tfrac12\hbar\omega_0$ 属单体与格点层，本节的零点能属集体模层，两者不同源、不可互换。

费米统计不在本节范围。最小量子化给的是玻色型集体模（平移模无内部扭转）；费米扇区需要 $\pi$ 扭转，归多体论文的统计分层处理。

## 9 三维形式（条件性）

同形泛函在 $d$ 维格点上给出 $(d-1)$ 维延展缺陷：二维给点状涡旋，三维给线缺陷，与三维复合位错线的形态同源。三维情形的定数与保护读数（驻留阈值、宽度窗口、弦结构）由 C1 线供给，本文只给形式，不给定数。

把本文的一维读数搬到三维需要两个前置：$K$ 的体系具体值与 C1 的驻留读数（$K_c = 0.24$ 至 $0.25$，壁宽 $l^{*} = 1.924$）。按第 5 节的口径结论，这两个前置未定之前，本文的质量与迁移率读数不能直接用于三维构型。

## 10 严格程度与遗留

| 结论 | 严格程度 |
| --- | --- |
| 方程形式与乙形式同 $k$ 结构 | 条件性（同势上的两种时间阶） |
| 涨落缺口 $m_{\rm gap} = 2\pi\sqrt K$ | 模型内严格（解析谱）加数值 |
| 孤子质量 $M = 4\sqrt{k_bK}/\pi$ | 解析（标准结果）加数值（$0.28\%$） |
| 终端速度律与响应质量等于形状范数 | 解析（平移模投影）加数值（$0.56\%$） |
| $\gamma_d = 0.5958$ | 口径值（由既有迁移率反解，非独立预测） |
| 两线口径同一与区间不相交 | 模型内严格（残差 $10^{-13}$） |
| 互补性的抽样形式 | 统计（$4096$ 次落点，$2.148\sigma$） |
| 密度入口 $f = \rho_b/(M\rho_P)$ | 读数（依赖量纲桥假设，见遗留） |
| 最小量子化 | 数值（零模、标度、饱和）加解析 |
| 三维定数 | 未做（C1 门控） |

遗留五项。其一，量纲桥：把模型单位换算为物理单位时取「模型能量单位等于 $m_Pc^2$」，这一步是口径假设，尚未从本体层导出。其二，$K$ 的体系具体值（C1 门控），本文已把它对结论的影响限定为 $7$ 倍。其三，份额剖面取平移零模，属模型选择，换成其它局域剖面会改变总变差的数值（定性结论不变）。其四，本节的「完全量子化」只做到单集体坐标，内部激发与多缺陷扇区未做。其五，三维定数与费米统计（分别挂 C1 与多体论文）。

## 11 结论

缺陷（σ 锁定孤子）的动力学可以用一条二阶晶格方程表述，其连续极限给出标准的 sine-Gordon 结构以及缺口与孤子质量两个量。质量按入路分成一组标签，响应质量与形状范数同源，终端速度律在 $0.56\%$ 内成立；阻尼系数由既有迁移率反解后从自由参数升为口径值。

与三维复合位错线的映射说明两线共享同一泛函而分居两段参数区；与写入机制的接口把互补性写成「份额 = 抽样落点分布，笔数 = 相位绕数增量」，并把欠计数比值与记录机制线独立对上；密度入口把观测重子密度翻译为格点层的稀疏因子 $9.07\times10^{-124}$；最小量子化在单个集体坐标上成立，零点能与格点缺口的零点能分属两层。
