## 一、任务与目标

P4-16 的目标是把「先验纠缠锁定帧」这句纲领表述形式化，第一步是回答锁定刚度 $\kappa$ 从哪里来。判据草案把路线分成三条：乙（保护距离，$\kappa = 1/d$）、丙（键能曲率，接第 178 条键线）、甲（由无穷张量积的整体态经同步相变投射导出）。作者裁决为乙为主、丙为对照、甲为升级，$\kappa$ 分两段走，谱隙与纠错条件的核算归测量纲领任务 2-3。

七轮的执行顺序是：200 立乙通道；205 把门槛系数从粗估定到实测带；209 交付丙通道并裁决归一化口径；208 挂起脱锁分量形状；210 起甲的测量先行轮；211 给出投射算符与纯度公式；212 独立导出扇区数 $N_W = L$；213 给出扇区分布的动力学来源；214 把成对事件接到缺陷密度；216 把扩散步数换成失配下的相干时间；218 给出扩散率的微观上限并报出缺口；219 裁决该缺口（判据过严，修正后所需通量落到 0.58、在因果上限之内；该读法与「适用窗」读法的区别见 §六 口径同步条）。

## 二、结论速览

其一，乙通道给出无自由常数的候选值：$\kappa = 1/d = 0.125$（$d = L = 8$），与场层闭式、同步门槛、保护距离与规模稀释逐条相容。

其二，门槛系数由粗估定到实测带：$\gamma_c/\kappa = 1.29 \pm 0.10$（六档，极差 $0.21$），比固定参考系高斯估计 $1.1774$ 高 $9.8\%$；噪声把门槛往下推。

其三，丙通道给出独立区间：键曲率可行域 $\kappa_e/\kappa_{\rm ref} \in [0.1, 1]$ 在线性口径下给 $\kappa_{\rm bond} \in [0.1, 1]$，含 $0.125$（所需曲率比 $0.125$，比第 178 条的刚度下限高 $25\%$）。口径裁决为线性。

其四，甲通道给出导出链：同步相变的像空间为「全站点同扇区」子空间（$P_{\rm sync}$ 幂等、迹为 $N_W$），裸耦合取扇区分布纯度 $\kappa = \sum_W p_W^2$；扇区数由整数格点恒等式独立导出为 $N_W = L$，故均匀分布下 $\kappa = 1/L = 0.125$。

其五，$p_W$ 的来源为相变前绕数扩散；$\pm1$ 单缺陷行走被宇称锁在两条子格内（纯度 $2/L$），达到 $1/L$ 需要成对事件（$\pm2$ 占比 $\ge 0.2$），且均匀值是吸引子。

## 六、边界与不成立范围

**模型边界。** 门槛与有效耦合的读数取回拉型模型（相位均值作参照）；键曲率通道取第 178 条的键能模型；投射与扇区部分取有限站点张量积与整数格点恒等式。

**口径同步（缺口消解的正确强度）。** 「缺口消解」只在「所需通量对因果上限」这一读法上成立：修正后所需通量落到 $0.58$，在 $\Gamma = p\,v \le 1$ 之内。
把框架自然取值 $p = 0.05$、$v = 1$ 代入，联合条件给 $\gamma \le 0.01388$，与门槛带中心 $1.29\kappa = 0.16125$ 不相交（前者约为后者的十二分之一）。
故 $\kappa = 1/L$ 的适用窗是失配约 $0.014$ 以下，门槛带所在的高失配区需按实际分布修正或走路线（b）对照；该限定与论文 [[锁定帧与格距无关性：先验纠缠的定量形式化]] 命题 20、21、24 对齐。

**不成立的读法。** 其一，不得把 $\kappa$ 的乘积形式 $\kappa(1-D)$ 或商形式 $(1-D)/N_{\rm eff}$ 当作甲的输出（第 210 条两候选均被否）。其二，不得把同步子空间当作全空间（它只是迹为 $N_W$ 的小投影）。其三，不得把叠加振幅平方和当纯度（份额恒为 $1$，纯度才给 $1/N_W$）。其四，不得跳过宇称谈绕数扩散的渐近分布。

其五，不得把 $V = \Gamma\tau$ 当方差关系（泊松计数的平方项即对事件，须写 $V = \tau(\Gamma+\Gamma^2)$）。其六，不得沿用 $V \ge L^2$ 的旧判据谈均匀化：正确阈值 $V^\ast = L^2/(4\pi)$（第 219 条裁决），且 $\kappa = 1/L$ 只适用于失配约 $0.014$ 以下的系统。

**覆盖边界。** 谱隙与纠错条件的独立核算归测量纲领任务 2-3；门槛闭式仍停在实测带（第 205 条），其阻塞点是脱锁分量形状（第 208 条挂起）；多维扇区标签口径未裁决。

## 八、剩余项与固化提案

**剩余项。** 其一，缺陷质量与穿越速度的关系（联合条件已用长波极限 $v = 1$ 给成 $\gamma \le \sqrt2\,p\,4\pi/L^2 = 0.0139$，质量修正已由第 227 条执行，结论是质量只把条件收紧：[[注记-缺陷质量与穿越速度的关系：晶格色散的质量缺口、v_max 的精确闭式与均匀化条件只被收紧]]；原记「归缺陷运动线 P1-32」为误标）；均匀化缺口已裁决（第 219 条，路线（a）成立，路线（b）登记为可选对照），裁决的适用范围见 §六 口径同步条：旧判据的过严部分消解，联合条件与门槛带不相交。
其二，多维扇区标签口径（$\kappa = 1/L$ 对 $L^{-d}$）。其三，脱锁分量的形状（第 208 条挂起），它阻塞门槛闭式。其四，由谱隙独立核算 $\kappa$（与测量纲领任务 2-3 分工）。

**固化提案（待作者裁决）。** 其一，是否把「锁定刚度 $\kappa = 1/d$ 与扇区纯度 $\kappa = \sum_W p_W^2$ 的同值关系」写入术语表（新增词条或补条目）。其二，速览第 27 条（复相干无序度）是否补一句"其与锁定耦合在同步扇区分布下取同一数值"。其三，子理论索引是否另立条目。其四，实验可检验预言清单是否补"失配边界 $\gamma_c = \kappa\sqrt{2\ln 2}$"（条件性命题）。
