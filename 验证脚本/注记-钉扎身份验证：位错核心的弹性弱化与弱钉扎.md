## 一、问题

2π 修正后 PN 势垒极弱（弱约 1000 倍），晶格离散性不足以锚定粒子，钉扎成为站稳的必要途径（Derrick 检查：裸点状 kink 塌缩，弱耦合柱 Jw = 0.3J 提供钉扎阱）。但弱耦合柱的体系内身份未定：真实元相子晶格里什么结构自然产生局域弱耦合？候选为位错核心（A3 位错网络节点）。

## 二、位错核心的弹性弱化

螺型位错（Burgers b = 1 格距，沿 z）：位移场 $u_z = b\theta/(2\pi)$（$\theta = \text{atan2}$），相邻格点相对位移 $\Delta u = b\Delta\theta/(2\pi)$，键耦合按 XY 型相位耦合 $J_{eff} = J\cos(2\pi\Delta u/b)$。

结果（N = 64）：

- x 键核心（r < 3）平均 J_eff/J = 0.844，弱化键占比（|J| < 0.5）= 7.7%，反号键 0%
- y 键核心平均 J_eff/J = 0.844，反号键 3.8%
- 远区（r > 20）J_eff/J = 0.9997（弹性区正确）
- 综合核心平均 J_eff/J = 0.844（RMS 0.906）

**弹性位错核心的等效耦合弱化约 16%，远强于代理 0.3**（即核心耦合 0.84，弱化不足）。

## 三、钉扎能对弱化强度的依赖

三维 XY 场（同 Derrick 模型），涡旋线沿 z，弱耦合柱（半径 3，Jw）距线 D 处，弛豫测 E(D)，阱深 = E(D=8) - E(D=0)：

| Jw | 阱深 |
|---|---|
| 0.84（位错核心） | 10.8 |
| 0.6 | 24.4 |
| 0.3（预印本代理） | 41.5 |

阱深随弱化增强单调增长（趋势与预印本一致；绝对值差异为归一化与弛豫参数所致）。**位错核心的弹性弱化（0.84）提供弱钉扎，阱深约为 0.3 代理的 1/4。**

## 四、结论

1. **钉扎身份部分确认**：位错核心 = 体系内的天然弱耦合区（弱钉扎源），A3 位错网络衔接成立
2. **强度不足**：弹性弱化（0.84）的钉扎阱约为强弱化（0.3）的 1/4，长期锚定（对抗碰撞扰动）可能不足；强钉扎需要更强的核心效应
3. **强核心效应候选**：空位/间隙缺陷（配位变化，耦合改变更强）、反相泡（A3 补丁：核心同相区，相位配置根本改变）、位错网络节点三重结（多个位错交汇，核心效应叠加）
4. **弱钉扎的物理角色**：弱钉扎足以解释"静止门槛"的定性存在，其定量充分性（对比环境扰动能标）为后续攻坚

## 五、严格程度

核心弱化分布、钉扎能依赖为可复现计算事实（脚本存档，确定性）；位错核心 = 弱钉扎源的识别为本验证解读；强核心效应候选未数值化，为后续方向。钉扎能绝对值与预印本（420）的差异源于归一化与弛豫参数，趋势一致。
