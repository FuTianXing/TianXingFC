## 一、实验设计

模型与边界同转换波运动学验证（FK 链、$K = 0.005$ 宽/轻 kink 可动区、缠绕守恒边界、$c_s = 1$）。理论靶标为**刚体平移的精确预言**：kink 整体平移时 $E = E_{rest} + \frac{1}{2}v^2\sum_n (\mathrm{d}u_{rest}/\mathrm{d}n)^2$，即形状范数 $m_{shape} = \sum_n (\mathrm{d}u_{rest}/\mathrm{d}n)^2$ 精确充当平移质量（时间平均意义下，PN 振荡取平均）。实测：$E_{rest} = 0.1303$，$m_{shape} = 0.2051$，最大滑移 0.309；连续 SG 对照比 $m_{shape} c_s^2/E_{rest} = 1.574$（离散性度量）。

两套测量：其一，**恒力直接测量（F = ma）**：轻阻尼（$\gamma_d = 0.02$）下恒力 $f$ 驱动，二次拟合 $x = \frac{1}{2}a t^2$ 提取 $a$，$m_{acc} = f/a$；其二，**迁移率响应**：永续阻尼（$\gamma_d = 0.2$）下倾斜力族 $f \in \{0.005, 0.01, 0.02, 0.04\}$（均低于真空脱钉阈值 $2\pi K = 0.126$），测终端速度 $v_{term}(f)$，响应质量 $m_{resp} = f/(\gamma_d |v_{term}|)$。

## 二、结果

| 测量 | 结果 |
|---|---|
| [A] 恒力直接测量（F = ma） | **不可用**：$f = 0.05/0.1$ 下 $|a| \approx 0.008\text{--}0.014$ 且与 $f$ 无关：kink 弛豫到窗口速度，非匀加速（窗口速度现象的独立再确认，与运动学验证互证） |
| [B] 线性响应 | $f = 0.005/0.01/0.02$ 下 $|v_{term}| = 0.095/0.186/0.342$：**小 $f$ 区严格线性**（$\mu = |v_{term}|/f \approx 18.9$），响应质量 $m_{resp} = f/(\gamma_d |v_{term}|) = 0.264$；$f = 0.04$ 时 $m_{resp} = 0.391$（偏离线性 = 相对论性/上限修正方向） |
| 方向 | 全部 $f$ 下 $v_{term}$ 与 $f$ 反号：kink 向 $\Sigma u$ 降低方向（下坡）定向漂移 |
| 速度上限 | 全部测量 $|v_{term}| < c_s$（最大 0.512，$f = 0.04$ 近饱和区） |
| 质量三角 | 形状范数（理论预言）0.2051；响应质量（小 $f$ 区）0.2642：**比值 1.29，O(1) 相符** |

## 三、结论

**⑥ 测地响应：闭合。** 线性响应确认（小 $f$ 区 $v_{term} \propto f$，迁移率恒定）、方向确认（下坡）、速度上限保持；大 $f$ 偏离线性为相对论性/上限修正方向；迁移率曲线的非单调细节解析待作（离散 kink 的已知行为类型）。

**④ 惯性：部分闭合。** 闭合的内容：kink 获得动量后匀速持续传播（牛顿第一定律，运动学验证）；倾斜场驱动的漂移以 kink 自身的平移代价（形状范数）为质量单位，O(1) 闭环。未闭合的内容：**F = ma 直接测量在离散区不可用**：恒力下 kink 弛豫到窗口速度，非匀加速（窗口速度现象的独立再确认），惯性质量的绝对提取需无辐射协议或连续极限（宽 kink 极限下 $m_{eff} \to E_{rest}/c_s^2$ 的 SG 定理适用）。

**等效原理：模型级 O(1) 闭环。** 响应质量（倾斜场测得）与形状范数（平移代价预言）比值 1.29：倾斜场以 kink 自身的平移代价驱动它，惯性质量与引力质量同源于转换代价。精确闭环（比值 → 1）需要连续极限或辐射退耦协议。

## 四、过程发现

其一，**恒力下的窗口速度弛豫**：恒力驱动的 kink 弛豫到其无辐射传播速度（全程无匀加速段）：这是窗口速度现象的独立再确认，也说明离散区的"加速度"概念被"弛豫到机制速度"替代。其二，**辐射清洗协议的失败**：以格点阻尼清洗声波会同步清洗 kink 的平移模（两者都耦合到 $\dot u$），"先清洗后测量"的方案不可行；迁移率响应是离散区唯一干净的惯性测量通道。其三，**钉扎的缺席**：$K = 0.005$ 宽 kink 在全部驱动下无脱钉阈值（$F_c$ 低于最小测试力），与 $K = 0.02$ 区（$F_c \approx 0.29$）对照，锚定-可动性联动再次确认。

## 五、边界

其一，toy 链代理（提升变量对应 σ 锁定提升的映射为模型假设）。其二，一维链，三维三元组孤子推广未做。其三，响应质量的 O(1) 偏差（1.29）来源未分解（辐射残余、PN 修正、离散形状漂移三者叠加）。其四，相对论色散 $E^2 = m^2c^4 + p^2c^2$ 的涌现（条目 33 遗留）：已由《注记-相对论色散完整验证：动量扇区与洛伦兹不变量》闭合（2026-09-06，$E$-$P$ 不变量平坦至 1.5%、场动量塌缩 $M_P \approx M_{zero}$、宽度趋势单调、协议独立），本实验的速度上限与 $|v| \le 0.5\,c_s$ 覆盖构成其低速度段前置。

## 六、通俗解读：这个实验说明了什么

**实验想干什么**：给"地毯褶皱"（粒子）称重。称重有两个经典办法：办法一，用恒定的力推它，测加速度，力除以加速度就是惯性质量（牛顿第二定律的标准操作）；办法二，把地面微微倾斜（模拟引力），看它往低处滑多快，滑速与倾斜程度的比例里也有一个"质量"。两个办法测到的应该是同一个质量：这就是等效原理，广义相对论的入口。本实验就是把这两个数都测出来，看它们是否相等。

**结果一：办法一失效了，但失效得很有信息量。** 用恒定的力推褶皱，按牛顿的预期它应该匀加速（越跑越快）。实测：它不加速。不管用多大的力（在安全范围内），它都很快稳定在一个固定的前进节奏上（约 0.14 倍格子速度），之后一直匀速，力再大也不变。这说明这个粒子自带"巡航挡"：它有别于推一下就一路加速的普通小球：它是一个有内在节奏的振动图案，格子只允许它以一个特定的、不产生损耗的节奏换装前进；多推的力气变成地毯上的微小波纹抖掉，然后它回到自己的节奏上。这首先再次独立确认了窗口速度现象，其次告诉我们：在这个格子里，想用"推了看加速多快"来称重，此路不通。褶皱的速度是机制定的，不是力气定的。

**结果二：办法二成功了，三个"质量"对上了。** 改用办法二：把地面倾斜不同的角度，测褶皱往低处滑的速度。结果四条：其一，方向对，倾斜朝哪边，褶皱就往哪边的低处走，它确实"被吸引"；其二，小推力下严格线性，推力加倍滑速加倍，滑行有一个确定的"迁移率"，背后站着一个确定的质量；其三，这个质量跟理论预言对上了：理论说褶皱的惯性质量应该等于"换装代价"换算出的那个数（形状范数，实测 0.205），响应测量给出来的是 0.264，比值 1.29，量级与结构完全对上，30% 的偏差来自格子离散性和残余波纹，属于这类测量的正常误差方向；其四，永远不超光速，所有测量里滑速都低于每拍一格，推力加大后趋于饱和逼近而不突破。

**结论：等效原理在模型里 O(1) 闭环。** 把三个来源的质量摆在一起：理论预言（换装代价换算）0.205、斜坡响应实测 0.264。响应质量与换装代价在 O(1) 内一致，而且大推力下的偏离方向恰好是"接近光速上限该有的样子"。这意味着：引导褶皱往低处走的力量，用的正是褶皱自己那份"搬家成本"当质量。引它多费劲，推它就多费劲，两种费力是同一份代价清单。等效原理在这套机制里，从假设变成了自然的产物。

**诚实边界**：还有三笔没算清：响应质量与理论值之间 30% 的偏差来源没有分解（格子杂波、锯齿修正、形状漂移三者叠加）；绝对质量的精确数字被"巡航挡"挡住了，需要消波协议或更光滑的极限；实验在一维链上做的，三维推广还没做。这些都是精度问题，方向上没有障碍。
