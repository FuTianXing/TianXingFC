## 二、稳定条件的精确化（对裁决注记公式的补全）

泡壁环的能量按二维读法写成（三维泡为同构形式，面积与体积幂次互换，结论不变）：

$$E(R) = 2\pi R\,a + \pi R^2\,\delta, \qquad a = \sigma_{\text{壁}} + \mu_{\text{芯}}, \quad \delta = \Delta\varepsilon_{\text{体}}$$

求驻点 $E' = 2\pi a + 2\pi R\delta = 0$ 给 $R^* = -a/\delta$；稳定性 $E'' = 2\pi\delta$。据此：

- $a > 0, \delta > 0$：单调增，塌缩；
- $a > 0, \delta < 0$：倒钟形，内部驻点是**极大**（两侧分别塌缩与膨胀，无驻留）；
- $a < 0, \delta > 0$：$R^* > 0$ 且 $E'' > 0$，**稳定极小**（唯一成立组合）；
- $a < 0, \delta < 0$：单调减，膨胀。

裁决注记「体项为正时出现稳定 $R^*$」的表述漏了线项前提。精确化：**稳定 $R^*$ 的充要条件为负线项加正体项（$a < 0 < \delta$）**。数值扫描印证：纯体项（线项为正固定）无论如何取号都不造内部极小（T1），只改变收缩与膨胀的方向与速率（T3）。

## 三、负线项与正体项的本体盘点

**负线项（$a < 0$）的候选。** 现成候选是锚核的界面钉扎：W1/W2 读数给出 $\mu_{\text{芯}} < 0$，且「临界缺口约为线张力的 $10\%$」，恰是 $a$ 距 0 的 10% 缺口。W1/W2 的「无稳定半径」在新框架下获得精确意义：**锚核还差 10% 才能越过 $a = 0$ 的临界**，越过之后稳定半径才由体项选定。缺口可从界面钉扎加强（更深的振幅锁定或界面结构）补。

**正体项（$\delta > 0$）的候选盘点**（环内相比环外贵）：

| 候选 | 体项 | 判定 |
|---|---|---|
| 层位真空（u 的 n 与 n+1） | 简并 $\delta = 0$ | 否（C1-2/C1-3 的面积律读数支持） |
| 复结构双井（$J = \pm 1$） | 对称简并 $\delta = 0$；且需局域偏置，体系无此源 | 否 |
| GL 两相（凝聚相与正常相） | 正常相更贵，$\delta > 0$ 明确 | **是（振幅通道内现成）** |
| 凝固相（格点相与元相海） | 相变尺度两相 | **排除：违反晶格刚性原理**（局部无格点的泡要求格距改变，一票否决） |

**判定结论。** 体项单独不成立（T1-T3 加条件分析与候选盘点）；「泡壁环复合体」的完整机制有具体可行形式：**GL 正常泡（正体项）+ 界面锚核钉扎（负线项）**。判定为有条件通过，条件为下一轮在 GL 载体上构造正常泡并测 $E(R)$ 与驻留。
