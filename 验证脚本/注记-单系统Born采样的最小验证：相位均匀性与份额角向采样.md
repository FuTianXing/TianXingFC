## 二、模型设定

采样协议三要素。其一，份额角向编码：结果 $a$ 对应相位圆上弧宽 $2\pi w_a$ 的弧段（$w_a = N_a/N$，份额恒等式的单系统像）。其二，随机触发：凝固时刻由探测器触发决定，触发与系统节律无共同零点（候选一）或被背景相位噪声抖动（候选二）。其三，弧段读出：快照相位落入哪个弧段，结果即哪个。

候选一的数值身份为 Weyl 等分布：系统相位 $\varphi(t) = \omega t$，触发时刻按独立节律 $t_j = jT_d$ 到达，频率比 $\omega T_d / 2\pi$ 取不可通约值（黄金比），快照相位序列 $\{2\pi\varphi j \bmod 2\pi\}$ 等分布。候选二的数值身份为环绕正态：触发相位 = 定态初相 + 高斯抖动（$\sigma_\phi$ 为背景相位噪声积累），分布为环绕正态，其对均匀的总变差 TVD($\sigma_\phi$) 由多像叠加解析数值积分。全确定性，固定种子。

## 四、过程记录（v1 判据修正教训）

初版 J3 要求卡方均匀性检验在 $n = 2\times10^6$、$\sigma = 3$ rad 下 p > 0.01，实测 p = 0。诊断：TVD(3) = 0.0071 是真实存在且有界的残余不均匀，卡方检验在大样本下必然拒绝任何有限 $\sigma$ 的环绕正态；修正后的演示项给出 p 值随 $n$ 的衰减序列（$10^3$：0.16，$10^4$：0.68，$10^5$：0.012，$10^6$ 起：0），量化了"检验功效追上偏差尺度"的过程。教训：对近似均匀性，正确语言是总变差容差（TVD ≤ 预定容差），严格均匀性检验只在偏差尺度小于统计分辨率时才有意义。判据预期写错即修正，本条按验证脚本规范登记。

2026-09-13 评审复核（论文《测量的三层判据》七维评审）：初版穿越点取步长 0.5 粗网格上首个 TVD < 0.05 的格点（2.50 rad），非收敛穿越点。解析首阶近似 $\mathrm{TVD} \approx (2/\pi)\,e^{-\sigma^2/2}$ 与细网格积分一致给出真穿越点 $\sigma^* = 2.256$ rad；TVD(3) = 0.0071 与解析值 0.00707 精确吻合，证明总变差约定无差别，偏差纯来自穿越点测量的网格分辨率。脚本已改为粗网格定位后二分细化，复跑全判据 PASS。教训：阈值型读数不能直接报网格格点值，须细化到判据容差以下一个数量级再报数。

## 五、严格程度声明

J5（均匀 + 弧段划分 $\Rightarrow P(a) = w_a$）：恒等式级。J1（Weyl 等分布）：数学定理的应用，条件性命题（前提为参照独立与频率比不可通约）。J2（噪声扩散）：条件性命题（前提为背景相位噪声积累超过周期尺度，$\sigma_\phi \gtrsim 2.26$ rad 时 TVD < 0.05）。J3（端到端 Born 恢复）：数值验证级，判据方向稳健（频率恢复不依赖参数微调）；容差 0.05 为约定选择，判据敏感。层级声明（裁决点 3 已采纳，2026-09-12）：相位均匀性为条件性命题，非独立新公设；结构面（无内禀零点 + 无共同时钟基准）与动力学面（背景噪声超过周期尺度）两面全采纳，本体层、事件层、频率层三层级表述一并采纳。
