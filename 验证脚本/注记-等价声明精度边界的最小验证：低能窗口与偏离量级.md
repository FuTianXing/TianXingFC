## 二、模型设定

格点色散取三维最近邻形式

$$\omega^2(\mathbf k) = \frac{4}{t_P^2}\sum_a \sin^2\!\Big(\frac{k_a l_P}{2}\Big),$$

单位取 $l_P = c = 1$，故 $u = kl_P$ 即 $E/E_P^{(t)}$。低能展开给出 $\omega/(ck) = 1 - u^2\sum_a n_a^4/24 + O(u^4)$。

约定声明照色散论文：该文用 $E_P^{(t)} = \hbar/t_P$，体系基准为 $E_P = \hbar\omega_P = 2\pi\hbar/t_P$，两者差 $2\pi$，故基准约定下系数为 $(2\pi)^2/24 = \pi^2/6$ 乘方向因子。本判据全部读数在基准约定下报告，方向因子 $\sum_a n_a^4 \in [1/3,\,1]$，最不利方向为 $[100]$。

## 三、结果

**L3-1 给出低能精确性。** 三个方向的 $\omega/(ck)$ 随 $u$ 减小趋于 1，在 $u = 10^{-6}$ 处到双精度极限。这与色散论文的数值读数一致。

**L3-2 给出首阶系数与方向比。** 实测系数与 $-(1/24)\sum_a n_a^4$ 相符到 $10^{-7}$ 量级（残差来自 $u^4$ 阶项的截断），方向比精确为 $3:1.5:1$。换算到基准约定，最不利方向的系数为 $\pi^2/6 = 1.644934$。

**L3-3 给出次阶。** 首阶之后的第一项按 $u^4$ 标度（比值稳定在 $5.208\times10^{-4}$），说明低能展开是偶次幂级数，误差界由首阶项控制，"偏离 $= C(E/E_P)^2$"这一形式在窗口内是可靠的。

**L3-4 给出窗口表。** 给定精度 $\epsilon$，窗口上界为 $(E/E_P) \le \sqrt{\epsilon/C_{\text{worst}}}$，$C_{\text{worst}} = \pi^2/6$。$\epsilon = 10^{-2}$ 对应 $5.98\times10^{27}$ eV，$\epsilon = 10^{-18}$ 对应 $5.98\times10^{19}$ eV。全部窗口都在 $E \ll E_P$ 内，与分层定理低能层（L1 至 L4）的适用范围一致。

**L3-5 给出实际能量对照。** 在 LHC 质子能量上偏离约 $4.7\times10^{-32}$，在 PeV 中微子上约 $2.8\times10^{-28}$，在最高能宇宙线上约 $2.8\times10^{-18}$。晶格的签名在可及能量上是不可见的。

## 四、物理读数

**等价声明的收窄形态。** 原声明"低能与标准量子场论逐项一致"可以写成：在单粒子扇区与自由场色散层面，本框架与标准量子场论的相对偏离为

$$\frac{\delta\omega}{\omega} = -\frac{\pi^2}{6}\frac{\sum_a k_a^4}{k^4}\Big(\frac{E}{E_P}\Big)^2\Big[1 + O\big((E/E_P)^2\big)\Big],$$

系数由几何常数固定（$1/24$ 与方向因子，换算后为 $\pi^2/6$），无自由参数。这就是这句声明的精度标签。

**与分层定理低能层的一致性。** 分层定理的两层是"低能精确不可探测"与"普朗克层预定签名"。本轮给出的窗口表说明：在 $E/E_P \le 10^{-2}$ 的广大区间里，偏离小于 $1\%$，而 L1 至 L4 要求的观测者本地物理重现在这一区间内成立。两条的边界因此吻合，没有留出"既不属于低能层、也没到普朗克层"的空白带。

**对 G2 的意义。** [[内部草稿/注记-G2论证链的装配：能标分界、底层规避与复合性借道]] 第五节的借道依赖这句等价声明；本轮把它从"逐项一致"收窄为"偏离 $O((E/E_P)^2)$、系数已知、窗口已知"，借道处因此带上了精度标签。六节所述的 G2 分量也随之具体：借道成立到什么精度，现在有数可查。

## 五、严格程度声明

**验证了什么**：L3-1 至 L3-5 均为可复现数值事实（色散的低能极限、首阶与次阶系数、方向比、窗口表与实际能量对照）。格点色散的形式与 $1/24$ 系数引自色散论文，本轮在基准约定下复算并给出窗口。

**未验证什么**：其一，色散的低能形式与首阶系数在该论文中自标为条件性命题（三维最近邻解释与同步态线性化条件下成立），本轮沿用该前提，不重新论证。其二，相互作用扇区的偏离未逐项核（该论文的遗留清单含 $\cos$ 展开高阶项与非线性效应）。其三，洛伦兹破坏张量在观测者 boost 下的变换行为未验证（同论文遗留），故本轮只报固定方向上的系数量级。其四，容量饱和与真空涨落谱属另一类签名（宇宙尺度与系综），不在单粒子扇区内，未纳入本轮窗口。

**边界**：本轮给出的是等价声明的精度标签与窗口，不是匹配证明；显式有效场论匹配仍属 G4 第二半的待办。
