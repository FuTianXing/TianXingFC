## 一、模型与判据

与第 525 条同一三维波场框架（N=40，RK4 正则积分，线性系统量子期望 = 经典能量份额）。两类候选通道的单声子耦合标度：**位移型** $H_{int} = \kappa d\,u_0$ 经弹簧实现 $\kappa(u_0 - d)$（与第 525 条同款），$|g_k|^2 \sim 1/(\omega_0\omega_k)$，$\Gamma \sim \kappa^2\rho(\omega_0)/\omega_0^2$，低频平坦（无禁戒）；**速度型** $H_{int} = \nu p_d u_0$（正则：$d' = p_d + \nu u_0$，$u_0' = P_0 + \nu p_d$），$|g_k|^2 \sim 1$，$\Gamma \sim \nu^2\rho(\omega_0)$，低频禁戒（$\Gamma \propto \omega^2 \to 0$）。

- **C1（位移型签名）**：弹簧耦合三档中 $\omega_0 = 0.8/1.2$ 两档的 $\Gamma\omega_0^2/\rho_N$ 常数性 $\max/\min \le 1.35$。
- **C2（速度型签名）**：速度耦合同三档的 $\Gamma/\rho_N$ 常数性 $\max/\min \le 1.35$（低频禁戒形态）。
- **C3（二分判别量，EP5 精神）**：判别量 $D = \Gamma\omega_0^2/\rho_N$ 在速度型的 $D(0.8)/D(1.2) = (0.8/1.2)^2 = 0.444$（容差 $[0.31, 0.58]$），与位移型常数互斥——套错公式即 FAIL，检验有齿。

## 四、过程记录（五轮调试，教训沉淀）

1. **速度型耦合项误入场力**：$\nu p_d$ 应作位置级修正（$u_0' = P_0 + \nu p_d$），首版误加进 $P_0'$（场动量的力）造成持续能量泵浦，份额爆炸至 $10^5$。教训：速度型耦合不出现在力的方程里。
2. **场方程符号写反**：$P' = -\nabla^2 u$ 给出指数增长解（无质量场 ü = +∇²u 才是波动方程），与第 525 条对照锁定符号。教训： lap 符号错误在衰减问题里伪装成"物理不稳定"。
3. **位移型交叉项哈密顿不自洽**：纯交叉 $H_{int} = \kappa d u_0$ 的实现中 $P_0'$ 取 $+\kappa d$ 而哈密顿要求 $-\kappa d$，力不对称导致泵浦爆炸；改用哈密顿自洽的弹簧型 $\kappa(u_0 - d)$（与第 525 条同款）后稳定。教训：哈密顿耦合的每一项符号都要对 $\partial H/\partial$ 逐项自检。
4. **RK4 平滑无纹波谷**：谷值检测（局部极小）在 RK4 平滑份额曲线上取不到点，回退为首穿段直接 log 拟合。
5. **观察项（诚实登记，不作判据）**：位移型 $\omega_0 = 1.0$ 档 $D = 0.286$，较另两档（1.04-1.05）与第 525 条同档（1.077）偏低约 3.7 倍，成因未定位（候选：RK4 长时能量行为与谷值交互），不进入判据。

## 五、严格程度声明与边界声明

- 严格程度：模型层结构判决（判决级）。签名互斥是两类通道的标度性质，换 N、换档位不翻。
- 验证什么：两类候选耦合通道的低频签名互斥可判，判别量 $D$ 的二分形态。
- 不验证什么：体系缺陷的真实耦合形式（需缺陷微观结构，属 P1-50 持续攻坚）；$\cos$ 高阶项矩阵元的推导；爱因斯坦 A 系数数值；介质折射。
- 对 P1-50 的推进：通道判定从"形式未知"变为"二分待判"——后续只需确定体系缺陷与真空的耦合属于位移型还是速度型（或两者的混合比例），低频禁戒是否成立的叙事问题随之定案。
