## 二、模型设定与代数

**标量扇道**（《微观根基》§2.2）：记录场由质量密度按泊松方程给出，

$$\nabla^2\theta = -s_\rho, \qquad s_\rho = \rho$$

**运动缺陷**：密度随缺陷轨迹平移，$\rho(\mathbf r, t) = \rho_0(\mathbf r - \mathbf R(t))$，且 $\dot{\mathbf R}(t) = \mathbf v$。

**守恒结构**：记录源与质量流满足连续性方程

$$\partial_t\rho + \nabla\cdot\mathbf j = 0, \qquad \mathbf j = \rho\mathbf v$$

**三步推导**：

- 第一步（链式法则）：$\rho$ 对时间的依赖完全经由平移，故任何由 $\rho$ 线性确定且局域的场都满足
$$\partial_t\theta = -\mathbf v\cdot\nabla\theta$$
这一步对任意运动解精确，不依赖缺陷内部结构。
- 第二步（泊松求导）：对 $\nabla^2\theta = -s_\rho$ 取时间导数，用连续性方程消去 $\partial_t s_\rho$，
$$\nabla^2(\partial_t\theta) = -\partial_t s_\rho = \nabla\cdot\mathbf j$$
- 第三步（源识别）：矢量通道的源就是 $\partial_t\nabla\theta$。它由记录场的运动唯一确定，不引入可自由选择的系数。

R5 给出远场结构：转动源（角速度 $\Omega$、转动惯量 $I_z$）的矢量响应在 $r = 8$、$12$、$16$ 处 $r^2\lvert A\rvert$ 对解析值 $J_z/(8\pi)$ 的比值随盒尺寸单调趋近 1（盒 64 给 $0.923$ 至 $0.968$，盒 128 给 $0.930$ 至 $0.995$），残差为周期镜像。

## 四、物理读数

**取向项不是一条独立的规则。** 判据 W 的注记原文把取向项写作「每拍写一份动量」，并承认这是从需求反推。本判据说明这条反推恰好命中了唯一可能的形式：任何由记录源线性确定、随源平移的场，其时间导数必然等于 $-\mathbf v\cdot\nabla\theta$，其梯度必然给出矢量通道的源。缺陷静止时这个源自动为零。

**形式上没有自由度。** 链式法则与连续性方程都是恒等式，源的形式因此被唯一确定，没有留下可调参数。判据 N 定下的系数 $16\pi\,p/(m_P c)$ 是同一结构在连续极限下的换算结果，两条判据互为核对（判据 N 从需求侧定系数，判据 R 从结构侧定形式）。

**与洛伦兹协变的对接。** 记录源与质量流合成四维流 $j^\mu = (\rho c, \rho\mathbf v)$，其分量守恒 $\partial_\mu j^\mu = 0$ 恰是连续性方程。判据 R 的三步等价于说：矢量块是标量块的洛伦兹协变化，取向项是这次协变化里时间与空间分量之间的转换项。这与 §4.3 把 $\rho$ 推广到 $T_{\mu\nu}$ 的第一步同源。

**精确类比的边界。** 电磁学的结构是同一个形状（电荷密度与电流密度合成四维流，矢量势由电流决定，洛伦兹规范下 $\partial_\mu A^\mu = 0$）。体系的分工双场把电磁划给实轴取向场、引力划给法线场，两个载体各有一套流。本判据用的是引力侧的流，不借用电磁侧的机制。

**这一步闭合了什么。** 矢量块的四项待攻至此全部落地：通道存在（判据 V）、源通道与结构（判据 W）、耦合归一化（判据 N）、受约束性（判据 Q）、取向项形式的微观来源（判据 R）。剩余的前置是守恒结构的本体来源，即「记录源与质量流为何满足连续性方程」，这一条属张量桥 d 与协变推广，不是矢量块独有的缺口。

## 五、严格程度声明

**验证了什么**：链式法则（R1）、泊松求导的代数恒等式（R2）、两条路径的数值一致（R3）、连续性方程残差（R4）、远场偶极结构（R5）均为可复现数值事实或代数恒等式。

**未验证什么**：守恒结构的本体来源（记录源为何与质量流满足连续性方程）；三维复合位错动力学；记录的完整时间依赖（本判据只取刚性平移，加速运动的高阶项未做）；系数绝对值由判据 N 独立定下，本判据不重复。

**边界**：本判据是线性结构与守恒核对，不构造微观动力学；结论不依赖缺陷内部结构，只依赖「记录由源线性确定且随源平移」这一条，后者由标量扇道的泊松结构保证。
