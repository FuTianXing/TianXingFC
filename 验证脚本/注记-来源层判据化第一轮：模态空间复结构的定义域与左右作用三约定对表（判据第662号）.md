## 摘要

手征攻坚总结把"来源层判据化"列为第一优先，其前置是"把'对应'形式化"。本轮从第 507 条的 $S^3$ 入口入手，把正稿 §3.1 与 §5.1 的三句纲领性表述落成显式读数，得三条结构结论。

**其一，复结构的定义域不在 $S^3$ 的切空间。** $S^3$ 切空间为实三维，奇维实空间上 $J^2 = -1$ 无解：3×3 反对称族上 $\|J^2+I\|_F$ 的解析最小值为 $1$（在 $\|\omega\| = 1$ 处），随机 3×3 实矩阵 2000 样本全部带实特征值。$J$ 的合法定义域是模态系数空间 $\mathbb{C}^2 \cong \mathbb{H}$（复二维内部空间），那里 $J_0^2 = -I$ 精确成立。

**其二，左右作用保持的不是正稿所写的那一对。** 四元数右乘共轭 $J_0$ 在 12 组（三方向四档）下偏差最大 $1.11\times10^{-16}$，即右乘保持 $J$；四元数左乘中只有 $U(1)_i$（$g_z$ 方向）保持，$g_x$ 与 $g_y$ 方向偏差最小 $0.295520$，$\theta = \pi$ 型元素给 $J \to -J$。

**其三，$T_3$ 是左右对角型，全纯投影荷的实矢量场读法两支恒等。** 按 $M = L_aR_b$ 分解，$J_0 = (i, 1)$ 为纯 $SU(2)_L$ 侧，而 $T_3 = (i, -i)$ 两侧分量都非平凡；$T_3$ 方向矢量场在 CR 结构两支上的模长相等（各 $0.353553$，比值 $1.000000000$）。

附带一条正面读数：$T_1$、$T_2$、$T_3$ 的左分量同为 $i$，故三个 $T_k$ 与 $J_0$ 全部对易。这给第 661 号的 $[\Gamma_5, \kappa\sigma_z] = 0$ 一个几何根源。

## 一、模型设定与被读对象

模态系数空间取 $\mathbb{C}^2 \cong \mathbb{H}$：$\psi = (z_1, z_2)^T$ 对应四元数 $q = z_1 + z_2 j$，实坐标 $(x_0, x_1, x_2, x_3)$ 对应 $(1, i, j, k)$ 的系数。$S^3$ 是单位球面。

复结构取 $J_0$：$\mathbb{C}^2$ 上乘 $i$，在四元数语言下即左乘 $i$，矩阵为 $L_i$。弱荷取 $T_k = \sigma_k$（$k = 1, 2, 3$），模式混合取 $g_k(\theta) = \exp(i\theta\sigma_k/2)$ 作为 $\mathbb{C}^2$ 矩阵左乘。

被读的三句原文是 §3.1 的"$S^3$ 即单位四元数流形，四元数乘法给出其上的两个互反复结构：左不变复结构 $J$，满足 $J^2 = -1$，几何内容为切空间上乘 $i$"与"左乘保持 $J$，右乘保持 $-J$"，以及 §5.1 的"弱荷 $T_3$ 的几何内容 = 全纯分支上的模态参与度，反全纯分支的模态参与度恒为零"。

## 四、结论

**结论一，复结构住在模态系数空间，不在 $S^3$ 的切空间。** 正稿 §3.1 的"$S^3$ 上的左不变复结构，几何内容为切空间上乘 $i$"，其"切空间"须读作 $\mathbb{H} \cong \mathbb{C}^2$ 的切空间（复二维内部空间）。$S^3$ 的切空间为实三维，奇维实空间上 $J^2 = -1$ 无解，这一条由解析最小值 $1$ 与 2000 样本的实特征值比例 $1.000$ 双向坐实。$S^3$ 上存在的是 CR 结构（复一维水平分布）与三组切矢量场（四元数左乘 $i, j, k$ 与右乘 $i, j, k$），复结构本身由这些矢量场承载。

**结论二，"左乘保持 $J$、右乘保持 $-J$"这一对须更正。** 读数为：四元数右乘全群保持 $J$（12 组偏差上限 $1.11\times10^{-16}$）；四元数左乘中只有 $U(1)_i$ 子群保持 $J$，$g_x$ 与 $g_y$ 方向把 $J_0$ 连续旋转到 $L_{i\cos\theta + k\sin\theta}$，$\theta = \pi$ 型元素给 $-J_0$。右乘保持的是 $J$ 本身，"右乘保持 $-J$"不成立。

该保持关系是左乘与右乘交换的代数恒等（把 $J_0$ 换成 $L_j$ 后右乘偏差仍为零），属构造恒真，其信息量在于排除"右乘保持 $-J$"这一读法。把 $J$ 翻转为 $-J$ 的操作由左乘的 $j$、$k$ 型元素实现，这与第 487 条"复结构符号取反"的操作位置一致。

**结论三，$T_3$ 是左右对角型，"反全纯分支恒为零"在两条读法下都不成立。** 身份分解给 $J_0 = (i, 1)$（纯 $SU(2)_L$ 侧）与 $T_3 = (i, -i)$（两侧分量都非平凡），故 $T_3$ 并不只住在全纯分支。矢量场层面，$T_3$ 方向在 CR 结构两支上的模长相等（各 $0.353553$，比值 $1.000000000$），实矢量的两支分量互为共轭，单支恒零无从出现。正稿 §5.1 的这句若要保留，须补出成立条件，例如改成复化矢量场上的陈述，或改指 $SU(2)_L$ 与 $SU(2)_R$ 的作用分工。

**附带正面读数**：$T_1$、$T_2$、$T_3$ 的左分量同为 $i$，故三个 $T_k$ 与 $J_0$ 全部对易。第 661 号读到的 $[\Gamma_5, \kappa\sigma_z] = 0$ 由此获得模态侧的几何根源：弱荷算符与复结构共享同一个 $SU(2)_L$ 分量，二者在几何上本就同侧，共享本征态是这一同侧的直接后果。

**一处命名提醒**：正稿把模式混合称为"左乘 $SU(2)_L$"（指 $\mathbb{C}^2$ 矩阵左乘），而在四元数左右分解下它是纯 $SU(2)_R$ 侧 $(1, b)$。正稿的结论"模式混合保持 $J$"因此是对的（右乘与左乘交换），但理由是右乘而非左乘。两种"左乘"（$\mathbb{C}^2$ 矩阵左乘与四元数左乘）在后续推导中容易混用，建议在表述层加一句约定。
