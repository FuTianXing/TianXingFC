## 二、定义与模型设定

FK 链工具链同 M5/M7（$k=1$、$K=0.005$、$\ell=2.25$、$N=1000$、窗口 $M=5$）。静态构型改用阻尼弛豫（$\gamma=2.0$、30000 步）替代 M5/M7 的无阻尼弛豫：无阻尼弛豫留有 $\pm10^{-6}$ 亏空底的弛豫辐射，污染支撑不交判据；阻尼弛豫后远场干净至 1e-15。

三类对象（同一套泛函）：**经典分瓣** $S(q)$：$u_n = n + qK(n-A) + (1-q)K(n-B)$，滑量按 $q:(1-q)$ 分割，总缠绕 1；**叠加像** $\mathrm{img}(q)$：载体映射的对角通道 $w^{\text{img}}_n = q\,w^{(A)}_n + (1-q)\,w^{(B)}_n$，其中 $w^{(X)}$ 为支链 $X$ 的窗口局域序参量；**系综像**：双 kink 链（缠绕 2）。

叠加像的对角通道是建模层定义，其合法性由压缩不等式给出：局域序参量的 $2\times2$ 压缩满足 $\lvert c_n\rvert^2 \le (1-\lvert a_n\rvert^2)(1-\lvert b_n\rvert^2)$，故一支安静处（$\lvert b\rvert = 1$）跨项恰为零。J7a 验证两支亏空支撑不交至 1.9e-15：对 $D\gg\ell$，对角像即真实叠加态的局域序参量，跨项禁闭使分离两瓣无局域干涉。

新增泛函：**实通道亏空** $\tilde\delta_n = 1-\mathrm{Re}\,w_n$。它是态的线性泛函（算符 $\mathrm{Re}\,\hat O$ 的期望），任何叠加精确折叠。模通道 $\delta_n = 1-\lvert w_n\rvert$ 非线性，携带混叠超额 $E_{\text{mix}}\ge0$（亚可加性 $\lvert x+y\rvert\le\lvert x\rvert+\lvert y\rvert$）。

本轮实测发现：对任何位形，$\sum_n(1-\mathrm{Re}\,w_n) = N(1-\lvert\Psi\rvert)$ 到窗口边缘修正 $O(M/N)$：实通道预算与全局代价是同一笔和的逐层分组（$\tilde R\equiv1$）。因此折叠的物理内容由 J3(a)(b) 承载：叠加像的全局代价与实通道预算都精确等于单 kink 的一份。

## 四、本轮物理结论（P4-5 的模型内回答）

**载体裁定**。两瓣叠加态由单一背景场承载的场侧对象是相干结构（叠加像），其精确性质为三条。其一，全局相干代价精确折叠：叠加态代价 $=$ 单 kink 代价，与权重 $q$ 无关（简并支），系综像为两倍；"背景 = 系综的局域化"由此获得精确形态：成员数折叠为预算单份化，人数变成份额深度。其二，权重的精确载体是线性泛函：实通道亏空份额与滑量份额都给出 $q$（前者机器精度、后者拓扑），模通道亏空非线性（读出映射 $g(q)$ 加混叠超额）。其三，混叠超额 $E_{\text{mix}}\ge0$ 是叠加态自身的真实局域失相干：压缩不等式下对角像即真实局域序参量，模通道比值降为 $R_I(q) = R_{\text{single}}/(1+E_{\text{mix}}$ 比份$)$。

**干涉禁闭**。$2\times2$ 压缩不等式把局域序参量的跨项禁闭在两支亏空的交集内：分离两瓣的支撑不交（1.9e-15），故其相对相位不由局域亏空承载。与之一体的是 J12：$q=1/2$ 时叠加像与系综像的归一化份额剖面逐位重合，局域读数不判载体；载体判定须全局量（缠绕、代价、预算）与局域量合取，与 M2c"两可测量单独均不判定"的合取结构同构。

**相位通道**。两瓣相对相位 $\gamma$ 的载体是零模（质心）相干：动量谱条纹相位读出 $\gamma$（误差 $\le 1.9\times10^{-11}$）；$\gamma$ 的守恒由支简并给出（同格内 $\Delta E = 6.5\times10^{-15}$），跨格进动率由 Peierls 劈裂（$3.4\times10^{-9}$，极小在半格位）给出，衔接 M2c 的佩耶尔斯相位口径。经典分瓣载体上相位被权重拓扑锁定：台面 $\arg w = 2\pi q$（两种滑量走向 $\pm$），连续 $\gamma$ 须由零模通道额外承载。

**经典场独木难支（判别）**。经典分瓣构型支付挫折弦：$\tau(q) = K(1-\cos 2\pi q)$ 每格（形状比 1.0000，无自由参数），全局代价随 $D$ 线性发散，模通道 $R_S\propto D$ 发散：弦的代价住在全局相位通道，局域模亏空对台面纯相位失明。动力学上台面经 onsite 势垒顶部失稳塌缩（$t_{\text{merge}} = 26.5$），双 kink 系综像则长寿命（漂移 0.0000）。结论：经典纯位形只能承载系综像或塌缩的分瓣像，两瓣叠加的稳定承载必须走相干结构（U 侧）。

## 五、过程记录（v1 判据修正教训）

初版 J5 设计用实通道比值 $\tilde R$ 作判别器，实测 $\tilde R\equiv1$：实通道预算与全局代价是同一和的两种分组，线性泛函把一切线性折叠，天然无判别力；判别器必须用非线性泛函，改用模通道 $R$（$R_S\propto D$ 发散对 $R_I$ 的 $D$ 无关）。教训：折叠判据与判别判据要分开选泛函，前者用线性（精确折叠），后者用非线性（有区分度）。

v1 三处实现与门不一致。J2 与 J10 的代码门残留初版值（1e-12 / 1e-8）未随头注修订同步，复跑时假性 FAIL；J10 的能量门误用纯势能：塌缩把弦能量转入动能与辐射，势能单独漂移 $2.9\times10^{-1}$，总能量（动能加势能）守恒至 $1.8\times10^{-6}$。教训：判据门改动必须同步头注与代码；能量守恒判据必须写明是总能量。

J7c 初版解调取共轭导致 $\gamma$ 反号（$\gamma=\pi/2$ 恢复 $-\pi/2$）：$\cos(pD-\gamma)e^{ipD}$ 的展开含 $e^{+i\gamma}$ 项，读出应取 $\arg C$。J3b 的支链预算差 1.35e-9 源于两支独立弛豫的非逐位平移（双重舍入），按实际协变水平（预算相对 1.5e-10）设门 5e-9。J5 的 $D=40$ 点 $R_I$ 偏差 $6.8\times10^{-7}$ 为支撑重叠尾部（随 $D$ 指数消退），平坦性门改在 $D=80/160$ 两点上。
