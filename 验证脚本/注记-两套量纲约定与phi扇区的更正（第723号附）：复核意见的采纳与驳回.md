## 一、复核的由来

判据 723 主注记的判语涉及三处论断：$\alpha$ 场在 $d=4$ 恰有一个边际自相互作用、紫外有限推不出可重整、重整化群流须拆扇区。这三处都指向物侧基础 §6.1 的改写，属于改动论文核心主张的判断，故派独立红队复核。

复核意见给出四条判定与六条「与转述不一致之处」。逐条核对后，三条采纳、两条驳回、一条部分采纳。

## 二、被驳回的两条

**驳回一：$\alpha$ 带量纲，$(\partial\alpha)^{2n}$ 维度为 $n(d+1)$，$d=4$ 下无边际项。**

复核意见由 $[\mathcal{L}] = m^d$ 与 $\mathcal{L} = \frac{I}{2}(\partial\alpha)^2$ 反解 $[\alpha] = m^{(d-1)/2}$，据此得算符维度 $n(d+1)$，$n \ge 2$ 全为负幂次，无边际解。

这条不成立，理由有三。

其一，与库内约定冲突。[[wiki/作用量]] 第 35 行明写相位角 $\theta$ 与几何角 $\alpha$ 之间隔一个约定 $\alpha = \pi\theta$，而 $\theta = S/\hbar$ 为弧度、无量纲。故 $\alpha$ 无量纲是体系既定约定。

其二，与余弦势能冲突。库内拉格朗日量含 $\cos(\Delta\alpha)$（[[wiki/拉格朗日量]] 第 66 行）。余弦的泰勒展开为 $1 - (\Delta\alpha)^2/2 + (\Delta\alpha)^4/24 - \cdots$，各项量纲须相同，故 $\Delta\alpha$ 必无量纲。若 $\alpha$ 带量纲，$\cos(\Delta\alpha)$ 无定义。

其三，复核意见自身的量纲推导不自洽。取 $[\alpha] = (d-1)/2$，动能项 $(\partial\alpha)^2$ 的维度为 $2 + 2\cdot(d-1)/2 = d+1$，不等于 $d$。要等于 $d$ 须 $[\alpha] = (d-2)/2 = 1$（$d=4$）。复核意见取 $1.5$ 却仍称 $I$ 为固定常数，两处不能并存。R5 的读数给出这一点。

R4 的读数确认：按复核意见自己的约定算下去，$d=4$ 下确实没有边际点。但这个约定不是库内约定，其结论不能用来否定库内约定下的分类。

**驳回二：单圈生成的算符是 $\dot\alpha^2(\partial_x\alpha)^2$，$d=4$ 维度 $8$。**

复核意见主张单圈生成四导数四场算符，维度 $8$。这与主注记 C4、C5 的读数不符。

主注记 C4 给出单圈气泡的 $\omega^2$ 展开系数相对量级 $0.5000$，C5 据此判对应算符维度为 $4+2=6$。复核意见把「含外部频率」直接等同于「多两个导数」，但没有区分频率依赖出现在哪个幂次。$O(\omega^2)$ 项对应两个时间导数，不是四个。R 组未重算这一项（主注记的闭式与 Feynman 参数化交叉核对已给偏差 $4.94\times10^{-12}$），故本轮维持主注记读数。

需要说明的是，这一条的实质分歧不影响结论方向：无论生成的算符维度是 $6$ 还是 $8$，两者在 $d=4$ 下都不可关，都被 $(E/E_P)$ 幂次压低。复核意见自己的判语也是「不可关、系数有限、不需抵消项」，与主注记结论三一致。

## 三、被采纳的三条

**采纳一：$\phi$ 扇区的维度我算错了。**

主注记结论四写「$\phi$ 场的 $\cos\phi$ 势能展开给 $\phi^4$ 型」，并称「两者的幂次分类恰好都在 $d=4$ 边际」。前半句是判据 719 注记的原表述，后半句是我加的，错在漏了 $\omega_0^2$ 的量纲。

体系 $\phi$ 场的势能不是裸 $\phi^4$，是 $\omega_0^2(1-\cos\phi)$。$\phi$ 为标量场，$[\phi] = (d-2)/2 = 1$（$d=4$）；$\omega_0$ 为频率，$[\omega_0] = 1$。故：

- $\omega_0^2\phi^2$ 维度 $2 + 2\cdot 1 = 4$，在 $d=4$ 恰为边际。
- $\omega_0^2\phi^4$ 维度 $2 + 4\cdot 1 = 6$，不可关。
- $\omega_0^2\phi^6$ 维度 $2 + 6\cdot 1 = 8$，不可关，以此类推。

即 $\omega_0^2$ 把所有偶次项整体抬高二。体系的 $\phi$ 四次项不因「纯 $\phi^4$ 在 $d=4$ 边际」而边际，它被抬到维度 $6$。R7 与 R8 的读数给出这一点。

主注记结论四据此收窄：$\alpha$ 扇区在 $d=4$ 确有唯一边际自相互作用；$\phi$ 扇区在 $d=4$ 的边际项是质量项 $\omega_0^2\phi^2$，四次及以上全部不可关。**两扇区的边际结构不同，不能并列称「都在 $d=4$ 边际」。**

**采纳二：物侧基础全文没有格点作用量。**

复核意见核出：物侧基础全文 374 行不含 $\alpha$，格点拉格朗日量的出处是《规范作用量的审计必然性》§3.5 与 [[wiki/拉格朗日量]]。

这一条我核了，属实（`grep -c 'alpha'` 给 0）。主注记把「物质侧链格点作用量」当作物侧基础的内容来核 §6.1，属引用失真。正确的说法是：§6.1 的重整化论证与该作用量所属的论文不是同一篇，本轮核的是「§6.1 的论证与库内格点作用量的幂次结构是否相容」。

这一条影响射程表述，不影响读数，但必须写明。

**采纳三：判据 718 不判物理取值，$\kappa = 2$ 是作者事后采纳。**

主注记与 README 正式行均写「经判据 718 修正后 $\kappa = 2$」。核对判据 718 注记第 74 行，原话为「本判据不判物理上应取何值，只判「作用量与它的三条后果不能同时成立」」。

故正确表述为：判据 718 判出三处后果与作用量差一个统一系数、修正唯一（$\kappa = 2$），取舍由作者裁决并已采纳。把「修正后 $\kappa = 2$」写成判据的结论，属把裁决结果归给判据。

## 四、部分采纳一条

复核意见称「论文未声明维数，§6.1 格点链一维（判据 719 一维周期链），§6.3 的维度 6 按 $d=4$ 算，两处口径不一致」。

核对结果：判据 719 注记第 119 行明写「本判据取一维周期链」，且「三维不在射程内」。故一维是判据 719 为算连续极限而取的简化，非体系维数。体系为三维空间格点加时间。

但复核意见指出的另一半成立：物侧基础论文确实没有声明维数。§6.1 的 $\Lambda = \pi/l_P$ 与 §6.3 的「维度 6」隐含 $d=4$，但正文未写明。这一条应作为论文的表述缺漏登记，留给作者裁决。

## 六、结论与射程修正

主注记的三条核心结论不变：紫外有限推不出可重整；重整化群流须拆扇区；$\alpha$ 场在 $d=4$ 恰有唯一边际自相互作用 $(\partial\alpha)^4$。

须修正四处表述。其一，$\phi$ 扇区的边际结构改述为「$d=4$ 的边际项是质量项，四次及以上全不可关」。其二，格点作用量的出处改写为《规范作用量的审计必然性》§3.5 与 [[wiki/拉格朗日量]]，不属物侧基础。其三，$\kappa = 2$ 标明为作者裁决采纳，不属判据 718 的结论。其四，论文未声明维数，属表述缺漏，登记待裁。

方法论收获一条：**派红队时须给出其可独立核实的原始文本，否则它会用自己的一套约定重算，得出方向相反的结论。** 本轮复核意见的两条驳回均源于它没有先核库内约定（$\alpha$ 无量纲）就直接从作用量反解量纲。反过来，它对 $\phi$ 扇区的批评恰好是因为那里确实有错。红队的价值落在另一处：它逼我把每一条都算一遍。
