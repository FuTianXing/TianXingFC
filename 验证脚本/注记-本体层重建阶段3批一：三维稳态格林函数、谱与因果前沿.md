## 二、设定与解析

三维立方格 $N^3$（周期边界），链接场 $u_e$ 为每条链接的记录读数，站点记录为各向链接读数的平均 $\theta_i = \frac{1}{2d}\sum_{e \ni i} u_e$，松弛规则

$$\frac{du_e}{dt} = \kappa\left(\frac{\theta_{i(e)} + \theta_{j(e)}}{2} - u_e\right) + s_e, \qquad \kappa = 1,$$

源写在链接上。该规则是阶段 2 一维规则的三维直推（一维下两者同形，速率相差常数因子 2），系数取一为最小选择。

由稳态方程与合成定义联立，站点侧给出 $\theta_i - \frac{1}{2d}\sum_{j \sim i}\theta_j = \frac{1}{d\kappa}\sum_{e \ni i}s_e \equiv f_i$，即平均拉普拉斯形式的泊松方程。源写在原点六条入射链接上（各得 $\kappa S/6$）时，$f$ 分布在原点与其六个近邻（分别为 $S/3$ 与 $S/18$），区域总荷 $Q = 2S/3$。

环面上净荷的泊松方程无解，零模约定把方程的常偏置显式化：数值解满足 $L_\mathrm{avg}\theta = f - \langle f\rangle$ 与合成恒等式 $\theta_u = \theta + \langle f\rangle/2$，其中 $\langle f\rangle = Q/n$；格面通量满足 $\Phi = 2d(Q - \vert R\vert\langle f\rangle)$，$\vert R\vert$ 为区域体积。远场读数取径向差分，并扣除环面镜像的解析贡献（非零镜像的连续场梯度之和）。

## 三、读数的意义

![图 1：阶段 3 批一的三幅读数。(a) 远场归一化读数（扣环面镜像）随半径变化，N=64 与 N=96 两例，目标值为 1；(b) 站点算符 S 的谱（N=4），落在 [0,1] 且顶层重数为一；(c) 松弛更新的支撑半径逐拍等于 n-1，即每拍一格。](../images/rebuild_3d.png)

**其一，三维稳态仍是同一条格林函数。** 泊松残差、合成恒等式与重构场的稳态残差都在 $10^{-17}$ 量级。重构规则 $u_e = (\theta_{i(e)} + \theta_{j(e)})/2 + s_e/\kappa$ 无调参，合成回来严格给出同一个 $\theta$。不可动清单第一条的"稳态格林函数"在链接型写入下保持：通量满足离散高斯（三例机器精度），归一化远场在 $r = 12$、$13$ 处为 1.0043 与 1.0002。

**其二，环面容源约束的可见形式。** 三处常偏置（$\langle f\rangle$、$\langle f\rangle/2$、$2d\vert R\vert\langle f\rangle$）都被先预测后核对，偏差在机器精度。它们随 $N$ 按 $1/n$ 与 $\vert R\vert/n$ 缩放，属环面几何的已知量，与重建无关；这解释了为何"残差为零"这一写法在环面上不可用，须写成含偏置的形式。

**其三，谱与零模结构。** 松弛算符的非零谱等于站点算符的谱，逐点偏差 $3.7\times10^{-15}$，符号式偏差 $2.2\times10^{-15}$；谱落在 $[0,1]$，顶层重数为一。含义是长度因子扇区的动力学只有一个零模（均匀平移，即 [[wiki/均匀缠绕背景]]），没有新增的零质量支或传播支；最慢非零速率随 $N$ 按 $1/N^2$ 标度并趋于 $\pi^2/3$，与阶段 2 的一维慢模同族，属泊松解的尺度效应。

**其四，因果前沿每拍一格。** 链接型显式更新的支撑半径逐拍等于 $n-1$，越界支撑为零，斜率 $1.000000000000$。与既有读数"因果前沿 = 每拍一格"一致，说明重建不改变每拍一格结构。

## 四、过程记录（订正五处）

**平均拉普拉斯符号漏二倍。** 首版把符号写成 $1 - \frac{1}{2d}\sum_\mu \cos k_\mu$，把六邻和当成了三个方向的和，解不是泊松解（远场读数整段偏移）。订正为 $1 - \frac{1}{d}\sum_\mu\cos k_\mu$ 后残差落到 $10^{-17}$。教训：六邻和的余弦因子是 $2\cos k_\mu$。

**环面容源约束。** 首版把泊松残差与通量的目标写成零与 $2dQ$，实测恒偏 $\langle f\rangle$ 与 $2d\vert R\vert\langle f\rangle$，一度判为失败。核对后确认这是环面上净荷无解的必然后果，判据改写为含偏置的精确形式。

**镜像扣除的归一化。** 首版把含 $n = 0$ 的镜像全和当作扣除项，远场读数整体系数错位（读数停在 3.9 而非 1）。订正为"归一化读数 $= v/(2dQ) - (\text{全和} - 1)$"。

**邻接表漏共线邻边。** 前沿测速的 BFS 邻接表初版只连不同方向的共享站点链接，漏掉同方向的共线邻边，读出支撑半径按二倍增长。补上后半径序列恢复 $0$ 至 $7$。

**交叉索引的标量索引。** 立方体面的索引初版把标量直接装入索引列表，NumPy 交叉索引只接受一维数组；改为单元素数组后通过。
