## 一、被合成的两条读数

受激率来自第 292、295、304 三条：$\dot N_{\rm 激} = A\,v\,g_{\rm 激}$，$g_{\rm 激} = \min(1, w/(v\,\Delta t_s))$。把它按 $v$ 分段即得

\[\dot N_{\rm 激} = A\,v \ \ (v \le v_{\min}),\qquad \dot N_{\rm 激} = A\,\frac{w}{\Delta t_s}\ \ (v > v_{\min}),\qquad v_{\min} = \frac{w}{\Delta t_s}。\]

驻留读数来自 C1 线：C1-4 给出格点内锁定的驻留窗口 $K \ge 0.24$ 至 $0.25$（能量型判据），C1-3 给出小 $K$ 档的塌缩命运。

## 三、结论：通道独立，但它是低速测速计

第一，独立性来自量的不同。C1-4 的驻留阈值测的是能量型锁定（势阱深度对动能），写入率测的是速度 $\dot N_{\rm 激} = Av$。两者不共线：锁定窗口可以很宽而速度非零（例如缺陷在深阱之间缓慢蠕动），也可以阱浅而速度为零（被边界钉住）。四格表把这两种情况单独列出为「矛盾格」，这正是独立通道的价值：它们不是冗余，出现矛盾格就指向第三因素。

第二，通道的可用区间是低速端。$v_{\min} = w/\Delta t_s$ 之上受激率饱和为 $A w/\Delta t_s$，速度信息被稀释吞掉。以 $w = 15.8\,l_P$ 计，$\Delta t_s \le 15.8\,t_P$ 时线性档覆盖全部物理速度；$\Delta t_s = 10^6\,t_P$ 时 $v_{\min} = 1.58\times10^{-5}c$，即通道只对慢于 $4.7$ km/s 的缺陷线性。作为驻留判据这恰好合适，驻留判据要分辨的是「停住」与「几乎停住」，低速端才是它的主场。

第三，与 C1-4 对照还缺一块读数。锁定窗内 $v = 0$ 应给受激项严格为零，这一条由模型构造保证；但塌缩档的速度没有实测（C1-3 只给 $E(R)$ 标度律与塌缩命运）。要把两通道的对照做成可判读数，需要补一条塌缩档的速度读数。
