## 二、模型与协议

三维立方格点 3-环面：$x$ 边 $e_x(i,j,k)$ 连 $(i,j,k)$ 与 $(i+1,j,k)$，$y$、$z$ 同理；键变量 $k_e \in Z_N$，$\omega = e^{2\pi i/N}$。

星项 $A_v = \Pi_e X_e^{s(v,e)}$（六个方向：出边 $+1$、入边 $-1$）；面项 $B_f = \omega^{\Sigma_e t(f,e)k_e}$（每个面逆时针环绕，四个边）。绕环三族（$Z$ 型原胞环，逐方向各 $L^2$ 个位置）；膜三族（$X$ 型：穿透一个平面的边集，每方向 $L^2$ 条边）。

核对项全为组合事实：对易条件的余数（$\Sigma s\cdot t \bmod N$）、绕环与膜的余数（$\Sigma s$ 与 $\Sigma t$）、最短支撑的构造计数、区域分类（区域是否包含完整环或膜，按已知环/膜族集合判定）。

## 三、主要读数

### 对易代数全通过（T3D-1 至 T3D-3）

九组参数（$N = 2, 3, 4$ 与 $L = 2, 3, 4$ 交叉）下，（星，面）对、全部绕环与全部膜的余数都是 $0$。定向口径的代数骨架在三维原样成立：局域项两两对易、两类非局域算符（环与膜）都是对称。

### 支撑尺度（T3D-4）

最短非可缩环 $= L$ 条边（与二维相同），最小非可缩膜 $= L^2$ 条边。含义：三维里"要动绕数荷"存在两种载体：环版的最小支持仍为 $L$，膜版的最小支持是 $L^2$。Q5 的"最小非平凡支撑 $= L$"在三维对环版原样成立，对膜版应改写为 $L^2$。

### 区域分类与最小支撑（T3D-5）

星区（一个顶点的六条边）：含完整绕环当且仅当 $L = 2$（$2$ 边环恰好是顶点两侧的出边与入边对）；$L \ge 3$ 时不含。面区（一个面的四条边）：任意 $L$ 都不含完整环，也不含完整膜。

由此：三维下不含完整环的最小区域支撑是 $L$（$L = 2$ 时 $6$ 边星区已足够承载 $2$ 边环；$L \ge 3$ 时需 $L$ 条边的路径）；膜版需要 $L^2$ 条边。与二维轮同型的小环面相合再次出现（$L = 2$ 的极小环面上，任意小区域都可能装下完整的绕环），判据必须按"是否含完整环/膜"逐例核对。

## 四、严格程度声明

全部读数为组合事实（有限枚举，无浮点近似）：对易余数为整数取模；最短支撑为构造计数；区域分类为集合包含判定。$N = 2, 3, 4$ 与 $L = 2, 3, 4$ 交叉共九组。本核对不含三维的谱、基态、简并与局域算子标量化数值。

## 六、过程记录（一处判据修正）

T3D-5 的预期写错一次。首版预期"面区在 $L = 2$ 时含完整绕环、星区不含"，实测相反：星区含（$L = 2$ 的 $2$ 边环即顶点的出/入边对），面区任何 $L$ 都不含。原因是把二维 plaquette 的几何（四边成一圈）直接搬到了三维的面（四边是 $2+2$ 两个方向，缺第三个方向的闭合）。修正为按实测的精确陈述后判据通过。教训：三维的面与二维的方块板在拓扑上并不等同，几何直觉跨维度搬运会错；判据的区域分类必须逐维度重算。
