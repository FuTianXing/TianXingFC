## 一、问题与口径

路线乙的问题是：把"声速等于 $c$"这条几何恒等式反过来当约束，能否钉出弹性系数的绝对值，还是只给比值。色散论文的原文已给出等式本身：$v_s^2 = K_0l_P^2/\bar t_P = c^2$，并声明 $K_0$ 的唯一可调参数（$f(0) = f(1)$ 各向同性条件）已由"声速等于光速"固定。

模型侧取带惯性的色散：$\omega^2(q) = (k_b/m_\Phi)\frac{4}{t_P^2}\sin^2(q l_P/2) + \frac{(2\pi)^2K}{m_\Phi t_P^2}$；几何侧为 $\omega^2(k) = \frac{4}{t_P^2}\sum_a\sin^2\frac{k_al_P}{2} + 3\omega_P\kappa_\phi$。两侧逐项相等给出两个条件。

## 三、解读

其一，**声速条件钉的是公理 4 的耦合**。$v_s^2 = K_0l_P^2/\bar t_P = c^2$ 是显式等式，给定 $\bar t_P$、$l_P$、$c$ 即得 $K_0$ 的绝对值。这与"速度值与传递强度无关"的接力几何一致：声速在这里是几何给定量，耦合由它来钉。

其二，**约定差仍是 $2\pi$**。$\bar t_P$ 取摆程本身还是摆程除以 $2\pi$，给 $K_0 = \omega_P$ 或 $K_0 = \omega_P/(2\pi)$；后一档对上 MB-1 的 $K_0 = 1/(2\pi t_P)$，即路线甲的字典用的就是这一档约定。

其三，**对 σ 锁定泛函只给比值**。两个匹配条件（$k_b/m_\Phi = 1$ 与 $K/m_\Phi = 3\kappa_\phi t_P/(2\pi)$）都含惯性 $m_\Phi$，一次都没有把它消掉。锚（电子档）只定出比值 $K/m_\Phi = (m_\delta/m_P)^2/(4\pi^2)$。

其四，**与路线甲合并的后果**。若取字典 $K = K_0t_P = 1/(2\pi) = 0.159155$，则 $m_\Phi = K/(K/m_\Phi) = 3.5866\times10^{45}$。也就是说，模型侧的质量层级并不住在 $K$ 的绝对值里，而住在惯性归一里；把 $m_\Phi$ 取为 1 会立刻把缺陷质量推回普朗克档。

其五，**判定**。路线乙是路线甲的前置：它先把 $K_0$ 钉死，路线甲才有资格谈"$K$ 是否等于 $K_0t_P$"。两者合并后剩下的唯一自由量是惯性 $m_\Phi$，登记为"惯性归一待裁"。
