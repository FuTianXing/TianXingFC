## 一、问题与口径

三轮把携源二阶项锁定为 $\rho_{\mathrm{eff}} = \rho_m(1 - \frac92\theta)$，但该值是"量出来的"：它的机制来源与归属未判。本轮把它拆成四问：形状（源侧修正长什么样）、系数（自然可导出的候选给什么值）、归属（$\frac92$ 从哪来）、以及源侧能否独立承担。

口径沿用三、四轮：完成式 $\theta_c = \theta_{\mathrm{lin}} - \theta_{\mathrm{lin}}^2$、规则 $h_{ij} = h_{00} + \frac78h_{00}^2$、机器 $G^{(1)}_{00} = -\nabla^2B$、单位 $\nabla^2\theta_{\mathrm{lin}} = -4\pi\rho_m$。源（软化高斯团块，$M$ 与 $\sigma$）与机器均不变。

## 三、解读

其一，**形状唯一**。把实测残差 $R = G_{00} - 8\pi\rho_m$ 逐点除以候选形状：局部乘性 $\rho_m\theta$ 的比值跨半径稳定在 $5\%$ 以内，且该散布随质量减半而减半，正是已知的 $O(\theta)$ 修正；$\rho_m\theta^2$、$(\nabla\theta)^2$ 与非局部窗口三类形状的散布为 $20\%$ 至 $234\%$。源侧修正的形状是局部乘性的，不含梯度、不含非局域项。

其二，**候选系数全判负**。自然可导出的机制候选给出 $\kappa = 0$（裸源）、$\kappa = -1$（红移，即按 $\sqrt{-g_{00}}$ 折算）、$\kappa = +2$（四维体积元）。实测的 $\kappa = -4.5$ 与三者都不符：$\frac92$ 不是源侧的自然量。

其三，**系数由几何合成**。把机器读数对到分解式 $G_{00} = -2\nabla^2\theta + 5\theta\nabla^2\theta - 4(\nabla\theta)^2$（相对差 $0.07\%$ 至 $0.7\%$），再代入清式 $\nabla^2\theta_c = -4\pi\rho_m(1 - 2\theta) - 2(\nabla\theta)^2$：两个几何槽位（$\theta$ 场项与 $\frac54$ 权重项）各把源因子放大一倍与 $\frac54$ 倍，给 $-2\theta$ 与 $-\frac52\theta$；梯度项两半精确相消。

$\frac92 = 2 + \frac52$，两部分都可追溯到已判的读数。

其四，**源侧单独不可能**。设源独模型 $\nabla^2\theta_S = -4\pi\rho_m(1 + \kappa\theta_S)$，把完成式的源因子搬来（$\kappa = -2$）后与完成场的曲率差仍在 $1.8\%$ 至 $13.2\%$ 之间，且两档质量的占比同量级（与 $M$ 基本无关）：这是真正的失配，不是微扰残渣。

逐点解出的 $\kappa_{\mathrm{req}} = -2 + (\nabla\theta)^2/(2\pi\rho_m\theta)$ 随半径单调变化（$-1.90$ 到 $-0.77$），没有任何常数 $\kappa$ 能同时满足全剖面：梯度项不属于源侧。

其五，**机制侧余项**。源侧能承担的是源因子 $(1 - 2\theta)$；它等价于完成式 $\theta = \theta_{\mathrm{lin}} - \theta_{\mathrm{lin}}^2$，而完成式目前仍是真空精确解的读数，不是机制导出。机制侧下一判据随之登记：把 $(1 - 2\theta)$（或等价的完成式）从満周/自耦合的写入结构导出。

## 四、严格程度声明

G1b5-1 为比值散布的判据（三类形状的失配为数十至数百个百分点，唯一存活者的残差为已解释的 $O(\theta)$ 修正）；G1b5-2 为候选清单与实测对照（清单的"自然性"属选择依据，判负为硬结论）；G1b5-3 为解析分解与机器的点态核对（$10^{-3}$ 级）；G1b5-4 为源独模型的构造性对照（泊松解由积分求积给出，曲率差为机器读数之差）。四条均为判据级。

## 五、边界声明

- 验证：源侧修正的形状、候选系数的判负、系数分解的几何归属、源侧单独不可能的定量判定。
- 不验证：机制侧导出本身（満周/自耦合给出 $(1 - 2\theta)$）留作下一判据；一般位形与时间依赖（本轮仍为静球对称高斯源）；$G_{ij}$ 通道（压力读数）未在本轮。
- 一条口径：本轮的"源独模型"是把源修正写成只含 $\rho_m$ 与 $\theta$ 的局部项；结论是这一类模型不可能。含梯度的源型修正不在判负范围（但那样已不属"源侧"）。
