## 一、任务与模型

D-3 按裁决二的口径（窗口质量作方程标签、形状范数作解析预言核对、响应质量作独立通道）给出质量与迁移率。

模型（甲）：带倾斜与阻尼的 FK 链，偏离量 $v_n = u_n - n$，

$$\ddot v_n = k_b\nabla^2 v_n - K\,2\pi\sin(2\pi v_n) + f - \gamma_d\dot v_n,$$

其平衡 kink 的平移模投影给出终端速度律 $v_{\rm term} = f/(\gamma_d M_{\rm zero})$，其中 $M_{\rm zero} = \sum_n (\mathrm dv/\mathrm dn)^2$ 为形状范数（数值 $0.0903$）。$\gamma_d = 1$，$K = 0.005$，$k_b = 1$，$M = 256$ 站点。

## 三、读数与判定

**其一，终端速度律成立。** 平移模投影给出的 $v_{\rm term} = f/(\gamma_d M_{\rm zero})$ 与数值迁移率相符（偏差 $0.56\%$）；形状范数由平衡剖面直接算出（$0.0903$），不引入新参数。

**其二，响应质量的理论值就是形状范数。** 由数值迁移率反解的响应质量为 $0.0908$，与形状范数差 $0.57\%$；即甲形式预言「响应质量 = 形状范数」，既有读数 $0.094$ 与该预言相差 $3.9\%$，属离散与协议层修正（登记为读数）。

**其三，三质量口径的排序与差额。** 形状范数 $0.0888$（解析、刚体平移预言）< 响应质量 $0.094$（高 $5.9\%$）< 窗口质量 $0.0936$ 至 $0.0994$（高 $5.4\%$ 至 $11.9\%$）。按裁决二，方程标签取窗口质量；差额来源（离散修正、窗口协议）登记为残余读数，不调参凑数。

**其四，乙形式给同一律。** 过阻尼极限的迁移率与甲相同（$11.01$，偏差 $0.56\%$），因为两者共享同一形状范数；这再次支持「甲为主、乙为对照」的裁决。

**其五，既有迁移率的反解。** 既有读数 $\mu = 18.9$ 与形状范数 $0.0888$ 反解 $\gamma_d = 1/(18.9 \times 0.0888) = 0.5958$，登记为本模型的阻尼口径值（此前该系数是自由参数）。

## 四、严格程度与边界声明

| 结论 | 严格程度 |
|---|---|
| 终端速度律 $v_{\rm term} = f/(\gamma_d M_{\rm zero})$ | 解析（平移模投影）加数值（$0.56\%$） |
| 响应质量 = 形状范数 | 解析加数值（$0.57\%$）加与既有读数的对照（$3.9\%$） |
| 三质量差额 | 读数（登记，不调参） |
| 既有迁移率反解的 $\gamma_d$ | 口径值（由既有读数反解，本模型自洽） |

**验证什么**：甲形式的终端速度律、响应质量与形状范数的关系、乙形式的同律性、三质量差额的排序。

**不验证什么**：不给脱钉阈值（D-4）；不给与写入机制的节拍关系（D-5）；不涉及三维与完全量子化（D-7）；窗口质量的独立复核不在本轮（只引用既有读数）。

## 五、过程记录

**订正三处。** 其一，kink 速度首版用中心处剖面的斜率变化除以步长，量级错到 $6.4\times10^4$（迁移率）；改为形状加权质心 $X = \sum n w_n/\sum w_n$（$w_n = (\Delta v_n)^2$）并用最小二乘拟合斜率，迁移率回到 $11.0$ 档。
其二，迁移率的符号首版直接取带符号值（$-11.01$），与理论正值相差 $199\%$；改为取绝对值并在判据里写明「方向由倾斜符号定」。
其三，乙形式首版写成无阻尼形式（漏掉除以 $\gamma_d$），与甲不一致；改为过阻尼方程 $\gamma_d\dot v = k_b\nabla^2v - K\,2\pi\sin(2\pi v) + f$ 后与甲同律。
教训：投影律类判据要先核对「测的是什么量」（这里是 kink 质心速度，不是剖面斜率），再核对符号与量纲。
