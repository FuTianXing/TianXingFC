## 一、问题与口径

前几轮的完成形式只用 00 支（记录方程与曲率读数）。四维组装要求 0i、ij 两支与 3+1 约束结构一起交代，否则"场方程"只在一个分量上成立。本轮在静球对称的完成场上把四类分量全部读出来。

口径沿用前几轮（完成式、规则、机器）。压力读法取流体形式 $T_{ij} = p\,g_{ij}$，径向与切向各给一个读数：$p_r = G_{xx}/(8\pi g_{xx})$、$p_t = G_{yy}/(8\pi g_{yy})$（各向同性坐标下 $g_{xx} = g_{yy} = 1 + G$，故 $p_r$ 与 $p_t$ 之差即各向异性）；迹取 $3p = p_r + 2p_t$。3+1 结构用 $N^2 = 1 - F$ 与 $\gamma_{ij} = (1+G)\delta_{ij}$。

## 三、解读

其一，**00 支回归**。与三轮同口径逐位一致（$4.3939$、$4.3533$、$4.2890$）：完成场的 00 支读数可复现，四维组装没有改变它。

其二，**ij 支与压力读数**。迹 $3p/(\rho_m\theta)$ 随质量趋于约 $0.5$：完成形式的源在空间扇区带一个正的小压力 $p \approx \frac16\theta\rho_m$，量级为 $O(\theta\rho_m)$。各向异性在 $O(\theta)$ 级、$\le 8\%$，其符号随质量变化，极限未定。这一条更订了三轮边界登记：那时的"$p = -\frac32\theta\rho_m$（负压）"是把 $\rho_{\mathrm{eff}} = \rho + 3p$ 当等式反推的猜想，实测为正压小量，该读法作废。

其三，**3+1 哈密顿约束**。$G_{00} = \frac12N^2R^{(3)}$ 在完成场上成立到 $10^{-7}$ 量级（**符号约定**：此处的 $R^{(3)}$ 用「$\nabla^2$ 取正的球坐标 Laplace」的约定；**标准 GR 约定下同一关系式写作 $G_{00}=-\frac12N^2R^{(3)}$**，2026-10-21 由第 787 号独立核对）：把 00 支写成"空间曲率的约束"，给出它在 3+1 语言里的等价形式，也是协变化在约束侧的第一步。

其四，**0i 支与守恒**。静场 $G_{0i}$ 恒等为零（机器读数为差分零）；矢量扇区的非零内容需要转动源，已在《微观根基》§5 的线性层给出（判据 Z、K），非线性版不在本轮。收缩比安基对任何度规都是恒等式，本轮只作登记。

其五，**协变余项**。四维组装在静球对称上齐备，"完整协变形式"仍缺四件：一般（非球）位形、时间依赖、源侧 $T_{ij}$ 的微观分解（张量桥 d，本轮给出它必须提供的读数）、以及介质不可探测性对观测协变的论证（构造在格架中给出，协变性在观测层兑现）。
