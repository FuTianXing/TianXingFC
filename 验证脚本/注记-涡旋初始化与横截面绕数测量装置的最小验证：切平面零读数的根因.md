## 二、模型与装置约定

模型取 kink3d A 部分（$J_0 = 1$、$\kappa = 0.6$、$N = 48$、格距 $1$、开放边界，边界外一圈取真空），

$$H = \frac{J_0}{2}\sum_{\text{bonds}}(1 - \cos\Delta\varphi) + \kappa\sum_{\text{sites}}(1 - \cos\varphi)$$

绕数在横切芯线的平面内测：法向为 axis 的第 $s$ 层格面上，逐 plaquette 累加最小像相位差并除以 $2\pi$。回路取向取平面内全局指标升序 $(a, b)$，等价于法向 $e_a \times e_b$，故读数符号 = 绕数符号 × (芯线切线 · 该法向)。

三条硬性规则由判据实证。其一，平面须横切芯线，顶点法向平面平切芯线或落在环外，读数恒零。其二，窗口不得同时套住环的两个交叉点，平面 $x = \mathrm{const}$（$\lvert x \rvert < R_c$）上环有两个交叉点且取向相反，大窗口的和为零。其三，格点须半格偏移，整数格点上芯位落格点时跨芯键相位差恰为 $\pm\pi$，$\mathrm{mi}(-\pi) = \mathrm{mi}(+\pi) = -\pi$ 破坏反对称，读数退化为一侧 $0$、另一侧加倍。

## 三、根因：零读数来自测量平面，不来自初态

2026-09-12 的中间尝试（[[minimal_verification_composite_dislocation_3d]]）把测量平面取成了环轴法向平面（$x = \mathrm{const}$，法向为 $\hat x$）。环芯圆位于 $z = 0$ 平面，顶点处芯线切线为 $\hat y$，与 $\hat x$ 垂直，故该平面族与芯线的关系是平切或落在环外：

- $x = +4.5$ 落在环外（环的最大 $x$ 为 $R_c = 4$），窗口内无任何交叉，读数 $0$；
- $x = +3.5$ 与环有两个交叉点（$y = \pm 1.94$），半宽 $3$ 的窗口把两者一起套住，取向相反的两个 $2\pi$ 相消，读数 $0$。

判据 M5 给出决定性对照：同一个初态在横切平面（$y = \pm 0.5$）上的读数为 $\lvert W \rvert = 1$，且精度到 $10^{-12}$；在 $x = +4.5$ 平面上复现旧读数 $0$。环裁决实验 v1 已记过同一约定（"涡量为方位角向，$z$ 平面 xy-plaquette 测的是 $z$-涡量分量"），v2 已给出正确读法（$y = 0$ 平面的 xz-plaquette 在 $x > 0$ 半平面求和）。

据此，中间尝试文档中的"环的涡旋初态构造有缺陷"不成立，须更正为"测量平面对"缺失。旧文档的三处表述（$\pi_2$ 记号、初态缺陷、绕数判定不可用）已在脚本头部与计划 §三、§四 同步更正。

## 四、两类初态构造的边界

**标准环**（$\varphi = \operatorname{arctan2}(z, \rho - R_c)$）：零集恰为芯圆，每面两个交叉，读数精确为 $\pm 1$，涡量集中（到芯圆 $0.03$ 格）。代价在渐近行为：其相位在无穷远趋于极角 $\pi/2 - \theta$，边界映射非平凡，故初态能量随盒增长（判据 M12：盒增大 $2.33$ 倍时能量增大 $8.01$ 倍），属非局域对象。

**遮罩式构造**（环裁决实验 v2）：取 $S = (1 - m) + m e^{i\psi}$，其中 $\psi$ 的奇异圆在 $\rho = R_{\text{param}} = R_c + 3.5$，而 $m \equiv 1$ 的管状区覆盖该奇异圆，于是相位在 $\rho = R_{\text{param}}$ 处另生一个反向涡环。判据 M7 实测：每面 $4$ 条真实涡量 plaquette（标准环只有 $2$ 条），内环 $\rho = 4.03$ 与外环 $\rho = 7.02$ 各一对，取向相反，故 $x > 0$ 半平面读数为零。

这条更正牵连 v2 注记的一处表述：该注记的 [G1] 校验在整数格点上进行，而整数格点的读数本身退化（判据 M4e：$+x$ 侧 $0$、$-x$ 侧加倍），嵌套反环的一半权重因此被隐藏。v2 注记的主结论（裸环在一切构造半径下 $E \to 0$）自述为"测量无关的硬事实"，不受影响；"芯位吻合"一项应按本注记 M4e 与 M7 重新表述。

读数有两层。其一，$\kappa_p \le 2$ 时全盒无涡量，构型被卸载成光滑的无绕数场，能量仍有限（$162$ 至 $577$），能量有限不能当作绕数守恒的证据。其二，$\kappa_p = 4$ 时保留的是一组正负配对的涡量网络，窗口恰有一个 $+1$ 落在其中，单点读数在此情形不足以判定环的存续。

两种锁定周期结果相同，故"$\pi$ 周期锁定留出 $\varphi \to \psi + \pi$ 的分支"这一猜测被排除：$\kappa_p$ 与协议不足以定住绕数，与锁定周期无关。原记录的"正向信号（构型驻留、能量有限）"应改判为"能量有限、绕数不守恒"。该结论的适用限度见第六节与第八节。

## 六、严格程度声明

判据 M1 至 M12 为格点最小模型的数值读数，$J_0 = 1$、$\kappa = 0.6$、$N = 48$、格距 $1$、开放边界。全部绕数读数取整数值，数值残差不超过 $10^{-12}$；能量末值到 $3.1\times10^{-9}$。确定性计算，随机数仅在判据 M11 使用且种子固定。判据覆盖构造与测量，不覆盖连续极限外推、格距与物理单位。

第五节的锚核读数只用一个协议（过阻尼梯度流，$\eta = 0.02$，1200 步）与一组较粗参数（$\kappa_p = 0.5$ 至 $4$，$R_c = 3$ 至 $6$），属 C1-4 的预备观察，未做 C1-1 要求的双协议对照与边界协议一致性检查，不构成 C1-4 的裁决结论。

## 七、过程记录（修正与教训）

第一，诊断脚本最初用 `argwhere(dens != 0)` 判非零，把 $10^{-16}$ 量级的浮点残渣当成涡量，得到"每面 $158$ 条"的错误计数，并据此把根因误判为初态构造。修正：以 $\lvert \text{dens} \rvert > 0.5$ 判非零。同类陷阱在同一轮内出现两次（一次在柱半径分组、一次在局域化判据），教训是凡以涡量密度判存在，必须带阈值。

第二，判据 M6 最初把"窗口中心平移 $\pm 1$ 格"实现为坐标平移 $1.0$，窗口整体越出芯位，读数归零被误判为装置不稳。修正：改用芯位四邻角窗口（坐标 $\pm 0.5$）。

第三，判据 M8 的符号预期写反（`ring_naive` 的默认参数已是 $n = 1$）。

第四，判据 M10 最初用固定窗口读动力学读数，把"芯位移出窗口"读成"绕数丢失"。修正：先定位交叉所在 plaquette 再读，固定窗口只对构造态有效。修正后读数给出裸环缩芯序列 $4.03 \to 3.04 \to 1.12$ 格，约 $200$ 步后交叉消失，与环裁决实验的塌缩一致。

第五，`ring_naive` 与遮罩构造的差别最初被误读为"零读数来自初态"，实际差别只在测量平面与遮罩引入的嵌套反环。

第六，脚本头部与计划文档中的 $\pi_2$ 记号一并更正为 $\pi_1(S^1)$：场取值在 $S^1$，线缺陷的分类是 $\pi_1(S^1) = \mathbb{Z}$。

## 八、边界（本注记不验证的内容）

其一，构型稳定性、驻留机制与锚核身份属 C1-1 至 C1-4，本注记只交付装置与构造层读数。其二，第五节结论限于所测协议与参数，双协议对照未做。其三，带真空渐近的**单**环构造尚未给出：标准环拓扑干净但非局域，遮罩构造局域但带嵌套反环，这一构造层缺口登记为 C1-1 的输入问题。其四，连续极限、格距与物理单位、以及写入动力学接口均不涉及。
