## 一、问题与口径

路线丁的判定问题是：记录写入幅度 $\delta\theta = m/m_P$ 里的 $m$，是物理质量还是模型质量。若是物理质量，则这一式已经把物理标度引进系统，桥的位置应前移到写入机制；若是模型质量，则缺口仍在，本路线判负。判定按原文溯源做，不引入新计算。

## 二、原文证据

其一，[[理论总纲/元相方程]] 把 $G$ 的角色写成：$G$ 通过 $l_P = \sqrt{\hbar G/c^3}$ 进入理论，单体层面隐含于 $\delta\theta = m/m_P = m\sqrt{G/\hbar c}\propto\sqrt G$。这一式把 $m_P$ 展开成 $\sqrt{\hbar c/G}$，故 $\hbar$、$c$、$G$ 三者都在式子里。

其二，[[理论总纲/元相子理论要点总览]] 的静态弱场链：每拍写入 $\delta\theta = m/m_P$ 到法线场，稳态为离散泊松格林函数（$4\pi$ 自动涌现），长波极限 $\nabla^2\Phi = 4\pi G\rho$。链的末端出现物理的 $G$ 与 $\rho$，说明这条链的单位体系是物理单位。

其三，[[从复合位错到爱因斯坦场方程：粒子机制现状综合与攻坚纲领]] 把"写入幅度 $w$ 与 $8\pi Gm$ 的归一化"登记为缺口，并注明 $G$ 目前为自洽输入。这条登记与本判定的分工是：写入幅度的**物理化**已由该式给出（本轮判定），而 $w$ 与 $8\pi Gm$ 的**同一性**（模型单位到物理单位的换算）仍待路线甲与路线丙。

## 三、判定

其一，$m$ 判为物理质量。依据是式子本身含 $m_P = \sqrt{\hbar c/G}$：只要写下 $m/m_P$，物理标度就已经在式子里面，这不是可以在模型内消掉的比例。

其二，路线丁判为正面。按计划的判据方向，"若为物理质量，则这一式已经把物理标度引进系统，桥的位置应前移到写入机制，不停在 §7"。据此，桥的位置登记在写入机制一侧（每拍碰撞写入的幅度给出物理倾斜），缺陷动力学 §7 的"待桥"标注可以在引力侧撤销。

其三，残余两项，都属他线。一项是模型侧缺陷质量与物理锚质量的等式（路线甲与路线丙的本职），本判定只解决"写入幅度用哪套单位"，不解决"缺陷质量是多少 kg"；另一项是 $w$ 与 $8\pi Gm$ 的同一性（纲领已登记），它是桥在写入机制内部的最后一环。

其四，与本轮其他判据的接口。MB-1 给出桥因子 $\epsilon = 1$，MB-2 给出 $K_0$ 的绝对值与 整周锁定势泛函的比值条件，本条说明写入幅度一侧不需要桥。三者合起来，桥只剩"模型缺陷质量 = 物理锚质量"这一处。
