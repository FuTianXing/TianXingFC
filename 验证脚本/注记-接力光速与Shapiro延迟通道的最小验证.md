## 二、模型设定

单位制取 $c=1$、$l_P=t_P=1$。静态源的法线场记录取

$$\theta(r) = \frac{\theta_0r_0}{r} \quad (r \ge r_0), \qquad \theta_0 = \frac{GM}{c^2r_0} = 0.002,$$

即 $GM/(c^2r)$ 的无量纲化。为让径向光穿过源心时表达式不发散，内区按均匀球正规化，$\theta$ 与 $\mathrm{d}\theta/\mathrm{d}r$ 在 $r=r_0$ 处连续；$b \ge 50$ 时路径不进入内区，S1 至 S3 与内区选择无关。光线在 $y=b$ 处沿 $x$ 方向入射，积分域 $x\in[-X,X]$，末端做末步裁剪，使终点精确落在 $x=X$，从而消除末步过冲带入的 $O(dt)$ 项。

B2 更新规则为

$$\frac{\mathrm{d}v}{\mathrm{d}t} = 2c^2\left(\nabla\theta - \hat v\,(\hat v\cdot\nabla\theta)\right),$$

横向投影使速率严格不变（S1）。对该规则，横坐标 $y=b$ 固定、沿 $x$ 匀速的直线近似给出横向量变化

$$\Delta v_y = -2\theta_0r_0b\int_{-X}^{X}\frac{\mathrm{d}x}{(x^2+b^2)^{3/2}} = -\frac{4\theta_0r_0X}{b\sqrt{X^2+b^2}},$$

即偏转角基准 $\alpha_{\text{有限}} = 4\theta_0r_0X/(b\sqrt{X^2+b^2})$；$X \gg b$ 时退化为标准形式 $4\theta_0r_0/b$。

GR 型对照取各向同性坐标下坐标光速 $c(1-2\theta)$，沿同一路径的一阶时间超出为

$$\Delta t_{\text{GR}} = \int_{-X}^{X}\left[\frac{1}{1-2\theta(x)}-1\right]\mathrm{d}x \approx 4\theta_0r_0\,\mathrm{arcsinh}\frac{X}{b},$$

这是标准 Shapiro 对数形式，用于摆放阶数与量级，不在本框架内推导。

## 四、物理读数

偏折通道与时间通道不对称。同一个 B2 规则在 $b$ 从 50 到 1000 的三组配置下逐位命中偏折解析基准，时间超出却停留在 $10^{-5}$ 至 $10^{-8}$，与 GR 型一阶延迟相差三到六个数量级，且差距随 $b$ 增大而拉大。两条通道由同一度规派生，兑现的只有方向，速率一侧的效应为零。

时间超出是路径弯折带来的几何长度增量，与场压低坐标光速的机制无关。S3b 给出该判断的定量形态：超出量与偏转角平方之比在 $\theta_0$ 变化八倍的范围内恒定在 $481.5$，说明它严格二阶。一阶项在该通道不存在。

径向通道给出最干净的对照。$\hat v$ 与 $\nabla\theta$ 平行时横向投影恒为零，光在径直穿过源附近时受不到任何作用，偏折与延迟同时为零；GR 型在同一配置下给出的是全量 Shapiro 延迟，因为径向是最强通道。两者的差别落在效应的有无上，用强弱之别不足以概括。

缺口的位置可以由 S6 与 S7 定死。S6 表明框架自身度规的完整零测地线读法同时给出正确的偏折与正确的 $O(\theta)$ 延迟，延迟系数对应 $\gamma = 1$，与太阳系的最精密测时约束相容。S7 把三条候选读法摆在一起：接力每拍一格给 $\gamma = -1$，仅钟率被场调制给 $\gamma = 0$，完整零测地线给 $\gamma = 1$。三者中只有第三条与观测相容。B2 规则与完整读法的差别只有一处：B2 强制 $\lvert v\rvert \equiv 1$，完整读法让坐标光速降为 $1-2\theta$。缺口因此坐落在速率通道的取舍上，不在度规识别的系数上。

这也把两条候选出路的地位改写了。出路二（补全纵向项）在系数层已经兑现，代价是"光速恒为 $c$"从全局陈述降为局域陈述，并与晶格刚性协调。出路一（仅钟率被场调制）在系数层给出半量延迟，对应 $\gamma = 0$，被 Cassini 的 $10^{-5}$ 级约束排除。S7 的输出是系数层的对照，不判定微观环节对应哪条读法，那一层属作者裁决。

经验锚受到的直接影响在 $\lambda = 1$。空间系数 $\lambda$ 即 PPN 参数 $\gamma$，经第四轮评审 A1 降为构造假设后，其唯一的独立经验检验是 P1-24。太阳系对 $\gamma$ 的最精密测定（Cassini 测时，$\gamma-1 = (2.1\pm2.3)\times10^{-5}$）测的是 Shapiro 延迟。若本机制交不出延迟，该锚点落空，$\lambda = 1$ 将只剩构造自洽而无外部检验。

S5 记录了一处口径陷阱。不裁剪末步的朴素欧拉法给出恰好等于 $dt$ 的假时间超出，比值恒为 1，容易被读成"存在一阶延迟"。这一读数与物理无关，来自末步过冲；裁剪末步后伪影消失，残余量稳定在真实的二阶弧长超出上。原临时核验据此把该读数判为离散化效应，判断正确，本注记补上了裁剪前后的对照证据。

## 五、严格程度与边界

S1 至 S5 为可复现数值事实（确定性计算，无随机数，判定依据为解析基准与 $dt$ 收敛性）。B2 更新规则是输入，取自 [[注记-测地线平行输运验证：法线场响应侧]]，本注记不重导它，也不核验其微观来源。GR 型对照取标准结果，用于摆放阶数与量级。有限路径解析基准在直线近似下成立，忽略路径弯曲对横向加速度积分的修正，实测偏差 $10^{-4}$ 量级的残余即该项近似。

本注记不验证接力几何的"每拍一格"在场存在区域是否严格成立，该问题属机制层裁决项。S6 与 S7 给的是同一度规三条读法的系数层对照，回答"若取某条读法，系数是否对得上"，不回答"微观上哪条读法成立"；后者的裁决依赖写入动力学在场存在区如何调制拍率，未在本注记中构造。$\theta_0 = 0.002$ 取便于与既有判据对照的数值，S3b 表明结论不依赖该取值。

## 七、过程记录（口径更正）

原临时核验用朴素欧拉法、末步未裁剪，测得时间长出恒等于 $dt$，当时的判断是纯离散化效应。提升为常驻资产时加入 S5 的裁剪前后对照，确认该读数的来源是末步过冲。S2 的参考量选择也作了更正：初版直接对照渐近式 $4\theta_0r_0/b$，在 $b = X$ 时偏差达 29%，属参考量不适用于有限路径，改为有限路径解析基准后三组偏差均落在 $10^{-4}$ 内。内区正规化是新增项，作用是让径向情形（$b=0$）可算。S6 与 S7 为提升后追加：提出动因是原结论只说明"B2 通道没有延迟"，未回答"框架能否给出延迟"。补上完整零测地线读法后，答案是该框架的度规本身能给出 $\gamma = 1$ 的延迟，缺口收窄到 B2 的速率约束这一处取舍。
