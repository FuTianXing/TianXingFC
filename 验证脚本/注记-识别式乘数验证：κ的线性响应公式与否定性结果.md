## 二、模型设定

一维束缚态有效算符（路径乙，度规型；草稿 §6.1）：

$$\Big[-c_s^2(1+a_1\theta)\,\partial_x^2 + \omega_{gap}^2(1+a_2\theta) + (1+a_4\theta)\,U(x)\Big]\psi = (1+a_3\theta)\,\omega_b^2\,\psi$$

四条线性响应 $c_s^2(\theta) = c_s^2(1+a_1\theta)$、$\omega_{gap}^2(\theta) = \omega_{gap}^2(1+a_2\theta)$、$A_{kin}(\theta) = 1+a_3\theta$、$W(\theta) = 1+a_4\theta$。一阶微扰给出时钟固有时比率

$$\frac{\omega_b(\theta)}{\omega_b(0)} = 1 - \kappa\,\theta + O(\theta^2), \qquad \kappa = \frac12\Big[a_3 - a_1 w_k - a_2 w_g - a_4 w_U\Big]$$

权重为无扰动基态的模平方期望值 $w_k = \langle -c_s^2\partial_x^2\rangle_0/\omega_b^2$、$w_g = \omega_{gap}^2/\omega_b^2$、$w_U = \langle U\rangle_0/\omega_b^2$，由无扰动本征方程保证 $w_k + w_g + w_U = 1$。

数值设定：$N = 4000$ 均匀格点、$L = 30$、$h = 2L/N$；$c_s^2 = \omega_{gap}^2 = 1$；基态用三对角精确对角化（`scipy.linalg.eigh_tridiagonal`，确定性，无随机迭代，无收敛容差参数）；$\kappa$ 用中心差分 $\theta = \pm10^{-5}$ 提取。阱形取谐振 $U = x^2/2$ 与四次 $U = x^4/4$。

基态基准核对：谐振阱 $\lambda_0 = 1.7069229325$，解析 $1 + \sqrt2/2 = 1.7071067812$，相对偏差 $1.1\times10^{-4}$，为 $O(h^2)$ 离散误差，与格点标度一致（此项为模型设定自检，非判据）。

## 四、判定

**M1 达成**：更正公式在全部案例中与中心差分实测吻合到 $10^{-6}$ 以内（最好到 $10^{-10}$），初版公式的符号错误与权重错配被复现确认。

**M2 达成**：权重归一在 $10^{-11}$ 内成立，且 $w_k$ 用离散拉普拉斯二次型独立计算，归一恒等式未被用作输入，故归一恒等式未被用作输入，本项为真实检验。

**M3 达成**：使 $\kappa = 1$ 所需的 $a_4$ 随阱形从 4.000 变到 6.000。所需的 $a_4 = 2(w_k+w_U)/w_U$，而 $w_k/w_U$ 是时钟构造（阱形、束缚质量、模式阶数）的属性，非微观固定量。故不存在一组彼此独立的响应系数赋值使 $\kappa = 1$。

**结论的形态**：$\kappa = 1$ 与根式完成是同一句陈述，内容为局部固有物理不变（坐标频率按 $\sqrt{-g_{00}}$ 标度）。该陈述要求全部局部固有标度（阱形、带隙、刚度、时间导数归一）协同变换，而协同变换恰恰要求这些系数彼此不独立；用一组独立响应系数去"数出" $\kappa = 1$ 因此结构上不可能。这是草稿 6.1.1 与 2.6 结论的独立数值复现。

## 六、边界声明（验证什么、不验证什么）

- **验证**：更正公式的正确性（M1）；权重归一的独立性（M2）；否定性结果"所需的 $a_4$ 随阱形变、故无普适赋值"（M3）。这三项在一维、正谱阱、固定外加约束势 $U(x)$ 的设定下成立。
- **不验证**：其一，记录场与束缚态算符的耦合是否独立于背景格距（草稿 4.4 的剩余义务；若收敛必须经由背景格距改变，则退回 4.2 的主体错位两难）；其二，T0 度规结构判定（由 S6 在 $\theta = 1/2$ 处的完成值裁决，本脚本不裁决）；其三，三维（本装置为一维，三维推广须等复合位错纲领 C1 的三维位错形态）；其四，负谱阱（$\lambda_0 < 0$ 时 $\omega_0$ 虚，一阶线性化失效，草稿 §7 的 S1-S3 均假定时钟存在正频基模，本脚本只取正谱阱）。
- **条件化提醒**：M3 的否定性结果条件化于"约束势 $U(x)$ 为外加固定输入"这一设定。草稿 6.1.1 末与 6.3 末登记的出口是：若约束势由包层自身张力撑起（不经由外加固定输入），则各系数彼此独立的前提失效，否定性结果不适用。该出口未做任何检验，本脚本不覆盖。

## 七、过程记录（判据与实现的两处修正）

其一，基态基准的核对。设定自检时先按连续谱解析 $1 + \sqrt2/2 \approx 1.7071$ 对照，初判脚本值 $1.7069$ 有疑；改用解析式复核后确认脚本正确（离散化给出 $O(h^2)$ 偏低，$1.1\times10^{-4}$），并保留此项为设定自检。教训：阱中基态能量须用含零点的解析式核对，勿凭记忆取基准。

其二，$w_k$ 的独立计算。草稿脚本以 $w_k = \langle -c_s^2\partial_x^2\rangle_0/\omega_b^2$ 计算并据归一恒等式检查。本脚本改用离散拉普拉斯二次型独立算 $w_k$，再由求和检验归一，使 M2 成为对三重求和结构的真实检验。两条路径给出一致结果（谐振阱 $w_k = 0.20708$）。

其三，M1 的最末案例（$(-1,0.5,0.25,0)$）相对偏差 $2.9\times10^{-7}$ 为全部案例中最大，源于该参数下 $\kappa$ 绝对值较小（$0.082$）使相对误差放大；绝对偏差仍在中心差分精度内。判据阈值取 $10^{-6}$ 已覆盖。
