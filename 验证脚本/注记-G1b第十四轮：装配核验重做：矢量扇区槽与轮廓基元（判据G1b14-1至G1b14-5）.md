## 一、问题与口径

第十三轮判定：TT 波残余的常数部在器械对角类内无对应项。本轮按裁决做两件：给器械加矢量扇区槽（$g_{0i}$，移位向量）与轮廓基元（$u^2$ 形迹扰动，其线性响应对 $u$ 恒定），重做装配核验。

解析预期：迹扰动 $h_{ij} = B(u)\delta_{ij}$（$u = t - z$）的零向三分量响应为 $-B''(u)(1, 1, -1)$；残余为 $\frac{a^2k^2}{4}(1 + 3\cos 2u)$，故所需修正为 $B_{u^2}(u) = -\frac{a^2k^2}{8}u^2$ 与 $B_2 = \frac{3a^2k^2}{16}$。

## 三、解读

其一，**常数部障碍解除**。第十三轮用"常数形 + $\cos2u$ 形"两个迹扇区基元时，残余的常数部（$\frac{a^2k^2}{4}$）无对应项；本轮加 $u^2$ 形轮廓后（其 $B''$ 恒定），拟合残差比从 $39.6\%$ 降到 $3.70\times10^{-5}$：常数部被消掉，而且系数与解析值吻合到 $0.01\%$。教训与第十二、十三轮同型：基元的**轮廓**与基元的**方向**同等重要，只试常数与单一频率会误判为无解。

其二，**零向三分量装配闭合**。修正系数 $B_2 = \frac{3a^2k^2}{16}$ 与 $B_{u^2} = -\frac{a^2k^2}{8}$ 由解析式给出、由数值拟合确认：TT 波的二阶修正（迹扇区的 $\cos2u$ 部与 $u^2$ 部）在零向三分量上完成组装，等价于罗森型 $R_{uu}$ 的二阶消去。

其三，**残余移到横向分量**。修正后总 $|G|$ 降 $2.7$ 至 $2.8$ 倍，仍按 $a^2$ 标度：修正自身是共形型（迹）扰动，它在横向分量上产生新的响应。装配由此变成分层结构：每一层的修正生成下一层的源。该条登记为下一层（横向/无迹基元，或全分量求解）。

其四，**矢量扇区槽已可用**。$g_{0i}$ 槽的标定通过（平坦零、静态回归），其响应读数登记备用：$N_z$ 两类形状在零向三分量上几乎为零（$10^{-7}$ 与 $10^{-14}$ 级），但在其他分量上有 $O(1)$ 响应——本轮装配未用它，后续轮（含时源项、强场端）需要它。
