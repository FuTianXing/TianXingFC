## 一、任务与消费方式

D-4 是消费式接口轮。C1 线当日已跑过三维环的驻留与脱钉复核（第 233 条），本线不重测同一对象，改为把 C1 的读数与 D 线的参数做口径映射，判定两线能否互相引用。

消费的上游读数三条。其一，C1-3 与 C1-4 的驻留阈值 $K_c = 0.24$ 至 $0.25$（第 233 条复现 $0.25$，壁宽 $l^{*} = 1.924$）。其二，C1-3 的脱钉读数 $\alpha^{*} = 0.15$。其三，C1 的弹性系数 $k = 1$、格点数 $N = 32$、梯度流步长 $\eta = 0.01$。

D 线的参数为 $k_b = 1$、$K = 0.005$、站点 $256$，闭式 $m_{\rm gap} = 2\pi\sqrt K = 0.4443$、$M = 4\sqrt{k_bK}/\pi = 0.0900$。

## 三、读数与含义

**其一，口径同一。** 两线的能量泛函在偏离量参数化（$v = u - n$）下逐点相等（残差 $0$）；C1 的梯度流步长与 D 的阻尼系数由 $\gamma_d = 1/\eta$ 换算后，右端逐点相等（残差 $4.00\times10^{-13}$，有限差分精度）。势形同为 $K(1-\cos 2\pi u)$，弹性归一化同为 $k = k_b = 1$，相位单位同为每格一单位。两线可以互换使用，不需要换算表。

**其二，区间不相交。** C1 的驻留与脱钉读数落在 $K \in [0.24, 0.25]$，D 线的孤子与迁移率读数落在 $K = 0.005$，两段不相交，孤子质量相差 $7.00$ 倍。C1-3 的边界声明早已写明「不验证 $K$ 的体系具体值」，本轮把这个空缺读成结构结论：两线共享同一口径，但在参数空间上分居两段，互相引用前必须先定 $K$。

**其三，$\alpha^{*}$ 的口径。** C1-3 的 $0.15$ 是在 $K = 0.25$、$R = 4$ 的驻留态上施加多模扰动后发生塌缩的幅度阈值，量纲与相位同；势的深度是 $K$ 的函数。两者不同量纲，直接比较会得到无意义的读数。可比的量是扰动能量与钉扎势幅度 $2K$ 之比，一维代理给出 $1.75\times10^{-1}$，属量级读数。

**其四，质量口径的合并规则。** 同一对象（kink 质量）的四个读数（$0.0888$、$0.0898$、$0.0900$、$0.0903$）相对散度 $1.67\%$，属同一刻度。窗口质量 $0.0936$ 与闭式偏离 $4.0\%$，按独立刻度登记，不并入同一组。

**其五，跨区桥梁。** 两线之间的桥是 $K$ 的体系具体值。它属 C1 门控下的未定项：C1 侧给出「$K$ 大于 $0.25$ 才有驻留」，D 侧给出「$K = 0.005$ 时孤子质量与迁移率自洽」，两句话都对，指向的是不同的物理情形。若体系最终定在刚性区，D 线的孤子读数需整体重标（质量乘 $7$）；若定在软区，C1 的三维环形态在该段不驻留。

## 四、严格程度与边界声明

| 结论 | 严格程度 |
| --- | --- |
| 两线口径同一（势形、弹性归一、相位单位、过阻尼换算） | 模型内严格（残差 $10^{-13}$） |
| 缺口关系 $m_{\rm gap} = 2\pi\sqrt K$ 在两线泛函上一致 | 解析加数值（$10^{-15}$） |
| 参数区间不相交与质量倍数 $7.00$ | 读数（由两线已定参数直接给出） |
| $\alpha^{*}$ 与势幅度的量级比 $1.75\times10^{-1}$ | 量级（1D 代理，非三维实测） |
| 跨区桥梁为 $K$ 的体系具体值 | 未定项（C1 门控） |

**本注记验证**：C1 与 D 两线的能量泛函、梯度流与缺口关系属同一口径；两线实际使用参数区间不相交；跨线引用的前置条件。

**本注记不验证**：$K$ 的体系具体值；两线读数中任何一项的重新测量；三维与完全量子化（D-7）；与写入机制的节拍关系（D-5）。
