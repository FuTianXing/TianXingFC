## 一、模型与判据

模型为最小解析族，全部量都是经典联合分布的函数：$a_1, a_2$ 均匀，$\alpha = a_1 \oplus a_2$，$b$ 均匀，盒关联 $P(A \oplus o = \alpha b) = (1 + \varepsilon)/2$，消息 $x = a_1 \oplus A$（1 比特），Bob 按查询 $k$ 取 $b = k - 1$、猜 $\beta = x \oplus o$。查询 $k = 1$ 对应 $b = 0$（要 $a_1$），$k = 2$ 对应 $b = 1$（要 $a_2$）。

判据 B0 至 B6 先行。B0 与 369、388 的读数相容；B1 条件化 DPI；B2 非条件化 DPI；B3 链的合成（$B$ 取测量后经典系统）；B4 容量侧三陈述对 $\varepsilon$ 的约束力；B5 C1 与 C3 的模型内核对；B6 判定。

## 三、四条解读

其一，与 369、388 的相容是解析的。本模型给出闭式：RAC $= (1 + \varepsilon)/2$，$J_{\text{sym}}(\varepsilon) = 2[1 - h((1+\varepsilon)/2)]$，类内最大 $J_{\max} = \max(1, J_{\text{sym}})$（只发 $a_1$ 的古典协议给 $J = 1$）。

模型边处 $J_{\max} = 1.000000$ 与 369 逐位一致；$J_{\text{sym}}$ 过 1 的交叉点 $0.779944$ 落在 369 实测区间 $(0.77, 0.78)$ 内，与 388 的单副本阈值 $0.779944271$ 逐位同数。

其二，C2 的第一口径成立且紧，但它不给上界。条件化 DPI $I(a_k : \beta \vert b = k) \le I(a_k : x, o \vert b = k)$ 在模型边处取等号，读数 $0.399124$。该式只界住单次查询的条件量，形式上不含记录预算 $m$，故不能推出 $\sum_k \le m$。

其三，C2 的第二口径与链的合成都失效。非条件化 DPI 在任意 $\varepsilon > 0$ 处失效（模型边处比值 $4.331350$，随 $\varepsilon$ 变化，并不恒定）；文献链的合成步骤 $\sum_k I(a_k : \beta \vert b = k) \le I(\vec a : x, o, b)$ 在 $\varepsilon > 0$ 处以恒定因子 $2$ 失效。两者合起来说明：在"$B$ 取测量后经典系统"这一口径下，激活项上界推不出来。

其四，容量侧三陈述与 $\varepsilon$ 无关。记录容量、设置免费、单侧不可写在每一档 $\varepsilon$ 上同样成立（构造性：每协议一次记录、设置不入记录、单侧边际同为 $0.5$），而 $J_{\text{sym}}$ 在同一读数下从 $0.377$ 变到 $2.000$。故三陈述给不出 $\varepsilon$ 的上界，激活项的界不在容量侧。

## 四、严格程度与边界

模型为最小解析族（32 状态枚举），RAC 与 $J$ 的闭式为引用级（文献式 (22) 的 $N = 1$ 情形），全部互信息读数与两条失效判定为判据级。**不验证什么**：不重做 368、369、388 的读数；$B$ 只取"测量后经典系统"一种口径（把设置或非经典相关性结构并入 $B$ 的读法未做）；不主张文献链对错，只报本口径下的读数；不触碰 [[子理论索引]] 与任何基准文档。
