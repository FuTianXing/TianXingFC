## 一、问题

并行会话惯性-响应合并实验测得响应质量 m_resp = 0.264（永续阻尼 γ_d = 0.2 迁移率法，μ ≈ 18.9），本工作窗口协议测得平移质量 m_eff ≈ 0.099（K=0.005）。两者差 2.7 倍，需验证线性关系并分解差异。

## 二、差异来源分解

1. **主因：并行合并实验脚本未修正 2π 因子**。`minimal_verification_inertia_geodesic.py` 第 27 行 `w2 = (2π)²K`（应为 `2πK`），力场放大 2π 倍、能量不守恒，其 m_resp = 0.264、μ ≈ 18.9、比值 1.29 全部在错误力场下测得。已修正
2. **参数不一致**：并行脚本 K = 0.005、N = 600；其注记"真空阈值 2πK = 0.126"对应 K = 0.02，注记与脚本参数不一致
3. **协议差异**：窗口协议（无阻尼 boost）vs 阻尼迁移率协议，经统一采样后差异消失

## 三、修正后的质量对齐（K = 0.005，同一 kink）

| 质量定义 | 数值 | 协议 |
|---|---|---|
| M_shape（形状范数 Σ(du/dn)²） | 0.0888 | 理论预言（刚体平移） |
| M_zero（平移零模 Σφ'²） | 0.0888 | 理论预言（动能系数） |
| m_resp（阻尼迁移率 f/(γ_d·v_term)） | 0.0940 | 阻尼协议，γ_d = 0.2，f = 0.005 |
| m_eff（窗口协议） | 0.099-0.108 | 无阻尼 boost，低速 |

比值：m_resp/m_shape = 1.058，m_eff/m_shape ≈ 1.1-1.2，全部 O(1) 一致。**2.7 倍差异分解为 2π bug 主导（0.264 → 0.094），参数与协议差异次要。**

残余偏差（比值 0.86-0.95）：γ_d 阻尼的有效系数与理论 μ = 1/(γ_d·S_tot) = 5 的细节差异（实测 μ ≈ 25），不影响线性确认与 O(1) 闭合，机制待后续分解。

## 五、结论

1. 测地响应线性关系验证清楚：小 f 区 v_term ∝ f 严格线性、方向正确、速度上限保持
2. 质量对齐闭合：m_resp ≈ M_shape ≈ m_eff（比值 1.06-1.2），等效原理模型级 O(1) 闭环成立
3. 并行合并实验注记的数值（m_resp = 0.264、比值 1.29、μ 18.9）需按修正后更新（m_resp = 0.094、比值 1.06）
4. 运动机制闭环达成：惯性（m_eff 定量 + 相对论性色散）+ 锚定（弱形式）+ 测地响应线性 + 速度上限，四判据全部闭合
