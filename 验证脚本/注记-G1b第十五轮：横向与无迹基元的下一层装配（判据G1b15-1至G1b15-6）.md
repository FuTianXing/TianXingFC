## 一、问题与口径

第十四轮的登记把下一层定为横向与无迹基元：迹修正自身是共形型（对角）扰动，它在横向分量上产生新响应，总 $|G|$ 仍按 $a^2$ 标度。本轮先把 $u$ 依赖修正（只依赖 $u = t - z$ 的扰动，含对角槽 $p_x, p_y, p_z$、标量槽 $F$ 进 $h_{00}$、矢量槽 $N_i$ 进 $g_{0i}$）的线性响应分类立出来，再做全分量装配。

以 $\bar h = h - \frac{1}{2}\eta\,h$ 作迹反转、$k$ 记 $u$ 的梯度、$T_\mu = k^\rho \bar h''_{\mu\rho}$，$u$ 依赖修正的线性响应为

$$G_{\mu\nu} = \frac{1}{2}(k_\mu T_\nu + k_\nu T_\mu) - \frac{1}{2}\eta_{\mu\nu}\,(k \cdot T).$$

由此得三块结构：null3 块 $G_{tt} = G_{zz} = -G_{tz} = -\frac{(p_x + p_y)''}{2}$；横向块 $G_{xx} = G_{yy} = -\frac{p_z''}{2} - \frac{F''}{2} - N_z''$；混合块 $G_{xt} = -G_{xz} = -\frac{(N_x + C_{xz})''}{2}$。无迹型（$P_+$、$P_\times$）的响应恒为零。

三条解析预期。其一，罗森条件 $\gamma_1''/\gamma_1 + \gamma_2''/\gamma_2 = 0$ 给 $(p + q)'' = 2A''A + A'^2$（$A = a\cos u$），对称分裂 $p = q = B$ 给 $B = \frac{3a^2}{16}\cos 2u - \frac{a^2}{8}u^2$，即第十四轮的拟合值。

其二，第十四轮修正等于罗森形加 $\Delta = \mathrm{diag}(0,0,B)$，$\Delta$ 的响应只剩横向块：$G_{xx} = G_{yy} = -\frac{B''}{2} = \frac{3a^2}{8}\cos 2u + \frac{a^2}{8}$。

其三，补偿条件 $N_z'' = -\frac{B''}{2}$ 给 $N_z = -\frac{3a^2}{32}\cos 2u + \frac{a^2}{16}u^2$；

对称分裂下 $\gamma''/\gamma$ 展开中不含 $B$ 的三阶项（来自 $\varepsilon^2$ 组与 $\varepsilon'^2\varepsilon$ 组）因 $\varepsilon_1 = A + p$、$\varepsilon_2 = -A + q$ 的反对称配对成对相消，首个含 $B$ 的非零阶是 $a^4$，故装配与罗森形的领先残差期望落 $a^4$。

## 三、解读

其一，**响应分类是结构判定**。三块加一条零定理：null3 块只由横向两轴迹 $(p_x + p_y)$ 生成；横向块由 $p_z$、$F$、$N_z$ 三来源按同一条通道承担（系数 $\frac{1}{2}$、$\frac{1}{2}$、$1$ 倍）；混合块只由 $N_x$（或其 $xz$ 对偶）生成；无迹型恒零。

含义有两条：TT 型修正进不了二阶装配（其效应从 $a^3$ 起，本轮读数 $\le 1.4\times10^{-6}$ 即该阶残余），"加 $P_+$ 型修正"在本层无效；横向块的实现槽有三种（迹槽的 $z$ 分量、标量槽、矢量槽），$a^2$ 阶在响应层等价，$a^3$ 起分流。

其二，**第十四轮残余有闭式来源**。第十四轮修正等于罗森形（迹支撑在横向两轴）加 $\Delta$（仅 $z$ 轴迹扰动），$\Delta$ 的线性响应恰为横向块上的 $-\frac{B''}{2}$：这一支与逐点读数吻合到 $1.7\%$，两形状拟合的 $c_0$、$c_2$ 偏差 $1.2\%$ 与 $0.09\%$。

残余的来源唯一，就是修正的 $z$ 轴分量本身。三点的其余分量 $\le 7.4\times10^{-9}$、$G_{yy} - G_{xx} \sim 7.5\times10^{-7}$（拟合残差比 $1.0\times10^{-2}$ 的来源）：它们属 $a^3$ 及以上的成分，登记为下一层之外的高阶项。

其三，**装配闭口落 $a^4$**。迹三轴加矢量槽把 $a^2$ 级残留全消：$|G|$ 从 $1.545\times10^{-4}$ 降到 $3.874\times10^{-10}$（约 $4\times10^5$ 倍），比值 $15.96$、倍率复核 $16.03$、$u = 1.2$ 复核 $16.18$，按 $a^4$ 标度；罗森形（迹支撑在横向两轴）同量级（$3.493\times10^{-10}$、$15.99$）。

$a^3$ 一层不出现有解析根据：对称分裂下 $\gamma''/\gamma$ 的展开里，不含 $B$ 的三阶项在 $\varepsilon_1 = A + p$、$\varepsilon_2 = -A + q$ 的反对称配对上相消，首个含 $B$ 的阶是 $a^4$。含义：TT 扇区的完成形式等于罗森完成（或等价的三轴迹加矢量槽实现），二阶层面的精确解已经到手。

其四，**系数精度决定装配精度**。$B_2$ 与 $N_{z,2}$ 的拟合偏差在 $10^{-4}$ 相对量级以下，$B_{u^2}$ 与 $N_{z,u^2}$（$u^2$ 轮廓）偏差 $2.5\times10^{-3}$ 与 $2.7\times10^{-3}$，来源是数据里的 $a^3$ 成分（不在 $\{\cos 2u, u^2\}$ 张成内）。

用解析系数时残留 $3.874\times10^{-10}$（按 $a^4$ 标度），用拟合系数时 $1.258\times10^{-7}$（按 $a^2$ 标度），差约三百倍。含义：二阶层面的解析系数是当前的精确解；拟合系数的精度上限由数据的高阶成分设定。
