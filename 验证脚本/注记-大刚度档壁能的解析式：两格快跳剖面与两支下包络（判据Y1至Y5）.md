## 一、两格快跳剖面与它的极小

大刚度档的最优剖面不是一格锐壁，而是「近整数平台加一次快速跳变」：跳变跨两条棱，中间两个站点的取值贴着整数，记偏离量为 $\varepsilon$，

$$\dots,\ 0,\ 0,\ \varepsilon,\ 1-\varepsilon,\ 1,\ 1,\ \dots$$

单位长度能量（除以列数 $N_y$）为三条棱的梯度项加两个中间站点的势项：

$$E(\varepsilon) = \frac12\bigl[\varepsilon^2 + (1-2\varepsilon)^2 + \varepsilon^2\bigr] + 2K\bigl(1-\cos 2\pi\varepsilon\bigr)。$$

势项在小 $\varepsilon$ 下展开为 $4\pi^2K\varepsilon^2$，于是

$$E(\varepsilon) \approx \frac12\bigl(1 - 4\varepsilon + 6\varepsilon^2\bigr) + 4\pi^2K\,\varepsilon^2。$$

对 $\varepsilon$ 求极小给出

$$\varepsilon^{*} = \frac{1}{3 + 4\pi^2K},\qquad \boxed{\ \sigma_{\rm disc}(K) = \frac12 - \frac{1}{3 + 4\pi^2K}\ }$$

代入时用了 $(3+4\pi^2K)/\varepsilon^{*} = 1$ 这一恒等，故闭式极简。大 $K$ 的渐近式为

$$\sigma_{\rm disc}(K) \to \frac12 - \frac{1}{4\pi^2K} + O(K^{-2})，$$

即二分之一是 $K \to \infty$ 的极限，从下方趋近。

## 三、适用范围与两处限定

其一，**适用分档**：$K \le 0.02$ 用连续式 $\frac4\pi\sqrt K$；$K \ge 0.15$ 用两格闭式 $\frac12 - \frac{1}{3+4\pi^2K}$；中间档（本轮的 $K = 0.10$）两者都不达，实测比下包络低 $3.07\%$，说明真最优要跨更多格，两格假设在那里失效。C1 线的驻留窗口 $K \ge 0.24$ 全部落在闭式区，偏差不超过 $0.5\%$。

其二，**交叉点在 $(0.05,\ 0.10)$ 之间**。这里如实登记一件事：我脚本里找交叉点的二分法方向写反了，输出 $0.12$，那个数不可用；可用的只是两侧的夹逼（$K = 0.05$ 时连续式更小，$K = 0.10$ 时闭式更小）。要精确交叉点需重跑一次二分，登记为待办。

其三，**闭式的量纲与极限自洽**：$K \to 0$ 时它给 $\frac12 - \frac13 = \frac16$，远高于连续式，故小刚度档由连续式接管；$K \to \infty$ 时它给 $\frac12 - \frac{1}{4\pi^2K}$，趋近二分之一，与第 336 条「一格锐壁是极限上限」的判断一致。

## 四、对 C1 线的直接用途

C1 窗口 $K \ge 0.24$ 的壁张力改用它自己档位的闭式：

$$\sigma_{\rm disc}(0.24) = 0.419839,\qquad \sigma_{\rm disc}(0.30) = 0.432631，$$

与实测 $0.417864$ 与 $0.431444$ 相差 $0.5\%$ 以内；而连续式在同一档给 $0.623757$ 与 $0.697382$，偏高约三成到四成。故凡在 C1 档做量级估计，用闭式即可，无需重跑数值。

## 五、过程记录

其一，闭式的极简形式是我在代入时发现 $\varepsilon^{*} = 1/(3+4\pi^2K)$ 与势项系数之间存在恒等而得到的：先算出 $E(\varepsilon^{*}) = \frac12 - \frac{2}{3+4\pi^2K} + \frac{3+4\pi^2K}{(3+4\pi^2K)^2}$，后两项合并即 $\frac{1}{3+4\pi^2K}$。若无这一步，容易停在一个带 $\varepsilon^{*}$ 的式子而看不出它与二分之一的关系。
