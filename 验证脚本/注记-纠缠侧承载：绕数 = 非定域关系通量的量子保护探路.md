## 一、背景与判据

绕数承载层问题（电荷 = 绕数应写在结构的哪一层）经《注记-环的裁决实验》定案：光滑场位形无亚稳、翻页、$\oint d\varphi \equiv 0$、$\pi_2(U(1)) = 0$ 四面否定位形侧承载。随后的疤探路（相位量子化、提升锁定两模型）给出两个补充否定：状态图全连通（路径存在，构造性保护不成立）、解缠障碍 $2\kappa_\varphi(1-\cos 2\pi/N)$ 与离散化 N 无关且依赖 $\kappa_\varphi$ 大，而体系内轻粒子恰为 $\kappa_\varphi$ 小（电子轻 = 锁定弱），弱保护路径关闭。

本探路的转向依据：体系注释 09 裁决"方向归波"（纠缠网络提供方向与关系结构），绕数作为方向/关系结构的整数圈按此定案应归波性侧。波性侧 = 元相子先验纠缠（冯·诺依曼无穷张量积），非定域。数值实现采用 toric code 风格最小模型：键变量为关系自由度（无相位差积分约束，通量可非平凡），绕数 = 大环通量算符本征值，哈密顿量局域（星项 = 格点内锁定对应 $\kappa_\varphi$，环项 = 格点间关系对应 $\kappa_\parallel$）。

判据：C1 局域扰动票价（经典层）；Q1 基态空间绕数投影量子数；Q2 基态简并 = $2^{2g}$（环面）与能隙；Q3 跨扇区一阶矩阵元与扰动下绕数保持。

## 四、结论

1. **绕数承载归波性侧**。非定域关系通量（大环算符）在量子动力学下受基态空间结构保护：绕数为基态空间投影量子数（可对角化），跨扇区一阶矩阵元为零（Q3）。这与"方向归波"定案（注释 09）一致，位形侧三模型失败的原因获得统一解释：绕数是非定域量子数，在局域位形里没有家。
2. **保护机制质变**：位形侧保护 = 能量票价（0.19 至 4.0，可翻越）；纠缠侧保护 = 基态空间投影量子数 + 跨扇区零矩阵元（全空间对易是 Z_2 特例）。轻粒子困局（$\kappa_\varphi$ 小则票价低）消失：对易保护与耦合强度无关。
3. **三块定案结构性归位**：质量 = 绑定能归粒（格点内锁定）、电荷 = 绕数归波（纠缠通量）、运动 = 转换波为两侧耦合。这是"波主粒从"（整体层面波主导）的体现：最守恒的量由波性侧承载。
4. **经典化丢失保护**：经典层（cos 软模型）通量线仍衰变，保护依赖量子相干（对易结构只在量子动力学中存在）。体系波性侧（先验纠缠、量子态空间）恰好提供此条件。
5. **与超选择论文的互补**：并行线《绕数超选择》从态空间扇区结构论证绕数是超选择荷（弦算符非局域性，局域生成元闭包不含跨扇区算符）。本探路的基态空间投影量子数是超选择的哈密顿量级数值形态（Z_2 全空间对易为 $N=2$ 特例；Z_N 暴露全空间 $[H, W] \ne 0$ 但基态空间内可对角化、扇区不相通），跨扇区矩阵元为零是禁戒的数值签名；弦算符论证为本探路结果提供算符代数基础。两线结论合一：电荷守恒的保护层 = 非定域结构，本探路给出其数值形态，超选择论文给出其算符代数论证。

## 八、2026-09-16 更正（Q4 轮）：Z_N 下 W 的「保持基态空间」读数

本注记 §七「超选择表述的精确化」写道：$Z_N$（$N > 2$）下 $[H, W] \ne 0$（全空间，激发部分），但 W 保持基态空间、基态空间内可对角化。Q4 轮（`验证脚本/minimal_verification_winding_leakage.py`，见 [[注记-量子层Q4：绕数跨扇区泄漏的最小阶数与尺寸标度]]）复验后更正如下。

$Z_3$（$L = 2$）下，探路口径的 $Z$ 型大环 $W = \Pi Z$ 的基态空间外分量为 $1.00$（$O(1)$），最简单的 X 型大环也是 $1.00$：两者都不与 $H$ 对易，W 并不保持基态空间。原因是模 $N$ 相位障碍：$Z$ 型在每个星项（无向四键）上得 $\omega^{-2}$，$X$ 型在每个定向环项上得 $\omega^{\mp 1}$；$N = 2$ 时两者都退化为 $\pm 1$，掩盖了障碍。
