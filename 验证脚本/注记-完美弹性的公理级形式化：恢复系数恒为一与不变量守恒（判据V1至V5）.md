## 一、公理层输入

- **A1 相位推进速率恒定**：$|\dot\theta_n| = \omega_P$（公理 5 的绝对值约定）。
- **A2 刚性锁定**：$z_n = \dfrac{l_P}{2\pi}\theta_n + z_n^0$（法线坐标与相位锁定）。
- **A3 圆心不可重合**：粒性互斥；圆心相遇即反向（补充注释03 第 3 至 5 点）。

## 二、定理与证明

**定理（公理级）**。设元相子满足 A1 至 A3，则：

1. 每支护的速度幅度恒为 $c$：由 A1 与 A2 得 $\dot z_n = \dfrac{l_P}{2\pi}\sigma_n\omega_P = \sigma_n c$（代数恒等，任意时刻成立）。
2. 碰撞的恢复系数恒为 1：碰撞前后两块的速度幅度都由 A1 固定为 $c$，故
$$e = \frac{|v_{\text{分离}}|}{|v_{\text{接近}}|} = \frac{c-(-c)}{c-(-c)} = 1,$$
   与运动学细节无关。**这是 A1 的推论，不需要"完美弹性"作为额外假设。**
3. 不变量：总动量 $P = \sum_n m\dot z_n$、逐支能量 $E_n = \hbar\omega_P$、摆程方向和 $S_\sigma = \sum_n\sigma_n$ 皆守恒（碰撞只做 $\sigma_i \leftrightarrow \sigma_j$，三者均不变）。
4. 位置多重集按自由运动演化：设自由轨迹 $\tilde z_n(t) = z_n(0) + \dot z_n(0)t$。碰撞之外多重集线性演化；碰撞是标签置换，而多重集对置换不敏感。由对碰撞次数的归纳得 $\{z_n(t)\} = \{\tilde z_n(t)\}$ 对所有 $t$ 成立。

**推论**：两体碰撞无耗散通道（$\gamma_{\text{碰撞}} = 0$）。

**充分性**（这是与模型内版本的关键差别）：证明只用到 A1 至 A3，未引入等速硬点链这一具体模型的任何额外结构；该模型因此从"定理的证明装置"降为"定理的独立核对装置"。
