## 一、问题与判据（先行）

第 292 条给出受激项的截面乘法（$\dot N = Av$），第 295 条给出分辨率侧的稀释律（注册率对 $\min(1,\tau/\Delta t_s)$）。两条合起来之后，剩下的问题是**本底与受激是否共用同一个时钟**。记录机制线的本底口径是每站点每周期一笔，周期取 $t_P = 1$；受激项的窗口是壁扫过一站的时间 $\tau_{\rm wall} = w/v$。两个窗口长度差 $158$ 倍，故即使共用全局时钟，稀释因子也不相同。

模型是事件级登记模型。输入取已测参数：壁速 $v = 0.1000$、有效穿越长度 $w = 15.8$（第 292、295 条），故 $\tau_{\rm wall} = 158.0$；本底窗口 $\tau_{\rm bg} = t_P = 1$。场取 $32\times8\times8 = 2048$ 站、截面 $64$、总时长 $320$，故本底 $653312$ 笔、受激 $1920$ 笔。注册规则按命题 17：全局时钟刻度落在事件窗口内则登记。

判据分四组：窗口读数（V1）、逐类稀释律（V2、V2s）、比值曲线与三段结构（V3、V3m、V3p）、本底在稀释下的结构性（V4）。

## 三、结论：三段结构

判别取样间隔与两个窗口的关系，比值 $R$ 呈三段。

低端（$\Delta t \le \tau_{\rm bg} = t_P$）：两类都全额登记，比值就是基准 $R_0$（实测 $0.0029$）。

中段（$t_P < \Delta t < \tau_{\rm wall}$）：本底按 $t_P/\Delta t$ 稀释而受激仍全额，比值按 $\Delta t/t_P$ 线性放大（$\Delta t = 50$ 给 $49.91$ 倍，解析 $50$）。

高端（$\Delta t \ge \tau_{\rm wall}$）：两类都稀释，比值回到平台，平台高度是基准的 $\tau_{\rm wall}/t_P$ 倍（$\Delta t = 500$ 给 $157.4$ 倍，解析 $158$）。

一句话：**稀疏取样系统性放大受激项相对本底的比重，放大倍数等于受激窗口对本底周期之比 $w/(v\,t_P)$。** 这不是第二个自由参数，它由第 292、295 条已测的 $w$ 与 $v$ 决定。把它作为可判读数的形式是：测量受激与本底的计数比随取样间隔的曲线，读出中段的斜率与高端的平台，两者分别给出 $1/t_P$ 与 $w/v$。

## 四、本底结构在稀释下不破

V4 给出的读数是：被稀释后登记下来的本底时刻仍全部落在 $t_P$ 的整数倍上（残差 $0.0\times10^{0}$），而同样笔数的泊松对照的残差是 $0.500$。故稀释只丢整拍，不改变格点结构。这与实验可检验预言清单里「本底时间结构为周期而非泊松」一条同向：稀疏取样会把这条预言的可测性变差（丢拍），但不会把它变成泊松。

## 五、与既有读数的接口

第 292 条与第 295 条分别给出截面乘法与分辨稀释，本条把两者接到记录机制线的本底与受激项上，得到的接口形式是

\[\dot N_{\rm 总} = N_{\rm site}\frac{1}{t_P}\,g_{\rm bg} + A\,v\,g_{\rm 激},\qquad g_{\rm bg} = \min\!\left(1,\frac{t_P}{\Delta t}\right),\ g_{\rm 激} = \min\!\left(1,\frac{w}{v\,\Delta t}\right)。\]

两个稀释因子只有在 $\Delta t \le t_P$ 时相等，此时总计数退化为 $N_{\rm site}/t_P + Av$；取样变粗之后两者分离，可分别测出。
