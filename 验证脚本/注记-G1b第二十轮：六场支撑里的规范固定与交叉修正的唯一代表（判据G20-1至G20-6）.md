## 一、问题与口径

第十九轮定出交叉修正的最小支撑（六场乘四个 $(u,v)$ 轮廓 = 24 列）与八维规范核，但共线基下的最小范数解幅度虚高。本轮把规范固定写成可计算的构造：显式给出八维规范子空间在 24 列系数上的基矢（槽 0 族与 $(\xi_x, \xi_z)$ 约束族），在规范正交补里求最小幅度解（$\min \vert c\vert$，$M c = b$，$c \perp$ 规范），并就阈值稳定性与截断谱做对照。

规范基矢的解析形式。槽 0 族（$\xi_0 = f$）：$C_{00} = 2(f_u + f_v)$、$C_{0x} = -f_v$、$C_{0z} = -f_u$，其余为零。$(\xi_x, \xi_z)$ 族：约束 $(\xi_z)_v = -(\xi_x)_u$ 使 $C_{xz} = 0$，给出四参数族；分量 $C_{0x} = (\xi_x)_u + (\xi_x)_v$、$C_{0z} = (\xi_z)_u + (\xi_z)_v$、$C_{xx} = -2(\xi_x)_v$、$C_{zz} = -2(\xi_z)_u$。两族共八维，与 $24 - 16 = 8$ 一致。

## 三、解读

其一，**规范固定成功，幅度回到物理量级**。唯一代表的最小幅度 $2.376\times10^{-4}$（$ab$ 的 $2.4$ 倍），最大单系数 $1.25\times10^{-4}$：第十九轮里 $10^{-2}$ 级的虚高幅度是共线基下最小范数解的伪影，规范正交补固定后消失。秩 $16$ 与 $24 - 8$ 的计数一致，闭合仍在地板（$0.71\%$／$0.62\%$）。

其二，**结构由两个轮廓主导，波交换对称自动成立**。$\cos u\cos v$ 与 $\sin u\sin v$ 之外的乘积（$\cos u\sin v$、$\sin u\cos v$）系数 $\le 5\times10^{-7}$（$0.4\%$）；$H_{xx} \approx H_{zz}$（$-12.503$ 对 $-12.482$）与 $N_x \approx N_z$ 是构型在 $x \leftrightarrow z$、$u \leftrightarrow v$ 交换下的对称性，唯一代表自动满足。

其三，**系数的读出与规范口径**。六场系数随规范选择变动（$F$、$N_x$、$N_z$ 受槽 0 族影响，$H_{xx}$、$H_{zz}$ 受约束族影响），不变的是支撑（两轮廓主导）与对称性。按 $ab = 10^{-4}$ 归一，代表里最醒目的一支是 $H_{yy} \approx -(\cos u\cos v - \sin u\sin v) = -\cos(u+v)$（系数 $-1.00$），$H_{xx} = H_{zz} \approx -1.25\sin u\sin v$。

其四，**闭式规则的路标**。$\cos(u+v)$ 与 $\sin u\sin v$ 都是两个波的乘积结构（$\cos u\cos v$ 与 $\sin u\sin v$ 是 $A \cdot B$ 与 $A'B'$ 型），提示交叉修正的闭式形式应由两束单波的完成剖面相乘给出；系数 $1.00$ 与 $1.25$ 是待识别的纯数。登记为下一项。
