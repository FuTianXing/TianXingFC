## 二、模型设定

耦合结构途径用识别式的各向同性形式 $h_{00} = 2\theta$、$h_{ij} = 2\theta\delta_{ij}$，代入作用量中的线性耦合项 $(1/2)h_{\mu\nu}T^{\mu\nu}$。

场方程途径在调和规范下进行，取 $\Box\bar h_{\mu\nu} = -(16\pi G/c^4)T_{\mu\nu}$。静态源取 $\rho$ 为高斯分布、$p = w\rho c^2$ 的正压流体，在傅里叶空间用解析变换 $1/|\mathbf x| \leftrightarrow 4\pi/k^2$ 联立两个方程，得到 $h_{00}$ 并与"源为 $\rho + 3p/c^2$"的形式逐点比较。取单位 $G = c = 1$。

## 三、结果

**L1b-1 给出耦合结构。** $(1/2)h_{\mu\nu}T^{\mu\nu}$ 在识别式的各向同性形式下等于 $\theta(T^{00} + T^i_i)$，两个通道共用同一个 $\theta$，没有相对系数。这说明空间应力的贡献以迹的形式与密度同权重进入记录场。

**L1b-2 给出一致性。** 由 $\bar h_{00} = 16\pi\rho/k^2$ 与 $\bar h_{ii} = 3\cdot16\pi p/k^2$ 联立（$h = \bar h_{00} - \bar h_{ii}$，$h_{00} = \bar h_{00} - h/2$），得到

$$h_{00} = \frac{8\pi}{k^2}\Big(\rho + \frac{3p}{c^2}\Big),$$

与"$\theta$ 的源为 $\rho + 3p/c^2$"的形式逐点相同（相对偏差到机器精度）。两条独立途径（耦合结构与场方程）指向同一个组合，这条判定因此不依赖单一路径。

**L1b-3 给出阶数定位。** 压强项相对密度项的量级是 $3p/(\rho c^2)$。对太阳中心约 $5\times10^{-6}$，属次阶修正；对中子星中心约 $0.9$，对相对论气体（$p = \rho c^2/3$）为 $1.0$。也就是说：弱场弥散源上这一项可以忽略，致密源与辐射源上它举足轻重。

**L1b-4 给出对写规则的后果。** 气体情形下所需组合的 $O(v^2)$ 系数是 $3/2$（每粒子的 $\gamma m(1+v^2) = m(1+3v^2/2)$）。静质量写给 $0$，纲领项的 $\gamma m$ 给 $1/2$。两者都欠，欠的就是应力迹那一部分。

## 四、物理读数

**口径判定。** $\theta$ 的源是 $T_{00} + T_{ii}$（在源的静止系里即 $\rho + 3p/c^2$）。此前登记为"泊松型源与加速度型源之分"的疑问，在此有了确定答案：就静态源而言，泊松型方程的源本身就是两者之和，而 $\rho + 3p$ 在加速度型方程（Raychaudhuri）里出现在首阶、在泊松型方程里出现在次阶。同一组合，两个方程中的阶数不同。

**对现行链的定位。** 本框架此前的链（源为 $\rho$）在首阶正确：它与史瓦西对齐、钟慢、偏折等检验的阶数一致，那些检验都在首阶。压强项属次阶，未被此前任何检验触及，也未被任何检验排除。

**对写规则的后果。** 次阶上写幅度须给出 $\rho + 3p$ 这一组合。这条要求与 G2-L1 登记的"源侧一致性要求"是同一件事，本轮把它从"应含动能"细化为一个具体的组合与系数。机制层仍未给：本框架的写入是按缺陷计数的，缺陷内部运动如何进入写幅度没有微观出处。

**不引入新常数。** 口径判定本身是标准物理的代数事实，与本框架的识别式联立后不产生任何新的量纲常数。G2-L1b 的通过条件（与标准物理的对应口径逐条对齐、不引入新常数）两条都满足。

## 五、严格程度声明

**验证了什么**：L1b-1 与 L1b-2 为代数恒等式（耦合结构与调和规范联立），在机器精度内成立；L1b-3 与 L1b-4 为纯数比较与量级估算。

**未验证什么**：其一，调和规范与体系所用的各向同性坐标约定之间的换算未逐步展开（两者在弱场首阶下给出同一个 $h_{00}$，本轮不重做规范变换的细节）。其二，含源的非静态情形的口径未处理（本轮取静态源）。其三，写规则如何在机制层给出 $\rho + 3p$ 未给，属开放项。

**边界**：本轮是口径判定，不是机制推导；它把"源该是什么"说定，把"写规则为什么能给出它"留给机制层。
