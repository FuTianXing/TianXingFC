## 一、问题与口径

第六轮把源因子的机制来源写成测度原理 $\theta = \theta_{\mathrm{bare}}/s(\theta)$，留下一条子项：把"写入的位移为绝对量、记录按当地尺读数"从事件结构给出。本轮把它拆成两条，各自落在已注册的层级上。

**条款一（位移绝对性）**：写入的位移与相位、绕数无关，每事件恰一个 $l_P$。这是法向跃迁注记的既有结论：判据 M4 给绕数 $w = 0, 1, 2$ 下每周期净轴向位移均为 $1.000000\,l_P$（本轮的复跑确认读数一致）；判据 M5 给折返为唯一可行处置。该条的层级是结构论证级加代价清单（替代方案需新增相位指标场、整数绕数与未定摆幅），本轮直接引用，不新增假设。

**条款二（读数的尺）**：记录 $\theta$ 是倾角，只能是"法向上升除以横向长度"的比值。横向长度在框架里有四种自然取法：坐标格距 $l_P$、时间因子 $\sqrt{-g_{00}}$、四维体积因子 $\sqrt{-g}$、空间扇区长度因子 $\sqrt{g_{ii}}$。四种尺各自解出不动点，算到曲率读数上做判别。

口径沿用三至六轮：规则 $G = F + \frac78F^2$（$F = 2\theta$）、曲率分解式 $G_{00} = -2\nabla^2\theta + 5\theta\nabla^2\theta - 4(\nabla\theta)^2$、拟合约定 $R = -8\pi\rho_m\kappa\theta + c\cdot4\pi(\nabla\theta)^2$。实测为 $\kappa = 4.5$ 且 $c = 0$（三轮，四档质量外推）。

## 三、解读

其一，**两条条款的性质不同**。条款一谈"写多少"：写入的位移是绝对量，与相位、绕数无关，这条已经在法向跃迁注记里核到结构论证级并列出代价。条款二谈"怎么读"：倾角是比值，分母是横向长度，这条在本轮之前是未判的选择。

其二，**四种尺的判别表**。把四种尺各自解不动点、算到曲率读数上，得到 $(\kappa, c)$：坐标尺 $(2.5, -0.318)$、时间尺 $(0.5, -0.637)$、四维体积尺 $(6.5, +0.318)$、空间扇区尺 $(4.5, 0)$（解析预测；数值外推与之相符到 $2\%$ 至 $5\%$）。实测是 $(4.5, 0)$：只有空间扇区尺两个分量同时对上。

其三，**空间尺解的收敛**。用空间尺不动点解逐点核对：$M = 0.05$ 给 $\kappa = 4.313$ 至 $4.372$，$M = 0.02$ 给 $4.425$ 至 $4.448$，梯度残余从 $0.65\%$ 降到 $0.06\%$：随 $M \to 0$ 收敛到 $(4.5, 0)$，与三轮的推一致。

其四，**相容性**。刚性晶格裁定说格距不变、晶格是固定坐标网格，于是"层数"记坐标距离、"倾角"记测量比值，两条并存；地标 $\theta_{\mathrm{bare}}(\theta = 1/2) = 2$ 保持；视界处时间尺到零点、空间尺仍为 $4$（有限），两尺在此分离，与光锥兼容线的内侧翻转读数不冲突。

其五，**层级与代价**。原理 = 条款一 + 条款二：条款一的代价已由法向跃迁注记登记（拒绝相位指标场、绕数、摆幅）；条款二属"四种自然读法里的唯一存活者"，不引入新结构。合起来的结论是：测度原理的代价为零新增，它不再是一条独立假设。
