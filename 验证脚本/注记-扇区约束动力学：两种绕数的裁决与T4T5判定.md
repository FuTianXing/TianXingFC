## 一、背景与判据

论文 T4 预言：每步投影回 $W = 1$ 扇区的约束动力学下，环不达真空而停在扇区极小，极小为离散锚核加有限宽度包层的 dressing 形态，宽度 $\ell^*$ 待测。本实验裁决该预言，过程中确立一个此前未分明的结构事实：相位场的"绕数"有两种，必须分开裁决。

**环面绕数**：$S^1$ 映射 $T^3 \to S^1$ 的逐线度数。记键分支指标 $k = \lfloor u / 2\pi + 1/2 \rfloor$（$u$ 为不取模键相位差），则 $W = -\Sigma_{\text{line}} k$。这是紧致场真正的超选择扇区：无约束动力学要改变它必须有键穿越 $e^{i\pi}$（撕裂事件）。

**局域涡量**：涡旋线/环的 plaquette 缠绕。它不构成扇区：可搬运、可对湮灭、可经边界清零（环的裁决实验 C1-C5、疤的裁决实验已定案）。

关键预备事实：arctan2 包络构造的"环"的绕数属于第二种且是表示性的。包络 $g < 1$ 使截面回路只扫过圆弧，$S^1$ 映射本身拓扑平凡；冻结分支只是冻住多值表示的标记，物理构型可经 $2\pi$ 偶极子隐藏退到真空。

## 二、模型与协议

裸 XY 单分量（周期盒 N = 32，E = $\Sigma(1 - \cos u)$）与三元组体系哈密顿量（$\kappa_\phi$ 格点内 + $\kappa_\parallel$ 格点间，铁磁或交错背景）。扇区投影的经典代理 = **冻结分支（分支夹取协议）**：每步梯度流后把越界键夹回本分支区间 $[2\pi k - \pi,\ 2\pi k + \pi]$（多轮扫描收敛，切向运动保留），事后校验全键距分支边界余量 $\ge 10^{-7}$。代数根据：沿闭合回路 $\Sigma u = 0$（数组周期性），故 $\Sigma_{\text{line}} w = -2\pi \Sigma_{\text{line}} k$；$k$ 逐键冻结则每条线的扭转内容严格守恒、不可消灭、只能重分布。

方法记录：前两轮使用的全局步拒绝协议把切向运动一并冻死（环在 E = 462 硬停滞、交错背景全步被拒），夹取协议为其修正。交错背景观测入档：无约束下整块背景滚向铁磁（$18N^3 \to 0$，动力学不稳定），冻结下近乎刚性（E 变化 1.9%）。交错设定对扇区检验退化，三元组判决性下降改在铁磁背景执行。

## 三、结果

### [A] 无约束基线

初条件 = 环（R0 = 6，$\rho_0$ = 2，E 贡献 479）+ 均匀扭转（$E_{\text{uni}} = N^3(1 - \cos(2\pi/N)) = 629.63$，$W_z = +1$）。环部分自由撕裂（479 → 0，复现 C1）；均匀扭转零温驻留（终态 E = 629.6279 = $E_{\text{uni}}$）：它是梯度流的零力驻点，撕裂需把扭转集中到单键并越过分支势垒（$\sim O(\kappa_\parallel)$），零温确定性流不触发。环面绕数的经典保护是有限势垒，非扇区。

### [B] 冻结分支流（扇区代理）

$W_z = +1$ 严格保持（冻结校验余量 $1.0 \times 10^{-7}$）。终态 E = 921.55 $\ge E_{\text{uni}}$，$r_g$ = 13.55 格距 = 盒尺度离域；流停在分支钉扎的亚稳态（扇区内弛豫路径依赖）。离域与下界一致：均匀扭转内容（每线 $\Sigma w = 2\pi$）的 per-line 极小为均匀分布，纯 $W_z = 1$ 扇区的全局极小即均匀扭转本身，局域化被拓扑禁止。

### [C] 窄区碗判决性下降（铁磁背景，$\kappa_\phi = 0.5$、$\rho_0 = 1.0$）

静态 E(R) 扫描单调（19.9 → 158，R $\in$ [0.8, 2.5]），无内点碗（$R^*$ 落扫描端点 0.8；复跑报告的 $\kappa_\phi = 0.5 / \rho_0 = 1.0$ 碗在其交错背景下测量，而该背景自身动力学不稳定，碗为双重伪影）。判决性下降：无约束从 $R^*$ 出发塌缩到精确真空；冻结分支同样 E → 0。冻结支的终态即**隐藏扭转**：分支标记冻结而 $S^1$ 构型真空化，绕数藏在 $2\pi$ 偶极子里，全部局域观测量（能量、作用密度、尺寸）清零。

## 四、结论（T4/T5 判定）

1. **T4 否定（两支归谬）**：局域 dressing 极小在相位场自由度内不存在。其一，局域涡量的绕数是表示性的，冻结分支只冻住标记，物理构型经 $2\pi$ 偶极子隐藏退到真空（[C] 冻结支 E = 0）；其二，真扇区的极小被拓扑强制离域，$W = 1$ 要求每条线缠绕，per-line 极小为均匀分布，粒子式局域化在扇区内拓扑禁止（[B]）。
2. **T5 消解**：无局域载体可测宽度；色散窗口问题转移到载体自由度。
3. **正面收获：扇区守恒职能的数值确认**。冻结分支下 $W_z$ 严格守恒（构造性）且扭转内容逐线冻结不可消灭，终态保持离域：超选择层的守恒职能在经典代理下按论文第四节的机制运转。扇区极小（均匀扭转）属箱线属性族（贯穿边界条件的整体扭转，与 T3 周期盒线稳定同类），非粒子。
4. **两层分工的动力学证明形态**：扇区（波性侧）守恒全局绕数但不供能量与尺寸；粒子的能量与尺寸必须由场外自由度承担（格点内离散结构 = 质量机制定案）。至此位形侧否定链闭合：光滑场环死（C1-C5）、孤立疤不可构造、扇区极小或离域或隐藏。场自由度内找不到粒子载体，载体判定收敛于格点内离散结构加波性侧保护的组合。

## 五、边界与遗留

其一，N = 32 单一尺寸（离域强制为拓扑论证，不依赖尺寸；分支钉扎亚稳族的分布未扫描）。其二，零温确定性梯度流：均匀扭转的撕裂需越有限势垒，热激活或量子隧穿路径未模拟；这不影响 T4 裁决（扇区内局域化被拓扑禁止，与势垒无关）。其三，冻结分支是超选择的经典代理（撕裂压除的硬约束），非先验纠缠本身；量子层的对易保护由《纠缠侧承载》toric code 数值承担。其四，均匀扭转作为扇区极小的物理解读（箱线属性族）与转换波运动学的缠绕守恒边界（同一族约束）的关系待整理。其五，本实验不改动基准文件；论文 T4/T5 状态已同步更新，未确认前不入理论总纲。
