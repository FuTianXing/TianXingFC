## 一、验证目标与判据

S3 的任务（裁决十三）是在真实场上比较 $\Gamma_c$ 与写入速率。本材料执行其可做部分：机器沿用 D1、D2（原样复现，保证读数同一坐标系），构型换成 S1 的真实场，并扫 $\lambda$ 给出依赖关系，使两个未定输入（$\lambda$ 实际值、$\kappa_\phi$）到位后可直接代入。

判据（先写期望，再算）：

S3a 机器锚点复现：同一构造（周期链 1D $N = 256$；周期立方 3D $L = 16$）下，1D 均匀 $I = 0.246351$（对闭式，偏差 $\le 10^{-5}$）；3D 均匀 $I = 0.144089$（对 D2 读数，偏差 $\le 5\times10^{-3}$）。

S3b 真实场构型：以 S1 写入场剖面为调制形状（弥散档 $M/m_P = 1$、过密档 $100$，$R_s = 8$，1D 等效为中心鼓包加 $1/r$ 尾）：$I_{\text{real}} < I_{\text{uniform(满幅)}}$；报告与「同均值均匀」之比。

S3c $\lambda$ 扫描：$\Gamma_c(\lambda)$ 单调增；拟合 $\beta = \mathrm{d}\ln I/\mathrm{d}\ln\lambda \in [0.2, 1]$。

S3d 终审预备：对写入速率 $\Gamma = 2.74\times10^{-39}$ 每拍（太阳档，S2 材料），$\Gamma_c(1)/\Gamma \ge 10^{30}$；交叉 $\lambda_{\min} = (\Gamma/\Gamma_c(1))^{1/\beta}$ 报出；$\kappa_\phi$ 与非线性在场按裁决十三留出。

报告 R：三维（$L = 16$）真实场构型与形状对照。

## 二、模型与设定

机器原样复用 D2：一维周期交错链（$N = 256$，对角 $2 + (-1)^n h_n$，近邻 $+1$）与三维周期立方（$L = 16$，对角 $6 + (-1)^{i+j+k} h_n$，六近邻 $-1$）；生长率 $\gamma(h) = \sqrt{\max(0, -\mu_{\min}(h))}$；$I = \int_0^1\gamma\,\mathrm{d}h$（61 点梯形）；$\epsilon_0 = 10^{-3}$，$\Gamma_c = I/\ln(1/\epsilon_0)$。

真实场构型取自 S1 可做部分（写入律加容量 $h \le 1$）：一维等效把 S1 的径向剖面嵌为中心鼓包（周期距离小于等于 26 格取剖面值，外侧按 $1/r$ 尾）；三维按球对称剖面嵌进 $L = 16$ 立方。$\lambda$ 作为调制幅度进入对角项（$\lambda = 1$ 即 D2 默认），扫描档取 $0.003$ 至 $1$。写入速率取 S2/S2G 结清的太阳档 $\Gamma = 2.74\times10^{-39}$ 每拍。eigsh 固定初矢（种子 20260918）。

## 三、结果

判据 4/4 全过（运行约 40 秒）。读数如下。

|---|---|---|---|---|---|

要点如下。其一，锚点复现：1D 均匀 $I = 0.246350$（闭式 $0.246351$，偏差 $1.1\times10^{-6}$）、3D 均匀 $I = 0.144088$（D2 读数 $0.144089$，偏差 $4.4\times10^{-7}$）；漏斗 $0.009013$ 对 D2 的 $0.009008$。机器与 D2 在同一坐标系。

其二，真实场构型读数：弥散档 $I = 0.017633$、过密档 $I = 0.222144$，均小于满幅均匀；对同均值均匀的比分别 $2.870$ 与 $3.764$，即集中核构型比同均值均匀更强（漏斗的比为 $0.935$，同量级）。

其三，$\lambda$ 扫描（过密档）：$I$ 由 $0.001336$（$\lambda = 0.003$）单调增到 $0.222144$（$\lambda = 1$）；幂律拟合 $\beta = 0.880$。S2 材料的 $\Gamma_c \propto \sqrt{\lambda}$ 为估算，本材料按实测更新（$\beta = 0.88$ 对过密档；方向性结论不变）。

其四，终审预备：过密档 $\Gamma_c(1) = 3.216\times10^{-2}$ 每拍，对写入速率 $2.74\times10^{-39}$ 的余量 $1.17\times10^{37}$；交叉 $\lambda_{\min} = 7.3\times10^{-43}$（低于此值才翻转）。$\kappa_\phi$ 与非线性在场两项按裁决十三声明未齐。

其五，三维报告（$L = 16$）：均匀 $I = 0.144088$（$\Gamma_c = 2.086\times10^{-2}$）、过密档 $I = 0.127964$（$\Gamma_c = 1.852\times10^{-2}$），两者同量级，即该剖面的三维调制覆盖较广。

## 四、解读

其一，坐标系统一：锚点在同一台机器上原样复现（1D 与 3D 的均匀值与 D2 逐位一致到 $10^{-6}$ 与 $10^{-7}$），故本材料的真实场读数可与 D2 的玩具构型表直接比较。

其二，真实场的谱读数不弱：过密档在 1D 等效下 $I = 0.2221$（对满幅均匀 $0.2464$ 的 $90\%$）、三维 $I = 0.1280$（对均匀 $0.1441$ 的 $89\%$）。含义是真实场构型落在「靠近均匀」的一侧，$\Gamma_c$ 量级 $10^{-2}$ 每拍，不是漏斗型的 $10^{-3}$ 以下。

其三，集中核比同均值均匀更强：比值 $2.87$ 与 $3.76$ 说明「平均调制密度」在同均值口径下低估了集中构型的驱动能力（核区贡献占优）；该读数与 D1 的平均密度结论互补，方向对终审有利（耦合先触发更强）。

其四，$\lambda$ 的依赖实测为 $\beta = 0.88$，交叉 $\lambda_{\min} = 7.3\times10^{-43}$：即使耦合系数比 $J$ 低四十二个数量级，判定方向也不翻转。这把终审的方向锁死，只留量值。（**2026-09-19 注**：直测小-λ 渐近指数 $\beta \to 0.50$（$\mu \propto \lambda$ 线性律），深外推翻转线 $8.6\times10^{-75}$；7.3e-43 为 [3e-3, 1] 局部拟合口径，方向锁定成立且更强，见 [[验证脚本/注记-M6-方向-λ核查：耦合系数翻转线的小-λ 渐近与 κ_φ 候选的对齐]]）

其五，终审的门槛状态：真实场构型（可做部分已交）、$\lambda$ 实际值（S2-1 的第二条提取途径）、非线性在场（容量裁剪已在 S1，但耦合的非线性演化未做）三项中，方向已由本材料与 S2 线共同锁定；归属按裁决十三待门槛齐备。

## 六、诚实边界

其一，一维等效：真实场构型以中心鼓包嵌入 1D 链，与三维几何有距离；三维只报一档（$L = 16$）且未做 $L = 32$ 的标度追踪（D2 的 $1/\sqrt{V}$ 下降趋势未在本材料重测）。

其二，线性谱：全部读数取线性谱判据（与 D1、D2 同源），非线性在场（容量约束下的演化）未进入；这正是裁决十三第三项门槛的状态。

其三，$\lambda$ 的口径：本材料的 $\lambda$ 为调制幅度（对角项系数），其物理身份是耦合重开系数（见 §7.6 命名定夺）；$\lambda$ 的实际值仍待 S2-1 的第二条提取途径。

其四，$\lambda_{\min}$ 由幂律外推（$\beta$ 从 $0.003$ 至 $1$ 档拟合），外推到 $10^{-43}$ 属量级性陈述。

其五，写入速率取太阳档单一值；其余质量档按 $\propto 1/M$ 缩放（S2 材料）。
