## 三、解读

其一，**为什么会偏离**。格子上的波方程是**差分**方程（键能写的是相邻两点的相位差），不是微分方程。平面波代进去得到的是

$$\omega^2(\mathbf{k}) = \frac{4}{t_P^2}\sum_a\sin^2\frac{k_a l_P}{2}$$

与固体里的声波同一个形状。只有波长远长于格距时它才退化成直线 $\omega = ck$；光速是这么"涌现"的。展开后第一项纯连续、不含格子的任何信息，第二项 $-\frac{c^2l_P^2}{12}\sum_a k_a^4$ 才是格子的签名。直观图像：波长与格子尺寸可比时，波开始踩到一个个格子本身。

其二，**公式的几何意义**。写成相对偏离：

$$\frac{\delta\omega}{\omega} = -\frac{l_P^2}{24}\frac{\sum_a k_a^4}{k^2} = -\frac{1}{24}\left(\frac{E}{E_P^{(t)}}\right)^2\frac{\sum_a \hat k_a^4}{k^4}$$

$(E/E_P^{(t)}) = k l_P$ 就是"一个格子占波长的比例"；**平方**的来源是偏离属于四阶导数项，比连续项多两个导数，每个导数各带一个 $k l_P$。换成几何语言：这是曲率级的修正（二阶小量），所以能量一降它自己就按平方变小。

其三，**方向指纹**。$\sum_a \hat k_a^4$ 是立方群的第一个方向依赖不变量：二阶项只能写成 $k^2$（天生各向同性），各向异性第一次显形在四阶。它沿坐标轴取 $1$、沿面对角线取 $\frac12$、沿体对角线取 $\frac13$：沿棱走感受最强，沿体对角线最弱，比值 $6:3:2$，没有自由参数。球面平均 $\frac35$ 则给出各向同性那一半的份额。

其四，**与晶格特征的对应**。

| 偏离的特征 | 晶格特征 |
|---|---|
| 标度 $(E/E_P)^2$ | 格距 $l_P$（唯一长度标尺） |
| 方向形状 $\sum_a\hat k_a^4$、比 $6:3:2$ | 立方对称（三轴等价、六邻） |
| 领头阶无方向差、偏离从四阶起 | 键能 = 邻居相位差平方（二阶、天生等向） |
| 只有一个形状、一个系数 | 均匀结构、无附加标尺 |
| 群速度处处 $\le c$ | 正弦型色散（$\sin x \le 2\sin(x/2)$），与能隙无关 |

其五，**可检验性**。方向比 $6:3:2$ 与 $(E/E_P)^2$ 标度是可检验指纹：$1$ eV 光子给 $2.8\times10^{-58}$，$1$ TeV 给 $2.8\times10^{-34}$，高能天体事件（伽马射线暴光子到达时间差、IceCube 中微子）是对应的实验窗口；SME 语言里属 $\xi^{(4)}$ 型算符。

其六，**"差分方程"这句话该怎样读**。两处容易读错。其一，连续的是倾角的取值，离散的是它的落脚点：$\theta$ 取实数、相邻格点几乎相等，看起来像连续场 $\theta(x)$，但元相子之间没有别的自由度，严格对象是每个格点一个数 $\theta_n$，"$\theta(x)$"是波长远长于格距时的近似记法。其二，决定方程形状的是能量的存储方式：键能只记在相邻元相子之间，作用在一点上的回复力就只由邻居决定，离散拉普拉斯自动出现。

用格点上的行波直接算：$\theta_n = e^{iknl_P}$ 时邻差和为 $2(1-\cos kl_P)\theta_n = 4\sin^2(kl_P/2)\theta_n$（判据 D1 的恒等核对），连续版严格给 $k^2l_P^2$；两者只在四阶项分道扬镳，那一项就是 $(E/E_P)^2$ 偏离。

一条立场声明：若把格子读成"画在连续空间上的坐标网"，差分方程只是数值近似，$(E/E_P)^2$ 是计算假象、随格距缩小而消失；框架取的是"格点即时空最基本单元"，于是差分方程是物理方程，$(E/E_P)^2$ 是预言。这不是装饰性选择：介质不可探测性与 R1 风险都架在这个立场上，而它可被证伪（标度或方向形状不对就要重估）。

其七，**两种离散不要混**。支撑离散（自由度只在格点上，造成差分方程与 $(E/E_P)^2$ 偏离）与能谱离散（一个模式里能量只能取 $n\hbar\omega$）是两件事，两条反例各证一边：连续电磁场照样给出光量子，经典晶格则不会自己把能量切成一份份。格子在量子侧实际提供的是紫外截断（格距给出最短波长，模式数与零点能求和天然有限）与模式标签的离散（$k$ 落在布里渊区内），两者都不回答"为什么是一份一份"。

本框架里具有几何必然性的量子化在另一处：相位是角度型变量、绕数只能取整数，那是电荷的量子化。$(E/E_P)^2$ 标度与 $6:3:2$ 方向比属经典色散的结论，与能量是否量子化无关；模式量子化在色散论文 §6.3 按教科书补全，框架自建的量子化规则仍登记为未建立。
