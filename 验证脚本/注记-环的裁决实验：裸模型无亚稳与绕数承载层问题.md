## 一、背景与判据

《两种危险》注记将钉扎降级为可选环境效应，其"危险一（散架）不成立"论证依赖三个待证命题：格距截断给出驻留极小、零温下相滑移有垒、逃逸通道已封闭。本实验直接测量前两个：其一，过阻尼流与惯性流从构造环出发停在何处（驻留极小判定）；其二，约束弛豫 $E(\lambda)$ 是否有垒。另设 $\kappa$ 刚度对照（0/0.6/1.2，检验"格点刚度能否保护绕数"）与步长对照（离散化伪影排查）。

## 二、模型、测量与两次构造教训

模型为 kink3d A 部分模型：$H = \frac{J}{2}\Sigma(1-\cos\Delta\varphi) + \kappa\Sigma(1-\cos\varphi)$（$J = 1$，最小像差分，$arphi = 0$ 垫片开放边界）。环构造为 derrick_3d [2c] 自旋空间族：奇点集 = {m = 1/2} ∩ {ψ = π}，即核心圆半径 $\rho_c = R_{param} - mask + w/2$（z = 0 平面）。绕数测量 = y = 0 平面 xz-plaquette 涡量在 x > 0 半平面的和（核心圆在 $	heta = 0$ 处垂直穿过该半平面，通量 = 绕数）。

两次构造教训（过程记录）：其一，v1 用 z = 0 平面的 xy-plaquette 涡量测绕数，测的是 z-涡量分量；本构造的涡量为方位角向，z 分量恒为零，读数恒 0（测量错误，非绕数丢失）。其二，v2 把 mask 随构造参数走（mask = R + w/2），奇点条件解出 ρ = 0：建出的是原点单点涡（π₂ = 0，无保护，塌缩是应该的），测错了对象。最终构造固定 mask = 5、w = 3，令 $R_{param} = R_c + 3.5$，核心圆半径恰为 $R_c$，[G1] 校验 |W| = 1、芯位吻合。测量界限：y = 0 半平面通量在 $R_c \lesssim 2.5$ 时出现 plaquette 离散加倍读数（[G1] 中 $R_c = 2.5$ 读 $W = -2$），小半径点未进入任何判据。

补充对照（判据 C6/C7）：尺寸缩放 N = 48 重跑 $R_c = 4$，结局不变（E_final = 0，绕数丢失 t = 2.5，与 N = 32 一致），边界残疑排除。无阻尼惯性（γ = 0，t = 2000）：绕数首次丢失于 t = 50，此后至 t = 2000 |W| 最大回弹 = 0.000，塌缩为终态。需如实标注：无阻尼 Verlet 在剧烈塌缩段存在数值能耗（E 从 1498 降至约 700 后守恒），轨迹精度受限于步长；但回弹为零与阻尼协议一致，且亚稳与否由能量景观决定（C1 的梯度流证据不依赖动力学）。

### 绕数丢失追踪（判据 C3/C4）

绕数在弛豫初始平滑化阶段丢失（$\eta$ = 0.02 时 $t pprox 5$ 即 250 步内，$\eta$ = 0.005 时 $t pprox 1.25$ 即 250 步内），丢失发生在体内部（末态能量精确为零，含边界在内全场无任何梯度，绕数未经边界逃逸，为体内部解缠）。步长减半倍增不改变结局：非离散化伪影。丢失机制为应变驱动的分支穿越：键相位差连续穿过 π，S¹ 场在该瞬间不连续，代价有限（约 J 量级），塌缩释放的线张力能（$10^2$-$10^3$）远超此代价。

### 滑移垒（判据 C2）与方法教训

约束弛豫 $E(\lambda)$ 全线单调下行、无 bump（各 $\lambda$ 下系统在约束两个端点的同时经**其他键**完成滑移并塌到近真空，$E(\lambda) pprox$ 真空 + 端点畸变）。约束弛豫法在此失效：冻结两个格点防不住别的键滑移，该法只适用于约束本身禁止滑移通道的场合（如一维 PN 势垒）。结合梯度流 E 单调降至零（下降路径上无垒），诚实的结论：**沿塌缩路径无滑移垒**；严格的极小能量路径垒需弦方法计算，登记为遗留。逻辑上，"存在一条下坡路"本身已足以否定亚稳（能量极小的定义不允许任何全下坡路径穿过其邻域），故"无有效垒"不依赖弦方法的后续计算，弦方法只给出垒的定量数值。

## 四、结论（定案级）

1. **裸模型中"拓扑自稳定"被否定**：光滑 U(1) 相场的涡旋环在零温、阻尼与无阻尼、有无 on-site 刚度、两种盒尺寸的全部测试下塌缩到真空。绕数同伦守恒的连续性前提在格点流下可被打破：应变驱动键穿越分支切割，代价有限。三条款第一条（内部相滑移有 $O(\kappa_\parallel)$ 垒）的量级预期被否定（约束路径实测垒约 $0.2\kappa_\parallel$，动力学塌缩路径无有效垒）；《两种危险》的"危险一不成立"论证撤回（危险一在裸模型中真实成立，且与边界无关）；《重新评估》的降级论证相应动摇。
2. **绕数承载层问题上升为核心问题**：光滑场实现中绕数不可承载，电荷定案（绕数 = 电荷，同伦守恒）需要绕数写在离散结构上才有保护。自然候选 = 质量机制定案的"缺陷 = 格点内异类"：绕数承载于格点内 σ 锁定扭转结构（离散、无连续解缠路径，保护为构造性）。此方向与质量机制定案、P8a 凝固图像汇合：粒子 = 格点内离散缺陷，光滑场孤子被排除。
3. **钉扎问题的重新定位**：本实验显示问题本身要换问法。钉扎锚位置、不锚绕数；绕数保护先于位置锚定。在绕数承载层解决之前，钉扎的必要性问题没有独立意义（载体未定，锚谁无从谈起）。
4. **derrick_3d [2c] 的重新解读**：其构造（mask = 8，w = 4，R_param = 10）的核心圆半径 = 4，是本轮真环族的一员；其塌缩与开放边界无关，属真环的真实无垒塌缩（本轮多协议重现并推广到体内部解缠）。
5. **并行复跑的独立确认**：另一会话在体系哈密顿量（交错真空三元组）与 arctan2 截面构造族上复跑四件套，重现 C1/C3/C5（含 $\kappa_\varphi$ 的完整哈密顿量下环照常塌缩、绕数体内部丢失），并补充静态窄区碗形（不构成动力学驻留）、一维单键垒 0.19（偏低，证据等级有限）与 n = 1/2 半圈塌缩（整数性确认）三项；其"单值场无法承载绕数"headline 经评估改写为测量协议教训。定案由此升级为双团队、双构造族、双哈密顿量可复现，见《注记-裁决实验四件套复跑：窄区静态极小与单值场绕数承载限制》。

## 五、两种载体的对照：为什么拧劲必死、疤可活（通俗提炼）

本节把第四节的结论翻译成机制语言，回答"为什么"。

涡旋环的绕数不存在任何单个格点"里面"：它是约 $2\pi R$ 个格点的相位恰好首尾相接排成的一个花样。这个花样有三个致命属性。其一，没有家：它只是排布方式，格点各自的相位连续可调，排布可以连续重排。其二，自带拆解发动机：环的线张力要把圈收紧，而收紧本身就是解体过程，圈越缩小应变越集中，最终某条键的相位差被挤过 $\pi$；$\pi$ 是绕数计数的翻页处，翻页的票价只是一个键的最大张力（$O(J)$），塌缩释放的线张力能（$10^2$-$10^3$）远超此数。发动机与过路费都自备，故必死。其三，对晶格只是借住：环横跨几十个格点，晶格的离散性管不到跨区域的连续排布，环可以从 5 个格距连续缩到更小，没有台阶拦截。

格点内缺陷（疤）在三个对应位置上全部反号。其一，有家：绕数写在一个格点内部少数元相子的锁定构型里，晶格的离散性直接就是它的离散性。其二，没有发动机：疤是一个点，点没有线张力，它坐在自己的能量井底（绑定能即井深），解体需要外力把它沿解缠路径拉出，而环境对单个粒子的扰动被普朗克压低。其三，保护的机制换挡：环靠势垒收费（实测票价太便宜），疤靠路径不存在（格点的离散性可能使"从拧到不拧"的连续路径画不出来，构造性保护）。

| | 涡旋环（拧劲） | 格点内缺陷（疤） |
|---|---|---|
| 绕数住在哪 | 散布在 $2\pi R$ 个格点的排布里 | 一个格点内部 |
| 有没有家 | 无：只是排布方式 | 有：格点自身的状态 |
| 谁拆它 | 自己的线张力（发动机自备） | 无发动机（点无张力，坐在井底） |
| 保护的机制 | 势垒收费（实测失败） | 路径不存在（构造性，待数值确认） |
| 对晶格的关系 | 借住（晶格是舞台） | 构成（疤就是晶格的离散性） |

由此得到对电荷定案的精确化：电荷 = 绕数、整数守恒的定案不必放弃，但整数要被守恒，必须锚在物理上真正离散的东西上。拧劲把整数锚在排布的计数方式上，计数可以翻页（实验所见）；疤把整数锚在晶格自己的一个格点上。三块定案（质量 = 格点内绑定能、电荷 = 绕数、运动 = 转换波）在此由同一个对象承载：格点内离散缺陷。方法学附记：本裁决由"论证留下待测数字、实验测量、当天修正"的闭环完成，论证双方（降级方与保留方）的预期各被修正一半。

## 六、边界

其一，$N = 32$ 盒与单一构造族（自旋空间族，w = 3-4）；kink_hamiltonian 静态扫描覆盖 $R \ge 3$、$\rho_0 \ge 1.5$ 区（同为单调），$R \sim \rho_0$ 窄区（$\kappa_\varphi = 0.5$、$\rho_0 = 1.0$）存在静态内极小 $R^* \approx \rho_0$（复跑注记补充，不构成动力学驻留，方向与本结果一致）。其二，真实体系三元组哈密顿量的涡旋环未在本脚本直测（kink_hamiltonian 的静态 E(R) 在 $R \ge 3$ 区单调，方向与本结果一致）。其三，严格的最小能量路径垒需弦方法（遗留）。其四，惯性动力学测试了 γ = 0.2 与 γ = 0 两点；无阻尼 Verlet 在剧烈塌缩段有数值能耗（dt = 0.1），精确能量守恒的无阻尼检验需更小步长或自适应积分器（遗留）。其五，本结果否定的是光滑场实现的亚稳性，不断言"任何实现都不可能"：格点内离散结构的保护是构造性论证，待其数值实现检验。
