## 一、验证目标与判据

复核的问题只有一句：坍缩期间，视界尺度的记录是否即时跟随当下静态剖面？S2 的预备读数以「是」为前提。体系档案中记录场的动力学有两支规范形式。其一，《爱因斯坦场方程的微观根基》§2.2 的每拍注入加最近邻抄写平均，注入与扩散平衡给出泊松稳态 $\theta = s_{eff}l_P/(4\pi r)$。其二，《记录场路线》§3.2 的阻尼波动方程

$$\ddot\theta + \gamma\dot\theta = c_s^2\nabla^2\theta + s,\qquad c_s = c,$$

其中弱阻尼极限是波（场的变化以 $c$ 携带），过阻尼极限退化为写入扩散。档案（判据 C）因共享 $\alpha$ 结构无法同时满足两种需求而把 $\gamma$ 独立出来，并把抄写平均定位为过阻尼极限的离散实现。由此，跟随是否即时取决于视界尺度模频与阻尼的比：$\gamma$ 远小于模频时记录随波即时跟随，$\gamma$ 远大于模频时记录按扩散滞后。

判据（先写期望，再算）：

S2R-1 模式谱：抄写平均的最低盒模衰减率等于 $\alpha(1-\cos\frac{\pi}{N-1})$，阻尼波动（$\gamma = 0$）的最低盒模频率等于 $\sqrt{6(1-\cos\frac{\pi}{N-1})}$；两支实测相对偏差 $\le 2\%$。

S2R-2 过阻尼等价：本积分格式下实测 $D_{\text{eff}}(\gamma)$ 正比于 $1/\gamma$（三点双对数斜率对 $-1$ 偏差 $\le 10\%$）；且 $\gamma = 6/\alpha = 6$ 的波动模拟与抄写平均的微型坍缩亏缺一致（最大差 $\le 0.05$）。

S2R-3 波区跟踪成立：$\gamma \le 0.1$ 时，三个探针半径（$r_h = 4/6/8$）的即时亏缺（$t = T_{\text{coll}}$）$\le 0.45$ 且晚期亏缺（$t = T_{\text{coll}} + 100$）$\le 0.10$。

S2R-4 扩散区跟踪失效：抄写平均与 $\gamma = 6$ 档，$r_h = 6/8$ 的即时亏缺 $\ge 0.85$，晚期亏缺 $r_h = 6$ 处 $\ge 0.30$、$r_h = 8$ 处 $\ge 0.60$。

S2R-5 转变位置：$r_h = 6$ 的即时亏缺跨 $0.5$ 的 $\gamma$（线性插值）落在 $[0.15, 1.5]$，与视界尺度模频同量级（报告两个解析候选 $\pi/r_h$ 与 $\sqrt{12}\sin\frac{\pi}{2(r_h+1)}$）。

报告项：R2 物理外推（必要与充分条件的门槛值、$\Gamma$ 上界与判定方向）；R3 前沿因果核对。

## 二、模型设定

格点为三维立方 $N = 25$（狄利克雷边界，内部 $23^3$ 格）。两支动力学在同一格点上实现。

抄写平均（过阻尼支）每拍更新 $\theta \leftarrow \theta + \alpha(\bar\theta_{nn} - \theta) + w$，取 $\alpha = 1$。阻尼波动支用速度 Verlet（$dt = 0.25$，CFL 上限 $2/\sqrt{12} = 0.577$）演化 $\ddot\theta = L\theta - \gamma\dot\theta + 6w$，其中 $L$ 为七点离散拉普拉斯、源强取 $s = 6w/\alpha$ 使两支静态解相同。

静态参照解一律取同格点、同源分布的共轭梯度泊松解（离散精确）。

微型坍缩：源取归一化高斯质量分布 $w \propto e^{-(d/R)^2}$（截断 $d \le 2.5R$），总注入 $W_{\text{tot}}$ 固定，半径 $R(t)$ 在 $T_{\text{coll}} = 20$ 拍内从 $R_0 = 10$ 线性收缩到 $R_c = 1.6$（内落速度 $v = 0.42$ 格/拍）。$W_{\text{tot}}$ 由最终静态解归一到 $\theta_{\text{post}}(5) = 0.5$（$W_{\text{tot}} = 8.2578$）。

亏缺定义：$\varepsilon = |\theta_{\text{actual}} - \theta_{\text{static}}| / |\theta_{\text{post}} - \theta_{\text{pre}}|$ 在半径壳 $|r - r_h| < 0.7$ 上取平均。两处读数时刻为 $t = T_{\text{coll}}$（坍缩完成，即时）与 $t = T_{\text{coll}} + 100$（六倍坍缩时标之后，晚期）。

## 四、解读

其一，斜坡假设的裁定形态。跟随是否即时，等价于记录阻尼与视界模频的比落在哪一侧：$\gamma \ll \pi c/r_s$ 时记录随波即时跟随（波区），$\gamma \gg \pi c/r_s$ 时记录按扩散滞后（扩散区），转变由格点实测定在 $\gamma_{50} \approx \pi c/r_h$。这一形态把 S2 的模型假设换成了可核对的数值条件。

其二，两支档案动力学的读数相反。抄写平均（过阻尼支）给即时亏缺 $0.89$ 至 $1.03$、晚期 $0.23$ 至 $0.76$，即坍缩期间记录几乎不动；阻尼波动在 $\gamma \le 0.1$ 时给即时亏缺 $0.00$ 至 $0.12$、晚期 $\le 0.04$，即记录随坍缩即时到位（含振铃）。

档案已把共享 $\alpha$ 结构定位为过阻尼极限（判据 C 因 DC 形成与弱阻尼的需求相反而否决单 $\alpha$），故本复核的直接含义是：在档案的健康实现（$\gamma$ 独立的阻尼波动、弱阻尼端）下，斜坡假设成立到 $O(1)$ 精度；在过阻尼端（含默认抄写平均）下，斜坡假设失败。

$\gamma$ 的数值在档案中未定，两支的取舍构成一条新的读数门槛。

其三，对 S2 预备读数的影响。$\Gamma = (M/m_P)(l_P/r_s)^2$ 是因果上界（坍缩以 $c$ 进行时记录变化的最快速率）：波区把它实现到 $O(1)$，扩散区的有效斜坡 $\Gamma_{\text{eff}} \approx \Gamma\cdot\kappa/(\gamma N_s)$ 更小。

D2 的交叉判据（$\Gamma < \Gamma_c$ 即耦合先触发）对斜坡速率单调，故判定方向（耦合先触发、破坏不必待满偏）不因本复核改变，且在任何 $\gamma \ge 0$ 下都朝同一方向强化。

需要改的是口径表述：$\Gamma$ 应写成上界形式，其即时跟随的等号条件为 $\gamma \le \pi c/r_s$。

其四，前沿与幅度的区分（本次复核的核心区分）。R3 显示「前沿 = 每拍一格 = $c$」只保证因果可达：首现幅度为静态值的 $10^{-8}$ 量级。档案中的 A2 读数（前沿 = $c$）与「场延展不用假设、接力传导即达」的解读之间因此需要一条幅度补充：前沿到达，幅度按模式动力学到达。

其五，新读数门槛候选。裁决十三规定的读数门槛有三项（真实场构型、$\lambda$ 实际值、非线性在场）。本复核暴露第四项候选：记录阻尼 $\gamma$ 的取值（或至少其与 $\pi c/r_s$ 的比值落在哪一侧）。在 M6-S2 的时间标定口径下，$\gamma$ 的带决定斜坡假设的成立性与 S2 读数的量值；该候选已由裁决十五结清（S2G 的观测上限把 $\gamma$ 钉在波区），口径登记见裁决十六。

其六，与上游材料的关系。该条与《记录场路线》§3.2 的 $\gamma$ 独立机制选择同源：判据 C 已经指出单 $\alpha$ 结构无法同时承担 DC 形成与弱阻尼波动；本材料把该结构性判断定量化为「DC 跟随的阻尼带 $\gamma \le \pi c/r_s$」，并给出两端的格点读数。若作者把 $\gamma$ 定在波侧，S2 预备读数按现有口径有效；若定在扩散侧，S2 读数的口径应改写为上界形式，触发时刻仍由噪声底设定（量级 $10^{21}$ 拍，见 S2 材料 §三）。

## 六、诚实边界

其一，微型几何的尺度比。微型坍缩里重排区域的外尺度（$R_0 = 10$）与探针半径（$r_h = 4$ 至 $8$）之比约 $1.2$ 至 $2.5$，物理档的对应比值（核心半径与视界半径）约 $10^3$；外尺度拖累在微型里被低估，故本材料对跟随条件给出的门槛是偏宽（有利于跟踪）的估计，报告 R2 的充分条件即用于覆盖该缺口。

其二，阻尼支的动力学问。$\gamma$ 的物理数值、其是否随尺度变化（记忆核或频率依赖阻尼）均未在档案中具文固定；本材料只测固定 $\gamma$ 的阻尼波动与抄写平均两支，不排除第三种动力学（例如带惯性的弹性支）给出不同的转变形式。

其三，振铃与容量。波区的亏缺含振铃相位（$\gamma = 0.05$ 与 $0.1$ 的即时亏缺非单调即由此而来），振铃超调与满偏容量（$h \le 1$）的相互作用属非线性，未在本材料范围（S3 项）。

其四，数值锥与物理锥。阻尼波动支的离散格式每步传播一格，数值锥比物理锥（每拍一格）宽，故前沿核对改用抄写平均（图锥恰为每拍一格）；连续极限下波支的前沿性质由档案的张量桥分段 b 判据承担。

其五，亏缺口径。亏缺在固定半径壳上平均，未做谐波分解，故即时亏缺是各模的合成读数；转变位置由跨 $0.5$ 的插值给出，未做不确定度传播。
