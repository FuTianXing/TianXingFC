## 二、模型设定

FK 链（$k=1$、$K=0.005$、$N=1000$），缠绕 0 自洽边界（$u_0 = 0$、$u_{N-1} = N-1$，均匀链 $u_j = j$ 为精确平衡态：$\sin 2\pi j = 0$、键均匀、零力，无需弛豫）。对撞设计：高斯速度包 A（$x_c - 100$ 向右）与 B（$x_c + 100$ 向左），$t = 100$ 对撞，$T = 150$。叠加相对偏差 $\varepsilon = \max|u_J - u_A - u_B + u_{\text{base}}| / \max|u_J - u_{\text{base}}|$（线性叠加恒等式扣除平衡基线；v2 曾漏减基线且底座缠绕约定错置，教训入第五节）。全确定性。

## 四、发现：线性域极深，破缺阈为缺陷形成

两个超出声明预期的发现。

其一，线性域极深：包位移振幅跨约两个量级（$v_a$ 从 0.01 到 0.1，位移波包高度从约 0.4 到约 4 个格距）叠加偏差始终为机器噪声级（$2\times10^{-9}$）：正弦非线性的相对强度由局域相位斜率决定，平滑的大高度包斜率仍小，叠加依旧精确。

其二，破缺为阈值型而非幂律型：$v_a = 0.2$ 时长包破缺（0.158）而同振幅窄包线性（$1.6\times10^{-5}$），破缺由场构型是否成核出晶格尺度的滑量结构（kink 形成阈）决定。物理表述：**线性叠加住在没有缺陷的地方；缺陷（kink）是非线性对象，不服从叠加**。破缺阈的完整机制（包的缠绕内容与持续时间如何决定成核）归后续，与 M2 复合模型落窗判据同族。

## 五、过程记录（v1 至 v3 三处构造教训）

v1：叠加恒等式漏减平衡基线（$u_J = u_A + u_B - u_{\text{base}}$ 的 $u_{\text{base}}$ 项），偏差被静态底座（幅度 $\sim N$）淹没。

v2：底座缠绕约定错置：把缠绕 0 底座（$u_j = j$）钉进缠绕 1 边界（$u_{N-1} = N$），等效在边界强制单位缠绕缺陷辐射污染全场；改用锚定 kink 作底座后 kink 尾巴又被左边界切断持续漂移（三个演化的场完全相同、包不可见）。v3：采用缠绕 0 自洽约定（$u_{N-1} = N-1$），均匀链为精确平衡态，问题消除。教训：边界钉扎的缠绕约定必须与底座解的缠绕数一致；叠加恒等式必须对平衡基线表述；诊断时先看三个场各自长什么样再改判据。

## 六、严格程度与边界声明

K1、K2、K3 为数值验证级，判据稳健（线性域深度与破缺幅度间有多个量级的分离，不依赖参数微调）。K4 的阈值两侧对照为数值验证级，门控方向的机制解释（键滑量、kink 成核）为定性层。不验证：KG 残差与 $(E/E_P)^2$ 修正在体系层面的具体形式（候选登记，本模型的正弦非线性为其化身）；破缺阈的完整相图；三维推广；声明的最终采纳（裁决点 5）。未确认前不入理论总纲。
