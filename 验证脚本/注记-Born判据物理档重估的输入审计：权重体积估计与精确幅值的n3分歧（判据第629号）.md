## 一、要判什么

第 624 号把 Born 判据推到物理档，得电子 $R_2 = 5.384\times10^{68}$，据此判"档位翻转、硬核执行者从格点约束重判为强投影势 $u_{kl}$"。该结论待写入多体论文 §4.2（属修订轮，标注"交作者裁决"）。

624 的势深输入逐字沿用多体论文 §4.1 的估计

$$u_{kl}(\mathbf r) = U_0\,\theta(\xi-\lvert\mathbf r\rvert),\qquad U_0 \sim \hbar\omega_0\left(\frac{\xi}{l_P}\right)^3 = \hbar\omega_0\,n^3,$$

其"量级来源"为权重体积图像：重叠区含 $n^3$ 个格点，每格点禁入能量取能隙 $\hbar\omega_0$。

同一论文 §4.3 给出**精确**相互作用

$$V(d) = M\sum_{N\ge1}\Big[4N-2\big(N^2-\epsilon_N\big)\theta\Big]e^{-N\theta},\qquad \theta = d/\xi,$$

并自标 §4.1 的 $\theta$ 型形式是它的 $N = 1$ 截断（"$\theta$ 型单带形式只保留第一阶"）。

本轮要判的是：§4.1 的估计与 §4.3 的精确幅值是否一致。若不一致，624 的物理档读数继承该分歧，论文 §4.2 的修订不能按 624 执行。

## 二、模型设定与判据

一维锁定势格点，SG 口径，逐字沿用第 627 号与论文 §4.3：

$$E = \sum_n\Big[\frac{k_b}{2}(\theta_{n+1}-\theta_n)^2 + K(1-\cos\theta_n)\Big],\qquad \xi = \sqrt{k_b/K},$$

单 kink $\theta = 4\arctan e^{(x-x_c)/\xi}$，质量 $M = 8\sqrt{k_bK}$，能隙 $\omega_0 = \sqrt K$。相互作用按 §4.3 定义 $V(d) = E[w_1+w_2]-2E[w_1]$（两条 kink 直接叠加，不做松弛）。格点单位取 $\hbar = c = l_P = k_b = 1$。

判据先立后测：

- Q1 冒烟（$V$ 有限、正、随 $d$ 单调衰减）；
- Q2 幅值标度（$V(d=\xi)$ 对 $\xi$ 的幂律指数为 $-1$）；
- Q3 档位比（$U_0^{\S4.1}/U_0^{\S4.3} = n^3/c_V$，模型档 $O(1)$、物理档 $>10^{60}$）；
- Q4 能量上界（物理档 $U_0^{\S4.1}$ 超两缺陷总能量）；
- Q5 修正 Born 参数（以 §4.3 幅值代入，物理档为 $O(1)$ 至 $O(10^3)$）；
- Q6 判据有牙（增强因子严格等于 $n^3/c_V$，去掉即落临界区）；
- Q7 约定核对（级数对数值叠加能，残差按 $1/\xi^2$ 收敛）与巧合点（§4.1 估计等于 §4.3 首阶幅值处 $n^*$）。

合计 7/7。

**其一，§4.3 的精确幅值是 $O(\hbar\omega_0)$，不含权重体积因子。** 五档 $\xi$ 扫描给出 $V(d=\xi)\cdot\xi$ 为 $4.369$ 至 $4.392$（散布 $0.5\%$），幂律指数 $-0.998$，与 $\omega_0 = \sqrt K = 1/\xi$ 同族。孤子质量 $M = 8/\xi$ 同族。故精确相互作用的量级由缺陷自身能量设定，与重叠体积无关。

**其二，§4.1 的估计超精确幅值 $n^3/c_V$ 倍。** 模型档 $n=2.25$ 处比值 $2.6$（$O(1)$），物理档 $n = 2.389\times10^{22}$ 处比值 $3.11\times10^{66}$。模型档两估计同量级，物理档差 $66$ 个数量级。

**其三，物理档的 §4.1 估计违反能量上界。** $U_0^{\S4.1} = n^2$（格点单位）为 $5.71\times10^{44}$，而两缺陷总能量 $2M = 6.70\times10^{-22}$，比值 $8.52\times10^{65}$。相互作用能不可能远超参与缺陷的总能量，故该估计在物理档不可用。

**其四，以 §4.3 幅值代入，物理档 Born 比为 $O(10^2)$ 至 $O(10^3)$。** 两口径给出 $R_2 = 173.14$（$d=\xi$ 幅值）与 $1263.3$（$N=1$ 截断幅值），落入临界区，而非 $10^{68}$ 的强势失效区。

**其五，翻转严格由 $n^3$ 承载。** 624 读数与修正读数之比为 $3.109714\times10^{66}$，对 $n^3/c_V$ 机器精度重合。把 $U_0$ 的 $n^3$ 换成 §4.3 精确幅值，读数落入临界区。

**其六，模型档两估计同量级是巧合。** §4.1 估计 $\omega_0 n^3$ 等于 §4.3 首阶幅值 $4M$ 当且仅当 $n^3 = 4M/\omega_0 = 32$，即 $n^* = 3.175$。模型档 $n = 2.25$ 落在该点附近（相对差 $29\%$），故两个量级在模型档近似相等，分歧从未暴露。

**其七，物理档 Born 比为 $O(1)$ 是按构造的。** Born 分母 $\hbar^2/(m\xi^2)$ 在物理档（$\xi = \hbar/(mc)$，康普顿恒等式）等于 $mc^2$，即粒子静能；§4.3 的精确相互作用幅值同样为 $O(\hbar\omega_0) = O(mc^2)$。分子与分母同为静能，比值只能是 $O(1)$ 量级，与 $n$ 无关。$10^{68}$ 全部来自 §4.1 的 $n^3$。这是本轮最干净的表述：物理档 Born 判据不翻转，它停在 $O(1)$。

## 四、裁决

**其一，624 的物理档翻转幅度由 §4.1 的权重体积因子 $n^3$ 承载，该因子与论文 §4.3 的精确幅值不一致。** 用 §4.3 的精确幅值，物理档 Born 比为 $R_2 = O(10^2)$ 至 $O(10^3)$（临界区）。624 的"超阈 $13$ 至 $18$ 个数量级"应改为"约 $2$ 个数量级"。

**其二，§4.1 的权重体积估计本身须订正，误标原因是把整体能隙当作单格点代价。** $\hbar\omega_0$ 是缺陷的整体能隙（静能标度），不是单格点的能量份额；单格点的能量份额是 $M/n^3$（$M$ 为缺陷总能量，$n^3$ 为格点数）。§4.1 把整体能隙 $\hbar\omega_0$ 当作每格点的禁入代价，再乘以 $n^3$ 个格点，等于把缺陷的整体能量数了 $n^3$ 遍。正确的量级是「单格点份额 $\times$ 格点数」$= (M/n^3)\cdot n^3 = M$，与 §4.3 的精确结果一致。这一条给出分歧的物理出身，不止是数值对不上。

**其三，论文 §4.2 的修订以 §4.3 的精确幅值为输入。** 用质量恒等式把宽度钉在 $n = m_P/m$ 后，Born 比 $R_2 = 4\pi^2 c_V$（$c_V$ 为 §4.3 幅值系数，$4.4$ 至 $32$），为 $O(10^2)$ 至 $O(10^3)$，与粒子档无关（质量恒等式使 $n^2(m/m_P)^2$ 为 $1$）。

**其四，624 的方向保留，强度降档。** $R_2 = O(10^2) > 1$ 仍判 Born 失效，故 $u_{kl}$ 在物理档从描述项升为承重项这一方向成立；但它是临界区的边缘失效，而非 $10^{68}$ 的强势失效。论文 §4.2 的"负面读数"改述须按此强度写。

**其五，本轮不改变 §4.3 的任何结论。** §4.3 的解析通项、前两阶系数对照、格点离散修正首项均为独立结果，本轮只审计 §4.1 与 §4.2 的势深输入。

## 六、过程记录

1. **Q5 首版判据阈值过紧**：初版把修正后的 $R_2^{\S4.3}$ 上界设为 $50$，判据未过。实测 $R_2^{\S4.3} = 173$（$d=\xi$ 口径）与 $1263$（$N=1$ 口径），均含 §4.2 的 $4\pi^2$ 约定因子。按纪律从理论可达范围重推：$4\pi^2 c_V$ 的量级上界取 $10^3$ 至 $10^4$，判据改为两口径并报，均过。
2. **Q6 首版把比值对象写错**：初版拿增强因子对 $n^3$ 比较，实为对 $n^3/c_V$，相对差读出 $0.77$ 误判。改为对代数预期 $n^3/c_V$ 比较，相对差 $0$（机器精度）。
3. **Q7a 首版容差拍脑袋**：初版把级数对数值叠加能的残差上界设为 $10^{-10}$，判据未过。实测残差 $1.5\times10^{-3}$，成因是格点离散化（$O(1/\xi^2)$），非约定不一致。按纪律改为收敛检验：偏差随 $\xi$ 翻倍而降约 $4$ 倍（实测比 $4.02$ 与 $4.00$），确认残差为协议伪影。**教训：级数与数值叠加能的残差须区分「约定不一致」（固定偏差）与「格点离散化」（$1/\xi^2$ 收敛），前者判否、后者属伪影。**
4. **编辑事故**：一次 Edit 把两行合并（打印语句与下一行粘连），运行时抛 `NameError`，按报错定位修复。属落盘后即读头核对的纪律范围。

## 七、严格程度与边界声明

**本注记验证**：§4.1 势深估计与 §4.3 精确幅值的档位一致性；精确幅值的 $\xi$ 标度（幂律指数 $-1$）；档位比 $n^3/c_V$；物理档估计对能量上界的违反；以精确幅值修正后的 Born 参数；翻转对 $n^3$ 的严格依赖；级数约定核对与巧合点。

**本注记不验证**：其一，不重算 §4.3 的解析通项与前两阶系数（已由留数轮与多体论文 §4.3 交付）；其二，不裁决 §4.1 权重体积图像的物理动机（只判它与 §4.3 的数值一致性）；其三，不做三维情形的相互作用计算（本轮在一维 SG 口径内，量级结论对维度不敏感）；其四，不改动多体论文正稿与第 624 号注记（落稿与指针属后续同步项）；其五，不涉及强场与引力侧。

**边界（模型级）**：精确幅值系数 $c_V = 4.386$ 为 $d=\xi$ 处的读数，$N=1$ 截断口径为 $32$，两者同为 $O(1)$ 至 $O(10)$，故 $R_2 = O(10^2)$ 至 $O(10^3)$ 的档位判定对口径不敏感。
