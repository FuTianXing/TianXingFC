## 一、模型设定

全空间 8 分量 = 内部模态 2（$\sigma_z$ 标签，本轮为恒等乘客）$\otimes$ 时空 3+1 维 Dirac 4（Dirac 基：$\gamma^0 = \operatorname{diag}(I,-I)$，$\gamma^i$ 反对角 Pauli，$\gamma^5$ 反对角单位）。哈密顿量

$$H = I_2 \otimes \bigl[\alpha_\theta c_\theta K_\theta + \alpha_h c_h K_h + \beta\, m\bigr],\qquad \alpha_i = \gamma^0\gamma^i,\quad \beta = \gamma^0,$$

$K_\theta = -iD_\theta$ 为反周期差分（$\pi$ 扭转口径，接缝移位带负号，复用第 489 条实现），$K_h$ 周期（D-b 主设定）。$\gamma^3$ 不激活但保留在 $\gamma^5$ 定义中。格点 $N_\theta = N_h = 16$，全矩阵 $2048\times2048$ 稠密对角化。冒烟：Hermitian、$\{\gamma^0,\gamma^5\}$、$\gamma^5{}^2$ 全部机器零。

## 二、判据与结果

**UP1（D2 主体）**。实空间谱与离散解析谱逐位吻合（$\max|\Delta E| = 1.87\times10^{-14}$）：每模式 $\pm E$ 各内部 2 重、时空 2 重，共 8 支，$E = \sqrt{c_\theta^2\sin^2 k_\theta + c_h^2\sin^2 k_h + m^2}$。两因子可分离性在谱上表现为内部 2 重精确简并。

**UP2（D2 连续极限）**。低 $k$ 档（$c^2k^2 < 0.06$，2 模式）残差 $1.28\times10^{-2}$，恰贴 $\sin$ 展开预算 $k^2/3 = 1.29\times10^{-2}$，判 PASS。

**UP3（宇称）**。$P = \gamma^0$ 在三十二个 Clifford 单项式（含与不含 $i$ 因子）的穷举中唯一满足 $[P,\gamma^0] = 0$、$\{P,\gamma^i\} = 0$、$P^2 = I$、厄米（复核 491 W2，2×4 结构下结论不变）；$\gamma^0\alpha_\theta\gamma^0 = -\alpha_\theta$（机器零），给出 $PH(k)P^{-1} = H(-k)$ 的代数根源。

**UP4（D4 关闭读数，本轮核心）**。显式投影构造：对任取的 8 个本征态作手征投影 $P_\pm = (1 \pm \Gamma_5)/2$，投影态的 $\langle\Gamma_5\rangle = \pm 1$ 精确（对照 491 W5 的质量本征态全零）。$m = 0$ 档的 Weyl 块（$\Gamma_5 = +1$ 子空间内 1024 维）谱与解析 $E = \pm c|\sin k|$ 逐位吻合（$\max|\Delta E| = 1.71\times10^{-14}$）：：单支无质量色散成立，质量项为块外耦合。**D4 的关闭形式就此明确**：$\pm n$ 两支作为 Weyl 分量存在于显式投影构造中（态有确定手性），质量是支间耦合；这与标准物理「Dirac 场分解为 Weyl 分量、质量为左右耦合」的结构同构。

**UP5（±n 镜像迁移）**。$w = \pm 1$ 绕数背景的 8 分量谱逐位恒等（$\max|\Delta E| = 0$）：第 489 条的镜像机制在升维结构下保持，$\pi$ 扭转落相位因子的裁定（待裁二）在谱层无阻碍。

## 三、过程记录（教训四条）

**教训一，空间算符的 Kronecker 须先合成空间再乘 γ 结构。**首轮把 $\gamma$ 结构直接与单维差分 kron（$4\times4 \otimes 32\times32 = 128$ 维），与质量项的空间维数（$4\times4 \otimes 512\times512$）不匹配。正确顺序：$K_\theta = -iD_\theta \otimes I_h$、$K_h = -iD_h \otimes I_\theta$ 先合成空间算符（512 维），再与 $\gamma$ 结构 kron（$4\times4 \otimes 512 = 2048$）。

**教训二，解析谱的简并度必须按算符的完整自由度计。**UP1 首版解析谱只给 $\pm E$ 两支，实测尺寸不匹配；每模式的支数 = 时空旋量支数 × 内部因子维数 = $4\times2 = 8$。

**教训三，全算符的维度链须逐层补齐。**$\Gamma_5$ 全算符 = $I_2 \otimes \gamma^5 \otimes I_{256}$，首轮缺空间单位阵（$8\times8$ 对 $2048\times2048$）。维度链的每一层（内部、γ、空间）都要显式补齐。

**教训四，解析对照的简并度同理。**Weyl 块解析对照首版漏内部 2 重与 ± 两支的重复计数；$P_+$ 块每模式含 $+|p|\times2$ 与 $-|p|\times2$。
