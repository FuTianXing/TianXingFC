## 二、模型与协议

原料与协议沿用动能流轮的锚定协议：FK 链 $E = \Sigma[\frac12\dot u^2 + \frac{k}{2}(u_{n+1}-u_n-1)^2 + K(1-\cos 2\pi u_n)]$，$k = 1$，$N = 1400$，$dt = 0.01$，窗口半径 $W = 30$，缠绕守恒边界，boost 沿 $v = -v_0\partial_n\theta$，中段拟合测速，尾段窗口平均。主判据区 $K = 0.005$，窄 kink 对照 $K = 0.02$（读数）。

口径约定：积分量（$E_{\rm rest}$、各通道、$\int T^{11}$）用哈密顿量形式（梯度能 = 键形 $\frac{k}{2}(\Delta\theta)^2$，与守恒锚一致）；逐点轮廓与逐点关系（$T^{11}$ 逐点残差、$\theta_x^2/V$ 比值）用中心差分 $\theta_x$（与动量读数一致）。两口径的差异以静息位力残差 $D_{\rm rest} = E_{\rm grad} - E_{\rm pot}$ 显式读出。

## 三、主要读数

### 判定的精确陈述

记 $\theta = u - n$ 为超额相位，$V_n = K(1-\cos 2\pi\theta_n)$，三段装配为：

$$T^{00}_n = \tfrac12\dot\theta_n^2 + \tfrac{k}{2}\theta_{x,n}^2 + V_n,\qquad T^{01}_n = -\dot\theta_n\theta_{x,n},\qquad T^{11}_n = \tfrac12\dot\theta_n^2 + \tfrac{k}{2}\theta_{x,n}^2 - V_n$$

这三式即 $\theta$ 场正弦-Gordon 拉格朗日量的正则张量。$\theta$ 场满足 $\ddot\theta_n = k(\theta_{n+1}-2\theta_n+\theta_{n-1}) - 2\pi K\sin 2\pi\theta_n$（格点整数处 $\sin 2\pi u = \sin 2\pi\theta$），两条守恒律 $\partial_tT^{00}+\partial_xT^{01}=0$ 与 $\partial_tT^{01}+\partial_xT^{11}=0$ 由运动方程精确给出。

$T^{11}$ 的"混合"有了精确形态：动能与梯度侧（$\frac12\dot\theta^2 + \frac{k}{2}\theta_x^2$）减去静质量侧（$V$）。静止时位力逐点恒等式 $\frac{k}{2}\theta_x^2 = V$ 使 $T^{11}$ 逐点归零；移动时两通道同乘 $\gamma^2$，$T^{11} = \frac12\dot\theta^2 + (\gamma^2-1)V = \frac12\dot\theta^2 + \gamma^2v^2V$。

### 通道标度与 γ 锚

三个通道各自按 $\gamma$ 标度（R1）：$E_{\rm grad}$ 与 $E_{\rm pot}$ 在 0.2% 内贴合 $\gamma E_{\rm grad,rest}$ 与 $E_{\rm pot,rest}/\gamma$；$E_{\rm kin}$ 系统性偏高 2.1% 至 2.7%（读数，见严格程度声明）。

总和给 $E_W = \gamma E_{\rm rest}$：塌缩幅度 $s = 1.0006$（R4），与既有色散验证在 K = 0.005 档的 $s = 1.005$ 在 1% 内一致。这是 (d) 总判据「γ 增强的写入幅度对应 $T^{00}$ 的洛伦兹变换」的场侧能量内容。

### 动量流

动量流增量（$\int T^{11}(v) - D_{\rm rest}$）对 $\gamma Mv^2$ 的相对偏差为 $+0.84\%$（$v = 0.194$）与 $+2.96\%$（$v = 0.367$）；低速档（$v = 0.0985$）相对偏差 $-6.0\%$，其绝对残差为 $0.06\%\,E_{\rm rest}$。

低速档按绝对残差判定（R3b）：增量本身只有 $0.9\%\,E_{\rm rest}$，通道差分的格点残差（$D_{\rm rest} = 0.653\%\,E_{\rm rest}$）构成相对判定的下限。这与既有纪律同型：低速档的 $O(v^2)$ 量受 $O(v^0)$ 格点残差限制。

逐点 γ² 平衡（R5）：核心区中位比值 $[(k/2)\theta_x^2]/V$ 相对静息比值之比为 $\gamma^2$（偏差 $+0.95\%$ 至 $+2.2\%$），静止的位力平衡在 boost 下按 $\gamma^2$ 保持。

静止零张力：窗口内 $\int T^{11} = 0.653\%\,E_{\rm rest}$（$D_{\rm rest}$，格点残差），静止逐点残差 $0.034$（连续极限为零）。静息态压强为零，移动 kink 的应力呈尘型（$T^{11} = \gamma Mv^2$ 的积分形式）。

### 接口读数（迹与嵌入假设）

把 1D 解按 $y$、$z$ 均匀延拓时，横向分量为 $T^{22} = T^{33} = -\frac12\dot\theta^2 + \frac{k}{2}\theta_x^2 + V$。静止时 $T^{11}$ 逐点为零而 $T^{22}$ 逐点等于 $T^{00}$，于是 $\operatorname{tr}T$ 在静止时逐点等于 $2T^{00}$。

这是应力迹耦合（[[注记-应力通道的最小验证：T^ij 的计数、迹耦合与源侧的 O(v^2) 要求]] 的 $\operatorname{tr}T$ 通道）在最小模型中的读数：迹耦合看到的是能量密度的两倍。均匀延拓是嵌入假设，三维实际形态由 C1 定。

## 四、严格程度声明

全部读数为格点最小模型的确定性数值（无随机数，能量守恒漂移 $\le 8.7\times10^{-10}$）。R0a 与既有色散验证的档案读数对接（$E_{\rm rest,W} = 0.08978$，$D_{\rm rest} = 0.653\%$ 为格点残差读数）。

通道标度中 $E_{\rm kin}$ 的系统性偏高（2.1% 至 2.7%）与 $E_{\rm grad}$、$E_{\rm pot}$ 的 0.2% 内贴合并列为读数。R3 的两肢划分是测量精度边界（见过程记录）。

## 五、边界声明

本注记验证 1D 最小模型上的应力项混合形式、$T^{00}$ 三项装配与通道标度。

不验证：三维应力通道的 3+1+2 结构（G2-L1 轮在计数层已给，显式三维形式门控 C1）；振幅通道（复场）的应力支；横向分量的非均匀延拓形态；连续极限外推与 $c_s$-$c$ 同一化。

## 六、过程记录（两处修正）

**其一，积分口径修正（中心差分到键形）。** 首版用中心差分梯度能装配 $T^{00}$，对接锚偏差 $-1.10\%$（既有档案为 $-0.278\%$）。原因是守恒锚与哈密顿量用键形梯度能 $\frac{k}{2}(\Delta\theta)^2$，中心差分低估非均匀区梯度能（差 $0.00074$，约 1.7%）。修正后积分用键形、逐点用中心差分，两者差异以 $D_{\rm rest}$ 显式读出。

**其二，动量流判据的两肢化。** 首版单肢相对判据（$\le 5\%$）在 $v_0 = 0.10$ 档判负（$-6.0\%$）。核查：增量是通道差分的组合，其量级只有 $0.9\%\,E_{\rm rest}$，而通道级格点残差约 $0.5\%\,E_{\rm rest}$，相对判定的下限由此残差主导；$v \ge 0.15$ 档相对判定正常。修正为 R3a（相对）+ R3b（全档绝对），失败读数记录为测量精度边界。
