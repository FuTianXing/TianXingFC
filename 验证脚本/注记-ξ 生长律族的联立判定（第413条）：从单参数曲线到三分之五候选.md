## 1 判据与设定

第 408 条把 $\xi$ 的约束清成两条不等式加一个方程：链条结构为单参数曲线 $\xi_c(t) = C (t/t_{\rm eq})^{1/2}$，系数 $C = (z_{\rm eq}^{-3}/f)^{1/3} = 2.2895\times10^{31}$（可见物质档 $f = 2.12\times10^{-105}$），$\xi$ 的独立依据缺席。本轮把生长律 $\xi = t^{\alpha}$ 作为额外输入与曲线联立，把曲线上的连续可能压成定点：交点位置、允许 $\alpha$ 带、分数候选（X1 至 X4），并对三档 $f$ 做端点敏感性（X5）。

设定：时间以拍计，长度以格计（$c = 1$ 格每拍）；健全性要求冻结间距不小于缺陷宽度，$\xi \ge w_{\rm def} = 3.80\times10^{21}$ 格；因果性要求 $\xi \le t$；相变时标不超过宇宙年龄 $8.07\times10^{60}$ 拍。相变时标口径取 W1 裁决（可见物质档；边界解 $t_* = 7.59\times10^{35}$ 拍）。

## 2 结果

X1（联立框架）：交点由 $t^{\alpha} = C\sqrt{t/t_{\rm eq}}$ 给出，闭式解 $t = (C/\sqrt{t_{\rm eq}})^{1/(\alpha-1/2)}$。链条曲线与健全性下界的交点核实：$\xi_c(7.562\times10^{35}) = 3.8001\times10^{21}$，与 $w_{\rm def}$ 逐位吻合。

X2（弹道律 $\alpha = 1$）：交点 $t = 1.910\times10^{7}$ 拍、$\xi = 1.910\times10^{7}$ 格，$\xi/w_{\rm def} = 5.03\times10^{-15}$，差 $14.3$ 个数量级。弹道生长（$\xi \propto t$）判负：交点在缺陷宽度之下，冻结图像无法成立。

X3（允许带）：$\alpha \in [0.5598, 0.6015]$，带宽 $0.0417$。上界由 $\xi = w_{\rm def}$ 给出（$\alpha_{\max} = 0.6015$），下界由 $t$ 达到宇宙年龄给出（$\alpha_{\min} = 0.5598$）。带内对应 $t_* \in [7.56\times10^{35}, 8.07\times10^{60}]$ 拍。

带内读数两例：$\alpha = 0.58$ 给 $t_* = 3.2\times10^{45}$ 拍、$\xi = 2.5\times10^{26}$ 格；$\alpha = 0.60$ 给 $t_* = 2.5\times10^{36}$ 拍、$\xi = 7.0\times10^{21}$ 格。带外读数两例：$\alpha = 0.55$ 给 $t_* = 6.4\times10^{72}$ 拍（超宇宙年龄约 $12$ 个数量级）；$\alpha = 0.65$ 给 $\xi/w_{\rm def} = 1.6\times10^{-6}$。

X4（$\alpha = 3/5$）：解 $t_* = 2.539\times10^{36}$ 拍 $= 1.369\times10^{-7}$ 秒、$\xi = 6.964\times10^{21}$ 格 $= 1.83\,w_{\rm def}$。四项校验全过：健全性、因果性（$\xi/t = 2.7\times10^{-15}$）、年龄上界、零新参数。

KZ 指数对照：$\nu/(1+\nu z) = 3/5$ 可由 $(\nu, z) = (3/2, 1)$ 给出，与 3D Ising 类（$\nu/(1+\nu z) \approx 0.28$）不同族；该对照属判识假设，机制来源未建立。

## 4 结论与移交

三条读数。其一，弹道律判负：$\xi \propto t$ 的交点比缺陷宽度低 $14.3$ 个数量级，任何档位移动都补不上。其二，允许带存在：$\alpha \in [0.5598, 0.6015]$，带宽 $0.0417$，由健全性与年龄两条硬约束夹出，与生长律的细节无关。

其三，$\alpha = 3/5$ 是带内自然分数：解在 $t_* = 2.54\times10^{36}$ 拍、$\xi = 1.83\,w_{\rm def}$，零新参数；带内距上端 $0.0015$，为带宽的 $3.6\%$，属紧配合。

两档口径张力登记。允许带的 $t_*$ 下端 $7.56\times10^{35}$ 拍与 W1 边界解 $7.59\times10^{35}$ 拍在 $0.4\%$ 内重合，两者同源：同一条 $\xi \ge w_{\rm def}$ 约束。若沿用 W1 之前的旧时标窗（$7.38\times10^{3}$ 至 $5.87\times10^{8}$ 拍），带为空、幂律族整体无解。W1 已裁决允许带移到 $t_* \gtrsim 7.6\times10^{35}$ 拍，故本条按 W1 口径成立；旧窗仍作为候选出现在部分注记中，引用时须注明口径。

移交三条。其一，$\alpha = 3/5$ 的机制来源：为何恰是 $3/5$，需要 KZ 指数判识的正面论证或超扩散谱的一般论证，本轮只登记数值相容。其二，带端对 $w_{\rm def}$ 与 $z_{\rm eq}$ 的灵敏度（X5 只扫 $f$ 档）。其三，$3/5$ 与带宽的关系：带中心约 $0.58$，$3/5$ 偏向上端，是否提示更深结构，留待机制论证。

## 5 严格程度与边界声明

严格程度：X1 至 X4 为定义加代数（换算级）；X2 的判负由数量级余量支撑（判据级）；X3 与 X4 的合法性在设定口径内成立（判据级）；X4 的 KZ 对照为判识假设，不构成机制论证；X5 为端点敏感性算术。

边界（本脚本不验证的内容）：其一，生长律的物理来源与 $\alpha$ 是否为常数（族取纯幂律，不含分段生长）；其二，不裁决档位（X5 仅登记敏感性）；其三，$t_{\rm eq}$ 与 $z_{\rm eq}$ 取标准值，不含框架内推导；其四，不含缺陷产额的后继演化（对接环）；其五，相变时标本身不做新裁决，取 W1。
