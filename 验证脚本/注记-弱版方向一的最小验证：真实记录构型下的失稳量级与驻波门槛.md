## 一、验证目标与判据

弱版耦合验证（W1 至 W4）确认了「一阶零、二阶非零」的耦合结构，并用均匀记录读出负模（失稳）。方向一的任务是把自由参数记录场换成由碰撞写入导出的真实构型（中心深、两侧衰减），检验失稳在真实构型下的量级。判据（先立期望，再算）：

W5a 对照复现：均匀 h = 1 的最低模与解析 $2J - \sqrt{(2J)^2 + (\lambda h)^2}$ 一致（偏差 $\le 10^{-10}$）。

W5b 两端复现：单点 h = 1 最低模为正；均匀 h = 1 最低模为负。

W5c 最小失稳条件：块状构型族（截断均匀）存在最小失稳宽 $w^*$（$1 < w^* < 64$）；并报告最低模对块宽的非单调性。

W5d 真实构型量级（修正版）：1/r 衰减构型（$h_n = h_0/(1+d_n)$，$h_0 = 1$）的失稳幅度不超过均匀情形的 5%。原始预期为「真实漏斗不失稳（最低模为正）」，实测给出小幅负值（$-0.0033$），预期被推翻；修正判据与教训见过程记录。

W5e 门槛对幅度的依赖（报告）：$h_0$ 取 $0.5$、$1$、$2$、$5$ 时 $w^*(h_0)$。

## 二、模型设定

模型与弱版验证同源：一维交错链、$N = 64$、周期边界、$J = 1$、$\lambda = 1$，交错背景下的 Hessian 为对角调制 $H_{nn} = 2J + \lambda(-1)^n h_n$ 与相邻项 $H_{n,n\pm1} = J$；最低模取 $\omega^2_{\min}$（负值即线性失稳）。

构型族四类。单点：一格有记录。块状（截断均匀）：以中心为对称、宽 $w$ 格内记录为 $h_0$、其余为零，$w$ 从 $1$ 扫到 $64$。1/r 漏斗：$h_n = h_0/(1+d_n)$，$d_n$ 为周期最近距离（三维泊松解在一维的衰减形状模拟，全链非零）。平滑族：$h_n = h_0/(1+2d_n/w)$，$w$ 从 $1$ 扫到 $256$（从窄峰到近平坦的连续过渡）。

平坦度 $F = (\sum h)^2/(N\sum h^2)$（均匀 $= 1$，单点 $= 1/N$），用于横向比较构型的「均匀程度」。

## 四、解读

**对判别点的回答**。BH3-5 留下的判别点是「耦合能否独立触发失稳」。本轮在一维层给出的回答：能，但弱。真实 1/r 构型的最低模为 $-0.0033$，线性增长率约为均匀情形的 $\sqrt{0.0033/0.236} \approx 1/8.5$。耦合路线未被排除（失稳不消失），其强度较均匀假设弱近一个数量级。若与「饱和路线」赛跑，耦合触发在时间尺度上处于劣势，这与 BH3-5 的饱和主导倾向方向一致，但以「弱失稳」而非「无失稳」的方式成立。定量结论留待强场工具（三维构型与 $\lambda$ 的实际值）。

**非单调性的结构观察**。块的两端是缺陷边界；最低模对半宽呈两类：奇数半宽锁定在与均匀相同的值 $-0.2361$，偶数半宽随宽度逐渐加深并趋近该值（样点：$w = 9$ 给 $-0.1676$、$w = 13$ 给 $-0.1984$、$w = 17$ 给 $-0.2123$）。这提示两点：其一，一维链上「最小失稳宽 3 格」是存在性门槛，失稳幅度由构型的对称类分档；其二，这一奇偶分类的精确形态（模式与缺陷边界的匹配关系）待进一步分析，「均匀度门槛」的简单化解读不可靠。

**平滑族的含义**。从窄峰到近平坦的连续过渡单调加深失稳，说明「记录覆盖越宽、失稳越强」的大方向在一维成立（与块族的锯齿叠加时不冲突：锯齿是同一覆盖下的对称类差异）。

## 六、诚实边界

其一，一维、$\lambda = 1$、无时间标定；增长率比较只到 $\sqrt{|\omega^2|}$ 的相对量级。

其二，构型形状为选择（1/r 的离散模拟与平滑族），并非从三维泊松解严格约化而来；三维真实场的失稳谱需要强场工具。

其三，非单调锯齿是一维结构效应（分档的精确形态已由补充材料收口，见 §八），球对称三维下是否保留未知。

其四，本材料不裁决「破坏是否必待满偏」，只为该判别点提供耦合侧的一维输入。

## 七、过程记录

其一，判据修正（W5d）：原始预期「真实漏斗不失稳」被实测推翻（$-0.0033 < 0$）。教训：把「局域化即无失稳」当作预期不可靠；一维链上 3 格以上的对称调制组即可诱发弱失稳，存在性由最小失稳宽决定、幅度由对称类决定。修正后的判据（弱失稳 $< 5\%$）通过。

其二，判据增补（W5c）：初版只判「门槛存在」，实测发现锯齿后增补非单调性报告项，并要求注记解释其结构来源。

其三，评审修正（2026-09-17，B1、B3）：原「缺陷中心取反节点／节点落在中心」的机制断言经本征矢中心分量检验（$w = 3, 5, 7, 9$ 均非零）不成立，改为数据规律表述并标注精确形态待分析；图 1 横轴由块宽改为平坦度 F（消除曲线与标记的坐标混用）。
