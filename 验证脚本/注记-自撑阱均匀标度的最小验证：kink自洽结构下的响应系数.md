## 二、模型设定

一维 phi^4 标量场，$V(\phi) = (\lambda/4)(\phi^2 - 1)^2$，kink 解 $\phi(x) = \tanh(kx)$，宽度与势参数由 BPS 一阶方程锁定为 $k^2 = \lambda/2$。涨落算符 $A = -\partial_x^2 + V''(\phi)$，束缚模满员 $\omega_b$ 为本征值 $3k^2$ 的平方根。本装置的关键是「自撑」：阱形 $V''$ 由 kink 自身结构给出，与质量参数共用同一个 $k$，非外加固定输入。

**自洽恒等式**（符号计算确认，是本判据的支点）：

$$V''(\phi) = \lambda(3\phi^2 - 1) = 4k^2 - 6k^2\operatorname{sech}^2(kx)$$

**与判据 M4 的对应**：M4 的四通道系数 $a_1$（动能）、$a_2$（质量）、$a_3$（时间导数归一）、$a_4$（限制势）在本装置中都有对应物。$a_4$ 对应定域阱，$a_2$ 对应常数项，$a_1$ 与 $a_3$ 由同一 $k$ 的缩放定出。

## 三、结果

P1 与 P2 给出结构骨架：涨落算符精确分裂为常数项 $4k^2$ 与定域阱 $-6k^2\operatorname{sech}^2$，束缚模谱恰好给出零模与 $3k^2$。

P3 是通道同源的直接证据：定域阱与常数项都正比于同一个 $k^2$，比值恒为 $-3{:}2$，与 $k$ 无关。在外加阱下这两项没有理由同源，$a_4$ 随阱形独立变动（判据 M3 的固定族失败签名即由此而来）。

P4 给出 $\mathrm{d}\ln\omega_b^2/\mathrm{d}\ln k = 2$，即 $\omega_b^2 \propto k^2$。结合 $a_2 = a_4 = a_1 = 1$（四通道同源于 $k^2$），判据 M4 的更正公式给出 $\kappa = 1$。

P5 检查格距无关性：$\kappa$ 在 $h$ 从 $0.04$ 细化到 $0.01$ 时稳定趋近 1，$k$ 从 $0.7$ 到 $1.4$ 时走势一致。这一项对应 §4.4 的义务：耦合不经由背景格距。

## 四、物理读数

**均匀标度来自自洽结构本身。** 判据 M4 的结论是：外加阱下要求 $\kappa = 1$ 对一切权重成立，唯一解是均匀标度 $a_1 = a_2 = a_4 = a$、$a_3 = a+2$，故那个解就是几何耦合假设的重述。本判据说明该前提在自撑阱下被机制满足：kink 的 BPS 结构使势阱与质量同源于一个参数 $k$，四通道自动连线，没有留给调参的自由度。

**与外加阱的差别可以一句话说清。** 外加阱下 $U(x)$ 的形状与深度是独立输入，$a_4$ 可自由赋值，要凑出 $a_4 = a_2$ 就得调参；自撑阱下 $a_4 = a_2$ 是恒等式，不占任何自由度。

**对识别式攻坚的后果。** 识别式的处境由「唯一解即假设的重述」改为「自洽结构自动给出均匀标度，唯一解被机制兑现」。承重墙出现第一道裂缝，但因两个前置仍在，尚不能宣布识别式已成为定理：其一，本装置是一维的，三维复合位错形态（纲领 C1）未验证；其二，自撑阱的完整弹性本构未构造，本判据只用了 BPS 型标量自洽结构这一最简实例。

## 五、严格程度声明

**验证了什么**：自洽恒等式（P1）、束缚模谱（P2）、通道同源（P3）、频率标度（P4）、格距无关性（P5）均为可复现数值事实；恒等式 $V'' = 4k^2 - 6k^2\operatorname{sech}^2$ 与 $\omega_b^2 = 3k^2$ 均有解析根据。

**未验证什么**：三维形态；自撑阱的完整弹性本构；$a_3$ 的独立值（本装置只用 $\kappa = 1$ 的差值结构，$a$ 的分摊约定不改变物理）；判据 M4 的权重普适性前提在外加阱情形下仍然成立，本判据只说明自撑阱满足该前提。

**边界**：结论建立在一维 phi^4 kink 的 BPS 型自洽结构上，不外推到三维或非 BPS 陷阱；本判据不改动任何基准文件。

## 六、过程记录

其一，恒等式三次写错：初版写 $V'' = 2k^2 - 3k^2\operatorname{sech}^2$（符号与系数均错），二版写 $V'' = 3k^2\operatorname{sech}^2 - k^2$（系数错），最终用符号计算确认 $V'' = 4k^2 - 6k^2\operatorname{sech}^2$。教训：自洽恒等式应先用符号计算确认再进数值管线，手推易在 $2$、$3$、$4$、$6$ 之间串位。

其二，P3 初版在 $\operatorname{sech}^2 \to 0$ 的点出现 $0/0$ 伪影（最大偏差 $1.0$）。加掩码 $|\operatorname{sech}^2| > 10^{-6}$ 后偏差降到 $3.1\times10^{-11}$。

其三，剖面参数与势参数的一致性：kink 解 $\phi = \tanh(kx)$ 要求 $k^2 = \lambda/2$，早期尝试混用 $\phi = \tanh(kx/2)$ 与 $\lambda = 1$ 导致本征值移动到 $2k^2$ 与 $3k^2$，误判为算符错误。修正剖面后谱逐位对上。
