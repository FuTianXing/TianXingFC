## 一、要判什么与模型设定

**来源。** 第 484 条在环面（一维周期链）上评估芯-芯束缚候选：正反对全档吸引但无内部极小，判负为定域化候选；缺口登记为守卫层（绕数超选择、toric code 对易结构）能否阻止对湮灭，须另立判据。本判据把守卫层的既有资产（Z_N toric code 判据、超选择论文的扇区结构）对接到该后续项上。

**拓扑口径（首版教训后定案）。** 周期链净绕数按端点差整化计：$Q = \mathrm{round}(v_{N-1} - v_0)$。键差折叠读法（$\sum\mathrm{round}(\Delta v_n)$）对宽 kink 失效：光滑台阶的最大键差不过 $0.5$，绕数是分布量，折叠读数恒零。环面扇区由 $u_{n+N} = u_n + m$ 给出，$Q = m - N$。

**守卫层的经典实现。** 扇区标签 $Q$ 作为固定参数进入 wrap 键差（$\Delta v_{N-1} = v_0 - v_{N-1} + Q$）：它不在动力学自由度里，梯度流改不动它。这正是超选择的经典对应（跨扇区禁止 = 标签不在演化算符的作用范围里）。

**判据。** G1 三档对照（模型同第 484 条：$k = 1$，$K$ 五档 $10^{-2}$ 至 $0$，$N = 256$，梯度流 120000 步）：a) $Q = 0$ 泡（间距 12）判湮灭通道是否开放；b) $|Q| = 1$ 单台阶判缺陷总数是否可灭，形态读数分档（局域保持对扇区极小离域）；c) 开放边界自由端对照判 kink 是否漏出（守卫来源确认）。G2 为结构核对（引既有读数，不重跑）：对湮灭对应弦算符收缩（基态空间内），单缺陷湮灭对应跨扇区（一阶矩阵元为零）。G3 为结论面。

## 三、读数的意义

**守卫层与定域化的分工就此收口。** 第 484 条的缺口（无守卫模型判负是否被守卫层翻案）答案是判否：守卫层守的是"缺陷带不带绕数"，管不着"缺陷待不待得住"。环面上粒子的稳定定域化必须另找承接者，候选收窄为两条已成立的：第 485 条内部壁承接（冻结环内键偏差能量非零、$K$ 无关平台）与第 483 条边界环冻结（开放边界下边界保护候选成立）。

**三层分工获得对接确认。** 拓扑序守电荷（扇区标签）、格点内锁定给质量（锚核钉扎）、弹性包层给宽度（色散），守卫层的职能与第一层严格对应：它在第 484 条判负处不补位，恰说明三层分工各司其职，环面设定下"电荷守恒"与"位置稳定"是两件独立的事。

**扇区极小离域在动力学面上复现。** G1b 的弱钉扎档弛豫终态逐位落到均匀扭转极小（$1/(2N)$），把超选择论文"扇区极小被拓扑强制离域"的静态结论接上了动力学通道：$Q = 1$ 扇区内没有局域化吸引子，均匀分布是唯一极小。

## 五、过程记录

其一，**梯度流符号连错两次**：拉普拉斯版把弹性梯度写成 $+k\,\Delta^2 v$（反扩散，能量上升）、键差版再反复弹一次，两次都由"能量上升违反梯度流定义"直接暴露；定案的写法是解析逐项核验 $\partial E/\partial v_j = -(\Delta v_j - \Delta v_{j-1}) + 2\pi K\sin(2\pi v_j)$ 并把推导写进注释。教训：梯度流实现前先写 $\partial E/\partial v$ 解析式，实现后用能量单调下降做冒烟。

其二，**绕数读法两版失效**：周期和 telescoping 恒零（第一版）、键差折叠对宽 kink 恒零（第二版，光滑台阶最大键差 $1/(2\xi) < 0.5$ 折叠不出整数）。定案读法为端点差整化 $Q = \mathrm{round}(v_{N-1} - v_0)$。教训：周期链的拓扑数载体是端点条件（$u_{n+N} = u_n + m$），不是键差的局域性质；宽 kink 的绕数是分布量。

其三，**扇区标签须进入能量**：$|Q| = 1$ 档首版用 $Q = 0$ 口径的能量演化，wrap 键差被强制往 $Q = 0$ 拉，读数漂移。修正后 $Q$ 作为固定参数进入 wrap 键差，这本身就是守卫层的正确经典实现（标签不在自由度里）。教训：拓扑扇区的数值演化必须把扇区参数写进边界条件，而不是指望场自己记住它。

其四，**形态读数的索引错**：局域度读数把 wrap 键差（$-0.996$）混进内部键差，把"已均匀化"误读成"局域保持"；能量读数与解析极小逐位吻合才暴露矛盾。教训：同一终态的能量读数与形态读数交叉核对，单读数不自洽时先查索引。

其五，**收敛性档位债**：$Q = 0$ 泡的湮灭时标随 $K$ 与间距变化（$K = 10^{-2}$ 档首版 120000 步内未塌完），按第 484 条教训把间距收近（12 格点）并加步数后全档塌缩。湮灭判据从"下降 $10^4$ 倍"改为"能量下降且 $Q$ 恒 0"（通道向下即开放），分档诚实报告下降倍数。
