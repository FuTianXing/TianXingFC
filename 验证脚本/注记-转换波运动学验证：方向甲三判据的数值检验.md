## 一、模型设定

提升变量 $u_n \in \mathbb{R}$ 对应整周锁定势的缠绕提升（格距 $a = 1$）：

$$E = \sum_n \left[ \frac{1}{2}\dot u_n^2 + \frac{k}{2}(u_{n+1} - u_n - 1)^2 + K(1 - \cos 2\pi u_n) \right]$$

真空 $u_n = n$；kink $u_n = n + 1$（多绕一格 = σ 锁定区，缠绕提升中可见的静态滑移）。链信号速度 $c_s = \sqrt{k} = 1$（每拍一格）。映射声明：FK 链的缠绕提升对应 σ 锁定的提升方向结构（σ 锁定的静态 Avatar），kink 平移即转换波；洗衣板势即格点离散性；弹簧即格点间耦合。**关键边界条件：缠绕守恒边界 $u_{N-1} = u_0 + N$（固定缠绕数、kink 位置自由）**：见第四节发现一。

参数两区：锚定验证用 $K = 0.02$（窄/重 kink，强钉扎）；运动学验证用 $K = 0.005$（宽/轻 kink，可动区）。原因见第四节发现三：$K = 0.02$ 区驱动窗口为空。

## 三、过程发现（三条升级为物理结论）

**发现一：缠绕守恒边界是转换波存在与运动的先决条件。** 初版边界条件每步强制 $u_{N-1} = N-1$，而 kink 构型的右边界提升为 $u_{N-1} = N$（缠绕 1）：边界钳制与拓扑缠绕对抗，链被张力绷死，kink 完全不能运动。改为 $u_{N-1} = u_0 + N$（固定缠绕数、kink 位置自由）后运动学才成立。物理结论：**转换波只能在尊重拓扑的边界条件下存在与运动；固定提升边界从拓扑上禁锢它。**

**发现二：驱动窗口可能为空（锚定-可动性联动）。** 诊断发现 $K = 0.02$ 区脱钉力 $F_c \approx 0.29$ **大于**真空稳定阈值 $2\pi K = 0.126$：能推动 kink 的力必先摧毁真空本身，驱动窗口为空。窗口只在宽/轻 kink（小 K）下打开（$F_c$ 随 K 下降快于线性的 $2\pi K$）。锚定与可动性是同一旋钮（K）的两端。

**发现三：费米子"慢"的机制形式（窗口速度饱和）。** 离散 kink 获得任意大的动量脉冲后，辐射掉超出部分、settle 到无辐射传播的窗口速度（实测 $\approx 0.14\,c_s$，与初动量无关）。速度不是任意参数，是离散晶格上转换波的无辐射传播窗口。宏观物体的极慢速 = 钉扎阵列的集体弛豫极限，与此同源。

## 四、结论与边界

**判定**：方向甲（转换波）作为费米子运动机制：锚定完全确认（PN 势垒实测存在且 E(s) 结构正确）；惯性确认到"匀速保持 + 能量守恒 + 绕数保持"（粒子性成立）；测地响应确认到方向性（定向下坡）；速度上限通过。定量部分（$m_{eff}$、$a = f/m_{eff}$、迁移率曲线）被离散 kink 的辐射/窗口物理掩盖，需要阻尼协议下的系统测量或连续极限（宽 kink 极限）分析，属后续工作。

**边界**：其一，toy 链代理（提升变量对应整周锁定势提升的映射为模型假设）；其二，一维链，三维三元组孤子的推广未做；其三，$\sigma$ 锁定时间向缠绕的动力学未进入本模型（模型直接以提升滑移为对象）；其四，相对论色散 $E^2 = m^2c^4 + p^2c^2$ 的涌现（条目 33 遗留）未验证，窗口速度与相对论极限的关系待查。
