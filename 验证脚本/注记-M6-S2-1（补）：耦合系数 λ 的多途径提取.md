## 一、验证目标与判据

S2-1 的判据是「至少两条独立途径给同一系数」。本材料在模型单位（$J = 1$）下定义四条途径，全部在同一能量泛函上操作，观测量彼此不同：能量写法（构造）、谱（线性响应）、Hessian（二阶导）、孤子（静态非线性解）。

判据（先写期望，再算）：

S2-1a 能量归一化：耦合项写成「记录调制 onsite 系数」的形式，与 $K$ 写法逐位恒等（差 $\le 10^{-15}$），得 $\lambda := K$（满幅记录下的 onsite 系数）。

S2-1b 谱反演：由谱闭式 $\omega^2_{\min} = 2J - \sqrt{(2J)^2 + (\lambda h)^2}$（弱版注记 §五）反演 $\hat\lambda_2(h)$，对 $h \in \{0.1, 0.25, 0.5, 1, 2\}$ 离散度 $\le 1\%$；并复核弱版注记 W4 表（$h = 0.1/0.5/1$ 的 $\omega^2_{\min} = -0.002498/-0.061553/-0.236068$，偏差 $\le 10^{-5}$）。

S2-1c Hessian 直测：单点记录的对角修正 $\Delta H = -\lambda h\cos\theta$，读出 $\hat\lambda_3$，偏差 $\le 10^{-12}$。

S2-1d 静态 kink：SG 链上 $E_{\text{kink}} = 8\sqrt{JA}$ 与 $\ell = \sqrt{J/A}$（$A = \lambda h$）两条子估计之比落在 $[0.9, 1.1]$；$\hat\lambda_4 = A/h$ 对 1 的偏差 $\le 10\%$。

S2-1e 汇总：四条途径提取值的最大相对偏差 $\le 10\%$（S2-1 判据本体）。

## 二、模型设置

一维交错链（$N = 256$，周期边界），能量 $E = J\sum\cos(\theta_{n+1}-\theta_n) + \lambda\sum(1-\cos\theta_n)h_n$，$J = 1$；交错背景 $\theta_n = \pi n$（途径一至三），铁磁背景（途径四）。途径一直接核对两种写法的能量恒等；途径二用精确对角化取最低模并反演；途径三读单点记录的对角修正；途径四在 $h = 0.05$ 与 $0.02$ 下的单扭结上测量 $E_{\text{kink}}$ 与轮廓拟合宽度 $\ell$，由两条解析关系独立反演 $A = \lambda h$。全部确定性，无随机数。

## 三、结果

判据 5/5 全过（运行约 3 秒）。

要点如下。其一，谱反演对五个记录幅度给出同一 $\hat\lambda_2 = 1.0000000000$；弱版注记 W4 表独立复现（$h = 0.1$ 给 $-0.002498$、$h = 1$ 给 $-0.236068$，最大偏差 $4.4\times10^{-7}$）。

其二，Hessian 直测为机器精度（偏差 $0.00\times10^{0}$）。

其三，静态 kink：$h = 0.05$ 给 $E_{\text{kink}} = 1.777369$（解析 $8\sqrt{JA} = 1.788854$，偏低 $0.64\%$，属离散修正）、$\ell_{\text{fit}} = 4.392$（解析 $\sqrt{J/A} = 4.472$）；$h = 0.02$ 给 $1.128513$（解析 $1.131371$）与 $\ell_{\text{fit}} = 7.019$（解析 $7.071$）；两条子估计之比 $0.952$ 与 $0.980$，$\hat\lambda_4 = 0.9872$ 与 $0.9950$。

其四，汇总最大相对偏差 $0.0089$（$0.89\%$），满足 S2-1 的 $10\%$ 判据。

其五，未完成项：物理常数比 $K/J$（挫折弦系数与键刚度之比，元相子格点本构）未给，本材料只在模型单位下验证四途径一致。

## 四、解读

其一，S2-1 的判据在模型层满足：四条观测量不同的途径给同一系数，最大偏差 $0.89\%$。此前「同族形式」是唯一来源，现在有了可核对的数值一致。

其二，途径的独立性：能量写法核对的是归一化约定；谱反演用的是线性响应的闭式；Hessian 用的是二阶导；kink 用的是静态非线性解的能量与宽度。后三条不共用中间量，只有共同的能量泛函。

其三，kink 途径同时给出离散修正的标尺：$E_{\text{kink}}$ 对解析值的偏差随 $\ell$ 增大而减小（$0.64\%$ 对 $\ell = 4.4$；$0.25\%$ 对 $\ell = 7.0$），与 $\ell$ 的解析关系一致。

其四，对 S3 的意义：终审的「$\lambda$ 实际值」门槛现在分成两层，模型层（本材料）已给一致读数；物理层待 $K/J$ 的元相子格点本构值。S3 的 $\lambda$ 扫描（[[验证脚本/注记-M6-S3（可做部分）：真实场构型的谱读数与 λ 扫描]]）已把依赖关系备好，$\lambda$ 一到即可代入。

其五，途径一的性质声明：$\lambda := K$ 是归一化约定（把记录读作 onsite 系数的调制），不是独立的物理推导；三条操作途径才是独立读数，故本材料把「同族形式」与「归一化约定」合为一条来源、另补三条。

## 六、诚实边界

其一，模型层与物理层：本材料给的是模型单位（$J = 1$）下的四途径一致，$\lambda$ 的物理数值仍依赖元相子格点的本构常数比 $K/J$，未给。

其二，途径一的约定性：$\lambda := K$ 依赖「记录读作 onsite 系数调制」这一归一化读法；换读法（例如记录只进入相位置移）会给不同的形式（弱版注记的 W1 至 W3 只钉住结构，不钉住该约定）。

其三，离散修正：kink 途径在 $\ell \approx 4$ 至 $7$ 档，离散偏差 $0.25\%$ 至 $0.64\%$，判据 $10\%$ 内；更小 $\ell$ 档未测。

其四，维数与背景：全部读数在 1D 链上；三维与更复杂背景未测（与 D1、D2 的三维读数无冲突，本材料不复测）。

其五，与真实场的关系：本材料不涉及记录的空间剖面，$\lambda$ 的构型依赖属于 S3 的读数。
