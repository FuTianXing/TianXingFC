## 摘要

丙案执行轮。第 492 条运动学写法（$\alpha_i = \gamma^0\gamma^i$、$\beta = \gamma^0$）下 $\Gamma_5$ 与 $H$ 的对易关系经解析推导与数值核对**逐位成立**：

$$[\Gamma_5, H] = 2m\,\Gamma_5\beta, \qquad \{\Gamma_5, H\} = 2\,\Gamma_5\,\alpha\cdot p.$$

两式在 $m > 0$ 时均非零（对易子与反对易子实测各 $1.000000$），故 $\Gamma_5$ 为非守恒标签；$m = 0$ 时对易子归零（手性守恒恢复），反对易子仍非零。$H^2 = K^2 + m^2$ 逐位零差（$\alpha_i^2 = +1$、$\alpha$ 与 $\beta$ 反对易故交叉项解析为零），两种运动学表述同式，丙案的定性修正与预计均获数值支持。**D4 区分量归属确认**：$\Gamma_5$ 在能量本征态基下不对角（最大非对角元 $0.734$），能量本征态上的期望是简并子空间内任意基的产物（EP3 极差 $0.1625$），按 EP4 报非守恒标签并停止读数；区分量为能量符号（正负能各 1024 重、零模零），与第 495 条裁定一致。

## 二、判据与结果

**Q1（EP4 守恒标签自检，$m > 0$）**。$[\Gamma_5, H] = 1.000000$、$\{\Gamma_5, H\} = 1.000000$，两者均非零：$\Gamma_5$ 与 $H$ 无守恒关系，能量本征态上不得读其期望值。合法结论为「非守恒标签」。

**Q2（$m = 0$ 对照）**。对易子归零（$0.00\times10^{0}$），手性守恒恢复；反对易子仍为 $1.000000$。即 $\Gamma_5$ 的守恒与否以 $m = 0$ 为界，「手性非守恒」须带此限定。

**Q3（解析式数值核对）**。$[\Gamma_5, H] = 2m\Gamma_5\beta$ 与 $\{\Gamma_5, H\} = 2\Gamma_5\alpha\cdot p$ 两式的数值与解析逐位吻合（偏差 $0.00\times10^{0}$）。丙案初稿称「既不对易也不反对易」属定性错误，正确表述为「有确定对易关系但两者均非零」。

**Q4 与 Q4b（$H^2$ 一致性）**。$\alpha_i = \gamma^0\gamma^i$ 满足 $\alpha_i\alpha_j = -\delta_{ij}$ 故 $\alpha^2 = +1$；$\alpha_i$ 与 $\beta = \gamma^0$ 反对易（实测 $\max|\alpha_\theta\beta + \beta\alpha_\theta| = 0$），交叉项 $\{\alpha\cdot p, \beta m\} = 0$ 解析为零。于是 $H^2 = K^2 + m^2$ 逐位零差。**两种运动学表述（$\alpha$ 形式与裸 $\gamma$ 形式）平方同式，丙案「UP1 至 UP3 与 UP5 不受影响」的预计由 $H^2$ 一致性支持**；丙案的实质是表述口径统一，不是回退。

**Q5（D4 区分量归属）**。正能 1024 重、负能 1024 重、零模零：能量符号给出两扇区的等维非空区分，与第 495 条裁定一致。EP3 拦截演示：正能子空间内 206 个组合矢的 $\langle\Gamma_5\rangle$ 落在 $[-0.068, +0.094]$，极差 $0.1625$，为简并子空间内任意基的产物，按 EP4 报非守恒标签并停止读数。对照读数：$\Gamma_5$ 在能量本征态基下的最大非对角元 $0.734$——$\Gamma_5$ 不与能量本征态基对角（$[\Gamma_5, H] \neq 0$ 的直接后果），故本征态上的期望值无物理意义。第 492 条 UP4 的「显式投影态 $\langle\Gamma_5\rangle = \pm 1$ 精确」应按此读作 $\Gamma_5$ 算符的对角化事实（对任意厄米对合成立），非 D4 的区分量。

## 三、过程记录（教训三条）

**教训一，$H^2$ 的代数结构须先定 $\alpha$ 的平方约定。**首版误写 $H^2 = m^2 + p^2$（$p = -iK$ 故 $p^2 = -K^2$）并假设存在交叉项，偏差 $2.0$；实为 $\alpha^2 = +1$（$K^2$ 口径）且 $\alpha$ 与 $\beta$ 反对易故交叉项解析为零。教训：色散判据的解析式须由生成元的平方关系推出，不由约定符号代入。

**教训三，EP3 的价值在于演示而非读数。**Q5 的 206 个组合矢给出的 $[-0.068, +0.094]$ 区间不是物理读数，而是「该标签在本设定下不可读」的证据。首版把这个区间当作 $\langle\Gamma_5\rangle$ 的读数来检验，判据方向反了。
