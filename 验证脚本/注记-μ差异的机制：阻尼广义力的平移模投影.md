## 一、问题

阻尼迁移率实测 $\mu = v_{term}/f \approx 53$（K = 0.005，γ_d = 0.2，f = 0.005），此前理论推导给出 $\mu = 1/(γ_d S_{tot}) = 5$（$S_{tot} = \Sigma φ' = 1$ 总缠绕），差 5 倍。该差异是等效原理 O(1) 闭环论证中唯一未解释的环节。

## 二、诊断

稳态驱动（f = 0.005，γ_d = 0.2，150000 步）下全场测量：

| 量 | 实测 | 对照 |
|---|---|---|
| v_term（kink 终端速度） | -0.266 | - |
| Σu̇ = Σv_n（全场速度总和） | +0.266 | v·S_tot = 0.266 ✓（S_tot 有效 = 1 精确） |
| γ_d·Σu̇ | 0.0532 | f = 0.005 ✗（格点平衡不成立） |
| Σv 窗口外（声子流） | 0.0000 | 边界固定的均匀力场被边界力平衡，真空静止 |

关键发现：$\Sigma\dot u = -v_{term}$ 精确成立（S_tot 无问题），但格点力平衡 $f = γ_d \Sigma\dot u$ 不成立（差 10.6 倍）。说明平衡必须用广义力（投影到 kink 平移模）。

## 三、机制：阻尼广义力的平移模投影

kink 的位形坐标 = 中心位置 $x_c$，形状导数 $\partial u_n/\partial x_c = -φ'_n$（φ = u - n）。驱动广义力：$F_{xc} = f \Sigma_n \partial u_n/\partial x_c = -f \Sigma φ' = -f S_{tot} = -f$。

阻尼广义力：投影 $-γ_d v_n$ 到平移模，$F_{damp} = γ_d \Sigma v_n φ'_n$。匀速平移 $v_n = -v φ'_n$（v = ẋ），故 $F_{damp} = γ_d v \Sigma φ'^2 = γ_d v M_{zero}$。

**关键区别**：$S_{tot} = \Sigma φ' = 1$（总缠绕，出现在广义驱动力），$M_{zero} = \Sigma φ'^2 = 0.0888$（形状范数，出现在广义阻尼）。此前误把 S_tot 用在阻尼项。

平衡：$f S_{tot} = γ_d v M_{zero}$ → $\mu = v/f = S_{tot}/(γ_d M_{zero}) = 1/(0.2 \times 0.0888) = 56.3$。

实测 $\mu = 53.2$（f = 0.005），偏差 6%；相对论性运动质量修正（v = 0.266 c_s → γ³ ≈ 1.11）后理论 50.7，偏差约 4%。闭合。

## 四、结论与含义

1. **μ 差异闭合**：机制为阻尼广义力的平移模投影（采用 M_zero，放弃 S_tot），理论修正后与实测吻合（偏差 4-6%，相对论修正方向正确），非数值错误
2. **m_resp 物理含义澄清**：m_resp = f/(γ_d·|v_term|) = M_zero = 惯性质量（形状范数），其与 M_shape 的 O(1) 对齐是定义使然（阻尼投影 = 平移模范数），等效原理 O(1) 闭环论证基础巩固
3. **文献修正**：此前登记与论文中的"μ 理论 = 1/(γ_d·S_tot) = 5"应更正为 $\mu = S_{tot}/(γ_d M_{zero}) = 56.3$；验证定稿论文开放问题 1（阻尼有效系数机制）闭合
4. **S_tot 与 M_zero 的分工**：S_tot 只出现在广义驱动力（F = f·S_tot），M_zero 只出现在广义阻尼（γ_d·v·M_zero），驱动耦合拓扑总量、阻尼耦合平移模范数，几何意义清晰

## 五、严格程度

数值（Σu̇ = -v_term、γ_d·Σu̇ vs f、μ 实测）为可复现计算事实；广义力投影推导在本文内完成；相对论修正方向正确但精确因子待连续极限确认。f = 0.01 及以上数据因 kink 越出盒子（诊断脚本无 stop 条件）无效，结论基于 f = 0.005。
