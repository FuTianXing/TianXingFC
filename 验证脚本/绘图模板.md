# 验证脚本绘图模板

供 `验证脚本/minimal_verification_*.py` 复制使用。AGENTS.md「数值验证脚本规范」第 6 条只要求"含中文标签时须设中文字体"，具体样板在此。

## 样板

```python
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

plt.rcParams["font.sans-serif"] = ["Microsoft YaHei", "SimHei"]
plt.rcParams["axes.unicode_minus"] = False
```

## 三点要求

**其一，设置位置**：`import matplotlib.pyplot as plt` 之后立即设置，与该导入语句同缩进（顶层导入顶格，函数内延迟导入随函数体）。

**其二，字体选择**：首选 `Microsoft YaHei` 或 `SimHei`，本机两者均存在。未设时 matplotlib 回退默认 `DejaVu Sans`，中文渲染为豆腐块且不报错，出图后才可发现。

**其三，修正既有脚本的字体缺失**按纯渲染层修正处理：改脚本、重跑、更新图，不动判据与数值，重跑读数须与修正前一致并在提交信息中说明。
