## 一、问题与口径

第二十四轮在共线端点上量到单波完成式的残余随振幅四次幂（比值 $16.0$ 与 $256.3$），当时只把它读作"地板"，系数与来源未导出。本轮从精确场方程入手，把这条地板解析化。

构型取 $g_{tt} = -1$、$g_{zz} = 1$、$g_{xx} = p(u)$、$g_{yy} = q(u)$，一切只依赖 $u = t - z$。这属 pp-波（Rosen 型）：唯一的非平凡分量是 $R_{uu}$，闭式为

$$R_{uu} = -\frac{1}{2}\left[(\ln p)'' + (\ln q)''\right] - \frac{1}{4}\left[((\ln p)')^2 + ((\ln q)')^2\right]$$

真空条件即 $R_{uu} = 0$（$R = 0$ 因零矢结构，故 Einstein 张量等于 Ricci 张量，$G_{tt} = R_{uu}$）。

代入 $A = a\cos u$、$p = 1 + A + B$、$q = 1 - A + B$ 作振幅级数。二阶方程由闭式给出 $B_2'' = A''A + A'^2/2$，其解正是框架完成式

$$B_2 = \frac{3a^2}{16}\cos 2u - \frac{a^2}{8}u^2$$

三阶与五阶由宇称封口：方程只通过 $A^2$ 与 $(\ln p)'^2 + (\ln q)'^2$（交换 $p$、$q$ 不变）依赖 $A$，故 $A \to -A$ 是方程的自同构，解 $B(a)$ 为 $a$ 的偶函数。
