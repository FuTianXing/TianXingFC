## 一、背景：宽度缺口与两线 T4 冲突

纠缠侧探路确认电荷保护（toric code 层：基态空间投影量子数、跨扇区零矩阵元），但 T5 显示该层粒子点状（涡旋激发宽度约 0、电荷激发约 1 格距），不满足 $\ell \ge 2$ 色散窗口。并行线《扇区约束动力学》独立裁决 T4：扇区极小 = 均匀扭转（离域，$r_g$ = 盒尺度），局域化被拓扑禁止；且本线协议 B 的"扇区极小 0.3045"被判定为投影操作畸变残留（协议伪影），本线更正为与并行线一致。宽度问题转移到载体自由度。

## 二、关键发现：转换波的弹性是平方型

查证 conversion_wave 模型（FK 链）：$E = \Sigma[\frac12\dot u^2 + \frac{k}{2}(u_{n+1}-u_n-1)^2 + K(1-\cos 2\pi u_n)]$。两点事实：

其一，弹性项为平方型且自然长度 = 1（相邻格点相位差 = 一个周期 = 2π）：平衡背景 = 均匀缠绕（每键 $\Delta u = 1$），即并行线"扇区极小 = 均匀扭转"的 1D 形态。其二，PN 势（周期 = 1）提供格点锁定。

对比：裸 U(1) 相位场（cos 弹性 + 周期 PN）中 2π 台阶可单键隐藏（$\Delta u = 1$ 时所有能量项识别为同相位，能量约 0），宽度概念无意义；平方弹性惩罚 $\Delta u \ne 1$，位错才有能量与宽度。这是转换波能局域化而裸 U(1) 场不能的机制原因，第三支确认并行线"隐藏扭转"结论。

## 三、复合模型与宽度参数区

粒子 = 均匀缠绕背景（W = 1 扇区极小）上的局域位错（kink：$\Delta u$ 从 1 到 2）。锚核 = PN 势（$\kappa_\phi$ 格点内锁定，钉住位错位置），包层 = 平方弹性（$\kappa_\parallel$，决定宽度）。即 T4 原预言的"离散锚核 + 有限宽度包层"结构，在裸 XY 中不存在（无 PN 势），在 FK 链中存在。

## 四、结论

1. **宽度缺口条件性闭合**：粒子宽度由 $\kappa_\parallel$ 包层提供，$\ell \ge 2$ 参数区存在（$K/k \le 0.02$），与洛伦兹色散兼容；该闭合依赖非紧致弹性（裁决实验确认），体系 cos 弹性下窗口为空，出路为螺旋高度差改写。
2. **粒子复合结构**：电荷核（toric code 层，点状保护）+ 锚核（$\kappa_\phi$ PN 阱，钉位置）+ 包层（$\kappa_\parallel$ 弹性，给宽度）三层拼成完整对象。
3. **两线整合**：并行线"扇区极小 = 均匀扭转离域"是背景（无缺陷的 W = 1 极小），粒子 = 背景上的位错（FK kink）；两线不矛盾，是同一结构的两个层面。
4. **三层分工第五次确认**：拓扑序守电荷、$\kappa_\phi$ 锚核钉位置、$\kappa_\parallel$ 包层给宽度与色散，各司其职。（2026-09-29 更新：钉位的载体现记为内部壁承载绕数，锚核改注质量侧，见《已解决难题总览》第 54 条。）

## 五、弹性身份裁决实验（2026-09-06 后续）

并行线评审指出决定性缺口：宽度机制寄生在平方弹性上，而体系键弹性是 cos 型（紧致），$\cos(\Delta\varphi)$ 对 $\Delta\varphi = 4\pi$ 惩罚为零，尖锐位错在体系哈密顿量里免费，宽度窗口在紧致弹性下为空。裁决实验（`_tools/elastic_identity_test.py`，未固化）：同一初条件（均匀缠绕 + 位错）、同一参数区（r = K/k）、同一宽度定义（弹性超量密度的惯性半径直径），并排测 cos 弹性与平方弹性。

| r = K/k | cos 弹性 $\ell^*$ | cos 弹性 E | 平方弹性 $\ell^*$ | 平方弹性 E |
|---|---|---|---|---|
| 0.0005 | 1.00 | 4.001 | 12.90 | 0.028 |
| 0.005 | 1.00 | 4.010 | 4.06 | 0.090 |
| 0.01 | 1.00 | 4.020 | 2.86 | 0.127 |

| 0.05 | 1.00 | 4.100 | 1.35 | 0.280 |
| 0.1 | 1.00 | 4.200 | 1.13 | 0.406 |

判决：cos 弹性（紧致）下位错塌缩为单键尖锐位错（$\ell^* = 1.00$ 恒等、与 r 无关，能量 = 两个格点的 PN 峰代价 4.0，弹性项对 $\Delta u = 2$ 完全免费）；平方弹性（非紧致）下位错展宽（$\ell^*$ 随 r 从 12.90 到 1.13，$K/k \le 0.02$ 落窗）。**宽度机制 100% 寄生在非紧致弹性上，紧致 cos 弹性下窗口为空**。并行线批评经实测确认。

出路（作者裁决 2026-09-06，经概念澄清修正）：键弹性（格点间同类耦合 $\kappa_\parallel$）的原始形式 = **螺旋高度差（非紧致）**，作者明确裁定，无保留。螺旋阶梯几何定案：相位状态空间 $S^1\times\mathbb{R}$ 中的 ℝ = **法线轴**（复平面圆心处的法线，垂直于复平面），满周闭合时元相子沿法线平移 $l_P$，**法线轴承载空间像素累积**（层数 = 距离，距离归粒 $x^a = l_P n^a$），非紧致且物理真实；相位圆的实轴（复平面内）与法线轴是两个不同的轴，注释 09 的"实轴方向差"（波矢、电磁场）指相位圆实轴方向（波性侧紧致角度差），与法线轴高度差（粒性侧非紧致距离）分工。转换波 u 变量（连续螺旋 + 整数格点钉扎）即 $S^1\times\mathbb{R}$ 的实现，其整数部分 = 沿法线轴的层数（ℝ）、小数部分 = 角度（S¹）。键弹性按法线轴高度差书写（平方型），cos 书写降级为角度部分投影；宽度窗口在体系内打开，复合模型闭合。体系哈密顿量既有 cos 书写的表述调整（cos 为投影/近似的定位）由作者主导基准更新。
