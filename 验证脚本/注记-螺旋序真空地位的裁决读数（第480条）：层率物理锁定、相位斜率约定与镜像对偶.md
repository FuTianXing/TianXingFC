## 摘要

P1-48 登记的二择一（均匀缠绕背景的序参量 $w_0$ 是约定零点还是真实序）在本注记中落到注册泛函上给出判据级读数。核心结果把二择一精细化拆层：相位计数斜率是纯约定（代换恒等，解析级）；层率被 commensurate 锁定到整数（非整数层率高能），整数层率族内局域物理逐位同构；$+w_0$ 与 $-w_0$ 背景物理镜像等价，CPT 冲突在两种读法下都不出现，等价由泛函反演联动保证、明确不由平移保证。层率的全局语义（空间像素累积密度）不可由局域判据裁决，归 P1-48 终裁，其执行入口为 D-b 的边界条件设定。

## 一、要判什么

电子场攻坚计划把「位错是否与量子场论的场激发相容」定位到螺旋序的真空地位一事上：法线轴 $\mathbb{R}$ 非紧致，$w_0 \neq 0$ 无法被连续变换消去，故 $w_0$ 或为约定零点（可恢复读法），或为真实序（破缺读法），一处不定则五项悬空（位错地位、体系相对量子场论的层级、CPT 后果、正反粒子来源、质量机制）。P1-48 档案页登记判据 S1 至 S4，形式已立未执行，本注记为该判据的执行轮。

判据设计对应关系：S1 检验 $w_0$ 的平移轨道与可消去性（背景能量对层率的依赖、整数平移变换、相位计数代换）；S2 检验 $+w_0$ 与 $-w_0$ 背景的等价性（镜像泛函的 kink 能量、宽度与谱）；S3 检验 CPT 映射像（周期边界下平移能否实现 $p \to -p$，等价由什么保证）；S4 检验零背景极限与层率量子化（零能背景的存在域、整数族同构性、色散的层率无关性、$r$ 档位稳健性与极小档离域趋势）。

## 二、模型设定

注册泛函取正稿甲形式，$k_b = 1$ 归一，$r = K/k_b = K$：

$$E[u] = \sum_n \Big[\tfrac{1}{2}\,(u_{n+1}-u_n-w_{\rm ref})^2 + K\,(1-\cos 2\pi u_n)\Big],$$

$u$ 以整圈为单位（$u$ 增一等于指针转满一圈、法线轴升一层），$w_{\rm ref} = 1$ 为注册参考层率。位错求解用偏离量参数化 $v_n = u_n - w_{\rm ref}\,n$，开放链两端固定，过阻尼梯度流松弛（$\eta = 0.01$，收敛判据 $\max|\nabla E| < 10^{-12}$）。主档 $r = 0.005$、$L = 256$；档位稳健性覆盖 $r \in \{0.005, 0.02, 0.1, 0.245\}$；极小档 $r = 10^{-6}$、$L = 2048$ 作离域趋势演示。

冒烟检查：随机位形 $\max|\nabla E| = 0.35$（非零合理），整数参考背景 $\max|\nabla E| < 10^{-12}$（PN 极小与弹性零点同时满足），力的变化性落在操作轴上，判 PASS。

## 三、判据与结果

**S1（$w_0$ 平移轨道与可消去性），3 项全过。**背景族 $u_n = w_0 n$ 的能量扫描给出唯一零能于 $w_0 = 1$（注册层率），实测 $\arg\min = 1.0000$、$E_{\min} = 0$。整数偏离 $w_0 = 1 + m$ 的代价为纯弹性项，逐点符合解析式 $(L-1)m^2/2$（$m = \pm 1$ 给 $127.5$，$m = 2$ 给 $510$），PN 势在整数层率处全零（$< 10^{-9}$）。相位计数斜率代换 $v = u - n$ 给出解析恒等 $E_{(+1)}[v+n] = E_0[v]$（$E_0$ 为平坦参考泛函，随机位形数值差 $0$）：第 479 条与 C1/D 线所用平坦参考泛函与注册泛函经此代换逐位等价（弹性刚度换算因子 $4\pi^2$ 显式化），故计数斜率是纯约定，层率内容藏在代换的 $n$ 中保持每格一层。

**S2（$+w_0$ 与 $-w_0$ 背景等价性），3 项全过。**镜像泛函满足解析恒等 $E_{(-1)}[u] = E_{(+1)}[-u]$（$\cos$ 偶性与平方项符号吸收）。两泛函各自松弛的 kink：能量同为 $0.089781$（闭式 $\frac{4}{\pi}\sqrt{r} = 0.090031$，偏差 $0.28\%$），参与比宽度差 $< 10^{-6}$，Hessian 谱最大差 $9.8\times10^{-15}$。两侧物理逐位镜像等价。

**S3（CPT 映射像），4 项全过。**周期边界 $L = 64$、固定泛函 $E_{(+1)}$：$p = +L$ 背景经平移达零能，$p = -L$ 背景的平移扫描最低能量 $= 128.00 = 2L$（每键弹性 $\frac{1}{2}(2)^2$，PN 项在整数平移处归零），平移不改变 $\Delta u$，无零能路径实现 $p \to -p$。结合 S2 恒等式，读数为：等价由理论反演联动（弹性参考随 CPT 同时翻转）保证，不由动力学位形空间内的平移保证。这回应 P1-48 结论三「等价由哪条边界条件保证须写明」：答案是反演联动，与边界条件无关。

**S4（零背景极限与层率量子化），5 项全过。**其一，零能背景仅整数层率存在：$E_{\rm bg}(1) = 0$、$E_{\rm bg}(0) = 0$，非整数层率（$0.5$、$0.1$、$0.02$）背景能量 $\approx 1.25$ 至 $1.28$（PN 错配，$K L$ 量级），commensurate 锁定成立。其二，整数层率族 $\{1, 0\}$ 的 kink 能量逐位同（$0.089781$）、Hessian 谱逐位同（最大差 $9.8\times10^{-15}$）：绝对层率在整数族内局域不可分辨。其三，背景色散与 $w_{\rm ref}$ 无关：最小本征值实测 $0.197544$，与理论 $(2\pi)^2 K + (\pi/(L-1))^2 = 0.197544$ 匹配（开放链内部点 $N = L-2$ 的精确最小模式修正）。其四，$r$ 档位稳健：镜像等价在 $r \in \{0.02, 0.1, 0.245\}$ 逐位成立；大 $r$ 档（$\xi = 1/(2\pi\sqrt r) < 1$ 格）连续闭式失效，能量自下方趋近单键台阶代价 $0.5$（$0.178 < 0.345 < 0.419$），与连续极限域一致。其五，$r = 10^{-6}$ 档：数值宽度 $289.1$ 格对解析孤子剖面参与比宽度 $288.6$ 格（偏差 $0.2\%$），连续宽度 $\xi = 159.2$ 格，宽度随 $r \to 0$ 发散，与第 479 条定稿档 $\xi = 2.39\times10^{22}$ 格为同族趋势。

## 四、裁决建议（不定案，归作者裁决）

**其一，二择一精细化拆层。**$w_0$ 不是单层二值，判据把它拆成三层。相位计数斜率：纯约定，代换恒等是解析级（S1），可恢复。整数层率选择：commensurate 锁定排除非整数（S4），整数族内局域物理逐位同构（S4 能量、谱、色散），局域可观测量无法分辨绝对层率，约定性在局域意义上成立。层率的全局语义：$w_0 = 0$（无空间像素累积）与 $w_0 = 1$（每格一个像素）的全局图像不同，像素密度是否算可观测由时空语义裁决（$x^a = l_P n^a$ 的格子生成公理），局域判据对此沉默。

**其二，CPT 后果解除。**无论最终取哪种读法，$+w_0$ 与 $-w_0$ 背景物理镜像等价（S2 解析恒等 + S3 数值确认），破缺读法无 CPT 冲突。等价机制已写明：泛函反演联动，非平移。

**其三，对攻坚计划五项裁决表的读数更新。**位错地位：整数族内「零背景自由激发」与「破缺 kink」在局域物理上不可区分，该区分降格为语义层，阶段 2 的 $\hat D$ 构造在两种读法下取同一局域泛函，D-c（手性来源）与 $g = 2$ 判据不受本二择一阻塞。体系相对量子场论的层级：不在本轮射程，维持悬置。正反粒子来源：维持方向不变（路径 A 的 D4 判据或缺陷族符号），镜像等价表明背景对 $\pm$ 符号无偏袒，符号分配仍归算符层。质量机制：维持原状，另受第 479 条驻留判据不满足的压力，独立处置。

**其四，D-b 的判据敏感性读数。**本轮以开放链（kink 求解）与周期边界（S3）双设定给出：解析恒等项（S1-c、S2、S3-c）边界无关；commensurate 锁定与整数族同构对边界不敏感（局域性质）；S3 的平移读数为周期边界特有，无限链下 $p$ 未定义、更无平移路径，有限环面设定未跑。若 D-b 取周期边界或无限链，本轮读数直接适用；若取有限环面，S3 须补跑（判据敏感项，其余判据预期不翻）。

## 六、过程记录（数值教训）

**教训一，对照类判据两侧同错不报错。**Hessian 弹性对角首版误写单键贡献（$1$ 而非 $2$）：梯度正确故松弛与能量读数全对，S2-c 镜像谱对照（两侧同错相消）仍 PASS，仅 S4-c 的理论闭式对照 FAIL 而暴露。教训：理论闭式对照与镜像对照两类判据必须并存，缺一不可。

**教训三，慢模式收敛按谱隙估算。**S4-e 首版斜坡初始化 + $2\times10^5$ 步松弛给出宽度虚大 $2.5$ 倍：最低模式弛豫速率 $\eta \cdot 4\sin^2(\pi/L)$ 下残留约 $9.5\%$，长波分量把参与比宽度摊大。改解析孤子剖面初始化 + $5\times10^4$ 步短程松弛后偏差 $0.2\%$。教训：收敛步数按谱隙估算或用解析剖面初始化，不以固定步数为准。
