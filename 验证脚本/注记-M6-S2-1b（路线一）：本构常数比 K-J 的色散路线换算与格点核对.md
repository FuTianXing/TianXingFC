## 一、验证目标与判据

目标：把 $K/J$（挫折弦每格 onsite 系数与键刚度之比，即弱版模型 $\lambda$ 在物理单位的化身）用色散论文的既有系数写出来，并在格点上核对。

判据（先写期望，再算）：

S2-1b1 色散逐点：三维线性化格点谱对闭式 $\omega^2 = (4/t_P^2)\sum_a\sin^2(k_al_P/2)$ 逐点核对：平面波作用（真正做矩阵向量乘）五点相对偏差 $\le 10^{-12}$；$L = 8$ 全谱集（512 个本征值对理论多重集）最大相对偏差 $\le 10^{-10}$。

S2-1b2 能隙公式：三相位系统线性化后 $\delta$ 模式能隙 $\omega_0^2 = 3\omega_P\kappa_\phi$（四档，相对偏差 $\le 10^{-12}$），$\Phi$ 模式本征值 $\le 10^{-12}$；正交基恒等式 $\sum_{a<b}(\theta^a-\theta^b)^2 = 3(\delta_1^2+\delta_2^2)$（偏差 $\le 10^{-14}$）。

S2-1b3 群速度表：$v_g = \sin k/\omega$（沿 [100]，格点色散）对论文 §8 表的十六点相对偏差 $\le 10^{-3}$。

S2-1b4 换算恒等式：$K/J = 3\kappa_\phi/K_0 = 6\pi\kappa_\phi t_P$（代数恒等 $\le 10^{-15}$）；报告模型惯例下的 $\kappa_\phi t_P$。

## 二、系数定义的出处

色散论文（单位制 $c = l_P = t_P = 1$）从公理 4 哈密顿出发：动能系数 $\hbar\bar t_P/2$（$\bar t_P = t_P/2\pi = 1/\omega_P$），同类键耦合 $K_{ij} = K_0f(\Delta n)$，$K_0 = \bar t_Pc^2/l_P^2 = 1/(2\pi t_P)$，且 $\omega_PK_0 = 1/t_P^2$。

线性化给出 $\omega^2 = 2\omega_PK_0\sum_a(1-\cos k_al_P) = (4/t_P^2)\sum_a\sin^2(k_al_P/2)$，带宽 $\omega_{\max} = 2\sqrt{3}/t_P$。

异类耦合 $H_{\text{het}} = -\hbar\kappa_\phi\sum_p\sum_{a<b}\cos(\theta_p^a-\theta_p^b)$ 在正交基 $(\Phi, \delta_1, \delta_2)$ 下给 $\delta$ 模式能隙 $\omega_0 = \sqrt{3\omega_P\kappa_\phi}$。

弹性侧的定义取既有裁决：键弹性的原始形式为螺旋高度差（法线轴非紧致差）的平方型，即键通道的同一 $K_0$ 项；onsite（圆心与回折约束）通道即 $\delta$ 模式所在通道。本材料不重推弹性本构，只把两侧的系数对齐。

## 四、解读

其一，换算恒等式成立：$K/J = 3\kappa_\phi/K_0 = 6\pi\kappa_\phi t_P$。含义是把本构比的取数归结为**无量纲组合 $\kappa_\phi t_P$ 的取数**：$K/J$ 与 $\kappa_\phi t_P$ 成线性正比（斜率 $6\pi$）。若上游把 $\kappa_\phi$ 的绝对标度定出，$K/J$ 随式落定。

其二，与模型惯例的接口：D1、D2、弱版与 S2-1 均取 $\lambda/J = 1$（满幅记录）；代回恒等式得 $\kappa_\phi t_P = 1/(6\pi) = 0.053052$。这是一个可对照的无量纲值：上游若给不同值，$K/J$ 线性跟随，且判定方向对 $K/J$ 的精度要求为量级级（$\Gamma_c \propto (K/J)^{0.88}$，方向要到 $10^{-40}$ 才翻转）。

其三，识别状态：本材料核对的是论文自身的结构（色散、能隙、群速度），把 onsite 通道与异类能隙对齐属**待确认**项；若确认，则本线的 S2-1b（耦合系数物理值）与 S1-3（$\kappa_\phi$ 上限与单格点容量）指向同一上游项 P1-2。

其四，论文 §8 表的独立复现顺带核对了群速度公式：$v_g = \sin k/\sqrt{4\sin^2(k/2)+\omega_0^2}$（格点式），它与连续式 $c^2k/\sqrt{c^2k^2+\omega_0^2}$ 的差别在高 k 端（表值用格点式）。

其五，能隙与带宽之比给出另一个可对照量：$\kappa_\phi t_P = 1/(6\pi)$ 时 $\omega_0/\omega_{\max} = 0.2803$。

## 六、诚实边界

其一，识别未裁：onsite 系数 <-> 异类能隙的对齐是路线一的假设，本材料只核对论文结构，不判定该识别。

其二，$\kappa_\phi t_P$ 的值仍待上游（P1-2）：本材料只给「$K/J$ 与 $\kappa_\phi t_P$ 的线性关系」与模型惯例下的反推值。

其三，单位制与无量纲性：全部核对在 $c = l_P = t_P = 1$ 下；$K/J$ 与 $\kappa_\phi t_P$ 均为无量纲组合，结论对单位制不敏感，但换算系数 $6\pi$ 依赖 $K_0 = 1/(2\pi t_P)$ 的定义式（论文原文）。

其四，弹性侧只对齐不同推：弹性本构路线（路线二）与时钟/摆程路线（路线三）未执行。

其五，本材料与格点动力学模型的对应：弱版模型的 $\lambda$ 作用于记录（交错调制分量），本材料的 onsite 通道取 $\delta$ 模式（异类相位差）；两者的对齐即识别项本身。
