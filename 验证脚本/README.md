## 一、脚本清单

### 1. `minimal_verification_frame_tilt.py`（标量版，2026-09-05）

**对应注记**：`验证脚本/注记-碰撞写入标架联络的最小验证.md`（P1-32 第三轮）

**验证内容**：方向 6 的核心主张，碰撞写入 + 邻居接力的稳态是离散泊松格林函数。

| 判据 | 结果 |
|---|---|
| 一维写入动力学收敛 | 稳态 = $(2w/\alpha) \times$ $s=1$ 格林函数，相对误差 $1.8\times10^{-11}$ |
| 三维远场 $1/r$ 系数 | $A = 0.07959257$ 对理论 $1/(4\pi) = 0.07957747$，偏差 $1.9\times10^{-4}$ |
| 离散高斯定律与 $4\pi$ | 格面通量恒等源强（机器精度、半径无关）；$4\pi$ 由立体角换算自动出现 |
| 修正标度 | 偏差 $\sim (l_P/r)^2$，与《论引力机制的微观起源》§2.3 声明一致 |
| 幅度线性 | $\theta(3s) = 3\theta(s)$ 至 $10^{-15}$ |

耗时约 1 分钟（含 CG 求解）。

### 2. `minimal_verification_so3_link.py`（SO(3) 链接变量版，2026-09-06）

**对应注记**：`验证脚本/注记-SO3链接变量版最小验证：路径B规则1-7的数值检验.md`（P1-32 第四轮）

**验证内容**：路径 B 的规则 1-7 几何机制层（精确 SO(3) 矩阵运算，非小角近似）。

| 判据 | 结果 |
|---|---|
| 真空平坦性（规则 7） | 常数标架下全部格面转角 $3.5\times10^{-32}$ |
| 纯规范陷阱 | 光滑单值标架任意转角幅度（0.05 至 0.95 rad）下格面 holonomy 恒为 I：曲率是拓扑性，与幅度无关 |
| 非可积判别式 | 非可积链接格面角随强度线性增长（$\kappa^{1.00}$）；判别式是可积性 |
| Volterra 亏损（规则 5-6） | 分支切割亏损恰为 Frank 矢量（12 位精度），绕环半径无关（锥面签名）；双缺陷可加且局域 |
| $\epsilon_h \propto m$ 线性 | 残差 $\le 2\times10^{-16}$，√m 陷阱在机制中不存在 |
| 分量离散泊松 | 三分量拟合偏差 $1.9\times10^{-4}$，格面通量恒等 $\Omega_i$ |
| 非阿贝尔压低 | 非平行双源下精确链接转角对线性化的偏差 $\sim r^{-10}$（线性项 $r^{-2}$） |
| 平滑/奇异分解 | 平滑响应场格面曲率严格为零：远场不复制源，无重复计数 |

**边界**：以 $F \in SO(3)$ 为输入，不触及 B1 命门（P1-32 存档登记：$\kappa_\phi$ 哈密顿量不导出 $F \in SO(3)$），命门结论不受本脚本影响。耗时约 2 分钟（六次 CG）。

**对应注记**：`验证脚本/注记-3+1雏形验证：时间向写入铰链补全牛顿极限.md`（P1-32 第五轮）

**验证内容**：Flag 1（纯空间构造缺时间向 sector）的补全，写入过程作为时间维演化。

## 二、三轮验证合起来的结论链

标量稳态（脚本 1）：写入过程收敛到离散泊松格林函数，$4\pi$ 自动涌现。SO(3) 几何机制（脚本 2）：格面联络层健全，绑定能作源为机制必要（光滑标架纯规范），亏损 $\propto m$ 线性。3+1 补全（脚本 3）：时间向写入节拍提供牛顿 sector，空间标架保持平坦。**合并图像：空间 Regge 几何（B1 存档的数学层，两路径共享）+ 时间向写入节拍（方向 6，主推候选）= 3+1 静态弱场引力雏形**；瞬时源决定、$c$ 传播、潮汐无迹三个相对论结构在机制级同时实现。

## 三、边界（脚本不验证的内容）

其一，本体层衔接：写入幅度 $w$ 与 $m/m_P$ 及 $\kappa_\phi$ 的定量对应、传导刚度身份（数值取单位刚度）、倾斜方向结构（吸引性指向来源）。其二，B1 命门（$\kappa_\phi$ 哈密顿量与 $F \in SO(3)$ 约束的关系），脚本 2 以该约束为输入。其三，空间 sector 的后牛顿激活（$v \ne 0$、时空混合分量）。其四，光子源项（P1-24）。其五，写入幅度与 $8\pi G m$ 的归一化（当前单位制）。
