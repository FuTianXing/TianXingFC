## 一、问题与口径

E1 至 E3 交付了三维源项的横截面积分装配，量纲是模型内单位。本判据把装配换到物理单位。量纲桥线已把缺口定位到第三段：模型能量单位对 $m_Pc^2$ 的比是一个纯数因子，其余段已给定或属模型约定。本判据的结论形态据此设定为"装配侧只含一个桥因子"。

换算字典（模型侧格距 $l_P = 1$、摆程 $t_P = 1$、$c = 1$，能量单位记为 $\epsilon\,m_Pc^2$；带帽为模型内读数）：
$$x = l_P\hat x,\quad t = t_P\hat t,\quad \rho = \epsilon\frac{m_Pc^2}{l_P^3}\hat\rho,\quad j = \epsilon\frac{m_Pc^2}{l_P^3c}\hat j,\quad T^{ij} = \epsilon\frac{m_Pc^2}{l_P^3}\hat T^{ij}$$

口径两条。其一，桥因子 $\epsilon$ 是唯一未知，本判据不导出它（属量纲桥线）。其二，物理侧取 $h_{00} = 2\Phi/c^2$ 与 $h_{00} = 2\theta$，故 $\theta = \Phi/c^2$，泊松式为 $\nabla^2\theta = 4\pi G\rho_m/c^2$（$\rho_m$ 为质量密度）。

## 三、解读

其一，**四个分量共用同一因子**。桥因子加倍时四个分量同倍放大（比值精确为 $2$），说明装配侧没有隐藏的第二座桥：长度、时间、能量三个单位一旦由 $l_P$、$t_P$、$\epsilon m_Pc^2$ 定下，四个分量的量纲就全部确定了。

其二，**可观测量比值与桥因子无关**。$j/\rho = v$、$T^{xx}/\rho = v^2$、$T^{yy}/\rho = -1/\gamma^2$ 三式都只用模型内读数即可核对，$\epsilon$ 在比值中抵消。这与量纲桥计划的判断一致：模型内结论用比值表述，比值不依赖桥。

其三，**单位链闭合**。$G/(c^2l_P)m_P = 1$ 与 $Gm_P/(l_Pc^2) = 1$ 在定义式（$l_P = \sqrt{\hbar G/c^3}$、$m_P = \sqrt{\hbar c/G}$）下机器级成立，$t_P = l_P/c$ 精确。把两式代入泊松式即得模型单位形式 $\nabla^2_{\rm model}\theta = 4\pi\epsilon\hat\rho$，$\epsilon = 1$ 时系数恰为 $4\pi$。

其四，**与 BH7 质量映射链自洽**。壁的静质量由模型内的 $\int\hat\rho$ 给出（$\epsilon = 1$ 档为 $62.48\,m_P$），对应的 $r_s = 124.96\,l_P$，且 $\theta(l_P) = M/m_P$ 与 BH7 的线性律一致。

其五，**缺口的准确位置**。装配侧需要且只需要 $\epsilon$ 这一个数；它的导出属量纲桥线（M 线），本判据不改变那边的缺口定位。

## 四、严格程度声明

E4-1 为齐次性核对（数值，偏差 $0$）；E4-2 为恒等式核对（三式与模型内读数，符号与因子逐项）；E4-3 为单位链恒等式（定义式下机器级）；E4-4 为链自洽核对（与 BH7 映射的代数关系）；E4-5 为登记。

## 五、边界声明

- 验证：换算字典、四个分量对桥因子的一次齐次性、比值与桥因子的无关性、单位链的两个恒等式、与质量映射链的自洽。
- 不验证（登记）：桥因子 $\epsilon$ 的数值导出（属量纲桥线）；观测阈值与绝对密度（依赖 $\epsilon$ 的物理值）；强非线性与量子层。
- 一条口径：E4-4 的 $M/m_P$ 取 $\epsilon = 1$ 档，物理读数按 $\epsilon$ 线性缩放。

## 六、过程记录

两处期望写错并订正。其一，$T^{xx}/\rho$ 的期望首版写成 $\gamma^2v^2$，实为 $v^2$：E2 与 E3 的 $\gamma^2v^2$ 是**绝对值**（$T^{xx} = \gamma^2v^2f'^2$），比值形式掉一个 $\gamma^2$（$T^{00} = \gamma^2f'^2$）。其二，闭合量首版写成 $\rho_*l_P^2G/c^2$，该组合等于 $c^2$；正确的无量纲组合是 $Gm_P/(l_Pc^2)$。两处都在判据实现阶段暴露，读数本身未受影响。
