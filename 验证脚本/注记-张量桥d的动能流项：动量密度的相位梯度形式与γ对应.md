## 二、模型与协议

FK 链 $E = \Sigma[\frac12\dot u^2 + \frac{k}{2}(u_{n+1}-u_n-1)^2 + K(1-\cos 2\pi u_n)]$，$k = 1$，$c_s = 1$，$N = 1400$，$dt = 0.01$，窗口半径 $W = 30$，缠绕守恒边界。

协议对齐 [[注记-相对论色散完整验证：动量扇区与洛伦兹不变量]]：静止剖面 $n + \frac{2}{\pi}\arctan e^{(n-x_0)/\ell}$ 弛豫，初速度场沿超额相位梯度方向 $v = -v_0\partial_n\theta$（$\theta = u - n$），中段线性拟合测速，尾段窗口平均测能量与动量。

判据区：主判据区 $K = 0.005$（$\ell = 2.25$ 格距），窄 kink 对照 $K = 0.02$（$\ell = 1.13$）。约定 $\theta_x$ 取中心差分（盒端安全口径），$P = -\Sigma\dot u_n\theta_{x,n}$（右移为正），$M_{\rm zero} = \Sigma\theta_x^2$。对照形式：原坡形 $T = \dot u u_x$、刚性拖动 $T = v u_x^2$。

### 动量-质量闭合与 γ 对应

$P_W = \gamma M_{\rm zero}v$ 偏差 1.00% 至 1.15%，与既有色散验证的 $M_P/M_{\rm zero} = 1.014$ 同向。换静能口径 $P_W = \gamma E_{\rm rest}v$，偏差降到 0.01% 至 0.14%。

两口径之差即位力比 $E_{\rm rest}/M_{\rm zero} = 1.0100$；连续极限下 $M_{\rm zero} = E_{\rm rest}$ 成立（扭曲解的位力恒等式）。

$\gamma$ 塌缩：$E_W = s\,\gamma E_{\rm rest}$ 的 $s = 1.0005$；不变量 $R = (E^2 - P^2)/E_{\rm rest}^2$ 全档为 1.0000、1.0001、1.0005、1.0028。这是 (d) 分段判据「γ 增强的写入幅度对应 $T^{00}$ 的洛伦兹变换」在流分量侧的模型级对应。

### 对照形式的判负结构

| 形式 | 积分 | 对 $P_W$ 的超量因子 |
|---|---|---|
| $T^{0i}_n = \dot u_n\theta_{x,n}$（判定值） | $M_{\rm zero}v$ | $1$ |
| $T = \dot u_n u_{x,n}$（原坡形） | $(M_{\rm zero} + 1)v$ | 12.27 至 11.26（预期 12.24 至 11.47） |
| $T = v u_{x,n}^2$（窗口刚性拖动） | 窗口内 $\Sigma u_x^2 v$ | 643 至 691 |
| $T = v u_{x,n}^2$（整链刚性拖动） | $\Sigma u_x^2 v$ | $1.45\times10^4$ 至 $1.56\times10^4$ |

原坡形的超量核对到 $v\Sigma_{\rm win}\theta_x$（偏差 0.34% 至 1.33%）：多算的是被搬运的绕数台阶。kink 每单位时间搬运 1 层，额外动量项为 $v$ 乘台阶总量。

含义：动能流只由超额相位梯度承载；均匀缠绕背景在流通道里是惰性的（远场 $\theta_x = 0$）。

### 首轮失败根因（判负记录）

同日早前一版草案（boost 沿 $u_x$、动量取原始坡形、窄 kink $K = 0.02$）判据 K1、K2 失败：动量漂移 126% 至 238%，$P/(v_{\rm meas}I_2)$ 偏差 1198% 至 5184%。

本轮把该初条件放进锚定协议复跑。boost 沿 $u_x$ 等于把整链当运动质量，注入能量 $\frac12 v^2\Sigma u_x^2 = 7.0104$，是 θ 方向注入（$\frac12 v^2M_{\rm zero} = 4.44\times10^{-4}$）的 15773 倍，实测与解析预测一致到 0.000%。

该初条件激起有隙滑移模（$\omega^2 = 4\pi^2K$）与边界输运，核心读数失真：$v = 0.256$、$E_W = 0.4766$（静能 0.0898 的 5.3 倍）、原坡形动量 2.2427（真实量级 0.0565）。教训两条：初条件必须沿超额相位梯度方向（该方向不拖动均匀缠绕背景）；动量口径必须用 $\theta_x$。

### 窄 kink 退化（读数）

$K = 0.02$（$\ell = 1.13$ 格距）：轮廓加权偏差升到 10.11% 与 12.77%；$P/(\gamma E_{\rm rest}v)$ 在 $v_0 = 0.10$ 为 0.9985，$v_0 = 0.20$ 时落点速度降到 0.1478（损失 26%），该口径退化到 0.9128。与既有宽度纪律一致：百分位闭合的窗口是 $\ell \gtrsim 2$ 格距。

### 与 (d) 其它两项的接口

静能密度、势能密度与相位梯度平方三者在读数上同轮廓（与 θ² 的重叠分别为 0.99996、0.99983 与 0.99988），连续 SG 扭结下势能密度与 $\theta_x^2$ 有严格同形关系（$\sin(2\arctan e^\xi) = {\rm sech}\,\xi$ 的平方）。

动量系数的判定因此只能落在积分系数上：$\int\theta_x^2 = M_{\rm zero} = E_{\rm rest}$（位力），而 $\int V = E_{\rm pot} = E_{\rm rest}/2$，相差整倍 2。W4-2 提示（静态梯度能在 $T^{00}$ 中的归属）在流侧的对应读数：动量系数的空间分布与梯度能密度同轮廓，积分由位力与静能锁定。

## 五、边界声明

本注记验证一维 FK 链上动量密度的场侧形式、积分系数与 γ 对应，两处对照形式的超量机制，首轮失败根因。

不验证：三维复合位错形态下的流分量（门控 C1）；复场 $T^{0i}$ 的振幅支 $2\dot A A_x$（本模型为纯相位扇区）；$T^{00}$ 完整场侧表达式与应力项（(d) 剩余两项）；连续极限外推与 $c_s$-$c$ 同一化。

## 六、过程记录（三处修正）

**其一，初条件修正（boost 方向）。** 早前一版草案的 boost 取 $v = -v_0\partial_n u$，把均匀缠绕背景一起拖动，激起 $\omega^2 = 4\pi^2K$ 的有隙滑移模；锚定协议用的是 $v = -v_0\partial_n\theta$。两方向的注入能量比 $\Sigma u_x^2/M_{\rm zero} = 15773$ 即失败的量级。

**其二，实现修正（盒端环绕伪值）。** 第一版轮廓读数用 np.roll 中心差分的全域版本，两端点分别沾染 $u_0$ 与 $u_{N-1}$ 的环绕值（盒端 $\theta_x \approx \mp 700$），峰值被劫持，核心掩码落空，加权偏差假读为 100%、重叠为 NaN。修正为盒端安全口径（np.gradient）并在窗口内取掩码；窗口动量 $P_W$ 不受影响（其掩码本就排除盒端）。

**其三，判据修正（超量预期的参照量与 γ 因子）。** 超量容差初版写在 $P$ 上（1% $P$），而超量本身是台阶滑移项 $v\Sigma_{\rm win}\theta_x$（比 $P$ 大 $1/M$ 量级），容差应写在滑移项上；预期因子初版漏掉 γ（$1 + 1/M_{\rm zero}$ 对 $1 + 1/(\gamma M_{\rm zero})$）。修正后超量核到 0.34% 至 1.33%，因子核到 0.3% 至 1.8%。
