## 一、问题与口径

$(u,v)$ 轮廓只有四个独立函数，可分解到两个波矢的模式：$k_+ = (2,-1,0,-1)$ 对应 $\cos(u+v)$，$k_- = (0,1,0,-1)$ 对应 $\cos(u-v)$。对 $h_{\mu\nu} = \varepsilon_{\mu\nu}\cos(kx)$，线性化爱因斯坦张量有精确代数式

$$G^{(1)}_{\mu\nu} = \cos(kx)\,\tfrac12\big[k^2\bar\varepsilon_{\mu\nu} - k_\mu(k\bar\varepsilon)_\nu - k_\nu(k\bar\varepsilon)_\mu + \eta_{\mu\nu}\,k\bar\varepsilon k\big],$$
其中 $\bar\varepsilon = \varepsilon - \frac12\eta\,\mathrm{tr}\,\varepsilon$。用它对六场支撑逐模式求响应、解线性方程，得到闭式系数，再用 4D 机器核验。

## 三、解读

其一，**解析响应与机器逐位一致**。$\Pi(k)\varepsilon$ 的代数式与 4D 机器在非零例上一致到 $10^{-8}$（$k_-$ 的 $H_{xx}$：$0.18118$ 对 $0.18118$）。附带一个小发现：$\cos(u+v)$ 型的 $h_{00}$ 与 $g_{0z}$ 扰动线性响应恰为零（$\Pi$ 给零、机器给 $10^{-15}$），即这两个方向是线性不可见的组合。

其二，**残差只有余弦型模式**。七个分量的 $C_\pm$ 系数最大 $8.8\times10^{-5}$，$S_\pm$ 系数 $\le 1.5\times10^{-6}$（相对 $1.7\%$，与三阶污染一致）。这与二阶张量的乘积结构相符：$h_1 h_2$ 与 $h_1'h_2'$ 只出余弦型。

其三，**闭式系数**。每个模式只有一支系数（六场里 $H_{yy}$ 在 $k_-$ 模式为零），$k_+$ 与 $k_-$ 的模式结构在 $x \leftrightarrow z$、$u \leftrightarrow v$ 交换下自洽（$N_x = N_z$、$H_{xx} = H_{zz}$）。小幅度复核给干净有理数：$k_+$ 为 $(-5/36, -5/18, -5/18, +5/8, -1, +5/8)$，$k_-$ 为 $(-1/4, +1/8, +1/8, -5/8, 0, -5/8)$（单位 $ab$）。

其四，**机器核验与地板**。闭式修正加入后交叉部降 $26$ 至 $55$ 倍，残余 $3$ 至 $4\times10^{-6}$ 即 $ab$ 的 $2\%$，与三阶污染（$a = 10^{-2}$ 给 $1\%$ 级，加余项）相符：二阶层面的闭式解完成，下一阶由三阶项接管。

其五，**口径订正**（详见第六节）：第 19、20 轮的"独立规范核测量"读数（$3.4\times10^{-7}$、$3.2\times10^{-10}$）来自三点拟合读常数项的伪影，作废；修正口径给 $10^{-7}$ 级（噪声），结论不变。
