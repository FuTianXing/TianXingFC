## 一、问题与口径

[[观测者响应与洛伦兹涌现：束缚态时钟的时间膨胀与长度收缩推导|观测者响应与洛伦兹涌现]]§6 的残差与频率偏差里混着两项：晶格离散修正，与"势阱以固定宽度平移、未按 $\sigma/\gamma$ 收缩"的 boost 失配。评审为此立了一条 B 级（正文已注明混合未分离，但未给量）。本轮把三项分开测：

- **混合**：晶格方程 + 固定宽度势阱（原文装置，用于回归）；
- **纯晶格**：晶格方程 + 按 $\sigma/\gamma$ 收缩的势阱；
- **纯失配**：连续方程 + 固定宽度势阱。

纯失配项有解析形式：boost 解满足连续 KG 方程当且仅当势阱同步收缩，故失配残差等于 $\Vert(U_{\rm 固定}-U_{\rm 收缩})\varphi\Vert/\Vert\varphi\Vert$。频率检验 B 在两种装置下各跑一遍（速度 Verlet，$dt = 0.02$，$T = 800\,t_P$），频率用正弦最小二乘拟合提取（比 FFT 取峰稳）。

## 三、解读

其一，**装置可复现**。原文未给势阱深度，本轮按原文的束缚频率反解：$\sigma = 10$ 取 $U_0 = 0.699955$、$\sigma = 20$ 取 $U_0 = 0.380017$，两个 $\omega_b$ 都回到原文读数（差 $10^{-13}$），$v = 0$ 残差为机器零（束缚态是离散方程精确解）✓。混合档残差（$2.4\times10^{-3}$、$2.0\times10^{-2}$、$9.7\times10^{-2}$）与原文表（$3.0\times10^{-3}$、$2.0\times10^{-2}$、$9.2\times10^{-2}$）同量级，回归成立。

其二，**两项的相对大小随速度反转**。低 $v$ 档两者可比（$\sigma = 10$、$v = 0.3$：晶格 $1.85\times10^{-3}$ 对失配 $2.40\times10^{-3}$）；高 $v$ 档晶格项压倒失配（$\sigma = 20$、$v = 0.8$：$1.40\times10^{-1}$ 对 $1.15\times10^{-2}$，相差十二倍）。原因是两项的标度不同：失配随 $v$ 增长接近线性（阱宽变化 $\sim v^2/2$），晶格项按 $(k_{\rm mod}l_P)^2$ 走，高 $v$ 时涨得更快。

其三，**频率读数：低 $v$ 档的"精度"有一半是装置假象**。本轮固定阱口径下 $\sigma = 20$、$v = 0.3$ 的偏差为 $0.126\%$，收缩阱后只剩 $0.054\%$，即约六成来自势阱未收缩这一 setup 失配（原文的 $0.07\%$ 用 FFT 取峰，与本轮固定阱口径的 $0.126\%$ 属不同提取方法，见其五）。$v = 0.6$ 与 $0.8$ 档失配只占约 $17\%$ 与 $16\%$，晶格项主导。也就是说：原文"修正由相位调制主导、与晶格色散非线性同源"的方向是对的，但低 $v$ 档的数字需要按收缩阱口径重报。

其四，**物理读数比原文更小**。按收缩阱（物理上正确的 boost 装置）：$v = 0.3$ 偏差 $0.054\%$、$v = 0.6$ 为 $1.310\%$、$v = 0.8$ 为 $7.853\%$。时间膨胀 $\omega = \omega_b/\gamma$ 在低能层的涌现精度因此比原文所报略好。

其五，**与原文数值的差异一处如实登记**。原文 $\sigma = 20$、$v = 0.6$ 报 $6.3\%$，本轮同装置给 $1.575\%$。差异不在物理而在提取口径：原文用 FFT 取峰（记录长度 $800$ 给频率分辨率约 $1.3\times10^{-3}$，在 $\omega\approx0.64$ 上是 $0.2\%$ 量级，不足以解释全部差异），本轮用正弦最小二乘拟合。两口径同向（偏差随 $v$ 增大），量级有别，登记备案。

## 五、边界声明

- 验证：三项残差的分离、两装置频率偏差的对照、装置参数的反解与回归。
- 不验证（登记）：三维推广（本轮一维）；失配项的解析表达式在一般势阱下的推广（本轮用高斯阱，且用连续方程给失配项）；$v > 0.8$ 档（晶格项已进入强非线性，拟合残余上升）。
- 一条可复用规则（供后续模拟遵守）：任何"运动观测者"的数值模拟必须把观测者自己的势阱或束缚结构按 $\sigma/\gamma$ 同步收缩，否则测得的"时间膨胀精度"会随 $v$ 以非物理方式漂移；本轮实测低 $v$ 档约六成偏差来自该失配。
- 一条口径：本轮的"物理读数"指势阱同步收缩的装置；现实观测者由自身束缚结构构成，其势阱如何随运动变化属 O5（自指闭合）登记项。

## 六、过程记录

三处器械订正，都由读数当场抓出。其一，束缚态搜索首版用"围绕 $\omega_{\rm gap}^2/2$ 的平移"求特征值，深阱档（$\sigma = 10$）会找到非基态，$U_0$ 拟合撞到天花板并给出错误的 $\omega_b$；改为求最小代数特征值后两档都回到原文读数。

其二，连续方程的 $\partial_x^2\varphi$ 首版末项符号写反，纯失配项被高估一个量级（$0.127$ 对正确值 $\sim0.01$）；按解析式 $\partial_x^2\varphi = \gamma^2F''\cos\theta + 2\gamma^2v\omega_bF'\sin\theta - (\gamma v\omega_b)^2F\cos\theta$ 修正后与"阱形差 $\times$ 场"的估计一致。

其三，频率提取首版用 FFT 取峰，两装置给出相同的错误读数（$-84\%$）；改为正弦最小二乘拟合后两装置分开，且与 $\omega_b/\gamma$ 的偏差落到 $0.05\%$ 至 $8\%$ 区间。
