## 二、模型与协议

模型为定向口径 $Z_N$ toric code 的三维版（星项六键出 $+1$ 入 $-1$；面项四键逆时针环绕；$n = 3L^3$ 条边）。

**简并**用稳定子秩公式（精确，无需对角化）：$\deg = N^{\,n - r_A - r_B}$，$r_A$ 为星矩阵的 $\mathrm{GF}(N)$ 秩、$r_B$ 为面矩阵的秩。推导要点：基态投影的迹 $= N^{-(V_a+F)}\Sigma_{a,b}\mathrm{tr}(\Pi A^a\Pi B^b) = N^{\,n-r_A-r_B}$（迹非零要求 $X$ 支撑与 $Z$ 支撑同时为零，计数给 $N^{V_a-r_A}\cdot N^{F-r_B}$）。

**局域平凡性**用稳定子判据（精确，非抽样）：$X$ 型局域算子（边集 $S$ 上的 $X$ 乘积）与全部面项对易的条件是"面偶"（$\Sigma t\cdot S \equiv 0$），与全部星项自动对易；$Z$ 型条件对称（"星偶"）。对易时：压缩为稳定子乘积（标量）或非平凡逻辑（$S$ 不在稳定子张成内）；不对易时：压缩为零。区域逐一全枚举（含 $Z_N$ 幂次）。

## 三、主要读数

### 简并的指数结构（S3D-1）

三维：$\deg = N^3$，$L = 2$ 与 $L = 3$ 一致（$N = 2$ 给 $8$，$N = 3$ 给 $27$）。秩读数：$L = 2$ 时 $n = 24$、$r_A = 7$、$r_B = 14$；$L = 3$ 时 $n = 81$、$r_A = 26$、$r_B = 52$，两者指数同为 $n - r_A - r_B = 3$。

二维交叉核对：$\deg = N^2$（$N = 2$ 给 $4$，$N = 3$ 给 $9$）。统一的写法：$\deg = N^{\,b_1}$（二维 $b_1 = 2$，三维 $b_1 = 3$）。三维的荷结构与二维同型，指数由一阶贝蒂数给出。

### 局域算子分类与最小支撑（S3D-3）

$L = 3$（及 $Z_3$、$L = 3$）：面区（4 边）、星区（6 边）、角区（3 边）上全部局域算子平凡（两条通道计数均为零）。$L = 2$：面区与角区全平凡；星区出现 $Z$ 型非平凡 7 个，恰为三条 2 边完整环及其两两、三者乘积（$2^3 - 1$）；$Z_3$ 同区给 124（读数）。

最小非平凡支撑：$Z$ 型 $= L$（$L = 2$ 的 2 边环、$L = 3$ 的 3 边环）；$X$ 型 $= L^2$（$L = 2$ 的 4 边膜、$L = 3$ 的 9 边膜）。三维的"要动荷的最小代价"因此有一张两面清单：环版 $L$ 条边，膜版 $L^2$ 条边；二维轮"最小支撑 $= L$"的读数在三维对 $Z$ 型原样成立。

## 四、严格程度声明

全部读数为组合精确事实（有限域线性代数与有限枚举）：简并公式为稳定子秩的闭式，区域分类为全枚举（非抽样）。"不交则零压缩、对易则为标量或逻辑"是稳定子码的标准判据（此处以解析判据使用，与 Q5 二维轮的数值压缩同构）。$L = 2$ 的星区计数 $2^3-1$ 与 T3D-5 的区域分类修正一致。

## 五、边界声明

本注记验证 3-环面 toric code（$L = 2, 3$；$N = 2, 3$）的简并指数与局域算子分类。

不验证：显式对角化的能谱与能隙（本轮的"谱"限于简并的指数结构）；三维带边界的版本；更大 $N$ 与 $L$ 的枚举；体系实体映射；U(1) 版本；膜版的最小性在 $L \ge 3$ 只给构造性上界（$L^2$ 的膜存在），未证"无更轻者"。

## 六、过程记录（两处修正）

**其一，简并推演中的核空间错误。** 推演 $r_B$ 时先写成"$r_B = $ 面数 $-$ $b_2$"（$b_2 = 3$ 给 $r_B = 21$），代回得 $2^{24-7-21} = 2^{-4}$，负简并立即暴露矛盾。正确做法是核空间含 3-链的像：$\dim\ker\partial_2 = b_2 + \mathrm{rank}\,\partial_3 = 3 + 7 = 10$，故 $r_B = 14$，代回得 $2^3 = 8$ 与数值一致。教训：贝蒂数并不等于核空间维数；小系统中"零与负数的荒谬值"是排查错了哪一环的最快信号。

**其二，S3D-3a 的区域分类修正。** 首版把 $L = 2$ 的星区列入"平凡区"，实测 $Z$ 型非平凡 7 个。核查后确认星区六条边恰好含全部三条 2 边完整环，$2^3-1 = 7$ 与乘积结构一致，且与前一注记 T3D-5 的修正结论（"星区含完整环当且仅当 $L = 2$"）逐字吻合。教训：区域分类必须与 T3D-5 的判据同步，两处不能各写一套。
