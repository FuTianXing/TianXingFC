## 一、判据与输入

判据（先写期望，再算）：

S2a 单位链锚点：换算链（$h = l_P\theta$、满偏 $= 1 = 180$ 度、拍 $= t_P$）下，N5 对齐恒等式 $\theta(r_s) = 1/2$ 对四个量级跨度的质量成立（偏差 $\le 10^{-3}$）；注入几何恒等式 $6N_c = 4\pi$（$N_c = 2\pi/3$）逐位成立。

S2b 注入量级（报告）：单次碰撞写入 $\delta\theta = m/m_P$；源强 $s_{eff} = 4\pi m/m_P$（每拍）。

S2c 斜坡速率（报告）：坍缩驱动下视界处记录的增长速率 $\Gamma = (M/m_P)(l_P/r_s)^2$（每拍）。

S2d 交叉判定：$\Gamma < \Gamma_c$ 即耦合先触发；以 D2 的四个门槛（一维均匀、三维均匀、一维漏斗、三维漏斗探路）比较。

S2e 噪声底口径（报告）：取单次碰撞写入量为噪声底（$\epsilon_0 = m/m_P$ 量级），给出门槛移动。

输入全部取自既有定案材料（写入动力学与固定点条件、$s_{eff} = 6w_{eff}/\alpha$、每拍注入 $\delta\theta = m/m_P$、拍 $= t_P$、$c = l_P/t_P$）。

## 二、结果

判据 3 项全过（运行 < 1 秒）。要点如下。

其一（S2a）：$\theta(r_s) = 0.500000071178$，对核子、$1$ 克、地球、太阳四个质量（跨约 $57$ 个数量级）一致，偏差 $7.1\times10^{-8}$（来源为常数精度）；$6N_c - 4\pi = 0$（$N_c = 2.094395$）。单位链自洽。

其二（S2b）：单次碰撞写入 $\delta\theta = 7.685\times10^{-20}$；源强 $s_{eff} = 9.657\times10^{-19}$（每拍）。

其三（S2c、S2d）：坍缩驱动的斜坡速率为 $\Gamma = (M/m_P)(l_P/r_s)^2$（每拍）：核子 $3.25\times10^{18}$、$1$ 克 $5.44\times10^{-6}$、地球 $9.11\times10^{-34}$、太阳 $2.74\times10^{-39}$、$10$ 太阳质量 $2.74\times10^{-40}$。

太阳质量档对四个门槛的比值分别为 $7.7\times10^{-38}$、$1.3\times10^{-37}$、$2.1\times10^{-36}$、$1.8\times10^{-36}$，全部远小于 $1$，即 $\Gamma \ll \Gamma_c$，耦合先触发。

其四（触发时刻）：取漏斗型生长率（$k = 0.018$，由 D2 的一维漏斗 $I$ 标定），触发时刻 $t_* = 5.3\times10^{20}$ 拍 $= 2.9\times10^{-23}$ 秒；换成新噪声底口径（S2e）为 $1.3\times10^{21}$ 拍 $= 7.2\times10^{-23}$ 秒。对照坍缩时标（毫秒级）约 $1.9\times10^{40}$ 拍。

其五（S2e）：噪声底取单次碰撞写入 $\epsilon_0 = 7.7\times10^{-20}$ 时 $\ln(1/\epsilon_0) = 44.012$（对照 $10^{-3}$ 的 $6.908$），一维漏斗门槛由 $1.304\times10^{-3}$ 移到 $2.047\times10^{-4}$（缩小 $0.157$ 倍）。

其六（S2f，报告）：交叉质量 $M_* = 1.98\times10^{-21}$ 千克（约 $1.1\times10^{6}$ GeV），即质量大于它的天体全部落在「耦合先触发」一侧。

## 三、解读（含与阶段口径的关系）

其一，单位链与注入量级全部自洽，$N_c = 2\pi/3$ 与 $4\pi$ 的几何因子关系逐位成立，标定通路可用。

其二，坍缩驱动的斜坡速率与 D2 的交叉速率相差 $36$ 至 $38$ 个数量级。按裁决十三的判定量（真实场的 $\Gamma_c$ 与写入速率之比），该读数指向**耦合先触发，破坏不必待满偏**，与裁决十二的阶段口径（饱和主导）相反。

其三，该读数对输入不敏感的方向有三处：噪声底只作对数移动（$0.157$ 倍）；$\Gamma$ 正比于 $1/M$，宏观天体全部在阈值同一侧（交叉质量仅 $10^{-21}$ 千克）；$\Gamma_c \propto \sqrt{\lambda}$，故结论在 $\lambda$ 小于 $10^{-70}$ 以前不会翻转。

其四，依裁决十三的规则，终审归属由判定量给出，本读数不自行改口径：阶段口径的效力为「真实场输入到位前」，现在到位的是时间标定一项，S1（真实场构型）与 S3（非线性复核）未完成，故本读数列为预备读数，报作者裁定。

## 四、严格程度声明

本材料为量纲与标定核算（解析式与常数计算），不构成黑洞语境的可观测量；$\Gamma$ 的定义取 D2 的斜坡模型，写入律形式取「坍缩驱动的几何斜坡」（每拍注入与固定点条件给出的静态剖面在坍缩下的变化率），该对应属模型假设。

## 五、诚实边界

其一，斜坡模型：D2 的 $\Gamma$ 原指记录幅度的线性斜坡；本文把坍缩驱动的剖面变化率代入同一参数，两者的等价性未证（若记录在坍缩中按静态剖面即时跟随，$\Gamma$ 即本材料所算；若跟随被扩散限制，则须改用扩散时标，读数量级会变）。

其二，模型到物理的时间单位取「$1$ 拍 $= t_P$」，依据是晶格因果（每拍一格）与格点频率单位；该映射未由独立演算复核。

其三，$\Gamma_c$ 取 D2 的四个模型门槛，真实构型的门槛待 S1；生长率的漏斗型参数化（$\gamma \propto h$）为拟合式。

其四，非线性（容量约束下的演化）未在场，S3 未执行；$\lambda$ 的绝对值仍取 $1$（提取路径见 §6 的 S2-1 状态）。
