## 一、背景与判据

途径三（粒性侧局部恢复）声称：粒子（复合位错）不摆程，其内部法线沿背景法线场平行输运，给出自由粒子的测地线运动。本验证把该声称翻译为脚本判据：

- **判据 B1（零场方向保留）**：无源时直线运动 $T$ 拍，方向角误差、速率与内部法线模长偏差均为机器精度，方向不漂移。
- **判据 B2（弱场轨迹与测地线方程一致）**：冲击参数 $b$ 掠源，测偏转角、线性（$\theta_0$ 加倍偏转加倍）、加速度方向（$a = -\nabla\Phi$ 形式）、速率保持。
- **判据 B3（轨迹与质量无关）**：更新规则无粒子质量参数，不同质量标签下轨迹逐拍一致（等效原理响应侧模型级成立）。
- **对照（边界声明）**：纯空间法线输运（层表面嵌入度规）的偏转标度，量化"一阶牛顿项缺失"的具体位置。

## 二、模型设定

- **背景倾角场**：$\theta(r) = \theta_0 r_0 / r$（$r_0 = 1$ 格，3D 泊松稳态形；源侧已在 `frame_tilt.py` 验证，本脚本只测响应侧）。$\theta = GM/(c^2 r) = -\Phi_N/c^2$，即倾角场就是无量纲牛顿势。
- **度规识别（弱场候选实现，明示假设）**：倾角进入度规为势函数 $\Phi = -c^2\theta$，取弱场各向同性度规 $g_{00} = -(1-2\theta)$、$g_{ij} = (1+2\theta)\delta_{ij}$。
- **粒子代理**：携带内部法线方向代理（水平投影），速率 $|v| = c$ 恒；速度经度规联络平行输运（测地线 = 切向量平行于自身的曲线）。弱场零测地线一拍更新：$v' = v + 2c^2\big(\nabla\theta - \hat v(\hat v\cdot\nabla\theta)\big)dt$（横向，保速率）。
- **解析基准**：该度规弱场零测地线偏转角 $= 4\theta_0 r_0/b$（$g_{00}$ 与 $g_{ij}$ 双贡献）。

## 四、判定与解读

1. **判据 B1 通过**：零场下平行输运退化为精确平移，方向、速率、法线模长全部机器精度保持，无伪漂移。
2. **判据 B2 通过**：给定度规识别（倾角以 $\Phi = -c^2\theta$ 进入 $g_{00}$ 与 $g_{ij}$），离散平行输运更新给出与弱场测地线方程一致的轨迹：偏转角命中解析基准（相对偏差 9e-05）、线性标度 n = 1.000、加速度沿 $-\nabla\theta$、速率保持。**响应侧的弱场测地线内容在数学层成立。**
3. **判据 B3 通过**：更新规则不含粒子质量参数，轨迹只依赖源强度与初始条件。等效原理响应侧在模型级成立：惯性质量 = 引力质量出自同一几何更新（等价于无质量参数）。
4. **对照确认边界**：纯空间法线输运（层表面嵌入度规 $\delta_{ij} + h_i h_j$，$\nabla h = \theta\hat r$）的偏转 ∝ $\theta_0^2$（n = 2.000，与解析 $-(\pi/4)(\theta_0/b)^2$ 一致）。一阶牛顿项 $\propto \theta_0$ 需要倾角进入 $g_{00}$ / 时间坐标耦合，此为本判据定位的**承重墙施工面（张量桥 b 响应侧 / P1-5）**：法线场空间倾角单独只给二阶偏转，牛顿极限依赖时间坐标侧，与"3+1 时间向写入节拍提供牛顿扇区"的既有结论衔接。

## 七、过程记录（缺陷修正与教训，2026-09-10）

1. **初版 B1 在源心取点除零**：零场检验误用 $\theta_0 = 0$ 且坐标 $(0,0)$，$0/0$ 产生 nan。修正：零场检验取非源心点，且 $\nabla\theta$ 在源心邻域设零。**教训：零场检验也要避开奇异点；nan 传染是脚本初跑必查项。**
2. **初版偏转符号约定反**：偏转朝源为负 $y$，解析基准初版取正号，相对偏差 2.0。修正：基准取 $-4\theta_0 r_0/b$，比较取幅值。**教训：方向性物理量先定符号约定再写期望。**
3. **对照表面测地线初版 $(v\cdot\nabla)^2h$ 用错**：初版把 $(v\cdot\nabla)^2h$ 实现为 $\nabla h\cdot\nabla(v\cdot\nabla h)$，应为 $v\cdot\nabla(v\cdot\nabla h)$，导致对照偏转 ~1e-26（伪零）与指数 3.0。修正后指数 2.000 与解析一致。**教训：张量表达式逐项核对指标收缩；数值伪零要追表达式而非直接信。**
