# 时间和空间是被数出来的：元相子理论的时空观

（天行新学研究院）

注：本文面向高中生，全部严格推导与判据予以省略。文中每条结论站得多稳，文末有一张对照表，定理级、条件性命题级、纲领、未闭合四档分开列出，请连同那张表一起读。

## 一、舞台的错觉

你坐在教室里。墙上的钟一秒一秒地走，课桌稳稳占着一块地方。时间和空间看起来是全天下最不需要解释的东西：它们就在那儿，事情发生在它们里面。

物理学用了一百多年才发现，这两样东西其实很怪。光的速度对谁都一样快，不管你站着不动还是迎着光跑；运动的钟会走慢，大质量天体旁边的钟也会走慢；整个宇宙的空间还在持续膨胀，远处的星系退行得越来越快。这些现象早被实验反复确认，可"为什么"始终没有被真正回答。相对论把时间和空间放进了方程，把它们的来历留白。

[[元相子]]理论想补的就是这块留白。它给出一句朴素得有点意外的话：时间和空间在这个理论里没有舞台的地位，它们是无穷多个小东西一起振荡时涌现出来的整体结构。它们是被造出来的，而且到今天还在继续被造。

## 二、世界的最小演员

这个理论里最基础的实在只有一样东西，叫元相子。它分两侧，物侧能够被画出来，心侧是自主校准[[相位]]的能力，本文只用到物侧。

物侧的形象很简单：复平面上一个圆，半径固定为 $\hbar$，圆上有一根指针（相位）以普朗克角频率 $\omega_P$ 匀速转圈，每秒转大约 $10^{43}$ 圈，转满一圈用时

$$t_P = 5.39\times10^{-44}\ \text{秒}$$

这个时间短到无法想象。拿它和一分钟相比，大致相当于拿一分钟和整个宇宙的年龄相比。

元相子的数量是潜无穷的：生成永无止境，永远数不完，但在任何一个时刻，它的数量都是有限的。每个元相子有自己的圆心和自己的复平面，彼此之间天然纠缠。

可以这么想象：教室的四面墙上挂满了小表，每只表只有一根秒针，全都以同一个节拍、同一个方向转动，永远不停。这个理论要做的，就是从这满墙的秒针里把空间和时间读出来。

## 三、空间是一格一格长出来的

规则只有一条：**指针每转满一圈，圆心就沿着垂直于圆面的方向跳一格**，步长是一个普朗克长度

$$l_P = 1.6\times10^{-35}\ \text{米}$$

普朗克长度与普朗克时间，是把几个基本常数拼在一起得到的长度与时间标度，它们标志着现有物理学能够谈论的边界。

写成方程就是 $\dfrac{dz}{dt} = 2\pi c\,\delta(\arg\psi)$。右边的 $\delta$ 是一把梳子，只在相位恰好扫过 $2\pi$ 的整数倍时才被激活，其余时刻导数为零，解出来是一个阶梯函数。

拿一支铅笔来想最直观：笔尖绕着圈，每绕满一圈，纸就朝垂直方向挪一格，笔尖留下的痕迹是一根极细的螺旋线，像一根被拉到极限的弹簧。空间就是这根弹簧上的格子。

为什么偏偏是垂直于圆面的方向？想象一个转得极快的陀螺，转起来之后，唯一不会让画面变形的移动方向，就是沿着它的转轴上下。圆心是旋转唯一的不动点，对称性把平移方向锁死在转轴上，别无选择。三维空间交给三类元相子，各管一个方向、互相锁定，长出三维的格阵。这里有一项分工值得记住：格阵负责距离，纠缠关系负责方向。

关键在于，格子是跳出来的。在跃迁发生之前，没有任何"地方"等着它去，空间由此逐格生成。

## 四、时间是被数出来的

时间在这个理论里更朴素，它是数出来的。指针从实轴出发扫过一整圈回到实轴，算一次摆程。实轴就是圆面上标着"3 点钟"的那个固定[[位置]]，指针每次从那里出发、绕一整圈、再回到那里。邻居的圆心不能重合，摆程走到边界就会撞上邻居并折返，去程与回程等长，构成一个来回。物理时间就是摆程的总数：

$$t = N t_P$$

摆程不倒退，时间便单调递增。这就是[[时间箭头]]在几何上的来源：转了一圈并不回到原处，螺旋往前推进了一格。

有一处分工必须分清，否则后面的现象会全部混乱。普朗克时间管的是"一步多长"，这个步长永远不变；相对论里那些钟慢尺缩管的是"一条路要走多少步"，步数随路径而变。所谓时间膨胀，比较的是步数之比，与步长毫无关系。由此还得到一个可检验的推论：固有时必然是 $t_P$ 的整数倍，$\tau = n t_P$，我们感觉到的连续流淌只是宏观平滑的幻觉。

时间自身还有三层生成次序。底层是复平面上那没有事件的连续转动；中间层是满周闭合从连续内部自己给出的记号，离散从外部强加不进去，这就是普朗克时间；最上层是带着刻度住在时间里的一切场，它们都是"被采过的连续"。一句话概括：**连续生成事件，事件组成尺子，尺子再次丈量连续。** 原初的连续只能有一次，因为它是时间本身，这也是全宇宙的物理规律共享同一个时间参数的原因。

## 五、光速是这个世界的固定汇率

转一圈走一格，一步一格，速度自然就是

$$c = \frac{l_P}{t_P} \approx 3.0\times10^{8}\ \text{米/秒}$$

体系里有三条互不相干的路子都走到这个结果：元相子振荡的宏观解、上面这种一棒接一棒的接力、格子上长波的传播速度。三条路子都不依赖任何介质的弹性参数。

这意味着光速是相位与空间之间的换算常数，性质上更接近汇率，不像水波或声波那样由介质的软硬决定。速度的来历也讲得通：元相子圆心按摆程节拍跃迁，撞上邻居的瞬间，邻居读出它的指向并整桶移交，事件链一步一摆程、一格一格地把传播读出为波前，这个波前速度就是光速。搬走的是状态，与传得卖力不卖力无关，所以强光、弱光、单个光子全都同速。

顺带还有一件重要的事：采样就是相撞，相撞就是抄写。宇宙里没有站在外边的记录员，观察者自己就是那个被撞的圆心。碰撞落在粒性侧，是现实化的采样；波性侧的相位演化另走一条路，保持可逆。两者分工，只有测量才是跨越两层的事件。宇宙对连续场的采样率因此等于格子的碰撞率，每摆程一次；而按采样定理，认出一个振荡至少需要两次采样（去一次、回一次），于是可分辨频率的上界约为普朗克频率的一半。短波的尽头就这样藏在普朗克采样网格里，任何物理过程都不可能发生在普朗克尺度以下。

## 六、为什么我们感觉不到格子

到这里一定会有人警觉：既然世界是一张格子，那不就有一个"绝对静止"的参照系了吗？这与相对论直接冲突。这个冲突曾是整个理论的最高风险。

解除的办法在于观测者本身。你、你的尺、你的钟，全都由这张格子做成，你全身都是钟。在能量远低于普朗克能量的情形下，描述观测者的有效方程恰好是洛伦兹不变的（这条性质是推导出来的，没有被额外当作假设塞进去），于是运动观测者由洛伦兹变换给出：内部时钟按 $\omega_b/\gamma$ 变慢，结构尺度按 $\xi_0/\gamma$ 收缩，其中

$$\gamma = \frac{1}{\sqrt{1-v^2/c^2}}$$

你用来测量的一切都跟着一起变，读数彼此抵消，格子系与任何一个运动系在低能层精确不可区分。数值检验在 $v = 0.3c$ 时的偏差只有 $0.07\%$。

不过格子并没有彻底藏住。能量接近普朗克能量时，不同频率的光会出现快慢差别，这个差别可以预先算出来：

$$\frac{\delta\omega}{\omega} = -\frac{l_P^2}{24}\frac{\sum_a k_a^4}{k^2}$$

它随 $(E/E_P)^2$ 增长，并且依赖方向，比例约为 6:3:2。这正是当前洛伦兹破坏实验搜索的靶子。这里要分清两件事：永远读不出的是你相对格子跑得多快，可以预言的则是极高能粒子在传播中露出的偏差。

## 七、弯曲是怎么写上去的

引力在这个理论里由一次次碰撞写入完成。有质量的粒子在每次碰撞事件中，把邻格的方向拨歪一个极小的角度

$$\delta\theta = \frac{m}{m_P}$$

对电子而言这个角约为 $4\times10^{-23}$ 弧度，相当于一根头发丝在一万光年之外张开的角。单单一格几乎笔直，这就是引力在微观世界里弱得离谱的直接原因。

但累积是可怕的。亿亿万万次写入叠起来，平直的格子就弯成了一口井，井的深浅就是牛顿引力势 $\Phi = -GM/r$；而泊松方程 $\nabla^2\Phi = 4\pi G\rho$ 描述的是井的形状如何随物质分布铺开，其中的 $4\pi$ 来自球面的立体角，是几何必然。体系还纠正了一个直觉：在光滑的格子上沿小圈搬运箭头一周，箭头并不转动，曲率只存在于缺陷（疤）那里，写入的幅度只决定场的形状。

钟为什么在井里变慢？井底的世界线被压短了，同样的高度差能数到的摆程变少，步数少就是慢。证据在我们头顶：GPS 卫星位于井外高处，数得的步子比地面多，所以它的钟更快。$G$ 在其中承担的角色值得一提，它对应的是时空的生成刚度，管的是格子被拨歪有多难，与"引力有多强"的通行理解并不相同。这里还有一处立场的显式化：元相子的基态能量充当的是时空结构的刚度能量，不承担引力源的角色，只有缺陷的能量差才产生引力，这为长期困扰物理学的真空能疑难提供了消解方向。

## 八、空间还在长

元相子的数量潜无穷增长，永不完成。新来的元相子必须有地方落脚，落脚就需要新空间，于是数量的增长必然转化为空间的膨胀。机制分两个通道。

第一个通道在边缘。边缘的元相子外侧没有定居的邻居，折返条件缺失，为了让它可以往返，外侧必须生出新的元相子，相位由天行力校准成正好相反；新的外侧又需要更新的邻居，如此递归。结果是边缘每摆程往外推一格，推进速度正好等于光速。

第二个通道在内部。相邻的两个元相子相位相反，圆心会在公共边界上相撞。就在相撞的瞬间，偶尔会诞生一个新的元相子，它复刻即将折返那一位的相位与节律，转一圈恰好跃迁一个格距，于是邻居毫无察觉，格子顺滑地多出一格。这个"偶尔"稀罕到什么程度？落位概率是

$$p = 3H_0 t_P \approx 3.7\times10^{-61}$$

平均约 $2.7\times10^{60}$ 次碰撞才落位一次，单个格点大约每 47 亿年才轮到一回。用 $\ln(1/p)$ 度量的指数深度约为 139，这份稀罕被 $e$ 的 139 次方压着。宇宙中格点总数约 $10^{184}$ 个，每秒仍有约 $10^{167}$ 次落位，叠加起来恰好是我们观测到的膨胀率，每个个体的慢与整体的快并不矛盾。

为什么内部也必须长？只有边缘长的话，内部任意两点的格点数不变，退行速度为零，哈勃定律在内部就不成立；更要紧的是，引力靠碰撞写入单向持续地加深弯曲，本身没有停止条件，没有新格子进来稀释，宇宙会在自身引力下重新缩回去。内部落位就是抵抗收缩的那一项。

于是大爆炸被拆成了两件事。成核凝固并不发生在某一个点上，它是一次过程：第一次结晶之后，各个能互相看见的范围内会各自独立成核，波前相遇的地方留下[[接缝]]。凝固作为过程则持续至今，每一次边缘补位都是一个格子从无时空变成有时空的微型大爆炸，与最初那次同源，但异步、局部、持续。有始的是成核，无始的是创生本身。

## 九、哪些站住了，哪些还在路上

科普文章最容易做的一件事，是把未完成的东西说得好像已经完成。下面这张表把话说清楚。

| 结论 | 站得多稳 |
|---|---|
| 时空二象性（数学连续侧与物理离散侧） | 定理级，从唯一公理导出 |
| 光速 $c = l_P/t_P$ | 几何恒等式级，三条独立来源互证 |
| 潜无穷增长必然转化为空间膨胀 | 定理级，公理的直接推论 |
| 时间 = 摆程计数 $t = Nt_P$ | 条件性命题级 |
| 狭义相对论的洛伦兹变换、钟慢尺缩 | 低能层条件性定理级，数值验证偏差 $0.07\%$ |
| 普朗克层的洛伦兹破坏 $(E/E_P)^2$ | 可检验预言，待实验 |
| 引力 = 碰撞写入，静态弱场给出泊松方程 | 模型级机制，数值验证 |
| 从标架网络到爱因斯坦场方程 | 纲领，尚未完成 |
| 离散镶嵌与 $p = 3H_0 t_P$ | 条件性命题级（数值结论） |
| 完整膨胀史（物质期、暗能量期） | 不取代广义相对论，只补恒速膨胀源 |
| 空间 = 法线的离散跃迁 | 模型假设，跃迁本身尚未从公理直接导出 |
| $G$ 的数值、$\hbar$ 与 $c$ 的数值 | 经验输入，尚未被机制导出 |
| 三维性的严格证明 | 未闭合 |
| 时间箭头与热力学箭头的衔接 | 未闭合 |

其中"[[法线跃迁]]"这一条尤其值得盯住，它是整个空间生成链条的起点，目前仍属于假设，还没有被提升为定理。理论对自身保持着这份自我批判。

## 十、几个关键数字

| 名字 | 数值 | 它管什么 |
|---|---|---|
| 普朗克时间 $t_P$ | $5.39\times10^{-44}$ 秒 | 时间的一步有多长，永远不变 |
| 普朗克长度 $l_P$ | $1.6\times10^{-35}$ 米 | 空间的一格有多大，永远不变 |
| 光速 $c$ | $3.0\times10^{8}$ 米/秒 | 相位与空间之间的汇率 |

另外两个数字各只出现一次，却决定了两件大事：电子每次碰撞把邻格拨歪 $4\times10^{-23}$ 弧度，这是引力弱到几乎看不见的原因；空间落位的概率 $3.7\times10^{-61}$，这是宇宙膨胀慢到需要用亿年计的原因。记住这几个数，整篇文章的骨架就拎起来了。

## 收束

把整篇文章压成一句话：**空间是转满一圈跳一格跳出来的，时间是数摆程数出来的，光速是这两者之间的汇率，弯曲是每一步被拨歪一点点累积出来的，膨胀则是新来的演员不断要有地方站。** 五件事，同一个源头。

如果这套图景有一丁点是对的，那么"时间和空间是什么"这个问题的答案，就藏在满墙秒针共同的节拍里。你手上恰好也有一只表，它数的，正是这个宇宙的脚步。
