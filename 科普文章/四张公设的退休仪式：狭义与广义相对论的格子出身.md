# 四张公设的退休仪式：狭义与广义相对论的格子出身

傅天行
（天行新学研究院）

注：本文面向高中生，不进入严格推导。1905 年狭义相对论立了两张公设（相对性原理、光速不变），1915 年广义相对论又立了两张（等效原理、广义协变性）。一百多年里这四张纸是物理学的地基，追问它们的来源，标准答案通常停在"实验验证得很准"。本文讲另一条路：在格子宇宙里，这四张公设怎样一张一张从假设变成推论。场方程的完整故事已有《引力的全图》专文，本文只取它需要的那一环。

## 一、公设是什么，退休是什么

物理学里有一类陈述与众不同：别的结论靠推理得出，它们靠宣布。宣布之后，实验反复核对，核对得越准，它们的地位越稳。但"准"只回答"对不对"，回答不了"从哪来"。爱因斯坦本人晚年一直在问光速不变为什么成立，问到最后也只好承认：它是公设，问到这里为止。

本文用"退休"形容一个转折：一条陈述从"必须宣布的地基"降为"可以推导的结论"，实验从此只负责验收，不再负责解释它为什么存在。退休不等于作废，狭义相对论的公式一个都不变；变的是它在理论里的位置，从地基移到了二楼。

格子宇宙是一套具体的图像：空间是三维格子网，每格住着一个元相子，一步一格来回摆动；时间是数摆动，全宇宙同用一个节拍；粒子是格子上锁死的褶子，质量是褶子的绑定能。地基在这个图景里另有其人（格子与节拍），四张公设都站在它上面，本文的任务是逐张对账。

## 二、光速不变：格子的出厂设置

光速不变原话说：真空光速与光源、观测者的运动无关，恒为 $c$。这条公设最反直觉：你追着一束光跑，它居然不慢下来。爱因斯坦十六岁就想这个问题，想了十年。

格子宇宙里它一点不神秘。光是一格一格接力的产物：每拍传一格，每格一个普朗克长度，每拍一个普朗克时间，于是 $c = l_P/t_P$。你跑你的，接力还是那个节拍、那个格距，光速凭什么变？它从来与光源无关，它是格子的出厂设置，写在与一切物质共享的节拍里。

更硬气的是这个值有三条独立来路：元相方程的宏观解直接给 $Z = cT$；接力几何给 $c = l_P/t_P$；格子上的色散关系 $\omega(k) = \frac{2}{t_P}\left|\sin(k l_P/2)\right|$ 在低能处退化回 $\omega = ck$。三条路不通气，答案同一个，而且没有任何可调的数。光速不变的级别因此是最高的"几何恒等式级"：在体系内它已经没有假设的成分（速度与动能的结构另见《为什么光总是一步到顶》）。

## 三、相对性原理：明明有绝对系，为什么看不见

这张公设说：物理定律在一切惯性系里等价，没有谁更特殊。它奇怪的地方恰好相反于光速：格子宇宙明明有一张固定的网，网就是优先参考系，相对性原理凭什么成立？

它成立，因为优先系在低能处读不出来。这里有一条普遍法则打底：一切能被看见的东西都是差异，绝对相同的东西不可见（见《同底异显》）。你在格子网里匀速滑行，你的钟、你的尺、你身边所有的物理过程都在做同一套换算，绝对速度在每一条读数里都以"差"的形式出现，而它恰好不在任何差里。低能处，介质退场。

这层退场有整套可检验的分层定理托底（见《全世界都是床垫做的》）：低能处不可探测是严格结论；高能处波长逼近格距，格子感开始露头，洛伦兹对称出现残缺，分歧点指明在哪些观测里找。相对性原理由此降级：从"宣布没有以太"变成"低能定理"，它藏起来的东西并非以太本身，真正的藏身处是低能处读出以太的一切手段。迈克尔逊-莫雷实验的 null 结果，在这套逻辑里从"空间的怪癖"变成"格子的必然"。

## 四、运动学全家桶：从两条公设到一张时刻表

狭义相对论的其余内容，洛伦兹变换、时间膨胀、长度收缩、同时性相对性、质能关系，标准物理从两条公设推出。格子宇宙逐条跟进，而且每一件都有格子版的说法。

时间膨胀：运动的褶子由抄写维持，抄写要走斜线，路程变长，钟慢就是抄写周期的稀释；同时全宇宙的普朗克节拍一格未乱，两幅图各管一层（见《永远滴答的表》）。同时性相对性最近被完整定理化：你问"哪些事件算同时"，答案是一张倾斜的切片，倾斜量恰为 $v/c^2$；两个异地钟对表，前面的钟落后 $\gamma vL_0/c^2$；"怎样对表"里留有约定自由度，爱因斯坦的方案自洽但非唯一；普朗克层还有一份小修正，随能量升高趋向 $(1/8)(E/E_P^{(t)})^2$。一件百年旧知识，如今有了格子出身与四条判据。

多观测者的全局读数也清了。甲说乙的钟慢，乙说甲的钟慢，两个人绕一圈回来把记录并在一起，差出来的一角是多少？答案漂亮得不像话：这一角恰好等于两人速度在速度空间里围出的那块双曲面片的面积，一格不多一格不少；差出来的读数里没有第三方优先系的痕迹。洛伦兹群的生成元与复合规则也做了完备构造，Wigner 旋转给出闭式。质能关系 $E = mc^2$ 同样有显式导出，动能项与薛定谔方程的降级路线对得上（质量本身的故事见《质量的来源》）。

## 五、等效原理：写字的手与读字的眼

广义相对论的第一张公设说：引力和加速度局域不可区分，电梯里你分不清自由落体与星际漂流。它的实验影子更古老：伽利略的斜塔，轻的重的同时落地。为什么？标准物理把它写进公设，牛顿力学里靠"惯性质量等于引力质量"这条经验事实硬撑。

格子宇宙给了一个直接的回答。引力是格子上的记录（机制见《引力的全图》），而记录的读与写用同一把刻度：褶子按自己的质量往格子里写字，它读别人的记录时也按同一个质量折算，两头一乘一除正好约掉，路径与质量无关。轻的重的同落由此有了结构解释：读写同源，折算系数恒为 1，有判据级的证明（通俗版见《音量旋钮与均衡器》）。

完整的等效原理还差另一半：不光轻重的同落（弱等效原理），局域处一切物理都分不清引力与加速度。这一半由两块合成：局域洛伦兹不变性，由色散关系的低能极限承担；局域位置不变性，由写入的平移不变承担。两块的合成判定已显式做完，等效原理整体升为条件性定理。

## 六、广义协变性：换笔不换事实

广义相对论的第二张公设说：物理定律在一切坐标系里形状相同，曲线坐标也好、直线坐标也好，定律不挑笔。它要求方程在任意坐标变换下保持形式。

格子宇宙的验证分三步，每步都有数值判据。第一步，取哪支笔读数，结果不挑笔：标架读数在任意坐标重标下不变，分量变化纯属表述，相对偏差 $10^{-16}$ 量级。第二步，重标这件事本身被认出来了：无穷小的坐标重标，恰好对应场空间的规范变换，曲率组合对它不变。第三步，守恒结构在格点上存活：离散的比安基恒等式精确成立，机器精度，格子不漏守恒。

三步走完，"协变推广"从爱因斯坦的一步构造升为表述层推论。它有明确的前提清单（记录场标量性、一致差分、弱场线性层等），所以级别是条件性定理级：前提在，结论在；前提失效的深处（强场、非线性）另有安排，那里是黑洞线的辖区。

## 七、最后一级台阶：场方程

等效原理管引力的"存在"，广义协变性管方程的"形状"，还差最后一个问题：方程的常数是多少。这一步从弱场的泊松方程出发走三步：源升级（褶子的四样分量装配成 $T_{\mu\nu}$，对到 $10^{-16}$）、侧升级（散度守恒配平出爱因斯坦张量）、定常数（$8\pi G/c^4$ 是推导结果）。每一步的微观供给都已判据化，弱场推导链闭合。

完整的账目在《引力的全图》里逐环展开，本文不重复。这里只记录它对本文主题的意义：场方程也退休了。它从"爱因斯坦的天才输入"变成"写字与抄写规则在低速弱场下的连续极限收据"，四张公设与方程在体系内的出处至此对齐。

## 八、计分板

四张公设加惯性，逐张登记现状如下（级别从高到低：几何恒等式级高于条件性定理级，条件性定理级高于结构论证级）。

| 陈述 | 标准物理里的地位 | 体系内现状 |
|---|---|---|
| 光速不变 | 公设 | 几何恒等式级：三条独立推导，无可调参数 |
| 狭义相对性原理 | 公设 | 条件性定理级：低能介质不可探测的分层定理 |
| 时间膨胀、同时性相对性等运动学 | 推论 | 条件性定理级：同时性第 470 条等判据化 |
| 洛伦兹群与多观测者协议 | 数学结构 | 条件性定理级：完备构造与全局账目（第 471、472 条） |
| 弱等效原理（WEP） | 经验事实 | 条件性定理级：读写同刻度，折算系数 1 |
| 等效原理（EEP） | 公设 | 条件性定理级：两半合成判定完成 |
| 广义协变性 | 公设 | 条件性定理级：三步判据（第 469 条） |
| 场方程 | 从公设推导 | 推论：弱场推导链闭合，强场归黑洞线 |
| 惯性 | 定律 | 结构论证级（半成品）：变率继承已立，定量来源开放 |

## 九、还欠什么，意义何在

计分板上没有满分。惯性只走了一半：它由"变率继承"机制给出（实轴方向的推进由校正事件逐摆程累加），结构立住了，但惯性的定量来源还没钉死。等效原理与广义协变性都是条件性定理级，前提清单里各留了一道未关的门（非线性层的缝合假设）。等效原理的最强版本（SEP，自引力体的判决）归强场，黑洞线接手。普朗克层的破坏项还要整理出完整的高能签名清单，交给观测去裁决。

意义压成两句。第一句：相对论在这套体系里从公设体系变成推论族，四张纸的权威来源从"实验很准"换成了"格子几何的必然"，而且推论在普朗克层与广义相对论分道，分歧点可检验。第二句：它是一张更大地图的一角，量子力学的方程与测量、规范动力学、引力机制都已逐条降级为同一套格子的推论；相对论四张公设的退休，补上了这张地图上最显眼的一片天。

## 收束

1905 年，爱因斯坦把光速不变写下来时，它是诏书；1915 年，广义协变性立起来时，它还是诏书。在格子宇宙里，四张诏书逐一改成了户口：光速是格距除以拍频，相对性是低能读不出差异，等效原理是读写同一把刻度，协变性是换笔不换事实。诏书变成户口，实验还在，敬意还在，只是解释权换了主人：从宣布，换成了推导。
