# 光在介质里为什么慢下来：被抬起来的那条曲线

## 一杯水带来的麻烦

把筷子插进水杯，看上去折成两截。把光放进水里，它跑得比在空气里慢（费佐 1851 年用齿轮法测得水中光速约为真空值的 0.76 倍，与理论值 $n\approx4/3$ 相合）。这两件事是同一件事：光走进介质之后，路线弯了，速度也慢了。

在[[元相子]]宇宙里问「为什么」，得先分清两件事。一件是真空里的光速恒等式，另一件是介质里的传播读数。[[元相子理论的时空观：体系对时空的完整认识|元相子时空观]]把这两件事分得很干净，干净到能直接告诉你慢化只能从哪扇门进来。

## 真空里的恒等式：格距除以摆程

真空是一大片振荡晶格，每个格点坐着一个元相子，手里举着一根指针（[[实轴方向场]]）。一束光就是这片看台上的人浪：某格点指针偏一点，邻居察觉，对齐过去，下一个再对齐。

人浪跑多快，只看两件事：相邻两人隔多远，每人做一个动作要多久。元相子的动作是摆程，指针扫一圈，耗时一个固定节拍 $t_P$；相邻格点隔一个格距 $l_P$。于是

$$c = \frac{l_P}{t_P}$$

这条恒等式有一个常被误读的性质：**接力棒怎么递，不进这个式子。** 耦合强弱不进入速度公式。所以「光速与介质参数无关」这句话在真空层是恒等式，在介质层需要限定口径，这正是问题的入口。

## 一道硬约束：均匀负载压不动它

现在做个思想实验：给真空光波均匀地加一份弹性负载，让介质拖着它走。慢了吗？

没有。体系内有一条已证明的引理（物质模式去耦引理，见[[元相子振荡晶格的色散关系：低能光速涌现与洛伦兹破坏首阶项]] §6.2）：光模式的相位扇区与介质的内部扇区，在线性理论里严格块对角，没有交叉项。弹簧项变换后仍正比于内部单位算符，两扇区互不看见对方。

通俗讲：看台上的人浪只跟着人浪走，介质是一群坐在旁边不动的观众，他们的弹性不会自动拖慢浪的节拍。要让观众真的上手牵动节拍，必须有人按下非线性开关。

## 唯一的门：非线性开关

去耦引理自己写明了破口：线性理论之外，$\cos$ 展开的高阶项会让两个扇区产生非对角耦合。慢化的机制入口被收敛成唯一一条：光模式与介质元相子的内部模式混在一起，变成一个混合模式。

一旦混合，本征频率被内部弹性从零抬起来。色散关系于是长成

$$\omega^2 = c^2 k^2 + 3\omega_P\kappa_\varphi$$

其中 $\kappa_\varphi$ 是介质元相子的内部弹性，$3\omega_P\kappa_\varphi$ 就是被抬起来的那一截高度，物理上读作一个能隙。传播读的是这个混合模式的斜率：

$$v_g = \frac{c^2 k}{\sqrt{c^2 k^2 + 3\omega_P\kappa_\varphi}} < c, \qquad n = \frac{c}{v_g} = \sqrt{1 + \frac{3\omega_P\kappa_\varphi}{c^2 k^2}}$$

对比真空那条从原点出发的直线：真光的曲线起点在零，斜率处处相同，所以速度与波长无关。介质光的曲线起点被抬高，起点越高曲线越平，同样的频率变化走过的距离更短，速度就慢下来了。**光在介质里变慢，因为它混进了一个有内禀频率的模式。**

## 三个可以直接对着实验看的推论

这张图有三个行为特征能拿去对材料实测。

其一，能隙之下禁戒。频率低于能隙时没有实数波矢，$n$ 虚化，掠射下出现全反射。其二，高频回归。频率远高于能隙时 $n\to1$，光又跑回真空速度，这是 X 射线在材料里的实际行为。其三，全程 $v_g<c$，光锥和因果不受威胁；相速度可以超 $c$，那不是信号速度，体系的光锥定理管的是群速。

材料侧的两条事实指认了是哪一扇门：X 射线段的 $n\to1$ 并伴随全反射区，指向能隙型图像；可见光频率恰在原子束缚频率同量级处，正落在能隙边缘，那里既有最强慢化也有正常色散。

这里有一处诚实交代：上面那条闭式只取了共振项的同相部分，因此低频端给 $n\to\infty$，而真实材料在频率趋零时折射率是一个有限值。静态那一段要另补完整响应，本轮不给。

## 折射与双折射是免费的

波矢在框架里读作相邻格点指针的差（$k_a l_P = \Delta\alpha_a$）。界面两侧切向波矢与频率连续，纵向波矢由上面那条弯曲的色散决定。Snell 律从非线性色散里直接掉出来，不用另设机制；介质各向异性给两个不同折射率，双折射也是同一出口。

## 还差什么，哪些已经定了

诚实分层：上面这套图像的解析形式取自体系内已有的物质模式色散，「光与介质内部模式混合」这一步目前是构造层方案，[[光的传播总论：时空晶格中的双层机制、光锥接合与移交判据]] §七把介质折射机制列为开放项（编号 P1-50）。

定量缺三样：内部弹性参数 $\kappa_\varphi$ 的原子值；耦合常数 $e$ 的定量来源（P1-49）；两扇区耦合矩阵元的具体形式（第 526 条已把候选通道判为二分待判，签名互斥可判）。

可即刻下手的一步：用 $n(\omega)$ 的高频回归加全反射区存在性，一次把候选通道分开；再用可见光段的低阶色散反推 $\kappa_\varphi$。两步都在现有判据框架内可搭，不需要新公理。
