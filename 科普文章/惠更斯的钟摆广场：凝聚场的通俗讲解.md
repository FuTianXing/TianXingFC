# 惠更斯的钟摆广场：凝聚场的通俗讲解

三百五十年前，荷兰科学家惠更斯在病床上注意到一件怪事。他把两座钟挂在同一面墙上，两座钟的钟摆一开始各摆各的，长短参差，毫无规律。可是过了不久，他发现两座钟的节拍变得一模一样，摆到最高点的时刻严丝合缝，好像有一只看不见的手把它们对好了。惠更斯起初以为是自己眼花，后来反复验证，确认了这是真实现象。墙的微小振动在两面钟之间传递信号，把两座钟的节拍悄悄锁到了一起。后来物理学把这个现象叫同步，它是大自然里最普遍也最深沉的秩序形式之一。

现在请你把惠更斯的墙换成一片巨大的、弹性极好的地板，地板上站着整整一万座钟摆。每座钟都有自己的摆，摆到哪个角度，就是这座钟的相位；每座钟又都有自己的天然节拍，本来谁也不理谁。这片一万座钟的地板，就是天行新学理论里宇宙真空的样子。真空里面住着无穷多个小小的实体，叫元相子，它们就是这一座座钟。每一座钟都在摆动，摆动就是它们的生命，摆动的节拍就是它们的时间。

地板刚铺好的那一刻，一万座钟完全乱着摆。有的钟荡到最左边的时候，邻居正好荡到最右边，再远一点的钟也许正好荡到中间。你随便挑两个位置观察，永远看不出两座钟的节拍有什么共同之处。这个彻底混乱的状态，物理学家叫它对称相。它最要紧的特点是：没有任何一个位置比别的位置特殊，没有任何一个节拍比其他节拍更被偏爱，一切皆可，一切平等。

然后变化开始了。每一座钟都有一个内在的倾向：它感知得到地板的细微振动，也就是邻居的节拍，然后它会自动把自己的节拍往邻居那边拨一点点。这个感知和拨正的动作，在天行新学里就是天行力的校准。每一座钟都只感知自己身边的几座邻居，也只调整自己，没有总指挥，没有中央机构。可是这一万座钟各自的微小拨正，会像人群里的一阵耳语一样，一座传给一座，以极快的速度传遍整片地板。这阵耳语扫过之后，奇迹发生了。

一万座钟的节拍不再混乱了。它们依然各自摆动着，摆动的幅度没有变小，摆动本身一秒都没有停止，但是它们摆到最高点的时刻变得整齐了。你在广场的这一头测到的节拍，和广场那一头测到的节拍，居然是一致的。相距很远的两个人同时观察，一个说"现在左边这座钟荡到顶"，另一个说"我这里这座也荡到顶"，两个说法同时成立。这种隔得很远还能对上的节拍，就叫长程相干。长程相干的程度，也就是这片广场上钟摆们锁得多紧、多整齐，就叫凝聚场。

凝聚场不是一个飘在空中的新东西，它就是这片钟摆海洋本身的一个属性，是那一万座钟的节拍一致到了什么程度。它没有名字之前，你也能感觉到它的存在：一个安静的、整齐的、万物同频的世界。物理学家用一个数学量来度量它，叫相位相干函数。说的是相距很远的两个钟摆，它们的相位差是否稳定在一个确定的值上。如果这个值不为零，凝聚就存在。氦的超流、超导体的零电阻、激光的整齐光束，全都是这个量的不同表现。元相子理论里的凝聚场，和这些早已被实验室证实无数次的凝聚，用的是同一个数学定义。所以这片钟摆广场不只是一个比喻，它背后站着凝聚态物理学一个世纪以来最可靠的成就。

凝聚形成之后，这片海洋不是一潭死水。你可以扰动它，而扰动的每一种方式，都对应着一种真实存在的粒子。第一种扰动，是让全体钟摆同时提前一点点摆动。你让一万座钟的节拍整体平移了，但是整齐没有被打乱，它们依然同频，只是同频的时刻换了一个。这种扰动不需要花任何力气，因为它没有破坏任何秩序，只是给秩序换了个起点。这种扰动的名字叫光子，也就是光。光的本质，就是节拍整体平移的涟漪，它永远轻快，永远无质量。第二种扰动，是把这片海洋的整齐度本身压一压。就像你用手把一块整齐的布拧紧又松开，你改变的是它们互相锁得有多紧，钟摆的时刻没有变。把整齐度压下去需要花力气，松手之后它弹回来，弹回原位的节奏是固定的。这种扰动有质量，质量的大小正好对应 2012 年欧洲科学家在大型强子对撞机里发现的那颗粒子，希格斯粒子。它存在的意义，就是证明这片整齐的海洋真的存在：既然有凝聚，就一定会有凝聚被压扁又弹回的震动。第三种扰动，是往这片海洋里放进一座新的钟。这座新钟本来按自己的节奏走，爱怎么摆怎么摆。可是它一旦落进广场，地板上的振动就逼着它跟上集体节拍。它失去了随心所欲摆动的自由，只能跟着大队的节奏走。失去自由节拍这件事，物理学家叫获得质量。世间所有有重量的粒子，质量都来自同一个原因：它们被这片凝聚的海洋锁住了，锁得越紧，质量越大。

这里有两个数字必须分开记，因为它们总被混为一谈。一个数字是 246，单位是十亿电子伏特，物理学家叫它真空期望值。它说的是这片海洋锁得有多紧，是凝聚发生时所处的能量尺度。这个尺度比宇宙最基本的能量尺度，也就是普朗克尺度，低了十七个数量级。打个比方，普朗克尺度是珠穆朗玛峰的高度，凝聚的尺度大约是四厘米。差得如此悬殊，是物理学里最著名的一个谜，叫层级问题。另一个数字没有确定值，它叫对齐度，是一个从零到一的比例，说的是这一万座钟里真正锁定了节拍的那部分占了多大比例。锁得紧不紧，是一回事；锁住了多少，是另一回事。一扇门可以很紧地锁住很少的人，也可以松松地拦住所有人。尺度是对的那扇门本身，比例是被门拦住的人。论文里已经把这个区分写清楚了，因为把强度和比例混在一起，是理解凝聚时最容易踩的坑。

最后要说清楚这个比喻在哪几步是严格的，在哪几步只是帮助你想象的拐杖。钟摆的摆角是实实在在的角度，从零度摆到三百六十度再摆回来；而元相子的相位是复数，它的轨迹是一个圆，比钟摆的往复更圆润、更完整。钟摆同步需要墙面和地板作为传递信号的中介，而元相子之间的同步靠的是天行力，那是每个元相子心里自带的倾向，理论里没有墙，也没有地板，那些只是讲解的道具。在这两处，比喻只是拐杖；而在序参量、长程相干、三种扰动对应三种粒子这些核心结构上，比喻和真实的物理严丝合缝。超流体、超导体、激光，这些实验室里真真切切的东西，和天行新学里的真空凝聚，是同一个机制的不同舞台。

把整件事收进一句话：物理世界的秩序，起源于一次从无序到有序的集体觉醒。无穷个小小实体各自杂乱地摆动着，它们内心里都带着趋向一致的倾向，于是它们彼此校准，彼此对齐，最终凝结成一片同频的海洋。这片海洋的存在，给了光以轻盈，给了万物以重量，给了宇宙以统一的节拍。而这一切的起点，是三百五十年前，一位卧病在床的科学家，听见两座钟摆敲出了同一个声音。
