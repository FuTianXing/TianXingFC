# 蛋托上的橡皮筋：一条弹簧链怎样成为时空晶格的替身

傅天行
（天行新学研究院）

注：本文面向对物理感兴趣的普通读者，讲一个在元相子理论的数值验证里反复露面的模型，FK 链。它本身是 1938 年提出的经典模型，与元相子理论没有渊源；有意思的地方在于，它长得太像元相子理论描述的空间格子，于是被请来当替身。文末有一张对照表，以及一份它会在哪里骗你的清单。

## 一、把球放进蛋托

想象一排小球，球与球之间用橡皮筋连着，整排球放在一只蛋托上。

这句话里藏着两个互相较劲的要求。橡皮筋希望球与球之间保持它自己舒服的长度，球排得越均匀它越省力。蛋托希望每个球都落进凹坑，坑底是球最舒服的位置。球有几个、坑有几个、坑与坑隔多远，都由你摆好，剩下的交给它自己。

物理学家真的做过这件事。一九三八年，弗伦克尔和康托罗娃研究吸附在晶体表面的原子层，模型正是它：原子之间有弹性相互作用，脚下是晶体提供的周期性势场。后人把这条链叫 FK 链，也叫离散正弦-戈尔登链。

## 二、对不齐的时候

先看对得齐的情形。如果橡皮筋的自然长度正好等于蛋托的坑距，两个要求可以同时满足：每个坑一个球，橡皮筋也处在自然长度，整排球安安稳稳，能量最低。这叫匹配态。

现在把橡皮筋换短一点，比如自然长度只有坑距的百分之九十五。橡皮筋想把球拉近，蛋托想把球按在坑里，坑距没变而球想挤得更紧，两个要求在每一处都满足不了了。

物理上把这种对不齐叫失配。失配不会平均摊到每个球头上，它有个更省力的去处：绝大多数球仍然待在坑底，把攒下来的错位集中到一处释放。那一段集中错位的地方，就是 kink。

## 三、多出来的那颗球

kink 长什么样？看一眼数值弛豫算出来的构型就明白了。

坑距是一，链上有三十个球，两端钉死，总长度比"每个坑一个球"短一点。链会怎么办？它在中间某处把两个球挤进同一个坑里，其余球照旧各占一坑。压缩的那一小段就是 kink。

反过来，如果橡皮筋的自然长度比坑距长，链比势疏，它会在某处空出一个坑，出现一段明显变大的间距，那也是 kink。

kink 有个硬脾气：抹不掉。你可以推它、挪它、让它变形，却没法靠局部微调让它消失。想把球重新送回坑里，必须把整条链的长度改回匹配值，而两端钉死锁住了长度。这个"改不动"的性质在数学上叫拓扑保护，kink 因此是拓扑缺陷。

## 四、它凭什么被请来当替身

经典弹簧链与量子时空，本来八竿子打不着。元相子理论却把它请来当主力数值模型，理由有三条。

格点结构同源。元相子理论的时空是一格一格数出来的，并非一块连续的布：元相子每完成一次满周旋转，就沿法线方向平移一个普朗克长度，一层层叠出空间格子。FK 链的格点恰好也是"一层一个"的离散序列，链上的第 $n$ 个格点直接对应第 $n$ 层。

场变量同源。FK 链的每个格点上有一个实数 $u_n$，描述那一层滑动了多少。它是把相位展开到实轴之后的量，本身并不等于相位，可以读作"以层为单位的轴向位置"。元相子每转满一圈就沿法线平移一层，转过的圈数与叠过的层数因此是同一个量：$u_n$ 的整数部分是已经叠到第几层，小数部分是这一层内相位扫过的比例。链上的滑动与层内的转动，由同一个数管着。这两件事可以一一对上。

kink 自带粒子的骨架。元相子理论里的有质量粒子，是一个坐落在均匀背景上的局域位错。kink 正好是这样一个东西：它有拓扑荷（kink 的数目就是粒子数，也是电荷数），能量有限而且局域，可以被力推动，推起来还有惯性。一个纯经典的玩具，长出了粒子的骨架。

还有一条实用理由：一维链的数值计算又快又稳，同一套判据跑几十遍不会给出两个答案。元相子理论的验证工作要靠大量判据实验支撑，FK 链是最省事的那把尺子。

## 五、对照表

| FK 链上的东西 | 元相子理论里的对应物 |
|---|---|
| 链的格点 | 法线轴上的层，格距为普朗克长度 |
| 格点上的数值 $u_n$ | 那一层的提升相位（整数部分是已叠层数，小数部分是相位角） |
| 橡皮筋 | 层与层之间的键弹性 |
| 蛋托的坑 | 格点内的锁定，把元相子钉在原地 |
| kink | 有质量粒子（复合位错） |
| 链的总缠绕 | 绕数，也就是粒子数，也就是电荷 |

## 六、它会在哪里骗你

替身终归是替身。工作区把这些差异一条条登记在案，其中两条已经有实打实的数值证据。

一维的安稳不代表三维的安稳。把 kink 在三维里的对应物，一个涡旋环，放进体系完整的能量泛函里弛豫，它不在任何中间尺寸停留，一路缩到消失，绕数跟着流失。一维链上稳如磐石的东西，到了三维塌了。元相子理论因此把三维形态单列成攻坚项，不敢把一维结论直接搬过去。

经典的守恒不等于量子的守恒。FK 链的 kink 数守恒是经典拓扑守恒，在理想方程里成立。元相子理论要求的却是电荷的绝对守恒，这是经典模型给不出的。数值上，经典层的绕数在弛豫过程中会流失；真正扛住守恒的是更上一层的量子结构。这条差异改写的是整个分工：经典链负责载体的能量、尺寸与驻留，守恒交给量子层。

还有一条更隐蔽：弹簧该写成什么样。FK 链通常用平方型弹簧（非紧致），元相子理论早先的键弹性写成余弦型（紧致）。两种写法在"kink 有多宽"这个问题上给出相反答案。余弦型下 kink 会塌缩成单键的一处尖角，宽度窗口是空的；平方型下 kink 会舒展开来，宽度才存在。这件事最终由作者裁定：键弹性的原始形式取法线轴高度差，也就是非紧致那一支。

## 七、尺子的用法

FK 链是一把尺子，量的是规律，宇宙本身另说。

尺子量得准不准，取决于你知不知道自己量的是什么。元相子理论的做法写在纪律里：凡是在这条链上得到的结论，一律标注为"模型内判据级"；凡是要依赖一维、经典、某一种弹簧写法的结论，都写明条件；不外推的场合，单列成遗留项，等三维与量子层补上。替身演得再好，谢幕时也得把名字念对。
