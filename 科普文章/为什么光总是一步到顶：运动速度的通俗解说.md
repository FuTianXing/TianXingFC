# 为什么光总是一步到顶：运动速度的通俗解说

## 一个常见但值得追问的现象

光以每秒三十万公里传播，一个电子在原子轨道里只以千分之几光速游荡，一块石头落地的速度只有每秒几米。同样是"动"，速度差别如此悬殊，原因是什么？

要回答这个问题，得先看[[元相子]]宇宙里"速度"和"动量"到底长什么样。

## 速度 = 色散曲线的斜率（几何定义）

元相子宇宙是一大片晶格，光和各种粒子都是晶格上的"波"（[[构型]]）。波的传播速度叫群速度，它由这条波的"色散关系"决定：频率（能量）随波矢（动量）变化的曲线，其斜率就是速度：

$$v = \frac{dE}{dp}$$

这句话的几何含义：一种波跑多快，只看它的能量-动量曲线在这个位置有多陡。**光与粒子的速度差异，完全归结为两条曲线的形状不同。**

## 动量 = 相位拧得多密（方向归波）

晶格里，动量对应什么？注释 09"方向归波"给出答案：[[相位]]差就是波矢，波矢就是动量。**动量是"相位在空间里拧得多密"**：

$$p = \hbar k, \qquad k = \frac{\text{相邻格点相位差}}{l_P}$$

光的动量 = 它那串相位涨落拧得多密；粒子的动量 = 锁定边界的相位梯度集体量。推动一个粒子，本质是让它的相位拧得更密。

## 光：没有势能的线性曲线，只能全力跑

体系里光的色散关系是已知的（注释 03）：

$$\omega^2 = \frac{4}{t_P^2}\sum_a\sin^2\!\Big(\frac{k_a l_P}{2}\Big)$$

在长波极限（波长远大于格距）它化简为 $\omega = c_{\text{eff}} k$：**一条从原点出发的直线**。直线的斜率处处相同，所以群速度恒为介质波速，与波长无关。

为什么光的曲线从原点出发（没有"抬高"）？因为光是方向指针的集体摆动（Goldstone 涨落），摆动没有回正弹性，没有[[势能]]项把频率抬高。**零质量 = 色散从原点出发 = 直线 = 只能以最快速度跑。** 光的 c 是几何锁死的。

## 粒子：曲线在原点被"抬高"，从零起步渐近到 c

粒子（kink，锁定区的边界层）的曲线不同：它有静止质量（拓扑缺陷的绑定能），色散在原点被抬高：

$$E^2 = m^2c^4 + p^2c^2$$

这条曲线的斜率（速度）为：

$$v = \frac{dE}{dp} = \frac{pc^2}{\sqrt{p^2c^2 + m^2c^4}} = \frac{pc}{\sqrt{p^2 + m^2c^2}}$$

从原点的零出发，随动量增大而增大，渐近接近 c 但永远差一口气。**粒子慢，是因为它的能量曲线在原点抬高了 m c²：同样的动量变化，曲线更平，速度更小。** 体重越大，抬高越多，曲线越平，同样推力下越慢。

## 微观实现：每拍走几格

粒子运动 = kink 边界在晶格中一格一格传播。速度对应每拍前进的格数：

$$\text{每拍前进格数} = \frac{v}{c}$$

静止时边界不动；慢速时每拍推进零点几格（边界格点间歇性锁定）；极限时每拍推进一格。**c 在这里是几何恒等式：每格 $l_P$、每拍 $t_P$，比值就是 $c$（注释 04）。**

## 为什么跑不赢光：每拍一格的晶格因果

为什么粒子永远到不了 c？因为晶格的因果结构：任何信息（锁定状态、相位涨落）每拍最多传递一格。kink 边界想跑赢光，就得让锁定状态一拍拍传不止一格，这在晶格结构上被禁止。**速度上限是格点因果的直接推论，不是额外规则。**

## 为什么起步难：格子的"齿"

还有一个微观细节：离散格子像齿轮有齿一样有"台阶"。kink 边界从锁在格点间到锁在下一格点间的过渡中，会出现边界部分跨格的中间状态，这些状态能量更高（奇偶错位）。这个周期性小能垒叫 Peierls 势垒，它给粒子一个静止门槛：推得太轻，粒子纹丝不动；越过了门槛才起步。惯性的微观来源就在这里。

## 宏观物体：天文数字的集体动量

地球的质量是 $10^{27}$ 千克量级，对应约 $10^{57}$ 个元相子。推动地球 = 同时改变这么多构型的相位梯度（集体动量）。要让集体动量大到接近光速对应的值，需要的能量是整个宇宙级别的。日常推力注入的动量相对集体质量微不足道，速度自然小得可怜。

同一个电子可以有两种命运：原子轨道里慢慢游荡（$v \sim c/137$），加速器里被推到 $0.999999c$。机制没有变，变的是相位梯度（动量）被注入多少。

## 还没验证的一环

粒子色散 $E^2 = m^2c^4 + p^2c^2$ 是从体系耦合常数（κ_φ）推导出来的目标（P1-33 遗留），目前晶格集体模式的色散已知（光），粒子（kink）的色散待验证。若推导成功，本图景完整成立；若晶格色散有微小修正，低速区接近牛顿力学，高速区可能出现普朗克尺度能量平方比量级的洛伦兹破坏，这正是体系的可检验预言方向。

## 一句话

**速度是能量-动量曲线的斜率，动量是相位拧得有多密；光的曲线从原点出发（零质量），所以恒速 c；粒子的曲线在原点抬高（绑定能），所以从零起步渐近 c；上限来自每拍一格的晶格因果，惯性来自格子的齿（Peierls 势垒），宏观慢来自天文数字的集体动量。每一步都有几何对应。**
