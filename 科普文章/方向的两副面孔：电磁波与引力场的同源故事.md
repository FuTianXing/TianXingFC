# 方向的两副面孔：电磁波与引力场的同源故事

- **日期**：2026-10-20
- **修订**：2026-10-20 载体口径改写：原"同一片指针、两种模式"改为分工双场，电磁住实轴方向场，引力住法线场（本文初稿成于 2026-09-06）

物理学有两座大山，一座叫电磁力，一座叫引力。它们看起来毫无关系：电磁力管光、电、磁，强度惊人，作用在电荷上；引力管天体、时空、潮汐，弱到拿一块磁铁就能对抗整个地球，作用在质量上。两者强度差了几十个数量级，机制也完全不同：电磁有场方程，引力有弯曲的时空。

但元相子理论给出一个让人意外的答案：这两座大山的地基是同一块石头，都来自一个再朴素不过的东西，方向。只不过它们记在两套不同的方向上。

## 一个根本视角：力都是方向的力

元相子理论的宇宙是一大片振动的晶格，每个格点上住着一个元相子。它的物侧是一个复平面单位圆，这个圆上有三件可以描述的事。

第一件事，圆上的点转到哪里，这叫相位，它滴答滴答地转，快慢恒定，是全宇宙统一的节拍。

第二件事，圆平面本身朝哪边，这叫实轴方向，可以把它想成钟面上立着的一根指针，指针指向哪里，是这个格点的取向。

第三件事，圆平面垂直于什么方向，那是法线轴。元相子每转满一圈就沿这根轴跳一格，轴的朝向因此也连成一片场，管它叫法线场。

力都写进方向，只是写的地方不同。电磁写在前两样上：实轴方向场的邻差给出波矢、光与静电，联络与曲率另有载体，归基准方向场。引力写在第三样上：法线场上的一层静倾角。

## 电磁：指针的摆动

想象一大片指南针，你轻轻拨动其中一个，它摆起来，邻居跟着摆，摆动一圈圈传开。这就是光：实轴方向场承载的波的集体摆动，通俗说就是"方向场自己发出的波"。

规范侧结构不走这条通道。电磁场里的曲率住在基准方向场的联络上，与实轴方向场的摆动是两套载体。把曲率记成指针之间的差，绕一圈的净转角会恒为零，电磁场便无从产生。

为什么光没有质量？因为指针摆动没有"回正"的弹性。一个钟摆摆动有质量，因为重力把它拉回竖直位置；方向指针没有一个"标准方向"把它拉回去，摆动起来就没有阻力，于是光以最快的速度传播，而且永不停息。

电荷呢？电荷是绕数：带电粒子的相位绕着圈走，拧了多少圈就是多少电荷。两个带电粒子怎么互相感觉到？每次碰撞，电荷的"拧圈"信息被邻居抄写走，写进实轴方向场的邻差。邻差沿面元一周求和给出环量，环量再走一圈给出绕数，光的传播与静电的分布都住在这张场里。

## 引力：法线场的静倾角

现在说引力。有质量的粒子（复合位错粒子，一个被"冻住"的拓扑缺陷）住在自己那一格，从头到尾没有动过。它做的唯一一件事，是每拍往法线场上写一笔。

写的是一份挂在法线轴上的倾角：

$$\delta\theta = \frac{m}{m_P}$$

法线场的静态形态可以这样看：每格点上方托着一张小小的牌面，牌面法线的方向就是法线轴的方向，这方向始终守住自己。记录落在牌面之间那一点高低差上。所谓法线场的静倾角，指的正是这层高低差，牌面不因记录而转向。

质量越大，每拍写下的高低差越多。粒子不动，它只是停在那里，让每次碰撞"看见"它，然后写下一笔。

高低差不会留在原地。每拍，邻居把彼此的高低差互相抄写、互相平均，就像把一片起伏的牌面向四周抹平。写一笔、抹平一点，两者达到平衡时，偏移从中心向外按 $1/r$ 衰减，这个分布的形状，正是牛顿引力势。

换句话说，引力场是一片静态起伏的牌面：质量在哪里，哪里的牌面偏得厉害，偏的程度随距离衰减。宏观上，这层静倾角就是时间膨胀和空间弯曲：离质量近的地方，倾角大，摆程计数慢，钟就走得慢。

引力为什么这么弱？因为每拍只写下 $10^{-23}$ 量级的微小倾角。它微弱的原因在于写入的份额本身就极小，这是引力在所有力中最弱的直接几何解释。

这道倾斜还有一个好性质：它向外"建立"的速度恰好是光速（每拍一格），所以引力场不会超光速传播，因果性完好；建立完成后它是静态的，不会像波一样永远向外跑。

## 两套朝向，两个载体

现在把两件事并排看。电磁在实轴方向场上，表现为指针在钟面里的摆动；引力在法线场上，表现为牌面高低差静静起伏。一个管取向，一个管倾斜，载体不同，物理上不混。

它们共享的是同一张格子与同一套几何。引力写下的倾斜会改变光走路的几何，光的能量又回头成为引力的源，两边是耦合的，却始终没有把一种场翻译成另一种场的交叉项。

这种分工回答了一个老问题：为什么电磁和引力都遵守平方反比律（$1/r^2$）？两者的场都由局域的源经同一张格子传出去，稳态分布都是格林函数型的 $1/r$，平方反比律是它的直接后果。电荷决定摆动的强弱，质量决定牌面偏得多深。

| | 电磁 | 引力 |
|---|---|---|
| 载体 | 实轴方向场（钟面内的指向） | 法线场（垂直于钟面的朝向） |
| 场的动作 | 指针摆动（交流，随时间振荡） | 牌面高低差（直流，不随时间变） |
| 源 | 电荷 = 拧圈数（绕数） | 质量 = 每拍写入的倾角幅度 |
| 微观动作 | 碰撞时读取并传递拧圈信息 | 碰撞时向法线场写入一笔倾角 |
| 宏观面目 | 光、电场、磁场 | 时空弯曲、时间膨胀 |
| 强度 | 强 | 极弱（每拍 $10^{-23}$ 弧度） |

## 还在路上的部分

需要说明的是，这两个机制的完成度不同。电磁机制在体系内已经定稿：光 = 实轴方向场的摆动，电荷 = 绕数，规范结构 = 基准方向场的联络与曲率，一整条链完整闭合。

引力机制走得更晚，它是碰撞写入加标架联络。静态弱场的四步链条已经完成并逐环有凭据：写入与扩散的稳态精确复现牛顿势，$4\pi$ 自动涌现，链接合成给出泊松方程，再由标准三步推广到协变形式。

即便如此，这幅图景已经足够清楚：宇宙最弱与最强的两种长程力，都写进方向，只是一张写取向，一张写倾斜。物理学的两座大山，在地基处是同一块石头。
