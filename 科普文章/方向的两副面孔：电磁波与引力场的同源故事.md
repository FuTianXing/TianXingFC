# 方向的两副面孔：电磁波与引力场的同源故事

物理学有两座大山，一座叫电磁力，一座叫引力。它们看起来毫无关系：电磁力管光、电、磁，强度惊人，作用在电荷上；引力管天体、时空、潮汐，弱到拿一块磁铁就能对抗整个地球，作用在质量上。两者强度差了几十个数量级，机制也完全不同：电磁有场方程，引力有弯曲的时空。

但元相子理论给出一个让人意外的答案：这两座大山的地基是同一块石头，都来自一个再朴素不过的东西，方向。

## 一个根本视角：力都是方向的力

元相子理论的宇宙是一大片振动的晶格，每个格点上住着一个元相子。它的物侧是一个复平面单位圆，这个圆有两件可以描述的事：

第一件事，圆上的点转到哪里，这叫相位，它滴答滴答地转，快慢恒定，是全宇宙统一的节拍。

第二件事，圆平面本身朝向哪个方向，这叫实轴方向。可以把它想成每个格点上插着的一根小指针，指针指向哪里，是这个格点的"方向感"。

邻居之间的小指针指向不同，这个"不同"里就藏着力的全部信息。格点之间每过一个普朗克时间碰撞一次，碰撞就是一次"快照抄写"：互相读取对方指针的方向，记入自己的状态。

在这个图景里，电磁力和引力是同一个小指针的两种变化方式。一种变化是摆动，另一种变化是静态偏移。就像同一根琴弦，可以振动出声音，也可以被弯成某个形状，两件事同时发生在同一根弦上。

## 电磁：指针的摆动

想象一大片指南针，你轻轻拨动其中一个，它摆起来，邻居跟着摆，摆动一圈圈传开。这就是光：实轴方向场承载的波的集体摆动，通俗说就是"方向场自己发出的波"。（规范侧结构不走这条通道：联络与曲率由基准方向场承载，与实轴的摆动是两套载体。）

为什么光没有质量？因为指针摆动没有"回正"的弹性。一个钟摆摆动有质量，因为重力把它拉回竖直位置；而方向指针没有一个"标准方向"把它拉回去，摆动起来就没有阻力，于是光以最快的速度传播，而且永不停息。

电荷呢？电荷是绕数：带电粒子的相位绕着圈走，拧了多少圈就是多少电荷。两个带电粒子怎么互相感觉到？每次碰撞，电荷的"拧圈"信息被邻居抄写走，影响邻居指针的摆动方向。相邻格点指针方向的差，就是电磁场在微观世界的身份；这个差的传播，就是电磁力的传递。电荷的拧圈数越大，对指针摆动的推动越强。

## 引力：指针的静态褶皱

现在说引力。有质量的粒子（复合位错粒子，一个被"冻住"的拓扑缺陷）每碰撞一次，就让自己格点的指针偏转一小角：

$$\delta\theta = \frac{m}{m_P}$$

质量越大，每拍拨得越多。注意一个关键点：粒子从头到尾没有动过，它只是停在那里，让每次碰撞"看见"它，然后写下一笔偏转。

偏转不会留在原地。每拍，格点还把指针方向向邻居平均一点，这叫抄写平均，就像把一堆沙向四周抹平。写一笔、抹平一点，两者达到平衡时，指针的偏转从中心向外按 $1/r$ 衰减。这个分布的形状，正是牛顿引力势。

换句话说，引力场是一道静态的褶皱：质量在哪里，哪里就把周围的"方向感"压弯，弯的程度随距离衰减。宏观上，这道褶皱的深与浅就是时间膨胀和空间弯曲：离质量近的地方，指针偏转大，摆程计数慢，钟就走得慢。

引力为什么这么弱？因为每拍只拨 $10^{-23}$ 量级的微小角度。它微弱的原因在于拨动的力度本身极其微小，这是引力在所有力中最弱的直接几何解释。

这道褶皱还有一个好性质：它向外"建立"的速度恰好是光速（每拍一格），所以引力场不会超光速传播，因果性完好；建立完成后它是静态的，不会像波一样永远向外跑。

## 同一片指针，两种用法

现在把两件事并排看：摆动是电磁，静态偏移是引力。它们住在同一片指针场里，互不干扰，因为一个是交流（随时间振荡），一个是直流（时间平均后不变的偏移）。信号处理里有个熟悉的图景：一条信号线可以同时携带直流偏置和交流振荡，叠加在一起，各自传播。

元相子理论把这两种力归结为方向指针的两种变化模式，这解决了一个老问题：为什么电磁和引力都遵守平方反比律（$1/r^2$）？因为它们都来自同一个方向场，只是源的种类不同。电荷决定摆动的强弱，质量决定褶皱的深浅。

| | 电磁 | 引力 |
|---|---|---|
| 指针的变化 | 摆动（交流，随时间振荡） | 静态偏移（直流，不随时间变） |
| 源 | 电荷 = 拧圈数（绕数） | 质量 = 每拍拨动幅度 |
| 微观动作 | 碰撞时读取并传递拧圈信息 | 碰撞时写入一笔偏转 |
| 宏观面目 | 光、电场、磁场 | 时空弯曲、时间膨胀 |
| 强度 | 强 | 极弱（每拍 $10^{-23}$ 弧度） |

## 还在路上的部分

需要说明的是，这两个机制的完成度不同。电磁机制在体系内已经定稿：光 = 方向场的摆动，电荷 = 绕数，规范场 = 取向差，一整条链完整闭合。引力机制（方向 6，碰撞写入加标架联络）走得更晚，它的数学骨架已经通过数值验证：写入加扩散的稳态精确复现牛顿势，$4\pi$ 自动涌现。但还有几个环节在形式化中，比如每拍拨动幅度与质量的精确换算、以及为什么摆动（光）不会在抄写平均中被抹平。

即便如此，这幅图景已经足够让人印象深刻：宇宙最弱与最强的两种长程力，在元相子理论里共享同一个微观对象，方向。电磁是它的舞动，引力是它的静默。物理学的两座大山，在地基处是同一块石头。
