# 三代粒子质量之谜：圆上三个点的影子

傅天行
（天行新学研究院）

标准模型回答了"粒子怎么获得质量"，却把另一个问题原封不动地留下了：电子、缪子、陶子这三种长得几乎一样的粒子，质量却分别是 0.511 MeV、105.7 MeV、1777 MeV，比例是 1 : 207 : 3517。这三个数字没有任何看得出的规律：不翻倍，不成平方，不成等比。更奇怪的是，为什么偏偏是三代，不是一代，不是四代？这篇文章想讲一个可能的答案，它来自元相子理论，而且答案的图景出奇地简单：三代粒子的质量，是同一个圆上三个等距点投在墙上的影子。三个点、一个圆、一面墙，这就是全部的道具。

先把这个谜题说清楚。1960 年代以来，粒子物理积累起一张精确得吓人的质量表。轻子这一栏有三个粒子：电子、缪子（可以理解成"电子的大哥"）、陶子（"最大的那个电子"），其他性质一模一样，只是质量依次变大。把它们开根号，得到 0.71、10.28、42.15，比例是 1 : 14.4 : 59。1982 年，日本物理学家小出（Koide）盯着这三个数，发现了一个令人坐立不安的关系：三个轻子的质量之和，除以三个质量根之和的平方，恰好等于三分之二。这个关系精确到什么程度？万分之一量级，相当于你量了三根头发的直径，发现它们满足一个精确的代数关系，误差不到一根头发丝的万分之一。四十年过去了，没有人能说出这个三分之二从哪来。它就这么躺在数据里，像一扇没人找到钥匙的门。本文的挑战，就是找这把钥匙。

钥匙的第一截在"为什么是三个"。元相子理论的科普前辈《质量的来源》讲过：物理真空是一张床垫，每个格点上有三根互相垂直的弹簧摆，它们之间有一股极软的牵连。这里要补充一个此前没被强调的细节：三根弹簧摆不只是互相垂直，它们是"完全等价"的。世界没有偷偷偏爱 X 方向，把 X 换成 Y、Y 换成 Z、Z 换成 X，所有物理规则原封不动。这句话听起来平淡，实际上是一条很强的对称性。打个比方：一片三叶草，旋转 120 度之后和原来一模一样，这种对称在数学上叫 Z₃ 轮换对称，意思是"转三分之一圈，一切照旧"。三根等价的弹簧摆，天然拥有这种三叶草式的对称。于是"三代"这个词第一次有了出处：一个三叶草式的对称结构，绕着圈数下去，恰好数到三个位置，就回到起点。第四代没有地方可放，就像三叶草没有第四片叶子，实验限度拦不住它，结构上它根本不存在。

钥匙的第二截接在上一篇文章的结尾。《质量的来源》讲过，粒子是那次古老"结冰"留下的冻坏角落（σ 锁定孤子），它携带的能量差和质量成正比，而这个能量差的来源是它和真空定居密度的耦合，耦合强度就是标准模型里那个神秘的 Yukawa 系数。现在我们问：这个耦合强度由什么决定？结论可以是这样的：每个粒子内部有一根"质量指针"，它是一个复数，有自己的长度和方向。粒子与真空凝聚的耦合强度，取决于这根指针在实轴上投下影子有多长。质量开根号，就等于影子的长度。为什么要开根号？因为复数向实轴的投影天然是"长度"这个量，而质量是长度平方，物理学家习惯叫它"模方"，和量子力学里概率是振幅模方的规则是一家人。这面"墙"就立在元相子理论里那条著名的实轴上：实轴承载粒性，承载一切落地的、实在的、可数的东西，质量是最实在的属性，从实轴的影子里来，顺理成章。

现在把两截钥匙合起来看。一根指针可以绕圈转，转的角度记作 $\theta$。如果粒子内部有三个方向等价的弹簧摆，那么"三根指针"没有理由挤在一起，三叶草对称性要求它们均匀地摊开：一根指 0 度，第二根就指 120 度，第三根指 240 度，正好把一圈三等分。于是三个质量根就是三个等距点在墙上的影子。这里数学上有一个漂亮的闭环：任意三个点，只要它们均匀分布在圆上（间隔 120 度），它们的影子按"平方"换算成质量之后，自动满足 Koide 那个三分之二的关系，一个不多一个不少。反过来，实验数据恰好落在三分之二上，说明三个质量根确实可以从圆上三个等距点的影子重新拼出来。四十年谜题的钥匙就在这里：Koide 公式那个神秘的 120 度（三分之二在数学上等价于三等分），就是三根等价弹簧摆的对称性在质量上的投影。数据没有眼花，物理结构早就在那里。

这个故事还剩最后一个惊人的细节。三个等距点均匀摊开之后，还剩一个自由度：整组点一起绕圆转多少度，这个起点角度记作 $\varphi$。用实验数据反推，$\varphi \approx 0.22227$ 弧度，约 12.7 度。这个数字看起来平平无奇，除非你注意到它非常接近 2/9，也就是 0.2222…，两者相差约万分之五。2/9 这个分数的来历值得注意，它是"2 除以 3 的平方"，而 3 正是模态数，是那三根弹簧摆的数目。模态数的逆平方，恰好出现在质量谱的起点角度里。如果大胆假设 $\varphi$ 精确等于 2/9，整个轻子质量谱就一个自由参数都不剩了：代入算出的质量比是 1 : 206.8 : 3477.5，实测是 1 : 206.768 : 3477.23，吻合到万分之二和十万分之八。一个传统上需要三个独立参数（三个 Yukawa 耦合）才能描述的谱，现在只剩一个角度，而这个角度还恰好等于模态数的逆平方。就像你拼图拼到最后，发现缺的那块不只形状吻合，连背面的颜色都对上了。

这个故事给出三个可以检验的承诺。第一个承诺，自然界不会有第四代轻子，也不会有什么第四代夸克。三叶草只有三片叶子，对称结构只给三个位置。如果未来的对撞机真的冒出一个第四代粒子，这个图景连同它的公理基础一起被推翻，这是硬碰硬的证伪条件。第二个承诺，把缪子和陶子的质量测得更准。起点角度 $\varphi$ 是否精确等于 2/9，直接决定质量比该是多少，实验精度每提高一档，这个数就被检验一次。数字会说话，不需要等什么未来技术。第三个承诺，高温下三代质量会渐渐靠拢。温度高到真空凝聚解体时，粒子与凝聚的锁定消失，三根指针的差别失去依托，三个质量根会慢慢并成同一个数。标准模型对"温度升高时三代质量各自如何变化"没有给出这种预言，这条温度曲线是独家的。

最后，诚实地交代这个图景还没有完成的三件事。第一，质量指针向实轴的投影这条规则，目前还是一把没有装配上门框的钥匙，它需要从体系的基础方程推导出来，不能只当作假设接受下来，这是接下来最硬的一块工作。第二，起点角度为什么恰好是 2/9，我们有一个候选的想法（它可能是天行力校准趋向最大相干的固定点），但还没有给出计算，目前它还是一个精度高得可疑的观测巧合。第三，夸克世界还没有完全对上号：顶夸克比陶子重近百倍，夸克的质量根也不严格满足三分之二的关系，色结构对质量谱的修饰只列明了方向，没有算完。轻子这条线已经咬合得很漂亮，夸克那条线是明摆着的后续工作。科学里最让人振奋的时刻，常是谜题终于露出可以继续啃下去的结构，结论完美与否反而在其次。三代质量之谜啃了四十年，现在我们知道它至少是一把带齿的钥匙了：圆上三个点，投在实轴的墙上，转过的角度是模态数的逆平方。
