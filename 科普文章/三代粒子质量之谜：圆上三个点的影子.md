# 三代粒子质量之谜：圆上三个点的影子

傅天行
（天行新学研究院）

标准模型回答了"粒子怎么获得质量"，却把另一个问题原封不动地留下了：电子、缪子、陶子这三种长得几乎一样的粒子，质量却分别是 0.511 MeV、105.7 MeV、1777 MeV，比例是 1 : 207 : 3517。这三个数字没有任何看得出的规律：不翻倍，不成平方，不成等比。更奇怪的是，为什么偏偏是三代，不是一代，不是四代？这篇文章想讲一个可能的答案，它来自[[元相子]]理论，而且答案的图景出奇地简单：三代粒子的质量，是同一个圆上三个等距点投在墙上的影子。三个点、一个圆、一面墙，这就是全部的道具。

先把这个谜题说清楚。1960 年代以来，粒子物理积累起一张精确得吓人的质量表。轻子这一栏有三个粒子：电子、缪子（可以理解成"电子的大哥"）、陶子（"最大的那个电子"），其他性质一模一样，只是质量依次变大。把它们开根号，得到 0.71、10.28、42.15，比例是 1 : 14.4 : 59。1982 年，日本物理学家小出（Koide）盯着这三个数，发现了一个令人坐立不安的关系：三个轻子的质量之和，除以三个质量根之和的平方，恰好等于三分之二。这个关系精确到什么程度？万分之一量级，相当于你量了三根头发的直径，发现它们满足一个精确的代数关系，误差不到一根头发丝的万分之一。四十年过去了，没有人能说出这个三分之二从哪来。它就这么躺在数据里，像一扇没人找到钥匙的门。本文的挑战，就是找这把钥匙。

钥匙的第一截在"为什么是三个"。元相子理论的科普前辈《质量的来源》讲过：物理真空是一张床垫，每个格点上有三根互相垂直的弹簧摆，它们之间有一股极软的牵连。这里要补充一个此前没被强调的细节：三根弹簧摆不只是互相垂直，它们是"完全等价"的。世界没有偷偷偏爱 X 方向，把 X 换成 Y、Y 换成 Z、Z 换成 X，所有物理规则原封不动。这句话听起来平淡，实际上是一条很强的对称性。打个比方：一片三叶草，旋转 120 度之后和原来一模一样，这种对称在数学上叫 Z₃ 轮换对称，意思是"转三分之一圈，一切照旧"。三根等价的弹簧摆，天然拥有这种三叶草式的对称。于是"三代"这个词第一次有了出处：一个三叶草式的对称结构，绕着圈数下去，恰好数到三个[[位置]]，就回到起点。第四代没有地方可放，就像三叶草没有第四片叶子，实验限度拦不住它，结构上它根本不存在。

这里值得停下来，把两个容易问到的细节说清楚。三根弹簧摆给出了三种模态，三代粒子也是三，这两件"三"是什么关系？模态是[[相位]]扰动的三种波形，对应三个方向，它们是原料；对称性把三种波形的相位拧成一条三等分的轨道，就像把三户人家安排进同一栋楼的三个楼层。楼[[层数]]是代际，住户是粒子家族。关键的事实是，每一层楼住的是一模一样的一套人家，电子、中微子、上夸克、下夸克全都齐备。一个家族是否齐全由别的自由度决定，[[电荷]]、色、弱相互作用定下住户名单；代际只决定这个家族住在哪一层，也就是质量有多大。三根弹簧摆给出楼层数，给不出住户名单。

电子为什么恰好是"第一代"？准确的说法是：电子是带电轻子家族在质量轴上的基态。三个质量根排成一行，0.71、10.28、42.15，最轻的那个被人类命名为电子，其次缪子，最重陶子。名字按质量贴，暗含一个历史的偶然：人类先遇到了最轻的成员。假如把整条轨道集体转 120 度，三个质量根一个都不会变，变的只是哪根对应哪个名字。物理只认三个数，不认编号，"第一代第二代第三代"的序号是人的约定，"谁最轻谁最重"才是物理事实。附带一个推论：既然三代是同一个家族住进三个楼层，第四代是否存在就等于这栋楼有没有第四层，而三叶草对称已经回答：没有。

钥匙的第二截接在上一篇文章的结尾。《质量的来源》讲过，粒子是那次古老"结冰"留下的冻坏角落（[[复合位错粒子]]），它携带的能量差和质量成正比，而这个能量差的来源是它和真空定居密度的耦合，耦合强度就是标准模型里那个神秘的 Yukawa 系数。现在我们问：这个耦合强度由什么决定？结论可以是这样的：每个粒子内部有一根"质量指针"，它是一个复数，有自己的长度和方向。粒子与真空凝聚的耦合强度，取决于这根指针在实轴上投下影子有多长。质量开根号，就等于影子的长度。为什么要开根号？因为复数向实轴的投影天然是"长度"这个量，而质量是长度平方，物理学家习惯叫它"模方"，和量子力学里概率是振幅模方的规则是一家人。这面"墙"就立在元相子理论里那条著名的实轴上：实轴承载粒性，承载一切落地的、实在的、可数的东西，质量是最实在的属性，从实轴的影子里来，顺理成章。

现在把两截钥匙合起来看。一根指针可以绕圈转，转的角度记作 $\theta$。如果粒子内部有三个方向等价的弹簧摆，那么三根弹簧的"舞步"必须均匀错开。注意这里的角度和空间方向无关：三根弹簧的站姿（法线朝向）依然是互相垂直的 90 度，120 度是它们相位零点（表盘零点）的相对错开，就像三相交流电的三根火线相位差 120 度，和电线在空间里怎么摆放没有关系。还要强调，三根弹簧的摆动快慢完全一样，统一的节拍由普朗克旋转钉死，谁也不能快慢不同；错开的只是各自表盘的零点刻度，走时同步，读数不同。这个零点刻度所在的那根轴，就是实轴：每个元相子的圆心处都有一条实轴，它当摆程的起点和回归点；它指向哪个方向是可以变的，这个方向叫实轴取向。角度的计算需要一把不动的尺子：每个复平面作为数学对象自带一个固定方向（叫零度基准），实轴相对这把尺子转过的角度，就是它的取向。为什么必须错开 120 度？因为"X 换成 Y、Y 换成 Z、Z 换成 X"再换回 X，一共换三圈必须回到原样，数学上这种"三阶循环"的固有节拍只有 0 度、120 度、240 度三种可能，再没有别的选择（先不关心整组指针转到哪，把起点对齐到 0 度）：一根指 0 度，第二根就指 120 度，第三根指 240 度，正好把一圈三等分。于是三个质量根就是三个等距点在墙上的影子。这里数学上有一个漂亮的闭环：任意三个点，只要它们均匀分布在圆上（间隔 120 度），它们的影子按"平方"换算成质量之后，自动满足 Koide 那个三分之二的关系，一个不多一个不少。反过来，实验数据几乎正好落在三分之二上，说明三个质量根几乎可以从圆上三个等距点的影子重新拼出来（这个"几乎"是诚实标注：数据高度接近、但并未完美落在三等分上，下文 φ ≈ 2/9 的预言正是对这个偏差的裁决）。四十年谜题的钥匙就在这里：Koide 公式那个神秘的 120 度（三分之二在数学上等价于三等分），就是三根等价弹簧摆的对称性在质量上的投影。数据没有眼花，物理结构早就在那里。

这个故事还剩最后一个惊人的细节。三个等距点均匀摊开之后，还剩一个自由度：整组点一起绕圆转多少度，这个起点角度记作 $\varphi$。用实验数据反推，$\varphi \approx 0.22227$ 弧度，约 12.7 度。这个数字看起来平平无奇，除非你注意到它非常接近 2/9，也就是 0.2222…，两者相差约十万分之五。2/9 这个分数的来历值得注意，它是"2 除以 3 的平方"，而 3 正是模态数，是那三根弹簧摆的数目。模态数的逆平方，恰好出现在质量谱的起点角度里。如果大胆假设 $\varphi$ 精确等于 2/9，整个轻子质量谱就一个自由参数都不剩了：代入算出的质量比是 1 : 206.8 : 3477.5，实测是 1 : 206.768 : 3477.23，吻合到十万分之一和十万分之七。一个传统上需要三个独立参数（三个 Yukawa 耦合）才能描述的谱，现在只剩一个角度，而这个角度还恰好等于模态数的逆平方。就像你拼图拼到最后，发现缺的那块不只形状吻合，连背面的颜色都对上了。

故事讲到一半，要把希格斯机制和这个方案的分工说清楚，免得误会成两套理论打架。希格斯机制管"井有多深"：真空里有一口所有粒子共用的井（定居密度，246 GeV），粒子像碗一样从井里舀水，碗舀到的重量就是质量；井深对所有代完全一样，它还顺手解释了 $W$、$Z$ 粒子为什么重、光子为什么天生没有质量。模态轮换方案管"碗有多大"：三代粒子的碗口大小之比是 1 : 14.4 : 59（质量是碗容量的平方）。碗的大小由轨道上的位置决定，与井的深度毫无关系，所以按代算的质量比（1 : 207 : 3517）才敢以万分之一精度成立，完全不需要知道电弱标度是多少。井深和碗大，各管各的，合起来才是质量。

这个分工还顺手解释了标准模型里最刺眼的一个小数字：电子的 Yukawa 耦合小到百万分之一量级，像一个苦心布置的巧合。在轨道图景里，原因简单得近乎平淡：电子的投影点几乎贴在墙根上。它对应的相位角是 132.7 度，而投影完全消失的那个角度是 135 度，两者只差 2.3 度。电子是三代里最轻的，而且轻得不成比例，因为它的指针影子恰好落在投影即将为零的位置附近；差的那 2.3 度救了它，让电子有了一点点质量，而没有彻底变成幽灵。标准模型里那个天文数字般的输入，在这里是一个几何事实加上一点运气。

这个故事给出三个可以检验的承诺。第一个承诺，自然界不会有第四代轻子，也不会有什么第四代夸克。三叶草只有三片叶子，对称结构只给三个位置。如果未来的对撞机真的冒出一个第四代粒子，这个图景连同它的公理基础一起被推翻，这是硬碰硬的证伪条件。第二个承诺，把缪子和陶子的质量测得更准。起点角度 $\varphi$ 是否精确等于 2/9，直接决定质量比该是多少，实验精度每提高一档，这个数就被检验一次。数字会说话，不需要等什么未来技术。第三个承诺，高温下三代质量会渐渐靠拢。温度高到真空凝聚解体时，粒子与凝聚的锁定消失，三根指针的差别失去依托，三个质量根会慢慢并成同一个数。标准模型对"温度升高时三代质量各自如何变化"没有给出这种预言，这条温度曲线是独家的。

最后，诚实地交代这个图景还没有完成的三件事。第一，质量指针向实轴的投影这条规则，目前还是一把没有装配上门框的钥匙，它需要从体系的基础方程推导出来，不能只当作假设接受下来，这是接下来最硬的一块工作。第二，起点角度为什么恰好是 2/9，我们有一个候选的想法（它可能是天行力校准趋向最大相干的固定点），但还没有给出计算，目前它还是一个精度高得可疑的观测巧合。第三，夸克世界还没有完全对上号：顶夸克比陶子重近百倍，夸克的质量根也不严格满足三分之二的关系，色结构对质量谱的修饰只列明了方向，没有算完。轻子这条线已经咬合得很漂亮，夸克那条线是明摆着的后续工作。科学里最让人振奋的时刻，常是谜题终于露出可以继续啃下去的结构，结论完美与否反而在其次。三代质量之谜啃了四十年，现在我们知道它至少是一把带齿的钥匙了：圆上三个点，投在实轴的墙上，转过的角度是模态数的逆平方。


# 这个方案的核心思想，用大白话说

## 一句话版

**三代粒子的质量，是"圆上三个等距点的影子"；而那三个点之所以等距，是因为世界的三个方向完全等价。**

## 一步步说

**第一个事实：粒子有"三代"，质量还很怪。** 电子、缪子、陶子长得一模一样，就是体重不同：1 斤、207 斤、3517 斤。物理学家盯着这三个数看了四十年，看不出任何规律，还发现一个更邪门的公式（Koide 公式），精度高到万分之二，却没人知道它从哪来。

**第二个事实：世界的格子点上有三根完全平等的弹簧。** 真空的每个格点上，有三根朝三个方向（X、Y、Z）摆动的弹簧，它们完全平等：把 X 换成 Y、Y 换成 Z、Z 换成 X，世界一点不变。就像三叶草，转 120 度还是它自己。

**核心思想的第一步：三代 = 三叶草的三片叶子。** 三根弹簧既然完全平等，它们没有理由挤在一起，对称性会把它们"抻"开，抻成圆上三个等距的点：0 度、120 度、240 度，正好一圈。转一圈只有三个位置，所以只有三代，第四代连位置都没有。

**核心思想的第二步：质量 = 影子。** 每个点都拿着一只手电筒，往一堵墙上照，墙是"实在"这堵墙（哲学上叫实轴，装的就是粒子、质量这些"实在的东西"）。影子长短开根号就是质量，影子长短的平方就是质量本身。三个等距点照出的影子长短当然不同，这就是三代质量不同的来源。

**核心思想的第三步：那个怪公式，原来是影子的必然结果。** 圆上三个等距点（120°）的影子，套进 Koide 公式，分数刚好是 2/3，一个不多一个不少。也就是说，四十年没人能解释的 2/3，就是"三个等距点必然砸出来的影子比"。谜底不是数字魔法，是几何。数据还真就几乎完美坐在这个 2/3 上。

**最后一步：唯一剩的自由度，恰好是 2/9。** 三个点整体绕圈转到哪里，还剩一个角度可以动，实验量出来是 12.7 度。而 12.7 度几乎就等于 2/9（差十万分之五），2/9 是"3 的平方"倒过来乘 2。用这个数去预言质量：1 : 206.8 : 3477.5，实测是 1 : 206.768 : 3477.23，准到十万分之一。传统上要三个参数才能描述的三代质量，现在只剩一个角度，而这个角度是 2/9，一个有理由的数字。

## 用一个画面收尾

> 宇宙深处的真空里，有三根一模一样的弹簧。它们司旋转，也守对称。在它们转圆的一圈里，匀匀地站着三个点，点上的光打到"实在"的墙上，落出三条长短不一的影子。我们把这三条影子称为：电子、缪子、陶子。影子转过的起点角度，刻着 2/9。

## 诚实的尾巴

这条链有三处还没焊死：为什么"质量等于影子"（而不是别的算法），目前是假设，还没从方程推出来；2/9 为什么偏偏是 2/9，只有候选解释；夸克那边（顶夸克比陶子重近百倍）还没完全对上。但骨架已经咬住了：**三代是三个等价方向的必然，怪比例是三等分圆的必然，2/9 是悬在头顶的终极考验。**
