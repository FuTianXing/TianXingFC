# 份额记录决定场论：量子场论物侧基础四通道的通俗解说

- **定位**：以"份额借贷 + 床垫扭结"讲透产生湮灭、泡利、相互作用与重整化的来源

---

教科书里的量子场论（QFT）有四个规定好的动作：粒子能从真空冒出来、费米子不能挤在一块、两个粒子的力长成某个形状、算出来的无穷大可以被抹掉。四个动作各有名字：产生湮灭算符、泡利不相容、拉格朗日量、重整化。它们的共同点是谁都答不上"为什么"。元相子方案做的事情，是把这四个规定动作逐一变成弹簧床垫上的必然结果。

先认识贯穿全场的工具：份额。一大群元相子组成世界，按模式分块，每块占一份比例，份额加起来恒等于 1。这一条废话级的恒等式，就是全部场论逻辑的开头。

第一件事，粒子从哪来。真空在元相子图像里始终携带剩余内容：它是"剩下的份额"，粒子是"从真空那份里划出来的块"。产生一个粒子 = 从剩余份额中划出一块凝结而成；湮灭 = 把份额还回去。份额恒等式 $p_{\text{真空}} + \sum_k n_k p_k = 1$ 让粒子数守恒变成份额记录的必然，脱离天降规则的地位。真空那份剩余的份额还会涨落（相干涨落），涨落可以"借出"一对粒子，这就是真空极化的来源。份额有限，宇宙能装的粒子数也就有限：划完了就没有了，$N_{\max} = \lfloor 1/p_{\min}\rfloor$。

第二件事，费米子为什么互相排斥。粒子内部是一根半扭转的环（莫比乌斯带式，绕一圈变号），这给出自旋 1/2，是几何与表示论的事实。但两个粒子交换时变不变号（费米子变号、玻色子不变号），体系诚实地承认几何本身拍不了板，需要一套定理，而定理的三个前提：相对论性（色散 $\omega^2 = \omega_0^2 + c^2k^2$ 与低能洛伦兹）、正能谱（能隙 $\omega_0 > 0$）、微观因果性（群速度小于光速、光锥即因果边界），在体系里逐一对得上号。三前提齐备，引用标准定理，半整数自旋为费米子。泡利不相容于是变成：两个同态粒子的联合份额为零，在份额记录里写死了。

第三件事，两个粒子的力从哪来。把床垫耦合从微小扰动的近似放开到全阶，余弦耦合的完整形式推出连续极限方程，结果恰是著名的 sine-Gordon 方程（线性极限精确回退到熟悉的波动方程，自检通过）。这个方程的扭结解就是粒子本体：一个粒子 = 床垫上的一个拓扑扭结，带正负电荷荷；两个同向扭结相斥、一正一反相吸，力随距离指数衰减（$V \sim \pm V_0 e^{-2s/\xi}$），相互作用的形式由此算出，猜测的角色被排除；一正一反的扭结对能绑在一起共振跳动（呼吸子），给粒子提供生成机制；包络调制还给出非线性色散：密度越高频率越高（Gross-Pitaevskii 型），高密度世界的签名藏在里面。

第四件事，无穷大为什么能抹掉，以及世界为什么精确洛伦兹。晶格有最小格子（$l_P$），动量自然截断在 $\pi/l_P$，圈积分天然有限，重整化从"抹无穷大的手术"变成"把小格合并成大格的粗粒化"，可重整性是自生的。更漂亮的一条：晶格留下的洛伦兹破坏项是高维的不可关算子，能量尺度每降一级它就被压制一次，最终蜷缩到 $(E/E_P)^2$ 的量级。低能世界精确洛伦兹因此有了证明：破坏项活不下来。顺带，干涉能力也有一条尺度律：相干因子在粗粒化下按 $\|\eta\|^2 \propto 1/L$ 稀释，系统越大宏观叠加越弱，宏观经典性从神秘之谜变成记录的自然流动，并给时间箭头一个微观侧面。

四件事合流之后的结论：整座量子场论变成份额记录的展开。概率 = 份额、联合概率 = 联合份额、占有数 = 份额量子、真空 = 剩余份额、容量 = 份额不等式，从份额记录开始，到份额记录结束。
