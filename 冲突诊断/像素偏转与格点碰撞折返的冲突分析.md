## 一、问题的提出

《论引力机制的微观起源》以像素偏转机制严格推导静态弱场引力的微观起源：有质量粒子每个普朗克时间生成一个空间像素，方向偏转 $\delta\theta = m/m_P$，相邻像素构成扇形回路，平行输运角差 $\delta\theta$ 定义微观曲率源，累积得泊松方程。该论文声称"像素的更新机制已由束缚振荡的逐摆程折返刷新解决"（§6.1），并把偏转与碰撞统一在"同一碰撞时刻的方向自由度"上（§8 接口二）。

体系基准运动学（注释 03）规定：元相子定居格点，圆心每摆程在格点区间 $[nl_P, (n+1)l_P]$ 内从一侧边界单向位移 $l_P$ 到另一侧边界，与相向而来的反相邻居圆心在公共边界弹性碰撞后折返，相邻两摆方向严格反平行，碰撞日历每 $t_P$ 精确重演一次。

两条机制的相容性未经过系统检验。本注记完成这项检验。

## 二、两个机制的精确表述

**机制 A：碰撞折返**（《元相子几何动力学》注释 03 第 2/3/5/7/9 点）

1. 摆程 = 从一侧边界到另一侧边界的单向位移，相位单调推进 $2\pi$（满周闭合），圆心匀速 $|\dot z| = c$，扫过完整格距 $l_P$
2. 到达边界 = 与邻居圆心碰撞（圆心不可重合），折返 = 相位推进方向沿螺旋反向，$\sigma(t)$ 每碰撞一次变号
3. 相邻反相（交错基态）是折返的必要条件；偏离反相配置则碰撞时序破坏、晶格无法成立（落位窗口注记 2026-09-05 裁决以此为依据排除旋转角相位差层）
4. 去程扫 $+2\pi$、回程扫 $-2\pi$，净绕数为零
5. 碰撞为何完美弹性（动能不损失）的微观机制待声明，记为开放问题（O10，即总览 P3-21）

**机制 B：像素偏转**（《论引力机制的微观起源》§2.2/§2.3）

1. 有质量粒子内禀频率 $\omega_0 = mc^2/\hbar$，每个 $t_P$ 生成一个 $l_P$ 像素，偏转角 $\delta\theta = m/m_P$
2. 第一个像素方向 $\mathbf{n}_1$，第二个像素方向偏转 $\delta\theta$ 变为 $\mathbf{n}_2$，两像素构成扇形回路，平行输运角差 $\delta\theta$，定义微观曲率源 $\kappa_{\text{pixel}} = \delta\theta/l_P^2$，时间累积率 $\dot\kappa = 4\pi Gm/\hbar$
3. 宏观曲率 = $N$ 个像素的线性叠加 $N\delta\theta$（弱场线性叠加）
4. §8 接口二：质量偏转与取向差发生在同一碰撞时刻的方向自由度上；"像素生成"应读作每摆程碰撞或跃迁携带的几何效应

## 三、冲突清单（按严重程度排序）

### 3.1 冲突一：扇形回路与折返往返几何直接矛盾（最尖锐）

扇形构造要求相邻两个像素方向大致同向、只差 $\delta\theta$，即粒子沿路径逐像素前行、方向逐拍微转。折返机制下，同一粒子相邻两摆严格反平行（夹角 $\pi$），围不成张角 $\delta\theta$ 的扇形，围出的回路面积为零。曲率定义 $\mathcal{R} = \lim_{A\to 0}\Delta\theta/A$ 的分母为零，构造失效。

扇形构造隐含的图景正是《论引力机制的微观起源》§6.1（第 217 行）明确废弃的"沿螺旋无限直飞的一次性固化像素不成立"。引力论文的曲率几何停留在已被取代的自由直飞图景上，未按束缚振荡重写。科普文章《质量如何让时间变慢》第 34 行"两步相邻摆程恰好构成这样一个小扇形"继承了同一个未适配的构造。

### 3.2 冲突二：主体错位与旋转轴锁定（机制级硬冲突）

**主体错位**：偏转主体必须有质量（$\delta\theta = m/m_P$），摆程主体必须无质量（真空格点 $m = 0$）。体系内唯一有质量客体是 σ 锁定孤子，而《有质量粒子的形成》§2.3/§4.1 明确：σ 锁定定义的是孤子的基态构型，相位不折返、单方向缠绕、绕数 $n$，静态拓扑构型，不涉及任何周期性往返。孤子没有摆程，因此没有"每 $t_P$ 生成一个像素"的节拍。两个前提在体系内没有任何客体同时满足。

对运动粒子存在一条逃逸路线：缺陷态经晶格中继运动，接力摆程可充当偏转节拍。但 σ 锁定保证孤子空间锚点局域、不扩散（《有质量粒子的形成》"局域性 = σ 锁定"），静止质量（引力最主要的源）无摆程可用，逃逸路线堵死，主体错位一般性成立。旁证：涨落分层登记（2026-09-05 作者修正，《注记-落位窗口的噪声遮蔽机制》）已写下"暴胀期无有质量粒子，$m = 0$，该通道为空"，体系在别处已默认偏转载体为有质量粒子且其存在稀缺，与主体错位相互印证。

**旋转轴锁定**：法线锚定定理链（定理 3.1 旋转轴唯一性；《形式化模型》第 51 行"相位无关且逐点 $SO(2)$ 不变的跃迁向量必须沿旋转轴"）把跃迁方向唯一锁定到旋转轴。偏转机制要求方向每个普朗克时间旋转 $\delta\theta$，等价于旋转轴逐拍进动。轴进动的动力学来源（质量如何破缺对称性唯一性）未形式化；若轴不进动，$\delta\theta$ 无处安放。此论证比"方向自由度被 $\pi$ 反转独占"的争用论证更强：方向自由度根本没有逐拍旋转的结构空间。

### 3.3 冲突三：碰撞日历破裂（几何冲突）

若偏转是摆程方向的真实旋转，回摆落点偏离原端点约 $l_P\delta\theta$，圆心回不到原格点边界。反相邻居的碰撞日历（公共边界每 $t_P$ 重合一次）破裂，圆心轨迹从直线变为折线，下一摆程起点漂移，不再回到固定边界 $nl_P$，碰撞链断裂，晶格随之变形。这与格距绝对性（定理 11：空间有绝对尺度，源于半径 $\hbar$ 的绝对性）冲突，也与落位窗口裁决同构：偏转 $\delta\theta$ 正是对碰撞时序的偏离。

### 3.4 冲突四：刚性格点无法承载连续偏转（最深的缺口）

距离归粒定案给出刚性整数格点阵 $x^a = l_P n^a$，相邻方向离散；偏转是连续小角（电子 $\delta\theta_e \approx 4.2\times10^{-23}$）。在刚性格点上，连续 $\delta\theta$ 的方向偏转不可表示（跳不到格点上）。引力论文用"弱场下像素间重叠或间隙可忽略"（§2.3）连续化滑过，并自认强场下失效。缺的是一个中间层：离散碰撞几何如何承载平滑变化的标架场或曲率场。

### 3.5 冲突五：刷新与累积的对立（逻辑自洽性冲突）

§6.1 用折返的净绕数为零论证"时空与历史轨迹累积相分离"（折返刷新抹掉历史）；§2.3 用 $N\delta\theta$ 线性叠加论证曲率的历史累积。同一方向自由度上，"不累积"（刷新）与"累积"（曲率）并存，分别支撑两个核心论证。回程符号两种选择都失败：去程 $+\delta\theta$、回程 $-\delta\theta$ 则净偏转为零，曲率消失；去程回程同号则方向连续累积成历史，与折返刷新语义冲突，且偏转在折返变号时不随之变号。

限定：在"写入当下度量"的度规化解读下，$N\delta\theta$ 的空间叠加（宏观区域内多像素求和）与逐摆程时间刷新可以并存，曲率是每拍持续再生，非历史累积，故本冲突严格说是论证缺口与图像残留，非纯逻辑矛盾；但扇形构造若坚持字面几何（两条径向边为实际空间像素），矛盾恢复为硬的。定级相应为"论证缺口 + 图像残留"。

### 3.6 附属冲突：与"完美弹性碰撞"开放问题（P3-21）的矛盾

注释 03 第 9 点：碰撞为何完美弹性（动能不损失）待声明，记为开放问题（总览 P3-21）。若偏转发生在碰撞时刻（接口二），方向改变即动量改变，碰撞非弹性，完美弹性的前提被破坏。

## 四、文档中已有的弥合尝试及其代价

接口二（《论引力机制的微观起源》第 262 行）与科普文章（第 18 行）给出统一解读：弯曲的累积不依赖走过的轨迹，靠亿万次摆程各自把偏转写进自己格点的当下度量；"像素生成"应读作每摆程碰撞或跃迁携带的几何效应。即偏转是度规记录，不是轨迹偏转。

**该解读保住了折返机制**：圆心照常弹跳，碰撞日历照常运转，"逐摆程刷新当下结构"与曲率释放速率 $\dot\kappa$ 兼容（曲率是每拍持续再生，非历史累积）。

**代价有二**：

1. "扇形的两条径向边是粒子生成的两个实际空间像素"失去字面意义，扇形退化为纯构造性辅助线。论文自称"严格论证"，严格程度声明与实际构造不符
2. 引出新的未闭合问题：偏转只写进自己格点的度量，远处格点的倾斜由谁写入？只能靠晶格耦合传播，则"源写入 vs 场延展"的回路未闭合。这与《论引力机制的微观起源》§6.1/§6.3 自认的缺口（引力波波动方程、无质量粒子机制）同源

另有已定向校正的措辞残留："动能调制像素生成频率"与 $|\dot\theta| = \omega_P$ 全局同步、步长恒定冲突，接口三已校正为源强度 $\gamma\omega_0$（调制偏转幅度），与读数率区分。

## 六、严重性分级

| 冲突 | 类型 | 可缓解性 |
|---|---|---|
| 3.1 扇形回路失效 | 构造字面失效 | 必须重写曲率构造：折返运动学下扇形不成立 |
| 3.2 主体错位 + 旋转轴锁定 | 机制级硬冲突 | 必须改机制：$\delta\theta$ 的载体或节拍需重新定义 |

| 3.5 刷新 vs 累积 | 逻辑自洽性冲突 | 需论证方向信息与位置信息的累积分离 |
| 3.6 弹性碰撞矛盾 | 表述级冲突 | 随 3.2 缓解 |

核心判断：冲突 3.2 在本体层面最深（体系内无任何客体同时满足有质量与有摆程两前提，偏转主体缺位），冲突 3.1 在构造层面最尖锐（曲率构造的字面几何失效），冲突 3.4 在数学层面最深刻（离散与连续之间缺桥）。§6.1 声称"像素更新机制已由束缚振荡解决"处理的是位置刷新，没有处理方向累积；接口二把偏转塞进碰撞时刻的方向自由度，恰恰是折返机制独占的自由度。

## 七、恢复兼容的可能方向（仅提示，未实施）

1. **偏转载体迁移**：$\delta\theta$ 从单粒子摆程方向迁移到孤子与邻居的相位差或碰撞传递事件上，保留折返的精确 $\pi$ 反转
2. **曲率载体迁移**：曲率改由格距或节律的局域调制承载（$l_P$、$t_P$ 重标），方向自由度还给折返
3. **中间层构造**：在刚性格点与连续曲率场之间建立离散微分几何（格点标架场、离散联络），回应冲突 3.4
4. **刷新与累积分道**：论证位置刷新（净绕数为零）与方向累积（$N\delta\theta$）由不同自由度承载，或重新定义回程偏转符号
5. **主体重新定义**：若孤子无摆程，则引力偏转的"每 $t_P$ 生成像素"节拍需重新锚定（孤子与真空格点耦合的节拍）

**方向评估（2026-09-05 第一轮，部分被同日角色批判修正）**：方向 1 与 5 合流曾被评估为最优路径：把 $\delta\theta$ 迁移到孤子内部相对相位模式（$\omega_0$ 为阱中相对相位模式的特征频率），节拍锚定全局普朗克节拍，"每全局 $t_P$ 内禀相位推进 $\delta\theta = \omega_0 t_P = m/m_P$"。**同日角色批判否决了其中的"推进速率"读法**：定案中 $\omega_0$ 是刚度参数（响应频率，基态静态、不振荡），恢复方向需要的却是推进速率（动力学量）。二难：若相对相位以 $\omega_0$ 实际推进，运动能标 $\hbar\omega_0$ 与绑定能标重合，定案"绑定能 vs 振荡激发能"防线被突破；若基态静态不推进，"推进"无物理主体。符号同一不等于机制同一，"三方闭合"降级为代数闭合（恒等式无矛盾、参数经济性成立），机制闭合未成立。存活形态为幅度参数读法（$\omega_0$ 只作每次写入的幅度，节拍来自全局碰撞事件，写入主体是碰撞而非孤子相位自身）。方向 2 与色散关系推演（格距固定）和时钟层不可观测性冲突较大，维持不建议。方向 3 维持有效。
