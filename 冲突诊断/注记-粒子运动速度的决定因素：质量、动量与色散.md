## 一、问题的提出

电磁场传播是光速 $c$，费米子与宏观物体的运动速度则非常慢。初版回答给出普适公式（$v = pc^2/E$），但未说明这些量在元相子晶格里的几何身份。本版把每个环节锚定到几何机制。

## 二、速度的几何定义：群速度 = 色散的斜率

在晶格理论中，任何激发的速度是**群速度**，即色散关系 $\omega(k)$（或 $E(p)$）对波矢的斜率：

$$v = \frac{dE}{dp} = \frac{1}{\hbar}\frac{d\omega}{dk}$$

速度的几何含义：一个波包（局域构型）在晶格中传播的速度 = 色散曲线的局部斜率。光与粒子的速度差异因此完全归结为**它们的色散关系形状不同**。

## 三、动量的几何身份：相位梯度

注释 09"方向归波"：相位差重新定位为波矢。在元相子晶格中，动量是相位梯度：

$$p = \hbar k, \qquad k_a = \frac{\Delta_a\phi}{l_P} \text{（相位差每格距的梯度）}$$

- 光（集体模式）：波矢 = 慢相位涨落的波长倒数，相位梯度分布在整个波上
- 粒子（kink）：波矢 = 构型的场动量（锁定边界层的相位梯度集体量）。动量关系 $p = \hbar k$ 期望在体系内导出（位置、动量算符的严格推导属开放问题 P3-10），此处按德布罗意关系使用

动量没有神秘，它就是"相位在空间里拧得多密"。

## 四、光的色散：体系已知，零质量 = 线性色散

体系的色散关系（注释 03 第 6 点）已给出：

$$\omega^2(\mathbf{k}) = \frac{4}{t_P^2}\sum_a\sin^2\!\Big(\frac{k_a l_P}{2}\Big)$$

长波极限（$k l_P \to 0$）展开：

$$\omega \approx c\, k, \qquad c = \frac{l_P}{t_P} \text{（几何恒等式，注释 04）}$$

长波极限对任意方向精确各向同性，$c_{\text{eff}} = c$ 无平均因子；有限 $k$ 时 $\sin$ 展开的高阶项给出 $(k l_P)^2$ 量级修正，$v_g < c$（注释 03 已有声明，洛伦兹破坏项）。

**光的零质量 = 这个色散在长波极限是线性的（$\omega \propto k$，无常数项）**。线性色散的群速度 $v_g = d\omega/dk$ 与 k 无关，恒为介质波速。零质量的几何根源：取向场涨落（Goldstone 模式）没有势能项把频率抬高，所以色散从原点出发（$\omega(0) = 0$），斜率即光速。

## 五、粒子的色散：期望相对论性（待验证）

粒子（kink）的能量有两部分：

$$E(k) = \underbrace{mc^2}_{\text{静止项：绑定能}} + \underbrace{\text{构型动能项}}_{\propto k^2 \text{（低速）}}$$

期望的完整形式（P1-33 待验证）：

$$E^2 = m^2c^4 + p^2c^2$$

若成立，群速度：

$$v = \frac{dE}{dp} = \frac{pc^2}{E} = \frac{pc^2}{\sqrt{p^2c^2 + m^2c^4}} = \frac{pc}{\sqrt{p^2 + m^2c^2}}$$

**粒子慢的几何根源：色散曲线在原点有"抬升"（$E(0) = mc^2$），斜率从零出发、随动量渐近到 c**。质量大时曲线在原点抬升更高（$E(0) = mc^2$ 更大），给定动量下曲线斜率（速度）更小。

## 六、速度的微观实现：kink 每拍传播几格

kink 运动 = 锁定边界在晶格中传播，速度对应每拍前进的格数：

$$\text{每拍前进格数} = \frac{v}{c}, \qquad c = \frac{l_P}{t_P} \text{（几何恒等式，注释 04）}$$

- 静止（$v = 0$）：边界不动
- 慢速：每拍推进零点几格（边界格点间歇性锁定/解锁）
- 极限（$v \to c$）：每拍推进一格

## 七、速度上限的几何来源：每拍一格

为什么 $v < c$ 对粒子也成立？晶格因果结构：任何构型信息（锁定状态、相位涨落）每拍最多传递一格（邻居接力，注释 03 碰撞节拍 + 注释 04 接力几何）。kink 边界传播不可能超过每拍一格 = $c$。速度上限是格点因果的直接推论，无需额外机制。

## 八、惯性门槛的几何来源：Peierls 势垒

离散格子的奇偶结构：kink 边界从"完全锁在格点间"到"完全锁在下一个格点间"的过渡中，存在边界部分跨格的中间状态，这些状态的能量更高（相位梯度奇偶错位），形成周期性能垒（Peierls 势垒）。因此：

- 静止 kink 需要越过能垒才开始动（惯性/静止门槛）
- 运动中的 kink 每跨一格也经过能垒（静止门槛在宏观上的感受来源）

惯性在几何上 = 离散晶格的奇偶错位能垒，从 κ_φ 哈密顿量可导出（P1-33 遗留）。

## 九、宏观物体慢的几何解释：集体动量

宏观物体 = 天文数字个 kink（及元相子）的集合。推动宏观物体 = 同时改变所有构型的相位梯度（集体动量）。地球质量 $m \sim 10^{27}$ kg 对应核子数约 $10^{51}$ 量级，让每份相位梯度都增大到接近光速对应的值，需要的能量是整个宇宙级别的。宏观慢 = 集体动量的惯性总和。

## 十、未验证项

关键一环：kink 色散关系 $E^2 = m^2c^4 + p^2c^2$ 是否从 κ_φ 哈密顿量涌现（P1-33 遗留）。若涌现，本注记速度图景成立；若晶格色散有修正，低速区接近牛顿 $v = p/m$，高速区出现 $(E/E_P)^2$ 量级洛伦兹破坏项（与体系既有预言一致）。另需 Peierls 势垒定量（第八节）。

## 十一、结论

速度的完整链条（几何机制版）：速度 = 色散斜率（群速度）；色散形状由静止质量项决定；动量 = 相位梯度（方向归波）；光的零质量 = 线性色散（无势能项），粒子有质量 = 色散在原点抬升（绑定能）；速度上限 = 每拍一格的晶格因果；惯性 = Peierls 势垒（离散奇偶错位）；宏观慢 = 集体动量。每个环节都有几何对应，无神秘。
