## 一、方案定位

"严格版 B 的完成形态"（2026-09-05 第二轮评估推荐候选）。核心转变：$\delta\theta = m/m_P$ 从"摆程方向的真实旋转"重新定义为**每次全局普朗克碰撞事件写入局部标架的倾斜幅度**。不推进、不振荡、不改变任何运动学，只改变"碰撞写下什么"。

## 二、三个组成部分

**组成 1：载体与节拍重安放。** 载体 = 缺陷刚度 $\omega_0$ 调制写入幅度（静态幅度参数，$\omega_0$ 不推进、不振荡）；节拍 = 全局普朗克碰撞事件（注释 03 已有节拍，每 $t_P$ 一次）。原则：物质不影响摆程怎么走，只影响碰撞写下什么。

**组成 2：曲率几何重写。** 曲率不住在格点上，住在标架场里。依据注释 09"距离归粒、方向归波"，连续标架倾斜住波性侧取向场（实轴方向 $\alpha$ 本为连续自由度），格点保持刚性（粒性侧）。相邻格点局部标架之差 = 离散联络；绕格面（plaquette）标架差累积 = holonomy（曲率）；弱场收敛为 $\delta\theta/l_P^2$（代数与原曲率公式相同）。杨-米尔斯晶格推导的模态联络与格面作用量工具整套复用。

**组成 3：写入动力学。** 静态局域形变经最近邻耦合逐层偏置邻居碰撞几何；稳态 = 格点上的离散调和分布；长波极限 = 离散泊松方程 $\nabla^2\Phi = 4\pi G\rho$；传导刚度与质量机制共用 $\kappa_\phi$ 族耦合，不引入新常数。

## 二·五、标架的精确含义与自由度澄清（2026-09-05 讨论修正）

**修正背景**：曾把标架解释为"三元组三个法线（螺旋轴）方向"，该解读引入体系内不存在的"轴向调整机制"（法线锚定定理下轴向固定），已撤回。本节给出修正后的精确含义。

**1. 标架 = 三元组实轴方向组。** 每个格点三个正交元相子的实轴方向构成标架：

$$\text{标架} = \{\alpha_x, \alpha_y, \alpha_z\} \quad \text{（三元组三个元相子的实轴方向）}$$

真空：三个 $\alpha$ 按正交排列（标架整齐）。倾斜 = $\alpha$ 组的慢分量偏转。

**2. 法线（螺旋轴）锚定不动。** 法线锚定定理的字面意义：旋转轴唯一、平移旋转轴重合、手性守恒（注释 03 第 3/8 点），螺旋轴是几何锚，不参与倾斜。引力倾斜在 $\alpha$ 上，不在法线上。【2026-09-10 两层读法补注（作者采纳法线场重读时确立）：本条“锚定不动”限定几何层（摆程轴），撤回的“法线倾斜”解读即几何轴向调整机制，该撤回在几何层仍然成立；波性侧法线方向场（法线场）作为场量自由倾斜，不反作用摆程，详见《内部草稿/注记-法线场重读：标架场的法线方向场语义重读与裁决清单》。】

**3. $\alpha$ 与 $\theta$ 是两个自由度。** $\alpha$ = 复平面实轴方向（坐标轴方向，慢变量，描述"圆平面朝哪"）；$\theta$ = 圆内相位（旋转角，快变量，$|\dot\theta| = \omega_P$ 注释 04 时钟层）。注释 04 的节律约束管 $\theta$，管不到 $\alpha$；落位窗口裁决"唯一可变方向自由度"正是 $\alpha$。$\alpha$ 从不快转，只有慢变化。

**4. 快慢分层在 $\alpha$ 内部（直流 + 交流）。** 电磁（光）与引力（倾斜）都住 $\alpha$ 场，按频率分层：

$$\alpha(t) = \underbrace{\alpha_{\text{DC}}}_{\text{静态偏移：引力}} + \underbrace{\alpha_{\text{AC}}(t)}_{\text{振荡：光}}$$

引力 = $\alpha$ 的直流静态模式（稳态泊松，$1/r$）；电磁 = $\alpha$ 的交流波动模式（光的取向差，保守传播）。线性叠加共存，无"快慢冲突"。此与接口二"电磁与引力同源于几何方向机制而分用"精确一致：同源 = 同一 $\alpha$ 场，分用 = 直流/交流分层。

**5. 引力场建立速度 = $c$（因果性）。** 抄写平均每拍传播一格（邻居平均），扩散步长 $l_P/t_P = c$。引力场建立过程以 $c$ 向外推进（源出现后场以光速覆盖空间），稳态后静态（注入与扩散平衡，不再传播）。远处 $1/r$ 是"源存在足够久后的渐近稳态"。与观测一致：引力场无超光速，引力波以 $c$ 传播。太阳场覆盖太阳系（$10^{13}$ m），因太阳存在 $10^{17}$ s，场建立距离 $ct \sim 10^{26}$ m 远大于太阳系尺度。

**6. 遗留两项**：其一，光的耗散豁免（抄写平均对长波 $k \to 0$ 的衰减率 $\propto k^2$ 趋向零，光几乎不受耗散影响，该豁免机制需形式化）；其二，$\alpha$（坐标轴取向）与 $\theta$（圆内相位）作为两个独立自由度的明确表述，需与《实轴方向场与规范结构的涌现》、P4-8（实轴方向惯性）对齐核实。

## 二·六、曲率的拓扑性：疤定源，场定形（2026-09-06 衔接 SO(3) 验证）

**1. 光滑场零曲率（纯规范）。** 光滑单值标架的格面 holonomy 恒为恒等：SO(3) 验证 1b 给出，转角幅度 $0.05/0.5/0.95$ rad 下残差 $\le 2\times10^{-16}$。曲率是拓扑性，与幅度无关：光滑场无论多弯都零曲率。

**2. 疤定源，场定形。** 曲率只存在于奇异缺陷（σ 锁定孤子）处；缺陷的曲率贡献与倾斜幅度无关，由 Frank 矢量（绕数拓扑）决定（Volterra 缺陷，SO(3) 验证 2a/2c，亏损残差 $\le 2\times10^{-16}$，$\epsilon_h \propto m$ 线性成立）。光滑区域的倾斜只是场的形状（引力势），不复制源（平滑/奇异分解 3c：平滑响应场的格面曲率严格为零 $2.3\times10^{-17}$）。

**3. 与引力势的关系（两类曲率对象）。** 引力势 $\Phi$ 是时间向标量记录（$h_{00}/2$），其潮汐 $E_{ij} = \Delta_i\Delta_j\Phi$ 源外无迹（3+1 验证 B1，机器精度）且非零（Weyl 潮汐 $2:-1:-1$，B3 逐位成立）；空间标架 holonomy 全在疤处。空间曲率（拓扑性，疤处）与时间向潮汐（形状性，处处）是不同对象，共同构成 3+1 静态弱场图像（空间 Regge 几何 + 时间向写入节拍）。

**4. 对旧直觉的纠正。** 原引力论文"歪一点就是一点曲率"（扇形累积）的直觉被纠正为"疤定源，场定形"；$\delta\theta = m/m_P$ 是写入幅度（场的形状参数），曲率由缺陷拓扑给出。此纠正与五层冲突 3.1（扇形失效）的消解同源：曲率几何从"幅度累积"改为"拓扑亏损"。

## 三、数学模型

### 3.1 场变量

格点标架倾斜 $\theta_n$：连续标量，住波性侧取向场，格点坐标全程不动。

### 3.2 机制过程（每拍两步）

第一步，邻居抄写平均（碰撞接力）：

$$\theta_n \leftarrow \theta_n + \alpha\big(\bar\theta_n^{\text{nb}} - \theta_n\big), \qquad \bar\theta_n^{\text{nb}} = \text{邻居平均}$$

（一维：$\bar\theta = \frac{1}{2}(\theta_{n-1}+\theta_{n+1})$；三维：$\bar\theta = \frac{1}{6}\sum_{\text{6邻居}}\theta$）

第二步，缺陷区每拍注入：

$$\theta_{\text{def}} \leftarrow \theta_{\text{def}} + w, \qquad w \propto \delta\theta = \frac{m}{m_P}$$

### 3.3 稳态方程

由每拍注入与扩散的平衡导出（$\alpha(\bar\theta - \theta_n) + w\,\delta_{n,c} = 0$）：

$$-\nabla^2\theta = s\,\delta, \qquad s = \frac{2w}{\alpha} \quad \text{（一维）}$$

三维同型：$s$ 为源强，$\nabla^2$ 为七点离散拉普拉斯算子 $\sum_{\text{nb}}\theta_{\text{nb}} - 6\theta_n$。

### 3.4 一维精确解（1D 牛顿势，离散格林函数）

$N = 201$，源于中心 $c = 100$，狄利克雷边界：

$$\theta_n^{\text{exact}} = \begin{cases} \dfrac{n\,(N-1-c)}{N-1}, & n \le c \\[8pt] \dfrac{(N-1-n)\,c}{N-1}, & n > c \end{cases}$$

分段线性，即一维牛顿势。

### 3.5 三维远场解

$$-\nabla^2\theta = s\,\delta \quad\Rightarrow\quad \theta(r) = \frac{s\,l_P^2}{4\pi r} \quad \text{（远场）}$$

理论系数 $A^* = s\,l_P^2/(4\pi)$。
