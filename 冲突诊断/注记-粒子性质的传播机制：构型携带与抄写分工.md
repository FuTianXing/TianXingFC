## 一、问题的提出

质量（ω₀ 标度）只是粒子性质之一。追问：电荷、自旋等性质在空间上如何传播？粒子移动时它们是否跟着走？如果跟，抄写机制（快照抄写）是否要把全部性质都写下来？本注记回答：不需要。

## 二、性质住在构型上

同一粒子（σ 锁定涡旋环）的不同性质住在环的不同几何属性上：

| 性质 | 几何载体 | 性质类型 |
|---|---|---|
| 质量 | 绑定能 = 构型偏离真空的能量差（∝ κ_φ） | 标量（能量） |
| 电荷 | 绕数 n = 相位沿环的拓扑缠绕圈数 | 拓扑（整体） |
| 自旋 | 环内部截面的 π 扭转（旋量几何） | 几何（内部结构） |
| 内禀频率 ω₀ | 缺陷刚度（势阱曲率 κ_φ） | 刚度（响应标度） |

这些性质是同一构型的不同属性，并非粒子身上悬挂的独立标签。

## 三、性质的传播 = 构型的传播

粒子运动 = 涡旋环整体在晶格中移动（kink 边界传播）。环移动时：绕数在环上（拓扑荷随构型走）、π 扭转在环内部、绑定能在环上，全部自动随行。没有任何性质需要单独传播：移动的是构型，属性是构型的属性。

类比：拧紧的橡皮筋环（圈数 = 电荷、扭转 = 自旋、张力 = 质量）在桌面上滚动，圈数、扭转、张力都跟着环走，不需要分别传播三样东西。

## 四、抄写机制写什么

抄写（快照抄写 = 采样 = 碰撞，粒性侧现实化）只写与相互作用相关的自由度：

- **引力纸条**只写标架倾斜（幅度 ∝ m/m_P）。引力只耦合能量动量（等效原理），源是绑定能；电荷不产生引力倾斜（电荷的引力效应经质量实现）
- **电磁抄写**只写实轴方向差（α 的取向差 = 规范场）。电荷经绕数调制取向差（电磁机制已定稿）
- **自旋**经磁相互作用参与（自旋 → 磁矩 → 磁耦合，P1-23 开放），也不靠引力纸条

接口二的分工写明：取向差对应电磁（信息层，无质量），质量偏转对应引力（方向效应）。碰撞时抄写的是方向自由度，不是全部性质。

## 五、核心区分

- 性质是构型的属性：随构型移动，不需要传输
- 纸条是构型在场中留下的记录：只记录构型对外界的影响（引力 = 质量标度的影响，电磁 = 取向的影响）

粒子移动时构型本身在动（边界层切换锁定状态），全部属性自动随行；纸条只是影响的载体，只需质量标度（引力）与取向（电磁）两个通道。如同一个人搬家：性格、指纹、体重跟着人走，不需要分别寄三封信；寄信只需与外界沟通相关的信息。

## 六、诚实边界

1. 涡旋环的整体运动学未完整验证：稳定性已验证（拓扑保护 + 普朗克尺度），环的滚动与传播的完整动力学（含内部扭转如何随移动保持）为候选机制的运动学部分，未定量
2. 自旋-碰撞耦合未闭合：自旋如何调制碰撞（磁相互作用微观机制，P1-23）仍为开放问题
3. 电磁与引力抄写的分层：同一 α 场直流/交流分层的图景已提出，光的耗散豁免机制未形式化

## 七、结论

粒子的质量、电荷、自旋是同一涡旋环的不同几何属性，构型移动时属性自动随行，不需要逐一传播；抄写纸条只记录构型对外界的影响（引力写质量标度、电磁写取向）。性质住在构型里，纸条只写影响。
