## 一、问题的提出

钉扎机制（弱耦合柱/位错核心）被引入以解释"粒子为何能站稳"，但用户质疑：这使理论复杂化，回到了先前 A3 位错网络的状态。本注记重新评估钉扎的必要性，结论是质疑成立：钉扎不是粒子存在的必要条件。

## 二、钉扎被引入的两个依据及其漏洞

### 依据一：Derrick 塌缩

Derrick 检查显示裸点状 kink 在三维弛豫中塌缩（能量归零、绕数流失），由此得出"粒子站不稳，需要钉扎"。

**漏洞：开放边界伪影（适用域已经作者裁决闭合，见修订记录）**。塌缩发生的条件是开放边界，绕数经边界逃逸离开系统。晶格读法原存两套图景：无穷格（时空观 §2 的 $\mathbb{Z}^3$ 表述）与有限增长格（离散镶嵌：格点持续创生、前沿外扩）。作者裁决取有限增长读法，绕数守恒前提由此修正为三条有限晶格条款（内部相滑移 $O(\kappa_\parallel)$ 垒、前沿因果不可达、插入相位复刻，全文见修订记录）：

- 涡旋环收缩到最小尺度后的驻留为待确认识别（$R < \rho_0$ 区未扫描，裁决实验登记 P1-33）
- 相滑移事件（绕数改变的唯一通道）需键相位差穿越分支切割，垒 $O(\kappa_\parallel)$，零温过阻尼流不可穿越（垒值待测）
- 早期静态验证（P1-33：E(R) 单调 → 收缩到最小环）给出的正是"拓扑保护 + 普朗克局域化"图像

Derrick 的塌缩把真实体系中不存在的"绕数逃逸通道"放进了数值盒子（$\varphi = 0$ 垫片盒是静态内部边界，物理晶格的边界是因果不可达的生长前沿）；粒子自稳定结论经作者裁决与三条款在有限增长晶格上闭合，P4-19 的增长律严格化（前沿相位衔接的严格表述）保留为基准层待办。

### 依据二：PN 势垒极弱

2π 修正后 PN 势垒弱约 1000 倍（K = 0.02 时 0.00014），由此得出"晶格齿不够，需要钉扎"。

**漏洞：易动不等于不稳定**。PN 势垒弱意味着粒子一旦被推动就会滑走。但静止粒子处于能量最低态（v = 0 无动能），没有外力就没有理由动。数值验证明确确认：零力 12 万步净位移 ≈ 0（弱形式保留）。静止 = 能量最低态，不需要钉扎。

## 三、简化后的正确图景

粒子稳定存在的充分条件只有两条：

1. **拓扑保护**：有限增长晶格上绕数守恒（三条款：内部相滑移垒、前沿因果不可达、插入相位复刻，见修订记录），σ 锁定最小涡旋环不能消失
2. **能量最低态**：无外力时 v = 0 的构型静止（零力净位移 ≈ 0 已验证）

粒子位置 = 构型中心（定义，不需要锚定）；粒子运动 = kink 边界传播（构型传播，圆心不动）。全部机制 = 拓扑环 + 转换波，零额外组件。这与"正确的方案通常简洁"的原则一致。

## 四、钉扎的正确地位：可选的环境效应

钉扎不是粒子存在的条件，它是真实晶格有缺陷时的环境锚定。位错核心（J_eff ≈ 0.84J）提供弱钉扎阱（10.8），对宇宙学长期稳定是加分项，但属于环境修正，与"粒子为何存在"无关。A3 位错网络因此从"粒子站稳的必要结构"降级为"可选的环境背景"。

钉扎是把"盒子里绕数逃逸"误当成"真实粒子不稳"的结果。在有限增长的真实晶格里（三条款闭合，见修订记录），粒子靠拓扑保护存在、靠能量最低态静止，钉扎是环境可选件，理论回到"拓扑环 + 转换波"的简洁状态。
