# FK 链

**FK 链**（Frenkel-Kontorova 链）是一排由弹簧相连的粒子坐在周期性基底势上的一维离散模型；当弹簧的自然间距与基底势周期不匹配时，失配会集中到一处，形成拓扑缺陷（kink）。体系用它作为元相子时空晶格的一维代理模型：链的格点取法线轴层位，位形取元相子的提升相位（相位展开到实轴），kink 即复合位错粒子。

## 概述

FK 链是体系验证工具链的核心模型，作为时空晶格在一维、标量、经典极限下的代理：格点结构取自晶格（法线轴层位，$x^a = l_P n^a$），场变量取自元相子的提升相位。代理意味着它并不等于晶格本身。有了这个对应，同一个模型就能同时承接量子力学侧与引力侧的问题。

量子力学侧用它承载三类内容。粒子本相与超选择荷：kink 的缠绕数就是粒子数与电荷，整数量子化由拓扑保证。概率权重与 Born 规则：局域序参量的亏空份额承载位置概率，线性泛函精确承载 Born 权重。叠加与测量：叠加态的场侧载体与 U/R 过程的区分都在链上兑现。

引力侧用它承载两类内容。源侧：缺陷的绑定能等于质量，自撑阱的自洽结构使响应系数自动均匀（$\kappa = 1$）。场侧：碰撞写入加邻居接力，稳态即离散泊松格林函数，$4\pi$ 自动涌现。

选它的理由是工具性质与体系需求吻合：一维链的数值求解廉价且确定性强，kink 的拓扑荷可精确核对，而 kink 恰好自带粒子的骨架（拓扑荷、有限能量、可动、有惯性）。

## 定义

体系内使用的标准形式为

$$E[u] = \sum_n \frac{k}{2}\left(u_{n+1}-u_n-1\right)^2 + \sum_n K\left(1-\cos 2\pi u_n\right),$$

第一项是弹簧项（自然长度为一个周期，即相邻相位差为 1），第二项是周期势（周期为 1）。连续极限称为 sine-Gordon 模型，体系内常并称 FK/SG 链。

kink 剖面取扭结形式

$$p_x(n) = n + \frac{2}{\pi}\arctan\, e^{(n-x)/\ell},\qquad \ell = \left(2\pi\sqrt{K/k}\right)^{-1},$$

缠绕为 $W[u] = u_{N-1}-u_0-(N-1) = 1$。链的边界条件取 $u_{N-1} = u_0 + N$（缠绕守恒边界）。

标准参数：$k = 1$、$K = 0.005$、$\ell = 2.25$、$N = 1000$、窗口 $M = 5$。

## 机制

1. **失配集中**：弹簧想保持均匀间距，基底势想把粒子拉进波谷；两者周期不匹配时，矛盾集中到一处释放，形成 kink。
2. **拓扑保护**：kink 的绕数为整数，不能连续消失；边界条件从拓扑上禁锢 kink，这是转换波存在与运动的前提。
3. **宽度来源**：平方型（非紧致）弹簧下位错展宽，$K/k \le 0.02$ 时核宽 $\ell^* \ge 2$ 落入洛伦兹色散窗口；紧致 cos 弹性下位错塌缩为单键尖锐位错，窗口为空。
4. **运动与惯性**：kink 可被力推动，有等效质量与惯性，测地响应与速度上限成立，相对论色散 $E^2 = m^2c_s^4 + p^2c_s^2$ 在能量、动量、不变量三层面闭合。
5. **作为引力源**：缺陷的绑定能等于质量；自撑阱的自洽结构使四个响应通道系数自动连线，$\kappa = 1$ 与阱宽、格距无关。
6. **作为记录场载体**：每拍在缺陷世界线写入幅度 $\delta\theta = m/m_P$ 的标架倾斜，邻居接力传导，稳态即离散泊松格林函数。

## 通俗类比

把小球放进蛋托，球之间用橡皮筋连成一串。橡皮筋希望球保持等距，蛋托希望每个球都落进凹坑；当两者对不上时，某一处的球就会被挤到凸起上，这个被挤出来的位置就是 kink。类比说明的是"两个周期对不齐时矛盾集中到一处"；局限在于橡皮筋与蛋托都是经典对象，而体系用这条链代理的是带相位与层数的元相子结构。

## 例子

| 例子 | 成立与否 | 原因 |
|---|---|---|
| kink 的缠绕数等于粒子数与电荷 | 成立 | 拓扑荷为整数，超选择约束保证整数量子化 |
| 位置权重由线性泛函精确承载 | 成立 | 实通道亏空份额与滑量份额都给出 Born 权重 |
| 紧致 cos 弹性下位错有有限宽度 | 不成立 | 位错塌缩为单键尖锐位错，$\ell^* = 1.00$ 与参数比无关 |
| 一维链的结论可外推三维 | 不成立 | 环的裁决实验显示光滑场涡旋环在三维塌缩，三维形态未验证 |
| 记录场稳态给出离散泊松格林函数 | 成立 | 一维相对误差 $1.8\times10^{-11}$，三维远场 $1/r$ 系数偏差 $1.9\times10^{-4}$ |
| kink 有等效质量与惯性 | 成立 | 测地响应线性、相对论色散与洛伦兹不变量三层闭合 |

## 与其他概念的关系

- [[位错]]：kink 就是位错的最小形态，其三层结构（电荷核、锚核、包层）在链上分别对应周期势、周期势阱与弹簧项。
- [[时空晶格]]：链的格点索引对应法线轴层位，链的格点间距对应普朗克长度。
- [[法线跃迁]]：链上每键的相位差为一个周期，对应满周闭合沿法线轴平移一层。
- [[绕数]]与[[超选择]]：链的缠绕即绕数，边界条件即超选择约束的拓扑形态。
- [[扇区]]：链上的缠绕守恒边界是扇区结构在一维的体现。
- 转换波：kink 的运动载体，运动学判据在链上验证。
