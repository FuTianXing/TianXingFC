# 畴壁

**畴壁**是同一介质里两块各自选了不同基态的区域的过渡层。

## 概述

当能量在两种位形上取到同样低的极小，而相邻区域各自独立地选了其中一个，两块之间就必须有一层过渡，这就是畴壁。

畴壁的意义有两层。其一，它把"选边"这件全局的事变成局域几何：一边一种选择，另一边另一种，壁是二者的接缝，介质在壁上并未损坏。其二，它是**宇称奇响应唯一可能落脚的地方**：诱导项取"序参量乘总导数"的形式，均匀基态里恒为零，物理内容全落在序参量变化处（见"宇称奇响应的落脚点"一节）。

体系内有两处用这个词。手征侧：复结构的两种符号对应两个基态，符号翻转处即畴壁。缺陷侧：层位与相位不同的两块之间的界面，其界面能属畴壁能的一类，是三维复合位错线的对象。

## 定义

取实标量序参量 $\varphi$，能量泛函

$$E = \int dx\left[\tfrac12(\partial_x\varphi)^2 + \lambda(\varphi^2 - v^2)^2\right],$$

基态在 $\pm v$ 简并。过渡解与其表面张力为

$$\varphi(x) = v\tanh\frac{x - x_0}{w},\qquad w = \frac{1}{v\sqrt{2\lambda}},\qquad \sigma = \frac{4}{3}\sqrt{2\lambda}\,v^3 .$$

**约定必须写明**：上式中的 $w$ 与 $\sigma$ 绑定于这个特定的势形式 $\lambda(\varphi^2-v^2)^2$，换势须重解（"宽度"本身也是约定量，随剖面参数化方式变）。数值核对：剖面偏差 $1.5\times10^{-4}$、表面张力偏差 $1.5\times10^{-3}$、均分关系 $\tfrac12(\partial_x\varphi)^2 = V$ 到 $1.2\times10^{-6}$（判据 G1 至 G3）。

对称恢复取 $V_{\mathrm{eff}} = V + \tfrac{aT^2}{2}\varphi^2$，转变点 $T_c = 2v\sqrt{\lambda/a}$，其中 $a$ 是热质量系数，属模型依赖量；数值转变点落在解析值两侧（判据 G4）。

## 机制

第一步，简并：能量在 $\pm v$ 取同一个极小，两个选择没有能量差。

第二步，局域选边：定域化之后序参量是逐点的场，不同区域各自落进一个极小。

第三步，接缝有代价：从 $+v$ 走到 $-v$ 必须穿过势垒，能量收敛在壁上，表现为表面张力；壁越厚，代价越小。

第四步，格点约束：壁宽必须远大于格距，否则过渡层没有格子去实现，判据等于落在不可分辨区。据此得 $v\sqrt{2\lambda} \ll 1/l_P$。

## 宇称奇响应的落脚点

宇称奇（$\varepsilon$ 型）项与序参量的乘积在微观偶性下为偶，故被允许，形式为 $\theta = c\varphi$；而该拓扑密度局部是总导数，于是

$$\int d^4x\, c\,\varphi\, D = -c\int d^4x\,(\partial_\mu\varphi)K^\mu .$$

**均匀基态里 $\partial_\mu\varphi = 0$，右端恒为零。** 也就是说，宇称奇响应不在基态里，只能活在序参量变化处，即畴壁上。"畴壁是 $\varepsilon$ 型通道的落脚点"由此从假设变为推导。

配套还有一条边界：均匀基态给出固定常数值的那一支，需要四维拓扑数非零，而本框架的四维拓扑数为零（空间绕数是超选择标签，能改变绕数的瞬子类过程不存在）。故常数项负担不成立，只剩壁承载的这一支。

## 通俗类比

一屋子人各自选"朝左坐"或"朝右坐"，左边一片朝左、右边一片朝右，中间那排只能侧身过渡，那排就是畴壁。

类比说明两件事：简并加局域选边必然产生接缝；效应集中在接缝上。局限在于人不守恒，且这里的选边由势能与涨落决定，壁的厚薄是梯度能与势能之间的平衡，与人数无关。

## 例子

| 例子 | 是否成立 | 原因 |
|---|---|---|
| 铁磁体的磁畴壁 | 成立 | 自旋方向简并、相邻区域选边不同 |
| 复结构符号的畴壁（体系内提案） | 成立（形式化第一轮 G1 至 G5） | 双井两个简并基态，泛函在符号翻转下严格不变 |
| 去掉双井势（$\lambda = 0$） | 不成立 | 没有简并基态，也就没有可选的边 |
| 壁宽取到约一格 | 不成立 | 过渡层无法在格点上实现，判据落在不可分辨区 |
| 加一个线性外场 $h\varphi$ | 不成立 | 两井出现高差，选边被外力决定，破缺从自发变显式 |

## 与时空晶格的关系

**晶格是底，畴壁是位形。** 时空晶格给出离散的底（格距 $l_P$、摆程 $t_P$），序参量是写在它上面的场；畴壁是场的一种位形。

**壁宽有下限。** 壁宽必须远大于格距，否则过渡层没有格子去实现。按分层定理，畴壁属低能（波性侧连续层）对象，格点属粒性侧基本层，壁宽须落在低能层可描述的尺度上。这条既是 $v\sqrt{2\lambda}\ll 1/l_P$，也是"无畴壁条件"的格点化写法。

**规则精确对称，基态自己选边。** 文档所用更新式在宇称下精确成立（判据 R1 至 R4），破缺发生在基态层。畴壁因而是对称的规则与不对称的基态之间的接缝。

**壁的存亡取决于晶格形成时的初始条件。** 破缺种子为初始旋向偏置；若无畴壁条件成立，宇宙中不出现复结构畴壁，$\varepsilon$ 型通道的自发来源随之被压住。

**取向依赖的因子**：壁的表面张力在离散化下带方向依赖，其因子为 $\sum_i\hat n_i^4$。该因子已由两条独立通道核对（判据 A1 至 A3，两途径偏差 $8.4\times10^{-8}$；四阶系数由 A4 核到 $10^{-5}$ 以内）；直接测壁张力的取向差经可行性判定不执行（幅值 $(a/w)^4$ 与"两大数相减取相对差"的测量方式导致信噪比不可接受，见参考资料末条的可行性判定注记）。

## 与其他概念的关系

- [[绕数]]：壁两侧的局域绕数可以差一个整数；在整体上这些差相互抵消，故全局绕数守恒不受影响（与 [[超选择]] 一致）。
- [[扇区]]与[[超选择]]：跨壁不改变守恒量，壁不连接不同扇区；壁只是同一种守恒量下的两种选边之间的接缝。
- 复结构：手征侧的两个基态由复结构的符号区分，壁即符号翻转处。
- 位错：缺陷侧的界面能属畴壁能的一类，是三维复合位错线需要处理的对象。
