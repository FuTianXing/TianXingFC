# 时间箭头

**时间箭头**是元相子理论中时间的单向性：记录只能沿一个方向累积，摆程计数 $N$ 单调不减。体系把不可逆性钉在第二层内生离散事件序列的单调性上，结构判据由采样压缩给出，方向由本体层的心侧校准给出。

## 概述

时间箭头要回答的问题是物理过程为什么有方向。标准物理处理这一问题的三条路径分别把箭头归给熵增、初始条件的低熵与测量的不可逆，三者共享一个特征：不可逆性被安放在偶然、认识论或待解释项上。体系的处理方式是改换住址。

体系的时间有三层生成结构：原初连续（参数 $\tau$）、内生离散（事件 $E_n$，$T = N t_P$）、次级连续被采样（一切场量）。三层之间是生成次序。不可逆性的住址在第二层，事件序列 $\{E_n\}$ 单调递增，摆程计数去程回程不倒退，第三层被采样的内容继承这个定向。

关键结论有两条。压缩在前，采样映射多对一，其不可逆性是纯结构事实，给出回不去。定向在校准，完整本体动力学为物侧哈密顿加心侧校准，校准既非保守也非可逆，给出往哪去。熵增退到统计层，它是压缩的表现，逻辑上排在压缩之后。

## 定义

时间箭头指物理时间的方向性，体系以两条命题刻画：不可逆性的结构根据是采样压缩，方向性由心侧校准给出。

结构命题。采样映射 $\pi_{t_P}$ 把连续螺旋映为阶梯函数，其核为无穷维（在采样节点集上取零的连续函数空间），相位在采样节点上恒为零（$\theta(\tau_n) = 2\pi n \equiv 0$），频率按模 $\omega_P$ 折叠。映射多对一，逆像为一整个纤维，挑一条需额外信息而体系未提供。

不可逆的判据为典范截面不存在。带限子类上典范逆存在，属可逆；完整轨迹类上不存在，属不可逆。这一判据不依赖概率、热力学与观察者。记录构成上升过滤 $\{\mathcal{D}_N\}$，$\mathcal{D}_N \subset \mathcal{D}_{N+1}$，计数 $N$ 单调不减。

方向命题。完整本体动力学为物侧哈密顿加心侧校准。物侧哈密顿保守可逆，Liouville 定理、能量守恒与时间反演对称三重禁令封死了均匀态自发同步的路；校准是能动的方向性对齐，既非保守也非可逆，三重禁令不约束它。

结构表述由此给出：数学时间是定义域参数 $\tau$，物理时间是像的指标 $N$，时间箭头即压缩方向。

## 机制

1. **三层生成结构**：原初连续给出参数 $\tau$，内生离散给出事件 $E_n$（$\tau_n = n t_P$，$T = N t_P$），次级连续承载一切场量。不可逆性住在第二层，第一层的 $\tau$ 仍可逆。
2. **压缩（结构分量）**：采样映射非单射，连续演化被压成离散刻痕。定理一 (iii) 的复历史铭刻是压缩的产物，其不可逆性由此获得结构根据。压缩给回不去。
3. **校准（心侧分量）**：天行力执行校准，校准不可逆，给出定向。校准给往哪去。
4. **来源收拢**：既有三条来源中，几何来源（螺旋每圈不回到原处）与铭刻来源（满周闭合的复历史铭刻）归于压缩这一根，校准来源独立承担定向。
5. **耗散与熵增**：耗散发生在第三层（内容层的相干衰减），其单向性从第二层的事件单调性借来。熵增是压缩在统计层的表现，依赖粗粒化与统计假设，排在压缩之后。

## 通俗类比

类比：把一段连续旋律按固定节拍打点记谱。打点之后，点与点之间的滑音与颤音全部丢失，从点阵重建不出原来的旋律，而记谱本上的点只会增加。类比说明的是压缩的单向性（多对一，无单侧逆）。局限在于方向本身未被解释：记谱本往前往后翻是另一回事，定向在体系内来自校准这一层，类比只呈现结构分量。

## 例子

| 情形 | 成立 / 不成立 | 原因 |
|---|---|---|
| 时间箭头由熵增单独给出 | 不成立 | 熵增依赖粗粒化与统计假设，压缩是确定性映射的代数性质，逻辑上更靠前；方向另由心侧校准给出 |
| 时间箭头源于偶然的初始条件 | 不成立 | 不可逆性被钉在事件序列的单调性上，属结构事实，不依赖初始条件 |
| 第一层的参数 $\tau$ 不可逆 | 不成立 | 第一层仍可逆，属波性侧，与定理一的二象一致；不可逆性住在第二层 |
| 结构分量与心侧分量互相代替 | 不成立 | 压缩给回不去，校准给往哪去，两者各管一段，不互相代替 |
| 耗散箭头独立于事件箭头 | 不成立 | 耗散在第三层，其单向性从第二层的事件单调性借来 |

## 与其他概念的关系

- **熵**：熵增是压缩在统计层的表现，逻辑上排在压缩之后；箭头另由校准定向
- **相位**：压缩抹去的是相位历史，相位混叠 $\theta(\tau_n) = 2\pi n \equiv 0$ 是压缩的代数来源
- **元相子**：校准的执行者；校准不可逆，箭头的心侧分量由此获得
- **时空晶格**：折返把自由直飞切成等长往返，摆程计数单调递增，几何定向的来源
- **先验纠缠**：纠缠随校准单调建立，与箭头同源
- **时间**（待建）：三层生成结构中的住址
