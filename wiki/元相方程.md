# 元相方程

**元相方程**是描述单个元相子演化的基本动力学方程组，由两条方程构成：方程 (I) $i\hbar\,d\psi/dt = E_P\psi$ 给出相位指针在单位圆上的连续旋转（波性侧），方程 (II) $dz/dt = 2\pi c\,\delta(\arg\psi)$ 给出每次满周闭合沿法线方向的离散跃迁（粒性侧）。两组方程共同刻画螺旋阶梯几何的生成，不含任何自由参数。

## 概述

元相方程是元相子作为个体基元的第一运动法则。它要解决的是同一个对象如何既连续又离散：元相子的波性侧以恒定角频率 $\omega_P$ 连续旋转，粒性侧在每次旋转满周时跃迁一个普朗克长度。连续流与离散跳并存，使这组方程属于混合动力系统，超出了单纯微分方程的范围。

方程组的全部内容是一条旋转加一次阶跃。相位指针在复平面单位圆上转一圈（连续活动），转满一圈的瞬间触发一次沿法线方向的平移（离散事件），平移量恰好是一个普朗克长度。旋转的累积在宏观上表现为匀速直线运动，阶跃的累积生成时空晶格。

方程 (I) 与定态薛定谔方程形式相同，但地位不同。标准量子力学把 $i\hbar\,\partial_t\Psi = E\Psi$ 当作不可推导的公设包，能量、频率、$\hbar$ 与虚数单位之间的关系只能接受。元相方程把它拆成三个来源独立的几何事实，$E_P = \hbar\omega_P$ 由三者的代数结合自然涌现，循环论证被排除。

方程组的数学灵魂是欧拉公式 $e^{i\theta} = \cos\theta + i\sin\theta$。它把复平面上的旋转编码为最简洁的形式，$\psi(t) = e^{i\theta(t)}$ 的时间导数直接给出方程 (I) 的左端，无需任何外部驱动。

元相方程与天行方程处于不同层级。元相方程描述单个元相子的内在运动法则，天行方程描述无穷多元相子纠缠网络的宏观统计兴衰。前者是微观基元的精确动力学，后者是其统计热力学极限。

## 定义

元相方程的标准形式为

$$\boxed{\;\text{(I)}\quad i\hbar \frac{d\psi}{dt} = E_P \psi, \qquad \text{(II)}\quad \frac{dz}{dt} = 2\pi c \,\delta(\arg\psi)\;}$$

其中

$$E_P = \hbar\omega_P, \qquad \delta(\arg\psi) = \sum_{k\in\mathbb{Z}} \delta(\arg\psi - 2\pi k).$$

方程组只有两个自由度 $(\psi, z)$，$\psi$ 取值在复平面单位圆上（$|\psi| = 1$），$z$ 是法线方向的实坐标。方程 (I) 是光滑微分方程，解由欧拉公式给出；方程 (II) 是分布意义下的阶跃方程，两者通过 $\arg\psi$ 的拓扑边界条件精确耦合。

方程 (I) 的解为

$$\psi(t) = \psi(0)e^{-iE_P t/\hbar} = \psi(0)e^{-i\omega_P t}.$$

初始相位定于正实轴时 $\psi(t) = \cos(\omega_P t) - i\sin(\omega_P t)$，余弦项对应实轴上的投影（可观测量），正弦项对应虚轴上的旋转（潜在演化）。

方程 (II) 的解为严格的阶梯函数

$$z(t) = l_P\left\lfloor \frac{ct}{l_P} \right\rfloor = c\,t_P\left\lfloor \frac{t}{t_P} \right\rfloor,$$

$\lfloor t/t_P \rfloor$ 即已逝去的普朗克时间整数计数。宏观极限 $t \gg t_P$ 下取整误差可忽略，$z(t) \approx ct$，即距离公式 $Z = cT$。

## 机制

方程 (I) 的推导起点是相位旋转本身。波性侧的相位以恒定普朗克角频率 $\omega_P$ 连续旋转，这一旋转不依赖外部参考系，也不需要外部原因驱动，波性侧的存在形式就是旋转。取 $\psi(t) = e^{i\theta(t)}$、$\dot\theta = \omega_P$，求导即得 $d\psi/dt = i\omega_P\psi$。

此时方程中尚无 $\hbar$，因为这里只描述了复平面旋转的运动学。补上能量标度需要 $E_P = \hbar\omega_P$，而这条关系由三个彼此独立的前提导出。前提一为复平面旋转的几何动力学（给出 $\omega_P$，不涉能量与作用量）；前提二为满周闭合的作用量量子，每次满周支付 $h = 2\pi\hbar$（涉作用量范畴，不涉能量与角频率）；前提三为能量作为作用量的时间密度，周期过程的时间平均能量等于每次支付的作用量乘频率（普遍定义，不含量子假设）。

三者结合即得

$$E_P = h \cdot f = 2\pi\hbar \cdot \frac{\omega_P}{2\pi} = \hbar\omega_P,$$

$2\pi$ 因子在分子分母中恰好消去。这一消去是同一满周闭合过程在空间侧面（弧长 $2\pi\hbar$）与时间侧面（周期 $2\pi/\omega_P$）几何自洽的必然结果。三个前提各自不包含结论或其等价形式，循环论证由此被排除。

方程 (II) 的推导从跃迁条件出发。粒性侧的离散跃迁要求每当 $\arg\psi$ 完成一个满周时 $z$ 阶跃一个 $l_P$。用周期狄拉克梳写成 $dz/dt = A\,\delta(\arg\psi)$，对时间积分得 $\Delta z = (A/\omega_P)\times(\text{满周次数})$，令每次满周 $\Delta z = l_P$ 即定出 $A = \omega_P l_P$，再由普朗克关系 $\omega_P l_P = 2\pi c$ 得到 $A = 2\pi c$。此方程除跃迁点外处处为零，仅在相位闭合瞬间产生无限大速度，其积分给出阶梯函数。

两方程由此分工：方程 (I) 管"何时跳"（满周闭合的触发时刻），方程 (II) 管"跳多远"（法线方向的固定步长）。跃迁的脉冲落点由满周闭合唯一确定，落点的必然性已单独论证。详见[[法线跃迁]]。

方程中的 $i\hbar\,d/dt$ 组合把虚数单位的旋转驱动与 $\hbar$ 的标度作用融在一起，规定了波性侧演化的基本动力学。$\hbar$ 在此获得几何身份：复平面单位圆作为作用-角变量 $(\theta,J)$ 下的转子，整圈相空间面积为 $2\pi J = h$，基态 $J = \hbar$，故 $\hbar$ 是单位圆携带的作用变量量子，量纲为作用量。$c$ 则控制离散跃迁的幅度与节拍比，是相位方向与法线方向之间的尺度转换常数，即螺旋面的本征斜率。$G$ 不直接出现在单体方程中，通过定义普朗克标度间接关联。

## 通俗类比

元相子像一只钟摆，摆锤沿圆周匀速转圈，每转满一圈，整个钟沿一条轨道向前挪一格。转圈是连续的，挪格是离散的，两个动作由"转满一圈"这一个事件连接起来。转圈的快慢由 $\omega_P$ 定，挪格的步长由 $l_P$ 定，两者的比值就是光速。

类比说明的是"连续活动如何触发离散事件"，局限在于现实钟摆会被摩擦拖慢，而元相子的旋转没有衰减也没有启动过程，它不需要任何外部驱动。

## 与其他概念的关系

- **[[元相子]]**：元相方程是元相子作为个体基元的运动法则，$\psi$ 与 $z$ 即其波性侧与粒性侧的状态变量
- **[[相位]]**：方程 (I) 描述的就是相位 $\theta$ 的连续推进，$\dot\theta = \omega_P$ 是其内容
- **[[法线跃迁]]**：方程 (II) 的狄拉克梳形式即法线跃迁的解析表达，方程 (I) 与之分工为触发时刻与固定步长
- **[[理论总纲/螺旋阶梯几何]]**：两方程合成的轨迹是螺旋面，$c$ 是螺旋面的本征斜率，几何体是方程的可视化（螺旋面、直纹参数化与本征斜率三语的原文在基准正稿，通俗读法见 [[wiki/螺旋阶梯几何]]）
- **[[时空晶格]]**：方程 (II) 的阶梯函数解累积成格点，格距 $l_P$，距离由层数计数给出
- **[[哈密顿量]]**：方程 (I) 即定态薛定谔，其哈密顿量为[[普朗克能量]]本征值，是哈密顿量时间生成元的出身
- **[[提升相位]]**：$\tilde\theta$ 把相位角与累积摆程数合记为一个连续实数，是元相方程两自由度的统一写法
- **[[拉格朗日量]]**：方程 (I) 是波性侧最短作用量路径的几何表达，最小作用量原理由此获得几何对应
- **天行方程**（待建）：元相方程管个体基元，天行方程管纠缠网络的宏观统计，前者是后者的微观极限

## 边界声明

- 严格程度：方程 (I) 的不循环推导与方程 (II) 的脉冲落点必然性均为已确认；宏观极限 $Z = cT$ 的导出为已确认。
- $c$ 的数值地位：$c$ 作为状态空间内禀标度，其内部不变性由螺旋斜率解释，数值仍为外部输入（由物理标度定理的公设承载），方程不独立预言其值。
- 未闭合：完整的洛伦兹不变性（多惯性观测者、以 $c$ 为参数的洛伦兹变换、涌现闵可夫斯基度规）尚待多体元相子的时空与动力学机制导出，不能仅凭单体螺旋的均匀斜率断言。
- 不涉项：本词条只覆盖单体元相方程，不涉其多体场论拓展（元相场论为展望方向）。
