# 相位通道

**相位通道**是元相子物侧两个通道之一，承载波性侧的连续相位旋转，取值于单位圆 $S^1$，态空间因子为 $L^2(S^1)$。

## 概述

元相子的物侧态空间是 $\mathcal{H}_k = L^2(S^1) \otimes \ell^2(\mathbb{Z})$，两个张量因子即相位通道与[[层数|层数通道]]，公理体系定下没有第三个。「慢相位场」不是第三个通道，它落在 $L^2(S^1)$ 这同一个因子上（相位通道的空间依赖部分）。

按空间归属读，两个通道构成一对正交方向：相位通道是螺旋体的**横截面**（复平面单位圆），属**内部空间**，其读数**非定域**；层数通道是螺旋体的**纵向法线轴**，属**外部空间**，其基本读数**定域**。正交性由三处独立保证：螺旋三定理链把相位方向与法线方向严格分开，状态空间度规可分离（$ds^2 = d\phi^2 + dz^2$），两层级是延展体与边界子集的关系。

## 定义

相位通道取值于复平面单位圆，元相子波性侧的状态由相位指针 $\psi(t) = e^{i\theta(t)}$ 完整描述。该指针模长恒为 1，始终沿单位圆边界移动，从不进入圆内部（物理标度下半径为 $\hbar$ 的圆记为 $S^1_\hbar$）。

相位通道的傅里叶指标是**瞬时谱指标**，与相位共轭。这与层数通道的指标（历史计数）对象不同，是两因子非冗余（判据 J6）的根据之一。

可观测性遵循「可观测的只有差」：绝对相位不可观测（整体乘相位因子不改变物理），可观测的只有相位差，见 [[先验纠缠]]。

## 机制

1. 相位指针连续旋转（波性侧，取值于 $S^1$）。
2. 满周闭合被圆周标记点检测，触发一次法线跃迁（这是[[层数|层数通道]]的读数更新，不是本通道的动作）。
3. 相位差的可观测结构由平行搬运规则给出，联络（载体为基准取向场）的曲率即电磁场。
4. 波矢由相邻格点的实轴方向差定义（$k_a l_P \propto \alpha_{n+\hat a} - \alpha_n$），即棱差读数。
5. 叠加与份额：局域读数算符 $\hat O_n = \frac{1}{M}\sum_{m \in \mathrm{win}(n)} e^{2\pi i u_m}$ 是相位的函数，**读数算符天然长在相位通道上**，故位置份额（概率幅）落在此通道。

**正交性归属（2026-09-30 作者裁决）**：相位通道 = 横向 = 内部空间 = 螺旋体横截面 = 非定域传播；层数通道 = 纵向 = 外部空间 = 法线轴 = 定域传播。两者正交。

## 通俗类比

**旋转楼梯上的脚步**。人在楼梯上走，脚下的圆环是相位（一圈圈的连续推进），身处的楼层是层数。脚步声是连续的、绕圈的，它本身不占楼层；楼层是累加的、可数的。「横向」是绕圈这件事，「纵向」是升高这件事。类比说明两通道为何正交；局限在于楼梯是现成的，而体系里楼梯本身由满周跃迁生成。

## 例子

| 情形 | 相位通道读数 | 成立与否 |
|---|---|---|
| 相位转半圈 | 连续推进，层数不变 | 成立（未满周不触发跃迁） |
| 相位转满一圈 | 连续推进，同时触发层数加一 | 成立（满周闭合触发） |
| 单点绝对相位 | 直接读出 | 不成立（须取相位差） |
| 位置份额（概率幅） | 读作此通道的连续权重 | 成立 |
| 位置确定落点 | 读作此通道 | 不成立（属层数通道） |

## 与其他概念的关系

与 [[螺旋阶梯几何]] 的关系：相位通道住其第一层级，即波性相位指针轨迹空间 $S^1 \times \mathbb{R}$（空心圆柱面，维 2），是物侧延展体 $D^2 \times \mathbb{R}$（实心圆柱体，维 3）的边界子集。横向即横截面。

与 [[位置]] 的关系：确定的位置（坐标标签、锚核位置）属层数通道；位置份额（概率幅）属本通道。三层口径见该词条。

与 [[绕数]] 的关系：[[绕数]]是层数沿闭合回路的净差，属层数通道的读数；本通道只提供被绕行的相位增量。
