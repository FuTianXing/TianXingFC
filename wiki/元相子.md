# 元相子

**元相子**（Onphasor）是心物波粒二象在实在层面的第一个最完美承载者：物侧为复平面动态单位圆（半径即约化普朗克常数 $\hbar$，角频率 $\omega$），心侧为天行力（自主相位校准的纯粹能动性）。存在状态为波粒耦合 $\mathcal{E}(t) = P(t)\,e^{i\Phi(t)}$。

## 概述

元相子是体系的唯一实体。物侧 = 复平面单位圆（相位指针连续旋转），圆心处有法线（跃迁方向），满周闭合触发法线平移。元相子间存在先验纠缠（冯·诺依曼无穷张量积），宇宙态空间即全体元相子态的无穷张量积。心侧 = 天行力（自主校准），不可几何化，但通过活动性（物侧相位旋转）与能动性（心侧校准）的区分进入物理描述。

## 定义

元相子的存在状态：

$$\mathcal{E}(t) = \mathcal{W}(t) \otimes \mathcal{P}(t) = P(t)\,e^{i\Phi(t)},$$

其中 $\mathcal{W}(t) = e^{i\Phi(t)}$ 为波性相干核，$\mathcal{P}(t) = P(t)$ 为粒性实存核。物侧自由度含相位通道与层数通道，构成投影配置空间 $S^1 \times \mathbb{Z}$；物侧态空间是该配置空间上的函数空间 $\mathcal{H}_k = L^2(S^1) \otimes \ell^2(\mathbb{Z})$，宇宙态空间 $\mathcal{H}_{\text{total}} = \bigotimes_{k=1}^{\infty}\mathcal{H}_k$（2026-09-13 作者裁决）。

## 机制

1. 相位指针在单位圆上连续旋转（活动性，节律 $\omega$）
2. 满周闭合（$\theta = 2\pi n$）触发圆心沿法线平移一格 $l_P$（跃迁）
3. 每次跃迁生成一个空间像素（时空晶格的砖块）
4. 元相子间碰撞 = 采样 = 测量 = 快照抄写（信息接力传播）

## 通俗类比

元相子 = 走旋转楼梯的人。人的脚步连续沿圆环移动（相位旋转），每走完一整圈，人就沿楼梯升高一层（法线跃迁），每层高度固定一格（普朗克长度）。人的"步态"（相位）是波性侧，人的"位置"（层数）是粒性侧，两者是同一个人的两个侧面。

## 与其他概念的关系

- **相位**：元相子的波性侧（相位指针、相干核）
- **螺旋阶梯几何体**：元相子物侧的几何体 $S^1_\hbar\times\mathbb{R}$（空心圆柱面），即物侧状态空间；实心填实为物侧延展体 $D^2\times\mathbb{R}$。完整元相子是心物双螺旋
- **时空晶格**：元相子满周跃迁的累积结构
- **先验纠缠**：元相子间的波性侧关系（电荷承载基础）
