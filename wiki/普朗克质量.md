# 普朗克质量

**普朗克质量**是元相子时空晶格能够承受的最大质量，兼作引力写入幅度的满量程标度，数值为 $m_P = \sqrt{\hbar c/G}$。

## 概述

普朗克质量的角色在体系内经过三步演进：归一化常数（写入幅度 $\delta\theta = m/m_P$ 的分母）、引力响应满量程标度（2026-09-05 固化）、晶格承载上限（2026-09-17 作者口径）。2026-09-27 起另有承载极限反向导出（判据第 446 条 DC1 至 DC3 闭合）；2026-10-11 写入幅值式整体定理化为定理 6（写入份额定理，条件性定理级），正稿 [[写入份额定理：碰撞写入幅度的唯一性与线性映射]]。

它最重要的澄清：普朗克质量与元相子自身的质量无关。若每个元相子自带 $m_P$，其史瓦西半径 $2l_P$ 与自身尺度同量级，空间处处是黑洞；按承载读法，同一归谬更直接：每个格点的最近邻读数恒为 1，全空间处处处在承载极限上，晶格无处可运转。空间里没有普朗克质量的"东西"，只有拓扑缺陷（粒子）才有质量，且实际粒子 $m \ll m_P$。

"最大质量"一词需与天体层级的坍缩上限分开：$m_P$ 是单格点的承载上限（局域读数），BH4a 的坍缩上限 $M_c = C m_P^3/m^2$（约太阳质量）分属另一层级，两者相差约四十个数量级。

## 定义

$$m_P = \sqrt{\frac{\hbar c}{G}}$$

承载上限口径：$m_P$ 是令最近邻格点写入读数达满偏 $\theta = 1$ 的质量，线性映射 $\alpha = 180^\circ\theta$ 下对应取向自由度压弯 $180^\circ$，即彻底反向与晶格破坏。它是局域读数：适用于局域到格距尺度的质量；延展物体的失效条件取决于紧致度，峰值载荷出现在表面（$\theta(R) = GM/(c^2R)$），与总质量无单调关系。

## 机制

承载力读法的形式结构：稳态记录 $\theta(r) = \frac{m}{m_P}\cdot\frac{l_P}{r}$ 在最近邻距离 $r = l_P$ 处给出 $\theta(l_P) = m/m_P$，即写入幅度恰是最近邻格点上的载荷读数。满偏发生的位置为 $r = Gm/c^2 = r_s/2$。

承载判据为满偏即退出。$m < m_P$ 时满偏点落在首格胞内部，无格点承载该读数，记录被紫外截断吸收，晶格完好；$m > m_P$ 时满偏点越过最近邻格点，取向自由度被压到 $180^\circ$，承载失效。$m = m_P$ 是分界，满偏半径恰等于格距：

$$\frac{Gm_P}{c^2} = l_P$$

作用量通道给出同一上限的等价读法：格点每拍能承载的作用量为一份 $\hbar$，$m_P c^2 t_P = \hbar$，满载即每拍作用量积累达一份作用量量子。

承载极限推导（候选）：由满偏退出判据与写事件分配规则（六链接均分）可反向导出 $\delta\theta = m/m_P$，使弱场匹配与史瓦西对齐从输入降为输出。三通道（满偏半径 $Gm_P/c^2 = l_P$、作用量份额 $m_P c^2 t_P = \hbar$、归一化 $l_P/m_P = G/c^2$）交汇于同一个数。判据状态与边界见来源注记，命题 B 尚待判据化。

引力微弱的承载力读法：已知最重的粒子（顶夸克）约 $1.4\times10^{-17}\,m_P$，比承载极限低十七个数量级。引力弱即载荷远未接近量程，与 $\delta\theta \ll 1$ 同义。

## 通俗类比

把格点想成额定载重已知的支座：粒子质量是负载，写入幅度是负载率（$\delta\theta = m/m_P$ 即承重比例），负载率达到额定值时支座退出工作。局限在于：普通支座超载会变形报警，晶格满偏是取向自由度彻底反向、跃迁无法完成，后续由黑洞线的晶格破坏与本原吸收机制处理，二者机理不同。

## 与其他概念的关系

**与 $G$**：$m_P = \sqrt{\hbar c/G}$，$G$ 在体系内是时空生成刚度，$m_P$ 是刚度在质量单位的翻译：$G$ 越大（刚度越小），$m_P$ 越小，同样质量的写入越大。

**与 $\hbar$**：承载上限的作用量投影为 $m_P c^2 t_P = \hbar$，格点每拍承载一份作用量量子对应质量 $m_P$。

**与史瓦西半径**：$m_P$ 的史瓦西半径 $r_s = 2Gm_P/c^2 = 2l_P$；满偏点在 $r_s/2$，视界（$\theta = 1/2$）与满偏（$\theta = 1$）分居两层，承载失效点在视界深处。

**与碰撞写入**：$\delta\theta = m/m_P$ 是碰撞写入公设 P3 的幅值句；承载极限推导（候选）把它从公设改标条件性命题，待作者确认。
