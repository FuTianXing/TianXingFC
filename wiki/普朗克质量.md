# 普朗克质量

**普朗克质量**是元相子时空晶格能够承受的最大质量，兼作引力写入幅度的满量程标度，数值为 $m_P = \sqrt{\hbar c/G}$。

## 概述

普朗克质量的角色在体系内经过三步演进：归一化常数（写入幅度 $\delta\theta = m/m_P$ 的分母）、引力响应满量程标度（2026-09-05 固化）、晶格承载上限（2026-09-17 作者口径）。2026-09-27 起另有承载极限反向导出，三组判据闭合：DC1 至 DC3（第 446 条，11/11）、DB1 至 DB4（第 458 条，8/8，命题 B 判据化）、平移不变侧第 447 条。2026-10-11 写入幅值式整体定理化为定理 6（写入份额定理），反向导出随之升条件性定理级，正稿 [[写入份额定理：碰撞写入幅度的唯一性与线性映射]]。

它最重要的澄清：普朗克质量与元相子自身的质量无关。若每个元相子自带 $m_P$，其史瓦西半径 $2l_P$ 与自身尺度同量级，空间处处是黑洞；按承载读法，同一归谬更直接：每个格点的最近邻读数恒为 1，全空间处处处在承载极限上，晶格无处可运转。空间里没有普朗克质量的"东西"，只有拓扑缺陷（粒子）才有质量，且实际粒子 $m \ll m_P$。

"最大质量"一词需与天体层级的坍缩上限分开：$m_P$ 是单格点的承载上限（局域读数），BH4a 的坍缩上限 $M_c = C m_P^3/m^2$（约太阳质量）分属另一层级，两者相差约三十八个数量级。

## 定义

$$m_P = \sqrt{\frac{\hbar c}{G}}$$

承载上限口径：$m_P$ 是令最近邻格点写入读数达满偏 $\theta = 1$ 的质量，份额 $\theta$ 为无量纲读数，几何角按 $\alpha = \pi\theta$ 线性映射，满偏对应取向自由度压弯 $\pi$ 弧度，即彻底反向与晶格破坏。$\theta_{\max}$ 的数值含弧度归一约定成分：第 512 号（U3 同根判据）登记了这一点，换成圈数映射数值变 2，而取向反向这一结构判据不变，对外表述优先用结构判据。它是局域读数：适用于局域到格距尺度的质量；延展物体的失效条件取决于紧致度，峰值载荷出现在表面（$\theta(R) = GM/(c^2R)$），与总质量无单调关系。

## 机制

承载力读法的形式结构：稳态记录 $\theta(r) = \frac{m}{m_P}\cdot\frac{l_P}{r}$ 在最近邻距离 $r = l_P$ 处给出 $\theta(l_P) = m/m_P$，即写入幅度恰是最近邻格点上的载荷读数。满偏发生的位置为 $r = Gm/c^2 = r_s/2$。

承载判据为满偏即退出。$m < m_P$ 时满偏点落在首格胞内部，无格点承载该读数，记录被紫外截断吸收，晶格完好；$m > m_P$ 时满偏点落到最近邻格点之外，该格点的读数越过满偏，取向自由度翻转超过 $180^\circ$，承载失效。$m = m_P$ 是分界，满偏半径恰等于格距：

$$\frac{Gm_P}{c^2} = l_P$$

**口径注（2026-10-24 作者裁决后补）**。上一段的「越过满偏」是**判据的条件句读法**，不是「动力学确实会把读数推到那里」的断言。两者的区别须分清：命题 A 说的是「若最近邻读数达到满偏，则该格点退出承载」，这是定义层判据，与格点能否真被压到满偏无关；而「强场动力学达到满偏」是另一问，目前只有模型层答案，且该答案是构造出来的。

模型层的封顶读数（$\theta_{\max}=0.9991$、亏损按 $e^{-9.4\sqrt{s_0}}$、扫至 $s_0=10^5$ 不越界）出自饱和源模型，其封顶由饱和因子 $(1-\theta^2)_+$ 的零点位置保证：$g(1)=0$ 时 $\theta\equiv1$ 是方程的解。同一方程去掉该因子时中心值随源强线性增长，$s_0=1$ 即给 $18$。

故「满偏不可达」不是理论预言，$g(\theta)$ 的微观导出仍缺。论证见 [[冲突诊断/注记-饱和因子是否有必要：封顶的恒真检验与模型地位（2026-10-24）|饱和因子注记]]。本条不改变命题 A 与承载极限的判据效力（第 446 条、第 458 条）。

作用量通道给出同一上限的等价读法：$m_P c^2 t_P = \hbar$，即满量程质量把静止能摊到一个摆程上，恰得 $\hbar$。它是每拍的作用量预算，等于作用量量子 $h$ 的 $1/2\pi$。体系里只有满周结算才兑现整份：$E_\Phi t_P = h$。故 $\hbar$ 不可称「一份作用量量子」，两者差 $2\pi$。

承载极限反向导出（条件性定理级，2026-10-11 随定理 6 转正）：由满偏退出判据与写事件分配规则（六链接均分）反向导出 $\delta\theta = m/m_P$，弱场匹配与史瓦西对齐由输入降为输出。三通道（满偏半径 $Gm_P/c^2 = l_P$、作用量份额 $m_P c^2 t_P = \hbar$、归一化 $l_P/m_P = G/c^2$）交汇于同一个数。

两条子命题各有判据：命题 A（满偏即退出，临界质量 $m_c = c^2l_P/G = m_P$）由 DC1 至 DC3 支撑（第 446 条 11/11），命题 B（载荷等同写入，$\theta(l_P) = \delta\theta$）由 DB1 至 DB4 支撑（第 458 条 8/8）。

引力微弱的承载力读法：已知最重的粒子（顶夸克）约 $1.4\times10^{-17}\,m_P$，比承载极限低十七个数量级。引力弱即载荷远未接近量程，与 $\delta\theta \ll 1$ 同义。

## 通俗类比

把格点想成额定载重已知的支座：粒子质量是负载，写入幅度是负载率（$\delta\theta = m/m_P$ 即承重比例），负载率达到额定值时支座退出工作。局限在于：普通支座超载会变形报警，晶格满偏是取向自由度彻底反向、跃迁无法完成，后续由黑洞线的晶格破坏与本原吸收机制处理，二者机理不同。

## 与其他概念的关系

**与 $G$**：$m_P = \sqrt{\hbar c/G}$。$G$ 在体系内是时空生成刚度，同时标定网格生成标度（$l_P = \sqrt{\hbar G/c^3}$）与质量到写入的换算。$G$ 越大，生成的格距越大，$m_P$ 越小，同一质量的写入份额越大（$\delta\theta \propto \sqrt{G}$）。把 $G$ 读成弹性模量或「被压弯的难易」属已退役的字面读法（术语表「$G$ 的生成标度与写入换算」目）。

**与 $\hbar$**：承载上限的作用量投影为 $m_P c^2 t_P = \hbar$，格点每拍承载 $\hbar$ 对应质量 $m_P$。元相子基模另有 $E_\Phi t_P = h$。两式相差 $2\pi$：前者按 $\hbar$ 计（每弧度一份），后者按 $h$ 计（每满周一份），见下条。

**与 [[普朗克能量]]**：$m_Pc^2 = \sqrt{\hbar c^5/G} = E_P^{(t)} \approx 1.2209\times10^{19}$ GeV，即折算约定的普朗克能量，与基准约定 $E_P = \hbar\omega_P = 2\pi E_P^{(t)}$ 差 $2\pi$。写入幅度的分母与 $m_Pc^2$ 同走折算侧；误取 $E_P$ 会使 $\delta\theta$ 偏小 $2\pi$ 倍。

**与史瓦西半径**：$m_P$ 的史瓦西半径 $r_s = 2Gm_P/c^2 = 2l_P$；满偏点在 $r_s/2$，视界（$\theta = 1/2$）与满偏（$\theta = 1$）分居两层，承载失效点在视界深处。

**与缺陷宽度**：粒子的质量与缺陷宽度由同一个锁定耦合定，二者互反，宽度乘质量比恒为一（$\xi\cdot m/m_P = 1$），故定稿档缺陷宽度精确等于电子的约化康普顿波长（判据第 622 号恒等式 $\xi = m_P/m_e$，$\xi l_P = \hbar/(m_e c)$）。$m_P$ 在此扮演格距与质量比之间的换算角色（见 [[康普顿波长]]）。

**与碰撞写入**：$\delta\theta = m/m_P$ 原为碰撞写入公设 P3 的幅值句。承载极限反向导出已把它从公设降为可导出结论，2026-10-11 随定理 6 转正，定级条件性定理级。
