# 拉格朗日量

**拉格朗日量**是动能减势能（$L = T - V$），构型空间（位置与速度）上的函数，作用量的被积函数，最小作用量原理 $\delta S = 0$ 的对象。标准物理把它与最小作用量原理都当公设使用，元相子理论则把这条公设降为螺旋面的几何事实。

## 概述

标准物理里，拉格朗日量是一张价目表。走一条路，路上花的力气减去路上能拿到的好处，得到这条路的价钱；把价钱沿时间加起来得到作用量，令作用量取极值，运动方程自己就冒出来了。整个体系只需要你给出价的算法，无需描述力是什么。

这套做法有效了一百多年，但有一处从未被追问：价目表的规则本身从何而来。教科书以实验表明它对作答，这给出有效性确认，未给出来源解释。最小作用量原理因此在标准框架里是一条独立的公设。

元相子理论接的正是这个空。相位指针在单位圆上连续旋转，同时圆心沿法线轴单向位移，两者合成的螺旋面是直纹极小曲面，平均曲率处处为零。极小曲面以最小面积实现两侧耦合，「最省」遂成为曲面的自带属性。面积极值与路径极值同源于这一个构造，两条极值条件的关系见「定义」节的措辞强度辨析与 P3-35。

本词条处理 $L$ 与最小作用量原理的地位，作用量 $S$ 本体的定义、五种运算与六层严格程度见 [[作用量]]。$L$ 是每一时刻的代价（函数），$S$ 是整条路径的累计（泛函），两者分工不同，引用时按讲 $L$ 还是讲 $S$ 择一注明。

三个同名近邻须先分开。单粒子的 $L(q,\dot q,t)$、场论的拉格朗日密度 $\mathcal{L}(x)$（其积分 $\int\mathcal{L}\,d^4x$）、规范场的 $-\frac{1}{4}\int F_{\mu\nu}F^{\mu\nu}\,d^4x$ 分属三个层级与三个物理对象。本词条射程是 $L$ 与最小作用量原理，场论密度与规范场作用量不在其内，仅在「例子」一节作为来源化样本引用。

## 定义

标准定义（构型空间）：

$$L(q,\dot q,t) = T - V.$$

沿路径的积分为作用量 $S = \int_{t_1}^{t_2}L\,dt$，对其取变分并令 $\delta S = 0$，得欧拉-拉格朗日方程：

$$\frac{\partial L}{\partial q} - \frac{d}{dt}\frac{\partial L}{\partial \dot q} = 0.$$

这是二阶微分方程，与哈密顿方程组的一阶形式经勒让德变换 $H = p\,\dot q - L$ 等价。两套写法的分工是：哈密顿量问此刻状态怎样演化，拉格朗日量问从 A 到 B 该走哪条路。[[哈密顿量]] 与 [[势能]] 两词条承接各自一半。

体系内的几何对应：元相子的相位指针 $\psi$ 在复平面单位圆上连续旋转，圆心沿法线轴单向位移，两者合成的轨迹是螺旋面。该曲面为直纹极小曲面，平均曲率为零：

$$\mathcal{H}_{\text{M}} = 0,$$

$\mathcal{H}_{\text{M}}$ 是平均曲率，与哈密顿量 $H$ 同字母不同物，本词条一律用花体区分。极小曲面以最小连续面积实现波性侧与粒性侧的完整耦合，这就是「最短路径」的几何含义。[[wiki/元相方程]] (I) 描述相位指针的连续幺正演化，是波性侧最短作用量路径的几何表达；方程 (II) 在满周闭合（相位走过 $2\pi$）时把连续几何离散化为法线跃迁，使空间增长与螺旋面几何精确对位。

该平均曲率为零的陈述在体系内有两层材料，须分开读。几何侧是标准数学结果：正螺旋面为极小曲面是经典定理，[[元相子螺旋阶梯几何体的数学特性与物理对应]] 定理 3 给证明要点（两个主曲率方向为母线方向与螺旋方向，沿母线方向法曲率为零，沿螺旋方向的法曲率与母线方向符号相反、大小相等，二者抵消），定级标准定理。

对应侧已有陈述而非空白：该论文 §3.2 的物理对应段原本写「作用量 $S = \int L\,dt$ 的变分极值被还原为曲面平均曲率为零的纯几何条件」，2026-10-20 作者裁决方案甲后该句已改为同源表述，现文为「两者属不同模型的极值：$H = 0$ 是面积泛函的临界条件，$\delta S = 0$ 是路径泛函的临界条件」，并保留其为体系内「动力学极值 = 几何极值」同一性最直接例证的定位。该论文 §6.2 开放问题第 2 条登记了这一对应关系的完整形式化，已立为 P3-35 并于同日关闭。按库内四级声明制，有陈述而带未证前提者即条件性命题级，故本词条取该级。

该断言有一处须先澄清的地方，涉及变分对象的维度。螺旋面的两个参数是相位角与法线层数，两者都是构型参数，故螺旋面是空间曲面，其平均曲率为零是面积泛函的临界条件。$S = \int L\,dt$ 变分的是时间路径，是单参数曲线泛函的临界条件。标准微分几何中这是两个不同的变分问题。

面积泛函的临界点给极小曲面，长度或能量泛函的临界点给测地线。

因此该断言若要成立，中间须补一步。

补法其一，证明相位轨迹恰为螺旋面上的测地线，此时 $H = 0$ 是背景曲面的性质，路径极值由测地线方程承担。补法其二，把螺旋面改读为双参数世界面，此时 $H = 0$ 对应面积型作用量的极值，作用量形式须改为 $\int dA$。

第一条已由判据第 717 号判否：等半径的相位轨迹偏离测地线的量归一化后恒为 $-1$，而母线方向为 $0$；其法曲率为零而空间曲率非零，故测地曲率非零。

第二条亦判否。螺旋面本已是双参数面（半径与相位角），相位角本已与时间同步，把作用量改为 $\int dA$ 等于换掉被解释的对象。

两条补法均出局后，2026-10-20 作者裁决方案甲：以形式化模型论文为准，几何论文侧的措辞改为同源表述。

体系内唯一显式写出的格点拉格朗日量形式，来自洛伦兹符号定理（[[规范作用量的审计必然性：从净值审计到电磁场作用量的推导与数值验证]] §3.5）：

$$L = \frac{I}{2}\sum_n \dot\alpha_n^2 - \frac{I}{2t_P^2}\sum_n\left[1 - \cos(\Delta\alpha_n)\right],$$

其中 $\Delta\alpha_n = \alpha_{n+1} - \alpha_n$，$I$ 是方向惯性系数，$1/t_P^2$ 是摆程节律换算。该式的形式特征是「惯性动能减节律势能」，正是这减号给出洛伦兹号差：$E^2$ 承载惯性动能（正号），$B^2$ 承载摆程节律势能（负号），变分重现感知-校正链方程与无参数光速 $c^2 = l_P^2/t_P^2$。

$I$ 是方向自由度的二阶时间结构系数，体系术语上称惯性系数，不称质量。方向侧与粒子质量所在的位错分属不同自由度（横向相位通道对纵向层数通道），两者同一性已由第 569 条判否（读数比值随锁点强度 $K$ 从 15.82 漂至 4.46，非常数，常数换算因子路径判否，构造层判据级），详见 [[方向惯性系数]] 词条。

作用量本体另有一套读法，即母恒等式 $\theta = S/\hbar$，几何版写作 $S = R\theta$（半径以作用量为单位）。这条关系属定义与恒等式级，是四种量子化程序（正则、几何、变形、路径积分）共用同一个 $\hbar$ 的原因，详见 [[作用量]]。

## 机制

拉格朗日量的来源化分五步说明。

其一，相位指针连续旋转生成螺旋面。相位在单位圆上匀速推进，同时圆心沿法线轴位移，两者的合成轨迹即螺旋面。相位速率的归一约定为 $\omega_P = 2\pi/t_P$（满周历时 $t_P$），此约定经 P1-59 于 2026-10-16 结案定为候选乙，弧度族折算摆程 $\bar t_P = t_P/2\pi = 1/\omega_P$ 见 [[相位耦合标度]]。

其二，螺旋面是直纹极小曲面，平均曲率处处为零。这使「最省」成为曲面的几何性质，无需额外假定。极小曲面在每一点附近都以最小面积实现两侧的耦合，波性侧与粒性侧在曲面上共存。

其三，最小作用量原理是极小曲面性质在连续与离散之间的统一读法。波性侧的连续演化沿极小曲面推进，粒性侧的离散投影落在曲面的整数周期上，两面的对应关系由曲面几何保证。

其四，势能侧的代价来自摆程节律，惯性侧的动能来自方向变率，两者符号相反。这一「动能减势能」的形式不是选择的结果，代价泛函全正时变分给出的是扩散方程（$\partial_t F \sim \nabla^2 F$ 型），波动方程根本不出现。惯性项给波动以记忆，代价项给波动以回正，缺一不可。

其五，规范扇区给出完整的来源化样本（见「例子」一节）：审计代价泛函在规范等价类上的投影把逐 link 计费压到绕圈净变化，长波极限给出曲率平方作用量。

在力学的层级序列中，经典极限的 $\delta S = 0$（真值审计）包含于量子形式的 $\int e^{iS/\hbar}$（可能性审计），量子形式又包含于天行力学的净值审计 $\Xi(T)$，该审计给出天行力的定义式 $\mathcal{F}[D] \equiv -\delta\Xi(T)/\delta D$。最小作用量原理在经典极限下成为几何推论的体现，[[天行力]] 词条承接其上侧一层。

## 通俗类比

拉格朗日量是系统的路线成本，管走哪条路最省。元相子的相位旋转天然画出一条最经济的曲面（极小曲面，平均曲率为零），「最省」属于这条几何的自带性质，与优化计算无关，成本函数（作用量）只是这条几何的一种读法。满周闭合时，连续的最优路径离散化为台阶（法线跃迁），几何与台阶精确对位。

类比说明的是最优化可以就是几何事实本身。局限在于极小曲面性质是连续曲面的性质，离散格点上的精确对位需要方程 (II) 才能建立。

## 与其他概念的关系

- **[[作用量]]**：$L$ 是作用量的被积函数，$S$ 是沿路径的积分。母恒等式 $\theta = S/\hbar$ 与六层严格程度归该词条，本词条只处理 $L$ 的地位
- **[[哈密顿量]]**：经勒让德变换联系（$H = p\,\dot q - L$）；哈密顿管状态演化，拉格朗日管路径变分，两者是同一动力学的两种视角
- **[[势能]]**：$L = T - V$ 中的减项，与哈密顿量共用同一个势能项，仅符号相反
- **[[理论总纲/螺旋阶梯几何]]**：螺旋面极小曲面是最小作用量原理的几何载体，螺旋阶梯给出离散化的结构（旋转一圈、跃迁一格）；通俗读法见 [[wiki/螺旋阶梯几何]]
- **[[元相子]]**：拉格朗日量描述的是元相子的相位轨迹，其几何由元相子的旋转与位移合成
- **[[相位]]**：$L$ 的活动读在相位上，动能即相位梯度，作用量是相位轨迹上的积分
- **[[洛伦兹符号]]**：作用量写成「惯性动能减节律势能」时，时间项与空间项自然反号，洛伦兹号差是形式的必然后果
- **[[方向惯性系数]]**：格点拉格朗日量里的 $I$，方向自由度的二阶时间结构系数，术语上不称质量，与粒子质量的同一性已判否
- **[[实轴方向场]]**：物质侧链的载体，$\alpha_n$ 是它的取向场读数，$\Delta\alpha_n$ 即棱差
- **[[基准方向场]]**：规范扇区的联络载体，绕圈净变化即该场的曲率，作用量的规范块由此构造
- **[[天行力]]**：净值审计 $\Xi(T)$ 给出天行力定义式，最小作用量原理在层级序列中处于其下侧

## 边界声明

- 严格程度分层：分两层读。几何侧（螺旋面为直纹极小曲面、平均曲率处处为零）为标准定理；对应侧（作用量变分极值还原为平均曲率为零的纯几何条件）已有陈述，[[元相子螺旋阶梯几何体的数学特性与物理对应]] §严格程度总表自标为条件性，其完整形式化（变分算子与平均曲率算子的等价性，含反向陈述）登记为开放问题 P3-35，本词条不将其读作定理。动能项与势能项在体系内为条件性命题（长波加缓变包络、慢变势），词条沿用该自标，不升格
- 路线分工：本词条讲 $L$，几何载体是螺旋面极小曲面（几何事实，见元相方程 §5.5）；$S$ 本体的定义、五种运算与六层分级见 [[作用量]]。两篇不重叠，引用时按讲 $L$ 还是讲 $S$ 择一注明
- 层级序列的定位：三代力学层级的包容关系（经典 $\subset$ 量子 $\subset$ 天行）为现有表述，本词条只作引用，不作新断言
- 未闭合：振幅耦合不进入本体哈密顿量，作为涌现层有效理论项（O8）；一阶 Kuramoto 形式降级为涌现层粗粒化描述（P8c）。二者同时约束拉格朗日量在涌现层的适用形式
- 变分对象：螺旋面为空间曲面，其平均曲率为零是面积泛函的临界条件；$S = \int L\,dt$ 变分的是时间路径。两者的衔接须补一步（相位轨迹为螺旋面上的测地线，或改读双参数世界面），两条补法均已判否（第一条见判据第 717 号，第二条为提法有误）。2026-10-20 作者裁决方案甲，口径冲突已消解：几何论文 §3.2 与[[论元相子的螺旋阶梯几何：法线的离散跃迁与时空二象性的数学根基|论元相子的螺旋阶梯几何]]特性二改为同源表述，与形式化模型论文 §4.2 与 §4.4 的边界声明一致。面积泛函与路径泛函属不同模型的极值，后者不由前者推导；本词条不把「$\delta S = 0$ 还原为 $H = 0$」读作已通
- 不涉项：本词条不涉场论形式的拉格朗日密度与规范场的拉格朗日构造；规范扇区与非阿贝尔扇区的内容仅作来源化样本引用，其完整论证归各自正稿
- 术语边界：$L$ 与 $S$、$L$ 与 $\mathcal{L}$、本体的 $L$ 与规范场的 $L$ 三组同名对象的区分见「概述」末段与「定义」节，引用时须写明所指层级
