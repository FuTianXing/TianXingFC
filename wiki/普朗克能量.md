# 普朗克能量

**普朗克能量**是由 $\hbar$、$c$、$G$ 组合出的能量标度，量级 $10^{19}$ GeV，标记量子引力效应开始显形的位置；体系内分两套约定，基准约定 $E_P$ 与折算约定 $E_P^{(t)}$ 相差 $2\pi$。

## 概述

标准物理里的普朗克能量只有一个值，$\sqrt{\hbar c^5/G}$，约 $1.2209\times10^{19}$ GeV，等于普朗克质量的静止能 $m_Pc^2$。在体系内这个值有明确承担者：折算约定 $E_P^{(t)} = \hbar/t_P$，数值与标准值逐位一致，无需任何修正。

体系另有一个基准约定 $E_P = \hbar\omega_P$，约 $7.6711\times10^{19}$ GeV。它是元相子转满一周的能量，恰为标准值的 $2\pi$ 倍。两个数并存，分歧的根源在记账单位，量纲上两数并不冲突：同一个摆程 $t_P$，按满周结算得 $h$，按弧度结算得 $\hbar$。

两套约定各有分工，混用会静默出错。凡是可观测的偏离（洛伦兹破坏的 $(E/E_P^{(t)})^2$、能带上限、普朗克温度、质量层级）一律走折算约定；基准约定只承担元相子自身的节律、能隙与基模能量，这些量没有对外读数。

用错一次的代价是固定的：交叉搭配使读数整体偏高 $4\pi^2 = 39.48$ 倍，而且不报错。

## 定义

$$E_{Pl} = E_P^{(t)} = \frac{\hbar}{t_P} = \sqrt{\frac{\hbar c^5}{G}} = m_Pc^2 \approx 1.2209\times10^{19}\ \text{GeV}$$

$$E_P = \hbar\omega_P = \frac{h}{t_P} = 2\pi E_P^{(t)} \approx 7.6711\times10^{19}\ \text{GeV}$$

其中 $t_P = \sqrt{\hbar G/c^5} \approx 5.391\times10^{-44}$ s，$m_P = \sqrt{\hbar c/G}$。两式之比精确为 $h/\hbar = 2\pi$。

配对规则：系数 $1/24$ 只配 $E_P^{(t)}$，系数 $\pi^2/6$ 只配 $E_P$，两者描述同一个量。另有全 $h$ 制对照值 $\sqrt{hc^5/G} \approx 3.0603\times10^{19}$ GeV，等于 $\sqrt{2\pi}\,E_P^{(t)}$，体系不采用，仅用于识别外部文献的口径。

## 机制

$2\pi$ 的来路是公理，不是约定俗成。公理 4 同时规定两件事：相位每满周使圆心沿法线轴跃迁一个 $l_P$；自由元相子以光速直飞。两者合起来，满周历时必须是 $l_P/c = t_P$，于是 $\omega_P = 2\pi/t_P$。

反支被这条公理直接排除。若取 $\omega_P = 1/t_P$，满周历时为 $2\pi t_P$，自由元相子的速度随之变成 $l_P/(2\pi t_P) = c/2\pi$，与"以光速直飞"冲突。这是 P1-59 的裁决依据（2026-10-16），候选甲就此出局。

两条作用量恒等式在体系内并存，差一个 $2\pi$：

$$m_Pc^2\,t_P = \hbar, \qquad E_\Phi\,t_P = h$$

两者不冲突，因为左边分别是两个不同身份的量：$m_Pc^2$ 是质量当量，$E_\Phi = \hbar\omega_P$ 是元相子的能量量子。它们的比值正是 $E_\Phi = 2\pi m_Pc^2$。

$2\pi$ 也不进入动力学。方程 $\dot\theta = \omega_P$ 里没有它，能量守恒的推导里也没有它。它只出现在"一圈含多少弧度"这一步换算上，位置固定，来历唯一。

口径分工如下，越界即错。

| 量 | 口径 | 说明 |
|---|---|---|
| 洛伦兹破坏 $\frac{1}{24}(E/E_P^{(t)})^2$ | 折算 | 与实验对话的主通道，判据第 679 号 |
| 能带上限 $E_{\max} = 2\sqrt{3}\,E_P^{(t)}$ | 折算 | 条件性命题（三维最近邻加同步态线性化） |
| 普朗克温度 $T_P = E_P^{(t)}/k_B$ | 折算 | $1.417\times10^{32}$ K，温度侧一律此口径 |
| 质量层级 $m/m_P$、$\delta\theta = m/m_P$ | 折算 | $m_Pc^2$ 即 $E_P^{(t)}$ |
| 采样截断 $\omega_N = \pi/t_P$ | 折算侧读数 | 折合 $\pi E_P^{(t)}$，在基准约定下写作 $E_P/2$ |
| 元相子基模 $E_\Phi = \hbar\omega_P$、能隙 | 基准 | 无对外读数 |

采样截断那一行最易混：$\omega_N = \pi/t_P$ 是 Nyquist 频率，其折算能量为 $\pi E_P^{(t)}$；同一个数若用基准约定写，就是 $E_P/2$。两种写法都指同一个频率。按旧口径把它记成 $E_P$ 会高出一倍，判据第 676 号修正的正是这一处（差 2 倍源于 Nyquist 因子）。

## 通俗类比

同一批饮料，报价可以按箱也可以按瓶，总价不变，变的是单价挂在哪个单位上。

局限在于：类比里的换算是整数（一箱 24 瓶），这里的换算是 $2\pi$，来自一圈含 $2\pi$ 弧度这一几何事实，所以换算系数带着 $\pi$，不能化整。

## 例子

| 对象 | $E/E_P^{(t)}$ | $\frac{1}{24}(E/E_P^{(t)})^2$ | 结论 |
|---|---|---|---|
| 1 eV 光子 | $8.19\times10^{-29}$ | $2.80\times10^{-58}$ | 偏离可忽略，低能精确 |
| 电子静止能 0.511 MeV | $4.19\times10^{-23}$ | $7.30\times10^{-47}$ | 同上 |
| 大型强子对撞机质子 13 TeV | $1.07\times10^{-15}$ | $4.72\times10^{-32}$ | 同上 |
| 100 EeV 宇宙线光子 | $8.19\times10^{-9}$ | $2.80\times10^{-18}$ | 全库最高档，仍低于观测灵敏度 7.7 至 8.2 个量级 |
| 元相子基模 $E_\Phi$ | $2\pi$ | 公式已失效 | 超出适用域，不得按 $mc^2$ 读 |
| 晶格能带顶 $2\sqrt3\,E_P^{(t)}$ | $3.46$ | 公式已失效 | 超出折算标度，仍在基模以下，属能带边缘 |

前四行说明一件事：所有可及能量下偏离都小得无法观测，这是体系与实验相容的量化内容。

最后两行的对照有结构含义：能带顶 $3.46\,E_P^{(t)}$ 低于元相子基模 $6.28\,E_P^{(t)}$，比值 $2\sqrt3/(2\pi) = 0.551$。也就是说，格子上跑得最快的波，频率仍不到元相子自身转速的六成。这正是"元相子不是格点上的激发、能带不越过基模"的数值形式。

## 与其他概念的关系

**与 [[普朗克质量]]**：$m_Pc^2 = E_P^{(t)}$，两者是同一个数的两种单位。写入公式 $\delta\theta = m/m_P$ 的分母若误取 $E_P$，$\delta\theta$ 会差 $6.28$ 倍，牛顿极限 $\theta(r) = Gm/(c^2r)$ 随之失效。此处一旦取错，数值随之改变，影响超出命名层面。

**与 [[元相子]] 基模**：$E_\Phi = \hbar\omega_P = E_P = 2\pi E_P^{(t)}$，是每格点时空结构自身的刚度能量，处处均匀，不进 $\delta\theta$ 的分子。若按 $mc^2$ 读它，$m = 2\pi m_P$，史瓦西半径约 $12.6\,l_P$，康普顿波长约 $0.16\,l_P$，每个格点都成黑洞。故"元相子基态 $m = 0$"是这个体系能够成立的必要条件之一。同一件事也是体系消解真空能灾难的方向：基态能量不进入引力源，量级问题就不会在 $\delta\theta$ 里堆积（目前为纲领性主张）。

**与 $t_P$**：两者共用同一个摆程，差别只在作用量子取 $h$ 还是 $\hbar$。这决定了 $E_P$ 与 $E_P^{(t)}$ 的关系是精确的 $2\pi$，不会有高阶修正。

**与普朗克温度**：$T_P = E_P^{(t)}/k_B \approx 1.417\times10^{32}$ K。温度侧与质量侧同属折算约定，混入基准约定会使 $T_P$ 整体偏高 $2\pi$，今天的无量纲温度 $D_0 = T_0/T_P$ 相应偏低 $2\pi$。

**与 [[色散]]**：首阶破坏项系数 $1/24$ 是 $l_P^2k^2$ 展开的几何常数，而 $l_P^2k^2 = (E/E_P^{(t)})^2$，故 $1/24$ 只配 $E_P^{(t)}$。改用基准约定时，同一项写作 $\pi^2/6$。

**与 [[洛伦兹不变性]]**：体系的签名预言 $(E/E_P^{(t)})^2$ 与标准文献的 $(E/E_{Pl})^2$ 完全同形，因为 $E_P^{(t)}$ 就是标准普朗克能量。这一条使体系的高能预言可以直接与实验上界对照，无需换算。

**与全 $h$ 制**：$\sqrt{hc^5/G} = 3.06\times10^{19}$ GeV，配 $l_P^{(h)} = \sqrt{hG/c^3}$、$t_P^{(h)} = \sqrt{hG/c^5}$。体系的 $E_P = h/t_P$ 是 $h$ 配 $\hbar$ 基 $t_P$ 的混合口径，只作内部基模能量用，对外不得称普朗克能量。
