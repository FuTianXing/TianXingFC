# 半荷分裂

**半荷分裂**是核沿棱移动走到一半时的状态：核原在的面元与棱另一侧的面元各携带 $\pi$，也就是各半个电荷。它是缺陷运动的连续侧读法，代价是中间态无法用单值站点方向场写出，必须带一条弦。

## 概述

站点层只允许整数绕数，核因此跳着走。要让位移连续，就得换到棱层：在棱差上做线性插值，核的位置可以停在半路上。走到一半时，整圈荷被两格平分，各拿半个。

半个荷在站点层写不出来。场取值模 $2\pi$，单值构型给不出半整数环量，半整数绕数因此成为障碍；绕道而行需要一条弦把缺口接上。弦在面元层看不见，只在棱层显形。

## 定义

记插值参数 $t \in [0, 1]$ 描述核从面元 $A$ 移向 $B$，两侧曲率随参数变化

$$F_A(t) = 2\pi(1-t), \qquad F_B(t) = 2\pi t .$$

两端 $t = 0$ 与 $t = 1$ 回到整数绕数的单值构型，中点 $t = 1/2$ 时两格各 $\pi$。全过程满足 $F_A + F_B = 2\pi$，移动只是把整圈在两格之间重新分配。

## 机制

其一，棱层插值。核的移动在棱层按棱差线性插值，位移因此连续，位置可以停在半路上。

其二，实现性障碍。站点场取值模 $2\pi$，半整数绕数给不出净环量，实测回路和为 $3.141593 = \pi$，恰与半个整圈一致。

其三，弦的角色。弦承担描述上的缺口，在面元层不可观测，只在棱层显形。

其四，总荷守恒。$F_A + F_B$ 恒为 $2\pi$，两端回到整数构型，荷既不生也不灭，只是换了落脚点。

## 通俗类比

两个人交接一床被子：中间那一刻，被子同时搭在两只手上，谁也没拿整条。类比说明荷分成两半是连续交接的必经阶段；局限在于被子可以由人任意分，而半个荷无法在单值站点场里写出来，写出来就得补一条弦。

## 例子

| 例子 | 结果 | 原因 |
|---|---|---|
| 核留在原面元（$t = 0$） | 成立：两侧读数为 $2\pi$ 与 $0$ | 单值站点构型，绕数为整数 |
| 核走到中点（$t = 1/2$） | 不成立（须带弦）：两格各 $\pi$ | 半整数绕数，单值场给不出净环量 |
| 核到达邻格（$t = 1$） | 成立：两侧读数为 $0$ 与 $2\pi$ | 回到整数绕数 |
| 半荷构型的回路和 | 读数 $3.141593 = \pi$ | 与半个整圈的预期一致 |
