# 内部弹性

**内部弹性**是元相子自身内部相位通道之间对齐的差动弹簧，由构造层异类耦合 的异类耦合承载，强度记作 $\kappa_\phi$（部分文献记 $\kappa_\phi$），它在长波下给介质内部振动一个能隙 $\omega_0^2 = 3\omega_P\kappa_\phi$。

## 概述

元相子的相位由一小组内部通道（三个相位分量）承载。定理 4 的耦合分两类：同类耦合连相邻格点（邻居弹簧，光波靠它传播），异类耦合管同一个格点内部各通道之间的对齐。异类耦合二次化后剩下的那份「通道之间越不一致越储能」的势，就是内部弹性。

它在体系里的地位有一个反直觉的转折：线性理论里光模式与内部弹性严格解耦（去耦引理），所以给光波加一份均匀弹性负载，光速一点都不动；慢化必须靠非线性把两者接通，接通后的色散由 Lorentz 型介电函数 $\varepsilon(\omega) = 1 + \beta^2/(\omega_0^2 - \omega^2)$ 描述，密度依赖由局域场修正 $\omega_r^2 = \omega_0^2 - \gamma\beta^2$ 承接（$\gamma=1/3$ 对对应球腔几何的 Clausius-Mossotti 形式）。

2026-10-05 作者裁决给出它的心侧身份：内部弹性是元相子对内校准的物理面，与对外校准（实轴方向，[[天行力与规范原理的物理来源：去中心化校准作为规范对称性与相干基态的基础|天行力与规范原理]] 定理 4 与定理 5 的射程）并列为同一内禀能动性的两个作用面。物侧读它为保守恢复力，心侧读它为对齐能动的执行，两读法是同一实在的双面描述。

## 定义

异类耦合项为

$$\mathcal{H}_{异类} = -\hbar\kappa_\phi\sum_p\sum_{a<b}\cos(\theta_p^a - \theta_p^b)$$

把每个格点的三个相位通道做正交组合，分成整体摆动模式 $\Phi$ 与两个内部差模式 $\delta_1,\delta_2$。利用恒等式 $\sum_{a<b}(\theta^a-\theta^b)^2 = 3(\delta_1^2+\delta_2^2)$（与 $\Phi$ 无关），二次化后得

$$\frac{3\hbar\kappa_\phi}{2}(\delta_1^2 + \delta_2^2)$$

这一项对内部差 $\delta$ 是标准弹簧势，弹簧刚度即 $\kappa_\phi$。对应的内部扇区能隙与物质模式群速为

$$\omega_0 = \sqrt{3\omega_P\kappa_\phi}, \qquad v_g(k) = \frac{c^2k}{\sqrt{c^2k^2 + 3\omega_P\kappa_\phi}} < c \quad (\kappa_\phi > 0)$$

去耦引理说明：同类耦合的弹簧项在内部正交变换下仍正比于内部单位算符，与空间差分严格对易，故总二次型对 $(\Phi,\delta)$ 无交叉项。符号约定：$\omega_P = 2\pi/t_P$ 为元相子基模频率，$\delta$ 下标 1、2 为两个正交内部差方向。

## 机制

内部弹性改变色散靠两条线。第一条线是它对介质自身模式的直接抬起：物质模式色散为

$$\omega^2 = \frac{4}{t_P^2}\sum_a \sin^2\frac{k_a l_P}{2} + 3\omega_P\kappa_\phi$$

多出的 $3\omega_P\kappa_\phi$ 是任何波长下都被垫高的部分，能隙由此来。第二条线是光波经非线性与它接通后，传播模式本身被改写，即 $\omega^2 = c^2k^2/\varepsilon(\omega)$。色散关系可以读作恢复力库存的账本：真空只有邻居弹簧一项，记作 $\omega = ck$；介质多了这份内部弹性，库存多一项，账本重写。

定性行为三段：频率远高于 $\omega_r$ 时内部弹性形同虚设，光速回归真空值；频率低于 $\omega_r$ 时光进不去（能隙下禁戒、全反射）；接近 $\omega_r$ 时响应最强（正常色散区）。密度推高还有两条预断：$\beta^2 = 3\omega_0^2$ 处振子软化失稳（极化灾难，介质密度上限），以及 Clausius-Mossotti 密度标度 $(\varepsilon_0-1)/(\varepsilon_0+2) = \beta^2/3$。

## 通俗类比

类比是「手挽三位舞伴的人」：光波晃的是他整体的手臂（$\Phi$），舞伴之间另有内部小弹簧（$\delta$）。手臂晃动本身不牵动小弹簧（解耦），只有高阶非线性像在两个房间之间开了门，两者混成联合体前进，每一拍都要分一份劲去压内部弹簧，步伐因此变慢。类比说明的是「额外的一处恢复力如何进入色散」；局限是真实机制是三通道的正交耦合，比「三个人」更严格的账本由上文恒等式给出。

## 与其他概念的关系

同类耦合：连相邻格点的邻居弹簧，承载光波传播，强度是[[相位耦合标度]]。

内部弹性：连同一个格点内部的通道，管介质振动能隙；两者在去耦引理下互不看见对方。

去耦引理：[[元相子振荡晶格的色散关系：低能光速涌现与洛伦兹破坏首阶项]] §6.2，定量了线性层的解耦与破口。

天行力：2026-10-05 裁决后，校准分对内（内部弹性）与对外（实轴方向）两个作用面。
