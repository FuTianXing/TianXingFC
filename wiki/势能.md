# 势能

**势能**是位置决定的能量储备，在元相子理论中有唯一出身：局域能隙扰动的能量 $V(\mathbf{x}) = \hbar\,\delta\omega(\mathbf{x})$。它与质量是同一把频率尺上的两段读数：质量由锁定能隙 $\omega_0$ 给出，势能是这份能隙的逐点调制 $\delta\omega$。

## 概述

势能 $V(\mathbf{x})$ 描述系统因所处位置而具有的能量。标准物理把它当作公设写进薛定谔方程，只说它是位置的函数 $V(\mathbf{x})$，不问它从哪来。元相子理论给出了它的微观出身：势能是能隙的局域偏离经 $\hbar$ 换算得到的能量。

在体系里，每个格点内部的三个相位通道经 $\kappa_\phi$ 锁定，给出一个能隙 $\omega_0 = \sqrt{3\omega_P\kappa_\phi}$，质量由它定。势能是在这个能隙上做逐点调制：某处能隙偏离 $\omega_0$，偏离量 $\delta\omega$ 经 $\hbar$ 换算就是当地的势能。能隙 $\omega_0$ 远小于普朗克角频率 $\omega_P$，两者不是同一把尺上的同一个数。

这个出身使势能与质量落在同一条坐标上。质量读能隙本身（$m = \hbar\omega_0/c^2$），势能读能隙的逐点调制，二者由同一把频率尺读出，是同一份能量在"全局取值"与"局域偏离"两个视角下的读数。

## 定义

**定理 5.1（含势薛定谔方程）**。在局域能隙调制与慢变近似下，

$$i\hbar\,\partial_t\Psi = \left(-\frac{\hbar^2}{2m}\nabla^2 + V(\mathbf{x})\right)\Psi,$$

其中势能定义为

$$V(\mathbf{x}) = \hbar\,\delta\omega(\mathbf{x}).$$

推导自能隙的局域化。把均匀能隙 $\omega_0$ 换成逐点变化的 $\Omega(\mathbf{x})$：

$$\omega_0 \to \Omega(\mathbf{x}) = \omega_0 + \delta\omega(\mathbf{x}),$$

其中 $\delta\omega$ 来自缺陷、晶格形变或外场对 $\kappa_\phi$、$\omega_P$ 的局域调制。慢变近似条件为

$$|\nabla\Omega| \ll \frac{\omega_0}{l_P},$$

即能隙在普朗克长度尺度上的变化远小于能隙本身。此时质量项变为 $-\Omega^2(\mathbf{x})\psi$，旋转波分解后落在包络方程上的对角贡献为 $-2\omega_0\,\delta\omega(\mathbf{x})\Psi$，与动能项并列即得上式。

势的语义：$V = \hbar\delta\omega$ 是局域能隙扰动携带的能量，对应局域质量调制

$$\delta m = \frac{V}{c^2}.$$

## 机制

势能的物理实质是"当地钟的快慢"。能隙偏离 $\omega_0$ 多少，当地就携带多少势能，换算系数为 $\hbar$。这一机制的三个要点如下。

其一，势能需要非均匀才出现。能隙处处相同时调制量为零，势能处处为零，粒子无处受力。势能是差分，只有梯度有意义，绝对值不可测。这一点比标准物理的"零点可任意选取"更强：均匀部分根本不可提取（源文档公理 8，见边界声明）。

其二，势能梯度给出力。$F = -\nabla V = -\hbar\nabla\delta\omega$，指向能隙变小的方向。机制不难想：能隙小的地方质量小（$m = \hbar\omega_0/c^2$），波包跨过能隙梯度时会向质量小的一侧偏折。这里不需要额外假定"场施加了力"，梯度本身在改写当地的节律。

其三，势能与质量共享同一把尺。质量是能隙 $\omega_0$ 本身经 $\hbar/c^2$ 换算所得，势能是能隙偏离 $\delta\omega$ 经 $\hbar$ 换算所得，把势能除以 $c^2$ 便得到当地的质量增量 $\delta m$。同一个位错在一处读作质量，在另一处读作势阱，区别只在读的是能隙还是能隙的扰动。

### 钟的快慢要分三层

"当地钟的快慢"这句准确，但"当地钟"有三个可能所指，混了就出错。

第一层是元相子自身的相位转速 $|\dot\theta| = \omega_P$。它由公设 3b 钉死，任何势能都不改变它。绝对节拍是这个体系的地基，地基动不得。

第二层是锁定能隙 $\omega_0 = \sqrt{3\omega_P\kappa_\phi}$。它决定"物质的钟"走多快：粒子的振荡频率、康普顿波长、静止质量都由它读出。势能改的是这一层。

第三层是坐标时与固有时的比例。引力势让远处的钟"看起来慢"，那是度规效应：当地固有时与坐标时的换算系数变了，元相子自身的节拍没变。

源文档定理 5.1 说 $\delta\omega$ 来自对 $\kappa_\phi$、$\omega_P$ 的局域调制。$\kappa_\phi$ 这一项是直接机制：锁定强度变了，能隙就变。$\omega_P$ 这一项须读作度规给出的坐标效应，读成本体节拍改变就与公设 3b 冲突。本词条对 $\omega_P$ 一项取度规读法。

$\delta\omega$ 的可能来源分三类：局域缺陷（$\sigma$ 锁定孤子构成的势阱，与有质量粒子的形成衔接）、晶格形变（引力势，与保角因子、度规衔接）、能隙的环境性调制（其他场的背景贡献）。三者的定量形式与彼此区分判据尚未给出，列为开放问题。

## 通俗类比

想象一条按固定步频敲击的节拍线，整条线的步频都一样，什么也不会发生。若某个地段被压慢了一点点，走过去的粒子就会被这个地段"拽住"，这个拽住的强度就是势能。势能属于当地节拍的偏差，与粒子身上贴的标签无关；偏差越大，拽得越狠。

再想弹簧床垫的比喻。床垫各处的疏密本来一致，放上一个重物就压出一个坑，坑边的东西会滑向坑底。势能就是这个坑的深度，只不过在体系里，坑的深浅由当地能隙偏离均匀值多少来度量。

## 例子

| 势能类型 | 标准物理 | 体系内的微源 |
|---|---|---|
| 粒子势阱 | 位置函数 $V(\mathbf{x})$ | 局域缺陷：$\sigma$ 锁定孤子 |
| 引力势 | 牛顿势 $\Phi$，$V = m\Phi$ | 晶格形变：接保角因子与度规 |
| 背景势 | 外场给出的 $V(\mathbf{x})$ | 其他场对能隙的环境性调制 |

三类微源在定性上都能引导出势能，定量形式与区分判据尚待给出。在标准形式 $H = T + V$ 下，势能项与动能项并列为哈密顿量的两个加数，与拉格朗日量则相差一个符号。

## 与其他概念的关系

- **哈密顿量**：$H = T + V$，势能是总能量的两个加数之一；体系的势能项 $V = \hbar\delta\omega$ 即定理 5.1
- **拉格朗日量**：$L = T - V$，与哈密顿量共用同一个势能项，仅符号相反，二者经勒让德变换 $H = p\dot q - L$ 联系
- **质量**：质量 = 能隙本身（$\kappa_\phi$ 锁定能隙），势能 = 能隙的局域调制 $\delta m = V/c^2$，二者是同一把频率尺上的两段读数
- **相位**：势能的来源是能隙的局域偏离 $\delta\omega$，读在当地相位节律上
- **慢相位场**：$\varphi^a$ 是慢相位场（扣掉普朗克节律后的构型部分），$\delta\omega$ 是其局域取值对能隙的扰动
- **引力**：三类微源之二的晶格形变给出引力势，接钟慢链条。此处的"钟慢"指当地固有时与坐标时的比例变小（第三层），元相子自身节拍不变
- **[[牛顿势]]**：引力势的具体实现另有法线场记录路线（$\theta = -\Phi/c^2$），与本词条的能隙调制路线分属两套记账口径，桥接关系尚未登记，列为开放项
- **[[等效原理]]**：势能与质量的同一性（$\delta m = V/c^2$）给出等效原理的一条侧面读法。正稿路线是作用量份额的双折算系数为一（判据第 457、459 条），以 [[等效原理]] 为准，本条只作旁证

## 边界声明

- 严格程度：定理 5.1 自标条件性命题，条件为长波、缓变包络与慢变势，三者均为物理近似级；本词条据此标注，不升格为定理级。
- 钟的快慢分三层：元相子相位转速由公设 3b 钉死，势能改不了它；锁定能隙是势能改的那一层；坐标时与固有时之比属度规效应。定理 5.1 中"对 $\omega_P$ 的调制"须读作第三层，读成本体节拍改变即与公设 3b 冲突，本词条取度规读法。
- 偏离签名：慢变条件下势能项无 $(E/E_P^{(t)})^2$ 型偏离（$E_P^{(t)}=\hbar/t_P$ 为折算约定），三条降级链对照表逐字标为「无」。
- 未闭合：三类微源（局域缺陷、晶格形变、能隙的环境性调制）的定量形式与区分判据未给出，登记为正稿 §8 开放问题 (b)。
- 不涉项：电磁势经实轴方向场 $U(1)$ 联络进入的最小耦合推导属衔接方向（开放问题 P0-2），本词条只涉位置型标量势。
- 不涉项（二）：均匀能隙自身的不可提取性（无梯度、无势差、不可做功）属源文档公理 8（真空能公理）的全局陈述，本词条只涉能隙的局域偏离；真空不空（源文档公理 8）与势能的局域来源不冲突。
