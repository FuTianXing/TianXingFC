# 齐雷尔森界

**齐雷尔森界**（Tsirelson bound，1980 年原文署名为 B. S. Cirel'son）是量子力学在贝尔类检验中允许的关联强度上限：CHSH 组合量的最大量子取值为 $2\sqrt{2}\approx 2.828$，夹在经典界 $2$ 与只受无信号约束的上限 $4$ 之间。

## 概述

贝尔违反说明量子关联超过经典；能超过多少，上限由齐雷尔森界给出。三个数值把关联强度分成三段：经典（局域隐变量）世界封顶 $S=2$；量子世界封顶 $S=2\sqrt{2}$；只禁止超光速传信、其余允许任意作弊装备的世界可以到 $S=4$，由 PR 盒（一种假想装置）饱和。量子力学为什么超过经典又摸不到 $4$，前一半是贝尔违反，后一半至今没有公认的根本答案。

数学侧另有一个近名的齐列尔松问题：张量积模型与对易模型是否给出同一量子关联集。它与这里的物理难题所指不同。

在体系内，齐雷尔森界对应开放问题 P1-29，战线二的最硬检验点。2026-09-14 的 v0 生死闸门已把存在性在纠缠锁定对最小模型内闭合：$S=2\sqrt{2}$ 精确成立，Born 采样越过经典界 $827$ 个标准差，全角度扫描无超量子区，违反的载体是表针相干通道。

原理级一半已由方向三两轮交付并于 2026-09-24 定稿（[[齐雷尔森界的体系内来源：单位相量结构、象限对齐与信息因果性判据]]）。

结构路线给出模型内来源：相关结构由单位相量 $\langle e^{i\Delta\alpha}\rangle$ 生成，象限块 $B^2 = \vert z\vert^2 I$，三奇异值 $(1, \vert z\vert, \vert z\vert)$，经 Horodecki 形式给 $S_{\max} = 2\sqrt{1+\vert z\vert^2} \le 2\sqrt{2}$；$4$ 界图案要求相量模 $\sqrt{2}$，落在单位圆外）。

信息因果性作交叉核对（接口陈述：成功概率形式紧，模型边与 $\cos^2(\pi/8)$ 逐位重合；互信息和式单副本不紧）。

剩余开放三项：其一，“1 比特消息”的体系内容量来源（判据：容量表达式只含框架量且先于目标值独立立起，防止重述与特设）；其二，两侧因子化的全场实现（P4-5 同族）；其三，$Y$ 象限的相位语言操作合成与弥散形状的家族依赖。

## 定义

CHSH 检验的设定：两方各持两个二值测量 $A_1,A_2$ 与 $B_1,B_2$，读数取 $\pm1$，两侧共享任意量子态，各自独立测量。组合量为

$$S=\langle A_1B_1\rangle+\langle A_1B_2\rangle+\langle A_2B_1\rangle-\langle A_2B_2\rangle .$$

三级上限依次为：局域隐变量世界 $S\le 2$（CHSH 不等式）；量子世界 $S\le 2\sqrt{2}$（齐雷尔森界）；只受无信号约束者（禁止超光速传信）$S\le 4$，由 PR 盒饱和。齐雷尔森界对任意维数的量子系统与任意二分设置成立，等号在最优角度与最大纠缠对上取到，是量子关联自己的天花板。中文通行译名为齐雷尔森界，作者人名亦译齐列尔松，多见于算子代数文献。

## 机制

第一步，数值来源。取贝尔态与最优角度搭配（子午面内 $0^\circ$、$90^\circ$ 对 $45^\circ$、$-45^\circ$），四个关联项各取 $\pm\cos 45^\circ=\pm\frac{\sqrt{2}}{2}$，符号拼齐后 $S=4\times\frac{\sqrt{2}}{2}=2\sqrt{2}$。四个关联项单独都能到 $1$，同时取满做不到，最优折中是每项都吃 $\frac{\sqrt{2}}{2}$。

第二步，结构来源。把组合写成算符 $C=A_1B_1+A_1B_2+A_2B_1-A_2B_2$，可验证恒等式 $C^2=4I+[A_1,A_2]\otimes[B_2,B_1]$。基础项 $4$ 来自平方和；附加项由两侧对易子相乘给出，每个对易子的范数最多为 $2$（测量算符谱落在 $[-1,1]$ 上），乘积最多贡献 $4$。

于是 $\langle C^2\rangle\le 8$，开方得 $|\langle C\rangle|\le 2\sqrt{2}$。量子超经典的那截力量来自同一侧两个测量的不可交换性，同一套算符结构又把这份力量封顶。

第三步，载体判别。同一个紧致几何支持两种读法：纤维角作预存值读（经典圈）封顶 $2$；锁定相干读法（联合分支锁定加相对表针相位）达 $2\sqrt{2}$；只清相干项、保留分支关联的退相干控制落到 $\sqrt{2}$。违反的载体是表针相干通道。

第四步，可见度门控。相干度 $p$ 的损失按 $S(p)=2\sqrt{2}\,p$ 折算，阈为 $p^*=1/\sqrt{2}\approx 0.707$。跨层记录把表针相干压到阈下（测量线实测末可见度 $4\times10^{-6}$），测量之后的世界回到经典界之下；先验纠缠保护层维持相干度 $1$，违反在测量之前可用。

第五步，体系内来源（2026-09-24 定稿）：相关结构由单位相量 $\langle e^{i\Delta\alpha}\rangle$ 生成，象限相关块 $B = \begin{pmatrix} c & s \\ s & -c \end{pmatrix}$（$c = \langle\cos\Delta\alpha\rangle$、$s = \langle\sin\Delta\alpha\rangle$）满足 $B^2 = \vert z\vert^2 I$，锐锁定时为反射。

相关矩阵三奇异值 $(1, \vert z\vert, \vert z\vert)$，经 Horodecki 形式给 $S_{\max} = 2\sqrt{1+\vert z\vert^2} \le 2\sqrt{2}$。$4$ 界的四象限图案要求 $(c, s) = (1, 1)$，相量模 $\sqrt{2}$ 在单位圆外，故到不了 $4$（缺口 $4 - 2\sqrt{2} = 1.171573$）。

## 通俗类比

把检验想成一次对答案：两人事先可以商量，随后分开、不许再通信，各自被问到两个问题，只准答 $+1$ 或 $-1$，答完后统计四种问法组合的默契度。只靠事先约定（经典），默契度最多 $2$；共享一对量子表针，最多 $2.828$；若允许上帝式作弊盒（PR 盒）在场，能拿到满分 $4$。类比说明台阶为什么夹在中间；它不讲 $2\sqrt{2}$ 的来源，那个数来自测量算符的代数结构。

## 例子

| 情形 | $S$ | 判定与原因 |
|---|---|---|
| 贝尔态加最优角度 | $2\sqrt{2}\approx 2.828$ | 成立，取到齐雷尔森界（达界） |
| 经典预存角读法（经典圈） | $2.000$ | 不成立，封顶于经典界 |
| 退相干控制（保留层位关联、清表针相干） | $\sqrt{2}\approx 1.414$ | 不成立，落到经典界之下 |
| PR 盒 | $4$ | 不成立，遵守无信号但超出量子界，体系内无实现 |
| 相干度 $p=0.6$ 的贝尔态 | $\approx 1.70$ | 不成立，按可见度阈折算是 2.828 的六成，低于经典界 |

## 与其他概念的关系

- [[先验纠缠]]：锁定对是齐雷尔森界的体系内承载态；v0 给出锁定族剖面 $S_{\max}(\gamma)=2\sqrt{1+\cos^2\gamma}$（子午面设置集），同相锁定饱和、正交象限骑线。
- [[相位]]：违反的载体是表针相干（相对相位）通道，非定域性住在相位通道这一体系判断在此兑现。
- [[超选择]]与[[扇区]]：保护层禁止单侧读取，是原理级推导（方向三）的候选机制来源。
- [[记录场]]：跨层记录把表针相干压到可见度阈以下，记录机制是齐雷尔森界在测量侧的物理执行者。
- 经典界与无信号上限：三级台阶的两个邻位，前者的物理内容是局域隐变量，后者由 PR 盒饱和。
