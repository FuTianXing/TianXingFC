# 普朗克长度

**普朗克长度**是时空晶格的格距，即元相子每完成一次满周跃迁所位移的距离；$l_P = \sqrt{\hbar G/c^3} = c\,t_P \approx 1.616\times10^{-35}$ m，在体系内是绝对常数。

## 概述

标准物理里的普朗克长度是三个常数的量纲组合，来自对量纲的分析。体系给它一个动作：元相子每转满一圈，圆心沿转轴跳一格，这一格就是 $l_P$。空间由这样的跳跃逐格生成，格距由生成动作给定，先验舞台的刻度在这里并不存在。

$l_P$ 因此有三个可互相核对的身份：满周跃迁的位移、光走一拍的距离、标准普朗克长度 $\sqrt{\hbar G/c^3}$。三者逐位一致，因为三者都以「一圈一格」为记账单位。

与能量侧不同，长度侧没有 $2\pi$ 分岔。$l_P$ 与标准值完全相同；若改用全 $h$ 制，会得到 $\sqrt{hG/c^3} = \sqrt{2\pi}\,l_P$，体系不取这一支。原因与时间侧相同：$l_P$ 由 $c\,t_P$ 定出，跟着 $t_P$ 一起按圈记账，故与标准值一致。能量侧之所以出现分岔，是因为 $E = \hbar\omega$ 里的 $\omega$ 是角频率，一圈含 $2\pi$ 弧度。

体系对 $l_P$ 最硬的一条主张是它绝对不变：格距恒定，改变的只能是格数。尺缩由此读作运动束缚态内部结构尺度的变化，格距本身不动。

## 定义

$$l_P = \sqrt{\frac{\hbar G}{c^3}} = c\,t_P = \frac{\hbar}{m_Pc} \approx 1.616255(18)\times10^{-35}\ \text{m}$$

括号内的不确定度主要来自 $G$：$G$ 是基本常数中测量精度最低的一个，$l_P$ 的相对不确定度约为它的一半。这一点决定了普朗克长度在计量学上是一个导出量，其精度上限由引力常数的实验精度设定。

格点坐标由整数计数给出：

$$x^a = l_P\,n^a, \qquad n^a \in \mathbb{Z},\quad a = x,y,z$$

配套恒等式：$c = l_P/t_P$、$m_P = \hbar/(c\,l_P)$、$E_P^{(t)} = \hbar c/l_P$。最后一条给出的正是 $1.22\times10^{19}$ GeV 的标准普朗克能量，三式共用同一个 $l_P$。

## 机制

**满周跃迁造出一格。** 元相子每完成一次满周闭合（相位扫过 $2\pi$），圆心沿复平面法线阶跃一个 $l_P$（元相方程 II）。跃迁路径由对称性唯一锁定：圆心是旋转中的唯一不动点，故转轴唯一；平移方向与轴重合；法线管空间几何，满周标记管时间触发（法线锚定三定理链）。

**三类元相子给出三个方向。** 格点由 x、y、z 三类元相子构成，同类平行、异类经 $\kappa_\phi$ 锁定。分工纪律是距离归粒、方向归波：距离由格点阵承载，方向由纠缠网络与实轴方向差承载，波矢满足 $k_a l_P \propto \Delta\alpha_a$。三维性的严格证明（维度定理 P10）仍是待证命题，现行依据是公设 2 的三类正交方向。

**格距绝对不变。** 晶格刚性原理：格距 $l_P$ 与摆程 $t_P$ 是绝对常数，处处恒定。理由分两层：刚性格点没有形变自由度，格距改变没有实现通道（本体侧）；任何需要背景格距改变才能成立的机制一律不成立（判据侧，一票否决）。引力弯曲、尺缩、保角因子与膨胀因此全部移到波性侧，分别读作法线场静倾角、内部结构尺度变化、度规刻度修正与格点数量增长。

**格数可变、格距不变。** 这是上一条的直接推论，也是理解尺缩的关键。运动束缚态的宽度按 $\xi(v) = \xi_0/\gamma$ 收缩，收缩的是以格距计的格数，格距不动。观测者的钟与尺都由晶格做成，两者同步变化，读数互相抵消，数值按判据第 809 号给出，自由波包装置上钟慢与尺缩四档相对差在 $10^{-6}$ 至 $10^{-4}$ 量级。旧记的 $0.07\%$（按收缩阱重报 $0.054\%$）出自符号错实现，已作废。

**绝对尺度与相对位置。** 定理 11：空间有绝对尺度，源于半径 $\hbar$ 的绝对性；空间只有相对位置有意义，源于相位本质上是相对量。两句话合起来说明 $l_P$ 的身份：它是一把真实且绝对的尺，可宇宙里没有印着「第零格」的绝对原点。格点集体重新编号，物理不变。

**膨胀靠加格点，不靠拉格子。** 元相子数量潜无穷增长，新格点在碰撞点落位。边缘每摆程补一格，速度为 $c$；内部按 $p = 3H_0t_P$ 稀疏落位，$H_0 \approx 70$ km/(s·Mpc) 时约 $3.7\times10^{-61}$。哈勃率由此写成 $H = p/(3t_P)$：$p$ 恒定则 $H$ 恒定，宇宙进入指数膨胀。空间长大用的是「多」，没有用「长」。

## 通俗类比

一把无限长的钢尺，刻度线是真的刻上去的，间距被焊死，谁也不许改。要量更长的东西，只能是钢尺自己接出新的一段，一段一段地接。接的速度可以超过光速，因为接的是刻度本身，没有任何东西在尺上跑。

局限在于：真实钢尺的刻度间距会随温度变，而 $l_P$ 被公理钉死；另外钢尺有零刻度，晶格没有，全体格点一起重新编号，量出来的物理一模一样。

## 与其他概念的关系

**与 [[普朗克时间]]**：$l_P = c\,t_P$，两者是一对，共用同一次折返。刚性原理对两者同时成立，改一个就同时改掉光速。时间侧的颗粒性对应空间侧的格点性，两条签名的标度同根。

**与 [[普朗克质量]]**：$m_P = \hbar/(c\,l_P)$，即 $Gm_P/c^2 = l_P$。满量程质量给出 $r_s = 2Gm_P/c^2 = 2l_P$，视界横跨两个格距。质量到写入的换算 $\delta\theta = m/m_P$ 与 $l_P$ 是同一个几何关系的两种写法。

**与 [[普朗克能量]]**：$\hbar c/l_P$ 正是标准普朗克能量 $E_P^{(t)}$。由 $k = 1/l_P$ 得 $l_P^2k^2 = (E/E_P^{(t)})^2$，洛伦兹破坏的平方标度由此而来。

**与 [[时空晶格]]**：$l_P$ 是格距，晶格是格距的三维累加。晶格属粒性侧，$l_P$ 是这一侧的度量单位。

**与 [[色散]]**：$\omega^2 = (4/t_P^2)\sum_a\sin^2(k_a l_P/2)$。长波极限精确给 $\omega = c|\mathbf{k}|$，光速由 $l_P/t_P$ 定；波矢上限 $\pi/l_P$ 是布里渊区边界，对应能带顶 $2\sqrt3/t_P$。

**与 [[洛伦兹不变性]]**：$l_P$ 是高能偏离的唯一尺度，偏离形态被定死为 $-\frac{1}{24}(l_P^2k^2)$ 乘方向因子，方向比 $6:3:2$。低能处 $l_P k \ll 1$，偏离按平方律缩小，这就是低能精确的来源。

**与引力**：写入公式 $\theta(r) = Gm/(c^2r)$，在 $r = l_P$ 处给 $\theta = m/m_P$，恰等于每拍写入的份额（命题 B，第 458 条 DB1 至 DB4，8/8）。$l_P$ 是引力读数的天然单位。

**与 [[康普顿波长]]**：缺陷宽度恒等式给出 $\xi_0 = m_P/m_e$（以格距计），乘 $l_P$ 恰为电子的约化康普顿波长。这是「格数乘格距等于物理长度」最精确的一次核对。

**与测量**：位置标签由层数通道承载，取整数格数；位置份额（概率幅）由相位通道承载，连续取值。两者正交，互不重复计数。$l_P$ 因此只管标签的步长，概率幅不按它栅格化。

## 辨析：$l_P$ 是否「最小长度」

体系不用「最小长度」这个说法，用的是「格距」。两者在三个地方分得开。

**其一，可分辨下限是 $2l_P$。** 波矢上限为 $\pi/l_P$，对应波长下限 $2\pi/k_{\max} = 2l_P$。这来自采样定理，与时间侧的 $\omega_N = \pi/t_P$、可分辨时间 $2t_P$ 完全平行。格距是步长，可分辨性比步长粗一倍。

**其二，物理长度可连续取值。** 位置标签是整数，可杆长、缺陷宽度这类物理长度是波性侧读数，以格距为单位不必是整数。电子缺陷宽 $2.39\times10^{22}$ 格，尺缩后变为 $\xi_0/\gamma$（仍以格计），都是连续变化的量。

**其三，存在与可读分属两层。** 判据第 442 号把两个上限拆开：谱支撑上限 $\omega_{\mathrm{BZ}} = 2\sqrt3/t_P$ 属演化层，可分辨上限 $\omega_N = \pi/t_P$ 属读数层，区间 $(\omega_N, \omega_{\mathrm{BZ}}]$ 的模式存在但不可分辨（4/4 通过）。空间侧有平行结构：$l_P$ 是结构尺度，$2l_P$ 是读数带通，把两者混成「最小长度」会同时丢掉这两层。
