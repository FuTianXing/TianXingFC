# 锚核

**锚核**是复合位错粒子三层结构中的一层，由格点内锁定 $\kappa_\varphi$ 提供，负责钉住位错的位置并供给绑定能即质量。它的名字取船锚之意，作用是把粒子锚定在晶格的某个格点上，使粒子有确定位置。

## 概述

复合位错粒子被刻画成均匀缠绕背景上的一道位错，这道位错有三层分工：电荷归[[电荷]]核（toric code 层关系自由度，对易守恒），宽度与色散归包层（[[键弹性]]，法线轴弹性），质量与位置归锚核。锚核是其中唯一供质量的一层。

质量在体系里的定义是「锚核与真空的能量差」，即把它钉住这件事本身所花的能量。术语表那句「质量 = 拓扑缺陷绑定能」讲的就是这一点：粒子之所以有质量，因为它比纯真空多出一份把缺陷锁在原地的代价。代价的标度由势阱曲率决定，写成 $\omega_0 \sim \sqrt{\kappa_\varphi}$。耦合越硬，锁得越牢，粒子越重。

锚核的第二件工作是钉住位错的位置。体系原把这一层概括为「局域性 = 锚核钉位」；2026-09-24 之后改称「锚核（粒性侧的显形面）」，「钉位」一词不再使用。它与电荷、自旋、质量并列为粒子的四个标签，四个标签落在同一个对象上。

第三件工作是给出驻留的能力边界。承载它的正稿给出判据 $l_{\max} = A/\sigma$，实测 $1.26$ 格，结论是局域锚核的内驻设计关闭，粒子在体内不可达。一条相关的读数须并列记住：锚核只保形状，不保标签。

## 定义

锚核由格点内的锁定耦合 $\kappa_\varphi$ 定义。格点由 x/y/z 三类元相子构成，同类平行、异类耦合 $\kappa_\varphi$ 锁定。锚核即这份格点内锁定在位错处的体现。

质量由它与真空的能量差给出，即绑定能

$$E_B = E_{\text{锚核}} - E_{\text{真空}},$$

标度由相对相位模式势阱曲率给出，特征频率

$$\omega_0 \sim \sqrt{\kappa_\varphi}.$$

在 FK 记号下，锚核的代理形式是周期势（PN 势）$K(1 - \cos 2\pi u_n)$，包层是链弹性项，两者竞争给出位错宽度 $\ell^* \sim \sqrt{\kappa_\parallel/\kappa_\varphi}$。

## 机制

**其一，质量归锚核。** 三层分工中质量唯一归锚核。绑定能随 $\kappa_\varphi$ 的标度已数值确认（实测 3.13/121.9/359.4）。物理读法是弹簧越硬，同一构型的绑定能越大；粒子之间的轻重差别须由各态的有效锁定曲率与构型自由度给出，该层机制尚未导出（谱形侧开放项，见 [[判据草案-κ_φ 的必要性：极限清单、替代机制与有效刚度分布]]）。质量表述有两条极限形式，能隙式 $m_f \sim \hbar\sqrt{\kappa_\varphi}$（微观）与 Yukawa 式 $m_f c^2 = y_f v/\sqrt2$（宏观），两者是同一质量的两个极限，Yukawa 系数降为导出量 $y_f = \sqrt2\,\hbar\sqrt{\kappa_\varphi}/v$。

**其二，局域定位与局域性。** 锚核把位错钉在格点上，粒子因此有确定位置；该确定属物理事实层，不进入读数层（见 [[八爪鱼]] 与 [[位置]]）。体系的两层分工定律写为「守卫归波、承载归粒」：守恒由波性侧承担，局域由粒性侧承担，锚核是粒性侧那一半的落点。

**其三，驻留判据。** 弦（切割线）的能量密度由弛豫 kink 的总能量给出，与连续预测 $\sigma_w = 4\sqrt{K}/\pi$ 一致（$K$ 从 0.0005 到 0.05 的七档读数差不超过 $1.63\%$）。$\sigma_w$ 是"把芯拉向边界"的定量尺度。锚核的增益由凹口提供（$K_{xy} = K_0[1 - d\exp(-r^2/w_a^2)]$，$d = 0.9$、$w_a = 8$），实测凹口中心增益 $A(12) = 0.1007$、近边界 $A(4) = 0.0549$、远处 $A(20) = 0.0556$。

判据由拉力与增益的比给出

$$l_{\max} = A/\sigma,$$

实测 $1.26$ 格。含义是：锚核能拉住粒子的最大距离只有一格多。标度对照给出 $K$ 从 0.005 到 0.02 时拉力与增益按 $\sqrt{K}$ 等比放大（$0.080 \to 0.175$、$0.101 \to 0.282$），而 $l_{\max}$ 近似不变（$1.26 \to 1.61$），判据量由锚核的空间尺度决定。

**口径限定（2026-09-21 补，第 342 条）。** 上式里的 $\sigma$ 身份是弦张力，而拉力的直接测量用的是「边界环按芯的解析相位冻结」的构型。第 342 条把该构型搬到 C1 实际窗口（$K \ge 0.24$）重测：实测拉力 $1.0731$ 与 $1.3011$，对同档张力 $0.4186$ 与 $0.4318$ 之比 $2.56$ 与 $3.01$；

诊断定位为边界环的相位随芯位漂移（其势能斜率占实测拉力 $84\%$ 与 $86\%$，小档只占 $24\%$），把环改成不带漂移的取法后拉力降到 $6.5\times10^{-4}$ 与 $2\times10^{-6}$。故本条的 $l_{\max} = 1.26$ 格只在 $K \lesssim 0.02$ 档作近似参考；C1 窗口的 $l_{\max}$ 与所需 $w_a$ 须用强制净跳变的条带几何重测后引用。

**张力的分档（2026-09-21 补，第 341 条）。** $K \le 0.02$ 用连续式 $\frac4\pi\sqrt K$；$K \ge 0.10$ 用大刚度档闭式 $\sigma_2 = \frac12 - \frac{1}{3+4\pi^2K}$ 或四阶式 $\frac12 - \frac{1}{A} - \frac{4\pi^4K}{3A^4}$（$A = 3+4\pi^2K$），两支交接于 $K^{*} = 0.051326$。连续式在 $K = 0.24$ 与 $0.30$ 档偏高 $49\%$ 至 $62\%$。

**其四，负结论与判别力检验。** 局域锚核的内驻设计关闭，粒子在体内不可达。判别力由自由芯两档检验：逃逸距离约 $10$ 与约 $3$，两档都逃逸到边界，与 $l_{\max}$ 远小于这两个距离的预期一致。该负结论在小刚度档成立；第 342 条在 C1 窗口复测时五档全部逃逸（含 $w_a = 16$ 居中档），结论方向不变，但逃逸的驱动量被判定为边界相位漂移，故窗口档的数值待条带几何重测。

**其五，锚核只保形状不保标签。** 四档对照（横截面 $N = 64$、$K_0 = 0.005$、梯度下降 20000 步）的读数：无保护时标签从 $1$ 衰减到 $0$（第 450 步，末能量 $0.0431$）；仅锚核同样衰减，钉芯救不了标签；仅保护（边界冻结）时标签全程恒为 $1$（非一记录为零），能量从 $36.6532$ 收敛到 $5.2529$。保护加锚核的末态里，芯处留下 $(+1, -1)$ 偶极，净 $+1$ 仍驻边界，体内剖面平坦（峰谷差 $0.042$ 与 $0.001$）。所以位置稳定与守恒是两件事：前者归锚核，后者归边界保护。

## 通俗类比

把复合位错粒子想成钉在墙上的一个挂钩：挂钩本身是那层负责固定的结构，挂上东西之后它承担了重量。锚核就是这枚挂钩，它供的"绑定能"就是让挂钩嵌进墙里所需的代价，这个代价即质量。

类比说明的是固定结构的两个职能（定位与承重）落在同一层上；局限在于墙上的挂钩可以钉得很深，而这里的锚核能力有硬上界（$l_{\max} = 1.26$ 格），超出这个距离就锁不住。

## 例子

| 情形 | 结果 | 原因 |
|---|---|---|
| 质量归属 | 归锚核 | 绑定能即质量（定案） |
| 绑定能随 $\kappa_\varphi$ 标度 | 3.13/121.9/359.4，正比关系成立 | 势阱越硬、绑定能越大 |
| 锁在原格点上 | 成立：位置确定 | 锚核局域定位；2026-09-24 后「钉位」一词不再使用 |
| 体内驻留（内驻） | 不成立：局域锚核内驻不可达 | $l_{\max} = 1.26$ 格，远小于体内距离 |
| 仅靠锚核保标签 | 不成立：标签从 $1$ 衰减到 $0$ | 钉芯救不了标签，须边界冻结 |
| 保护加锚核 | 锚核只保形状，净荷仍驻边界 | 芯处留 $(+1, -1)$ 偶极 |
| 弹簧越硬 | 同一构型绑定能越大（粒子间轻重差另有来源，机制未导出） | $\omega_0 \sim \sqrt{\kappa_\varphi}$ |

## 与其他概念的关系

- **[[复合位错粒子]]**：锚核是三层结构之一，与电荷核、包层并列，唯一供质量的一层。
- **[[位错]]**：锚核钉住位错的位置，位错的能量学由锚核与包层两层弹性决定。
- **[[键弹性]]**：两者是竞争关系，$\ell^* \sim \sqrt{\kappa_\parallel/\kappa_\varphi}$，锚核（格点内）与包层（格点间）分工位置与宽度。
- **[[均匀缠绕背景]]**：锚核是背景上的一道位错的定位结构。
- **[[绕数]]**：电荷归电荷核与守卫层，锚核不承担守恒，两者分工明确。
- **[[电荷]]**：四标签（电荷、自旋、质量、局域性）中质量与局域性归锚核。
- **[[FK链]]**：FK 链上锚核对应周期势（PN 势）项，包层对应弹簧项。
- **[[时空晶格]]**：锚核由格点内锁定 $\kappa_\varphi$ 定义，格点由三类元相子异类耦合锁定。
- **标准模型的耦合对照**：$\kappa_\varphi$ 对应汤川型耦合（质量侧，$y_f = \sqrt{2}\,\hbar\sqrt{\kappa_\varphi}/v$）；精细结构常数 $\alpha$ 与强耦合 $\alpha_s$ 对应顶点型耦合（力侧）。两者地位不同：顶点耦合给力、随能标跑动，锁定耦合给质量、现记为相变后冻结的有效值，跑动方程未导出（见 [[判据草案-κ_φ 的必要性：极限清单、替代机制与有效刚度分布]]）。量级对照：$\alpha \approx 7.3\times10^{-3}$、$\alpha_s(M_Z) \approx 0.118$、$\kappa_\varphi t_P \approx 9.3\times10^{-47}$。

## 边界声明

本词条把锚核作为独立条目列出，其内容散在正稿、术语表与速览三处，本词条把质量机制、局域定位职能、驻留判据与"只保形状不保标签"四事并列。

四处须注意。其一，锚核身份未结项：$\kappa_\varphi$ 的严格形式是 PN 势还是格点内三元组锁定，尚未建立，子理论索引把"锚核恒等关系"登记为遗留项 C2，正稿诚实边界第一条亦记"锚核代理"。故本词条所述机制依托一个代理模型。
