# 边界项

**边界项**是位置-动量对易关系的期望与 $i\hbar$ 之差：圆上的相位取值模一圈，故对易关系的期望多出一项，其大小由态在 [[接缝]] 处的物理密度给出。它是「圆上正则关系与直线上的标准关系差多少」的定量形式。

## 概述

把圆上的描述搬到直线上，标准对易关系 $[\hat x,\hat p] = i\hbar$ 并不逐字成立：圆上的相位多绕一圈，于是关系的期望里多出一项。这一项不是常数，它随态在接缝处有多少重量而变；改变切割选择（把接缝挪到别处）就能改变它，故它属描述的痕迹，不属可观测量。

要恢复标准形式，需要三条同时成立：取 $e^{i\theta}$ 版本、限制在无接缝权的带限态、取准经典极限。三条齐备时标准形式恢复，接缝项与因子一起趋零。

## 定义

以 $l_P = \hbar = 1$ 计，取 $\hat x = l_P\hat\theta$（站点基对角）与 $\hat p = (\hbar/l_P)\hat L$（模基对角），则对归一化态

$$\langle [\hat L, \hat\theta] \rangle + i = i\,Z\,\lvert \psi_{s}\rvert^{2},$$

写成物理密度（$\int\lvert\psi\rvert^{2}\,\mathrm{d}\theta = 1$）即

$$\langle [\hat x, \hat p] \rangle = i\hbar\left(1 - 2\pi\rho_{\rm 接缝}\right).$$

两式之间的换算依据是格距 $\mathrm{d}\theta = 2\pi/Z$，故 $Z\lvert\psi_s\rvert^{2} \to 2\pi\rho_{\rm 接缝}$。

## 机制

其一，接缝处的密度。边界项的大小完全由态在接缝处的权重决定；态在别处的形状只通过归一化进入。

其二，光滑态上成立。光滑带限态上相对偏差为 $3.65\times10^{-2}$（$Z = 32$）至 $3.14\times10^{-4}$（$Z = 128$），随格距收敛。

其三，以动量窄带为前提。站点 δ 态（动量平坦）上偏差为 $O(1)$（$|X| = 1.000$），且不随格距缩小，属范围之外。

其四，两类接缝须分开。站点侧分支切割给出与格距无关的偏差，模侧提升回绕给出超指数衰减的接缝项；两者不是同一个量。

其五，幂律排除与切割自由度。若接缝项按幂律衰减，$Z = 256$ 档应落在 $10^{-26}$ 或 $10^{-27}$ 量级，实测 $2.13\times10^{-29}$，小两个量级以上；同一态把接缝从支撑外挪到支撑内，有效接缝项由 $4.60\times10^{-25}$ 跳到 $7.906$（$Z = 32$），相差二十五个量级。

## 通俗类比

给闭合山路标注海拔：起点选在哪里是你的自由，改起点只会让所有数字一起加同一个常数，任意两点的高差不变。类比说明描述自由与读数不变的分离；局限在于海拔的零点是人为约定，而这里的边界项会真的改变对易关系的期望值，只是它随切割选择移动，故不可观测。

## 例子

| 例子 | 结果 | 原因 |
|---|---|---|
| 光滑带限态 | 成立：相对偏差 $10^{-2}$ 至 $10^{-4}$ | 动量窄带，接缝权由密度给出 |
| 站点 δ 态 | 不成立：偏差为 $O(1)$ | 动量平坦，接缝权不再是小的 |
| 移动分支切割 | 成立：偏差跟随新接缝处的密度 | 边界项只依赖接缝处的权重 |
| 准经典极限 | 成立：比值趋近 $1$（$1.0158$） | 接缝项与因子同时趋零 |
| 硬壁盒与环上转子 | 偏移为 $1$ 与 $0$ | 折返点计数不同，由闭式谱直接读出 |

## 与其他概念的关系

[[接缝]]：边界项的量由接缝处的密度给出，接缝给结构、边界项给数值。

[[棱差]]：棱差是相邻之差，边界项是沿一圈累积后剩下的那一项。

[[相位]]：单站点相位不可读，是边界项出现的根源。

[[绕数]]：绕一圈的整数与边界项同源，都来自圆上的闭合条件。

[[序参量份额定理]]：份额恒等式在关系层上成立，边界项属算子层的偏离，两者分工不同。
