# 立方对称性

**立方对称性**是格点规则在立方格的全部 $48$ 个符号置换下保持不变的性质；在本体系中，它既是标量扇区边际各向异性的禁止者，也是高能色散方向指纹 $6:3:2$ 的承载者。同一个群在两处给出相反方向的结论，区别在作用对象的阶数。

## 概述

立方格的方向结构带取向。沿坐标轴、沿面对角线、沿体对角线，三个方向在格点上并不等价。把它们区别开的那个对称群，就是立方群。

体系对这个群的处理分两层，结论相反。

**禁止层。** 四维（边际）算符里凡带方向指标、且不合立方不变性的那些，被群平均直接压到零。标量扇区的各向异性属于这一层，它被精确禁止，不靠能标压低。

**允许层。** 高能色散的偏离项 $\sum_a k_a^4$ 带方向依赖，却完整满足立方不变性，因此被允许存在。它给出的方向比 $6:3:2$ 是体系的签名预言，本身属正常结构。

两层看似矛盾，实则同源：立方群禁止的是一切不合它的二次各向异性，允许的是合它的四次不变量。这条区分是理解本词条的关键。

## 定义

设格点坐标 $\mathbf x = (x, y, z)$。「符号置换」指把三个坐标重新排列，再把任意几项取反。这类操作共有 $3! \cdot 2^3 = 48$ 个，它们两两复合仍在这 $48$ 个之内，构成一个群，即立方群。

按行列式分两半：$24$ 个真转动（行列式 $+1$，保留手性），$24$ 个含反射（行列式 $-1$，翻转手性）。反射对称性正好是后一半，见[[反射对称性]]。

若格点规则（哈密顿量与更新规则）在全部 $48$ 个操作下逐项不变，则称规则具有立方对称性。按晶体学记号，这个群记作 $O_h$；只取 $24$ 个真转动的子群记作 $O$。

**判定一个方向系数矩阵是否合于立方群，用群平均：**

$$\bar C = \frac{1}{|G|}\sum_{R \in G} R\,C\,R^{\mathsf T}$$

群平均是一个投影：$\bar C$ 一定合于立方群，而差 $C - \bar C$ 落在不合群的部分（再作一次群平均即为零）。故差为零等价于原矩阵本就合群。判据给出的是精确零，未作近似：$48$ 个群元的显式求和偏差为 $0.000\times10^{0}$，正交性偏差亦为零（判据 M1）。

对任意的对称二阶张量，这个平均把矩阵压成迹的三分之一乘单位阵：

$$\bar C = \frac{\operatorname{tr} C}{3}\,\mathbb{1}$$

也就是说，立方群能容许的二阶各向同性张量只有一个，即单位阵的倍数。任何形如 $k_x^2 - k_y^2$ 的二次各向异性都被压掉。

## 机制

### 一、标量扇区：精确禁止

四维标量动能项若带方向指标，其系数矩阵即上述二阶张量。群平均把它压到 $\operatorname{tr}C/3$ 乘单位阵，各向异性部分归零（判据 M1，偏差 $0.000\times10^{0}$，通过阈值为 $10^{-14}$）。

这一步的意义在于零的性质：它来自对称性，不来自幂次计数。六维色散项是被能标压低才变小的，能量一升就会回来；这里的零在任何能标都成立，只要群精确。

### 二、张量扇区：只给一条关系

立方对称性在张量扇区不给同样的保护，原因是数数：立方弹性有三个独立常数 $C_{11}$、$C_{12}$、$C_{44}$，而各向同性只要求一条关系

$$C_{11} - C_{12} = 2C_{44}$$

三个常数减去一条约束，还剩两个自由度。故立方群允许一整族各向异性弹性，不把它们压成零。

体系的补法在键能形式上：键能取「罚差值向量的平方」，逐条键累加，按均匀应变反解给 $(C_{11}, C_{12}, C_{44}) = (2k, 0, k)$，关系构造性成立（判据 E1）。中心力对照（只罚键长）给 $(2k, 0, 0)$，关系被破坏、偏离 $100\%$，横波在 $[100]$ 方向刚度归零（判据 E2、E4）。

判据 M2 测出破坏后的量级：把关系破坏 $5\%$，横波与纵波分别出现 $-1.60\times10^{-2}$ 与 $+8.30\times10^{-3}$ 的方向分裂。这个数就是「张量扇区没有自动保护」的代价。

这一条与自旋 2 链条上的「各向同性封装」是同一个位置。两条线从不同方向走到同一坐标：一条从算符量纲出发，一条从守恒荷的构造出发，都指向 $C_{11} - C_{12} - 2C_{44}$。

### 三、高能色散：允许的那一侧

格点色散的四阶修正含 $\sum_a k_a^4$。这个组合在立方群下不变：交换坐标只是重排求和次序，取反不改变四次幂。故它是立方不变量，立方对称性允许它存在。

它的方向依赖由 $\sum_a k_a^4/k^2$ 承载，三个典型方向的取值为：

| 方向 | $\sum_a k_a^4/k^2$ | $\delta\omega/\omega$ |
|---|---|---|
| $[100]$ | $k^2$ | $-\frac{1}{24}(E/E_P^{(t)})^2$ |
| $[110]$ | $k^2/2$ | $-\frac{1}{48}(E/E_P^{(t)})^2$ |
| $[111]$ | $k^2/3$ | $-\frac{1}{72}(E/E_P^{(t)})^2$ |

比值 $6:3:2$，沿格子轴最强、沿体对角线最弱。这记录的是对称性在起作用，与对称性被破坏无关：只有合于立方群的项才有这样的方向结构。

把 $\sum_a k_a^4$ 分解为各向同性部分与各向异性部分：

$$\sum_a k_a^4 = \frac{3}{5}k^4 + \Big(\sum_a k_a^4 - \frac{3}{5}k^4\Big)$$

第二项球面平均为零，是纯粹的立方各向异性。系数 $3/5$ 是四阶张量的球面平均，与体系无关。

### 四、低能为什么看不见

首阶色散是 $k^2$，这一项在任何方向上都一样，因为它只含 $|\mathbf{k}|^2$。故低能端的旋转各向同性成立，且这一结论与立方对称性无关：即使格子只有立方对称性，$k^2$ 项也不显形（色散论文 §4）。

方向差别从 $k^4$ 阶才开始露头。这正是「低能精确、高能见指纹」这条分层在方向自由度上的表现。判据 M3 给出定量分界：各向同性模板下方向差随 $k^2$ 收缩（$\kappa = 10^{-3}$ 给 $5.56\times10^{-8}$，减半给 $1.39\times10^{-8}$，收缩比 $4.000$），落在不可关通道；把沿 $z$ 的耦合改 $5\%$ 后，方向差直接跳到 $1.67\times10^{-2}$，落进边际通道。

两者差的不只是数值，处置方式也不同：前者随能标自灭，后者只能靠对称性。

## 通俗类比

一张方格纸，横竖两个方向在纸上被画了出来，斜方向没有。你若在纸上量「走一步有多远」，横着走、斜着走、沿对角线走，走同样的步数到达的直线距离并不相同。这个差别就是立方结构。

现在要问：纸上的物理能不能「感觉」到这个差别？

若只看最粗的那一层（走一步的平均效果），横竖斜三者一样，感觉不到。若看到第二层细纹，差别就出来了，但出现的形态有规矩：沿横轴最大、沿对角线最小，比值固定。

体系的两种处置正对应这两层。粗层里不许出现「横比竖快」这类项，因为方格纸不允许它；细层里允许出现方向差异，但只允许方格纸自己能写出的那一类形状。

类比局限：纸的比喻给不出群论，也说不清为什么二阶被禁、四阶被允许。实际的判定靠 $48$ 个群元的显式求和。

## 例子

| 例子 | 是否合于立方群 | 后果 |
|---|---|---|
| 单位阵的倍数 $\operatorname{tr}C/3\cdot\mathbb{1}$ | 合 | 标量动能项的各向同性部分 |
| $k_x^2 - k_y^2$ 型二次各向异性 | 不合（交换 $x,y$ 后变号） | 被精确禁止（判据 M1） |
| $\sum_a k_a^4$ | 合 | 六维色散修正、方向比 $6:3:2$ |
| $(C_{11}, C_{12}, C_{44}) = (2k, 0, k)$ | 合（满足 $C_{11}-C_{12}=2C_{44}$） | 体系键能给出的各向同性弹性 |
| $(C_{11}, C_{12}, C_{44}) = (2k, 0, 0)$ | 不合（偏离 $100\%$） | 中心力键能，横波沿轴刚度归零 |
| 恰含一个全反对称符号的算符 | 不合（需反射对称性另行禁止） | 见[[反射对称性]]、[[边际通道]] |

## 与其他概念的关系

- [[反射对称性]]：立方群的一半（$24$ 个含反射的操作）。两者合起来才是 $48$ 元全群；宇称奇类算符的保护落在反射那一半。
- [[边际通道]]：立方对称性是该通道中标量各向异性的取零依据，属三族取零依据之一。
- [[时空晶格]]：立方对称性随格点结构一起给出，是格点规则的性质。
- [[洛伦兹不变性]]：立方群是洛伦兹群的离散子群，低能端旋转对称性在首阶恢复，方向差别从 $k^4$ 起才出现。
- [[自旋]]：张量扇区的各向同性关系与自旋 2 链条的「各向同性封装」是同一个位置。
- [[δ型与ε型算符]]：$\delta$ 型走立方对称性与键能形式，$\varepsilon$ 型走反射对称性。

## 严格程度

| 结论 | 严格程度 |
|---|---|
| 立方群为 $48$ 元，含 $24$ 真转动与 $24$ 反演型 | 群论事实 |
| 二阶对称张量的群平均等于迹三分之一乘单位阵 | 线性代数事实（判据 M1，偏差 $0.000\times10^{0}$） |
| 标量扇区各向异性被精确禁止 | 条件性：前提为格点规则满足全部 $48$ 个操作 |
| 张量扇区只受一条关系约束 | 解析事实（判据 M2） |
| 体系键能满足该关系 | 解析事实加可复现数值（判据 E1 至 E4） |
| $\sum_a k_a^4$ 为立方不变量并给 $6:3:2$ | 解析事实加可复现数值（色散论文 §5） |
| 立方对称性在量子层面不被反常破坏 | 未证，登记为开放项（判据 M1 注记 §六） |

最后一行是整表的软处。经典层面的群平均是精确的，量子修正下是否保持，尚未计算，与边际通道封口的前提是同一条。
