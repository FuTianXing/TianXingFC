# 哈密顿量

**哈密顿量**是系统的总能量，也是量子力学中管时间演化的那个算符。标准物理用相空间（位置与动量）上的函数 $H(q,p) = T + V$ 表示它，把它的三项成分当作公设写进薛定谔方程。元相子理论把这三项全部降为束缚振荡晶格的推论：哈密顿量 = 晶格能量，势能项是局域能隙扰动的能量 $V = \hbar\,\delta\omega$，质量项是绑定能（$\kappa_\varphi$ 锁定能隙）。

## 概述

哈密顿量是系统的总能量清单，同时是"下一步怎么变"的演化规则。标准物理用它给出两套方程：经典力学中是哈密顿方程组

$$\dot q = \frac{\partial H}{\partial p}, \qquad \dot p = -\frac{\partial H}{\partial q},$$

量子力学中是薛定谔方程

$$i\hbar\,\partial_t\psi = H\psi.$$

前者是相空间（位置与动量）里的一阶方程组，后者把哈密顿量从"能量"变成"时间演化生成元"，它是"状态如何演化"的视角。

标准物理把哈密顿量的成分当作公设：薛定谔方程的时间生成元、动能、势能三项各自独立地写进框架。元相子理论把这三项的独立地位全部取消，证据来自五项公设的系统降级[[量子力学物侧基础的总结论：从公设到晶格的五步降级]]：哈密顿量 = 束缚振荡晶格的能量，每一项成分都在晶格上找到微观出身，降级完成的标志是两处恒等式（质量恒等式与动能系数恒等式）。

## 定义

标准定义（相空间）：$H(q, p) = T + V$，广义动量 $p = \partial L/\partial\dot q$，与拉格朗日量经勒让德变换联系

$$H = p\,\dot q - L.$$

体系内的哈密顿量给出在公理 4 的耦合哈密顿（[[元相子几何动力学——束缚振荡修订整合版|元相子几何动力学]]），本体层以三类耦合写成

$$\mathcal{H} = \sum_i\frac{\hbar\bar t_P}{2}\dot{\tilde\theta}_i^2 - \sum_{i<j,\ \text{同类}}\hbar K_{ij}\cos(\theta_j - \theta_i) - \mathcal{H}_{\text{异类}} + \mathcal{H}_{\text{束缚}},$$

其中

$$\mathcal{H}_{\text{异类}} = -\hbar\kappa_\phi\sum_p\sum_{a<b}\cos(\theta_p^a - \theta_p^b), \qquad K_0 = \frac{\bar t_P c^2}{l_P^2} = \frac{1}{2\pi t_P}.$$

三类耦合依次提供哈密顿量的三项成分，每一项都有晶格上的物理来源。

- 同类相位差耦合 $-\hbar K_{ij}\cos(\theta_j-\theta_i)$：梯度代价，提供动能与传播，对应算符 $-\hbar^2\nabla^2/2m$，有效质量 $m^* = \hbar\omega_0/c^2$
- 异类三元组内耦合（$\kappa_\varphi$）：提供能隙，对应质量项，绑定能即质量（$m \sim \hbar\sqrt{\kappa_\varphi}$）
- 圆心不可重合的硬核排斥 $\mathcal{H}_{\text{束缚}}$：提供束缚与碰撞，是折返机制的来源
- 时间生成元 $i\hbar\partial_t$：元相方程 (I) $i\hbar\,d\psi/dt = E_P\psi$ 即定态薛定谔，$E_P = \hbar\omega_P$ 由几何导出

## 机制

哈密顿量的晶格来源在公理 4 的三类耦合，每一类都在格点上有明确的物理动作。

其一，同类耦合提供动能。相邻格点之间的相位差产生梯度代价，相位场越"拧"代价越高，这份代价在长波极限下化为动能项。耦合刚度由光速涌现条件固定为 $K_0 = \bar t_P c^2/l_P^2$，三类方向相同，这是各向同性的来源。

其二，异类耦合提供质量。每个格点上的三类元相子（三个正交方向）经 $\kappa_\varphi$ 耦合，使 $U(1)^3$ 对称性显式破缺为整体 $U(1)$，相位差因此获得能隙 $\sim\sqrt{\kappa_\varphi}$。这个能隙就是质量：色散关系在带底被打开一个缺口，缺口宽度经 $\hbar/c^2$ 换算即静止质量，与缺陷绑定能同义。

其三，硬核排斥提供束缚。圆心不可重合给出无穷高的排斥势，相邻格点的圆心相向运动并在公共边界重合，重合瞬间即弹性碰撞、运动折返。折返是"波性驱动"与"粒性阻挡"在边界处冲突的必然解决，无墙也无外部设施，只有邻居。

三者的合成使时间演化获得物侧出身。元相方程 (I) 用 $\omega_P$ 定出定态薛定谔，能量-频率换算 $E_P = \hbar\omega_P$ 由连续旋转方程的几何推导给出，不引入循环。运动方程向下衔接哈密顿方程组与薛定谔方程，向上则与拉格朗日量的路径变分互补。

势能项另有独立机制：相位旋转角频率 $\omega$ 的局域偏离 $\delta\omega$ 经 $\hbar$ 换算为能量。基态 $\omega_0$ 处处均匀（真空无势差、不可做功），任何让 $\omega$ 偏离的东西（缺陷即粒子势阱、晶格形变即引力势、环境调制即背景场）都在当地制造势能。详见[[势能]]。

## 通俗类比

哈密顿量 = 系统的"总能量清单"，管"下一步怎么变"。体系把清单的每一项变成结构事实：动能是相位梯度（越拧越贵），势能是当地钟的快慢（$V = \hbar\delta\omega$，频率偏离基态多少就携带多少能量），质量是能隙（格点内三类方向锁定的强度），束缚是邻居不许你穿过去。

类比说明的是"能量清单可以逐项溯源"，局限在于晶格的每一条耦合都对应一个具体参数（$K_0$、$\kappa_\varphi$、硬核半径），类比本身给不出这些数值。

## 与其他概念的关系

- **[[拉格朗日量]]**：哈密顿量经勒让德变换得自拉格朗日量（$H = p\,\dot q - L$）；哈密顿管状态演化（粒性侧），拉格朗日管路径变分（波性侧），二者是同一动力学的两种视角
- **[[势能]]**：$V = \hbar\,\delta\omega$，局域能隙扰动，与质量在同一把频率尺上一体两面
- **[[元相子]]**：元相子的相位 $\theta$ 与提升相位 $\tilde\theta$ 是哈密顿量的本体层变量，三类耦合皆定义在它们之上
- **[[相位]]**：同类耦合是相位差的余弦，动能即相位梯度的代价，哈密顿量的"动力学"读在相位上
- **[[时空晶格]]**：哈密顿量的三项都定义在晶格上（格点、格键、格点内锁定），晶格是它的定义域
- **[[螺旋阶梯几何]]**：时间生成元的几何来源在螺旋阶梯（相位旋转一圈、圆心跃迁一格），哈密顿量的时间项由此获得出身
- **质量**（待建）：绑定能（$\kappa_\varphi$ 能隙），势能是质量的局域调制，二者由 $\delta m = V/c^2$ 衔接
- **元相方程**：方程 (I) 即定态薛定谔，哈密顿量的时间生成元部分与它同源

## 边界声明

- 严格程度分层：时间生成元、质量、束缚为已确认或公理级；动能项为条件性命题（长波 + 缓变包络）；势能项为条件性命题（慢变势）。词条不把条件性项升格为定理级。
- 力学的适用域限定：本体哈密顿的"保守可逆"限定为物侧动力学在同步态邻域、无校准作用时的有效描述，完整本体动力学的对称群不含时间反演（[[元相子几何动力学——束缚振荡修订整合版|元相子几何动力学]]修订说明第 3 项）。
- 未闭合：碰撞为何完美弹性的微观机制待声明；振幅耦合不进入本体哈密顿量，作为涌现层有效理论项（O8）；一阶 Kuramoto 形式降级为涌现层粗粒化描述（P8c）。
- 不涉项：本词条只覆盖哈密顿量本身的成分与出身，不涉其量子化与二次量子化形式。
