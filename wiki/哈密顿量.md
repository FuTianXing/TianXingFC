# 哈密顿量

**哈密顿量**是系统的总能量（动能加势能），相空间（位置与动量）上的函数，量子力学中的时间演化生成元。在元相子理论中，哈密顿量从束缚振荡晶格的能量降级推导，势能 = 局域能隙扰动的能量 $V = \hbar\delta\omega$，质量 = 绑定能（$\kappa_\varphi$ 锁定）。

## 概述

哈密顿量 $H = T + V$（动能加势能 = 总能量）是标准物理的核心对象：经典力学中哈密顿方程 $q\dot = \partial H/\partial p$、$\dot p = -\partial H/\partial q$ 给出一阶演化方程组；量子力学中 $i\hbar\partial_t\psi = H\psi$ 使哈密顿量成为时间演化生成元。它是"状态如何演化"的视角，与拉格朗日量的"路径"视角互补，二者经勒让德变换 $H = p\dot q - L$ 联系。

标准物理把哈密顿量当作公设（薛定谔方程的三成分：时间生成元、动能、势能）。元相子理论把三者全部降为束缚振荡晶格的推论：哈密顿量 = 晶格能量，其成分逐一获得微观出身。

## 定义

标准定义（相空间）：$H(q, p) = T + V$，其中 $p = \partial L/\partial\dot q$（广义动量），$H = p\dot q - L$（勒让德变换）。哈密顿方程 $q\dot = \partial H/\partial p$、$\dot p = -\partial H/\partial q$。

体系内的成分（薛定谔方程公设降级）：

- 动能算符 $-\hbar^2\nabla^2/2m$：同类相位差耦合（相位梯度代价），有效质量 $m^* = \hbar\omega_0/c^2$
- 势能 $V(\mathbf{x}) = \hbar\,\delta\omega(\mathbf{x})$：局域能隙扰动的能量（定理 5.1）
- 时间生成元 $i\hbar\partial_t$：元相方程 (I) $i\hbar d\psi/dt = E_P\psi$ 即定态薛定谔，$E_P = \hbar\omega_P$ 由几何导出

## 机制

哈密顿量的晶格来源在公理 4 的耦合哈密顿（三类项）：

1. **同类相位差耦合**：梯度代价，提供动能/传播
2. **异类三元组内耦合（$\kappa_\varphi$）**：提供能隙，质量 = 绑定能（$m \sim \hbar\sqrt{\kappa_\varphi}$）
3. **圆心不可重合的硬核排斥**：提供束缚与碰撞

势能的机制：$\omega$（相位旋转角频率）的局域偏离 $\delta\omega$ 经 $\hbar$ 换算为能量。基态 $\omega_0$ 处处均匀（真空无势差、不可做功），任何让 $\omega$ 偏离的东西（缺陷 = 粒子势阱、晶格形变 = 引力势、环境调制 = 背景场）在当地制造势能。势能与质量一体两面，都来自同一把频率尺。

## 通俗类比

哈密顿量 = 系统的"总能量清单"，管"下一步怎么变"（演化）。体系把清单的每一项变成结构事实：动能是相位梯度（越拧越贵），势能是当地钟快慢（$V = \hbar\delta\omega$，频率偏离基态多少就携带多少能量），总能量是同一座晶格能量景观的读数。

## 与其他概念的关系

- **拉格朗日量**：哈密顿量 = 勒让德变换自拉格朗日量（$H = p\dot q - L$）；哈密顿管状态演化（粒性侧），拉格朗日管路径变分（波性侧）
- **势能**：$V = \hbar\delta\omega$，局域能隙扰动，与质量同一频率尺
- **质量**：绑定能（$\kappa_\varphi$ 能隙），势能是质量的局域调制
- **引力**：晶格形变（三类微源之二）= 引力势，接钟慢链条（势阱 = 当地摆程频率降低）
- **元相方程**：方程 (I) 即定态薛定谔（哈密顿量 = 普朗克能量本征值）
