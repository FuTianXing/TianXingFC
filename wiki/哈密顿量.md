# 哈密顿量

**哈密顿量**是系统的总能量（确切说，可提取的那一部分），也是量子力学中管时间演化的那个算符。标准物理用相空间（位置与动量）上的函数 $H(q,p) = T + V$ 表示它，把它的三项成分当作公设写进薛定谔方程。元相子理论把这三项全部降为束缚振荡晶格的推论：哈密顿量 = 晶格能量，势能项是局域能隙扰动的能量 $V = \hbar\,\delta\omega$，质量项是绑定能（$\kappa_\phi$ 锁定能隙）。降级强度并不一致：时间生成元与质量已闭合到代数恒等式，动能与势能各带一条近似前提。

## 概述

哈密顿量是系统的总能量清单，同时是"下一步怎么变"的演化规则。标准物理用它给出两套方程：经典力学中是哈密顿方程组

$$\dot q = \frac{\partial H}{\partial p}, \qquad \dot p = -\frac{\partial H}{\partial q},$$

量子力学中是薛定谔方程

$$i\hbar\,\partial_t\psi = H\psi.$$

前者是相空间（位置与动量）里的一阶方程组，后者把哈密顿量从"能量"变成"时间演化生成元"，它是"状态如何演化"的视角。

标准物理把哈密顿量的成分当作公设：薛定谔方程的时间生成元、动能、势能三项各自独立地写进框架。元相子理论把这三项的独立地位全部取消，证据来自五项公设的系统降级[[量子力学物侧基础的总结论：从公设到晶格的五步降级]]：哈密顿量 = 束缚振荡晶格的能量，每一项成分都在晶格上找到微观出身，形式对应的完成标志是两处恒等式级闭环：有效质量恒等式 $m^* = \hbar\omega_0/c^2$ 与份额恒等式 $|c_a|^2 = N_a/N$。形式对应成立并不等于每项都是定理，强度差异见下文的成分清单与边界声明。

## 定义

标准定义（相空间）：$H(q, p) = T + V$，广义动量 $p = \partial L/\partial\dot q$，与拉格朗日量经勒让德变换联系

$$H = p\,\dot q - L.$$

体系内的哈密顿量给出在源文档公理 4 的耦合哈密顿（[[元相子几何动力学——束缚振荡修订整合版|元相子几何动力学]]），本体层以三类耦合写成

$$\mathcal{H} = \sum_i\frac{\hbar\bar t_P}{2}\dot{\tilde\theta}_i^2 - \sum_{\langle i,j\rangle,\ \text{同类}}\hbar K_{ij}\cos(\theta_j - \theta_i) - \mathcal{H}_{\text{异类}} + \mathcal{H}_{\text{束缚}},$$

其中

$$\mathcal{H}_{\text{异类}} = -\hbar\kappa_\phi\sum_p\sum_{a<b}\cos(\theta_p^a - \theta_p^b), \qquad K_{ij} = K_0\,f(n_i - n_j), \qquad K_0 = \frac{\bar t_P c^2}{l_P^2} = \frac{1}{2\pi t_P}.$$

几处记号先立住。$H$ 用于标准形式（$H = p\dot q - L$、哈密顿方程组），$\mathcal{H}$ 用于本体层，两者是同一个量的两种写法，本词条不混用。$\bar t_P = t_P/2\pi = 1/\omega_P$ 是弧度族的折算摆程，周期族与弧度族的换算见 [[相位耦合标度]]；动能项的系数 $\hbar\bar t_P$ 即 [[方向惯性系数]] 词条里的 $I$。

$\mathcal{H}_{\text{异类}}$ 取负号定义（源文档写法），代入整式后展开为 $+\hbar\kappa_\phi\sum\cos$，与同类项的负号相反：同类耦合是铁磁型，相位对齐时能量最低；异类耦合是反铁磁型，相位差越大能量越低。三条内边无法同时取到 $\pi$，三角阻挫的具体基态不在本词条射程。

三类耦合给出动能、质量、束缚三项，势能与时间生成元各另有一条来路，下面连在一起列。

- 同类相位差耦合 $-\hbar K_{ij}\cos(\theta_j-\theta_i)$：提供波动刚度，配合旋转波分解与长波近似给出动能算符 $-\hbar^2\nabla^2/2m^*$，有效质量 $m^* = \hbar\omega_0/c^2$
- 异类三元组内耦合（$\kappa_\phi$）：提供能隙 $\omega_0 = \sqrt{3\omega_P\kappa_\phi}$，经 $\hbar/c^2$ 换算给出质量 $m = \hbar\omega_0/c^2$，对应哈密顿量的质量项
- 圆心不可重合的硬核排斥 $\mathcal{H}_{\text{束缚}}$：提供束缚与碰撞，是折返机制的来源
- 时间生成元 $i\hbar\partial_t$：[[wiki/元相方程]] (I) $i\hbar\,d\psi/dt = E_P\psi$ 即定态薛定谔，$E_P = \hbar\omega_P = h/t_P$ 由几何导出。这是体系基准的能量约定，等于 $2\pi E_P^{(t)}$，两套约定的来历见 [[普朗克能量]]

## 机制

哈密顿量的晶格来源在源文档公理 4 的三类耦合，每一类都在格点上有明确的物理动作。

其一，同类耦合提供波动刚度。相邻格点之间的相位差耦合给出谱中的刚度项

$$\omega^2(\mathbf{k}) = \frac{4}{t_P^2}\sum_a\sin^2\frac{k_al_P}{2} + 3\omega_P\kappa_\phi,$$

其中前半即刚度贡献，低能展开为 $c^2|\mathbf{k}|^2$。耦合刚度由光速涌现条件固定为 $K_0 = \bar t_P c^2/l_P^2 = 1/(2\pi t_P)$，三类方向相同，这是各向同性的来源，也是横纵刚度的共同出处。

其二，异类耦合提供能隙。格点上三个正交方向经 $\kappa_\phi$ 耦合，$U(1)^3$ 显式破缺为整体 $U(1)$。经正交变换

$$\Phi = \frac{\theta^x+\theta^y+\theta^z}{\sqrt3}, \qquad \delta_1 = \frac{\theta^x-\theta^y}{\sqrt2}, \qquad \delta_2 = \frac{\theta^x+\theta^y-2\theta^z}{\sqrt6},$$

整体相位模式 $\Phi$ 保持无质量，是 Goldstone 模式；两个相位差模式 $\delta_1$、$\delta_2$ 获得能隙

$$\omega_0 = \sqrt{3\omega_P\kappa_\phi},$$

经 $\hbar/c^2$ 换算给出静止质量 $m = \hbar\omega_0/c^2$。注意能隙与质量分两步：能隙是频率尺上的缺口宽度 $\omega_0$，质量是同一缺口的能量读数。色散曲率定出的 $m^*$ 与缺陷绑定能定出的 $m$ 落在同一个能隙上，两条独立路径一致，这是该机制最硬的一环（定理 4.2 恒等式）。两个记号同值，本词条不据此分作两个量。

其三，硬核排斥提供束缚。圆心不可重合给出无穷高的排斥势，相邻格点的圆心相向运动并在公共边界重合，重合瞬间即弹性碰撞、运动折返。折返是"波性驱动"与"粒性阻挡"在边界处冲突的必然解决，无墙也无外部设施，只有邻居。

约束的写法也要交代。体系用无穷高势实现圆心不可重合，不用拉格朗日乘子，故 $\mathcal{H}$ 在物侧仍等于总能量；若换成乘子写法，哈密顿量与能量的等式须另行讨论，这是标准力学的一般结论，非本体系特有。

三类耦合需要与两重近似合起来才给出薛定谔方程。同类耦合提供波动刚度，异类耦合提供抽出快本底所需的 $\omega_0$，旋转波分解抽走 $e^{-i\omega_0 t}$ 本底后，长波极限与旋转波近似（能量 $\ll\hbar\omega_0$）把晶格方程化为动能项与质量项。缺异类耦合则无本底可抽，动能系数 $\hbar c^2/2\omega_0$ 里的 $\omega_0$ 正来自它，故长波极限单独给不出动能项。

时间生成元另有出身：元相方程 (I) 用 $\omega_P$ 定出定态薛定谔，能量-频率换算 $E_P = \hbar\omega_P$ 由连续旋转方程的几何推导给出，不引入循环。运动方程向下衔接哈密顿方程组与薛定谔方程，向上则与作用量的路径变分互补（见 [[作用量]]）。

还有一层结构要说：它不显含时间。$\mathcal{H}$ 只依赖相位与相位差，$K_0$ 与 $\kappa_\phi$ 是格点常数，格点排布不随时间变，故 $\partial_t\mathcal{H} = 0$。诺特定理的时间平移前提因此在本体层成立，能量守恒作为条件继承下来（[[诺特定理的元相子根基：哈密顿继承、几何守恒与守恒律的分级]] 的 A 层）。这里要分清两件事：守恒的**存在**由不含时给出，守恒的**刚性**由元相子没有内部自由度、碰撞不耗散给出，后者是判据 V1 至 V5 的内容。

对称群要按离散层读，不能照搬连续群。空间平移群是 $\mathbb{Z}^3$，对应的守恒量是准动量，动量只是长波极限的读法；旋转对称只有立方点群 $O_h$，不是连续 $SO(3)$，角动量在离散层应读作点群标签。异类耦合把 $U(1)^3$ 显式破缺为整体 $U(1)$，故只有与总相位对应的荷严格守恒，三个分向的相位各自并不守恒。

势能项另有独立机制：能隙 $\omega_0$ 的局域偏离 $\delta\omega$ 经 $\hbar$ 换算为能量，即在均匀能隙上做逐点调制 $\Omega(\mathbf{x}) = \omega_0 + \delta\omega(\mathbf{x})$。可归为三类候选微源：缺陷即粒子势阱、晶格形变（引力势，与保角因子、度规衔接）、环境调制即背景场。三者的定量形式与彼此区分判据尚未给出。

引力一路另有法线场的稳态记录路线（$\theta=-\Phi/c^2$），与本词条的能隙调制路线之间的换算形式尚未在文本中列举并筛选。详见[[势能]]，其中「当地钟的快慢」须分三层读（元相子节拍、锁定能隙、度规给出的时钟比例），势能只改第二层。

还有一栏必须单列。$\mathcal{H}$ 的基态不为零：每个格点带着 $E_\Phi = \hbar\omega_P$ 的真空刚度能量，处处相同、不可提取。这一份不进入引力写入幅度的分子（$\delta\theta = m/m_P$）。若把它当质量，每个格点都成黑洞：$r_s(2\pi m_P) = 4\pi l_P \gg \lambda_C$（[[康普顿波长]]）。故"哈密顿量 = 总能量"在本体层须读作"可提取能量加一份均匀本底"，引力只认前者。真空能为何不可提取属源文档公理 8（真空能公理）的全局陈述，与上面那段的局域来源分属两件事，勿混。

## 通俗类比

哈密顿量 = 系统的"总能量清单"，管"下一步怎么变"。体系把清单的每一项变成结构事实：动能是相位梯度（越拧越贵），势能是当地钟的快慢（$V = \hbar\delta\omega$，频率偏离基态多少就携带多少能量），质量是能隙经 $\hbar/c^2$ 换算的能量读数，束缚是邻居不许你穿过去。

类比说明的是"能量清单可以逐项溯源"，局限在于晶格的每一条耦合都对应一个具体参数（$K_0$、$\kappa_\phi$、硬核半径），类比本身给不出这些数值。

## 与其他概念的关系

- **[[拉格朗日量]]**：哈密顿量经勒让德变换得自拉格朗日量（$H = p\,\dot q - L$）；哈密顿管状态演化（粒性侧），拉格朗日管路径变分（波性侧），二者是同一动力学的两种视角
- **[[势能]]**：$V = \hbar\,\delta\omega$，能隙的局域调制，与质量是同一把频率尺上的两段读数（$\delta m = V/c^2$）
- **[[元相子]]**：元相子的相位 $\theta$ 与 [[提升相位]] $\tilde\theta$ 是哈密顿量的本体层变量，三类耦合皆定义在它们之上
- **[[相位]]**：同类耦合是相位差的余弦，动能即相位梯度的代价，哈密顿量的"动力学"读在相位上
- **[[时空晶格]]**：哈密顿量的三项都定义在晶格上（格点、格键、格点内锁定），晶格是它的定义域
- **[[wiki/螺旋阶梯几何]]**：时间生成元的几何来源在螺旋阶梯（相位旋转一圈、圆心跃迁一格），哈密顿量的时间项由此获得出身
- **[[质量]]**：绑定能（$\kappa_\phi$ 能隙），能隙经 $\hbar/c^2$ 换算即静止质量；势能是质量的局域调制，二者由 $\delta m = V/c^2$ 衔接
- **[[诺特定理]]**：$\mathcal{H}$ 不显含时间，时间平移前提在本体层成立，能量守恒由此作为条件继承（A 层）；守恒的刚性另由完美弹性给出。心侧校准不在 $\mathcal{H}$ 内，故守恒覆盖的是物侧被动演化
- **[[wiki/元相方程]]**：方程 (I) 即定态薛定谔，哈密顿量的时间生成元部分与它同源

## 边界声明

- 严格程度分层：时间生成元与质量为代数级，束缚为公理级（条件于 A2），动能项为条件性命题（长波 + 缓变包络），势能项为条件性命题（慢变势）。词条不把条件性项升格为定理级。
- 前置依赖：动能项与质量项的推导都要用束缚振荡的摆程节律，即 §5bis 记作"定理 3 束缚振荡与摆钟"的条目，该条自 2026-10-03 起列为待推导。故二者在本体层的严格性以该条成立为前提。
- 力学的适用域限定：本体哈密顿的"保守可逆"限定为物侧动力学在同步态邻域、无校准作用时的有效描述，完整本体动力学的对称群不含时间反演（[[元相子几何动力学——束缚振荡修订整合版|元相子几何动力学]]修订说明第 3 项）。
- 未闭合：振幅耦合不进入本体哈密顿量，作为涌现层有效理论项（O8）；一阶 Kuramoto 形式降级为涌现层粗粒化描述（P8c）。完美弹性本体已公理级形式化（判据 V1 至 V5，条件于刚性锁定 A2），残留开放项为多体与场耦合表观阻尼、三维含缺陷构型的推广、非等速情形（注记 §六）。
- 不涉项：本词条只覆盖哈密顿量本身的成分与出身，不涉其量子化与二次量子化形式。
