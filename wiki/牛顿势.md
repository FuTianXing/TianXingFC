# 牛顿势

**牛顿势**是描述引力场的标量函数 $\Phi$，数值上等于空间中每一点上单位质量所具有的引力势能：在静止球对称质量 $M$ 之外为 $\Phi(r) = -GM/r$，引力场等于它的负梯度 $\mathbf{g} = -\nabla\Phi$。

## 概述

牛顿势把一个矢量场换成一个标量场。引力本是三个分量、处处不同的箭头，势只给一个数，箭头由它的坡度读出。算轨道、比强弱、画场形，用势都比直接用箭头省事。

它在元相子理论里有一个直接对应物。法线场的稳态记录 $\theta(r) = Gm/(c^2r)$ 与牛顿势只差一个常数因子，即 $\theta = -\Phi/c^2$。井的形状由记录场承载，"每拍写入一笔、邻居抄写平均"的过程收敛到这个形状，数值上逐位吻合。

势的三条基本性质各有出处。负号来自零点约定，越靠近质量势越低。$1/r$ 的形状来自力的 $1/r^2$ 沿半径累积。势的源头是质量密度，这层关系写在泊松方程里。

它的射程停在弱场静态区。强场与动态过程需要完整场方程，势的作用是先把弱场区钉死。

## 定义

对静止球对称质量 $M$，势与场的关系为

$$\Phi(r) = -\frac{GM}{r}, \qquad \mathbf{g} = -\nabla\Phi, \qquad \nabla^2\Phi = 4\pi G\rho .$$

单位为 $\mathrm{m}^2/\mathrm{s}^2$，即每千克的焦耳数。零点约定为无穷远处取零。换一个零点等于给全图加一个常数，物理不变。

除以 $c^2$ 无量纲化，得到体系内的记录场

$$\theta = -\frac{\Phi}{c^2} = \frac{Gm}{c^2 r},$$

度规时间分量按弱场约定与之耦合，即 $g_{00} = -(1 + 2\Phi/c^2) = -(1 - 2\theta)$。空间各向同性时 $h_{ij} = h_{00}\delta_{ij}$。

## 机制

1. **定形**：质量密度 $\rho$ 经泊松方程定出势的空间分布，球对称解为 $1/r$。
2. **传力**：引力线摊在第一层球面上，球面积为 $4\pi r^2$，力的衰减因此是 $1/r^2$；势是力沿半径的累积，指数减一即为 $1/r$。
3. **生效**：势的坡度给出加速度，势差给出单位质量的能量差，势的深浅给出钟的快慢。
4. **体系侧**：每普朗克拍写入 $\delta\theta = m/m_P$，邻居抄写平均，写入与扩散的平衡给出离散泊松格林函数。$4\pi$ 由三维立体角自动涌现，$G$ 经 $m_P$ 单一入口带入，恒等式为 $G/(c^2l_P) = 1/m_P$。

## 通俗类比

把势想成地形图上的海拔。海拔是一个数，坡度与坡向由它算出来；引力场就是坡度，物体往低处滑等于往势低处去。等势面是等高线，一池静水会自己躺成等势面。

类比说明两件事。只有落差有意义，绝对高度可以整体平移；坡度越缓，力越小。局限有两条：地形只是平面上的图，势住在三维空间里；势还管时间那一半，势越低的地方钟越慢。

## 史瓦西对齐中 1/2 的通俗解释

体系里有一个数被反复引用：记录场在史瓦西半径处恰好取 $1/2$。这个数的来历分三层，混在一起讲容易把它读成体系的新预言。

**算术层，一次除法。** 史瓦西半径的定义式为 $r_s = 2GM/c^2$。把 $r = r_s$ 代进 $\theta = GM/(c^2r)$，$G$、$M$、$c$ 全部约掉，剩下的就是 $1/2$。

打个比方：一场赛跑的终点线由"走完一半路程"来规定，冲线时的读数必然是百分之五十。这一层用到的东西全在标准物理里，任何学过广义相对论的人都能一步写出。

**物理层，体系读作饱和点。** $\theta$ 是无量纲读数；按作者 2026-09-15 裁定的线性映射，$1/2$ 对应法线压弯 $90^\circ$，即视界，详见 [[注记-记录场读数的角度映射审查：满偏与视界角的三套候选读法]]。此时线性化所用的 $\tan\theta \approx \theta$ 已有约一成的偏差，弱场构造到此开始失准，再往里走要换强场动力学（饱和、缠绕、耦合重开三个候选）。

标准物理里没有记录场这个概念，也没有饱和点这种读法，这层解读是体系自己的。

**检验层，零参数的分量。** 体系声称机制里没有可调的旋钮。设记录场带归一化自由度 $\theta = \kappa\,GM/(c^2r)$，对齐要求 $\kappa = 1$。三道闸门（同源无量纲化、稳态唯一性、单点识别）把它挤到 1，链上任何一处藏入旋钮都要破坏另一处已验证的闭合。

四例数值给出 $\theta(r_s) = 0.500000000000$，其间跨六十个数量级（电子、质子、地球、太阳）。

**边界。** 这个数值取自标准物理的代数恒等式，体系做的是把它识别为饱和点并论证它不容偏离，对齐锁死的仍是归一化自由度（乘积 $\kappa N_c$）。面向外部的写作不得表述为体系预言了 $1/2$。同类数值在特征半径处属常见现象，光子球半径处读到的是 $1/3$。
