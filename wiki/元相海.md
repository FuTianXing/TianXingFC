# 元相海

**元相海**是元相子的最大集合：公理 1 无穷系综的显式命名，宇宙全部元相子（个体、格点阵、相位场、纠缠与相干）的总和，含粒性海与波性海两个互补侧面，永在增长、永不完成。

## 概述

体系中有小傅（单个元相子）与大傅（宇宙整体的宏观涌现），本体层缺一个显式的"最大集合"概念及其波粒双侧结构。元相海补上这一层：它是本体层的最大集合，大傅是它的涌现层表现，两者是同一个"海"的两个视角。

元相海要回答的问题：创生之后无穷元相子的集合状态如何描述，集合层面的结构与个体层面有何不同。关键结论：因元相子 = 心物波粒二象，元相海 = 粒性海 ⊕ 波性海，是唯一公理在最大集合尺度上的直接展开；海持续演化（格点增长、相位演化、凝固扩张），但创生与校准的能动动作归于本原与天行力。

## 定义

元相海 = 元相子的最大集合，即公理 1 的无穷系综（"无穷"指生成的潜无穷，每一时刻数量肯定有限；不可数指标集的无穷张量积为其数学理想化，公理体系有明文）。数学上，宇宙态空间是冯·诺依曼无穷张量积

$$\mathcal{H}_{\text{total}} = \bigotimes_{k=1}^{\infty}\mathbb{C},$$

元相海是该无穷系综的集合基底。

波粒双侧互补：元相海 = 粒性海 ⊕ 波性海。

| | 粒性海 | 波性海 |
|---|---|---|
| 内容 | 元相子个体、格点阵、绕数 | 相位场、纠缠、相干（实轴方向场、先验纠缠） |
| 特征 | 定域、离散 | 非定域、连续 |
| 本体论 | 还原论侧 | 整体论侧 |

## 机制

行动者分工（2026-09-04 作者裁决）：创生归于本原（生生不息，注释 17），集合状态归于元相海，相位校准归于天行力。元相海不发起行动，但持续演化：格点增长、相位演化与凝固扩张都是海的内部过程。"元相海提供元相子"的表述废弃：海是创生之后集合状态的总和，创生与校准的能动动作归于本原与天行力。

潜无穷设定在海层面获得集合表述：元相海永在增长、永不完成；大一统（趋向相干）是元相海趋向整全的运动，潜无穷与大一统互为表里。

遗留两项：元相海的整体态 $|\Psi_{\text{total}}\rangle$ 与其局域化的数学描述待严格化；海的整体相干与先验纠缠（公设 5）的精确关系待裁决。

## 通俗类比

元相海如海洋，元相子如水滴。海是全部水滴的总和：潮汐与洋流是海自身的状态变化（演化），哪片云降下雨来（创生）不由海决定。类比说明：集合的状态演化与个体的诞生分属不同层面，两者都真实存在。局限：海洋的洋流有外力（风、月亮）驱动，元相海的演化动力全部来自本原的创生与天行力的校准，海内没有外来的驱动者。

## 与其他概念的关系

- **元相子**：海的元素，心物波粒二象的承载者；海继承个体的双侧结构
- **小傅 / 大傅**：小傅 = 单个元相子（本体层个体），大傅 = 宇宙整体（涌现层整体），元相海居中 = 本体层最大集合
- **先验纠缠**：波性海承载纠缠与相干；海的整体相干 = 先验纠缠（精确关系待裁决）
- **绕数**：粒性海承载格点阵与绕数，电荷守卫在波性侧（超选择）
- **时空晶格**：粒性海的格点阵构成物理时空，海持续凝固扩张
- **量子比特海（文小刚）**：量子比特海 = 信息本体（波性单侧）；元相海 = 实体本体（波粒双侧），实体本体论比信息本体论完整（纲领性）
