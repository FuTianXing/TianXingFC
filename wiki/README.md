# 名词解释（wiki）

- **日期**：2026-09-06
- **定位**：体系重要名词的通俗解释集合，采用 wiki 风格词条（定义首段 + 分类小节 + 参见与参考资料）。每个词条先给出可独立阅读的定义，再用类比讲清机制，末尾可溯源到定案文档。服务于快速理解与科普写作，严谨形式见对应论文/注记
- **目录规范**：`wiki/` 下每个名词一个文件（命名取名词本身）；新词条按下方通用模板

## 通用词条模板

每个词条包含以下结构（按需增减小节，顺序不变）：

```markdown
# <名词>

**<名词>**是<一句话定义>。（加粗术语开头，定义必须独立可读：不依赖本词条之外的概念解释）

| 元数据 | |
|---|---|
| 分类 | <类别：物理概念 / 几何结构 / 机制 / 术语 / 定案> |
| 定案状态 | <状态：已确认 / 数值确认 / 已定案 / 方案定案 / 纲领性> |
| 首次出现 | <最早引入该词的文档> |
| 相关词条 | <相关词条的 wikilink 列表，多个用顿号分隔> |

## 概述

两到三段：该词在体系中的地位、要解决的问题、关键结论。概述应能独立阅读。

## 定义

正式定义。涉及公式时用 LaTeX 行内 $...$ 或独立 $$...$$。给出数学形式与符号约定。

## 机制

机制如何运转：分步骤或分要点，可与数值验证、定案文档对应。

## 通俗类比

一个类比帮助建立直觉。类比说明什么、局限在哪，各写一句。

## 例子

两到四个具体例子，用表格或列表。每个例子给出"成立 / 不成立"与原因。

## 与其他概念的关系

与相关概念的异同与衔接。每个关系一行：<概念>：<关系描述>。

## 参见

相关词条链接列表。已建立的词条用 wikilink，未建立的用纯文本（待建）。

## 参考资料

严谨出处：论文、注记、验证脚本、开放问题登记。格式：<文档名>（<位置>，<日期>）
```

## 写作要求

1. 遵守写作铁律（禁 em-dash、禁"否定词开头、肯定词转折"的对比句式、公式 LaTeX、禁 Unicode 数学符号）
2. 定义首句独立可读，类比放在机制之后
3. 每个词条在"参考资料"标注定案对应，保证通俗解释可溯源
4. 元数据表的"定案状态"与"首次出现"保持可核实
