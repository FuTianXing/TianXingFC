# 时空晶格

**时空晶格**是元相子满周跃迁累积生成的普朗克长度立方体格点结构：三个基态光子（x/y/z 三类元相子）两两正交、同类平行，格点坐标 $x^a = l_P n^a$（距离归粒）。离散晶格是客观结构，源于单位圆相位旋转的必然几何特性，与计算便利无关。

|---|---|
| 分类 | 几何结构 |
| 定案状态 | 已确认（距离归粒定案） |

| 相关词条 | 法线跃迁、元相子、螺旋阶梯几何、相位、[[FK链]] |

## 概述

时空晶格是物理时空的粒性侧结构：每次满周闭合（法线跃迁）生成一个 $l_P$ 空间像素，跃迁累积成格点阵。晶格的 x/y/z 三个方向由三类正交元相子承载（同类平行、异类耦合 $\kappa_\varphi$ 锁定）。连续性是平滑化的涌现，宏观时空是离散晶格的统计连续极限。

晶格的客观性论证：格距 $l_P$ 由 $\hbar$、$c$、$G$（定理二）确定，格点坐标由满周计数直接给出，不依赖任何"为了计算方便"的截断选择。紫外正则（动量截断 $\pi/l_P$）是晶格结构的自然属性。

## 定义

格点坐标 $x^a = l_P n^a$（$n^a \in \mathbb{Z}$，a = x/y/z）。元相子每满周闭合沿法线平移一格。波矢由实轴方向差定义（$k_a l_P \propto \alpha_{n+\hat a} - \alpha_n$，方向归波），与距离归粒正交统一。空间维度数 = 公理 2 的三类正交方向（维度定理 P10 为待证命题）。

## 机制

1. 满周闭合触发法线跃迁（生成像素）
2. 三类正交元相子给出三个空间方向
3. 同类平行 + 异类锁定（$\kappa_\varphi$）构成格点结构
4. 距离归粒（$x^a = l_P n^a$）、方向归波（实轴方向差 = 波矢）

## 通俗类比

晶格 = 乐高积木墙。每一块积木是 $l_P$ 见方的像素（满周跃迁生成一块），积木只有三种朝向（x/y/z 三类元相子），拼成三维立方体格架。墙的"连续性"（看起来是光滑平面）只是积木太小的统计效果，本质是离散的。

## 与其他概念的关系

- **法线跃迁**：晶格像素的生成机制
- **距离归粒 / 方向归波**：晶格的两侧分工（粒性距离 / 波性方向）
- **膨胀**：晶格的生长（内部离散镶嵌 + 边缘连续补位）
