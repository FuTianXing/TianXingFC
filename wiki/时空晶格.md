# 时空晶格

**时空晶格**是元相子满周跃迁累积生成的普朗克长度立方体格点结构：三个基态光子（x/y/z 三类元相子）两两正交、同类平行，格点坐标 $x^a = l_P n^a$（距离归粒）。离散晶格是客观结构，源于单位圆相位旋转的必然几何特性，与计算便利无关。

## 概述

时空晶格是物理时空的粒性侧结构：每次满周闭合（法线跃迁）生成一个 $l_P$ 空间像素，跃迁累积成格点阵。晶格的 x/y/z 三个方向由三类正交元相子承载（同类平行、异类耦合 $\kappa_\varphi$ 锁定）。连续性是平滑化的涌现，宏观时空是离散晶格的统计连续极限。

晶格上有运动：元相子以束缚振荡的方式在格点区间内往返，一次摆程同时给出空间一格、时间一拍与光速 $c = l_P/t_P$。晶格属粒性侧，其存在以波性侧相干为根（波粒互根），两层机制均见"机制"节。

晶格的客观性论证：格距 $l_P$ 由 $\hbar$、$c$、$G$（定理二）确定，格点坐标由满周计数直接给出，不依赖任何"为了计算方便"的截断选择。紫外正则（动量截断 $\pi/l_P$）是晶格结构的自然属性。

## 定义

格点坐标 $x^a = l_P n^a$（$n^a \in \mathbb{Z}$，a = x/y/z）。元相子每满周闭合沿法线平移一格。摆程是相位单调扫过 $2\pi$ 的一次过程，圆心位移 $l_P$，历时 $t_P$；摆程数 $N$ 给出物理时间 $t = N t_P$。波矢由实轴方向差定义（$k_a l_P \propto \alpha_{n+\hat a} - \alpha_n$，方向归波），与距离归粒正交统一。空间维度数 = 公理 2 的三类正交方向（维度定理 P10 为待证命题）。

## 机制

**束缚振荡：晶格内的往返**。元相子定居格点，相位每摆程单调扫过 $2\pi$（$|\dot\theta| = \omega_P$），圆心在格点区间 $[n l_P, (n+1) l_P]$ 内从一侧边界单向位移到另一侧边界，位移 $l_P$。折返的原因是相邻格点元相子的存在：粒性个体不可穿透（波不能穿透粒，波粒互斥），前进 $l_P$ 到达邻居边界后折返。振荡是波粒互斥互补的动态平衡（波驱动加粒约束），是波粒互根最纯粹的力学实现。

四构件：定居（三元组格点）、摆程（相位扫过 $2\pi$，位移 $l_P$，历时 $t_P$）、折返（圆心不可重合的硬核碰撞，无墙、无外部设施）、计时（$t = N t_P$，$E = \hbar\omega_P$）。

**交错基态**。相邻格点的运动方向相反，奇偶格点交替地相向碰撞、背向分开，净绕数恒为零。真空由此表现为电中性；突破折返的单向缠绕即带电。

**一次摆程的三件产物**：空间 $x = l_P n$、时间 $t = N t_P$、光速 $c = l_P/t_P$。三者出自同一次折返，晶格由此同时生成空间、时间与光速。自由极限下的时间是反解的数学参数，束缚振荡后的时间才是可数出的物理量。

**碰撞接力：晶格间的传播**。元相子圆心按摆程节拍跃迁，撞上邻居的瞬间，邻居读出它的实轴指向并整桶移交，事件链以一步一摆程、一格一格的节律把传播读出为因果前沿（传播动力学住连续波动层，波纹向四面八方铺开，链式图像为一维插图）。搬走的是状态，格点之间的实轴指向差原样保留，这正是波矢的形状。

**格点结构的构成**。满周闭合触发法线跃迁生成像素；三类正交元相子给出三个空间方向；同类平行加异类锁定（$\kappa_\varphi$）构成格点；距离归粒、方向归波；格点结构的维持以波性侧相干为根（波粒互根，纲领级，前提待裁决）。

严格程度：束缚振荡为模型假设级。硬核碰撞的完美弹性已由结构性论证给出（无内部自由度、反转由符号翻转实现、折返为约束的瞬时解，见 [[内部草稿/注记-碰撞的完美弹性：无内部自由度与符号翻转实现的结构性论证]]）；翻转规则的严格形式（摆程方向因子的变号与「束缚势」旧措辞退役）仍待闭合（O10，见 [[内部草稿/开放问题总览：元相子理论待解决问题清单]] P1-21）。

## 通俗类比

晶格 = 乐高积木墙。每一块积木是 $l_P$ 见方的像素（满周跃迁生成一块），积木只有三种朝向（x/y/z 三类元相子），拼成三维立方体格架。墙的"连续性"（看起来是光滑平面）只是积木太小的统计效果，本质是离散的。

晶格中的元相子 = 一排摆钟。每座钟的指针连续旋转，转满一圈就嘀嗒一声，同时整座钟沿钟链平移一格；相邻两座钟的摆向相反，一个向前摆时另一个向后摆，在中间相遇后各自折返。嘀嗒一次即一个摆程，往返一回即一个普朗克时间。一座钟折返时，邻居读出它的读数并接着走一格，事件链把传播读出为因果前沿的速度固定为一格一摆程，这就是光速（钟链为一维插图）。

## 与其他概念的关系

- **法线跃迁**：晶格像素的生成机制
- **束缚振荡**：晶格内元相子的往返运动（定居、摆程、折返、计时），派生物理时间与能量标度；钟摆的嘀嗒即往返一次
- **碰撞接力**：事件侧把传播读出为因果前沿每拍一格（整桶移交，链式图像为一维插图），速度即光速 $c = l_P/t_P$
- **距离归粒 / 方向归波**：晶格的两侧分工（粒性距离 / 波性方向）
- **波性侧纠缠**：晶格存在的根。第四法则波粒互根给出"粒若脱离波，则失去动力与演化"；同步相变中波性海冻结出粒性海，母液并未消失。该依赖关系为纲领级，前提"海的整体相干与先验纠缠的精确关系"待裁决（[[wiki/元相海]] 注释 24 遗留 b）
- **膨胀**：晶格的生长（内部离散镶嵌 + 边缘连续补位）
