# 时空晶格

**时空晶格**是元相子满周跃迁累积生成的普朗克长度立方体格点结构：三类元相子（基态光子）两两正交、同类平行，格点坐标 $x^a = l_P n^a$（距离归粒）。它是物理时空的粒性侧，也是时空本身，不充当背景舞台。

## 概述

晶格由生成动作累加而成：每个元相子转满一圈，圆心沿法线跳一个 $l_P$，落下就是一个格点。三个空间方向由三类正交元相子承载，同类平行、异类经 $\kappa_\varphi$ 锁定。宏观时空的连续性是统计平滑的结果，晶格本身离散。

晶格上有运动：元相子被束缚在格点区间内往返，一次摆程同时给出空间一格、时间一拍与光速 $c = l_P/t_P$。这三样出自同一次折返，不是三套独立设定。

最硬的一条纪律是晶格刚性：格距 $l_P$ 与摆程 $t_P$ 绝对不变，改变的只能是格数与拍数。引力弯曲、尺缩、保角因子与膨胀因此全部住在波性侧记录与响应上，「像素被压弯」「格点被拉伸」这类字面读法在体系内退役。

晶格属粒性侧，其存在以波性侧相干为根（波粒互根）。这条依赖是纲领级的，前提「海的整体相干与先验纠缠的精确关系」待裁决。

## 定义

格点坐标：

$$x^a = l_P\,n^a, \qquad n^a \in \mathbb{Z},\quad a = x,y,z$$

元相子每满周闭合沿法线平移一格。摆程是相位单调扫过 $2\pi$ 的一次过程，圆心位移 $l_P$，历时 $t_P$；摆程数给出物理时间 $t = N t_P$。

距离与方向分居两侧：距离由格点阵承载（距离归粒），方向由实轴指向差承载（方向归波），波矢满足 $k_a l_P \propto \alpha_{n+\hat a} - \alpha_n$。两侧正交统一，早期纯纠缠网络方案中的相位差度规已降级为涌现层的有效描述。

空间维度数等于公设 2 的三类正交方向。为什么正好三类，与空间为什么正好三维是同一个问题，严格证明（维度定理 P10）仍是待证命题。

物侧状态空间另有两条通道：相位通道取值于单位圆，连续旋转；层数通道承载满周计数 $n$，取整数。两通道正交（度规可分离 $ds^2 = d\phi^2 + dz^2$），读写分工随之确定：确定的位置标签归层数通道，位置的份额（概率幅）归相位通道。

## 机制

**满周跃迁造出像素。** 元相子每完成一次满周闭合，圆心沿复平面法线阶跃一个 $l_P$。跃迁路径由对称性唯一锁定，构成法线锚定三定理链：圆心是旋转中唯一的不动点，故转轴唯一；平移方向与转轴重合；法线管空间几何，满周标记管时间触发。

**束缚振荡：折返造出等长的拍。** 元相子定居格点，相位每摆程单调扫过 $2\pi$（$|\dot\theta| = \omega_P$），圆心在区间 $[n l_P, (n+1)l_P]$ 内从一侧边界移到另一侧，位移一个 $l_P$。到边界必须折返，因为圆心不可重合：一个圆心旁边不能站另一个圆心，这是唯一的粒性约束，也正是「粒」的全部内容。没有墙，没有外部设施，折返是约束的瞬时解。

四构件：定居（三元组格点）、摆程（相位扫过 $2\pi$，位移 $l_P$，历时 $t_P$）、折返（圆心不可重合的硬碰撞）、计时（$t = N t_P$）。折返是完美弹性的，恢复系数恒为 1，由相位转速恒定、刚性锁定与圆心不可重合三条输入直接导出（判据 V1 至 V5，公理级，条件于刚性锁定 A2），这条派生链里没有耗散自由参数。

**交错基态。** 相邻格点的运动方向相反，奇偶格点交替相向碰撞、背向分开，净绕数恒为零。真空由此表现为电中性；突破折返的单向缠绕即带电。

**一次摆程的三件产物。** 空间 $x = l_P n$、时间 $t = N t_P$、光速 $c = l_P/t_P$。自由极限下的时间是反解出来的数学参数，束缚振荡之后的时间才是可数出的物理量。折返把自由直飞切成等长往返，也让时间单调递增。

**碰撞接力与传播。** 圆心按摆程节拍跃迁，撞上邻居的瞬间，邻居读出它的实轴指向并把整份状态接过去，事件链以一步一摆程、一格的节律把传播读出为因果前沿。搬走的是状态，格点之间的实轴指向差原样保留，这正是波矢的形状。

传播动力学住在连续层，由最近邻弹簧耦合的哈密顿线性化给出：

$$\omega^2(\mathbf{k}) = \frac{4}{t_P^2}\sum_a \sin^2\left(\frac{k_a l_P}{2}\right)$$

长波极限精确给 $\omega = c|\mathbf{k}|$，$c = l_P/t_P$ 不需要介质弹性参数；群速处处不超过 $c$，等号只在 $k\to0$ 取得。波长缩到格距附近，正弦开始弯：布里渊角点处能带顶 $\omega_{\max} = 2\sqrt3/t_P$。

这里有一条层属纪律：连续色散是动力学本身，逐摆程递推只作采样序列的对照读法。把离散递推当成动力学，斜向高动量模式会无实数频率解，长波端还会超光速（判据第 441 条），这是体系最容易自毁的地方。

**格距绝对不变。** 晶格刚性原理：格距与摆程是绝对常数，处处恒定。理由分两层：刚性格点没有形变自由度，格距改变没有实现通道（本体侧）；任何需要背景格距改变才能成立的机制一律不成立（判据侧，一票否决）。

由此，四类「变形」全部移到波性侧：引力是法线场静倾角记录，尺缩是运动束缚态内部结构尺度的变化（格数随观测者变、格距不变），保角因子是涌现层度规的刻度修正，膨胀是格点数量增长。满偏之后的格点退出同样只动标记：邻居坐标差由 2 变 1、全链格距不变、边界自动靠拢。

**绝对尺度与相对位置。** 定理 11：空间有绝对尺度，源于半径 $\hbar$ 的绝对性；空间只有相对位置有意义，源于相位本质上是相对量。格点集体重新编号，物理不变，所以没有「第几格」这种绝对位置。尺子是真的且绝对，原点并不存在。

**长大靠加格点。** 元相子数量潜无穷增长，新格点在碰撞点落位。相邻元相子 A、B 反相，圆心在公共边界重合；碰撞瞬间新元相子 C 在碰撞点诞生，复刻即将折返者的节律与相位，从实轴起旋，一圈恰好跃一个 $l_P$。因为复刻了节律，邻居感知不到它的出现。

落位伴随格点归属重排：原配置 A$[0,l_P]$、B$[l_P,2l_P]$，插入后重排为 A$[0,l_P]$、C$[l_P,2l_P]$、B$[2l_P,3l_P]$，相邻反相、隔一同相，格距全程保持 $l_P$。让位链是纯标记的重标操作，瞬时全局完成，不需要任何物理传播（依据定理 11、圆心不可重合与元相海整体相干）。

落位有两个窗口。边缘是缺邻居即补位，每摆程每边缘格点一次，推进速度 $c$。内部是稀疏落位，单次碰撞落位概率 $p = 3H_0t_P \approx 3.7\times10^{-61}$（取 $H_0 \approx 70$ km s$^{-1}$ Mpc$^{-1}$），每个格点平均约 47 亿年一次。由此得 $H = p/(3t_P)$：$p$ 恒定则 $H$ 恒定，宇宙进入德西特型指数膨胀；总格点增长率 $3H_0 + 3c/R$ 给出 $\dot R = RH_0 + c$，边缘半径指数超光速扩张。创生边界与信号边界不同，$v > c$ 的空间生成不违反因果。

**弯曲不进格点。** 有质量粒子不改摆程、不变速、不动格点，只在每次全局普朗克碰撞事件向法线场写入一个标架倾角 $\delta\theta = m/m_P$。注入加邻居抄写的稳态给出 $\theta(r) = Gm/(c^2r)$，$G$ 只经 $m_P$ 单一入口进来，记录场不含普朗克尺度。$G$ 在这里的身份是生成标度：$G$ 越大，生成出来的格距越大，同一质量的写入份额越大。

## 辨析：晶格与以太的分界

有格子就有一个格子静止系，这曾是全体系最高级别的风险。分三步说清。

**其一，背景存在。** 这个静止系是真的，由全体元相子的共同朝向定义，不靠计算方便来假设。

**其二，判据缺席。** 要判定自己相对格子怎么动，至少得抓住两个锚点之一：格子上的标记，或一个不随运动改变的公共钟。两样都拿不到。格点集体重编号，物理不变；全体节拍同步，这份共同节拍在任意读数里都抵消，两点之间只剩相位差。

**其三，为什么结构上碰不到。** 最近邻弹簧项的空间差分算符只作用于格点指标，对内部分量是恒等算符，二次型在传播扇区与内部规范扇区严格块对角。弹簧的软硬进不了速度公式，运动的钟与尺又同步变化，读数互相抵消（第 691 号晶格原生读数：$v = 0.30$ 偏差 $5.6\times10^{-4}$，模型档 $\xi$ 约 $10\,l_P$）。

结果是：低能处洛伦兹不变性精确成立，高能处留下可算的指纹，$\delta\omega/\omega = -\frac{l_P^2}{24}\sum_a k_a^4/k^2$，标度 $(E/E_P^{(t)})^2$，方向比 $6:3:2$。高能偏离是采样层留下的痕迹，低能精确是连续基本层托底的结果，两者并不矛盾。完整论证见 [[洛伦兹不变性]] 与《晶格何以不破坏洛伦兹不变性》。

与声子晶格的本体论区别也在这里：声子晶格从纯离散拼出连续，凑近总能看见缝；元相子的连续是本来就有的基本层，晶格只是它被读出来的方式（波主粒从）。

## 通俗类比

晶格 = 乐高积木墙。每块积木是 $l_P$ 见方的像素（满周跃迁生成一块），只有三种朝向（x/y/z 三类元相子），拼成三维格架。墙的「连续」是积木太小的统计效果，本质离散；积木的边长焊死，想变长只能往上接新块。

晶格中的元相子 = 一排摆钟。指针连续旋转，转满一圈就嘀嗒一声，同时整座钟沿钟链平移一格；相邻两座摆向相反，一个向前摆时另一个向后摆，在中间相遇后各自折返。嘀嗒一次即一个摆程，用时一个普朗克时间；往返一回是两拍。一座钟折返时，邻居读出它的读数并接着走一格，因果前沿的速度由此固定为一格一摆程。

局限在于：真实积木的尺寸有公差，真实摆钟的周期随温度变，而 $l_P$ 与 $t_P$ 被公理钉死；另外积木墙有墙根，晶格没有原点。

## 与其他概念的关系

**与 [[法线跃迁]]**：晶格像素的生成机制，一格对应一次满周跃迁。

**与 [[元相子]]**：晶格是元相子的排列，元相子是晶格的砖。三类正交元相子给出三个方向。

**与 [[普朗克长度]]**：$l_P$ 是格距，两者是同一个量的单体与集体两面。

**与 [[普朗克时间]]**：$t_P$ 是摆程，$c = l_P/t_P$ 是两者的比值。刚性对两者同时成立。

**与 [[洛伦兹不变性]]**：晶格给出优选系，不给出可读的绝对运动。低能精确、高能指纹，完整论证见该条。

**与膨胀**：格点数量增长，格距不动。边缘补位与内部落位两个窗口，$H = p/(3t_P)$。

**与纠缠**：晶格存在的根。第四法则波粒互根给出「粒若脱离波，则失去动力与演化」；同步相变中波性海冻结出粒性海，母液并未消失（[[wiki/元相海]] 注释 24 遗留 b）。

**与格点退出**：满偏后的标记操作，邻居坐标差由 2 变 1、全链格距不变，是刚性原理的又一实例。
