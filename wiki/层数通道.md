# 层数通道

**层数通道**是元相子物侧两个通道之一，承载满周闭合事件的累计计数，取值于整数集 $\mathbb{Z}$，态空间因子为 $\ell^2(\mathbb{Z})$。

## 概述

元相子的物侧态空间是 $\mathcal{H}_k = L^2(S^1) \otimes \ell^2(\mathbb{Z})$，两个张量因子即[[相位通道]]与层数通道，公理体系定下没有第三个。

本词条讲通道本身的性质：它是什么类型的空间、为什么与相位通道不冗余、它承载哪些读数、按几何与本体论各属什么归属。层数这个**读数**本身的定义、基准与类比见 [[层数]]，两者分工不同，不重复展开。

按空间归属读，层数通道与相位通道构成一对正交方向：层数通道是螺旋体的**纵向法线轴**，属**外部空间**，其基本读数**定域**；相位通道是横截面，属**内部空间**，其读数**非定域**。

层数通道因此就是物理空间的**生成方向**与**三维空间的骨架**：元相子每完成一次满周闭合，沿法线阶跃一个 $l_P$，空间逐格生成，格点坐标 $x^a = l_P n^a$ 即本通道读数。三维空间由公设 2 的三类正交方向元相子（x/y/z）的法线跃迁共同生成，本通道承载这三类方向的格点计数（维度定理 P10 待证）。

## 定义

层数通道取值于整数集 $\mathbb{Z}$，其基矢 $|n\rangle_k$ 取法线轴上相对局域基准（邻居链与均匀缠绕背景）的层数量子数，真空锚定 $n = 0$，由沿法线轴的键差分定义。

层数通道的指标是**历史计数**，即 $\theta \bmod 2\pi$ 无法恢复的量。配置空间冠「投影」之名正由此来：$(\theta, n)$ 是对跃迁历史的投影，读数只保留累计结果。

两个通道的指标类型不同，这是它们非冗余的根据之一：相位通道的傅里叶指标是瞬时谱指标（与相位共轭），层数通道的指标是历史计数。

**「历史计数」与「空间维」不互斥。** 两者说的是不同的事：「历史计数」是读数类型，与相位通道的瞬时谱指标相对，说明本通道的读数由逐次跃迁累积、$\theta \bmod 2\pi$ 不可恢复；「空间维」是几何归属，说明本通道落在纵向法线轴上、属外部空间。空间逐格生成，位置由跃迁次数累积，故空间坐标天然带历史性，两者互为表里。**本通道不是额外维度候选**：体系的三维由公设 2 的三类正交方向给出，不引入额外维度。

## 机制

1. 相位指针连续旋转（波性侧），满周闭合被圆周标记点检测，触发一次法线跃迁，本通道读数加一。
2. 跃迁累积生成时空晶格，本通道给出距离的计数（$x^a = l_P n^a$，距离归粒）。
3. 沿闭合回路取净差得[[绕数]]，绕数即电荷。
4. 法线高度差藏无可藏（非紧致），故本通道兼有粒子可见性根源的职能。

**正交性归属（2026-09-30 作者裁决）**：层数通道 = 纵向 = 外部空间 = 法线轴 = 定域传播；相位通道 = 横向 = 内部空间 = 螺旋体横截面 = 非定域传播。两者正交。正交性由三处独立保证：螺旋三定理链把相位方向与法线方向严格分开，状态空间度规可分离（$ds^2 = d\phi^2 + dz^2$），两层级是延展体 $D^2 \times \mathbb{R}$ 与其边界子集 $S^1 \times \mathbb{R}$ 的关系。

**非冗余性（判据 J6）**。按 [[内部草稿/审查报告-元相子的物侧态空间：六种用法清点、冲突诊断与应然判据]]，两因子不得互为共轭变量，也不得是同一自由度的两种写法。三个支撑：两通道的指标对象不同（瞬时谱对历史计数），元相方程给出状态空间度规可分离，螺旋三定理链把两方向严格分开。早前「一维因子无纠缠结构」的理由已退役，纠缠承载改述为双路分工。

**可观测性结构**。单个元相子的绝对层数与绝对相位一样不可观测，可观测的只有相邻差分与沿闭合回路的累计，两通道共同遵守「可观测的只有差」。

**一处须分辨的限定**。本通道的基本读数定域，但其中的绕数读数沿闭合回路是非定域的。绕数的对象是相位，它是分支拓扑量、整数、依赖整条回路而非单点；层数是绕数的读数，满周闭合对应一层（判据第 740 号定案，2026-10-21）。准确表述为「层数通道定域于外部空间，其中绕数读数非定域」。

## 通俗类比

**旋转楼梯的楼层计数**。人在楼梯上走，楼层的读数是整数的、累加的、可以数出「第几层」；它给出的是位置，是纵向的、可数的。类比说明整数性、累加性与纵向读数的性质；局限在于楼梯是现成的，而体系里楼梯本身由满周跃迁生成，且类比说不出绕数那种「走完一圈才有的整数」。

## 例子

| 性质 | 读数或表现 | 成立与否 |
|---|---|---|
| 整数性 | 满周闭合后读数加一 | 成立（满周事件计数） |
| 历史变量性 | 读数只保留累计，不含跃迁细节 | 成立（配置空间冠「投影」之名） |
| 定域 | 坐标标签 $x^a = l_P n^a$ 完全局域 | 成立（属外部空间） |
| 非定域 | 绕数沿闭合回路取分支拓扑量 | 成立（须分辨的例外，依赖整条回路；对象是相位，层数为其读数） |
| 单点绝对值 | 相对局域基准给出 | 不成立（绝对层数不可观测） |
| 位置份额 | 读作本通道 | 不成立（属相位通道） |

## 与其他概念的关系

与 [[相位通道]] 的关系：本词条的正交伙伴，纵向对横向、外部对内部、定域对非定域。

与 [[理论总纲/螺旋阶梯几何]] 的关系：本通道对应其纵向法线轴，[[理论总纲/螺旋阶梯几何]] §3.1 的两层级严格区分即两通道的几何对应；该文 §3.1 的层级划分另见根目录论文 [[论元相子的螺旋阶梯几何：法线的离散跃迁与时空二象性的数学根基]] §4.1 与 §4.2（波性状态空间与物侧延展体），两处章节号分属不同文件，不可混引。

与 [[层数]] 的关系：[[层数]]讲本通道上的读数（距离、基准、类比），本词条讲通道性质（空间类型、非冗余、归属），分工不重复。

与 [[绕数]] 的关系：绕数是本通道沿闭合回路的净差，是通道内唯一非定域的读数。

与 [[位置]] 的关系：确定的位置（坐标标签、锚核位置）归本通道，位置份额（概率幅）归相位通道。

与 [[位错]]、[[构型]] 的关系：位错是层数分布中的局部异常，构型是位错的层数偏离。
