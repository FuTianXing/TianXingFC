# 扇区

**扇区**是态空间被守恒量切成的互不相通的子空间：每个扇区装着一个电荷值（绕数）的全部状态，任何局域操作都不能把状态从一个扇区搬到另一个扇区。

## 概述

量子力学的态空间（所有可能状态的集合）按守恒量分解是普遍结构：守恒量把态分成若干类，每类内部状态可以互相演化，类与类之间没有演化通道。这个"类"就是扇区。

在绕数承载层方案中，守恒量是绕数（电荷）。基态空间按绕数算符的本征值分解为扇区：电荷 = 0 的扇区、电荷 = 1 的扇区、电荷 = 2 的扇区。扇区结构的两个关键事实由 Z_N toric code 全系数值确认：扇区内绕数可对角化（基态空间投影量子数），扇区之间矩阵元为零（跨扇区无通道）。扇区总数由环面拓扑给出（基态简并 = $N^2$）。

扇区结构解释了三件事：电荷为什么不叠加（超选择规则的结构来源）、叠加的合法边界（同扇区内可相干，跨扇区禁戒）、电荷守恒的绝对性（通道不存在，守卫无需站岗）。

## 定义

设态空间 $\mathcal{H}$ 上存在守恒算符 $\hat{W}$（绕数算符），其本征值 $W \in \mathbb{Z}$（或 $Z_N$）。扇区定义为本征子空间

$$\mathcal{H}_W = \{|\psi\rangle : \hat{W}|\psi\rangle = W|\psi\rangle\},$$

态空间分解为

$$\mathcal{H} = \bigoplus_W \mathcal{H}_W.$$

扇区结构的严格性由两点保证：其一，$\hat{W}$ 在基态空间内可对角化（基态空间投影量子数）；其二，跨扇区矩阵元为零，任意局域算符 $\hat{O}$ 满足

$$\langle\psi_a|\hat{O}|\psi_b\rangle = 0, \qquad |\psi_a\rangle \in \mathcal{H}_{W_a},\ |\psi_b\rangle \in \mathcal{H}_{W_b},\ W_a \ne W_b.$$

Z_N toric code 数值（L = 2 与 L = 3，N = 2/3/4）：基态简并 = $N^2$（环面拓扑）、跨扇区一阶矩阵元 $10^{-16}$ 量级、基态通量全零。

## 机制

扇区结构的形成分三层：

1. **分解**：绕数算符 $\hat{W}$ 把态空间分成本征子空间，每个本征值对应一个扇区
2. **保护**：局域算符与跨扇区跃迁的矩阵元为零，源于非局域拓扑结构（环面环绕、纠缠组织），与势垒高度无关
3. **计数**：扇区数由环面亏格给出（$N^{2g}$，g = 1 时即 $N^2$），是拓扑的必然

保护机制的量级判断：位形侧（局域势垒、离散化、标记冻结）全部被裁决实验否定，波性侧（纠缠拓扑、基态空间投影量子数）获得全系确认。

## 通俗类比

把态空间想成一栋没有楼梯也没有电梯的楼房。每一层是一个扇区：第 0 层装电荷 = 0 的状态，第 1 层装电荷 = 1 的状态。任何局域操作（翻转、碰撞、扰动）都只能在本楼层活动，搬不到别的楼层。楼层总数由建筑的拓扑结构决定：Z_2 制 4 层、Z_3 制 9 层、Z_4 制 16 层。

类比的局限：楼层之间真的没有通道（矩阵元为零），类似"守得严"（高势垒可以翻越）的说法在这里不成立。这是扇区与普通能级间隔的本质区别。

## 与其他概念的关系

- **绕数**：扇区的划分依据（电荷 = 绕数定案），绕数算符是扇区标签
- **超选择**：扇区结构即超选择规则的机制内容，电荷超选择从经验规则变为结构推论
- **基态空间投影量子数**：扇区保护机制的严格形态（基态空间内绕数可对角化）
- **均匀缠绕背景**：W = 1 扇区的极小态（复合粒子的背景），与扇区结构同属一层
- **复合粒子**：粒子落在某个扇区（电荷固定）内，其位置叠加在该扇区内自由进行
