# 洛伦兹符号

**洛伦兹符号**（Lorentzian signature）是时空度规的号差约定：时间方向与空间方向在度规与作用量中取相反符号（号差 $(+,-,-,-)$），与之相对的是全正号的欧氏符号。号差决定波动方程为双曲型（有传播）还是抛物型（只有扩散），因此洛伦兹符号是"存在光传播"的代数前提。

## 概述

时空度规的号差有两种典型选择：洛伦兹符号（时间一个号、空间三个相反的号）与欧氏符号（四个同号）。号差不是排版细节，它决定二阶方程的类型：洛伦兹符号下波动方程是双曲型，允许振荡与传播；欧氏符号下同一方程是抛物型，只有衰减与摊平。物理学的历史把洛伦兹符号当实验事实接受（狭义相对论的度规），为什么宇宙选了这个号差而没有选欧氏号差，长期没有解释。

天行新学体系给出了一个来源化答案（洛伦兹符号定理，2026-09-26，见 [[规范作用量的审计必然性：从净值审计到电磁场作用量的推导与数值验证]] §3.5）：只要一个系统同时具备方向惯性（动能）与校准代价（势能），其作用量按"动能减势能"写出，洛伦兹符号就是必然结果；去掉任何一半，方程退化为扩散，光消失。该定理在格点上经四判据与规范侧三档对照双重数值核验。

## 定义

洛伦兹符号指度规的号差 $\eta_{\mu\nu} = \mathrm{diag}(+,-,-,-)$，其直接后果是作用量中时间导数项与空间导数项反号。电磁场的标准作用量为

$$S = -\frac{1}{4}\int F_{\mu\nu}F^{\mu\nu}\,d^4x = \frac{1}{2}\int\left(E^2 - B^2\right)d^4x$$

其中 $F_{\mu\nu}F^{\mu\nu} = 2(B^2 - E^2)$：电场 $E = -\partial_t A - \nabla\varphi$ 由时间导数构成（动能性，正号），磁场 $B = \nabla\times A$ 由空间旋度构成（势能性，负号）。对照欧氏符号下同一构造为全正的 $\sum F_{ab}^2 + \sum F_{0i}^2$ 型，变分给出扩散方程而非波动方程。

## 机制

体系内的来源由洛伦兹符号定理给出。物质侧链（耦合块）的含惯性项作用量为

$$L = \frac{I}{2}\sum_n \dot\alpha_n^2 - \frac{I}{t_P^2}\sum_n\left[1-\cos(\Delta\alpha_n)\right], \qquad \Delta\alpha_n = \alpha_{n+1}-\alpha_n,$$

其中 $I$ 为方向惯性系数（公理层资源，即感知-校正链方程的 $\ddot\alpha$ 项），势能系数中的 $1/t_P^2$ 为摆程节律的换算。变分精确重现感知-校正链方程与离散色散 $\omega(k) = \frac{2}{t_P}|\sin(k l_P/2)|$，长波光速 $c^2 = l_P^2/t_P^2$ 无自由参数。

规范侧（基准方向场）的对应作用量取曲率余弦

$$L = \frac{I_0}{2}\sum_n\sum_i\dot\varphi_i^2 - \frac{I_0}{t_P^2}\sum_p\left[1-\cos(F_p l_P^2)\right], \qquad \varphi_i = A_i l_P,$$

其中 $F_p$ 为联络绕一个面元的净变化，惯性系数两侧同源 $I_0 = I$（2026-09-26 作者裁决）。低幅展开给

$$L_2 = \frac{I_0}{2}\left(\frac{1}{\Delta t^2} - \frac{1}{2t_P^2}\right)E^2 l_P^2 - \frac{I_0}{4t_P^2}B^2 l_P^4 + \cdots$$

在时间步取摆程历时的档位 $\Delta t = t_P$，电型系数为正、磁型系数为负，等幅反号，洛伦兹符号成立。归属：$E^2$ 承载取向惯性能与曲率余弦时间型平面的双重计费（电型双归属），$B^2$ 承载空间型曲率平面的单次计费，洛伦兹符号是这一不对称计费的净效果。

物理必要性：去掉惯性项的纯代价泛函梯度下降给出扩散（场扭曲被瞬时摊平，无光）；惯性项给波动以记忆，代价项给波动以回正，两者缺一不可。规范侧的选通行为由第 434 条给出：随单拍时间参数 $\Delta t/t_P$ 变化，$\Delta t = t_P$ 时等幅反号（洛伦兹成立），$\Delta t = \sqrt{2}\,t_P$ 时电型项临界相消，$\Delta t = 2t_P$ 时符号翻转（三档比值 $+7$、$+1$、$-0.5$），洛伦兹符号由此成为可调结构下的选通结果而非假定。

## 通俗类比

荡秋千：秋千来回摆，因为它遵循"动能减势能"的符号结构；假如两项同号相加，秋千只会单向滑落或指数离位，永远荡不回来。洛伦兹符号就是那个减号：它是"来回"与"滑落"的分水岭。局限：秋千是一维往复，电磁波是场的横向振荡，类比只覆盖"号差决定能否振荡"这一层。

## 例子

| 情形 | 是否洛伦兹符号 | 原因 |
|---|---|---|
| 连续麦克斯韦作用量 $\frac{1}{2}(E^2 - B^2)$ | 是 | $E^2$ 正、$B^2$ 负，双曲型 |
| 纯格点代价 $\sum[1-\cos(F l_P^2)]$ 单独变分 | 否（欧氏型） | 全正，变分给扩散，无光 |
| 含方向惯性项的格点作用量（洛伦兹符号定理） | 是 | 惯性动能正号 + 节律势能负号 |
| 第 434 条 $\Delta t/t_P = \sqrt{2}$ 配置 | 否（临界相消） | $a_E = 0$，电型项消失 |
| 第 434 条 $\Delta t/t_P = 2t_P$ 配置 | 否（符号翻转） | 比值为 $-0.5$，电型与磁型同号 |

## 与其他概念的关系

- **[[实轴方向场]] 与 [[基准方向场]]**：洛伦兹符号定理的作用量横跨两侧，物质侧链挂在实轴方向的时间演化上（$\alpha$ 场），规范侧挂在基准方向配置的曲率上（联络绕面元的净变化，载体见 [[基准方向场]]），惯性系数两侧同源 $I_0 = I$（2026-09-26 作者裁决）。
- **光的存在性**：洛伦兹符号是双曲型的代数前提，因而也是光传播的前提；体系内"为什么有洛伦兹符号"与"为什么有光"是同一个问题。
- **惯性**：洛伦兹符号定理把洛伦兹符号的来源归到方向惯性（动能半边）；惯性自身的微观来源已由变率继承提案承接（2026-09-27 作者裁决采纳；[[内部草稿/注记-惯性的微观来源：变率继承与二阶动力学的结构必然性|惯性的微观来源注记]]，二阶唯一性：完美弹性禁耗散、Ostrogradsky 禁高阶，二阶是唯一稳定形式）。
- **[[绕数]] 与 [[电荷]]**：$\theta$ 型拓扑项（$F\tilde{F}$）不进入代价泛函，其拓扑归属归磁单极扇区（电荷住物质侧、磁型住规范侧的两侧分置裁决）。
