# 复合位错粒子

**复合位错粒子**是体系现行的粒子图像：粒子由锚核、电荷核与包层三层复合而成，运动由转换波执行。

## 概述

三层分工是本词条的核心：质量归[[锚核]]（格点内锁定，绑定能即质量，已定案；锚核给的是质量的数值，这份能量的分布摊在整片缺陷上、主体在包层，核区一格在电子档约占 $2.1\times10^{-23}$，见判据第 627 号）；电荷归**电荷核**（关系自由度加绕数超选择守卫）；宽度与色散归**包层**（法线轴弹性）。运动由转换波执行：前端格点锁定、后端格点释放，锁定区边界像波一样前进。

2026-09-20 形态收束（见 [[复合位错粒子的形态收束：宽度的波性侧承载、边界保护与锚核驻留判据]]）：宽度精确化为波性侧软模的关联长度 $\xi = 1/(2\pi\sqrt{K})$（解析桥因子 $l^{*}/\xi = \pi/\sqrt{3}$，落窗 $K \le 1/48$ 与色散窗 $K \le 1/(16\pi^2)$ 联立）；保护以边界冻结实现（标签精确守恒），位置归锚核且可驻留距离有上界（$l_{\max} = A/\sigma$）（2026-09-29 更新：位置的载体现为内部壁承载绕数，锚核改注质量侧）。

由此得到一句常被引用的话：材料元相子待在原地，粒子是**材料上的图案**，其身份由绕数与位错构型作为整体携带。使用该词条时须注意与历史方案的分界：旧表述（粒子等于 σ 锁定孤子、单向缠绕）不得再用于现行粒子。

## 定义

粒子 = 锚核（提供质量）× 电荷核（提供电荷与绕数守卫）× 包层（提供宽度与色散）三层复合；局域性自由度由内部畴壁承载绕数给出（第 54 条），运动自由度由转换波的边界传播给出。

## 机制

第一步，定位与供质量：位置由内部壁承载绕数给出（2026-09-29 更新），质量由锚核的格点内锁定给出绑定能，绑定能即质量。锚核给的是质量的数值；这份能量的分布摊在整片缺陷上、主体在包层，核区一格在电子档约占 $2.1\times10^{-23}$（判据第 627 号）。

第二步，电荷核赋荷：关系自由度加绕数超选择守卫给出电荷。

第三步，包层定形：法线轴弹性与格点锁定的比值定出软模关联长度，宽度读数即该长度（2026-09-20 收束）。

第四步，转换波推进：边界处前端锁、后端放，整体表现为匀速位移。

## 通俗类比

地毯上的一道褶子被推着走：褶子在移动，地毯的材料没有跟着走。局限在于地毯是静态图像，这里的"褶子"还携带内部三层结构（质量、电荷、形状各由不同层承担）。

## 例子

| 例子 | 是否成立 | 原因 |
|---|---|---|
| 粒子作为材料上的图案 | 成立（定案） | 材料元相子原地不动，图案前进 |
| 电荷归电荷核并受超选择守卫 | 成立 | 绕数超选择给出绝对守恒 |
| 旧方案（σ 锁定孤子、单向缠绕） | 不成立（2026-09-05 废弃） | 六矛盾，A1 直指锁定判据 |
| 把质量归包层 | 分两层看 | 质量的数值归锚核（锁定耦合定），能量的分布归整片缺陷、主体在包层（第 627 号，核区一格约占 $2.1\times10^{-23}$） |
| 宽度 = 波性侧软模关联长度 | 成立（2026-09-20 收束） | 尾、包络、带边三读数一致；桥因子 $\pi/\sqrt{3}$ |
| 局域锚核把净荷钉在体内 | 不成立（负结论） | 驻留判据 $l_{\max} = A/\sigma = 1.26$ 格 |
