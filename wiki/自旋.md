# 自旋

**自旋**是粒子的内禀角动量量子数，在体系中源于相位结构的扭转（π 扭转）：费米子的半整数自旋来自扭转拓扑与三条前提定理（相对论性、正能谱、微观因果性）的共同作用。

## 概述

自旋是粒子"自带"的旋转量子数：电子自旋 1/2，旋转 $2\pi$ 回到自身时波函数变号，旋转 $4\pi$ 才回到原值。体系给出自旋的几何来源：π 扭转（相位结构的半圈扭转）给出旋量结构，费米统计由三前提定理从相对论量子场论引用。

## 定义

自旋量子数 $s$：费米子 $s = 1/2 + \mathbb{Z}$，玻色子 $s \in \mathbb{Z}$。旋量态满足 $R(2\pi) = -1$（旋转 $2\pi$ 变号），$R(4\pi) = +1$。体系内自旋来自相位结构的 π 扭转（半扭转的环，莫比乌斯带式：绕一圈变号），它给出自旋 1/2 的几何事实。

费米统计的三前提（在体系内逐一对得上号）：相对论性（色散 $\omega^2 = \omega_0^2 + c^2k^2$ 与低能洛伦兹）、正能谱（能隙 $\omega_0 > 0$）、微观因果性（群速度小于光速、光锥即因果边界）。三前提齐备后引用标准定理：半整数自旋为费米子，泡利不相容变为联合份额为零的记录事实。

## 机制

1. 相位结构的 π 扭转给出旋量（半整数自旋）的几何载体
2. 三前提定理把"变号统计"固定为费米/玻色区分
3. 泡利不相容 = 两个同态粒子的联合份额为零（份额记录写死）
4. 新模型的粒子复合结构（均匀缠绕背景上的位错）与编织相位（涡旋交换）衔接：费米统计可经位错/涡旋编织重新获得（toric code 框架），与 π 扭转两条路径需协调

## 通俗类比

自旋 = 莫比乌斯带（扭转半圈的纸带）。在带上爬一圈回到起点，却到了带的"背面"（变号）；爬两圈才回到原处。纸带的半圈扭转是几何事实，不需要额外解释；粒子的半整数自旋就是这种"扭转后回到背面"的结构。

## 与其他概念的关系

- **相位**：自旋 = 相位结构扭转的量子数（π 扭转）
- **元相子**：自旋的载体是元相子的相位结构
- **绕数**：电荷 = 整数圈（绕数），自旋 = 半圈（π 扭转），同属相位拓扑
- **费米统计**：三前提定理 + 扭转拓扑（与编织相位路径的衔接为遗留）
