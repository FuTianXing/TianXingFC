# 螺旋阶梯几何

**螺旋阶梯几何**是心物波粒二象公理的几何体现：元相子的完整物侧几何体为 $D^2\times\mathbb{R}$（豪斯多夫维数 3，实心圆柱体），相位轨迹空间为边界 $S^1\times\mathbb{R}$；相位指针连续旋转一圈，圆心沿法线方向跃迁一格（普朗克长度）。本质是心物双螺旋。

## 概述

螺旋阶梯几何是体系的空间根基：它同时给出紧致与非紧致两把尺子（$S^1$ 表盘与 $\mathbb{R}$ 楼梯）、连续与离散的统一（旋转流与跃迁梳）、波与粒的边界关系（$S^1 = \partial D^2$）、方向与距离的分工（相位圆实轴与法线轴）。多数关键定案最终追溯到这里的结构事实：弹性身份（键弹性写在法线轴高度差）、距离归粒（层数 = 距离）、电荷整数性（圈数）。

## 定义

- 相位轨迹空间：$\mathcal{T}_{\text{波}} = S^1\times\mathbb{R}$
- 完整物侧几何体：$D^2\times\mathbb{R}$（边界包含 $S^1 = \partial D^2$）
- 法线轴：复平面圆心处的法线（垂直于复平面），承载空间像素累积
- 双螺旋：实轴螺旋（物侧结构信息）与虚轴螺旋（心侧），相位差恒 $\pi/2$；第二层级为元相子间相位差分布形成的双螺旋网络

生成机制：相位指针连续旋转一圈（满周闭合），圆心沿法线平移一格 $l_P$。旋转连续、跃迁离散。

## 机制

1. 满周闭合（$\theta = 2\pi n$）触发法线跃迁
2. 每次跃迁生成一个空间像素（层数 +1，距离 +$l_P$）
3. 层数累积 = 时空晶格生成（距离归粒）
4. 相位圆实轴方向差 = 波矢、电磁场（方向归波），与法线轴分工

## 通俗类比

旋转楼梯：表盘（$S^1$）告诉你转到哪个角度，楼梯高度（$\mathbb{R}$）告诉你总共转了几圈。同一个几何体里，角度是紧致的（转一圈回到原位），高度是非紧致的（圈数无限累积）。人的相位 = 表盘读数，人的楼层 = 楼梯高度，每次满圈自动上升一层。

## 例子

| 结构事实 | 对应定案 |
|---|---|
| $S^1$ 紧致 | 相位角（表盘） |
| $\mathbb{R}$ 非紧致 | 法线轴层数 = 距离（距离归粒） |
| $S^1 = \partial D^2$ | 波是粒的边界（轨迹是实体的边界） |
| 两轴分工 | 方向归波（实轴方向差）vs 距离归粒（法线轴） |
| 键弹性身份 | 弹性写在法线轴高度差（非紧致，作者裁定） |

## 与其他概念的关系

- **元相子**：螺旋阶梯几何是元相子的完整几何体
- **法线跃迁**：螺旋的阶梯动作（满周后平移一格）
- **时空晶格**：螺旋累积的宏观结构
- **双螺旋**：个体（实轴 + 虚轴）与世界（相位差网络）的结构同构
- **弹性身份**：键弹性 = 螺旋高度差（法线轴），本攻坚的决定性定案
