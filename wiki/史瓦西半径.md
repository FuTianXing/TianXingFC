# 史瓦西半径

**史瓦西半径**是球对称质量 $M$ 的临界尺寸 $r_s = 2GM/c^2$，数值约为 $2.95\ \mathrm{km}\times(M/M_\odot)$；任何物质体系一旦被压缩到自身史瓦西半径以内，该半径处即形成事件视界，界内的光无法逃向远处。

## 概述

史瓦西半径把质量换算成一个长度。式中只有质量一个自变量，$G$ 与 $c$ 都是常数，因此半径与质量严格成正比：质量翻十倍，半径也翻十倍。代入行星质量得到毫米与公里的量级，代入星系中心黑洞的质量得到天文单位的量级，两端的差别全部来自质量本身。

它在元相子理论里承担的角色与在标准物理里不同。标准物理从场方程的解里读出这个半径，把它当作精确解的一个参数；体系把它当作绝对归一化的检验对象。写入幅度与格点标度锁定之后，记录场在 $r_s$ 处的取值自动落在 $1/2$，全程不含可调的耦合常数。

这个取值同时标出弱场构造的射程。记录场读数远小于 $1/2$ 时线性近似有效，读数接近 $1/2$ 时线性构造失准，继续向内侧需要强场动力学。这给体系的强场补全一个具体入口：饱和位置恰好与视界重合，强场动力学应从记录饱和机制入手。

## 定义

对球对称、无自转、不带电的质量 $M$，史瓦西半径为

$$r_s = \frac{2GM}{c^2} \approx 2.95\ \mathrm{km} \times \frac{M}{M_\odot}.$$

在 $r > r_s$ 的弱场区，史瓦西度规的时间分量与其弱场展开为

$$g_{00} = -\left(1 - \frac{r_s}{r}\right), \qquad h_{00} \equiv \frac{r_s}{r} = \frac{2GM}{c^2 r}.$$

体系用无量纲记录场 $\theta$ 表述同一个势场，它与牛顿势只差一个常数因子

$$\theta(r) = -\frac{\Phi}{c^2} = \frac{GM}{c^2 r}, \qquad \theta(r_s) = \frac{1}{2}.$$

体系把记录场与[[度规]]的对应压缩成一个识别式：$h_{00}/2 = \theta$。由 $r_s$ 派生的特征半径有两个：光子球半径为 $1.5r_s$，该处 $\theta = 1/3$；最内稳定圆轨道半径为 $3r_s$，该处 $\theta = 1/6$。单位取国际单位制，$G$ 为引力常数，$c$ 为真空光速，$M_\odot$ 为太阳质量。

## 机制

1. **临界性的来源**：把逃逸速度 $\sqrt{2GM/r}$ 取到 $c$ 反解半径，得到的正是 $r_s$。这条路径的数值是对的，理由却取自弱场直觉，强场行为需要由因果结构说明。
2. **因果结构**：在 $r = r_s$ 处 $g_{00}$ 为零，静止观察者无法停留，所有朝向未来的光锥都向内倾斜，向外的类光测地线不再存在。视界因此是一条单向膜，只允许由外向内穿越。
3. **体系侧写入**：有质量粒子每普朗克拍在法线场上写入一份倾斜 $\delta\theta = m/m_P$，邻居抄写平均扩散，稳态收敛为离散泊松格林函数给出的 $1/r$ 形状。$G$ 经 $m_P = \sqrt{\hbar c/G}$ 这一单一入口进入，恒等式 $G/(c^2 l_P) = 1/m_P$ 在浮点精度内成立，写入幅度由普朗克标度刚性锁定。
4. **饱和点**：把 $r = r_s$ 代进 $\theta = GM/(c^2 r)$，$G$、$M$、$c$ 全部约掉，剩下 $1/2$。体系把这个数读作记录场的饱和读数；按作者 2026-09-15 裁定的线性映射（压弯角与 $m/m_P$ 成正比），$1/2$ 对应法线压弯 $90^\circ$，即视界，详见 [[注记-记录场读数的角度映射审查：满偏与视界角的三套候选读法]]。线性化所用的 $\tan\theta \approx \theta$ 在此已有约一成的偏差，弱场构造在自身的射程边界上失效。
5. **派生半径**：有效势 $V_{\mathrm{eff}} = (1 - r_s/r)(1 + L^2/r^2)$ 的极值条件给出圆轨道，稳定性的边界落在 $r = 3r_s$，该处 $\theta = 1/6$，与视界处的 $1/2$ 属同一类代数结果。

## 通俗类比

把记录场想成一张以弧度标注的地形图。图上有一条等值线，读数是 $0.5$ 弧度。线外坡度平缓，光线可以自由进出；压到这条线上，坡面已经陡到光线也爬不出去。史瓦西半径就是这条等值线的水平位置。

类比说明两件事：临界性只取决于读数达到某个固定值，与天体的材质、组成无关；半径随质量线性增长，质量翻倍则半径翻倍。局限有两条：地形图画的是空间，视界是时空里的因果边界；光线在视界上失去的是"向外"这个方向本身，与攀爬力气的大小无关。

## 例子

| 例子 | 成立与否 | 原因 |
|---|---|---|
| 地球 $r_s = 8.87\ \mathrm{mm}$ | 成立 | $2GM/c^2$ 直接计算，整颗地球压进一颗弹珠 |
| 太阳 $r_s = 2.95\ \mathrm{km}$ | 成立 | 同式，约 $2.95\ \mathrm{km}\times M/M_\odot$ |
| 银心 Sgr A*（$4.3\times10^6 M_\odot$）$r_s \approx 1.27\times10^7\ \mathrm{km}$ | 成立 | 半径随质量线性增长，约 18 个太阳半径 |
| 把太阳压到 3 公里以内 | 成立，形成视界 | 表面缩到自身 $r_s$ 以内，光无法外逃 |
| 视界是物质的表面 | 不成立 | 视界是因果边界，物质集中在中心附近的极小区域 |
| 视界处曲率发散 | 不成立 | $r_s$ 属坐标奇点，曲率有限，物理奇点在 $r = 0$ |
| 超大质量黑洞视界内平均密度低于水 | 成立 | $r_s \propto M$ 而体积 $\propto M^3$，平均密度 $\propto 1/M^2$ |
| $r_s$ 处 $\theta = 1/2$ 是体系预言 | 不成立 | 该值的算术来源属标准物理的代数恒等式；体系的工作是识别为饱和点并论证其不容偏离 |

## 与其他概念的关系

- [[牛顿势]]：记录场 $\theta = -\Phi/c^2$ 是势的无量纲形式，势阱的读数在 $r_s$ 处为 $1/2$。
- [[时空晶格]]：绝对标度由格点结构与 $m_P$ 锁定，$r_s$ 的量级因此不含自由参数。
- [[FK链]]：一维代理模型，为写入与抄写的平衡提供可算的类比结构。
- [[记录场]]：体系侧承载 $r_s$ 的场，在视界处达到饱和读数。
- [[法线场]]：记录场的载体，写入与抄写发生在它的格点上。
- [[史瓦西对齐]]：以 $r_s$ 处的记录场取值为检验点的零参数判据（N5）。
- 事件视界（待建）：$r_s$ 就是事件视界的半径，因果边界的几何位置。
- 引力时间膨胀（待建）：$r_s$ 处坐标钟停，$d\tau/dt = \sqrt{1 - r_s/r}$ 在该处为零。
