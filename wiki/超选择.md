# 超选择

**超选择**是态空间的扇区结构带来的绝对守恒规则：属于不同扇区的状态之间不存在可观测的相干叠加，任何局域操作都不能建立或破坏这种相干。在体系中，电荷（绕数）超选择由基态空间投影量子数推出。

## 概述

标准量子力学把电荷超选择当作经验插入的规则：电荷不同的态之间没有相干项。体系的贡献在于给出机制级理由：态空间按绕数算符分解为扇区，扇区之间的矩阵元为零，因此跨扇区的相干叠加在结构上不存在。

超选择的保护来自非局域拓扑（环面环绕、纠缠组织），与势垒无关。它解释电荷守恒的绝对性：守恒的根源是通道不存在，守卫无需站岗。

## 定义

设态空间分解为 $\mathcal{H} = \bigoplus_W \mathcal{H}_W$（按绕数算符 $\hat{W}$ 的本征值）。若任意局域算符 $\hat{O}$ 的跨扇区矩阵元为零

$$\langle\psi_a|\hat{O}|\psi_b\rangle = 0, \qquad W_a \ne W_b,$$

则 $W$ 是超选择荷：不同 $W$ 的态的叠加没有可观测的干涉项，等价于不存在这样的叠加。

保护机制的严格形态：$\hat{W}$ 与局域哈密顿量在全空间不对易（$[H, W] \ne 0$，仅 Z_2 特例对易），但 $\hat{W}$ 保持基态空间、基态空间内可对角化（基态空间投影量子数），跨扇区一阶矩阵元为零。

## 机制

1. 态空间按绕数分解为扇区（每个电荷值一个扇区）
2. 局域算符不能连接不同扇区（跨扇区矩阵元零，数值 $10^{-16}$ 量级）
3. 扇区数由环面拓扑给出（基态简并 = $N^2$，与 L、N 无关）
4. 经典化丢失保护（经典层绕数衰变）确认保护依赖量子相干

## 通俗类比

超选择 = 没有楼梯的楼房（同"扇区"词条的类比）。不同楼层之间没有通道，所以"楼上的人"与"楼下的人"之间不存在任何互动，谈论"楼上与楼下的叠加"没有意义。楼层的存在是建筑的拓扑结构决定的，规则本身不需要守卫执行。

## 例子

| 情形 | 是否允许 | 原因 |
|---|---|---|
| 电子在 A、B 两处叠加 | ✓ | 同电荷扇区内，可相干 |
| 电子与正电子叠加 | ✗ | 不同电荷扇区，跨扇区无矩阵元 |
| 绕数 1 的态演化为绕数 0 | ✗ | 局域动力学到不了别的扇区 |
| 热扰动下的电荷泄漏 | ✗ | 扰动是局域算符，跨扇区禁戒与温度无关 |

## 与其他概念的关系

- **扇区**：超选择的载体结构（楼层），两者是同一机制的两个侧面
- **基态空间投影量子数**：保护机制的严格数学形态
- **弦算符**：跨扇区算符的唯一类型（沿闭合回路分布，非局域，不在局域生成元闭包内）
- **经典化**：经典层无超选择保护（绕数衰变），保护依赖量子相干
