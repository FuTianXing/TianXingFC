# 键变量

**键变量**是定义在格键上的自由度，即一对相邻元相子之间那个可以独立取值的量。它的取值就是[[棱差]]（两端的实轴方向之差取模一圈），体系用它承载波矢、曲率、绕数与电荷。

## 概述

[[格键]]上挂着两个物理内容不同的量，键变量是波性侧的那一个。它的取值取在圆上、模一圈，就是两端实轴方向之差。波矢由它定义，沿面元一周求和给出曲率，沿闭合路径求和给出绕数。体系里凡属关系层的几何读数，都从它派生。

它与其他量的分别在于地位：[[棱差]]是键变量的具体取值，属同一个东西的两个层次的说法；[[面元]]曲率是键变量沿一圈的和；绕数是这个和的整圈读数。键变量在链条的最底端，是那条被反复求和的原始量。

键变量在电荷机制里换了更强的身份。复合位错粒子的电荷核住在 toric code 层的关系自由度上，基准文本写为"$Z_N$ toric code 键变量 = 关系自由度"。这个词变量不写在任何一个元相子身上，只住在两个元相子之间；电荷守恒正是这个键自由度的对易保护带来的，局域过程改不动它。键变量因此不只是几何量，它是守恒荷的存储位置。

## 定义

设晶格格点为 $n$，沿方向 $\hat a$ 的格键连接站点 $n$ 与 $n + \hat a$。记站点上的实轴取向为 $A_n \in \mathbb{R}/2\pi\mathbb{Z}$，键变量取两端之差的最小角差

$$d_{n,\hat a} = \big(A_{n+\hat a} - A_n\big)_{\min} \in \mathbb{R}/2\pi\mathbb{Z}.$$

它是圆上变量，取值模 $2\pi$。由它可以派生三个量：波矢 $k_a l_P \propto d_{n,\hat a}$（方向归波）；面元曲率 $F_{\rm plaq} = \sum_{\ell \in \partial F} d_\ell$；绕数 $W = \big(\sum_{\rm loop} d\big)/2\pi$。

在电荷机制一侧，键变量写成 $Z_N$ 谱的独立自由度：取值 $\mathbb{Z}_N$，住在棱上，面项与星项两类算子在其上作用，构成 toric code 的对易结构。

## 机制

**其一，两读法与身份裁决。** 键变量可以直接定义成"实轴方向差"，也可以由两端站点值相减反推。键身份轮（第 80 条，判据 22/22）核过两种读法在整数绕数下一致，差别只出现在被截断的边界模与半整数构型上。这一轮把选择做成对照裁决，读数是：

- **派生读法（键 = 相邻格点读数之差）**：面通量与绕数恒零（枚举最大 19683 个构型），面约束独立条数为零。荷在该读法下根本不存在非零构型，与位形侧四重否定合流。
- **独立读法（键自由度独立取值）**：面秩 $F-1$、星秩 $V-1$、简并 $= N^2$，绕数取遍 $N^2$ 个取值对且均匀（每对各 $N^{\,n-2}$ 个构型），面通量图案均匀。

作者据此裁定弦网棱自由度 = 实轴方向差。保护结构要求键按独立自由度读。

**其二，一维链上的恒等式。** 开放链上 $\sum \Delta u$ 等于边界差（可任意取值），周期链上恒为零。即绕数在边界上是数据、在环面上是自由量子数。这条恒等式是边界着装锁定绕数的机制来源。

**其三，两个耦合须同时在场。** 只留星项或只留面项时简并指数远大于 $2$（$L = 2$ 给 $5$、$L = 3$ 给 $10$）。保护需要格点内锁定与格点间关系同时在场，键变量单独不足。

**其四，弦作为切割线不改动键变量。** 把方向场沿切割线整体平移 $2\pi$ 的整数倍，键变量逐条不变（偏差 $8.9\times10^{-16}$）。故切割线属描述，作为墙则等于局部键变量偏移，弦网骨架无需额外公设。

## 通俗类比

一排人手拉手站成一列，每个人手里握着一个小指针。相邻两人指针的夹角就是一个键变量：它不记任何一个人自己的指针指着哪，只记两人之间的差。想读出这个差，必须两个人一起看；单看一个人，什么也读不出来。

局限在于人手握指针的夹角是普通角度，而键变量取值模一圈，绕整圈与不动在读数上不可区分，这正是绕数只能整圈计数、半整数构型需要补一条弦的原因。

## 例子

| 情形 | 结果 | 原因 |
|---|---|---|
| 派生读法（键 = 站点之差） | 面通量与绕数恒零 | 荷在该读法下不存在非零构型（第 80 条） |
| 独立读法（键独立取值） | 简并 $= N^2$、绕数均匀可达 | 保护结构要求键为独立自由度 |
| 均匀波矢（梯度型） | 各键变量非零，面元环量全零 | 键有差、圈内相消 |
| 绕数型缺陷（$w = 1$） | 核面元环量 $2\pi w$ | 键变量沿核一圈的和恰为整圈 |
| 开放链 | $\sum \Delta u$ = 边界差（任意值） | 绕数在边界上降为数据 |
| 周期链 | $\sum \Delta u$ 恒为零 | 无边界则无净差 |
| 半整数构型 | 单值键变量写不出 | 须带一条弦（切割处跳变 $2.9442$ rad） |
| 切割线平移 $2\pi$ 整数倍 | 键变量逐条不变 | 移位属描述，不进入读数 |

## 与其他概念的关系

- **[[格键]]**：键变量是格键上承载的波性侧量，两者是载体与内容的关系。
- **[[棱差]]**：键变量的具体取值，即两端实轴方向之差取模一圈。
- **[[面元]]**：键变量沿面元一周求和给出曲率，键是面元的边界。
- **[[实轴方向场]]**：键变量是该场沿格键的差分，方向场取值在站点上。
- **[[电荷]]**：电荷核住在 toric code 层的关系自由度上，这个自由度即键变量，其键变量 = 关系自由度。
- **[[扇区]]**：扇区由绕数算符的本征值分解，绕数是键变量的闭合和。
- **[[超选择]]**：跨扇区通道为零即键变量层面的对易保护。
- **[[绕数]]**：键变量沿闭合路径求和后整除一圈的整数读数。

## 边界声明

本词条把键变量作为独立条目列出，与[[格键]]词条的"键即读数落处"一段互补：格键管载体与两种键身份的分工，本词条管波性侧那一支的内容。

三处须注意。其一，键变量与[[棱差]]在多数文本中可互换，本词条的区分在角色：棱差强调它是"相位读数的最小单元"，键变量强调它是"定义在键上的自由度"，后者在电荷机制一侧才显出必要。其二，键变量的谱在电荷机制中取 $Z_N$（有限群），在几何读数中取圆上连续值，前者是有保护结构的独立自由度、后者是被求和的原始量。其三，本词条不裁决键变量的本体层地位，弦网棱自由度与实轴方向差的三层状态（概念层已定案、机制层已核、本体层未建）挂在接口 O1 上。
