# 键弹性

**键弹性**是格点之间的弹性耦合，即相邻两个格点在法线轴高度差上受的回复力，其强度记 $\kappa_\parallel$。它是复合位错粒子三层结构中包层的那一层，决定粒子的宽度与洛伦兹色散。

## 概述

[[格键]]上挂着两个物理内容不同的量，键弹性是粒性侧的那一个。它写在相邻格点的法线轴高度差上，取平方型，惩罚一切偏离自然长度一层的键差。位错的宽度由它与格点内锁定 $\kappa_\varphi$ 的竞争给出，两者之比决定粒子的可见性。

这个概念的分量在于它曾是整个粒子载体问题的开关。复合模型把粒子刻画为均匀缠绕背景上的位错，宽度机制寄生于平方弹性，而体系注册哈密顿量的键弹性当初写成 $\cos$ 型。两种形式对 $2\pi$ 整数倍键差的态度相反：平方弹性惩罚一切偏离，$\cos$ 弹性对整数倍缠绕零惩罚。弹性身份裁决以统一协议完成对照，结论是紧致 $\cos$ 读法下可见位错恒非基态、隐藏形才是基态，粒子形状只是盆地浅薄的亚稳；螺旋平方读法下可见宽态在全部参数区为最低态，粒子作为基态真实存在。

作者据此裁定键弹性原始形式 = 螺旋高度差（非紧致），$\cos$ 书写降级为小角下的角度投影。复合模型在体系内由此闭环。

## 定义

键弹性作用在法线轴高度上。设相邻两格点的法线轴高度为 $h_n$、$h_{n+\hat a}$，键能取平方型

$$E_{\text{bond}} = \frac{\kappa_\parallel}{2}\big(h_{n+\hat a} - h_n\big)^2.$$

它惩罚一切偏离自然键差（一层）的偏离量，取值空间非紧致（高度差可取任意实数）。

紧致写法为

$$E_{\text{bond}}^{(\cos)} = \kappa\big(1 - \cos 2\pi\Delta u\big),$$

对整数倍缠绕零惩罚（$1 - \cos 4\pi = 0$）。两种写法在小角下等价，大角关系未给出，故紧致形式降级为角度投影。

位错宽度由键弹性与格点内锁定竞争给出

$$\ell^* \sim \sqrt{\kappa_\parallel/\kappa_\varphi}.$$

在 FK 记号下（$k$ 为 PN 势强度、$K$ 为弹性刚度）写作 $\ell^* \sim \sqrt{k/K}$，$K/k \le 0.02$ 时 $\ell^* \ge 2$，宽度落入洛伦兹色散窗口。

## 机制

**其一，弹性身份裁决的对照。** 协议在两侧完全相同：$N = 400$ 开边界链，$u_0 = 0$、$u_{N-1} = N$ 强制恰好一个额外缠绕，同一 PN 势（$K(1 - \cos 2\pi u_n)$），同一平滑位错初条件，同一参与比宽度定义，过阻尼梯度流。唯一变量是弹性形式。

**其二，紧致 $\cos$ 侧：隐藏形是稳定极小。** 尖锐位错（全格点整数、单键 $e = 1$）能量恰为零；加 $0.05$ 微扰后弛豫回到 $E = 1.5\times10^{-12}$、$\ell = 1.000$。宽阔的可见态（$E = 1.13$、$\ell = 69.7$）向尖锐形方向对半混合后直接滑到 $E = 0$、$\ell = 1.00$。可见位错对窄化扰动不稳健，形状的吸引盆被隐藏基态占据。这与扇区约束动力学的隐藏扭转定案一致，本裁决把"隐藏"从数值终态升格为紧致投影读法下的热力学必然。

**其三，螺旋平方侧：全参数区可见宽态为最低态。** 尖锐初始化的弛豫终态在全部七个 $r$ 值下能量都高于平滑宽态（$0.0569$ 对 $0.0285$、$0.1138$ 对 $0.0569$、……、$0.8629$ 对 $0.8318$）。可见位错就是基态，宽度窗口在基态意义上真实。隐藏形（$E = 0.5$ 起）被可见态压制，位形侧否定链的第三支确认闭合。

**其四，弹性身份裁决（2026-09-06 作者裁定，无保留）。** 键弹性原始形式 = 螺旋高度差（非紧致），其中 $\mathbb{R}$ = 法线轴（复平面圆心处的法线，满周闭合沿法线平移 $l_P$，层数 = 距离，距离归粒 $x^a = l_P n^a$）。相位圆实轴（复平面内）与法线轴是两个不同的轴，实轴方向差属波性侧。

**其五，宽度参数区。** $K/k \le 0.02$ 时 $\ell^* \ge 2$ 落窗，色散已证为波系统长波性质。位错的能量学由两层决定：格点内锁定 $\kappa_\varphi$（[[锚核]]，供绑定能即质量）与格点间键弹性 $\kappa_\parallel$（包层，供宽度）。

## 通俗类比

把时空晶格想成一排弹簧，每个格点是一个小球，相邻球之间由一根弹簧连着。弹簧的自然长度是一层；把某个球多推了半层，弹簧就绷紧、产生回复力。键弹性就是这根弹簧的劲度。

类比说明的是弹性把局部扰动往外摊开的机制，摊开的范围即位错宽度；局限在于弹簧的劲度是常数，而这里的紧致写法对整数倍位移的惩罚为零，这一差别正是弹性身份裁决要处理的问题。

## 例子

| 情形 | 结果 | 原因 |
|---|---|---|
| 平方弹性（非紧致） | 可见宽态为基态，全参数区成立 | 偏离自然键差处处有代价，高度藏无可藏 |
| 紧致 $\cos$ 弹性 | 隐藏形（$E = 0$）为基态，可见形为亚稳 | 整数倍缠绕零惩罚，尖锐形不被惩罚 |
| 均匀缠绕背景 | 每键相位差恰为一层，键能为零 | 自然键差，无偏离 |
| 位错核 | 局部多出或少出一层 | 键差偏离自然值，键能非零 |
| 宽度落窗条件 | $K/k \le 0.02$ 时 $\ell^* \ge 2$ | 键弹性与锁定竞争给出宽度 |
| 小角极限 | 两种写法等价 | $\cos$ 展开为二次型，等效刚度 $(2\pi)^2\kappa$ |

## 与其他概念的关系

- **[[格键]]**：键弹性是格键上承载的粒性侧量，与键变量分居两侧。
- **[[位错]]**：位错的宽度由键弹性与格点内锁定之比给出，包层即键弹性。
- **[[复合位错粒子]]**：包层（法线轴弹性）是三层结构之一，供宽度与洛伦兹色散。
- **[[均匀缠绕背景]]**：背景满足每键一层，即键能处处取自然值。
- **[[螺旋阶梯几何]]**：键弹性写在法线轴高度差上，法线轴即 $S^1 \times \mathbb{R}$ 里的 $\mathbb{R}$。
- **[[时空晶格]]**：键弹性的自然键差为格距一层，格距绝对不变（晶格刚性）。
- **[[法线场]]**：键弹性作用在法线轴高度上，与法线场的记录取值同轴。
- **[[FK链]]**：FK 模型是一维代理，其链弹性即键弹性的代理形态。

## 边界声明

本词条把键弹性作为独立条目列出，与[[格键]]词条的分工是：格键管载体与两种键身份的总说，本词条管粒性侧那一支的内容。

三处须注意。其一，记号在文献中有两套：体系侧用 $\kappa_\parallel$（键弹性）与 $\kappa_\varphi$（格点内锁定），FK 记号用 $K$ 与 $k$，两套在不同文档中并存，本词条以体系侧记法为主、括注 FK 记法。其二，紧致与平方两种写法属同一对象的两种书写：紧致是角度投影，平方是原始形式，小角下等价，大角下由作者裁定取平方。其三，本词条不裁决 PN 势与 $\kappa_\varphi$ 的身份关系（站点势 vs 格点内三元组锁定），该项为弹性身份裁决注记所记的接续攻坚内容，归 P1-33 一线。
