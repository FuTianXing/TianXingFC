# 位错

**位错**是均匀缠绕背景上多出（或少出）一层的局部缺陷：整齐的螺旋阶梯阵中某处挤进一层台阶，形成一道有位置、有宽度、带能量的"褶子"。有质量粒子 = 背景上的法线轴位错；位错网络作为粒子诞生宿主的同生方案为纲领性。

## 概述

电荷 = 绕数定案之后，理论面对载体困境：绕数住在哪、谁守卫它、携带它的对象为何看得见。守恒要求全局性，粒子要求局域性，色散要求宽度，三个要求在单一光滑自由度上不可同时满足。排除链先后否定了光滑场涡旋环（塌缩）、孤立疤（对偶反绕数湮灭）与扇区极小（拓扑强制离域），结论是相位场内没有粒子载体。

复合位错粒子给出出路：粒子 = 均匀缠绕背景（法线轴逐键一层）上的法线轴位错，三层结构各司其职。电荷核（toric code 层关系自由度）对易守恒，锚核（$\kappa_\varphi$ 格点内锁定）供给绑定能即质量，包层（法线轴弹性）给出宽度与洛伦兹色散。位错能成为粒子，依赖弹性身份裁决：键弹性原始形式 = 法线轴高度差（非紧致），高度藏无可藏，位错必须以有限能量、有限宽度存在。

位错的第二处出场在粒子形成问题：宇宙结晶时波前相遇的相位失配凝固为晶格位错网络，绕数缺陷被位错钉扎而凝固为有质量费米子（同生方案，纲领性）。两处位错层次不同：法线轴位错是粒子本体，晶格位错网络是背景宿主。

## 定义

设真空为均匀缠绕背景：每一对相邻元相子沿法线轴相差一层（$S^1 \times \mathbb{R}$ 螺旋真空，物理相位投影均匀）。法线轴位错是背景上的额外一层集中于邻域的结构，即螺旋阶梯阵中局部多出（或少出）一个台阶。

位错的能量学由两层弹性决定：格点内锁定 $\kappa_\varphi$（锚核）与格点间键弹性 $\kappa_\parallel$（包层）。键弹性的原始形式为法线轴高度差（平方型，非紧致），紧致 cos 书写降级为角度投影。FK 模型中位错宽度

$$\ell^* \sim \sqrt{\kappa_\parallel/\kappa_\varphi},$$

$K/k \le 0.02$ 参数区 $\ell^* \ge 2$ 格距，宽度落入洛伦兹色散窗口。注意档位债（第 479 条）：定稿耦合 $K = 2.788142\times10^{-46}$ 与该验证窗口相差 43 至 46 个数量级，落窗结论属模型档位。裁决点 D-d 已消解（2026-09-29：位错基态性成立、质量钉位交内部壁承载），钉扎侧的 45 个数量级弥合问题随之消解。残余为 $\kappa_\phi$ 层级的输入登记与 D-4 钉扎未决项。

晶格位错网络是另一类对象：波前相遇处相位失配凝固的位错线，节点处交汇为三重结，满足 Burgers 矢量守恒

$$\mathbf{b}_1 + \mathbf{b}_2 + \mathbf{b}_3 = 0.$$

## 机制

复合位错粒子分三层运转。电荷核：绕数写在 toric code 层关系自由度上，$[H, W] = 0$ 精确成立，基态简并 $2^{2g}$，跨扇区一阶矩阵元为零，局域过程偷不走圈数。锚核：$\kappa_\varphi$ 锁定供给绑定能 $E_B \propto \kappa_\varphi$（实测标度 3.13/121.9/359.4），锁定越硬质量越大；其旧钉位职能已改判退役（第 54 条）。包层：法线轴弹性决定位错宽度，近背景二次型给出 FK 孤子族，宽度落入色散窗口后位错获得正常的相对论性运动学。

运动由转换波执行：位错（图案）换装前进，材料元相子原地不动。惯性、测地响应与速度上限均已数值验证，等效原理在模型级 O(1) 闭环。

粒子形成机制（同生方案）中，位错的角色变为宿主。波前推进埋下晶格位错与接缝（Kibble 必然性）；绕数缺陷核心处序参量亏损，位错处序参量本被抑制，两者重叠省去创造亏损的能量代价，总能量最低，缺陷被钉扎而凝固为费米子。此与超导涡旋钉扎同一物理。局域性由钉扎承担，运动由位错滑移承载（候选）。吸附动力学与密度定量未建模，属纲领性主张。该方案的局域性分工早于第 54 条改判：现行局域性机制见 [[畴壁]]（内部壁承载绕数，K 无关、零模）。第 486 条进一步判明复结构畴壁与粒子位错同源。

## 通俗类比

位错 = 平整地毯上鼓起的一道褶子。地毯多出的一截是真实布料，压平需要用力，褶子带着绷劲；它鼓在哪儿是确定的，鼓包有一片宽度。类比说明：位错必须花能量存在、有位置、有宽度，这三点恰好是粒子需要的。局限：地毯褶子可以随时压平消失，法线轴位错却被绕数守卫与内部畴壁的自撑结构守住，压平它需要跨过拓扑与能量的双重门槛，这点超出地毯类比。

位错网络的类比：水结冰时两股冰晶碰到一起，分子排列对不上号，形成接缝线。磁铁屑喜欢吸在桌面划痕上，粒子的核喜欢待在接缝处，因为那里本来就乱，待着最省能量。

## 例子

| 情形 | 成立 / 不成立 | 原因 |
|---|---|---|
| 复合位错（法线轴位错，三层结构） | 成立（定稿） | 守恒、局域、色散三要求在两层结构上各得其所，宽度落窗于 $K/k \le 0.02$ |
| 光滑场涡旋环 | 不成立 | 全部协议下塌缩到精确真空，绕数经分支穿越体内部丢失 |
| 孤立疤 | 不成立 | 核心 $+1$ 与分支切割片 $-1$ 精确成对、两格距内对湮灭 |
| 晶格位错网络钉扎（同生方案） | 成立（纲领性） | 波前相位失配必然产生位错线，钉扎给出局域性；吸附动力学未建模 |
| 内部畴壁承载绕数（第 486 条） | 成立（判据级） | 定义性联结 K 无关，壁位零模；位错自撑不瓦解，与运动相容 |

## 与其他概念的关系

- **绕数**：位错的电荷由绕数承载，守卫在波性侧（超选择与对易结构）；绕数藏进 $2\pi$ 时位错不可见，法线轴高度差让藏无可藏
- **键弹性**：包层的弹性耦合，位错宽度由它与格点内锁定之比给出（$\ell^* \sim \sqrt{\kappa_\parallel/\kappa_\varphi}$）
- **质量机制**：[[锚核]]绑定能 = 质量（$E_B \propto \kappa_\varphi$），缺陷刚度特征频率 $\omega_0 \sim \sqrt{\kappa_\phi}$
- **螺旋阶梯几何**：法线轴 = $S^1 \times \mathbb{R}$ 的 $\mathbb{R}$，满周闭合平移 $l_P$，层数 = 距离，位错即层数分布中的局部异常
- **超选择**：扇区结构守卫总绕数，跨扇区算符为弦算符，位错的电荷不可被局域过程改变
- **畴壁**：位错自撑与绕数承载的现行承接者（第 486 条）；复结构畴壁与粒子位错同源（第 54 条）
- **转换波**：位错的运动由换装前进执行，材料元相子原地不动
- **时空晶格**：均匀缠绕背景即空间格距结构，位错是居住其上的缺陷，时空与粒子同源于螺旋阶梯
