# 康普顿波长

**康普顿波长**是标准物理学中与粒子质量配对的长度尺度（约化形式 $\lambda_C = \hbar/(mc)$，1923 年由康普顿散射得名）；在元相子理论中它获得机制出身：缺陷（粒子）的宽度由决定其质量的同一个耦合给出，宽度与质量天然成反比（耦合越弱，缺陷越宽、越轻），两者的乘积在 Planck 单位下恒为一，故宽度精确等于约化康普顿波长。

## 概述

标准物理学里康普顿波长是量子散射的产物：光子撞电子，波长改变 $\Delta\lambda = \lambda_C(1-\cos\theta)$，其中的 $\lambda_C = h/(mc)$ 被读出为一个长度。它是一个实验关系的常数，本身没有更深的机制解释。

元相子理论给出另一条路。粒子是晶格上的缺陷（复合位错粒子），缺陷的宽度由锁定势的耦合 $K$ 决定，缺陷的质量也由同一个 $K$ 决定：宽度正比于 $1/\sqrt{K}$，质量正比于 $\sqrt{K}$。两者天然互反，乘积与 $K$ 无关。代入体系的两条已裁决关系（声速等于光速、质量由能隙定义），乘积的数值被钉为 1（Planck 单位），于是宽度精确等于约化康普顿波长。

这条关系不产生新预言，也不改变任何可检验数值。它的作用是取消一个本可以是自由参数的宽度：在体系里，粒子的尺寸与质量不独立，质量定了，尺寸就跟着定。

质量的数值与能量的分布分居两处：锚核的锁定耦合定出数值，这份能量摊在整片缺陷上、主体在包层，核区一格在电子档约占 $2.1\times10^{-23}$，能量质心在单体时与锚核落点重合（第 627、628 号，见 [[质量]]）。

## 定义

约化康普顿波长（标准物理）：$\lambda_C = \hbar/(mc)$；非约化形式 $\lambda_C^{\rm(nr)} = h/(mc) = 2\pi\lambda_C$。

体系内的宽度恒等式（第 622 号）：

$$\xi = \frac{1}{2\pi}\sqrt{\frac{k_b}{K}}, \qquad K = 3\kappa_\phi t_P, \qquad \kappa_\phi t_P = \frac{(m_e/m_P)^2}{6\pi}, \qquad k_b = 2\pi,$$

逐步化简得

$$\xi = \frac{1}{2\pi}\sqrt{\frac{2\pi \cdot 6\pi}{3(m_e/m_P)^2}} = \frac{m_P}{m_e}, \qquad \xi\,l_P = \frac{\hbar}{m_e c}.$$

符号：$\xi$ 为缺陷宽度（格距计），$k_b$ 为键刚度，$K$ 为锁定势系数，$\kappa_\phi$ 为格点内异类耦合，$m_P$ 为普朗克质量。四条输入（M6 字典链、M-E 锚、势系数定义、公理刚度）中任何一条被修订，恒等式随之改变。

## 机制

**宽度与质量同出一耦合。** 锁定势 $K$ 是格点上把相位拉回整数值的刚度，它同时决定两件事：缺陷的宽度（$K$ 越小，相位越松，缺陷摊得越宽）与缺陷的质量（$K$ 越大，绑定能越高）。写成式子，$m_{\rm gap} = 2\pi\sqrt{K/J}$ 与 $\xi = \frac{1}{2\pi}\sqrt{k_b/K}$，相乘即 $m_{\rm gap}\xi = \sqrt{k_b/J}$。声速归一等价于 $k_b = J$，乘积为 1。

**物理链条三步。** 第一步，模型的相对论性色散给出"宽度乘能隙频率等于光速"（$\xi\omega_0 = c$，与声速等于光速同源，已在色散线上数值验证）。第二步，质能定义给出 $m = \hbar\omega_0/c^2$，即缺口模式的频率就是质量（M-E 裁决）。第三步，两式联立即得 $\xi = \hbar/(mc)$，这就是康普顿关系。整条链没有用到新假设。

**系数为 1 是条件性的。** 它依赖声速归一（$k_b = J$）与锚选择（缺口模式即电子）。若锚改取孤子口径，系数变 $4/\pi$ 量级；若刚度归一不同，系数变 $2\pi$ 量级。**缩放关系（宽与质量互反）是结构结论，系数数值是条件性结论**，引用时须分开对待。

## 宽度读数与周期读数（$2\pi$ 的归宿）

同一个粒子身上有两个都能叫康普顿波长的长度，两者差 $2\pi$，须分辨哪个属于缺陷宽度。

宽度是缺陷偏离场的实空间衰减长度。真空色散 $\omega^2 = \omega_0^2 + c^2k^2$ 下，静止局域缺陷的波矢为虚（$k = i\omega_0/c$），偏离按 $e^{-x/\xi}$ 衰减，$\xi = c/\omega_0$。代入 $\omega_0 = mc^2/\hbar$ 得 $\xi = \hbar/(mc)$，即约化康普顿波长。角频率逼出 $\hbar$，宽度随之取约化。

螺距是相位转整整一圈（$2\pi$ 弧度）沿轴推进的距离，$2\pi c/\omega_0 = h/(mc)$，即全周康普顿波长。圈频率逼出 $h$，螺距随之取全周。

两者相差 $2\pi$，成因是"衰减长度"与"周期"两种读数。此 $2\pi$ 与 $h$ 对 $\hbar$ 的差别同源，是"一整圈"与"一弧度"的换算，属同一处圈约定。判别式：凡问"多大范围"取约化，凡问"一个周期多长"取全周。康普顿散射公式 $\Delta\lambda = \lambda_C(1-\cos\theta)$ 里的 $\lambda_C = h/(mc)$ 是波长读数，取全周正确，与宽度取值不冲突。详见 [[注记-台阶面宽度取约化康普顿波长：衰减读数对周期读数与系数口径]]。

**一处符号须分清。** 本节与「机制」节都写 $\omega_0$，它有两层身份，不可混（[[理论总纲/元相子理论已解决难题总览]] 第 29 条 2026-10-14 补语）：其一是这里用到的物质场相位旋转速率 $\omega_0 = mc^2/\hbar$（康普顿频率，整体相位不可观测），其二是相对相位模式的特征频率 $\omega_0 \sim \sqrt{\kappa_\varphi}$（构型、基态静态，载体在锚核一侧）。两者符号相同而所指不同，引用时须指明是哪一条。

## 作为分界尺度

标准物理把康普顿波长读作一条能量与长度的分界线，探针波长落在线的哪一侧，物理图像随之改变。光子波长远大于它时，光子能量远低于电子静能，散射像"光子撞上一个几乎不动的电子"；光子波长与它相当时，光子能量与电子静能相当，散射中波长的改变量达到康普顿波长的量级；光子波长远小于它时，光子能量远高于电子静能，撞击足以从真空中激发出一对电子与正电子（对产生），过程从低能散射过渡到相对论量子过程。这一图像在体系内可以重建，且机制基础更具体。

**分界的根源是缺陷的双尺度结构。** 缺陷有两个不同尺度：电荷核在格点尺度（管相互作用），包层在康普顿尺度（管结构与色散）。低能探针（光子）只与电荷核耦合，读不到包层；探针波长缩到康普顿尺度时，探针尺度与缺陷的场结构尺度（包层宽度 $\xi$）可比，分辨缺陷场结构的门槛在此。标准物理里电子是点、康普顿波长是量子散射的常数组合，没有这层结构；体系里这条分界来自两个几何尺度之比：探针波长与缺陷宽度。

**分界的绝对位置由恒等式钉住。** $\lambda_C \leftrightarrow m_e c^2$ 这个对应在体系内是恒等式的改写：$\xi l_P = \hbar/(m_e c)$ 给出探针波长等于缺陷宽度时 $E = \hbar c/(\xi l_P) = m_e c^2$。标准物理里 $\lambda_C$ 的组合值需要输入 $m_e$ 才能定；体系里宽度的位置随质量自动走（$\xi = m_P/m_e$），质量仍是输入，但"分界恰在此处"不需要额外解释。

**对产生一段机制不同型。** 标准物理的对产生阈值由能量守恒定（光子能量超过 $2m_ec^2$）；体系的对产生由拓扑跃迁定（棱差代表值跨过阈值，两侧面元曲率各跳 $\mp 2\pi$，即正反核生成，见 [[阈值穿越（电荷对生成）]]，第 142 条）。体系另有 [[质量阈值]]（$D_c = m/m_P$）规定缺陷激发的门槛无序度。两套阈值的换算关系未建立。

**三项已闭合（2026-10-12，判据第 623 号）**：其一，分辨判据由归一化形状因子给出，$F(q) = \operatorname{sech}(\pi q\xi/2)$（缺陷场剖面）与 $(\pi q\xi/2)/\sinh(\pi q\xi/2)$（能量密度剖面），5% 偏离门槛为 $\lambda = 30.6\xi$ 与 $17.7\xi$。该形状因子是**探针与缺陷（整体结构）的弹性散射形状因子**，即"探针能否分辨缺陷的场结构"的门槛，不是电磁耦合的源（2026-10-15 第 630 号重新定位，见下）。

其二，对产生阈值换算建立，缺口口径（2026-09-22 裁决）给 $2m_ec^2$（对标准之比 1），孤子口径给 $(8/\pi)m_ec^2$（之比 $4/\pi$）。其三，中间段为二次律 $F \approx 1-(\pi q\xi)^2/c$，适用上限从误差预算推导。

三段自洽：对产生阈值（$q\xi = 2$）处 $F$ 已降到 $0.1$ 至 $0.3$，两段不重叠。

**残余边界两项**：形状因子的前因子（数值系数）未定，本轮只给归一化形状与门槛位置；光子与包层（法线轴）的直接耦合仍未计算，本轮说明其领头阶为零（分工双场）。

**电荷耦合的形状无关性（2026-10-15，判据第 630 号）**：电磁场耦合到拓扑绕数（整数 $w$），与缺陷宽度及场剖面形状无关；五档宽度下总绕数均为 $1$（偏差 $1.19\times10^{-13}$），AB 相位全为 $2\pi$。故形状因子不进入电磁耦合，上述分辨门槛只描述探针分辨缺陷场结构的能力。$w=0$ 的局域凸起在拓扑荷读法下中性、在密度读法下带电，两读法由此分开。

## 与点粒子图像的关系

标准物理把电子当点粒子处理，而本体系给电子一个宽度（约化康普顿波长）。两者是否冲突？**不冲突，因为"点"与"宽度"说的是两件不同的事，分属不同层。**

**标准物理的"点"说的是电磁探测测不出结构。** 电子在实验上被限制在 $10^{-18}$ 米以内，标准模型的拉格朗日量不含形状因子（电子按点处理）。这是有效描述层的陈述：用任何探针都读不出内部结构；至于它是否数学上零尺寸，标准物理不作断言。

**体系的"宽度"说的是包层的形变尺度。** 电子是三层复合位错（见 [[复合位错粒子]]）：电荷核（绕数，torus code 层关系自由度，管电荷与电磁耦合）、锚核（格点内锁定，管质量）、包层（法线轴弹性，管宽度与色散）。宽度 $3.86\times10^{-13}$ 米是**包层**的尺度。

**为什么两者可以同时为真**：光子只耦合到电荷核。电荷核局域在格点尺度（绕数的承载尺度），与包层宽度无关，所以电磁探针读到的仍是点状耦合。包层宽度是内部结构尺度，不被电磁探针直接读出。这与"原子核有 $10^{-15}$ 米尺寸、但低能光子看它像点"同型：**内部结构尺度与相互作用点状性是两个量，不必相等。**

**一处读法张力已裁决（2026-10-15，判据第 630 号）**：本节按「光子耦合到拓扑绕数、形状无关」的读法写（判据第 445 号的 Aharonov-Bohm 耦合只含总绕数）。本词条「作为分界尺度」一节的形状因子（判据第 623 号）原按另一读法写（电荷分布继承缺陷剖面、宽度进入耦合），两读法曾不相容。判据第 630 号裁定前者成立：电磁场耦合到拓扑绕数，形状无关；623 的形状因子是弹性散射形状因子（分辨门槛），不是电磁耦合的源。故 $5.6$ 个数量级的实验冲突不成立（该冲突只在密度读法下出现）。详见 [[验证脚本/注记-电荷耦合的形状无关性裁决：拓扑荷对密度展布（判据第630号）]]。

**体系内部的正式表述**：[[从绕数困境到复合位错粒子：电荷载体问题的完整解决]] 给出不相容命题，守恒（要求绕数写在全局结构上）、局域（要求绕数聚拢在格距尺度）、色散（要求载体有宽度，"点状对象无非相对论色散可言"）三者在单一光滑自由度上不可同时满足。解法是把三要求分到两层：守恒归波性侧（超选择与 toric code 对易保护）、局域归锚核、宽度归包层。**宽度在此读作包层结构的尺度，与粒子的"大小"一词所暗示的硬核半径无关**，两者分属不同自由度。

**如实声明**：体系尚未把"康普顿尺度（$10^{-13}$ 米）与散射探测上限（$10^{-18}$ 米）的对接"作为独立判据正面算过。两者量级差五个数量级，且分属不同层，不构成冲突。若追问"$10^{-18}$ 米以内是什么"，体系现在的回答是：电荷核在格点尺度、包层在康普顿尺度，哪个实验读到哪一层，需要逐个对接；这份对接清单尚未系统做过。此项与本词条「作为分界尺度」一节的光子-包层耦合矩阵元为同一待办。

## 通俗类比

面团与发酵：面团越软（耦合越弱），摊得越开，同时内部能存的"张力能"越低。宽度与能量由同一团软硬决定，一涨一落。局限：面团类比给的是"互反"，不给精确系数；系数 1 来自声速与质量两条定义的相遇，类比照不出这一层。

## 与其他概念的关系

**与复合位错粒子**：宽度是该粒子的三层解剖之一（包层供宽度），本词条给出宽度的定量闭式。

**与普朗克质量**：恒等式两侧是 $m_P/m_e$ 与宽度，故普朗克质量在此扮演"格距与质量比之间的换算"角色。

**与德布罗意波**：两者是同一粒子两种长度。德布罗意波长 $h/p$ 随动量变，是运动学长度；康普顿波长 $\hbar/(mc)$ 随静止质量定，是结构长度。粒子静止时德布罗意波长发散而康普顿波长有限，两者不可混用。

**与色散**：恒等式的一个输入（声速等于光速）由色散关系给出，两者共享同一组耦合常数。
