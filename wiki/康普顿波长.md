# 康普顿波长

**康普顿波长**是标准物理学中与粒子质量配对的长度尺度（约化形式 $\lambda_C = \hbar/(mc)$，1923 年由康普顿散射得名）；在元相子理论中它获得机制出身：缺陷（粒子）的宽度由决定其质量的同一个耦合给出，宽与质量天然互反，两者的乘积在 Planck 单位下恒为一，故宽度精确等于约化康普顿波长。

## 概述

标准物理学里康普顿波长是量子散射的产物：光子撞电子，波长改变 $\Delta\lambda = \lambda_C(1-\cos\theta)$，其中的 $\lambda_C = h/(mc)$ 被读出为一个长度。它是一个实验关系的常数，本身没有更深的机制解释。

元相子理论给出另一条路。粒子是晶格上的缺陷（复合位错粒子），缺陷的宽度由锁定势的耦合 $K$ 决定，缺陷的质量也由同一个 $K$ 决定：宽度 $\propto K^{-1/2}$，质量 $\propto K^{1/2}$。两者天然互反，乘积与 $K$ 无关。代入体系的两条已裁决关系（声速等于光速、质量由能隙定义），乘积的数值被钉为 1（Planck 单位），于是宽度精确等于约化康普顿波长。

这条关系不是新预言，不改变任何可检验数值。它的作用是消去一个本可以是自由参数的宽度：在体系里，粒子的尺寸与质量不独立。

## 定义

约化康普顿波长（标准物理）：$\lambda_C = \hbar/(mc)$；非约化形式 $\lambda_C^{\rm(nr)} = h/(mc) = 2\pi\lambda_C$。

体系内的宽度恒等式（第 622 号）：

$$\xi = \frac{1}{2\pi}\sqrt{\frac{k_b}{K}}, \qquad K = 3\kappa_\phi t_P, \qquad \kappa_\phi t_P = \frac{(m_e/m_P)^2}{6\pi}, \qquad k_b = 2\pi,$$

逐步化简得

$$\xi = \frac{1}{2\pi}\sqrt{\frac{2\pi \cdot 6\pi}{3(m_e/m_P)^2}} = \frac{m_P}{m_e}, \qquad \xi\,l_P = \frac{\hbar}{m_e c}.$$

符号：$\xi$ 为缺陷宽度（格距计），$k_b$ 为键刚度，$K$ 为锁定势系数，$\kappa_\phi$ 为格点内异类耦合，$m_P$ 为普朗克质量。四条输入（M6 字典链、M-E 锚、势系数定义、公理刚度）中任一修订，恒等式随之。

## 机制

**宽度与质量同出一耦合。** 锁定势 $K$ 同时决定两件事：缺陷的宽度（$K$ 越小、缺陷越胖）与缺陷的质量（$K$ 越大、绑定能越高）。写成式子，$m_{\rm gap} = 2\pi\sqrt{K/J}$ 与 $\xi = \frac{1}{2\pi}\sqrt{k_b/K}$，相乘即 $m_{\rm gap}\xi = \sqrt{k_b/J}$。声速归一等价于 $k_b = J$，乘积为 1。

**物理链条三步。** 其一，模型的相对论性色散给出"宽度乘能隙频率等于光速"（$\xi\omega_0 = c$，与声速等于光速同源，色散线上已数值验证）。其二，质能定义给出 $m = \hbar\omega_0/c^2$（缺口模式频率即质量，M-E 裁决）。其三，两式联立即得 $\xi = \hbar/(mc)$，即康普顿关系。这一步不含新假设。

**系数为 1 是条件性的。** 它依赖声速归一（$k_b = J$）与锚选择（缺口模式即电子）。若锚改取孤子口径，系数变 $4/\pi$ 量级；若刚度归一不同，系数变 $2\pi$ 量级。**缩放关系（宽与质量互反）是结构结论，系数数值是条件性结论**，两者要分开记。

## 作为分界尺度

标准物理把康普顿波长读作一个能量与长度的分界：$\lambda \gg \lambda_C$ 时光子能量远小于电子静能，散射近似为"光子撞静止电子"；$\lambda \sim \lambda_C$ 时两者相当；$\lambda \ll \lambda_C$ 时进入对产生等相对论量子过程。这一图像在体系内可以重建，且机制基础更具体。

**分界的根源是缺陷的双尺度结构。** 缺陷有两个不同尺度：电荷核在格点尺度（管相互作用），包层在康普顿尺度（管结构与色散）。低能探针（光子）只与电荷核耦合，读不到包层；探针波长缩到康普顿尺度时开始分辨包层，散射图像改变。标准物理里电子是点、康普顿波长是量子散射的常数组合，没有这层结构；体系里分界来自两个几何尺度之比。

**分界的绝对位置由恒等式钉住。** $\lambda_C \leftrightarrow m_e c^2$ 这个对应在体系内是恒等式的改写：$\xi l_P = \hbar/(m_e c)$ 给出探针波长等于缺陷宽度时 $E = \hbar c/(\xi l_P) = m_e c^2$。标准物理里 $\lambda_C$ 的组合值需要输入 $m_e$ 才能定；体系里宽度的位置随质量自动走（$\xi = m_P/m_e$），质量仍是输入，但"分界恰在此处"不需要额外解释。

**对产生一段机制不同型。** 标准物理的对产生阈值由能量守恒定（光子能量超过 $2m_ec^2$）；体系的对产生由拓扑跃迁定（棱差代表值跨过阈值，两侧面元曲率各跳 $\mp 2\pi$，即正反核生成，见 [[阈值穿越（电荷对生成）]]，第 142 条）。体系另有 [[质量阈值]]（$D_c = m/m_P$）规定缺陷激发的门槛无序度。两套阈值的换算关系未建立。

**未闭合三项**：其一，光子与包层耦合的矩阵元（探针能否分辨包层的定量判据）；其二，体系对产生阈值（棱差跨阈值）与能量阈值 $2m_ec^2$ 的换算；其三，中间段（探针尺度与缺陷尺度相当）的散射图像。三项均未计算，登记为待办。

## 与点粒子图像的关系

标准物理把电子当点粒子处理，而本体系给电子一个宽度（约化康普顿波长）。两者是否冲突？**不冲突，因为"点"与"宽度"说的是两件不同的事，分属不同层。**

**标准物理的"点"说的是电磁探测测不出结构。** 电子在实验上被限制在 $10^{-18}$ 米以内，标准模型的拉格朗日量不含形状因子（电子按点处理）。这是有效描述层的陈述，即"用什么探针都读不出内部结构"，而非"数学上的零尺寸"。

**体系的"宽度"说的是包层的形变尺度。** 电子是三层复合位错（见 [[复合位错粒子]]）：电荷核（绕数，torus code 层关系自由度，管电荷与电磁耦合）、锚核（格点内锁定，管质量）、包层（法线轴弹性，管宽度与色散）。宽度 $3.86\times10^{-13}$ 米是**包层**的尺度。

**为什么两者可以同时为真**：光子耦合到电荷核，电荷核局域在格点尺度（绕数的承载尺度），与包层宽度无关。所以电磁探针读到的仍是点状耦合；包层宽度是内部结构尺度，不被电磁探针直接读出。这与"原子核有 $10^{-15}$ 米尺寸、但低能光子看它像点"同型：**内部结构尺度与相互作用点状性是两个量，不必相等。**

**体系内部的正式表述**：[[从绕数困境到复合位错粒子：电荷载体问题的完整解决]] 给出不相容命题，守恒（要求绕数写在全局结构上）、局域（要求绕数聚拢在格距尺度）、色散（要求载体有宽度，"点状对象无非相对论色散可言"）三者在单一光滑自由度上不可同时满足。解法是把三要求分到两层：守恒归波性侧（超选择与 toric code 对易保护）、局域归锚核、宽度归包层。**宽度在此读作包层结构的尺度，与粒子的"大小"一词所暗示的硬核半径无关**，两者分属不同自由度。

**如实声明**：体系尚未把"康普顿尺度（$10^{-13}$ 米）与散射探测上限（$10^{-18}$ 米）的对接"作为独立判据正面算过。两者量级差五个数量级、且分属不同层，不构成冲突；但若追问"$10^{-18}$ 米以内是什么"，体系现在的回答是"电荷核在格点尺度、包层在康普顿尺度，哪个实验读哪一层需逐个对接"，该对接清单未系统做过。此项与本词条「作为分界尺度」一节的光子-包层耦合矩阵元为同一待办。

## 通俗类比

面团与发酵：面团越软（耦合越弱），摊得越开，同时内部能存的"张力能"越低。宽度与能量由同一团软硬决定，一涨一落。局限：面团类比给的是"互反"，不给精确系数；系数 1 来自声速与质量两条定义的相遇，类比照不出这一层。

## 与其他概念的关系

**与复合位错粒子**：宽度是该粒子的三层解剖之一（包层供宽度），本词条给出宽度的定量闭式。

**与普朗克质量**：恒等式两侧是 $m_P/m_e$ 与宽度，故普朗克质量在此扮演"格距与质量比之间的换算"角色。

**与德布罗意波**：两者是同一粒子两种长度。德布罗意波长 $h/p$ 随动量变，是运动学长度；康普顿波长 $\hbar/(mc)$ 随静止质量定，是结构长度。粒子静止时德布罗意波长发散而康普顿波长有限，两者不可混用。

**与色散**：恒等式的一个输入（声速等于光速）由色散关系给出，两者共享同一组耦合常数。
