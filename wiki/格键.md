# 格键

**格键**是时空晶格上连接相邻两个格点的连线，即网格里的一根小线段，也就是[[站点]]词条里"棱"的实体名称。它的体系地位在于：相位读数不写在点上、写在键上，因此格键是波矢、棱差、曲率与绕数这些关系量的定义处。

## 概述

时空晶格是一张格点阵，格点是地址，连接相邻两格点的线段就是格键。这个名称借自化学里的化学键，取的是"把两个东西连起来"这层意思。体系把量分成站点量与键量两类，分工的一条要害判据是：**单站点给不出相位**，能与参照比较的量是相邻两点的差，而这个差正好属于连接那两点的键。键是读数落处，点是地址落处。

键上承载的物理量有两类，各有一个专门的名称。波性侧承载几何读数的量叫**键变量**，其取值即[[棱差]]（两端实轴方向之差取模一圈），波矢由它定义、沿面元一周的和给出曲率与绕数。粒性侧承载力学的量叫**键弹性**，其原始形式为法线轴高度差（非紧致平方型，2026-09-06 作者裁定），位错的宽度由它与格点内锁定 $\kappa_\varphi$ 之比给出。

到了电荷机制，键又以一种更强的身份出场。复合位错粒子的电荷核由 toric code 层的关系自由度承载，基准文本写为"$Z_N$ toric code 键变量 = 关系自由度"。这个词变量不写在任何一个元相子身上，只住在两个元相子之间；电荷守恒正是这个键自由度的对易保护带来的，局域过程改不动它。

## 定义

设晶格格点为 $n$，沿方向 $\hat a$ 的格键记 $\ell = (n, n + \hat a)$，其两端的站点为 $n$ 与 $n + \hat a$，长度为格距 $l_P$。

波性侧键变量取两端的实轴方向之差，取最小角差

$$d_\ell = \big(A_{n+\hat a} - A_n\big)_{\min} \in \mathbb{R}/2\pi\mathbb{Z},$$

即棱差。键变量是圆上变量，取值模 $2\pi$。

粒性侧键弹性写在法线轴高度差上。设两端元相子的法线轴高度为 $h_n$，则

$$E_{\text{bond}} = \frac{\kappa_\parallel}{2}\big(h_{n+\hat a} - h_n\big)^2,$$

取平方型、非紧致，故高度藏无可藏（紧致的 $\cos$ 书写降级为小角下的角度投影）。位错宽度由此与格点内锁定竞争

$$\ell^* \sim \sqrt{\kappa_\parallel/\kappa_\varphi}.$$

## 机制

**三层坐标中的位置。** 格键是「站点 / 棱 / 面元」三层里的中间层。站点只有模读数、给得出计数；棱上是差值，可读波矢与写入时刻差；面元由一圈棱围成，其环量给出曲率与绕数。键是中间那一层，把两端站点的模读数接成可比较的量。

**键变量的两读法与键身份裁决。** 键变量可以直接定义成"实轴方向差"，也可以由两端站点值相减反推。键身份轮（第 80 条，判据 22/22）核过两种读法在整数绕数下一致，差别只出现在被截断的边界模与半整数构型上。这一轮的关键读数是：**派生读法（键 = 相邻格点读数之差）下面通量与绕数恒零**（枚举最大 19683 个构型），即荷在那里根本不存在非零构型，与位形侧四重否定合流；**独立读法（键自由度独立取值）下**面秩 $F-1$、星秩 $V-1$、简并 $= N^2$、绕数取遍 $N^2$ 个取值对且均匀。故保护结构要求键按独立自由度读，作者已裁定弦网棱自由度 = 实轴方向差。

**键即电荷的家。** 电荷核住在 toric code 层的关系自由度上，这个自由度正是键变量。跨扇区一阶矩阵元为零、局域过程偷不走圈数，说的是键层面的对易保护。键因此不只是一根几何线段，它是守恒荷的存储位置。

**均匀缠绕背景的逐键判据。** 均匀缠绕背景的定义写成"每键一层"，即每一根格键两端的相位差恰好一层，处处如此。背景的均匀性是逐键检查的，可见键也是背景构型的核查单元。

**弦的分层。** 把切割线上的方向场整体平移 $2\pi$ 的整数倍，棱差、面元环量、写入时刻三项逐项不变（偏差 $8.9\times10^{-16}$ 与 $0$）；把同形台阶的幅度取成半圈，棱层立刻显形而面元层不动。故弦作为切割线属描述，作为墙则等于局部键变量偏移。棱自由度天然存在，弦是把偏差处连起来的画法，弦网骨架无需额外公设。

## 通俗类比

把时空晶格想成一张方格纸，格点就是纸上的交叉点，格键是连接两点的那些短线。单独看一个点，你只能数出过了几格；要说指针朝哪、拧了多少，必须看连接两个点的那条短线。类比说明的是关系量相对单体量的优先地位。

局限在于纸上那根线是实体，而格键没有独立本体：实际存在的是两个元相子，键描述的是它们之间的关系，是关系层借用的坐标。

## 例子

| 情形 | 结果 | 原因 |
|---|---|---|
| 单站点读相位 | 不成立：只给计数 | 相位模一圈，一个模读数不构成可比较的量 |
| 键变量读棱差 | 成立：给出波矢方向 | 键是两端之差所在的层 |
| 派生读法（键 = 站点之差） | 面通量与绕数恒零 | 荷在该读法下不存在非零构型（第 80 条） |
| 独立读法（键变量独立取值） | 成立：简并 $= N^2$、绕数均匀可达 | 保护结构要求键为独立自由度 |
| 均匀缠绕背景 | 每键相位差恰为一层 | 逐键判据，处处如此 |
| 切割线平移 $2\pi$ 整数倍 | 棱差与面元环量逐项不变 | 弦作为描述不可观测，墙只活在棱层 |
| 半圈台阶（$\delta = \pi$） | 棱层显形（$1.5708$），面元层不变 | 半圈不是整圈，墙留在棱层 |

## 与其他概念的关系

- **[[站点]]**：键连接相邻的两个站点，两者是坐标分层的相邻两层。站点给计数，键给读数。
- **[[棱差]]**：键变量在波性侧的具体取值，即两端实轴方向之差取模一圈。
- **[[时空晶格]]**：键是晶格上的线段，长度恰为格距 $l_P$。
- **[[实轴方向场]]**：方向场定义在站点上，沿格键的差分给出棱差。
- **[[均匀缠绕背景]]**：其"每键一层"的判据以键为核查单元。
- **[[电荷]]**：电荷核住在 toric code 层的键变量上，键变量的对易保护即电荷守恒。
- **[[扇区]]**：扇区由绕数算符的本征值分解，而绕数是键变量的闭合和。
- **[[位错]]**：位错的宽度由键弹性（法线轴高度差）与格点内锁定之比给出。
- **[[接缝]]**：单站点读不出相位所付的代价，落在连接相邻站点的那一条键上。

## 边界声明

本词条把"格键"与[[站点]]词条中的"棱"统一为同一对象，属词条归纳，不引单一定案文档。术语层面依据是它在各文档中的一致用法：棱差词条"定义在晶格的格键上，每段键带一个圆上读数"、对偶基词条"每个格键上的相位读数"、实轴方向场词条"方向场沿格键的差分"。

三处须注意。其一，"格键"与"键"在体系文档中混用，本词条统一以格键为词条名。其二，键的两种身份须分开读：波性侧的键变量承载棱差与电荷，粒性侧的键弹性承载位错宽度，两者同挂在键上但物理内容不同。其三，本词条不裁决键对应的本体层地位，弦网棱自由度与实轴方向差的三层状态（概念层已定案、机制层已核、本体层未建）挂在接口 O1 上，见对应判定注记。
