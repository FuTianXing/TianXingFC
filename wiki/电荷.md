# 电荷

**电荷**是粒子携带的整数量子数，在体系中与绕数等同（电荷 = 绕数定案）：电荷 = 相位场沿闭合路径的整数圈数，由波性侧纠缠结构承载，受基态空间投影量子数保护。

## 概述

电荷是物理学中最守恒、最量化的物理量：所有电子电荷精确相等，任何过程中电荷守恒绝对。体系把这两个事实变成结构推论：电荷 = 绕数（整数圈，拓扑类无参数，同类必同荷），电荷守恒 = 非局域拓扑不可局域改变（扇区之间无通道）。

电荷与质量的分工：质量 = 粒性侧局部能量（绑定能，可受扰动），电荷 = 波性侧全局拓扑（扰不动）。两者守恒精确度的差异是承载结构不同，这是"电荷守恒比能量守恒更严格"的机制性解释。

## 定义

电荷 $Q$ 定义为沿闭合路径的绕数：

$$Q = W(C) = \frac{1}{2\pi}\oint_C d\varphi_{\text{lift}} \in \mathbb{Z}.$$

承载在波性侧纠缠结构（关系自由度通量，非局域），保护为基态空间投影量子数（跨扇区一阶矩阵元为零）。体系内电荷的规范对称性（U(1)）与电荷同源：荷 = 纠缠拓扑类，规范 = 该类描述的自由度冗余。

## 机制

1. 整数性：拓扑类无连续参数，同类实现必同电荷（所有电子电荷精确相等的原因）
2. 承载：波性侧纠缠结构（toric code 风格，键变量 = 关系自由度）
3. 保护：基态空间投影量子数，跨扇区零矩阵元（Z_N 全系数值确认）
4. 规范：U(1) 对称性 = 纠缠结构描述冗余，与电荷同源

## 通俗类比

电荷 = 金条上刻的编号（绕数），存放在保险库的指定房间（扇区）。所有金条编号相同（拓扑类无参数），房间之间没有门（跨扇区禁戒），所以编号绝对不变。金条的重量（质量）可以因环境改变，编号（电荷）在任何情况下不动。

## 例子

| 情形 | 电荷行为 | 说明 |
|---|---|---|
| 所有电子 | 严格相等 | 拓扑类无参数 |
| 任何局域过程 | 严格守恒 | 跨扇区无通道 |
| 位置叠加 | 电荷不变 | 同扇区内自由叠加 |
| 慢变化、热扰动、强场 | 电荷不变 | 与能量、温度无关（区别于质量） |

## 与其他概念的关系

- **绕数**：电荷 = 绕数（定义）
- **超选择 / 扇区**：电荷是超选择荷，扇区按电荷划分
- **质量**：电荷归波、质量归粒（三层分工）；电荷守恒精确度远高于能量
- **规范**：U(1) 规范对称性 = 电荷同源（描述冗余）
- **引力**：引力源是质量（粒性侧），电荷不进入引力机制
