# 电荷

**电荷**是粒子携带的整数量子数，在体系中与绕数等同（电荷 = 绕数定案）：电荷 = 沿闭合路径的整数圈数，是拓扑不变量，由波性侧纠缠结构承载，受基态空间投影量子数保护。

## 概述

电荷是物理学中最守恒、最量子的物理量：所有电子电荷精确相等，任何过程中电荷守恒绝对。体系把这两个事实变成结构推论。

电荷的整数性来自拓扑类无连续参数：能取的圈数只有整数，同类实现必给同一个数，所以所有电子的电荷精确相等，不依赖任何标定。电荷的绝对守恒来自非局域拓扑不可局域改变：绕数写在波性侧的纠缠结构（关系自由度）上，局域过程够不着它，跨扇区的一阶矩阵元严格为零。

电荷与质量的分工是体系三层解剖的一角：质量 = 粒性侧的局部能量（绑定能，可受扰动、有标定），电荷 = 波性侧的全局拓扑（扰不动）。两者守恒精确度的差异由此获得机制性解释。

## 定义

电荷 $Q$ 定义为沿闭合路径的绕数：

$$Q = W(C) = \frac{1}{2\pi}\oint_C d\varphi_{\text{lift}} \in \mathbb{Z}.$$

它是整数。这个整数量与"衰减长度""周期"两种读数差 $2\pi$ 无关（该 $2\pi$ 归宿见 [[wiki/康普顿波长]]「宽度读数与周期读数」节）：圈数本身是拓扑类，无量纲。

承载在波性侧纠缠结构（关系自由度通量，非局域），保护为基态空间投影量子数（跨扇区一阶矩阵元为零）。体系内电荷的规范对称性（$U(1)$）与电荷同源：荷 = 纠缠拓扑类，规范 = 该类描述的自由度冗余。

## 机制

**其一，整数性。** 拓扑类无连续参数，同类实现必同电荷。这是"所有电子电荷精确相等"的机制，电荷量子化不需要额外输入。

**其二，承载。** 绕数写在波性侧的键变量上（[[键变量]]：$Z_N$ toric code 键变量 = 关系自由度，住在一对元相子之间，不写在任何单个元相子身上），由 [[超选择]] 与 [[绕数]] 定案。

**其三，保护。** 基态空间投影量子数给跨扇区零矩阵元（$Z_N$ 全系数值确认），局域过程偷不走圈数。

**其四，与电磁场的耦合形状无关（2026-10-15，判据第 630 号）。** 电磁场耦合到的是这个整数本身，不是电荷的空间分布。拓扑耦合取 Aharonov-Bohm 形式 $2\pi w\oint A\cdot\mathrm{d}l$，只含圈数与所围通量，与缺陷的宽度和剖面形状无关；对轨道变分给 $m\ddot x_\nu = 2\pi w F_{\mu\nu}\dot x^\mu$（判据第 445 条）。数值核对：五档缺陷宽度（$\xi$ 跨 16 倍）下总绕数恒为 $1$（偏差 $1.19\times10^{-13}$，机器精度），AB 相位恒为 $2\pi$。

**其五，电荷与磁单极的不对称。** 电荷 = 内部 $U(1)$ 空间的缠绕，内部空间的点源允许；磁单极 = 外部空间的扭转，外部空间的点源禁止（[[基准方向场]] 全局单值下）。两者数学同源（都是绕数），物理分居两个空间。

## 通俗类比

电荷 = 金条上刻的编号（绕数），存放在保险库的指定房间（扇区）。所有金条编号相同（拓扑类无参数），房间之间没有门（跨扇区禁戒），所以编号绝对不变。金条的重量（质量）可以因环境改变，编号（电荷）在任何情况下不动。

**类比说明**：圈数不可连续改变，故量子化与绝对守恒同时到手。**局限**：金条的编号可以重刻（外部干预），而绕数是几何结构，没有"重刻"这个操作；另一个局限是类比给不出"耦合形状无关"这一层，编号在保险库里 vs 编号跟着金条走，都不是绕数的实际耦合方式。

## 例子

| 情形 | 电荷行为 | 原因 |
|---|---|---|
| 所有电子 | 严格相等 | 拓扑类无参数 |
| 任何局域过程 | 严格守恒 | 跨扇区无通道 |
| 把缺陷拉宽（$\xi$ 变） | 电荷不变，电磁耦合不变 | 圈数是拓扑不变量（判据第 630 号） |
| $w = 0$ 的局域凸起 | 中性（场剖面非零而圈数为零） | 电荷判圈数，不判场剖面（判据第 630 号） |
| 位置叠加 | 电荷不变 | 同扇区内自由叠加 |
| 慢变化、热扰动、强场 | 电荷不变 | 与能量、温度无关（区别于质量） |

## 与其他概念的关系

- **绕数**：电荷 = 绕数（定义）。[[绕数]] 词条讲绕数本身，本词条讲它作为荷的一面。
- **扇区 / 超选择**：电荷是超选择荷，扇区按总绕数划分，跨扇区算符为弦算符。
- **键变量**：电荷的存储位置，[[键变量]] 住在一对元相子之间。
- **质量**：电荷归波、质量归粒（三层分工）；电荷守恒精确度远高于能量。数值落点见 [[质量]]。
- **复合位错粒子**：电荷是该粒子三层解剖中的电荷核，[[复合位错粒子]]。
- **基准方向场 / 实轴方向场**：电荷住物质侧（内部 $U(1)$ 缠绕），规范侧的拓扑（曲率）归 [[基准方向场]]，两侧由 Dirac 量子化条件相连。
- **引力**：引力源是质量（粒性侧），电荷不进入引力机制。
