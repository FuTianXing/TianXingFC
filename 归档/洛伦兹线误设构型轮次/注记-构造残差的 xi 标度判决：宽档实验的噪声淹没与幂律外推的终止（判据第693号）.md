## 1 问题与路线

第 692 号把外推缺口定位为 boost 构造残差，并留给本轮一个问题：这个残差是否随 $\xi$ 收缩？若它按 $1/\xi^2$ 走，物理档闭合（外推值落入预算 $2.47\times10^{-8}$）；若它是常数，闭合失败为结构性。692 号的五档 $\xi$ 全在 7 至 32 格，截距与斜率难以分离。

本轮的做法是把 $\xi$ 范围扩大 38 倍（$\sigma$ 从 63 推到 2400，即 $\xi/l_P$ 从 31.5 到 1200），用宽档曲线直接判决。前侦察确认成本可行：最宽档只需盒长 10960 格，运行时间约为基线 2.7 倍。

## 2 判据与读数

**BD1 冒烟。** 五档宽度的束缚频率全部对表（差 $\le 3.3\times10^{-15}$），阱深从 $0.365454$ 缓变到 $0.358896$，宽档拟合收敛良好。

**BD2 宽档行程（$v=0.30$）。**

| $\sigma$ | $\xi/l_P$ | dev | $1/\xi^2$ 预期 |
|---|---|---|---|
| $63$ | $31.5$ | $3.20\times10^{-4}$ | $1.51\times10^{-5}$ |
| $180$ | $90$ | $3.20\times10^{-4}$ | $1.86\times10^{-6}$ |
| $400$ | $200$ | $3.20\times10^{-4}$ | $3.76\times10^{-7}$ |
| $1000$ | $500$ | $8.00\times10^{-5}$ | $6.01\times10^{-8}$ |
| $2400$ | $1200$ | $1.60\times10^{-4}$ | $1.04\times10^{-8}$ |

前三档 dev 逐位相同（$3.20\times10^{-4}$），$\xi$ 扩大 6.3 倍而 dev 毫无下降，与 $1/\xi^2$ 预期（应降 40 倍）完全背离。

**BD3 标度判决（判「带宽不足」）。** 联合拟合给斜率 $a = 4.82\times10^{-1}$、截距 $b = 2.12\times10^{-4}$、$R^2 = 0.216$。初版判据以 $a/\xi_{\max}^2$ 为分母比较显著性，该量在宽 $1/\xi^2$ 范围上无物理意义（两种机制的联合斜率），已改为低四档恒定性判决。改后读数：低四档 dev 跨度 $92.3\%$（$\sigma=1000$ 档的 $8.0\times10^{-5}$ 破坏恒定），判「过渡区，带宽不足」。判据本身经历了两次修正，过程见 §4。

**BD4 防恒真。** 幂律模型残差 $4.01\times10^{-8}$，常数模型 $2.56\times10^{-7}$，下降比 $6.38$ 倍。对比 692 号窄档同型对照的 $39.6$ 倍：宽档下幂律拟合的解释力大幅丧失。

**BD5 收敛外推。** 宽档参数外推 $\mathrm{dev}_{\rm phys} = 2.12\times10^{-4}$，窄档（692 号）$3.64\times10^{-4}$，两者同量级（比 $0.58$），对预算比值 $8.6\times10^{3}$。外推缺口不是窄档范围的伪影，稳健。

## 3 诊断轮：宽档读数被量化噪声淹没

BD3 判「带宽不足」需要诊断：宽档 dev 的跳动（$3.2\times10^{-4}$、$3.2\times10^{-4}$、$3.2\times10^{-4}$、$8.0\times10^{-5}$、$1.6\times10^{-4}$）是物理还是量化伪影。对三个可疑档位改变采样时长 $T$ 与步长 $dt$：

| $\sigma$ | 装置 | dev |
|---|---|---|
| $400$ | $T=1600, dt=0.02$ | $3.6\times10^{-4}$ |
| $400$ | $T=3200, dt=0.02$ | $2.8\times10^{-4}$ |
| $400$ | $T=3200, dt=0.01$ | $3.2\times10^{-4}$ |
| $1000$ | $T=1600, dt=0.02$ | $4.0\times10^{-5}$ |
| $1000$ | $T=3200, dt=0.02$ | $2.0\times10^{-4}$ |
| $1000$ | $T=3200, dt=0.01$ | $2.0\times10^{-4}$ |
| $2400$ | $T=1600, dt=0.02$ | $1.6\times10^{-4}$ |
| $2400$ | $T=3200, dt=0.02$ | $1.2\times10^{-4}$ |
| $2400$ | $T=3200, dt=0.01$ | $1.2\times10^{-4}$ |

$\sigma=1000$ 档的 dev 随 $T$ 改变 5 倍，$\sigma=400$ 档改变 $1.3$ 倍。所有宽档读数都挤在 $10^{-5}$ 至 $3.6\times10^{-4}$ 之间无规律跳动，处在取频分辨率的极限附近（阱心采样序列的有效周期数随阱宽变化，宽档下信噪比恶化）。窄档读数不呈现这种行为（$\sigma \le 63$ 时 dev 逐位复现）。

结论：宽档实验不能判决幂律与常数，因为信号已沉入噪声。由此，本轮结论应读作「宽档装置测不出差别」，不得读作「测出来是常数」。

## 4 判据设计的两次修正（教训入库）

其一，初版 BD3 以 $a/\xi_{\max}^2$ 为分母比较截距显著性。该量由两种机制的联合拟合斜率决定，在宽 $1/\xi^2$ 范围上无物理意义，算出 $1912.7$ 这类荒谬值并误判「幂律主导」。修正为直接读平台的低四档恒定性判决。教训：显著性比较的分母必须是有独立定义的物理量，不能从被检验的拟合参数里现造。

其二，改用低四档恒定额后，$\sigma=1000$ 档的噪声读数破坏恒定性，判「带宽不足」。这说明修正后的判据正确地报告了自己的局限，判据设计达到自检。

## 6 严格程度与边界

本注记结论按四级声明制：BD2 前三档读数为判据级（窄档复现，逐位稳定）；宽档读数为条件性（噪声淹没，只作趋势）；BD4 对照为可复现数值；BD5 为判据级数值支撑；噪声淹没的判决为判据级（$T$ 与 $dt$ 双参数对照）。

验证什么：构造残差在 $\xi/l_P \le 200$ 范围内不随 $\xi$ 收缩（前三档 dev 逐位相同，与 $1/\xi^2$ 预期背离）；宽档装置测不出更精细的标度（噪声淹没）；外推缺口不是窄档范围的伪影（宽窄档外推同量级）。

不验证什么：不判决构造残差在物理档的精确行为（宽档实验被噪声淹没，该问题在本装置路线下不可达）；不完成物理档闭合（缺口性质已从「未知」收窄为「在可测范围内是常数」，但物理档仍无直接读数）；不动 `理论总纲/` 基准。

**路线终止登记。** 「用更宽的格点模拟外推构造残差标度」这条路线到此终止：信号在 $\xi/l_P \sim 200$ 以上沉入取频噪声，而物理档在 $\xi/l_P \sim 10^{22}$，中间没有任何可逐步逼近的台阶。后续若要闭合物理档，只剩两条不依赖宽档模拟的路线：对连续极限作用量做解析精确 boost 后把离散修正作微扰展开（读出构造残差的解析形式，判断其 $\xi$ 标度）；或用第 622 号恒等式把钟慢偏差写成质量比的显式函数（直接给物理档读数）。两条均见第 692 号注记 §4，本轮未做。
