## 误设构型的确切内容

`验证脚本/minimal_verification_p691_boost_closure.py` 的文档字符串写的是正确的 boost 构造（「$s_0 = \gamma x$ 收缩包络、按 $-\omega_b \gamma v x$ 给相位梯度」），代码把两处都取了倒数，调用处一律传 `shrink = 1.0/g`。三处同时反向：

| 项 | 文档字符串声明 | 代码实写 | 后果 |
| --- | --- | --- | --- |
| 包络 | $\psi(\gamma x)$，宽 $\sigma/\gamma$ | `s0 = shrink*xf` $\Rightarrow$ $\psi(x/\gamma)$，宽 $\sigma\gamma$ | 放大 $\gamma$，方向相反 |
| 相位梯度 | $-\omega_b \gamma v x$ | `th0 = -wb*shrink*v*xf` | 差 $\gamma^2$ 倍 |
| 阱宽 | 外场，boost 不变换 | `sg = sigma*shrink` | 外场被收缩 |

故旧构型是「阱收缩、包络放大 $\gamma$、相位差 $\gamma^2$」的混合体，初值包络与阱的束缚态宽度不匹配。运动档读到的是强烈弛豫瞬态，而非 boost 态。

## 为什么另有一套装置

格点色散 $\omega^2 = 1 + 4\sin^2(k/2)$ 在动量变量 $p = 2\sin(k/2)$ 上是精确的相对论形式 $\omega^2 = 1 + p^2$，boost 写在 $p$ 上逐位保持质量壳不变量。亚隙束缚态的 $p$ 为虚数，格点没有实模载体，故以波数构造的亚隙态 boost 必然离壳。第 809 号因此改用自由波包的谱构造，包络宽 $W = 300$ 格，$p$ 采样 101 点。
