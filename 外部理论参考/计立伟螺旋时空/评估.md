# 计立伟矢量光速螺旋时空归一化体系：评估

> 整理日期：2026-09-09
> 资料来源：计立伟本人 CSDN 综述《计立伟矢量光速螺旋时空归一化体系：理论溯源、核心建构与学术图景》（blog.csdn.net/2602_95435592/article/details/163534819，2026-09-08），以及同目录《方案简介与评估.md》。
> 本文件为外部理论参考的独立评估，供与天行新学对照研究之用。评估依据的是作者自述综述，其引用的约 89 篇预印本论文、推导细节与实验数据未经整理者独立核验，这一限制本身构成评估结论的一部分。

## 一、评估立场

评估沿用三条标准：内部自洽性、经验可检验性、与既有知识的兼容性。本评估依据的材料是计立伟本人撰写的综述，其引用的约 89 篇预印本论文、全部推导细节与实验数据均未经独立核验，因此针对的是作者所宣称的理论，对推导的真实性只能依据文本内部一致性判断。

## 二、定位：张祥前体系的公理化升级版

与张祥前相比，计立伟体系的进步是实质性的，可从五个维度确认：

| 维度 | 张祥前 | 计立伟 |
|---|---|---|
| 数学形式 | 初等微积分，量纲混乱 | 微分几何语言，双轨制量纲兼容 SI |
| 本体论 | 主观观念论（时间依赖观察者） | 物理实在论（时间是客观几何度量） |
| 与主流关系 | 公开否定相对论与标准模型 | 声称极限退化兼容，给出退化条件 |
| 实验路径 | 电瓶线圈定性测试 | 万元级定量装置 + 七重排他验证 + 证伪阈值 |
| 自我反思 | 无系统自我评估 | 明确标注局限、继承来源、思辨与实证之分 |

这种"民间直觉 + 专业重构"的路径本身值得严肃对待，它说明非主流理论也可以通过形式化升级获得可讨论的学术形态。评估的关键问题因此从"它是否比张祥前强"（答案是肯定的）转为"它是否因此成为科学理论"，这是本评估的主题。

## 三、公理体系与数学形式的评估

三公理（时空同一化 $r = Ct$、矢量光速 $\vec{C} = d\vec{R}/dt$、圆柱螺旋时空 $\vec{R}(t) = r\cos\omega t\,\hat{i} + r\sin\omega t\,\hat{j} + Ct\,\hat{k}$）内部一致，作为形式系统没有明显矛盾。统一主方程

$$G_{\mu\nu} + \Lambda g_{\mu\nu} = \frac{8\pi G}{c^4}\hat{U}T_{\mu\nu}\hat{\Phi}$$

在形式上模仿爱因斯坦场方程，但存在两个结构性问题：

1. **算子的定义域与作用方式不明确**。$\hat{U}$ 把"螺旋运动频率"映射为"质量能量"（$m \propto \omega$），$\hat{\Phi}$ 是"相互作用归一化场量"，两者在方程中的具体作用方式（数乘、微分算子或积分核）未见定义。没有明确作用方式的算子方程在形式上接近符号游戏，无法被独立验算。
2. **"唯一自由参数"与"无自由拟合参数"自相抵触**。体系宣称螺旋径轴比 $\kappa$ 是唯一自由几何参数，同时宣称 4.01% 预言无任何自由拟合参数。若 $\kappa$ 需要从实验定标（文章给出 $\kappa \lesssim 10^{-3}$ 的上限，未给出推导值），则 $\kappa$ 就是拟合参数，两个声称只能保留一个。

## 四、核心预言 4.01% 的评估：强可证伪性设计与黑箱推导并存

4.01% 普适剩余质量是该体系最值得讨论的部分，需要分开评估它的两个侧面。

**设计侧值得肯定**：预言"任意材质、任意形状，一阶相变后剩余质量恒为静质量的 4.01%"，数值精确到小数点后两位，明确给出失效阈值（偏差 >0.1% 模型失效，零变化则机制崩塌），配套万元级装置与七重排他验证。这符合波普尔意义上的强可证伪设计，在非主流理论中十分罕见，方法论姿态值得称道。

**推导侧是黑箱**：文章没有展示从三公理到 4.01% 这个具体数值的任何推导步骤。参数共振（马蒂厄方程）是已知数学，质量拓扑相变是概念假设，两者如何结合产生"与材质无关的普适常数 4.01%"，中间链条完全缺失。黑箱预言的强证伪性与弱解释力并存：它要么是重大发现，要么是数字巧合，文本没有提供区分两者的途径。更关键的是文章自述的辩护空间："若测量值接近但略有偏差，理论仍可通过高阶相变未完全触发进行有限度的辩护"，这削弱了刚性的证伪承诺，使 4.01% 的强证伪在实际执行中退化为可谈判的证伪。

## 五、各"原创突破"的科学审查

1. **精细结构常数的 $\pi$ 级数展开（2.22 ppm 匹配）**：典型的数字巧合陷阱。任何实数都可以事后构造出多种级数展开，历史上爱丁顿的 $1/137$ 猜测、Wyler 公式等经验公式都曾精确匹配而后被弃。文章自承"完整无穷级数的收敛性、更高阶系数的确定规则仍有待研究"，等于承认级数缺乏系统推导，2.22 ppm 的匹配不构成第一性解释的证据。
2. **等效原理的算子证明**：把惯性质量与引力质量定义为两个响应算子的本征值，宣称耦合常数完全相同故恒等（$m_i \equiv m_g$）。若两个算子的耦合常数相同是被假设进去的（同一螺旋通量拓扑荷），则等价关系是定义的重言，证明是循环的。等效原理作为广义相对论的实验基石已有大量检验，把它降为定理需要展示算子定义中不预设结论的推导。
3. **规范群 $U(1)\times SU(2)\times SU(3)$ 的拓扑导出**：最宏大的声称（从螺旋时空拓扑自然得出标准模型规范群），但文章未给出任何推导示意。从连续几何的挠率结构自然涌现出规范群在数学上是非平凡的（需要纤维丛、示性类等工具），"自然结果"四个字承载不了这个结论。
4. **涡旋引力方程 $\nabla\times\boldsymbol{G} \propto -\partial\boldsymbol{B}/\partial t$**：若时变磁场可直接激发人工引力场，该效应在实验室尺度应早已被观测到（强磁场装置普遍存在），文章未解释现有实验中该效应为何不可见，也未给出与已有引力实验约束（如扭秤对等效原理的检验）的定量兼容分析。
5. **GNSS 0.26% 残差归因与亚毫米级定位声称**：GNSS 相对论修正（引力红移约 45 $\mu$s/天）的残差受电离层、对流层、多径等多因素限制，把 0.26% 系统性残差单一归因于螺旋时空内禀拓扑常数缺乏排他性论证；单点定位从厘米级到亚毫米级的声称（两个数量级提升）远超当前 GNSS 物理极限的通行估计，需要与误差预算文献逐项对照，而文章没有提供。

## 六、方法论层面的评估

1. **自我综述的信息不对称**：评估依据的是作者本人写的推介性综述，"首次提出"高频出现，优势自我罗列，局限自我声明的口径也由作者控制。独立评估必须等到预印本原文与第三方验算可查。
2. **50 天 89 篇论文的产出模式**：高产出本身不构成问题，但伴随"覆盖从常数到宇宙学再到意识宗教的全领域"属于典型的覆盖面过宽信号。成熟理论通常聚焦少数可检验预言，全领域解释是民间科学体系的常见特征。
3. **借主流之短的修辞**：文章以弦论低能可证伪性极低衬托自身桌面可检验，以堪比迈克尔逊-莫雷实验类比 4.01% 验证。这些类比有宣传价值，没有论证价值，弦论难以检验不构成另一个理论成立的理由。
4. **学术诚实性的部分兑现**：明确标注继承张祥前、区分实证与思辨、承认预印本地位与零实验支撑，这些在民间科学文本中罕见，应予承认。但诚实标注与理论成立是两回事，前者提高讨论价值，后者仍取决于实验。

## 七、总体结论

**定位**：计立伟体系是当前中国民间统一场论谱系（张祥前 $\rightarrow$ 计立伟）中形式化程度最高、可检验性设计最强的版本，在民间科学光谱上处于值得严肃检验其预言的特殊位置，其 4.01% 预言是少数具有真实证伪内容的非主流主张。

**科学上仍未成立**，理由有三：其一，底层公设（空间点以矢量光速做圆柱螺旋运动）无任何独立经验基础，整个理论大厦悬于一个未经验证的形而上学前提，这与张祥前及所有民间科学理论共享的困境并无本质不同；其二，核心预言的推导链条未公开可验（4.01% 的黑箱、规范群导出的缺失、等效原理证明的循环风险）；其三，零第三方复现，且文章自留的"高阶相变未完全触发"辩护空间削弱了其强证伪承诺。

**方法论贡献可保留**：把裁决权交给万元级桌面实验、给出刚性失效阈值、明确标注思辨与实证边界，这三条路径即使理论整体失败，也对民间科学的自我规范具有示范价值。

**一句话定性**：计立伟体系是穿着现代理论物理外衣、拥有真实可检验预言的前范式理论；其形式已入流，其公设未落地，其预言在等待实验，其结论在证据面前悬置。它比张祥前更接近科学，但接近不等于到达，4.01% 的实验结果将是这个体系命运的唯一裁决者。

## 八、与天行新学的关系

两套体系在"质量几何化/拓扑化"与"螺旋几何为底层"方向上同路，但天行新学的公理是心物波粒二象（含不可形式化的心侧能动性），计立伟是纯物理实在论；天行新学的质量机制给出 $\omega_0 \sim \sqrt{\kappa_\phi}$ 与 $y_f = \sqrt{2}\hbar\sqrt{\kappa_\phi}/v$ 等可计算关系，计立伟的关键预言则悬于黑箱推导。前者把验证分散到多领域定量关系，后者把命运押在单一数值（4.01%）上。详细对照见同目录《方案简介与评估.md》第八节。
