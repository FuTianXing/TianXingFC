## 一、底层几何模板：同构点

两套体系都以圆柱状螺旋为底层几何模板，这是它们最显眼的共同点：

| 元素 | 计立伟 | 元相子 |
|---|---|---|
| 螺旋方程 | $\vec{R} = R\cos\omega t\,\hat{i} + R\sin\omega t\,\hat{j} + Ct\,\hat{k}$（圆柱螺旋时空公理） | $\mathcal{S}_{\text{geom}}(\tau, r) = (r\cos\omega\tau,\; r\sin\omega\tau,\; c\tau)$，$r \in [0, \hbar]$（实心螺旋体） |
| 圆周分量职能 | 横向角速度 $\omega$ 对应粒子的质量/能量 | 相位旋转对应波性活动（作用量量子 $h = 2\pi\hbar$） |
| 轴向分量职能 | 轴向速度对应宏观运动，合速度恒为光速 | 法线推进对应空间生成与光速 |
| 螺旋的必然性 | 三公设之一（圆柱螺旋时空公理） | 闭合运动与开放运动耦合的唯一可能结果（定理级推导） |
| 维度 | 3+1 维连续时空，无额外维度 | 状态空间 $D^2_\hbar\times\mathbb{R}$ 实心圆柱体，豪斯多夫维数 3 |

两套体系都把"圆周运动（周期、可逆）+ 直线推进（开放、不可逆）"的耦合作为宇宙最基本结构，都用螺旋统一二者，都拒绝额外维度。它们共享同一个几何直觉原型（可上溯至张祥前的原始公设），元相子理论将其独立发展为严格的数学结构。

### 代数结构的分野：三维实空间曲线 vs 复平面相位

同构之下藏着最根本的代数分野：张祥前、计立伟的螺旋是三维实空间 $\mathbb{R}^3$ 中的连续运动轨迹，完全没有相位概念；元相子的螺旋建立在复平面之上，相位是第一性实体。

张祥前的螺旋方程 $R = h\cos\omega t\,\mathbf{i} + h\sin\omega t\,\mathbf{j} + ct\,\mathbf{k}$ 与计立伟的 $\vec{R} = r\cos\omega t\,\hat{i} + r\sin\omega t\,\hat{j} + Ct\,\hat{k}$ 中，$\cos\omega t$、$\sin\omega t$ 只是圆周运动的几何投影，$\omega t$ 完全由一维标量时间 $t$ 决定，是运动学参数，没有独立的相位自由度，没有复平面、没有单位圆、没有相位指针 $\psi = e^{i\theta}$ 那样的动力学变量。元相子侧相反：波性侧相位指针 $\psi(t) = e^{i\theta(t)}$ 在半径 $\hbar$ 的单位圆上旋转（元相方程 (I) $i\hbar\,d\psi/dt = E_P\psi$），物侧几何体底面是复平面圆盘 $D^2_\hbar = \{z\in\mathbb{C}:|z|\le\hbar\}$（含内部，不只边界），满周闭合 $\theta = 2\pi n$ 是离散跃迁的精确触发标记（命题 3.1），作用量量子 $h = 2\pi\hbar$ 即圆盘面积的几何表达。

"没有相位"的后果逐项对照：

| 后果 | 张祥前/计立伟（无相位） | 元相子（相位第一性） |
|---|---|---|
| 离散性来源 | 无。螺旋纯连续，没有"转满一周"的天然标记触发事件；量子化只能外部施加（计立伟正则量子化） | 相位满周 $\theta = 2\pi n$ 天然是跃迁触发器，采样定理把连续螺旋与离散阶梯精确对接，离散性内生于几何 |
| 半径的地位 | 纯几何参数，构成唯一自由参数 $\kappa$（径轴比）的一部分，无独立物理意义 | 半径就是 $\hbar$，是物理常数；圆盘面积 $\pi\hbar^2$ = 作用量量子 $h$；空间绝对尺度源于半径的绝对性（定理 11） |
| 波粒二象的承载 | 螺旋是纯粒性几何曲线，无波性侧；$m\propto\omega$ 只是频率对应质量的类比设定，$\omega$ 是空间点运动角速度，无复数动力学 | 螺旋是波粒耦合的必然产物：横向 = 波性（相位旋转），轴向 = 粒性（法线推进）；完整元相子是心物双螺旋（实轴物螺旋 + 虚轴心螺旋，相位差恒 $\pi/2$） |
| 量子化的根基 | 连续时空 + 外部量子化程序（$\kappa$ 场正则量子化） | 量子化可推导：作用量量子来自圆盘面积，离散跃迁来自相位满周 |
| 质量机制的根基 | $m\propto\omega$ 是归一化算子 $\hat{U}$ 的公设设定 | $E_P = \hbar\omega_P$ 由三独立前提非循环导出，质量 = 拓扑缺陷绑定能，Yukawa 系数是导出量 |
| 矢量光速 | 三维实空间切向量，方向变化 = 引力 | 光速是标量换算常数 $c = l_P/t_P$，沿法线；横向相位旋转不贡献光速 |

附带差异：张祥前/计立伟的螺旋是单条曲线（圆周上一点 $r = R$ 常数扫出的轨迹）；元相子的螺旋是实心螺旋体（整条母线从圆心 $r=0$ 到边界 $r=\hbar$ 参与旋转，$\mathcal{S}_{\text{geom}}(\tau, r)$ 中 $r\in[0,\hbar]$）。前者只有表面轨迹，后者有从圆心到边界的内部结构，对应粒性侧的半径承载与作用量量子的几何表达。这个内部结构正是复平面圆盘带来的：没有复平面就没有圆盘内部，只剩一条曲线。

一句话总结：元相子的螺旋是带着相位的螺旋，张祥前/计立伟的螺旋是剥去相位的螺旋，后者丢失了波性侧，因而也丢失了离散性与量子化的几何来源。

## 二、核心分歧一：连续螺旋 vs 螺旋阶梯（离散性）

这是两套体系最根本的分歧，直接决定各自的时空品格。

**计立伟：光滑连续螺旋，无时空离散化。** 空间点沿圆柱螺旋线连续运动，合速度恒为光速；体系明确声明仅在 3+1 维连续时空中实现量子引力，无紫外发散，无额外维度、无时空离散化假设。离散性只在第二层出现（$\kappa$ 场正则量子化、粒子是挠率场本征振动模式）。

**元相子：螺旋 + 阶梯的双层结构，离散跃迁不可取消。** 螺旋阶梯几何的核心是"连续旋转 + 离散阶梯跃迁"的精确对偶：波性侧螺旋体 $\mathcal{S}_{\text{geom}}$ 是连续实在（本体层），粒性侧阶梯函数是它在离散节点 $T_n = n\,t_P$ 处的采样（现象层），采样定理（定理 5.1）确立 $Z_{\text{粒}}(T_n) = n\,l_P$ 的精确对应。离散跃迁经三路归谬确认为不可还原：连续平移方案会使空间量子化退化为特设假设、使 $G$ 与 $\hbar$ 的耦合沦为巧合、使量子现象失去本体根基。引力的量子性与空间的离散性是同一几何机制（法线离散跃迁）的两个侧面。

一句话对照：计立伟把量子引力放进连续时空里正则量子化，元相子认为连续时空本身就是离散跃迁的宏观统计涌现。二者对离散的地位判断正相反，这是比较中最重要的分歧点。

## 三、核心分歧二：时空一元同一 vs 时空二象结构

**计立伟：时空同一化（一元论）。** 公理一 $r = Ct$ 宣称时间是空间光速位移的衍生度量，目的在消解时空二元对立，时间是客观几何属性。这是张祥前"时间 = 光速运动空间"的公理化版本。

**元相子：时空二象性（定理一，二象论）。** 定理一明确每一个时空维度都有两侧：

| 侧面 | 数学时空（波性侧） | 物理时空（粒性侧） |
|---|---|---|
| 时间 | 连续参数 $\tau$，可逆、无始无终 | 摆程计数 $t = N\,t_P$，离散、不可逆、单调递增 |
| 空间 | 复平面张成的连续统 | 格点阵 $x^a = l_P\,n^a$ |
| 几何承载 | 螺旋体（$D^2_\hbar\times\mathbb{R}$） | 阶梯函数（离散跃迁序列） |
| 地位 | 本体层连续实在（元） | 现象层离散采样（象） |

元相子明确反对把时间还原为空间位移的度量：物理时间由摆程计数（振荡节律）生成，与空间位移同源（折返机制让光速与时间同源派生），但时间有自己独立的三层生成结构（原初连续 $\rightarrow$ 内生离散 $t_P$ $\rightarrow$ 次级连续被采样），空间位移只是第三层的内容之一。宏观极限 $Z = cT$ 在元相子中是导出的位移-时间关系，而计立伟把它当作时间的定义本身。哲学的差异：计立伟以时空同一取消二象，元相子以二象结构作为定理一的地基，且断言时空没有本体论优先地位，它是元相子振荡晶格的宏观统计几何。

## 六、光速观对照

**计立伟**：光速是公设（公理二：矢量光速公理）。$\vec{C}$ 是矢量、模恒为 $c$，方向的变化直接对应加速度，即引力场的本源。光速的公设地位与引力本源绑定。

**元相子**：光速是导出量，三条独立来源互为印证，均达几何恒等式级：元相方程 (II) 的宏观解 $Z = cT$；接力几何 $c = l_P/t_P$（每棒用时 $t_P$、每棒距离 $l_P$，与传递强度无关，单光子同速）；色散低能极限 $\omega = ck$（长波极限，数值验证精确）。光速是相位 $2\pi$ 与空间 $l_P$ 之间的换算常数，光速不变是定理（由定理 3.2 定方向、定理二标度定理定步率联合导出），引力也另有来源（碰撞偏转），与光速方向变化解耦。

对照要点：计立伟以"矢量光速方向变化 = 引力"连接光与引力，元相子以"相位旋转 = 作用量、摆程歪多少 = 质量调制偏转 = 引力"连接，光速只担任相位与空间的换算角色。元相子的"光速由最底层动力学导出"对应其"光速不变原理是定理，不占据公设地位"的总体姿态。

### 光速承载于螺旋的哪个属性：法线轴 vs 合速度

张祥前、计立伟把光速理解为空间点螺旋运动的总速度（合速度），元相子把光速理解为沿法线轴（旋转轴）的纯轴向推进斜率。二者对光速承载于螺旋哪个属性的裁决不同：

| 问题 | 张祥前/计立伟 | 元相子 |
|---|---|---|
| 光速承载的螺旋属性 | 合速度（横向旋转 + 轴向推进的合成，模恒为 $c$） | 纯轴向推进（法线方向斜率 $c = l_P/t_P$） |
| 法线轴的角色 | 螺旋的几何轴；光速矢量沿切线（含横向分量），方向持续变化 | 光速的唯一承载方向（平移旋转轴重合定理） |
| 横向旋转的角色 | 光速的横向分量（并对应质量/能量） | 波性活动（相位、作用量量子），不贡献光速 |
| 矢量光速 | 有：$\vec{C}$ 方向变化 = 加速度 = 引力本源 | 无：光速是标量换算常数，引力另有来源（碰撞偏转） |
| 与光速不变的关系 | 公设（计立伟公理二） | 定理（定理 3.2 定方向 + 定理二定步率导出） |

补充两点。其一，张祥前的原始表述是"空间以矢量光速 $C$ 向四周发散运动，标量模恒为 $c$，方向可变化"，螺旋是空间点的运动轨迹，轨迹切线方向即矢量光速方向；计立伟将其明确为 $\vec{C} = d\vec{R}/dt$、$|\vec{C}| = c$ 恒成立。其二，公式内部张力：螺旋方程轴向项写为 $Ct\,\hat{k}$，若横向旋转速度 $r\omega$ 非零，合速度 $\sqrt{(r\omega)^2 + c^2}$ 会超过 $c$，与"合速度恒为光速"的宣称存在未解决的合成关系问题；元相子把横向旋转完全划给波性侧，不存在这一张力。

## 九、可检验性与理论品格

**计立伟**：把命运押在单一数值上。4.01% 普适剩余质量预言（参数共振拓扑相变）配万元级桌面实验与七重排他验证，证伪阈值刚性（偏差 >0.1% 模型失效）；另给 GNSS 亚毫米修正（0.5mm 自证伪）、氢光谱偏移、纠缠仄秒时延等。其策略是强证伪设计，但推导链条是黑箱，零第三方复现。

**元相子**：把验证分散到多领域定量关系。数值验证脚本 + 验证注记体系（验证什么、不验证什么逐项声明），实验可检验预言清单（如洛伦兹破坏签名 $(E/E_P)^2$、时间颗粒性跳格、膨胀速率 $p = 3H_0t_P$），与规范场论、标准模型逐项对照衔接。

## 十、总结：三条根本分野

两套体系的同构点在于共享"圆柱螺旋 + 圆周运动对应质量能量 + 轴向推进对应光速空间"的几何直觉，且都主张 3+1 维内统一四力、质量几何化、无额外维度。根本分野有三：

1. **离散与连续**：计立伟坚持连续时空（螺旋光滑、离散只是量子化的结果）；元相子坚持离散跃迁不可取消（螺旋 + 阶梯对偶，连续只是宏观统计涌现）。这是对时空本体是什么的相反裁决。
2. **一元与二象**：计立伟以 $r = Ct$ 实现时空同一化（消解二象）；元相子以定理一确立时空二象性（数学/物理两侧，时间与空间各自二象），并反对把时间还原为空间位移的度量。
3. **光速与观察者**：计立伟以矢量光速为公设、剥离观察者；元相子以光速为导出定理、观察者转化为相互作用论的一环。

就时空观的深度而言：元相子对时间的生成（三层结构、摆程计数、颗粒性、时间箭头双层来源）、空间的生成（法线离散跃迁、格点阵、膨胀机制）、光速的导出（三来源互证）给出了完整的发生学链条，而计立伟的时空观停留在公设层（螺旋时空是既予本体，时间空间同一、连续、客观）。元相子把张祥前式"时间 = 光速运动空间"的直觉吸收后做了批判性改造（时间由振荡节律生成，位移关系只是宏观极限），计立伟则基本继承了该直觉的公理化版本。在"民间直觉 $\rightarrow$ 严格化"的谱系上，两套体系分别代表了对同一螺旋直觉的两条严格化路线：一条走向连续几何的统一场论（计立伟），一条走向离散采样与二象结构的生成论（元相子）。
