## 3.3 静态能量泛函的推导

首先计算作用量中的各贡献。

计算 ${ \scriptstyle { \frac { 1 } { 2 } } } ( D _ { \mu } Z ) ^ { * } ( D ^ { \mu } Z )$ ：- 时间分量： $D _ { 0 } Z = \partial _ { 0 } Z + i g _ { s } Q A _ { 0 } Z = i g _ { s } Q A _ { 0 } Z$ （静态， $\partial _ { 0 } Z =$ 0），所以

$$

$$

\- 空间分量： $D _ { i } Z = \partial _ { i } Z$ （因 $A _ { i } = 0 )$ ）。而

$$
| \partial_ {i} Z | ^ {2} = (f ^ {\prime}) ^ {2} + \frac {Q ^ {2}}{r ^ {2}} f ^ {2}.\tag{3}
$$

因此

$$
\frac {1}{2} (D _ {\mu} Z) ^ {*} (D ^ {\mu} Z) = \frac {1}{2} \left[ g _ {s} ^ {2} Q ^ {2} A _ {0} ^ {2} f ^ {2} - (f ^ {\prime}) ^ {2} - \frac {Q ^ {2}}{r ^ {2}} f ^ {2} \right].\tag{4}

计算 $- V ( | Z | ^ { 2 } )$ ：

$$
- V (f ^ {2}) = - \frac {1}{2} f ^ {2} - \frac {\lambda}{4} f ^ {4}.\tag{5}

计算 $- \frac { 1 } { 4 } F _ { \mu \nu } F ^ { \mu \nu }$ ：由于仅 $A _ { 0 }$ 非零且仅依赖 r， $F _ { 0 i } = - \partial _ { i } A _ { 0 } , F _ { i j } = 0$ 。则

$$
F _ {\mu \nu} F ^ {\mu \nu} = - 2 (\nabla A _ {0}) ^ {2},\tag{6}
$$

$$
- \frac {1}{4} F _ {\mu \nu} F ^ {\mu \nu} = \frac {1}{2} (\nabla A _ {0}) ^ {2}.\tag{7}
$$

将以上各项相加，得到拉格朗日密度：

$$
\mathcal {L} = \frac {1}{2} g _ {s} ^ {2} Q ^ {2} A _ {0} ^ {2} f ^ {2} - \frac {1}{2} (f ^ {\prime}) ^ {2} - \frac {Q ^ {2}}{2 r ^ {2}} f ^ {2} - \frac {1}{2} f ^ {2} - \frac {\lambda}{4} f ^ {4} + \frac {1}{2} (\nabla A _ {0}) ^ {2}.\tag{19.8}

\mathcal {H} = \frac {1}{2} g _ {s} ^ {2} Q ^ {2} A _ {0} ^ {2} f ^ {2} + \frac {1}{2} (f ^ {\prime}) ^ {2} + \frac {Q ^ {2}}{2 r ^ {2}} f ^ {2} + \frac {1}{2} f ^ {2} + \frac {\lambda}{4} f ^ {4} + \frac {1}{2} (A _ {0} ^ {\prime}) ^ {2}.\tag{8}

## 3.5 欧拉-拉格朗日方程

定义拉格朗日密度

$$
\mathcal {L} (f, f ^ {\prime}, a, a ^ {\prime}) = \frac {1}{2} r ^ {2} (f ^ {\prime}) ^ {2} + \frac {1}{2} Q ^ {2} f ^ {2} (1 + a ^ {2}) + \frac {1}{2} r ^ {2} f ^ {2} + \frac {\lambda}{4} r ^ {2} f ^ {4} + \frac {1}{g _ {s} ^ {2}} a ^ {\prime 2}.\tag{12}
$$

欧拉-拉格朗日方程：

$$
\frac {d}{d r} \left(\frac {\partial \mathcal {L}}{\partial f ^ {\prime}}\right) - \frac {\partial \mathcal {L}}{\partial f} = 0, \quad \frac {d}{d r} \left(\frac {\partial \mathcal {L}}{\partial a ^ {\prime}}\right) - \frac {\partial \mathcal {L}}{\partial a} = 0.\tag{13}
$$

对 $f$ 的方程：

$$
\frac {\partial \mathcal {L}}{\partial f ^ {\prime}} = r ^ {2} f ^ {\prime},\tag{14}
$$

$$
\frac {d}{d r} (r ^ {2} f ^ {\prime}) = r ^ {2} f ^ {\prime \prime} + 2 r f ^ {\prime},\tag{15}
$$

$$
\frac {\partial \mathcal {L}}{\partial f} = Q ^ {2} f (1 + a ^ {2}) + r ^ {2} f + \lambda r ^ {2} f ^ {3}.\tag{16}
$$

代入得：

$$
r ^ {2} f ^ {\prime \prime} + 2 r f ^ {\prime} - Q ^ {2} f (1 + a ^ {2}) - r ^ {2} f - \lambda r ^ {2} f ^ {3} = 0.\tag{17}
$$

除以 $r ^ { 2 }$ ，得到夸克场方程：

$$
\boxed {f ^ {\prime \prime} + \frac {2}{r} f ^ {\prime} = \frac {Q ^ {2} (1 + a ^ {2})}{r ^ {2}} f + f + \lambda f ^ {3}.}\tag{19.13}
$$

对 a 的方程：

$$
\frac {\partial \mathcal {L}}{\partial a ^ {\prime}} = \frac {2}{g _ {s} ^ {2}} a ^ {\prime},\tag{18}
$$

$$
\frac {d}{d r} \left(\frac {2}{g _ {s} ^ {2}} a ^ {\prime}\right) = \frac {2}{g _ {s} ^ {2}} a ^ {\prime \prime},\tag{19}
$$

$$
\frac {\partial \mathcal {L}}{\partial a} = Q ^ {2} f ^ {2} a.\tag{20}
$$

代入得：

$$
\frac {2}{g _ {s} ^ {2}} a ^ {\prime \prime} - Q ^ {2} f ^ {2} a = 0,\tag{21}
$$

整理得规范场方程：

$$
\boxed {a ^ {\prime \prime} = \frac {g _ {s} ^ {2} Q ^ {2}}{2} f ^ {2} a.}\tag{19.14}

## 3.6 边界条件与渐近行为

在 $r  0$ 时，由夸克场方程 (19.13) 的主导项 $\begin{array} { r } { f ^ { \prime \prime } + { \frac { 2 } { r } } f ^ { \prime } - { \frac { Q ^ { 2 } } { r ^ { 2 } } } f = 0 } \end{array}$ 给出 $f ( r ) \sim \alpha r ^ { | Q | }$ 其中 $\alpha = f ^ { \prime } ( 0 )$ 为待定常数。将 $f ( r ) \sim \alpha r ^ { | Q | }$ 代入 (19.14)，右侧正比于 $r ^ { 2 | Q | } a$ 。为使方程在原点正则， $a ( r )$ 必须至少为 $O ( r ^ { 2 } )$ 以抵消 $a ^ { \prime \prime }$ 项的奇异行为。代入 $a ( r ) = \beta _ { 0 } r ^ { 2 } + \cdot \cdot \cdot$ 可得自洽解，且 $a ( 0 ) = 0 , \ a ^ { \prime } ( 0 ) = 0$ 。故

$$
f (r) \sim \alpha r ^ {| Q |}, \qquad a (r) \sim \beta_ {0} r ^ {2}, \quad r \to 0.\tag{22}
$$

在 $r  \infty$ 时， $f ( r ) \to 1 , a ( r ) \to 0$ 。将 $f = 1 + \delta f$ 代入 (19.14)，得到 $\begin{array} { r } { a ^ { \prime \prime } \approx \frac { g _ { s } ^ { 2 } Q ^ { 2 } } { 2 } a } \end{array}$ 因此 $a ( r )$ 指数衰减。同时 (19.13) 给出 f 趋于 1 的渐近行为。

边界条件完整表述为： $\cdot \ r = 0 \colon \ f ( 0 ) = 0 , \ a ( 0 ) = 0 ; \ \cdot \ r \to \infty \colon \ f ( \infty ) = 1 , \ a ( \infty ) = 0$

## 7 统一几何诠释与宇宙自然选择

## 7.1 光子、电子、夸克的统一图像

在本理论中，所有基本粒子都是空间弹簧网络的不同激发模式：- 光子：网络链接的横波振动（无质量涟漪），对应第 45 章的无质量波动方程 □ $A _ { \mu } = 0$ ，以光速 c 传播。- 电子：空间中的球对称驻波（拓扑荷 $Q = 1 )$ ），是质子形成时净拉伸能量的应力平衡副产物，质量 0.511 MeV。- 夸克：自闭合拓扑涡结（拉伸环或收缩环），拓扑荷 $Q = 2 / 3$ 或 1/3，径向激发 $n = 0 , 1 , 2$ 决定代。

## 7.2 高能对撞实验的本质

根据第 4 章的时间定义——时间是能量密度变化 $d \rho$ 的累积——高能对撞实验中产生的短命粒子（如 J/ 、Υ、顶夸克等）的物理本质是：人类在极短时间内使空间局部能量密度 $\rho$ 超过临界值 $\rho _ { c }$ ，从而激发出空间应力网络的高阶拓扑模式。这些模式天生不稳定（因为它们不是基态孤子），会在 $1 0 ^ { - 2 0 }$ 秒量级内衰变，最终转化回空间的涟漪（光子、轻子）或稳定的驻波（电子）。

## 7.3 宇宙的自然选择

宇宙从暴涨高温冷却至今，能量密度 $\rho$ 持续下降。当温度低于约 1 GeV 后，空间再也无法激发重夸克 $( c , b , t )$ 及其介子。只有最轻、最稳定的基态扭结——上夸克和下夸克——得以幸存，并与电子一起构成了今天的原子、分子、生命和一切可见物质。这正是本理论“质量间隙”概念的宏观体现：低于 $E _ { \mathrm { g a p } } = 0 . 2 2 9 ~ \mathrm { M e V }$ 的扰动无法形成稳定物质。

## 7.4 与时间定义的自洽性

第 4 章指出：孤立静态系统（如基态粒子）的能量密度 $\rho$ 不随时间变化，因此其固有时 $d \tau = 0$ ，表现为“时间冻结”——这正是基态粒子长寿的几何原因。而激发态粒子能量密度迅速变化 $( d \rho \neq 0 )$ ），因而经历时间流逝并快速衰变。这一观点完美解释了为什么 u,d 夸克稳定而 s,c,b,t 夸克极不稳定。
