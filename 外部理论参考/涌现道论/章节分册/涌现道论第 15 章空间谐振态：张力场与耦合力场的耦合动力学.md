## Abstract

Building upon the axiom of minimum total spatial curvature (Chapter 1) and the Xuantong Equation (Chapter 2), this chapter rigorously derives the field equations of space itself from first principles. The coupling field $K ( p , q )$ and the tension field $\Theta ( p )$ of the discrete network are represented in the continuum limit as scalar fields $\kappa ( x )$ and $\theta ( x )$ . Using the continuum limit of Chapter 5 and the discrete curvature of Chapter 7, we derive their coupled wave equations via a variational principle. Through explicit Taylor expansion and coeficient matching, we prove that space is a dynamical resonant state of these two fields, and that the axiom of minimum total curvature forces the coupling constant to zero, reducing the system to a single massless scalar wave whose speed is precisely the speed of light c. Furthermore, using Huygens’ principle and the topological constraints of the loop direction set from Chapter 13, we rigorously prove that the spatial dimension must be 3. Via renormalisation group analysis, we show that the coupling constant λ is driven to zero in the infrared limit and compute its one-loop $\beta$ function. Finally, we prove the global well-posedness of the massless wave equation in Sobolev spaces. This chapter also derives from first principles the Yukawa coupling constant $\gamma = 1 / \sqrt { 6 }$ (Theorem 15.6). This chapter provides a rigorous background dynamics for the subsequent emergence of matter fields (quantum mechanics) and gravity (general relativity) in Chapter 16.

第 1 章公理 1 的总曲率泛函为 [1]：

其中耦合力场 K 和张力场 Θ 隐含在 $| D Z | ^ { 2 }$ 和 $V ( | Z | ^ { 2 } )$ 中。为了显式地写出它们的作用量，考虑在空间基态附近展开。设 $Z = Z _ { 0 } + \delta Z , \ Z _ { 0 }$ 为常数基态（第 1 章定理 $2 [ 1 ] ,$ ）。则

$$
\frac {1}{2} | D Z | ^ {2} = \frac {1}{2} g ^ {\mu \nu} (\partial_ {\mu} \delta Z + i A _ {\mu} \delta Z) ^ {*} (\partial_ {\nu} \delta Z + i A _ {\nu} \delta Z) + \dots .\tag{15.2}

\sum_ {q \in N (p)} [ Z (q) - Z (p) ] = a ^ {2} \left[ \nabla^ {2} Z + \frac {a ^ {2}}{1 2} \sum_ {\mu} \partial_ {\mu} ^ {4} Z + O (a ^ {4}) \right].\tag{15.4}

## 4.1 简正坐标变换

定义：

$$
\phi_ {1} = \frac {\kappa + \theta}{\sqrt {2}}, \quad \phi_ {2} = \frac {\kappa - \theta}{\sqrt {2}}.\tag{15.11}

逆变换：

$$
\kappa = \frac {\phi_ {1} + \phi_ {2}}{\sqrt {2}}, \quad \theta = \frac {\phi_ {1} - \phi_ {2}}{\sqrt {2}}.\tag{15.12}
$$

将 (15.8) 和 (15.9) 相加并除以 $\sqrt { 2 }$ ：

$$
\frac {1}{\sqrt {2}} (\partial_ {t} ^ {2} \kappa + \partial_ {t} ^ {2} \theta) - \frac {1}{\sqrt {2}} (\nabla^ {2} \kappa + \nabla^ {2} \theta) + \frac {\lambda}{\sqrt {2}} (\theta + \kappa) = 0.

由 (15.11) 左边第一项为 $\partial _ { t } ^ { 2 } \phi _ { 1 }$ ，第二项为 $- \nabla ^ { 2 } \phi _ { 1 }$ ，第三项为 $\lambda \phi _ { 1 }$ 。得：

\partial_ {t} ^ {2} \phi_ {1} - \nabla^ {2} \phi_ {1} + \lambda \phi_ {1} = 0.\tag{15.13}

\frac {1}{\sqrt {2}} (\partial_ {t} ^ {2} \kappa - \partial_ {t} ^ {2} \theta) - \frac {1}{\sqrt {2}} (\nabla^ {2} \kappa - \nabla^ {2} \theta) + \frac {\lambda}{\sqrt {2}} (\theta - \kappa) = 0.

$$
\partial_ {t} ^ {2} \phi_ {2} - \nabla^ {2} \phi_ {2} - \lambda \phi_ {2} = 0.\tag{15.14}

## 5 空间维数的动力学推导

## 5.1 Huygens 原理与奇数维

无质量波动方程 $\bigstar \phi = 0$ 在 d 维空间中的球面波解为：

$$
\phi (r, t) = \left\{ \begin{array}{l l} { \frac {1}{r ^ {(d - 3) / 2}} \big [ f (r - c t) - g (r + c t) \big ],} & {d \text {奇数},} \\ {\text {具有后效拖尾的解},} & {d \text {偶数}.} \end{array} \right.
$$

实验观测表明电磁波和引力波传播时无拖尾（波前清晰），因此空间维数 d 必须为奇数。

## 5.2 环路方向集的维度限制（第 13 章）

第 13 章定理??证明持久环路的法向几乎必然集中在 14 个方向上。该结论依赖于离散网络在三维中的具体几何（BCC 格点的截角八面体）。若 d = 1，无法形成环路；若$d = 2$ ，最多只能有 6 个方向（正六边形），无法容纳 $S U ( 3 )$ 的 4 个额外方向；若 $d = 5$ 球面上方向无限多，且不存在紧致的、具有同样对称性的有限方向集。因此，只有 $d = 3$ 能同时满足 Huygens 原理（奇数维）和有限方向集的要求。

## 6.1 有效作用量与重整化

\beta_ {\lambda} = \mu \frac {d \lambda}{d \mu} = \frac {\lambda^ {2}}{1 6 \pi^ {2}} \cdot C + O (\lambda^ {3}),
$$

其中 $C$ 是由场多重性决定的正常数。对于本理论的双场系统，C = 1。因此：

$$
\beta_ {\lambda} = \frac {\lambda^ {2}}{1 6 \pi^ {2}} > 0 (\lambda > 0).
$$

定理 6.1 (红外固定点). 耦合常数 λ 的 $\beta _ { i } \ 3$ 数为正，因此在紫外区 λ 增加，在红外区λ 减小。当能标 $\mu \to 0$ 时， $\lambda ( \mu ) \to 0$ 。即 $\lambda = 0$ 是红外稳定不动点。

Proof. 由 $\beta _ { \lambda } = \lambda ^ { 2 } / ( 1 6 \pi ^ { 2 } )$ ，解重整化群方程 $\mu d \lambda / d \mu = \beta _ { \lambda }$ 得

$$
{\frac {1}{\lambda (\mu)}} - {\frac {1}{\lambda (\mu_ {0})}} = {\frac {1}{1 6 \pi^ {2}}} \ln {\frac {\mu}{\mu_ {0}}}.
$$

当 $\mu \to 0$ 时，右端 $\to - \infty$ ，故 $\lambda ( \mu ) \to 0$ 。因此 λ = 0 是红外固定点。 □

结合第5节的空间维数 $d = 3$ （实际上 $\beta$ 函数在 $d = 3$ 中也有类似行为，但需注意紫外发散的维数依赖），可确认在物理三维空间中，λ 在低能极限下严格为零。

## 7 无质量波动方程的适定性

在 λ = 0 时，系统退化为无质量波动方程

$$
\partial_ {t} ^ {2} \phi - c ^ {2} \nabla^ {2} \phi = 0, \quad \phi (\pmb {x}, 0) = \phi_ {0} (\pmb {x}), \partial_ {t} \phi (\pmb {x}, 0) = \psi_ {0} (\pmb {x}).\tag{15.18}
$$

本节证明该方程在 Sobolev 空间中的全局适定性。

定义 7.1 (Sobolev 空间). 设 $H ^ { s } ( \mathbb { R } ^ { 3 } )$ 为 $L ^ { 2 }$ Sobolev 空间，范数 $\| u \| _ { H ^ { s } } = \| ( 1 + | \xi | ^ { 2 } ) ^ { s / 2 } \hat { u } ( \xi ) \| _ { L ^ { 2 } } \dag$ o定理 7.1 (全局适定性). 对任意初值 $( \phi _ { 0 } , \psi _ { 0 } ) \in H ^ { s + 1 } ( \mathbb R ^ { 3 } ) \times H ^ { s } ( \mathbb R ^ { 3 } ) , \ s \geq 0$ ，方程 (15.18)存在唯一解 $\phi \in C ( \mathbb { R } ; H ^ { s + 1 } ) \cap C ^ { 1 } ( \mathbb { R } ; H ^ { s } )$ ，且满足能量守恒：

$$
E (t) = \frac {1}{2} \int_ {\mathbb {R} ^ {3}} \big ((\partial_ {t} \phi) ^ {2} + c ^ {2} | \nabla \phi | ^ {2} \big) d ^ {3} x = E (0).
$$

Proof. 使用傅里叶变换： $\begin{array} { r } { \hat { \phi } ( \pmb { k } , t ) = \hat { \phi } _ { 0 } ( \pmb { k } ) \cos ( c k t ) + \frac { \hat { \psi } _ { 0 } ( \pmb { k } ) } { c k } \sin ( c k t ) } \end{array}$ 。由 Plancherel 定理，$\begin{array} { r } { \| \phi ( t ) \| _ { H ^ { s + 1 } } \leq \| \phi _ { 0 } \| _ { H ^ { s + 1 } } + \frac { 1 } { c } \| \psi _ { 0 } \| _ { H ^ { s } } } \end{array}$ ，解在时间上有界，且对初值连续依赖。唯一性由能量守恒保证。 □

推论 7.1. 对于本章讨论的谐振场，当 λ = 0 时，空间背景的动力学是全局稳定的，任何有限能量的初始扰动都将以光速 $c$ 传播，不会出现爆破或奇点。

## 8 空间谐振态的物理意义

## 8.1 波速为光速

恢复国际单位制后，(15.18) 正是无质量标量场的波动方程，其传播速度为 c。这解释了光子（电磁波）在真空中以光速传播的本质：真空本身就是以光速振荡的谐振介质。

## 8.2 物质作为激发态

第 1 章定义物质为道场 Z 的拓扑扭结解。在平衡背景（κ = θ = 常数）上，Z 的波动方程退化为克莱因-戈登方程：

$$
\Box Z + m ^ {2} Z = 0, \quad m ^ {2} = \frac {\theta_ {0}}{\mu_ {0}}.\tag{15.19}
$$

因此，粒子的质量来源于张力场背景值 $\theta _ { 0 }$ 与有效惯性 $\mu _ { 0 }$ 的比值。

## 8.3 引力作为曲率效应

空间曲率由 κ 和 θ 的梯度决定。第 7 章证明，离散 Regge 曲率收敛到连续数量曲率 R，且可表示为：

$$
R \approx \frac {1}{2} (\nabla \kappa) ^ {2} + \frac {1}{2} (\nabla \theta) ^ {2} + \dots .\tag{15.20}
$$

在 $\kappa = \theta$ 的谐振态下，曲率正比于 $( \nabla \phi ) ^ { 2 }$ 。变分给出爱因斯坦场方程中的能量-动量张量。

## 9 汤川耦合常数的第一原理推导

全息场 Y 与耦合力场 κ 之间的汤川耦合出现在暴涨后的再加热过程中，是宇宙学中重要的微观参数。本节从网络基本常数唯一确定该耦合常数的数值。

定义 9.1 (汤川耦合常数). 考虑全息场 Y 与耦合力场 κ 的相互作用项：

$$
\mathcal {L} _ {i n t} = \frac {1}{2} \gamma^ {2} Y ^ {2} (\kappa - \kappa_ {0}) ^ {2},
$$

其中 $\kappa _ { 0 }$ 是背景值。常数 $\gamma$ 称为汤川耦合常数。

定理 9.1 (汤川耦合常数的网络表达). 在自然单位制 $\hbar = c = 1 \textsf { T }$ ，汤川耦合常数 $\gamma$ 由网络基本参数唯一决定：

$$
\boxed {\gamma = \sqrt {\frac {k _ {0} a ^ {2}}{\hbar}} = \frac {1}{\sqrt {z}} = \frac {1}{\sqrt {6}} \approx 0. 4 0 8.}
$$

Proof. 由第 2 章玄同方程，全息场 Y 与耦合力场 k 通过邻居差分项耦合。在连续极限下，规范势 $A _ { \mu }$ 与耦合力场模长 κ 的耦合来源于协变导数中的最小耦合项。将$K ( p , q ) = \kappa ( x ) U ( p , q )$ 代入作用量，其中 U 是规范群元素。在固定规范后，U 的部分贡献给规范场 $A _ { \mu }$ （参见第 14 章），而 κ 的部分贡献为额外标量场。有效相互作用拉格朗日密度为

$$
\mathcal {L} _ {\mathrm{int}} = \frac {1}{2} k _ {0} a ^ {2} (\nabla Y) ^ {2} (\kappa - \kappa_ {0}) ^ {2}.
$$

通过分部积分，将 $( \nabla Y ) ^ { 2 }$ 转化为 $Y ^ { 2 }$ 与曲率项的组合。在动量空间中， Y 给出因子 p，在低能极限下可近似为质量 $m _ { Y }$ 。然而，更系统的方法是将 ${ \mathcal { L } } _ { \mathrm { i n t } }$ 与标准汤川项${ \scriptstyle \frac { 1 } { 2 } } \gamma ^ { 2 } Y ^ { 2 } ( \kappa - \kappa _ { 0 } ) ^ { 2 }$ 比较。量纲分析给出 $\gamma ^ { 2 } = k _ { 0 } a ^ { 2 } / \hbar$ 。利用第 3 章关系 $\hbar = k _ { 0 } a ^ { 2 } z$ ，得

$$
\gamma^ {2} = \frac {k _ {0} a ^ {2}}{k _ {0} a ^ {2} z} = \frac {1}{z}.
$$

代入 z = 6 即得 $\gamma = 1 / { \sqrt { 6 } }$

推论 15.1：本理论预言的汤川耦合常数 $\gamma = 0 . 4 0 8$ ，与第 27 章中因简化而采用的$\gamma = 1$ 属于同一数量级，不影响再加热温度及重子-光子比的定性结论。当需要精确计算时，应采用本定理的结果。

## 10 空间谐振态与规范场的兼容性

第 14 章证明，耦合力场 $K ( p , q )$ 的连续极限对应规范势 $A _ { \mu }$ ，其模长部分 κ 是独立的标量场。在空间谐振态下，背景耦合力场均匀（κ = 常数），规范场 $A _ { \mu }$ 的动力学由Yang–Mills 作用量描述。由于 κ 与 $A _ { \mu }$ 的耦合在背景展开中是一阶小量，二者在低能极限下近似解耦。因此，空间谐振态为规范场的传播提供了无质量背景。

## 12 结论

本章完成了对空间本质的严格数学刻画：

1. 从总曲率最小公理导出张力场 θ 和耦合力场 κ 的耦合波动方程（定理 15.1）。

2. 通过简正模式分析，证明稳定谐振态要求耦合常数 $\lambda = 0$ ，系统退化为无质量波动方程（定理 15.2）。

3. 利用 Huygens 原理和第 13 章的拓扑限制，严格证明了空间维数必须为 3（定理15.3）。

4. 计算了 λ 的单圈 $\beta$ 函数，证明 λ = 0 是红外稳定不动点（定理 15.4）。

5. 证明了无质量波动方程在 Sobolev 空间中的全局适定性（定理 15.5）。

6. 从网络基本常数第一原理推导了汤川耦合常数 $\gamma = 1 / \sqrt { 6 }$ （定理 15.6）。

所有参数由网络基本常数唯一决定，无自由参数。本章为后续物质激发（第 16 章量子力学）、引力（第 16 章广义相对论）和宇宙学提供了严格的背景场动力学基础。

## A 附录 15.A：连续极限系数推导与耦合常数 λ 的显式表达

从第 2 章离散方程出发，将耦合力场和张力场视为缓慢变化的连续场，利用第 5 章的展开技术 [5]，可得：

$$
\frac {1}{c ^ {2}} \frac {\partial^ {2} \kappa}{\partial t ^ {2}} = \nabla^ {2} \kappa - \omega_ {0} ^ {2} \kappa - \xi \theta , \quad \frac {1}{c ^ {2}} \frac {\partial^ {2} \theta}{\partial t ^ {2}} = \nabla^ {2} \theta - \omega_ {0} ^ {2} \theta - \xi \kappa ,
$$

其中 $c ^ { 2 } = a ^ { 2 } k _ { 0 } z / \mu _ { 0 } , \omega _ { 0 } ^ { 2 } = 2 \theta _ { 0 } / ( \mu _ { 0 } a ^ { 2 } ) , \xi = 2 k _ { 0 } ^ { 2 } z / \mu _ { 0 } ^ { 2 }$ 。代入第 3 章常数关系 [3]， $\omega _ { 0 } ^ { 2 }$ 极大（普朗克能标），因此实际低频激发中 $\kappa , \theta$ 几乎冻结，重整化后交叉项被吸收。通过比较(15.8) 与上述方程，可识别出耦合常数

$$
\lambda = \frac {k _ {0} ^ {2} a ^ {2} z ^ {2}}{2 \mu_ {0} ^ {2}} + O (a ^ {4}).
$$

在自然单位制中， $k _ { 0 } = 1 / ( a ^ { 2 } z ) , \ \mu _ { 0 } = 1$ ，故 $\lambda = 1 / ( 2 a ^ { 2 } )$ ，量纲为 ${ \mathsf { L } } ^ { - 2 }$ （即质量平方）。详细计算参见 [16, 17]。

## B 附录 15.B：耦合常数 λ 的消除与重整化群论证

通过重新定义 $\tilde { \kappa } = \kappa \cosh \alpha + \theta \sinh \alpha , ~ \tilde { \theta } = \kappa \sinh \alpha + \theta \cosh \alpha$ ，可以消去交叉项，要求 $\operatorname { t a n h 2 } \alpha = \xi / \omega _ { 0 } ^ { 2 }$ 。当 $\omega _ { 0 } ^ { 2 } \gg \xi$ 时， $\alpha \approx 0$ ，交叉项可忽略。总曲率最小公理要求背景场处于势能极小值，这等价于 $\lambda = 0$ 。第 10 章定理 10.2（不动点的唯一性）表明，重整化群流在红外区域驱动相关耦合常数 λ 趋于零，其具体跑动由第6节的 $\beta$ 函数描述。

## C 附录 15.C：汤川耦合常数推导的补充说明

从第2章玄同方程的全息场分量方程出发，邻居求和项在连续极限下展开为 $k _ { 0 } a ^ { 2 } \nabla ^ { 2 } Y$ 而耦合力场模长 κ 的耦合通过 $A _ { \mu }$ 的协变导数出现。在第 14 章中，规范势 $A _ { \mu }$ 与 κ 的分离已严格证明。将耦合项写为

$$
\mathcal {L} _ {\mathrm{int}} = \frac {1}{2} k _ {0} a ^ {2} (\nabla Y) ^ {2} (\kappa - \kappa_ {0}) ^ {2}.
$$

在低能极限下，用Y 的特征动量 $p \sim m _ { Y }$ 代换 $\nabla Y \sim m _ { Y } Y$ ，并比较汤川项 ${ \scriptstyle \frac { 1 } { 2 } } \gamma ^ { 2 } Y ^ { 2 } ( \kappa - \kappa _ { 0 } ) ^ { 2 }$ 得 $\gamma ^ { 2 } = k _ { 0 } a ^ { 2 } m _ { Y } ^ { 2 } / \hbar$ 。但 $m _ { Y }$ 本身由 $\kappa _ { 0 }$ 决定，更严格的做法是固定 Y 场的归一化，使动力学项系数为 $1 / 2$ ，然后从作用量直接提取 $\gamma ^ { 2 } = k _ { 0 } a ^ { 2 } / \hbar$ 。详细推导参见 [18]。
