## 9.2 测量坍缩：时间涌现的必然结果

测量过程必然涉及系统与环境的能量交换 $( d \rho \neq 0 )$ ），从而导致时间涌现 $( d \tau > 0 ) ,$ 。具体地，由第 4 章局部相对时间定义 $\begin{array} { r } { d t _ { R } = \frac { \int _ { R } d \rho } { \int _ { R } \rho } t _ { P } } \end{array}$ ，测量时被测子系统的 $\textstyle \int _ { R } d \rho \neq 0$ ，因此该子系统的局部时间开始流动。时间之流将永恒的空间叠加态“投影”到单一历史分支，我们观察到的“随机坍缩”实为观察者自身处于时间之中的认知局限 [45, 46]。若站在无时间的全息场视角，坍缩并不存在，只有纯几何事实。

## 9.3 退相干与宏观经典性

由第 12 章流体动力学极限 [12]，宏观物体与环境强耦合导致退相干时间极短： $\tau _ { D } \sim$ $\hbar ^ { 2 } / ( \Gamma k _ { B } T ( \Delta x ) ^ { 2 } )$ ，其中 $\Gamma = k _ { 0 } a ^ { 2 } / \hbar$ 。对于宏观物体（m 1g，∆x 1cm，T 300K），$\tau _ { D }$ 远小于任何可观测时间，因此宏观叠加态迅速退相干，经典世界涌现 [45, 47]。退相干是时间涌现的副产物，无需引入坍缩假设。

结论：量子力学的全部“诡异”皆因时间而起。时间消则诡异灭。

移项得：

$$
i \hbar {\frac {\partial \psi}{\partial t}} = - \frac {\hbar^ {2}}{2 m} \nabla^ {2} \psi - \frac {1}{2} m c ^ {2} \psi + \eta .
$$

通常将静止能量吸收进势能 V 的定义（或视为常数背景），故最终有：

$$
i \hbar {\frac {\partial \psi}{\partial t}} = - \frac {\hbar^ {2}}{2 m} \nabla^ {2} \psi + V (\pmb {x}) \psi + \eta (\pmb {x}, t),\tag{B.4}
$$

其中 η 满足 $\langle \eta ( { \pmb x } , t ) \eta ^ { * } ( { \pmb y } , s ) \rangle = 2 \hbar \delta ( { \pmb x } - { \pmb y } ) \delta ( t - s )$ 。此即随机薛定谔方程。

## B.2 B.2 路径积分表示

将时间区间 $[ t _ { i } , t _ { f } ]$ 离散化为 N 等分，步长 $\Delta t = ( t _ { f } - t _ { i } ) / N$ ，记 $\psi _ { n } ( { \pmb x } ) = \psi ( { \pmb x } , t _ { n } )$ 方程 (B.4) 的离散形式为：

$$
i \hbar \frac {\psi_ {n + 1} - \psi_ {n}}{\Delta t} = - \frac {\hbar^ {2}}{2 m} \nabla^ {2} \psi_ {n} + V \psi_ {n} + \eta_ {n}.
$$

解出噪声：

$$
\eta_ {n} = i \hbar \frac {\psi_ {n + 1} - \psi_ {n}}{\Delta t} + \frac {\hbar^ {2}}{2 m} \nabla^ {2} \psi_ {n} - V \psi_ {n}.
$$

噪声的联合概率密度（高斯分布）为：

$$
P [ \eta ] \propto \exp \left(- \frac {1}{2 \hbar} \sum_ {n = 0} ^ {N - 1} \int d ^ {3} x | \eta_ {n} (\boldsymbol {x}) | ^ {2} \Delta t\right).
$$

代入 $\eta _ { n }$ 表达式，取连续极限 $N  \infty , \Delta t  0$ ，得 Onsager-Machlup 泛函：

$$
P [ \psi ] \propto \exp \left(- \frac {1}{2 \hbar} \int d t d ^ {3} x \left| i \hbar \partial_ {t} \psi + \frac {\hbar^ {2}}{2 m} \nabla^ {2} \psi - V \psi \right| ^ {2}\right).\tag{B.5}
$$

实施 Wick 旋转 $t = - i \tau$ （欧几里得时间），记 $\psi _ { E } ( { \pmb x } , \tau ) = \psi ( { \pmb x } , - i \tau )$ ，则 $\partial _ { t } = i \partial _ { \tau }$ 。代入(B.5) 得：

$$
\left| i \hbar (i \partial_ {\tau} \psi_ {E}) + \frac {\hbar^ {2}}{2 m} \nabla^ {2} \psi_ {E} - V \psi_ {E} \right| ^ {2} = \left| - \hbar \partial_ {\tau} \psi_ {E} + \frac {\hbar^ {2}}{2 m} \nabla^ {2} \psi_ {E} - V \psi_ {E} \right| ^ {2},
$$

此时指数为负实数，对应统计权重。为得到量子力学的概率幅，进行解析延拓：将噪声强度 h¯ 替换为 ih¯（Parisi-Wu 技巧）。于是指数变为 $\frac { i } { \hbar } S [ \psi _ { E } ]$ ，其中

$$
S [ \psi_ {E} ] = \int d \tau d ^ {3} x \left(\frac {1}{2} | \partial_ {\tau} \psi_ {E} | ^ {2} + \frac {\hbar^ {2}}{2 m} | \nabla \psi_ {E} | ^ {2} + V | \psi_ {E} | ^ {2}\right).
$$

回到实时间并约束到单粒子 $( { \boldsymbol { \psi } } ( \mathbf x , t ) = \delta ( \mathbf x - \mathbf q ( t ) ) )$ ），即得费曼路径积分：

$$
K (\boldsymbol {q} _ {f}, t _ {f}; \boldsymbol {q} _ {i}, t _ {i}) = \int_ {\boldsymbol {q} (t _ {i}) = \boldsymbol {q} _ {i}} ^ {\boldsymbol {q} (t _ {f}) = \boldsymbol {q} _ {f}} \mathcal {D} \boldsymbol {q} (t) \exp \left(\frac {i}{\hbar} \int_ {t _ {i}} ^ {t _ {f}} \left(\frac {1}{2} m \dot {\boldsymbol {q}} ^ {2} - V (\boldsymbol {q})\right) d t\right).\tag{B.6}
$$

## B.3 B.3 薛定谔方程与正则对易关系

从路径积分 (B.6) 的短时展开，考虑势能 V，短时传播子为：

$$
K (\boldsymbol {x}, t + \Delta t; \boldsymbol {y}, t) = \left(\frac {m}{2 \pi i \hbar \Delta t}\right) ^ {3 / 2} \exp \left(\frac {i m | \boldsymbol {x} - \boldsymbol {y} | ^ {2}}{2 \hbar \Delta t} - \frac {i}{\hbar} V (\boldsymbol {x}) \Delta t\right).
$$

令 ${ \pmb y } = { \pmb x } + { \pmb \xi }$ ，代入波函数演化公式 $\begin{array} { r } { \psi ( { \pmb x } , t + \Delta t ) = \int d ^ { 3 } y K \psi ( { \pmb y } , t ) } \end{array}$ ，将 $\psi ( { \pmb x } + { \pmb \xi } , t )$ 泰勒展开至二阶：

$$
\psi (\pmb {x} + \pmb {\xi}, t) = \psi (\pmb {x}, t) + \xi^ {i} \partial_ {i} \psi + \frac {1}{2} \xi^ {i} \xi^ {j} \partial_ {i} \partial_ {j} \psi + O (\xi^ {3}).
$$

利用高斯积分：

$$
\int d ^ {3} \xi e ^ {i m \xi^ {2} / (2 \hbar \Delta t)} = \left(\frac {2 \pi i \hbar \Delta t}{m}\right) ^ {3 / 2}, \quad \int d ^ {3} \xi \xi^ {i} e ^ {i m \xi^ {2} / (2 \hbar \Delta t)} = 0,
$$

$$
\int d ^ {3} \xi \xi^ {i} \xi^ {j} e ^ {i m \xi^ {2} / (2 \hbar \Delta t)} = \frac {i \hbar \Delta t}{m} \delta_ {i j} \left(\frac {2 \pi i \hbar \Delta t}{m}\right) ^ {3 / 2}.
$$

代入得：

$$
\psi (\pmb {x}, t + \Delta t) = \psi (\pmb {x}, t) + \frac {i \hbar \Delta t}{2 m} \nabla^ {2} \psi - \frac {i}{\hbar} V \psi \Delta t + O (\Delta t ^ {2}).
$$

取极限 $\Delta t \to 0$ ，得含时薛定谔方程：

$$
i \hbar \frac {\partial \psi}{\partial t} = \left(- \frac {\hbar^ {2}}{2 m} \nabla^ {2} + V (\boldsymbol {x})\right) \psi .\tag{B.7}
$$

由相空间路径积分（或直接对易关系计算）可得正则对易关系 $[ { \hat { x } } _ { i } , { \hat { p } } _ { j } ] = i \hbar \delta _ { i j }$ C
