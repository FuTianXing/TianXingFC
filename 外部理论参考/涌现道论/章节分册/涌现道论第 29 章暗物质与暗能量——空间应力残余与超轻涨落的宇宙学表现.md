凝聚态系统中观测到的“轴子绝缘体态”（如 $\mathrm { M n B i _ { 2 } T e _ { 4 } } )$ 发生在完全不同的能量尺度 $\mathrm { ( m e V - e V ) }$ ），与本理论预言的 $m _ { a } = 4 . 8 \times 1 0 ^ { - 1 1 } ~ \mathrm { e V }$ 能隙无直接数值关联。两者共享的是拓扑场论的数学结构（周期性势能、拓扑磁电效应），而非同一物理现象。本理论在此仅指出：主流粒子物理中作为基本粒子的轴子概念并非唯一可能；空间应力凝聚提供了另一种数学上等价但物理上不同的实现方式，其具体能标取决于空间应力网络的特征尺度。
