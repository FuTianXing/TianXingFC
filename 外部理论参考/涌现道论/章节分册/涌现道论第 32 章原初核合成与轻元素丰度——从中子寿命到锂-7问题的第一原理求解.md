## 4.2 从全息场方程导出有效势的微观机制

在本理论中，空间应力网络 $\Theta ( \mathbf { x } )$ 满足第 6 章的全息场方程：

$$

$$
\phi_ {2} (\mathbf {x}) \nabla^ {2} \psi_ {e} (\mathbf {x}) + 2 \nabla \phi_ {2} (\mathbf {x}) \cdot \nabla \psi_ {e} (\mathbf {x}) + \psi_ {e} (\mathbf {x}) V ^ {\prime \prime} (\Theta_ {\mathrm{bg}}) \phi_ {2} (\mathbf {x}) = 0.\tag{32.7}
$$

在核表面附近 $( r \sim R _ { 0 } )$ $\phi _ { 2 }$ 场的变化尺度远大于电子波长的尺度 $( L \sim 1$ fm， $\lambda _ { e } \sim$ 0.071 fm），因此 $\phi _ { 2 }$ 场在核尺度上是缓慢变化的。做平均场近似，忽略 $\nabla \phi _ { 2 } \cdot \nabla \psi _ { e }$ 项，保留 $\phi _ { 2 } \nabla ^ { 2 } \psi _ { e }$ 的主项，将式 (32.7) 重新整理为薛定谔方程的形式：

$$
- \frac {\hbar^ {2}}{2 m _ {e}} \nabla^ {2} \psi_ {e} + V _ {C} (r) \psi_ {e} + \gamma \phi_ {2} (\mathbf {r}) \nabla^ {2} \psi_ {e} (\mathbf {r}) = E \psi_ {e} (\mathbf {r}).\tag{32.8}
$$

其中 $\gamma$ 由网络基本常数决定，量纲分析给出 $\gamma \sim \hbar ^ { 2 } / ( 2 m _ { e } M _ { \mathrm { P l } } )$ 。将 ${ \nabla ^ { 2 } } \psi _ { e } / \psi _ { e }$ 视为有效势的乘数，定义：
