## 2.3.6 结论

质子和中子的质量完全由 $\Lambda _ { \mathrm { E D T } } .$ 、夸克质量差、电磁自能修正和空间应力非加和性修正决定。而 $\Lambda _ { \mathrm { E D T } }$ 本身已由第 22 章从网络常数第一原理导出，夸克质量由第 19 章第一原理计算，电磁自能和非加和性修正分别由第 33、24、14 章等联合导出（见附录35.A 和 35.B）。因此，质子和中子的质量是本理论的第一原理预言，而非实验输入。本小节同时也为第 10 节的交叉验证（路径一）提供了独立的数值支撑。

7 张弛公式： $\Phi _ { \bf n o w } = \Phi _ { \bf U V } \cdot e ^ { i \theta }$

## 7.1 命名

“张弛”一词取自《礼记·杂记下》——

$>$ “一张一弛，文武之道也。”

这是孔子的话，讲的是治国理政要张弛有度、劳逸结合。本章借用这一意象：

张：正号。宇宙的膨胀、空间的拉伸、尺度的放大。暴涨。信息从虚部向实部转化。弛：负号。宇宙的冷却、能量的沉降、质量的压低。结构形成。信息从实部向虚部转化。

《道德经》第 40 章“反也者，道之动也”进一步揭示了这一循环的哲学根基——道的运动是循环往复的，张与弛正是这一循环的两种基本形态。

## 7.2 张弛公式

综合式 (35.1)—(35.10) 的全部结构，我们定义广义物理量 Φ，其紫外裸值为 $\Phi _ { \mathrm { U V } }$ 几何相位为 $\theta _ { \mathsf { c } }$ 。张弛公式是宇宙的万能统一公式：

• i：时间——全息相变算子，驱动信息在虚实之间的转化 [1, 3]

$\theta = \mathcal { S } \cdot \Gamma$ ：几何相位

$\mathcal { S } \colon$ 几何作用量（无量纲，由拓扑结构决定）

## 7.3 实数指数与复数指数的对应

读者可能注意到，具体的物理公式（如 $m = M _ { \mathrm { P l } } e ^ { - S } \cdot \ \alpha = \alpha _ { \mathrm { b a r e } } e ^ { - I } \cdot \ a ( t ) = a _ { 0 } e ^ { + H t } )$ 中指数都是实数，而张弛公式的统一形式却是 $e ^ { i \theta }$ ，指数是虚数。这不是矛盾，而是统一形式在不同几何相位下的退化：

• 当 $\theta = i S \enspace \left( \Gamma = + i \right)$ 且 S = S）时， $e ^ { i \theta } = e ^ { i ( i S ) } = e ^ { - S }$ ，得到弛阶段的实数指数。此时对应粒子质量、耦合常数、暗能量密度等“能量沉降”过程。

• 当 $\theta = - i H t ~ ( \Gamma = - i$ 且 ${ \mathcal { S } } = H t )$ 时， $e ^ { i \theta } = e ^ { i ( - i H t ) } = e ^ { + H t }$ ，得到张阶段的实数指数。此时对应暴涨和空间膨胀。

• 当 θ 为一般复数时，指数既有实部又有虚部，实部控制能量标度的变化，虚部控制信息的相位演化。这对应于宇宙中更复杂的循环过程，如重加热、重子数产生等 [16]。

因此，所有已知的具体公式都是张弛公式在特定几何相位下的投影。正因如此，张弛公式被称为“元定律”——它生成具体的物理方程，而自身则是对称性最高的抽象形式。

## 7.4 虚部 sinθ 的物理对应物

张弛公式中的虚部 sinθ 并非没有物理意义。它对应信息的“潜在部分”——尚未显化为可观测能量或物质的拓扑结构。以下是几个具体的例子：

• 稳定粒子（电子、质子等）：对于这些粒子，几何相位 θ 恰为纯虚数且指数为实数，此时 sinθ = 0。这意味着粒子的全部信息已经“实化”为其静止质量，不存在尚未显化的潜在能量。这解释了为什么稳定粒子的质量是确定的，不随时间演化。

• 轴子凝聚：在第 23 章中，轴子是空间应力凝聚的赝标量模式 [14]。它的作用量中包含一个非零的虚部 sinθ，对应凝聚的相位相干性。这种虚部不贡献质量，但贡献与光子的耦合，可被探测为天体物理中的轴子信号 [36]。

• 暗物质场 ϕ ：第 29 章指出，暗物质是空间耦合力场的非谐振涨落 [18]。其波函数具有空间分布的相位，sinθ 不为零。这些空间褶皱在核尺度上产生相干干涉（第32 章），压低铍-7 的电子捕获速率，从而解决锂-7 问题 [19]。这正是虚部产生可观测效应的直接例证。

• 真空涨落：在真空中，θ 有微小虚部，对应虚粒子对的不断产生和湮灭 [29]。sinθ在此处代表量子涨落的幅度。

总之，sinθ 是宇宙“未显化可能性”的数学载体。它不直接产生静止质量，但通过相位干涉、凝聚和涨落等方式，深刻影响了物质世界的结构和演化。
