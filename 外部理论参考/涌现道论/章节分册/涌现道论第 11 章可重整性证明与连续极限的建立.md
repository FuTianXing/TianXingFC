## 3.1 减除操作

在格点正则化下，所有动量积分（求和）有限，但发散出现在 $a \to 0$ 极限。BPHZ方案通过对每个发散子图进行泰勒展开减除来获得有限的重整化关联函数。

$$
\mathcal {R} G = (1 - t ^ {\omega}) G,\tag{11.5}
$$

其中 $t ^ { \omega }$ 是将被积函数在零动量处泰勒展开至 $\omega$ 阶的算子（对于 $\omega \geq 0 )$ ），对于 $\omega < 0$ ${ \mathcal { R } } G = G$ o

引理 3.1 (Reisz 定理的适用性验证). 本网络的格点 $\phi ^ { 4 }$ 作用量满足 Reisz (1988) 构造性重整化中使用的四个条件：

1. 自由传播子 $C _ { 0 } ( p )$ 在布里渊区内处处有定义，且当 $a \to 0$ 时连续极限存在，高阶项为 $O ( a ^ { 2 } p ^ { 4 } )$ ；

2. 相互作用项 $\lambda _ { 0 } \phi ^ { 4 } / 4$ 是局域多项式，顶点形式简单；

3. 幂次计数给出只有有限个发散图（推论2.1）；

4. 格点 BPHZ 森林公式成立，且减除后的积分核满足幂次衰减，保证紫外收敛。

因此，Reisz 关于格点 $\phi ^ { 4 }$ 理论可重整性的定理 $\it { \Omega } / \it { 1 3 } \mathrm { { } ] }$ 可以直接应用。

定理 3.1 (BPHZ 减除后的收敛速度). 设 Γ 是一个 1PI图，其表观发散度 $\omega \geq 0$ 。在格点正则化下，对 Γ 应用森林公式减除后，其积分核 $\mathcal { R } \Gamma ( p ; a )$ 满足

\int_ {\mathrm{BZ}} \frac {d ^ {4} k}{(2 \pi) ^ {4}} \frac {1}{k ^ {2} + m _ {0} ^ {2}} = \frac {c _ {1}}{a ^ {2}} + \text {有限项}, \qquad c _ {1} \approx 0. 2 5 2 7.\tag{11.11}

固定物理质量 $m$ 和物理耦合常数λ（在某个能标 $\mu$ 处）。选择裸参数 $m _ { 0 } ( a ) , \lambda _ { 0 } ( a ) , Z _ { \phi } ( a )$ 使得重整化关联函数满足：

$$
\Gamma_ {R} ^ {(2)} (p ^ {2} = 0) = m ^ {2}, \quad \frac {\partial}{\partial p ^ {2}} \Gamma_ {R} ^ {(2)} (p ^ {2}) \big | _ {p ^ {2} = 0} = 1, \quad \Gamma_ {R} ^ {(4)} (0, 0, 0) = \lambda .\tag{11.22}
$$

定理 5.1 (裸参数的存在性与渐近展开). 存在唯一的函数 $m _ { 0 } ^ { 2 } ( a ) , \lambda _ { 0 } ( a ) , Z _ { \phi } ( a )$ ，在 $a \to 0$ 时发散，使得上述重整化条件满足。它们的渐近展开为：

$$
\lambda_ {0} (a) = \lambda + \frac {3 \lambda^ {2}}{1 6 \pi^ {2}} \ln (1 / a) + O (\lambda^ {3} \ln^ {2} (1 / a)),\tag{11.23}
$$

$$
m _ {0} ^ {2} (a) = m ^ {2} - \frac {\lambda c _ {1}}{1 6 \pi^ {2} a ^ {2}} + \frac {\lambda m ^ {2}}{1 6 \pi^ {2}} \ln (1 / a) + O (\lambda^ {2}),\tag{11.24}
$$

$$
Z _ {\phi} (a) = 1 + \frac {\lambda}{1 9 2 \pi^ {2}} + O (\lambda^ {2}).\tag{11.25}
$$

其中 $c _ { 1 } \approx 0 . 2 5 2 7$ 是格点积分常数。

Proof. 将单圈结果代入重整化条件，解出 $m _ { 0 } ^ { 2 } , \lambda _ { 0 } , Z _ { \phi }$ 作为 a 的函数。通过重整化群方程可证明这些级数对充分小的 λ 是收敛的（形式幂级数可求和）。详细构造参见 Reisz(1988)[13] 定理 4.1。 □

注 (与第 10 章重整化群压缩性的衔接). 第 10 章定理 10.3 证明了对任意初始测度，重整化群变换 $\mathcal { R } _ { b }$ 在 Wasserstein 度量下是压缩映射，且存在唯一的高斯不动点 $\mu _ { * }$ 。该不动点对应的关联函数正是由上述裸参数序列在 $a \to 0$ 时定义的连续极限测度。换言之，若定义 $\mu _ { a }$ 为格距 a 下的测度（由裸参数 $m _ { 0 } ^ { 2 } ( a ) , \lambda _ { 0 } ( a ) , Z _ { \phi } ( a )$ 确定），则重整化群迭代$\mathcal { R } _ { b } ^ { n } \mu _ { a b ^ { n } }$ 收敛到 $\mu _ { * }$ 。因此，定理 11.2 的裸参数序列恰好是第 10 章压缩映射下的一条重整化群轨道。

## 哲学注记

引力作为低能有效理论，高阶曲率项如同“张弓”——弯折处产生额外效应。“损有余而益不足”正是重整化群跑动的写照：紫外细节（有余）被吸收进低能系数（不足）。

第 7 章定理 7.3 证明了 Regge 曲率 $\begin{array} { r } { R _ { v } = \frac { 1 } { V _ { v } } \sum _ { e \ni v } \ell _ { e } \delta _ { e } } \end{array}$ 在连续极限下收敛到连续曲率 R，且收敛速度为 $O ( a ^ { 2 } )$ 。离散爱因斯坦-希尔伯特作用量为

$$
S _ {\mathrm{GR}} = \frac {1}{1 6 \pi G} \sum_ {v} a ^ {3} R _ {v}.\tag{11.26}
$$

将 Regge 作用量展开至二阶（曲率平方项），可得有效作用量：

$$
S _ {\mathrm{eff}} = \int d ^ {4} x \sqrt {- g} \left(\frac {1}{1 6 \pi G} R + \alpha_ {1} l _ {P} ^ {2} R ^ {2} + \alpha_ {2} l _ {P} ^ {2} R _ {\mu \nu} R ^ {\mu \nu} + \alpha_ {3} l _ {P} ^ {2} R _ {\mu \nu \rho \sigma} R ^ {\mu \nu \rho \sigma} + \dots\right)\tag{11.27}
$$

引理 6.1 (曲率平方项的离散收敛). 由第 7 章定理 7.3，Regge 曲率 $R _ { v }$ 在连续极限下收敛到 R，且 $| R _ { v } - R ( x _ { v } ) | \leq C a ^ { 2 }$ 。利用该收敛性，可进一步证明曲率平方量的离散和$\textstyle \sum _ { v } a ^ { 3 } R _ { v } ^ { 2 }$ 收敛到 $\textstyle \int d ^ { 4 } x { \sqrt { - g } } R ^ { 2 }$ ，误差为 $O ( a ^ { 2 } )$ 。同理， $R _ { \mu \nu } R ^ { \mu \nu }$ 和 $R _ { \mu \nu \rho \sigma } R ^ { \mu \nu \rho \sigma }$ 的离散版本也有相同的收敛速度。

Proof. 将 $R _ { v } = R ( x _ { v } ) + \delta R _ { v }$ ，其中 $| \delta R _ { v } | \le C a ^ { 2 }$ 。则

$$
\sum_ {v} a ^ {3} R _ {v} ^ {2} = \sum_ {v} a ^ {3} \big (R (x _ {v}) ^ {2} + 2 R (x _ {v}) \delta R _ {v} + \delta R _ {v} ^ {2} \big).
$$

第一项收敛到 $\textstyle \int R ^ { 2 }$ ，后两项由于 $\delta R _ { v } = { \cal O } ( a ^ { 2 } )$ ，总和为 $O ( a ^ { 2 } )$ o

定理 6.1 (高阶曲率系数的网络参数表达). 对于本网络的三维空间离散化（时间连续），低能有效引力作用量中的高阶曲率项系数由有效场论唯一确定，与网络参数无关（仅由维数决定），具体为：

$$
\alpha_ {1} = \frac {1}{1 9 2 \pi^ {2}}, \quad \alpha_ {2} = \frac {1}{2 4 0 \pi^ {2}}, \quad \alpha_ {3} = \frac {1}{7 2 0 \pi^ {2}}.\tag{11.28}
$$

这些系数是有效场论中的标准结果 $[ 1 6 , \ 1 7 ]$ 。由引理6.1和第 7 章定理 7.3，离散曲率平方项在连续极限下确实收敛到连续曲率平方项，因此上述系数可直接应用于本理论。网络参数通过普朗克长度 $l _ { P }$ 进入高阶项： $l _ { P } = \sqrt { \hbar G / c ^ { 3 } }$ 。

Proof. 将 Regge 曲率 $R _ { v }$ 在光滑极限下展开，利用引理6.1，离散作用量中的曲率平方项收敛到连续曲率平方项。在低能有效场论中，这些项的系数由量子引力的一圈计算确定，与紫外完成无关（只要理论存在可重整化或有效场论一致）。本理论的紫外完成正是第 9-11 章构造的格点 $\phi ^ { 4 }$ 模型，因此标准系数适用。 □
