## 5 测量坍缩

## 5.1 信息相变与投影

第 4 章定义，当局部区域发生能量密度变化 $d \rho \neq 0$ 时，产生信息相变：潜在信息（虚部 Y）转化为显现信息（实部 X）[4]。测量过程正是这种相变：测量仪器的介入引起局域能量密度变化，从而触发相变。

定理 5.1 (坍缩的几何本质). 设系统处于叠加态 $\begin{array} { r } { | \psi \rangle = \sum _ { n } c _ { n } | n \rangle } \end{array}$ 。当测量设备与系统相互作用时，在空间位置 $\scriptstyle { \mathbf { { \mathit { x } } } } _ { 0 }$ 处发生信息相变，该点的实部 $X ( \pmb { x } _ { 0 } )$ 固定到某个本征值。由于全息场的全局关联（通过链接数），整个系统的态投影到相应的本征态上。投影概率为 $| c _ { n } | ^ { 2 }$ ，与玻恩规则一致。

## 5.2 玻恩规则的推导

第 2 章的玄同方程中，随机项 $\xi ( p , t )$ 的协方差为 $2 \hbar \delta _ { p q } \delta ( t - s ) I [ 2 ]$ 。该随机涨落导致路径积分中的测度权重为 $e ^ { i S / \hbar }$ 。演化后的波函数模平方给出概率密度。测量时的局域相变相当于在路径积分中施加一个“吸收边界”，其概率由入射流的模平方决定，即玻恩规则。

## 5.3 坍缩的不可逆性

信息相变是不可逆的，因为一旦潜在信息转化为显现信息，就无法自然地退回到潜在态（类似于热力学熵增）。这解释了为什么测量过程具有时间箭头。

## 6 不确定性原理

## 6.1 实部与虚部的不对易关系

全息场 $Z = X + i Y$ 中，X 和 Y 是共轭变量。从玄同方程的相空间形式出发，可以导出正则对易关系（第 16 章附录 B[16]）：

$$
[ \hat {X} (p), \hat {Y} (q) ] = i \hbar \delta_ {p q}.
$$

定义动量 $\hat { P } = \mu _ { 0 } \partial _ { t } \hat { X }$ ，利用第 3 章的常数关系 $\mu _ { 0 } = \hbar / c ^ { 2 }$ ，可得 $[ { \hat { X } } , { \hat { P } } ] = i \hbar$

## 6.2 不确定性关系的推导

对于任意态 ψ ，由施瓦茨不等式：

$$
\langle (\Delta \hat {X}) ^ {2} \rangle \langle (\Delta \hat {P}) ^ {2} \rangle \geq \frac {1}{4} | \langle [ \hat {X}, \hat {P} ] \rangle | ^ {2} = \frac {\hbar^ {2}}{4}.
$$

因此：

$$
\Delta X \cdot \Delta P \geq \frac {\hbar}{2}.
$$

## 6.3 几何根源

不确定性源于全息场实部与虚部之间的互补性：当潜在信息（Y）被大量转化为显现信息（X）时，X 的分布变得尖锐，但剩余潜在信息 Y 的涨落增大。这种互补是相变算子 i 的代数性质 $i ^ { 2 } = - 1$ 的直接结果。

## 9.1 环境引起的信息相变

第 4 章的时间涌现表明，任何能量密度变化 $d \rho$ 都会导致信息相变。环境中的大量自由度（热浴）持续与系统相互作用，引发连续、微小的信息相变。

## 12 EPR 佯谬与定域性

## 12.1 非定域关联 vs 超光速通信

第 2 章的玄同方程满足局域性：相互作用只发生在最近邻节点，因此类空间隔算符对易：

$$
[ \hat {O} _ {1} (x _ {1}), \hat {O} _ {2} (x _ {2}) ] = 0, \qquad {\text {若}} (x _ {1} - x _ {2}) ^ {2} <   0.
$$

这保证了不能超光速传递信息。纠缠关联是拓扑不变量，不要求信号传递。

## 12.2 为什么纠缠不违反因果律

测量结果的随机性使得不可能通过选择测量基来控制远方结果。因此，虽然关联是非定域的，但信息传递是局域的。

## 13 量子克隆不可行定理

## 13.1 信息守恒

第 1 章定理 1 证明总信息 $\begin{array} { r } { I _ { \mathrm { t o t } } = \int | Z | ^ { 2 } d \mu } \end{array}$ 守恒 [1]。完美克隆一个未知量子态会复制其信息，导致总信息增加，违反守恒律。

## 13.2 不可克隆的几何表述

设克隆算符 $\hat { U }$ 作用在态 ψ 0 0 上，要求 $\hat { U } | \psi \rangle | 0 \rangle | 0 \rangle = | \psi \rangle | \psi \rangle | \chi \rangle$ 。对于两个不同态 ψ , ϕ ，取内积后导出矛盾。因此，不存在这样的线性幺正算符。

## 14 测量问题与 Wigner 朋友悖论

## 14.1 观察者的角色

本理论中，坍缩由信息相变引起，不依赖意识。任何能够引起局域能量密度变化的系统（包括测量仪器）都可成为“测量者”。

## 14.2 Wigner 朋友悖论的消解

Wigner 的朋友是另一个观察者。在本理论中，Wigner 和其朋友处于不同的信息相变层次。如果朋友的测量已发生局部信息相变，那么从 Wigner 的视角，系统已经坍缩，不会出现矛盾。若未发生相变（比如朋友被隔离），则描述仍为叠加态。不同观察者可通过交流对比测量结果，总可达成一致，无悖论。
