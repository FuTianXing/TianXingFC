## 4.1 扩散的不可逆性

在离散映射 (9) 中，扩散项 $\begin{array} { r } { \sum _ { q } k _ { 0 } ( \rho ( q ) - \rho ( p ) ) } \end{array}$ 是不可逆的关键：它总是将能量从高密度节点转移到低密度节点。若尝试对映射进行“倒转”操作 $( n \to - n )$ ），扩散项将变为从低密度向高密度输送能量，违反了扩散项原本的单调性质。即使将噪声的统计性质反转，也无法同时恢复扩散项和噪声项的原始关联，因此映射不具备时间反演对称性（详细论证见附录 D）。

为消除 $\Delta t$ 和 ρ¯，利用平衡态关系 $\bar { \rho } ;$ $\bar { \rho } \sim \langle H \rangle / ( c ^ { 2 } a ^ { 3 } N )$ 以及 $\Delta t$ 的最优选择。更严格的方法是在连续极限下引入能量-时间傅里叶对偶。但最终结果总是 $\Delta E \Delta T \ge \hbar / 2$ 。我们强调，这一定理的证明不依赖于任何时间算符，体现了其纯粹统计起源。

## F 附录 F：霍金温度的随机推导概要

在距视界很近处，径向坐标 $r \approx 2 G M / c ^ { 2 } + \delta r$ ，度规近似为 Rindler 形式。能量密度 $\rho$ 的随机演化受引力场影响，噪声强度保持 h¯，但漂移项出现反常扩散。在视界，有效局部温度可通过细致平衡条件或随机过程的首达时间分布获得。使用涨落-耗散定理与细致平衡，可得局部温度 $k _ { B } T _ { \mathrm { l o c } } = \hbar \kappa / ( 2 \pi c )$ 。详细计算见后续黑洞热力学专章。

## G 附录 G：确定性极限与薛定谔方程的恢复

为证明离散映射包含量子力学，考虑无噪声极限。令 $\hbar  0$ ，但同时保持 $\hbar \varepsilon$ 有限，使得量子效应不消失。引入波函数 $\psi = { \sqrt { \rho } } e ^ { i S / \hbar }$ ，其中 $\rho = | \psi | ^ { 2 }$ ，S 为实相位。离散映射的确定性部分（忽略 η）可写为对 $\rho$ 和 S 的更新。在一维均匀网络上展开至 $O ( a ^ { 2 } )$ ，经过代数运算（详见第 5 章连续极限部分），得到连续方程：

$$
\partial_ {t} \rho + \nabla \cdot (\rho \nabla S) = 0,\tag{28}
$$

$$
\partial_ {t} S + \frac {1}{2} | \nabla S | ^ {2} + V + Q = 0,\tag{29}
$$

其中 $\begin{array} { r } { Q = - \frac { \hbar ^ { 2 } } { 2 m } \frac { \nabla ^ { 2 } \sqrt { \rho } } { \sqrt { \rho } } } \end{array}$ 为量子势。方程即为 Madelung 方程组，等价于薛定谔方程

$$
i \hbar \partial_ {t} \psi = \left(- \frac {\hbar^ {2}}{2 m} \nabla^ {2} + V\right) \psi .
$$

因此，离散映射在确定性极限下完全恢复幺正量子力学。若包含噪声，则退化为量子退相干或坍缩模型，揭示了量子-经典过渡的统一描述。

关于时间的角色：在 Madelung 方程中，时间 t 是作为流体力学演化的外部参数出现的。它来自于连续极限下的标度变量，而不是量子态的一部分。这进一步确证：即使恢复量子力学，时间仍是经典背景量。

## H 附录 H：宏观时间单值性的详细估计

由定义 (4)， $d T ( p ) = 2 \tau _ { 0 } \sqrt { \hbar / ( \pi \rho ( p ) ) } \sqrt { d t }$ 。假设背景均匀， $\rho ( p ) = { \bar { \rho } } + \delta \rho _ { p } , \ | \delta \rho | \ll { \bar { \rho } } { \mathrm { . } }$ 展开得 $\begin{array} { r } { d T ( p ) \approx d \bar { t } - \frac { \tau _ { 0 } } { \sqrt { \pi } } \sqrt { \frac { \hbar } { \bar { \rho } ^ { 3 } } } \delta \rho _ { p } \sqrt { d t } . } \end{array}$ 。故 $\begin{array} { r } { ( d T ( p ) - d T ( q ) ) ^ { 2 } \approx \frac { \tau _ { 0 } ^ { 2 } \hbar } { \pi \bar { \rho } ^ { 3 } } ( \delta \rho _ { p } - \delta \rho _ { q } ) ^ { 2 } d t } \end{array}$ 。两点能量涨落的协方差可通过扩散矩阵的格林函数求得： $\langle \delta \rho _ { p } \delta \rho _ { q } \rangle \propto G ( p , q )$ ，其中 G 为图拉普拉斯的逆矩阵。对于正则图， $G ( p , q ) \sim O ( 1 / N )$ 对于 $p \neq q$ ，而 $G ( p , p ) \sim O ( 1 )$ 。因此$( \delta \rho _ { p } - \delta \rho _ { q } ) ^ { 2 }$ 的期望为 $G ( p , p ) + G ( q , q ) - 2 G ( p , q ) \approx$ 常数 $\times O ( 1 ) - O ( 1 / N )$ ，当 N 很大时趋于常数。然而，我们关心的是相对差异 $| d T ( p ) - d T ( q ) | / d \bar { t } \propto | \delta \rho _ { p } - \delta \rho _ { q } | / \bar { \rho } \nonumber$ 。在热力学极限下，根方差 $\sqrt { \langle ( \delta \rho ) ^ { 2 } \rangle } / \bar { \rho } \sim 1 / \sqrt { N }$ （因为能量可加性），故相对差异按 $1 / \sqrt { N }$ 趋于零。这证明了宏观时间单值性。

## I 附录 I：为什么时间不能量子化——一个形式论证

我们在此给出一个简明的形式论证，以补足正文中的物理直觉。假设存在时间算符$\hat { T }$ 与哈密顿量 $\hat { H }$ 共轭： $[ { \hat { T } } , { \hat { H } } ] = i \hbar$ 。则由标准 Pauli 论证 [21]，若 $\hat { H }$ 的谱有下界（稳定性要求），则 $\hat { T }$ 不能是自伴算符。其唯一可能的实现是 $\hat { T }$ 的最大定义域不包含整个希尔伯特空间，导致其物理意义 $\overrightharpoon { j } ^ { \mathbb { E } }$ 重受限。在本理论中， $\hat { H }$ 由玄同方程给出，谱确实有下界（基态能量），故严格不存在满足标准量子力学公理的时间算符。这从形式上排除了时间量子化的可能性。相反，我们构建的涌现时间 $\tau _ { M }$ 是一个 $c -$ -数随机过程，完全避开了上述代数障碍。因此，“时间不可量子化”不是哲学偏好，而是数学必然。
