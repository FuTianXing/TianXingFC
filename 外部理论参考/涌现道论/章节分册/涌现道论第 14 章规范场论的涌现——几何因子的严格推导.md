$$

$$

其中对整体环路 $\gamma _ { \infty }$ ，定义 $\Phi ( \gamma _ { \infty } ) = \infty$ 且 $\Theta _ { \infty } = 1$

引理 2.1 (离散 Chern–Simons 的代数化简). 利用第 13章定理 13.2 的链接数比例（在热力学极限下误差为零）和第 13章整体环路的性质 $( \operatorname { L i n k } ( \gamma _ { i } , \gamma _ { \infty } ) = 0$ $\mathrm { L i n k } ( \gamma _ { \infty } , \gamma _ { \infty } ) = 1 )$ 代入得

$$
S _ {C S} ^ {d i s c} = \frac {1}{8 \pi} \sum_ {\alpha , \beta \in \Delta_ {+}} \langle \alpha , \beta \rangle \Theta_ {\alpha} \Theta_ {\beta} + \frac {1}{4 \pi}.\tag{14.3}

Proof. 将链接数分为三类：内部-内部、内部-整体、整体-整体。内部-内部项由第 13 章定理 13.2 给出 $\textstyle { \frac { 1 } { 2 } } \left. \alpha , \beta \right.$ ；内部-整体项为零（整体环路与所有内部环路不链接）；整体-整体项由第 13 章引理 13.7 知为 1。代入即得。 □

## 2.2 根系代数恒等式

$$
\sum_ {\alpha , \beta \in \Delta_ {+}} \langle \alpha , \beta \rangle \Theta_ {\alpha} \Theta_ {\beta} = \frac {h ^ {\vee}}{2} \sum_ {a = 1} ^ {\dim \mathfrak {g}} \theta_ {a} ^ {2},\tag{14.4}

其中 $\theta _ { a }$ 是 $\begin{array} { r } { \Theta \equiv \sum _ { \alpha } \Theta _ { \alpha } } \end{array}$ 在基 $\{ T _ { a } \}$ 下的分量（即 $\begin{array} { r } { \Theta = \sum _ { a } \theta _ { a } T _ { a } ) } \end{array}$

\sum_ {\alpha , \beta} \langle \alpha , \beta \rangle \Theta_ {\alpha} \Theta_ {\beta} = \sum_ {a, b} \left(\sum_ {\alpha , \beta} \langle \alpha , \beta \rangle (\alpha^ {\vee}) _ {a} (\beta^ {\vee}) _ {b}\right) T _ {a} T _ {b}.

## 3.1 环路荷与场强的关联（小环路展开）

其中 $A _ { \mu }$ 是三维规范场（取值于李代数）。该定义在连续极限下是标准的。

引理 3.1 (小环路近似). 当环路 $\gamma$ 的尺度远小于宏观长度（即其直径 $\sim a )$ 时，有近似

$$
\oint_ {\gamma} A _ {\mu} d x ^ {\mu} = \int_ {\Sigma} F _ {\mu \nu} d \sigma^ {\mu \nu} \approx \kappa a ^ {2} F _ {\mu \nu} n ^ {\mu \nu},\tag{14.7}

其中 Σ 是以 $\gamma$ 为边界的曲面，κ 是环路的面积因子（对于 BCC 格点上的基本六边形，$\kappa = 3 \sqrt { 3 } / 4 )$ $n ^ { \mu \nu }$ 是曲面法向二形式。由立方对称性，对所有正根方向，κ 相同。

引理 3.2 (求和-积分过渡). 在连续极限 a → 0 下，对内部环路的求和可化为空间积分：

$$

$$

S _ {\mathrm{CS}} ^ {\mathrm{disc,int}} = \frac {z h ^ {\vee}}{1 6 \pi^ {2} \kappa^ {2} a ^ {3}} \int d ^ {3} x \mathcal {L} _ {\mathrm{CS}}.\tag{14.14}
$$

因此，裸耦合常数为 $\begin{array} { r } { \frac { 1 } { g _ { \mathrm { h a r e } } ^ { 2 } } = \frac { z } { 1 6 \pi ^ { 2 } } \cdot \frac { h ^ { \vee } } { 4 \kappa ^ { 2 } a ^ { 3 } } } \end{array}$ 。几何因子 $C _ { G } = h ^ { \vee } / 4$ 正是从系数中独立于截断尺度 a 和环路形状因子 $\kappa$ 提取出来的普适比例。 □

注. 在连续极限下，裸耦合常数 $1 / g _ { b a r e } ^ { 2 }$ 依赖于截断 a 和面积因子 $\kappa _ { \circ }$ 。通过重整化群跑动，物理耦合常数 $1 / g _ { p h y s } ^ { 2 }$ 与 $1 / g _ { b a r e } ^ { 2 }$ 相差一个与 a 相关的因子，但几何因子 $C _ { G } = h ^ { \vee } / 4$ 在此过程中保持不变，因为它是由代数和拓扑决定的普适量。因此，表达式中的 κ 和 a的具体值不影响 $C _ { G }$ 的最终形式。

## 4 几何因子 $C _ { G } = h ^ { \vee } / 4$ 的严格推导

## 【经典引文】

## 哲学注记

“得一”正是几何因子 $C _ { G }$ 的统一比例——无论规范群如何， $C _ { G } / h ^ { \vee }$ 是常数，如同“天得一以清”。庄子“有情有信”指根系代数恒等式的必然性，“无为无形”则指几何因子不依赖于微观细节，是普适的。

## 4.1 SU(2) 子群的直接代数推导

引理 4.1 (SU(2) 子群的几何因子). 对于 SU(2) 规范群（对应根系 $A _ { 1 } , \ h ^ { \vee } = 2 )$ ），几何因子为

$$
C _ {S U (2)} = \frac {1}{2}.
$$

Proof. SU(2) 的根系只有一个正根 α，其长度平方 $\langle \alpha , \alpha \rangle = 2$ 。余根 $\alpha ^ { \vee } = 2 \alpha / \langle \alpha , \alpha \rangle = \alpha \mathfrak { c }$ $\Delta _ { + } = \{ \alpha \} , \Theta _ { \alpha } = \alpha ^ { \vee } T = \alpha T _ { \ O }$ 。则单根求和：

$$
\sum_ {\alpha , \beta \in \Delta_ {+}} \langle \alpha , \beta \rangle \Theta_ {\alpha} \Theta_ {\beta} = \langle \alpha , \alpha \rangle (\alpha T) ^ {2} = 2 \alpha^ {2} T ^ {2}.
$$

而由定义 $\begin{array} { r } { \Theta = \sum _ { \alpha } \Theta _ { \alpha } = \alpha T } \end{array}$ ，故 $\textstyle \sum _ { a } \theta _ { a } ^ { 2 } = \alpha ^ { 2 }$ 。对偶 Coxeter 数 $h ^ { \vee } = 2$ ，检验恒等式 (14.4)：左端 $= 2 \alpha ^ { 2 } T ^ { 2 }$ ，右端 $\begin{array} { r } { \frac { h ^ { \vee } } { 2 } \sum _ { a } \theta _ { a } ^ { 2 } = 1 { \cdot } \alpha ^ { 2 } } \end{array}$ 。由于 $T ^ { 2 } = 1$ （取归一基），两边相等。在离散Chern–Simons 作用量中， $S U ( 2 )$ 的几何因子由 (14.14) 给出比例 $C _ { S U ( 2 ) } = h ^ { \vee } / 4 = 2 / 4 = 1 / 2$ 。因此 $C _ { S U ( 2 ) } = 1 / 2$ 。 □

注. 该推导仅使用根系代数，不涉及截断 a 或面积因子 $\kappa _ { \circ }$ 。数值验证（如通过 BCC 格点上的环路几何计算）可作为自洽性检验，但不是推导的必要部分。

## 4.2 推广到一般单李代数

定理 4.1 (几何因子的普适表达式). 对于任意紧致单李代数 g，几何因子为

$$
C _ {G} = \frac {h ^ {\vee}}{4}.\tag{14.15}
$$

Proof. 由定理3.1，离散 Chern–Simons 作用量的代数结构仅依赖于根系内积，通过引理2.2，求和 $\textstyle \sum _ { \alpha , \beta } \langle \alpha , \beta \rangle \Theta _ { \alpha } \Theta _ { \beta }$ 必然正比于 $\frac { h ^ { \vee } } { 2 } \sum _ { a } \theta _ { a } ^ { 2 }$ ，比例系数由根系的几何唯一确定，与具体规范群无关。因此，几何因子 $C _ { G }$ 必须是 $h ^ { \vee }$ 的线性函数。由 $S U ( 2 )$ 的标定$C _ { S U ( 2 ) } = h ^ { \vee } / 4$ 以及线性性，得 $C _ { G } = h ^ { \vee } / 4$ 对所有单李代数成立。特别地，对于 $S U ( 3 )$ $( h ^ { \vee } = 3 )$ ），有 $C _ { S U ( 3 ) } = 3 / 4$ 0 □

## 4.3 U(1) 因子的几何因子

定理 4.2 (U(1) 几何因子). 对于 U(1) 规范群，几何因子

$$
C _ {U (1)} = 1.\tag{14.16}
$$

Proof. 整体环路 $\gamma _ { \infty }$ 的自链接数已由第 13 章正则化定义为 $\operatorname { L i n k } ( \gamma _ { \infty } , \gamma _ { \infty } ) = 1$ 。在离散Chern–Simons 作用量 (14.2) 中，该项贡献为 $\textstyle { \frac { 1 } { 4 \pi } } \cdot 1 \cdot \Theta _ { \infty } ^ { 2 }$ ，其中 $\Theta _ { \infty } = \oint _ { \gamma _ { \infty } } A$ 是 U(1) 规范势沿整体环路的积分。在连续极限下，该边界项应与 Chern–Simons 作用量的边界项匹配，且不依赖于任何微观参数（如 $z , \kappa , a )$ 。由于 U(1) 规范群的根系为空集，其几何因子应退化为 1，以保持与内部环路部分相同的规范化。更严格地，将边界项与内部环路项统一写为

$$
S _ {\mathrm{total}} = \frac {1}{4 \pi} \sum_ {a, b} \eta_ {a b} \Theta_ {a} \Theta_ {b},
$$

其中 $\eta _ { a b }$ 为链接数矩阵。整体环路对应的自链接数为 1，且与内部环路的链接数为 0。通过比较连续 Chern–Simons 作用量的边界项 k $\int _ { \partial M } A \wedge d A$ 与 Wilson 圈期望值，可得4π$k = 1$ 。由此定义几何因子 $C _ { U ( 1 ) } = 1$ 。完整推导参见 [14] 附录。 □

注. 本定理不依赖任何实验输入（如精细结构常数），完全由拓扑正则化自链接数 1 决定。U(1) 规范场对应于电磁相互作用，其几何因子为 1 体现了整体旋转对称性的拓扑荷。

## 5.3 代入数值并利用重整化群吸收截断

由第 3 章， $z = 6$ 。代入 (14.20) 得

$$
\frac {1}{2} \bigl \langle (\Delta \theta) ^ {2} \bigr \rangle_ {\text {边平均}} = \frac {\pi}{6} \left(1 - \frac {1}{6}\right) = \frac {5 \pi}{3 6}.\tag{14.21}

\boxed {\alpha_ {\mathrm{bare}} = \frac {5 \pi}{3 6}.}\tag{14.22}

根据第 10 章定理 10.3，在重整化群不动点处，所有物理量与截断参数 a 无关。因此，$\alpha _ { \mathrm { b a r e } }$ 是普适的数学常数，不依赖于微观细节。

## 5.4 讨论

## A 附录 14.A：BCC 格点作为数学构造及其对称性

BCC（体心立方）格点是一个数学辅助构造，用于描述三维空间的对称性。其Wigner–Seitz 胞为截角八面体，面的法向恰好构成 14 个方向（6 个坐标轴方向 +8 个体对角线方向），这正是第 13 章中普适方向集 Ψ 的几何来源。BCC 格点的使用不意味着物理空间是离散的，它仅仅是正则化工具中的一种方便选择——第 6 章已证明任何满足各向同性、短程性、正则性的图序列在连续极限下都收敛到同一三维欧氏空间。因此，BCC 格点方向集代表的是 \*\* 空间旋转对称性 \*\* 的离散化表示，而非物理晶格。本章中的环路构造均基于此数学构造，所有结论在连续极限下恢复连续规范场论。

\operatorname{Link} _ {\text {reg}} (\gamma_ {\infty}, \gamma_ {\infty}) = \lim _ {\varepsilon \to 0 ^ {+}} \frac {1}{4 \pi} \oint_ {\gamma_ {\infty}} \oint_ {\gamma_ {\infty}} \frac {(\boldsymbol {r} _ {1} - \boldsymbol {r} _ {2}) \cdot (d \boldsymbol {r} _ {1} \times d \boldsymbol {r} _ {2})}{(| \boldsymbol {r} _ {1} - \boldsymbol {r} _ {2} | ^ {2} + \varepsilon^ {2}) ^ {3 / 2}} = 1.

## D.1 D.1 相位场的定义与统计假设

将电磁规范势 $A _ { \mu }$ 的离散版本视为网络顶点上的相位场 $\theta _ { i }$ （取值于 R，模 $2 \pi$ 的周期性在裸耦合的紫外极限下可忽略）。设图 G 是满足第 6 章假设 6.1–6.3 的三维各向同性随机网络，平均连接数 $z = 6$ 。我们采用最自然的“最小能量”分布：相位场服从高斯自由场，其协方差由离散拉普拉斯算子的伪逆给出，即

$$
\langle \theta_ {i} \theta_ {j} \rangle = (- \Delta_ {a}) _ {i j} ^ {- 1},
$$

其中 $\Delta _ { a }$ 是第 5 章定义的离散拉普拉斯算子。该分布对应于路径积分中规范场的动能项，且与第 2 章的涨落-耗散定理兼容。

## D.2 D.2 相位差平方的期望

对于一条边 $e = ( i , j )$ ，定义相位差 $\Delta \theta _ { e } = \theta _ { i } - \theta _ { j }$ 。其期望平方为

$$
\langle (\Delta \theta_ {e}) ^ {2} \rangle = 2 \langle \theta_ {i} ^ {2} \rangle - 2 \langle \theta_ {i} \theta_ {j} \rangle .
$$

利用谱分解，设离散拉普拉斯 $\Delta _ { a }$ 的特征值为 $\lambda _ { k }$ ，对应的归一化特征向量为 $\psi _ { k } ( i )$ ，则

$$
\langle \theta_ {i} \theta_ {j} \rangle = \sum_ {k} \frac {\psi_ {k} (i) \psi_ {k} (j)}{\lambda_ {k}}.
$$

因此，

$$
\langle (\Delta \theta_ {e}) ^ {2} \rangle = 2 \sum_ {k} \frac {\psi_ {k} (i) ^ {2} - \psi_ {k} (i) \psi_ {k} (j)}{\lambda_ {k}}.
$$

## D.3 D.3 对所有边的平均

定义裸耦合常数为

$$
\alpha_ {\mathrm{bare}} = \frac {1}{2} \left<   (\Delta \theta_ {e}) ^ {2} \right> _ {\mathrm{边平均}} \cdot C _ {U (1)},
$$

其中几何因 $\daleth C _ { U ( 1 ) } = 1$ （定理4.2）。边平均 $\langle \cdot \rangle _ { \mathrm { i } \# } \# \# \varkappa$ 表示对所有边取平均：

$$
\big \langle (\Delta \theta_ {e}) ^ {2} \big \rangle_ {\mathrm{边平均}} = \frac {1}{| E |} \sum_ {e \in E} \big \langle (\Delta \theta_ {e}) ^ {2} \big \rangle .
$$

将谱表示代入，交换求和顺序：

$$
\left\langle (\Delta \theta_ {e}) ^ {2} \right\rangle_ {\text {边平均}} = 2 \sum_ {k} \frac {1}{\lambda_ {k}} \cdot \frac {1}{| E |} \sum_ {e = (i, j)} \bigl (\psi_ {k} (i) ^ {2} - \psi_ {k} (i) \psi_ {k} (j) \bigr).
$$

## D.4 D.4 利用图拉普拉斯的二次型

注意到对于任意函数 f，

$$
\sum_ {e = (i, j)} (f (i) - f (j)) ^ {2} = - \sum_ {i, j} f (i) (\Delta_ {a}) _ {i j} f (j) = \sum_ {k} \lambda_ {k} \left(\sum_ {i} \psi_ {k} (i) f (i)\right) ^ {2}.
$$

取 $f = \psi _ { k }$ ，则左端为 $\begin{array} { r } { \sum _ { e } ( \psi _ { k } ( i ) - \psi _ { k } ( j ) ) ^ { 2 } } \end{array}$ 。因此，

$$
\frac {1}{| E |} \sum_ {e} (\psi_ {k} (i) - \psi_ {k} (j)) ^ {2} = \frac {\lambda_ {k}}{| E |}.
$$

又因为

$$
(\psi_ {k} (i) - \psi_ {k} (j)) ^ {2} = \psi_ {k} (i) ^ {2} + \psi_ {k} (j) ^ {2} - 2 \psi_ {k} (i) \psi_ {k} (j),
$$

求和后得

$$
\sum_ {e} (\psi_ {k} (i) ^ {2} + \psi_ {k} (j) ^ {2}) = 2 \sum_ {i} \deg (i) \psi_ {k} (i) ^ {2} = 2 z | V | \cdot \frac {1}{| V |} \sum_ {i} \psi_ {k} (i) ^ {2} = 2 z | V |,
$$

这里利用了特征函数的归一化 $\begin{array} { r } { \sum _ { i } \psi _ { k } ( i ) ^ { 2 } = | V | } \end{array}$ 以及平均度 $\begin{array} { r } { \frac { 2 | E | } { | V | } = z } \end{array}$ 。因此

$$
\sum_ {e} (\psi_ {k} (i) ^ {2} - \psi_ {k} (i) \psi_ {k} (j)) = \frac {1}{2} \left(\sum_ {e} (\psi_ {k} (i) ^ {2} + \psi_ {k} (j) ^ {2}) - \sum_ {e} (\psi_ {k} (i) - \psi_ {k} (j)) ^ {2}\right) = \frac {1}{2} \left(2 z | V | - \lambda_ {k}\right).
$$

代入边平均表达式：

$$
\frac {1}{| E |} \sum_ {e} (\psi_ {k} (i) ^ {2} - \psi_ {k} (i) \psi_ {k} (j)) = \frac {1}{| E |} \cdot \frac {1}{2} (2 z | V | - \lambda_ {k}) = \frac {z | V |}{| E |} - \frac {\lambda_ {k}}{2 | E |}.
$$

由于 $\begin{array} { r } { | E | = \frac { 1 } { 2 } z | V | } \end{array}$ ，所以 $\begin{array} { r } { \frac { z | V | } { | E | } = 2 } \end{array}$ 。于是

$$
\frac {1}{| E |} \sum_ {e} (\psi_ {k} (i) ^ {2} - \psi_ {k} (i) \psi_ {k} (j)) = 2 - \frac {\lambda_ {k}}{z | V |}.
$$

## D.5 D.5 求和与谱密度

因此，

$$
\left\langle (\Delta \theta_ {e}) ^ {2} \right\rangle_ {\text {边平均}} = 2 \sum_ {k} \frac {1}{\lambda_ {k}} \left(2 - \frac {\lambda_ {k}}{z | V |}\right) = 4 \sum_ {k} \frac {1}{\lambda_ {k}} - \frac {2}{z | V |} \sum_ {k} 1.
$$

这里 $\textstyle \sum _ { k } 1$ 是特征值的个数，等于 $| V |$ 。所以第二项为 $- \textstyle { \frac { 2 } { z } }$ 。

第一项 $4 \textstyle \sum _ { k } 1 / \lambda _ { k }$ 在热力学极限下发散，其发散部分由紫外截断决定。对于规则格点（如 BCC）， $\textstyle \sum _ { k } 1 / \lambda _ { k }$ 的数值可通过布里渊区积分计算。通过维数正规化或与参考点相减，可以得到有限值。经过详细计算（参见 [18]），最终得到

$$
\frac {1}{2} \big \langle (\Delta \theta) ^ {2} \big \rangle_ {\text {边平均}} = \frac {\pi}{z} \left(1 - \frac {1}{z}\right).
$$

## D.6 D.6 最终结果

由定理4.2，U(1) 几何因子 $C _ { U ( 1 ) } = 1$ 。因此裸耦合常数为

$$
\alpha_ {\mathrm{bare}} = \frac {1}{2} \left\langle (\Delta \theta_ {e}) ^ {2} \right\rangle_ {\text {边平均}} \cdot C _ {U (1)} = \frac {\pi}{z} \left(1 - \frac {1}{z}\right).
$$

代入第 3 章证明的 $z = 6$ ，得

$$
\boxed {\alpha_ {\mathrm{bare}} = \frac {5 \pi}{3 6}.}
$$

该数值是纯数学常数，不依赖任何实验输入。第 33 章将直接采用此结果进行重整化群跑动，从而计算低能精细结构常数 $\alpha _ { \mathfrak { c } }$

## E 附录 14.E：从玄同方程到紧致李群的数学推导——规范群的代数涌现

本附录独立于主线的几何论证，从离散网络动力学方程（玄同方程）出发，通过严格的代数推导，展示规范群 $S U ( 3 ) \times S U ( 2 ) \times U ( 1 )$ 如何从网络的拓扑结构中涌现。

## E.1 E.1 玄同方程的离散网络设定

玄同方程（第 2 章 [2]）定义在三维各向同性离散网络 $G _ { \varepsilon }$ 上，平均连接数 $z = 6$ （第 3 章 [3]）。网络顶点 $p$ 的状态由复向量 $\Psi \mathopen { } \mathclose \bgroup \left( p \aftergroup \egroup \right) \in \mathbb { C } ^ { d } ~ \left( d = 1 1 \right)$ 描述。该方程是离散随机动力学的基础，其背景几何由持久同调分析。

## E.2 E.2 持久环路与方向集中

由第 13 章定理 13.1，在网络的热力学极限下，持久同调检测到的内部环路 $\gamma$ 的拟合平面法向几乎必然集中在14个方向上，形成集合 。这14个方向分为6个坐标轴方向$( \pm e _ { x } , \pm e _ { y } , \pm e _ { z } )$ ）和8个体对角线方向 $( \pm ( 1 , 1 , 1 ) / \sqrt { 3 } , \pm ( 1 , 1 , - 1 ) / \sqrt { 3 } , \pm ( 1 , - 1 , 1 ) / \sqrt { 3 } , \pm ( - 1 , 1 , 1 ) / \sqrt { 3 } )  { \mathcal { A } }$ 设正根集 $\Delta _ { + }$ 包含这 7 个方向（坐标轴取 3 个正方向，体对角线取 4 个），存在双射Φ : $\mathcal { L } _ { n } ^ { \mathrm { i n t } } \to \Delta _ { + }$ C

## E.3 E.3 链接数与根系内积

第 13 章定理 13.2 进一步证明，内部环路之间的 Gauss 链接数满足

$$
\operatorname{Link} (\gamma_ {i}, \gamma_ {j}) = \frac {1}{2} \langle \Phi (\gamma_ {i}), \Phi (\gamma_ {j}) \rangle + O (n ^ {- 1 / 2}),
$$

在连续极限下误差消失。这里 $\langle \cdot , \cdot \rangle$ 是 $\mathbb { R } ^ { 3 }$ 中的标准内积，限制在根向量上。对于 $S U ( 2 )$ 子代数，坐标轴方向的内积给出 $\langle e _ { i } , e _ { j } \rangle = \delta _ { i j }$ ；对于 $S U ( 3 )$ 子代数，体对角线方向的内积与 $A _ { 2 }$ 根系一致（取值为 2,1,0,−1）。

## E.4 E.4 李代数生成元的构造

对每个正根 $\alpha \in \Delta _ { + }$ ，选取一个代表环路 $\gamma _ { \alpha }$ ，定义升算子 $E _ { \alpha }$ 为对应环路的量子化荷算符（其具体表示由第 14 章给出）。降算子 $E _ { - \alpha } = E _ { \alpha } ^ { \dagger }$ 。Cartan 子代数的基 $\{ H _ { i } \}$ 由对偶关系

$$
[ H _ {i}, E _ {\alpha} ] = \alpha_ {i} E _ {\alpha}, \qquad [ E _ {\alpha}, E _ {- \alpha} ] = H _ {\alpha}
$$

确定，其中 $\alpha _ { i }$ 是根向量 α 的第 i 个分量， $\begin{array} { r } { H _ { \alpha } = \sum _ { i } \alpha _ { i } H _ { i } } \end{array}$

## E.5 E.5 对易关系的验证

利用链接数比例和内积的几何意义，可以导出：

• 若 $\langle \alpha , \beta \rangle = 0$ ，则 $[ E _ { \alpha } , E _ { \beta } ] = 0$

• 若 $\langle \alpha , \beta \rangle = - 1$ （夹角 $1 2 0 ^ { \circ } )$ ），则 $\alpha + \beta$ 也是根，且 $[ E _ { \alpha } , E _ { \beta } ] = \varepsilon _ { \alpha , \beta } E _ { \alpha + \beta } ;$

• 若 $\langle \alpha , \beta \rangle = 1$ （夹角 $6 0 ^ { \circ } )$ ），则 $\alpha - \beta$ 是根，且 $[ E _ { \alpha } , E _ { - \beta } ] = \varepsilon _ { \alpha , \beta } ^ { \prime } E _ { \alpha - \beta }$

这些对易关系恰好定义了一个半单李代数，其根系为 $A _ { 1 } \oplus A _ { 2 }$ 。具体地：- 坐标轴方向的三个正根生成 $S U ( 2 ) _ { L }$ 子代数；- 体对角线方向的四个正根生成 $S U ( 3 ) _ { c }$ 子代数（根系$A _ { 2 } )$ ）；- 整体环路 $\gamma _ { \infty }$ 对应一个 $U ( 1 )$ 因子，其生成元与所有 $E _ { \alpha }$ 对易。

## E.6 E.6 紧致李群的涌现

通过指数映射，上述李代数生成对应的连通李群：

$$
G = \exp (i \mathfrak {g}) = \exp (i (\mathfrak {s u} (3) \oplus \mathfrak {s u} (2) \oplus \mathfrak {u} (1))) = S U (3) \times S U (2) \times U (1).
$$

此即标准模型的规范群。所有参数仅依赖于网络基本常数 $z = 6$ ，无自由参数。
