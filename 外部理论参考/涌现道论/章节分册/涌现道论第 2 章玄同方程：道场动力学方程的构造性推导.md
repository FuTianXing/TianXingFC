## 6.1 内在涨落（源自第 1 章定理 3 和定理 5）

性质 6.1 (不确定性). 离散网络在普朗克尺度存在内在量子涨落，表现为随机项 $\xi ( p , t )$ C该涨落的强度由第 1 章定理 5（温度统计）和定理 3（时间涌现）决定 $[ 7 , 8 ] \circ$

定理 6.1 (随机项的最一般形式). 设 $\xi ( p , t )$ 是定义在概率空间 $( \Omega , \mathcal { F } , \mathbb { P } )$ 上的随机过程，取值于 C<sup>d</sup>，满足：

1. 马尔可夫性： $\xi ( p , t )$ 与 $\xi ( q , s )$ 在 t ̸= s 时独立；

2. 高斯性：任意有限维分布是高斯的；

3. 时间局域性： $\langle \xi ( p , t ) \xi ^ { \dagger } ( q , s ) \rangle \propto \delta ( t - s )$

4. 空间局域性：不同采样点的涨落独立，即 $\langle \xi ( p , t ) \xi ^ { \dagger } ( q , s ) \rangle = 0$ 对 $p \neq q .$ 则存在正定矩阵 $D _ { p }$ 使得

$$
\langle \xi (p, t) \rangle = 0, \qquad \langle \xi (p, t) \xi^ {\dagger} (q, s) \rangle = 2 D _ {p} \delta_ {p q} \delta (t - s).\tag{11}
$$

证明. 由马尔可夫性和高斯性，过程由协方差函数唯一确定。时间局域性要求协方差正比于 $\delta ( t - s )$ 。空间局域性来自离散网络的基本尺度 a：不同采样点在连续极限下独立[9]。因此 $D _ { p q } = D _ { p } \delta _ { p q }$ 。 □

## 6.2 涨落-耗散定理与普朗克常数

引理 6.1 (涨落-耗散定理——第 1 章定理 5 的量化). 在平衡态附近，涨落强度 $D _ { p }$ 与耗散系数通过温度关联。对于均匀各向同性背景 $K ( p , q ) = k _ { 0 } I , \Theta ( p ) = \theta _ { 0 } I$ ，线性响应理论给出 $\displaystyle { [ \gamma , \ 8 ] }$

$$
D _ {p} = \hbar I,\tag{12}
$$

其中 $\hbar = k _ { 0 } a ^ { 2 } z$ 。该结果与第 1 章定理 5 中的关系 $k _ { B } T = \hbar \omega _ { c } / 2 ( \omega _ { c } = c / a )$ 自洽。

定理 6.2 (普朗克常数的涌现). 随机项的强度由网络基本参数决定：

$$
\hbar = k _ {0} a ^ {2} z,\tag{13}
$$

且

$$
\langle \xi (p, t) \xi^ {\dagger} (q, s) \rangle = 2 \hbar \delta_ {p q} \delta (t - s) I.\tag{14}
$$

证明. 量纲分析： $[ k _ { 0 } ] = M T ^ { - 1 } , \ [ a ] = L , \ [ z ] = 1$ ，故 $[ k _ { 0 } a ^ { 2 } z ] = M L ^ { 2 } T ^ { - 1 } = [ \hbar ]$ 。具体数值由连续极限匹配给出，唯一自洽的选择即上述表达式 [4, 5]。该结果直接联系了第 1 章定理 5 中的温度统计与动力学涨落，并由第 1 章定理 3 中能量密度变化率的微观起源自然导出。 □

注. 随机项 $\xi ( p , t )$ 的物理意义正是第 1 章定理 2 中空间谐振态在普朗克尺度上的振荡（虚粒子对产生与湮灭）的宏观表象 $[ 1 1 , \ 1 2 ] \mathrm { { c } }$ 。其强度 h¯ 决定量子涨落的幅度，与第 1 章定理 3 定义的时间尺度 $t _ { P }$ 通过 $t _ { P } = { \sqrt { \hbar G / c ^ { 5 } } }$ 关联。

## 7 对应原理的定性要求与示意验证

性质 7.1 (对应原理). 在连续极限 a → 0 和经典极限 $\hbar  0$ 下，离散演化方程必须恢复已知的经典物理定律（牛顿力学、麦克斯韦方程组、广义相对论等）[15]。该原理用于验证方程的正确性，具体严格的推导将在后续章节（如连续极限与规范场涌现）中完成。本节仅给出一个示意性验证：在忽略随机项、取均匀背景、连续极限下，方程 (10)简化为克莱因-戈登方程的非相对论近似。

示意验证：设 $K ( p , q ) = k _ { 0 } I , \Theta ( p ) = \theta _ { 0 } I$ ，忽略随机项。对充分光滑的场 $\Psi ( p , t )$ 做泰勒展开： $\begin{array} { r } { \Psi ( q ) = \Psi ( p ) + a \partial _ { e } \Psi ( p ) + \frac { a ^ { 2 } } { 2 } \partial _ { e } ^ { 2 } \Psi ( p ) + \cdot \cdot \cdot } \end{array}$ ，其中 e 沿邻居方向。在各向同性网络 $( z = 6 )$ 中，一阶项求和为零，二阶项求和给出 $\begin{array} { r } { a ^ { 2 } \sum _ { e } \partial _ { e } ^ { 2 } = a ^ { 2 } z \nabla ^ { 2 } } \end{array}$ （这里 $\nabla ^ { 2 }$ 是连续拉普拉斯算子）。代入方程 (10)：

$$
i \partial_ {t} \Psi (p) = k _ {0} a ^ {2} z \nabla^ {2} \Psi (p) + \theta_ {0} \Psi (p).
$$

设 $\theta _ { 0 } = m c ^ { 2 } / \hbar$ ，且 $\hbar = k _ { 0 } a ^ { 2 } z$ ，则上式化为

$$
i \hbar \partial_ {t} \Psi = \left(- \frac {\hbar^ {2}}{2 m} \nabla^ {2} + m c ^ {2}\right) \Psi ,
$$

这正是克莱因-戈登方程在非相对论近似下（去掉静止能）的薛定谔形式。因此对应原理得到满足。更严格的推导（包括规范场耦合和几何动力学）见后续章节。
