## Abstract

This chapter rigorously defines three discrete curvatures—Ollivier‑Ricci curvature, Kailuo‑Forman (KF) curvature, and Regge curvature—and proves their convergence to the Ricci (or scalar) curvature of smooth Riemannian manifolds for three types of graphs: regular graphs, general graphs satisfying Assumptions 6.1– 6.3, and random geometric graphs. Convergence rates depend on the graph type: $O ( a ^ { 2 } )$ (Ollivier,Regge) or even $O ( a ^ { 4 } )$ (KF) for regular graphs, and $O ( a ^ { 1 / 2 } )$ for general/random graphs. From the unique axiom of minimum total spatial curvature, we derive five fundamental theorems for discrete curvature functions: scale consistency, locality, flat vanishing, boundedness, and convergence verification. We then construct a unified discrete curvature function ${ \cal K } _ { a } ^ { \mathrm { L u o } }$ (Luo curvature, hereafter referred to as LK curvature) that specialises to each of the three classical curvatures. Using the Bramble‑Hilbert lemma and Sobolev interpolation error estimates, we prove the universal convergence theorem: any discrete curvature satisfying the five theorems converges to the continuous curvature with the same rate. This is a pioneering result in discrete geometry, providing a unified mathematical tool for the discretised approximation (regularisation) of the continuous Einstein field equations in Chapter 16. A new application guide compares the three classical curvatures in terms of computational cost, accuracy, and scenarios, and discusses the future prospects of LK curvature in high dimensions, Lorentzian manifolds, and machine learning. It is emphasised that the discrete network is only a regularisation tool; physical spacetime remains continuous, and the continuous Einstein field equations emerge strictly in the continuum limit in Chapter 16.

Keywords: discrete curvature; Ollivier‑Ricci curvature; Kailuo‑Forman curvature; Regge curvature; Luo curvature; LK curvature; universal convergence; Emergent Dao Theory

## 2 Ollivier‑Ricci 曲率

## 【经典引文】

《道德经》S7.3：见小曰明，守柔曰强。

《庄子·秋水》：消息盈虚，终则有始。

## 哲学注记

“见小曰明”——Ollivier 曲率通过观察微观随机游走测度的差异（“小”）来推断宏观弯曲 ${ \binom { 6 6 } { 5 } }$ “明”）。“守柔曰强”则对应 1‑Wasserstein 距离这一“柔”的度量。

定义 2.1 (一步转移概率). 对顶点 $v \in V$ ，定义概率测度 $\mu _ { v }$ 为

$$
\mu_ {v} (u) = \frac {w _ {v u}}{\sum_ {z \in N (v)} w _ {v z}}, \quad u \in N (v), \qquad \mu_ {v} (v) = 0.\tag{7.1}
$$

定义 2.2 (1‑Wasserstein 距离). 设 $\mu , \nu$ 是度量空间 (X,d) 上的概率测度。定义

$$
W _ {1} (\mu , \nu) = \inf _ {\pi \in \Pi (\mu , \nu)} \int_ {X \times X} d (x, y) d \pi (x, y),\tag{7.2}
$$

其中 $\Pi ( \mu , \nu )$ 是 $\mu , \nu$ 的所有耦合。

定义 2.3 (Ollivier‑Ricci 曲率). 对边 $e = ( x , y ) \in E$ ，定义

$$
\kappa_ {O R} (x, y) = 1 - \frac {W _ {1} (\mu_ {x} , \mu_ {y})}{d _ {G} (x , y)}.\tag{7.3}
$$

## 2.1 规则图情形

定理 2.1 (Ollivier‑Ricci 曲率收敛（规则图）). 设 $( M , g )$ 是三维光滑黎曼流形（由第 6章定理 6.5，M 为 $\mathbb { R } ^ { 3 }$ 或 T<sup>3</sup>）， $\left( G _ { a } \right)$ 是一列规则图（如立方格点或 BCC格点），格距 a，边权为欧氏距离。则对任意单位切向量 $v \in T _ { p } M$ ，存在常数 $C _ { O R }$ 使得当 $a$ 充分小时，

$$
\left| \kappa_ {O R} (x, y) - \frac {1}{2} R i c _ {p} (v, v) a ^ {2} \right| \leq C _ {O R} a ^ {2},\tag{7.4}
$$

其中 $x , y$ 是对应于点 $p , q$ 的顶点，且 $q = \mathrm { e x p } _ { p } ( a v ) + O ( a ^ { 3 } )$ 。特别地，由于 $R i c = 0$ $\kappa _ { O R } ( x , y ) = O ( a ^ { 2 } )$

证明概要. 在规则图中，图距离 $d _ { G } ( x , y ) = a$ 精确。光滑流形上，热核短时展开给出

$$
W _ {1} (\mu_ {p} ^ {\mathrm{(cont)}}, \mu_ {q} ^ {\mathrm{(cont)}}) = a - \frac {1}{2} \mathrm{Ric} _ {p} (v, v) a ^ {3} + O (a ^ {4}).
$$

离散转移概率测度 $\mu _ { x }$ 与连续热核测度的 Wasserstein 距离偏差为 $O ( a ^ { 4 } )$ （因为规则格点的高阶展开系数精确）。因此

$$
\kappa_ {\mathrm{OR}} (x, y) = 1 - \frac {a - \frac {1}{2} \mathrm{Ric} _ {p} a ^ {3} + O (a ^ {4})}{a} = \frac {1}{2} \mathrm{Ric} _ {p} a ^ {2} + O (a ^ {3}).
$$

实际上主项为 $O ( a ^ { 2 } )$ ，误差中 $O ( a ^ { 3 } )$ 可吸收进 $C _ { \mathrm { O R } } a ^ { 2 }$ 。由平坦性 $\operatorname { R i c } = 0$ 得 $\kappa _ { \mathrm { O R } } = { O } \left( a ^ { 2 } \right)$ o

## 2.2 一般图情形

定理 2.2 (Ollivier‑Ricci 曲率收敛（一般图）). 设 $( M , g )$ 是三维平坦光滑黎曼流形（R<sup>3</sup>或 T<sup>3</sup>）， $\left( G _ { a } \right)$ 是一列满足第 $\it 6$ 章假设 6.1-6.3 的图，收敛到 M。则存在常数 $C _ { O R } ^ { \prime }$ 使得当 $a \to 0$ 时，

$$
| \kappa_ {O R} (x, y) | \leq C _ {O R} ^ {\prime} a ^ {1 / 2}.\tag{7.5}
$$

Proof. 由第6章附录6.A，图距离与测地距离的偏差满足 $| d _ { G } ( x , y ) - a | \le C _ { 1 } a ^ { 1 / 2 }$ 。Wasser-stein 距离的离散化误差由第 6 章引理 6.2 保证为 $O ( a ^ { 1 / 2 } )$ 。因此

$$
\kappa_ {\mathrm{OR}} (x, y) = 1 - \frac {a + O (a ^ {1 / 2})}{a + O (a ^ {1 / 2})} = O (a ^ {1 / 2}).
$$

由于流形平坦，连续曲率为 0，故离散曲率以 $O ( a ^ { 1 / 2 } )$ 趋于 0。

## 2.3 随机几何图情形

定理 2.3 (Ollivier‑Ricci 曲率收敛（随机几何图）). 设 $\left( G _ { a } \right)$ 是三维随机几何图（泊松点过程，连接半径 $r _ { n }$ 使平均度 $ 6 )$ ），则以概率 $1 - O ( e ^ { - c n } ) ~ ( n \sim a ^ { - 3 } )$ ）有

$$
| \kappa_ {O R} (x, y) | \leq C _ {O R} ^ {\prime \prime} a ^ {1 / 2}.\tag{7.6}
$$

Proof. 由第 13 章指数浓度，假设 6.1-6.3 以概率 $1 - O ( e ^ { - c n } )$ 成立，因此随机几何图以该概率落入一般图范畴，从而定理 7.2 的结论成立。 □

## 3 Kailuo‑Forman 曲率（KF 曲率）

## 【经典引文】

《道德经》H3.1：大方无禺，大器免成，大音希声，天象无刑。

《周易·系辞上》：易，无思也，无为也，寂然不动，感而遂通。

## 哲学注记

KF 曲率是对 Forman 曲率的“归一化”，使其在平坦背景上归零，从而“大方无禺”真正的曲率显现。

定义 3.1 (原始 Forman 曲率). 对边 $e = ( x , y )$ ，定义

$$
\kappa_ {F} (e) = \frac {w _ {e}}{w _ {x}} + \frac {w _ {e}}{w _ {y}} - \sum_ {e ^ {\prime} \sim e} \frac {w _ {e}}{w _ {e ^ {\prime}}},\tag{7.7}
$$

其中 $\begin{array} { r } { w _ { x } = \sum _ { z \sim x } w _ { x z } } \end{array}$ ，求和 $\sum _ { e ^ { \prime } \sim e }$ 遍取与 e 共享端点的所有边（不含 e 自身）。

定义 3.2 (归一化 KF 曲率). 利用第 3 章和第 6 章证明的平均连接数极限 $\operatorname* { l i m } z _ { n } = 6$ 背景常数取为规则立方格点上的原始 Forman 曲率值的相反数，即 $\begin{array} { r } { B = { \frac { 2 9 } { 3 } } } \end{array}$ 。归一化 $K F$ 曲率为

$$
\kappa_ {K F} (e) = a ^ {2} \left(\kappa_ {F} (e) + \frac {2 9}{3}\right).\tag{7.8}
$$

注. 在规则立方格点 $( \deg = 6$ ，所有边权为 1）上， $w _ { x } = 6 , \ w _ { y } = 6$ ，共享边数 $| \{ e ^ { \prime } \sim$ $e \} | = 6 + 6 - 2 = 1 0$ ，每条共享边的权重 $w _ { e ^ { \prime } } = 1$ 。因此

$$
\kappa_ {F} (e) = \frac {1}{6} + \frac {1}{6} - 1 0 \cdot \frac {1}{1} = \frac {1}{3} - 1 0 = - \frac {2 9}{3}.
$$

于是 $\kappa _ { K F } ( e ) = a ^ { 2 } \left( - \textstyle { \frac { 2 9 } { 3 } } + \textstyle { \frac { 2 9 } { 3 } } \right) = 0$ 。对于一般满足假设 6.1-6.3 的图，平均连接数 $z _ { n }  6$ 背景常数取极限值 $\frac { 2 9 } { 3 }$ 是自洽的。

## 4 Regge 曲率

## 【经典引文】

《道德经》D1.2：皆知善，斯不善矣。

《周易·系辞下》：天地之道，贞观者也。

## 哲学注记

Regge 曲率通过“赤字角”测量弯曲，如同“天地之道，贞观”——以正直（欧氏）为参照，观察偏差。

定义 4.1 (三维单纯复形). 设 K 是三维单纯复形，顶点集 V，边、三角形、四面体满足相容性。每条边 e 赋予长度 $\ell _ { e } > 0$

定义 4.2 (赤字角). 对边 e，定义赤字角

$$
\delta_ {e} = 2 \pi - \sum_ {T \supset e} \theta_ {T} (e),\tag{7.12}
$$

其中 $\theta _ { T } ( e )$ 是四面体 $T$ 中边 e 处的二面角（用欧氏几何计算）。

定义 4.3 (Regge 曲率). 顶点 v 处的数量曲率为

$$
R _ {v} = \frac {1}{V _ {v}} \sum_ {e \ni v} \ell_ {e} \delta_ {e},\tag{7.13}
$$

其中 $V _ { v }$ 是与 v 关联的四面体体积之和。

## 4.1 规则图情形

定理 4.1 (Regge 曲率收敛（规则图）). 对于规则立方格点或 BCC格点的标准三角剖分（四面体剖分），当最大边长 $a \to 0$ 时，

$$
| R _ {v} - R (p) | \leq C _ {R e g} a ^ {2},\tag{7.14}
$$

## 5 离散涌现里奇流

## 哲学注记

里奇流是几何流的“弱”形式——曲率驱动度量演化，如同“弱也者，道之用”。离散涌现里奇流则是在离散网络上模拟这一“生生”过程。

定义 5.1 (涌现里奇流). 设 $G ( t ) = ( V , E , w ( t ) )$ ，边权 $w _ { e } ( t ) > 0$ ，定义

$$
\frac {d}{d t} w _ {e} (t) = - 2 \kappa_ {K F} (e, t) w _ {e} (t),\tag{7.16}
$$

其中 $\kappa _ { K F } ( e , t )$ 是根据当前边权计算的归一化 $K F$ 曲率。初始条件 $w _ { e } ( 0 )$ 给定。时间 t 是第 4 章定义的涌现物理时间。

定理 5.1 (解的存在唯一性). 对任意初始正边权 $w _ { e } ( 0 ) > 0$ ，方程 (7.16) 在 $t \in [ 0 , \infty )$ 上存在唯一解。

Proof. $\kappa _ { \mathrm { K F } } ( e )$ 是 w 的分式线性函数，在正象限内光滑，局部 Lipschitz。由 Picard‑Lindelöf定理，存在唯一局部解。延拓性由边界行为保证：当 $w _ { e } \to 0 ^ { + }$ 时， $\kappa _ { \mathrm { K F } }$ 趋于负无穷，导致 $d w _ { e } / d t > 0$ ，故不会达到零；当 $w _ { e }$ 过大时，曲率可能转为正，减缓增长，故解全局存在。 □

## 5.1 收敛性

定理 5.2 (离散里奇流收敛到连续里奇流). 设 $( M , g ( t ) )$ 是连续里奇流 $\partial _ { t } g = - 2 R i c ( g )$ 的光滑解，初始度规 $g ( 0 )$ 。又设 $\left( G _ { a } \right)$ 是一列图（规则或一般，满足相应假设），初始边权由 $g ( 0 )$ 采样得到。则当 $a \to 0$ 时，离散涌现里奇流的解 $w _ { e } ( t )$ 收敛到连续度量 $g ( t )$ 在边上的限制，收敛速度分别为：

• 一般图/随机几何图： $O ( a ^ { 1 / 2 } )$ o

对于随机几何图，收敛以概率 $1 - O ( e ^ { - c n } )$ 成立。

Proof. 由前述曲率收敛定理，离散 KF 曲率 $\kappa _ { \mathrm { K F } } ( e )$ 以相应速度 $( O ( a ^ { 2 } )$ 或 $O ( a ^ { 1 / 2 } )$ ）逼近连续里奇曲率。离散里奇流方程 (7.16) 是连续里奇流的一阶有限差分离散化。通过比较原理和能量估计，可以证明离散解与连续解的误差由初始误差和曲率逼近误差控制，从而收敛速度与曲率收敛速度一致。详见附录 7.C。 □

## 7 从唯一公理导出的离散曲率五条基本定理

本节从本理论的唯一公理（空间总曲率最小）出发，推导出任何合理的离散曲率必须满足的五条基本定理。

定理 7.1 (尺度一致性). 设离散曲率函数 $\kappa _ { a } ( e )$ 定义在边集上。若将所有边权乘以 $\lambda > 0$ （即 $w _ { e }  \lambda w _ { e } )$ ），则 $\kappa _ { a } ^ { \lambda } ( e ) = \lambda ^ { - 2 } \kappa _ { a } ( e )$ o

Proof. 由公理 1，总曲率泛函 $\mathcal { R } _ { \mathrm { t o t a l } }$ 具有量纲 [长度]<sup>2</sup>（在自然单位制下）。度规的伸缩$g _ { \mu \nu }  \lambda ^ { 2 } g _ { \mu \nu }$ 导致曲率张量变为 $\lambda ^ { - 2 } R _ { \mu \nu }$ 。由于离散曲率是连续曲率的逼近，它必须继承这一伸缩性质。在离散网络中，边长 $w _ { e }$ 的伸缩对应度规的伸缩，因此离散曲率应满足$\kappa _ { a } ^ { \lambda } ( e ) = \lambda ^ { - 2 } \kappa _ { a } ( e )$ 。这是量纲分析的必然要求，可从公理 1 导出。 □

定理 7.2 (局部性). 存在与 $a$ 无关的常数 $L > 0$ ，使得 $\kappa _ { a } ( e )$ 的值只依赖于以 $e$ 为中 $\therefore \because$ 、半径 La 的球内的顶点和边。

Proof. 公理 1 中的总曲率泛函是局域积分的和。在离散化中（第 2 章玄同方程），相互作用只发生在最近邻节点之间（局域性假设）。因此，任何由离散网络涌现的几何量（包括曲率）必须满足局域性——它只能由有限半径内的邻居决定。这是因为空间谐振态（第 15 章）要求信息传递速度有限（光速）。由此可得存在固定的 L 使得 $\kappa _ { a } ( e )$ 是$L a \mathrm { - } \textstyle \overbrace { \mathrm { F } \mathrm { J } } ^ { \bigstar }$ 域的。 □

定理 7.3 (平坦归零). 若 $( M , g )$ 是平坦的（欧氏空间或环面），且图序列 $G _ { a }$ 满足第 6 章假设（从 $\bar { \hbar }$ 收敛到平坦流形），则存在依赖于图类型的常数 $p > 0$ ，使得 $| \kappa _ { a } ( e ) | \leq C a ^ { p }$ 其中 $p = 2$ （规则图）或 $p = 1 / 2$ （一般/随机图）。

Proof. 由公理 1，当空间完全平坦时，总曲率最小泛函退化为零，此时所有曲率量应为零。在离散网络中，由于离散化误差，平坦背景下的离散曲率不会严格为零，但会以某种速度趋于零。第 6 章已证明规则图中图距离与测地距离的偏差为 $O ( a ^ { 2 } )$ ，一般图中为$O ( a ^ { 1 / 2 } )$ 。将曲率表达式展开并利用平坦性，可证得 $| \kappa _ { a } ( e ) |$ 的上界。具体地，对于 Ollivier曲率，误差来自 Wasserstein 距离的近似，其阶与距离偏差相同；对于 KF 曲率，来自局部度数的涨落；对于 Regge 曲率，来自赤字角的数值积分。这些已在第 7.2-7.4 节中分别证明。因此，平坦归零的阶由图的收敛速度决定。 □

定理 7.4 (有界性). 存在常数 $B > 0$ ，使得对所有图 $G _ { a }$ 和所有边 e， $| \kappa _ { a } ( e ) | \leq B a ^ { - 2 }$

Proof. 离散曲率是连续曲率的逼近，连续曲率在光滑流形上有界（因为流形紧致或考虑局部）。离散网络中，最大可能曲率受限于最小边长和最大角度偏差。例如，在规则格点上，Forman 曲率的绝对值有显式上界（与 $a ^ { - 2 }$ 成正比）。一般地，由定理7.2， $\kappa _ { a } ( e )$ 只依赖于有限半径内的有限个顶点，每个顶点度有界（由第 6 章假设），边权有界（最大边长 $\leq R a )$ ），因此 $\kappa _ { a } ( e )$ 不超过 $O ( a ^ { - 2 } )$ 。取上确界可得绝对常数 B。 □

定理 7.5 (收敛性验证). 至少存在一种图序列（例如规则立方格点）和一个光滑流形$( M , g )$ ，使得 $\kappa _ { a } ( e )$ 收敛到连续曲率。对于 Ollivier、KF、Regge，这已在第 7.2-7.4 节中具体证明。

Proof. 这是前几节定理的总结，无需额外证明。它确保了存在性。

## 11 LK 曲率的综合优势与未来前景

## 11.1 理论优势

1. 统一性：LK 曲率首次将 Ollivier‑Ricci、Kailuo‑Forman、Regge 三种离散曲率纳入同一个数学表达式，揭示了它们本质上是同一几何量的不同投影。

2. 公理化基础：从唯一公理导出的五条基本定理，为任何合理的离散曲率提供了严格的准则。

3. 普适收敛定理：填补了离散几何中“离散 → 连续”曲率逼近的一般理论空白。

## 11.2 计算优势

1. 灵活性：通过调节系数可在不同精度和效率间权衡。

2. 计算效率：KF 主导系数仅需局部邻居计数，适合实时处理大规模图数据。

3. 误差可控：普适收敛定理给出了严格的误差界 $O ( a ^ { \operatorname* { m i n } ( p , \gamma ) } )$ 。

## 11.3 物理与引力模拟优势
