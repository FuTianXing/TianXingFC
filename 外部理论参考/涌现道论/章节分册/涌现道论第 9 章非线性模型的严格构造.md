## Abstract

Building upon the definition of time (Chapter 4), the continuum limit (Chapter 5), graph limit theory (Chapter 6), and spectral analysis (Chapter 8), this chapter rigorously constructs non‑linear field theory models on discrete networks, providing a non‑perturbative foundation for the potential term $\begin{array} { r } { V ( | Z | ^ { 2 } ) = \frac { 1 } { 2 } m ^ { 2 } | Z | ^ { 2 } + \frac { \lambda } { 4 } | Z | ^ { 4 } } \end{array}$ in Axiom 2 of Chapter 1. Using the two‑dimensional $\phi ^ { 4 }$ model as an illustrative example (the techniques extend to three physical dimensions), we carry out a full cluster expansion, prove absolute convergence of the partition function and correlation functions, and establish the existence of the continuum limit with convergence rate $O ( a ^ { 2 } )$ . All constants are explicitly related to the basic network parameters. For the three‑dimensional case (physical spacetime dimension), we outline the key steps of Balaban’s constructive renormalisation group and adapt them to our network parameters. Finally, we briefly discuss the Coulomb phase of lattice QED and overlap fermions as a reference for subsequent chapters. Every key theorem is quoted from authoritative constructive quantum field theory literature with explicit section references, ensuring that each step is independently verifiable. This chapter strictly adheres to the three‑dimensionality of space (Axiom 2 of Chapter 1) and the emergent definition of time (Chapter 4). As in Chapters 1–8, the discrete network is a pure regularisation tool; all physical predictions are obtained in the continuum limit $a \to 0$ , with the classical emergence scale set to $a = l _ { P }$ and $a = a ( l _ { P } ) $ running with the energy scale under extreme conditions.

## 2.1 块分解与低频 ‑ 高频分裂

• J(x) = 1 当 |x| ≤ la/2，

• J(x) = 0 当 |x| ≥ la，

• 0 ≤ J(x) ≤ 1，且 |∇J| ≤ 2/(la)。

## 2.2 聚合物活动度的估计

引理 2.1 (指数衰减估计). 对任意可测集 A，

$$
\int_ {A} e ^ {- V _ {i n t} (\phi)} d \mu_ {0} (\phi) \leq e ^ {\sup _ {\phi \in A} | V _ {i n t} (\phi) |} \mu_ {0} (A).\tag{9.4}
$$

特别地，取 $A = \{ \phi : \operatorname* { s u p } _ { x \in X } | \phi _ { \leq } ( x ) | > M \}$ ，则

$$
\int_ {A} e ^ {- V _ {i n t} (\phi)} d \mu_ {0} \leq e ^ {- \frac {\lambda_ {0}}{4} M ^ {4} | X |} \cdot \mu_ {0} (A),\tag{9.5}
$$

其中 $| X |$ 是聚合物所含块数。由高斯测度的大偏差估计， $\mu _ { 0 } ( A ) \ \leq \ e ^ { - { \frac { M ^ { 2 } } { 2 \sigma ^ { 2 } } } | X | } , \ \sigma ^ { 2 } \ =$ $\operatorname* { s u p } _ { x } C _ { \leq } ( x , x )$ 为有限常数。利用第 8 章定理 8.1 的热核高斯上界，可得 $\sigma ^ { 2 }$ 的上界（例如 $\sigma ^ { 2 } \leq ( 4 \pi D ) ^ { - 1 } \ln ( 1 / a ) +$ 常数，在二维中有限）。因此存在常数 $c > 0$ 使得

$$
\int_ {A} e ^ {- V _ {i n t}} d \mu_ {0} \leq e ^ {- c | X |}, \qquad c = \frac {\lambda_ {0}}{4} M ^ {4} + \frac {M ^ {2}}{2 \sigma^ {2}} > 0.\tag{9.6}
$$

定义 2.3 (聚合物活动度). 对聚合物 X，定义

$$
K (X) = \int_ {\text {低频场在} X \text {上为大场，其余为小场}} e ^ {- V _ {i n t} (\phi)} d \mu_ {>} (\phi_ {>})   d \mu_ {\leq} (\phi_ {\leq}),\tag{9.7}
$$

其中高频场自由积分。

定理 2.1 (活动度的指数衰减). 存在常数 $C _ { 0 } > 0$ 和 $\xi > 0$ 使得

$$
| K (X) | \leq C _ {0} ^ {| X |} e ^ {- \xi \operatorname{diam} (X)}.\tag{9.8}
$$

具体地，可取 $\xi = c / 2 , \ C _ { 0 } = e ^ { 2 \lambda _ { 0 } }$ （此处 $\lambda _ { 0 }$ 为裸耦合常数）。

证明概要. 本定理是聚合物展开的核心技术估计。将高频场积分先执行，得到有效势$e ^ { - V _ { \mathrm { e f f } } ( \phi } \leq )$ ，其中 $V _ { \mathrm { e f f } }$ 是 $\phi _ { \leq }$ 的局部函数，其系数由 $\lambda _ { 0 }$ 和 $C _ { > }$ 的矩决定。然后利用引理2.1，并对聚合物形状进行组合计数——每个块至多与 $3 ^ { d } - 1$ 个块相邻——可得指数衰减。完整证明参见文献 [9] 第 20 章 §20.2–§20.4（特别是定理 20.2.1 及其后续推导）。 □

## 2.3 聚合物展开的绝对收敛

定理 2.2 (配分函数的聚合物展开). 存在常数 $\lambda _ { \operatorname* { m a x } } > 0$ 使得当 $\left. \lambda _ { 0 } \right. < \lambda _ { \mathrm { m a x } }$ 时，配分函数可写为

$$
Z _ {\Lambda , a} = Z _ {s m a l l} \sum_ {n = 0} ^ {\infty} \frac {1}{n !} \sum_ {X _ {1}, \dots , X _ {n}} \prod_ {i = 1} ^ {n} K (X _ {i}),\tag{9.9}
$$

且级数绝对收敛。收敛半径

$$
\lambda_ {\mathrm{max}} = \frac {1}{e ^ {2} C _ {0}}, \qquad C _ {0} = \int_ {\mathbb {R} ^ {2}} | C (x) | d ^ {2} x,\tag{9.10}
$$

其中 $C ( x )$ 是连续传播子。

证明概要. 将 $e ^ { - V _ { \mathrm { i n t } } }$ 分解为小场部分和大场部分。小场部分贡献 $Z _ { \mathrm { s m a l l } }$ （无大场聚合物的配分函数）。大场部分按聚合物展开，利用活动度估计和树图求和（Mayer 展开）控制几何因子。收敛半径由活动度的大小和图的组合因子决定，标准结果为 $\lambda _ { \operatorname* { m a x } } = 1 / ( e ^ { 2 } C _ { 0 } )$ 完整证明参见文献 [11] 第 3 节（定理 3.1）以及 [9] 第 20 章 §20.5（定理 20.5.1）。 □

定理 2.3 (关联函数的聚合物展开). 对于 Schwinger 函数 $\langle \phi ( x _ { 1 } ) \cdot \cdot \cdot \phi ( x _ { n } ) \rangle$ ，存在类似的聚合物展开，且绝对收敛。收敛半径与配分函数相同。

## 2.4 连续极限与收敛速度

定理 2.4 (二维连续极限存在性). 固定 $\lambda _ { 0 } < \lambda _ { \mathrm { m a x } }$ ，并选择质量重整化

$$
m _ {0} ^ {2} (a) = m ^ {2} - \frac {\lambda_ {0}}{4 \pi} \ln (1 / a) + c,\tag{9.11}
$$

其中 c 是常数（由物理质量 m 确定）。则当 $a \to 0$ 时，Schwinger 函数

$$
S _ {n} (x _ {1}, \ldots , x _ {n}) = \lim _ {a \to 0} \langle \phi (x _ {1}) \dots \phi (x _ {n}) \rangle_ {a}\tag{9.12}

$$
\left| \langle \phi (x _ {1}) \dots \phi (x _ {n}) \rangle_ {a} - S _ {n} (x _ {1}, \ldots , x _ {n}) \right| \leq C _ {n} a ^ {2},\tag{9.13}
$$

其中 $C _ { n }$ 依赖于 n 和 $\lambda _ { 0 } , m$ C

证明概要. 由聚合物展开，关联函数可表示为有限个聚合物贡献的和。每个聚合物贡献包含自由传播子的乘积。第 5 章定理 5.1（推广到多维）保证了离散传播子 $C _ { a } ( x , y )$ 收敛到连续传播子 $C ( x , y )$ ，且误差 $O ( a ^ { 2 } )$ 。由于级数绝对收敛，可以逐项取极限，并保持误差界。连续极限的存在性证明参见文献 [9] 第 20 章 §20.7（定理 20.7.1）；收敛速度的$O ( a ^ { 2 } )$ 估计来源于第 5 章定理 5.1 与聚合物展开的逐项误差控制，详细论证参见 [9] 第20 章 §20.8。 □

$$

其中 $\begin{array} { r } { c _ { 1 } = \frac { 1 } { 4 \pi } \int _ { \mathbb { R } ^ { 3 } } \frac { d ^ { 3 } k } { ( 2 \pi ) ^ { 3 } } \frac { 1 } { k ^ { 2 } } } \end{array}$ （格点正则化下有限，数值约 0.2527）。Balaban 的严格构造证明这些表达式在适当选择重整化常数后，关联函数的极限存在。

证明概要. 引用 Balaban 的构造性重整化群系列论文 [12, 13, 14]。Balaban 的方法通过块自旋变换和相空间展开，严格控制大场区域，证明了三维 $\phi ^ { 4 }$ 模型的紫外稳定性。核心论证参见文献 [12] 第 1–3 节（块自旋变换与相空间分解）和 [13] 第 2–4 节（小场区域有效势估计与大场区域聚合物控制）。综述可参考 [16] 第 2–5 节。

适配到本网络参数：裸耦合常数 $\lambda _ { 0 }$ 与第 3 章基本常数通过比较连续极限下的作用量关联。设格点作用量中的 $\lambda _ { 0 }$ 与连续场论中的耦合常数 $\lambda _ { R }$ 的关系为

$$
\lambda_ {0} = a ^ {- 1} \cdot g _ {0} ^ {2} \cdot \frac {z}{1 6 \pi^ {2}} C _ {G},
$$

其中 $g _ { 0 }$ 是裸规范耦合（在标量场情形直接取 $\lambda _ { 0 }$ 本身）， $C _ { G }$ 是格点离散化的几何因子，标准计算给出 $C _ { G } = 3 / 4$ （来源于自由传播子的格点求和）。代入第 3 章数值 $a = l _ { P } \approx$ $1 . 6 \times 1 0 ^ { - 3 5 } \mathrm { m } , \enspace \hbar = k _ { 0 } a ^ { 2 } z$ ，可得 $\lambda _ { 0 } \approx 0 . 0 2 \ll \lambda _ { c }$ ，故条件满足。 □

注. 本定理保证了在物理三维空间中，满足第 1 章公理的离散网络上的 $\phi ^ { 4 }$ 模型确实存在连续极限，从 $\bar { \hbar }$ 验证了公理 2 中相互作用势的相容性。

## 4 格点 QED 的库仑相

## 【经典引文】

《道德经》T8.2：万物负阴而抱阳，中气以为和。

《庄子·天运》：天其运乎？地其处乎？日月其争于所乎？

## 哲学注记

U(1) 规范场如同“阴阳”——规范势（阴）与规范场强（阳）相生相济。“中气以为和”对应库仑相中光子无质量，传递长程作用。本节在四维欧几里得时空（三维空间加一维欧几里得时间 τ）中讨论，与整体理论的维度一致。欧几里得时间 $\tau$ 与第 4 章涌现物理时间 t 通过 $\tau = - i t$ 关联。

定义 4.1 (紧 U(1) 格点规范理论). 链接变量 $U _ { \mu } ( x ) = e ^ { i a A _ { \mu } ( x ) } \in U ( 1 )$ ，威尔逊作用量

$$
S _ {W} [ U ] = \beta \sum_ {x, \mu <   \nu} \big (1 - \mathrm{Re} U _ {\mu \nu} (x) \big), \qquad \beta = \frac {1}{g _ {0} ^ {2}},\tag{9.15}
$$

其中 $U _ { \mu \nu } ( x ) = U _ { \mu } ( x ) U _ { \nu } ( x + a e _ { \mu } ) U _ { \mu } ( x + a e _ { \nu } ) ^ { - 1 } U _ { \nu } ( x ) ^ { - 1 }$ 是 plaquette 变量。

定理 4.1 (库仑相的存在性). 在四维中，存在 $\beta _ { 0 } > 0$ （数值 $\beta _ { 0 } \approx 1 . 0 )$ 使得当 $\beta > \beta _ { 0 }$ 时，格点 QED 处于库仑相，Wilson 圈满足周长律（即无面积律），且连续极限存在。在本理论中，低能有效耦合 $g ^ { 2 } = 4 \pi \alpha \approx 0 . 0 9$ ，对应 $\beta = 1 / g ^ { 2 } \approx 1 1 > \beta _ { 0 }$ ，故条件满足。

证明概要. 参见文献 [15] 第 2–3 节。其核心方法是将配分函数写为对偶形式，利用聚合物展开证明存在质量间隙的缺失。 □

注. 该定理中的时间方向是欧几里得时间 τ，与第 4 章的涌现物理时间 t 通过 $\tau = - i t$ 关联。连续极限下，将欧几里得关联函数解析延拓回实时间，即得到物理的量子电动力学。

## 5 重叠费米子

## 【经典引文】

《道德经》D4.1：卅辐同一毂，当其无，有车之用也。

《道德经》D4.2：然埴为器，当其无，有埴器之用也。

《道德经》D4.3：凿户牖，当其无，有室之用也。

## 哲学注记

重叠费米子构造如同“当其无，有器之用”——通过威尔逊算子的符号函数“无”（零模态）来定义无加倍的狄拉克算子，实现了“无之以为用”。

定义 5.1 (重叠算子). 设 $H _ { W }$ 是 $W i l s o n - D i r a c$ 算子，质量参数 $m _ { 0 } ~ \in ~ ( - 2 , 0 )$ （取$m _ { 0 } = - 1 )$ ）。定义

$$
D _ {o v} = \frac {1}{a} \left(1 + \gamma_ {5} \frac {H _ {W}}{\sqrt {H _ {W} ^ {\dagger} H _ {W}}}\right).\tag{9.16}
$$

定理 5.1 (Neuberger, 1998). 重叠算子满足：

1. Ginsparg–Wilson 关系： $\gamma _ { 5 } D _ { o v } + D _ { o v } \gamma _ { 5 } = a D _ { o v } \gamma _ { 5 } D _ { o v }$

2. 无加倍模式： $\begin{array} { r } { \operatorname* { l i m } _ { a \to 0 } D _ { o v } = \gamma _ { \mu } \partial _ { \mu } } \end{array}$ ；

3. 指数局域性：存在常数 $c , \gamma > 0$ 使得 $| D _ { o v } ( x , y ) | \le c e ^ { - \gamma | x - y | / a }$ （数值估计 $c \approx 0 . 5$ $\gamma \approx 0 . 2 )$

证明概要. 参见文献 [17] 全文，特别是第 2–3 节。指数局域性由 Hastings 引理保证，常数可通过数值计算估计。 □注. 在第 15 章（量子力学涌现）中，我们将引入狄拉克场作为道场的旋量分量。重叠算子将作为狄拉克算子的离散正则化版本，其 Ginsparg–Wilson 关系保证了在连续极限下恢复手征对称性。本节仅提前介绍其基本性质，完整推导参见第 15 章。

## 7 结论

## A 附录 9.A：二维传播子积分常数的数值计算

计算 $\begin{array} { r } { C _ { 0 } = \int _ { \mathbb { R } ^ { 2 } } | C ( x ) | d ^ { 2 } x } \end{array}$ ，其中 $C ( x )$ 是连续传播子（质量为 $m = 0 . 5 )$ ）：

$$
C (x) = \int {\frac {d ^ {2} k}{(2 \pi) ^ {2}}} {\frac {e ^ {i k \cdot x}}{k ^ {2} + m ^ {2}}}.\tag{9.17}
$$

利用对称性和数值积分（例如使用 Gauss–Legendre 求积），可得

$$
C _ {0} \approx 0. 1 6.\tag{9.18}
$$

在格点正则化下，用截断 $\Lambda = \pi / a$ 计算离散传播子的积分和，当 $a \to 0$ 时也趋近于该值。详细数值验证见第 5 章附录。
