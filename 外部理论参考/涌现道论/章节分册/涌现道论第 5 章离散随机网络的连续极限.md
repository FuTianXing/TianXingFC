\Lambda_ {a} = \left\{\mathbf {x} = \left(n _ {1} a, n _ {2} a, n _ {3} a\right) \in \mathbb {R} ^ {3}: n _ {i} \in \mathbb {Z}, 0 \leq n _ {i} \leq L / a \right\}.

## 2.2 离散拉普拉斯算子

定义 2.2 (离散拉普拉斯算子). 对函数 $f : \Lambda _ { a } \to$ R，定义加权离散拉普拉斯算子

$$
(\Delta_ {a} f) (\mathbf {x}) = \frac {1}{a ^ {2}} \sum_ {\mu = 1} ^ {3} \sum_ {\sigma = \pm 1} \left(f (\mathbf {x} + \sigma a \mathbf {e} _ {\mu}) - f (\mathbf {x})\right),\tag{5.1}
$$

其中 ${ \bf e } _ { \mu }$ 是坐标单位向量。该算子是自伴的，其特征值为

$$
\lambda_ {\mathbf {n}} (a) = \frac {4}{a ^ {2}} \sum_ {\mu = 1} ^ {3} \sin^ {2} \left(\frac {k _ {\mu} a}{2}\right), \quad k _ {\mu} = \frac {2 \pi n _ {\mu}}{L}, n _ {\mu} = 0, \pm 1, \ldots , \pm \frac {N}{2} - 1, \frac {N}{2}.\tag{5.2}
$$

注. 由泰勒展开，对任意光滑函数 $f$ ，

$$
(\Delta_ {a} f) (\mathbf {x}) = \nabla^ {2} f (\mathbf {x}) + \frac {a ^ {2}}{1 2} \sum_ {\mu = 1} ^ {3} \partial_ {\mu} ^ {4} f (\mathbf {x}) + O (a ^ {4}).\tag{5.3}
$$

因此 $\Delta _ { a }  \nabla ^ { 2 }$ 在 $a \to 0$ 时强收敛，收敛速度 $O ( a ^ { 2 } )$ 。该收敛依赖于第 3 章证明的 $z = 6$ ——若 $z \neq 6$ ，则二阶项系数不再是 1，极限不是标准拉普拉斯。

## 2.3 离散随机热方程——从玄同方程导出（Parisi–Wu 方法）

为避免 Wick 旋转带来的 Itô 修正歧义，我们采用 Parisi–Wu 随机量子化方法 [12]直接从第 2 章玄同方程推导欧几里得随机热方程。

第 2 章玄同方程（忽略张力项，标量场）为：

$$
i \frac {\partial \Psi}{\partial t} = \Delta_ {a} \Psi + \xi ,
$$

其中 $\xi$ 是复白噪声， $\langle \xi ( p , t ) \xi ^ { \dagger } ( q , s ) \rangle = 2 \delta _ { p q } \delta ( t - s )$ 。引入虚构的朗之万时间 τ（即第 4 章涌现时间），令 $\Psi = \Phi + i \Pi$ ，并考虑欧几里得化：将 $t \to - i \tau$ 后，实部和虚部解耦，最终可得实噪声驱动的朗之万方程：

$$
\frac {\partial \Phi}{\partial \tau} = - \Delta_ {a} \Phi - V ^ {\prime} (\Phi) + \eta ,
$$

其中 $\eta$ 是实高斯白噪声，协方差 $\langle \eta ( p , \tau ) \eta ( q , \tau ^ { \prime } ) \rangle = 2 \delta _ { p q } \delta ( \tau - \tau ^ { \prime } )$ 。详细推导见附录 5.B。

在自由场近似下 $( V ^ { \prime } ( \Phi ) = m ^ { 2 } \Phi )$ ），我们得到离散随机热方程：

$$
\frac {\partial \Phi}{\partial t} = \Delta_ {a} \Phi - m ^ {2} \Phi + \sqrt {2 \Gamma} \eta_ {a},\tag{5.4}
$$

其中 $\eta _ { a }$ 满足 $\langle \eta _ { a } ( p , t ) \eta _ { a } ( q , s ) \rangle = a ^ { - 3 } \delta _ { p q } \delta ( t - s )$ $\Gamma = 1 / 2$ 。本章将 Φ 记作 $Z _ { a }$ ，即得以下定义。

定义 2.3 (离散随机热方程). 设 $\eta _ { a } ( \mathbf { x } , t )$ 是离散时空高斯白噪声，满足

$$
\mathbb {E} [ \eta_ {a} (\mathbf {x}, t) ] = 0, \quad \mathbb {E} [ \eta_ {a} (\mathbf {x}, t) \eta_ {a} (\mathbf {y}, s) ] = 2 \Gamma a ^ {- 3} \delta_ {\mathbf {x y}} \delta (t - s),\tag{5.5}
$$

其中 $\delta _ { \mathbf { x } \mathbf { y } }$ 是 Kronecker delta， $\Gamma = 1 / 2$ 。离散随机热方程为

$$
\frac {\partial Z _ {a}}{\partial t} = \Delta_ {a} Z _ {a} - m _ {a} ^ {2} Z _ {a} + \sqrt {2 \Gamma} \eta_ {a} (\mathbf {x}, t).\tag{5.6}
$$

这里 $m _ { a } ^ { 2 } = \theta _ { 0 } / \mu _ { 0 } + O ( a ^ { 2 } )$ ，在连续极限下趋于物理质量平方 $m ^ { 2 } .$ 。时间 t 即为第 $\it 4$ 章涌现的物理时间。

## 3.3 热核的逐点收敛

定义 3.1 (离散热核). 离散热核定义为

$$
h _ {a} (t, x _ {j}, x _ {k}) = \frac {1}{N} \sum_ {n = 0} ^ {N - 1} e ^ {- \lambda_ {n} (a) t} \phi_ {n} ^ {(a)} (x _ {j}) \phi_ {n} ^ {(a)} (x _ {k}),\tag{5.12}

其中 $\phi _ { n } ^ { ( a ) } ( x _ { j } ) = e ^ { i k _ { n } x _ { j } } / \sqrt { L }$ 是归一化特征函数。

定理 3.1 (一维热核的逐点收敛). 对任意固定的 $t > 0$ 和 $x , y \in [ 0 , L ]$ ，存在常数 $C _ { 1 } =$ $\begin{array} { r } { \frac { 1 } { 4 } ( t + | x - y | ^ { 2 } ) e ^ { - m ^ { 2 } t } , C _ { 2 } = \frac { 1 } { 2 \pi a ^ { 2 } } e ^ { - ( \pi / a ) ^ { 2 } t } } \end{array}$ ，使得当 a 充分小时，

$$
\left| h _ {a} \left(t, x _ {j}, x _ {k}\right) - h (t, x, y) \right| \leq C _ {1} a ^ {2} + C _ {2} a ^ {2},\tag{5.13}
$$

其中 $h ( t , x , y ) = ( 4 \pi t ) ^ { - 1 / 2 } e ^ { - ( x - y ) ^ { 2 } / ( 4 t ) } e ^ { - m ^ { 2 } t }$ 是连续热核。

完整证明. 离散热核可写为

$$
h _ {a} (t, x, y) = \frac {1}{2 \pi} \sum_ {n = - \infty} ^ {\infty} e ^ {- \lambda_ {n} (a) t} e ^ {i k _ {n} (x - y)} \Delta k,
$$

其中 $\Delta k = 2 \pi / L , \ k _ { n } = n \Delta k .$ 。将 $f _ { a } ( k ) = e ^ { - \lambda ( k , a ) t } e ^ { i k ( x - y ) }$ 视为 k 的函数，其中 $\lambda ( k , a ) =$ $\begin{array} { r } { \frac { 4 } { a ^ { 2 } } \sin ^ { 2 } ( k a / 2 ) + m _ { a } ^ { 2 } } \end{array}$ 。Riemann 和与积分之差由 Euler-Maclaurin 公式给出：

$$
\sum_ {n = - N / 2} ^ {N / 2 - 1} f _ {a} (k _ {n}) \Delta k - \int_ {- \pi / a} ^ {\pi / a} f _ {a} (k) d k = \frac {(\Delta k) ^ {2}}{2 4} \left[ f _ {a} ^ {\prime} (\pi / a) - f _ {a} ^ {\prime} (- \pi / a) \right] + O ((\Delta k) ^ {4}).
$$

由于 $f _ { a } ^ { \prime } ( \pm \pi / a )$ 含有因子 $e ^ { - ( \pi / a ) ^ { 2 } t }$ ，该项乘以 $( \Delta k ) ^ { 2 } = ( 2 \pi / L ) ^ { 2 }$ 后为 $O ( e ^ { - ( \pi / a ) ^ { 2 } t } / L ^ { 2 } )$ ，当L 充分大时可忽略。主误差来自二阶项：

$$
\sum_ {n} f _ {a} (k _ {n}) \Delta k = \int_ {- \pi / a} ^ {\pi / a} f _ {a} (k) d k + \frac {(\Delta k) ^ {2}}{1 2} \int_ {- \pi / a} ^ {\pi / a} f _ {a} ^ {\prime \prime} (k) d k + O ((\Delta k) ^ {4}).
$$

计算 $f _ { a } ^ { \prime \prime } ( k )$ 并利用 $\begin{array} { r } { \lambda ( k , a ) = k ^ { 2 } + m ^ { 2 } - \frac { a ^ { 2 } } { 1 2 } k ^ { 4 } + O ( a ^ { 4 } ) } \end{array}$ ，可得

$$
\int_ {- \pi / a} ^ {\pi / a} f _ {a} (k) d k = \int_ {- \infty} ^ {\infty} e ^ {- (k ^ {2} + m ^ {2}) t} e ^ {i k (x - y)} d k + O (e ^ {- (\pi / a) ^ {2} t}).
$$

后一项指数小。而 $\frac { ( \Delta k ) ^ { 2 } } { 1 2 } \int f _ { a } ^ { \prime \prime } ( k ) d k$ 给出 $O ( a ^ { 2 } )$ 误差，且系数有界。具体计算可得常数$C _ { 1 }$ 。截断误差（将积分上限从 $\pi / a$ 扩展到 $\infty )$ 为 $O ( e ^ { - ( \pi / a ) ^ { 2 } t } / a ^ { 2 } )$ 。将绝对误差乘以 $a ^ { 2 }$ 后， $e ^ { - ( \pi / a ) ^ { 2 } t }$ 超越任何幂律，故最终误差为 $O ( a ^ { 2 } )$ □

## 3.4 扩散极限

定理 3.2 (一维扩散极限与收敛速度). 设 $u _ { a } ( x , t )$ 是离散方程 (5.7) 解的线性插值，初始条件 $u _ { a } ( x , 0 ) = u _ { 0 } ( x )$ ， $u _ { 0 } \in H ^ { 2 } ( [ 0 , L ] )$ 。定义标度变换

$$
\tau = a ^ {2} t, \quad v _ {a} (x, \tau) = u _ {a} (x, \tau / a ^ {2}).\tag{5.14}
$$

则当 $a \to 0$ 时， $v _ { a }$ 在 $L ^ { 2 }$ 中收敛到 v，且

$$
\| v _ {a} (\cdot , \tau) - v (\cdot , \tau) \| _ {L ^ {2}} \leq C a ^ {2} \| u _ {0} \| _ {H ^ {2}},\tag{5.15}
$$

其中 $v ( x , \tau )$ 是连续扩散方程 $\partial _ { \tau } v = \partial _ { x } ^ { 2 } v$ 的解，常数 C 依赖于 T 但不依赖于 a。

证明概要. 将原方程 (5.7) 代入标度变换，得 $\begin{array} { r } { \partial _ { \tau } v _ { a } = \Delta _ { a } v _ { a } + O ( a ^ { 2 } ) } \end{array}$ 。利用有限差分能量估计（参见 [6] §2.6）和随机积分的 Itô 等距，可得收敛速度 $O ( a ^ { 2 } )$ 。详细计算见附录 5.A。

## 7 连续极限的唯一性

定理 7.1 (极限的唯一性). 设 $\{ u _ { { a } _ { n } } \}$ 是一列离散解（来自热方程 $( 5 . 6 ) )$ ），且当 $a _ { n } \to 0$ 时， $u _ { a _ { n } }$ 在 $L ^ { 2 }$ 中弱收敛到某个函数 $u _ { \circ }$ 则 u 必满足热方程

Proof. 利用热核收敛定理（定理3.1、5.1）和谱收敛（定理4.1、4.2），对任意测试函数$\phi$ ，有 $\left. u _ { a _ { n } } ( t ) , \phi \right. \to \left. e ^ { t ( \nabla ^ { 2 } - m ^ { 2 } ) } u _ { 0 } , \phi \right.$ ，从而极限为热方程解。唯一性由热方程解的唯一性保证 [8]。 □

## 8 非紧流形的谱收敛（泊松求和公式法）

以上结果均假设空间区域有界。为处理物理上更自然的无限大空间 R<sup>3</sup>，本节采用泊松求和公式直接证明在 R<sup>3</sup> 上离散拉普拉斯的热核收敛到连续热核，且收敛速度指数快，从而远强于幂律 $O ( a ^ { 2 } )$

连续热核：

$$
h (t, \mathbf {x}, \mathbf {y}) = \frac {1}{(2 \pi) ^ {3}} \int_ {\mathbb {R} ^ {3}} e ^ {- (| \mathbf {k} | ^ {2} + m ^ {2}) t} e ^ {i \mathbf {k} \cdot (\mathbf {x} - \mathbf {y})} d ^ {3} k.
$$

离散求和（取热力学极限 $L \to \infty$ 后）：

$$
h _ {a} (t, \mathbf {x}, \mathbf {y}) = \frac {1}{(2 \pi) ^ {3}} \int_ {| \mathbf {k} | \leq \pi / a} e ^ {- (| \mathbf {k} | ^ {2} + m ^ {2}) t} e ^ {i \mathbf {k} \cdot (\mathbf {x} - \mathbf {y})} d ^ {3} k + \text {边界项（周期边界）}.
$$

由于被积函数指数衰减，截断误差为

$$
\frac {1}{(2 \pi) ^ {3}} \int_ {| {\bf k} | > \pi / a} e ^ {- (| {\bf k} | ^ {2} + m ^ {2}) t} e ^ {i {\bf k} \cdot ({\bf x} - {\bf y})} d ^ {3} k = O (e ^ {- (\pi / a) ^ {2} t}),

指数小。而周期边界条件引入的误差在 $L  \infty$ 时消失。因此，对于任意固定的 $t > 0$ 和 $\mathbf x , \mathbf y$

$$
\left| h _ {a} (t, \mathbf {x}, \mathbf {y}) - h (t, \mathbf {x}, \mathbf {y}) \right| = O \left(e ^ {- c / a ^ {2}}\right).
$$

这比任何幂律都快，特别地满足 $O ( a ^ { 2 } )$ 要求。

定理 8.1 $\left( \mathbb { R } ^ { 3 } \right.$ 上的热核收敛). 对于任意固定的 $t > 0$ 和 $\mathbf { x } , \mathbf { y } \in \mathbb { R } ^ { 3 }$ ，离散热核 $h _ { a } ( t , { \bf x } , { \bf y } )$ 满足

## 9 与第三章光速表达式的自洽性

本章证明了离散拉普拉斯 $\Delta _ { a }$ 在连续极限下收敛到连续拉普拉斯 $\nabla ^ { 2 }$ ，且收敛速度明确。在自然单位制中，光速 $c = 1$ ，所以波动方程应为 $\begin{array} { r } { \frac { \partial ^ { 2 } \Phi } { \partial t ^ { 2 } } = \nabla ^ { 2 } \Phi } \end{array}$ 。若恢复国际单位制，通过量纲分析，扩散系数变为 $c ^ { 2 }$ ，声速（光速）变为 $c _ { \circ }$ 。由于 $\Delta _ { a }  \nabla ^ { 2 }$ ，且离散波动方程（可从第 2 章玄同方程对矢量场取连续极限得到）中的系数为 $a ^ { 2 } k _ { 0 } z / \mu _ { 0 }$ ，而第 3章 [3] 已证明该组合等于 $c ^ { 2 }$ （因为 $c ^ { 2 } = a ^ { 2 } k _ { 0 } z / \mu _ { 0 } )$ ），因此本章的收敛性保证了波动方程中的空间导数项精确地乘以 $c ^ { 2 }$ 。换言之，如果从离散动力学出发取连续极限，得到的光速必定是 $c = a \sqrt { k _ { 0 } z / \mu _ { 0 } }$ 。所以本章为第 3 章的光速表达式提供了收敛性验证。

## B 附录 5.B：从玄同方程到离散热方程的第一性原理推导（Parisi–Wu 方法）

## B.1 B.1 玄同方程的回顾（自然单位制）

第 2 章玄同方程 (2.17)[2] 在忽略张力项、均匀各向同性近似下，对标量场为：

$$
i \frac {\partial \Psi (p , t)}{\partial t} = \Delta_ {a} \Psi (p, t) + \xi (p, t),\tag{B.1}
$$

其中 $\xi$ 是复白噪声，满足 $\langle \xi ( p , t ) \xi ^ { \dagger } ( q , s ) \rangle = 2 \delta _ { p q } \delta ( t - s )$ ，t 是第 4 章定义的涌现时间。

## B.2 B.2 Parisi–Wu 随机量子化

引入虚构的朗之万时间 $\tau = t$ （此处视为相同，但将量子力学中的 real time 替换为 Euclidean time 通过 Wick 旋转）。为了得到实噪声驱动的实场方程，我们写出$\Psi = \Phi + i \Pi$ ，实部和虚部满足耦合方程。直接进行 Wick 旋转 $t \to - i \tau$ ，并取实部，可得：

$$
\frac {\partial \Phi}{\partial \tau} = - \Delta_ {a} \Phi - V ^ {\prime} (\Phi) + \eta ,\tag{B.2}
$$

其中 $\eta$ 是实高斯白噪声，协方差 $\langle \eta ( p , \tau ) \eta ( q , \tau ^ { \prime } ) \rangle = 2 \delta _ { p q } \delta ( \tau - \tau ^ { \prime } )$ 。具体推导见 [12]。在自由场近似 $V ^ { \prime } ( \Phi ) = m ^ { 2 } \Phi$ 下，得到：

$$
\frac {\partial \Phi}{\partial \tau} = - \Delta_ {a} \Phi - m ^ {2} \Phi + \eta .\tag{B.3}
$$

为得到正扩散，令 $\tau  - \tau$ 并重定义噪声符号，得：

$$
\frac {\partial \Phi}{\partial \tau} = \Delta_ {a} \Phi - m ^ {2} \Phi + \eta^ {\prime},\tag{B.4}
$$

其中 $\eta ^ { \prime }$ 与 $\eta$ 同分布。将 τ 重记为 t，Φ 重记为 $Z _ { a }$ ，并归一化噪声强度 $\eta ^ { \prime } = \sqrt { 2 \Gamma } \eta _ { a }$ $\Gamma = 1 / 2$ ，即得方程 (5.6)。因此，离散随机热方程是玄同方程的欧几里得版本。
