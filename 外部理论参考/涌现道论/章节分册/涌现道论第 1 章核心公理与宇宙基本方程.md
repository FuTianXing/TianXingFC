## 与前沿理论对话：量子引力中的时间问题

本理论与当前量子引力前沿研究的核心问题——时间问题（problem of time）存在深刻关联，同时也展现出根本不同的解决思路。

量子引力中最具挑战性的问题之一是“时间问题”：在广义相对论中，时间是演化的参数，而在量子引力中，Wheeler-DeWitt 方程给出的宇宙波函数却满足 [11]：

$$
\hat {\mathcal {H}} \Psi [ h ] = 0,
$$

该方程不含时间参数，暗示了量子宇宙在某种意义上是“无时”的。这一困境的根源在于广义相对论的时间重参数化不变性（difeomorphism invariance）与量子力学中外部时间的预设之间的不兼容 [11]。

针对这一困境，学界已发展出多种解决路径：

• Page-Wootters 机制：通过将宇宙分为时钟子系统和剩余系统，相对时间从纠缠中涌现，原始提议存在动力学歧义性，但近年的研究正逐步解决这些歧义、拓展其适用范围 [11]；

• Rovelli 的热时间假说：时间的流动不是基本的，而是由系统的统计状态和热力学作用量定义；在平衡态附近，热时间流动与外部时间一致，但这一定义在远离平衡态时变得模糊，且背景独立性和规范不变性的实现仍是难题 [12, 13, 14, 15]；

• 关系量子力学：将量子理论重构为不同系统之间信息的理论，否认绝对态的存在，将物理量理解为系统间的关系，适用于无背景、无演化的元理论 [16]；

• 圈量子引力中的完全忽略时间：通过构建无背景、无时间的量子引力形式体系，发展了在完全无时框架下的量子理论，但其与经验的连接是持续的研究焦点 [11]。

此外，时空热力学框架揭示引力动力学可从热力学原理导出 [17]，而非对易几何（量子群）方案将时空坐标视为非对易算子以模拟量子引力效应 [18]，但这两者仍需深层机制的支撑。

本理论与上述前沿工作共享“时间不是基本维度”的核心洞见，但在根本机制上截然不同：

• 根源不同：Page-Wootters 将相对时间归因于子系统间的量子纠缠；热时间假说依赖统计状态和平衡态假设；本理论则将时间的涌现归因于虚数单位 i 所驱动的信息相变——每次相变对应一次“潜在 → 显现”的信息转化，其宏观累积即时间。这一机制在基础层面上为 i 赋予了物理意义，是 Page-Wootters 演化算符 $e ^ { - i H t / \hbar }$ 中 i 的生成元解释，而非仅作为功能记号。

注 (规范场的涌现来源). 公理中出现的规范场 $A _ { \mu }$ 并非基本自由度，而是从道场 Z 的相位梯度通过规范固定涌现的有效场。后续章节将严格证明，离散网络中的持久环路方向集唯一地给出规范群 $S U ( 3 ) \times S U ( 2 ) \times U ( 1 )$ ，并且环路链接数与根系内积的关系直接导出杨-米尔斯作用量。

## 4.1 定理 1（道场的复结构与全息相变）

定理 4.1 (道场的复结构与全息相变). 由公理3.1的变分原理，道场 $Z = X + i Y$ 的实部与虚部通过虚数单位 i 耦合，且 $i ^ { 2 } = - 1$ 对应于两次全息相变后状态回归。总信息

$$
I _ {t o t} = \int_ {M} | Z | ^ {2} d \mu\tag{7}
$$

在演化中守恒。时间的微观起源：虚数单位 i 驱动着潜在信息（虚部 Y）向可观测信息（实部 X）的持续转化，每次转化对应一个基本的信息量子，其宏观累积效应即时间 $[ { \mathcal { 3 } } ] _ { \mathfrak { i } }$ 固有时微分 $\begin{array} { r } { d \tau = \frac { d \rho } { \rho } t _ { P } } \end{array}$ 正比于单位时间内发生的信息相变次数。

证明概要. 公理3.1的作用量具有全局 $U ( 1 )$ 对称性 $Z \to e ^ { i \theta } Z$ （因 $| D Z | ^ { 2 }$ 和 $V ( | Z | ^ { 2 } )$ 在该变换下不变，且 $A _ { \mu }$ 作为背景场不变）。由诺特定理 [2]，守恒流

$$
J ^ {\mu} = i \left(Z ^ {*} \partial^ {\mu} Z - Z \partial^ {\mu} Z ^ {*}\right)\tag{8}
$$

满足 $\nabla _ { \mu } J ^ { \mu } = 0$ ，积分得总信息守恒。虚数单位的出现源于协变导数 $D _ { \mu } = \partial _ { \mu } + i A _ { \mu }$ 中的最小耦合，其平方 $i ^ { 2 } = - 1$ 是代数必然。信息相变的解释来自定义5.1。 □推论 4.1 (时间的全息起源). 由上述，时间本质上是信息相变计数器： $\tau = N \cdot t _ { P }$ ，其中N 是累积相变次数， $t _ { P }$ 是普朗克时间。能量密度变化率 $\dot { \rho } / \rho$ 正比于相变速率。

## 4.2 定理 2（空间基态与宇宙常数）

定理 4.2 (空间基态与宇宙常数). 空间是张力场 Θ 与耦合力场 K 的动态谐振态（Θ 和K 将在后续章节精确定义，本章借用其名称表达空间谐振的物理思想）。

1. 存在常数 $Z _ { 0 } \in \mathbb { C }$ （基态道场）使得 $V ^ { \prime } ( | Z _ { 0 } | ^ { 2 } ) Z _ { 0 } = 0$ （势能极小），且满足平衡条件$\Theta ( p ) Z _ { 0 } = 0$ 与 $\begin{array} { r } { \sum _ { q \in N ( p ) } K ( p , q ) ( Z ( q ) - Z ( p ) ) = 0 } \end{array}$ 在 $Z \equiv Z _ { 0 }$ 时成立。基态能量密度 $\rho _ { 0 } = | Z _ { 0 } | ^ { 2 }$ ，宇宙常数

$$
\Lambda = \frac {8 \pi G}{c ^ {4}} \rho_ {0}.\tag{9}
$$

2. 激发态 $\delta Z = Z - Z _ { 0 }$ 在闵可夫斯基背景（作为零级近似）上满足线性化波动方程

$$
\Box \delta Z + m _ {p h y s} ^ {2} \delta Z = 0, \qquad \Box = \partial_ {t} ^ {2} - \nabla^ {2},\tag{10}
$$

其中物理质量 $m _ { p h y s }$ 由势能二阶导数决定：对于标准 $\phi ^ { 4 }$ 势，若 $Z _ { 0 } = 0$ 则 $m _ { p h y s } ^ { 2 } =$ $m ^ { 2 }$ ；若对称破缺 $( m ^ { 2 } < 0 )$ ），则 $m _ { p h y s } ^ { 2 } = - 2 m ^ { 2 }$ ，具体见后续章节。波动传播速度

$$
c = a \sqrt {\frac {k _ {0} z}{\mu_ {0}}},\tag{11}
$$

由耦合力场背景值 $k _ { 0 }$ 、平均连接数 z = 6 和有效惯性 $\mu _ { 0 }$ 决定。

3. 谐振态的本质：空间基态并非静止常数场，而是张力场与耦合力场之间的动态谐振。在经典层次，该谐振表现为稳定平衡；在量子化后（后续章节），该谐振表现为普朗克尺度上的虚粒子对产生与湮灭 $\displaystyle { \bigl [ } 4 , \ 7 { \bigr ] }$ ，其平均能量密度正是 $\rho _ { 0 }$ 。微观振荡与宏观膨胀兼容：瞬时振荡是对称的，长时间平均给出 $\rho _ { 0 }$ ，非零的 $\rho _ { 0 }$ 驱动宇宙加速膨胀（见后续章节）。

证明概要. 公理3.1的势能项 $V ( | Z | ^ { 2 } )$ 的极小值点给出 $Z _ { 0 }$ 。在一级近似下，取背景度规为闵可夫斯基 $\eta _ { \mu \nu }$ ，规范场 $A _ { \mu } = 0$ ，忽略非线性项，将 $Z = Z _ { 0 } + \delta Z$ 代入变分方程，线性化即得波动方程 [4]。宇宙常数由爱因斯坦场方程（源于 $R ( g )$ 的变分）与物质场能量-动量张量匹配得出。谐振态的解释来自后续章节的动力学方程。 □

## 4.3 定理 3（时间涌现）

定理 4.3 (时间涌现). 时间不是基本维度，而是信息相变（由虚数单位 i 驱动）的宏观累积。定义三个层次的时间：

1. 微观固有时：设 $\rho ( x ) = | Z ( x ) | ^ { 2 } > 0$ 。对任意光滑路径 $\gamma$ ，沿该路径定义

$$
d \tau_ {m i c r o} (x) = \frac {d \rho (x)}{\rho (x)} t _ {P}, \qquad t _ {P} = \sqrt {\frac {\hbar G}{c ^ {5}}}.\tag{12}
$$

$d \rho$ 是沿固有时方向（即信息相变方向）的微分。若沿世界线 $\rho \equiv$ 常数（如光子、静态基态），则 $d \tau _ { m i c r o } = 0$ ，表示该粒子不经历固有时流逝。

2. 局部相对时间：对局部区域 $R \subset M$ （如一个粒子或体积元），定义

$$
d t _ {R} = \frac {\int_ {R} d \rho (x)}{\int_ {R} \rho (x) d ^ {3} x} t _ {P}.\tag{13}
$$

$d t _ { R }$ 是区域 R 作为整体的时间流速，依赖参考系（通过 $\rho$ 的变换）。不同运动状态的区域有不同的 $d t _ { R }$ ，体现了时间的相对性。

3. 全局坐标时间：定义平均固有时微分

$$
d \tau = \frac {\int_ {M} d \rho (x)}{\int_ {M} \rho (x) d ^ {3} x} t _ {P},\tag{14}
$$

并令全局坐标时间 t 满足 $d t = d \tau$ （可加常数）。孤立系统总能量不变，故 $\textstyle \int _ { M } d \rho = 0$ 从而 $d \tau = 0$ ，即整体固有时停止；但内部局部时间仍可流动（如热力学第二定律的熵增 $[ { \boldsymbol { \vartheta } } ] )$

物理本质：时间源于虚数单位 i 驱动的信息相变——每次相变将部分潜在信息（Y）转化为可观测信息（X），伴随能量密度变化 $d \rho$ 。累积相变次数 $N = | d \rho | / \rho$ 与固有时 $\tau$ 成正比。因此，时间不是背景，而是道场内部虚实转化的自度量 $\it { \Delta } \it { \it { / 3 } } \it { \Delta }$

例证：

• 光子：平面波模式能量密度恒定，无信息相变，固有时为零。

• 有质量粒子（电子）：局域能量密度沿世界线变化（如加速、势能变化）， $\dot { \bar { y } }$ 生连续相变，固有时流逝。

• 孤立宇宙：整体固有时为零，不阻碍内部能量重新分布（熵增），与热力学第二定律兼容。

• 时间箭头：能量从高密度流向低密度，使总曲率减小，方向即信息相变的方向。

底层解释：薛定谔方程的位置：在非相对论近似且信息相变速率 $\dot { \rho } / \rho$ 近似恒定时，道场演化方程可约化为含时薛定谔方程

$$
i \hbar \frac {\partial}{\partial t} \psi = \hat {H} \psi ,\tag{15}
$$

其中 $\psi$ 是道场的投影（如 Z 的归一化模式），时间 t 正比于累积相变次数 N。不含时薛定谔方程

$$
\hat {H} \psi = E \psi\tag{16}
$$

对应于 $\dot { \rho } = 0$ 的稳态解（如原子定态、自由光子）。因此，含时与不含时方程是统一信息相变动力学的两个特例：前者描述恒定相变速率下的演化，后者描述相变暂停的静态。测量过程涉及瞬时相变速率突变，故无法用含时方程自洽描述，必须回归本框架。

证明概要. 从公理3.1导出的能量-动量守恒 $\nabla _ { \mu } T ^ { \mu \nu } = 0$ ，在非相对论近似下得连续性方程 $\begin{array} { r } { \partial _ { t } \rho + \nabla \cdot \boldsymbol { S } = 0 , } \end{array}$ 。沿流线， $d \rho / d t = - \rho ( \nabla \cdot \pmb { v } )$ ，故 $d \rho / \rho$ 是时间微元的自然度量 [4]。普朗克时间 $t _ { P }$ 由量纲分析固定。信息相变的解释由推论4.1给出。 □

## 4.4 定理 4（质量惯性）

定理 4.4 (质量惯性). 质量是空间抵抗自身几何形变以维持结构稳定的惯性度量。设$\delta Z = Z - Z _ { 0 }$ 为偏离基态的形变。定义惯性质量密度

$$
\rho_ {i n e r t i a l} (x) = \mu_ {0} | \partial_ {t} \delta Z (x) | ^ {2},\tag{17}
$$

其中 $\mu _ { 0 } > 0$ 是有效惯性常数（其与网络参数的关系在后续章节给出）， $\partial _ { t }$ 是定理4.3定义的固有时导数。引力质量密度

$$
\rho_ {g r a v} (x) = T _ {0 0} (x) / c ^ {2},\tag{18}
$$

$T _ { \mu \nu }$ 由公理3.1中物质场的变分导出（在闵可夫斯基背景上，

$$
T _ {\mu \nu} = \partial_ {\mu} Z \partial_ {\nu} Z + \partial_ {\nu} Z \partial_ {\mu} Z - \eta_ {\mu \nu} | \partial Z | ^ {2}\tag{19}
$$

）。则惯性质量与引力质量逐点相等：

$$
\rho_ {i n e r t i a l} (x) = \rho_ {g r a v} (x) \quad \forall x \in M.\tag{20}
$$

静止质量：对局域拓扑扭结解（物质粒子），总能量 $\begin{array} { r } { E _ { 0 } = \int \rho _ { g r a v } d ^ { 3 } x . } \end{array}$ ，静止质量 $m _ { 0 } = E _ { 0 } / c ^ { 2 }$ 静止质量在粒子自身质心系中定义，体现空间形变的幅度；惯性质量反映形变随时间的抵抗。

证明概要. 从公理3.1对 Z 变分得到场方程，其时间分量的平方项给出动能密度 $\frac { 1 } { 2 } | \partial _ { t } Z | ^ { 2 }$ 同时，从 $R ( g )$ 变分得到爱因斯坦场方程，右端 $T _ { 0 0 }$ 包含同样的项 [4]。比较系数即得$\mu _ { 0 } = 1$ （在自然单位制中）。 □

## 4.5 定理 5（温度统计与涨落-耗散关系）

定理 4.5 (温度统计与涨落-耗散关系). 系统的热平衡态由正则系综描述：

$$
\rho_ {e q} (Z) = \frac {1}{\mathcal {Z}} e ^ {- H [ Z ] / (k _ {B} T)}, \qquad \mathcal {Z} = \int \mathcal {D} Z e ^ {- H [ Z ] / (k _ {B} T)},\tag{21}
$$

其中 $H [ Z ]$ 是公理3.1作用量对应的哈密顿量 $[ { \boldsymbol { \mathscr { g } } } ]$ 。温度 $T$ 与微观涨落强度 h¯ 满足涨落-耗散定理：

$$
k _ {B} T = \frac {\hbar \omega_ {c}}{2}, \qquad \omega_ {c} = \frac {c}{a},\tag{22}
$$

其中 $a$ 是平均格距（正则化截断）。该关系在连续极限下通过重整化群保持有限（见后续章节 $[ 5 ] )$ ）。

证明概要. 在离散网络（定义2.4）中，公理3.1的泛函离散化为格点作用量。路径积分测度 DZ 在离散化下成为有限维积分，其高斯部分的方差由涨落-耗散定理决定 [9]。通过匹配连续极限下的两点函数，得到 $k _ { B } T = \hbar c / ( 2 a )$ 。正则系综形式由平衡态的最大熵原理导出。正则化参数 a 在连续极限下被吸收进重整化常数，不出现于最终物理量中。

定义 5.1 (全息相变算子 i). 虚数单位 i 表征信息从潜在关联（道场虚部 $Y = \operatorname { I m } Z )$ 向可观测存在（实部 $X =  { \mathrm { R e } } Z )$ 的转化算子。 $i ^ { 2 } = - 1$ 对应于两次转化后状态回归（先由隐至显，再由显至隐）。该转化过程在宏观上表现为时间的流逝：每一次信息相变贡献一个普朗克时间单位 $t _ { P }$ ，累积的相变次数即固有时 $\tau / 3 ]$

$$

定义 5.3 (时间). 由定理 $4 . 3 ,$ ，物理时间分为：微观固有时 ${ { \tau } _ { m i c r o } }$ 、局部相对时间 $t _ { R }$ 、全局坐标时间 $t _ { \circ }$ 。三者分别对应能量密度变化率的点值、区域平均值、全局平均值。物理时间本质上是信息相变（由 i 驱动）的累积 $[ { \mathcal { B } } ] .$

## 核心哲学总结

• 空间本质上是张力场与耦合力场构成的波动海洋——在普朗克尺度永不停息地振荡（虚粒子对产生与湮灭），在宏观尺度表现为稳定的几何结构，其平均水位（基态能量密度）驱动宇宙膨胀 [7]。

• 时间不是绝对容器，而是由虚数单位 i 驱动的信息相变的宏观累积 [3]，表现为能量密度变化率 $d \rho / \rho$ 的积分。因此，时间是一种涌现的相对概念。

• 虚数单位 i 获得了明确的物理意义：它是信息从潜在到显现的转化生成元，是时间涌现的决定性参数。任何出现在物理方程中的 i 都隐含了这种虚实转化的动态过程。

• 量子力学的地位：含时薛定谔方程中的时间 t 不再是先验背景，而是信息相变速率恒定时的近似参数；不含时薛定谔方程描述相变暂停的稳态。两种方程分别对应不同的信息相变场景，它们都是本理论统一动力学方程在特定条件下的投影。测量、纠缠等现象的所谓“诡异”源于我们预设了绝对时间背景；一旦剔除时间作为基本维度，这些现象就成为无时间本体论的自然推论。

本理论以大统一为目标，不回避颠覆认知，但承诺在经典极限下完美重现已知物理定律，并解释它们各自的局限。
