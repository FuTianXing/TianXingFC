## 6.1 质子作为空间应力平衡构型

由第 17 章，质子由上夸克 (uud) 组成，拓扑荷分别为 $Q = 2 / 3 , 2 / 3 , 1 / 3$ 。三个夸克的扭结通过空间应力互补咬合在一起，形成空间应力的平衡构型。具体地，两个 $Q = 2 / 3$ 的上夸克提供拉伸应力，一个 $Q = 1 / 3$ 的下夸克提供收缩应力。在质子中，空间应力几乎完全抵消，因此质子极其稳定。

## 6.2 衰变能量的转移

标准模型中质子衰变（如 $p  e ^ { + } \pi ^ { 0 } )$ 需要将一部分质量能量转化为正电子和中性π 介子。在本理论中，质子形成时已经由第 18 章的空间能量转化过程将多余的质量能量释放给了电子（电子质量正是空间形变能量阈值的结果）。因此，质子处于局部能量最小值，不再有额外的能量可用于弱衰变。任何试图打破质子拓扑结构的尝试都需要输入至少 $m _ { p } c ^ { 2 }$ 的能量，这远大于任何已知过程的能量尺度。
