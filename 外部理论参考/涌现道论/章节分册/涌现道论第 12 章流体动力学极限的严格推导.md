## 3.1 单粒子分布函数

定义单粒子分布函数 $f ( \pmb { x } , \pmb { p } , t )$ ，使得 $f ( \pmb { x } , \pmb { p } , t ) d ^ { 3 } x d ^ { 3 } p$ 为在 t 时刻、相空间体积元$d ^ { 3 } x d ^ { 3 } p$ 内的平均粒子数。归一化：

$$
\int f (\pmb {x}, \pmb {p}, t) d ^ {3} x d ^ {3} p = N.\tag{12.3}
$$

## 3.2 BBGKY 层级

从微观 Liouville 方程出发，对 N 粒子分布函数积分，得到 BBGKY 层级。第一级方程为：

$$
\frac {\partial f}{\partial t} + \frac {\boldsymbol {p}}{m} \cdot \nabla_ {\boldsymbol {x}} f + \boldsymbol {F} ^ {\text {ext}} \cdot \nabla_ {\boldsymbol {p}} f = \int d ^ {3} p _ {1} \int d \Omega | \boldsymbol {v} - \boldsymbol {v} _ {1} | \frac {d \sigma}{d \Omega} \left(f ^ {(2)} (\boldsymbol {x}, \boldsymbol {p} ^ {\prime}, \boldsymbol {p} _ {1} ^ {\prime}, t) - f ^ {(2)} (\boldsymbol {x}, \boldsymbol {p}, \boldsymbol {p} _ {1}, t)\right),\tag{12.4}
$$

其中 $f ^ { ( 2 ) }$ 是两粒子分布函数， $( \pmb { p } ^ { \prime } , \pmb { p } _ { 1 } ^ { \prime } )$ 是碰撞后的动量， $d \sigma / d \Omega$ 是微分散射截面。

## 3.3 分子混沌假设与玻尔兹曼方程

性质 3.1 (分子混沌假设). 在碰撞前，两粒子分布因子化为单粒子分布之积：

$$
f ^ {(2)} (\pmb {x}, \pmb {p}, \pmb {p} _ {1}, t) = f (\pmb {x}, \pmb {p}, t) f (\pmb {x}, \pmb {p} _ {1}, t) + O (1 / N),\tag{12.5}
$$

其中 ${ \cal O } ( 1 / N )$ 项在热力学极限 $N \to \infty , V \to \infty \ G a = N / V$ 固定）下趋于零。

注. 该假设在低密度极限下由 Lanford 定理 $[ 1 6 ]$ 保证。对于本网络中短程弹性碰撞的粒子系统，Lanford 定理的条件（硬球势或足够短程的势）满足。第 9 章 $[ { \boldsymbol { \mathscr { g } } } ]$ 的聚合物展开进一步保证了低密度下关联函数的指数衰减： $\rho ^ { ( 2 ) } ( { \pmb x } , { \pmb p } , { \pmb p } _ { 1 } ) = \rho ( { \pmb p } ) \rho ( { \pmb p } _ { 1 } ) + R$ ，且 R 满足指数小上界 $| R | \leq C e ^ { - | x | / \xi }$ ，这比 ${ \cal O } ( 1 / N )$ 更强，足以支撑分子混沌假设。因此，分子混沌假设在热力学极限下严格成立。

将分子混沌假设代入 BBGKY 方程，得到玻尔兹曼方程：

$$
\frac {\partial f}{\partial t} + \frac {\pmb {p}}{m} \cdot \nabla_ {\pmb {x}} f + \pmb {F} ^ {\mathrm{ext}} \cdot \nabla_ {\pmb {p}} f = \int d ^ {3} p _ {1} \int d \Omega | \pmb {v} - \pmb {v} _ {1} | \frac {d \sigma}{d \Omega} \big (f ^ {\prime} f _ {1} ^ {\prime} - f f _ {1} \big),\tag{12.6}
$$

其中 $f = f ( { \pmb x } , { \pmb p } , t ) , f _ { 1 } = f ( { \pmb x } , { \pmb p } _ { 1 } , t ) , f ^ { \prime } = f ( { \pmb x } , { \pmb p } ^ { \prime } , t ) , f _ { 1 } ^ { \prime } = f ( { \pmb x } , { \pmb p } _ { 1 } ^ { \prime } , t ) .$

定理 3.1 (收敛到玻尔兹曼方程). 在分子混沌假设下，当 $N \to \infty , V \to \infty$ 且 $n = N / V$ 固定时，单粒子分布 $\therefore \overrightarrow { A } - \cdot$ 数在 $L ^ { 1 }$ 范数下收敛到玻尔兹曼方程的解，收敛速度为 $O ( 1 / N ^ { 1 / 2 } )$ （中心极限定理型涨落）。该收敛的严格证明参见 Lanford (1975)[16] 定理 2.1 及 Spohn$( 1 9 9 1 ) / 1 \%$ 第 4 章。

## 哲学注记

流体力学极限如同“高者抑之，下者举之”——碰撞项迫使分布趋于平衡，如同“损有余而补不足”。查普曼-恩斯科格展开则是“消息盈虚”的量化描述：从平衡态出发，逐阶修正，最终“终则有始”（闭合的宏观方程）。

## 4.1 无量纲化与 Knudsen 数

引入宏观特征量：长度 L，速度 U，时间 $T = L / U$ ，数密度 $n _ { 0 }$ ，温度 $T _ { 0 }$ 。定义无量纲变量：

$$
\tilde {\pmb {x}} = \frac {\pmb {x}}{L}, \quad \tilde {t} = \frac {t}{T}, \quad \tilde {\pmb {v}} = \frac {\pmb {v}}{U}, \quad \tilde {f} = \frac {f}{n _ {0} U ^ {- 3}}.\tag{12.7}
$$

无量纲玻尔兹曼方程变为：

$$
\frac {\partial \tilde {f}}{\partial \tilde {t}} + \tilde {\pmb {v}} \cdot \nabla_ {\tilde {\pmb {x}}} \tilde {f} + \frac {L}{U ^ {2}} \pmb {F} ^ {\mathrm{ext}} \cdot \nabla_ {\tilde {\pmb {v}}} \tilde {f} = \frac {1}{\varepsilon} \tilde {Q} (\tilde {f}, \tilde {f}),\tag{12.8}
$$

其中 $\varepsilon = \ell _ { \mathrm { m f p } } / L$ 是 Knudsen 数， $\tilde { Q }$ 是无量纲碰撞项。

在流体力学极限 $\varepsilon \to 0$ 下，碰撞项占主导，迫使分布函数趋于局部平衡分布（麦克斯韦-玻尔兹曼分布）。

## 4.2 局部平衡分布

定义 4.1 (局部平衡分布). 在给定宏观密度 $\boldsymbol { n } ( \boldsymbol { \boldsymbol { x } } , t )$ 、流速 ${ \pmb u } ( { \pmb x } , t )$ 和温度 $T ( \pmb { x } , t ) ~ \top$ ，局部平衡分布为

$$
f ^ {(0)} (\pmb {x}, \pmb {p}, t) = n \left(\frac {m}{2 \pi k _ {B} T}\right) ^ {3 / 2} \exp \left(- \frac {| \pmb {p} - m \pmb {u} | ^ {2}}{2 m k _ {B} T}\right).\tag{12.9}
$$

## 4.3 查普曼-恩斯科格展开

定义 4.2 (展开). 将分布函数展开为 Knudsen 数的幂级数：

$$
f = f ^ {(0)} + \varepsilon f ^ {(1)} + \varepsilon^ {2} f ^ {(2)} + \dots .\tag{12.10}
$$

代入玻尔兹曼方程，并令同次幂相等，得到各级近似。

• 零阶 $( \varepsilon ^ { 0 } )$ ）：碰撞项 $Q ( f ^ { ( 0 ) } , f ^ { ( 0 ) } ) = 0$ ，自动满足，因为 $f ^ { ( 0 ) }$ 是平衡分布。

• 一阶 $( \varepsilon ^ { 1 } )$ ）：得到线性积分方程

$$
\mathcal {L} f ^ {(1)} = \left(\frac {\partial}{\partial t} + \boldsymbol {v} \cdot \nabla_ {\boldsymbol {x}} + \frac {\boldsymbol {F} ^ {e x t}}{m} \cdot \nabla_ {\boldsymbol {v}}\right) f ^ {(0)},\tag{12.11}
$$

其中 $\mathcal { L }$ 是线性化的碰撞算子。

## 4.4 宏观方程的推导

将玻尔兹曼方程乘以碰撞不变量 $\{ 1 , \pmb { p } , \frac { 1 } { 2 } m | \pmb { v } - \pmb { u } | ^ { 2 } \}$ 并对动量积分，得到宏观守恒方程：

$$
\frac {\partial n}{\partial t} + \nabla \cdot (n \pmb {u}) = 0,\tag{12.12}
$$

$$
\frac {\partial (n \pmb {u})}{\partial t} + \nabla \cdot (n \pmb {u u}) + \frac {1}{m} \nabla \cdot \pmb {P} = \frac {n}{m} \pmb {F} ^ {\mathrm{ext}},\tag{12.13}
$$

$$
\frac {\partial}{\partial t} \left(\frac {3}{2} n k _ {B} T\right) + \nabla \cdot \left(\frac {3}{2} n k _ {B} T \boldsymbol {u}\right) + \boldsymbol {P}: \nabla \boldsymbol {u} + \nabla \cdot \boldsymbol {q} = 0,\tag{12.14}
$$

其中 P 是压力张量， $\pmb q$ 是热流矢量。

在查普曼-恩斯科格展开的一阶近似下，可得到本构关系：

$$
P _ {\alpha \beta} = p \delta_ {\alpha \beta} - \eta \left(\frac {\partial u _ {\alpha}}{\partial x _ {\beta}} + \frac {\partial u _ {\beta}}{\partial x _ {\alpha}} - \frac {2}{3} \delta_ {\alpha \beta} \nabla \cdot \boldsymbol {u}\right),\tag{12.15}
$$

$$
\pmb {q} = - \kappa \nabla T,\tag{12.16}
$$

其中 $p = n k _ { B } T$ 是压强，η 是剪切粘性系数，κ 是热导率。

定理 4.1 (纳维-斯托克斯方程). 将本构关系代入宏观守恒方程，得到纳维-斯托克斯方程：

$$
\rho \left(\frac {\partial \pmb {u}}{\partial t} + \pmb {u} \cdot \nabla \pmb {u}\right) = - \nabla p + \eta \nabla^ {2} \pmb {u} + \left(\zeta + \frac {\eta}{3}\right) \nabla (\nabla \cdot \pmb {u}) + \pmb {f},\tag{12.17}
$$

$$
\frac {\partial \rho}{\partial t} + \nabla \cdot (\rho \pmb {u}) = 0,\tag{12.18}
$$

$$
\rho c _ {p} \left(\frac {\partial T}{\partial t} + \boldsymbol {u} \cdot \nabla T\right) = \nabla \cdot (\kappa \nabla T) + \Phi ,\tag{12.19}
$$

其中 $\rho = m n$ 是质量密度，ζ 是体粘性系数，Φ 是耗散函数。

Proof. 标准查普曼-恩斯科格展开结果，参见 [14, 15]。

## 5.1 粘性系数的显式表达式

$$

代入质量 $m = \sqrt { \theta _ { 0 } / \mu _ { 0 } }$ （第 3 章 [3]），得

$$
\eta = \frac {5}{1 6 a ^ {2}} \sqrt {\frac {\sqrt {\theta_ {0} / \mu_ {0}} k _ {B} T}{\pi}}.\tag{12.21}
$$

温度 T 由第 1 章公理 5[1] 与涨落-耗散定理关联： $\begin{array} { r } { k _ { B } T = \frac { \hbar c } { 2 a } } \end{array}$ ，其中 $\hbar = k _ { 0 } a ^ { 2 } z , \ c =$ $a \sqrt { k _ { 0 } z / \mu _ { 0 } }$ 。因此

$$
k _ {B} T = \frac {k _ {0} a ^ {2} z}{2 a} \cdot a \sqrt {\frac {k _ {0} z}{\mu_ {0}}} = \frac {k _ {0} a ^ {2} z}{2} \sqrt {\frac {k _ {0} z}{\mu_ {0}}} = \frac {k _ {0} ^ {3 / 2} a ^ {2} z ^ {3 / 2}}{2 \mu_ {0} ^ {1 / 2}}.\tag{12.22}
$$

代入 (12.21)，得到 η 完全由网络基本参数 $( a , z , k _ { 0 } , \mu _ { 0 } , \theta _ { 0 } )$ 表达。在经典涌现场景下，取$a = l _ { P }$ ，可得到具体数值。

## 5.2 热导率的显式表达式

对于硬球模型，热导率与粘性系数的关系为 [14]：

$$
\kappa = \frac {1 5}{4} \frac {k _ {B}}{m} \eta .\tag{12.23}
$$

代入 m 和 η 的表达式，得

$$
\kappa = \frac {1 5}{4} \frac {k _ {B}}{\sqrt {\theta_ {0} / \mu_ {0}}} \cdot \frac {5}{1 6 a ^ {2}} \sqrt {\frac {\sqrt {\theta_ {0} / \mu_ {0}} k _ {B} T}{\pi}} = \frac {7 5}{6 4 a ^ {2}} \frac {k _ {B} ^ {3 / 2}}{\sqrt {\pi}} (\theta_ {0} / \mu_ {0}) ^ {- 1 / 4} \sqrt {T}.\tag{12.24}
$$

再次代入 $k _ { B } T$ 表达式，可完全用网络参数表示。

## 5.3 与网络参数的自洽性

所有输运系数均用网络基本参数 $( a , z , k _ { 0 } , \mu _ { 0 } , \theta _ { 0 } )$ 表达，无自由参数。温度 T 由第 1章公理 5[1] 通过涨落-耗散定理与噪声强度 h¯ 关联，而 $\hbar = k _ { 0 } a ^ { 2 } z$ 。因此输运系数最终仅由网络参数决定。

## A 附录 12.A：分子混沌假设的严格证明概要

分子混沌假设在低密度极限下可由 Lanford 定理 [16] 证明。具体地，对于短程相互作用的经典粒子系统（如硬球模型），在热力学极限下，两粒子分布函数可展开为

$$
f ^ {(2)} (\boldsymbol {x}, \boldsymbol {p}, \boldsymbol {p} _ {1}, t) = f (\boldsymbol {x}, \boldsymbol {p}, t) f (\boldsymbol {x}, \boldsymbol {p} _ {1}, t) + \frac {1}{N ^ {1 / 2}} g (\boldsymbol {x}, \boldsymbol {p}, \boldsymbol {p} _ {1}, t) + O (1 / N),\tag{12.26}
$$

其中 g 是有界函数。本网络的粒子为全息场扭结，其有效相互作用力程 $\sim a$ 且为弹性散射，满足 Lanford 定理的前提条件。第 9 章 [9] 的聚合物展开进一步保证了低密度下关联函数的指数衰减，为 Lanford 定理的应用提供了自洽性验证。详细证明参见 Lanford(1975)[16] 第 3 节。

## B 附录 12.B：典型宏观流动的 Knudsen 数估算

对于空气在标准条件 $( T = 2 9 3 \mathrm { K } , \ p = 1 \mathrm { a t m } )$ 下，分子数密度 $n \approx 2 . 5 \times 1 0 ^ { 2 5 } \mathrm { m ^ { - 3 } }$ 分子直径 $d \approx 3 . 7 \times 1 0 ^ { - 1 0 } \mathrm { m }$ （与本网络 $a = l _ { P }$ 量级不同，但这里仅为示意；实际本网络的$a = l _ { P }$ 极小，因此 $\ell _ { \mathrm { m f p } }$ 极大， $\varepsilon$ 可以非常小）。平均自由程 $\ell _ { \mathrm { m f p } } = 1 / ( \sqrt { 2 } n \pi d ^ { 2 } ) \approx 6 8 \mathrm { n m } .$ 取宏观特征尺度 $L = 1 \mathrm { c m } = 1 0 ^ { - 2 } \mathrm { m }$ ，则 $\varepsilon \approx 6 . 8 \times 1 0 ^ { - 6 }$ ，误差 $O ( \varepsilon ^ { 2 } ) \approx 4 . 6 \times 1 0 ^ { - 1 1 }$ ，极端精确。对于本网络参数， $a = l _ { P } \approx 1 . 6 \times 1 0 ^ { - 3 5 } \mathrm { m } , ~ \ell _ { \mathrm { m f p } }$ 远大于宏观尺度，因此 ε 极小，纳维-斯托克斯方程的精度远超实验需求。
