量纲验证： $[ \hbar ^ { 2 } ] = { \mathsf { M } } ^ { 2 } { \mathsf { L } } ^ { 4 } { \mathsf { T } } ^ { - 2 } , \ [ G c ] = { \mathsf { L } } ^ { 3 } { \mathsf { M } } ^ { - 1 } { \mathsf { T } } ^ { - 2 } \cdot { \mathsf { L } } { \mathsf { T } } ^ { - 1 } = { \mathsf { L } } ^ { 4 } { \mathsf { M } } ^ { - 1 }$ T−<sup>3</sup>，相除得 $\mathsf { M } ^ { 3 } \mathsf { T }$ ，与表3.1 中 $\theta _ { 0 }$ 的量纲 M<sup>3</sup>T 一致。

代入数值：

$$
\hbar^ {2} = (1. 0 5 4 5 7 1 8 1 7 \times 1 0 ^ {- 3 4}) ^ {2} = 1. 1 1 2 1 2 1 \times 1 0 ^ {- 6 8} \mathrm{J} ^ {2} \mathrm{s} ^ {2},
$$

$$
G c = 6. 6 7 4 3 0 \times 1 0 ^ {- 1 1} \times 2. 9 9 7 9 2 4 5 8 \times 1 0 ^ {8} = 2. 0 0 1 3 1 2 \times 1 0 ^ {- 2} \mathrm{m} ^ {4} \mathrm{kg} ^ {- 1} \mathrm{s} ^ {- 3},
$$

$$
\theta_ {0} = \frac {1 . 1 1 2 1 2 1 \times 1 0 ^ {- 6 8}}{2 . 0 0 1 3 1 2 \times 1 0 ^ {- 2}} \approx 5. 5 6 \times 1 0 ^ {- 6 7} \mathrm{kg} ^ {3} \mathrm{s}.
$$

该值将在后续章节中作为已知参数使用。

## 9 正则化参数 a 的哲学与物理意义

## 9.1 连续极限与重整化群不动点

本理论中，离散网络作为正则化工具，其物理内容由重整化群流描述 [3]。连续极限并非简单地令 $a \to 0$ ，而是要求耦合常数 $\left( k _ { 0 } , \mu _ { 0 } , \theta _ { 0 } \right)$ 在重整化群变换下趋近于一个高斯不动点。在此不动点附近，离散细节被吸收，理论恢复为连续场论，所有物理可观测量与截断 a 的具体取值无关。因此，a 本身不是一个可直接观测的参数；物理上，a 总是大于零的有限值（因为空间必须有定义），数学上的 $a = 0$ 仅代表极限过程，并不对应任何物理状态。

## 9.2 正则化参数 a 的物理取值范围

• 数学上，a 可以取任何非负实数。宇宙方程（第 1 章推论 1.1[1]）允许 $a = 0$ 的情形，此时道场仅有虚部 Y（即 $Z = i Y )$ ），对应全息态——信息完全处于潜在态，空间尚未展开。这是理论的源头状态。

• 物理上，一旦空间生成（宇宙暴涨），a 必须严格大于零，因为空间的存在需要正尺度。在经典物理适用的能标下，为了验证自洽性，我们取 $a = l _ { P }$ 作为标度固定点。这一选择使得网络参数 $k _ { 0 } , \mu _ { 0 }$ 与实验常数呈现最简单的数值关系，便于计算和推导经典物理（如牛顿极限、爱因斯坦场方程）。由于连续极限下物理与 $a$ 无关，使用 $a = l _ { P }$ 是安全的，不会引入歧义。

• 高能标下的 $a < l _ { P } \colon$ 在黑洞内部或宇宙暴涨极早期，有效截断 $a$ 可能远小于 $l _ { P }$ ，此时离散效应显著，连续近似失效。本理论将直接使用第 2 章的玄同方程描述这些极端过程，产生可观测的修正（如非高斯性、修正的色散关系）。此时 $a$ 作为重整化群跑动参数，与能量标度相关。

## 9.3 宇宙作为无限空间中的一个普通相变点

本理论的一个深层见解是：我们的可观测宇宙可能只是无限空间（或更大尺度的全息母体）中的一个局域相变区域。在这个区域中，发生了一次从全息态 $( a  0 )$ ）到经典空间 $( a > 0 )$ 的相变。其他区域可能仍处于不同相，或具有不同的 a 值。这一观点将宇宙学的初始条件归结为无限空间中的普遍相变现象，而非特殊选定的初始奇点。该思想将在后续宇宙学章节中详细展开。

## 9.4 引力不可量子化的重申

本理论中，引力本身是经典的（爱因斯坦场方程），从未被量子化。普朗克长度$l _ { P } = \sqrt { \hbar G / c ^ { 3 } }$ 仅是常数组合，不代表引力量子化尺度。物质（包括量子场）是空间的行为（道场的激发），因此 h¯ 出现在物质场的涨落中，但不影响引力的经典性。离散网络的使用与这一哲学完全兼容。
