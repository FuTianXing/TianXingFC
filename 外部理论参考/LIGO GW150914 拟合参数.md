# 外部理论参考：LIGO/Virgo 首例引力波事件 GW150914 的拟合参数

- **采集日期**：2026-10-02 首次采集（分量质量）；2026-10-03 补全（GWTC-1 拟合参数）
- **采集方式**：联网检索（作者 2026-10-02 授权：允许联网检索，引入外部数据，放入外部理论参考）
- **用途**：黑洞线任务 BH1-3「后视界区与并合波形的相位结构对照」的数值对表基准（第二轮）
- **状态**：**已补全**。质量类参数与波形模型已取到官方值；1.5 阶后牛顿频率演化率 $\dot f$ 经查证**官方不发布后验**（见第三节），对表改用官方发布的量（质量与频率）。

## 一、并合前质量类参数（GWTC-1，PRL 116, 241102 (2016)，arXiv:1602.03840，Table I）

官方发布 90% 可信区间（中位数与上下限）。**Overall 为 EOBNR 与 IMRPhenom 两族后验的平均。**

| 量 | 源系（Overall） | 探测器系（Overall） |
|---|---|---|
| 并合前总质量 $M$ | $65.0^{+4.5}_{-4.0}\,M_\odot$ | $70.6^{+4.6}_{-4.5}\,M_\odot$（含系统差 $+0.5_{-1.3}$） |
| 约化质量 $\mathcal{M}$ | $28.0^{+2.0}_{-1.7}\,M_\odot$ | $30.4^{+2.1}_{-1.9}\,M_\odot$（含系统差 $+0.2_{-0.5}$） |
| 质量比 $q$ | $0.82^{+0.17}_{-0.20}$（下界 $> 0.66$，90%） | 同 |

分量质量（发现论文 PRL 116, 061102 (2016)，arXiv:1602.03837）：$m_1 = 36^{+5}_{-4}\,M_\odot$，$m_2 = 29^{+4}_{-4}\,M_\odot$（源系，90%）。

红移（源系）：$z = 0.088^{+0.032}_{-0.037}$（90%）。

GWTC-1 机器可读版本（源系，90%）：$\mathcal{M} = 28.6^{+1.7}_{-1.5}\,M_\odot$，$m_1 = 35.6^{+4.7}_{-3.1}\,M_\odot$，$m_2 = 30.6^{+3.0}_{-4.4}\,M_\odot$。GWTC-2.1 重跑值：$\mathcal{M} = 27.9^{+1.7}_{-1.5}\,M_\odot$，$M = 64.5^{+3.7}_{-3.2}\,M_\odot$。

**可靠性说明**：官方只发布 90% 区间，非 1-sigma；GWOSC JSON 的 `*_lower`/`*_upper` 字段记录的是 90% 区间。质量比 $q$ 的不确定度接近先验，论文明确说 $q$ 只被弱约束。

## 二、频率读数（发现论文 PRL 116, 061102 (2016)）

- 事件扫频范围：35 至 250 Hz；
- 振幅峰值处瞬时频率：**约 150 Hz**（原文：信号在 0.2 s 内约 8 个周期内从 35 Hz 升到 150 Hz，振幅在此达最大）；
- 起点约 30 至 35 Hz；并合前约 10 个周期；
- 75 Hz 对应轨道频率（引力波频率的一半）。

## 三、$\dot f$（1.5 阶频率演化率）：官方不发布

经查证：GWTC-1 参数估计论文**不直接发布 $\dot f$ 后验**，只给约化质量与时频图读数；GWOSC 的 JSON 亦无 $\dot f$ 字段。故 BH1-3 数值对表**不使用 $\dot f$**，改用官方发布的量（质量类参数与频率读数）。

参考量级（按 1.5PN 公式 $\dot f = \frac{96}{5}\pi^{8/3}(G\mathcal{M}/c^3)^{5/3}f^{11/3}$ 对上述官方质量与频率重算，**非 LIGO 发布值**）：源系 $\mathcal{M} = 28.0\,M_\odot$、$f = 30$ Hz 时 $\dot f \approx 4.3\times10^{20}$ Hz/s；探测器系 $\mathcal{M} = 30.4\,M_\odot$、$f = 150$ Hz 时 $\dot f \approx 2.1\times10^{23}$ Hz/s。

## 四、拟合波形模型

- **EOBNR**（有效单体族，含黑洞自旋）：论文明确命名为 **SEOBNRv2**（双自旋对齐，主结果）、**SEOBNRv3**（双进动）、**SEOBNRv2_ROM_DoubleSpin**（降阶快速版）；
- **IMRPhenom**（进动唯象族，PN 与 EOB/NR 混合）；
- **无 EOBNRv4 与 SEOBNRv4 拟合**：GW150914 早于这些模型发布，官方数据不含此类值。

## 五、多值差异来源

其一，源系与探测器系之差来自光度距离红移（$65.0\times(1+0.088)\approx 70.7$，与探测器系 70.6 吻合）。其二，EOBNR 与 IMRPhenom 两列之差（源系约化质量 27.9 对 28.1）是波形系统误差，论文用两者后验方差作为系统误差条（量级 $\pm 0.2$ 至 $\pm 0.5\,M_\odot$）。其三，GWTC-1 与 GWTC-2.1 之差（$\mathcal{M}$ 28.6 对 27.9）来自历年后验重跑所用的波形族与先验改动（GWTC-2.1 参考条目 doi:10.7935/qf3a-3z67）。

## 六、对表口径（按 E-a 裁决，2026-10-01）

数值对表取「已公开的并合波形拟合族作为观测允许族的代表，以区间口径处理拟合参数不确定性，不做逐事件拟合」。故本条目第二节的质量与频率值为观测允许族的代表值；对表时以区间而非点值入判，且质量比 $q$ 因弱约束按区间处理。

## 八、边界

一，本条目为外部观测数据，不含体系推断。二，官方只发布 90% 区间（非 1-sigma），对表须按 90% 区间处理。三，第三节的 $\dot f$ 量级为按 1.5PN 公式的重算值，**非 LIGO 发布值**，对表不采用。四，质量比 $q$ 为弱约束，区间宽（$0.66$ 下界），对表时须按区间而非点值。五，本条目按外部理论参考规范维护，不进入理论总纲基准。
