## 一、立项背景

黑洞物理分三段：外部、视界、内部与奇点。外部段已有零参数支撑（N5 史瓦西对齐、测地线判据）。视界与内部段此前建立在「写入-补位竞赛」的形成图像上，该图像在 2026-09-15 的零阶执行中被否定：速率平衡在零阶不存在密度阈值；补位时标与坍缩时标相差约二十一个数量级，不属同一物理过程。

形成机制因此需要重排。本计划把形成段的任务改为支撑失效判据，把终态段保留在记录饱和，并新增一条体系特有的正反馈通道跟踪。三项改动均属任务定位层面，不预设任何科学结论。

## 三、候选方案与判定方式

形成段的候选四项，排序与理由见牵头注记：支撑失效（主框架）、运动引力增强（体系特有通道）、记录饱和（终态接管）、缺陷网络失稳（远期）。本计划只登记判定方式，不预设结论。

BH4a 的判定方式：写出引力势阱、缺陷动能与传播上限三者的平衡关系，导出最大质量的量级与常数因子，与钱德拉塞卡极限、TOV 极限对照。零阶即可执行，输入全为既有定案。

**执行结果（2026-09-16）**：判据 12 项全过。临界质量结构为满偏标度乘「满偏与颗粒质量之比」的平方；中子星带 $1.9$ 至 $6.9$、白矮星带 $0.5$ 至 $1.7$ 太阳质量，两处观测上限落在带内。见 [[验证脚本/注记-BH4a支撑失效的最大质量零阶判据：相空间压缩、相对论化软化与临界质量带]]。

BH4c 的判定方式：先把「运动引力增强」的形式固定下来，再判定该通道是否进入质量扇区（时间反演偶的通道此前被判为不进入矢量扇区，质量扇区需单独判定），随后估其对接纳的坍缩时标与最大质量的影响量级。

BH2 的判定方式沿用原立项文档第四节，编号不变。BH3（三候选判别）拆为三条可先行子判据与一条建模判据。

**BH3-1（同一性，可先行）**：倾角满 $2\pi$ 与相位满周闭合是不是同一个条件。（表述注：旧写法「倾角满 $2\pi$」已按 2026-09-17 裁决退役；该条件即 $\alpha = 360$ 度，位于满偏之外。）若是，缠绕自动获得内容，因为满周闭合已定案触发法线跃迁；若否，回绕属外加假设，方案应当否掉。（**已执行，2026-09-16**：按读法分叉判定为否；见 [[内部草稿/注记-BH3-1与BH3-2执行：倾角与相位的定义关系、缠绕两道闸门的判定]]。）

**BH3-2（可观测性，可先行）**：圈数由 $n$ 变为 $n+1$，除整数本身外还有什么物理差异。若答不出，回绕在原理上不可观测，属理论冗余。（**已执行，2026-09-16**：圈数三读法分别为记法冗余、基态计数、与绕数保护冲突，均不通过。）

**BH3-3（零接触测试设置的核查，可先行；已执行 2026-09-15，判定撤回，判据需重新设计）**：核查零接触那次数值测试的倾斜取值与场强。若在倾斜约为零或极弱场下测得严格零，则高阶耦合未被排除，耦合重开仍可走「高阶显现」路径；若在有限倾斜下仍测得严格零，则高阶项也被排除，耦合重开须另找出路。即 [[注记-耦合重开方案评估：约束、优势、缺陷与可能成立方式]] 中的判据 CR-1。

**执行结果与撤回（2026-09-15）**：检验实现于 `验证脚本/minimal_verification_derrick_3d.py` 第一部分。复跑读数：碰撞点（$s = 0$ 与 $0.5$）差为零，拍内 $s = 0.25$ 与 $s = 0.75$ 的差分别为总能量的 $3.2\%$ 与 $4.4\%$。

该差异已解析求出，等于 $2\times$（锁定滴内部由异 σ 变同 σ 的键数），属纯几何计数（$84$ 与 $114$ 个键，对应 $-168$ 与 $-228$）。

脚本不含写入过程，比较的是两种静态配置的能量，故它回答不了 CR-1 的问题；初版「候选 A 存活」的判定撤回。

### 7.1 D1 判据清单与最小实现（草案，2026-09-17）

模型定义（三维推广）：简单立方格点、周期边界、交错背景 $\theta_n = \pi(i+j+k)$，能量泛函

$$E = J\sum_{\langle nm\rangle}\cos(\theta_n - \theta_m) + \lambda\sum_n (1 - \cos\theta_n)\,h_n .$$

在交错背景处展开，Hessian 为对角 $6J + \lambda(-1)^{i+j+k}h_n$、近邻 $-J$；度数为 $6$，与一维同源。

解析锚点（先立期望）。其一，均匀记录的三维带边值为 $\mu = 6J - \sqrt{36J^2 + \lambda^2h^2}$（取 $J = \lambda = 1$、$h = 1$ 时等于 $6 - \sqrt{37}$）。

其二，薄板（记录只依赖一个坐标）不与一维块族同值：横向 Bloch 动量经 $(-1)^{j+k}$ 把 $(0,0)$ 与 $(\pi,\pi)$ 配对，薄板等价于两分量一维链

$$(2-\mu)\varphi_i + \Delta\varphi_i + (-1)^i h_i \psi_i = 0,\qquad (10-\mu)\psi_i + \Delta\psi_i + (-1)^i h_i \varphi_i = 0 .$$

该约化既作代码校验，也预告三维薄板读数与一维块族在数值上分家。

判据清单（先写期望，再算）：

D1-1 解析锚点：均匀带边值对 $6 - \sqrt{37}$ 逐位一致（$\le 10^{-10}$）；薄板对两分量约化逐位一致（$\le 10^{-10}$）。

D1-2 存在性门槛：立方体（边长 $\ell$）与柱体（截面 $\ell \times \ell$、长 $w$）族存在最小覆盖；报告 $\ell^*$ 与 $w^*(\ell)$。

D1-3 三维漏斗量级：$h_n = h_0/(1+r_n)$（$r_n$ 为最小镜像欧氏距离），格距 $L$ 取 $16$、$24$、$32$、$48$、$64$，报告比值 $|\mu_{\min}|/|\mu_{\text{均匀}}|$ 与收敛趋势；一维对照为 $1.40\%$（$N = 64$）与 $1.23\%$（$N \ge 256$ 收敛值）。

D1-4 分档的三维命运：薄板厚度序列是否存在同型奇偶锁定（用两分量约化做高精度扫描）；柱体与立方体上是否保留（报告）。

D1-6 尺寸与边界稳定性：$L$ 加倍时读数变化低于阈值；读数对边界距离不敏感（报告）。

两路时钟的最小定义。写入律取线性斜坡 $h_n(t) = \Gamma t\, h_n^{(0)}$，饱和时钟为 $t_{\text{饱}} = 1/\Gamma$（指数斜坡作变体报告）。耦合时钟由模式增长给出：$\int_{t_*}^{t}\gamma(s)\,ds = \ln(1/\epsilon_0)$，其中 $\gamma(h) = \sqrt{-\mu_{\min}(h)}$，$t_*$ 为最低模首次变负的时刻，$\epsilon_0$ 为噪声底。换元到振幅坐标后，耦合先触发的条件（本模型多数构型 $h_* = 0$）为

$$\int_{0}^{1}\gamma(h)\,dh > \Gamma\ln(1/\epsilon_0)\quad\Longleftrightarrow\quad \Gamma < \Gamma_c = \frac{\int_0^1\gamma\,dh}{\ln(1/\epsilon_0)} .$$

慢写入下耦合路线必胜、快写入下饱和路线必胜；$\Gamma_c$ 即该判别点的单一数字。两路前置条件：耦合路线要求构型的最低模可变负（单点调制为稳定化，不触发）；饱和路线无前置条件。
