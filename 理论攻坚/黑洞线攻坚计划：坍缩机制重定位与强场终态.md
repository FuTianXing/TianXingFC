## 一、立项背景

黑洞物理分三段：外部、视界、内部与奇点。外部段已有零参数支撑（N5 史瓦西对齐、测地线判据）。视界与内部段此前建立在「写入-补位竞赛」的形成图像上，该图像在 2026-09-15 的零阶执行中被否定：速率平衡在零阶不存在密度阈值；补位时标与坍缩时标相差约二十一个数量级，不属同一物理过程。

形成机制因此需要重排。本计划把形成段的任务改为支撑失效判据，把终态段保留在记录饱和，并新增一条体系特有的正反馈通道跟踪。三项改动均属任务定位层面，不预设任何科学结论。

### 7.2 D2 判据清单与最小实现（草案，2026-09-17）

判别点与两路时钟。BH3-4 的判别点是「破坏是否必待满偏」：饱和路线要求记录先到满偏（峰值 $h = 1$）再破坏；耦合路线允许在满偏之前由线性失稳触发。

两路时钟的最小定义。写入律取线性斜坡 $h_n(t) = \Gamma t\, h_n^{(0)}$，饱和时钟为 $t_{\text{饱}} = 1/\Gamma$（指数斜坡作变体报告）。耦合时钟由模式增长给出：$\int_{t_*}^{t}\gamma(s)\,ds = \ln(1/\epsilon_0)$，其中 $\gamma(h) = \sqrt{-\mu_{\min}(h)}$，$t_*$ 为最低模首次变负的时刻，$\epsilon_0$ 为噪声底。换元到振幅坐标后，耦合先触发的条件（本模型多数构型 $h_* = 0$）为

$$\int_{0}^{1}\gamma(h)\,dh > \Gamma\ln(1/\epsilon_0)\quad\Longleftrightarrow\quad \Gamma < \Gamma_c = \frac{\int_0^1\gamma\,dh}{\ln(1/\epsilon_0)} .$$

慢写入下耦合路线必胜、快写入下饱和路线必胜；$\Gamma_c$ 即该判别点的单一数字。两路前置条件：耦合路线要求构型的最低模可变负（单点调制为稳定化，不触发）；饱和路线无前置条件。

解析锚点。一维均匀的 $\gamma(h) = h/\sqrt{2+\sqrt{4+h^2}}$ 给出闭式

$$\int_0^1\gamma\,dh = \frac{2}{3}\sqrt{\sqrt{5}+2}\,(\sqrt{5}-4) + \frac{8}{3} = 0.246351\ldots$$

三维均匀把 $4$ 替换为 $36$，同为初等闭式（约 $0.1442$）。
