## 一、立项背景

缺陷动力学线交付了一条判据级成果：σ 锁定孤子的质量有闭式 $M = 4\sqrt{k_bK}/\pi$，涨落缺口有闭式 $m_{\rm gap} = 2\pi\sqrt K$，数值与既有绑定能读数逐位一致（偏差 $0.28\%$）。这两个式子的输入端是格点单位的量（$k_b$ 是键弹性，$K$ 是锁定势强度，两者以格点单位无量化），输出端是纯数。

接物理世界时出现一处断点。论文要把缺陷质量接到能量密度上，写出的式子是 $\rho_{\rm def} = fM\rho_P$，其中 $\rho_P = m_P/l_P^3$。这一步隐含一个前提：模型算出的能量单位等于 $m_Pc^2$。论文把这一点如实标注为「量纲桥」假设，写明该步尚未从本体层导出，并把入口份额 $f$ 的数值随该假设浮动的情况一并记下。

缺口的分量由此判断。它不影响模型内的结论（那些结论全用比值表述，比值不依赖桥），它影响的是跨层翻译：把格点层的数译成千克、米、秒制的数。凡是需要在模型与观测之间架桥的位置，都要经过这座桥，而桥的桥墩还没打。

一处必须分清的事：并非所有跨层对接都缺桥。引力线的记录场对接已经做完，其做法是证明记录倾斜、$h_{00}$、牛顿势除以 $c^2$ 三者都无量纲，故对接只需一个常数匹配，不需新桥梁。缺陷质量这一条路径缺桥，原因是质量有量纲而记录倾斜没有。这个区别是本计划与引力线归一化工作的边界所在。

## 二、缺口的精确位置

把从本体层到物理质量的路分成四段，逐段标注状态。

第一段是公理层的独立经验输入，落在 [[元相子几何动力学——束缚振荡修订整合版]] 的第六部分：$\bar t_P$（或 $t_P$）、$c$、$\hbar$（或 $E_\Phi$）、$\lambda = l_P$，加上方向与配对结构、初始分布。这一段是**给定**的，公理 5 承担经验输入。$m_P$ 由 $m_P = \hbar/(t_Pc^2)$ 派生，论文已用这一式校验量纲自洽，偏差为零。

第二段是格点单位的能量与被无量纲化。模型的能量泛函 $E = \sum[\frac12k_b(u_{n+1}-u_n-1)^2 + K(1-\cos 2\pi u)]$ 里，$k_b$ 与 $K$ 未带物理单位，故 $M$ 与 $m_{\rm gap}$ 输出纯数。这一段是**模型约定**，只要比值自洽即可，本身不需要物理单位。

第三段是模型能量单位到物理能量的换算。论文在此取「模型能量单位等于 $m_Pc^2$」。这一段是**缺失的**，它就是量纲桥。判断它是否真的为假设，只需问一个问题：$k_b$ 与 $K$ 这两个格点弹性系数，能否用 $l_P$、$t_P$、$\hbar$、$c$ 四个已给量拼出来？若答案是能，桥就该由拼法给出，取 $m_Pc^2$ 只是巧合地猜对了；若答案是不能，桥必须另有来源，例如由某种自洽条件（如晶格声速等于 $c$、或键能等于某个可算量）钉定。

第四段是从物理质量到观测密度。论文已写出逆式 $f = \rho_b/(M\rho_P)$，在桥的假设下给 $f = 9.1\times10^{-124}$（后按质量档重标至 $9.07\times10^{-124}$ 或电子档 $1.95\times10^{-102}$，见 D 线计划修订记录）。这一段是**已完成但随桥浮动**，桥一旦导出，$f$ 即被钉定。

缺口落在第三段，且它的性质是一个纯数因子。这一点使任务有了明确的目标形态：要找的是「$k_b$ 与 $K$ 在物理单位下的值」这一组数，或者等价地，「模型能量单位对 $m_Pc^2$ 的比」这一个数。找到它，桥就通了。

## 三、候选路线（四条，待作者裁决）

### 路线甲：格点弹性的几何值导出（从公理 4 的字面读）

公理 4 的哈密顿已经把同类耦合写成 $K_{ij} = K_0 f(\Delta n)$，而 $K_0 = \bar t_P c^2/l_P^2 = 1/(2\pi t_P)$ 是**显式给出的派生量**，不是自由参数。若 $\sigma$ 锁定泛函里的 $k_b$ 与 $K$ 对应公理哈密顿的某些项，则两者的物理值直接由 $K_0$ 与 $\hbar$ 给出，桥通。

本路线与 [[内部草稿/研究方向-K 的体系值导出：判据草案与三条候选路线]] 的路线甲是同一件事的两侧：本计划要的是 $K$ 的物理值，那份草案要的是 $K$ 的导出判据。两份计划应当合并推进或明确分工，避免重复。

判据方向：写出公理 4 哈密顿到 σ 锁定泛函的变量字典（相位 $u$ 与 $\theta$、层数 $n$ 与格点序号），核对字典是否为纯比（不含自由标度）；再用 $K_0$ 的显式式代入，检查导出的 $k_b$ 与 $K$ 是否使 $M$ 的物理值落在一个数量级内的可辨区间。

### 路线乙：晶格声速的自洽条件（动力学钉定）

波在晶格里的声速是被本体层固定的：接力几何给出 $c = l_P/t_P$，且明确「速度值与耦合强度无关」。若把这条几何恒等式反过来用作对晶格动力学的约束，则 $k_b$ 与 $K$ 的组合必须使低能声速等于 $c$。这是一条**自洽条件**而非自由选择，可能唯一地钉出弹性系数的组合。

判据方向：写出晶格声速对 $k_b$、$K$、$m_\Phi$（元相子惯性）的表达式，令其等于 $c$；结合接力几何第三条（速度值与耦合强度无关，$K_0$ 的角色退化为「保证事件确实传递」），判断这条条件是否给出 $k_b$ 或 $K$ 的绝对值，还是只给出比值。若只给比值，本路线降为路线甲的辅助。

### 路线丙：由质量比值反解（唯象定标）

承认桥的形式暂不可导出，改用既有读数把它定标。可用的锚有两类：孤子质量与缺口之比 $4.93$（纯模型内，无量纲，不能定标）；孤子质量与普朗克质量之比（需外部输入，例如取电子质量档，则 $m_\delta/m_P = 4.1855\times10^{-23}$，回路乙第一步已给）。

判据方向：以 $m_\delta/m_P$ 为唯一外部锚，写出桥因子对锚的表达式，检查它是否给出一个与四条窗口（见 [[验证脚本/注记-参数区四窗口对照轮：三窗相容、P1-40 的状态更新与待裁决的通道分岔（判据P1至P5）]]）相容的数。若相容，桥获得「条件性定标值」，严格程度停在条件性命题级。

### 路线丁：与引力线归一化的共用（对照路线）

引力线的记录场对接没有量纲桥，只有常数匹配。检查缺陷质量这条路能否借道：若缺陷能量最终以记录倾斜的形式写入（D 线已把质量与写入幅度通过 $m/m_P$ 相连），则质量的物理标度可能由记录场的归一化一并给出，而不必单独造桥。

判据方向：核对记录写入幅度 $\delta\theta = m/m_P$ 里的 $m$ 是物理质量还是模型质量。若为物理质量，则这一式已经把物理标度引进系统，桥的位置应前移到写入机制而非停在 §7；若为模型质量，则缺口仍在，本路线判负。

## 六、作者裁决点

- **裁决点 M-A**：四条路线的优先顺序。建议 MB-3（路线丁）先行，理由是它成本最低且结论会改变后续入口；若判负，则 MB-1 与 MB-2 并行。
- **裁决点 M-B**：本计划与 [[内部草稿/研究方向-K 的体系值导出：判据草案与三条候选路线]] 是否合并为一条线。两者的路线甲、路线丙高度重叠，分开推进有重复劳动风险；合并的代价是文档数量减少但单篇变长。
- **裁决点 M-C**：桥的严格程度目标。是要求导出到「唯一值」（定理级），还是接受「条件性定标值」（条件性命题级）即可结项。这一选择决定 MB-4 与 MB-5 的验收标准。
- **裁决点 M-D**：若 MB-5 判定桥有可能是一组分层的条件而非单一因子，是否接受这一结论作为收口形态。分层桥意味着不同物理量走不同的换算路径，这将影响 D 线正稿 §7 的表述方式。

## 七、失败与降级预案

- **预案一（路线甲、乙皆判负）**：桥的形式不可由公理层导出。此时把桥明确定位为「本体层与现象层之间的经验接口」，与 $\hbar$、$G$ 一类常数并列登记，严格程度上与公理 5 的经验输入同级。这一降级不损模型内结论，但须在 D 线正稿 §7 与 §10 改写措辞，把「尚未导出」改为「定为经验接口」。
- **预案二（多解）**：四条路线给出互相不等的桥因子。此时按是否能同时满足四条窗口与声速条件筛选，判为过约束说明某条路线的前提有误，须逐条回溯。
- **预案三（桥导出但与观测不合）**：桥导出后 $f$ 的数值使格点层稀疏度落在不合理区间（如超过 $10^{-150}$）。此时问题不在桥，在缺陷生成机制（D 线与相变线），本计划照常结项并把矛盾移交。
- **预案四（路线丁判负且路线甲、乙不可行）**：只剩路线丙（唯象定标）。此时本计划的目标收缩为「给出条件性定标值与敏感性表」，并在登记中标明它为最弱形态。

## 十、边界声明

本计划验证什么：格点弹性系数的物理值能否由本体层的既有设定（$l_P$、$t_P$、$\hbar$、$c$、$K_0$）导出，以及由此确定的桥因子是否唯一、是否与四条参数窗口相容。

本计划不验证什么：不修改 σ 锁定方程的形式；不重测孤子质量与缺口的模型内读数（已由 D 线交付，偏差 $0.28\%$）；不裁决 $m_\delta$ 的两族标度与相变时标；不触碰 理论总纲 基准。桥若导出，其与观测的最终比对（例如电子质量的复现精度）属粒子线的验收范围，本计划只交付换算关系。

## 十一、附：通俗说明（供跨线引用）

量纲桥的问题可以用一句话讲清：模型算出来的缺陷质量是「$0.09$ 个单位」，论文要把它写成千克，于是假设「一个单位就是普朗克质量对应的能量」。这个假设没有被推导出来。

用弹簧比方。挂上砝码量出「弹簧伸长 3 个单位」，又称出「砝码重 5 斤」。要把两者连起来，需要知道「每单位伸长对应多少斤」，而那个数取决于钢丝的材质与粗细。现在的情况是：伸长量测得很准，砝码重量也称得很准，但「每单位对应多少斤」是从别处借来的，不是从钢丝算出来的。

缺了这座桥，后果有两条。一是不能预言只能拟合：桥若导出，给定元相子参数质量就唯一确定，可与电子质量比；桥若假设，就只能反过来拿电子质量倒推桥，正用是预言、倒用是拟合，证据分量差得多。二是层级之间不能自动通话：普朗克层的量（$l_P$、$t_P$）与粒子层的量（电子质量、缺陷宽度）本该由桥连起来，桥没导出的情况下两层各自定参数，这正是 D 线用 $K = 0.005$、C1 线用 $K \in [0.24, 0.25]$ 却没人替它们对齐的原因。

严格程度上，这是一条**已知的缺口**而非错误。论文自己把它列进遗留清单，标注方式是诚实的；公式本身的正确性已在模型内验证，尚未确定的是「公式算出的数对应物理世界多少千克」。
