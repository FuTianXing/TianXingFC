## 一、线定位与命名说明

本线目标一句话：给自旋锚定强度 $\kappa_2$ 建立独立于 $\kappa_1$ 的读数通道，据此检验 $\kappa_1$-$\kappa_2$ 同一性；若判同，电磁耦合常数的物质侧来源通道打开（磁化强度决定联络锚定量），M3 与 M4 的前置之一随之齐备。

**命名说明（撞名消歧，2026-10-11 核）**。本线的 $\kappa_2$ 与体系内两处既有记号撞名，须区分。其一，[[元相子螺旋阶梯几何体的数学特性与物理对应]]（定理 3 极小曲面论）用 $\kappa_1$、$\kappa_2$ 指螺旋体主曲率（$H=(\kappa_1+\kappa_2)/2=0$），与电磁耦合常数无关。

其二，[[三代费米子质量谱的模态轮换方案：Z₃对称与实轴投影]] 用 $\kappa_1$、$\kappa_2$ 指两个模态的二次型系数（$E=\kappa_1n_1^2+\kappa_2n_2^2$），亦无关。本线的 $\kappa_1$、$\kappa_2$、$\kappa_3$ 是 P1-49 档案页第一轮判定设立的会话层临时编号：$\kappa_1$ = 作用量系数（$=1/e^2$），$\kappa_2$ = 自旋锚定强度（映射 $A_al_P=\kappa_2\hat{\mathbf s}\cdot\hat a$），$\kappa_3$ = 记录场识别式系数（$=1$）。

**建议**：本线成文时三个临时编号改用带限定语的名（如 $\kappa_{\rm act}$、$\kappa_{\rm spin}$、$\kappa_{\rm rec}$），避免与主曲率、模态系数两处撞名；改名时机与命名交作者裁决。

**量纲核验（2026-10-11，本线立论前提）**。$A_al_P$ 为格点搬运的相位角（无量纲），故 $\kappa_2$ 无量纲；$\kappa_1=1/e^2$ 无量纲。二者量纲可比，同一性检验在量纲上不被排除（此点排除了"量纲不同故无需检验"的短路，审计结论成立）。$\kappa_3=1$ 亦无量纲，第一轮已判否与 $\kappa_1$ 同一（比值 10.89 无换算族桥）。

## 三、路径组合

主攻为读数通道构造。核心洞察：映射 $\mathbf B=\kappa_2\nabla\times\hat{\mathbf s}$ 与标准磁学的源结构 $\mathbf B=\mu_0(\mathbf H+\mathbf M)$ 在"源在旋度处"这一点上逐条对应，故 $\kappa_2$ 可由真实磁化物质的响应数据反推。具体路径三步。

第一步，把体系映射的 $\hat{\mathbf s}$（自旋序参量）对应到标准磁学的磁化方向 $\hat{\mathbf M}$，$\kappa_2\nabla\times\hat{\mathbf s}$ 对应到磁化旋度源项。由量纲齐次性解出 $\kappa_2$ 的表达式（含 $\hat{\mathbf s}$ 的归一约定与格距 $l_P$）。

第二步，接入真实磁化数据的响应比值（磁化强度与磁场强度的量级比，如铁磁体饱和磁化 $M_s\sim10^6$ A/m 量级对应的 $\mathbf B\sim1$ T 量级），反推 $\kappa_2$ 的量值。关键：读数须经量纲桥工具换算到体系单位，且**不经过 $\kappa_1$ 或 $e$**（否则检验构造恒真，对照第 448 条判据无量纲化把 $\kappa$ 约掉的反面）。

第三步，与 $\kappa_1=1/e^2\approx10.89$ 对比，检查比值是否落在换算族常数（$2\pi$、$4\pi$、$\pi^2/4$ 等，见量纲桥 MB-1b 的换算族清单）上。判同则该通道为耦合常数的物质侧来源；判否则 $\kappa_2$ 与 $\kappa_1$ 彻底分开（磁铁机制不提供耦合常数来源）。

副攻为恒真检验设计：必须构造一个"若 $\kappa_2$ 与 $\kappa_1$ 无关也不影响读数"的反例，确认读数通道真的独立于 $\kappa_1$。若读数通道唯一经过 $\kappa_1$，则本检验为构造恒真，判 FAIL。

## 五、判据设计约束（沿用体系标准）

1. **恒真检验必配**：读数通道须给出"独立于 $\kappa_1$"的反例检验。若 $\kappa_2$ 的表达式唯一地经过 $\kappa_1$ 或 $e$，则为构造恒真，判 FAIL。

   参照第 448 条的教训：该判据无量纲化后 $\kappa$ 被约掉，读数不含 $\kappa$，是反向的构造恒真。
2. **多档扫描**：$\kappa_2$ 的反推须在多档磁化数据（不同材料或不同温区）下扫描，单档吻合不构成证据（对照第 569 条 B2 的多档纪律）。
3. **不动既有判据与映射**：第 448 条判据与 2026-09-30 裁甲的映射形式只作引用，不改动。
4. **读数先行核合法**：若反推落在与 $\kappa_1$ 的换算族疑点附近，须先查是否构造巧合（对照第 506 条的四段检验）。
5. **口径分层声明**：量纲桥换算是模型单位到物理单位的映射，读数结果须声明其依赖哪一层（模型层读数 / 换算层口径），不得跨层混报（对照反例：K_0 与 κ 的混淆正源于功能与量纲未分层）。
