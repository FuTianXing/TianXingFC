## 一、立项背景

### 1.1 P11 要解决什么

P11 全称介质不可探测性。提问形式是：元相子理论把真空设定为实在介质（元相子晶格），介质物理上总会留下效应，为何观测者测不出自己相对介质的速度？

这个问题的分量在两处。第一，相对性原理能否成立。若介质可探测，格点系成为特权参考系，相对性原理降级为近似。第二，光速不变能否成立。若介质参数进入传播速度的观测值，光速随观测者运动状态改变。

洛伦兹曾用长度收缩与本地时间给出运动以太中的补偿，那是特设性补丁。P11 要做的事是证明补偿是介质的结构性后果。现行论证框架已由牵头文档给出：分层定理（低能层精确不可读、普朗克层留预定签名）加四条引理（L1 测量协议不变性、L2 低能补偿、L3 光速外置、L4 绝对运动态不可读）。

### 1.2 现处位置

论证框架已写出，两处在体系内的自标需要如实引用。`以太问题的终结` 严格程度总表把 P11 列为「候选命题（观测者自指模型待完成）」；`开放问题总览` 第 3 条未关闭，第 29 条洛伦兹涌现链的形式化遗留标为「纲领」层。

框架与定理之间的差距由四处形式化缺口构成。本计划把这四处拆开，各自给出可执行的判据，并显式化它们的相互依赖。四处缺口的共同点是：L1、L4 停在物理图像，L2、采样适用性停在未闭合的计量层，L3 与 L2 的任务边界不清。

### 1.3 一个必须先说的事实

`开放问题总览` 第 29 条把洛伦兹涌现链的形式化遗留标为「纲领」层，这个层级与「条件性命题」不同。纲领层意味着论证方向已定、链节未逐一验证。本计划的目标是把纲领层逐节升级为条件性命题级，而非一步跳到定理级。四个任务的验收标准据此设定：每一节给出判据与读数或明确登记为未做。

## 三、缺口 P1：复合体构成规则（L1 的载体）

### 3.1 缺什么

L1 的现行表述是「快照抄写、摆钟、格距、光信号四类基本操作与运动状态无关」。支撑它的物理图像是「观测者全身都是钟」：测量者本身也是束缚振荡模式，与被测对象处在同一动力学层级。

这个图像要变成论断，需要两份形式化。第一份是构成规则：给定一族束缚模式，如何组装为复合体（观测者），组装规则的形式是什么。第二份是不含绝对速度的证明：组装后的复合体，其内部过程对格点系绝对速度的依赖项严格为零。

### 3.2 为什么不能只靠 L4

L4 说可探测量只含相位差，绝对格点速度不进入任何局域可观测量。从 L4 到「测量协议与运动状态无关」需要一步：任何测量协议的读数都是可探测量。这一步看似显然，实则是一个论断，它的内容是观测者的全部仪器由束缚模式构成，且读数生成过程只把相对相位差输出为可见量。

这个论断的证明落在构成规则上：若复合体由束缚模式组装，且读数是复合体内部相位关系的函数，则读数继承 L4 的相位差性质。缺少构成规则，「测量协议」这个概念就没有形式载体，L1 只能停在文字。

### 3.3 任务 PB-1：构成规则的形式化

目标：给出复合体（观测者）的构成规则，形式为「一族束缚模式的耦合配置」，并给出该配置的稳定性条件。

可选路线两条，待裁决（裁决点 A）。**路线甲（模式叠加）**：复合体定义为多个束缚模式在同一势阱背景上的叠加，耦合由模式间的相位差决定；优点是直接落在既有束缚振荡形式语言内，不必新建对象；风险是叠加态的时间演化可能引入额外交叉相位，需要证明该交叉不携带绝对速度信息。**路线乙（层级嵌套）**：复合体定义为束缚模式的嵌套结构（观测者的子部件各自是束缚模式，部件间由弱耦合连接）；优点是天然给出「全身都是钟」的层级图像，与测量协议的分层（快照抄写、摆钟、格距、光信号）对应；风险是嵌套规则的递归终止条件需要论证，否则无限嵌套。

判据先行（PB-1 四判据）：C1，构成规则在单模式下退化回既有束缚振荡方程；C2，组装后的复合体存在稳定束缚态（本征值实且谱有下界）；C3，复合体的内部过程频率与本征系内部频率之比为 \(1/\gamma\) 而不含 \(v/c\) 的一次项（这是「不含绝对速度」的直接体现）；C4，两条路线在同一物理装置下给出同量级的读数。

### 3.4 任务 PB-2：协议不变性的证明

目标：在 PB-1 给出的复合体上，证明四类基本操作（快照抄写、摆钟、格距、光信号）的输出与绝对速度无关。

技术的核心是：把每类操作写成复合体的相位关系函数，然后证明该函数对绝对速度的偏导为零。这条证明不依赖动力学的精确形式，只依赖两点：其一，操作的定义域是相位差空间；其二，复合体的内部耦合是平移不变的（不含格点绝对位置）。

若 PB-2 成立，「任何测量协议的读数都是可探测量」这一步补上，L1 从物理图像升级为条件性命题。此处需登记一个边界：PB-2 证明的是低能层不受绝对速度影响，普朗克层的签名不在本任务范围内（归 PB-6 的边界部分）。

## 四、缺口 P2 与 P3：计量层与束缚振荡精确动力学

### 4.1 缺什么

两处缺口共同挂在同一条上游：束缚振荡方程的精确形式。`内部草稿/研究方向-P11的解决` 的四引理中，L2 的低能补偿依赖运动束缚态的 boost 解，而 boost 解出自束缚振荡方程的 \(\sigma\) 版本。该方程的翻转规则（\(\sigma(t) = \pm1\) 的变号律与完美弹性判据）与交错基态的选择机制（相邻元相子为何反相）尚未从公理导出。这两条在 `开放问题总览` 里列为门控主障碍。

采样定理的物理适用性依赖同一处。阶梯函数与螺旋体的采样关系本身是数学恒等式（采样定理的数学内容为定理级，见 `螺旋阶梯几何` 定理 5.1），但「粒性侧的阶梯函数确实是波性侧螺旋体的采样」是物理论断，它要求满周闭合触发跃迁是精确的、周期性的。若翻转规则不严格，「精确」二字失去基础，几何恒等式地位被削弱为近似关系。

### 4.2 上游归属与接口

翻转规则的严格形式由 [[理论攻坚/缺陷动力学攻坚计划：σ 锁定方程的候选形式、与写入机制的接口与降级预案|缺陷动力学攻坚计划（代号 D）]] 承接，本计划不重复施工。需要显式化的接口有三条。

第一条，D 线的方程形式若落定为 \(\sigma\) 版本，本计划要求它给出可代入观测者响应装置的显式形式（势阱、耦合、边界条件），以便 PB-4 直接调用。第二条，D 线若给出翻转规则的严格形式，须同时给出该形式在低速极限下退化回自由方程（\(\sigma \equiv 1\)）的核对，这是本计划判据 C1 的上游对应。第三条，交错基态的选择机制若由 D 线或某条相变动力学线给出，本计划须核对它与晶格规范变换 \(\theta_n \to \theta_n + \pi n\) 下色散关系、光速涌现与洛伦兹破坏项的不变性相容。

### 4.3 任务 PB-3：计量层闭合度的判据化

目标：把「计量层闭合」这个定性说法换成可判定的判据，使「闭合到什么程度」有读数。

这里的困难在于，翻转规则与交错基态两条不是布尔量。可能的中间状态是：翻转规则的变号律有形式但完美弹性未证；交错基态有选择机制但仅在特定参数区成立。任务 PB-3 要做的是给出三档判据（完整闭合、部分闭合、不闭合），并明确每档对采样适用性的影响。

判据（PB-3 三判据）。C1，变号律在数值上成立：碰撞事件与 \(\sigma\) 变号一一对应，无漏计与多计。C2，完美弹性判据成立：碰撞前后的相位速度绝对值相等（相对偏差低于设定阈值），且阈值不随速度变化。C3，交错基态的选择机制在参数区上覆盖观测者响应的装置参数（\(\sigma = 10\)、\(20\) 两档）。

PB-3 的交付是判据本身加一次对现存装置的核对，不新建物理。若三条全部通过，采样适用性与 L2 同时升到条件性命题级；若 C1 与 C2 过而 C3 不过，登记为部分闭合，L2 的适用范围须附加参数区限制。

### 4.4 任务 PB-4：自指闭合（O5）

这是本计划最难的一项，也是 P11 自标「观测者自指模型待完成」正对的那一项。

问题的形式是：观测者的势阱由观测者自身的束缚结构构成，因此「观测者的势阱如何随运动变化」这个问题的答案包含在「观测者是什么」这个问题里，构成自指。

残差分离轮给出一条关键约束：任何运动观测者的数值模拟必须把观测者自己的势阱按 \(\sigma/\gamma\) 同步收缩，否则测得的「时间膨胀精度」会随 \(v\) 以非物理方式漂移（低 \(v\) 档约六成偏差来自该失配）。这条约束是自指的入口：势阱要收缩，而势阱是观测者自身的一部分，收缩这件事由谁执行？

任务 PB-4 的目标是把自指转成不动点问题：设观测者的势阱宽度依赖其自身的运动状态，写出这个依赖的自洽方程，求其不动点，并判定不动点是否与 boost 解一致。

当前被验证的是「外势阱按 \(\sigma/\gamma\) 收缩」这一后验装置。PB-4 要证的是该装置的自洽性：从束缚振荡方程出发，不预设收缩，证明自洽解恰好是收缩阱。若成立，残差分离轮的读数（收缩阱口径：\(v = 0.3\) 偏差 \(0.054\%\)、\(v = 0.6\) 为 \(1.310\%\)、\(v = 0.8\) 为 \(7.853\%\)）从「物理上正确的装置」升级为「方程的唯一自洽解」。

判据（PB-4 四判据）。C1，自洽方程有解且解唯一（在给定装置参数下）。C2，自洽解在低 \(v\) 极限退化回 \(\sigma/\gamma\) 收缩的外势阱结果。C3，自洽解下的频率偏差与残差分离轮的收缩阱读数相符（相对偏差低于设定阈值）。C4，自洽方程不含绝对速度的一次项（与判据 C3 的 PB-1 呼应）。

若无解或多解，登记为自指缺口未闭合，L2 维持条件性命题级并附加「势阱收缩为外部给定」的适用范围声明。这是降级预案的一条，不是失败。

## 五、缺口 P4：快照抄写投影与置零公约

### 5.1 缺什么

L4 的物理直觉是「可探测量只含相位差」。要变成论断，需要把「快照抄写」这一操作形式化为投影算子，然后证明该投影的像空间是相位差空间，且绝对格点速度不在该空间的坐标里。

「快照抄写」在体系内的角色是记录机制的基本操作（见 [[记录机制：碰撞即写入的算符形式、三维缺陷读数与弦的分层]]）。它把某种本体层状态写为可读记录。L4 的论断等价于：该抄写算符的核空间包含全部携带绝对速度的信息。

### 5.2 任务 PB-5：投影算子的构造

目标：构造快照抄写算符 \(P_{\rm snap}\)，给出其像空间与核空间，并验证核空间包含绝对速度自由度。

路线候选两条（裁决点 B）。**路线甲（代数构造）**：在既有模空间形式上把抄写写成线性算符，用提升关系与魏尔关系（见 `三-1` 对易关系线的读数：提升关系在模空间内部成立、魏尔关系在有限环上精确）确定其代数性质。**路线乙（动力学构造）**：把抄写定义为一次碰撞写入过程，用记录机制线的写入算符形式（见 D 线接口）给出。

判据（PB-5 四判据）。C1，算符幂等（抄写两次等于一次）。C2，像空间的坐标可写成相位差的函数，且不存在依赖绝对格点位置的坐标。C3，核空间包含整体平移生成元（绝对位置不可读）。C4，算符作用后整体 \(U(1)\) 变换的可观测量不变（时钟层绝对参数不可读的对应）。

### 5.3 任务 PB-6：跨观测者的置零公约

这一项是我在光速不变分析中提出、体系内尚无登记的缺口（出处为我，须标明）。

跨观测者比较光速，需要先约定「以谁定义的置零为准」。若以格点系定义置零，运动观测者无法校正波动源自身的因子，因为源的固有频率不被 boost 改变，这会强出 \(1/\gamma\) 的多普勒偏移。

正解的方向来自内部过程的计数结构。束缚振荡模式的内部过程计数速率，在本征系恒为一摆程一计数；跨越不同格点的总时长由所需摆程数决定，\(N = \gamma T_0\)，与振幅无关。由此 \(\rho_0\) 不变，横向多普勒与时间膨胀同为 \(\omega_b/\gamma\)。

任务 PB-6 的目标是把这个方向写成引理。引理内容（候选形式）：内部过程的计数速率在复合体的本征系恒为常数，且该常数与模式的振幅、宽度、所在格点无关。

判据（PB-6 三判据）。C1，计数速率的本征系恒常性在既有装置上成立（可由观测者响应线的读数反推核对）。C2，计数速率与振幅无关（振幅扫描下速率漂移低于阈值）。C3，从该引理导出横向多普勒与时间膨胀同源于 \(\omega_b/\gamma\)。

PB-6 与本计划第二节的 PB-7（引理收敛）直接相关，见下节。

另外登记一个相邻缺口：纵向多普勒的观测量是源频率与接收端取景之差，而「接收端取哪把钟」在体系内尚未形式化。我检索过「取景」「时钟同步」「Fizeau」，`开放问题总览` 与相关论文均无登记。这一项挂为 PB-6 的后续（PB-6b），本轮不开工，登记理由与建议入口写明。

## 六、缺口 P0：引理收敛（L3 并入 L2）

### 6.1 收敛的理由

L3（光速外置）与 L2（低能补偿）存在任务重叠。L3 说的是光速不定义于介质参数，即介质参数不进入传播速度的表达式，这属于「数值」一侧（命题 A）。真正承担「不变」的是 L2 的补偿机制（命题 B）。

若 L2 与 L3 共用同一条引理，内容是「内部过程计数速率在本征系恒为一摆程一计数」，则四引理可以收敛为三条，且收敛后逻辑更紧：源置零外置、路径传播内在地洛伦兹不变，由同一机制保证。

收敛的技术条件是 PB-6 的引理成立。因此 PB-7 的裁决点排在 PB-6 的读数之后。

### 6.2 任务 PB-0：裁决执行情况（2026-09-21 完成）

裁决已于 2026-09-21 执行，结论与原先的预设不同，此处如实记录。

**新发现**：L3 可以由体系既有结果独立证明。色散论文 §6.2 的物质模式去耦引理（二次型在 \((\Phi, \delta_1, \delta_2)\) 分解下严格块对角，误差只出现在超越线性理论的非线性项）给出空间传播扇区与内部规范扇区的严格分离；`元相子几何动力学` 补充注释 04 第三条（速度值与耦合强度无关，\(K_0\) 的角色退化为「保证事件确实传递」）给出传播速率由几何与节律给定。两条合起来即 L3 的完整证明，其中不含需要逐案核对的环节。

**收敛理由随之改述**：L3 与 L2 的收敛依据不是任务重叠，而是二者共用同一结构。去耦引理给出的「内部扇区与空间扇区严格分离」正是 boost 解能给出 \(\omega_b/\gamma\) 与 \(\xi_0/\gamma\) 的结构前提。故收敛的正确形式是把去耦引理提升为 L2 与 L3 的共用前提，两引理成为该前提在传播侧与测量侧的分别推论。论证链由「四引理并列」变为「一前提、两侧推论、两引理（L1 与 L4）」。

**裁决**：收敛成立。四引理的组织形式改为三引理加一前提。原草案中倾向结局甲的理由（L3 无法独立证明）不成立，改用以共用结构为依据的理由。

详细论证与严格程度分档见 [[内部草稿/研究方向-PB-0 引理收敛的裁决：L3 并入 L2 与三引理论证链|PB-0 裁决轮]]。裁决点 C 的时机相应提前，可立即裁定。

### 6.3 收敛对后续任务的影响

三处同步已在计划内完成：缺口总览与任务表已更新；PB-6 的内容并入前提的证明（P-a 与 P-c）；PB-7 撤销，其内容并入 PB-6 与 PB-8。

一处新增登记：收敛把 P-c（计数节律不变）提为机制层内容，其证明依赖对「摆程计数」的形式化，而摆程计数的严格形式正是缺口 P2/P3 的计量层内容。P-c 与计量层共用前置，此条已在依赖链中标出。

## 九、失败与降级预案

六条，按缺口分列。

- **PB-1 两条路线均无稳定解**：复合体构成规则降级为「弱形式」，即只给出组装后的有效描述而不给组装规则；L1 维持在物理图像层，登记未闭合环节。下游影响：PB-2 的不变性证明改为在给定复合体的有效描述上做，证明强度降低。
- **PB-2 不变性证明遇阻**：L1 降级为条件性命题并附加适用范围声明（四类操作中的哪几类已证、哪几类未证）。
- **PB-3 部分闭合**：L2 与采样适用性附加参数区限制，登记 C3 失败的具体参数区。
- **PB-4 自洽方程无解或多解**：自指缺口维持未闭合，L2 附加「势阱收缩为外部给定」的适用范围声明。这是预登记的降级方向。
- **PB-5 投影算子构造遇非自伴算符障碍**（与 `三-1` 对易关系线同族风险）：降级为形式对应加边界声明，L4 维持条件性命题。
- **PB-7 引理不成立**：置零公约无载体，跨观测者比较退回「以格点系定义置零」的原始口径，光源 \(1/\gamma\) 多普勒问题作为独立缺口登记（PB-6b 升为主项）。

一条全局降级：若 MB3 依赖的 D 线长期未交付，本计划按「PB-1、PB-2、PB-5、PB-6、PB-7 五节独立成立、L2 一节挂起」的形式分两批交付，不等齐。
