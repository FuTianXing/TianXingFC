## 三、攻坚策略总纲

**逻辑链**。三条承重墙构成一条单向依赖链：先有"什么事件定案"的判据（阶段一），才有"定案时按什么概率发生"的采样协议（阶段二），才有"被采样对象是什么存在"的语义同一（阶段三）。顺序不可颠倒，但阶段一与阶段三的准备工作可并行（分类学盘点与 P7 层级梳理互不依赖）。

**最小可行闭环原则**。每个阶段内部再拆为可独立评审的最小单元（里程碑，见第八节）。任一单元失败或降级，不影响其他单元的进展；阶段的验收标准独立判定，全部单元的结论汇总后才进入登记。本原则吸收《粒子机制阶段总结》的教训：战线过长、结论互相牵连会导致反复返工，最小闭环保证每步都有可复核的凭据。

**工具基础**。三个阶段共享两套既有工具：快照抄写与份额语言（《序参量份额定理》）、法线轴层位基与复合位错模型（《注记-新模型下的叠加态与概率幅》及其载具注记）。数值验证一律遵守 AGENTS.md 数值验证脚本规范：脚本命名 `minimal_verification_<主题>.py`、判据先行、确定性协议、结果注记配套、随机固定种子。

**纪律条款（吸收 2π 教训）**。验证脚本的力项与方程必须独立复核后才登记结论；数值结论标注可逆性等级（判据敏感 / 判据稳健）；协议伪影与物理结论分层报告。此条款先行在本线生效，是否推广为全局规范待作者决定。

## 四、阶段一：凝固判据攻坚（内部张力，最高优先级）

### 4.1 任务分解

**任务 1-1：碰撞分类学盘点。** 体系内现有四类共用"碰撞"一词的操作。按读写对象建立判别矩阵：

| 碰撞类型 | 载体 | 读写对象 | 是否触碰层位占据 |
|---|---|---|---|
| 晶格背景逐拍采样（束缚振荡常态） | 元相子对撞 | 波性侧（相位差、取向场 $\alpha$） | 否 |
| 引力碰撞写入（每拍重写标架记录） | 格面标架 | 波性侧（标架倾斜记录，格点保持刚性） | 否 |
| 弹性碰撞折返（P3-21） | 相邻圆心互斥 | 几何坐标，无信息读写 | 否 |
| 探测锚定凝固（测量事件） | 探测器晶格 | 粒性侧（质心层位、绕数转移） | 是 |

矛盾现状：四类只有探测类坍缩。分类学的目标是显式化每类碰撞的读写对象，使"坍缩与否"成为读写对象的函数，而非碰撞事件的函数。

**任务 1-2：判据提案。** 候选判据为，定案碰撞 = 质心自由度与背景建立相位锁定（定理 9）且伴随粒性侧层位占据的不可逆转移；相干碰撞 = 只读写波性侧信息，不触碰层位占据。为使判据可计算，给出两个可测量的定义。其一，相位锁定度 $L = 1 - \mathrm{Var}(\Delta\Phi)$，其中 $\Delta\Phi = \Phi_{\text{cm}} - \Phi_{\text{bg}}$ 为质心相位与背景相位的差，锁定意味着方差塌缩（$L \to 1$）。其二，块内相干因子 $\eta_a = \frac{1}{N_a}\sum_{i\in a} e^{i\delta_i}$ 的演化：定案碰撞应使 $\eta_a$ 衰减至 $|\eta_a| \ll 1$，相干碰撞应保持 $|\eta_a| \approx 1$。判据的操作形式：碰撞事件按"是否改变层位占据"二分，层位改变者触发锁定与相干衰减，其余保持叠加。

**任务 1-3：最小模型数值验证。** 一维 FK 链（沿用复合模型参数区 $K/k \le 0.02$，保证 $\ell \ge 2$ 落窗）上构造 kink，施加两类碰撞协议。协议甲：背景弹性碰撞，只读取相位信息，不改变层位。协议乙：层位转移事件，kink 质心与背景某层位建立锁定、背景相位重排。测量量为位置叠加的干涉可见度 $\mathcal{V} = 2|\rho_{nm}|/(\rho_{nn}+\rho_{mm})$（密度矩阵非对角元）与相干因子演化。判据先行：协议甲下 $\mathcal{V}$ 保持（不低于初始值 0.9），协议乙下 $\mathcal{V}$ 衰减至经典混合（低于 0.1）。两协议轨迹必须可区分，否则判据失效。

**任务 1-4：心侧角色裁决。** 整理两个方案及兼容性代价。方案 A：物侧碰撞加数定律独立承担凝固时机，心侧不进入测量语义，与《序参量份额定理》"推导链心侧不进入"的声明一致，但需要解释单次随机性的物侧来源（移交阶段二相位均匀性假设）。方案 B：天行力校准参与凝固时机，可提供随机性来源，但与"心侧不进入"声明冲突，需修订声明并给出校准的物侧签名。两方案各自列明改动面，提交作者裁决并登记。

### 4.2 失败与降级预案

- 若协议乙下叠加仍保持相干（层位转移不导致定案）：判据方向反了，转备选判据"能量阈值"，定案需要超过锚核绑定能 $E_B$ 的能量注入。该备选与 P1-31 钉扎势垒工作同族，可借用其数值工具。
- 若协议甲下叠加也衰减（弹性碰撞即退相干）："碰撞即测量"字面成立，双缝存活需要额外保护机制，转 P4-10 退相干独立推导路线，本线结论降级为"所有碰撞都是弱测量，定案是累积效应"。
- 若两协议轨迹不可区分：判据候选整体失效，将四类碰撞的观测签名差异整理为登记表，转作者裁决是否引入新的分类维度（如能量尺度、纠缠度）。

- 验证脚本 `验证脚本/minimal_verification_collision_taxonomy.py`（两协议对比 + 可见度演化）

判据同时容纳四类事实：双缝干涉存活（探测前）、测量定案（探测时）、引力碰撞写入不坍缩物质叠加（每拍重写当下）、宇宙整体不坍缩（晶格背景采样为常态）。数值上协议甲/乙轨迹可区分，且区分方向与判据预测一致。

## 五、阶段二：单系统概率桥（系综-单系统鸿沟）

### 5.1 任务分解

**任务 2-1：相位均匀性假设的形式化。** 提出凝固时刻的快照相位 $\tilde\Phi$ 在 $[0, 2\pi)$ 均匀分布的假设，由份额权重加随机快照时刻构造单次测量采样协议：单次测量 = 随机时刻的快照采样，结果 $a$ 出现的条件概率为份额 $N_a/N$，频率收敛性由大数定律补齐。该假设的物侧来源有两个候选：先验纠缠的整体相干（零度基准是数学约定，相位无内禀零点，"无别圆"结构给出均匀性）与背景涨落 $\sigma_\phi$ 的统计（信息层噪声）。检验方法两条：数值模拟系综快照相位的分布直方图；与 P1-29 挂钩，若相位均匀性成立，纠缠锁定的 $\Delta\alpha$ 关联应能导出 Tsirelson 界 $2\sqrt{2}$，把非定域性的定量推导从定性论证升级为可算对象。假设若被采纳，需声明其层级（波性侧公设级推论或导出命题）。

**任务 2-2：位置叠加的份额语义落地。** 把 $N_a/N$ 从人数份额推广为层位相干份额。位置基 = 法线轴层位 $|n\rangle$（距离归粒定案，$x^a = l_P n^a$），位错位置概率幅定义为 $c_n = \sqrt{W_n}\,e^{i\Phi_n}$，其中 $W_n$ 为位错与背景在第 $n$ 层的耦合权重，即背景序参量在层位 $n$ 的局域相干强度归一化。份额守恒 $\sum_n W_n = 1$ 来自背景序参量归一化，人数守恒不再承担位置概率的物侧意义。此定义消除单粒子语境下"人数"无指涉的语义漂移，同时保留份额恒等式的代数结构。

**任务 2-3：块分解唯一性攻坚。** 论证测量基为何是层位基。证明路线分两步：其一，超选择扇区结构（跨扇区矩阵元为零）已有数值确认，严格化路线已定为 Knill-Laflamme 条件（局域支撑 $r \ll L$ 时矩阵元指数压低，热力学极限严格零），沿电荷论文遗留路线推进；其二，测量装置同为晶格，探测 = 层位转移事件，基由转移事件类型决定，由此论证层位基的唯一性。若论证不闭合，降级为条件性命题"测量基由装置响应类型决定"并登记成立条件。

**任务 2-4：单次采样与退相干的层级澄清。** 单次采样是粒性侧事件（快照抄写），退相干是系综层相干因子 $\eta_a$ 的衰减。两者关系候选：退相干 = 大量相干碰撞的累积效应，每个相干碰撞读取相位信息但不定案，多次读取使相对相位信息散失到背景。该图像给"弹性碰撞为何不立即坍缩但长期会退相干"一个统一解释，同时为阶段一协议甲提供长期行为预测（可见度随时间缓降而非骤降）。

### 5.2 失败与降级预案

- 若相位均匀性假设被数值或论证否定：随机性来源改由凝固判据本身承担（定案时刻由碰撞几何决定，随机性来自碰撞事件的不可预知性），均匀性降级为有效近似并声明适用域。
- 若 Tsirelson 界推导失败：P1-29 维持开放，不影响本阶段其余任务，仅登记"相位均匀性与非定域界未挂钩"。
- 若层位份额的 $W_n$ 无法从背景序参量场唯一定义：降级为"份额语义 = 有效理论描述"，与 P4-5 系综到单粒子投影缺口同登记，标注为体系根本性开放问题。

### 5.3 交付物

- 《单系统 Born 采样：凝固时刻、层位份额与随机性来源》（内部草稿）
- 验证脚本 `验证脚本/minimal_verification_single_system_sampling.py`（随机时刻采样模拟，频率收敛 $|c_a|^2$，含有限 $N$ 偏差；相位分布直方图检验）
- 块分解唯一性论证或降级登记

### 5.4 验收标准

采样协议显式可执行；数值收敛与解析论证双通道闭合；层位份额有物侧定义，不再依赖人数隐喻；块分解唯一性成立条件明确陈述或降级登记；单次采样与退相干的层级关系有明确结论。

## 六、阶段三：叠加语义同一（P7 与新模型统一）

### 6.1 任务分解

**任务 3-1：同一性论证。** 位错 = 背景 W=1 均匀缠绕上的序参量亏空。候选亏空泛函形式：位错位置概率幅 $\psi_n = \sqrt{|w_n^{\text{bg}}|}\,e^{i\arg w_n^{\text{bg}}}$，其中 $w_n^{\text{bg}}$ 为去掉位错占据后的背景序参量在层位 $n$ 的分量。把 P7"波函数 = 序参量开方像"从系综平均（全体元相子相位的集体平均 $\Psi = \frac{1}{N}\sum_i e^{i\theta_i}$）推广为背景序参量场的局域亏空泛函，衔接逻辑为"背景 = 系综的局域化"，即序参量场的空间不均匀分布。未闭合环节预估：亏空算符的形式化（背景场如何减去位错占据）、三维推广。论证过程中若某环节无法闭合，逐项标注为纲领性主张并给出替代候选。

**任务 3-2：P7 层级对照表。** 显式化两个表述的层级关系：

| 层级 | P7 表述 | 承担职能 |
|---|---|---|
| 系综层（定案） | 波函数 = 全体元相子序参量的开方像 | 概率的数值来源（份额恒等式） |
| 单粒子层（推广） | 位错波函数 = 背景序参量局域亏空的开方像 | 叠加的内容（位置相干和） |
| 衔接命题 | 背景 = 系综的局域化（序参量场空间不均匀） | 同一性论证的对象 |

对照表明确：两表述分属不同层级，同一性论证的任务是建立衔接命题，而非把两个表述强行合并。

**任务 3-3：叠加普适性边界声明。** 声明叠加原理的适用域：长波（$k l_P \ll 1$）、缓变包络、小振幅线性区。线性波动方程的解空间性质给出适用域内的精确叠加性，不冒充普适。强场非线性修正以候选形式登记：Klein-Gordon 残差（$(E/mc^2)^2$ 阶）与晶格离散修正（$(E/E_P)^2$ 阶，与体系洛伦兹破坏分析同源）。声明的意义：消除"以线性近似冒充普适来源"的漏洞，把叠加原理的合法范围从隐含默认变为显式命题。

**任务 3-4：兼容性检查。** 与 P7 定案、五步降级总结论、复合位错三层解剖（电荷核/锚核/包层）逐项核对。检查清单：亏空泛函与份额恒等式不冲突；层级对照表与五步降级表的公设降级路径不冲突；叠加适用域声明与薛定谔方程推导的条件性声明（长波 + 缓变包络）一致。写作铁律与术语一致性验证。

### 6.2 失败与降级预案

- 若亏空泛函无法从背景序参量场唯一定义：同一性论证降级为"两表述并存的层级声明"，衔接命题登记为开放问题（并入 P4-5），本阶段产出改为层级对照表 + 声明，不宣称同一。
- 若层级对照表与五步降级总结论冲突：以总结论为准，本阶段结论修订后重新核对，冲突记录入评审报告。
