## 一、问题

三问同源。「电子是电子场的激发」在体系内是定义性要求，不需要独立验证，因为电荷、自旋、质量、局域性四个标签的载体已经分别安置完毕，而它们落在紧致性与局域性都不同的四个自由度上。

若存在电子算符，它必须是这四层的单一接合。「电子场对应什么」的答案被逼成波性侧绕数承载层与粒性侧锚核层在同一算符里的缺陷算符，读作 $S^1\times\mathbb{R}$ 上的算符，形式上形如

$$\hat D = \gamma^{i}\bigl(\partial_\theta + \gamma^{h}\partial_h + \cdots\bigr), \qquad i = 1,2,3,\ h\in\mathbb{R}.$$

这是二维 Clifford 代数上的 Dirac 型算符。[[从绕数困境到复合位错粒子：电荷载体问题的完整解决]] 已把电荷核与锚核的耦合机制列为开放问题其三，该耦合至今未建立。

## 二、四标签的落点与同源性

体系在四标签上的安置并非拼凑。每个标签被推到哪一层由同一条规则决定：信息性越强的标签越靠非定域的结构，质量这类实存性标签越靠局域的结构。位形侧四重否定、承载层裁决、弹性身份裁决三轮排除全在执行这条规则。

| 标签 | 载体 | 所在空间 | 紧致性 |
| --- | --- | --- | --- |
| 电荷 | 绕数 $n\in\mathbb{Z}$ | 相位圆 $S^1$ | 紧致 |
| 自旋 | $\pi$ 扭转奇偶 | 内部 $\mathrm{SU}(2)$ 的 $\mathbb{Z}_2$ | 二值 |
| 质量 | 锚核绑定能 $\propto\kappa_\varphi$ | 法线轴高度 $\mathbb{R}$ | 非紧致 |
| 局域性 | 锚核钉位 | 法线轴 $\mathbb{R}$ | 非紧致 |

四者中只有质量与局域性共用粒性侧，电荷住波性侧，自旋需要第三个因子。这解释了单一自由度上三要求不可同时满足的原因，也解释了为什么两层结构是唯一出路。

## 三、核心二择一：螺旋序的真空地位

「位错是否与量子场论的基本粒子是场的激发相容」这一问的答案不由位错的形象决定，由螺旋序是否被对称恢复决定。均匀缠绕背景（法线轴逐键一层）在物理上是自发破缺的有序态，序参量为单位键上的缠绕密度 $w_0$。

法线轴 $\mathbb{R}$ 非紧致，$w_0\neq 0$ 无法被连续变换消去。因此存在唯一真正卡住全线的二择一：$w_0$ 是约定零点（可恢复读法），或者 $w_0$ 是真实的序（破缺读法）。

| 项 | 可恢复读法 | 破缺读法 |
| --- | --- | --- |
| 位错的地位 | 零背景自由激发 | 自发破缺理论的 kink 或规范场涡旋线 |
| 体系相对 QFT 的层级 | 紫外完成 | 凝聚相的有效理论 |
| CPT | 自动满足 | 须论证 $w_0\mapsto -w_0$ 的等价性 |
| 正反粒子的来源 | Dirac 算符的负能分支 | 缺陷族的背景偏离符号 |
| 质量的机制 | 算符本征值 | 缺陷绑定能（现行裁决） |

这一个裁决同时决定上表五项。任何在它之上展开的构造都是空中楼阁，所以其余阶段一律挂起。

阶段 0 第二半的结果（2026-09-29，第 481 条）。判据 T2 已执行并全部通过，把缺陷分成共相位型与单通道型分别测。读数三条：$\kappa_\phi$ 对共相位缺陷完全失明（格点内项只依赖相位差，共相位位移是其对称变换，跨六个数量级锁定强度比为机器零）；共相位缺陷的残余钉扎只来自键项与离散性并随宽度指数衰减（斜率 $-3$ 至 $-4$ 每格）；单通道缺陷的钉扎由锁定供给，且与单相位 FK 的基底势逐位同形，恒等为 $K_{\text{FK}} = 2\kappa_\phi$。

C2 据此判为**不等价**：PN 势是单通道缺陷的语言，$\kappa_\phi$ 锁定是共相位缺陷的对称性。由此暴露一个二难：取单通道型则 $K_{\text{FK}} = 2\kappa_\phi$ 而 $\kappa_\phi t_P = 9.293805\times10^{-47}$ 极小、钉扎退到可忽略；取共相位型则 $\kappa_\phi$ 失明、PN 代理不成立。两条路都不能在既有参数下给出锚核的钉扎来源。位错型别判定须另行立项，登记为阶段 0 第二半的后续。

换算字典的结果（2026-09-29，第 482 条）。判据 KD1 至 KD4 全部通过。KD1：481 的恒等 $K_{\text{FK}} = 2\kappa_\phi$ 与定稿势系数 $3\kappa_\phi t_P$ 相差因子 $1.5\,t_P$，属 $O(1)$ 口径项，两处同源。

KD2 至 KD4：框架的定稿值表只给出一个比值 $r = 4.437466\times10^{-47}$；该比值满足全部落窗（以离域方式，软模关联长度 $2.3892\times10^{22}$ 格），落在驻留阈值以下 $45.73$ 个数量级，判定判负。驻留所需的异类耦合为 $\kappa_\phi t_P \ge 5.026548\times10^{-1}$，现值为 $9.293805\times10^{-47}$，倍率 $5.41\times10^{45}$。

两条附带发现须并入本计划。其一，**定稿值表对两层结构欠定**：框架只给出一组（势系数, 键刚度），而锚核驻留与包层宽度要求两个互斥的比值，第二个刚度未定稿。其二，**目标值为 $O(1)$ 量级而推导值为 $10^{-47}$**，这个错位指向归一化环节，并且把量纲桥收束报告第六节其三已登记的层级问题（$10^{-47}$ 为何如此小）与锚核钉扎失败连成同一件事。后续入口为重走 MB-1 至 MB-9 的归一化链条以判定 $10^{-47}$ 的来源。

来源判定的结果（2026-09-29，口径判定注记，不另立脚本）。七环逐环核对完毕，**无一环引入可调数值尺度**；链条只输出结构（$\epsilon = 1$、$K = 3\kappa_\phi t_P$、$m_\Phi = 2\pi$、$k_b = 2\pi$）与一组分层条件，不输出 $\kappa_\phi$ 的数值。判定为第 482 条的第二条出路并加一处限定：$10^{-47}$ 是体系的**输入值**，由电子质量这一尺度锚在缺口模式关系 $m = \hbar\sqrt{6\pi\kappa_\phi t_P}$ 上反解得到，链条内部无来源，其小属已登记的层级问题。

一处疑似不一致已复核排除：$m_\Phi$ 的 $2\pi$（MB-9）对 $3.5866\times10^{45}$（MB-2、MB-5 的场景一）差约 45 个数量级，实为 MB-9 关闭了 MB-2 登记的最后一维自由，后者属被取代的口径。内部一致性核对通过：缺口 $2\pi\sqrt{K/m_\Phi} = 4.1855003\times10^{-23}$ 与 $\sqrt{6\pi\kappa_\phi t_P} = 4.1854999\times10^{-23}$ 相符到八位有效数字。

**由此得到本计划阶段 0 的实际结论：锚核须拆为两项。** 质量侧要求 $\kappa_\phi t_P = 9.293805\times10^{-47}$（电子质量锚定），钉位侧要求 $\kappa_\phi t_P \ge 5.026548\times10^{-1}$（驻留阈值），两者相差 $5.41\times10^{45}$。同一层不可能由同一个耦合同时满足。量级换算进一步给：可钉扎的锚质量为 $3.758\times10^{19}$ GeV，约 $3.1$ 倍普朗克质量，高于体系描述的失效能标；故钉扎尺度的来源不能是质量锚。
