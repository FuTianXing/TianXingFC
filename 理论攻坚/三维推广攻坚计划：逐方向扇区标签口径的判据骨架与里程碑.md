## 一、任务定位

一维链上锁定刚度已闭环：$\kappa = 1/L = 0.125$ 由三条独立通道（保护距离、键曲率、扇区纯度）合流给出，门槛带 $\gamma_c/\kappa = 1.29 \pm 0.10$、均匀化联合条件 $\gamma \le \sqrt2\,p\,4\pi/L^2 = 0.0139$ 均以一维口径交付。案甲裁决把三维推广的路线定为逐方向复用：物理空间的三维性体现为三个方向各持一套单向扇区标签，锁定刚度按方向定义，方向间的物理内容由异类耦合 $\kappa_\phi$ 承载。

本计划回答四个问题。其一，整数格点恒等式与扇区计数如何逐方向三维化（T1）。其二，锁定刚度的逐方向分解与方向间同步动力学（T2）。其三，绕数扩散的宇称子格结构在三维的形态与案甲口径下的纯度读法（T3）。其四，门槛带与均匀化条件的三维形式，特别是维度因子落在哪一侧（T4）。附带一项接口核对：方向间同步的耦合是否与格点锁定耦合同源、有无新自由参数（T5）。

## 二、判据组设计

每组判据按体系纪律给出：理论期望、判据形式、容差来源（误差预算）、简并检测归属、多档扫描点与恒真检验（EP5）。脚本实现遵循验证脚本规范：判据先行写死于头注、冒烟检查先于判据循环、协议伪影与物理结论分层报告、可逆性等级标注。

### T1 逐方向整数格点恒等式与扇区计数（对接第 212 条）

- **理论期望**：三维格点上每方向独立满足 $\theta^{(a)}_{j+L} \equiv \theta^{(a)}_j \pmod{2\pi}$（$a = x, y, z$），单向标签下每方向相异扇区数 $N_{W_a} = L$；联合构型计数 $L^3$ 仅作计数事实并存。
- **判据 T1-1**：三方向分别读出模恒等式成立与 $N_{W_a} = L$，三档规模 $L = 4, 8, 16$ 扫描。
- **容差预算**：整数格点恒等式无截断项，误差全部来自浮点舍入，预算 $\varepsilon \cdot L \cdot$ 迭代数 $\approx 10^{-14}$ 量级，取 $10^{-12}$ 起步（对标一维实测 $1.42\times10^{-14}$，留两个数量级余量）；超容差即回查实现而非放宽。
- **简并检测**：扇区构型空间按方向直和，单向扇区投影算符的谱最大簇重数预期为 $L^{2}$（固定该方向扇区后其余两方向的自由构型数）；读数一律走子空间谱分类，禁单矢期望。
- **EP5 恒真检验**：把恒等式替换为 $\theta^{(a)}_{j+L} = \theta^{(a)}_j + \pi$，判据必须 FAIL；不 FAIL 则判据构造恒真，无物理信息。

### T2 锁定刚度的逐方向分解与方向间同步（案甲核心）

- **理论期望**：场层闭式按方向分解，每方向回拉份额 $\kappa_a = 1/L$；方向间经 $\kappa_\phi$ 同步后三方向 $\kappa_a$ 取同一数值（各向同性）。
- **判据 T2-1**：逐方向 $\kappa_a = 1/L$，模投影法读出，三档 $L$ 扫描。
- **容差预算**：一维场层闭式残差实测 $9.082\times10^{-4}$（第 200 条），三维按三方向独立残差平方和开根放大 $\sqrt{3}$ 倍，起步容差取 $2\times10^{-3}$；判据敏感级（换闭式口径会翻）。
- **判据 T2-2**：方向间同步：三方向 $\kappa_a$ 的相对极差 $\le 5\%$（多档 $\kappa_\phi/\kappa$ 比值扫描，至少四档）。
- **冒烟检查（本组强制）**：先打印 $\max|F_p|$ 与逐轴变化性，核对「变化的轴 = 扰动的轴」：仅扰动 $x$ 方向扇区分布时，回拉响应须以 $x$ 方向为主、其余两方向响应按 $\kappa_\phi$ 耦合衰减，非零且合理再进判据循环。
- **EP5 恒真检验**：$\kappa_\phi = 0$ 时三方向退耦，同步判据（T2-2）必须 FAIL；同步判据在退耦极限不 FAIL 即为构造恒真。

### T3 绕数扩散的宇称子格结构与纯度读法（对接第 213、214 条）

- **理论期望**：一维宇称锁两条子格，三维按方向独立宇称锁得 $2^3 = 8$ 条子格；案甲口径下纯度按方向读：每方向从 $2/L$（单缺陷，宇称锁内）经成对事件落到 $1/L$；联合构型纯度为逐方向纯度之积（若方向独立成立），它属构造内事实，不承载耦合定义。
- **判据 T3-1**：8 子格结构经宇称投影谱分类确认（简并检测先行：宇称投影算符谱最大簇重数与簇结构须先报告）。
- **判据 T3-2**：逐方向渐近纯度 $2/L \to 1/L$，成对事件占比阈值 $\ge 0.2$ 附近至少四档 $\rho$ 扫描（单缺陷速率与成对速率之比），阈值判据禁止单档超阈即判 PASS。
- **判据 T3-3（独立性核对）**：联合构型纯度实测值与逐方向纯度之积一致，作为方向独立性的数值支撑。
- **容差预算**：纯度读数为抽样统计量，容差 = $1/\sqrt{N_{\rm eff}}$；要求 $N_{\rm eff} \ge 10^6$ 给 $10^{-3}$ 档，阈值扫描档距须大于三倍抽样标准误差，否则加长采样。
- **测量合法性**：纯度读数落在扇区简并空间，EP1 至 EP4 四段检验为模板必调，EP3 取子空间内随机组合矢的分布半宽（禁本征基列实现）。

### T4 门槛带与均匀化条件的三维形式（对接第 205、216、219、224、234 条）

- **理论期望**：第 234 条已给三维横模谱隙等于回拉份额 $\kappa$、洛伦兹口径 $\gamma_c = 0.5\kappa$；待判的是维度因子落点：三维随机行走每方向方差与一维同型（案甲逐方向读法，联合条件形式不变），或三方向方差相加使均匀化条件收紧（维度因子 3 进阈值）。两者可判别，判别结果即三维推广的主要新读数。
- **判据 T4-1**：三维横模谱隙逐方向等于 $\kappa_a$（对接第 234 条 Z1，容差从谱计算精度预算：精确对角化取机器精度档 $10^{-13}$，迭代法按收敛残差另定）。
- **判据 T4-2（判别性）**：均匀化阈值按方向 $V^\ast_a = L^2/(4\pi)$ 与联合 $3V^\ast$ 两案，数值扫描判定实测门槛带与哪案相容；$L = 4, 8, 16$ 三档，档间标度关系本身作为判据（案甲预言逐方向阈值与 $d$ 无关，联合案随 $d$ 移动）。
- **判据 T4-3**：三维联合条件终形与门槛带的相交性判定（一维结论为不相交，三维按 T4-2 判别结果重推）。
- **容差预算**：门槛系数沿一维口径 $1.29 \pm 0.10$（六档极差 0.21），三维起步容差 $\pm 0.15$，至少六档扫描；行走方差判据容差从 $V = \tau(\Gamma + \Gamma^2)$ 的截断项与采样噪声合并预算，禁未预算设数。
- **EP5 恒真检验**：T4-2 的两案判别须给出「改掉维度因子就 FAIL」的对照：把逐方向读法错误地套上维度因子 3，判据应翻转。

### T5 方向间耦合的同源性核对（参数经济）

- **理论期望**：方向间同步的耦合常数与格点锁定的异类耦合 $\kappa_\phi$ 同源，不引入新自由参数（对接一维 K7 判据「新增常数 0」）。
- **判据 T5-1**：同步率读数对 $\kappa_\phi$ 的依赖形式（预期线性），斜率无自由系数；四档 $\kappa_\phi$ 扫描。
- **边界**：若同步率出现独立于 $\kappa_\phi$ 的第二项，按判据敏感级登记并交作者裁决，不强行归一。
