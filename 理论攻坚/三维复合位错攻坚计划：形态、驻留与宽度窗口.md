## 一、立项背景

C1 登记为「三维复合位错（形态枚举 + Derrick 复查 + 双协议驻留判定）」，依赖关系为空（首发）。它被三条下游压着：张量桥分段 (c)（潮汐项与里奇对应）、分段 (d)（源项 $T_{\mu\nu}$ 微观分解）、以及强场物理（P1-34a）。

体系当前的粒子机制数值工具链是一维的（FK 链与三元组链），而已有一次定案级的负面结果：裸格点模型中涡旋环不存在亚稳驻留态，一切协议下塌缩到真空、绕数丢失（[[注记-环的裁决实验：裸模型无亚稳与绕数承载层问题]]）。此后又有一次正面结果：$\sigma$ 锁定 kink 在三维拓扑稳定、绑定能随 $\kappa_\phi$ 单调增长（[[注记-kink三维稳定性与体系哈密顿量构造的最小验证]]）。

两次结果的差别在于载体的绕数写在结构的哪一层。复合位错纲领的立论是：锚核的存在改变问题（钉扎阱已确认）。本计划把该立论拆成可判定的任务序列，并把 2026-09-12 的中间尝试（一条硬负面结果与一个未判定候选）如实登记为起点。

## 三、C1-0 的专项说明（已执行，2026-09-12）

C1-0 是本轮投入的首项，产物为常驻脚本 [[minimal_verification_vortex_init_apparatus]]（判据 M1 至 M12 全部通过）与注记 [[注记-涡旋初始化与横截面绕数测量装置的最小验证：切平面零读数的根因]]。它交付两类公共资产：目标构型的初始化，以及横截面绕数测量装置。

**根因更正。** 2026-09-12 的尝试把零读数归因于初态构造有缺陷。实测否定了该判定：初态合法性没有问题，零读数来自测量平面的选取。

环芯圆位于 $z = 0$ 平面，顶点处芯线切线为 $\hat y$，旧代码把平面法向取成了环轴方向 $\hat x$，该平面族与芯线的关系是平切（$x = R_c$）或落在环外（$x = R_c + 0.5$）。$x < R_c$ 的平面虽与环有两个交叉点，但半宽 $3$ 格的窗口把两者一起套住，两个反号的 $2\pi$ 相消。

三条硬性规则（平面须横切芯线、窗口不得套住两个交叉点、格点须半格偏移）由判据 M4 至 M6 逐条实证。

整平面求和为零与盒的周期性无关：环在平面上有两个取向相反的交叉点（判据 M4c）。开放边界的作用是给真空渐近（边界外一圈取 $\varphi = 0$）。

**术语更正。** 环芯线缺陷的分类是 $\pi_1(S^1) = \mathbb{Z}$（场取值在 $S^1$），计划与旧注记中的「$\pi_2$」属记号误用，判据内容不受影响。

**构造层的边界。** 标准环初态（$\varphi = \operatorname{arctan2}(z, \rho - R_c)$）每面两个交叉、读数精确为 $\pm 1$、涡量集中到 $0.03$ 格，代价是相位在无穷远趋于极角，初态能量随盒增长（判据 M12），属非局域对象。遮罩式构造（环裁决实验 v2）局域且有真空渐近，代价是在 $\rho = R_c + 3.5$ 处多出一个反向涡环（判据 M7），不可作单环基准。带真空渐近的单环构造尚未给出，登记为 C1-1 的输入问题。

**装置的常驻形式。** 绕数在横切芯线的平面内测，窗口半宽 $2$ 格，格点半格偏移，开放边界。动力学读数须先定位交叉所在 plaquette 再读（判据 M10）。直线涡自检给出 $1.0000$。

## 四、已登记的中间结果（2026-09-12，含修正）

**负面结果（硬）。** 锚核按「键耦合弱化」（环芯处降低 $J$）实现时，depth 从 $0$ 扫到 $0.95$、半径 $3$ 至 $6$，环全部塌缩到真空、绕数归零，与裸环结局相同。可读的原因：降低键耦合减少的是空间梯度代价，环的整体线张力由体积项与磁项主导，故驻留不出现。

**原「正向信号」的改判。** 相位锁定型锚核（钉扎势把芯位相位锁到目标角）下构型驻留、能量有限（$\kappa_p = 0.5$ 至 $4$ 给 $162$ 至 $681$），原记录为「未判定」。

测量装置修正后读数可用，判据为不守恒：$\kappa_p \le 2$ 时全盒涡量归零，构型被卸载成光滑的无绕数场；$\kappa_p = 4$ 时保留的是正负配对的涡量网络（每面 $16$ 对），窗口恰好读到 $+1$ 属网络中的一个分量。

$2\pi$ 周期的锁定形式给同一结果，故「$\pi$ 周期留出 $\varphi \to \psi + \pi$ 分支」这一猜测被排除。这些读数为单协议预备观察，双协议对照归 C1-1。改判结论：能量有限不等于绕数守恒，「驻留」在锚核实现层尚未成立。

**三条过程教训（修正后）。** 其一，环芯的绕数在横切芯线的平面内测，方位角向涡量与顶点法向平面都给零（环裁决实验 v1 与本注记 M4 各记一次）。其二，决定读数的是测量平面族与环的关系：平切平面、环外平面、双交叉窗口都给零。其三，锚核的物理语言仍是钉扎阱（势项），但相位锁定型实现不守恒绕数。两条结果的通道归属与载体层结论见 §八。

## 八、载体层裁决（2026-09-12 新增，C1-4 之前置）

### 立项理由

两次锚核尝试（键弱化、相位锁定）在修正测量后均判为绕数不守恒。归因不在锚核概念，在载体：纯相位载体上芯没有凝聚能代价，锚核没有可节约的对象；三维闭合环的边界映射 $S^2 \to S^1$ 给不出拓扑兜底（$\pi_2(S^1) = 0$）。完整论证、失败边界与判据 W1 至 W6 见 [[注记-载体层裁决：纯相位的失败边界与振幅通道的实现路径]]。

### 作者主张（2026-09-12）

粒性侧对应振幅自由度，波性侧对应相位。锚核的本体由此定为振幅锁定，即格点内异类耦合 $\kappa_\phi$。

### 交付物与判据

载体取复标量（或三元组），判据见注记 §六：载体判据 $E(R)$ 稳定点、锚核判据 $R^*$、脱钉判据 $\Delta E$、粒性可观测量 $A(0)$ 与 $\int (1 - A^2)$、窗口接口、识别式接口。落地脚本按目录规范入 `验证脚本/`。

**执行状态（2026-09-12）**：W1 与 W2 已执行，见 [[注记-振幅通道下涡旋环径向曲线的最小验证：钉扎井存在但无稳定半径]]。读数：钉扎井成立（$\Delta E(R)$ 有内部极小，位置随锚核半径单调移动，偏移 $+0.5$ 至 $+1.0$ 格），粒性读数成立（芯处振幅亏损可测）

；稳定半径不成立（$\lambda$ 至 $16$、$d$ 至 $0.9$ 并另测 $d = 1$ 硬锚核、$w$ 至 $3.0$ 全部单调，临界缺口约线张力的 $10\%$）；经典自由复场弛豫下绕数全部卸载。

C1-4a 的实现形式因此在「四次项（Hopf 路线）」与「格点内锁定（半径取格距整数倍）」之间取舍，待作者裁决。

### 与任务序列的关系

C1-4 的锚核筛选以载体层完成为前置。C1-6 的三元组哈密顿量是本节所指载体的完整形态：格点内耦合 $\kappa_\phi$ 提供振幅通道，格点间耦合 $\kappa_\parallel$ 提供相位相干。

### 超选择层的输入（2026-09-12 增补）

C1 的读数全是经典层结果。经典层通量线仍衰变，超选择保护依赖量子相干，故 C1 在经典层的结论上限是载体的能量、尺寸与驻留；荷的判决与判据 Q4、Q5 必须搬进量子层，见 [[注记-载体层裁决：纯相位的失败边界与振幅通道的实现路径]] §八。

拓扑序层的激发是点状的（涡旋激发约 $0$ 格距，电荷激发约 $1$ 格距），与经典层 $\ell^* = 1.00$ 一致，宽度问题由转换波或 $\kappa_\parallel$ 软模承担。
