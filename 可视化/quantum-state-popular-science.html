量子力学里有一串让人头疼的名词：波函数、希尔伯特空间、概率幅、态叠加、投影、幺正演化。它们看起来像六个彼此独立的知识点，需要分别记忆、分别考。

其实不是。它们是同一个数学结构在不同层面上的投影。把这层结构看穿，六个名词会自然归位成一个整体，就像看懂了一台机器，再去看它的六个零件。

而顺着这条线继续往下追问，问题会变得越来越不像"物理题"：波函数和态矢量能不能画等号？态矢量到底是不是物理实在？如果不是，那它对应了什么？这些追问最终会走到两条定理面前：Bell 与 PBR。它们做的事情很残酷也很漂亮：告诉我们哪些立场已经被逻辑和实验封死，哪些还开着。

这份笔记就按这个顺序展开。

1六个概念，其实是同一套结构的六个面

先搭骨架，再填细节。下面六小节，每一节只做一件事：说明这个零件在整个结构里承担什么角色。

1.1希尔伯特空间：一切发生的舞台

量子力学的第一条公理是：一个物理系统的状态，由复希尔伯特空间中的一个单位矢量描述。

"希尔伯特空间"这四个字，每个限定词都在实际干活：

线性空间态可以相加、可以被复数乘。这是「态叠加」能存在的唯一前提。
内积定义了长度、正交、夹角。它随后会变成「概率幅」。
复数域带来「相位」。这是干涉条纹的来源；换成实数域，条纹立刻消失。
完备性保证无限维下的展开与极限都合法，连续谱（位置、动量）才有意义。

所以它不是背景布景。它同时提供了三样东西：叠加的自由、概率的度量、演化的容器。

1.2态矢量与波函数：本体与坐标

抽象层面的态矢量 |ψ⟩ 是与表象无关的对象，它住在希尔伯特空间里。选定位置本征基 {|x⟩} 之后，态矢量在这组基上的分量就是波函数：

ψ(x) ≡ ⟨x|ψ⟩

反过来，完备性关系 ∫dx|x⟩⟨x| = I 让你能从波函数把矢量拼回去：|ψ⟩ = ∫dx ψ(x)|x⟩。

所以它们属于同一个对象的两种描述：一个是本体，一个是坐标。

把三层分清楚物理态是射线（|ψ⟩ 与 e^(iα)|ψ⟩ 代表同一个态）；态矢量是这条射线的代表元；波函数是这个代表元在某组基下的坐标。三层里只有最后一层随坐标变：ψ(x) 与动量表象的 ψ(p) 是同一矢量的两张坐标卡，二者之间是傅里叶变换；一般幺正变换都可读作换坐标。随坐标不变的是内积，相位差与份额都装在里面。

这里说的"本体"取数学含义：基无关的对象，与"世界中的实物"分属两层，后者没有共识（见 2.2）。把两层合读，才会觉得这句话在主张波函数不实在；它没有这个意思。

这里有个几乎所有人都会踩的坑：ψ(x) 一般是复函数。教科书上画的那条漂亮的波浪线，通常只是它的实部，或者干脆是个"示意"。真实波函数还有虚部，而决定干涉的，恰恰是那个看不见的部分：相位。

1.3概率幅：带相位的箭头

概率幅就是内积 ⟨φ|ψ⟩。它是一个复数：既有长度（模），也有方向（相位）。物理上可观测的只有它的模方，这就是玻恩定则：

P = |⟨φ|ψ⟩|²

为什么不能一开始就用概率？因为量子力学做的是「幅相加」，而不是「概率相加」：

|ψ₁+ψ₂|² = |ψ₁|² + |ψ₂|² + 2·Re(ψ₁*ψ₂)

最后那一项就是干涉项，由相位决定。如果从一开始就用正实数当"概率"，这一项永远是零，双缝条纹、原子能级、化学键统统无法解释。

一个有用的类比概率像长度，概率幅像带方向的箭头。箭头合成要按方向相加，方向相反处互相抵消；长度只能直接相加，永远得不到相消。你看到的通常是长度（模方），决定结果的却是方向（相位差）。

1.4态叠加：线性结构的物理宣言

若 |ψ₁⟩ 与 |ψ₂⟩ 都是系统可能的态，那么任意复线性组合 |ψ⟩ = c₁|ψ₁⟩ + c₂|ψ₂⟩ 也是可能的态。叠加系数 cᵢ 就是概率幅，|cᵢ|² 是相应结果的概率。

必须强调一句：叠加不是"我们不知道是哪一个"。如果是经典的无知，系统会用对角的密度矩阵描述；而真正的叠加态 ρ = |ψ⟩⟨ψ| 含有非对角元，这些非对角元正是"干涉能力"的量化，也是量子性最本质的标志。

1.5投影：把概率幅读成事件

可观测量写成 A = Σ aᵢPᵢ，其中 Pᵢ 是投影算符，满足 Pᵢ² = Pᵢ = Pᵢ†。测量公理包含两部分。

概率：测得 aᵢ 的概率是 pᵢ = ⟨ψ|Pᵢ|ψ⟩，正是"幅分量"的模方。
更新（坍缩）：测完之后，态被"拍"到那个子空间上，|ψ⟩ → Pᵢ|ψ⟩ / √pᵢ。

投影算符的幂等性（P² = P）有一个直接可检验的后果：刚刚测完再测一次，必然得到相同结果。这一条由数学结构自带，无需额外假设。

投影只是最干净的特例真实仪器总有噪声，一般用 POVM（正算符值测度）{Eᵢ} 描述，满足 Eᵢ ≥ 0、ΣEᵢ = I，概率为 pᵢ = ⟨ψ|Eᵢ|ψ⟩。投影测量就是 Eᵢ = Pᵢ 这一情形。所以"投影"的本质，其实是用一族正算符对态做双线性评估。

1.6幺正演化：保内积的旋转

封闭系统的演化由薛定谔方程 iℏ ∂ₜ|ψ⟩ = H|ψ⟩ 给出，解是 |ψ(t)⟩ = U(t)|ψ(0)⟩，其中 U = e^(−iHt/ℏ) 是幺正算符。

幺正性意味着什么？它恰好保持内积不变：⟨Uφ|Uψ⟩ = ⟨φ|ψ⟩。由此自动得到一连串守恒。

长度守恒归一化不变，于是总概率守恒。
概率幅守恒所有内积不变，干涉图样稳定演化。
叠加关系守恒Σcᵢ|ψᵢ⟩ 被整体搬运，不会凭空产生或消灭叠加。
谱守恒可观测量期望值按确定性规律演化，测量取值集合不变。
Wigner 定理反过来看更漂亮：任何保持跃迁概率 |⟨φ|ψ⟩|² 不变的对称变换，必然是幺正的（或反幺正的）。所以幺正性由"保持概率幅结构"这一要求逼出，属必然结果，无需外加假设。

2两个必须澄清的问题

骨架搭好了，接下来是两个几乎人人都会问、但答案比想象中微妙的问题。

2.1波函数和态矢量，能等同吗？

短答：在固定位置表象、且系统没有内部自由度时，二者一一对应，可以互换使用；但严格讲，它们不等同。

对无自旋单粒子，这个对应确实是双向的：给定 |ψ⟩，ψ(x)=⟨x|ψ⟩ 唯一确定；给定一个平方可积的 ψ(x)，|ψ⟩ 也唯一确定。换句话说，ℋ ≅ L²(ℝ³) 是一个同构，它们在数学结构上完全等价。这就是为什么教科书可以直接对 ψ(x) 写薛定谔方程而从不提抽象空间：在这个特定场景里，这么做完全合法。

但一旦离开这个场景，等价关系就会散架。下面三个反例，每一个都足够致命。

差别态矢量 |ψ⟩波函数 ψ(x)
表象依赖不依赖任何基依赖选了位置基；换到动量表象就是另一个函数
存在性任何量子系统都有只有存在"位置"可观测量时才有。量子比特、腔模 Fock 空间里压根没有波函数
内部自由度自然容纳（张量积）自旋 ½ 要写成旋量 ψ_σ(x)，不再是单个标量函数
平方可积性动量本征态是合法（广义）态它的"波函数"是平面波，不可归一化，不在 L² 里
非纯态密度矩阵 ρ 是算符混态无法用波函数表示
一句话判据无自旋单粒子 + 位置表象固定 + 纯态 → 可以把它们当同一个东西（这也是绝大多数入门、化学、固体物理的场景）。只要有自旋、多个粒子、有限维系统、混态，或者需要换表象 → 不可以。

2.2态矢量是物理实在吗？

这个问题里其实藏着三个不同的问题，混在一起谈就永远谈不清：

子问题答案状态
① 态矢量是不是一个数学对象？是。没有争议。
② 它描述的东西存在于世界中吗？高度争议，取决于诠释。
③ 它描述的是三维空间里的波吗？不是。这一点几乎无争议。

绝大多数困惑来自把 ① 和 ③ 混为一谈，或者以为 ② 有一个标准答案。

先看无争议的部分。不管哪个学派，下面五条是所有人都同意的：态矢量是希尔伯特空间的元素，而希尔伯特空间不是三维物理空间；它本身不可直接观测，只能通过制备加测量统计被间接推断；它带冗余，整体相位无物理意义；它的全部可观测内容就是映射 A ↦ Tr(ρA)（Gleason 定理给出这一指派的唯一性，要求维数 ≥ 3）；它是关系性的：对纠缠态，子系统的态必须"从外部看"，并不是它自己的完整状态。

这些性质已经强烈暗示：这东西不像一个经典的"东西"。

为什么它不像经典实在 参数爆炸：N 个粒子的态需要指数级多的参数，且不可分解成"每颗粒子的状态"的堆叠。这指向它是一种关联的编码，并非叠加起来的实物。
定义域是组态空间：双粒子波函数住在 ℝ⁶，所谓"波"从来没在三维空间里波动过。
上下文性：Kochen–Specker 定理表明，无法给所有可观测量一致地指派预先存在的值（非语境性的经典属性图像被排除；玻姆力学靠语境性绕开这一条）。

但反过来说"它只是我的主观知识"同样站不住。你无法免费知道它：要确定一个态的完整信息，需要大量相同制备的副本做层析。它也不可随意修改：局部操作既不能克隆、也不能删除一个未知量子态（若它只是一段经典信息，复制原则上没有障碍）。它的结构约束（希尔伯特空间维度、内积、张量积）更是被实验钉死的，比如 CHSH 违背量逼近 Tsirelson 界。

所以它是客观的；但客观，不等于"像石头那样存在于空间中"。

三层回答 操作层（确定）它对应一族概率指派的紧凑编码：任意可观测量的结果分布。这是它百分之百可靠的身份，无一多余、无一缺失。
结构层（较可靠）它是一个关系性对象：在给定的系统划分与测量语境下，该系统会怎样响应。剥离语境谈"这个态的绝对身份"，本身就不良定义。
本体层（未知）它是否还对应世界中某个独立存在的东西？没有公认答案。这是一个真正未解决的基础问题，不是"我们还没算完"那种未解决。

3态矢量的七种身份

同一个数学对象，被最主流的七种诠释赋予了截然不同的本体论身份。数学上它是清楚的，物理上它的身份至今未被裁决。

诠释态矢量对应什么
哥本哈根 · 工具主义一个计算工具，用来预言测量统计。问「它实在吗」被视为不合法的提问
QBism单个行动者的信念度。主观，但受经验约束
多世界（Everett）唯一真实的全部实在；"坍缩"只是观察者分支的错觉
玻姆力学真实的导引场（活在组态空间中），粒子另有确定位置
GRW 客观坍缩真实的物理场，会自发随机坍缩
关系性 QM（Rovelli）永远是"相对于另一个系统"的态，没有绝对态
量子信息 / 认识论编码关联与可区分性的信息载体

同一个数学对象，七种截然不同的本体论身份；这本身就说明了一件事：数学上它是清楚的，物理上它的身份未被裁决。

而这两派立场，可以被归成两个阵营：

4两条定理，如何压缩了选择空间

上面那七种身份看起来自由得很。但两条定理把这个自由度砍掉了一大半：它们是能被证明的排除性结论，超出哲学争论的范围。

4.1Bell 定理：局域性出局

Bell 定理说：任何同时满足"局域性"和"隐变量存在"的理论，都会给出一个不等式，而这个不等式被实验系统性违背。

它的意义不在于"量子力学是对的"，而在于：如果你想让世界既局域、又在测量之前就带着确定的属性，你做不到。这两个愿望必须舍弃至少一个。

4.2PBR 定理：通俗拆解

PBR 定理（2012 年，Pusey–Barrett–Rudolph）走的是另一条路。它不问"能不能局域"，而问：量子态能不能只是"信息"？

先把两种立场摆清楚。假设每个量子系统内部都藏着一张底牌 λ（物理学家叫它 ontic state，"本体状态"），量子态 |ψ⟩ 只是贴在牌背上的标签。那么：

ψ-ontic（态是本体）：标签唯一决定底牌。不同标签，底牌必然不同。
ψ-epistemic（态是知识）：标签只是知识。两张标签不同的牌，可能藏着同一张底牌。

第二个立场听起来很自然，毕竟在经典统计力学里，"温度 300K"确实只是宏观描述，同一个温度对应无数微观状态。很多人以为量子态也一样。PBR 说：不，不一样。

把它拆成四步来看：

第一步，设局。准备两个系统，各自独立地制备成 |ψ₀⟩ 或 |ψ₁⟩。这两个态故意选成不垂直的（重叠度 1/√2）。于是共有四种组合。
第二步，关键测量。存在一个联合测量，能无歧义地分辨这四种情形：每种制备都有一个只可能由它触发的读数。技术理由是这四个联合态在四维空间里线性无关。
第三步，共享底牌。现在假设 ψ-epistemic 成立，那么"底牌 λ 能同时支撑 |ψ₀⟩ 和 |ψ₁⟩"就有一个共同的 λ*。再叠加"两系统独立制备"这个前提，两边的底牌也独立，于是 (λ*, λ*) 这一对底牌，在四种制备下都会出现。
第四步，矛盾。做第一种制备时，底牌是 (λ*, λ*)，测量必须报出"第一种"；做第二种时，底牌还是它，同一个测量却必须报出"第二种"……四种制备，四种答案。同一个输入、同一台机器，被要求给出四个互不相同的输出，这不可能。

所以"共享底牌"必须被否掉：不同的量子态必然对应不同的底层实在。

承重墙：制备独立性上面推理里有一块砖绝对不能松："两个系统若被独立制备，它们的底牌也相互独立"。如果允许两次制备之间存在隐藏关联（比如共同的过去），(λ*, λ*) 就不再自动出现，论证随之失效。这正是想挽救 ψ-epistemic 的人唯一能走的门，而这条路要付出"精细调节"的代价。
它没有排除什么（常被误传） 它不等于"波函数是空间里真实振动的波"。PBR 只说"不同态对应不同底层实在"，没说那实在是什么。
它也不排除 QBism：QBism 根本否认存在独立于观察者的 λ，因此压根不在 PBR 的前提范围内。
它更不是"所有认识论解读都死了"。死的是一大类满足那两个前提的模型，不是全部。

4.3剩下的生存空间

把两条定理放在一起看，逃生出口就被压缩得极窄了。

如果你相信"每个系统背后藏着一个客观的底层状态，量子态只是关于它的知识"，并且相信"独立制备的系统互不影响"，那么 PBR 就告诉你：这两个信念不能同时为真。量子态必须"是"什么，而不只是"关于"什么。第四部分 · 核心结论

尾声回到最初的那个问题

现在可以回答开头那些追问了。

六个概念是什么关系？它们是同一套数学结构的六个面。希尔伯特空间提供线性与内积；态矢量是空间中的点，波函数是它的坐标；态叠加是线性性的物理化；概率幅是内积的物理化，概率只是它的模方；投影把概率幅读成事件；幺正演化在两次测量之间以保内积的方式搬运所有概率幅。
