时空晶格的振荡往返机制

元相子定居格点，每摆程沿轴向单向位移一个格距，相向邻居在公共边界碰撞折返。
同一次摆程同时给出空间标度、物理时间与光速换算。

速度 1.00x
束缚振荡元相子 σ 锁定缺陷（绕数累积） 碰撞折返点 接力信号（在碰撞处交接）

机制说明

定居与摆程。每个格点由一个 x 类、一个 y 类、一个 z 类元相子构成三元组，轴向位置锁定在区间 [n·lP, (n+1)·lP] 内。一个摆程中，圆心从一侧边界单向位移到另一侧边界，同一过程里相位单调扫过 2π 完成满周闭合，速率 |ż| = c，历时 tP。螺旋刚性 z = (λ/2π)·θ 把轴向位移与相位推进绑成同一事件的两个侧面。

折返。粒性不可穿透的几何含义是圆心不可重合。格点 n 与 n+1 共享边界 (n+1)·lP，两者圆心相向运动并同时抵达该处，重合瞬间即弹性碰撞，相位推进方向沿同一条螺旋曲线反向（手性守恒不变，反转的是瞬时旋转方向）。这里没有墙与外部设施，反转是波性要求继续推进与粒性禁止继续前进相互冲突的唯一出路。相邻格点必须反相，也就是动画中的交错基态；若全体同相运动，圆心间距恒为 lP，永不碰撞，系统退化为自由极限下的无限前进。

一次摆程，三件产物。轴向位移给出空间标度 x = lP·n；摆程计数给出物理时间 t = N·tP，去程回程都不倒退因而自带箭头；接力几何给出光速 c = lP/tP。

接力发生在碰撞处。格点 n 完成摆程，圆心抵达公共边界，就在这一刻与相向邻居碰撞，同时把摆程完成事件交给格点 n+1；格点 n+1 接过棒，再花一个摆程走到下一条边界。动画上方的接力信号在一个摆程内从一条公共边界匀速走到下一条，抵达时绿环与红闪光同地亮起，表示交接完成。一步跨多远、一步耗多久定下速度，与耦合强度无关，强光、弱光、单光子同速皆源于此。接力信号标记的是长波集体模式即相位场包络的行进，不绑定某一个格点的圆心；基态的锯齿呼吸与光的传播属于尺度分离的两个模式，呼吸在 k = π/lP 处承载时间，光在 k → 0 处承载信号。

σ 锁定模式。切换模式后，中间格点的摆程方向因子 σ 从交替锁定为恒定，相位不再折返、单方向缠绕，绕数从 0 开始累积，轴向每摆程前进一格（为便于观察，动画在链端循环）。这是大爆炸同步相变的局域缺陷，也就是有质量粒子的形成判据。相位时间轨迹由三角波转为单调上升，正是两种遗产的分野：凝固完好的部分成为时空砖块，凝固残留的部分成为粒子。

模型口径：本动画按《元相子几何动力学（束缚振荡修订整合版）》公理 4 与补充注释 03、04 绘制，取一维链示意，相位差 π 的交错偏移未绘制以突出运动学。
待闭合项：束缚排斥势的精确形式为开放问题 O10，硬核碰撞为何完美弹性的微观机制尚待声明；束缚图像下量子数的来源与守恒性为 O11；法向跃迁本身仍是模型假设，未从公理直接导出。
