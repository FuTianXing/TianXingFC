态矢量怎样动起来

希尔伯特空间里态矢量的转动、概率幅各自的相位旋转、波函数在位置空间的模样，三块面板联动，参数可调。

三块联动面板 · 六个可调参数 · 建议阅读 12 分钟

面板 A｜波函数 ψ(x, t)：位置空间的三种读数

实线 Re ψ，虚线 Im ψ，橙色填充 |ψ|²，下方色带是相位 arg ψ（色相一圈对应 2π）。读数：⟨x⟩ = 0.500，⟨E⟩ = 0.00。

面板 B｜概率幅 cₙ(t)：各自的箭头在转

每个能级一支箭头，模不变、相位按 e^(−iEₙt) 各自旋转；下方条是该能级的份额 |cₙ|²。归一化读数 Σ|cₙ|² = 1.000（幺正演化下恒为 1）。

面板 C｜态矢量：希尔伯特空间里的箭头

二能级：态矢量画在布洛赫球上，箭头 = 布洛赫矢量（极角 θ 给布居差，方位角 φ 给相对相位）。

1三块面板各看什么

三块面板画的是同一个态的三层读数。面板 C 画态矢量本身（在能画的地方画成箭头，在画不出的地方画成它的全部不变量），面板 B 画它的分量（概率幅），面板 A 画这些分量在位置空间拼出来的波函数。

面板画的是什么对应口径
A 波函数位置表象下的 ψ(x, t)：实部、虚部、模方、相位集体合成读数的约化表象，模方是份额
B 概率幅各能级分量 cₙ(t) 在复平面上的箭头与模方概率幅 = 态矢量在某组基上的分量
C 态矢量二能级：布洛赫球上的箭头；多能级：模方谱与相对相位轮态矢量 = 全部分量打包成的元素，整体相位冗余
为什么多能级时态矢量画不成一支箭头两个能级时，态空间的几何恰好是球面（布洛赫球），一支箭头就能画完。能级多于两个之后，态空间是复射影空间，维数迅速变大，平面或球面都装不下。能画出来的是它的全部物理内容：一组模方（各分量多长）加一圈相对相位（各分量之间差多少）。整体相位被约掉，那正是"物理态是射线"的意思。

2参数怎样改变结果

能级数与布居预设决定模方谱，也就是"概率摊在哪些能级上"。单能级只剩一个分量，箭头不动（只转整体相位），波函数的模方是一幅静止的驻波。等权叠加给出最明显的拍频：两个能级之间形成一次完整的相位追逐，⟨x⟩ 来回摆动。

初始相位梯度 Δφ给相邻能级之间加一个固定的初始相位差，它决定波包在位置空间从哪里出发、朝哪个方向走。相位差为 0 时波包居中并对称展开，相位差给到 π/2 附近时波包整体朝一侧移动。

驱动 Ω只对二能级起作用：它在哈密顿量里加一项横向耦合，布洛赫矢量绕着倾斜的轴进动，表现为布居在两能级之间来回倒（拉比型振荡）。Ω = 0 时只剩绕竖直轴的拉莫尔进动，布居差不变，只有相对相位在走。

时间缩放只改变观看速度，不改变物理：所有相位按同一个因子放慢或加快。

这个演示最值得盯住的一处在多能级、无驱动的设置下，面板 B 里每支箭头的长度全程不变（模方守恒），可面板 A 里概率分布却明显地来回移动。概率没有凭空搬运，移动来自相对相位：各分量以不同速率旋转，相对相位在变，干涉项的位置随之改变。份额给出"有多少"，相位给出"在哪里"。

3边界与严格程度

这是演示，不是验证。它做三件事：把三个层次的对象并排画出来，把参数与结果的关系摆明，让人能亲眼看到模方守恒与相对相位搬运概率这两件事。

数值方法为谱方法加定步长演化：能级取一维无限深势井，φₙ(x) = √2 sin(nπx)，Eₙ = n²（ℏ = 1、L = 1 的自然单位），态矢量按 cₙ(t) = cₙ(0) e^(−iEₙt) 演化；二能级带驱动时，2×2 的幺正矩阵用 Rodrigues 公式精确构造，不做近似展开。位置空间的曲线由 320 个采样点给出，⟨x⟩ 与 ⟨E⟩ 在采样点上数值求和。
