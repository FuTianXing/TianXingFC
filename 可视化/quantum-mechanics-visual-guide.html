1希尔伯特空间：一切发生的"舞台"

它同时提供了三样东西：叠加的自由（线性空间）、概率的度量（内积）、演化的容器（完备 + 复数）。

线性态可以相加、可以被复数乘 —— 这是"叠加"能存在的唯一前提。
内积定义了长度、正交、夹角 —— 它会变成"概率幅"。
复数域带来"相位" —— 干涉条纹的来源。换成实数域干涉就没了。
完备性保证无限维下展开与极限都合法 —— 连续谱（位置、动量）才有意义。
打个比方：希尔伯特空间就像一张无限大的地图。地图规定了「哪些点算合法位置」（态）、「怎么量两点距离」（内积）、以及「两条路线能不能首尾相接」（叠加）。

2态矢量与波函数：同一个态的两种"衣服"

|ψ⟩ 是抽象矢量；ψ(x) = ⟨x|ψ⟩ 只是它在位置基下的一组坐标（一般是复数）。

态矢量 |ψ⟩与表象无关的物理对象，住在抽象空间里，长度恒为 1。
波函数 ψ(x)态矢量在位置基下的分量，一般是复函数，不能直接画成一条实曲线。
归一化⟨ψ|ψ⟩ = ∫|ψ(x)|²dx = 1：把矢量限制在单位球面上，这就是概率诠释的几何写法。
多表象等价ψ(x) 与 φ(p) 之间是傅里叶变换 —— 同一支箭换了个坐标系而已。
关键：波函数不是"物质波"，它只是态矢量的一件衣服。所以"波函数坍缩"这个说法才让人困惑 —— 坍缩的其实不是波，是态矢量本身。

3概率幅：不是概率，而是"带相位的箭头"

概率幅就是内积 ⟨φ|ψ⟩，是一个复数：既有长度（模），也有方向（相位）。

打个比方：概率是"水面的高度"，概率幅是"水下的波浪"。你只看得到高度（模方），但波浪之间的相位差决定了它们会互相加强还是抵消。
为什么不能直接用概率？因为量子力学做的是「幅相加」，不是「概率相加」：
|ψ₁+ψ₂|² = |ψ₁|² + |ψ₂|² + 2·Re(ψ₁*ψ₂)
最后一项就是 干涉项，由相位决定。用正实数就没有它，双缝条纹将无法解释。
进阶（Gleason 定理）：在维数 ≥ 3 的希尔伯特空间上，任何与叠加结构一致的概率赋值，必然具有 p = Tr(ρP) 的形式。也就是说，概率幅框架不是人为选择，而是被"叠加 + 概率"这两条要求逼出来的唯一解。

打个比方：两个水波在同一处汇合。同相时波峰叠波峰 → 更高（相长干涉）；反相时波峰顶波谷 → 抵消（相消干涉）。粒子不会这样，波才会 —— 这就是"叠加"和"我们不知道是哪一个"的本质差别。
进阶（为什么"不知道是哪一个"不一样）：若是经典无知，系统用对角密度矩阵描述；而真正的叠加态 ρ = |ψ⟩⟨ψ| 含非对角元，这些非对角元正是干涉能力的量化，也是"量子性"最本质的标志。

🖱 5投影机制：把概率幅"读成"事件的唯一关口（可交互）

可观测量写成 A = Σ aᵢPᵢ，Pᵢ 是投影算符。测得 aᵢ 的概率是 ⟨ψ|Pᵢ|ψ⟩；测完之后，态被"拍"到那个方向上。

测量前：叠加态 |ψ⟩ = cosθ·|1⟩ + sinθ·|2⟩

拖动滑块改变态的方向，然后点「测量！」看它如何被投影到某一条本征轴上。
打个比方：把态矢量想成一根斜插的杆子，投影就是它在两条坐标轴上的影子。影子长度的平方 = 命中概率。测量的瞬间，杆子被"拍平"到其中一条轴上 —— 这就是坍缩。投影算符满足 P² = P：拍一次和拍两次结果一样，所以"刚测完再测必然同结果"。
进阶（投影只是特例）：真实仪器总有噪声，一般用 POVM {Eᵢ}，满足 Eᵢ ≥ 0 且 ΣEᵢ = I，概率为 pᵢ = ⟨ψ|Eᵢ|ψ⟩。投影测量就是 Eᵢ = Pᵢ 这一最干净的特例 —— 所以"投影"的本质是"用一族正算符对态做双线性评估"。

🖱 6幺正演化：让所有概率幅"整体旋转"（动画）

封闭系统的演化是 |ψ(t)⟩ = U(t)|ψ(0)⟩，U = e^(−iHt/ℏ) 是幺正算符。它保持一切内积不变。

U = e^(−iHt/ℏ)：长度与夹角都被锁死；两支箭头始终同速旋转

长度守恒归一化不变 → 总概率守恒。
内积守恒⟨Uφ|Uψ⟩ = ⟨φ|ψ⟩ → 概率幅不变 → 干涉图样稳定演化。
叠加关系守恒Σcᵢ|ψᵢ⟩ 被整体搬运，不会凭空产生或消灭叠加。
谱守恒可观测量期望值按确定性规律演化，测量结果的取值集合不变。
一句话：幺正演化是希尔伯特空间里的一次"刚性旋转"。它只搬运概率幅、旋转相位，绝不改变任何内积。
进阶（Wigner 定理）：任何保持跃迁概率 |⟨φ|ψ⟩|² 不变的对称变换，必然是幺正的（或反幺正的）。所以幺正性不是外加假设，而是"保持概率幅结构"这一要求的必然结果。

7核心张力：旋转 vs 跳跃

第 5 节和第 6 节住在同一套数学里，性质却完全相反。这个对立就是量子力学最深的问题。

为什么这是"问题"：如果把测量仪器也纳入系统一起算，整体仍应该幺正演化 —— 那"坍缩"到底从哪来？

退相干给出主流的部分回答：环境让干涉项（密度矩阵非对角元）指数级衰减，ρ → Σ pᵢ|i⟩⟨i|，于是叠加在有效意义上退化成经典混合。
但必须说清楚：退相干解释了"为什么看不见干涉"和分支概率，并没有严格解决单次结果的唯一性。这一点不能含糊。

9态矢量的七种身份：它到底"是"什么？

同一个数学对象 |ψ⟩ ∈ ℋ，被主流诠释赋予了截然不同的本体论身份。数学上它是清楚的，物理上它的身份尚未被裁决。

① 操作层（确定）一族概率指派的紧凑编码：任意可观测量的结果分布。这是它百分之百可靠的身份。
② 结构层（较可靠）关系性对象：在给定的系统划分与测量语境下，该系统会怎样响应。
③ 本体层（未知）是否对应世界中某个独立存在的东西 —— 真正的未解决问题。
ψ-ontic 阵营态矢量描述世界真实的存在方式。
代表：多世界 · 玻姆力学 · GRW 客观坍缩
ψ-epistemic 阵营态矢量只编码观察者关于系统的信息。
代表：QBism · 部分哥本哈根解读
两条定理堵死了两边的"舒适区"：
· PBR 定理（2012）：在"实在论 λ-模型 + 制备独立性"前提下，两个不同量子态必须对应互不相交的底层本体集合 —— 朴素的"态只是对同一实在的无知程度"这一图像被排除。
· Bell 定理：排除局域隐变量 —— "态是局域实在的经典知识"这条路也走不通。
五个无争议的事实（所有学派都同意）：
  1. 它是希尔伯特空间中的元素，而希尔伯特空间不是三维物理空间（可以是有限维，如量子比特）。
  2. 它本身不可直接观测，只能通过制备 + 测量统计被间接推断。
  3. 它带冗余：整体相位无物理意义；只有概率指派承载物理内容。
  4. 它的全部可观测内容就是映射 A ↦ Tr(ρA)（Gleason 定理）。
  5. 它是关系性的：对纠缠态，子系统的态必须"从外部看"，并不是它自己的完整状态。
为什么它不像经典实在：不可克隆定理（若是经典场，复制它本无障碍） · 参数随粒子数指数爆炸（更像"关联的记账"而非"叠加的实物"） · 定义域是组态空间而非三维空间（双粒子就是 ℝ⁶） · 上下文性（Kochen–Specker：无法一致地指派预先存在的值）。
