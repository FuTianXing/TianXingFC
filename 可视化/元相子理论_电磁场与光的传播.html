一、一句话总纲

电磁场

元相子实轴方向场（每个元相子的相位零点朝向）的曲率。电场取时间-空间分量 $E_a = F_{a0}$，磁场取纯空间分量 $B_a = \tfrac{1}{2}\epsilon_{abc}F_{bc}$。

麦克斯韦方程组

双重来源。无源组是比安基恒等式 $dF = 0$，由 $F = dA$ 自动推出；有源组是校准代价最小化的运动方程。

光

实轴方向偏转沿晶格的逐格接力。每个元相子感知邻居、校正自己，偏转由此传播。光速由格点延迟给定，$c = l_P/t_P$。

二、电磁场的几何本体

每个元相子拥有独立复平面与独立实轴方向 $\alpha_n$，即相位零点。相邻格点的实轴方向差定义空间联络 $A_a$，实轴方向的演化定义时间分量 $A_0$。规范势在元相子语言中对应实轴方向场的联络（图 1）。

实轴方向的局域重定义 $\alpha_n \to \alpha_n + \lambda_n$ 即局域 $U(1)$ 规范变换，此重定义不改变物理。规范对称性因此从公设变为实体结构的推论。

静电势与时间分量的衔接已解决：$A_0 = -\varphi$（库仑规范），静电场是相位搬移畸变的空间梯度。静电学与电动力学由此合并为同一套语言。

严格程度：实轴方向场对应规范势为条件性命题（$U(1)$ 情形为严格对应）；实轴方向重定义等于规范变换为严格结论。

三、麦克斯韦方程组的双重来源

把电磁场等于联络曲率这一事实代回四行方程，四行立刻分成性质不同的两组。无源组是比安基恒等式 $dF = 0$ 的分量形式，由 $F = dA$ 与 $d^2 = 0$ 自动推出。法拉第定律于是从实验归纳的定律变成曲率的一致性条件，其成立只靠混合偏导可交换 $\partial_t\partial_a = \partial_a\partial_t$（图 2）。

有源组是校准代价最小化的运动方程。电流对应绕数结构的迁移，位移电流对应校准重排自身的磁场源。元相子语言中的图像：电流是绕数结构在晶格中迁移，迁移处拖着周围指针转，搅出漩涡；位移电流是校准重排本身拧出扭转。

严格程度：无源组等于比安基恒等式为严格结论；有源组等于校准动力学为纲领性主张，其闭合依赖校准作用量。

四、光的传播：感知-校正链

每个元相子内禀天行力，即心侧自主校准能力。它只做两件事：感知邻居的实轴方向，校正自己的实轴方向。设 A 的实轴方向偏转 $\delta\alpha_A$，邻居 B 感知到相位差变化并自主校正，B 的校正又触发 C，偏转以感知-校正链逐格传下去，这就是光（图 3）。这个过程像人浪：每个个体只做局部动作，事件沿链前进。

该链的最小模型为

$$\ddot\alpha_n=\omega_{\text{cal}}^2\big(\alpha_{n+1}+\alpha_{n-1}-2\alpha_n\big)$$

左侧是方向惯性，右侧是邻居耦合的二阶差分。方程不含一阶时间导数项：校准动作瞬时完成且无损，既不耗散，也不引入"感知-校正耗时"这一额外延迟（作者 2026-09-26 裁决）。取连续极限 $x = n l_P$ 得

$$\frac{\partial^2\alpha}{\partial t^2}=c^2\frac{\partial^2\alpha}{\partial x^2},\qquad c^2=\omega_{\text{cal}}^2 l_P^2$$

即得波动方程，低能色散给出 $c = \omega_{\text{cal}} l_P$，与摆程接力的 $c = l_P/t_P$ 一致，要求 $\omega_{\text{cal}} = 1/t_P$。光速的有限性来自摆程节拍：每步前进一格、每步对应一个摆程，$t_P$ 由公理 5 的节律设定，与耦合强度无关。如同接力赛，速度由每棒跑多远与每棒用时决定，与接力棒的传递方式无关。

注记：碰撞接力的完美弹性是已转正的结构性结论（《束缚振荡动力学的物侧闭合：完美弹性定理、交错基态与校准通道》，2026-09-20）。元相子没有组成部分，态变量只有提升相位、旋向与方向标签，径向不构成状态自由度，因此没有内部模式可以吸收碰撞能量；折返的实现是摆程方向因子翻转，只取 $\pm 1$，运动学中不存在承载损耗的连续量，恢复系数无处安放；折返是约束的瞬时解，不存在接触时间窗。三条合起来给出 $\gamma_{\text{碰撞}} = 0$，其含义是"没有被放置的位置"，强于"小到测不出"。

表观阻尼若存在，只能落在多体与场耦合侧（碰撞对向场的辐射、元相海相干损失），观测上界为 $\gamma \le 1.04\times10^{-16}$ 每秒。据此，方程不含耗散项是物理上正确的形式，无需附加近似。

频率的来源同一机制。基态所有元相子以 $\omega_P$ 摆程，光的颜色来自实轴方向演化的偏移 $\omega = \omega_P + \delta\omega$。光子不携带净绕数，故零电荷，属平凡表示。光子因此有双重身份：基态光子是元相子本身，构成时空砖块；激发光子是校准波，是时空上的扰动。

光的本质因此从"物"推进到"心物协同"：无数自主校准行为（感知邻居、校正自身）的协同传播，即天行方程的执行波。

这套介质图像不违反相对论。元相子介质满足爱因斯坦 1920 年给出的以太三要素：没有可供探测的静止参照系，具有物理性质（真空不空），不定义光速（光速是 $c = l_P/t_P$ 的几何恒等式，与介质参数无关）。迈克尔逊-莫雷实验排除的是定义光速的力学介质，元相子介质属于爱因斯坦意义上允许的以太，并补上其缺失的载体。

严格程度：光等于偏转沿链的传递、频率偏移等于实轴方向演化速率，两者为条件性命题；光速等于元相子跃迁速率属严格（摆程接力为公理 4 与公理 5 的几何推论，与晶格色散互为印证）；最小模型本身是提案性演示，其形式待校准动力学的涌现层有效理论验证。

五、平面波的正交关系

真空无源时两组方程联立给出波动方程，色散 $\omega = ck$。四条正交关系各自有来源：$\mathbf{E}\perp\mathbf{k}$ 来自无源高斯定律，$\mathbf{B}\perp\mathbf{k}$ 来自比安基恒等式，$\mathbf{E}\perp\mathbf{B}$ 来自法拉第定律，$|\mathbf{E}| = c|\mathbf{B}|$ 来自 $\omega = ck$。

共同的几何本质：电场与磁场是同一个相位扰动 $\delta\alpha \propto e^{i(\mathbf{k}\cdot\mathbf{x}-\omega t)}$ 的空间旋度与时间导数。扰动只能在垂直于 $\mathbf{k}$ 的平面内振动（晶格介质波的横向极化），其空间旋度与时间导数自动垂直。三者两两垂直，对应四维时空结构在平面波上的投影（图 4）。

电场的行为依有无源而异：静电场管喷（散度等于电荷），电磁波中的电场散度为零，喷不存在，只剩转（旋度由法拉第感应给出）。磁场始终管转。

严格程度：正交关系的推导为严格结论，属标准波解分析。

七、遗留问题

  1. 校准作用量的完整形式：从感知-校正链动力学导出麦克斯韦有源方程，是有源组从纲领升级为定理的关键，也是整个电磁学攻坚的收敛点。
  2. 洛伦兹力机制：运动电荷在磁场中的偏转 $\mathbf{F} = q\mathbf{v}\times\mathbf{B}$ 如何从绕数结构与涡旋线的耦合涌现。
  3. 磁铁定量桥梁：自旋（内部 $\pi$ 扭转）的有序排列如何具体产生外部实轴方向场的空间扭转。
  4. 位移电流定量验证：校准重排的磁场源与 $\partial_t\mathbf{E}$ 项的精确对应。
  5. 感知-校正链的三项参数：感知机制（邻居如何感知偏转）、传递节拍（每步 $t_P$ 由摆程节律给出，耦合只保证事件传出）、响应强度（完全对齐或部分对齐决定色散）。
  6. 紫外预言待检验：洛伦兹破坏首阶项 $\delta\omega/\omega \sim -(E/E_P)^2$，立方各向异性 $[100]:[110]:[111] = 6:3:2$，由粒性侧格点结构决定。
