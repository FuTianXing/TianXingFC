元相子理论：电磁场与光的传播

傅天行（天行新学研究院）· 可视化整理 2026-09-26 · 材料取自工作区已定稿论文，严格程度按体系四级制标注

本页把元相子理论对电磁场与光的全部工作压缩成一条主链：实轴方向场 → 联络 → 曲率 → 电场与磁场 → 感知-校正链 → 光。每一节末尾给出该环节的严格程度，纲领性主张与严格结论分开标注。

一、一句话总纲

电磁场

元相子实轴方向场（每个元相子的相位零点朝向）的曲率。电场取时间-空间分量 $E_a = F_{a0}$，磁场取纯空间分量 $B_a = \tfrac{1}{2}\epsilon_{abc}F_{bc}$。

麦克斯韦方程组

双重来源。无源组是比安基恒等式 $dF = 0$，由 $F = dA$ 自动推出；有源组是校准代价最小化的运动方程。

光

实轴方向偏转沿晶格的逐格接力。每个元相子感知邻居、校正自己，偏转由此传播。光速 $c = l_P/t_P$ 是格点延迟，属几何恒等式。

二、电磁场的几何本体

每个元相子拥有独立复平面与独立实轴方向 $\alpha_n$，即相位零点。相邻格点的实轴方向差定义空间联络 $A_a$，实轴方向的演化定义时间分量 $A_0$。规范势在元相子语言中就是实轴方向场的联络。

实轴方向的局域重定义 $\alpha_n \to \alpha_n + \lambda_n$ 即局域 $U(1)$ 规范变换，此重定义不改变物理。规范对称性因此从公设变为实体结构的推论。

严格程度：实轴方向场等于规范势为条件性命题（$U(1)$ 情形为严格对应）；实轴方向重定义等于规范变换为严格结论。

三、麦克斯韦方程组的双重来源

把电磁场等于联络曲率这一事实代回四行方程，四行立刻分成性质不同的两组。无源组是比安基恒等式 $dF = 0$ 的分量形式，由 $F = dA$ 与 $d^2 = 0$ 自动推出。法拉第定律于是从实验归纳的定律变成曲率的一致性条件，其成立只靠混合偏导可交换 $\partial_t\partial_a = \partial_a\partial_t$。

有源组是校准代价最小化的运动方程。电流对应绕数结构的迁移，位移电流对应校准重排自身的磁场源。元相子语言中的图像：电流是异物游动搅出漩涡，位移电流是校准重排本身拧出扭转。

严格程度：无源组等于比安基恒等式为严格结论；有源组等于校准动力学为纲领性主张，其闭合依赖校准作用量。

四、光的传播：感知-校正链

每个元相子内禀天行力，即心侧自主校准能力。它只做两件事：感知邻居的实轴方向，校正自己的实轴方向。设 A 的实轴方向偏转 $\delta\alpha_A$，邻居 B 感知到相位差变化并自主校正，B 的校正又触发 C，偏转以感知-校正链逐格传下去。这就是光。

该链的最小模型为

$$\ddot\alpha_n+\frac{1}{\tau_{\text{corr}}}\dot\alpha_n=\omega_{\text{cal}}^2\big(\alpha_{n+1}+\alpha_{n-1}-2\alpha_n\big)$$

左侧是惯性项与阻尼项，右侧是邻居耦合的二阶差分。取连续极限 $x = n l_P$ 得

$$\frac{\partial^2\alpha}{\partial t^2}+\frac{1}{\tau_{\text{corr}}}\frac{\partial\alpha}{\partial t}=c^2\frac{\partial^2\alpha}{\partial x^2},\qquad c^2=\omega_{\text{cal}}^2 l_P^2$$

忽略阻尼即得波动方程，光速 $c = \omega_{\text{cal}} l_P$。与接力几何的 $c = l_P/t_P$ 统一，要求 $\omega_{\text{cal}} = 1/t_P$。光速的存在要求感知与校正之间存在格点延迟，若感知是瞬时的，光速将为无限大。

频率的来源同一机制。基态所有元相子以 $\omega_P$ 摆程，光的颜色来自实轴方向演化的偏移 $\omega = \omega_P + \delta\omega$。光子不携带净绕数，故零电荷，属平凡表示。

光的本质因此从"物"推进到"心物协同"：无数自主校准行为（感知邻居、校正自身）的协同传播，即天行方程的执行波。

严格程度：光等于感知-校正链、光速等于格点延迟、频率偏移等于实轴方向演化速率，三者均为条件性命题；最小模型本身是提案性演示，其形式待校准动力学的涌现层有效理论验证。

五、平面波的正交关系

真空无源时两组方程联立给出波动方程，色散 $\omega = ck$。四条正交关系各自有来源：$\mathbf{E}\perp\mathbf{k}$ 来自无源高斯定律，$\mathbf{B}\perp\mathbf{k}$ 来自比安基恒等式，$\mathbf{E}\perp\mathbf{B}$ 来自法拉第定律，$|\mathbf{E}| = c|\mathbf{B}|$ 来自 $\omega = ck$。

共同的几何本质：电场与磁场是同一个相位扰动 $\delta\alpha \propto e^{i(\mathbf{k}\cdot\mathbf{x}-\omega t)}$ 的空间旋度与时间导数。扰动只能在垂直于 $\mathbf{k}$ 的平面内振动（晶格介质波的横向极化），其空间旋度与时间导数自动垂直。三者两两垂直，对应四维时空结构在平面波上的投影。

严格程度：正交关系的推导为严格结论，属标准波解分析。

七、遗留问题

  1. 校准作用量的完整形式：从感知-校正链动力学导出麦克斯韦有源方程，是有源组从纲领升级为定理的关键，也是整个电磁学攻坚的收敛点。
  2. 洛伦兹力机制：运动电荷在磁场中的偏转 $\mathbf{F} = q\mathbf{v}\times\mathbf{B}$ 如何从绕数结构与涡旋线的耦合涌现。
  3. 磁铁定量桥梁：自旋（内部 $\pi$ 扭转）的有序排列如何具体产生外部实轴方向场的空间扭转。
  4. 位移电流定量验证：校准重排的磁场源与 $\partial_t\mathbf{E}$ 项的精确对应。
  5. 感知-校正链的三项参数：感知机制（邻居如何感知偏转）、格点延迟（每格 $t_P$ 需从耦合动力学导出）、响应强度（完全对齐或部分对齐决定色散）。
  6. 紫外预言待检验：洛伦兹破坏首阶项 $\delta\omega/\omega \sim -(E/E_P)^2$，立方各向异性 $[100]:[110]:[111] = 6:3:2$，由粒性侧格点结构决定。
